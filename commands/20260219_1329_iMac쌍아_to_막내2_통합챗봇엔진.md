## Context

MONKOS 챗봇이 현재 2개 함수로 분리되어 있음:

| 함수 | 채널 | 프롬프트 | RAG | temp | 토큰 |
|------|------|---------|-----|------|------|
| `chatWithGemini()` L449 | 포털 웹 | SYSTEM_PROMPT (L122, 고정) | ❌ 없음 | 0.7 | 300 |
| `chatWithGeminiCS()` L307 | 텔레그램 CS | CS_SYSTEM_PROMPT (L180) + RAG | ✅ 있음 | 0.5 | 500 |

**문제:** 포털은 RAG가 없어서 법률/환불/브랜드 지식을 모름. 채널마다 별도 함수라 확장 어려움.

**해결:** 1개 통합 함수 `chatWithMonkos(channel, chatId, message)` + 채널별 설정 테이블 + 공통 RAG

### 1-3. chatWithMonkos 통합 함수

기존 `chatWithGemini()` (L449~489)와 `chatWithGeminiCS()` (L307~347)를 **하나로 통합**.

```js
async function chatWithMonkos(channel, chatId, userMessage) {
  const config = CHANNEL_CONFIG[channel];
  if (!config) throw new Error(`Unknown channel: ${channel}`);

  // 히스토리 관리
  let history = config.historyMap.get(chatId);
  if (!history) {
    // web 채널만 Firestore 복원 시도 (기존 로직 유지)
    if (channel === 'web') {
      history = await loadChatHistory(chatId);
    }
    if (!history) {
      history = { messages: [], lastAccess: Date.now() };
    }
    config.historyMap.set(chatId, history);
  }
  history.lastAccess = Date.now();

  // RAG: 전 채널 공통 (핵심 변경점!)
  await loadCsKnowledge();
  const ragDocs = searchCsKnowledge(userMessage);
  let ragContext = '';
  if (ragDocs.length > 0) {
    ragContext = '\n\n[참고 지식]\n' + ragDocs.map(d =>
      `【${d.title}】\n${d.content}`
    ).join('\n\n');
  }

  // 히스토리에 유저 메시지 추가
  history.messages.push({ role: 'user', parts: [{ text: userMessage }] });
  if (history.messages.length > config.maxHistory) {
    history.messages = history.messages.slice(-config.maxHistory);
  }

  // 시스템 프롬프트 + RAG 컨텍스트
  const systemPrompt = config.systemPrompt + ragContext;

  const response = await ai.models.generateContent({
    model: 'gemini-2.0-flash',
    contents: history.messages,
    config: {
      systemInstruction: systemPrompt,
      maxOutputTokens: config.maxOutputTokens,
      temperature: config.temperature,
    },
  });

  const text = response.candidates?.[0]?.content?.parts?.[0]?.text || '';
  history.messages.push({ role: 'model', parts: [{ text }] });

  // 비동기 로깅 (채널별 Firestore 컬렉션)
  if (channel === 'web') {
    logChatConversation(chatId, userMessage, text).catch(() => {});
  } else if (channel === 'telegram') {
    // 기존 logCsConversation 호출 (호출부에서 처리)
  }

  return text;
}
```

### 1-4. 기존 호출부 수정

**포털 웹 (chatWithGemini → chatWithMonkos):**

`chatWithGemini(sessionId, userMessage, lang)` 호출부를 찾아서:
```js
// Before
const reply = await chatWithGemini(sessionId, userMessage, lang);

// After
const reply = await chatWithMonkos('web', sessionId, userMessage);
```

**텔레그램 CS (chatWithGeminiCS → chatWithMonkos):**

`chatWithGeminiCS(chatId, userMessage)` 호출부를 찾아서:
```js
// Before
const reply = await chatWithGeminiCS(chatId, userMessage);

// After
const reply = await chatWithMonkos('telegram', chatId, userMessage);
```
