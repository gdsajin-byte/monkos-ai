## 배경
- `commands/` 폴더에 지시서/보고서가 git push로 오가는 중
- 현재는 수동으로 `git pull`해서 확인 → 병목
- 기존 `@monkos_factory_bot` 파이프라인에 commands/ 감시를 얹어서 자동 알림

## 구현 방식

`scripts/monkos/command_watcher.js` 신규 생성 (command_bridge_simple.js와 별도)

### 동작 흐름

```
30초 간격 git pull
  → commands/ 폴더에 새 .md 파일 감지 (이전 스캔 대비)
  → 파일명에서 발신/수신/제목 파싱
  → @monkos_factory_bot으로 텔레그램 알림 발송
```

### 핵심 로직

```javascript
// 1. git pull origin main (30초 간격)
// 2. commands/ 폴더 .md 파일 목록 스캔
// 3. 이전 스캔 결과와 비교 → 새 파일만 추출
// 4. 파일명 파싱: 20260218_1101_발신_to_수신_제목.md
// 5. 텔레그램 직접 발송 (Firebase 경유 불필요)
```

### 텔레그램 직접 발송 (Firebase 우회)

```javascript
const BOT_TOKEN = process.env.TELEGRAM_BOT_TOKEN || '기존토큰';
const CHAT_ID = process.env.TELEGRAM_CHAT_ID || '작가님채팅ID';

async function sendTelegram(text) {
    const url = `https://api.telegram.org/bot${BOT_TOKEN}/sendMessage`;
    await fetch(url, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ chat_id: CHAT_ID, text, parse_mode: 'Markdown' })
    });
}
```
