## 작업 순서

### 1. Docker로 n8n 실행

```bash
docker run -d --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  -e TZ=Asia/Seoul \
  n8nio/n8n:latest
```

- `-v n8n_data`: 데이터 영구 저장 (컨테이너 재시작해도 유지)
- `-e TZ=Asia/Seoul`: 스케줄 시간대 한국시간

### 2. 동작 확인

```bash
# 컨테이너 상태 확인
docker ps | grep n8n

# 로그 확인 (정상 기동 시 "n8n ready on 0.0.0.0, port 5678" 메시지)
docker logs n8n --tail 20
```

### 3. 접속 테스트

```bash
curl -s -o /dev/null -w "%{http_code}" http://localhost:5678
```
- 200 응답이면 성공

### 4. 자동 재시작 설정

```bash
docker update --restart unless-stopped n8n
```
- 서버 재부팅 시에도 n8n 자동 기동
