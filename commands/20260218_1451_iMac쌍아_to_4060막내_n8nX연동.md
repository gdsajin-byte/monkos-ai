## 작업

### 1. n8n에 X(Twitter) Credential 등록

n8n 웹 UI에서:
1. Settings → Credentials → Add Credential
2. **X (formerly Twitter) OAuth1 API** 선택
3. `monkos_AI/.env`에서 4개 키 값 읽어서 입력:
   - Consumer Key → `X_CONSUMER_KEY`
   - Consumer Secret → `X_CONSUMER_SECRET`
   - Access Token → `X_ACCESS_TOKEN`
   - Access Token Secret → `X_ACCESS_TOKEN_SECRET`
4. "Test" 버튼으로 연결 확인

### 2. 테스트 워크플로우 생성

간단한 워크플로우 생성하여 API 동작 확인:
1. Manual Trigger → X(Twitter) 노드
2. X 노드: **Create Tweet** 액션
3. 테스트 트윗 내용: `MONKOS AI test - automated posting via n8n 🤖`
4. 실행하여 @MONKOS_AI 타임라인에 트윗 게시 확인
5. 확인 후 테스트 트윗 삭제

### 3. (선택) 정기 포스팅 워크플로우 초안

일본 시장 타겟 자동 포스팅 워크플로우 구조만 잡아두기:
```
Schedule Trigger (매일 10:00 JST)
  → AI 콘텐츠 생성 (향후 연동)
  → X Create Tweet
  → 텔레그램 알림 (작가님에게 게시 알림)
```
