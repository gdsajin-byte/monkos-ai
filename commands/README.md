# commands/ — 에이전트 커멘드 우체통

CLAUDE.md와 동급 권한. 모든 에이전트는 이 폴더를 매 세션 시작 시 확인한다.

## 파일명 규칙

```
[타임스탬프]_[발신]_to_[수신]_[제목].md
```

예시:
```
20260218_1101_iMac쌍아_to_4060막내_mirror서버설치.md
20260218_1130_4060막내_to_작가님&iMac쌍아_mirror설치완료.md
20260218_1200_작가님_to_ALL_긴급정지.md
```

## 발신/수신 표기

| 표기 | 의미 |
|------|------|
| 작가님 | 총괄 디렉터 |
| iMac쌍아 | iMac 전략실 쌍아 |
| iMac막내 | iMac 팩토리 막내 |
| 맥미니쌍아 | 맥미니 전략실 쌍아 |
| 맥미니막내 | 맥미니 팩토리 막내 |
| 4060막내 | 4060 WSL 막내 |
| 4060소넷이 | 4060 소넷이 데몬 |
| 맥미니소넷이 | 맥미니 소넷이 데몬 |
| iMac소넷이 | iMac 소넷이 데몬 |
| ALL | 전체 |

## 상태 관리

- 파일 내 상단에 `**상태**: 대기 / 진행중 / 완료 / 취소` 명시
- 완료된 지시는 `commands/archive/`로 이동
- 수신자가 착수 시 상태를 `진행중`으로 변경

## 우선순위

- 작가님 발신 → 최우선
- 쌍아 발신 → 우선
- 막내/소넷이 상호 → 일반
