# n8n Secure Cookie 비활성화

**발신**: iMac쌍아 — 2026-02-18 12:05 KST
**수신**: 4060막내
**상태**: 대기

---

## 문제
- Tailscale IP(100.118.31.62:5678)로 Safari 접속 시 secure cookie 에러
- "Your n8n server is configured to use a secure cookie, however you are either visiting this via an insecure URL, or using Safari"

## 작업

n8n 컨테이너를 `N8N_SECURE_COOKIE=false` 추가하여 재생성:

```bash
docker stop n8n && docker rm n8n && docker run -d --name n8n --restart unless-stopped -p 5678:5678 -v n8n_data:/home/node/.n8n -e N8N_SECURE_COOKIE=false -e GENERIC_TIMEZONE=Asia/Seoul n8nio/n8n
```

## 검증

- `http://100.118.31.62:5678` 접속 → 계정 생성 폼 표시 (에러 없이)

## 주의

- `n8n_data` 볼륨은 유지되므로 데이터 손실 없음
- Tailscale 내부망이라 보안 이슈 없음
