### 작업 3: 토스페이먼츠 SDK 연동 준비

**목표:** 토스 결제위젯 SDK 로딩 + 결제 함수 스캐폴딩. 실제 결제는 클라이언트 키 수령 후 활성화.

**대상:** `monkos_AI/idphoto-kr/public/index.html`

#### 3-1. SDK 스크립트 추가 (head 또는 body 하단)
```html
<script src="https://js.tosspayments.com/v2/standard"></script>
```

#### 3-2. 결제 함수 스캐폴딩
```js
// 토스페이먼츠 결제 — 클라이언트 키 수령 후 활성화
const TOSS_CLIENT_KEY = ''; // TODO: 토스 계약 완료 후 키 입력
const TOSS_ENABLED = false; // TODO: 키 입력 후 true로 변경

async function requestTossPayment(packageInfo) {
  if (!TOSS_ENABLED || !TOSS_CLIENT_KEY) {
    console.log('[Toss] 결제 모듈 미활성화 (클라이언트 키 미설정)');
    return;
  }

  try {
    const tossPayments = TossPayments(TOSS_CLIENT_KEY);
    const payment = tossPayments.payment({ customerKey: currentUser?.odid || 'anonymous' });

    await payment.requestPayment({
      method: '카드',
      amount: { currency: 'KRW', value: packageInfo.price },
      orderId: `MONKOS-${Date.now()}-${Math.random().toString(36).substr(2, 8)}`,
      orderName: `MONKOS 크레딧 ${packageInfo.credits}c`,
      successUrl: `${window.location.origin}/api/payment/success`,
      failUrl: `${window.location.origin}/api/payment/fail`,
    });
  } catch (err) {
    console.error('[Toss] 결제 요청 실패:', err);
    alert('결제 요청에 실패했습니다. 다시 시도해 주세요.');
  }
}
```

#### 3-4. portal (`monkos_AI/portal/public/index.html`)에도 동일 적용
- 기존 크레딧 구매 버튼이 있다면 해당 함수에 `requestTossPayment` 연결
- 없다면 SDK 로딩 + 함수 스캐폴딩만 추가

**주의:**
- `TOSS_ENABLED = false` 유지 — 키 없이 활성화 금지
- `TOSS_CLIENT_KEY = ''` 유지 — 하드코딩 금지
- 기존 결제 로직(Lemon Squeezy 관련)이 있다면 주석 처리 (삭제 금지)
