### 2단계: GEMINI_API_KEY 설정

코칭 CF Function이 Gemini API를 직접 호출하려면 API 키가 필요하다.

```bash
cd "/Users/developer/monk_project /MONK_kr"
npx wrangler pages secret put GEMINI_API_KEY --project-name=monk-kr
```

프롬프트가 나오면 Google AI Studio API 키를 입력한다.
- 키 위치: 작가님에게 확인 필요. 기존 monkos_AI에서 사용하는 키가 있다면 그것 사용.
- 키가 없으면 `⏳ 대기` 보고.

### 3단계: CF Pages 배포

```bash
cd "/Users/developer/monk_project /MONK_kr"
wrangler pages deploy . --project-name=monk-kr --branch=main
```

배포 URL 확인: `https://monk.kr`

### 4단계: 엔드포인트 개별 검증

```bash
# 크레딧 프록시 확인 (404가 아닌 에러 응답이면 성공)
curl -s -X POST https://monk.kr/api/idphoto-credit-use \
  -H "Content-Type: application/json" \
  -d '{"userId":"test","type":"download"}' | head -c 200

# 코칭 확인 (GEMINI_API_KEY 설정 후)
# 실제 이미지 base64가 필요하므로, 브라우저 테스트로 대체 가능
curl -s -X POST https://monk.kr/api/idphoto-coaching \
  -H "Content-Type: application/json" \
  -d '{"image":"test","style":"id_photo"}' | head -c 200
```

### 5단계: 모바일 E2E 테스트 (가능하면)
