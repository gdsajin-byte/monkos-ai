## 작업 내용

### 1. server.js — Gemini 3.0 Flash 완전 제거

#### A. QC 전체 제거
- `buildQCInstruction()` 함수 전체 삭제 (L215~)
- `QC_MODELS` 상수 삭제 (L363)
- `runQC()` 함수 전체 삭제 (L365~)
- `/api/qc` 라우트 핸들러 삭제 (L589~)
- health 엔드포인트 QC 표시 삭제 (L518, L745, L753)
- 파일 상단 주석 QC 언급 삭제 (L7)

#### B. 사전분석 — 3.0 제거, 2.0만 유지
- `QC_MODELS` 배열 참조하는 부분을 **`'gemini-2.0-flash'` 단일 모델**로 변경
- `runPreCheck()` 함수 내부: for-of 루프(QC_MODELS) → 단일 모델 직접 호출
- 폴백 로직 제거 (모델 1개이므로 불필요)
- health 엔드포인트: `preCheck: 'active (gemini-2.0-flash)'`
- 로그: `사전분석: 활성 (gemini-2.0-flash)`

#### C. 정리
- `QC_MODELS` 상수 완전 삭제 (QC도 사전분석도 더 이상 참조 안 함)
- 상단 주석 정리: Gemini 3.0 Flash 언급 제거

### 2. index.html — QC UI 완전 제거

#### A. CSS 제거
- `#qc-badge` 스타일 전체 (L358~366)

#### B. HTML 제거
- `<div id="qc-badge">` (L943)

#### C. JS 제거
- 번역키: `qcChecking`, `qcVerifying`, `qcVerifyingSub` (L1060~1062)
- `showQCResult()` 함수 전체 (L1865~)
- `showQCError()` 함수 전체 (L1901~)
- 생성 성공 후 QC 호출 블록 (L1827~L1850):
  - `apiPost('/api/qc', ...)` 호출
  - `showQCResult(qcResult)` 호출
  - QC 관련 try/catch
- `qc-badge` DOM 조작 코드 전부 (L1746, L1785~L1787, L1795~L1796, L1803, L1816, L1831~L1834)

#### D. 플로우 변경
- 생성 성공 후 → **QC 건너뛰고 바로 결과 표시 + 다운로드 활성화**
- 기존: 생성 → QC → 결과표시 → 다운로드
- 변경: 생성 → 결과표시 → 다운로드
- `showPreview(generatedImageBase64)` 직행
- 다운로드 버튼 활성화 로직이 QC 결과에 의존하는지 확인 → 의존하면 무조건 활성화로 변경
