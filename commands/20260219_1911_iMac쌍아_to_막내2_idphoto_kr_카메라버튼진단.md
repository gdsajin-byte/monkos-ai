1. **KR index.html vs JP index.html** — 카메라 초기화 관련 코드 diff

   - 카메라 스트림 연결 → 촬영 버튼 활성화 로직
   - `video` 엘리먼트 바인딩

2. **최근 변경 영향** — git log로 index.html 최근 커밋 확인
   - 막내1/막내2 작업에서 카메라 관련 코드가 영향받았는지

3. **카메라 버튼 활성 조건** — 어떤 조건이 충족되어야 버튼이 활성화되는지

   - 카메라 스트림 ready 체크인지?
   - 다른 상태 변수 의존이 있는지?

4. **서버 로그** — dev 배포 서버에서 에러 발생하는지 (가능하면)
