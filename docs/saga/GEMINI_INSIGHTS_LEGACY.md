- [05_046] 작동 원리 (요청-응답 모델)

- [05_046] 내부 호출: 요청이 유효하면, API는 내부 시스템(데이터베이스 등)을 호출하여 필요한 데이터나 기능을 처리합니다
- [05_046] 🛠️ API의 주요 유형

- [05_046] 웹 API (Web API)

- [05_046] REST API (Representational State Transfer API)
현재 웹 API 설계에서 가장 널리 사용되고 유연한 아키텍처 스타일입니다
- [05_046] 특징	설명

- [05_046] WebSocket API: 클라이언트와 서버 간의 양방향 통신을 지원하여 실시간 데이터 전송에 효율적입니다
- [05_046] 🌐 API의 중요성
재사용성 및 효율성: 개발자가 기존 기능을 처음부터 다시 만들 필요 없이 API를 호출하여 쉽게 사용할 수 있게 합니다
- [05_046] 플랫폼 중립성: 클라이언트가 어떤 프로그래밍 언어나 플랫폼을 사용하든, 표준화된 API를 통해 서버의 데이터와 기능에 접근할 수 있습니다
- [05_046] API는 현대 디지털 생태계에서 서비스 간의 통합과 혁신을 가능하게 하는 핵심 기반 기술입니다
