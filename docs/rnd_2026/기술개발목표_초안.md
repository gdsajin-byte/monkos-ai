# 기술 개발 목표

## 최종 목표

K-뷰티 전문 지식과 AI 기술을 융합한 소상공인 맞춤형 룩북 제작 및 지능형 비주얼 큐레이션 플랫폼 **monk.kr** 개발 및 사업화

---

## 세부 기술 목표 (요약)

1. AI 이미지 정체성 유지율 85% 달성, 외부 API 의존율 50% 이하로 기술 자립화
2. 자체 고해상도 파이프라인으로 인쇄품질(300dpi) 실사 이미지 대형 출력 실현
3. Human-AI 협업 기반 자가 진화형 K-뷰티 특화 지능 파이프라인 구축
4. 소상공인 맞춤 AI 챗봇 탑재 저비용 홈페이지 서비스 사업화

---

## 세부 기술 목표 (상세)

### 목표 1. AI 이미지 생성 기술 자립화

| 지표 | 현재 | 목표 |
|------|:----:|:----:|
| 인물 정체성 유지율 | - | **85% 이상** |
| 외부 API 의존율 | 100% | **50% 이하** |

빅테크 클라우드 의존에서 탈피하여 자체 이미지 생성 역량을 확보한다. 이를 통해 대기업 정책 변화 리스크에 대응하고, K-뷰티 도메인에 최적화된 기술 내재화를 실현한다.

---

### 목표 2. 인쇄 품질 고해상도 이미지 생성

| 지표 | 현재 | 목표 |
|------|:----:|:----:|
| 출력 해상도 | 72dpi (웹용) | **300dpi (인쇄용)** |

단순 업스케일링이 아닌 자체 개발 파이프라인을 통해 피부결까지 재현되는 실사 수준의 대형 이미지(A3 이상)를 생성한다. 이를 통해 AI 이미지의 상업적 활용 범위를 오프라인 인쇄물까지 확장한다.

---

### 목표 3. 자가 진화형 AI 파이프라인 구축

**Human-AI 협업 순환 학습 구조:**

[데이터 수집] → [이미지 생성] → [지능형 검수] → [자동 태깅] → [전문가 큐레이션] → [재학습] → (순환)

K-뷰티 전문가의 고밀도 큐레이션과 AI 자동화가 협업하는 **자가 지능 증식형 파이프라인**을 구축한다. 사용할수록 K-뷰티 도메인에 특화되어 진화하는 지능을 실현한다.

---

### 목표 4. 소상공인 맞춤형 AI 챗봇 서비스

| 항목 | 내용 |
|------|------|
| 콘셉트 | "나보다 내 가게를 더 잘 아는 챗봇" |
| 핵심 기술 | 할루시네이션 제거 (학습된 정보만 응답) |
| 서비스 형태 | 지능형 챗봇 탑재 홈페이지 저비용 구축 |

소상공인, 1인 창업자, 청년 창업자를 대상으로 클라이언트별 특화 파인튜닝된 AI 챗봇 서비스를 제공한다.
