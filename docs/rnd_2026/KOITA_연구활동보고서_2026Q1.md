## 1. 연구소 개요

### 1.1 기관 정보

| 항목 | 내용 |
|------|------|
| 연구소명 | MONK.KR 기업부설연구소 |
| 도메인 | monk.kr |
| 연구 비전 | Evolution of Creative Intelligence |
| 핵심 사업 | AI 기반 이미지 생성 및 자동화 플랫폼 |

### 1.2 연구 목표

1. **생성형 AI 이미지 파이프라인 고도화**
   - Google Vertex AI 이미지 생성 API 기반 실시간 이미지 생성 시스템 구축
   - 증명사진, 프로필 이미지 등 실용 도메인 특화 최적화

2. **실시간 컴퓨터 비전 코칭 시스템 개발**
   - WebSocket 기반 양방향 실시간 통신 아키텍처
   - 포즈/표정/조명 자동 감지 및 피드백 알고리즘

3. **클라우드 네이티브 서버리스 아키텍처 연구**
   - GCP Cloud Run 기반 무중단 배포 체계
   - 멀티리전 CDN 최적화

## 2. 연구개발 조직

### 2.1 인적 구성

| 역할 | 담당 | 비고 |
|------|------|------|
| 연구소장 / 총괄 디렉터 | 대표 | 아키텍처 설계, 의사결정 |
| AI 연구 자동화 | LLM Agent 시스템 | 코드 생성, 문서화, 테스트 |

### 2.2 AI 협업 시스템 (LLM 기반 연구 자동화)

본 연구소는 **대규모 언어 모델(LLM) 기반 멀티에이전트 시스템**을 연구 프로세스에 도입하여 운용 중.

| 에이전트 유형 | 역할 | 기술 스택 |
|--------------|------|-----------|
| 코드 생성 에이전트 | 소프트웨어 개발, 디버깅 | Claude Opus 4.5/4.6 |
| 전략 에이전트 | 아키텍처 설계, 의사결정 지원 | Gemini 2.0 |
| 자동화 에이전트 | CI/CD, 배포 자동화 | Claude Code CLI |

**연구 방법론**: Human-AI 협업 기반 Agile R&D
- 일일 세션 로그 기록 (연구 노트 역할)
- LLM 대화 기반 설계 → 코드 생성 → 테스트 → 배포 사이클
- 모든 의사결정 과정 문서화 (추적 가능성 확보)

## 3. 핵심 연구 분야

### 3.1 생성형 AI 이미지 파이프라인

**연구 목표**: 사용자 업로드 이미지를 기반으로 고품질 AI 이미지 생성

| 기술 요소 | 상세 |
|-----------|------|
| 기반 모델 | Google Vertex AI 이미지 생성 API |
| 입력 처리 | 이미지 전처리, 얼굴 감지, 품질 검증 |
| 프롬프트 엔지니어링 | 도메인 특화 프롬프트 최적화 |
| 출력 후처리 | 해상도 조정, 포맷 변환 |

**주요 연구 성과**:
- Identity Preservation 알고리즘 최적화 (90:10 비율 도출)
- 세이프가드 우회 없는 안정적 생성 파이프라인 구축
- 스타일별 프롬프트 분기 시스템 (증명사진/이력서/프로필)

### 3.2 실시간 컴퓨터 비전 코칭 시스템

**연구 목표**: 촬영 중 실시간 자세/표정 교정 피드백 제공

| 기술 요소 | 상세 |
|-----------|------|
| 통신 프로토콜 | WebSocket (양방향 실시간) |
| 영상 처리 | MediaPipe Face Mesh, Pose Detection |
| 피드백 생성 | 규칙 기반 + LLM 자연어 코칭 |
| 지연 시간 | < 100ms (실시간 요구사항 충족) |

**주요 연구 성과**:
- 스타일별 코칭 프롬프트 분기 (COACHING_INSTRUCTIONS)
- 얼굴 가이드 오버레이 시스템
- 다국어 코칭 메시지 (한/영/일)

### 3.3 클라우드 네이티브 아키텍처

**연구 목표**: 확장 가능하고 비용 효율적인 서버리스 인프라 구축

| 기술 요소 | 상세 |
|-----------|------|
| 컴퓨팅 | GCP Cloud Run (서버리스 컨테이너) |
| 스토리지 | Google Cloud Storage |
| CDN | Cloudflare (글로벌 엣지) |
| 데이터베이스 | Cloudflare D1 (SQLite Edge) |
| 인증 | OAuth 2.0 (Kakao, LINE, Google) |

**주요 연구 성과**:
- 콜드스타트 최적화 (< 2초)
- OOM(Out of Memory) 문제 해결 및 메모리 관리 최적화
- 멀티 서비스 동시 배포 파이프라인
