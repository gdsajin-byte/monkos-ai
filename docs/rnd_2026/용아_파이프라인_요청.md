# Vertex AI Agent Designer 파이프라인 설계 요청

Vertex AI Agent Designer에서 우리 MONKOS "자가 진화형 AI 파이프라인"을 설계하려고 해.

다음 7단계를 노드로 구성해줘:

## 1. 데이터 수집 (Data Ingestion)
- K-뷰티 트렌드 크롤링
- 사용자 업로드 이미지
- 입력: 외부 소스
- 출력: Raw Data

## 2. 전처리 & 벡터화 (Preprocessing & Vectorization)
- GCS 저장
- Vertex AI Embedding
- 입력: Raw Data
- 출력: Vector DB

## 3. 이미지 생성 (Image Generation)
- Imagen 4.0 API
- K-뷰티 프롬프트 라이브러리
- 입력: 프롬프트 + 레퍼런스
- 출력: 생성 이미지

## 4. 지능형 검수 (AI Quality Check)
- Gemini 2.0 Pro
- 품질/스타일 자동 평가
- 입력: 생성 이미지
- 출력: 평가 스코어 + 피드백

## 5. 자동 태깅 (Auto Tagging)
- 패션/헤어/메이크업 스키마
- 리버스 프롬프팅
- 입력: 검수 통과 이미지
- 출력: 메타데이터 + 태그

## 6. 전문가 큐레이션 (Human Curation)
- K-뷰티 연구원 검수
- Human-in-the-loop
- 입력: 태깅된 이미지
- 출력: 최종 승인 이미지

## 7. 피드백 학습 (Feedback Loop)
- 큐레이션 결과 → 프롬프트 개선
- 모델 재학습 데이터
- 입력: 큐레이션 피드백
- 출력: 1단계로 순환

---

이 구조를 Agent Designer에서 노드로 구성하고, 스크린샷 찍어서 R&D 계획서에 첨부할 거야.

각 노드 간 연결(Edge)과 조건 분기도 설계해줘.
