## 2. 핵심 연구 분야

### 2.1 BWYA 6대 학문 체계

**BWYA (Become Who You Are)**: 니체 철학 기반 AI 시대 크리에이터 양성 학문 체계

| 학문 | 영역 | 핵심 태그 |
|------|------|----------|
| 제1학문 | 사진학 | 조명, 구도, 색감 |
| 제2학문 | 패션학 | 소재, 텍스처, 레이어드 |
| 제3학문 | 헤어조형학 | 볼륨, 컬러, 형태 |
| 제4학문 | 신체구조학 | 포즈, 바디라인 |
| 제5학문 | AI 디렉팅학 | Imagen, FLUX 활용 |
| 제6학문 | 언어의 철학 | 프롬프트 엔지니어링 |

**코퍼스 현황**: 48개 문서, 2,347 문단, 206,131자, 53개 프롬프트 태그

### 2.2 레이어드 아키텍팅

**핵심 인사이트**: "옷은 한 겹만 입는 것이 아니다"

```
[패션 레이어]                    [헤어 레이어]
Layer 0: 이너웨어               Base: 두상+피부톤
    ↓                              ↓
Layer 1: 캐미솔                 Structure: 레이어드컷
    ↓                              ↓
Layer 2: 블라우스               Volume: 에어리/슬릭
    ↓                              ↓
Layer 3: 자켓                   Texture: 웨이브/C컬
= 콰이엇 럭셔리                 = K-뷰티 스타일링
```

**왜 이너웨어/헤어조형학부터인가**
- 누구나 "예쁜 모델"은 생성 가능
- 브랜드 코드 + 레이어 구조 소화 → 진입장벽
- 기초(Layer 0)부터 설계해야 비즈니스급 품질 달성

### 2.3 학문-실무-마케팅-교육 순환

```
학문 (BWYA) → 실무 (생산) → 마케팅 (상업화) → 교육 (전파) → 학문...
     ↑                                                    │
     └────────────────── 무한 순환 ──────────────────────┘
```

**순환 효과**: 프롬프트 정밀도↑, 스타일 재현↑, 브랜드 이해도↑, ML 고도화↑

## 3. 기술적 차별화

### 3.1 빅테크 세이프가드 정면돌파

**과제**: 상용 모델(Gemini/Imagen)로 정체성 유지 전신 이너웨어 생성

**발견**: Identity Preservation 90:10 비율 최적화
- 100% 동일 요구 시 → 세이프가드 발동 → 변형/거부
- **90% 정체성 보존 + 10% 보정 자유도 = 최적값** (실전 테스트 검증)

### 3.2 K-뷰티 데이터 스키마

| Layer | 카테고리 | 태깅 항목 |
|-------|---------|----------|
| Face | 헤어스타일 | style, length, texture, volume |
| Face | 메이크업 | eye, lip, blush, brow |
| Body | 이너웨어 | type, material, coverage |
| Body | 패션룩 | style, silhouette, season |

**DB 테이블**: `soso_prompt_dictionary`, `soso_face_tags`, `soso_body_tags`, `mina_model_instances`

## 6. 인프라 전략

### 6.1 5090 도입 필요성

| 항목 | 4060 (현재) | 5090 (목표) |
|------|------------|------------|
| VRAM | 8GB | 32GB |
| 파인튜닝 | 2B~3B | **7B~35B** |
| 추론 | 7B (양자화) | **70B+** |
| FLUX | ❌ OOM | ✅ |

**비즈니스 필수 논거**:
- 현재 테스트: Sonnet 데몬 (우리 디바이스, Claude Max)
- 실제 납품: 부스 100개 × API 비용 = 월 $10,000~30,000
- **자체 70B 모델 납품 = API $0 = 비즈니스 생존 조건**

### 6.2 M5 + eGPU 하이브리드

- **2024.12 발표**: Thunderbolt 5 + NVIDIA eGPU 공식 지원
- **조합**: M5 Ultra (크리에이티브) + RTX 5090 eGPU (연산)
- **장점**: Mac 생태계 + NVIDIA 연산력 동시 확보

### 6.3 로컬/클라우드 50:50 전략

```
[내가 쓰는 것] 클라우드 최강 (Gemini, Claude) — R&D 벤치마크
[실제 납품] 자체 파인튜닝 모델 — API $0, 독립적 비즈니스

"로컬 없는 클라우드 = 남의 집 장사 = 납품 불가"
```

### 6.4 소형 특화 지능 철학

- ❌ "모든 것을 잘 아는 LLM" (빅테크 영역)
- ✅ **"K-뷰티 특화, BWYA 기반, 7B~70B 자체 모델"** (우리 경쟁력)
