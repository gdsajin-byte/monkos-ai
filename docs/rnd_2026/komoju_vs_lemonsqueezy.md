## 수수료 비교

| 항목 | KOMOJU | LemonSqueezy |
|------|--------|-------------|
| **초기비용** | 무료 | 무료 |
| **월정액** | 무료 | 무료 |
| **카드 수수료** | 3.25% | 5% + $0.50/건 |
| **편의점 수수료** | 2.75% | ❌ 미지원 |
| **PayPay 수수료** | 3.5% | ❌ 미지원 |
| **디지털 상품 카드** | 3.25% (동일) | 5% + $0.50 |
| **해외 거래 추가** | 없음 (JPY 기준) | 추가 수수료 발생 (US 외) |

**1,000엔 카드 결제 실수령 비교**:
- KOMOJU: 1,000 - 32.5(3.25%) = **967.5엔** (- 정산 수수료 분할)
- LemonSqueezy: 1,000 - 50(5%) - 75($0.50≈75엔) = **875엔**

→ KOMOJU가 건당 **~92엔(약 9.5%) 유리**

## 결론

### KOMOJU 채택 근거 (일본 시장 한정)

1. **편의점 결제 + PayPay** = 신용카드 미보유 일본 대학생 도달의 유일한 경로
2. **수수료 3.25%** vs 레몬스퀴지 5%+$0.50 = 건당 9.5% 유리
3. **토스 코드 재사용 50~60%** — Basic Auth 동일, 세션 기반 유사
4. 한국 사업자 계약 가능, SWIFT로 한국 은행 정산

### KOMOJU 리스크

1. **MoR 아님** → 일본 소비세, 특정상거래법 표기 등 직접 관리 필요
2. **심사 기간 불명** → 레몬스퀴지와 같은 무응답 가능성 존재
3. **디지털 상품 편의점 결제** 가능 여부 공식 확인 필요
4. 한국 사업자 실제 운용 사례 미발견

### 제안 전략

```
[병행 전략]
토스페이먼츠 → 한국 시장 (KRW, 국내 카드)
KOMOJU → 일본 시장 (JPY, 편의점+PayPay+JCB)
레몬스퀴지 → 글로벌 시장 (심사 통과 시, MoR 활용)
```

토스와 KOMOJU는 동일 인증 방식(Basic Auth)이므로 서버 코드를 지역 분기로 운용 가능.
