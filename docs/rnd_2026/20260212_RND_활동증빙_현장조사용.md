## 1. 연구개발 개요

### 1.1 연구 배경

기존 AI 증명사진 서비스는 "셀카 업로드 → AI 후처리" 방식으로, 촬영 자세/표정/조명을 사전에 교정하지 못하는 한계가 있음. 본 연구는 **실시간 AI 음성 코칭 + Image-to-Image 재생성** 파이프라인을 통해 오프라인 사진관 수준의 품질을 온라인에서 구현하는 것을 목표로 함.

### 1.2 연구 목표

- **실시간 AI 코칭 시스템**: Google Gemini Live API 기반 실시간 음성 코칭 (자세, 표정, 조명 교정)
- **AI Image-to-Image 재생성**: Google Vertex AI 이미지 생성 API 기반 정체성 보존 (90:10) 증명사진 생성
- **다국어 글로벌 서비스**: 한국(KR), 일본(JP), 글로벌(EN) 3개 시장 동시 서비스
- **크레딧 기반 결제 시스템**: 글로벌 결제(Lemon Squeezy) + 한국 결제(TossPayments) 이중 구조

### 1.3 경쟁 우위

| 구분 | 기존 서비스 (PhotoAiD, 픽미 등) | MONKOS |
|------|-------------------------------|--------|
| 촬영 방식 | 셀카 업로드 후 AI 보정 | **실시간 AI 음성 코칭 + 촬영** |
| AI 엔진 | 단일 모델 후처리 | **Gemini Live + Vertex AI 듀얼** |
| 정체성 보존 | 보정 과정에서 왜곡 | **90:10 비율 최적화** |
| 규격 대응 | 국가별 수동 설정 | **자동 규격 크롭 (여권/이력서/면허)** |
| 코칭 | 없음 | **실시간 음성 가이드 (한국어/일본어)** |

## 2. 핵심 기술 스택

### 2.1 AI / ML 기술

| 기술 | 용도 | 상세 |
|------|------|------|
