## [08:43~09:02] PDF↔HWP 변환 모듈 전략 기획

### 용아(Gemini) 브리핑 내용

**Q1**: PDF↔HWP 변환 가능여부 브리핑 요청

**A1**: 용아 보고 요약
- HWP → PDF: 99% 정확도, 한글 내장 기능으로 즉시 변환
- PDF → HWP: 한글 2022+ 지원, 복잡한 레이아웃은 서식 깨짐 가능
- 핵심 변수: OCR (텍스트형 PDF vs 이미지형 PDF)

---

**Q2**: 우리가 개발할 수 있는 방법론 질의

**A2**: 용아 제시 3가지 방안
1. 한컴 오피스 SDK/API 활용 (최고 정확도, 라이선스 비용)
2. 오픈소스 라이브러리 조합 (pyhwp 등, 무료)
3. AI 기반 레이아웃 분석 (Vertex AI Vision, 차세대)

---

**Q3**: Vertex AI Vision 통합 가능성 질의

**A3**: 용아 비전 제시
- Vision 분석 → 구조적 데이터 정렬 → HWP API 주입
- 비정형 표(Table) 완벽 복원 가능
- OCR + Contextual Correction으로 오타 자동 교정
- **"지능형 문서 자산화 플랫폼"** 구축 가능

---

**Q4**: 라이선스/법적 리스크 보고 요청

**A4**: 리스크 분석 결과

| 구분 | 리스크 | 대응 |
|------|--------|------|
| PDF 특허 | 낮음 | ISO 표준화로 자유 |
| HWP 라이선스 | 중간 | HWPX 직접 생성 시 무관 |
| 폰트 저작권 | **높음** | Noto Sans KR 기본 적용 |
| 개인정보 | 높음 | Vertex AI 서울 리전 + 휘발성 처리 |

---

**Q5**: HWP 호환성 엔진 개발 가능성 확인

**A5**: 용아 확인
- HWPX(XML 기반) 활용으로 직접 생성 가능
- **"문서 통역기(Document Translator)"** 역할
- 양방향 변환: PDF/이미지 ↔ HWP ↔ Markdown/JSON
