### [06:42] 데스크톱 블랙 화면 버그 재발

**증상:**
- 데스크톱에서 QR 모달이 표시되지 않고 검은 화면
- 맥미니 리부팅, 브라우저 캐시 클리어 후에도 재현
- 어제와 동일한 문제 반복

**원인 분석 (CSS Specificity 충돌):**
```css
/* 충돌 구조 */
.qr-modal { display: flex; }     /* 커스텀 CSS - specificity: 0,0,1,0 */
.hidden { display: none; }        /* Tailwind - specificity: 0,0,1,0 */

/* 문제: 같은 우선순위일 때 선언 순서에 따라 .qr-modal이 이김 */
/* 결과: .hidden 클래스가 무시됨 → 항상 display: flex */
```

**수정:**
```css
.qr-modal.hidden {
    display: none !important;
}
```

**근본 원인 패턴 (반복되는 문제):**
1. Tailwind utility 클래스와 커스텀 CSS의 우선순위 충돌
2. inline style vs class 우선순위 이해 부족
3. 카메라 모달 구현 시에도 같은 문제 발생했었음
4. `.hidden` 클래스의 동작을 믿지 못하고 계속 다른 방법 시도

**교훈:**
- CSS specificity 충돌 시 `!important` 또는 더 구체적인 선택자 사용
- Tailwind 프로젝트에서는 가급적 커스텀 클래스에 `display` 속성 지양
- 또는 inline style로 통일 (우선순위 가장 높음)
