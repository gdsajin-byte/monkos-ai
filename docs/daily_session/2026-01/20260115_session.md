**원인 분석**:
- LLM은 내부적으로 "현재 시간"을 모름
- 추정/기억 기반으로 시간 기재 → **Y2K급 잠재 오류**

**해결책**: `.cursorrules`에 타임스탬프 강제 규칙 추가
```
✅ 필수: 매 응답 시작 전 반드시 `date "+%H:%M"` 실행
❌ 금지: 추정/기억 기반 시간 기재 절대 금지
📌 원칙: 시스템 시간 = 유일한 진실
```
