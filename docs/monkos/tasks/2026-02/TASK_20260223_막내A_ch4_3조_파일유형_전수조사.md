## 배경

2026-02-23 새벽 ch4 개정(7조 체제 완성) 이후, 낮 세션에서 ch4 3조 네이밍 패턴 10종에 등록되지 않은 파일 유형(ORDER_, RESEARCH_)이 다수 생성되었다. 또한 ch4 1조에서 "신규 파일은 부서 폴더에 생성한다"고 명시했으나 구 번호폴더(01_전략/orders/)에 신규 파일 7건이 생성된 충돌이 확인되었다.

법률 개정안을 상정하기 위해, 먼저 프로젝트 전체에서 ch4 3조 미등록 파일 유형의 현황을 전수조사한다.

## 목표

프로젝트 내 모든 파일의 접두사(유형)를 집계하고, ch4 3조 10종 패턴과 대조하여 **미등록 유형 전량을 식별**한다.

## 조사 범위

1. `docs/monkos/` 하위 전체
2. `monkos-ops/` 하위 전체
3. `governance/constitution/petitions/` 하위
4. `monkos-ops/ops/agenda/` 하위

## 조사 항목

### 1. 접두사별 파일 수 집계
- 현행 ch4 3조 10종: TASK_, REPORT_, SPEC_, INCIDENT_, DESIGN_, SPRINT_, PETITION_, 세션로그 3종
- 미등록 접두사: ORDER_, RESEARCH_, 기타 발견되는 모든 접두사
- 접두사 없는 파일도 별도 집계

### 2. 미등록 유형 상세
각 미등록 유형별로:
- 파일 목록 (경로 + 파일명)
- 생성 시점 (커밋 해시 또는 날짜)
- 생성 에이전트
- 내용 성격 (1줄 요약)

### 3. 번호폴더 신규 파일 현황
- `monkos-ops/01_전략/` ~ `monkos-ops/06_로그/` 내 .gitkeep 외 파일 전수 목록
- 각 파일의 정본 이관 대상 부서 폴더 제안
