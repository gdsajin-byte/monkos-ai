#### 3. 우선순위 정비 로드맵

| Phase | 대상 | 소요 시간 추정 | 의존성 | 배포 영향 |
|-------|------|-------------|--------|----------|

- P0: 외부 공격으로 즉시 악용 가능한 것
- P1: 내부 보안 위생
- P2: 금전 관련 (결제/크레딧)
- P3: 아키텍처 개선

#### 4. 각 취약점별 수정 방안

**코드를 직접 수정하지 마라.** 수정 설계만 작성:

```
### C1: JWT 토큰 미서명 — 수정 방안

**현행:** alg: 'none', Base64 인코딩만
**수정:** HMAC-SHA256 서명 도입 (jose 또는 jsonwebtoken 라이브러리)

**변경 범위:** signJWT(), verifyJWT() 함수
**테스트:** 기존 토큰 → 신규 토큰 마이그레이션 필요 여부
**롤백 계획:** 서명 검증 실패 시 구 토큰 허용 (30일 유예)
```
