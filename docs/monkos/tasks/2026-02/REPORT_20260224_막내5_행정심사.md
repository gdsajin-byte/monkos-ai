## 1. 세션 로그 추적성

**판정: 불충분 — 태그 신설 필요**

### 현행 상태
- ch3 2조 본문 형식: `### [HH:MM] 작업 주제` + `**작가님**: "직접 인용"` + 실행 내용/결과
- 현행은 모든 막내 작업이 지시서 기반이라는 전제. "이 작업의 기원이 지시서인지 직접 지시인지" 구분하는 필드/태그가 없음

### 문제점
- 직접 지시 작업은 `TASK_*` 지시서 파일이 존재하지 않으므로, 세션 로그만으로 작업 경위를 추적해야 함
- 사후 추인 시점도 세션 로그에서 식별 불가

### 필요 조치
1. **`[직접지시]` 태그**: 세션 로그 작업 블록 제목에 부기 — `### [HH:MM] [직접지시] 작업 주제`
2. **`[추인]` 태그**: 쌍아가 사후 추인 완료 시 세션 로그에 기록 — `### [HH:MM] [추인] 작업 주제`
3. ch3 2조 본문 형식에 "직접지시 시 작가님 원문 인용 필수" 조항 추가 권장 (지시서 대체)

### ch3 개정 필요 여부
- **소폭 개정 필요**: ch3 2조에 `[직접지시]`/`[추인]` 태그 규격 추가. 형식 자체 변경은 불요.

- 복수 막내 간 충돌은 기존 규율(git pull 선행)로 관리

### 방지 방안
- **현행 규율 유지**: 작업 시작 전 `git pull` + 대상 파일 재확인
