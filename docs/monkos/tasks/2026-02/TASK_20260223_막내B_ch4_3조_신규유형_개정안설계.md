## 설계 항목

### 1. 신규 유형 패턴 설계

각 유형별로 아래를 정의:

| 항목 | 내용 |
|------|------|
| 패턴 | `{TYPE}_YYYYMMDD_{detail}.md` 형식 |
| 대상 폴더 | 정본 배치 경로 |
| 예시 | 실제 파일 기반 |
| 기존 유형과의 차이 | ORDER vs TASK, RESEARCH vs REPORT 등 구분 근거 |

**검토 대상 유형**:
- `ORDER_` — 쌍아/철창이가 발행하는 지시서. TASK_(막내 실행지시)와의 성격 차이 분석
- `RESEARCH_` — 어젠다 기반 조사. REPORT_(실행 결과 보고)와의 성격 차이 분석
- 기타: 막내A 전수조사에서 추가 발견 시 대비

### 2. 기존 유형과의 경계선 분석

다음 질문에 명확히 답할 것:
- ORDER와 TASK는 왜 같은 유형이 아닌가?
- RESEARCH와 REPORT는 왜 같은 유형이 아닌가?
- 하나로 통합하는 것이 더 나은 경우는 없는가?

### 3. ch4 3조 개정안 초안

현행 10종 테이블에 신규 유형을 추가한 개정 테이블 전문. 적용 범위/적용 제외도 갱신 필요 여부 검토.

### 4. 번호폴더 파일 이관 계획

`monkos-ops/01_전략/orders/` 7건의:
- 이관 대상 경로 (4부서 체제 기준)
- 파일명 변경 필요 여부 (신규 패턴 적용)
- git mv 순서 (원자적 커밋 가능 여부)
