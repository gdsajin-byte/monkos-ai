## 3. 작업 내용

### 3-1. 히어로 섹션 변경

**현재:**
```
LIVE SERVICE 배지
MONKOS AI
AI 증명사진 플랫폼
```

**변경:**
```
LIVE SERVICE 배지
MONKOS AI
AI Creative Platform (또는 i18n: "AI 크리에이티브 플랫폼" / "AIクリエイティブプラットフォーム")
```
- 서브타이틀(`heroSub`)을 i18n 3개 언어 모두 변경
- 증명사진 한정 표현 제거, MONKOS 브랜드 전체를 아우르는 문구로

### 3-2. 서비스 카드 → 복수 카드 그리드

현재 단일 서비스 카드를 **복수 카드 그리드**로 확장:

| 순서 | 카드명 | 상태 | 포인트 색상 | CTA | 비주얼 |
|------|--------|------|------------|-----|--------|
| 1 | **AI 증명사진** | **LIVE** | 기존 accent(보라) | 기존 CTA 유지 | **활성 카드** — 선명, 호버 시 살짝 들어올림 |
| 2 | **AI Image Pro** | COMING SOON | blue (`#60A5FA`) | 비활성 | **실사 화면 캡처 느낌** + `filter: blur(2px)` + 반투명 오버레이 |
| 3 | **AI Studio** | COMING SOON | emerald (`#34d399`) | 비활성 | 흐리게 + COMING SOON 배지 |
| 4 | **AI Business** | COMING SOON | gold (`#f59e0b`) | 비활성 | 흐리게 + COMING SOON 배지 |

**카드 상태별 스타일**:

**LIVE 카드 (증명사진만 해당)**:
- 선명하고 또렷한 카드 — `opacity: 1`, 보더 accent 컬러
- **호버 시 `translateY(-4px)` + 글로우 shadow** — LIVE임을 강조
- CTA 버튼 활성 상태

**COMING SOON 카드 (Image Pro, Studio, Business)**:
- 카드 내부 콘텐츠를 **흐리게** 처리 (`filter: blur(1.5~2px)` 또는 반투명 오버레이)
- Image Pro는 실사 UI 화면 느낌의 CSS 배경 (몽크 앱 스크린샷 분위기)
- `opacity: 0.55` + `pointer-events: none` (클릭 불가)
- "COMING SOON" 배지가 카드 중앙에 선명하게 오버레이
- 호버 효과 없음 (비활성 느낌)

**카드 레이아웃**:
- 모바일: 1열 세로 스택
- 태블릿+: 2열 그리드
- 각 카드에 짧은 설명 + 특징 태그 2~3개

**카드 비주얼**:
- 각 카드에 CSS 그라디언트 배경 (카드별 색상 톤)
- 외부 이미지 사용 금지 — CSS만으로 해결

### 3-3. 챗봇 시각 분리

현재 챗봇 패널(`.chat-panel`)이 페이지와 같은 다크톤이라 구분 안 됨.

**변경:**
- 챗봇 패널 배경: `rgba(20, 20, 40, 0.95)` → 약간 밝은 톤 또는 블러 강화
- 챗봇 헤더: accent 색상 배경 그라디언트 적용 (현재는 `.chat-header` 배경 없음)
- 챗봇 경계: `border: 1px solid var(--border-hover)` + `box-shadow` 추가
- 챗봇이 열려있을 때 뒤 페이지에 `backdrop` 오버레이 (모바일에서 특히)
