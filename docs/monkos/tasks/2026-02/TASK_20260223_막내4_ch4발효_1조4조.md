### 변경

기존 docs/ 트리를 유지하되, **앞에 4계층 위계 + governance/ 트리를 추가**, **뒤에 monkos-ops/ 트리를 추가**.

#### 삽입할 내용 (docs/ 트리 앞):

```markdown
**4계층 위계:**

| 계층 | 성격 | 물리 위치 |
|------|------|----------|
| 헌법 | 커널. 불변 원칙 | CLAUDE.md (자동 인식) |
| 거버넌스 | 법률+역사+철학. 절차·상세·근거 | governance/ |
| 세칙 | 부서별 운영 규정 | monkos-ops/ 각 부서 README |
| 데이터 | 실행 산출물 | 부서 하위 |

**governance/ 구조:**

governance/
├── laws/                    ← 법률 ch1~ch8 (정본)
├── constitution/            ← 개정 절차
│   └── petitions/           ← 청구서 보관
├── history/                 ← 역사 (결정기록)
├── philosophy/              ← 철학 (비전, 가치관, 어록)
└── MIGRATION_LOG.md
```

#### docs/ 트리 수정:

- `laws/` 행 제거 (governance/로 이동 완료)
- `constitution/` 행 제거 (governance/로 이동 완료)
- docs/ 설명문에 "원천 아카이브 — 프로젝트의 뿌리이자 보물창고. 보존 대상." 추가

#### 삽입할 내용 (docs/ 트리 뒤):

```markdown
**monkos-ops/ 구조:**

monkos-ops/는 4부서 체제로 재편 중이며, 과도기에는 번호 폴더와 병존한다.

| 부서 | 소관 | 출발 번호 폴더 |
|------|------|--------------|
| ops/ | 운영관리 (전략, 결정, 세션로그, 메트릭스) | 01_전략, 06_로그 |
| tech/ | 기술 (스펙, 리뷰, R&D, 릴리즈) | 02_리서치, 03_개발 |
| contents/ | 콘텐츠 (아카데미, 출판, 다국어) | 04_문서 |
| marketing/ | 마케팅 (외부 협업, SNS) | 05_공유 |

- 번호 폴더(01~06)는 부서 이관 완료 후 별도 법률 개정으로 정리한다.
- 이관 전까지 번호 폴더는 유지하되, 신규 파일은 부서 폴더에 생성한다.
- scripts/는 귀속 미확정. 부서 결정 전까지 현 위치 유지.
```
