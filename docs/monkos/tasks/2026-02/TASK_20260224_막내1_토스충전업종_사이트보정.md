## 임무

### A-1. refund.html 보정 (충전 포인트 환불 조항 추가)

파일: `monkos_AI/idphoto-kr/public/refund.html`

현재 환불 규정 **뒤에** 아래 조항을 **한국어로** 추가:

```
제○조 크레딧(포인트) 결제 및 환불

① 크레딧 구매 이후 환불은 결제가 되었던 수단으로 진행됩니다.
② 구매한 크레딧은 현금 가치 양도가 불가합니다.
③ 구매한 크레딧의 사용 및 취소/환불할 수 있는 기한은 결제시점으로부터 1년입니다.
④ 미사용 크레딧은 구매 시점에 결제된 금액에 따라 취소 및 환불됩니다.
⑤ 이미 사용한 크레딧은 취소 및 환불이 불가합니다.
```

기존 7일 미사용 전액환불 조항과 **병존** — 삭제하지 말 것.

### A-2. terms.html 확인 및 보정

파일: `monkos_AI/idphoto-kr/public/terms.html`

이미 "크레딧 유효기간은 구매일로부터 1년" 조항이 있으나, 아래 문구가 **정확히** 포함되어 있는지 확인:

> "충전된 크레딧의 이용기간과 환불가능기간은 결제시점으로부터 1년 이내로 제한됩니다."

없으면 제4조(크레딧 시스템)에 추가.

### A-3. 크레딧 비용 정합성 확인

현재 코드와 약관 간 불일치 가능성:
- `config.js`: 생성 10c / 다운로드 70c (v2)
- `terms.html`: 생성 1c / 다운로드 8c (구버전?)

**terms.html을 config.js(v2) 기준으로 보정**:
- 생성: 1회당 **10** 크레딧 차감
- 다운로드: 1회당 **70** 크레딧 차감
- 공유 보너스: SNS 공유 시 **70** 크레딧 지급

### A-4. 충전금액 한도 확인

현재 최고가 패키지: ₩50,750 (500c) → 10만원 이하 ✅ 적합
- 자유 금액 입력 방식이 **없음을 확인** (옵션 선택형만 존재)
- 만약 자유 입력이 있다면 10만원 이하 제한 추가 필요

### B. 결제창 테스트 연동

토스 테스트용 클라이언트 키로 결제창을 띄워서 **캡처**해야 한다.

1. 토스 테스트 키 확인: `monkos_AI/.env` 또는 토스 대시보드에서 테스트 클라이언트 키 확인
2. `config.js`의 `TOSS_CLIENT_KEY`에 **테스트 키** 임시 설정
3. 로컬 또는 Cloud Run에서 결제 플로우 테스트
4. 아래 **8개 화면을 URL이 보이도록 캡처** (PPT 제출용):

| # | 화면 | 설명 |
|---|------|------|
| 1 | 가맹점 정보 표시 | footer 사업자 정보 |
| 2 | 판단정보 (footer) | 상호/사업자번호/대표/주소/전화/통신판매번호 |
| 3 | 충전 관련 이용약관 | terms.html 크레딧 조항 |
| 4 | 취소/환불 규정 | refund.html |
| 5 | 로그인 경로 | Google OAuth 화면 |
| 6 | 크레딧 선택/구매 과정 | 옵션 선택형, 10만원 이하 |
| 7 | 카드 결제 경로 | 토스 결제창 (BC/삼성 등 카드사 화면까지) |
| 8 | 결제 후 크레딧 사용처 | AI 증명사진 생성 화면 |

**캡처 시 반드시 브라우저 URL 바가 보이도록** (도메인 확인용)
