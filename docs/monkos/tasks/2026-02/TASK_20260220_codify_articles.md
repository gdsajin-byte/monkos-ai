## 작업 내용

### Step 1: 참조 문서 읽기

### Step 2: 헌법 조항 작성

세션 이력에서 **불변 원칙**으로 확인된 것들을 헌법 조항으로 성문화.

형식:
```markdown
## 헌법 (Constitution)

### 제1조: 타임스탬프 절대 준수
- **내용**: 매 턴 응답 시작 시 시스템 명령으로 정확한 KST 취득. 추정/기억/계산 금지.
- **근거**: 2026-01-15 세션에서 결정, 멀티에이전트 시계열 추적 필수
- **작가님 원문**: "..." (있으면 인용)
- **위반 시**: 모든 하위 법률의 시간 기반 추적이 무력화됨
- **예외**: 없음 (절대)

### 제2조: ...
```

조항 작성 원칙:
1. **각 조항에 반드시 세션 날짜 근거를 부기** — 언제 결정되었는지
2. **작가님 직접 발화가 있으면 원문 인용** — 최고 근거
3. **위반 시 영향 범위를 명시** — "이 조항이 깨지면 법률 제N장이 무력화"
4. **예외 가능 여부를 명시** — 없음(절대) / 작가님 승인 필요 / 상황 판단

### Step 3: 법률 조항 작성

세션 이력에서 **운용 규칙**으로 확인된 것들을 법률 조항으로 성문화.

형식:
```markdown
## 법률 (Laws)

### 제1장: 코딩 규칙
#### 1조: 순수 JavaScript, async/await 패턴
- **내용**: ...
- **근거**: 2026-0X-XX 세션
- **상위 헌법**: 제N조 (연결되는 헌법 조항)
- **예외**: 작가님 승인 시 가능

#### 2조: 네이밍 규칙
...

### 제2장: 배포 규칙
...
```

법률 작성 원칙:
1. **장(Chapter) → 조(Article) 2단계 구조**
2. **각 조항이 어느 헌법 조항의 하위인지 명시** (상위 연결)
3. **미반영 21건 중 법률급 해당 건 포함** — 이전 조사에서 식별한 누락 규칙

### Step 4: 규정 참조표 작성

기술 상세(모델명, API 경로, 크레딧 단가 등)는 조항화하지 않고 **참조표**로 정리.

```markdown
## 규정 (Regulations) — 참조표

| 코드 | 항목 | 현재 값 | 변경 가능 | 근거 |
|------|------|---------|----------|------|
| R-01 | Gemini 모델 | gemini-3-flash-preview | 에이전트 자율 | 2026-02-18 |
| R-02 | Imagen 모델 | gemini-3-pro-image-preview | 작가님 승인 | 2026-02-18 |
| ...  | ... | ... | ... | ... |
```

### Step 5: 폐기/변경 부록

이전 조사의 폐기/변경 21건을 **조항 변천사**로 정리.

```markdown
## 부록: 조항 변천사

| 원 조항 | 결정일 | 변경일 | 현 조항 | 사유 |
|---------|--------|--------|---------|------|
| (구) WS 코칭 | 02-08 | 02-18 | 법률 제N장 N조 (REST 코칭) | 79 임계점 |
```
