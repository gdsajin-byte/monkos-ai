# 지시서: KR 리전 로그인 선택 팝업 추가

> **[2026-02-24 19:13 KST] iMac/쌍아 → 막내1**
> **역할**: 자율 코딩 (ch7)
> **엔드라인**: KR 로그인 팝업 구현 + 커밋&push
> **선행 조건**: 현재 진행 중인 직접지시 작업 완료 후 수행

---

## 1. 문제

현재 포털 헤더 로그인 버튼 (line 1193):
```html
<button class="header-login-btn" id="headerLoginBtn" onclick="googleLogin()">로그인</button>
```
- **Google만 바로 실행** — KR 리전에서도 카카오 선택지 없음
- `loginKakao()` 함수 (line 1480)는 존재하지만 호출 경로가 없음

---

## 2. 요구사항

KR 리전(`region === 'kr'`) 로그인 버튼 클릭 시:
- **Google + 카카오 선택 팝업** 표시
- 글로벌 리전: 기존대로 Google 바로 실행 (변경 없음)

---

## 3. 구현 방향

### 3-1. 로그인 선택 모달

기존 `consent-modal` 스타일을 재활용하여 간결한 선택 팝업:

```html
<!-- 로그인 선택 모달 -->
<div class="consent-modal" id="loginModal">
  <div class="consent-modal-content" style="max-width:340px; text-align:center;">
    <h3>로그인</h3>
    <div class="gate-login-buttons">
      <button class="gate-login-btn" onclick="googleLogin(); closeLoginModal();">
        <svg ...>G</svg> Google로 로그인
      </button>
      <button class="gate-login-btn gate-login-kakao" onclick="loginKakao();">
        카카오로 로그인
      </button>
    </div>
    <button class="consent-modal-close" onclick="closeLoginModal()">닫기</button>
  </div>
</div>
```

### 3-2. 헤더 로그인 버튼 분기

```javascript
function headerLogin() {
  if (region === 'kr') {
    // KR: 선택 팝업
    document.getElementById('loginModal').classList.add('active');
  } else {
    // Global: Google 바로
    googleLogin();
  }
}
```

헤더 버튼: `onclick="googleLogin()"` → `onclick="headerLogin()"`

### 3-3. 로그인 버튼 텍스트 i18n

- KR: "로그인"
- JA: "ログイン"
- EN: "Login"
(기존 i18n에 이미 있으면 재활용)
