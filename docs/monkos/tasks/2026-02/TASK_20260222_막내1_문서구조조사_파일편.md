# 막내1: 문서 전수조사 — 파일 인벤토리 + 현재 분포 분석

## 배경
- 현재 docs/ 하위 파일이 폴더 분류 없이 평면적으로 쌓여 있음
- 자동 분류 시스템 설계를 위해 "지금 뭐가 어디에 얼마나 있는지" 전수 파악 필요
- 막내1 = 파일 인벤토리, 막내2 = 기술명세 로직, 막내3 = 템플릿/자동화 규격 (병렬)

## TASK

### T1: docs/ 전체 파일 인벤토리
- `docs/` 하위 모든 `.md` 파일을 재귀 탐색
- 파일별 다음 정보 수집:
  - 경로, 파일명, 크기(줄 수), 생성일(frontmatter 또는 파일명), 타입(TASK/SPEC/REPORT/INCIDENT/SESSION/LAW/기타)
- **총 파일 수, 타입별 분포, 폴더별 분포** 통계 산출

### T2: 현재 네이밍 패턴 분석
- 파일명에서 추출 가능한 패턴:
  - `TASK_YYYYMMDD_[에이전트]_[작업명].md` — 몇 개?
  - `SPEC_[주제].md` — 몇 개?
  - `REPORT_YYYYMMDD_[주제].md` — 몇 개?
  - `YYYYMMDD_session*.md` — 몇 개?
  - 패턴 미준수 파일 — 목록
- **일관성 점수** (패턴 준수율) 산출

### T3: 폴더 구조 현황
- 현재 docs/ 하위 폴더 트리 출력
- 각 폴더의 역할이 명확한지 판단 (폴더명 ↔ 내용물 일치도)
- 빈 폴더, 혼재 폴더(여러 타입 섞임) 식별

### T4: 프로젝트 루트의 문서성 파일
- docs/ 밖에 있는 .md 파일 전수 조사 (CLAUDE.md, README.md 등)
- 각각 docs/에 들어가야 하는지, 루트에 있어야 하는지 판단

### T5: 보고서 작성
- 파일: `docs/monkos/REPORT_20260222_문서인벤토리.md`
- 구조:
  1. 총괄 통계 (파일 수, 타입 분포, 폴더 분포)
  2. 네이밍 패턴 분석 (준수율, 미준수 목록)
  3. 폴더 구조 현황 (트리 + 문제점)
  4. 루트 문서 목록
  5. 발견 사항 + 개선 제안

## 대상 디렉토리
- `docs/` 전체 (재귀)
- 프로젝트 루트 `.md` 파일
