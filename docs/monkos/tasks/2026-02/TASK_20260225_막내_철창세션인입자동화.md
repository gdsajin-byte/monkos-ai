현재 작가님이 세션 내용을 **수동으로 복사 → 파일 저장 → 프로젝트에 투입**하는 상태.

기존 우체통 지시서(ORDER_20260223)에서 폴더 경로는 어젠다 #8 대기로 보류되었으나,

이 지시서는 **세션 로그 인입**에 한정하여 자동화를 구축한다.

## 1. 목표

작가님이 철창이 세션을 내보낼 때:
1. `~/Desktop/철창이/` 폴더에 `.md` 파일 저장 (수동 또는 Chrome 확장)
2. **자동 감지** → 파일명 정규화 → `monkos-ops/ops/sessions/`로 복사
3. git add + commit (push는 수동 — 작가님 승인 후)

---

## 2. 작업 1: launchd WatchPaths 스크립트

### 2-1. 감시 스크립트

**경로**: `monkos-ops/scripts/cheolchang_session_watcher.sh`

**동작**:
1. `~/Desktop/철창이/` 내 새 `.md` 파일 감지 (마커 파일 또는 `find -newer` 방식)
2. 파일명 정규화:
   - 입력: 아무 이름 (예: `session_log_marketing.md`, `철창_세션.md`)
   - 출력: `YYYY-MM-DD_Web_철창.md` (ch4 3조 패턴 #7 준용)
   - 같은 날짜에 2건 이상이면: `YYYY-MM-DD_Web_철창_2.md`
3. `monkos-ops/ops/sessions/`로 **복사** (원본 유지)
4. 복사 완료 시 로그 기록: `monkos-ops/scripts/logs/cheolchang_watcher.log`
5. git add + git commit (메시지: `[로그] 철창 세션 인입 — YYYY-MM-DD`)
6. **push는 하지 않는다** — 작가님 승인 후 수동 push

**변수 분리** (경로 확정 후 1줄 수정으로 대응):
```bash
SOURCE_DIR="$HOME/Desktop/철창이"
DEST_DIR="/Users/developer/monk_project/monkos-ops/ops/sessions"
PROJECT_ROOT="/Users/developer/monk_project"
LOG_FILE="/Users/developer/monk_project/monkos-ops/scripts/logs/cheolchang_watcher.log"
```

**주의사항**:
- `.md` 파일만 처리 (이미지, 기타 파일 무시)
- 이미 sessions/에 같은 이름의 파일이 있으면 덮어쓰지 않고 `_2`, `_3` 등 서픽스
- 스크립트 실행 권한: `chmod +x`

### 2-2. launchd plist

**경로**: `monkos-ops/scripts/com.monkos.cheolchang-session.plist`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.monkos.cheolchang-session</string>
    <key>ProgramArguments</key>
    <array>
        <string>/Users/developer/monk_project/monkos-ops/scripts/cheolchang_session_watcher.sh</string>
    </array>
    <key>WatchPaths</key>
    <array>
        <string>/Users/developer/Desktop/철창이</string>
    </array>
    <key>StandardOutPath</key>
    <string>/Users/developer/monk_project/monkos-ops/scripts/logs/cheolchang_watcher_stdout.log</string>
    <key>StandardErrorPath</key>
    <string>/Users/developer/monk_project/monkos-ops/scripts/logs/cheolchang_watcher_stderr.log</string>
</dict>
</plist>
```

- `~/Desktop/철창이/` 폴더에 변경이 감지될 때만 스크립트 실행 (이벤트 드리븐, CPU 소모 없음)
- **plist를 `~/Library/LaunchAgents/`에 등록하는 것은 보고만 하고 작가님 승인 후 실행**
