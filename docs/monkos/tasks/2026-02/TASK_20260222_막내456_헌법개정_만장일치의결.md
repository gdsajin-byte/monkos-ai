### 개정 1: governance/ 신설

```
monk_project/
├── CLAUDE.md                        ← 헌법 (커널, 자동 인식)
├── governance/                      ← 거버넌스 (신설)
│   ├── laws/                          법률 ch1~ch8 (정본)
│   ├── constitution/                  개정 절차 (amendment.md)
│   │   └── petitions/                 청구서 보관
│   ├── history/                       역사 (결정기록)
│   └── philosophy/                    철학 (비전, 가치관, 어록)
├── docs/                            ← 원천 아카이브 (보존)
└── monkos-ops/                      ← 운영 (현행 유지, 재편은 후속)

**4계층 위계:**

| 계층 | 성격 | 물리 위치 |
|------|------|----------|
| 헌법 | 커널. 개요·강제 | CLAUDE.md (자동 인식) |
| 거버넌스 | 법률+역사+철학. 절차·상세·근거 | governance/ |
| 세칙 | 부서별 운영 규정 | monkos-ops/ 각 README |
| 데이터 | 실행 산출물 | 부서 하위 |

**docs/ = 원천 아카이브.** 프로젝트의 뿌리이자 보물창고. 발췌·연구·보존 대상.

```
