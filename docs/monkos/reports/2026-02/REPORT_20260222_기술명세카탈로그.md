```

   │
   └── [촬영 퍼널]
         │
         ├── prep.html (선택) → sessionStorage
         │     ↓
         ├── camera.html (촬영 + 코칭)

         │
         ├── result.html (분석 + 생성 + 다운로드)
         │     ├── 사전분석 → server.js → Gemini 2.0 Flash (Vertex ADC)
         │     ├── 생성 → server.js → Imagen NB3 (API Key)
         │     │     └── 크레딧 차감 → server.js → portal /api/credits/use → Firestore
         │     │           └── 실패 시 → portal /api/credits/refund → Firestore
         │     ├── 다운로드 → 크레딧 차감 → server.js → portal
         │     └── 크레딧 부족 → 토스 결제 → portal /api/payments/toss/confirm → Firestore
```
