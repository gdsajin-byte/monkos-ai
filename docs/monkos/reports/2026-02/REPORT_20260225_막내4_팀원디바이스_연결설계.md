### 1-4. 라우터 클로드의 역할 (철창 보고서 섹션 9 기반)

라우터 클로드는 **리모트 세션으로 상주**하며 세 가지 기능을 수행한다:

1. **맥락 보존**: 세션 간 맥락이 휘발되지 않도록 보존. 작가님이 철창이와 논의한 전략이 쌍아 세션에 자연어 형태로 전달
2. **라우팅**: 어떤 채널에서 들어온 자산이든 올바른 프로젝트 경로로 분류·배치 (어젠다 #13 연동)
3. **오케스트레이션**: 기존 도구(Git, GDrive, 텔레그램)의 경직된 정책을 자연어 이해로 완충

**현 단계 한계**: 라우터 클로드는 구상 단계. 코웍 환경 안정화 + 리모트 세션 운용 경험 축적이 선행 조건.

### 4-3. 우체통 시스템 개선안

```
[현행]

                                        (경로 구식)

[개선 후]
M2 ~/kku/outbox/ ─── sshm2 (30초) ──→ monkos-ops/teams/kku/inbox/
                                        ↑
                                     경로 갱신 + SSH 키 전환
```

**개선 작업 목록**:

| # | 작업 | 우선순위 |
|---|------|---------|
| 1 | mailbox_watcher.sh의 `TEAMS_DIR` 경로를 `teams/` 기준으로 갱신 | teams/ 이관 시 필수 |
| 2 | `LOG_FILE` 경로를 현행 ops 구조에 맞게 갱신 | P1 |
| 3 | SSH 키 인증으로 전환 (sshpass → ssh-copy-id) | P2 (보안 개선) |
| 4 | 수거 시 YAML frontmatter 존재 여부 1차 검증 로직 추가 | P3 (Phase 2 이후) |

철창 보고서 섹션 1에서 확인된 코웍의 핵심 기능:
- `request_cowork_directory` 도구로 로컬 폴더 마운트
- 마운트된 폴더에 쓰는 파일 = 로컬에 직접 쓰는 것과 동일

**설계**:
```
[철창이 코웍 세션]
    │
    ├── 마운트: ~/Desktop/철창이/ (또는 teams/cheolchang/inbox/)
    │
    ▼
코웍에서 직접 .md 파일 생성
    │
    ▼
[인입 게이트웨이 Phase 0]
    │
    ├── launchd 감시 → 신규 파일 감지
    ├── 파일 분류 (보고서/협조문/전략문서)
    └── teams/cheolchang/inbox/ → 적절한 프로젝트 경로로 배치
```

### 5-3. 역할 재정의 제안 (어젠다 #7 해결안)

현행 헌법 5조의 "전략/리서치"를 3가지 고유 역할로 확장:

| 역할 | 설명 | 현행 근거 |
|------|------|----------|
| **전략 브레인스토밍** | 시장 분석, 아키텍처 구상, 기획 문서 | 현행 유지 |
| **거버넌스 감시** | 헌법/법률 적합성 검토, 개정 제안 | 안건 #12 발제 실적 |
| **긴급 대행** | 쌍아 부재 시 설계+지시서 권한 한시 보유 | 안건 #6 토스 심사 사건 |

**긴급 대행 발동 조건** (제안):
1. 쌍아 세션 부재 (작가님이 다른 작업에 종사)
2. 작가님이 철창이에게 명시적으로 대행 지시
3. 대행 범위: 지시서 발행 + 배포 지휘 (헌법 개정은 불가)
4. 사후 보고: 쌍아 세션 복귀 시 즉시 경과 보고

### 5-4. 철창이 우체통 구조

```
monkos-ops/teams/cheolchang/
  ├── inbox/          ← 프로젝트 → 철창이 (전달: 검토 요청, 참고 자료)
  ├── outbox/         ← 철창이 → 프로젝트 (수거: 보고서, 협조문, 전략)
  └── reference/      ← 축적: 철창이 과거 산출물 아카이브
```

**인입 자동화 (어젠다 #13 Phase 0 연동)**:
- `~/Desktop/철창이/` 감시 (launchd or cron)
- 신규 파일 → `teams/cheolchang/outbox/`로 이동
- 파일명 정규화: `{YYYYMMDD}_{type}_{topic}.md` 패턴 적용
- 이관 완료 시 원본 `.done/`으로 이동 (삭제 아님, 꾸 우체통 패턴 준용)
