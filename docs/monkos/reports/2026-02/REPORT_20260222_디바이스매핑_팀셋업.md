### 4.3 시나리오 3: 완전 자동 온보딩 (스크립트 1개)

> **대상**: 미래 대량 팀원 합류 시나리오
> **전제**: macOS 또는 Linux 환경

```bash
#!/bin/bash
# monkos-onboard.sh — MONK OS 팀원 자동 온보딩
# 사용법: curl -sL https://[배포URL]/onboard.sh | bash -s -- [팀원코드]

TEAM_MEMBER=$1  # han, kku, etc.

echo "=== MONK OS 팀원 온보딩: $TEAM_MEMBER ==="

# 1. Tailscale 설치
if ! command -v tailscale &>/dev/null; then
    curl -fsSL https://tailscale.com/install.sh | sh
    echo "[1/6] Tailscale 설치 완료"
fi

# 2. Tailscale 네트워크 합류 (인증 키 필요)
sudo tailscale up --authkey=$TAILSCALE_AUTH_KEY
echo "[2/6] Tailscale 네트워크 합류"

# 3. Git clone
git clone https://github.com/[repo]/monk_project.git ~/monk_project
echo "[3/6] 저장소 클론 완료"

# 4. Claude Code 설치
npm install -g @anthropic-ai/claude-code
echo "[4/6] Claude Code 설치 완료"

# 5. MEMORY.md 초기화 (팀원용)
mkdir -p ~/.claude/projects/-Users-$(whoami)-monk-project/memory
cp ~/monk_project/docs/infrastructure/templates/MEMORY_TEAM_INIT.md \
   ~/.claude/projects/-Users-$(whoami)-monk-project/memory/MEMORY.md
echo "[5/6] MEMORY.md 초기화 완료"

# 6. 우체통 폴더 생성
mkdir -p ~/$TEAM_MEMBER/{inbox,outbox}
echo "[6/6] 우체통 폴더 생성 완료"

echo "=== 온보딩 완료 ==="
echo "다음 단계: VSCode에서 monk_project 폴더를 열고 Claude Code를 시작하세요."
```

**스크립트 관리 위치**: `monkos-ops/scripts/monkos-onboard.sh`
**전제 조건**:
- Tailscale Auth Key 사전 발급 (tailscale.com/admin → 키 생성)
- Git 접근 권한 사전 부여
- Claude Code API 키 사전 설정

| **경량 팀원 (꾸)** | 없음 | 없음 | 우체통만 | 없음 |
| **외부 협력** | PR만 | 없음 | 없음 | 없음 |

### 6.3 위험 요소

1. **`mailbox_watcher.sh`에 SSH 비밀번호 평문 하드코딩** → 환경변수 또는 SSH 키 인증으로 전환 권고
2. **텔레그램 봇 인프라가 Windows 경로 하드코딩** → Mac 대응 스크립트 필요
3. **팀원 디바이스 분실/탈취 시** → Tailscale ACL로 접근 범위 제한, 원격 키 폐기 절차 필요
4. **CLAUDE.md 변조 방지** → Git 서명 커밋(GPG) 도입 검토
