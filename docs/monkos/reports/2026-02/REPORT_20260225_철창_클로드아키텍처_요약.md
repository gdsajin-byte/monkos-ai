# 클로드 데스크탑 앱 아키텍처 세션 정리

**일시:** 2026-02-25
**참여:** 작가님(몽크스튜디오스) × 철창(Cowork/M1)

---

## 1. 코웍(Cowork)의 로컬 폴더 접근 구조

코웍은 사용자 컴퓨터 위의 경량 리눅스 VM(Ubuntu 22)에서 실행된다. 로컬 파일시스템에 직접 접근 권한은 없으며, 사용자가 디렉토리 피커로 폴더를 명시적으로 선택(마운트)해야 접근이 가능하다.

**핵심:** 샌드박스 + 사용자 승인 + 물리 폴더 마운트

---

## 2. 챗 / 코웍 / 코드 — 세 모드의 차이

데스크탑 앱 안의 챗, 코웍, 코드 세 탭이 존재하며, 가장 큰 차이는 **실행 환경의 유무**다.

- **챗(Chat):** 텍스트 대화만 가능. 파일시스템 접근·코드 실행 불가.
- **코웍(Cowork):** VM 샌드박스 안에서 코드 실행, 파일 생성, 브라우저 조작 가능. 민감 작업은 사용자 확인 필요.
- **코드(Code):** CLI 클로드 코드와 동일한 엔진에 GUI를 씌운 것. 로컬 실행 시 터미널과 같은 권한.

권한 범위: **Chat < Cowork < Code**

---

## 3. 데스크탑 코드 탭 = CLI 클로드 코드

데스크탑 Code 탭은 "코드 아티팩트 생성기"가 아니라, CLI 클로드 코드와 **동일한 엔진**(same underlying engine)이다.

- 설정 파일 공유: CLAUDE.md, MCP 서버, 훅, 스킬 등
- CLI → 데스크탑 세션 이관 가능 (`/desktop` 명령)
- GUI 추가 기능: 비주얼 diff, 앱 프리뷰, PR 모니터링, 병렬 세션(Git worktree)
- CLI 전용 기능: `--print` 스크립트, `dontAsk` 모드, 엔드포인트 프로바이더, 에이전트 툴

---

## 4. 세 모드는 각각 별도 세션

챗, 코웍, 코드는 같은 앱 안의 탭으로 존재하지만 **컨텍스트를 공유하지 않는다.** 유일하게 공유되는 것은 설정 파일(CLAUDE.md, MCP 설정 등) 수준이다.

---

## 5. CLAUDE.md 파일의 계층 구조

이름은 모두 `CLAUDE.md`이지만, **파일이 놓인 위치가 곧 권한 범위를 결정**한다.

| 위치 | 범위 | 공유 여부 |
|------|------|-----------|
| `~/.claude/CLAUDE.md` | 글로벌 (모든 프로젝트) | 디바이스 귀속 |
| 프로젝트 루트 `CLAUDE.md` | 해당 프로젝트 전체 | git 추적 → 팀 공유 |
| 프로젝트 `CLAUDE.local.md` | 해당 프로젝트 (개인) | .gitignore → 디바이스 귀속 |
| 하위 폴더 `CLAUDE.md` | 해당 폴더 범위 | git 추적 → 팀 공유 |

충돌 시 더 가까운(구체적인) 쪽이 우선한다.

---

## 6. 공유/귀속의 설계 원리

**git이 가져가면 공유, git이 무시하면 디바이스 귀속.**

- **공유(git 따라감):** 프로젝트 `CLAUDE.md` → 팀 규칙, 프로젝트 헌법
- **귀속(디바이스 잔류):** 글로벌 `~/.claude/CLAUDE.md`, `CLAUDE.local.md`, 메모리 파일

이는 유닉스 설정 오버라이드 패턴(`.gitconfig`, `.npmrc`, `.eslintrc` 등)을 AI 에이전트 컨텍스트에 적용한 것이다.

프로젝트 안에서도 동일 원리 반복: CLAUDE.md는 git에 따라 공유되고, 메모리 파일은 디바이스에 귀속되어 개인 환경을 보존한다.

---

## 7. 리모트 세션 (Anthropic 클라우드)

데스크탑 Code 탭에서 **Remote** 환경을 선택하면 Anthropic 서버에서 실행된다.

- 앱을 꺼도 작업 계속됨
- 모니터링: 데스크탑 앱, claude.ai/code, iOS 앱
- 권한: Ask permissions 없음(이미 샌드박스), Bypass도 없음
- 멀티 레포 지원
- 별도 컴퓨트 요금 없음 (구독 플랜 내 소모)

---

## 핵심 인사이트

> 이름이 다 CLAUDE.md라 사거리가 없어 보이는 것일 뿐, 각 영향력은 전혀 다르게 작동한다. 파일 내용이 아니라 **파일이 놓인 자리가 그 규칙의 사정거리를 정한다.**
