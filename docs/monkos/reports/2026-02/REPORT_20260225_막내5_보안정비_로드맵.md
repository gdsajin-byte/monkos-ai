#### C1: JWT 토큰 미서명 — 수정 방안

**현행:** `btoa(JSON.stringify(payload))` — Base64 인코딩만
**수정:** HMAC-SHA256 서명 도입 (CF Workers의 Web Crypto API 사용)
**변경 파일:** `functions/api/auth.js`
**변경 범위:**
1. `generateToken()` → HMAC-SHA256으로 서명 추가
2. `verifyToken()` → 서명 검증 로직 추가
3. 서명 키: `env.JWT_SECRET` (Cloudflare Workers Secrets에 등록)

**구현 방향:**
```
// 토큰 형식: base64(payload).base64(hmac_sha256(payload, secret))
// CF Workers에서 crypto.subtle.importKey + crypto.subtle.sign 사용
```

**마이그레이션:** 기존 미서명 토큰 호환 기간 설정 (14일). 신규 토큰은 서명 포함, 검증 시 서명 없으면 14일 내에만 허용 후 만료.
**롤백 계획:** 서명 검증 실패 시 기존 Base64 토큰으로 폴백 (14일 유예)
