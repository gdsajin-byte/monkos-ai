## 1. 4계층 × 라우터 매핑표

라우터 클로드(command_bridge v2)는 iMac에서 pm2 상주. Remote Session은 Anthropic VM에서 실행.

| 계층 | 파일 | Git | iMac 라우터 접근 | Remote Session 접근 | 동기화 방식 |
|------|------|-----|-----------------|-------------------|-----------|
| L1 | `~/.claude/CLAUDE.md` | ❌ | ✅ (로컬 자동 로딩) | ❌ **미적용** | 수동 배치 (디바이스별) |
| L2 | `CLAUDE.md` | ✅ | ✅ (cwd 로딩) | ✅ (GitHub 클론) | Git push/pull |
| L2.5 | `CLAUDE.local.md` | ❌ | ✅ (로컬 자동 로딩) | ❌ **미적용** | 수동 배치 (디바이스별) |
| L3 | 하위폴더 `CLAUDE.md` | ✅ | ✅ (cwd 하위 탐색) | ✅ (GitHub 클론) | Git push/pull |
| MEM | `MEMORY.md` | ❌ | ✅ (로컬 자동 인젝션) | ❌ **미적용** | CHANGELOG + 수동 |

**핵심 갭**: Remote Session은 Git 공유 레이어(L2·L3)만 적용된다. L1(디바이스 정체성)·L2.5(디바이스 프로젝트 설정)·MEMORY(세션 상태)가 모두 탈락.

**영향**: Remote Session에 위임된 중량 태스크는 헌법 요약(L2) + 폴더 규칙(L3)만으로 동작. 팀 통신 경로·디바이스 쿼터·세션 프로토콜·디버깅 교훈 등이 미적용.
