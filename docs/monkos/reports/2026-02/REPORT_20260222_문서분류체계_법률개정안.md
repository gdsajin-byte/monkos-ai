### 개정안 3조 (신설): 파일 네이밍 규칙

**목적**: 파일명에서 타입·날짜·에이전트를 자동 추출 가능하도록 표준화.

**패턴 규격 (7종)**:
| # | 패턴 | 대상 폴더 | 예시 |
|---|------|----------|------|
| 1 | `TASK_YYYYMMDD_{agent}_{name}.md` | `tasks/YYYY-MM/` | `TASK_20260222_막내3_chatbot_update.md` |
| 2 | `REPORT_YYYYMMDD_{topic}.md` | `reports/YYYY-MM/` | `REPORT_20260222_문서인벤토리.md` |
| 3 | `SPEC_{service}_{feature}.md` | `specs/{service}/` | `SPEC_idphoto-kr_credit-system.md` |
| 4 | `INCIDENT_YYYYMMDD_{service}.md` | `incidents/YYYY-MM/` | `INCIDENT_20260220_cf-function.md` |
| 5 | `DESIGN_YYYYMMDD_{feature}.md` | `designs/YYYY-MM/` | `DESIGN_20260215_tts-architecture.md` |
| 6 | `SPRINT_{range}.md` | `sprints/` | `SPRINT_0217-0223.md` |
| 7 | `YYYY-MM-DD_{device}_{agent}.md` | 세션 로그 (정본) | `2026-02-22_iMac_막내3.md` |

**표기 통일 규칙**:
- 에이전트명: `쌍아`, `막내3`, `소넷이` 등 (디바이스 접두어 불포함)
- 우선순위: `P0`~`P3` (HIGH, CRITICAL 등 자유형 금지)
- 날짜: `YYYYMMDD` (하이픈 없음, 세션 로그만 예외로 `YYYY-MM-DD`)

**미분류 파일**: 패턴 미매칭 파일은 `_unsorted/`에 임시 배치. 7일 내 분류 미완료 시 경보.

### 개정안 4조 (신설): monkos-ops 연동 규칙

**목적**: `docs/`와 `monkos-ops/` 간 역할을 명확히 분리하여 이중화를 방지.

**역할 분리**:
| 영역 | 정본 위치 | 참조 위치 | 비고 |
|------|----------|----------|------|
| 세션 로그 | `monkos-ops/06_로그/sessions/` | `docs/corpus/sessions/` (아카이브) | 신규는 정본에만 생성 |
| 전략 문서 | `monkos-ops/01_전략/` | `docs/infrastructure/strategy/` | ops가 원본, docs는 확정본만 이관 |
| 리서치 | `monkos-ops/02_리서치/` | `docs/rnd_2026/` | ops가 원본, docs는 정제본만 이관 |
| 지시서/보고서 | `docs/monkos/tasks/`, `reports/` | - | docs가 정본 (ops에 복제 금지) |
| 팀 공유 | `monkos-ops/05_공유/` | - | ops 전용 (docs에 복제 금지) |
| 법률/헌법 | `docs/infrastructure/laws/` | - | docs 전용 (ops에 복제 금지) |

**원칙**:
- 정본은 하나만 존재. 참조본은 읽기전용(수정 금지).
- 정본 이동 시 참조본에 리다이렉트 노트 남김 (파일 삭제 대신).
- 양쪽 동일 문서 발견 시 → 정본 판정 → 비정본 삭제 또는 리다이렉트.
