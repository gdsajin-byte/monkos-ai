## 2. 통합 스키마 제정안

### 2.1 수발신 헤더 스키마

**정규 형식**:
```
[YYYY-MM-DD HH:MM KST] {디바이스}/{에이전트} → {수신자}
```

**필드 정의**:

| 필드 | 허용값 | 규칙 |
|------|--------|------|
| `디바이스` | 디바이스 레지스트리 약칭만 | `M1`, `iMac`, `M2`, `4060`, `iPhone`, `M4` |
| `에이전트` | 에이전트 레지스트리 약칭만 | `쌍아`, `용아`, `막내N`(N=숫자), `소넷이`, `철창이`, `한`, `꾸` |
| `수신자` | 에이전트 약칭 or `작가님` | 작가님일 때 디바이스 생략 (ch1 4조 현행) |

**막내 표기 정규화**: `막내N` (공백 없음, N은 아라비아 숫자). 파일명/헤더/보고 전부 동일.

**유효 조합 예시**:
```
[2026-02-22 15:00 KST] iMac/쌍아 → 막내2          ← AI → AI (지시서)
[2026-02-22 15:10 KST] iMac/막내2 → iMac/쌍아      ← AI → AI (완료 보고)
[2026-02-22 16:00 KST] M4/한 → 작가님              ← 팀원 → 작가님
[2026-02-22 16:30 KST] M2/꾸 → 작가님              ← 팀원 → 작가님
[2026-02-22 17:00 KST] 4060/소넷이 → iMac/쌍아     ← 크로스 디바이스
```

**금지 조합**:

| 금지 패턴 | 이유 |
|-----------|------|
| `iMac/한송이` | 정식명 사용 금지 → `iMac/한` |
| `iMac/막내 2` | 공백 포함 금지 → `iMac/막내2` |
| `쌍아 → 막내2` | 디바이스 누락 (발신 측 필수) |
| `iMac/쌍아 → 막내2 (이관)` | 자유 텍스트 부가 금지. 이관은 본문에 기술 |

### 2.2 파일명 필드 정규화

ch4 3조 7종 패턴의 각 필드 허용값:

**{agent} 허용값**:

| 값 | 대상 |
|----|------|
| `쌍아` | 쌍아 |
| `막내N` (N=숫자) | 막내 N호 |
| `소넷이` | 소넷이 |
| `한` | 한송이 |
| `꾸` | 와이프 |
| `철창이` | 철창이 (지시서 발신은 없으나 보고서 가능) |

**{device} 허용값**: 디바이스 레지스트리 약칭과 동일 (`M1`, `iMac`, `M2`, `4060`, `iPhone`, `M4`)

**{service} — 서비스 약칭 레지스트리** (신설):

| 약칭 | 서비스 | Cloud Run / 배포 대상 |
|------|--------|----------------------|
| `portal` | monkos.ai 포털 | monkos-portal |
| `idphoto-kr` | 한국 AI 증명사진 | monkos-idphoto-kr |
| `idphoto-jp` | 일본 AI 증명사진 | monkos-idphoto-jp |
| `photolab` | monk.kr 프로덕션 증명사진 | Cloudflare Pages (monk-kr) |
| `monk-kr` | monk.kr 포털 | Cloudflare Pages (monk-kr) |
| `image-engine` | Imagen API 서비스 | monk-image-engine |
| `ops` | 운영 체계 (monkos-ops) | 인프라 (비배포) |

**{topic} 허용값**: 자유 텍스트 (영문 소문자 + 하이픈 권장, 한글 허용)

**통합 로그 접미사 규격화** (현행 불일치 해소):

| 유형 | 파일명 패턴 | 예시 |
|------|------------|------|
| 단일 에이전트 | `YYYY-MM-DD_{device}_{agent}.md` | `2026-02-22_iMac_막내1.md` |
| 통합 (디바이스 복수) | `YYYY-MM-DD_{agent}_통합.md` | `2026-02-22_쌍아_통합.md` |
| 통합 (에이전트 복수) | `YYYY-MM-DD_{agent범위}_통합.md` | `2026-02-22_막내456_통합.md` |

→ 통합 로그는 디바이스 생략을 허용하되, `_통합` 접미사를 **공식 패턴**으로 인정.

## 5. 즉시 실행 vs 작가님 판단

### 즉시 가능
- ch1 1조 "막내 N" → `막내N` 공백 제거 — 실태에 맞춘 정규화 (의미 변경 없음)

### 작가님 판단 필요

| 판단 항목 | 선택지 | 비고 |
|-----------|--------|------|
| **수발신 금지 조합 엄격도** | 엄격 (본안) / 완화 (괄호 부가 허용) | 이관 표기 등 실무 편의 vs 파싱 정확성 |
