### 충돌 방지 규칙

1. **각 막내는 자기 담당 파일만 수정** — 타 영역 수정 필요 시 쌍아에게 요청
2. **`index.html` 마크업 수정은 막내E만** — 다른 막내가 HTML 구조 변경 금지
3. **`app.js` (공통 변수/유틸) 수정 시** — 쌍아 승인 필수 (전역 상태 영향)
4. **커밋 메시지에 담당 영역 태그**: `[portal]`, `[download]`, `[camera]`, `[chatbot]`, `[design]`
5. **develop 브랜치에서 작업** → dev 배포 테스트 → main 머지는 쌍아가 통제
