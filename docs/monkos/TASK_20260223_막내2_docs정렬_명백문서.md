# 지시서: docs/ 명백 문서 정렬

> **근거**: 2026-02-22 PM3 세션 — 작가님 지시 "명백한 문서들을 뚜렷한곳으로 이동"
> **전제**: 막내1의 governance/ 이행 커밋이 완료된 후 시작할 것
> **원칙**: 애매한 것은 남겨둔다. 명백한 것만 이동한다.

---

## 1. 작업 철학

작가님 원문:
> "각 단위가 명백한 문서들을 영역별로 뚜렷한곳으로 이동시킬것. 세부적인 조율이 필요한것들은 내일로 미루되 잠든사이 거대한 밑작업은 진행한다. 서로영역에서 조금씩 겹치거나 중복되는부분은 불가피할것이나 파트마다의 관점이나 철학적 기술적 시각이 다르니 최선을 다해 파트에 맞는 문서들로 정렬시켜주길 바란다."

**핵심**: "명백한 것만" 이동. 판단이 어려우면 현 위치에 남겨두고 보고서에 "미분류 사유" 기재.

## 3. 분류 판단 기준

| 판단 | 행동 |
|------|------|
| **명백** — 접두사와 내용이 일치 | 이동 |
| **대체로 명백** — 접두사 있으나 내용이 다소 다름 | 이동 + 보고서에 "참고" 기재 |
| **애매** — 접두사 없음, 또는 2개 영역에 걸침 | **이동하지 않음** + 보고서에 "미분류 사유" 기재 |
| **위험** — 이동 시 다른 문서 참조가 깨질 수 있음 | **이동하지 않음** + 보고서에 "참조 의존성" 기재 |
