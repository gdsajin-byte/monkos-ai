## 1. 도메인 & 인프라 구조

### 도메인 체계

| 도메인 | 역할 | 공개 범위 |
|--------|------|-----------|
| monk.kr | 회사 홈페이지, 정부심사용, 내부 테스트베드 | 비공개 (심사위원 전용) |
| monkos.ai | 검증 완료 서비스 배포 플랫폼 (현재 Gemini 2.0 챗봇) | 글로벌 공개 |
| idphoto.monkos.ai | 증명사진 앱 — 일본 1순위 진출 서비스 | 일본 시장 공개 |

### 배포 인프라

```
Cloudflare DNS (monk.kr + monkos.ai 모두 관리 중)
│
├── monkos.ai → Cloud Run (기존 챗봇, Vertex AI 바우처 기반)
├── idphoto.monkos.ai → Cloud Run (신규, 도쿄 리전 asia-northeast1)
│     ├── 프론트엔드 (일본어 UI)
│     ├── Vertex AI — Imagen 3.0 (i2i 증명사진 생성)
│     ├── Vertex AI — Gemini Live (실시간 촬영 코칭 + QC)
│     └── Stripe (엔화 결제, 추후)
│
└── Firebase Hosting (기존 1개 배포 중)
```

- **GCP $350K 바우처 소진 전략**: Cloud Run + Vertex AI 전량 바우처 처리
- Cloudflare에서 서브도메인 CNAME/A 레코드 추가 → SSL 자동, 도쿄 엣지 CDN 자동
- 기존 GCP 프로젝트 내 Vertex AI 리소스 공유

## 2. 핵심 파이프라인 — 증명사진 앱 원리

```
[촬영 전] Gemini Live (실시간 스트리밍)
    │  카메라 피드 → 환경 체크 (조명, 배경, 그림자)
    │  음성 코칭: 포즈, 표정, 헤어 가이드
    ▼
[촬영] 원본 확보
    │  Gemini Live 코칭으로 원본 품질 극대화
    ▼
[생성] Imagen 3.0 (i2i)
    │  원본 → 증명사진 규격 생성
    │  배경 처리, 조명 보정, 규격 맞춤
    ▼
[QC] Gemini API (비동기, Live와 별도)
    │  원본 vs 생성물 유사도 검증
    │  얼굴 구조, 피부톤, 인상 일치 여부
    │  규격 적합 여부 (여백, 크기, 배경색)
    │  임계값 미달 시 재생성 루프
    ▼
[출고] 정체성 유지된 증명사진 전달
```

### 역할 분리 (중요)

| 모듈 | 역할 | 방식 |
|------|------|------|
| Gemini Live | 촬영 코칭 (환경 + 포즈) | 실시간 스트리밍 세션 |
| Imagen 3.0 | 증명사진 이미지 생성 (i2i) | API 호출 |
| Gemini API | 생성물 QC (유사도 검증) | 비동기 API 호출 |

- Imagen 4는 아직 i2i 미지원 → Imagen 3.0으로 프로덕션
- 증명사진 해상도는 3.0으로 충분
- Imagen 4 i2i 지원 시 업그레이드 경로 확보

## 3. 비즈니스 모델 — 퍼널형 락인 구조

### 핵심 개념

증명사진 앱 = **원본 수급 채널** (입구)  
몽코스프로 = **백엔드 공장** (수익화 엔진)

```
[유저 진입] — "여권사진 찍으러 왔는데"
    │
    ▼
여권사진 (가장 낮은 허들)
    │  원본 촬영 → AI가 "가장 닮은 원형" 추출
    │  = 이 원형이 유저의 MONKOS 자산
    │
    ├─→ 여권 규격 출력 ✅ (첫 결제)
    ├─→ 비자/면허 사진 (규격만 변경, 추가 과금)
    ├─→ 취활 이력서 사진 (리터칭 + 스-츠 합성)
    ├─→ 비즈니스 프로필 (스타일링 + 정체성 유지) ← 5,000엔+
    └─→ AI 모델 생성 등 무한 확장
```

### 가격 구조 (일본 시장)

| 단계 | 서비스 | 가격 | 역할 |
|------|--------|------|------|
| 입구 | 여권/비자 사진 | 무료~1,500엔 | 원본 수급 + 첫 결제 |
| 확장 | 규격 추가 (비자, 면허 등) | +500엔 | 원형 재활용, 거의 무원가 |
| 심화 | 취활 이력서 사진 | 3,000~5,000엔 | 한국식 리터칭 프리미엄 |
| 프리미엄 | 비즈니스 프로필 | 5,000~8,000엔 | 정체성 유지 + 스타일링 |
| 구독 | 연간 원형 업데이트 | 年 3,000엔 | 락인 완성 |

### 락인 포인트

- **원형(原形)** = 유저의 "가장 본인다운 얼굴"이 MONKOS에 저장
- 다른 앱 가면 원형부터 다시 만들어야 함 → 이탈 비용 발생
- 데이터 인질이 아닌 **경험 락인**: "내 얼굴의 가장 좋은 버전이 여기에 있다"
- 정체성 유지가 핵심 차별화 — 기존 AI 앱(SNOW, 에픽포토)은 딴 사람을 만듦

## 4. 일본 시장 진입 전략

### 타이밍

- 就活(취활) 시즌: **3월~6월** 피크
- 증명사진 수요: **1~2월** 준비 시작 → **지금이 진입 적기**
- 3/1 ES(엔트리시트) 제출 데드라인 → 대학생들이 바로 지금 사진 준비 중

### 일본 증명사진 규격

| 용도 | 사이즈 | 비고 |
|------|--------|------|
| 履歴書(이력서) | 30×40mm | 가장 큰 볼륨 |
| パスポート | 35×45mm | ICAO 기준 |
| マイナンバー | 35×45mm | 배경 흰색 필수 |
| ビザ申請 | 각국 상이 | 미국비자 51×51mm 등 |

### 경쟁 환경 & 차별화

| 경쟁사 유형 | 약점 | MONKOS 우위 |
|------------|------|-------------|
| 스피드 사진기 (Ki-Re-i 등) | 하드웨어 고정, 700~1,000엔 | 스마트폰으로 어디서든 + AI 코칭 |
| 스마트폰 앱 (履歴書カメラ 등) | 셀카 품질 들쭉날쭉, 과도한 보정 | 실시간 Gemini 코칭 + 정체성 유지 |
| 사진관 (写真スタジオ) | 1,500~3,000엔+, 시간 부담 | 동등 품질을 무료~저가에 제공 |

### 초기 마케팅 — 무료 100명/일 + 바이럴 조건

**사용자 동선:**
```
LINE 미니앱 → "무료 증명사진?" → 사진 업로드 → AI 처리
→ 결과물 보고 놀람 → 다운로드 조건: 비포/애프터 X에 후기 포스팅
→ #MONKOS #AI証明写真 자동 확산
```

**무료 운영 비용:**
- Imagen API 1건당 ~$0.02~0.04
- 100명/일 = $2~4/일 → 월 $60~120
- GCP 바우처 소진 → 사실상 비용 제로

**바이럴 조건:**
- 비포/애프터 X 포스팅 필수
- "本日残り23枚" 한정 카운터 → 일본인 한정(限定) 심리 자극
- 비포/애프터 차이 자체가 광고

- 해시태그: #就活 #証明写真 #ES写真 #AI写真 #25卒 #26卒

### LINE公式アカウント — 전환·리텐션

**세팅 주의사항:**
- LINE for Business(linebiz.com)에서 개설, 한국 LINE과 별도
- 초기: 미인증(未認証) 계정으로 시작 → 법인 전환 후 인증
- 무료 플랜: 월 200통 (1:1 채팅은 무료 통수 미포함)
- 계정명 변경 까다로움 → 처음부터 "MONKOS AI証明写真" 확정

**기술 연동:**
- Messaging API 모드 전환 시 기본 자동응답 꺼짐 → 자체 봇 서버 필요
- LINE Login과 Messaging API는 별도 채널 (LINE Developers 콘솔)
- Webhook URL: HTTPS 필수, 도쿄 리전 서버 권장

**리치메뉴:**
- 이미지: 2500×1686px 또는 2500×843px
- 초기 3분할: "無料で撮影" / "料金プラン" / "使い方"
- 유저 첫인상 = 리치메뉴

**일본 특이사항:**
- 友だち追加 후 즉시 블록률 30~50%
- 첫 메시지 짧고 명확: "AI証明写真を無料でお試しいただけます📸"
- 메시지 빈도 주 1~2회 이하

### 결제 플로우

LINE 내 결제(LINE Pay) = 일본 법인 필요 → 초기 비현실적

**현실적 구조:**
```
LINE 리치메뉴 "有料プラン"
  → idphoto.monkos.ai/pricing (외부 링크)
    → Stripe 결제 (엔화, 한국 사업자로 개설 가능)
```

LINE은 유입·소통 채널, 결제는 자체 웹 Stripe 처리.

### 연동 플로우

```
X (인지) → LINE (전환) → idphoto.monkos.ai (서비스) → LINE (리텐션/업셀)
```
