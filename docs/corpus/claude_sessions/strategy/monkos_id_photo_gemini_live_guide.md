# MONKOS 증명사진 가이드 — Gemini Live 교육용

> **문서 목적**: Gemini Live가 실시간 촬영 코칭 및 촬영 후 QC 검증 시 참조하는 마스터 가이드
> **버전**: v1.0 (2025-02-08)
> **관리**: MONKOS

---

## 1. 증명사진 용도별 규격 사양

### 1-1. 여권 / 비자 (ICAO 기준 — 최상위 엄격도)

| 항목 | 규격 |
|------|------|
| 인화 크기 | 가로 3.5cm × 세로 4.5cm |
| 디지털 크기 | 가로 413px × 세로 531px (권장) |
| 해상도 | 300 DPI 권장 |
| 머리 길이 | 정수리(머리카락 제외)~턱: 3.2~3.6cm |
| 배경 | 균일한 흰색, 테두리 없음 |
| 촬영 기한 | 신청일 기준 6개월 이내 |
| 근거 | 여권법시행령 제5조, ICAO Doc 9303 |

**여권 전용 추가 규정:**
- 포토샵 등 편집 프로그램으로 배경 제거/합성 불가
- AI 생성·합성·가공 사진 사용 불가 (2024년 강화)
- 치아 노출 불가 (입 다문 자연스러운 표정)
- 흰색 의상 지양 (배경과 구분 안 될 경우 반려)
- 컬러렌즈 착용 불가
- 뿔테안경 지양 (렌즈 반사·눈 가림 시 불가)
- 두 귀 노출 필수 (선천적 비노출 제외, 머리카락으로 가리기 불가)

### 1-2. 주민등록증 / 운전면허증

| 항목 | 규격 |
|------|------|
| 인화 크기 | 가로 3.5cm × 세로 4.5cm (여권 규격 통일) |
| 디지털 크기 | 가로 350px × 세로 450px |
| 해상도 | 300 DPI |
| 머리 길이 | 정수리~턱: 3.2~3.6cm |
| 배경 | 흰색 권장 (옅은 단일색 가능) |
| 촬영 기한 | 6개월 이내 |

**참고:** 2016년부터 공공기관 사진 규격이 여권 규격(3.5×4.5cm)으로 통일됨. 기존 반명함판(3×4cm)도 일부 수용되나, 여권 규격으로 촬영하면 모든 신분증에 범용 사용 가능.

### 1-3. 이력서 / 취업용

| 항목 | 규격 |
|------|------|
| 표준 크기 | 가로 3cm × 세로 4cm (반명함판) |
| 여권 규격 | 가로 3.5cm × 세로 4.5cm (일부 기업 요구) |
| 온라인 지원 | 기업별 상이 (1:1 비율 또는 3:4 비율) |
| 배경 | 흰색 또는 옅은 파란색/회색 (기업별 상이) |
| 촬영 기한 | 3~6개월 이내 권장 |

**이력서 사진 특이사항:**
- 여권 사진 대비 규정이 유연함
- 자연스러운 미소 허용 (치아 살짝 보이는 정도 OK)
- 약간의 측면 포즈 허용 (15도 이내)
- 배경색 다양화 가능 (흰색, 회색, 옅은 파란색)
- 적절한 보정 허용 (과도한 보정 주의)

### 1-4. 학생증 / 사원증

| 항목 | 규격 |
|------|------|
| 일반 크기 | 가로 3cm × 세로 4cm |
| 배경 | 기관별 상이 (흰색 기본) |
| 촬영 기한 | 6개월 이내 |

**참고:** 기관별 세부 규정이 다를 수 있으므로, 사전에 요구 사항 확인 필요.

## 2. 공통 규격 요건 (전 용도 공통)

### 2-1. 얼굴 방향 및 포즈
- 얼굴과 어깨는 정면을 향할 것
- 머리는 사진 중앙에 위치
- 눈동자는 정면 응시
- 고개를 기울이거나 돌리지 않을 것
- 어깨선은 수평

### 2-2. 표정
- 자연스러운 표정, 무표정에 가까운 편안한 표정
- 입은 자연스럽게 다문 상태
- 치아 노출 불가 (여권/신분증)
- 웃거나 찡그리지 않을 것
- 눈은 뜬 상태 (반감은 상태 불가)

### 2-3. 배경
- 균일한 흰색 (여권/신분증 기본)
- 잉크 자국, 그림자, 패턴 없어야 함
- 테두리 없음
- 다른 사람이나 사물 노출 불가

### 2-4. 조명
- 얼굴에 그림자가 없어야 함
- 배경에 그림자가 없어야 함
- 빛 반사 없어야 함 (안경 렌즈, 피부, 이마)
- 원래의 피부톤을 정확하게 표현
- 적목 현상 없어야 함
- 조명이 적정하여야 하며 초점이 명확해야 함

### 2-5. 의상
- 흰색 의상 지양 (배경과 구분 안 될 경우)
- 연한색 의상은 배경과 구분되면 사용 가능
- 제복 착용 불가 (여권)
- 모자, 머플러 착용 불가
- 종교적 머리덮개는 허용 (얼굴 전체 이마~턱 노출 조건)
- 목을 덮는 옷/스카프는 얼굴 윤곽 가리지 않으면 가능

### 2-6. 안경 및 액세서리
- 안경: 일상 항상 착용자에게만 허용
- 렌즈 반사 불가
- 안경테가 눈을 가리면 불가
- 선글라스, 색안경, 컬러렌즈 불가
- 귀걸이 등 장신구: 빛 반사 또는 얼굴 윤곽 가림 시 불가

### 2-7. 머리카락
- 앞머리로 눈썹/눈을 가리면 불가
- 옆머리로 귀를 가리면 불가
- 두 귀 노출 권장 (얼굴 윤곽 뚜렷)
- 가발은 일상 항상 착용자에게만 허용

## 3. Gemini Live 촬영 전 환경 체크 가이드

### 3-1. 조명 체크리스트

**[필수 확인]**
- [ ] 주 광원이 피사체 정면 또는 정면 약간 위에 있는가?
- [ ] 얼굴 양쪽에 균일한 밝기가 확보되었는가?
- [ ] 코 그림자가 생기지 않는가?
- [ ] 턱 아래 그림자가 과도하지 않은가?
- [ ] 이마나 코에 빛 반점(하이라이트)이 없는가?
- [ ] 배경에 인물 그림자가 투영되지 않는가?

**[조명 셋업 권장]**
- **이상적**: 소프트박스 또는 링라이트 정면 배치 + 좌우 보조등으로 그림자 제거
- **간이 환경**: 큰 창문을 정면에 두고, 반대편에 흰색 반사판(흰 종이/스티로폼)
- **금지**: 직사광선, 형광등 단독(녹색 캐스트), 역광, 머리 위 직하향 조명

**[프로 노하우: 조명 비율]**
- 증명사진은 1:1 ~ 1:1.5 조명비가 이상적
- 한쪽이 지나치게 밝으면 반대쪽에 리플렉터 추가
- 안경 착용자: 조명 각도를 약 15도 위로 올려 렌즈 반사 방지
- 이마 번들거림: 파우더 또는 기름종이로 사전 제거

### 3-2. 배경 체크리스트

**[필수 확인]**
- [ ] 배경이 균일한 흰색 또는 단색인가?
- [ ] 배경에 무늬, 그림자, 얼룩이 없는가?
- [ ] 피사체와 배경 사이 거리가 충분한가? (최소 50cm 이상 권장)
- [ ] 배경 조명이 균일한가? (코너 어두움 없이)

**[프로 노하우: 배경]**
- 피사체와 배경 거리가 멀수록 배경 그림자 제거 용이
- 배경지(롤 페이퍼) 사용 시 주름 없이 당겨 설치
- 흰 벽 사용 시: 벽 재질에 따른 그림자 확인 필수
- 배경 밝기: 피사체 얼굴보다 약간 밝게 (0.5~1스톱 오버)

### 3-3. 카메라/기기 체크리스트

**[필수 확인]**
- [ ] 카메라 렌즈가 깨끗한가? (스마트폰 전/후면)
- [ ] 카메라 높이가 피사체 눈높이와 동일한가?
- [ ] 촬영 거리가 적절한가? (왜곡 방지를 위해 1~1.5m 권장)
- [ ] 해상도 설정이 최대인가?
- [ ] 플래시 OFF 상태인가? (외부 조명 사용)
- [ ] HDR/뷰티모드/필터 OFF 상태인가?

**[프로 노하우: 촬영 기기]**
- 스마트폰 셀카(전면 카메라)는 왜곡 심하므로 후면 카메라 + 삼각대 권장
- 인물 왜곡 최소화: 50mm 환산 초점거리 이상 권장
- 타이머 촬영 또는 리모컨으로 흔들림 방지
- RAW 촬영 가능하면 RAW로 (후보정 여유 확보)

### 3-4. 피사체 준비 체크리스트

**[필수 확인]**
- [ ] 얼굴에 머리카락이 걸리지 않는가?
- [ ] 눈썹이 완전히 보이는가?
- [ ] 양쪽 귀가 노출되어 있는가?
- [ ] 안경 착용 시: 렌즈가 깨끗하고 반사 없는가?
- [ ] 의상이 배경색과 구분되는가?
- [ ] 이마 번들거림은 없는가?
- [ ] 머리카락이 정돈되어 있는가?
- [ ] 칼라/넥타이/목걸이 등이 단정한가?

**[프로 노하우: 피사체 준비]**
- 촬영 30분 전 세안 권장 (피부 유분기 제거)
- 남성: 면도 직후보다 2~3시간 후가 피부색 안정적
- 여성: 매트 파운데이션으로 T존 번들거림 방지
- 의상: 네이비, 차콜그레이, 검정 정장이 가장 무난
- 라운드넥/V넥 무지 의상도 깔끔 (취업용)

## 4. Gemini Live 실시간 촬영 코칭 스크립트

### 4-1. 포즈 교정 음성 가이드

**[정면 정렬]**
- "고개를 살짝 왼쪽/오른쪽으로 돌려주세요" (정면 미정렬 시)
- "턱을 살짝 당겨주세요" (턱이 올라간 경우)
- "턱을 살짝 올려주세요" (턱이 내려간 경우)
- "어깨를 수평으로 맞춰주세요" (어깨 기울기 감지 시)
- "고개가 약간 기울어져 있어요, 바로 세워주세요"

**[표정 가이드]**
- "자연스럽게 입을 다물어주세요"
- "눈을 자연스럽게 떠주세요, 크게 뜨지 않아도 됩니다"
- "살짝 미소를 머금되 치아는 보이지 않게 해주세요" (취업용)
- "편안한 표정 유지해주세요, 잘하고 계세요"

**[시선 가이드]**
- "카메라 렌즈를 정면으로 바라봐주세요"
- "시선이 약간 위/아래를 향하고 있어요, 렌즈 중앙을 봐주세요"
- "눈동자가 한쪽으로 치우쳐 있어요, 정면 주시 부탁드립니다"

### 4-2. 환경 교정 음성 가이드

**[조명 교정]**
- "왼쪽 얼굴에 그림자가 생기고 있어요. 오른쪽으로 조금 이동하시거나 왼쪽 조명을 보강해주세요"
- "이마에 빛 반점이 있어요. 조명 각도를 살짝 올려주세요"
- "안경에 빛이 반사되고 있어요. 고개를 아주 살짝 숙여주세요"
- "배경에 그림자가 보여요. 배경에서 조금 떨어져 주세요"

**[배경 교정]**
- "배경 왼쪽 모서리가 어두워요. 배경 조명을 확인해주세요"
- "배경에 물체가 보여요. 프레임 밖으로 치워주세요"

## 5. 촬영 후 QC 검증 기준 (Gemini API)

### 5-1. 기술 규격 검증

**[자동 측정 항목]**
| 검증 항목 | 합격 기준 | 불합격 조건 |
|-----------|-----------|-------------|
| 이미지 크기 | 413×531px 이상 | 미달 시 불합격 |
| 해상도 | 300 DPI 이상 | 미달 시 경고 |
| 머리 비율 | 이미지 세로 대비 70~80% | 범위 이탈 시 불합격 |
| 얼굴 중앙 정렬 | 좌우 편차 5% 이내 | 초과 시 불합격 |
| 배경 균일도 | RGB 편차 ±10 이내 | 초과 시 경고 |
| 배경색 | R/G/B 각 230 이상 (흰색 계열) | 미달 시 불합격 (여권) |

### 5-2. 외관 검증 (Gemini 멀티모달 분석)

**[얼굴 방향]**
- 정면 응시 여부 (좌우 회전 ±5도 이내)
- 상하 기울기 (±5도 이내)
- 어깨 수평 (기울기 ±3도 이내)

**[표정]**
- 입 다문 상태 확인
- 치아 노출 여부 (여권/신분증은 불합격)
- 자연스러운 표정 여부
- 눈 뜬 상태 확인

**[가림 요소]**
- 머리카락이 눈썹/눈/귀를 가리는지
- 안경 렌즈 반사 여부
- 안경테가 눈을 가리는지
- 그림자가 얼굴에 있는지

**[의상/배경]**
- 의상과 배경의 구분 가능 여부
- 배경에 사물/타인 노출 여부

### 5-3. 원본 vs 생성물 유사도 검증

**[Imagen 3.0 생성물 QC — Gemini 비교 분석]**

Gemini에 원본 촬영 사진과 Imagen 3.0 생성 결과물을 동시에 전달하여 비교:

| 검증 항목 | 설명 | 임계값 |
|-----------|------|--------|
| 얼굴 구조 | 눈/코/입 비율 및 위치 일치도 | 유사도 90% 이상 |
| 피부톤 | 원본 대비 색온도/채도 일관성 | 색차 ΔE ≤ 5 |
| 전체 인상 | 원본 인물임을 즉시 식별 가능한지 | Gemini 판정: "동일 인물" |
| 헤어 스타일 | 머리카락 형태/볼륨 유지 여부 | 주요 형태 유지 |
| 안경/액세서리 | 원본에 있던 것 유지, 없던 것 추가 안 됨 | 완전 일치 |

**[QC 판정 로직]**
```
IF 기술규격_전항목_통과 AND 외관검증_전항목_통과 AND 유사도_임계값_통과:
    → 출고 승인 ✅
ELIF 유사도_미달:
    → Imagen 3.0 재생성 요청 (최대 3회 재시도)
ELIF 기술규격_미달 OR 외관검증_미달:
    → 재촬영 요청 (구체적 수정사항 안내)
```

## 6. 용도별 Gemini Live 대응 분기

### 6-1. 용도 선택에 따른 설정 차이

| 설정 항목 | 여권/비자 | 주민등록증/면허증 | 이력서/취업용 | 학생증/사원증 |
|-----------|-----------|-------------------|---------------|---------------|
| 엄격도 | ★★★★★ | ★★★★☆ | ★★★☆☆ | ★★☆☆☆ |
| 배경색 | 흰색만 | 흰색 권장 | 흰/회/연파랑 | 기관별 상이 |
| 표정 | 무표정(입 다문) | 무표정(입 다문) | 자연스러운 미소 OK | 자연스러운 미소 OK |
| 의상 제한 | 흰색 지양 | 흰색 지양 | 유연 (정장 권장) | 유연 |
| AI 생성 허용 | ❌ 불가 | △ 주의 | ⭕ 허용 | ⭕ 허용 |
| 보정 허용 | ❌ 불가 | △ 최소 | ⭕ 적절 범위 | ⭕ 적절 범위 |

### 6-2. 여권 사진 AI 생성 관련 주의사항

> ⚠️ **중요**: 2024년 기준 한국 여권 사진은 AI를 활용한 편집·가공·합성·창조 제작물 사용이 불가합니다.
> Imagen 3.0으로 생성된 증명사진은 여권 용도로 사용할 수 없으며, 이력서/취업용/사원증 등에만 사용 가능합니다.
> Gemini Live는 여권 용도 선택 시 반드시 이 제한을 사용자에게 고지해야 합니다.

## 7. 촬영 노하우 (스튜디오 10년 경험 기반)

### 7-1. 얼굴형별 촬영 팁

**[둥근 얼굴]**
- 카메라 각도를 눈높이보다 살짝 위에서 (얼굴이 갸름해 보임)
- 턱을 약간 당기면 페이스 라인 강조
- 조명: 좌우 사이드 라이트 살짝 강하게 (입체감)

**[긴 얼굴]**
- 카메라 정확히 눈높이
- 턱을 내리지 말 것 (더 길어 보임)
- 조명: 정면 플랫 라이트로 길이감 완화

**[사각 얼굴]**
- 정면보다 아주 약간(5도) 틀면 부드러워짐 (취업용만)
- 조명: 부드러운 소프트 라이트로 턱선 그림자 최소화

### 7-2. 피부 타입별 조명 조절

**[지성 피부]**
- 파우더 필수, 촬영 직전에도 T존 재터치
- 조명 파워 살짝 낮추어 번들거림 방지
- 디퓨저(확산판) 사용 권장

**[건성 피부]**
- 보습 후 촬영 (과도하면 광택)
- 조명 파워 약간 높여도 OK

**[다크 스킨톤]**
- 조명 강도 높일 것 (노출 +0.5~1EV)
- 배경과 피부톤 대비 확인

### 7-3. 안경 착용자 촬영 노하우

- 안경 렌즈 반사 제거가 가장 까다로운 포인트
- **방법 1**: 조명을 피사체 위 45도에 배치, 카메라는 약간 아래에서 올려 찍기
- **방법 2**: 안경을 코끝 쪽으로 아주 살짝 내려 착용 (렌즈 각도 변경)
- **방법 3**: 편광 필터 사용 (전문 장비)
- 두꺼운 뿔테: 여권용에서는 지양 권고 (ICAO 기준 위변장 오인 우려)

### 7-4. 영유아 촬영 노하우

- 유아는 정면 주시 + 눈 뜬 상태가 핵심
- 카메라 뒤에서 소리 나는 장난감으로 시선 유도
- 3세 이하: 입 벌려 치아 살짝 보이는 것 허용
- 신생아: 흰색 이불에 눕혀 촬영 가능
- 의자/장난감/보호자가 프레임에 노출되면 불가
- 자연광 환경이 영유아에게 가장 편안 (스트로보 깜빡임 주의)

### 7-5. 흔한 반려 사유 TOP 10

1. 배경이 흰색이 아님 (회색 벽, 무늬 배경)
2. 얼굴/배경에 그림자
3. 과도한 포토샵 보정 (피부 뭉개짐)
4. 머리카락이 눈썹/눈/귀 가림
5. 안경 렌즈 반사
6. 흰색 의상으로 배경과 구분 불가
7. 해상도 부족 (픽셀 깨짐)
8. 얼굴 크기가 규격 범위 이탈
9. 입 벌림 또는 치아 노출
10. 정면이 아닌 측면 포즈

## 8. 디지털 파일 출력 규격 정리

### 8-1. 용도별 디지털 파일 사양

| 용도 | 픽셀 (WxH) | 비율 | 포맷 | 최대 용량 |
|------|-------------|------|------|-----------|
| 여권 온라인 | 413×531 | 약 3.5:4.5 | JPG | - |
| 운전면허 온라인 | 350×450 | 약 3.5:4.5 | JPG | 200KB |
| 이력서 (사람인) | 기업별 상이 | 3:4 또는 1:1 | JPG/PNG | 기업별 상이 |
| 범용 고해상도 | 1050×1350 | 3.5:4.5 | JPG/PNG | - |

### 8-2. Imagen 3.0 출력 시 권장 설정

- 최종 출력 해상도: 최소 413×531px, 권장 1050×1350px
- 색공간: sRGB
- 포맷: PNG (무손실) → 용도별 JPG 변환
- 배경: 순백 (RGB 255,255,255)
- 얼굴 크기 비율: 이미지 세로의 70~80%
