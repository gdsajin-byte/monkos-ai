## 1. 아키텍처: n8n 기반 자동화 파이프라인

### 왜 n8n인가

| 비교 | n8n (셀프호스트) | Buffer (무료) | Hootsuite |
|------|-----------------|---------------|-----------|
| 비용 | **무료** (Docker) | 무료 (3채널, 10포스트/채널) | $99/월~ |
| AI 연동 | Gemini/Claude API 직접 연결 | 제한적 AI assistant | 제한적 |
| 커스텀 로직 | 무제한 (노드 기반) | 불가 | 불가 |
| 셀프호스트 | 가능 (기존 인프라 활용) | 불가 | 불가 |
| 멀티플랫폼 포스팅 | X, Instagram, LINE, TikTok 모두 가능 | 지원 | 지원 |
| 스케줄링 | cron 기반 무제한 | 10개/채널 | 무제한 |

**결론: n8n 셀프호스트가 압도적.** 이미 Tailscale VPN + GCS 인프라 보유 → Docker 컨테이너 하나 추가로 끝.

### 설치 (5분)

```bash
# 기존 서버에 Docker로 n8n 추가
docker volume create n8n_data
docker run -d --restart always \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n
```

Tailscale 통해 어디서든 접근 가능. 별도 도메인/SSL 불필요.

## 2. 자동화 파이프라인 설계

### 전체 흐름

```
[콘텐츠 시드]
    │
    ▼
[Gemini 2.0 — 콘텐츠 생성]
    │
    ├──→ X용 텍스트 (280자 이내)
    ├──→ Instagram용 캡션 + 해시태그
    ├──→ LINE VOOM용 일본어 텍스트
    └──→ TikTok/Reels용 스크립트
    │
    ▼
[n8n — 플랫폼별 포맷 변환 + 예약 게시]
    │
    ▼
[Google Sheets — 성과 로깅]
```

### 파이프라인 A: 일일 자동 포스팅

**트리거**: 매일 오전 7시 (JST) / 오후 8시 (JST)
**프로세스**:

1. **Google Sheets에서 콘텐츠 시드 가져오기**
   - 주 1회 30분 투자 → 7일치 시드(주제/키워드/이미지) 일괄 입력
   - 시드 예시: "일본 취활 증명사진 규격 4x3cm", "비자사진 반려 사유 TOP5"

2. **Gemini 2.0로 플랫폼별 콘텐츠 생성**
   ```
   시스템 프롬프트:
   "증명사진 전문 서비스 monk.kr의 SNS 콘텐츠를 작성해라.
   톤: 전문적이면서 친근. 10년 사진관 운영 경험 기반.
   X: 280자 이내, 일본어, 임팩트 있는 한 줄.
   Instagram: 3~5줄 캡션 + 해시태그 10개.
   LINE VOOM: 일본어, 정중체, 실용정보 중심."
   ```

3. **n8n 노드로 각 플랫폼 동시 게시**
   - X: Twitter API v2 → 텍스트 + 이미지
   - Instagram: Graph API → 이미지 + 캡션
   - LINE: Messaging API → VOOM 포스트
   - TikTok: (이미지 기반 슬라이드쇼 자동 생성)

4. **결과 Google Sheets에 자동 로깅**
   - 게시 시간, 플랫폼, 콘텐츠 ID, 임프레션, 인게이지먼트

### 파이프라인 B: 트렌드 반응형 (반자동)

**트리거**: Google Trends API (일본 지역) 모니터링
**프로세스**:

1. 就活, 証明写真, ビザ, パスポート 관련 키워드 급상승 감지
2. Gemini가 트렌드에 맞는 콘텐츠 초안 생성
3. **작가님 Slack/텔레그램으로 알림 → 승인 버튼 클릭 → 게시**

이건 완전 자동이 아니라 "1클릭 승인" 방식. 품질 관리 + 속도 균형.

### 파이프라인 C: UGC(사용자 생성 콘텐츠) 자동 수집

**트리거**: monk.kr 서비스 이용 완료 시
**프로세스**:

1. CS 챗봇이 사용 완료 고객에게 "후기 남기기" 제안
2. 후기 텍스트 + 별점 → Firestore에 저장
3. n8n이 별점 4점 이상 후기 자동 수집 → SNS용 인용 카드 생성
4. 주 2~3회 "고객 후기" 포스트로 자동 게시

## 3. 콘텐츠 자동 멀티플라이어

**1개 소스 → 7개 아웃풋** 자동 변환:

```
[원본: X 쓰레드 (일본어)]
    │
    ├──→ Instagram 캐러셀 (이미지 자동 생성)
    │     └ n8n + Gemini: 각 트윗을 카드 이미지로 변환
    │
    ├──→ LINE VOOM (일본어 정중체로 자동 변환)
    │     └ Gemini: 캐주얼 → 정중체 톤 변환
    │
    ├──→ TikTok/Reels 스크립트 (자동 생성)
    │     └ Gemini: 쓰레드 → 30초 나레이션 스크립트
    │
    ├──→ 블로그 포스트 (SEO용)
    │     └ Gemini: 쓰레드 → 800자 블로그 아티클
    │
    ├──→ 영어 버전 (글로벌 X 계정)
    │     └ Gemini: 일→영 번역 + 문화 로컬라이제이션
    │
    └──→ Google Sheets 아카이브 (재활용 풀)
```

**핵심: Gemini 2.0 비용이 극히 낮으므로** 이 모든 변환을 API 호출로 처리해도 월 수천원 수준.

## 5. 도구별 세팅 가이드

### 5-1. n8n 워크플로우 세팅

**필요 노드 목록:**
- Schedule Trigger (cron)
- Google Sheets (콘텐츠 시드 + 성과 로깅)
- HTTP Request (Gemini API 호출)
- Twitter/X (게시)
- Facebook Graph API (Instagram 게시)
- LINE Messaging API (VOOM 게시)
- Slack/Telegram (승인 알림)
- Code (JavaScript — 플랫폼별 포맷 변환)

**주의: n8n 셀프호스트 버전은 모든 노드 무료.** 클라우드 버전은 유료.

### 5-2. X (Twitter) API 설정

```
1. developer.twitter.com → Free tier 신청 (월 1,500 트윗 게시 가능)
2. App 생성 → API Key, Secret, Bearer Token 발급
3. OAuth 2.0 User Context 설정 (게시 권한)
4. n8n Twitter 노드에 인증 정보 연결
```

Free tier: 월 1,500 트윗 게시 + 읽기 가능. MONKOS 규모엔 충분.

### 5-3. Instagram Graph API

```
1. Facebook Developer 계정 → 앱 생성
2. Instagram Business 계정 연결
3. Graph API로 이미지 + 캡션 게시
4. n8n HTTP Request 노드로 호출
```

### 5-4. LINE Messaging API

```
1. LINE Developers 콘솔 → Provider 생성
2. Messaging API 채널 생성
3. Channel Access Token 발급
4. n8n HTTP Request 노드로 VOOM 포스팅
```

### 5-5. Buffer (백업 + 수동 관리용)

n8n이 메인이지만, **Buffer 무료 플랜을 백업으로 병행** 권장:
- 3채널 무료 (X + Instagram + LINE 중 선택)
- 채널당 10개 예약 가능
- 모바일앱 지원 → 외출 중 긴급 포스팅 가능
- AI Assistant 무제한 (캡션 생성 보조)
