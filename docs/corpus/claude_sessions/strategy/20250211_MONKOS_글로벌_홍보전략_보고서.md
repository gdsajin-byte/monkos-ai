## 1. 시장 환경 분석

### 경쟁 구도

글로벌 AI 증명사진 시장은 이미 다수 플레이어가 존재하나, 대부분 **"사진 크롭 + 배경 제거"** 수준에 머물러 있음.

| 경쟁사 | 특징 | 약점 |
|--------|------|------|
| AI Passport Photo | 웹 기반, 96개국 지원 | 무료 버전 없음, CS 부재 |
| PhotoGov | 900+ 문서 타입, 프라이버시 강조 | 가격 높음, 모바일 UX 부족 |
| PassportMaker | AI 배경/의상 변경 | 품질 불안정, ICAO 규격 미달 다수 |
| 이력서카메라 (リクルート) | 일본 시장 점유, 무료 | 기능 제한적, 비자용 미지원 |
| PhotoDirector (CyberLink) | 범용 편집앱, 증명사진 기능 추가 | 전문성 부족 |

### MONKOS 차별점

- **10년 사진관 운영 노하우** + AI = 프로급 품질 보장
- **실시간 딥페이크 방지** 기술 (신뢰성)
- **Gemini 2.0 기반 CS 챗봇** — 법적 규격 지식 + 자가 학습
- **비자/여권 규격 자동 검증** (경쟁사 2/3~3/4이 ICAO 검증 미통과)
- **향후 비자대행 연결** 가능한 유일한 플랫폼

## 2. 채널별 전략

### 2-1. LINE 미니앱 (일본 시장 — 최우선)

**왜 LINE이 핵심인가:**
- 일본 인구 80%+ 사용 (9,500만 MAU), 90%가 매일 접속
- 앱스토어 다운로드 없이 즉시 실행 → 전환율 극대화
- LINE Pay 연동으로 결제 마찰 제로
- 메시지 오픈율 60%+ (이메일/SNS 대비 압도적)

**실행 계획:**

| 단계 | 시기 | 액션 |
|------|------|------|
| Phase 1 | 즉시 | 무료 서비스 론칭, LINE Official Account 개설 |
| Phase 2 | 결제 승인 후 | LINE Pay 연동 유료 전환 |
| Phase 3 | 3~4월 | 취활(就活) 시즌 집중 프로모션 |
| Phase 4 | 4월~ | 리치메뉴에 "비자용 사진" 카테고리 추가 |

**콘텐츠 전략:**
- **취활 시즌 공략 (3~4월)**: "就活証明写真、スマホで3秒" 메시지
- **쿠폰 활용**: 첫 사진 무료 → LINE 친구 추가 유도 (L'Occitane 사례: 디지털 멤버십 + 무료 샘플로 폭발적 팔로워 확보)
- **리치메뉴 구성**: 증명사진 촬영 / 규격 확인 / CS 챗봇 / 쿠폰
- **숏폼 비디오**: LINE VOOM에 Before/After 3초 변환 영상

**핵심 KPI:** LINE 친구 수, 미니앱 실행수, 유료 전환율

### 2-2. X (Twitter) — 글로벌 바이럴 엔진

**왜 X인가:**
- 비용 제로로 바이럴 가능한 유일한 플랫폼
- 실시간성 → 트렌드 탑승 용이
- AI/테크 커뮤니티 활성화 → 초기 얼리어답터 확보
- 일본 X 사용자 6,700만+ (LINE 다음 2위)

**알고리즘 공략 포인트:**
- 게시 후 **첫 5~10분** 인게이지먼트가 노출 결정
- 이미지/영상 포함 게시물이 텍스트 대비 2배 CTR
- 쓰레드(4~8개)는 체류시간 증가 → 알고리즘 부스트
- X Premium 구독 시 오가닉 도달률 상승 (검토 필요)

**콘텐츠 필러 (80/20 법칙):**

**① 빌드 스토리 (40%)** — 개발 과정 공개
- "AI 증명사진 앱을 만들고 있습니다. Day 1~" 시리즈
- 사진관 10년 운영 → AI 전환 스토리 (공감 유발)
- 실시간 딥페이크 방지 기술 시연 영상
- "사진관 사장이 AI로 자기 사업을 디스럽트한 이야기" 쓰레드

**② 실용 콘텐츠 (30%)** — 공유 유발
- "각국 비자 증명사진 규격 총정리" 인포그래픽 쓰레드
- "증명사진 반려되는 5가지 이유" (Before/After 이미지)
- "취활 증명사진, 8,300엔 사진관 vs 모바일 3초" 비교
- 국가별 증명사진 규격 차이 시각화

**③ 비하인드/퍼스널 (20%)** — 팬덤 형성
- 기타리스트 20년 → 사진관 → AI CEO 여정
- "15시간 코딩 세션" 실시간 스냅
- AI 에이전트(용아/쌍아/막내) 소개 및 역할 분담 이야기

**일본어 계정 별도 운영 권장:**
- @monkos_jp (일본어) + @monkos_global (영어)
- 일본어 계정: 就活 관련 키워드, 証明写真 해시태그 집중

**포스팅 빈도:** 초기 하루 3~5회 (일/영 합산)
**최적 시간대:** 
- 일본: 오전 7~8시, 점심 12~13시, 저녁 20~21시 (JST)
- 글로벌: 오전 9시 EST, 정오 12시 EST

### Segment A: 일본 취활생 (最優先)

- **시기**: 3~5월 피크 (1~3월 촬영)

### Segment B: 재일 외국인 노동자

- **페인포인트**: 언어 장벽, 비자 규격 사진 반려

### Segment C: 글로벌 여행자/유학생

- **페인포인트**: 급하게 비자사진 필요, 현지 사진관 접근 어려움
- **메시지**: "Passport photo in 3 seconds, accepted worldwide"

### Segment D: 한국 내 외국인 노동자 (중기)

- **페인포인트**: 비자 연장/변경 시 규격 사진 필요

## 5. 제로 버짓 바이럴 전술

### 5-1. "Audience Siphoning" (X)
대형 계정(AI/스타트업/취활 관련) 게시물에 **가치 있는 리플라이**를 꾸준히 달아 팔로워 유입 유도. 게시 후 15분 내 리플라이가 핵심.

### 5-2. 쓰레드 바이럴 공식
```
Hook: 대담한 주장 또는 질문
→ 6~15개 스텝별 가치 전달
→ 숏 문장 + 줄바꿈 + 이모지
→ CTA: "도움이 됐다면 RT + 팔로우"
```
예시: "증명사진에 연간 300억원을 쓰는 일본. 근데 이 중 80%는 불필요한 지출입니다 🧵"

### 5-3. 콘텐츠 멀티플라이어
하나의 콘텐츠를 7가지로 재활용:
1. X 쓰레드 → 2. Instagram 캐러셀 → 3. TikTok 숏폼 → 4. LINE VOOM → 5. 블로그 포스트 (SEO) → 6. Reddit 포스트 → 7. YouTube Shorts

### 5-4. 시즈널 해킹
| 시기 | 이벤트 | 콘텐츠 |
|------|--------|--------|
| 3~5월 | 일본 취활 시즌 | 就活写真 집중 |
| 4~6월 | 여름 여행 준비 | 여권사진 수요 |
| 9~10월 | 후기 취활/인턴 | 証明写真 리마인드 |
| 연중 | 비자 갱신 | 외국인 노동자 타겟 |

## 7. 핵심 권고사항

1. **LINE 미니앱이 1순위.** 일본 시장은 LINE이 곧 인프라. X/Instagram은 LINE으로 유입시키는 퍼널 역할.

2. **"사진관 출신 AI CEO" 스토리를 무기로.** 순수 테크 회사와의 차별점은 10년 현장 경험. 이걸 콘텐츠화하면 신뢰와 바이럴을 동시에 잡음.

3. **무료 → 유료 전환 퍼널에 CS 챗봇 배치.** 무료 사진 촬영 후 "비자 규격 확인" 챗봇 대화 → 유료 고품질 다운로드 자연스러운 연결.

4. **다국어는 Phase 2.** 론칭 초기는 일본어 + 영어에 집중. 베트남어/중국어는 유저 데이터 확인 후 추가.

5. **매일 30분 X 인게이지먼트.** 초기 성장은 콘텐츠 퀄리티보다 **꾸준한 커뮤니티 참여**가 결정. 대형 계정 리플라이 → 팔로워 유입 → 콘텐츠 노출 선순환.
