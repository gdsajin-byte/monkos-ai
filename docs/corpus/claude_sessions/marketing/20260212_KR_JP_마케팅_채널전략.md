## 1. 한국 (KR) 마케팅 채널

### 2트랙 구조

```
[로컬 트랙]                         [전국구 트랙]
당근 + 네이버 플레이스               Instagram + YouTube Shorts + TikTok
       ↓                                      ↓
    monk.kr                           직접 타겟팅 (Z세대/취준생)
       ↓
   monkos.ai 전환
```

### 로컬 트랙
| 채널 | 역할 | 비고 |
|------|------|------|
| 당근마켓 | 지역 기반 유입 | 전환율 양호, 사진관 카테고리 활용 |
| 네이버 플레이스 | 검색 노출 | monk.kr 사진관 등록 → monkos.ai 전환 |

### 전국구 트랙
| 채널 | 역할 | 비고 |
|------|------|------|
| Instagram | 비주얼 쇼케이스 | 비포/애프터, 리얼 후기 |
| YouTube Shorts | 바이럴 | 촬영 과정 15~60초 |
| TikTok | Z세대 직접 도달 | 챌린지/밈 활용 |

### 키워드 트랙
| 채널 | 역할 | 비고 |
|------|------|------|
| 네이버 블로그 | 키워드 선점 | "AI 증명사진", "여권사진 셀프", "이력서사진 무료" |
| 체험단 (필요시) | 리뷰 확보 | 초기 신뢰도 구축 |

### 한국 특이사항
- X(트위터) 한국 침투율 14% → 비효율, 제외
- 카카오 채널은 CRM/리텐션 용도로 후순위 도입 검토

## 2. 일본 (JP) 마케팅 채널

### 2트랙 구조

```
[ローカルトラック]                     [全国トラック]
ジモティー + Google MEO              Instagram + X + TikTok
       ↓                                      ↓
    monk.kr                           直接ターゲティング (Z世代/就活生)
       ↓
   monkos.ai 転換
```

### 로컬 트랙
| 채널 | 역할 | 비고 |
|------|------|------|
| ジモティー | 지역 기반 유입 | 일본판 당근마켓, 무료 게시 |
| Google ビジネスプロフィール (MEO) | 검색 노출 | "証明写真" + 지역명 검색 대응 |

### 전국구 트랙
| 채널 | 역할 | 비고 |
|------|------|------|
| Instagram | 비주얼 쇼케이스 | Z세대 71.6% 사용, 사진 서비스 필수 |
| X (Twitter) | 바이럴 + 정보 확산 | 일본 7,090만 유저, 필수 채널 |
| TikTok | Z세대 직접 도달 | 就活 콘텐츠 활성화 중 |

### 키워드 트랙
| 채널 | 역할 | 비고 |
|------|------|------|
| SEO 블로그 | Google 검색 점령 | "証明写真 アプリ", "パスポート写真 無料", "就活写真 AI" |

### 일본 특이사항
- X 필수 (한국과 반대) — 일본 SNS 1위 채널
- 네이버 플레이스 → Google MEO로 대체
- LINE: 공식 계정으로 CRM/리텐션 (마케팅보다 CS 채널)

## 4. 공통 콘텐츠 전략

### 콘텐츠 유형
1. **비포/애프터**: 셀카 → AI 생성 결과 비교 (가장 강력한 바이럴)
2. **촬영 과정 영상**: AI 코칭 실시간 화면 캡처 (차별점 시각화)
3. **규격 가이드**: 여권/비자/이력서 사진 규격 정보 (SEO 유입)
4. **사용자 후기**: 실제 여권/비자 통과 사례 (신뢰도)

### 키워드 매트릭스 (초기 선점 대상)

| 한국 | 일본 |
|------|------|
| AI 증명사진 | AI証明写真 |
| 여권사진 셀프 | パスポート写真 アプリ |
| 이력서사진 무료 | 就活写真 無料 |
| 증명사진 앱 | 証明写真 スマホ |
| 여권사진 규격 | パスポート写真 規格 |
