## 4. MONKOS 차별점

```
경쟁사 전부:  [셀카 업로드] → [AI 후처리] → [결과물]
                (수동)         (블랙박스)

MONKOS:      [AI 실시간 코칭] → [최적 셀카] → [I2I 재생성] → [결과물]
              (능동 가이드)     (품질 보장)    (Imagen 4.0)
```

### 핵심 차별화
1. **실시간 AI 코칭**: 촬영 전에 자세/표정/조명을 교정 (Gemini Live)
2. **I2I 재생성**: 단순 필터가 아닌 Image-to-Image 재생성 (Imagen 4.0)
3. **규격 자동 적용**: 국가별·용도별 규격 자동 매칭
4. **무료 모델**: 기본 무료 → 크레딧 과금 (진입 장벽 제로)

### 약점 (정직한 평가)
1. SynthID 워터마크 (Imagen 생성물 공통)
2. 미국 2026.1월부터 AI 편집 여권사진 즉시 거부 정책
3. 바이럴/리뷰 아직 부재 (서비스 초기)
