## 2. Phase별 출현 로드맵

### Phase 1: 정적 이미지 SNS (난이도 ★★☆☆☆) — 즉시 가능

```
[Imagen 4.0 생성] → [일관된 페르소나 이미지] → [Instagram 포스팅]
```

- 모델별 인스타 계정 운영, 일상/패션 이미지
- Imagen 4.0 I2I 기반 80~90% 일관성 확보 가능
- "AI 모델" 컨셉이 약간의 변주 허용
- 모델당 기본 세트 20~30장 = 1~2일

### Phase 2: 캐러셀/슬라이드 숏폼 (난이도 ★★☆☆☆) — 즉시 가능

```
[기본 이미지 세트] → [캡컷 템플릿] → [BGM + 전환효과] → [릴스/숏폼]
```

- 정적 이미지 → 슬라이드쇼/캐러셀 릴스화
- 현재 버추얼 인플루언서 대다수 방식 (이마, 로지 등)
- 15초 숏폼으로 전 채널 커버

### Phase 3: AI 애니메이션 영상 (난이도 ★★★★☆) — 2026 하반기

```
[정적 이미지] → [AI 영상 생성] → [립싱크/표정] → [숏폼 영상]
```

| 도구 | 수준 (2026.02) | 비고 |
|------|----------------|------|
| Runway Gen-3/4 | 3~10초 영상 | 얼굴 일관성 불안정 |
| Pika 2.0 | 5초 립싱크 | 품질 편차 큼 |
| Google Veo 2 | 고품질 영상 | Vertex AI 연동 가능성 |
| Kling AI | 5~10초, 얼굴 유지 양호 | 중국, 라이선스 주의 |
| HeyGen | 아바타 영상 | 립싱크 최고, 월 $29~ |

- 5090 서버 도입 시 로컬 SVD/AnimateDiff 가능
- 핵심 과제: 얼굴 일관성(ID preservation) — MONKOS 기존 노하우 활용

### Phase 4: 실시간 라이브 (난이도 ★★★★★) — 2027년 이후

- 일본 VTuber 시장 $6B+ (수요 검증됨)
- HeyGen Interactive Avatar, D-ID 등 시도 중
- 아직 "진짜 사람" 수준 미달

## 7. 핵심 원칙

> **"정교한 타이밍에 폭발적으로 쏟아낼 수 있도록"**
>
> 상반기는 참는 시간이 아니라 장전하는 시간.
> 이미지 자산 = 영상의 원본 소스 (I2V의 I).
> 100장의 정교한 이미지 → 하반기 300개 영상으로 변환 가능.
