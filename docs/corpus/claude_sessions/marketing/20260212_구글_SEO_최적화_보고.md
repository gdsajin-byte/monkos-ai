## 2. 구현 완료 항목 (커밋 67cf65f)

### 2-1. 메타 태그 + OG 태그 (3개 서비스)

**Portal**: 일본어 title + description + OG + Twitter Card
**idphoto-jp**: 일본어 키워드 최적화 (パスポート, 履歴書, 就活)
**idphoto-kr**: 한국어 키워드 최적화 (여권, 비자, 이력서)

### 2-2. robots.txt + sitemap.xml

- robots.txt: `Allow: /`, `Disallow: /api/`
- sitemap.xml: 5페이지, hreflang 상호참조, lastmod 포함

### 2-3. 폰트 로딩 최적화

- `@import url(...)` → `<link rel="stylesheet">` + `<link rel="preconnect">`
- 렌더링 블로킹 제거 → LCP 개선

### 2-4. 구조화 데이터 (JSON-LD)

- Schema: `WebApplication` (PhotographyApplication)
- offers, provider, inLanguage 포함

### 2-5. canonical + hreflang

- ja / ko / x-default 3방향 상호 참조
- 중복 콘텐츠 방지 + 다국어 검색 최적화
