```
[원본 제작]
  비포/애프터 이미지 → Instagram 캐러셀 (메인)
                     → X 이미지 트윗 (일본)

  촬영 과정 영상     → TikTok 세로 (메인)

[원칙]
  1장의 콘텐츠 → 3개 채널에 최적화 리포맷
  동일 콘텐츠 그대로 복붙 ❌ → 채널별 톤 조정 ⭕
```

## 6. X (일본) 상세 운영

### 최적 빈도: 2~3회/일

| 시간대 | 내용 | 이유 |
|--------|------|------|
| 오전 7~8시 | 정보성 (규격 팁, 체크리스트) | 통근 시간 스크롤 |
| 점심 12~13시 | 비포/애프터 or 후기 | 점심시간 피크 |
| 저녁 20~21시 | 바이럴용 (촬영 영상, 밈) | 밤 엔터테인먼트 시간 |

### 초기 전략
- 1일 2회로 시작 → 반응 보고 3회까지 증가
- 6회 이상 → 언팔/뮤트 유발, 역효과

### 일본 X 골든타임
- 통근: 7~9시
- 점심: 12~13시
- 밤: 20~23시

## 8. 핵심 원칙

**1개 콘텐츠 → 3개 채널 리포맷 = 초기 1인 운영의 핵심**

매일 새 콘텐츠를 만들 필요 없이:
- 비포/애프터 이미지 1장 + 촬영 영상 1개 → 주간 전체 커버 가능
- 월 기준: 이미지 4~5장 + 영상 2~3개 = 전 채널 운영 가능
