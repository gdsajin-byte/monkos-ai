**개발 프로세스 확립**
```

  →→→ monkos_AI/ (배포 앱스: 정식 상품/강화판)
    →→→ Cloud Run 배포

예: apps/photo-coach → monkos_AI/idphoto-jp/ → idphoto-jp.monkos.ai
```
