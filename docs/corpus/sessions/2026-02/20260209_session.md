### 결정사항

**monk.kr vs monkos.ai 분리 운영 체계 확립**

| | MONK_kr | monkos_AI |
|---|---|---|
| 도메인 | monk.kr | monkos.ai |
| 인프라 | Cloudflare Pages + Workers | GCP Cloud Run (Vertex AI) |
| 배포 | Git push → 자동 | deploy.sh → Cloud Build |
| 역할 | 포털 홈페이지 | 완성 앱 서비스 |

**개발 프로세스 확립**
```
apps/ (공유 앱스: 프로토타입/실험)
  →→→ monkos_AI/ (배포 앱스: 정식 상품/강화판)
    →→→ Cloud Run 배포

예: apps/photo-coach → monkos_AI/idphoto/ → idphoto.monkos.ai
```
