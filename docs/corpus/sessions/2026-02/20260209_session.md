### 8-2. 증명사진 규격 크롭 엔진 (Spec Crop) [18:13]

**배경**
- 작가님 지적: 현재 어떤 AI 서비스도 여권/증명사진 mm 규격 정밀 크롭 불가
- 포토샵에서도 가이드라인 수동 설정 → 얼굴 크기 맞춰 출고하는 수작업
- **핵심 아이디어**: 얼굴 감지 → mm 규격표 → Canvas 크롭 = CV + 산술

**PHOTO_SPECS 테이블**
```javascript
const PHOTO_SPECS = {
    id_photo: { name: '証明写真 (35×45mm)', widthMM: 35, heightMM: 45, faceTopMM: 4, faceLenMM: 34 },
    resume:   { name: '履歴書 (30×40mm)',   widthMM: 30, heightMM: 40, faceTopMM: 3, faceLenMM: 28 },
    mynumber: { name: 'マイナンバー (35×45mm)', widthMM: 35, heightMM: 45, faceTopMM: 4, faceLenMM: 34 },
    profile:  { name: 'プロフィール (35×45mm)', widthMM: 35, heightMM: 45, faceTopMM: 6, faceLenMM: 30 },
};
```

**크롭 수학**
```
DPI = 300
mmToPx(mm) = Math.round(mm / 25.4 * 300)
pxPerMM = faceHeight(px) / faceLenMM(mm)  ← 얼굴 높이로 실세계 스케일 역산
```
- 35×45mm → 413×531px (300dpi)
- Imagen 출력 1024px+ → 300dpi 크롭에 충분 (오히려 다운스케일)

**cropToSpec() 함수**
1. 이미지 로드 → 얼굴 감지
2. `pxPerMM` 역산 (얼굴 높이 기준)
3. 규격 px 계산 → Canvas 크롭
4. 결과: `croppedImageData` (base64 PNG)

**UX 통합**
- QC PASS 시 자동 `cropToSpec()` 호출
- Step 4: 規格クロップ 라벨 표시
- 규격 정보: 사진 이름, 크기(mm), 300dpi, 픽셀 수 표시
- 다운로드 시 크롭 버전 우선 (`_spec` 접미사)
