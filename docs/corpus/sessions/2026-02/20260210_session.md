### [15:35] Q12: 규격 크롭 정밀화 방안 조사 (쌍아 — 전략 대화)

**작가님**: "크롭 기준을 정밀하게 해야하는데 얼굴의 중심이나 이목구비에서 기준을 잡지말고 윤곽선 기준으로 비율을 잡는 방안 보고"

**조사 결과**:
- 현재: MediaPipe Face Detection → 바운딩 박스(이마~턱, ~27mm 상당) + 고정 보정값
- 문제: 정수리 미감지 (~7mm 누락), 헤어스타일 따라 오차 큼
- 제안: **MediaPipe Face Mesh (468 랜드마크)** → 턱(#152) + 이마(#10) 윤곽 기준
  - 이마~턱 거리 × 1.26 = 정수리 추정 (ICAO 34mm 중 이마~정수리 7mm ≒ 7/27)
  - 규격 34mm에 직접 매핑, 좌우 윤곽(#234, #454) 중심 정렬
  - 모델 ~1MB 추가 (백그라운드 로딩)

**일본 여권 규격 확인**:
- 顔の長さ = 턱 끝 ~ **정수리(頭頂, 머리카락 포함)** = 34 ±2mm (32~36mm)
- 이마 헤어라인이 아님, 두개골 꼭대기 기준

### [16:11] Q13: 크롭 전략 2-Tier 확정 (쌍아)

**작가님**: "메인 창에서는 클로즈업으로만 보여주고 생성원본 다운로드후 여권 등 규격 크롭은 퍼널 서비스로 준비"

**확정 구조**:
```
[무료] 촬영 → 코칭 → 생성 → 클로즈업 프리뷰 → 원본 JPEG 다운로드
                                    ↓
[퍼널] "여권 규격으로 크롭" → Face Mesh 정밀 크롭 → 결제 → 납품
       "이력서 규격으로 크롭"
```

| Tier | 용도 | 제공물 |
|------|------|--------|
| 무료 (현재) | 클로즈업 프리뷰 | 생성 원본 JPEG |
| 퍼널 (유료) | 여권/이력서 규격 크롭 | Face Mesh 윤곽선 기준 300dpi 정밀 파일 |
