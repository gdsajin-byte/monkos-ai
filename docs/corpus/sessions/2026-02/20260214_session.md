### [06:01] 텔레그램 콘텐츠 도달 구조 해부

**작가님**: "알고리즘과 상관없다는것이 장점일수도 있겠지만 그럼 대체 어떤 구조로 도달한다는 것이지?"

- **4가지 도달 경로**:
  1. **구독자 직접 도달 (Push)** — 구독자 100% 푸시, 알고리즘 필터 없음
  2. **포워딩 체인 (바이럴)** — 사람이 알고리즘 역할, 그룹(20만명) 공유 시 폭발
  3. **디스커버리 (탐색)** — 유사 채널 추천, 앱 내 검색, 검색 광고, 스토리 해시태그, 구글 인덱싱
  4. **외부 유입 퍼널 (Pull)** — 인스타/유튜브/블로그에서 텔레그램으로 퍼널링
- **결론**: "텔레그램은 도착지이지, 출발점이 아니다"
- 모으기는 어렵지만 모이면 100% 내 것 (vs 유튜브: 모으기 쉽지만 알고리즘 변하면 끝)

### 기술명세: UX 개선 상세

#### 1. Sticky 버튼 동작 원리

```
┌─────────────────────┐
│      Header         │
├─────────────────────┤
│                     │
│   Prep Screen       │
│   (scrollable)      │
│                     │
│   ▼ 스크롤 영역     │
│                     │
├─────────────────────┤ ← sticky: bottom 24px
│  [📸 촬영 시작]     │   뷰포트 하단에 고정
└─────────────────────┘
```

- `position: sticky` + `bottom: 24px`: 부모 내에서 스크롤되지만 뷰포트 하단에 걸림
- `margin-top: auto`: flexbox에서 남은 공간을 위로 밀어 자연스러운 배치

#### 2. 가격 표기 UX 의도

- **사전 고지**: 버튼 클릭 전 비용 인지 → 결제 단계 이탈 감소
- **시각적 계층**: opacity 0.7 + 작은 폰트 → 메인 액션보다 보조 정보
- **일관성**: 다운로드 버튼 `(10c)` 표기와 동일 패턴

#### 3. 리전 선택기 쿠키 구조

```javascript
// 쿠키 설정 (cross-subdomain)
document.cookie = `monkos_region=${region};domain=.monkos.ai;path=/;max-age=31536000;SameSite=Lax`;

// 도메인 흐름
portal.monkos.ai (리전 선택)
    ↓ 쿠키 공유
idphoto-kr.monkos.ai / idphoto-jp.monkos.ai (리전 읽기)
```

- `domain=.monkos.ai`: 서브도메인 간 공유
- `max-age=31536000`: 1년 유지
- `SameSite=Lax`: 일반 탐색에서 쿠키 전송
