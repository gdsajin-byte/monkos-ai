### [12:03] SSH 직접 통신 방향 확정

**VPN vs SSH 논의:**
- Tailscale은 WireGuard 기반 메시 VPN → 전통 VPN과 다름 (P2P 직접 연결)
- 목적: VPN 자체가 아니라 **SSH 직접 통신 인프라**로 활용
- 구글앱(원격 데스크톱) 경유 제거 → **터미널 직접 통제** 방향 확정

**멀티 디바이스 통신 구조:**
- iPhone ↔ 4060: Termius + Tailscale ✅ (이미 완료, 텔레그램 연동에서 발전)
- Mac ↔ 4060: Tailscale SSH (세팅 중)
- Mac mini(집) ↔ 4060: 동일 구조 예정
- 보안 단계적 접근: 하나씩 열어가며 테스트

### [12:07] Mac CLI PATH 문제 진단

**증상:** App Store에서 Tailscale 설치 완료, 프로세스 구동 중이나 터미널 CLI 미작동
**원인:** App Store 버전은 `/Applications/Tailscale.app/Contents/MacOS/Tailscale`에만 존재, PATH 미등록
**해결방안:** 심볼릭 링크 생성 (`sudo ln -s ... /usr/local/bin/tailscale`) 권장
- brew 별도 설치는 App Store 앱과 충돌 가능성 있어 비권장

**5090 서버 도입 시 구상:**
