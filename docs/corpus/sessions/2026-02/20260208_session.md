### [12:27] WebRTC P2P 벤치마크 — 성공

**구성:** iPhone (카메라 송신) → WebRTC P2P → iMac (영상 수신)
**시그널링:** Node.js HTTPS+WSS 서버 (자체서명 인증서, iMac 로컬)
**코드:** `apps/monk-cam/demo/` (signaling_server.js, sender.html, receiver.html)

**측정 결과:**

| 항목 | 측정값 | 판정 |
|------|--------|------|
| 해상도 | 1280x720 (HD) | OK |
| FPS | 30 | OK |
| 비트레이트 | 2,398 kbps | 우수 (HD 영상통화급) |
| **RTT** | **7ms** | 로컬 네트워크급 |
| 패킷 손실 | 0.00% | 완벽 |
| 코덱 | H264 | 하드웨어 가속 |
| 전송 방식 | **P2P 직결** | 중앙 서버 없음 확인 |

**검증 완료:**
- 중앙 서버 없이 P2P 직결 성공 → 비용 0원 구조
- 철창이 예측 RTT 5~30ms 범위 내 (7ms)
- glass-to-glass 100ms 이내 가능한 수치
- 몽코스 영상 파이프라인 L1(네트워크) + L2(WebRTC) 실증

**디버깅 이력:**
1. HTTP → 카메라 접근 차단 (Safari HTTPS 필수) → HTTPS 전환
2. Blob 파싱 오류 → `e.data.text()` 변환 추가
3. 영상 까만 화면 → `video.play()` 명시적 호출로 해결
