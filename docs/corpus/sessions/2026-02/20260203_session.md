### [11:40] 증명사진 배치 오류 분석

**증상:** 4배치 생성 중 2컷 이후 오류 발생 → 전체 실패

**테스트 결과:**
- 1x1 테스트 이미지: 4/4 성공 (약 13-16초/컷)
- 1MB 실제 이미지: 4/4 성공
- API Rate Limit 아님

**원인 발견:**
```javascript
// 기존: throw로 전체 중단
if (!response.ok) {
    throw new Error(...)  // 2컷 성공해도 3번째 실패 시 전체 날아감
}
```

**수정:**
```javascript
// 수정: continue로 개별 실패 처리
if (!response.ok) {
    slot.innerHTML = "생성 실패"
    continue  // 다음 컷으로 계속
}
```

**효과:**
- 부분 성공 시 성공한 컷 유지
- 실패 슬롯에 "생성 실패" 표시
- `⚠️ 2/4장 생성 (일부 실패)` 메시지
