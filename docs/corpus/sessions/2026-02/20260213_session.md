### [05:11] DNS Only vs Proxied 개념 정리

**작가님**: "dns 온리로 세팅한게 문제인가 보군 dns와 프록시 차이와 정확한 개념 설명 짚고 넘어가자"

- DNS Only: 주소만 안내, 이후 Cloudflare 관여 안 함
- Proxied: 모든 트래픽이 Cloudflare 엣지 경유 (CDN + WAF + SSL)
- Cloud Run 커스텀 도메인 초기 연결 시 DNS Only 필요했으나, SSL 발급 후에는 프록시 전환 가능
