**주제:** SSH + Tailscale 원격 개발 환경 구축 - 폰에서 Claude Code 접속
**환경:** Windows (Claude Code CLI, Opus 4.5)
**시작:** 2026-01-31 오전

---

## 배경

텔레그램 봇으로 Claude와 통신은 가능하지만, 실제 터미널 권한(파일 읽기/쓰기, 명령 실행)이 없는 한계.

**철창이 제안:** 모바일 SSH 앱(Termius)으로 로컬 PC에 접속해서 Claude Code 실행

---

## 구축 완료

### 1. OpenSSH 서버 설치 (Windows)

```powershell
# 관리자 PowerShell에서 실행
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'
```

- 방화벽 자동 설정 (포트 22)
- 서비스 자동 시작 설정

### 2. Tailscale VPN 설치

외부 네트워크에서도 접속 가능하도록 Tailscale 설정.

| 기기 | Tailscale IP |
|------|--------------|
| PC (DESKTOP-70GOMAR) | `100.118.31.62` |
| 폰 | `100.115.57.53` |

**장점:**
- 포트포워딩 불필요
- DDNS 불필요
- 어디서든 같은 네트워크처럼 접속

### 3. Termius 설정

**PC 및 폰에 Termius 설치**

접속 정보:
- Host: `100.118.31.62`
- Port: `22`
- Username: `smuse73`
- Password: Windows 로그인 비밀번호

### 4. Claude Code 실행

SSH 세션에서 npm global 경로가 PATH에 없어서 전체 경로로 실행:

```cmd
%appdata%\npm\claude.cmd
```

## 작업 흐름

### 집에서
```
VSCode + Claude (GUI 편집)
```

### 외출 시
```
폰 Termius → SSH → PC → Claude Code CLI (터미널 파워)
```

### 핵심 가치
- IDE가 "장소"에서 해방
- PC만 켜져있으면 어디서든 풀 개발환경
- 폰 성능/저장공간 무관 - PC 풀 스펙 사용
