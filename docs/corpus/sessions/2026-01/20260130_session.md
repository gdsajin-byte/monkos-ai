#### 1. 텔레그램 봇

- **봇**: @monkos_factory_bot
- **웹훅**: Firebase Functions `telegramWebhook`
- **명령어**: `/쌍아`, `/막내`, `/용아`, `/철창`, `/전체`

#### 2. Firebase Functions 배포

```javascript
// apps/MonkosChat/functions/index.js
- telegramWebhook: 텔레그램 → Firestore 명령 저장
- notifyWriter: AI → 텔레그램 알림
- getCommands: AI가 대기 명령 조회
- completeCommand: 명령 완료 처리
- updateAiStatus: AI 상태 업데이트
```

#### 3. Git Hooks

```bash
# .git/hooks/post-commit
# 커밋 시 자동 알림: "Git commit: [hash] on [branch]"

# .git/hooks/pre-push
# 푸시 시 자동 알림: "Git push: [branch] -> [remote]"
```

#### 4. PowerShell 알림 스크립트

```powershell
# scripts/monkos/notify.ps1
Send-Monkos "complete" "작업 완료"
monkos-done, monkos-error, monkos-ask, monkos-wait, monkos-fire
```

#### 5. 야간 자율 운영 스크립트

```python
# scripts/monkos/night_operator.py
# 퇴근 후 실행 → Firestore 폴링 → claude -p 실행 → 텔레그램 알림
```
