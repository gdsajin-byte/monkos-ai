## 핵심 흐름 (시간순)

### 1. 시사/전략 대화 (2025년 11월)
- 한미 관세 협상 타결 분석
- 한국 핵추진 잠수함 건조 합의 (조인트 팩트시트)
- 핵연료 조달 방안 (미국산 LEU 공급)

### 2. GPU 인프라 전략 (2025년 12월)
**삼원화 지능망 설계**:
```
RTX 5090 (사무실)  → monk.kr 상업용 본진, 고해상도 뮤즈 생산
RTX 4060 (아이 방) → 용아쌤 프로젝트, 교육용 R&D
Google Cloud       → 백업, 무중단 서비스 보장
```

**핵심 원칙**:
- 로컬 우선, 클라우드 백업
- 5090 도입 시점(2026년 1월)에 맞춘 하이브리드 구조

### 3. 용아쌤 프로젝트 (2025년 12월)
**목적**: 중2 진학 아들을 위한 AI 튜터

**데이터베이스 구축 전략**:
- EBS 중학 프리미엄
- 국정/검인정 교과서 (국, 영, 수, 사, 과)
- 최상위 문제집 (블랙라벨, 에이급수학, 쎈)
- 전국단위 학력평가 기출

**추천 모델 (RTX 4060 최적화)**:
| 순위 | 모델 | 특징 |
|------|------|------|
| 1위 | Qwen 2.5 7B-Instruct | 수학/과학 특화, 4-bit 양자화 |
| 2위 | Llama 3.1 8B-Instruct | 범용성, 한국어 이해 |
| 3위 | Mistral NeMo 12B | 긴 문맥 이해 |

**아키텍처**:
- 구글 팩토리 라인 (Gemini 1.5 Pro)으로 데이터 정제
- 로컬 RAG로 검증된 데이터만 참조
- 아이 계정 독립성 존중 + 로컬 지식 엔진

### 4. B2B 솔루션 설계 (2026년 1월)
**가비아 → Cloudflare 전환 완료**

**Monk-Engine 비즈니스 모델**:
```
무료 버전: 표준 레이아웃 + 무중단 결제/예약
유료 버전: AI 추천, 마케팅 팩, 데이터 대시보드
```

**아임웹 대비 차별점**:
| 항목 | 아임웹 | Monk 솔루션 |
|------|--------|-------------|
| 디자인 | 무료 스톡 이미지 | AI 생성 커스텀 |
| 속도 | 공용 서버 | Cloudflare 엣지 |
| SEO | 메타태그 자동화 | JSON-LD + Indexing API |
| 구조 | 플랫폼 종속 | 중앙 템플릿 독립 |

**핵심 전략**:
- "Powered by Monk" 각인으로 네트워크 효과
- 비용 비대칭성 (고객 증가해도 운영 리소스 불변)
- 기술 수직 통합 (기획+디자인+개발 원스톱)

### 5. 아카데미/커뮤니티 구상 (2026년 1월)
- Cloudflare Workers + D1 기반 서버리스 커뮤니티
- B.W.Y.A University 연동
- 콘텐츠 자산화 + 팬덤 형성
