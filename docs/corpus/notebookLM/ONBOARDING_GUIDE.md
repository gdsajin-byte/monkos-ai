# 🧠 NotebookLM 온보딩 가이드

> **"AI에게 기억을 심어주면, AI가 너 대신 기억해준다"**

---

## 🎯 이게 뭐야?

**NotebookLM** = 구글이 만든 AI 노트북
- 네가 올린 문서를 읽고 기억함
- 그 문서 기반으로 질문에 답변함
- **아빠/선배한테 물어보듯이** AI한테 물어볼 수 있음

---

## 🚀 3분 만에 시작하기

### Step 1: 접속
👉 [notebooklm.google.com](https://notebooklm.google.com) 접속 (구글 계정 로그인)

### Step 2: 노트북 만들기
`+ 새 노트북` 클릭

### Step 3: 소스 업로드
`소스 추가` → 파일 업로드 (`.md`, `.pdf`, `.txt` 등)

### Step 4: 질문하기
채팅창에 궁금한 거 물어보기

---

## 💡 핵심 개념: RAG

```
RAG = Retrieval-Augmented Generation
     (검색 증강 생성)

쉽게 말하면:
┌─────────────────────────────────┐
│  네가 올린 문서 (기억)           │
│         ↓                       │
│  AI가 검색해서 찾음              │
│         ↓                       │
│  그걸 바탕으로 답변 생성         │
└─────────────────────────────────┘
```

**일반 ChatGPT**: 학습된 일반 지식만 사용
**NotebookLM**: **네가 올린 문서** 기반으로 답변

---

## 🎮 실습: 이렇게 물어봐

### ❌ 나쁜 질문
```
"AI가 뭐야?"  → 일반 지식 (구글 검색이랑 똑같음)
```

### ✅ 좋은 질문
```
"우리 프로젝트에서 4 MUSE가 뭐야?"
"어제 회의에서 뭐 결정했어?"
"이 코드 왜 이렇게 짰어?"
```

💡 **핵심**: 올린 문서에 있는 내용을 물어봐야 RAG가 작동함

---

## 🔥 이게 왜 강력해?

### Before (전통 방식)
```
신입: "이거 왜 이렇게 해요?"
선배: (바쁨) "나중에..."
신입: (기다림...)
선배: (까먹음)
신입: (포기)
```

### After (NotebookLM)
```
신입: "이거 왜 이렇게 해요?"
AI: "2026-01-15 회의록에 따르면, 
     작가님이 A 방식 대신 B 방식을 선택한 이유는..."
신입: "아 그렇구나!" (즉시 해결)
```
