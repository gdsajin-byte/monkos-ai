## 1. 검토 배경

### 1.1 현재 크레딧 시스템
```
Firestore users/{user_id}
  └─ credits: number (정수)

- 충전: Lemon Squeezy (글로벌) / 토스페이먼츠 (KR)
- 사용: 생성 1c, 다운로드 10c
- 양도: 불가 (계정 귀속)
- 환불: 7일 이내 미사용 시 전액
```

### 1.2 NFT화 검토 목적
- 크레딧 **거래 가능성** (P2P 양도)
- 프로모션 **희소성 부여** (한정판 크레딧)
- **Web3 마케팅** 활용
- 장기 **커뮤니티 빌딩**

## 2. 법적 검토

### 2.1 한국 규제 현황

#### 2.1.1 적용 법률
| 법률 | 적용 여부 | 설명 |
|------|----------|------|
| 특정금융정보법 (특금법) | ⚠️ 가능성 | 가상자산 해당 시 VASP 등록 필요 |
| 가상자산이용자보호법 | ⚠️ 가능성 | 2024.7 시행, 이용자 보호 의무 |
| 전자금융거래법 | ❌ 해당 없음 | 선불전자지급수단 아님 (용역 교환용) |
| 자본시장법 | ⚠️ 주의 | 투자 목적 판매 시 증권 해당 가능 |

#### 2.1.2 핵심 쟁점: "가상자산" 해당 여부

**금융위원회 가이드라인 (2023)**
```
가상자산 = 경제적 가치를 지닌 것으로서 전자적으로 거래 또는 이전될 수 있는 전자적 증표

예외:
- 게임물의 이용을 통해 획득한 결과물 (게임아이템)
- 특정 사업자만 재화/용역 교환에 사용 가능한 것
```

**MONKOS 크레딧 분석:**
| 요소 | 현재 | NFT화 시 |
|------|------|----------|
| 발행 주체 | MONK STUDIO 단독 | 동일 |
| 사용처 | MONKOS 서비스 한정 | 동일 |
| 양도 가능성 | 불가 | **가능 (P2P)** |
| 외부 거래소 상장 | 없음 | 가능성 있음 |

**결론:**
- 현재: **가상자산 아님** (폐쇄형 포인트)
- NFT화 시: **가상자산 해당 가능성 높음** (양도 가능 + 2차 거래)

#### 2.1.3 VASP 등록 시 의무
```
1. 정보보호관리체계(ISMS) 인증
2. 실명계좌 발급 (은행 제휴)
3. 자금세탁방지(AML) 시스템
4. 이용자 자산 분리 보관
5. 정기 감사 및 보고
```
**예상 비용:** 초기 5억+ / 연간 운영 2억+

### 2.2 일본 규제 현황

#### 2.2.1 적용 법률
| 법률 | 적용 여부 | 설명 |
|------|----------|------|
| 資金決済法 (자금결제법) | ⚠️ 가능성 | 암호자산 해당 시 교환업 등록 |
| 金融商品取引法 | ⚠️ 주의 | 전자기록이전권리 (ST) 해당 시 |
| 景品表示法 | ✅ 적용 | 프로모션 규제 |

#### 2.2.2 NFT 분류 (일본 금융청)
```
1. 결제수단형 NFT → 암호자산 (규제 대상)
2. 콘텐츠형 NFT → 비규제 (예: 디지털 아트)
3. 유틸리티형 NFT → 상황에 따라 판단
```

**MONKOS 크레딧 NFT:**
- 서비스 이용권 → **유틸리티형**
- 1:1 가치 교환 가능 → **결제수단 성격**
- **암호자산 해당 가능성 있음**

#### 2.2.3 암호자산 교환업 등록 요건
```
1. 자본금 1,000만엔 이상
2. 순자산 양수
3. 이용자 재산 분별 관리
4. 정보 보안 체계
5. AML/CFT 체제
```
**예상 비용:** 초기 3억엔+ / 연간 운영 1억엔+

    // 토큰 ID = 크레딧 단위 (1c, 10c, 100c)

    // 발행 (MONK만 가능)

        external onlyOwner;

    // 사용 (서비스 이용 시 소각)
    function burn(address from, uint256 tokenId, uint256 amount)
        external onlyAuthorized;

    // 양도 (P2P)
    function safeTransferFrom(...) // ERC-1155 표준
}

## 4. 대안 검토

### 4.1 완전 NFT화 vs 부분 적용

| 방식 | 설명 | 법적 리스크 | 기술 난이도 |
|------|------|------------|------------|
| **완전 NFT화** | 모든 크레딧 온체인 | 🔴 높음 | 상 |
| **한정판 NFT** | 프로모션용만 NFT | 🟡 중간 | 중 |
| **멤버십 NFT** | 크레딧 아닌 자격증명 | 🟢 낮음 | 하 |
| **포인트 유지** | 현행 유지 | 🟢 없음 | - |

### 4.2 권장 대안: 멤버십 NFT

```
기존 크레딧 시스템 유지
  +
멤버십 NFT (VIP 패스) 별도 발행
  ├─ 혜택: 할인, 우선 예약, 한정 기능
  ├─ 양도: 가능 (2차 거래)
  └─ 법적: 디지털 컬렉터블 (규제 낮음)
```

**장점:**
- 크레딧 = 폐쇄형 포인트 유지 (규제 회피)
- NFT = 멤버십/컬렉션 (마케팅 효과)
- 법적 리스크 최소화
