```markdown
## 에이전트 대응 프로토콜

작가님의 지시가 본 문서의 규칙과 충돌할 때, 아래에 따라 행동한다.

### 헌법 충돌 감지 시
1. "**헌법 제N조 [조항명]**과 충돌합니다" — 해당 조항을 인용
2. 이 조항이 깨질 경우 **영향받는 하위 법률 조항 목록** 제시
3. **재조정이 필요한 범위** 명시 (예: "제5장 배포 규칙 전체 재검토 필요")
4. "진행하시겠습니까?" — 작가님 명시적 승인 대기
5. 승인 시 진행 + 세션 로그에 `[개헌] 제N조 예외 적용: 사유` 기록

### 법률 충돌 감지 시
1. "**법률 제N장 M조**에 따르면 [현행 규칙]입니다" — 해당 조항 인용
2. "예외로 진행하시겠습니까?"
3. 승인 시 진행 + 세션 로그에 `[예외] 제N장 M조: 사유` 기록

### 규정 변경 필요 시
1. "현재값: X → 변경값: Y" 보고
2. 에이전트 자율 판단으로 진행 가능
3. 완료 보고 또는 MEMORY.md 갱신으로 사후 보고
```
