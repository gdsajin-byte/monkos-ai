## 📊 구글 클라우드 어시스트 설계도 요약

### 3단계 분리형 아키텍처 (여권사진 기준)

```
┌─────────────────────────────────────────────────────────────────┐
│              Google Cloud Assist 설계도                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  [1단계] Photo-Ingestion (입고)                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ Global Load Balancer → Cloud Run                        │   │
│  │ → 요청 수신 → Firestore에 주문 정보 기록                  │   │
│  │ → Pub/Sub로 다음 단계 트리거                             │   │
│  └─────────────────────────────────────────────────────────┘   │
│                         │                                       │
│                         ▼ Pub/Sub                              │
│  [2단계] Photo-Validation (검수)                                │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ Pub/Sub 메시지 수신 → Cloud Run                         │   │
│  │ → Vertex AI Vision으로 검수                              │   │
│  │   (얼굴 위치, 눈 감음, 배경 등)                           │   │
│  │ → 통과 시 다음 단계로                                    │   │
│  └─────────────────────────────────────────────────────────┘   │
│                         │                                       │
│                         ▼ Pub/Sub                              │
│  [3단계] Image-Processing (생성)                                │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 검수 통과 사진만 수신 → Cloud Run                        │   │
│  │ → Vertex AI Imagen으로 처리                              │   │
│  │ → processed-photos-bucket에 저장                        │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 핵심 특징
- **비동기 이벤트 처리**: Pub/Sub 기반 느슨한 결합
- **노드 분리**: 각 단계가 독립적으로 스케일
- **엔터프라이즈급**: 글로벌 부하 분산, 장애 격리
