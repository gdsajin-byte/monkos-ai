# MONK_kr 프로젝트 컨텍스트

이 폴더는 용아(Gemini)와의 전략 대화 및 프로젝트 컨텍스트를 저장합니다.

## 파일 구조

- `yong_a_strategy.md` - 용아와의 전략 대화 내용
- `project_vision.md` - 프로젝트 비전 및 방향성
- `business_model.md` - 비즈니스 모델 및 수익 구조
- `technical_decisions.md` - 기술적 결정사항
- `timeline.md` - 개발 타임라인 및 우선순위

## 사용 방법

1. Gemini(용아) 대화창에서 중요한 전략/결정사항 복사
2. 해당 파일에 날짜와 함께 저장
3. Cursor에서 `@.context/파일명` 으로 참조
4. 쌍아(Claude)가 자동으로 컨텍스트 이해

## 업데이트 원칙

- 매주 주요 결정사항 업데이트
- 전략 변경 시 즉시 반영
- 날짜 기록 필수
