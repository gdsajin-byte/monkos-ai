## 1. 프로젝트 개요

### 1.1 프로젝트명
**MONKOS Retouch Live** (가칭)

### 1.2 컨셉
> "아프리카TV 별풍선 + 실시간 포토샵 리터칭"

전문 리터처의 작업 화면을 실시간 스트리밍하며, 고객이 텍스트 채팅으로 요청사항을 전달하고 즉각 반영받는 **원격 1:1 리터칭 서비스**.

### 1.3 배경 및 필요성
- 기존 리터칭 서비스: 사진 전송 → 작업 → 수령 (비동기, 소통 불편)
- 고객 니즈: 실시간으로 작업 과정 확인, 즉각적인 피드백 반영
- 글로벌 확장: 일본/한국/영어권 고객 대응 필요 (자동 번역)
- MONKOS 시너지: 기존 AI 증명사진 고객 → 정밀 리터칭 업셀

## 3. 핵심 기능

### 3.1 실시간 화면 공유
| 항목 | 설명 |
|------|------|
| 방식 | 브라우저 Screen Capture API (getDisplayMedia) |
| 공유 범위 | 특정 창 하나만 선택 (포토샵/라이트룸 등) |
| 전송 | WebRTC P2P 또는 서버 릴레이 |
| 품질 | 720p~1080p, 적응형 비트레이트 |

### 3.2 실시간 채팅 + 자동 번역
| 항목 | 설명 |
|------|------|
| 프로토콜 | WebSocket (기존 MONKOS 인프라 활용) |
| 번역 | Gemini 2.0 Flash 실시간 번역 (JP↔KR↔EN) |
| UI | 원문 + 번역문 동시 표시 |

### 3.3 크레딧 시스템
| 항목 | 설명 |
|------|------|
| 기본 세션 | 10분 포함 (예: 30c) |
| 추가 시간 | 5분당 10c 자동 차감 |
| 추가 요청 | 복잡한 작업 시 협의 후 추가 크레딧 |
| 팁 (별풍선) | 고객 만족 시 자발적 추가 결제 |

### 3.4 텔레그램 통합
| 기능 | 설명 |
|------|------|
| 예약 접수 | 봇으로 사진 업로드 + 요청사항 접수 |
| 알림 | 세션 시작/종료, 파일 완료 알림 |
| 채팅 | 세션 중 실시간 대화 (번역 포함) |
| 결제 | Telegram Payments 또는 크레딧 연동 |
| 계정 연결 | Google/카카오/LINE ↔ 텔레그램 매핑 |

### 3.5 파일 전달
| 단계 | 설명 |
|------|------|
| 작업 중 | 스트리밍으로 실시간 확인 |
| 완료 후 | GCS 업로드 → 다운로드 링크 (24시간 유효) |
| 전달 채널 | 텔레그램 봇 / 이메일 / 웹 대시보드 |

## 4. 기술 스택

### 4.1 프론트엔드
```
- 리터처 웹앱: HTML/CSS/JS (순수 JS, 프레임워크 미사용)
- 고객 웹앱: 텔레그램 Mini App (TWA) 또는 독립 웹
- 화면 공유: navigator.mediaDevices.getDisplayMedia()
- 영상 재생: WebRTC / HLS.js (폴백)
```

### 4.2 백엔드
```
- 서버: Node.js (Cloud Run)
- 실시간 통신: WebSocket (ws 라이브러리)
- 데이터베이스: Firestore
- 스토리지: Google Cloud Storage
- 번역: Gemini 2.0 Flash API
```

### 4.3 텔레그램
```
- Bot API: node-telegram-bot-api
- Mini App: 텔레그램 WebApp SDK
- Payments: Telegram Payments API (선택)
```

### 4.4 인프라
```
- 호스팅: GCP Cloud Run
- CDN: Cloudflare (기존 인프라)
- 도메인: retouch.monkos.ai (예정)
- 인증: Firestore 기존 users 컬렉션 연동
```

## 5. 유저 플로우

### 5.1 고객 플로우
```
1. 텔레그램 봇 접속 (@monkos_retouch_bot)
2. "리터칭 예약" 선택
3. 사진 업로드 + 요청사항 입력
4. 일정 선택 (가능 시간대 표시)
5. 크레딧 결제 (기본 세션 30c)
6. 예약 확정 알림 수신
7. 세션 시간에 Mini App 접속
8. 리터처 작업 화면 실시간 시청
9. 채팅으로 피드백 ("피부 좀 더 밝게")
10. 시간 초과 시 추가 결제 안내
11. 작업 완료 → 파일 다운로드
12. (선택) 팁 전송 / 리뷰 작성
```

### 5.2 리터처 플로우
```
1. 예약 알림 수신 (텔레그램/웹)
2. 고객 요청사항 + 원본 사진 확인
3. 세션 시간에 리터처 웹앱 접속
4. "세션 시작" 버튼 → 창 선택 (포토샵)
5. 화면 공유 시작 → 고객에게 스트리밍
6. 채팅 수신 (번역됨) → 작업 반영
7. 타이머 확인 (기본 10분)
8. 추가 시간 필요 시 고객에게 요청
9. 작업 완료 → 파일 업로드
10. "세션 종료" → 고객에게 알림
```
