## 📋 **Phase 2: VM 실행 (승인 후)**

### Cursor → VM 연결 방법:

#### 1. VM 생성 (Cloud Shell)
```bash
gcloud compute instances create monk-rocket-t4 \
  --zone=us-central1-a \
  --machine-type=n1-standard-8 \
  --accelerator=type=nvidia-tesla-t4,count=1 \
  --image-family=ubuntu-2204-lts \
  --image-project=ubuntu-os-cloud \
  --boot-disk-size=100GB \
  --preemptible \
  --metadata="install-nvidia-driver=True"
```

#### 2. SSH 키 설정 (로컬 맥북)
```bash
# SSH 키 생성
ssh-keygen -t ed25519 -C "monk-vm"

# GCP에 키 등록
gcloud compute config-ssh
```

#### 3. Cursor SSH 연결
```
1. Cursor 열기
2. Cmd+Shift+P
3. "Remote-SSH: Connect to Host"
4. monk-rocket-t4.us-central1-a.gen-lang-client-0105707468
5. 연결! ✅
```

#### 4. 작업 흐름
```
로컬 Cursor:
├─ 코드 편집
├─ Git 커밋
└─ SSH로 VM 연결

VM (GPU):
├─ 코드 자동 동기화
├─ 학습 실행
├─ 결과 저장
└─ GCS 백업
```
