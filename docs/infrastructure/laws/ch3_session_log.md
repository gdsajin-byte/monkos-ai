# 법률 제3장: 세션 로그

> 상위 헌법: 제1조(시계열 정합성), 제2조(보고 의무)
> 변경 권한: 작가님 승인 시 개정 가능

---

### 1조: 기본 규칙

- **위치**: `docs/corpus/sessions/YYYY-MM/YYYYMMDD_session.md`
- 1일 1파일, append only, Q&A 번호 연속 증가.
- **원본 수정/삭제 절대 금지.**
- 타임스탬프 필수 (시스템 시간만 사용, 추정 금지 — 헌법 제1조 준용).

> 근거: 2026-01-13 결정, 01-14 강화(대화록 누락 절대 금지), 02-08 템플릿 확장
> 작가님 원문: "하루에 8천만 토큰씩 생성하는 찐 데이터들이야. 노트북LM 학습에 결정적" (01-13) / "대화록 누락 절대 금지" (01-14)
> 위반 시: 프로젝트 지식 자산 손실. 멀티 에이전트 시계열 추적 불가.
> 상위 헌법: 제1조(시계열 정합성)

---

### 2조: 형식

**헤더** (세션 시작 시 1회):
```markdown
# 세션 로그: YYYY-MM-DD (요일)

**환경:** [위치] ([장비] + Claude Code Opus 4.6)
**시작:** YYYY-MM-DD HH:MM
```

**본문** (매 작업 블록):
```markdown
### [HH:MM] 작업 주제

**작가님**: "중요 발언 직접 인용"
- 실행 내용
- 결과
```

**종료** (세션 마감 시):
```markdown
## 완료 사항
- [x] 작업 1

## TODO
- [ ] 다음 작업

---
**세션 종료: HH:MM KST**
```

> 근거: 2026-02-08 형식 확정
> 상위 헌법: 제1조, 제2조

---

### 3조: 타임스탬프

- 시스템 명령(`date`)으로만 취득. 추정/기억/이전 시간 기반 계산 **절대 금지**.
- 세션 로그 내 모든 시각은 헌법 제1조를 직접 준용한다.

> 근거: 2026-01-15 최초 결정, 01-31 "1규칙" 승격, 02-08 CLAUDE.md 최상단 배치
> 작가님 원문: "Y2K처럼 이 작은 오류들이 훗날 엄청난 에러로 도출될 수 있어" (01-15)
> 상위 헌법: 제1조
