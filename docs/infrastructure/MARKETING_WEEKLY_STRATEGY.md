## 0. 브랜드 스토리

### 코어 메시지

> 20년 경력의 사진가가 직접 개발한 AI 사진관 MONK.
> 자체 브랜딩한 MONKOS AI가 촬영·보정을 스튜디오 출력 수준으로 제공합니다.
> 전문 개발자는 아니나 진심으로 사진을 대합니다.
> 조명, 배경은 물론 각 국가의 여권·비자 규격까지 완벽히 이해하고
> 인물사진에 대한 전문성으로 최고 품질의 인물사진 서비스를 제공합니다.

## 0-5. 안전성·윤리 포지셔닝 — "불편한 안전"

### 핵심 메시지

> MONK는 사진 편집 앱이 아닙니다.
> 못해서가 아닙니다. **안 하는 겁니다.**
> 그 불편함이 당신의 얼굴을 지킵니다.

### 기존 AI 사진 앱 vs MONK — 구조적 차이

```
[기존 AI 사진 앱]
갤러리에서 사진 선택 → AI가 변형 → 결과물
  ↑ 문제: 누구 사진이든 올릴 수 있다 = 딥페이크 가능

[MONK]
로그인 본인인증 → 실시간 카메라 촬영 → AI가 보정 → 결과물
  ↑ 본인만 가능     ↑ 라이브만 허용     ↑ 정체성 90%+ 유지
```

### MONK의 5대 안전 원칙

| 원칙 | 내용 |
|------|------|
| **본인인증** | 로그인(카카오/LINE/구글) → 본인 확인 후 촬영 |
| **실시간 촬영** | 갤러리 업로드 차단, 라이브 카메라만 허용 |
| **정체성 보존** | 일치율 90%+ 보장, 10%는 자연스러운 보정(피부톤/잡티)만 |
| **윤리적 보정** | 윤곽·눈 크기 변형 없음, 아동은 보정 일체 금지 |
| **데이터 보호** | 동의 없는 사진 서버 저장 X, AI 학습 X, 처리는 고객 모바일 완결 |

### 정체성 일치율 90:10 원칙

```

       얼굴 윤곽, 눈·코·입 비율, 골격 구조 → 변형 없음
       "나는 나다"

10% — 자연스러운 보정 (Natural Enhancement)
       피부톤 균일화, 잡티 정리, 조명 보정
       "스튜디오에서 찍은 것 같은 마무리"

       윤곽 변형 ✕ | 눈 확대 ✕ | V라인 ✕ | 턱 축소 ✕
```

## 4. 텔레그램 아키텍처

### 구조

```
@monk_channel (채널 — 쇼윈도)
  │  봇이 관리자로 참여
  │  ├ 예약 게시 (이벤트, 룩북, 비포/애프터)
  │  ├ 유료 콘텐츠 게시 (Stars 잠금)
  │  └ 게시물 하단 인라인 버튼: [1:1 상담] [예약하기]
  │                                │          │
  │                                ▼          ▼
  │                          @monk_bot (봇 DM — 접객)
  │                            ├ CS 자동 응답 (AI 연동)
  │                            ├ 촬영 예약
  │                            ├ 원본 파일 전달 (4GB)
  │                            ├ 결제 (Stars/TON)
  │                            └ 1:1 리터칭 → 영상통화 전환
  │
  ├── 연결 그룹 (Discussion Group)
  │     게시물에 댓글, 봇이 댓글 자동 응답
  │
  └── 리터칭 개별 그룹
        고객 + 리터처 + 봇 (파일 전달 자동화)
```

### 활용 3모드

| 모드 | 대상 | 활용 | 수익 모델 |
|------|------|------|----------|
| 채널 라이브 | 1→무제한 | 강의, 리터칭 시연, 룩북 공개 | 무료 (마케팅) |
| 그룹 영상통화 | 1→30/1,000 | 워크숍, 단체 코칭, 아카데미 | 유료 (Stars) |
| 1:1 영상통화 | 1→1 | 프리미엄 1:1 리터칭 | 프리미엄 과금 |

### 라이브 리터칭 세션 기능

- 화면 공유 + 음성 대화 + 텍스트 채팅 동시 가능
- 데스크톱: 특정 프로그램만 선택 공유 (포토샵만 송출)
- 상담 → 리터칭 시연 → 파일 전달 → 하나의 채팅에서 완결
- 이력 영구 보존, 비용 무료
