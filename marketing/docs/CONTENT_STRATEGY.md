## 핵심 원칙

**콘텐츠 재고 먼저, 채널은 그 다음.**
- API 워크플로우 고민 전에 콘텐츠를 쌓는다
- n8n은 배달부일 뿐, 생산은 사람+AI가 한다
- 하나의 서사에서 블로그/X/인스타/영상이 모두 파생된다

## 채널별 역할 (각각 다른 전략)

### 네이버 블로그 — 서사 보드 (저서 감각)

| 항목 | 내용 |
|------|------|
| **역할** | 전체 서사를 기술/학술/패션/헤어/프롬프팅 등으로 연재 |
| **감각** | 쌓이면 한 권의 저서가 되는 분량과 깊이 |
| **SEO** | 다양한 키워드로 네이버 검색 유입 → 몽코스 우회 홍보 |
| **콘텐츠 단위** | 인사이트 레토릭 = 목차 제목, 적정 분량씩 분절 |
| **이미지** | 매 포스트 고유 이미지 (메타데이터 중복 회피 필수) |
| **배포** | 수동 (API 폐지 상태, 복붙 or 향후 자동화 검토) |

### X (@MONKOS_AI) — 정밀 타격 (일본 취활 시즌)

| 항목 | 내용 |
|------|------|
| **역할** | 짧지만 정밀한 타격, 전파력 극대화 |
| **타겟** | 일본 취활 시즌 맞춤, 취활 관련 키워드 |
| **콘텐츠** | 타겟팅된 카피, 280자 이내 일본어 |
| **배포** | n8n + OAuth1 (연동 완료) |

### 인스타그램 (monkos.ai) — 이미지 축적 + 모델 셀럽화

| 항목 | 내용 |
|------|------|
| **역할** | 이미지 + 태그 + 릴스 조합, AI 모델 셀럽화 런웨이 |
| **운용** | 한송이 출근 시 촬영 → 한/일 태그만 변경하며 양쪽 시장 동시 공략 |
| **전략** | 꾸준한 이미지 누적 = 모델 포트폴리오 + 팔로워 빌딩 |
| **배포** | Meta API 연동 후 n8n (현재 Meta 일시 제한, 48h 대기) |

### 영상 (유튜브/틱톡) — 숏폼 + 롱폼

| 항목 | 내용 |
|------|------|
| **15초 숏폼** | 스토리 서사라인 + 기술적 큐 → 캡컷 제작 |
| **롱폼** | 심층 서사 (블로그 연재와 연동) |
| **배포** | 캡컷 제작 → 적시 배포 |

## 콘텐츠 생산 흐름

```
docs/ 기존 서사 코퍼스 (이미 풍부)
  ↓
막내: 블로그 연재 원고 정리 (저서 감각, 단위별 분절)
  ↓
철창이/용아: 키워드 전략 + 카피 다듬기
  ↓
┌─ 블로그 원고 (네이버 — 적정 분량 + SEO 키워드)
├─ X 카피 (일본 취활 타겟 — 280자 압축)
├─ 인스타 캡션 + 태그셋 (한/일 버전)
├─ 영상 큐시트 (15초 숏폼 + 롱폼 시나리오)
└─ 각 콘텐츠에 맞는 이미지 매칭
  ↓
캡컷 제작 (영상) / 이미지 가공 (파이프라인)
  ↓
n8n → 각 채널 배포
```

## 이미지 전략

### 재고 확보
- 사진관 경력 기반, 이미지 콘텐츠 축적은 강점
- 한송이 연구원이 촬영 담당으로 합류
- 카테고리: 증명/패션/헤어/스트릿/카페 등

### 이미지 가공 파이프라인 (4060 — 구축 예정)

```
원본 투입 (촬영본)
  ↓
자동 처리 (Sharp + 스크립트, 4060)
├── 채널별 크롭 (얼굴 인식 중심 스마트 크롭)
│   ├── 인스타 정방형 (1:1)
│   ├── 블로그 가로형 (3:2)
│   ├── X 카드 (16:9)
│   ├── 스토리/릴스 세로형 (9:16)
│   └── 썸네일
├── 메타데이터 재생성 (EXIF 초기화 + 새 타임스탬프)
├── 미세 변조 (밝기/대비 ±1~3%, 품질값 변동)
│   └── 동일 원본도 해시값 매번 상이 → 네이버 중복 회피
└── 파일명 리네이밍 (날짜_카테고리_시퀀스)
  ↓
섬네일 갤러리 (눈으로 확인 + 선택)
  ↓
CF Images 업로드 (CDN 서빙) or 직접 서빙
  ↓
n8n → 배포
```

### 네이버 SEO 이미지 주의사항
- 동일 메타데이터 이미지 반복 사용 = 저품질 판정
- 파일 해시, EXIF가 같으면 네이버가 감지
- **반드시 매 포스트마다 고유 이미지** (가공 파이프라인이 자동 처리)

### CF Images 활용 (기존 구독 유지)
- 역할: 모델 이미지 CDN 서빙 전용
- 한계: 폴더 없음, 섬네일 미리보기 불가, UI 빈약
- 네이밍 규칙: `{카테고리}/{모델명}/{시퀀스}_{태그}`
- variant: `original`, `blog`(800w), `insta`(1080sq), `x-card`(16:9), `thumb`(400w)
- 관리는 별도 갤러리 or 로컬에서, CF Images는 서빙만

|------|------|------|
