## 운용 규칙

- **폴더 = 작업 단위**. 큰 작업이면 전용 폴더, 작으면 루트에 파일로.
- 루트에 쌓인 파일이 커지면 폴더로 승격.
- **파일명 스키마**: `{유형}_{YYYYMMDD}_{주체}_{주제}.md`
  - 유형: STRATEGY, SPEC, DESIGN, REVIEW, REPORT, ARTIFACT, BRIEF, NOTE
- 각 폴더 README.md = 개요 + 출납 로그 (문서 입출 시 어펜드)
