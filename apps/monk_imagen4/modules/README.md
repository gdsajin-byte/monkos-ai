# modules (monk_imagen4)

> **소관**: 막내
> **성격**: 프로토타입/PoC
> **법적 근거**: ch4 2조

## 개요

monk_imagen4 AI 이미지 생성 엔진 모듈 모음. 코어 EngineInterface를 구현하는 플러그인 방식으로, 다양한 AI 프로바이더별 생성 로직과 UI를 캡슐화.

## 하위 폴더

| 폴더명 | 설명 |
|--------|------|
| imagen3-pro/ | Imagen 3 Pro Suite 모듈 (생성 로직 + UI) |
| imagen4-generator/ | Imagen 4 Generator 모듈 (생성 로직 + UI) |
| lumina-lookbook/ | Lumina Lookbook 모듈 (패션 특화 AI 생성) |
