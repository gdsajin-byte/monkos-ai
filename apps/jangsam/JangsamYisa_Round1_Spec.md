# 장삼이사 (張三李四) — 1라운드 설계서
## ROUND 1 SPEC · 무명 건달의 자수성가, 관아 추대 입성으로 졸업

> 기획: 신작가 · 정리: 철창
> 산출: 2026-06-13 (WORLDBIBLE.md 커밋 1)
> 상태: PoC v0.1~v0.4로 검증된 설계. 로컬 이관 사양서 겸 RAG 카드 토대.

## 0. 위치 — 이 문서는 무엇인가

1라운드는 게임 전체의 축소판이자 진수다. 무명에서 시작해 무력·인연·민심·명분을
쌓고 마침내 추대받아 첫 이름을 얻는 한 호(arc) 안에, 이 게임의 모든 매력이 담긴다.
1라운드를 끝까지 즐길 수 있게 만들면 2라운드(통치·동맹·현 쟁탈)는 검증된 매력의
스케일 확장일 뿐이다.

**개발 철학 (오늘 확정):** 상위 모델(Opus/Sonnet)은 설계 단계의 금형 제작 도구,
로컬 모델·코드는 운영 단계의 수행기. 똑똑함을 런타임에 매번 소모하지 않고,
한 번 증류해 로컬이 실행 가능한 자산(프롬프트 템플릿·분기 트리·RAG 카드)으로 고정한다.
이 문서가 그 금형이다. 플레이가 곧 콘텐츠 생산 — 잘 나온 발현을 건져 RAG로 적립하는
선순환으로 "즐기면서 만들어가는" 구조.

## 1. 무대와 시점

- **때**: 184년(갑자년) 말. 황건 봉기는 진압되고 장각·장보·장량 삼형제는 스러졌다.
- **곳**: 기주 거록군. 첫 무대는 그 안의 한 고을(광종 일대 — 장량이 최후를 맞은 땅).
- **주인공**: 그 들판에 살아남은 **이름 없는 건달** 하나. 가진 것이라곤 제 한 몸.
- **시점**: 철저히 아래로부터. 황건은 '역적 떼'가 아니라 굶주려 일어선 아픈 이웃.
  영웅사관이 아니다. 시작 문법은 "황건이 일어나 천하가 어지러웠다"(객체)가 아니라
  "간신배가 설쳐 우리가 일어났다"(주체).
- **공리**: 명성은 행적으로만 발행되고, 양도되지 않으며, 약탈로만 이전된다.
  엔드 콘텐츠 = 작명(作名). 이름을 얻는 것이 보상.

## 2. 핵심 루프 — 4장소 × 막당 3걸음

한 막(幕)에 행동 3회. 네 장소는 위계 없이 **동등**하다. 어디에 발걸음을 쓰느냐가 전략.
늘 하나는 못 가므로 매 막이 선택이 된다. (코에이식 행동경제: 결핍이 긴장을 만든다)

| 장소 | 성격 | 주는 것 | 비고 |
|---|---|---|---|
| **들판 野** | 무력의 장 | 도적 사냥 → 무리·민심 | 실시간 교전 모듈 (4장) |
| **객잔 店** | 인연의 장 | 정보·인재 대화·공지(퀘스트) | 다축 평판·결속 (5장). 유저자리=멀티 예약 |
| **시장 市** | 재화의 장 | 곡식·물자 | 상인 거두면 시세·물류 확장(2R) |
| **관가 官** | 노선의 장 | 정보, 그리고 졸업 관문 | 체제 거리 다이얼 (6·7장) |

**위계 주의**: 들판·객잔·시장·관가는 1라운드의 개인 활동. 통치(유민 규합·탐관 퇴출·
경제 재건)는 관아 점령 후 2라운드에 열리는 상위 층. 1라운드에 통치 버튼을 노출하지 않는다.

## 3. NPC 통일 구조 — 모두가 가려진 스탯을 품는다

이 게임의 세계 법칙: **모든 NPC는 가려진 스탯을 품는다.** 도적도 무력이 있고,
서생도 격이 있고, 떠돌이도 정체가 있다. 차이는 "있냐 없냐"가 아니라 "보이냐 가려졌냐".
"이름 없는 자" = "값이 없는 자"가 아니라 "값이 아직 안 드러난 자". 그 가림을 걷는 행위가
곧 플레이다. 안목(가림을 걷는 능력)이 곧 실력.

```
NPC = {
  face:    보이는 표면 ("무명 도적", "행색 단정한 사내")
  hidden:  숨은 무력 / 격(格) / 잠재 / 정체
  reveal:  드러냄 조건 — 전투(무력 드러남) / 대화(격·성향) / 정보수집(미리 가늠)
  yield:   꺾거나 거두면 주는 것 (경험치·무리·재화·인연)
}
```

**가림의 4단계** (완전 깜깜이는 답답하므로 안개 속 윤곽을 더듬게):
1. 완전 가림 (?? 만)
2. 흐릿한 단서 ("범상치 않은 기운", "굶주렸으나 눈빛이 매섭다")
3. 부분 공개 (정보를 모았거나 한 번 겪은 상대 — 대략의 등급)
4. 완전 공개 (야사에 이름이 박힌 자)

표면 유형: 무력형(도적) · 지력형(서생) · 미지형(떠돌이=잠재 영웅). 구조는 동일, 표면만 다름.

> **검증된 발현 (PoC v0.4, 보존)**: 객잔 서생이 "이름을 남기지 못한 자들의 일이라도
> 적어두려 한다"고 자기 사명을 말함 — 모델이 史官(야사를 쓰는 존재)을 NPC로 구현.
> → 이 서생을 史官이라는 고정 인물로 정식 편입 검토. 시스템(야사 로그)에 얼굴을 주는 장치.

## 4. 실시간 교전 모듈 (들판 결투)

서사판 옆에 붙는 가벼운 시각 모듈. 본체는 사서 서사, 전투는 막대 두 개가 깎이는 정도.
"무거운 전투 시스템"이 아니라 "유동감". 과하면 텍스트 정체성이 흔들리므로 절제.

```
조작: 자동 틱 기본 + 터치 개입(맹공/수비) + 불리하면 후퇴
흐름:
  막대 2개(내 무리/적). 적 막대는 처음 가려짐 → 첫 합에 드러남 ("붙어봐야 안다")
  0.65초/합 자동 교환 (템포는 플레이 감으로 조정)
  내 무리 < 45% → [물러난다] 등장 (정보 없이 강적 만난 자의 퇴로)
  적 < 30% → 종말선택:
     · 끝을 본다 (명성↑, 원한, 전리품 적음)
     · 항복을 받는다 (무리에 흡수, 병↑)
     · 길을 터준다 (살려보냄 → 지연후과 씨앗 = 숨은 조운 복선)
  결판 → 전리품 공개 → 사서 편찬
```

나머지 해결(포섭·화해·거래)은 즉시 처리로 유지. 결투만 이 모듈로 깊게(수직 슬라이스).

**지연후과 / 숨은 조운 (설계 보류, 2R 또는 후속):**
유민 무리에 낮은 확률(~10%) [숨은 잠재] 플래그. 결투로 죽이면 소멸("범상치 않은 자가
이름 없이 스러지다"), 거래로 흩으면 타 세력행 후 적으로, 포섭/화해면 휘하 잠복 후 N턴 뒤
각성("거두었던 그 사내, 이제 ○○이라 부른다"). 자비가 기대값 게임이 되는 구조.
※ 자주 터지면 김 빠짐 — 희소성이 감동의 밀도.

## 5. 객잔 관계 시스템 — 다축 평판 → 결속 등위

### 5-1. 다축 평판 (단일 호감 → 복합 평가)
NPC는 플레이어를 여러 잣대로 동시에 읽는다. LLM은 각 축 점수만 정직하게 매기고,
어떻게 받아들일지는 NPC 가중치(코드/데이터)가 결정한다. (판단=LLM, 취향=데이터)

축: **예(禮)** 매너·말투 / **담(膽)** 호기·그릇 / **신(信)** 말과 행적의 일치 / **격(格)** 식견·됨됨이

```json
{ "reply":"인물 대사",
  "read":{ "예":-1, "담":+2, "신":-1, "격":0 },
  "inner":"건방지나 그릇은 있다… 두고 볼 만하군" }
```

**NPC별 가중치가 다르다** (단조로움 방지):
- 서생: 격·신 중시 → 무식한 큰소리에 면박
- 건달/장수: 담 중시, 예는 낮게 → 거친 호기를 오히려 좋아함
- 상인: 신(실리) 중시 → 허세보다 줄 것/받을 것 분명한 말
- 떠돌이(잠재 영웅): 격을 깊이 봄 → 어설픈 아부 안 통함

같은 말도 상대에 따라 다르게 채점. 플레이어가 상대를 읽고 화법을 바꿔야 함.
(= 마케팅의 "플랫폼마다 통하는 말투가 다르다"와 동형)

**표시 원칙**: 점수판을 직접 보여주지 않는다. NPC의 말투와 inner(속내) 흘림으로만
느끼게 한다. "이 자가 날 시시하게 보는군"을 숫자가 아니라 대사에서 읽는 것.

> **검증된 발현 (PoC v0.4)**: 명성 0 건달의 큰소리에 서생이 "칼을 들기 전에 글을 읽어야지"
> 면박. 사관평 "허세에 흔들리지 않음 · 호감 +1" — 깐깐하게 줌. 칭찬 인플레 억제 작동.

### 5-2. 이름 묻기 의식
"공의 성함이 어찌되오?" = 가림을 걷는 핵심 의식. 대화 중 언제든 시도, 응답이 3분기:
- **거절**: "불초는 한낱 떠도는 서생일 뿐, 더는 묻지 마시오" (호감 < 임계, 재시도 가능)
- **응함**: "영웅께서 이리 물으시니 하찮은 소명이나마…" (임계 충족 → 정체 공개·등용 게이트)
- **동조**: "아, 뜻이 통하는 영웅이십니다" (호감 ≫ 임계 → 먼저 따르겠다 청함)

**거물일수록 임계가 높다** — 떠돌이(잠재 조운)는 한참 공들여야 "…조자룡이라 하오"가 나온다.
늦게 열리는 이름일수록 큰 인물. 그 뜸이 긴장이고, 이름이 드러나는 순간이 작은 클라이맥스.
"언제 이름을 묻느냐"가 플레이어의 안목 — 조급하면 퇴짜, 뜸 들이면 거둔다.

### 5-3. 결속 등위
```
관계 등위 = (그가 매긴 숨은 다축 평가) + (내가 이미 가진 공적 점수: 명성·무리·야사)
```
사적 인상 + 공적 소문의 합. 무명일 땐 대화로만 승부, 이름값 쌓이면 후광이 더해짐
("그 ○○이 직접 날 찾아왔다"). 명성이 본인보다 먼저 도착한다.

| 등위 | 조건 | 결속 | 권력관계 | 무게 |
|---|---|---|---|---|
| **의기투합** | 합산 中 | 동행·협력 | 나란히 | 느슨, 더 큰 주군 만나면 흔들림 |
| **결의형제** | 합산 高 | 생사를 함께 | 나란히, 피로 묶임 | 강한 유대, 잘 안 떠남 |
| **충성맹세** | 합산 최고 + 위계 성립 | 주종(主從) | 그가 나를 위로 모심 | 절대 충성, 핵심 가신 |

**충성맹세는 호감만으론 안 열린다** — 내 격이 상대를 넘어서야 무릎 꿇는다. 거물일수록
충성받기 어렵고, 받아내면 그게 내가 주공의 격에 올랐다는 증명(이름값 폭증).
결속 등위 = 그 인재가 얼마나 단단히 내 것이냐 → 출사 시 따라오는지를 결정(2R 연결).

## 6. 관아 졸업 시퀀스 — 튜토리얼의 닫힘

### 6-1. 관아 = 개인의 거점 (현과의 구분)
| | 관아(官衙) | 현(縣) |
|---|---|---|
| 단위 | 개인의 거점 | 지역의 행정 단위(지명 고정) |
| 획득 | **혼자 힘으로** 탈취 가능 | **결코 혼자 못 함** — 세력·동맹 필요 |
| 의미 | 튜토리얼 졸업장. 첫 "내 것" | 2라운드 통치의 무대 |
| 경제 | **세금** 발생 = 첫 정주(定住) 경제 | 통치 파라미터 언락 |

관아 점령 = 유랑 건달 → 다스리는 자로의 전환. 약탈 경제(플로우) → 세금 경제(스톡).
"현을 혼자 못 먹는다"는 벽이 동맹·출사를 강제(2R 동선의 동기).

### 6-2. 명분 = 백성의 추인 (핵심 전환)
**명분은 내가 세우는 게 아니라 백성이 인정하는 것.** 난세이므로 현 관아 = 탐관은 기본값
(입증 불필요). 진짜 질문은 "저놈이 나쁜가"가 아니라 **"내가 저놈보다 나은가"**이며,
판정자는 백성이다. (= "중심을 누가 정하는가" — 정당성은 아래로부터 추인되어야 진짜)

```
명분 = 민심의 저울이 탐관 → 나로 기운 정도
  ├─ 퀘스트 수행 (백성의 곤란 해결) → "저 자는 우리를 돌본다"
  ├─ 민심 축적 (약탈 않고 베풂)     → "관아는 빼앗는데 저 자는 준다"
  └─ 명성 (탐관의 위세를 넘는 이름값) → "저 자라면 믿을 만하다"
  ※ 탐관도 수탈로 위세를 키운다 → 저울은 경주(經走)다. 늦으면 백성이 더 도탄,
     서두르면 명분 부족으로 도적질이 됨. (압력의 시간)
```

### 6-3. 졸업 = 4기능 체크 → 추대 입성
관아 공략은 1라운드 전 기능을 한 번에 쓰게 만드는 졸업 관문. 한 장소만 판 자는 못 넘는다.

입장 조건 (= 1라운드 체크리스트):
- **무력**(들판) — 교전을 치를 무리
- **민심**(퀘스트·베풂) — 백성이 안에서 성문을 열어줄 만큼
- **인재풀**(객잔·덕망) — 명분을 거들고 통솔할 사람
- **명분**(정보·명성) — 탐관을 넘어선다고 백성이 추인한 정도

```
관가에서 [탐관 인지] → 명분 쌓기(네 장소 순회) → 저울이 나로 기울면
[관아를 친다] 언락 (명분 없으면 안 열림 / 열려도 '도적질' 경로)
  ↓ 교전 — 민심이 보정: 성문이 안에서 열리고 백성이 호응 (혼자 아닌 "민중과 함께 입성")
관아 점령 → 명분의 크기가 작명의 질을 결정:
  · 추인된 점령 → 빛나는 이름(義) + 안정된 세금·민심 + "현을 노린다" 언락
  · 강압된 점령 → 탁한 이름 + 불안한 출발 (탐관을 도적으로 갈아치운 것뿐)
```

힘으로 가질 순 있어도 정당성은 못 산다. (= BM 헌법 "결제는 안락을 살 뿐 영광은 못 산다"와 동형)
무명 건달의 첫 이름이 **추대받은 의병장**으로 새겨지는 것 — 선언문 "蒼天已死, 그래서
우리가 일어났다"가 한 고을에서 구현되는 첫 사례.

## 7. 관가의 미래 변주 (2R 이후, 봉인)

관가는 플레이어 노선에 따라 얼굴이 바뀌는 유일한 장소 = **체제 거리 다이얼**.
1R에선 '탐관의 소굴(졸업 관문)'로만 쓰고, 아래는 관계 변수(관 우호도·황건 정체성) 선행 후 개방:
- **현상금 게시처**: 역적·도적 토벌 의뢰. 단 동족(황건 잔당) 토벌이면 자기모순 딜레마.
- **탐관의 서식지**: 점유 후 통치 막의 '탐관 퇴출' 표적.
- **관 퀘스트처**: 체제 안으로 한 발 = "조조에게 출사"의 축소판. 엮일수록 황건 정체성에서 멀어짐.
