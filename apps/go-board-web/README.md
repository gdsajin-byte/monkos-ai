  - 불러온 기보는 보기 전용 방(`up-{sha1 12자}`, `source: upload`, 원본 파일명 보관)이 된다. 같은 내용을 다시 올리면 기존 방으로 안내한다. 원본은 `~/.monkos/go-board/uploads/`(테스트는 `_test/uploads`)에 보관.

  - GIB(타이젬): 헤더 `\[KEY=값\]`과 수순 `STO 0 n 색(1흑·2백) x y`(0부터, y는 위에서부터)를 읽는다. `INI` 치석은 GTP 표준 배치(3점 = D4·Q16·D16, 실기보로 확인), 덤은 GONGJE/10, 결과는 영·한 문구에서 뽑는다. 인코딩은 UTF-8, 실패하면 CP949로 읽는다.
  - 실패는 `❌ 불러오기 실패: {파일명} — {사유}`로 보인다(19줄 외·깨진 SGF·1MB 초과·형식 아님 실측).
  - 픽스처: `fixtures/`(README에 출처·MIT 고지).

## 그래프는 보는 곳에서만 (2026-10-25, 쌍아-막내17 — ORDER_20261025 그래프 보는 곳에서만)
