# 작가님 녹음 넣는 곳

여기에 WAV를 넣고 바둑판 페이지를 새로 고치면 기본 착수음 대신 이 녹음을 쓴다(서버 재기동 불필요).

- `stone*.wav` → 착수음 (예: `stone_1.wav`, `stone_2.wav` — 여러 개면 돌아가며 재생)
- `capture*.wav` → 따냄 소리
- 파일 이름은 영문·숫자·`_`·`-`만. 한글 이름은 무시된다.
- 권장: 돌이 닿는 순간부터 0.3~0.5초로 자른 짧은 파일(앞 무음이 길면 그만큼 늦게 들린다).

녹음을 레포에 올릴지는 작가님 판단 — 올리지 않으려면 커밋 전에 빼 둔다.
