# 판·돌 디자인(스킨팩) 규격

> 2026-10-23 iMac/쌍아-막내13. 출처: 작가님 14:2x "바둑판 바둑돌 디자인도 일단 캡처해서 적용해, 나중에 클로드 디자인에게 더 멋지게 만들라고 하자" (쌍아 전달).
> 목적: Claude Design 시안을 코드 수정 없이 폴더 하나로 꽂는다.

## 위치

레포 **밖** `~/.monkos/go-board-skins/<팩 이름>/` — 팩 이름은 영문·숫자·`_`·`-`. 서버가 `/skin/<팩>/<파일>`로 내보낸다(jpg·jpeg·png·webp만, 다른 파일은 404).
화면 '판·돌 디자인'에서 팩을 고르고, 팩 안에 판·돌 이미지가 여러 장이면 '판'·'돌' 선택지가 함께 나온다. 선택은 브라우저에 저장된다.

## 파일

| 파일 | 내용 |
|---|---|
| 판 이미지(`*.jpg` 또는 이름에 `board`) | 정사각형 권장(800×800 이상). **격자선·화점·좌표는 넣지 않는다** — 화면이 그린다. 비율이 다르면 가운데를 잘라 채운다 |
| 돌 스프라이트(`*stone*.png`) | 투명 PNG 한 장에 백·흑 돌. 칸 좌표는 skin.json `white`·`black` |
| `skin.json`(선택) | 아래 값. 없으면 기본값으로 해석 |
| `README.txt`(선택) | 첫 줄이 팩 표식. "내부"가 들어 있으면 선택지에 '(내부 실험 — 출시 전 교체)'가 붙는다 |

## skin.json

```json
{
  "board": "board.jpg",
  "stones": "stones.png",
  "sprite": [256, 240],
  "white": [0, 112, 128, 128],
  "black": [128, 112, 128, 128],
  "stoneScale": 1.0,
  "grid": "#3a2c18",
  "gridWidth": 0.7,
  "shadow": { "dx": 0.8, "dy": 1.2, "blur": 0.8, "opacity": 0.35 }
}
```

| 키 | 뜻 | 기본값 |
|---|---|---|
| `board` · `stones` | 기본으로 쓸 판·돌 파일 | `en`으로 시작하는 파일, 없으면 첫 파일 |
| `sprite` | 스프라이트 전체 크기(px) | `[256, 240]` |
| `white` · `black` | 돌 한 개의 칸 `[x, y, 너비, 높이]`(px). 칸이 판 한 칸(줄 간격)에 맞춰 늘어난다 — 돌 둘레 여백도 칸에 포함 | 128px 칸(백 왼쪽·흑 오른쪽, y=112) |
| `stoneScale` | 칸 대비 돌 크기 배율 | `1.0` |
| `grid` · `gridWidth` | 격자선·화점·좌표 색과 선 굵기(판 400 단위 기준) | `#3a2c18`, `0.7` |
| `shadow` | 돌 그림자(SVG drop-shadow, 판 400 단위) | 위 값 |

## 현재 팩

- `tygem-ref` — 내부 실험 전용 참조본(쌍아 수집, 출시 전 자체 디자인으로 교체 — 원장 191). **레포 복사·커밋 금지.** skin.json 없이 기본값으로 해석된다. 스프라이트 좌표 실측(10-23): 256×240, 128px 칸 백 (0,112)·흑 (128,112) — enstone3·stone_1~3·9·10은 돌이 칸을 꽉 채움, stone_4~8은 칸 안 120px 돌(여백 4px).
