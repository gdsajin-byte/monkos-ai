===== 핵심 기술 =====

4개 연구과제:
1. [1-1] AI 이미지 정체성 유지율 90% 달성, 외부 API 의존율 50% 이하로 기술 자립화
2. [1-2] 자체 고해상도 파이프라인으로 인쇄품질(300dpi) 실사 이미지 대형 출력 실현
3. [1-3] Human-AI 협업 기반 자가 진화 파이프라인 — 사용할수록 K-뷰티 도메인에 특화되어 스스로 진화하는 지능
4. [1-4] 소상공인 맞춤 AI 챗봇 탑재 저비용 홈페이지 서비스 사업화

핵심 파이프라인 7단계:
1단계 데이터 수집 → 2단계 전처리·필터링 → 3단계 AI 검수 → 4단계 모델 학습(LoRA·파인튜닝) → 5단계 AI 평가 → 6단계 전문가 큐레이션(RLHF) → 7단계 배포

GPU(RTX 5090×2)의 목적: 서비스 서버가 아닌 연구장비. VRAM 확보를 통한 오픈소스 모델 적재·MLOps·파인튜닝용.
클라우드 API = 프로덕션 서비스, 로컬 GPU = R&D. 이 병렬 구조가 API 의존율 50% 목표의 핵심.

===== 반박서 핵심 — 8건 지적에 대한 반론 =====

① "발색 수치 정확성 미흡"
→ 제안서에 "발색"이라는 단어가 0회 기재. 핵심 연구과제는 "인물 정체성 유지율 90%". K-뷰티를 화장품 발색으로 전제한 과제 오독.

② "GPU 처리 속도 방안 부족"
→ GPU는 서비스 서버가 아닌 연구장비(파인튜닝·MLOps용 VRAM). 연구 단계표에서 3단계(4~7월) 도입 → 4단계 파인튜닝. 서비스 인프라라면 1단계에 와야 함. 연구장비를 서버로 오독.

③ "전문가 편향 우려"
→ RLHF는 GPT·Gemini 등 글로벌 AI의 표준 학습 방법론. 뷰티에 절대적 정답이 없으므로 "편향"의 판단 기준 자체가 부재. 파이프라인 3단계(AI 검수)+5단계(AI 평가)가 전문가 큐레이션을 양면 교차 검증.

④ "범용 GenAI 대비 차별성 미흡"
→ 자가 진화 파이프라인은 "차별점"이 아니라 모든 AI 서비스의 핵심 엔진. AI 서비스를 앱처럼 고정된 제품으로 이해한 오류. 실제로 6개 서비스가 가동 중이며 진화 중.

⑤ "크롤링 저작권 리스크"
→ 크롤링은 데이터 수집의 일반명사(Google도 네이버도 크롤링 기업). 서비스 이미지는 100% 사용자 본인 사진 기반 AI 재생성이므로 저작권 분쟁 구조 자체가 부재. R&D 계획서에 수익 배분 방안 요구는 평가 범위 초과.

⑥ "빅테크(Adobe·Runway·Stitch Fix) 대비 경쟁력 부족"
→ Adobe Firefly는 크리에이티브 도구, Runway는 영상 생성, Stitch Fix는 의류 추천 — 세 기업 모두 증명사진 서비스가 없으며 시장·고객·가치제안이 겹치지 않음. 범주 오류. 빅테크는 엔진 공급자이지 경쟁자가 아님.

⑦ "고해상도 비용과 저비용 서비스 간 모순"
→ 1-2항(고해상도)과 1-4항(저비용 챗봇)은 서로 다른 연구과제이자 서로 다른 상품 라인. 제안서 작성 시점(25.12) AI 출력 1024×1024 → 3개월 후 AI 엔진 자체 업스케일 도입. 현 시점 1회 원가 $0.04, 판매가 $10. 모순이 아니라 기술 진화가 해소.

⑧ "사업화 전략 구체성 미흡"
→ 디딤돌은 R&D 연구과제이지 투자 심사가 아님. 6개 서비스 개발·배포, 결제 연동, KOITA 인증, OAuth 획득, SNS 파이프라인, 연구원 고용 — 서류가 아닌 실행으로 증명 중. 20페이지 제한 내 사업화 전략은 최대 1페이지로 제한되는 포맷 구조적 한계.
