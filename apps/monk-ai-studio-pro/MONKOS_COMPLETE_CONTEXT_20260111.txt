3. 핵심 기술 아키텍처
================================================================================

[전체 구조]

Browser (React Frontend :3000)
    ↓ HTTP Requests
Backend Proxy (Express :3001)
    ↓ API Key (Secure)
AI Engines (Vertex/Anthropic/MonkOS)
    ↓
Generated Images
    ↓
Storage (Cloudflare R2 + D1)

[백엔드 프록시]
파일: backend/server.js
프레임워크: Express
포트: 3001
주요 역할:
- API 키 보안 관리
- 요청 프록시
- 에러 핸들링
- 로깅

엔드포인트:
1. POST /api/generate
   - Imagen 4.0 배치 생성 (4장)
   - aspectRatio, safetyLevel 설정
   - Base64 이미지 반환

2. POST /api/refine  
   - I2I/EDIT/UPSCALE
   - 입력 이미지 + 프롬프트
   - mode: I2I, EDIT, UPSCALE
   - imageSize: 1K, 2K, 4K

3. POST /api/analyze
   - Gemini 3 Pro Vision
   - 이미지 분석
   - JSON 스키마 응답 (prompt, style, tags)

[프론트엔드]
파일: App.tsx (주요 로직)
프레임워크: React 19 + TypeScript
빌드: Vite 6.2

주요 컴포넌트:
- Header.tsx: 로고, 언어 전환, 로그, 내보내기
- Sidebar.tsx: 모드 선택, 프롬프트, 빠른 변주, 설정
- QuickVariations.tsx: 6개 변주 버튼 (확장 가능)
- BatchDisplay.tsx: 배치 이미지 그리드
- PromptSection.tsx: 3단 프롬프트 시스템
- ControlPanel.tsx: 비율 선택

상태 관리:
- useState 기반
- LocalStorage (프롬프트 영속성)
- 히스토리 관리 (GeneratedImage[])

[프롬프트 템플릿 시스템]
파일: promptTemplates.ts

핵심 개념:
- 정체성 유지 고정 프롬프트 (IDENTITY_PRESERVATION)
- 카테고리별 변주 템플릿 (VARIATION_TEMPLATES)
- 자동 프롬프트 생성 (createVariation, getRandomVariation)

정체성 유지 프롬프트:
"CRITICAL INSTRUCTION: Maintain the exact facial features, body proportions, 
skin tone, facial structure, eye shape, nose, lips, and overall model identity. 
Preserve the person's unique characteristics completely and precisely."

변주 프롬프트 구조:
- 고정부: 정체성 + 유지할 요소
- 변주부: 변경할 요소만 명시

예시 (의상 변경):
고정: "정체성, 포즈, 배경, 조명 유지..."
변주: "casual summer dress, light fabric, relaxed style"

[서비스 레이어]
파일: services/geminiService.ts

주요 메서드:
- generateBatch(prompt, config): T2I 4장 배치 생성
- refineImage(prompt, config): I2I/EDIT/UPSCALE 1장
- analyzeImage(imageData): 이미지 분석

모든 메서드가 백엔드 API 호출로 변경됨 (보안)

파일: services/storageService.ts
- saveImage(): Cloudflare R2 + D1 저장
- saveBatch(): 배치 저장

[타입 시스템]
파일: types.ts

주요 타입:
- SynthesisMode: 'T2I' | 'I2I' | 'EDIT' | 'UPSCALE'
  (UI에서는 T2I, I2I만 노출, EDIT/UPSCALE은 내부 사용)
- AspectRatio: '1:1' | '3:4' | '4:3' | '9:16' | '16:9'
- ImageSize: '1K' | '2K' | '4K'
- SafetyLevel: BLOCK_NONE (디폴트)
- GeneratedImage: 이미지 메타데이터 구조
- AppState: AUTH | MAIN | LOADING

4. 핵심 혁신: 고정 프롬프트 변주 시스템
================================================================================

[문제 인식]
기존 AI 이미지 생성 도구들의 문제:
1. 매번 긴 프롬프트 작성 필요
2. 정체성 유지 어려움 (얼굴이 미묘하게 변경됨)
3. 실수 빈번 (프롬프트 오타, 빠뜨림)
4. 시행착오 많음 (15분/변주)
5. 비효율적 (반복 작업에 부적합)

[MONKOS의 해결책]

고정 프롬프트 변주 시스템:
- 정체성 유지는 자동 (시스템이 처리)
- 변경 원하는 부분만 명시
- 버튼 클릭만으로 완성
- 실수 제로, 일관성 보장

작동 원리:

Step 1: 카테고리 선택 (버튼 클릭)
[👕 의상] 버튼 클릭

Step 2: 시스템이 자동으로 프롬프트 조합
고정: "Maintain exact facial features, body proportions, skin tone, facial structure, eye shape, nose, lips, and overall model identity. Maintain current pose, background, and lighting exactly. Only change clothing."
변주: "casual summer dress, light fabric, relaxed style" (랜덤 또는 사용자 지정)

Step 3: I2I 생성 실행
결과: 정체성 완벽 유지 + 의상만 변경

Step 4: 반복 가능
[🚶 포즈] 클릭 → 의상 유지 + 포즈 변경
[🖼️ 배경] 클릭 → 모델/의상 유지 + 배경 변경

[실사용 시나리오: 모델 에이전시]

목표: 다인 모델의 캐주얼 룩북 100장 제작

기존 방식:
- 스튜디오 촬영 10회
- 의상 교체, 포즈 변경, 조명 조절
- 시간: 1개월
- 비용: 3,000만원

MONKOS 방식:
1. 다인 모델 확정 이미지 1장 업로드
2. [👕 의상] × 10회 클릭 → 10가지 의상
3. 각 의상마다 [🚶 포즈] × 5회 클릭 → 50가지 포즈
4. 각 조합마다 [🖼️ 배경] × 2회 → 100장 완성
5. 마음에 드는 10장만 [4K] 업스케일
- 시간: 1-2일
- 비용: 10만원

ROI: 300배 개선

[UI 구조]

빠른 변주 섹션 (I2I 모드 + 소스 이미지 있을 때만 표시):

기본 사용 (원클릭):
[🚶 포즈] 클릭
→ 디폴트 포즈 변주 자동 실행

고급 사용 (옵션 확장):
[🚶 포즈] 옆 [▼] 클릭
→ 확장 옵션 표시
  ├─ 텍스트 입력: "walking pose, confident"
  ├─ 이미지 드롭: 포즈 레퍼런스 사진
  └─ [변주 실행] 버튼

향후 (인페인팅):
[👕 의상] + 드레스 사진 드롭
→ 정확히 그 드레스를 모델에게 입힘

사용자 액션 (기본):
1. "변주" 모드 선택
2. 소스 이미지 업로드 (96×96 버튼 클릭)
3. 빠른 변주 버튼 클릭 (예: [👕 의상])

시스템 처리:
1. VARIATION_TEMPLATES에서 'outfit' 템플릿 로드
2. 고정 프롬프트 자동 설정
   "Maintain exact facial features... Only change clothing."
3. 변주 프롬프트 자동 설정
   "casual summer dress, light fabric, relaxed style"
4. 백엔드 /api/refine 호출
5. Imagen 3 Pro로 I2I 생성 (1K)
6. 결과 이미지 수신
7. 히스토리 추가
8. 포커스 뷰로 자동 전환

결과:
- 정체성 완벽 유지
- 의상만 변경된 1K 이미지
- 즉시 확인 가능

기능: 빠른 변주 버튼 클릭 시 자동으로 프롬프트 설정

매개변수:
- category: 'pose' | 'outfit' | 'background' | 'hair' | 'lighting' | 'accessory'
- customPrompt: 사용자 지정 텍스트 (선택)
- referenceImage: 레퍼런스 이미지 (선택, 향후)

처리 흐름:
1. createVariation(category, customPrompt) 호출
2. 템플릿에서 고정 프롬프트 가져오기
3. 변주 프롬프트 가져오기 (커스텀 또는 랜덤)
4. setFixedPrompt(고정) - 정체성 유지
5. setPrompt(변주) - 변경 요소
6. setMode('I2I') - I2I 모드로 자동 전환
7. setError(null) - 에러 초기화
8. 콘솔 로그

사용자는 버튼만 클릭, 나머지는 자동!

[performSynthesis - 생성 실행]

위치: App.tsx, 약 370번 줄

기능: T2I 또는 I2I 생성 실행

처리 흐름:
1. 프롬프트 조합 (고정 + 메인 + 네거티브)

3. 유효성 검사
4. setIsGenerating(true) - 로딩 시작
5. mode에 따라 분기:
   
   T2I:
   - GeminiService.generateBatch() 호출
   - 4장 생성
   - setCurrentBatch(urls) - 배치 저장
   - setViewMode('grid') - 그리드 표시
   - 로그 기록
   
   I2I/EDIT/UPSCALE:
   - GeminiService.refineImage() 호출
   - 1장 생성
   - setHistory 추가
   - setViewMode('single') - 포커스 표시
   - 로그 기록

7. setIsGenerating(false) - 로딩 종료

[백엔드 엔드포인트 상세]

1. POST /api/generate

요청:
{
  "prompt": "combined prompt with negative",
  "config": {
    "aspectRatio": "16:9",
    "safetyLevel": "BLOCK_NONE"
  }
}

처리:
- GoogleGenAI 초기화
- generateImages() 호출
  * model: 'imagen-4.0-generate-001'
  * numberOfImages: 4
  * aspectRatio 설정
- Base64 이미지 배열 반환

응답:
{
  "success": true,
  "images": ["data:image/png;base64,...", ...]
}

2. POST /api/refine

요청:
{
  "prompt": "variation prompt",
  "config": {
    "aspectRatio": "1:1",
    "imageSize": "1K",
    "safetyLevel": "BLOCK_NONE"
  },
  "inputImage": "data:image/png;base64,...",
  "mode": "I2I"
}

처리:
- 입력 이미지 파싱 (Base64)
- mode에 따른 instruction 생성
  * I2I: "Using image as foundation, synthesize..."
  * EDIT: "Modify based on instructions..."
  * UPSCALE: "4K reconstruction, enhance..."
- generateContent() 호출
  * model: 'gemini-3-pro-image-preview'
  * imageConfig: aspectRatio, imageSize
- 이미지 추출 및 반환

응답:
{
  "success": true,
  "image": "data:image/png;base64,..."
}

3. POST /api/analyze

요청:
{
  "imageData": "data:image/png;base64,..."
}

처리:
- Gemini 3 Pro Vision 호출
- JSON 스키마 응답 강제
  * prompt: STRING
  * style: STRING
  * tags: ARRAY[STRING]
- 파싱 및 반환

응답:
{
  "success": true,
  "analysis": {
    "prompt": "detailed recreate prompt...",
    "style": "artistic style description...",
    "tags": ["tag1", "tag2", ...]
  }
}
