# 크로스포스팅 패턴 성공/실패 기록

> 2026-03-23 작가님 직접 교정
> 원본 세션: "AI 사진으로 여권사진이 가능한가?" 3개 언어 크로스포스팅

## 성공 패턴

### MONKOS 블로그 본문 수정 (에디터 API 직접 제어)
- **방법**: `getEditor()` → `getMarkdown()` → 수정 → `setMarkdown()`
- **결과**: ✅ 성공 — 소제목 삽입, 띄어쓰기 교정, SEO 요약 입력 모두 정상 반영
- **핵심**: 자체 플랫폼이므로 에디터 API 접근 가능, JS 모듈 import로 인스턴스 확보

### 티스토리 — 복붙 (작가님 방식)
- **방법**: MONKOS 블로그 라이브 페이지에서 본문 전체선택(Ctrl+A) → 복사(Ctrl+C) → 티스토리 기본모드에 붙여넣기(Ctrl+V)
- **결과**: ✅ 이미지 포함 완벽 삽입
- **핵심**: WYSIWYG ↔ WYSIWYG 간 브라우저 클립보드가 서식+이미지를 함께 전달

### note.com — X(트위터) 공유
- **방법**: 발행 완료 팝업에서 X 아이콘 클릭 → 트윗 작성 팝업 → 게시
- **결과**: ✅ @MONKOS_AI 태그 + note.com 링크 자동 포함

### Medium — 발행 + X 공유
- **방법**: ProseMirror 에디터에 ClipboardEvent paste로 HTML 주입 → Publish → Share on X
- **결과**: ✅ 본문·소제목·볼드·링크 모두 정상, X 공유 정상

## 실패 패턴

### ❌ 티스토리 — API 주입 방식 (막내 방식)
- **시도한 방법**: HTML 모드(CodeMirror)에 setValue → 기본모드 전환 → 내용 소실 → TinyMCE API setContent 재시도
- **결과**: 에디터 내부에서는 렌더링 보였으나, 실제 발행 시 본문 비어있음
- **원인**: 에디터 모드 전환 시 내부 동기화 불완전. TinyMCE setContent 후에도 발행 데이터에 반영 안 됨
- **교훈**: **복붙이 가장 확실하다. 엔지니어링 삽질 전에 단순한 방법 먼저.**

### ❌ note.com — 이미지 없이 텍스트만 게시
- **시도한 방법**: ClipboardEvent paste로 HTML 주입 (이미지 태그 제외)
- **결과**: 텍스트만 올라감, 이미지 전혀 없음
- **원인**:
  1. note.com은 외부 이미지 URL을 허용하지 않음 (자체 CDN만 사용)
  2. 작가님이 라이브 페이지에서 복붙 시도 → 텍스트는 들어가나 이미지 영역은 로딩 시도 후 실패
- **교훈**: **note.com 이미지는 에디터 내 직접 업로드(드래그/+ 버튼)만 가능. 텍스트 복붙 → 이미지 수동 삽입 순서로 진행**

## 플랫폼별 크로스포스팅 SOP

| 플랫폼 | 텍스트 | 이미지 | 권장 방식 |
|--------|--------|--------|----------|
| **티스토리** | 복붙 ✅ | 복붙 ✅ | 라이브 페이지에서 전체선택 → 복붙 (1단계 완료) |
| **note.com** | 복붙 ✅ | 복붙 ❌ | 텍스트 복붙 → 이미지 위치에 수동 업로드 |
| **Medium** | API paste ✅ | 외부URL ❌ | ClipboardEvent paste로 텍스트+서식 → 이미지는 Medium 자체 업로드 |

### 절대 원칙
1. **단순한 방법 먼저 시도** — 복붙으로 되면 API 안 건드린다
2. **발행 전 라이브 미리보기 필수** — 에디터에서 보이는 것 ≠ 실제 발행물
3. **이미지는 플랫폼별 제약 확인** — 외부 URL 허용 여부가 핵심 분기점
