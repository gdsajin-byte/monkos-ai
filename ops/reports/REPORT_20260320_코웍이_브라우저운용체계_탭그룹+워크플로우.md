## 4. 운용 원칙

### 탭그룹 vs 북마크 사용 기준

| 기준 | 탭그룹 (상시 열기) | 북마크 (필요 시) |
|------|-------------------|----------------|
| 사용 빈도 | 매일 또는 작업 시 항상 | 주 1~2회 이하 |
| 예시 | note.com, GSC, Canva | KOITA, Unsplash, 경쟁사 |
| 메모리 부담 | 높음 → 7~10탭 이내 권장 | 없음 |

### 일상 운용 패턴

**출근 시 (기본 탭그룹 3개)**
- TG2 체크/분석 — GSC + GA 빠르게 확인
- TG1 배포 — 오늘 배포할 채널만 열기
- TG6 본진 — 서비스 상태 확인

**콘텐츠 작업 시 (추가)**
- TG3 제작 — Canva, YouTube Studio

**지원금 작업 시 (전환)**
- TG4 R&D — 해당 사이트만 열기

**레퍼런스 서칭 시 (전환)**
- TG5 크롤링/레퍼런스 — 필요 카테고리만

    │
    ├─ [코웍이] 브라우저 배포 — TG1 탭그룹 사용
    │   ├─ note.com → JA 경어체 직접 작성

    │   ├─ 네이버 블로그 → KR 직접 작성

    └─ [코웍이] 체크 — TG2 분석 도구 사용

## 7. 결정 필요 사항

1. **탭그룹 7개 체계 승인** — 과다 시 축소 가능
2. **북마크 폴더 구조 확정** — Chrome 프로필에 바로 세팅 가능
