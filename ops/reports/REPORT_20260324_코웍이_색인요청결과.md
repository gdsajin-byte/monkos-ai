- 크롤링 허용: 예 / 페이지 가져오기: **실패(404)**

**추정 원인**: 서버 라우팅이 `/ja/` (트레일링 슬래시 포함) 경로를 제대로 핸들링하지 않을 가능성. `/?lang=ja` 방식으로만 서빙되는 구조라면 `/ja/` 경로는 서버에서 리라이트 또는 리디렉션 필요.

**→ 쌍아 확인 요청**: `server.js` 라우팅에서 `/ja/`, `/ja/blog`, `/ja/faq` 경로 처리 로직 점검. `/ja/blog`과 `/ja/faq`은 색인 요청이 접수됐으므로 실제로는 200을 반환하는 것으로 보임 — `/ja/`만 문제일 수 있음.

- 하지만 SEO를 위해서는 최소한 메타태그와 기본 HTML은 서버에서 제공해야 함

**→ 쌍아 확인 요청**: `idphoto-jp` 서버의 `/shoot` 경로 SSR 여부 점검
