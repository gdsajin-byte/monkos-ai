## 원인 (브라우저 직접 확인)

### 매거진 카드 — 현재 렌더 HTML

```html
<div class="mag-img" style="background:linear-gradient(135deg,#f0eee8,#e8e5de)">
  <span class="icon">🤖</span>
  <span class="tag tip">클로드</span>
</div>
```

- `<img>` 태그 없음, `background-image`에 thumbnail URL 미적용
- `post.thumbnail` 존재 여부 체크 로직 자체가 없음

### 블로그 리스트 — 현재 렌더 HTML

```html
<div class="bi-thumb">🤖</div>
```

- `<img>` 태그 없음, 이모지 텍스트만 삽입
- thumbnail URL 참조 로직 없음

### Firestore 데이터 상태

- `thumbnail` 필드: 정상 존재 (크롤링 시 저장됨)
- 블로그 상세 페이지: 해당 이미지 정상 표시 ✅
- 홈 메인 양쪽 영역에서만 미반영 ❌

## 수정 내용

### 1. 매거진 카드 (`.mag-img`)

```js
// AS-IS: thumbnail 무시
`<div class="mag-img" style="background:linear-gradient(135deg,#f0eee8,#e8e5de)">
  <span class="icon">🤖</span>
  <span class="tag tip">${tag}</span>
</div>`

// TO-BE: thumbnail 있으면 이미지 사용
const magStyle = post.thumbnail
  ? `background:url('${post.thumbnail}') center/cover no-repeat; background-color:#f0eee8`
  : `background:linear-gradient(135deg,#f0eee8,#e8e5de)`;

const magIcon = post.thumbnail
  ? ''
  : `<span class="icon">${emoji}</span>`;

`<div class="mag-img" style="${magStyle}">
  ${magIcon}
  <span class="tag tip">${tag}</span>
</div>`
```

**포인트**:
- thumbnail 존재 시 `background-image`로 표시, icon 숨김
- tag 라벨은 thumbnail 유무와 관계없이 유지 (카테고리 식별)
- `background-color` 보조 → 이미지 로드 실패 시 graceful fallback

### 2. 블로그 리스트 (`.bi-thumb`)

```js
// AS-IS: 이모지만
`<div class="bi-thumb">${emoji}</div>`

// TO-BE: thumbnail 있으면 이미지
post.thumbnail
  ? `<div class="bi-thumb"><img src="${post.thumbnail}" alt="${post.title}" loading="lazy" style="width:100%;height:100%;object-fit:cover;border-radius:inherit;"></div>`
  : `<div class="bi-thumb">${emoji}</div>`
```

**포인트**:
- `<img>` 태그 사용 (SEO alt 텍스트 포함)
- `loading="lazy"` 적용 (메인 페이지 성능)
- `object-fit:cover` → 비율 유지하며 영역 채움
- thumbnail 없는 글은 기존 이모지 fallback 유지

## CSS 보강 (필요 시)

```css
/* 블로그 썸네일 이미지 오버플로 방지 */
.bi-thumb img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  border-radius: inherit;
}

/* 매거진 카드 이미지 위 태그 가독성 */
.mag-img .tag {
  position: relative;
  z-index: 1;
  /* 이미지 배경 위에서도 태그 텍스트 가독성 확보 */
  text-shadow: 0 1px 2px rgba(0,0,0,0.3);
}
```
