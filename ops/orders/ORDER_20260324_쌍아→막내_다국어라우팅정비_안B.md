## 수정 2. renderHome forceLang 파라미터 추가 (home.js)

**파일**: `monkos_AI/portal/lib/cms/home.js`
**위치**: 70행 함수 시그니처 + 85행 lang 결정

수정 전:
```javascript
export async function renderHome(req, res) {
  // ...
  const lang = reqUrl.searchParams.get('lang') || 'ko';
```

수정 후:
```javascript
export async function renderHome(req, res, forceLang = null) {
  // ...
  const lang = forceLang || reqUrl.searchParams.get('lang') || 'ko';
```

### 주의사항
- `/?lang=ja` 기존 호출도 그대로 동작 (하위 호환)
- `forceLang`이 null이면 현행 로직 100% 동일

### 완료 조건

## 수정 5. i18n.js 언어 전환 경로 보정

**파일**: `monkos_AI/portal/public/js/i18n.js`
**위치**: 122-124행

수정 전:
```javascript
if (window.location.pathname === '/' || window.location.pathname === '/index.html') {
  window.location.href = '/?lang=' + newLang;
  return;
}
```

수정 후:
```javascript
if (window.location.pathname === '/' || window.location.pathname === '/index.html'
    || window.location.pathname === '/ja/' || window.location.pathname === '/ja'
    || window.location.pathname === '/en/' || window.location.pathname === '/en') {
  if (newLang === 'ko') window.location.href = '/';
  else window.location.href = '/' + newLang + '/';
  return;
}
```

### 주의사항
- `/ja/`에서 KO 선택 시 `/`로 이동
- `/`에서 JA 선택 시 `/ja/`로 이동
- 비홈 페이지 언어 전환은 기존 `applyLang()` 유지

### 완료 조건
