## 태스크 3. 건2 보고서 정정 — `/shoot` 경로 오류

코웍이가 건2에서 `idphoto-jp.monkos.ai/shoot`에 색인 요청했으나, **`/shoot` 경로는 존재하지 않음.**

idphoto-jp 촬영 플로우 실제 경로:
```
/app → /prep → /camera → /result → /thankyou
```

이 기능 페이지들은 `robots.txt`에서 전부 `Disallow` 처리됨 — **색인 대상 아님.**

사이트맵에도 미포함. 검색으로 유입될 페이지가 아니라 앱 내부 플로우.

→ `/shoot` 색인 거부는 정상 동작. 보고서의 "(B) `/shoot` 색인 거부" 항목은 **정정 필요 없이 종결.**
