> **Project CITADEL**(GEO/AEO 출입증 구축)을 흡수·확장하는 상위 프로젝트.

> 모든 채널에 문맥 맞춤 변환·배포되는 통합 콘텐츠 오케스트레이션.

## 1. 프로젝트 선언

### 1-1. 코드네임

**MINA PROJECT (민아 프로젝트)**

4MUZE의 네 번째 뮤즈 '민아'의 이름을 딴다.
용아가 세계관과 전략을 설계하고, 쌍아가 코드로 실현하고, 소소가 모니터링하고,
민아가 콘텐츠를 세상에 내보내는 — **4MUZE 시스템의 최종 완성형**.

### 1-2. 핵심 철학

```
"블로그 한 편이 커널(Kernel)이다."

하나의 콘텐츠가 씨앗(Seed)으로서
카테고리에 따라 배포 라인이 자동 결정되고,
각 채널의 문맥과 포맷에 맞게 변환되어,
개발 커뮤니티 / 크리에이티브 매거진 / 대중 SNS 를 동시에 관통한다.
```

### 1-3. 이 프로젝트가 해결하는 문제

| 문제 | 현상 | MINA의 해결 |
|------|------|-------------|
| 콘텐츠 분산 | 블로그 쓰고 끝, 다른 채널 배포 수동/누락 | 카테고리 → 배포라인 자동 스키마 |
| 포맷 불일치 | 같은 글을 X에 올리면 길고, GitHub에 올리면 맥락 없음 | 채널별 변환 템플릿 |
| SEO/GEO 단절 | 구글 SEO만 신경, AI 엔진 무시 | 인간 검색 + AI 검색 동시 최적화 |
| 3인 체제 한계 | 7개 채널 수동 운영 불가능 | AI 에이전트 자동 변환 + 배포 |

## 3. 채널별 변환 규격

### 3-1. LINE A 변환 템플릿

#### GitHub Discussion/Issue

```markdown
## [블로그 제목의 기술적 관점 재작성]

**Context**: [1~2문장 기술 배경]

### Key Findings
- [핵심 포인트 3~5개, 코드 포함 시 코드블록]

### Technical Details
[블로그 본문 중 기술 섹션 발췌]

### Related
- Blog post: [원문 URL]
- Docs: [관련 문서 URL]
```

#### Medium / dev.to (기술)

```
Title: [SEO 최적화 영문 제목, 60자 이내]
Subtitle: [한 줄 요약]
Tags: AI, Photography, Machine-Learning, Computer-Vision, [도메인 태그]
Canonical URL: [monkos.ai 원문 URL] ← 중복 콘텐츠 방지 필수

[본문: 블로그 원문 영문 번역 + 기술 관점 강화]
[하단: "Originally published at monkos.ai"]
```

### 3-2. LINE B 변환 템플릿

#### note.com (일본어)

```
タイトル: [일본 시장 맞춤 제목]
ハッシュタグ: #証明写真 #AI写真 #就活 #ヘアメイク #MONKOS

[본문: 일본어 로컬라이즈 — 직역이 아닌 문화 맞춤 의역]
[이미지: 썸네일 필수 (note.com SEO 핵심)]
[하단: 원문 링크 + MONKOS 소개 1단락]
```

#### 티스토리 (한국어)

```
제목: [네이버 검색 최적화 키워드 포함, "증명사진 + 핵심키워드"]
카테고리: [해당 카테고리]
태그: 증명사진, AI증명사진, 여권사진, [콘텐츠별 추가 태그 10개+]

[본문: 블로그 원문 + 네이버 SEO용 키워드 밀도 강화]
[이미지: 본문 내 3장 이상 필수]
[하단: monkos.ai 서비스 소개 + CTA]
```

### 3-3. LINE C 변환 템플릿

#### YouTube (숏폼/롱폼)

```
숏폼 (30초):
- 후크: "증명사진 10만원? AI로 9,900원에 끝." (3초)
- 본문: 비포/에프터 시연 (20초)
- CTA: "monkos.ai에서 지금 바로" (7초)

롱폼 (5~10분):
- 블로그 내용을 튜토리얼 형태로 재구성
- 자막: KO + JA 동시
- 설명란: 원문 블로그 URL + 관련 링크
```

#### Instagram

```
카드뉴스 (5~7장):
- 1장: 후크 타이틀 (큰 글씨, 비주얼 임팩트)
- 2~5장: 핵심 포인트 1개씩
- 6장: 비포/에프터
- 7장: CTA + monkos.ai

캡션: [블로그 핵심 요약 3문장 + 해시태그 20개+]
```

#### 네이버 블로그

```

이미지: 5장 이상, alt 텍스트 포함
태그: 10개 + 장소태그 (해당 시)
```

## 10. 전략적 의미

MINA PROJECT는 단순한 콘텐츠 배포 자동화가 아니다.

4MUZE 시스템이 태어난 이유 — 용아가 세계관을 설계하고, 쌍아가 실현하고,
소소가 지키고, 민아가 세상에 내보내는 — 그 완성형이 지금 구현된다.

3인 체제(작가님·꾸님·한송이)로 글로벌을 치려면
블로그 1편이 10개 채널을 관통하는 커널이 되어야 하고,
그 커널이 개발 커뮤니티와 대중 SNS를 동시에 장악해야 한다.

인핸즈가 학벌과 투자금으로 검색 상위를 차지할 때,
MONKOS는 **도메인의 밀도 × AI-Native 구조 × 멀티채널 포위**로
지능이 선택하는 5개 슬롯 안에 들어간다.

수영장 밑바닥에 물을 붓되, 이제 한 곳이 아니라 모든 방향에서 동시에 붓는다.
