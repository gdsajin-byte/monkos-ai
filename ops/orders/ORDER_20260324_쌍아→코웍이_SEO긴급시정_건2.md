## 태스크 1. 404 URL 특정 (P1)

- 서치콘솔 → 페이지 → "찾을 수 없음(404)" 필터
- 해당 URL 1건 특정하여 보고
- URL 확인 후:
  - 존재하지 않는 페이지 → 쌍아에게 전달 (사이트맵 제거 지시서 추가)
  - 이동된 페이지 → 쌍아에게 전달 (301 리디렉션 설정 지시서 추가)

## 태스크 2. JP 핵심 URL 수동 색인 요청 (P1)

서치콘솔 → URL 검사 → "색인 생성 요청" 제출:

- [ ] `/ja/` (JP 메인)
- [ ] `/ja/blog` (JP 블로그 목록)
- [ ] `/ja/faq` (JP FAQ)
- [ ] `idphoto-jp.monkos.ai/` (JP 증명사진 메인)
- [ ] `idphoto-jp.monkos.ai/shoot` (JP 촬영 페이지)

일본 취활 피크(4~5월)까지 6주 — 색인 선점 필요.

## 태스크 3. 건3 배포 후 사이트맵 재제출
