## 건 1. FAQ 구조화 데이터 — mainEntity 누락 (P0)

### 현상
- 서치콘솔 → 개선사항 → 잦은 문의 사항: **"'mainEntity' 입력란이 누락되었습니다"**
- 유효 2건 / 오류 항목 존재
- 리치 결과(검색에서 FAQ 펼침 노출) 차단 상태

### 원인 추정
- FAQ 페이지 SSR 시 JSON-LD 출력에서 `FAQPage` 스키마의 `mainEntity` 배열이 누락
- 일부 페이지(유효 2건)에만 올바르게 적용, 나머지 미적용

### 수정 방향
- `render.js` 또는 FAQ SSR 함수에서 JSON-LD 생성 로직 확인
- 올바른 구조:

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "질문 텍스트",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "답변 텍스트"
      }
    }
  ]
}
```

- 모든 FAQ 페이지(KO/JA/EN)에 동일 구조 적용
- 홈 FAQ 프리뷰에도 JSON-LD 포함 여부 검토

### 완료 조건
- [ ] 서치콘솔 리치 결과 테스트 도구에서 FAQ 유효 판정
- [ ] KO/JA/EN 전 FAQ 페이지 mainEntity 포함 확인

## 건 2. 미색인 페이지 대응 (P1)

### 현상
- 색인됨: 26 / 미색인: 74
- 72건 "발견됨 — 현재 색인이 생성되지 않음" (구글 크롤링 우선순위 밀림)
- 404: 1건
- 리디렉션: 1건

### 수정 방향

#### (A) 404 URL 특정 + 처리
- 쌍아가 서치콘솔에서 404 해당 URL 확인
- 존재하지 않는 페이지면 사이트맵에서 제거
- 이동된 페이지면 301 리디렉션 설정

#### (B) 주요 JP 페이지 수동 색인 요청
- 코웍이 또는 민아가 서치콘솔 URL 검사에서 다음 페이지 색인 요청 가능:
  - `/ja/` (JP 메인)
  - `/ja/pricing` (JP 가격)
  - `/ja/blog/*` (JP 블로그 개별 글)
  - idphoto-jp 주요 페이지

#### (C) 내부 링크 강화
- 메인 → 블로그 개별 글 링크 추가 (크롤러 발견 경로 확대)
- 블로그 글 간 상호 링크 (관련 글 추천)
- JP/EN 메인에서 해당 언어 블로그로 직접 링크

### 완료 조건
- [ ] 404 URL 제거 또는 리디렉션 완료
- [ ] JP 핵심 5개 URL 수동 색인 요청 제출
- [ ] 내부 링크 보강 — 최소 메인→블로그 3건 이상
