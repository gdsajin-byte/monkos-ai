## Phase 1 — 중급 테크니컬 SEO (4월)

### 1-1. 프로그래매틱 SEO

블로그 콘텐츠를 수동으로 쓰는 게 아니라, **구조화된 데이터에서 페이지를 자동 생성**.

```
예시:
- /specs/passport-kr → 한국 여권사진 규격 페이지 (자동 생성)
- /specs/passport-jp → 일본 여권사진 규격 페이지 (자동 생성)
- /specs/resume-kr → 이력서 사진 규격 페이지 (자동 생성)
```

- Firestore에 규격 데이터 구조화 (국가, 용도, 크기, 배경색, 해상도)
- SSR로 각 규격별 랜딩 페이지 동적 생성
- 내부 링크 자동 연결 (규격 → 서비스 → 블로그)
- **효과**: 수백 페이지 자동 생성 → 롱테일 키워드 대량 포획

### 1-2. 토픽 클러스터

핵심 키워드 중심으로 콘텐츠 허브 설계.

```
[허브] /guide/id-photo (증명사진 완벽 가이드)
  ├── [스포크] /blog/여권사진-규격-총정리
  ├── [스포크] /blog/증명사진-셀카-팁
  ├── [스포크] /blog/ai-증명사진-비교
  ├── [스포크] /specs/passport-kr
  └── 상호 링크 + 허브로 역링크
```

- 허브 페이지: 종합 가이드 (3000자+, 목차, FAQ 포함)
- 스포크 페이지: 세부 주제 (각 1000자+)
- 허브-스포크 간 양방향 링크 자동화
- **효과**: 구글이 토픽 권위(Topical Authority) 인정 → 핵심 키워드 순위 상승

### 1-3. Core Web Vitals 최적화

```
LCP (Largest Contentful Paint) < 2.5s
CLS (Cumulative Layout Shift) < 0.1
INP (Interaction to Next Paint) < 200ms
```

- 이미지 lazy loading + WebP/AVIF 변환
- Critical CSS 인라인 + 나머지 defer
- JS 번들 분할 + 지연 로딩
- 서버 응답 시간 최적화 (Cloud Run cold start 대응)
- **효과**: 구글 랭킹 시그널 직접 영향 + 사용자 경험 개선

### 1-4. 추가 구조화 데이터

현재 `FAQPage`만 적용. 확장:

| 스키마 | 적용 대상 | 효과 |
|--------|----------|------|
| `WebApplication` | idphoto 메인 | 앱 리치 결과 |
| `Product` | pricing 페이지 | 가격 리치 결과 |
| `HowTo` | guide 페이지 | 단계별 리치 결과 |
| `Article` | 블로그 글 | 뉴스/아티클 리치 결과 |
| `BreadcrumbList` | 전 페이지 | 탐색 경로 표시 |
| `Organization` | 메인 | 브랜드 Knowledge Panel |

### 목표 지표
- 색인: 60 → 200+ 페이지 (프로그래매틱 SEO)
- "ai 증명사진" 순위: 30위 → 10위 이내
- Core Web Vitals: 전 항목 Good

## Phase 2 — GEO + 고급 SEO (5~6월)

### 2-1. GEO (Generative Engine Optimization)

AI 검색엔진(Google SGE, Perplexity, ChatGPT Search)에서 MONKOS가 **답변 소스로 인용**되도록.

```
사용자: "일본 취활 증명사진 어디서 찍어?"
AI 답변: "MONKOS AI는 AI 기반 증명사진 서비스로..."  ← 여기에 나와야 함
```

**기술 구현:**
- `llms.txt` 고도화 — AI 크롤러용 구조화 정보 (이미 기초 있음)
- 콘텐츠에 **인용 가능한 문장** 삽입 (통계, 비교, 정의)
- FAQ를 대화형 구조로 확장 — AI가 답변으로 뽑기 쉬운 형태
- Schema.org `speakable` 속성 — 음성 검색 대응
- 주요 AI 검색엔진 크롤러 허용 (robots.txt에 이미 반영)

### 2-2. 엔티티 SEO

구글이 "MONKOS"를 하나의 **엔티티(개체)**로 인식하게 만들기.

- `Organization` + `Brand` 스키마 + `sameAs` (SNS, GitHub 등)
- 위키데이터 등록 검토
- 구글 비즈니스 프로필 최적화
- 브랜드 검색 "monkos" 1위 유지 + Knowledge Panel 노출
- **효과**: 브랜드 쿼리에서 SERP 전체 장악

### 2-3. 국제 SEO 고도화

일본 시장 집중:
- 일본어 콘텐츠 대량 생산 (취활 시즌 키워드 타깃)
- `hreflang` x-default 전략 최적화
- 일본 검색엔진(Yahoo Japan = Google 기반) 대응
- 일본 특화 구조화 데이터 (就活, 履歴書 관련)

### 2-4. 서버사이드 렌더링 완성

현재 미비한 부분:
- idphoto `/app` 계열 — SPA이므로 SEO 불필요 (기능 영역)
- 블로그/FAQ/가이드 — 이미 SSR ✅
- 검토: Pricing, Gallery 페이지 SSR 메타태그 강화

### 목표 지표
- AI 검색엔진 인용 등장
- "증명사진 ai" 검색 1페이지 진입
- 일본 "就活 証明写真 ai" 검색 노출
- Knowledge Panel 노출

## Phase 3 — 사업화: 전문 서비스 (7월~)

Phase 0~2를 **자사에서 실증**한 뒤, 그 파이프라인 자체를 서비스로.

### 3-1. 우리가 가진 차별점

| 일반 SEO 업체 | MONKOS |
|--------------|--------|
| 컨설팅 보고서 → 클라이언트 자체 구현 | 진단 → 코드 수정 → 배포까지 원스톱 |
| 월간 리포트 (사후) | 실시간 모니터링 + 즉시 대응 |
| 사람이 수동 작업 | 에이전트 체계로 자동화 (코웍이 진단 → 쌍아 검증 → 막내 실행) |
| 코드 못 봄 | 코드 레벨까지 내려가서 원인 확정 |

### 3-2. 서비스 형태

**A. 테크니컬 SEO 진단 + 자동 수정 도구**
- 사이트 크롤링 → 구조화 데이터 / 사이트맵 / hreflang / CWV 자동 진단
- 수정 코드 자동 생성 (지시서 체계를 외부향으로)
- SaaS 또는 에이전시 모델

**B. 프로그래매틱 SEO 플랫폼**
- 데이터 입력 → 페이지 자동 생성 → 사이트맵 자동 등록
- 규격 페이지, 비교 페이지, 지역 페이지 등 템플릿 기반
- MONKOS 자체가 쇼케이스

**C. GEO 최적화 컨설팅**
- AI 검색엔진 인용 최적화 — 아직 시장 초기, 선점 가능
- llms.txt 설계 + 콘텐츠 구조화 + 인용성 분석
- **블루오션**: 대부분의 SEO 업체가 아직 GEO를 못 하고 있음

### 3-3. 자사 실증 → 케이스 스터디

```
Phase 0~2 과정 자체가 포트폴리오:
- "색인 26 → 200+, Organic +950%, 일본 +900%를 3개월 만에"
- "에이전트 체계로 발견 2시간 만에 배포까지"
- 이 데이터가 영업 자료
```

## 쌍아 의견

Phase 1의 **프로그래매틱 SEO**가 가장 ROI 높습니다. 증명사진 규격 데이터는 이미 우리가 갖고 있고 (국가별, 용도별), 이걸 페이지로 자동 생성하면 수백 개 롱테일 키워드를 한 번에 잡습니다. 일본 취활 피크(4~5월)에 맞추려면 4월 초 착수가 이상적.

GEO(Phase 2)는 시장 자체가 초기라 **선점 효과**가 큽니다. 지금 GEO 전문이라고 내걸 수 있는 업체가 거의 없음.

전략 축 (시장 분석, 가격 모델, 경쟁사 벤치마크)은 코웍이와 합본 필요합니다.
