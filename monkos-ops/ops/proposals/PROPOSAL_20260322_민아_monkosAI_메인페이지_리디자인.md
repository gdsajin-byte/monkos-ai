## 3. 수정 사항 (전체)

### 3-1. 서비스 소개 문구 ✅ (코드 반영 완료, 배포 확인 필요)

**정본:**
> MONKOS AI는 20년 경력 사진작가가 만든 AI 증명사진 플랫폼입니다. 여권사진, 이력서사진을 셀카 한 장으로 완성합니다. 리얼 스튜디오의 실무와 노하우를 학습한 AI가 촬영, 배경과 조명 세팅, 피부부터 의상, 헤어 세팅까지 완벽하게 맞춤 처리하며, ICAO 국제 규격에 부합하는 증명사진을 제공합니다.

- "비자사진" 삭제 (아직 미지원)
- "MONKOS" → "MONKOS AI"
- 문구 전면 개편: 리얼 스튜디오 실무 강조

### 3-2. 서비스 카드 디자인 강화

**현재 문제:**
- 화이트 배경 위 화이트 카드 → 묻힘
- 왼쪽 보더 3px만으로 구분 → 눈에 안 띔
- 폰트/뱃지/아이콘 사이즈 너무 작음

**수정 방향:**
- 화이트 기본 유지 + 과하지 않으면서 눈에 띄도록
- AI 증명사진: 연한 보라 그라데이션 배경 + 보더 강화 + LIVE 뱃지 키우기
- 무료 크롭앱: 연한 그린 그라데이션 배경 + 보더 강화 + FREE 뱃지 키우기
- 호버 시 그림자 강화 + 스케일업
- CTA 링크 → 소형 버튼화
- 모바일 밸런스 깨지지 않을 것
- **"비자" 삭제**: AI 증명사진 설명 "여권·이력서·비자" → "여권·이력서"

**대상:** `portal.css` (.svc, .svc.live, .svc.free, .svc-bdg, .svc-link)

### 3-3. 앱 활용법 섹션 개편

**현재 문제:**
- 번호 + 텍스트만 있어서 어색 — 이도저도 아님

**수정 방향 (택 1, 작가님 판단 필요):**
- **A안:** 이미지 포함 설명 카드 — 각 단계별 스크린샷/일러스트 삽입
- **B안:** 페이지 넘김(캐러셀) 카드 — 스와이프로 3단계 확인 + "전체보기" 버튼

### 3-4. 메인 영역 콘텐츠 순서 변경

```
현재 (1차 배포 상태):
소개 → 서비스카드 → 활용법 → (FAQ가 블로그 라벨 아래) → 업계소식 → 블로그 → 푸터

정본 (확정):
소개 → 서비스카드 → 활용법 → FAQ → 게시판 → 블로그 → 푸터
```

- **FAQ**: "자주 묻는 질문" 라벨 + 상위 3~5건 (기존 FAQ 페이지에서 가져오기)
- **게시판**: "고객 게시판" 라벨 + 최근 답변 완료 게시글 미리보기
- **블로그**: 좌 패널에도 있으므로 메인에서는 후순위
- **업계 소식**: 삭제 또는 블로그에 통합

### 3-5. 게시판 메인 노출 리스크 분석

| | 장점 | 리스크 |
|--|------|--------|
| 실시간 대응 | 고객 신뢰도 향상, "살아있는 서비스" | 답변 지연 시 역효과 |
| 투명성 | FAQ로 안 되는 질문 접점 | 부정적 글 메인 노출 |
| 활성도 | 사용자 참여 유도 | 초기 빈 게시판 역효과 |

**완화 방안:**
- "최근 답변 완료" 게시글만 필터링 노출
- 또는 "Q&A 하이라이트" 형태로 선별 노출
- 초기에는 운영팀이 직접 Q&A 시딩

### 3-6. 우측 사이드바 재구성 (신규)

**현재:**
```
├── 사용 가이드 (증명사진 촬영법 영상)
├── 사용 가이드 (크롭앱 사용법 영상)
└── 크레딧 안내
```

**변경:**
```
├── 크레딧 안내 (최상단 유지 — 매출 직결)
├── 이벤트 배너 (프로모션/할인/신규 가입 보너스)
├── 고객 게시판 미리보기 (실시간 대응 노출)
├── SNS 채널
│   ├── YouTube (@monkosAI)
│   ├── Instagram (@monk_photo)
│   ├── X (@MONKOS_AI)
│   └── LINE (일본 타겟)
├── 고객 채팅 연동
│   ├── 텔레그램 (향후 통합 채널)
│   ├── LINE
│   └── 카카오톡
├── PWA 다운로드 버튼
└── 영상 가이드 링크 (사용법 페이지로 이동, 사이드바에서 영상 직접 재생 X)
```

**설계 원칙:**
- 초기에는 채널을 많이 열어두는 게 유리 (향후 텔레그램 통합 계획)
- 영상은 사용법 페이지에서 링크로 안내 (사이드바 공간 절약)
- SNS 친구맺기 + 채팅 연동 = 고객 접점 최대화
