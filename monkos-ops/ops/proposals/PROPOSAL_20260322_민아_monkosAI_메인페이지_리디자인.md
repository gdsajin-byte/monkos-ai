# monkos.ai 메인페이지 메인영역 리디자인 기안서

> 작가님 직접 지시 기반. 모바일 우선 설계, 카드 단위 디자인.

---

## 1. 배경

- monkos.ai 메인 영역은 모바일에서 주로 노출되는 핵심 영역
- 현재 AI 증명사진/크롭앱 서비스 카드가 눈에 잘 안 띈다는 지적
- 앱 활용법 섹션이 이도저도 아닌 상태
- 메인 콘텐츠 순서가 사용자 동선에 최적화되지 않음

## 2. 수정 사항

### 2-1. 서비스 소개 문구 수정 ✅ (이미 반영)

**변경 전:**
> MONKOS는 20년 경력 사진작가가 만든 AI 증명사진 플랫폼입니다. 여권사진, 이력서사진, 비자사진을 셀카 한 장으로 완성합니다. 사진관 촬영 노하우를 학습한 AI가 배경 정리, 조명 보정, 피부 보정, 의상 정돈까지 처리하며 ICAO 국제 규격에 부합하는 증명사진을 제공합니다.

**변경 후:**
> MONKOS AI는 20년 경력 사진작가가 만든 AI 증명사진 플랫폼입니다. 여권사진, 이력서사진을 셀카 한 장으로 완성합니다. 리얼 스튜디오의 실무와 노하우를 학습한 AI가 촬영, 배경과 조명 세팅, 피부부터 의상, 헤어 세팅까지 완벽하게 맞춤 처리하며, ICAO 국제 규격에 부합하는 증명사진을 제공합니다.

- "비자사진" 삭제 (아직 미지원)
- "MONKOS" → "MONKOS AI"
- 문구 전면 개편: 리얼 스튜디오 실무 강조

### 2-2. 서비스 카드 디자인 강화

**현재 문제:**
- 화이트 배경 위 화이트 카드 → 묻힘
- 왼쪽 보더 3px만으로 구분 → 눈에 안 띔
- 폰트/뱃지/아이콘 사이즈 너무 작음

**수정 방향:**
- 화이트 기본 유지하되 과하지 않으면서 눈에 띄도록
- AI 증명사진: 연한 보라 그라데이션 배경 + 보더 강화 + LIVE 뱃지 키우기
- 무료 크롭앱: 연한 그린 그라데이션 배경 + 보더 강화 + FREE 뱃지 키우기
- 호버 시 그림자 강화 + 스케일업
- CTA 링크 → 소형 버튼화
- 모바일 밸런스 깨지지 않을 것

**대상 파일:** `monkos_AI/portal/public/css/portal.css`
**대상 클래스:** `.svc`, `.svc.live`, `.svc.free`, `.svc-bdg`, `.svc-link`, `.svc-top`, `.svc-icon`

### 2-3. 앱 활용법 섹션 개편

**현재 문제:**
- 번호 + 텍스트만 있어서 어색
- 이미지도 없고, 페이지 넘김도 없고, 이도저도 아닌 상태

**수정 방향 (택 1):**
- **A안:** 이미지 포함 설명 카드 — 각 단계별 스크린샷/일러스트 삽입
- **B안:** 페이지 넘김(캐러셀) 카드 — 스와이프로 3단계 확인 + "전체보기" 버튼

**작가님 판단 필요:** A안 vs B안

### 2-4. 메인 영역 콘텐츠 순서 변경

**현재:**
```
서비스 소개 → 서비스 카드 → 앱 활용법 → 최근 블로그 → 업계 소식 → 푸터
```

**변경:**
```
서비스 소개 → 서비스 카드 → 앱 활용법 → FAQ → 게시판 → 블로그 → 푸터
```

- **FAQ 추가:** 활용법 다음에 FAQ가 오는 게 자연스러운 동선
- **게시판 추가:** 실시간 대응이 된다는 것을 노출 (고객 신뢰)
- **블로그 위치 이동:** 좌 패널에도 있으므로 메인에서는 후순위
- **업계 소식 삭제 또는 블로그에 통합**

### 2-5. 게시판 노출 리스크 분석

**장점:**
- 실시간 대응 노출 → 고객 신뢰도 향상
- "살아있는 서비스"라는 인상
- FAQ로 해결 안 되는 질문에 대한 접점

**리스크:**
- 게시판에 부정적 글(불만, 버그 리포트)이 메인에 노출될 수 있음
- 답변 지연 시 역효과 (대응 안 되는 것처럼 보임)
- 초기 게시판이 비어있으면 오히려 활성도 낮아 보임

**완화 방안:**
- "최근 답변 완료" 게시글만 필터링해서 노출
- 또는 "Q&A 하이라이트" 형태로 선별 노출
- 초기에는 FAQ 스타일로 운영팀이 직접 Q&A 시딩

- 서비스 카드 CSS는 막내 1건 단독 가능
