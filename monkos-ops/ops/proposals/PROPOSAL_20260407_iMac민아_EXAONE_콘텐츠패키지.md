> 첫 SPREAD 순환 파일럿. 민아 제안 → 쌍아 배분 → 막내 CDP 실행.

---

## 1. 왜 이 소재인가

- **LG EXAONE 3.5 2.4B** — 한국어 벤치마크 동급 압도적 1위 (KoMT 7.24), 그런데 아직 블로그/커뮤니티에서 실사용 후기가 거의 없음
- **llamafile 단일 실행파일** — 설치 제로, USB 꽂고 더블클릭
- **실증 데이터 보유** — 디딤돌 이의신청 반론 8건을 EXAONE이 조목조목 응답한 스크린샷 확보 (오늘 테스트)
- **SEO 잠재력** — Claude Max 후기가 GSC에서 노출 9,600% 스파이크. 기술 실사용 후기 = 오가닉에 먹히는 포맷
- **디딤돌 PT 연계** — 4/9 대면평가에서 USB 시연 예정. 블로그가 백링크 + 신뢰도 보강

## 3. 콘텐츠 시드

### 제목안

- EN: **"AI on a USB Stick — LG EXAONE 3.5 Real-World Review"**

### 본문 골격
1. **훅** — "설치 없이, 인터넷 없이, USB 꽂으면 AI가 대답한다"
2. **EXAONE 소개** — LG AI Research, 2.4B 파라미터, 한국어 KoMT 7.24 (2위 대비 +27%)
3. **llamafile이란** — Mozilla 프로젝트, 단일 실행파일, 크로스플랫폼
4. **실전 테스트** — 사업 제안서 10K 토큰 주입 → Q&A 8건 응답 (스크린샷)
5. **vs ChatGPT/Gemini** — 온디바이스 = 보안, 오프라인, 무료. 클라우드 API 불필요
6. **활용 시나리오** — 소상공인 현장 시연, 교육, 보안 민감 환경
7. **결론** — "2GB USB가 비서가 되는 시대"
