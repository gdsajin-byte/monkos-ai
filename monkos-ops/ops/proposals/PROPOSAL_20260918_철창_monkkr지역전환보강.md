## 배경 (꾸님 현장 판단, 9/18)

- 네이버 블로그는 전국 규정 글로 조회는 크지만(6월 2,974) 매장 방문 전환은 미미. 지역 검색("미사역 사진관" 등) 화면은 파워링크 → 플레이스 → 블로그 순이라 지역 손님은 블로그까지 안 내려옴. 8/19 장수사진 글이 지역 검색 블로그 칸 3번째에 떠 있어도 4주 조회 56, 문의 0
- 반면 9/7 인화 총정리 글(가격 기재)은 실제 인화 건수로 이어짐. **가격이 보이고 결정이 쉬운 글이 지역 손님을 움직인다**
- 경쟁사 우리동네사진관(sajinkwan.com / thesajinkwan.com, 워드프레스)은 자체 홈페이지에 "강남역 취업사진"식 지역+상품 페이지, 가격표, 네이버 예약 버튼, 블로그(가격·후기 글)를 두고 네이버 웹사이트 칸·통합탭 피드를 차지함
- 현재 https://monk.kr/monk_studio/monk_studio 는 뼈대(상품 3갈래·철학·갤러리 3장·오시는 길·톡톡·간편예약·전화·영업시간)는 있으나 **가격표 없음 / 블로그·후기 없음 / 포트폴리오 3장 / 단일 페이지**

## 채널 역할 분리 (중복 콘텐츠 방지)

| 채널 | 역할 | 글 종류 |
|---|---|---|
| 네이버 블로그 | 전국 유입·AI 브리핑 인용 | 규격·규정 글 (지금처럼) |
| monk.kr | 지역 손님 전환 | 후기·포트폴리오 글, 지역+상품 페이지, 가격표, 예약 |

네이버 블로그 글을 monk.kr에 복사하지 않음. 같은 글이 두 곳에 있으면 둘 다 불리.

## 요청 사항 (우선순위 순)

1. **네이버 서치어드바이저 등록 여부 확인** — monk.kr이 등록돼 있는지, 사이트맵(sitemap.xml)·RSS가 제출돼 있는지. 안 돼 있으면 등록. 이게 없으면 아래 전부 검색에 안 잡힘
2. **가격표 섹션 추가** (현 페이지) — 플레이스 가격표와 동일 내용. 촬영 상품 섹션 바로 아래. 네이버 블로그 가격 미기재 방침은 블로그 한정이고, 홈페이지는 가격이 전환 장치
3. **갤러리 확장** — 현재 3장 → 결과물 중심 20장 이상. 증명·취업·프로필·가족·장수 골고루. 손님 사진은 동의분만, 나머지는 자체 촬영본
4. **지역+상품 하위 페이지 5개** — URL 예: /monk_studio/misa-idphoto 등. 페이지 제목 = 검색어 그대로
   - 미사역 증명사진
   - 미사역 여권사진
   - 미사역 취업사진
   - 미사역 운전면허사진
   - 미사역 프로필사진
   - 각 페이지: 결과물 사진 + 규격 요약 + 가격 + 예약 버튼 + 오시는 길. 본문은 철창이 작성
5. **블로그(후기·포트폴리오) 섹션** — 목록 페이지 + 글 페이지. 첫 편은 9월 인화 손님 후기(꾸님 확인 후). 원고는 철창이 작성
6. (선택) 가격표 옆 **네이버 예약 버튼** 상단 고정 — 현재 간편 예약이 있으면 동일 역할

- 후기·포트폴리오 글 원고 (첫 편: 인화 후기)
