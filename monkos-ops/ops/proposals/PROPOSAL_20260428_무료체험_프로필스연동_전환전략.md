# 무료 체험 → 프로필스 연동 전환 전략

## 핵심 구조

증명사진 1장 무료 체험(loss leader) → 프로필 사진 서비스(profit center) 전환

## 현재 문제

- 랜딩 → 첫 행동 전환: **86% 이탈** (2,904세션 → 258진행)
- 결과 → 결제 전환: **58% 이탈** (77세션 → 32결제진입)
- 10c(₩1,450) 소액 결제 시 LS 수수료 비율 과다 → 수익 불가
- 생성 원가 $0.04(≈₩100) + 광고 클릭 비용 → 소액 단위로는 남는 게 없음

## 전략

### Phase 1 — 증명사진 무료 1장 (미끼)

- 첫 로그인 10c → 프리뷰(워터마크) 건너뛰고 **생성 → 다운로드(thankyou) 직행**
- 광고 카피: "지금 바로 무료로 만들어보세요"
- 목표: "써본 사람" 모수 확보 + 입소문(오가닉 부스터)

### Phase 2 — 프로필스 노출 (전환)

- 증명사진 결과(thankyou) 페이지에서 **프로필 사진 갤러리** 샘플 노출
- "이 퀄리티로 프로필 사진도 만들어보세요" — 다양한 스타일 시각적 제시
- 프로필스는 고단가 상품 → LS 수수료 비율 희석, 수익 구조 성립

### 플로우

```
[광고: 무료 증명사진]
    ↓
랜딩 → 로그인(10c 증정) → 촬영 → 생성 → 즉시 다운로드
    ↓
thankyou 페이지
    ↓
┌─────────────────────────────────┐
│  프로필스 갤러리 샘플            │
│  "이 사진으로 프로필도 만들어볼까요?" │
│  [비즈니스] [SNS] [이력서] [캐주얼]  │
└─────────────────────────────────┘
    ↓
프로필스 서비스 → 충전 → 수익
```
