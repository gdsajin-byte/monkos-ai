## 2. 핵심 진단 — CDP 직접 조회 3건

### P0 (치명): idphoto-jp / idphoto-kr sitemap에 URL 1개씩

**사이트맵 현황**
| Sitemap | 발견 페이지 | 마지막 읽음 | 상태 |
|---|---|---|---|
| monkos.ai/sitemap.xml | 198 | 2026.4.8 | 성공 |
| **idphoto-jp.monkos.ai/sitemap.xml** | **1** ⚠️ | 2026.4.17 | 성공 |
| **idphoto-kr.monkos.ai/sitemap.xml** | **1** ⚠️ | 2026.4.17 | 성공 |

**해석**: 일본 유료 타깃 서비스인 `idphoto-jp`의 색인 대상이 사실상 **URL 1개**. 즉 일본 검색 엔진에 노출되는 monkos 자산이 거의 루트 페이지뿐. Phase 1.7에서 HEAD 404·구슬러그 301 등 코드 수정은 했지만 **서브도메인 sitemap 자체에 URL을 채우는 작업은 포함되지 않았음.**

**확인 필요**: idphoto-jp/kr SPA 라우팅 구조에서 개별 규격·FAQ·가이드 페이지가 실제로 존재하는지, 존재한다면 왜 sitemap에서 누락됐는지 (빌드 스크립트·SPA rewrite·sitemap 생성 로직 어느 단에서 끊겼는지).

### P1 (치명): 404 33개 — Phase 1.7 이후에도 잔존

**색인 커버리지 (4/21 실측)**
| 항목 | 수치 |
|---|---|
| 색인 생성됨 | 78 |
| 색인 생성 안 됨 | 38 |
| └ **찾을 수 없음(404)** | **33** ⚠️ |
| └ 리다이렉션 포함 | 3 |
| └ NOINDEX 제외 | 1 |
| └ 적절한 표준 태그 대체 | 1 |

**해석**: 
- 3/25 기준점(비색인 74) 대비 Phase 1~1.7로 약 절반 감축 — 개선 추세 확인
- 그러나 **404 33개**가 여전히 색인 후보를 갉아먹는 중. 크롤 버짓·도메인 품질 시그널 동시 손상
- 4/10 구슬러그 301 리다이렉트 10건 매핑 이후에도 이 숫자가 남아있다는 것은 **새로운 경로 또는 미발견 유령 URL**이 계속 태어나는 중이라는 의미 (hreflang·내부링크·외부링크·Firestore 구식 슬러그 중 어느 쪽인지 재조사 필요)

### P2 (구조): 일본 코어 키워드 SERP 부재

**타깃 vs 실측 매트릭스**
| 타깃 쿼리 | 28일 노출 | 순위 |
|---|---|---|
| `就活写真` | 0 | 권외 |
| `証明写真 アプリ` | 0 | 권외 |
| `パスポート写真 アプリ` | 0 | 권외 |
| `証明写真 AI` | 0 | 권외 |
| `運転免許 写真` | 0 | 권외 |

**해석**: 
- 노출되는 쿼리는 자가 브랜드(`monkos`) + 한국어(`일본 취업 증명사진`) + 외곽 롱테일뿐
- 일본인 타깃 **자국어 핵심 쿼리 SERP에 MONKOS 자산이 단 하나도 걸리지 않음**
- 이는 단순 색인 문제가 아닌 **(1) 각 쿼리 매칭 랜딩 페이지 부재 + (2) topical authority 부재 + (3) 일본어 콘텐츠 양 부족**의 복합 결과

## 3. 왜 Phase 1.7로 충분하지 않았는가

| Phase 1.7 목표 | 달성 여부 | Phase 2에서 남은 과제 |
|---|---|---|
| 기술 오류 제거 (HEAD 404, NOINDEX 충돌, canonical) | ✅ | — |
| 코드 레벨 hreflang/JSON-LD 정합 | ✅ | — |
| **색인 대상 URL을 실제로 채워넣기** | ❌ | idphoto-jp/kr sitemap 확장 |
| **404 원천 차단** | ⚠️ 부분 | 33개 원인 재조사 + 새 규칙 |
| **타깃 쿼리별 랜딩 페이지** | ❌ | `就活写真`·`証明写真アプリ` 등 핵심 쿼리 L1 랜딩 신설 |
| **외부 신호(백링크)** | ❌ | note.com·SNS·디렉토리 |

**요약**: Phase 1.7은 "구조 결함 제거"였고, Phase 2는 "노출 자산을 실제로 만드는 단계"가 되어야 함.

## 5. 쌍아·작가님 논의 포인트

제안서에서 **결정되지 않은 사항**이니 지시서 환급 전 합의 필요:

1. **Phase 2.0 먼저 분리 실행 vs 2.0+2.1 묶음 실행** — 속도 vs 설계 응집도 선택

4. **일본 코어 키워드 확정 주체** — 민아 초안 → 한송이 검수 vs 한송이 주도
5. **Phase 2.1-C(note.com 연계)** — 한송이 연구원 작업 범위 확정 필요 (M4 디바이스)
