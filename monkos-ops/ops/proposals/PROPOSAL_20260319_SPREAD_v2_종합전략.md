## 4. 자동화 체계

### 4-1. 자동 처리 파이프라인 (발행 즉시)

| 단계 | 처리 | 도구 | 상태 |
|------|------|------|------|
| **번역** | KO → EN/JA 자동 생성 | Gemini 2.0 Flash (translate.js) | ✅ 운영 중 |
| **SEO** | JSON-LD, OG 메타, hreflang | 자체 CMS render.js | ✅ 운영 중 |
| **GEO** | llms.txt 갱신 | MINA STEP 2 | ⏳ 연동 필요 |
| **sitemap** | sitemap.xml 자동 갱신 | 자체 CMS | ✅ 운영 중 |

### 4-2. n8n 자동 배포 (방식 B)

| 워크플로 | 트리거 | 동작 | 상태 |
|----------|--------|------|------|
| **블로그→GitHub Issue** | Firestore 신규 문서 (lang=en) | GitHub API → 이슈 생성 | ❌ 미구축 |
| **블로그→티스토리** | Firestore 신규 문서 (lang=ko) | 티스토리 API → 자동 게시 | ❌ 미구축 |
| **블로그→텔레그램** | Firestore 신규 문서 | Bot API → 채널 알림 | ❌ 미구축 |
| **벤치마크 크롤링** | 야간 스케줄 | Apify → 수집 → 주간 분석 | ❌ 미구축 |
| **X 예약 포스팅** | 시간 트리거 | X API → 자동 게시 | ✅ 가동 중 |

**n8n 인프라**: 4060 서버 Docker 가동 중

### 4-3. 네이버 블로그 크롤러 (역방향 유입)

```
네이버 블로그 기존 글 → RSS 수집 → 본문 추출 → 자동 번역 → Firestore 저장
→ monkos.ai 블로그에 자동 게시
```

| 항목 | 상태 |
|------|------|
| 크롤러 코드 (naver.js) | ✅ 완성 |
| 4카테고리 매핑 | ✅ 설정 완료 |
| 실행 | ❌ **미실행** (어젠다 #4) |

### 4-4. 코웍이 SPREAD 프로토콜 (방식 C)

작가님: "스프레드" → 코웍이 가동
