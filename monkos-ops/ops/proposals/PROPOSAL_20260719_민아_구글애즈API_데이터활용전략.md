## 0. 왜 지금이 적기인가

오늘 V2 퍼널이 처음으로 전 슬러그에서 실작동하게 됐다(스포크 ①~④ 종결). 지금까지 광고 트래픽의 상당분이 **죽은 퍼널(V1 데드 UI)로 흘러 증발**했고, 전환 측정도 0이라 증발 사실조차 계량되지 않았다(5/1 진단: Ads 의존도 87%·전환 측정 0·자산화 키워드 0). **퍼널이 살아난 첫날 + 측정 API가 열린 날** — 광고→전환→오가닉 자산화 루프를 처음으로 끝까지 닫을 수 있는 시점이다.

## 1. 신규 확보 데이터 6종 — 기존 키와의 차별점

| # | 데이터 | 기존 키(GSC·GA4)와의 차이 |

## 2. 3축 활용 설계

### 축 A — 마케팅 (광고 효율, 부스터 전제 하에서만)

- **A1 (P0) 전환 루프 닫기**: 전환 액션 2단 정의 — 마이크로=무료 T0 생성 완료, 매크로=결제. GA4 이벤트 연동 또는 Ads 태그. 전환 없는 CPC 최적화는 장님 — 모든 후속의 전제.
- **A2 네거티브 키워드 컷**: D1에서 무의도 쿼리(예: "무료 앱 다운로드"류) 주간 발굴 → 낭비 차단. 증발 방지의 최속 수단.
- **A3 스마트 캠페인 → 검색 캠페인 전환 판단**: 5/10 진단(스마트 이탈 82.4%)의 후속 — D3로 키워드 통제권 확보 시의 CPA 비교 데이터 산출.
- **A4 지역·시장 재배분**: 일본 CPC 5~10배 문제(5/1) — 키워드별 CPA 실측 후 일본/한국/동남아(체류 260만 비자 수요) 배분 재설계.

### 축 B — CITADEL (SEO 자산화 — 본 제안의 핵심)

- **B1 자산화 파이프라인 (D1 × GSC 교차)**: 주간 자동 대조 —
  - 광고에서 전환 나는 검색어 ∧ 오가닉 순위 없음 → **콘텐츠 신설 타깃** (specs 보강·블로그·FAQ). "광고비가 오가닉으로 전환 안 되고 증발"을 역전시키는 정본 루프.
  - 오가닉 상위(1~3위) ∧ 광고 동시 구매 중 → **광고비 회수 후보**.
  - KPI: **자산화 키워드 수 0 → N** (광고 검색어가 오가닉 10위 내 진입한 수) — 부스터 전략의 유일 성적표.
- **B2 429 슬러그 수요 지도 (D2)**: 전 슬러그 키워드 검색량 랭킹 → 유니크 콘텐츠 레이어·도해 시스템(스포크 ⑤)·재색인의 **우선순위 정본** 교체. 지금은 감각 기반 → 수요 실측 기반으로.
- **B3 시즌 캘린더 (D2 월별 검색량)**: 일본 취활·비자 시즌 등 수요 파동 → 콘텐츠 발행 캘린더 선행 배치.

### 축 C — 콘텐츠 제작 (꾸 트랙 연계)

- **C1 주제 파이프라인**: D1의 질문형·롱테일 쿼리 → 주간 Top 후보를 꾸 우체통으로 전달 → kku-blog(PSSR 공식) 주제 입력으로 직결. "무엇을 쓸까"를 실검색어가 결정.
- **C2 카피 피드백**: D5 RSA 승자 소구 → 블로그 제목·specs seoTitle·CTA 문구에 역이식. 광고에서 검증된 문장을 오가닉 자산에 재사용.
- **C3 반려·통념 콘텐츠 소재**: D1에서 "반려", "거절", "재촬영"류 쿼리 클러스터 → specs 품질 기준(공식 정독·실반려 중심) 콘텐츠의 수요 검증.

## 4. 주의·거버넌스

1. **GA4 내부 오염**: 전환 연동 전 내부 트래픽 필터 미설정 문제(기지) 우선 처리 — 안 하면 전환 데이터도 오염 승계.
2. **전환 정의는 작가님 합의 사항** — 무료 생성을 전환으로 볼지(트래픽·DA 전략 정합) / 결제만 볼지(수익 직결). 2단 병기 권고.
3. Basic Access 쿼터(일 15,000 ops)는 주간 배치엔 충분 — 실시간 폴링 설계 금지.
4. 광고 효율 수치가 나빠도 **"광고 끄자"는 표면 처방 금지** (전략 정본 명문) — 진단 1차 질문은 언제나 자산화 여부.

## 6. 작가님 결정 요청 3건

1. **전환 정의**: 마이크로(무료 생성)+매크로(결제) 2단 병기안 승인 여부.
2. **접근 인프라 형태**: scripts 유틸(권고) vs 별도 서비스.
3. **P0 착수 시점**: 즉시(쌍아 지시서) vs 런팟·재색인 등 기존 잔여 소화 후.

## 7. 기대 효과 요약

지금까지 광고는 "태우면 세션이 온다"까지만 보였다. 이 체계가 서면 **어떤 검색어가 → 얼마에 → 전환되고 → 오가닉 자산으로 축적되는지**가 주간 단위로 계량된다. CITADEL의 다음 분기(콘텐츠 보강·도해·재색인)가 전부 수요 실측 위에서 우선순위를 갖게 되는 것이 최대 효과다.
