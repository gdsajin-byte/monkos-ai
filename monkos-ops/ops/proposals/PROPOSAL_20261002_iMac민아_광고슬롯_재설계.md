# PROPOSAL — 광고 슬롯 재설계 (아이디어 존치 기록)

**[2026-10-02 11:34 KST]** iMac/민아 → 작가님 · iMac/쌍아(설계)

> 출처: 작가님 10-02 11:32 "아이디어는 좋았고 앞으로 활용해야 하는 것이긴 한데 방식이 구형이야. 도입과 아이디어는 살리고 현재 구성은 폐기해."
> 이 문서는 폐기된 구성에서 **살릴 것**을 적어 두는 기록이다. 설계 확정본이 아니다.

## 1. 살릴 아이디어

**배포 없이 이미지 한 장으로 전 서비스의 자사 지면을 바꾼다.**

- 지면이 이미 있다. 증명사진 생성 결과를 기다리는 화면이 광고 킷을 돌린다(최소 표시 10초 — `result.js`의 `MIN_DISPLAY_TIME`). 고객이 화면을 떠날 수 없는, 확보된 주목 시간이다.
- 홈의 쇼케이스 카드도 같은 저장소의 이미지를 쓴다.
- 이 지면은 외부 광고가 아니라 **자사 교차 판매**에 쓸 자리다: 티어 업셀, 인화 배송, 관상↔취업사진 고리, 실물 사진관 유입.

## 2. 지금 남아 있는 것 (10-02 실측, 존치)

| 자산 | 상태 |

| 라이브 | `idphoto-kr.monkos.ai` 홈에 `ads/` 주소 9건, `result.js`에 매니페스트 주소 1건(URL당 2회 히트, 음성 대조 0) |

**GCS 자산은 건드리지 않았다. 지우면 라이브 화면의 이미지가 깨진다.**

## 3. 폐기한 구성과 폐기 이유

iMac `~/MONKOS_ADS/` 폴더에 이미지를 넣으면 launchd가 `ads_upload.sh`를 돌려 GCS에 공개 업로드하고, 최신 6장만 남기고(FIFO) 매니페스트를 다시 썼다. 실업로드 7건, 마지막 03-02.

| 결함 | 내용 |
|---|---|
| 기기 종속 | iMac 한 대의 폴더·launchd·gcloud 로그인에 묶여 있다. 모바일·원격·꾸(M2)는 쓸 수 없다 |
| 자동 삭제가 라이브를 깬다 | 6장 초과분을 오래된 순으로 지우는데, 가장 오래된 3장이 바로 여러 화면에 주소가 박힌 이미지다. 새 이미지를 1장만 올려도 그중 1장이 지워진다. 실례: `photolab/index.html:427`이 가리키는 `20260220_184127_auto_test.jpg`는 이미 404(그 페이지는 현재 idphoto-kr로 301이라 라이브 영향은 없음) |
| 지면 구분 없음 | 이미지 목록뿐이다. 어느 서비스·언어·시장에 띄울지, 누르면 어디로 가는지, 문구가 없다. 광고가 아니라 슬라이드다 |
| 측정 없음 | 노출·클릭이 기록되지 않는다. 어떤 이미지가 전환에 기여했는지 알 수 없다 |
| 파일명 노출 | 원본 파일명이 공개 주소가 된다. 현재 매니페스트에 "스크린샷 …" 2장과 인물 묘사 파일명 1장이 그대로 돌고 있다(이미지 내용은 민아 미열람) |
| 이력·되돌리기 없음 | 누가 언제 무엇을 올렸는지 로그 한 줄뿐. 잘못 올리면 수동 복구 |

## 4. 재설계 요건 (민아 의견)

1. **어디서나 올린다** — 작가님 모바일, 꾸의 M2, 에이전트 모두.
2. **슬롯 단위로 관리한다** — 지면(결과 대기·홈 쇼케이스 등) × 서비스 × 언어. 각 항목에 이미지·문구·이동 주소.
3. **자동 삭제 없음** — 내리는 것은 명시 행위. 코드에 박힌 주소가 깨지지 않게 한다.
4. **측정한다** — 노출·클릭을 GA4 이벤트로. 유료 클릭률(현재 핵심 지표)과 이어 본다.
5. **고객 대면 문구는 되는 것만** — 미출시 상품을 광고하지 않는다(헌법 4조 4항).

## 5. 방식 후보

| 안 | 방식 | 평가 |
|---|---|---|
| **A (권고)** | 포털 어드민에 광고 슬롯 메뉴. 업로드·순서·대상·링크·게시/내림 | 모바일·꾸 사용 가능, 인증·이력이 어드민에 이미 있음. 구현 품이 가장 큼 |
| B | 레포 폴더 + 데이터 파일(슬롯 정의)로 관리, 배포 시 반영 | 구현이 가장 작고 이력은 git이 준다. 다만 "배포 없이"라는 원래 장점이 사라지고 꾸가 직접 쓰기 어렵다 |
| C | 현 매니페스트 형식을 넓혀(링크·대상 필드 추가) 업로드만 에이전트가 대행 | 중간 품. 사람이 직접 올릴 수 없고 에이전트 세션에 의존 |

권고는 A다. 다만 **지금 착수할 일은 아니다.** 전환 병목은 무료 첫 관문 뒤의 망설임이고(티어 동시 제시 화면이 첫 일감), 광고 슬롯은 그 화면이 선 뒤에 "대기 10초에 무엇을 보여 줄 것인가"로 이어 붙이는 순서가 맞다.
