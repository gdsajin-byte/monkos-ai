# 스튜디오 고도화 — 모델 스왑 아키텍처 + 프로필스 완성

## 1. 목적

현재 내부용 증명사진 샘플 생성 도구(monkos-studio)를 고도화하여:
1. **모델 스왑**: Gemini 3 Pro에 고정된 엔진을 추상화, 나노바나나·Flux 등 모델 체인지 가능
2. **프로필스 완성**: 증명사진 전용 → 프로필 사진 모드 추가, 스타일링 템플릿 제공
3. **프로덕션 백본**: 스튜디오에서 완성 → idphoto-kr/프로필스 앱으로 엔진 이식

## 2. 현재 코드 구조 (AS-IS)

### 백엔드 (server.js, 395줄)

```
POST /api/precheck  → gemini-2.0-flash (Vertex AI) → 7항목 적합성 분석
POST /api/idgen     → gemini-3-pro-image-preview (REST) → I2I 증명사진 생성
```

- 모델명 하드코딩 (L310)
- REST 엔드포인트·요청포맷·응답파싱 전부 Gemini 종속
- 프롬프트 빌더 `buildPromptV5` — 증명사진 전용 (passport/id만)
- 인증/결제 없음 (내부용)

### 프론트엔드 (app.js, 589줄)

```
3컬럼 SPA: 사이드바(옵션) + 워크스페이스(B/A) + 아카이브(미구현)
```

- 옵션 체계 정교함: 규격·성별·연령·의상(색상·넥타이·패턴)·헤어·배경·표정
- 조건부 렌더링 잘 되어 있음 (연령별 의상 분기, 여권→배경 고정 등)
- 생성 결과 다운로드 + B/A 비교컷 Canvas 합성

### 3.4 API 확장

```
기존:
  POST /api/precheck          ← 그대로
  POST /api/idgen             ← model 파라미터 추가

신규:
  GET  /api/models            ← 사용 가능 모델 목록
  GET  /api/templates         ← 프로필 템플릿 목록
  POST /api/generate          ← 통합 생성 (mode + model + options)
```

`/api/idgen`은 하위호환 유지, `/api/generate`가 신규 통합 엔드포인트.
