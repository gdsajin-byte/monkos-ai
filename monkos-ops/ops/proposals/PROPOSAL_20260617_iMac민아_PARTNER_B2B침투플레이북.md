## 1. 인크루트 5대 교훈 — 자산화 코어

협상 실패를 가정하고도 남기는 자산. 모든 카테고리 제안에 기본 탑재.

| # | 교훈 | 실패의 구조 | 플레이북 규칙 |
|---|------|------------|--------------|
| L1 | **숫자 0의 역설** | 단가를 완전히 비우자 상대가 우리 소매가(₩9,900)를 납품가로 오해 → "마진 안 난다" 거절 | 1차 제안부터 **"소매 대비 현저히 낮은 B2B 티어"** 방향성은 명시. 구체 숫자만 미팅 카드로 보류 |
| L2 | **네이티브 강제의 부메랑** | 우리가 차별화로 민 "네이티브 통합"이 상대엔 "핵심 플로우 강제 삽입 리스크" | 통합 깊이를 **옵션 스펙트럼**(선택형 위젯 ↔ 추천 진입점 ↔ 네이티브)으로 제시. 강제는 독점 대가 카드로만 |
| L3 | **매출 프레임의 함정** | 상대가 "이거 팔아서 마진 남나"에 갇히면 작은 매출에 막혀 거절 | **마케팅비/회원혜택 프레임**을 디폴트 앵글로. "매출원"이 아니라 "경쟁사에 없는 회원 혜택"으로 리프레임 |
| L4 | **독점 = MG 결속** | 독점은 우리 시장 절반 포기 = 공짜로 못 줌 | 독점 요구 시 **MG(최소물량보장)**가 가격표. "독점 주면 MG 사라"를 전 카테고리 고정 원칙 |
| L5 | **3층 격리 = 신뢰 자산** | 프롬프트·모델·원가가 노출되면 협상력·기밀 붕괴 | iframe 감옥 + Partner API GW + 엔진 금고. B2B 공통 무기로 모든 제안 코어에 탑재 |

> 메타 교훈: **"빈칸은 상대가 최악으로 채운다."** 숫자든 통합 방식이든 의도든, 공백을 남기면 상대가 자기 리스크 회피 방향으로 메운다. 침묵이 아니라 *방향성*을 흘려야 한다.

증명사진/AI사진이 B2B 가치를 갖는 7개 세그먼트. **채용/구직만 P1 디테일**, 나머지는 확장 슬롯.

|---------|----------|----------|----------|----------|---------|
| **채용/구직** | 인크루트·잡코리아·사람인·원티드·잡플래닛 | 이력서 사진 | 회원혜택·차별화 | 침투가(트래픽) | **P1 (진행)** |
| 교육/자격 | 시험원서·자격증·학원·대학 입학처 | 원서 사진 | 규격 준수 자동화 | 중립 | P2 (슬롯) |
| 공공/여권 | 여권대행·비자·민원 서비스 | 여권·신분증 | 규격·반려 방지 | 중립 | P2 (슬롯) |

| HR/기업 | 사원증·인트라넷·헤드헌팅 | 사원증·프로필 | 온보딩 자동화 | 프리미엄 | P3 (슬롯) |
| 결혼/프로필 | 결혼정보·소개팅 | 프로필 사진 | 첫인상 품질 | 중립 | P3 (슬롯) |

## 3. 제안서 시스템 — 모듈식 템플릿

상대마다 새로 쓰지 않는다. **3블록 조립** 구조.

```
[A. 공통 코어]  +  [B. 카테고리 모듈]  +  [C. 상대별 커스텀]
   재사용            세그먼트 교체           이름·로고·시나리오
```

### A. 공통 코어 (모든 제안 고정)
- 회사 소개 + **원본 정체성 보존 기술**(헌법 1조 — commodity와 분리되는 차별점)
- 실 스튜디오 운영 기반(품질 신뢰) + 상시 개발·CS 흡수(운영 역량)
- **3층 격리** 신뢰 구조(L5) + 코브랜딩 원칙("X with MONKOS AI")
- 정산 투명성(우리 호출 카운트 = 정산 근거)

### B. 카테고리 모듈 (세그먼트별 교체)
- 용도별 가치 제안(이력서/원서/여권/KYC…) + 규격 자동화 효과
- 통합 시나리오(선택형↔네이티브 옵션) + 회원혜택/마케팅비 프레임 예시

### C. 상대별 커스텀
- 상대 브랜드·로고·실제 플로우 반영. **사명 오기 절대 금지**(인크루트 잡코리아 오기 사고 재발 방지)

### 제안서 발송 체크리스트 (사고 방지)
- [ ] 타사 사명·로고 흔적 0건 (전수 grep)

- [ ] 통합 방식 = 옵션 제시(강제 단정 금지)
- [ ] 외부 금지어 점검(엔진명 Gemini/Imagen, 내부 호칭, 원가) → "MONKOS"만
- [ ] 발송 전 작가님 승인(헌법 4조)

## 4. 판매전략 — 가격·정산 아키텍처

> ⚠️ 내부 숫자. 외부 절대 비노출.

### 4.1 정산 모델 (전 카테고리 공통 골격)
- **월 정액 + 포함 건수 + 초과분 종량** — 도매단가 기반, 우리 호출 카운트로 검증.
- 명목상 "매출 쉐어"로 포장 가능하되 실질은 **도매단가 하한**을 둔다(정산 불투명 차단).

### 4.2 원가·티어 기준선 (협상 카드)
| 항목 | 기준 |
|------|------|
| API 실원가 | ~₩58/건 (인프라 포함 ~₩100~120) |
| 도매 기준 단가 | 건당 ~₩1,000 (마진 80%, **침투가 = 트래픽 사는 전략가**) |
| MG 기준점 | 1만 건/월 ≈ ₩1,000만 (= 독점의 가격표) |
| 폴백 티어 | S(1,000건/₩3,000) · M(5,000건/₩1,400) · L(1만건/₩1,000) — 상대가 부담 시 하향 카드 |
| 프리미엄 AS | 몽크사진관 사람 보정 별도 ₩5,000 (도매와 분리) |

### 4.3 카테고리별 가격 차등
- **침투가(채용·플랫폼/긱)**: 트래픽·대량 온보딩 목적 → 도매 하한 가깝게.
- **프리미엄(금융/KYC·HR)**: 본인확인·신뢰가 핵심 가치 → 단가 상향 여지.
- **중립(교육·공공·결혼)**: 규격 자동화 가치로 표준 티어.

### 4.4 방어 장치
- **MAP(최소판매가)**: 상대 판매가 ≥ 본진 직판가 → 채널 자기잠식 차단(R1).
- **AS 2레이어**: 자동생성(도매) vs 사람보정(별도 ₩5,000). "전부 무료 흡수" 약속 금지.
- **엔진 면책 3조항**(계약 필수): 제3자 엔진 정책변경 불가항력 / 베스트에포트 SLA / 대안엔진 전환 유예.

## 5. 침투전략 — 어떻게 뚫는가

### 5.1 진입 경로 4종
| 경로 | 방식 | 적합 |
|------|------|------|
| **콜드 아웃리치** | 제안서 직접 발송 | 명확한 담당 라인이 있을 때 |
| **백채널·인맥** | 지인·대표 라인을 *신뢰 윤활유*로 | ⚠️ 실무자 패싱 절대 금지(한국 비즈니스 치명) |
| **파일럿 미끼** | 소규모 무료/저가 PoC로 진입 | 상대가 리스크 회피적일 때 |
| **인바운드** | SEO·콘텐츠로 *발견되게* (specs/블로그 GEO 자산 활용) | 중장기. 상대가 먼저 찾아오게 |

### 5.2 언더독 × 언더독 프레임
- 인크루트(업계 4위) × MONKOS(신생) = "서로의 무기가 되는 결합". 1위 플랫폼보다 **2~4위가 차별화에 목마르다** → 침투 1순위.

### 5.3 거절 대응 플로우 (인크루트 실전 검증)
```
거절 수신
  → ① 단가 오해 정정 (소매≠도매, L1)
  → ② 프레임 전환 (매출원 → 마케팅비/회원혜택, L3)
  → ③ 통합 부담 해소 (강제 철회 → 선택형 옵션, L2)
  → ④ 재고 요청 (짧은 통화/미팅 1회, "안 되면 따르겠다"로 출구 확보)
  → ⑤ (닫히면) 백채널 정비 + 시즌 후 재타진 or 동일 카테고리 차순위로 선회
```

### 5.4 떠보기 5문 (상대 패 끌어내기)
정산모델 / 회원 판매가 포지셔닝 / **용도(유료·무료)** / 독점 경쟁사 범위 / 예상 월 거래량 → 각각 우리 티어·MG 산정 입력값.

## 9. 다른 에이전트 액션

- **작가님**: ① 본 플레이북 방향 승인 ② 차 카테고리 1곳 선정(백채널 유무 기준) ③ 잡코리아/사람인 선접촉 타이밍.
- **쌍아**: PF_PARTNER 메타 격상 반영 — 카테고리 맵·플레이북 5축·Phase를 PF 본문에 정착. 보안 3층 격리 문서화 후속.
- **막내**: 대기. 채용-P1.5 타결 시 입점 구현(현행 노출 표면 4건 선행 보강 우선).
- **민아(본인)**: 제안서 모듈 템플릿화 + 잡코리아/사람인 커스텀 초안(작가님 신호 시).

> 본 문서는 PF_PARTNER 메타 정본의 근거 문서다. 실제 발송·계약·구현은 작가님 승인 → 쌍아 설계 → 막내 실행 경로를 따른다.
