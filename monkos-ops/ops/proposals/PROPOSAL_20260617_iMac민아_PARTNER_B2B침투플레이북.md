## 1. 인크루트 5대 교훈 — 자산화 코어

협상 실패를 가정하고도 남기는 자산. 모든 카테고리 제안에 기본 탑재.

| # | 교훈 | 실패의 구조 | 플레이북 규칙 |
|---|------|------------|--------------|
| L1 | **숫자 0의 역설** | 단가를 완전히 비우자 상대가 우리 소매가(₩9,900)를 납품가로 오해 → "마진 안 난다" 거절 | 1차 제안부터 **"소매 대비 현저히 낮은 B2B 티어"** 방향성은 명시. 구체 숫자만 미팅 카드로 보류 |
| L2 | **네이티브 강제의 부메랑** | 우리가 차별화로 민 "네이티브 통합"이 상대엔 "핵심 플로우 강제 삽입 리스크" | 통합 깊이를 **옵션 스펙트럼**(선택형 위젯 ↔ 추천 진입점 ↔ 네이티브)으로 제시. 강제는 독점 대가 카드로만 |
| L3 | **매출 프레임의 함정** | 상대가 "이거 팔아서 마진 남나"에 갇히면 작은 매출에 막혀 거절 | **마케팅비/회원혜택 프레임**을 디폴트 앵글로. "매출원"이 아니라 "경쟁사에 없는 회원 혜택"으로 리프레임 |
| L4 | **독점 = MG 결속** | 독점은 우리 시장 절반 포기 = 공짜로 못 줌 | 독점 요구 시 **MG(최소물량보장)**가 가격표. "독점 주면 MG 사라"를 전 카테고리 고정 원칙 |
| L5 | **3층 격리 = 신뢰 자산** | 프롬프트·모델·원가가 노출되면 협상력·기밀 붕괴 | iframe 감옥 + Partner API GW + 엔진 금고. B2B 공통 무기로 모든 제안 코어에 탑재 |

> 메타 교훈: **"빈칸은 상대가 최악으로 채운다."** 숫자든 통합 방식이든 의도든, 공백을 남기면 상대가 자기 리스크 회피 방향으로 메운다. 침묵이 아니라 *방향성*을 흘려야 한다.

## 3. 제안서 시스템 — 모듈식 템플릿

```
[A. 공통 코어]  +  [B. 카테고리 모듈]  +  [C. 상대별 커스텀]
   재사용            세그먼트 교체           이름·로고·시나리오
```

### A. 공통 코어 (모든 제안 고정)
- 회사 소개 + **원본 정체성 보존 기술**(헌법 1조 — commodity와 분리되는 차별점)

- 정산 투명성(우리 호출 카운트 = 정산 근거)

### B. 카테고리 모듈 (세그먼트별 교체)
- 용도별 가치 제안(이력서/원서/여권/KYC…) + 규격 자동화 효과

### C. 상대별 커스텀

### 제안서 발송 체크리스트 (사고 방지)

## 4. 판매전략 — 가격 티어 아키텍처 (정밀판)

> ⚠️ 내부 정본. 외부 절대 비노출. 인크루트 단가 사고(소매가 오해)를 막기 위해 **티어를 명확·방어가능하게** 재설계.
> 원가 기준선: API 실원가 ~₩58/건, 인프라 포함 실원가 ~₩120/건.

### 4.1 정산 모델 4종 (형태 선택)
| 모델 | 구조 | 적합 | 정산 근거 |
|------|------|------|----------|
| **M1 도매 종량** | 건당 고정 단가 | 소량·변동 입점 | 우리 호출 카운트 |
| **M2 정액+초과** | 월 기본료 + 포함 N건 + 초과 종량 | 중대량·안정 | 우리 호출 카운트 |
| **M3 독점+MG** | M2 + 최소물량보장(MG) | 독점 요구처 | MG = 독점의 가격표 |
| **M4 회원혜택(무료배포)** | 정액 MG only, 회원 무료 제공 | 마케팅비 전환처 | MG 고정(매출 무관) |

> M4가 인크루트 교훈의 핵심 — 상대가 "팔아서 마진 남나"에 갇히면 M4로 프레임 전환(매출원→회원혜택/마케팅비).

### 4.2 가격 티어 (3 가격군 × 4 물량 티어 · 건당 ₩)
| 물량 티어 | 월 건수 | 침투가군 | 표준군 | 프리미엄군 |
|----------|--------|---------|--------|-----------|
| **S** | ~1천 | 1,200 | 2,500 | 4,500 |
| **M** | ~5천 | 1,000 | 2,000 | 3,800 |
| **L** | ~1만 | 850 | 1,700 | 3,200 |
| **XL** | 1만+ | 협의 | 협의 | 협의 |

- 침투가군도 **마진 85%+**(원가 ₩120 기준). 물량↑ → 단가 체감(상대 유인) but 총액↑(우리 이득).
- MG 기준점: 1만 건/월 × 해당군 L단가 = 독점 가격표(예: 표준군 독점 ≈ 월 ₩1,700만).
- 프리미엄 AS(사람 보정): 몽크사진관 별도 **₩5,000**(도매와 완전 분리, AS 2레이어).

### 4.3 카테고리 → 가격군 매핑
| 가격군 | 카테고리 | 근거 |
|--------|---------|------|
| **침투가** | 채용/구직, 플랫폼/긱 | 트래픽·대량 온보딩, 시장 학습 비용 |
| **표준** | 교육/자격, 공공/여권, 여행사 | 규격 자동화 가치, 중간 예산 |
| **프리미엄** | 금융/KYC, 비자대행, 사원증/HR | 본인확인·신뢰·B2B 예산 여력 |

### 4.4 방어 장치
- **MAP(최소판매가)**: 상대 판매가 ≥ 본진 직판가 → 채널 자기잠식 차단(R1).
- **AS 2레이어**: 자동생성(도매) vs 사람보정(별도 ₩5,000). "전부 무료 흡수" 약속 금지.
- **엔진 면책 3조항**(계약 필수): 제3자 엔진 정책변경 불가항력 / 베스트에포트 SLA / 대안엔진 전환 유예.

### 4.5 외부 가격 노출 정책 (L1 교훈 — 사고 재발 방지)
- **1차 제안**: 구체 단가 0, 단 **방향성은 명시** — "B2B 전용 티어, 소매(₩9,900) 대비 현저히 낮은 수준, 물량·형태 연동".
- **2차**(조율 의사 확인 후): 해당 카테고리 가격군 티어표 제시.
- ❌ **절대 금지**: 단가를 빈칸으로 남겨 상대가 우리 소매가를 납품가로 오해하게 두는 것(= 인크루트 사고).

## 5. 침투전략 — 어떻게 뚫는가

### 5.1 진입 경로 4종
| 경로 | 방식 | 적합 |
|------|------|------|
| **콜드 아웃리치** | 제안서 직접 발송 | 명확한 담당 라인이 있을 때 |
| **백채널·인맥** | 지인·대표 라인을 *신뢰 윤활유*로 | ⚠️ 실무자 패싱 절대 금지(한국 비즈니스 치명) |
| **파일럿 미끼** | 소규모 무료/저가 PoC로 진입 | 상대가 리스크 회피적일 때 |
| **인바운드** | SEO·콘텐츠로 *발견되게* (specs/블로그 GEO 자산 활용) | 중장기. 상대가 먼저 찾아오게 |

### 5.2 언더독 × 언더독 프레임
- 인크루트(업계 4위) × MONKOS(신생) = "서로의 무기가 되는 결합". 1위 플랫폼보다 **2~4위가 차별화에 목마르다** → 침투 1순위.

### 5.3 거절 대응 플로우 (인크루트 실전 검증)
```
거절 수신
  → ① 단가 오해 정정 (소매≠도매, L1)
  → ② 프레임 전환 (매출원 → 마케팅비/회원혜택, L3)
  → ③ 통합 부담 해소 (강제 철회 → 선택형 옵션, L2)
  → ④ 재고 요청 (짧은 통화/미팅 1회, "안 되면 따르겠다"로 출구 확보)
  → ⑤ (닫히면) 백채널 정비 + 시즌 후 재타진 or 동일 카테고리 차순위로 선회
```

### 5.4 떠보기 5문 (상대 패 끌어내기)
정산모델 / 회원 판매가 포지셔닝 / **용도(유료·무료)** / 독점 경쟁사 범위 / 예상 월 거래량 → 각각 우리 티어·MG 산정 입력값.

## 6. 배포전략 — 카테고리 병렬 시퀀스

- **비독점 원칙** → 카테고리·플랫폼 **동시 진행** 가능(독점 양보 시에만 해당 카테고리 한정 잠금).
- 화이트라벨 별도 엔드포인트 템플릿(`monkos-{partner}`)은 **복제 비용 ≈ 0** → 입점처 늘려도 한계비용 낮음.
- 배포 시퀀스: **채용 P1 안정화 → 동일 템플릿으로 차 카테고리 1곳 PoC → 검증 후 확산**. 한 번에 전선 확대 금지(운영 부하·CS 흡수 한계).

## 7. 채용/구직 트랙 (P1 — 디테일)

작가님 선정 우선 카테고리. 인크루트를 선행 사례로, 동일 템플릿 복제.

| 타겟 | 규모(월) | 진입 경로 | 상태 |
|------|---------|----------|------|
| 인크루트 | 웹 350~540만 / 앱 MAU 41만 | 콜드+백채널(대표 약한연결) | 협상 중(재고 요청 발신) |
| 잡코리아 | 554만 | 콜드 아웃리치 | 대기(템플릿 복제) |
| 사람인 | 487만 | 콜드 아웃리치 | 대기 |
| 원티드 | (IT 특화) | 인바운드+콜드 | 후보 |

- **공통 앵글**: 이력서 사진은 구직자의 반복 마찰점 → "회원이 별도 이동 없이 규격 맞는 증명사진 확보". 매출원 아닌 **회원 혜택**으로.
- **인크루트 학습 반영**: 차순위 접촉(잡코리아 등)엔 처음부터 ①방향성 시그널 ②선택형 통합 ③마케팅비 프레임을 제안서에 내장 → 인크루트가 겪은 오해 사전 차단.
- **독점 처리**: 채용 카테고리 한정 독점만, MG 전제. 미수용 시 비독점 멀티 입점(병렬).

## 10. 세일즈 운영 파이프라인 (발굴 → 온보딩)

수요처는 퀄리티만 받쳐주면 넓다 — 좁히지 않고 **시스템으로 전수 커버**한다.

```
[발굴]   카테고리별 타겟 DB 자동 수집 (§11)
   → [선별]  우선순위 스코어링 (규모 · 퀄리티 수요 강도 · 백채널 · B2B 예산)
   → [컨택]  카테고리 모듈 제안서 자동 조립(§3) · 발송 · 추적
   → [협상]  거절 5단 플로우(§5.3) · 떠보기 5문(§5.4) · 티어 협상(§4)
   → [계약]  독점·MG·MAP·엔진 면책
   → [온보딩] 화이트라벨 엔드포인트 복제 (monkos-{partner})
   → [관리]  호출 카운트 정산 · 갱신 · 업셀(AS·프리미엄)
```

### 자동화 지점
| 단계 | 자동화 수준 | 수단 |
|------|-----------|------|
| 발굴 | 반자동 | WebSearch/스크래핑 → 타겟 DB 적재 |
| 선별 | 반자동 | 스코어링 룰(규모·수요·백채널·예산) |
| 컨택 | 반자동 | 제안서 3블록 자동 조립 + 발송 로그 |
| 협상 | 수동 | 작가님·쌍아(거절 플로우는 규칙화) |
| 계약 | 수동 | 작가님 승인 |
| 온보딩 | 자동 | `monkos-{partner}` 템플릿 복제(복제비≈0) |
| 정산 | 자동 | 호출 카운트 집계 |

> 자동화 원칙: **발굴·컨택·정산은 기계가, 협상·계약은 사람이.** 막내가 발굴/적재 파이프라인을, 작가님·쌍아가 협상·계약을 맡는 분업.

### 수집 자동화 (3단)
1. **시드(수동)**: 카테고리별 대표 플레이어를 본 플레이북 지식으로 선등록(완료 — TARGET_CONTACTS.md)
2. **보강(반자동)**: WebSearch로 카테고리별 기관 목록 확장 + 공개 제휴문의 채널 수집
3. **정기 갱신**: 신규 진입·연락처 변경 주기 점검 (막내 루틴화 가능)

> ⚠️ 이메일 주소는 **공개 출처 확인 후에만** 기입. 추측·생성은 헌법 4조 1항 위반.
