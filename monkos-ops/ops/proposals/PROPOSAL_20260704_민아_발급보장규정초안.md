## 1. 보장 범위 정의 (초안)

### 1.1 정의

> **발급보장**: T2 상품(촬영실 idphoto-kr/jp, ₩9,900 / ¥990)으로 제작·다운로드한 사진을 관공서(여권·주민등록증·운전면허 등 해당 규격 기관)에 제출하여, **"사진 규격" 사유로 접수가 반려된 경우**에 한하여 보상하는 약속.

### 1.2 보장 대상 (포함)

접수기관의 반려 사유가 **사진 자체의 규격 결함**인 경우만 해당한다.

| 유형 | 예시 |
|------|------|
| 치수·비율 | 얼굴 크기·머리 위 여백 규격 미달, 인쇄 치수 불일치 |
| 품질 | 해상도 부족, 초점 흐림, 픽셀 깨짐 판정 |
| 배경·조명 | 배경색 부적합, 그림자·반사 판정 |
| 표현·보정 | 과보정(합성 의심) 판정, 표정·자세 규격 위반 판정 |

### 1.3 보장 제외 (명시적)

사진 외 사유는 보장하지 않는다. 규정·카피 양쪽에 명시하여 CS 분쟁을 원천 차단한다.

| 제외 사유 | 이유 |
|-----------|------|
| 서류 미비·기재 오류 등 사진 외 사유의 반려 | 사진 품질과 무관 |
| 신원 불일치·본인 확인 실패 | 서비스 통제 범위 밖 |
| 수수료 미납·접수 절차상 문제 | 서비스 통제 범위 밖 |
| 사용자가 다운로드본을 임의 편집·재압축·타 서비스 재가공한 경우 | 원본 무결성 훼손 |
| T2 산출물이 아닌 사진 (T1 ₩2,000 셀프서브 산출물 포함) | 보장은 T2 전용 — QC 판정을 거치지 않은 산출물은 보장 불가 |
| 규격 자체가 변경·개정된 이후의 제출 (제작 시점 규격 기준) | 규격 개정 리스크 차단 |
| 제작(결제)일로부터 **90일** 경과 후 제출분 | 무기한 보장 방지. 기간은 작가님 결정 사항 (60/90/180일 옵션) |

### 1.4 T1과의 경계 (2-티어 정합)

- **T1 (₩2,000 셀프서브)**: 보장 없음. 페이지에 "보장" 단어 자체를 쓰지 않는다.
- **T2 (₩9,900 발급보장)**: Gemini Live 코칭 + QC 판정을 거친 산출물만 보장. 보장은 QC 게이트가 있어야 성립한다 — T1에 보장을 붙이면 QC 없는 산출물에 법적 약속을 거는 것.

## 2. 보상 방식 — 2안 비교

| 축 | **A안: 전액 환불** | **B안: 무제한 재작업 → 최종 환불** |
|----|-------------------|-----------------------------------|
| 내용 | 규격 사유 반려 증빙 시 결제액 전액 환불, 종결 | 반려 시 우선 무료 재작업(재코칭+재생성). 재작업 후에도 규격 사유 반려 시 전액 환불 |
| CS 리스크 | **낮음.** 처리 1회로 종결, 분쟁 여지 최소. 단, "환불 노리기" 악용 가능성 (증빙 절차로 방어) | **중간.** 재작업 왕복으로 CS 접점 증가, "몇 번까지?" "이번에도 반려면?" 등 단계별 분쟁 포인트. 처리 SOP 필요 |
| 원가 | 건당 손실 = 결제액 전액(₩9,900) + PG 수수료. 발생률이 낮으면 총원가 미미 | 재작업 원가 = 생성 API 비용(수십 원 수준)으로 환불 대비 극히 낮음. 최종 환불은 A안과 동일하나 발생 빈도가 낮아짐 → **총원가 최소** |
| 전환 효과 | "안 되면 100% 환불" — 직관적, 카피가 짧고 강함. 경쟁사(증명한컷)와 동일 문법이라 차별화 약함 | "될 때까지 + 안 되면 환불" — 책임지는 풀서비스 포지셔닝과 정합. 경쟁사 전무 영역(§5)이라 **차별화 강함** |
| 고객 실익 | 돈은 돌려받지만 사진 문제는 미해결 (다시 어딘가서 찍어야 함) | 발급 완료까지 동행 — 고객의 실제 목적(발급) 달성 |

### 민아 권고: **B안** (무제한 재작업 + 최종 전액 환불)

- 원가 구조상 재작업(API 비용)이 환불(₩9,900)보다 압도적으로 싸다. 재작업 게이트가 환불 발생률 자체를 낮춘다.
- "촬영부터 발급까지 책임지는 풀서비스" 포지셔닝(§5 벤치마크 문서의 핵심 요약)과 정합. A안은 경쟁사(환불만)와 같은 층위로 내려간다.
- 단, CS SOP(재작업 접수→처리 기한→최종 환불 판정 기준)를 승인 후 별도 문서로 확정해야 한다. **"무제한" 표기 여부는 작가님 결정 사항** — 보수적으로 가면 "재작업 후에도 반려 시 전액 환불"로 횟수 언급 자체를 생략하는 방법도 있다(카피 초안은 이 보수 버전 기준).

## 3. 증빙 절차 (초안) — 개인정보 최소 수집 원칙

### 3.1 프로세스

1. **접수**: 고객이 문의 채널(info@monkos.ai 또는 사이트 내 문의)로 보상 신청
2. **증빙 제출**: 접수기관의 **반려 통지**(문자·전자민원 화면·접수증 반려 표기 등) 중 **①반려 사유 ②반려 일자**가 확인되는 부분
3. **대조**: 주문번호(결제 내역)로 T2 산출물 여부 + 90일 이내 여부 확인
4. **판정**: 반려 사유가 §1.2 보장 대상인지 판정 → 재작업 안내(B안) 또는 환불 처리
5. **기록**: 처리 결과를 감사 로그에 어펜드 (append only)

### 3.2 개인정보 최소 수집

| 원칙 | 실행 |
|------|------|
| 수집 최소화 | 필요 항목 = **주문번호 + 반려 사유·일자가 보이는 증빙 이미지**뿐. 주민등록번호·여권번호·신청서 사본 전체는 **수집 금지** |
| 마스킹 요청 | 증빙 이미지 내 이름·번호 등 식별정보는 가리고 제출하도록 안내 문구에 명시 |
| 보관 기한 | 처리 완료 후 증빙 이미지 파기(분쟁 대비 최소 보관 기간은 작가님 결정 — 통상 3개월 제안), 처리 기록(주문번호·판정·일자)만 잔존 |
| 목적 외 사용 금지 | 증빙은 보상 판정에만 사용. 마케팅·통계 활용 금지 |

## 4. 노출 카피 초안 — 보수적 문구 (헌법 4조 5항: 미확정·과장 표현 금지)

> 원칙: "100% 통과" "무조건 발급" 같은 결과 보증형 표현 금지. 보장의 실체는 **"규격 사유 반려 시 보상"**이므로 카피도 그 범위만 말한다. 아래 카피는 승인 전 어디에도 노출하지 않는다.

### 4.1 specs 업셀 한 줄 (T1 페이지 → T2 링크 병기용)

**주안**:
> 반려 걱정 없이 — 규격 반려 시 보상하는 발급보장 촬영실 ₩9,900

**대안** (더 짧게):
> 규격 반려 시 보상 — 발급보장 촬영실 ₩9,900

- "반려 걱정 없이"까지는 정서 소구, 대시 뒤에서 보장의 실체(규격 반려 시 보상)를 즉시 한정. "무조건" "100%" 부재 확인.

### 4.2 촬영실 랜딩용 문단 (KR)

> **발급보장 — 규격 때문에 반려되면, 저희가 책임집니다.**
> 실시간 촬영 코칭과 규격 검수를 거친 사진이 관공서에서 **사진 규격 사유로 반려**될 경우, 무료로 다시 만들어 드리고 그래도 해결되지 않으면 결제 금액을 전액 환불해 드립니다.
> ※ 보장은 사진 규격 사유의 반려에 한하며, 서류 미비 등 사진 외 사유는 해당하지 않습니다. 반려 통지 확인 후 처리됩니다. 자세한 조건은 발급보장 규정을 확인해 주세요.

- 3문장 구조: 약속 → 실행 방식(B안 기준) → 한정·절차 고지. 브랜드 표기는 "MONKOS"만 사용(내부 엔진명 미노출, 헌법 4조 3항).
- A안 확정 시 두 번째 문장을 "결제 금액을 전액 환불해 드립니다"로 축약.

### 4.3 JP 시장용 방향 메모 (번역 아닌 방향)

- **직역 금지.** 일본 시장은 보상 약속에 대한 심리적 무게가 크다 — "保証(보증)"은 법적 뉘앙스가 강하므로 남발하지 않고, 조건 명시가 신뢰를 만든다.
- 방향: **「規格不備による受理拒否の場合、無料再作成・全額返金」** 계열의 조건 병기형. 「絶対」「100%合格」류 결과 보증형 표현 금지.
- 특정상거래법(特定商取引法) 표기 페이지와의 정합 확인 필요 — 반려 보상 조건은 반드시 특商法 표기·이용약관과 일치해야 한다. 카피 확정은 **JP 가격(¥990) 및 T1 일본 가격 확정 이후** (DESIGN §2: en/ja는 v1 유지 중, JP 신가격 미정 — STATUS_pricing §4).
- 일본어 최종 카피는 승인 후 꾸/콘텐츠 트랙에서 현지화 감수를 거쳐 확정 제안.

## 6. 작가님 결정 요청 사항

1. **보상 방식**: A안(전액 환불) vs **B안(재작업+환불, 민아 권고)** — 택일
2. **"무제한" 표기 여부**: B안 채택 시 횟수 명기 여부 (카피 초안은 횟수 미언급 보수 버전)
3. **보장 기간**: 결제일로부터 60 / **90(초안 기준)** / 180일
4. **증빙 보관 기간**: 처리 후 파기 시점 (초안 제안: 3개월)
5. **카피 승인**: §4.1 한 줄(주안/대안 택일) + §4.2 문단 — 승인 시 idphoto-kr 촬영실 반영 지시서 발행 가능
6. JP 카피는 JP 가격 확정 후 별도 트랙 (§4.3)
