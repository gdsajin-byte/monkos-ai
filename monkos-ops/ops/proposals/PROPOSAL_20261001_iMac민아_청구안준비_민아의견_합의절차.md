1. **발췌형으로.** 인덱스 행은 원문의 제목·첫 줄·식별자를 그대로 뽑는다. 모델 요약은 본문 없는 289건 같은 잔여분에만. (근거: 모델이 과거 기록을 재서술하면 의혹이 확정으로 변질된 전례 — 08-13.)

3. **커밋하지 않는 파생 산출물로.** `monk_index.db`와 같은 취급(.gitignore). 여러 세션이 한 파일에 덧붙이면 충돌한다(10-01 PF_MONK_OS 실례).
4. **오탐 축소.** 식별자 칸 분리 + 낱말 경계 조회. 인덱스에 안 걸리면 원문 grep → 의미 검색 순으로 내려간다.
5. **시각 대조 훅은 경고부터.** 본문에 과거 시각 인용이 많아 헤더 줄만 정확히 골라내지 못하면 정상 기록을 막는다. 푸시 훅의 인덱스 재빌드는 가벼운 단계(BM25)만.
