## 0. 한 줄 정의

**IDPASS = `specs`(규격 DB) × `crop`(엔진)을 묶은 Photo Aid형 "규격 맞춤 증명사진 도구" 브랜드.**
브랜드 간판은 서브도메인 SPA 한 장, 실제 SEO·도구 엔진은 본진(monkos.ai)에서 가동한다.

---

## 1. 핵심 구조 — 간판 / 엔진 분리

```
IDPASS (브랜드 레이어)
├─ idpass.monkos.ai ............ SPA 한 장 = 간판 + 라우터
│   · IDPASS 브랜드 소개 / 앱(iOS) 다운로드 링크 / 인기 국가·문서 진입 / 검색→라우팅
│   · 클라이언트 렌더(SPA) — SEO 부담 없음(간판이므로)
│
└─ monkos.ai/specs/{국가-문서} ... 실제 엔진룸 (본진, SSR)
    · 위: 규격 콘텐츠(SEO·백링크 미끼) · 아래: crop 엔진(그 국가 규격 주입)
    · = 각 페이지가 "그 규격 전용 미니 서비스 앱"
    · IDPASS 브랜드 셸(헤더/풋터)을 입되, 도메인·권위는 본진 유지
```

**원리**: crop 엔진을 *규격 파라미터를 받는 형태로 한 번* 일반화 → specs 445개 데이터가 각자 규격 주입 → **엔진 1개 = 도구 N개**. 신규 개발이 아니라 `specs(데이터) × crop(엔진)`의 곱셈.

---

## 2. 왜 이 구조인가 (의사결정 근거)

| 쟁점 | 이 구조의 답 |
|------|------------|
| **독립 브랜딩** | idpass.monkos.ai 간판 + 본진 페이지에 IDPASS 셸 → 사용자는 URL 아닌 '옷'으로 브랜드 인지 |
| **SEO 권위** | 445페이지가 본진(monkos.ai) 권위 유지. crop을 내부로 들인 권위 집중 전략과 **일관** |
| **권위 분리 리스크** | 도메인 이관 없음 → 301·색인 출렁임 0. 애즈 끊고 오가닉 전환하는 시점에 안전 |
| **전환(이탈률 92%)** | specs가 정보 페이지 → 도구 페이지로 격상. "보고 나감" → "보고 씀" |
| **백링크** | 규격표보다 "무료 도구 페이지"가 자발적 링크를 압도적으로 더 받음 = specs 미끼 강화 |
| **리팩토링 부담** | crop(무료·경량) + specs(정적 DB) 연동. 매출 나는 idphoto의 크레딧/스토리지는 무관 |

> IDPASS SPA가 한 장이라 가벼운 것이지, 프로젝트가 가벼운 게 아니다.

| 작업 | 무게 | 담당(안) |
|------|------|---------|
| **본진 specs 도구화** — crop 엔진 규격 파라미터화 + specs 페이지 임베드 | 🔴 **핵심·무거움** | 막내 |
| IDPASS 브랜드 셸 — specs 페이지 헤더/풋터 IDPASS 옷 | 🟡 중 | 막내 + 꾸(디자인) |
| idpass.monkos.ai SPA — 간판/라우터 한 장 | 🟢 가벼움 | 막내 |
| 서브도메인 매핑 (crop.monkos.ai 패턴 재사용) | 🟢 가벼움 | 막내 |

## 4. idphoto와의 위상 (카니발 방지)

| | **IDPASS** (본 제안) | **idphoto-kr/jp** (현행) |
|---|---|---|
| 본질 | 규격 맞춤 **도구** (내 사진 → 규격 크롭/검증) | AI **생성** (셀카 → AI 증명사진) |
| 모델 | Photo Aid형 / 무료 유입 엔진 | 프리미엄 생성 / 매출 엔진 |
| 무기 | specs 445국 + crop + SEO | AI 품질 + 크레딧 |

두 라인은 겹치지 않고 스펙트럼을 넓힌다(도구 + 생성). Photo Aid는 '도구'만 보유.

## 5. 미결 결정 (작가님 판단 대기)

1. **IDPASS ↔ idphoto 관계** — 완전 별도 2브랜드 vs IDPASS를 상위 우산으로 두고 AI생성을 프리미엄 옵션으로 흡수
2. **IDPASS 매출 모델** — 무료 유입 극대화 + idphoto AI생성으로 업셀 (작가님 "IDPASS 무료배포" 발언 기준 유력) vs 다운로드 일부 유료
3. **이관 범위 확정** — 본 제안은 "각 페이지는 본진 유지, 간판만 IDPASS"로 확정. (specs 도메인 이관 안 함)
