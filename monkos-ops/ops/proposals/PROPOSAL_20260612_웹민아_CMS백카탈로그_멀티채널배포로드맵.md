# PROPOSAL — CMS 백카탈로그 멀티채널 배포 로드맵

> **[2026-06-12 18:58 KST] 웹/민아 → 작가님**
> 작가님 직접 지시(③경로): "이미 CMS에 올라와 있는 콘텐츠를 스레드·X·노트닷컴 등으로 게시할 로드맵을 기획해."
> **전제**: 본 로드맵은 [DISTRIBUTION_SCHEMA.md](../../contents/DISTRIBUTION_SCHEMA.md)(R1~R5) **안에서의 실행 계획**이다 — 스키마 재발명이 아니다. 단 스레드(Threads)는 스키마에 없는 신규 채널이라 §3에서 등재를 제안한다.
> ⚠️ 스키마·전략 정본이 현재 draft(작가님 승인 대기) 상태 — **본 로드맵 승인 시 두 정본의 승인을 함께 처리**해 주시기 바란다 (조향 장치 없는 배포 가동 방지).

## 1. 자산 현황 (잠자는 재고)

| 자산 | 규모 | 상태 |
|---|---|---|
| monkos.ai 블로그 발행분 | **208건** (채널 마스터 실측 04-22) | 발행됐으나 채널 배포는 X 일부뿐 — **백카탈로그 대부분 미배포** |
| CMS 드래프트 (6월 생산분) | 11편 업로드 + 적체분 | 🔴 자판기 401로 06-11 이후분 적체 (기보고) |
| 스테이징 (contents/blog) | 13편 (P1 7·P2 3·P3 2·JP 1) | P2·P3 6편 = 저서 계보, 채널 적합도 최상 |

핵심 판단: **새로 만들 필요 없이, 이미 만든 것의 유통만으로 1개월치 배포 캘린더가 채워진다.** "제작이 싼 시대, 유통이 해자" 원칙의 첫 실전 적용 대상이 우리 자신의 재고다.

## 3. 신규 채널 등재 제안 — Threads (레시피 R6 후보)

## 4. Phase 1 — 백필 선별 (1주차)

**선별 룰** (전수 살포 금지 — 스팸 신호 방지):
- **P2·P3 전량 6편** (dead-folders, claude-harness, 4060 벤치마크, least-privilege, morning-patrol 등) — 저서 계보(book_thread) 자산, note·Medium·Threads 적합도 최상.
- **P1 에버그린 톱 10** — GSC 노출 실적 상위 페이지 우선 (수집: GH Actions 자동 브리핑 데이터 활용, 막내 1회 추출). 노출 0인 글의 채널 살포는 후순위.
- 산출: `contents/DISTRIBUTION_QUEUE.md` — 글 × 채널 × 상태(대기/가공완료/게시/측정) 추적 테이블. 에이전트가 가공 완성본을 큐에 채우고, 작가님은 큐에서 꺼내 게시만.

## 5. Phase 2 — 채널 가동 케이던스 (1~2주차, 작가님 공정 일 15분 박스)

| 채널 | 케이던스 | 가공 | 작가님 공정 |
|---|---|---|---|
| X | 일 1 (API 자동) | P1: 1줄+링크+썸네일 / P2: 스레드 3~5트윗 | 0분 (에이전트 게시) |
| **Threads** | 주 3~5 | KR 토막 서사 (R6) | 폰 붙여넣기 2분/건 (API 검증 후 0분) |
| note.com | 주 2 (R3 기존) | JA 재작성 완성본 | 붙여넣기 5분/건 |
| Medium | 주 1 (R3 기존) | EN 재작성 | RTF 이식 5분/건 |
| 네이버 | 기존 09:00 루틴 유지 (R1-2) | T2 변환 | 기존과 동일 |

- 순서 불변: 항상 monkos.ai 원본이 canonical (스키마 §4-2). 백필도 원본 링크 명기.
- 채널당 일 상한 2건 — 백카탈로그 일괄 살포 금지 (도배 = 계정 신뢰 훼손).
- 가공 주체: 웹/민아 데일리 루틴 6번에 "배포 큐 채우기" 1항 추가 (쌍아 보정 시 v5에 반영 — REVIEW 품질평가 #3과 동일 개정 사이클로).

## 6. Phase 3 — 측정 환류 (3주차~)

- **UTM 규칙**: `?utm_source={x|threads|note|medium}&utm_medium=social&utm_campaign=backfill2606` — 채널별 유입을 GA4에서 분리 측정.
- 주간 자산 스냅: 채널별 팔로워·게시 수·유입 클릭 → PF_SPREAD §7 에셋 표 갱신 (R5 절차 준용).
- 4주 시점 판정: 채널별 유입/공정시간 비율로 케이던스 재배분. 죽는 채널은 접고(에셋 30 임계 원칙), 사는 채널에 증편.
