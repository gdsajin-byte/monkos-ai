# 제안서 — GA4 유저 동선 이벤트 퍼널 설계

**[2026-03-27 03:11 KST] M1/민아 → M1/쌍아**

---

## 1. 배경

GA4 + Google Ads 세부 검토 결과, 현재 monkos.ai는 **page_view만 수집 중**이며 유저의 서비스 이용 동선이 전혀 추적되지 않는 상태.

**현재 문제:**
- Google Ads ₩31,000 지출 / 39클릭 → 전환 0 (태그 미설치)
- Paid Search GA4 참여율 7.1%, 참여 시간 0초 → 원인 분석 불가
- 채널별(Organic/Paid/Social/Referral) 어디가 실전환까지 이어지는지 판단 근거 없음
- JP vs KR 캠페인 예산 배분 판단 불가

**작가님 방향 (3/27):**
- 유저 동선 면밀히 파악 → 전략 대응
- 궁극 전환: 크레딧 충전 → 다운로드 완료(땡큐)까지
- 광고는 일 ₩10K 유지하며 데이터 수집 (중지 아닌 개선)

## 2. 제안 퍼널 구조

```
[유입] → [랜딩] → [사진 업로드] → [AI 생성] → [결과 확인] → [크레딧 충전] → [다운로드/땡큐]
```

### 이벤트 설계안

| 단계 | 이벤트명 (제안) | 설명 | 유형 |
|------|---------------|------|------|
| 1 | `page_view` | 페이지 진입 | 이미 수집 중 |
| 2 | `photo_upload` | 사진 업로드 시작/완료 | 커스텀 이벤트 |
| 3 | `photo_generate` | AI 증명사진 생성 요청 | 커스텀 이벤트 |
| 4 | `result_view` | 생성 결과 확인 (미리보기) | 커스텀 이벤트 |
| 5 | `purchase` | 크레딧 충전 완료 | **GA4 권장 이벤트** (Ads 전환 연동) |
| 6 | `download_complete` | 최종 다운로드 (땡큐 페이지) | 커스텀 이벤트 |

> `purchase`는 GA4 권장 이벤트명이므로 Google Ads 전환 추적과 자동 연동됨.

### 이벤트 파라미터 (제안)

```javascript
// purchase 이벤트 예시
gtag('event', 'purchase', {
  currency: 'KRW',        // 또는 'JPY'
  value: 3900,             // 충전 금액
  transaction_id: 'TXN_xxx',
  items: [{
    item_name: 'credits_pack',
    quantity: 1,
    price: 3900
  }]
});

// photo_generate 이벤트 예시
gtag('event', 'photo_generate', {
  photo_type: 'id_photo',      // 증명사진 유형
  service: 'idphoto-kr',       // 또는 'idphoto-jp'
  spec: '3x4'                  // 규격
});
```

## 3. 쌍아에게 요청사항

### 코드 레벨 분석

아래 서비스별로 **각 이벤트를 어느 파일, 어느 함수/핸들러에 삽입해야 하는지** 분석해주세요.

| 서비스 | 분석 대상 |
|--------|---------|
| **idphoto-kr.monkos.ai** | 업로드 → 생성 → 결과 → 결제 → 다운로드 전체 플로우 |
| **idphoto-jp.monkos.ai** | 동일 플로우 (JP 버전) |
| **monkos.ai (portal)** | 메인 랜딩, 블로그 유입 → idphoto 전환 경로 |

### 분석 산출물 (지시서 전 단계)

각 이벤트별로:
1. **삽입 위치**: 파일 경로 + 함수/핸들러명
2. **트리거 시점**: 어떤 사용자 액션 또는 API 응답 시점에 발화
3. **파라미터**: 해당 시점에 취득 가능한 데이터 (금액, 규격, 서비스명 등)
4. **기존 gtag 설치 현황**: 이미 GA4 스니펫이 어디에 있는지, 추가만 하면 되는지

### 산출물 형식

분석 완료 후 지시서 형태로 막내에게 하달할 수 있는 수준의 **삽입 매핑표** 작성.

## 4. 기대 효과

태그 설치 후 2~4주 데이터 축적 시:

- **퍼널 이탈률**: "업로드 100명 → 생성 80명 → 충전 10명" 같은 병목 가시화
- **채널별 ROAS**: Organic vs Paid vs Social 중 충전까지 이어지는 채널 식별
- **JP vs KR CPA 비교**: 어디에 예산 집중할지 데이터 기반 판단
- **Ads 자동 최적화**: purchase 이벤트 30건 이상 축적 시 Google 스마트 입찰 활성화 가능
- **랜딩 페이지 A/B 테스트 근거**: 참여율 0초 문제의 원인 추적
