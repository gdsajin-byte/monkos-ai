# 어젠다 — 관상·사주 해석 서비스 (IDPASS 체류 엔진)

> 발단: 7/24 작가님 아이디어 — "증명사진이 IDPASS로 브랜딩되면 포털 체류 요인으로 관상 서비스"
> 착수 시점: **IDPASS 완성 후** 프로젝트로 전환

## 작가님 원문 구상

- 포털에서 크레딧 구매 + 체류 요인으로 관상·사주·주역 서비스
- 재미와 흥미 + 정보 + 실제 필요(사진)를 동시 구동
- **엉터리가 아닌 정통 학문 기반** — 마의상법 등 원전 DB
- 취업사진·수능사진에 관상학적 한줄 평 → 부가가치
- 얼굴 표정별 귀상(貴相) 해석 + 주의사항 품평
- **도식**: 한쪽에 얼굴 매핑표 + 원문 ○○상 해석 인터랙트 표출
- 기존 Face Mesh 인프라 활용 → 큰 리소스 없이 매력 포인트
- **중국어 타겟**: 바이두·샤오홍슈 — 관상학 본고장, 바이럴 소재

## 왜 MONKOS에 맞는가

1. **인프라 이미 있음**: Face Mesh 478포인트, 크롭 엔진 랜드마크, 실시간 촬영 파이프라인
2. **자연스러운 퍼널**: 증명사진 촬영 → 관상 한줄평(무료 훅) → 상세 풀이(크레딧) → 취업사진 각도 추천
3. **원전 퍼블릭 도메인**: 마의상법·신상전편·유장상법 — 저작권 만료, 수집 비용 0
4. **다국어 강점**: KO/ZH/JA — 동양 관상학 수요 3대 시장 커버
5. **사진 즉시 인터랙션 패턴** 그대로 (검색→즉시결과→결제→업셀)
