# 제안: 규격 상품 입력 게이트 — 촬영 가이드 주 경로 + 실측 사전 차단

**[2026-07-08 13:03 KST]** iMac/민아 → 작가님, M1/쌍아

## 0. 전제 (2026-07-08 작가님 확정)

- **실 유입 0 간주** — GA4 현 수치는 작가님 자가 테스트 오염 (50:50 디바이스 분포 등 관측 트래픽 기반 판단 금지). 설계 기준은 관측이 아니라 **타깃 페르소나 = 모바일 셀카 사용자**.
- 방향 확정: 여권·비자 등 규격 상품은 "아무 사진"이 아니라 **가이드 촬영 셀카**가 정체성. 사전 차단이 원칙. 헤드샷은 관대 게이트로 분리.
- 선행 의존: **EXIF orientation 수정** (REPORT_20260708_iMac민아_00428검증_EXIF회전결함.md) — 실측 게이트가 이 위에 선다.

## 1. 상품별 게이트 계약

| 상품군 | 계약 | 입력 정책 | 게이트 강도 |
|--------|------|----------|------------|
| 여권·비자 (specs 규격) | 규격 보장 — 관공서 통과가 결과물 | **가이드 촬영 = 주 경로**, 갤러리 = 보조 | 실측 사전 차단 (결제 전) |
| 발급보장 ₩9,900 | 반려 시 책임 | 가이드 촬영 강력 권장(또는 필수) | 최엄격 |
| 헤드샷 | 창작·보정 | 자유 업로드 | 관대 (얼굴 검출 수준) |

## 2. 모바일 주 경로 — 가이드 촬영 (IDPASS 웹 이식)

1. specs 페이지 첫 CTA를 "지금 셀카로 찍기"로: `getUserMedia` + 실시간 얼굴 프레임 오버레이 (눈높이선·머리 상단선·중심선).
2. 프레임 안착 시에만 셔터 활성 — IDPASS 카메라 가이드가 강제하던 입력 조건의 웹 재현 (7/7 fit 정규화와 동일 철학, 이번엔 입력 원천에서).
3. 촬영물은 EXIF 회전·프레이밍·해상도가 통제된 상태로 파이프라인 진입 → FaceMesh 실측 신뢰도 최대.
4. 갤러리 선택은 보조 경로로 유지하되 §3의 동일 게이트 통과 필수.

## 3. 사전 차단 게이트 — 감성 판정이 아니라 실측

- 현행 문제: Gemini 게이트가 faceRatio 3배 오판, measurable=true + suitability=F 동시 반환 (7/8 실측). 감성 판정으로 세게 조이면 오차단·오통과 병발.
- 전환: EXIF 수정 후 FaceMesh 실측이 거의 전 입력에서 동작 (7/8 A/B: 밤·전신·11% 얼굴도 회전 보정만으로 face 34.0mm 측정 성공) → **차단 기준 = "실측 후 규격 안착 가능 여부"** (IDPASS 정본 판정표 그대로).
- 순서: 업로드/촬영 → 실측 → ① 안착 가능 → 진행 ② 측정 불가/규격 밖 → **결제 전 차단** + 사유 + "가이드로 다시 찍기" CTA (모바일) — 00428의 FIT_SANITY 결제 차단을 촬영 재유도와 결합.
- Gemini 비전의 역할은 판정이 아니라 심미 보조(7/7 역할 분리 원칙 유지) + 실측 불가 항목(선글라스·표정 등)의 경고 표시로 축소.

## 4. 데스크톱 처리 (실 유입 0 전제의 최소 구현)

- 초기: 업로드 허용 + §3 동일 실측 게이트. 그 이상 만들지 않는다 (트래픽 0에 과투자 금지).
- 확장(트래픽 발생 후): "휴대폰으로 이어 찍기" QR 핸드오프. 웹캠 촬영은 화질상 도입하지 않음.

## 5. 단계 제안 (쌍아 설계 재량)

- **P0 (선행)**: EXIF `.rotate()` 정규화 — fit·matte·precheck 전 sharp 접점 + 좌표계 일원화. 기수정분(00428) 위에 얹기.
- **P1**: 실측 게이트 전환 — FIT_SANITY/규격 밖 = 결제 차단 + 사유 + 재촬영 유도 (00428 차단 로직의 기준 교체·메시지 정교화).
- **P2**: 모바일 가이드 촬영 UI (getUserMedia 오버레이) = 주 경로 승격.
- **P3**: 발급보장 트랙 엄격 모드 + 데스크톱 QR 핸드오프.
- 잔여 정합: 10c 미환불 1건 감사, 원본 3회 왕복 전송 축소(compressImage API 적용), GA4 내부 트래픽 필터(작가님 디바이스 제외).

## 6. 열린 결정 (작가님)

1. 발급보장 트랙에서 가이드 촬영을 "필수"로 할지 "강력 권장"으로 할지.
2. 갤러리 업로드(모바일 보조 경로)를 규격 상품에서 아예 숨길지, 게이트 뒤에 둘지. — 민아 의견: 게이트 뒤 유지 (이미 잘 찍힌 셀카 보유자의 재촬영 강제는 불필요한 마찰).
3. P2(촬영 UI)와 P1(실측 게이트)의 선후 — 민아 의견: P1 선행 (P0+P1만으로도 "쓰레기 입력 결제" 원천 차단 완성, P2는 전환 최적화).
