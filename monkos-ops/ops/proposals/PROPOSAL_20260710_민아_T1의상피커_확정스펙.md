## 2. T1 보정 구성

- **기본 포함 (선택 없음)**: 스튜디오 조명 평탄화 / 자세·정면화 보정 / 피부 정돈(광·잡티, 텍스처·점 보존) / **헤어 정돈 — "드라이 수준"**: 잔머리 정리, 스타일·길이·색·가르마 유지. 의상에 맞게 분위기 해치지 않는 선. 헤어 별도 피커는 후속 과제(복잡도상 지금은 자동).
- **의상 = 유일한 선택 지점**: 기본값 **[지금 옷 그대로]** → 다수는 선택 없이 통과(퍼널 실질 0단 증가). 변경 원하는 고객만 피커 사용.
- 모델: **나노2(gemini-3.1-flash-image-preview) 고정** — 작가님 실측: 증명 보정 품질은 Pro/나노2/2.5 큰 차이 없음, 단 나노2의 **i2i 의상 합성(재생성 인페인트 아님)이 압도적** → 유료 하한이자 적정 티어. Pro 불필요.

## 3. 의상 피커 스키마 (작가님 확정)

- **자산 위치**: 우리 GCS 버킷에 상품컷 저장 (벤더 납품 이미지와 동일 포맷 = 고스트 마네킹 상품컷).
- **기본 팔레트**: 그레이(밝은/차콜 투톤) · 베이지(투톤) · 네이비(투톤).
- **종류 옵션**: 셔츠 / 블라우스 / 탱크탑 등 — 남녀 구분.
- **업로드 창**: 본인이 원하는 의상 사진 업로드 → 동일 i2i 경로. 부적합(화질·각도) 시 프리셋 폴백 + 안내.
- **아이템 스키마 = 벤더형 선탑재** (커머스 비전 — 작가님 장기 구상: 피커에 커머셜 납품, 중개 수수료·벤더 크레딧 구독):
```yaml
attire_item:
  id: string
  label: "차콜 정장 A"
  gender: m | f | unisex
  kind: suit | shirt | blouse | tank
  colorway: gray-light | gray-charcoal | beige-* | navy-*
  image_gcs: gs://.../attire/{id}.png   # 고스트 마네킹 상품컷
  vendor: null | { name, product_url, commission_rate }   # 커머스 슬롯 — 초기 null
  active: bool
```
- 선례 참조: 구 idphoto kr/jp는 타이 종류까지 선택했으나 **t2i 방식** — 이번은 상품컷 i2i라 재현 충실도가 본질적으로 다름(실증 §6). 합성 결과에는 "연출 이미지" 고지.

## 5. 정체성 게이트 (T1 활성화 선행 조건)

- crop-engine에 ArcFace 인식 모델 미탑재 확인(현재 det_10g/2d106det/6drepnet뿐) → **w600k_r50 ONNX 추가 + 사이드카 /api/embed + generate 경로 검사** (6DRepNet 편입과 동일 패턴 소형 작업).
- 판정: 보정 전(매팅본) vs 보정 후 코사인 유사도 ≥ 임계. **임계 캘리브레이션 = 공식 B/A 페어(be_f_1↔ref.jpg)** — 작가님이 합격시킨 보정 강도의 라벨.
- 게이트 실패 시: 재생성 1회 → 재실패 시 보정 강도 낮춘 폴백(피부·조명만) — "딴사람" 출고 구조적 차단.
- 참고 성능: ArcFace 계열 LFW 99.8% — 우리 유스케이스(동일 사진 전/후 대조)는 벤치마크보다 쉬운 문제.
