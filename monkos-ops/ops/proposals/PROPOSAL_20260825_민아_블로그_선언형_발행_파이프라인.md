## 2. 전환 원칙 — 콘텐츠가 자기 배포를 선언한다

- **frontmatter 계약 확장**: `target 언어(파일 단위 lang)` + `head_term`(언어별 검색어 — 번역이 아닌 헤드텀 기준 제작) + `category` + `cta_link`(specs 연동)
- **언어 선택 기준**: 국가 규격 가이드 → 타깃 시장 언어(en 본체, 필요시만 ja) / 운영 에세이 → ko만. 무조건 3개국어 폐지
- **1콜 발행**: 원본 md → 검증 → Firestore 발행 → 라이브 200 검증까지 `tools/blog-publish/publish.mjs` (dry-run 기본, `--publish` 명시)

싱가포르 규격 가이드 ko+en 발행 완주:
