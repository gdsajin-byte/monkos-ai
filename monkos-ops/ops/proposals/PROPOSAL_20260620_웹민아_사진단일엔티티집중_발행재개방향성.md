## 1. 진단 — 왜 시타델·스프레드가 병목이었나

- monkos.ai가 **엔티티 모호성**에 빠졌다. 구글/AI봇이 "증명사진 단일 서비스"인지 "종합 SaaS"인지 분류 불가 → 모든 키워드에서 약하게 잡힘.
- 원인: 한 도메인에 이질적 정체성 3개(제품 + 기술블로그 + SaaS 야망) 혼재 + 같은 키워드 내부 자기경합.
- 결과: 유입(시타델)·배포(스프레드) 콘텐츠가 통째로 병목. 며칠간 발행 유보된 근본 이유 = 이 방향 미확정 + 키워드 사전전략 미완.
- 인사이트('증명한컷' 단조 BM 관찰): **초기 자리매김엔 단일 엔티티 또렷함이 압도적으로 유리.** 한 도메인에 많은 걸 담는 게 오히려 불리.

## 2. 결정 (작가님 확정)

> **monkos.ai = "AI 사진 플랫폼" 단일 엔티티로 집중. 기술·저서·커뮤니티 발산은 보류.**

- 사진 관련 앱은 이미 다수 구축됨(idphoto-kr/jp·headshot 등) = 키울 자산이 충분.
- 내부 기술(포털·콘텐츠 자동화·배포라인)은 **콘텐츠로 발산하지 않고 제품·운영에 응집 기술로 내재**한다. 기술블로그로 따로 빼지 않음.
- **아직 없는 것(저서·에이전트 카페)을 위해 기존 사진 자산 성장을 막지 않는다.** 실적 우선.

## 3. 표면 역할 지도 (단순화 — 사진 우산 일관)

| 표면 | 역할 | 콘텐츠 |
|------|------|--------|
| monkos.ai (제품·specs·블로그) | AI 사진 플랫폼 본체 | 제품(idphoto·headshot·profile·전문직명함) + specs(규격 데이터 색인) + 사진 가이드 블로그(사진 우산 한정) |
| 외부: 네이버블로그·인스타 | 한국 마케팅 → 백링크 | 증명사진 홍보·후기 |
| 외부: 영어권(Reddit·Medium 등) | 영어권 headshot 유입 → 백링크 | headshot/profile 가이드 |

→ monkos.ai는 "AI 사진 서비스" 한 가지 신호만 발산.

## 4. 콘텐츠 전략 변경점 (CONTENT_STRATEGY 보정 방향)

- **P1(사진 마케팅) = 본류로 집중·확장**: 한국 증명사진 가이드 + **영어권 headshot/profile 가이드 신설**(현재 0편) + 한국 전문직 명함(공인중개사·세무사) 클러스터.
  - 역할 분리(쌍아 6/20): 블로그=규격 **가이드**(사람용) / specs=규격 **데이터**(기계 색인용). 중복 규격 나열형 글만 중단, 가이드형은 유지.
- **P2(빌더 서사)·P3(기술 실측) = 보류**: 저서축·기술 발산은 사진 엔티티가 자리잡은 뒤로 후순위. 생산 루틴에서 당분간 제외.
- **2-트랙 원칙(마케팅/기술) → 단일 트랙(사진 마케팅)으로 일시 수렴.** 기술 트랙은 폐기가 아니라 보류.
