# AI 실무 비즈니스 & 에이전트 마스터 클래스

## 과정 개요

- 대상: 비개발자·소상공인·창업자
- 형식: 12주, 주 1회 2시간. 정가 150만 원 / 이벤트 80만 원. 사무실 1:1 → 소그룹(스터디룸) → 웨비나·온라인 실시간.
- 매주 세 칸: ① 개념 ② 도구 찾는 법 ③ "내가 만든 것은 이렇다"(작가님 실제 사례·도구 시연)
- 도구 단계(작가님 결정): **1~3주는 웹 채팅(Claude) + 아티팩트로 손 복붙하며 만든다.** 4주(멀티 에이전트)부터 클로드 코드·깃허브·규칙 파일. 불편을 겪은 뒤에 도구가 왜 필요한지 배운다.
- 기반: Claude + Google
- 수료 결과물: 내 홈페이지 1개 + 앱 1개(또는 프로토타입) + 일하는 체계 1벌

## 1. AI와 에이전트의 시대, 기본기 다지기

1. 나만의 AI 에이전트 만들기
2. AI? 에이전트? AI 관련 기본 용어 익히기
3. 바이브 코딩(Vibe Coding)이란 무엇인가
4. AI에게 이름을 붙여 보자(페르소나 부여의 기술)
5. 내게 맞는 AI 선택하기(Claude, ChatGPT, Gemini 특장점)
6. 클로드(Claude)와 클로드 코드(Claude Code)는 어떻게 다른가요?

## 2. "딸깍" AI로 홈페이지와 나만의 챗봇 만들어 보기

1. 내 개인 홈페이지나 비즈니스 홈페이지를 기획하고 만들어 봅시다
2. HTML, CSS 기본 개념 익히기(필수적인 최소한의 코드 이해)
3. AI에게 "홈페이지 만들어 줘!"라고 효과적으로 지시하는 법
4. RAG(검색 증강 생성) 시스템이란 무엇인가?
5. 내부 데이터와 연동된 나만의 챗봇을 만들어 보자 — **2주에는 웹 채팅 안에서 체험**(프로젝트에 내 자료 올리기 = RAG 체감). 내 홈페이지에 붙이는 실물 챗봇은 API 키가 필요하므로 7주(시크릿) 이후.

## 3. 세상과 소통하기: 배포와 마케팅

1. 홈페이지를 만들었으니 세상에 출시해야죠?
2. 클라우드플레어(Cloudflare)로 무료 호스팅하고 도메인 연결하기 — 대시보드 끌어다 놓기 업로드(명령줄 없음)
3. 내 홈페이지를 세상에 알리는 법(SEO·AI 검색 인용 및 초기 마케팅)

## 4. 멀티 에이전트: 혼자가 아닌 팀으로 일하기

1. 멀티 에이전트는 왜 필요한가요?
2. 개인의 시대에서 '에이전트 팀'의 시대로
3. 깃허브(GitHub)에 나만의 저장소를 개설하고 에이전트 규칙(Rule) 제정하기
4. 에이전트끼리 대화하고 협업한다?
5. 일하는 에이전트, 관리하는 에이전트: AI 팀의 체계화

## 5. AI로 내 업무를 자동화한다

1. 매일 반복되는 내 업무를 코드로 직접 자동화해 보자
2. API로 내게 맞는 비즈니스 앱과 서비스 연동시키기
3. 나의 반복 업무에 대한 분석과 프로세스 이해

## 6. 디자인? AI에게 디자인을 맡긴다

1. 클로드 아티팩트 및 디자인 기능 활용해 보기
2. 피그마(Figma)를 꼭 배워야 하나요?(AI 시대의 디자인 협업)
3. 모션 그래픽과 시각적 몰입감 높이기
4. 레퍼런스 디자인을 분석하고 AI에게 참고시키는 법

## 7. 클라우드 시스템과 데이터 인프라

1. GCP? AWS? 내 프로젝트에 맞는 클라우드 선택하기
2. 데이터 시스템에 대한 이해(Firestore, SQL 등)
3. 권한 설정 및 비용 폭탄 방지 체크리스트
4. 시크릿(API Key, 비밀번호) 안전하게 관리하기

## 8. 오픈소스와 로컬 AI 활용하기

1. 폐쇄형 AI와 오픈소스 AI의 차이점
2. 내 컴퓨터나 모바일에서 오픈소스 AI 구동해 보기
3. 내 컴퓨터에서 AI를 돌릴 때 주의할 점

## 9. AI 콘텐츠 공장: 블로그와 유튜브 자동화

1. 브라우저 컨트롤에 관하여(Playwright, 디버그 크롬 활용)
2. 블로그 제작 팀, 유튜브 쇼츠 제작 팀 구성하여 자동 발행하기
3. 콘텐츠 품질 검수 및 에이전트 피드백 루프 구축

## 10. 하네스(Harness) 엔지니어링: AI를 길들이는 법

1. 컨텍스트 윈도우와 토큰은 유한하다(메모리 관리)
2. 무엇을 기억하고 무엇을 지켜야 하는가
3. AI가 절대 피해야 할 금기 사항을 코드로 막기
4. 에이전트 규율을 지키며 상호 감시하고 협업하기

## 11. 비개발자의 모바일 앱 출시(App Store & Google Play)

1. 나만의 게임 앱, 유틸리티 앱 개발해 보기
2. 애플(Apple) 및 구글(Google) 디벨로퍼 가입하기
3. 내가 만든 앱 업로드하고 심사받고 출시하기
4. 고객의 모바일·PC 환경에서 앱이 안정적으로 작동하는지 모니터링하기

## 12. AI에게 내 비즈니스를 맡길 수 있을까?

1. 내 서비스에 로그인, 결제 시스템(국내 토스, 해외 Lemon Squeezy 등) 붙이기
2. 사업자 연동 및 법적 세팅 마무리하기
3. 개인정보보호법, 초상권법, 현지 법령 파악하기
4. 24시간 내 서비스가 잘 유지되는지 모니터링하고 예외 상황 대처하기
5. AI 비즈니스 운영 최종 점검 및 고도화

## 상품 구조

| 층 | 형태 | 가격(안) | 역할 |
|---|---|---|---|
| 강의집(저서) | 12장 = 12주 | 서점가 | 입구·신뢰 |
| 온라인 콘텐츠 | 주차별 10분 영상·글(유튜브·블로그) | 무료/일부 유료 | 유입 |
