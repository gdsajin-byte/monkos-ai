## 1. 배경 — 4.7이 드러낸 분기

### 1-1. "분기 사건"은 산업 전반에서 동시 발생

- Anthropic 4.7: SWE-bench 급등 + 일반 체감 퇴행 (메모리 *Claude 4.7 운용 관찰* 그대로)
- OpenAI GPT-5.5 (2026-04-23 출시, 현 메인): Terminal-Bench 2.0 **82.7%** 점프, Codex CLI 통합. 토큰 효율 5.4 대비 −40%
- Google Gemini 3 Pro: Deep Think 별도 모드
- DeepSeek V3.1: thinking/non-thinking 토글

→ **단일 모델이 모든 수직을 커버 못 한다는 자백**이 동시에 4건. 4.7은 1개 회사의 일이 아니라 프론티어 진영 전체의 항복 선언.

### 1-1-A. 정량 확인 — 4.7 vs GPT-5.5 (둘 다 4월 출시, 동시 격돌)

| 벤치마크 | GPT-5.5 (4-23) | Opus 4.7 (4-초) | 차이 |
|---|:---:|:---:|---|
| Terminal-Bench 2.0 | **82.7%** | 69.4% | 5.5가 **13.3p** 우위 (다중 턴 워크플로우) |
| SWE-bench Pro | 58.6% | **64.3%** | 4.7이 **5.7p** 우위 (1턴 이슈 해결) |
| OSWorld-Verified | 78.7% | 78.0% | 동률 |
| 컨텍스트 | 1M(API) / 400K(Codex) | 1M | 동급 |

→ 같은 4월에 두 회사가 정확히 반대 축에서 우위. **4.7 = 깊이 / 5.5 = 넓이**. 분기는 한 회사의 일이 아니라 두 회사의 합의된 전공 분리.

### 1-2. 두 시간성의 분리

- **일상 영역의 시계**: 2년 내 정지 (노트북 30GB·핸드폰 GPT-5.5급 도달)
- **해커 영역의 시계**: 4개월 단위로 가속 지속
- 두 시계가 갈라진 첫 순간 = 4.7 = 분기 신호

### 1-3. MONK OS의 현 종속도

| 층위 | 종속도 | 비고 |
|---|---|---|
| 거버넌스(헌법·법률·세션 로그·PF) | **0%** | Markdown + Git. 모델 독립. 영속 |
| 운용 인프라(`.claude/skills/`, hooks, worktree, MCP) | **70%** | Anthropic 규격 일부 + 표준(MCP) 일부 |
| 에이전트 인격(쌍아·민아·막내·소소) | **95%** | Opus/Sonnet 인스턴스 |
| 코딩 실행(막내 = 해커 영역) | **100%** | 4.7 퇴행 직격 부위 |
| 콘텐츠 생성(이미지·TTS) | **30%** | Imagen·Gemini·ElevenLabs 분산 |

위험 집중점: ③④. 거버넌스는 안전, 콘텐츠는 이미 분산.

### 4-1-A. 키미 "Tier" 정체 — 구독 아닌 Rate Limit 자동 승급

작가님 의문(2026-05-03 16:09) 정확. 키미 API는 **Pay-as-you-go + 누적 충전액 기반 Rate Limit 자동 승급** (OpenAI Tier 1~5와 동일 구조).

| Tier | 누적 충전 조건 | RPM | 동시 호출 |
|---|---|:---:|:---:|
| Tier 0 (무료) | 가입만 | 3 | 1 |
| **Tier 1** | **$10+** | **200** | **50** |
| (마일스톤) | $100+ | 5,000 | 200 |
| Tier 5 | $3,000+ | 10,000 | 1,000 |

- 구독료 0원, 충전한 만큼만 차감
- 작가님 $10 충전 = 정확히 Tier 1 진입선
- 별도 "Kimi Code" 프리미엄 구독 상품(300~1200 req/5h)은 다른 트랙
- **함정**: 잔액 0 시 429 Rate Limit 에러로 위장. 잔액 모니터 별도 의무화

### 4-2. 코덱스는 별도 시범 (성격이 다름)

키미·코덱스를 "동시 시범"으로 묶지 않음. 위상이 다르기 때문:
- **코덱스 = 본진 교체 평가** — 앤스와 대체관계. 교체 시점 검증 작업
- **키미 = 보조 자원 측정** — 구독 없이 용병으로 어디까지 쓸 수 있나

### 4-3. 평가표 산출 절차

1. 키미 API 사전 점검 4건 통과 시 → 키미 1자리 시범 → 평가표 키미 컬럼 채움
2. 코덱스 별도 시범 → 코덱스 컬럼 채움
3. 4.6/4.7 컬럼은 일상 운용 중 누적 측정값 보정
