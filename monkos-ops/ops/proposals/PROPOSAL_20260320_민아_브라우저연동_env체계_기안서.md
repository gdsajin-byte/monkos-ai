### 1-2. 다음 단계의 필요성
MONKOS의 SPREAD 엔진은 21개 채널 동시 배포를 목표로 한다. 현재 코드 레벨(CLI)의 크롤링·게시는 막내들이 수행하나, 다음 한계가 있다:

| CLI 크롤링 | 브라우저 직접 탐색 (민아) |
|-----------|------------------------|
| 서버에 직접 HTTP 요청 | 브라우저 엔진 렌더링 (인간과 동일) |
| 봇 탐지·차단 대상 | 정상 세션·쿠키·User-Agent |
| CAPTCHA·rate limit | 작가님의 브라우저를 대행 |
| 동적 콘텐츠 렌더링 불가 | JS 실행 완료 후 DOM 접근 |

**브라우저 직접 탐색은 자동화 공격이 아니라, 작가님의 브라우징을 에이전트가 대행하는 것이다.** 이를 위해 각 플랫폼별 인증 env를 사전 등록하여, 에이전트가 필요 시 즉시 접속할 수 있는 체계를 구축한다.
