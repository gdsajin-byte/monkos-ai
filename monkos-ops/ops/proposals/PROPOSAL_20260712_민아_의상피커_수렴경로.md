# 의상 피커 수렴 제안 — 쌍아 인라인(조합형) × 공유 피커(프리셋형)

**[2026-07-12 12:13 KST]** iMac/민아 → 작가님, iMac/쌍아

## 1. 발견 (병렬 트랙 실사)

민아 피커 트랙 착수 중 `render-specs.js`에 **미커밋 +204줄** 확인 — 쌍아 트랙의 **Phase 2.7 의상 선택(조합형)** 이 금일 세션에서 구현 중. 범위: `v2-phase-attire` 마크업 + 타입 4종(그대로/정장/블라우스/캐주얼) × 컬러·타이 조합 칩 + 조합형 `getAttireDesc()` + `proceedToPay()` 분기 + `body.attireDesc` 배선까지 **완결 수준**.

→ 같은 파일 동시 수정 = 실사고 경로라 **민아 트랙은 render-specs.js를 건드리지 않고 신규 파일로 완결**했다. 본 문서는 두 구현의 수렴 경로 제안이다.

## 2. 두 구현의 성격 (충돌 아님 — 계승 관계)

| 축 | 쌍아 인라인 (Phase 2.7) | 민아 공유 피커 (components/attire-picker) |
|----|------------------------|------------------------------------------|
| 방식 | **조합형** — 타입×수트컬러×셔츠컬러×타이×무늬 (구 kr방식 재현) | **프리셋형** — 큐레이션 12종 (32종 스키마 그릇) |
| 자유도 | 정장만 128조합 | 12종 정제 (작가님 검수 가능 단위) |
| 위치 | render-specs 내장 (specs 전속) | 독립 모듈 (idpass·헤드샷·스타일러 공용) |
| 데이터 | 하드코딩 (ATTIRE_COLORS/LABELS) | attire-presets.json 정본 (벤더·상품컷·3언어·use_case) |
| 상품컷/커머스 | 불가 — 조합에는 SKU·이미지가 존재할 수 없음 | 프리셋=SKU 단위. image_gcs·vendor 슬롯 선탑재 |
| 론칭 속도 | **오늘** (이미 완성) | 컴포넌트 완성·시현 완료, specs 편입은 시점 선택 |

핵심: **조합형은 지금을 위한 최속 경로, 프리셋형은 커머스·멀티서비스를 위한 정본.** 조합 결과에는 상품컷 이미지를 만들 수 없으므로, 썸네일·벤더 단계에 들어서는 순간 프리셋형 전환이 구조적으로 강제된다.

## 3. 제안 — A안 (권장)

**v1 론칭 = 쌍아 조합형 그대로 진행 (무수정).** 공유 피커 편입 시점은 다음 셋 중 먼저 오는 것:

1. **v1.5 상품컷 썸네일 도입** — 12종 AI 생성+작가님 검수 완료 시. 조합형은 이미지를 못 붙이므로 이 시점 전환이 자연 강제. specs 쪽 교체 diff는 3개소(§5).
2. **헤드샷 서비스 의상 선택 탑재** — 공유 컴포넌트 3줄 마운트로 시작 (specs와 무관하게 선행 가능).
3. **스타일러 PF 레퍼런스 피커(v2)** — 같은 스키마에 image_gcs 소비 로직만 증축.

**B안(즉시 교체)** 은 비권장 — 조합형 실주행 신호(고객이 조합 자유도를 쓰는가?)를 버리고 교체할 근거가 아직 없다. **C안(조합 데이터의 JSON 이관)** 은 스키마에 조합 축 확장이 필요해 과설계 — v1.5 전까지 보류.

## 4. 지금 합칠 것 1건 — 계측 이벤트명 통일

쌍아 조합형에 GA4 `attire_select { attire_id, category }` 이벤트를 지금 넣어두면(조합형은 attire_id 대신 조합 문자열), v1.5 전환 후에도 **선택 분포 시계열이 끊기지 않는다**. 이 데이터가 12종 큐레이션 조정(§2 스키마의 sort_order·active 판단)과 벤더 영업 수치의 원료다.

## 5. 전환 시점용 diff 스니펫 (지금 적용 아님 — v1.5 게이트)

```
① 자산 로드 (t1RetouchOn 시 fragment에):
   <link rel="stylesheet" href="/components/attire-picker/attire-picker.css">
   <script src="/components/attire-picker/attire-picker.js" defer></script>

② v2-phase-attire 내부 교체:
   <div class="v2-attire-side"> 안의 cards/sub-options/summary → <div id="atp-mount"></div>
   pageScript: var picker = AttirePicker.mount(document.getElementById('atp-mount'),
     { service:'idpass', lang: CFG.lang || 'ko',
       onChange: function(sel){ gaTrack('attire_select', { attire_id: sel.id }, true); } });

③ doGenerate body:
   if(CFG.t1 && attireConfirmed){ var ad = picker.getAttireDesc(); if(ad) body.attireDesc = ad; }
   (조합형 getAttireDesc() 함수 제거 — 시그니처 동일해 이 한 줄이 전부)
```
