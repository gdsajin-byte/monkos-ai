## 1. 문제

생성·보정 결과물이 **AI티가 나는지 / 과보정인지 / 적절하게 예쁜지**를 사람은 한눈에 알지만 기계 판정은 어렵다. 기준이 상대적이기 때문이다 — 문화(한국=보정 디폴트, 글로벌=자연), 용도(여권 vs 프로필), 개인(원래 피부·골격). 사진 한 장의 절대 판정은 막힌다.

지금은 출고 전 품질을 사람이 보거나 아예 보지 않는다. 결과물이 늘수록 "그럴듯한 엉터리"가 무음 출고될 위험이 커진다.

## 2. 핵심 착안 — 우리는 항상 원본을 갖고 있다

"이 사진이 AI 같나"(절대)가 아니라 **"원본에서 얼마나, 어느 방향으로 멀어졌나"(상대)** 를 잰다. 상대 판정은 수치화가 된다.

| 축 | 측정 | 위반 시 의미 | 기존 자산 |
|---|---|---|---|
| ① 동일인 | 얼굴 임베딩 유사도(원본 대비) | 정체성 붕괴 — 제1원칙 | InsightFace(유료 퍼널) |
| ② 골격 변형 | 랜드마크 이동량 %: 눈 크기·턱선·코 폭·얼굴 폭 | 과보정, 골격 불변 위반, 여권 반려 위험 | FaceMesh(spec-crop.js·gwansang.js) |
| ③ 피부 질감 | 피부 영역 고주파 에너지 잔존율 | AI티의 주범(플라스틱 피부) | 신규 |
| ④ AI 흔적 | 머리카락 뭉개짐·과대칭·눈 반사광 불일치·귀/치아 왜곡 | 생성 모델 결함 | 신규(머리 경계는 10-22 매팅 띠 MAE 도구 재사용) |
| ⑤ 색·조명 | 피부색 ΔE·조명 방향 불일치 | 다른 사람처럼 보임 | 신규 |

①~⑤는 측정 가능. 남는 주관 = **"적절하게 예쁜가"**.

## 3. "예쁜가" = 작가님의 눈을 학습

- **라벨링**: 매일 쌓이는 원본·결과 쌍에서 200쌍 → 작가님·꾸가 `부족 / 적당 / 과함` 또는 `A vs B` 선택(쌍당 수 초).
- **선호 모델**: 라벨 + ①~⑤ 수치 → 작은 모델. 출력 = "작가님이 적당하다고 할 범위"(문화·용도별).
- **해자**: 사진관을 운영하는 전문 사진가의 판정 데이터는 남이 살 수 없다. 바둑에서 "급수별 사람 같은 AI"가 빈자리였듯, 여기서는 **전문가 기준 적정 보정 판정**이 고유 자산.

## 4. 3층 구조 (바둑 해설 봇 구상에서 이식)

| 층 | 바둑 | 사진 |
|---|---|---|
| 판단 엔진 | KataGo | ①~⑤ 수치 + 선호 모델 |
| 개념 번역 | 승률 → "대마 미생" | 수치 → "눈 12% 확대·피부 질감 65% 손실 → AI티, 여권 반려 위험" |
| 입담 | 해설위원 말투 | "고객님, 원래 피부결을 조금 살렸어요. 실물과 같은 사람으로 보여야 하니까요" |

**원칙: LLM은 판정하지 않는다.** 판정은 수치·선호 모델, LLM은 번역층이 넘긴 사실만 말한다.

## 5. 쓰임새

1. **출고 게이트**(1순위): 유료 결과물이 ① 붕괴·② 한도 초과·③ 과손실이면 출고 보류 → 재생성 또는 명시 실패 + 생성권 미소모(기존 원칙과 정합).
2. **강도 자동 조정**: 문화·용도 파라미터별 목표 범위로 보정 강도를 되먹임.
3. **고객 설명**: 결과 화면에 "무엇을, 왜 이만큼" 한 줄(신뢰·반려 불안 해소).
4. **사진관 역수입**: 같은 판정기를 사진관 촬영본 보정에도 적용(꾸 작업 품질 기준선).
