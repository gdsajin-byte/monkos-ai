# PROPOSAL — 시크릿 인지의 코드화 + 권한·SA·키 관리 시스템 진단·개선

**[2026-07-24 08:15 KST]** iMac/민아 → 작가님, iMac/쌍아

> 발단: 작가님 — "시크릿 인지를 코드화하려면? 매번 찾고 있네없네 하지 않도록. 전체 권한·SA·키 관리 시스템 현 수준과 개선방안"
> 전제: [REPORT_20260724 시크릿SA 종합감사](../reports/2026-07/REPORT_20260724_iMac민아_시크릿SA_종합감사.md)의 실측 위에서, "관리 **시스템**"으로서의 수준을 라이프사이클로 재평가.

## 0. 진단 요지

"있네없네"가 반복된 근원은 **정본이 둘**이기 때문이다: SM(실상태) vs 인벤토리 문서(수기 메타). 문서는 사람이 갱신하므로 반드시 drift가 난다 — 오늘 하루에만 3건 실증(PAGESPEED 미등재·구세대 credentials_inventory.md 이원화·도구맵 secret 위치 오기). **코드화의 방향 = 문서를 읽게 하지 말고, 실상태를 1콜로 묻게 하라. 장기적으로는 메타를 값 옆(SM)에 저장해 문서를 '생성물(뷰)'로 강등하라.**

## 1. 현 수준 — 라이프사이클 5단계 평가

| 단계 | 현행 체계 | 수준 |
|------|----------|------|
| ① 등록 | `secret` 커맨드(대화식·값 비접촉) + SM 단일 정본 + 인벤 메타 수기 | **상** — 규약 확립, 침해 전례 0 |
| ② 인지 | 인벤토리 Read + `secret check` — 규율 의존, drift 3건 실증 | **중하 → 금일 `secret map`으로 중상** |
| ③ 사용 | deploy.sh SM 주입(secretKeyRef) + 임퍼소네이션 도구 2종(gsc_submit·adc) + 키리스 런타임 | **상** |
| ④ 순찰 | 웹민아 48h 커밋 diff(레포 유출) + sa_audit.sh·audit_secrets.sh — **크론 미배선(수동 호출)** | **중** |
| ⑤ 로테이션·폐기 | 부재 — yong-a 무만료 키(6/10), 폐기는 수동 disable | **하** |

종합: 등록·사용은 시스템, **인지·순찰·로테이션은 아직 규율+문서** — 오늘 지시가 정확히 이 간극을 겨눴다.

## 2. 금일 완료 (P1 실행분)

1. **`secret map [NAME]` 신설** — 인지 1콜: SM 존재+버전 상태(enabled/disabled)+용도+비고+**레포 실소비처**(git grep 실측). 무인자 = 전체 맵+미등재 자동 적발. 스모크: MATTE_SECRET(활성)·N8N_API_KEY(disabled 표시)·전체 맵 3모드 실작동.
2. **규칙 코드화**: data-access.md — "있네없네 판단 = `secret map` 1콜, grep·문서 탐색 금지" 1줄. 도구맵 secret 위치 오기 교정.
3. **정본 이원화 해소**: 구세대 `credentials_inventory.md`(2/19) 리다이렉트 노트 — 헌법 3조 4항 집행.
4. (선행 완료) 권한 매트릭스 + sa_audit.sh — SA·IAM 인지의 1-Read/1콜 짝.

## 3. 개선안 — P1 잔여 + P2·P3

**P1-ⓓ 메타 정본의 SM 이전 (승인 요청 — 등록 프로토콜 확장이라 쌍아 합의 계층)**
- SM **labels**(기계용 슬러그: `service=portal`, `consumer=deploy-sh`)와 **annotations**(한글 용도 자유텍스트)에 인벤토리 메타를 백필 → `secret map`의 조인 소스가 문서→SM 자체로 승격 → **인벤토리 문서는 스크립트 생성 뷰로 전환, "미등재" 개념 자체 소멸**.
- 실행 설계: 백필 스크립트(dry-run 기본, 인벤 파싱→라벨 매핑표 출력→검수→적용 53건), `secret add`에 용도 입력 1문항 추가(등록 순간 라벨 기록). 값 비접촉·전량 가역(라벨 제거 가능).

**P2 — 순찰·로테이션 배선 (지시서, 각 반나절)**
- 소넷이 일간 크론: `secret map`(무인자) + `sa_audit.sh` → 전일 스냅샷 diff → 변화·미등재·키 90일+·IAM drift만 텔레그램 경보. (도구는 완비 — 배선만 남음)
- yong-a 키 90일 로테이션 크론: 신키 발급→SM 신버전→구키 폐기→로컬 캐시 자동 재복원(gsc_mcp.sh 기존 복원 로직 재사용).

**P3 — 구조 개선 (트랙)**
- 서비스별 SA 분리(감사 T2·T3 승계) · gitleaks pre-commit · (P1-ⓓ 후) 인벤토리 완전 자동 생성.
