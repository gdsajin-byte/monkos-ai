## 1. 청구 사유

### 현행 법률 (제5장 2조)

> "반드시 deploy.sh 경유. gcloud run deploy 직접 실행 금지."
> "배포 타겟: 전 서비스 us-central1 (MEMORY.md 참조)."

### 위반 사실

법률이 존재함에도 **지시서에서 gcloud 명령을 직접 기재**하여 반복 위반이 발생.

| 날짜 | 지시서 | 위반 내용 |
|------|--------|----------|
| 2026-02-15 | (직접 배포) | asia-northeast1 고아 서비스 4건 생성 |
| 2026-02-16 | 정리 실행 | 고아 4건 삭제 |
| 2026-03-18 | 막내3 포털 배포 | asia-northeast1에 rev 00003 배포 |
| 2026-04-03 | pt.monkos.ai 배포 | asia-northeast1 직접 지정 (이건 pt 전용 리전이라 결과적으로 정상) |
| 2026-04-08 | 민아 Specs 26종 지시서 | asia-northeast1만 지정 → 실서비스(us-central1) 미반영. 막내가 현장 판단으로 양쪽 배포하여 구제 |

### 근본 원인

- 2조가 "deploy.sh 경유"를 명시했으나, **지시서 내에서 gcloud 명령을 예시로 제공하는 것**을 금지하지 않음
- 지시서 작성자(쌍아/민아)가 편의상 gcloud 명령을 직접 기재 → 막내가 그대로 실행
- deploy.sh 존재를 모르거나 잊는 경우 방어 수단 없음

## 2. 개정안

### 현행 2조

```
### 2조: monkos.ai 배포 (Cloud Run)

- 반드시 `deploy.sh` 경유. `gcloud run deploy` 직접 실행 **금지**. `gcloud builds submit` 단독 **금지**.
- 배포 타겟: 전 서비스 `us-central1` (MEMORY.md 참조).
- `./deploy.sh dev` — 막내 허용.
- dev 배포 후 **반드시 동작 확인** → 완료 보고에 결과 명시.
- prod 배포가 필요한 경우 `⏳ 대기: prod 배포 필요` 명시.

> 근거: CLAUDE.md L290-301, 2026-02-16 유령 서비스 발견 교훈
> 위반 시: 배포 추적 불가, 유령 서비스 발생.
> 상위 헌법: 제4조(구속·윤리)
```

### 개정 2조 (추가분 ★ 표시, 영향평가 보정분 ☆ 표시)

```
### 2조: monkos.ai 배포 (Cloud Run)

- 반드시 `deploy.sh` 경유. `gcloud run deploy` 직접 실행 **금지**. `gcloud builds submit` 단독 **금지**.
- ★ **지시서에 배포용 gcloud 명령을 직접 기재하는 것을 금지한다.** 배포가 필요한 지시서는 `./deploy.sh {env}` 형태로만 기재한다.
- ☆ **비배포 gcloud 명령(describe, list, domain-mappings 등)은 본 조항의 금지 대상이 아니다.**
- ★ **리전 하드코딩 금지.** deploy.sh 내 REGION 변수가 정본이다. 지시서·구두 지시·스크립트에서 리전을 별도 지정하지 않는다.
- 배포 타겟: 전 서비스 `us-central1` (MEMORY.md 참조).
- ☆ **한시적 예외: pt.monkos.ai** — `pt` 서비스는 asia-northeast1에 도메인 매핑. pt 전용 deploy.sh가 제작될 때까지 gcloud 직접 배포를 허용하되, 지시서에 `[2조 한시적 예외: pt]`를 명기한다. deploy.sh 제작 완료 시 본 예외는 자동 소멸한다.
- ☆ **적용 제외: monk-n8n** — 워크플로우 엔진 특수 서비스로 본 조항의 적용 대상에서 제외한다.
- `./deploy.sh dev` — 막내 허용.
- dev 배포 후 **반드시 동작 확인** → 완료 보고에 결과 명시.
- prod 배포가 필요한 경우 `⏳ 대기: prod 배포 필요` 명시.
- ★ **막내 방어 의무**: 지시서에 배포용 gcloud 명령이 직접 기재되어 있을 경우 막내는 실행 전 2조 위반을 보고하고 deploy.sh 경유로 전환한다.

> 근거: CLAUDE.md L290-301, 2026-02-16 유령 서비스 발견 교훈
> 개정: 2026-04-08 — asia-northeast1 유령 서비스 재발 (4건 삭제). 지시서 경유 위반 방지 보강.
> 영향평가: 막내1 찬성 (위반율 53%, 유령 8건), 막내2 조건부 찬성 (pt deploy.sh 제작 권고). 보정 반영 완료.
> 위반 시: 배포 추적 불가, 유령 서비스 발생, 비용 누수.
> 상위 헌법: 제4조(구속·윤리)
```
