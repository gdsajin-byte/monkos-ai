## 0. 한 줄 정의

**"AI에게 일을 시키는 사람이 되는 12주"** — 프롬프트 요령이 아니라 **위임·검증·기록**의 구조를 가르친다. 매주 세 칸으로 진행한다: ① 개념 ② 도구 찾는 법(고르는 기준) ③ "내가 만든 것은 이렇다"(작가님 실제 사례·도구 시연). 끝나면 수강생 손에 **자기 홈페이지 1개 + 앱 1개(또는 앱 프로토타입) + 일하는 체계 1벌**이 남는다.

## 2. 수강생 제공 도구 (등록 혜택)

- 지시서·보고서·작업 로그 템플릿, PF(프로젝트 장부) 키트
- 홈페이지 시작 템플릿(정적 사이트 + 측정 연결)
- 자동화 키트: 브라우저 자동화 래퍼·알림 봇·예약 작업 예제
- 앱 키트: 실기기 테스트 도구(무료 한도 가드), 스토어 제출 점검기
- 공개 전 정리: 우리 시크릿·내부 경로·내부 호칭 제거본으로 따로 묶는다(헌법 4조 3항 — 외부에는 내부 운영 정보 비공개).

## 4. 정하실 것

1. **대상 1순위**: ① 1인 창업자·프리랜서·크리에이터(내 사이트·앱이 필요한 사람) ② 자영업자 — 메모리상 자영업자는 '배우기'보다 '대행'을 원함(10-06) → 이분들은 레슨보다 대행 상품이 맞을 수 있다. 권장: ①
2. **수업 방식**: 1:1만 vs 소그룹 병행.
3. **이벤트 80만 조건**: 선착순 N명·기간·후기 제공 조건.
4. **강의집 순서**: 레슨 1기 진행하며 장별 원고 축적 → 1기 종료 후 출간(권장).

## 추가 (2026-11-06 06:27 KST — 작가님 사람 턴)

출처 원문: "소그룹도 차차 가능해지면 사무실이 아니라 스터디룸 같은 데서 해야겠지. 웨비나, 온라인 대면 강의도 가능할 거고. 이번에 바둑 해설에 대한 도구와 프로세스가 정리되면 PT를 활용하여 교육 커리큘럼과 콘텐츠를 쌓아가야지. 그러면서 강의노트도 정리되고, 클로드와 구글 기반으로."

- **형식 확장 순서**: 사무실 1:1 → 소그룹(스터디룸 대관) → 웨비나·온라인 실시간 강의. 같은 12주 원고를 형식만 바꿔 재사용한다.
- **제작 파이프라인 = PF_PRESENTATION 재사용**: 바둑 해설 영상 공정을 강의 콘텐츠 공정으로 옮긴다. 바둑 공정은 대본 JSON → 화자별 음성 → 화면 싱크 → 얼굴 창 → 합성이다. 강의에서는 판 화면 자리에 슬라이드·화면 녹화가, 해설자 자리에 강사 아바타·유니(진행)가 들어간다. 1분 관통 시험(11-06)이 강의 쇼츠의 원형이다.
- **강의노트 = 부산물**: 주차별 대본·슬라이드·사례 기록이 쌓이면 그대로 강의집 원고가 된다. 별도 집필 공정을 두지 않는다.
- **기반**: Claude(대본·설계·에이전트 작업) + Google(Gemini·Vertex·YouTube·Workspace·Firebase). 수강생 실습 환경도 같은 두 축으로 맞춘다.
- **순서**: 바둑 해설 도구·프로세스 정리(PF_GO·PF_PRESENTATION) → 그 공정으로 1주차 강의 콘텐츠 1편 시범 → 주차별 확장.
