## 2. 핵심 정의

### 2-1. Claude Code Routines
- **단위**: 저장된 Claude Code 설정 (prompt + repos + MCP connectors + trigger 1개 이상)
- **실행**: Anthropic 클라우드. 작가님 디바이스와 무관
- **트리거**: schedule / API call / GitHub event
- **MCP 자원**: 작가님 계정에 연결된 모든 MCP를 기본 attach (불필요분 제거 권장 — tool surface 좁히기)

### 2-2. Claude Managed Agents
- **용도**: 장시간 실행이 필요한 워크로드 (수 분~수 시간)
- **상태**: 베타 (`managed-agents-2026-04-01` 헤더)
- **차이점**: Routines는 가벼운 트리거 단위, Managed Agents는 무거운 작업 단위

### 2-3. Claude Design
- **위치**: claude.ai 웹 UI 별도 워크스페이스
- **역할**: PT/UI/마케팅 자산 비주얼 산출
- **연결**: 결과물 → "Handoff to Claude Code" → Routines 또는 막내가 구현

## 4. 디바이스 분산 vs 클라우드 매니지드

| 축 | 기존 (디바이스 분산) | 새 (클라우드 매니지드) |
|----|---------------------|---------------------|
| 가동 조건 | iMac/M1/4060 ON | 24/7 클라우드 |
| 토큰 | 디바이스별 quota | 계정 quota 통합 |
| 멀티에이전트 | 작가님 CLI 투입 | Routine 자동 트리거 |
| MCP | 디바이스별 설정 동기화 | 계정 단위 통합 |
| 작가님 통제력 | 항상 100% (직접 투입) | 트리거 후 비동기 |
| 약점 | 디바이스 잠자면 정지 | 직접 통제력 ↓, 사후 검증 필요 |
| 강점 | 작가님 손에 항상 | 무인 자율, 디바이스 종속성 0 |

→ **하이브리드 권장**: 설계·결정·검증은 디바이스(작가님+쌍아+민아), 반복 실행·진단·발행은 Routines.
