# PROPOSAL — specs SSG 빌드 가드레일 3종 (신규 빌드 도구 아님)

**[2026-09-01 05:07 KST]** iMac/민아 → 쌍아 (작가님 발제 "SSG 빌드패턴 자동화 도구" 검토)

## 0. 판정 — 빌드 자동화는 이미 있다, 없는 것은 가드레일이다

빌드·배포·스모크는 `edge/deploy.sh` 한 줄로 이미 자동 (SSG 강제 선행 + 2,581 자산 + 스모크 4/4 + 빌드 신선도 검사, 08-25 신설). 금일 441건 치환 실행에서도 빌드 자체는 무마찰.
실제 잔존 리스크는 빌드가 아니라 **결합**이다:
1. 소스 변경 → 엣지 재배포 의무를 **사람이 기억**해야 함 (누락 = 무음 구본 — 기록된 사고 계열)
2. 스모크가 200/헤더만 보고 **변경 내용 반영은 검증 안 함** (금일 콘텐츠 검증은 민아 수동 2회 히트)
3. 엣지만 갱신되고 **Cloud Run 오리진 사본이 표류** — 추적 장치 없음

## 1. 제안 — 기존 체계에 얹는 3종 (신규 파이프라인 금지)

### G1. specs_drift.sh — 무음 구본 감지 게이트
- deploy.sh가 이미 쓰는 **배포 매니페스트 해시 vs 현행 소스(specs-data·render-specs·specs-i18n·components) 해시** 비교 → 불일치 시 "엣지 구본 상태 — 재배포 필요" 명시 경고.
- 훅 연결: pre-push 훅에서 대상 파일 변경 커밋 감지 시 경고 (기존 gitleaks-precommit.sh 패턴 준용). 무인자 실행 = 현황 1줄 보고.
- 오리진 표류도 동일 출력에 병기 ("오리진 미동기 — 차기 포털 배포 시 해소").

### G2. 콘텐츠 어서션 스모크 — 변경 의도 검증 자동화
- `edge/smoke_assert.txt` (임시 파일): `URL<TAB>+기대문구` / `URL<TAB>-부재문구` 행 나열 → deploy.sh 스모크 말미에 **2회 히트 규칙으로 자동 판정** (live-verify.md 코드화). 파일 없으면 스킵 — 기존 흐름 무영향.
- 금일 수동 검증(3슬러그 10항목)이 표준 절차로 승격되는 효과.

### G3. 도구 맵 등재 + 3요건
- references.md 도구 맵 1행 + 인지 경로(rules/deployment.md 포인터) + 스모크 실증 + 실패 가시화(경고는 stderr·exit 1).
