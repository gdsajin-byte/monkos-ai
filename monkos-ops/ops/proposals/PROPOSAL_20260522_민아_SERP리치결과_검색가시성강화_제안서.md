## 2. 제안 — 4단계 리치 결과 무장

### Phase A. 이미지 썸네일 (즉시 — 1~2주 내 반영)

**대상 페이지**: `idphoto-kr.monkos.ai/app`, `/specs/*`, `/guide/*`, `/blog/*`

| 작업 | 상세 | 담당 |
|------|------|------|
| og:image 세팅 | 서비스 페이지별 대표 이미지 1200×630px. 증명사진 비포/애프터 합성 | 막내 |
| 본문 이미지 삽입 | `/app` 히어로 영역에 AI 증명사진 결과물 샘플 3~4장. 최소 300px 이상 | 막내 |
| Schema.org ImageObject | `Product` 또는 `WebApplication` 스키마에 `image` 필드 추가 | 막내 |
| 이미지 alt 텍스트 | "AI 증명사진 결과물", "여권사진 AI 생성" 등 타겟 키워드 포함 | 막내 |
| robots.txt 확인 | 이미지 크롤링 차단 여부 점검. `Disallow: *.jpg` 등 제거 | 막내 |

**기대 효과**: Google 이미지 인덱싱 → SERP 썸네일 노출. 썸네일 유무에 따른 CTR 차이는 업계 평균 **2~3배**.

**비용**: 코드 수정 + 이미지 에셋 준비. 막내 지시서 1건 분량.

---

### Phase B. 동영상 카드 (2~3주)

**경로**: YouTube 영상 → VideoObject Schema → SERP 동영상 카드

| 작업 | 상세 | 담당 |
|------|------|------|
| YouTube 영상 제작 | "MONKOS AI 증명사진 사용법" 2~3분. PF_PRESENTATION(3D캐릭터/TTS) 활용 | 막내 + 한송이 |
| 타임스탬프 | 주요 순간 마커 3~5개 (HitPaw처럼 "이 동영상의 주요 순간" 표시) | 한송이 |
| VideoObject Schema | `/app` 페이지에 영상 임베드 + 구조화 데이터 | 막내 |
| YouTube SEO | 제목·설명·태그에 "AI 증명사진" 키워드 최적화 | 한송이 |

**기대 효과**: SERP 면적 2배 확보 (동영상 카드 + 주요 순간). YouTube 검색 유입 추가.

---

### Phase C. 앱 리뷰 별점 (IDPASS iOS 출시 연동)

**선행 조건**: PF_IDPHOTO — IDPASS iOS App Store 등록 완료

| 작업 | 상세 | 담당 |
|------|------|------|
| SoftwareApplication Schema | `aggregateRating` 필드 포함 | 막내 |

**기대 효과**: 픽미(4.8★ 2,498건), Monica(4.9★ 17,668건)처럼 별점 시각 요소. 신뢰도 강화.

## 3. 우선순위 + 타임라인

```
[Phase A] 이미지 썸네일  ━━━━━━━ 즉시 착수 → 1~2주 반영
[Phase B] 동영상 카드    ━━━━━━━━━━ 2~3주 (영상 제작 포함)
[Phase C] 앱 별점        ━━━━━━━━━━━━━ IDPASS 출시 후 (PF_IDPHOTO 의존)
[Phase D] SNS 인덱싱     ━━━━━━━━━━━━━━━━━ 상시 (PF_SPREAD 연계)
```
