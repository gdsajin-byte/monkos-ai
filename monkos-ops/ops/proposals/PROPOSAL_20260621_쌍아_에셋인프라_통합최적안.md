```
┌─────────────────────────────────────────────────────┐
│                    MONK 에셋 4축                      │
│                                                      │
│  ① 워크벤치         ② 소통 허브        ③ 프로드        │
│  ~/MONKOS_ASSETS/   Google Drive      GCS 버킷        │
│  (로컬, 자유)       (공유, 자동 백업)   (서비스 정본)    │
│       ↕ macOS 동기화 앱 ↕                              │
│       ↕ 자동 양방향    ↕  승격 스크립트 →               │
│                                                      │
│  ④ 아카이브                                           │
│  리뷰안2T + LaCie (냉장 보관, 비상 복원)               │
└─────────────────────────────────────────────────────┘
```

| 축 | 물리 위치 | 역할 | 접근 주체 | 동기화 |
|---|---|---|---|---|
| **① 워크벤치** | iMac `~/MONKOS_ASSETS/` | 작업 — 자유롭게 만지기 | 작가님, 꾸(M2) | → Drive 자동 |
| **② 소통 허브** | Google Drive `MONKOS_ASSETS/` | 공유 — 에이전트·팀원 접근 | 클로드 디자인, 철창이, 코웍이, 쌍아, 막내 | ← 로컬 자동, → GCS 수동 |
| **③ 프로드** | GCS 버킷 | 서비스 — 코드가 URL 참조 | 코드, 막내(배포) | ← Drive 승격 스크립트 |
| **④ 아카이브** | 리뷰안2T + LaCie | 냉장 — 촬영 원본, 과거 백업 | 작가님 (필요 시) | 수동 |
