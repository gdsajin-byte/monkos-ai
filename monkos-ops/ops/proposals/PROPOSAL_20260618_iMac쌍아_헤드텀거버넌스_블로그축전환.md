## 1. 배경

### 1.1 "AI 증명사진" 키워드 현황 (웹/민아 06-17 경쟁분석 기반)

- `idphoto-kr.monkos.ai/app` 순위 62.7 (CTR 67% — 뜨기만 하면 클릭됨)
- `monkos.ai` 포털 내 블로그/가이드 3페이지가 같은 키워드를 물고 있어 **포털 내 자기잠식** 발생
- `idphoto-kr` 서브도메인 내 루트(/)와 /app이 동일 파일을 서빙하면서 canonical/sitemap/robots 설정 모순 → **버그 수준 중복**

### 1.2 작가님 전략 방향 (06-18 세션 토론)

- **monkos.ai 블로그 축 전환**: 증명사진 주제 신규 발행 중단 → AI 개발/바이브코딩 교육/AI 활용 길라잡이로 고정
- **증명사진 SEO/GEO 권위**: specs(수천 페이지)가 전담
- **monk.kr**: 사진관 + 크리에이티브 콘텐츠 (꾸 네이버 블로그 기반)
- **monkos.ai**: AI 서비스 기업 (증명사진 엔진 + 글로벌 AI 개발/서비스)

### 1.3 서브도메인 vs 포털 경합 논리 보정

- 웹/민아 보고서: "5페이지 자기잠식" → **과잉 진단 보정 필요**
- 서브도메인(idphoto-kr)은 별도 도메인으로 인식 → 포털(monkos.ai) 블로그와 **별도 전선에서 독립 경쟁**, 상호 잠식이 아님
- **진짜 자기잠식**: monkos.ai 포털 내부 블로그 2개 + 가이드 1개 (같은 도메인, 같은 키워드)
- 서브도메인과 포털이 같은 키워드에 **동시 1페이지 노출**은 오히려 이상적 (면적 확장)
- 단, 10위권 밖이면 노이즈 수준 → 각 채널이 독립적으로 순위를 끌어올리는 게 선행

## 2. 제안 사항

### 2.1 [P0] idphoto-kr 루트/앱 canonical 통일 (버그 수정)

**현황:**

| 설정 | 가리키는 곳 | 모순 |
|------|-----------|------|
| canonical | `/app` | "정본은 /app" |
| sitemap | `/` (루트만) | "크롤링은 /" |
| robots.txt | `/app` Disallow | "/app 접근 금지" |

- 둘 다 동일한 `index.html` 서빙 (server.js 737-738줄)
- Google이 둘을 다른 페이지로 인식 → 순위 62(app) / 96(루트) 분산

**처방:**
- canonical을 `/`(루트)로 통일
- sitemap `/` 유지 (현행 유지)
- robots.txt `/app` Disallow 유지 (촬영 퍼널 중간진입 방지)

### 2.2 [P0] monkos.ai 포털 내 자기잠식 해소 (title/H1 교정)

대상 3페이지 (같은 도메인 내 같은 키워드 경합):

| 페이지 | 현재 역할 | 조치 |
|--------|----------|------|
| `monkos.ai/blog/vol38-ai-kr` | 블로그 | title/H1에서 "AI 증명사진" 헤드텀 제거, 고유 롱테일로 교체 |
| `monkos.ai/guide/ai-photo` | 가이드 | 동일 — 가이드 고유 역할(사용법)에 맞는 키워드로 교체 |
| `monkos.ai/blog/ai-kr` | 블로그 | 동일 |

- 본문 삭제 불필요. title + H1만 교정.
- 각 페이지 본문에 `idphoto-kr.monkos.ai`로 내부링크 삽입 (권위 양보)
