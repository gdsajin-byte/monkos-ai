## 1. 서비스 정의 (작가님 확정)

- **specs 증명사진 파트 = IDPASS 브랜딩**으로 완성형 서비스 정의.
- 기존 IDPHOTO KR/JP 앱으로 넘기는 이관 퍼널 폐지 → **전환은 웹에서 완결, 앱은 리텐션 채널**.
- 근거: 웹→앱 설치는 퍼널 최대 절벽. SEO 유입(specs V2)이 결제까지 브라우저 안에서 닫혀야 함.

## 2. 퍼널 확정 (07-09 설계 §2-1 개정)

**분기 선택을 처리 앞(③)에서 처리 뒤(결과 화면)로 이동. 무료(T0)가 기본 흐름.**

```
① 업로드 precheck → ② fit 프리뷰 → ③ 무료 처리(매팅+크롭) → ④ 땡큐(결과+업셀)
```

- 원가 근거: T0 전체 ~₩20/건, 무료 3회/일 캡. 매팅 결과 캐시 → T1/T2 승격 시 재사용(연산 낭비 없음).
- 캡 위치: **무료 결과 생성(매팅)에만** 3회/일. fit 프리뷰·재업로드(~₩1)는 사실상 무제한.

### 2-1. fit 프리뷰 화면

- **수치 뱃지 제거** (33mm·45% 등은 로그/QA로. 필요 시 접힌 "상세 보기").
- 사람 말 판정 1줄: "이 사진으로 만들 수 있어요 / 없어요 — 왜".
- 불가 사유 → 추천 경로 매핑 (문제 = 업셀 사유):
  - 사진 교체 필요(눈감음·저해상·과도한 각도) → [다른 사진] primary
  - AI 교정 가능(배경·조명·경미한 기울기) → [AI 보정으로 해결] 승격
  - 애매/보증 수요 → 발급보장 안내
- CTA: **[무료로 만들기]** 단일 primary + [다른 사진]. 가격 노출은 발급보장 직행 링크 1개만(고의도 유저 우회로).

### 2-2. 땡큐(결과) 화면 위계

1. **완성물** (배경 제거 + 규격 크롭)
2. **[다운로드] + [다른 사진]** — 완성물 직하, 무조건적. 잔여 무료 횟수 표기. 무료 약속의 완전 이행이 업셀보다 먼저.
3. **T1 카드 (AI 보정 ₩2,000)** — 정적 샘플 비교 티저 + [내 사진으로 미리보기] 클릭 게이트
4. **T2 카드 (발급보장 ₩9,900)** — 보증 배지 스타일, 로그인 필수 사전 표기
5. **이벤트 슬롯** (배너 시스템, §6)
6. **앱 카드** — "이 사진, 폰 안에서도 — IDPASS 앱 보관함" (다운로드 이후 리텐션 카드, §5)

- 크레딧 카드는 상품 존에서 **제거** → 이벤트 슬롯 + T1 결제 시트 내 옵션("로그인 시 10c 지급 → 이 건 ₩1,500")으로 이동.
- 현행 버그: 발급보장 점선 각주 2회 중복 렌더 — 수정 대상.

## 3. 상품 정의

### T1 — AI 보정 ₩2,000 (익명 존: "너도 모르고 나도 모르고 땡")

| 구성 | 내용 |
|------|------|
| AI 리터칭 | 본인 정체성 유지 — 보정 후 얼굴 임베딩 유사도 게이트를 검수 항목으로 명문화 |
| **AI 규격 검수** | 표기 확정. '정밀' 금지(책임 오독). T2 병치 문맥이 책임 귀속을 분리. 단독 노출 지면(결제시트·영수증·블로그)에만 각주 "최종 판정 권한은 접수 기관에 있습니다" |
| 파일 제공 | 보정 원본(마스터) + 여권 규격 파일 |
| 프라이버시 | 비로그인 구매 시 원본·결과물 **24시간 후 자동 삭제** — 신뢰 카피로 전면화 |

- 재다운로드·보관은 **상품 약속이 아니라 계정 속성** — 로그인 상태 구매 시 보관함에 자동 적재.
- 결제: 카드/토스 즉시결제, 로그인 불필요.

### T2 — 발급보장 ₩9,900 (회원 존)

- **전문(스튜디오) 검수 + 반려 시 100% 환불**. 로그인 필수 = 마이페이지가 상품 기능의 일부.
- 마이페이지 최소 스코프: 주문 이력 / 보증 청구(반려 증빙 제출→환불) / 보관함.

### 비교 프리뷰 (T1 업셀 도구) — 3중 구조

1. **의도 게이트**: 정적 샘플 티저 → [내 사진으로 미리보기] 클릭 시에만 생성(~₩50). 손익분기 = T1 전환 +2.5%p (T2 환산 +0.5%p).
2. **프리뷰 ≠ 납품물**: 워터마크/저해상.
3. **전환 시 재사용**: 결제 시 기생성본 클린 버전 즉시 납품 — 전환자 프리뷰 원가 ₩0.

- 캡: 사진당 1회, 무료 3회/일 연동. 클릭률·전환 이벤트 계측 필수(실측은 실유입 이후 — GA4 오염 유의).

### 로그인 혜택 스택 (단일 목록으로 통일)

> 로그인하면 — ① 10c 크레딧 지급 ② 내 사진 보관함(재다운로드·타 규격 재크롭) ③ 발급보장 이용 자격

- 타 규격 재크롭 = 보관함 기능(순수 기하, 원가 ~0). 동일 원본 1장 기준.
