## 2. 일반 영상 제작 vs MONKOS 파이프라인

### 일반 영상 제작 워크플로우 (업계 표준)

```
① 기획 (1~3일)
   주제 선정 → 타깃 정의 → 레퍼런스 수집
     ↓
② 구성 (1~2일)
   장면 설계 (씬 리스트/스토리보드)
   → 각 장면: 화면 구성 + 나레이션 + 자막 + BGM + 전환효과
   → 촬영 목록 (로케이션, 인물, 소품)
     ↓
③ 촬영/수집 (1~3일)
   현장 촬영 / 스톡 영상 구매 / 화면 녹화
   → 인물 출연 시: 캐스팅 + 헤어메이크업 + 의상 + 리허설
     ↓
④ 편집 (2~5일)
   프리미어/파이널컷 + 모션그래픽(After Effects)
   → 컷 편집 → 자막 → 효과 → 색보정 → 사운드 믹싱
     ↓
⑤ 검수 + 수정 (1~2일)
   피드백 → 재편집 → 최종 승인
     ↓
⑥ 배포 (1일)
   유튜브 업로드 + 썸네일 + 설명 + 해시태그
   → 다국어: 각 언어별 ①~⑥ 반복 (x3)
```

**총 소요**: 7~16일/건, 다국어 시 x3 = **21~48일**
**인력**: 기획자 + 작가 + 촬영감독 + 편집자 + 모션 디자이너 + 성우
**비용**: 건당 200~500만원 (외주 기준)

---

### MONKOS 파이프라인

```
① 블로그 작성 (30분~1시간)
   한송이/작가님이 CMS에서 KO 글 작성
   → 제목, 본문(마크다운), 이미지, 태그
     ↓
② 자동번역 + 발행 (자동, ~2분)
   blog.js → translate.js
   → {base}-kr, {base}-ja, {base}-en doc 생성
   → sitemap 자동 반영, hreflang 자동 매칭
   → 3개국어 블로그 발행 완료
     ↓
③ 스크립트 추출 (자동, ~30초)          ← 신규
   블로그 본문 → Gemini로 영상 대본 변환
   → 장면(씬) 자동 분할
   → 각 씬: 나레이션 텍스트 + 슬라이드 요약 + 키 비주얼 지시
   → 3개국어 대본 동시 생성
     ↓
④ TTS + 립싱크 (자동, ~5분)            ← 4060 GPU
   대본 → ElevenLabs/edge-tts → 음성 파일
   → SadTalker (사진+음성 → 나레이터 영상)
   → 3개국어 × 씬 수 = 영상 클립 세트
     ↓
⑤ 슬라이드 생성 (자동, ~1분)           ← 신규
   각 씬 요약 → HTML/이미지 슬라이드
   → 블로그 이미지 + 도표 자동 배치
   → 몽코스 캐릭터 PIP 레이아웃
     ↓
⑥ 합성 + 배포 (반자동, ~10분)
   ffmpeg: 슬라이드 + 나레이터 클립 + BGM + 자막 → 최종 영상
   → 유튜브/릴스/틱톡 업로드 (수동 or n8n)
   → 설명란에 블로그 URL (백링크)
```

**총 소요**: 블로그 작성 1시간 + 자동 처리 ~10분 + 검수 30분 = **~2시간/건**
**다국어**: 추가 비용 0 (자동)
**인력**: 한송이(작성) + 에이전트(자동) + 작가님(검수)
**비용**: TTS ~0.04$/컷, GPU 전기세, 바우처 범위

## 3. 상세 플로우 — 각 단계 설계

### ③ 스크립트 추출 (blog → script)

```
입력: 블로그 마크다운 본문
  ↓
Gemini 프롬프트:
  "이 블로그 글을 2~3분 영상 대본으로 변환.
   - 5~8개 씬으로 분할
   - 각 씬: 나레이션(200자 이내) + 슬라이드 제목 + 키 비주얼 설명
   - 도입/전개/결론 구성
   - CTA: MONKOS AI 사용 유도"
  ↓
출력 JSON:
{
  "scenes": [
    {
      "id": 1,
      "narration": "증명사진 찍을 때 안경, 써도 될까요? ...",
      "slide_title": "안경 착용 기준",
      "visual": "안경 O/X 비교 이미지",
      "duration_sec": 20
    },
    ...
  ],
  "total_duration": 150,
  "cta": "지금 MONKOS AI에서 무료로 체험하세요"
}
```

### ④ TTS + 립싱크

```
씬별 narration → TTS 엔진
  ├ 프로덕션: ElevenLabs (고품질, 구독 중)
  └ 프로토: edge-tts (무료, 즉시)
  ↓
음성 파일 (.wav) × 씬 수
  ↓
SadTalker (4060 GPU)
  사진(모델/캐릭터) + 음성 → 립싱크 영상 클립
  ↓
나레이터 클립 세트 (.mp4) × 씬 수
```

**캐릭터 옵션**:
- 몽코스 3D 캐릭터 (PT앱 기존 에셋)
- 실사 모델 사진 (작가님 모델)
- 한 연구원 사진 (전문가 포지셔닝)

### ⑤ 슬라이드 생성

```
씬별 slide_title + visual 지시
  ↓
HTML 슬라이드 생성 (기존 PT앱 패턴 재활용)
  ├ 배경: 블로그 이미지 또는 생성 이미지
  ├ 제목: slide_title
  ├ 포인트: narration 요약 3줄
  └ 브랜딩: MONKOS 로고 + URL
  ↓
슬라이드 이미지 (.png) × 씬 수
```

### ⑥ 합성

```
ffmpeg 파이프라인:
  ├ 레이아웃: 슬라이드(메인) + 나레이터 PIP(우하단 200px)
  ├ 자막: narration 텍스트 → SRT → burn-in
  ├ BGM: 로열티 프리 배경음악 (볼륨 20%)
  ├ 인트로: MONKOS 로고 3초
  ├ 아웃트로: CTA + QR코드 5초
  └ 출력: 1080p MP4 (유튜브) + 9:16 세로 (릴스/틱톡)
```

## 5. 구현 단계

### Phase A: 수동 파이프라인 검증 (1주)

```
vol36 (한송이 신규 글) 기준으로 수동 실행:
1. vol36 본문 → Gemini에 수동으로 대본 추출 요청
2. 대본 → edge-tts로 음성 생성
3. 음성 + 모델사진 → SadTalker 4060에서 영상
4. 슬라이드 수동 제작 (캔바 or HTML)
5. ffmpeg로 수동 합성
6. 유튜브 업로드
→ 전체 프로세스 시간 측정 + 품질 검수
```

### Phase B: 스크립트 추출 자동화 (1주)

```
blog.js 발행 → script-generator.js 자동 트리거
→ Gemini로 대본 JSON 생성 → Firestore 저장
→ 3개국어 대본 동시 생성
```

### Phase C: TTS + 립싱크 자동화 (2주)

```
대본 JSON → tts-pipeline.js
→ ElevenLabs/edge-tts API → 음성 파일
→ SadTalker CLI → 나레이터 클립
→ GCS 업로드
```

### Phase D: 슬라이드 + 합성 자동화 (2주)

```
대본 JSON + 블로그 이미지 → slide-generator.js
→ HTML→이미지 변환 (Puppeteer)
→ ffmpeg 합성 스크립트
→ 최종 영상 GCS 업로드
```

### Phase E: 원클릭 파이프라인 (1주)

```
CMS "발행" 버튼 → 블로그 3건 + 영상 3건 자동 생성
→ 유튜브/릴스 업로드 큐 (수동 검수 후 게시)
```
