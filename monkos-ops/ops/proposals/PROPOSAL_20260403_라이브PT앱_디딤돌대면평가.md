# 제안서: 라이브 PT 앱 — 디딤돌 대면평가

**[2026-04-03 12:30 KST] iMac/민아 → 작가님**

---

## 1. 배경

### 1-1. 목적
4/9(목) 디딤돌 이의신청 대면평가(15분 발표 + 15분 Q&A)에서 **슬라이드 안에서 서비스가 살아 움직이는 프레젠테이션**을 제공하여 평가위원을 압도한다.

### 1-2. 기존 자산 (2026-02-08 구축, 검증 완료)

| 파일 | 기능 | 위치 |
|------|------|------|
| `presentation_server.js` | HTTPS + WSS + Gemini Live API 브릿지 | `apps/monk-cam/demo/` |
| `presenter_sender.html` | iPhone 송신 (카메라 + AI 코칭 오버레이) | 같은 위치 |
| `presenter_receiver.html` | iMac 수신 (프레임 캡처 + 1fps 씬 디텍션) | 같은 위치 |

**실측 성능**: 1280×720 HD, 30FPS, RTT 7ms, 패킷 손실 0%, Gemini 응답 ~5초, 비용 $0

### 1-3. 전략적 가치
- 이번 PT 한정이 아님. **4월 내내 재활용**: 강한소상공인(4/24), 모두의 챌린지 AX(4/21)
- 향후 MONKOS 프레젠테이션 서비스의 PoC (기존 기획 어젠다와 합류)
- 막내 리서치 시 과거 세션(2/8, 2/13, 2/19)의 구상·설계를 참조할 것

## 1-4. 신규 발견: monkos-3d 프로토타입 (막내 당일 구현)

| 파일 | 기능 |
|------|------|
| `apps/monkos-3d/src/character.js` | SVG 정본 기반 3D 몽코스 (Three.js, S귀·K귀·M다리·N코) |
| `apps/monkos-3d/src/animations.js` | 7종 애니메이션 (립싱크·바운스·걷기·시선·가리키기·눈깜빡임·걸어다니기) |
| `apps/monkos-3d/src/tts.js` | Web Speech API + boundary 이벤트 립싱크 |
| `apps/monkos-3d/src/slides.js` | 슬라이드 매니저 (5장 더미 + 대사 매핑) |
| `apps/monkos-3d/index.html` | **오버레이 구도 완성** — 슬라이드 풀스크린 + 3D 캐릭터 우하단 200×220 |

**현재 dev 서버**: `http://localhost:5174/` (Vite)
**스택**: Three.js + Vite (의존성 2개뿐. 경량)
**이미 오버레이 구도**: `character-panel`이 absolute 포지션으로 슬라이드 위에 플로팅

→ **이 프로토타입을 기반으로 확장하는 것이 가장 빠른 경로.** 새로 만들 필요 없음.

## 4. 막내 리서치 과제

> 과거 세션·코드를 먼저 파악한 후 실행계획 수립

### 리서치 1: 기존 프로토타입 파악
- `apps/monk-cam/demo/` 전체 코드 리딩
- `apps/photo-coach/` 구조 파악
- 2/8 세션 로그 (`monkos-ops/ops/sessions/2026-02/20260208_session.md` 238~387줄) 정독
- 2/13, 2/19 세션 로그에서 프레젠테이션 관련 논의 추출

### 리서치 2: React 프레젠테이션 프레임워크 조사
- reveal.js + React wrapper
- mdx-deck
- Spectacle (Formidable)
- 커스텀 경량 구현 (12장이면 프레임워크 없이도 가능)
- **판단 기준**: iframe 임베드 자유도, 빌드 속도, CF Pages 배포 용이성

### 리서치 3: 라이브 임베드 기술 검증
- monkos.ai iframe 임베드 가능 여부 (X-Frame-Options 확인)
- 크롭앱 임베드 가능 여부
- 챗봇 컴포넌트 단독 임베드 방안
- iframe 불가 시: 서비스 화면을 컴포넌트로 직접 포팅하는 대안

### 리서치 4: iPhone 리모컨 연동
- 기존 `presenter_sender.html`의 WebSocket 구조 재활용 방안
- 슬라이드 이전/다음 + 발표자 노트 표시
- Tailscale 네트워크 내 P2P 통신
