# PF_RND 신설 제안서 — 정부 R&D·IP·창업 지원사업 통합 추적

## 1. 배경

### 1-1. 현재 상황 (2026-04-24 기준)
MONKOS는 다수의 정부 R&D·지원사업을 동시 또는 연속 진행 중:

| # | 사업 | 주관 | 상태 | 마감 |
|---|---|---|---|---|
| 1 | **강한소상공인 v8** | 소상공인진흥공단 | 기획서 작성·반영 단계 | 2026-05-06 (연장분) |
| 2 | **하남시 IP 긴급지원 2차** | 경기지식재산센터 (RIPC) | 신청서 초안 완성, 접수 준비 | 2026-05-11 18:00 |
| 3 | 창업성장기술개발(디딤돌) | 중기부 IRIS | 1월 불선정 (이의신청 기록 有) | — |
| 4 | KOITA 연구활동보고서 | 한국산업기술진흥협회 | 작성 완료 | 완료 |
| 5 | 모두의 챌린지 AX-LLM | 정부 공고 | 수행계획서 제출 | 진행 중 |

**공통점**: 모두 "정부·공공 R&D/IP/창업 지원사업"이며, **신청서·사업계획서·증빙·선정·수행·결산** 공통 라이프사이클.

### 1-2. 기존 추적 한계
- 개별 PF 부재 → 각 사업이 `tech/rnd/`·`ops/orders/`·`ops/reports/` 여기저기 흩어져 있음
- 타임라인·마감일·제출 파일·심사 결과 일관 기록 없음
- 서로 다른 사업 간 **중복지원 위반 여부** 교차 점검 불가
- 정부지원금 수령·분담금·정산 현황 통합 조회 불가
- 작가님·민아·쌍아·막내 간 "현재 어느 사업 어느 단계"의 실시간 공유 부재

### 1-3. 오늘 세션 계기
작가님 지시: *"강한소상공인 v8과 이 파트(하남 IP)를 PF-RND로 개설 — 내부에서 분기 추적한다"* (2026-04-24 15:15 KST)

→ PF 개설 + 내부 2트랙 분기 + 향후 확장 구조 필요.

## 2. PF_RND 목적과 범위

### 2-1. 목적
**정부·공공 R&D·IP·창업·컨설팅 지원사업의 생애주기 통합 관리 허브**

- 사업별 신청·선정·수행·정산 타임라인 단일 정본 추적
- 사업 간 중복지원·우선권 충돌 자동 점검
- 정부지원금 수령·기업분담금·보고 의무 통합 대시보드
- MONKOS 현금흐름에서 "정부자금 비중" 투명화
- 에이전트(쌍아·민아·막내) 간 현재 사업 단계 공유

### 2-2. 범위 — 포함 사업군

| 유형 | 예 |
|---|---|
| R&D 기술개발 | 디딤돌, Tips, 혁신개발사업 등 |
| 지식재산권(IP) | RIPC 긴급지원, IP 나래, IP 디딤돌, 소상공인 IP창출 |
| 창업·소상공인 | 강한소상공인, 신사업창업사관학교, 재도전성공패키지 |
| 컨설팅 지원 | IP R&D, 경영혁신 바우처, 수출 바우처 |
| 연구개발 증빙 | KOITA 연구활동보고서, 직무발명보상 |
| 협업 과제 | 모두의 챌린지 AX-LLM, 산학협력 과제 등 |

### 2-3. 범위 — 제외
- **일반 B2C 상용 서비스** (monkos.ai/idphoto-jp 운영 등) — 타 PF(PF_PORTAL, PF_CROP 등)
- **내부 기술 개발만** (정부 지원 없는 자체 개발) — 기술 PF
- **법인·세무·회계** — 별도 관리 영역

| PF_SECURITY | 보안 인프라 | 별도 |
