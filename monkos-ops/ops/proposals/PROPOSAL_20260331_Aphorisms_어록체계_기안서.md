# 기안서: Aphorisms(어록) 체계 신설

**[2026-03-31 11:24 KST] iMac/민아 → 작가님**

---

## 1. 배경 및 필요성

작가님과 에이전트 간 대화에서 발생하는 철학적 인사이트, 촌철살인적 선언, 핵심 통찰이 세션 로그·MEMORY·PHILOSOPHY.md 등에 산재되어 있다. 컨텍스트 컴팩팅 이후 유실되거나, 존재하더라도 발굴이 어려운 상태.

작가님 요청 (2026-03-31):
> "좋은 인사이트가 생길때는 그걸 '어록' 폴더에 기재해놓고 맥락을 남기자. 차후 저서의 단락 제목으로도 멋진 타이포로도 저서로도 담길 '주제'가 될 것이다."

## 2. 신설 체계

### 2.1 폴더 위치

```
governance/philosophy/aphorisms/
```

- `governance/philosophy/`는 MONK OS 철학·세계관의 정본 위치
- "Aphorisms" 채택 근거: 촌철살인·통찰의 뉘앙스. Dicta(선언/판결)는 하중이 한쪽으로 쏠리는 톤 → 작가님 판단으로 배제

### 2.2 파일 네이밍

```
PHIL_YYYYMMDD_키워드.md
```

- `PHIL` = Philosophy 접두사 (법률 ch4 3조 15종 패턴에 신규 추가). 당초 APH(Aphorism) → 직관성 문제로 PHIL로 변경 (2026-03-31 작가님 합의)
- 키워드: 어록의 핵심 테마를 한영 혼용 가능하게 (예: `헌법AI_상호성장`, `쥐와구조`)

### 2.3 파일 내부 구조

```yaml
---
type: PHIL
date: YYYY-MM-DD
speaker: 작가님 | 에이전트명 | 공동
session: 세션 출처 (예: iMac/쌍아 2026-03-31)
tags: [키워드1, 키워드2]
---

> "어록 본문 — 한 줄 또는 핵심 문단"

## 맥락

당시 대화 흐름, 왜 이 인사이트가 나왔는지, 어떤 논의에서 도출되었는지.

## 활용 가능성

- 저서 단락 제목 후보
- 브랜드 타이포/카피
- 대외 발표 키메시지
- 내부 원칙 강화
```

### 2.4 기재 원칙

| 원칙 | 설명 |
|------|------|
| **즉시 기재** | 인사이트 발생 시 해당 세션에서 바로 기재. 나중에 모아쓰기 금지 |
| **원문 보존** | 작가님 발화는 원문 그대로. 에이전트가 윤색하지 않음 |
| **맥락 필수** | 어록만 떨어뜨리면 차후 의미 퇴색. 맥락 섹션 필수 |
| **중복 방지** | 같은 인사이트의 변주는 기존 파일에 어펜드 (신규 파일 X) |
| **speaker 명시** | 작가님 어록 vs 에이전트 분석 vs 공동 도출 구분 |

### 2.5 기존 산재 인사이트 수집 대상

현재 파악된 수집 후보:

| 출처 | 어록 | 비고 |
|------|------|------|
| MEMORY.md | "쥐가 드러낸 것이지, 만든 것이 아니다" | 버그 vs 구조 철학 |
| MEMORY.md | "법은 달리는 열차의 레일이지 벽이 아니다" | 예외 vs 진화 |
| 세션 로그 | "북치고 장구치기" (쌍아 Agent spawn 금지 맥락) | 역할 분리 원칙 |
| 본 세션 | 헌법AI 상호성장론 — "앤스가 원칙을 따르는 AI를 만들고, 내가 진짜 원칙 체계를 짜고, Claude가 준수하고, 상호 성장 루프" | Constitutional Multi-Agent Governance |
| 본 세션 | "제미나이는 유저의 체계를 무시한다" — 모델의 규율 수용력 차이 | 플랫폼 철학 비교 |
| PHILOSOPHY.md | 다수 산재 (정밀 스캔 필요) | 별도 수집 태스크 |
| 과거 세션 로그 | 미발굴 (grep 수집 필요) | 별도 수집 태스크 |

### 2.6 수집 태스크 (승인 시)

1. **즉시**: 본 세션 인사이트 2건 기재 (헌법AI 상호성장, 규율 수용력)
2. **단기**: MEMORY.md 기존 어록 2건 이관
3. **중기**: PHILOSOPHY.md 정밀 스캔 → 어록 후보 추출 → 작가님 선별
4. **장기**: 과거 세션 로그 grep → 작가님 발화 중 인사이트성 문장 후보 리스트업
