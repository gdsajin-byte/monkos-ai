## 4. 4시선 분석

### 4-1. 마케팅부 시선
- **3축 키워드**(§1) × **채널 매트릭스**: KR=오가닉(specs+blog)+네이버/인스타 백링크 / EN=ASO(IDPASS)+pSEO(profiles)+어필리에이트 / B2B=아웃바운드+사원증 랜딩.
- **무료체험 깔때기**: 첫 1장 10c 증정 + 결제 전 미리보기(전환 마찰 0, InstaHeadshots 검증).
- **차별화 수식어 필수**: "아시아 얼굴 + 정체성 보존 90%" (ProfileBakery "자연스러움" 선점 회피).
- KPI: 오가닉 클릭(축별)·앱 설치·B2B 리드·무료→유료 전환율.

### 4-2. 디자인부 시선
- **포털 카드 단일 허브**(2라운드): /id-photo·/headshot·/content + specs·reviews·support. "100c=$10 전 서비스 공용" 상단 고정.
- **스타일 우선 UX**: 1차 선택 = 용도(취업/링크드인/프로필), 규격은 출력단 cropToSpec 자동(침투가격안 §A).
- **신뢰 장치**: /reviews 전후 비교 갤러리 + /support 스튜디오 검수 보장 배지.
- **Special Order 섹션**: 요구사항 입력 폼 + 50c. "사람이 직접 보정 = 경쟁 12사 중 0."

### 4-3. 기술부 시선
- **2라운드 통합**: Cloud Run 5→2, 인증·결제·크레딧 1풀, 스튜디오 API 프록시. 코드 수정 1회로 수렴.
- **SEO 이관**: idphoto-kr/jp → /id-photo 301 (GSC 신호 보존). canonical 통일(6/18 P0).
- **🔴 전환추적 복구 (최우선)**: thankyou.js purchase value:0 버그 — 새 $10 과금 들어오면 측정 깜깜이 치명. 실적 측정 선결.
- **헤드텀 게이트 자동화**: 발행 시 레지스트리 충돌 점검 + 카드별 JSON-LD.
- **Special Order**: Firestore 큐 + 텔레그램 알림 + 이메일 납품.

### 4-4. 경영부 시선
- **통합 과금**: $10/100c, 뭐든 10c, 다운로드 별도과금 폐지(현 kr 80c→10c). 마진 87~93%.
