### 동기화 스크립트 기안

```bash
#!/bin/bash
# sync-assets.sh — 로컬 워크벤치 → GCS 동기화
# 사용법: ./sync-assets.sh [prefix]  (prefix 생략 시 전체)

BUCKET="monk-ai-images"
LOCAL_ROOT="$HOME/MONKOS_ASSETS"

sync_prefix() {
  local prefix=$1
  echo "▶ $prefix"
  gcloud storage rsync "$LOCAL_ROOT/$prefix/" "gs://$BUCKET/$prefix/" \
    --recursive --delete-unmatched-destination-objects=false
}

case "${1:-all}" in
  profiles) sync_prefix "profiles" ;;
  ads)      sync_prefix "ads" ;;
  assets)   sync_prefix "assets" ;;
  all)
    sync_prefix "profiles"
    sync_prefix "ads"
    sync_prefix "assets"
    ;;
esac
```

> ⚠️ 이 스크립트는 **기안**이며, `--delete-unmatched-destination-objects=false`로 GCS 삭제를 방지합니다. 실제 적용 시 작가님 승인 필수.

## 8. 미결 사항 (작가님 판단 필요)

1. **CROP APP HTML/JS 코드**: 현재 Desktop에 Git 미추적 상태로 존재. `apps/crop-app/`에 이미 있는 코드와 관계 확인 필요.
2. **실제샘플 8개의 귀속**: `profiles/master/`에 올릴 것인지 `research/`에 둘 것인지.
3. **GCS에 guides prefix 신설 여부**: 현재 규격 가이드는 MONK_kr(CF Pages)에 정적 배포. GCS에도 올릴 것인지.
4. **워크벤치 루트 이름**: `MONKOS_ASSETS` vs `MONK_ASSETS` vs `Assets` 등.
5. **아카이브 위치**: 삭제 대신 아카이브할 파일의 물리 위치 (`~/MONKOS_ARCHIVE/` 등).
6. **쌍아/crop-electron 전체**: Electron PoC 코드+빌드물을 Git에 보존할지 로컬 아카이브할지.
