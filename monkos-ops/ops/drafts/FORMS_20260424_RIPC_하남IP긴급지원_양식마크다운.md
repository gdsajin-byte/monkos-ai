| 도구 | 용도 | HWP 대응 | 평가 |

| **pyhwp (local)** | HWP 읽기·변환 | ✅ 읽기만. 쓰기는 미지원 | 양식 구조 분석용 ⭐ |
| **pdf (anthropic-skills)** | PDF 생성·조작 | ❌ HWP 미지원 | 첨부 PDF 변환용 |
| **PMS 시스템 업로드** | `pms.ripc.org` | ✅ HWP/DOC/PDF/이미지 허용 추정 | 실측 필요 |

### 추천 파이프라인
```
[Step 1] 민아 초안 작성
  → 마크다운으로 신청서 A·B 내용 완성 (본 문서 확장)
  → Google Docs에 업로드 (공유 가능한 작업 문서화)

[Step 2] 작가님 한컴 오피스에서 양식 열기
  → ~/Desktop/지식산업/extracted/02 ... .hwp (원본 양식)
  → ~/Desktop/지식산업/extracted/03 ... .hwp (원본 양식)

[Step 3] 내용 붙여넣기
  → 민아 마크다운 → 한컴 표 셀에 텍스트 복붙
  → 체크박스 ☑ 직접 체크
  → 저장 (파일명: 02_MONKOS_국내특허.hwp, 03_MONKOS_국내특허_양식7.hwp 등)

[Step 4] 첨부 파일 PDF화
  → 사업자등록증·중소기업확인서·재무제표 등 스캔/PDF 변환

[Step 5] PMS 업로드
  → pms.ripc.org 로그인 → 지원사업 공고 선택 → 업로드
  → 신청 건별 별도 접수 (2회)
```

### 대안 — 한컴 오피스 미보유 시

- **한글 Online** (제한적, 양식 호환성 낮음)
