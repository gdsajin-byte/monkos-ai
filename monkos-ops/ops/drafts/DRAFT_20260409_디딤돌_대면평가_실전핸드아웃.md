## 3. 예상 Q&A (15분)

> 왼쪽 질문, 오른쪽 핵심 답변. 30초 이내로 답하세요.

---

### Q1. "빅테크 API에 의존하면 사업 리스크 아닌가요?"

**답변**:
"맞습니다. 그래서 API 의존율 50% 이하가 연구 목표입니다. 현재 Google Vertex AI를 메인으로 쓰면서, 로컬 GPU에서 오픈소스 모델 파인튜닝을 병행하고 있습니다. 한 벤더에 종속되지 않도록 멀티벤더 전략을 취하고 있고, 이것이 5090 도입의 본질적 목적입니다."

---

### Q2. "매출이 있습니까?"

**답변**:
"결제 시스템은 토스페이먼츠(국내)와 Lemon Squeezy(해외) 모두 연동 완료했습니다. 론칭 초기라 매출 데이터를 축적 중입니다. 다만 원가 구조상 — 1건당 4센트, 판매가 10달러 — BEP 진입 장벽이 극히 낮습니다. 한 건만 팔아도 흑자입니다."

---

### Q3. "일본 시장은 검증했습니까?"

**답변**:
"일본어 서비스(idphoto-jp.monkos.ai)는 이미 배포 완료 상태입니다. LINE OAuth 인증을 획득했고, 일본 내 마케팅 테스트를 착수했습니다. 다국어·다결제 인프라가 완비되어 있어, 시장 검증은 마케팅 집행의 문제이지 기술적 장벽은 아닙니다."

---

### Q4. "왜 K-뷰티입니까? 화장품 아닌 거 알겠는데, 왜 이 용어를 쓰셨나요?"

**답변**:
"K-뷰티를 화장품이 아닌 '한국적 비주얼 브랜딩' 개념으로 사용했습니다. 서구 중심 AI 모델은 동양인을 생성할 때 부자연스러운 결과를 내놓습니다. 이것을 한국적·동양적 감성으로 교정하는 것이 연구 목적입니다. 연구원이 헤어메이크업 실무 7년, 미용교육학 석사, 향장생물학 박사과정으로 이 도메인의 전문가입니다. 다만 '화장품 발색'으로 오독될 여지를 준 점은 인정합니다."

---

### Q5. "크롤링 데이터 출처가 구체적으로 뭡니까?"

**답변**:
"공식 오픈 API 경유 이미지입니다. Pinterest API, Instagram Business API 등 플랫폼이 공개적으로 제공하는 데이터를 사용합니다. 불법 스크래핑이 아닙니다. 그리고 서비스에 사용되는 이미지는 100% 사용자 본인이 업로드한 사진 기반 AI 재생성이므로, 저작권 분쟁의 구조 자체가 없습니다."

---

### Q6. "6개 서비스면 집중이 안 되는 것 아닙니까?"

**답변**:
"쐐기 전략입니다. 증명사진이 진입 상품이고, 사용자가 들어오면 크롭앱·룩북·포토랩 등으로 확장됩니다. 하나의 엔진 위에 여러 출구를 만든 구조입니다. 각 서비스는 독립 앱이 아니라 MONKOS라는 하나의 플랫폼 안의 메뉴입니다."

---

### Q7. "자체 모델 개발 일정은 어떻게 됩니까?"

**답변**:
"3단계입니다. Phase 1은 현재 — API 기반으로 서비스를 검증하고 데이터를 축적합니다. Phase 2에서 축적된 데이터로 LoRA 파인튜닝을 진행합니다. 이것이 5090 도입 이후 4단계 연구 계획입니다. Phase 3에서 경량 모델로 자체 서빙까지 갑니다. 현재 RTX 4060에서 28종 모델 벤치마크를 마쳤고, FLUX.1-dev 같은 차세대 모델은 8GB로 불가능해서 32GB 5090이 필수임을 실증했습니다."

---

### Q8. "KOITA 인증은 언제 받았고, 전담부서 인원은?"

**답변**:
"2026년 1분기에 인증 완료했습니다. 연구개발 전담부서 인원은 연구책임자 1명과 연구원 1명입니다. 소규모이지만, 연구원이 미용교육학 석사·향장생물학 박사과정의 도메인 전문가입니다. 기술 개발은 AI 에이전트 기반 자동화 시스템으로 2인이 6개 서비스를 운영할 수 있는 구조를 갖추었습니다."

---

### Q9. "특허 출원은 어떤 내용입니까?"

**답변**:
"FaceMesh 478포인트 기반 증명사진 자동 규격 검증 기술입니다. 사용자가 업로드한 사진에서 얼굴 랜드마크를 추출하고, 각국의 증명사진 규격(ICAO, 한국, 일본 등)에 자동으로 맞추는 기술입니다. 현재 출원 접수 완료 상태입니다."

---

### Q10. "온디바이스 AI는 왜 필요합니까?" (EXAONE 시연한 경우)

**답변**:
"두 가지 이유입니다. 첫째, 고객 데이터 보호 — 인물 사진이라는 민감 데이터를 클라우드에 올리지 않고 로컬에서 처리할 수 있습니다. 둘째, 서비스 연속성 — 인터넷이 끊겨도, API 공급자가 정책을 바꿔도 서비스가 멈추지 않습니다. 방금 보여드린 것처럼 2.4B 파라미터 모델이 일반 노트북에서 돌아갑니다. 한국어 벤치마크 1위 모델(LG EXAONE)을 사용하고 있습니다."

---

### Q11. (압박) "솔직히 2인 팀으로 이걸 다 할 수 있습니까?"

**답변**:
"1,421개 커밋이 증거입니다. 4개월간 6개 서비스를 배포하고, 25개 SNS 채널을 운영하고, 3개국어 서비스를 론칭했습니다. 비밀은 AI 에이전트 기반 개발 체계입니다. 코드 생성, 테스트, 배포, 콘텐츠 제작까지 AI 에이전트가 보조합니다. 이것 자체가 연구의 산출물입니다. 2인이 200인분의 생산성을 낸다 — 이것이 AI 시대의 R&D입니다."
