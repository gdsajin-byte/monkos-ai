## 📋 03. 국내권리화(특허/실용신안) 신청 세부사항

### 종래기술 및 문제점

**(1) 규격 복잡성**: 증명사진 규격은 국가·용도마다 상이하다. 한국 여권(35×45mm, ICAO 9303), 반명함(30×40mm), 미국 여권(2×2인치), 일본 여권(35×45mm) 등 출력 크기·얼굴 비율·여백 기준이 모두 다르다. 일반 사용자가 이를 정확히 충족하기 어렵다.

**(2) 서버 전송 필수**: 기존 온라인 크롭 서비스는 사진을 서버에 업로드하여 처리한다. 증명사진에는 안면 정보가 포함되어 개인정보 유출 우려가 있다. 2024년 이후 GDPR·PIPA 등 개인정보 규제 강화로 서버리스 설계 요구 증대.

**(3) 정수리 인식 불가**: MediaPipe FaceMesh 등 AI 얼굴 인식 기술은 478개 랜드마크를 제공하지만 이마 상단까지만 커버하며 두정부(정수리)는 감지하지 못한다. 증명사진 규격은 **정수리~턱 끝 거리**로 얼굴 크기를 정의하므로 정수리 위치 추정 기술이 필수.

**(4) 사후 판정**: 기존 도구는 크롭 결과물을 생성한 후에야 규격 적합 여부를 확인할 수 있다. 조정 과정에서 실시간 피드백이 없어 시행착오를 반복해야 한다.

### 출원 예정 특허 기술 개요

**1) 발명의 목적**

본 발명은 사용자가 업로드한 사진에서 AI로 얼굴 랜드마크를 추출하고, 국가별·용도별 증명사진 규격에 **자동 대응**하는 크롭 영역을 산출하며, 규격 적합성을 **실시간 3단계**로 판정하는 **완전 클라이언트 기반** 이미지 처리 시스템을 제공하는 것을 목적으로 한다.

**2) 발명의 기술구성**

본 발명은 다음 5개 핵심 구성으로 이루어진다:

**① 얼굴 랜드마크 추출부**
- MediaPipe FaceMesh(478점) 브라우저 내 실행
- 5개 핵심 랜드마크 선별: 좌동공(159), 우동공(386), 턱(152), 좌볼(234), 우볼(454)

**② 양안대칭 정수리 추정부** (핵심 발명)
- 인체 해부학적 비례(눈~정수리 ≈ 눈~턱) 기반 상방 반전 알고리즘
- 수식: `정수리_Y = 눈_중심_Y − (턱_Y − 눈_중심_Y)`
- 최소 3점(양 동공 + 턱)만으로 정수리 추정 가능
- 헤어스타일·모자·히잡 영향 최소화

**③ 규격 DB 기반 자동 배치부**
- 규격 데이터 객체(wMm, hMm, pxW, pxH, faceMin, faceMax, faceTarget, 여백)만 추가하면 알고리즘 변경 없이 신규 국가·용도 대응
- autoPlace 알고리즘: cover 스케일 → 얼굴 크기 맞춤 → 눈 앵커링(43%) → 좌우 중앙 정렬

**④ 실시간 3단계 적합성 판정부**
- 얼굴 크기(ICAO 32~36mm)·눈 위치(40~48%)·좌우 중심(1~2mm)·상단 여백(3mm) 4축 동시 평가
- 적합(녹)/허용(황)/부적합(적) 3단계 색상 피드백
- 부적합 시 다운로드 버튼 자동 차단

**⑤ 완전 클라이언트 처리부**
- 사진 로드·AI 분석·크롭 계산·JPEG 생성·다운로드 모든 단계 브라우저 내 완결
- AI 모델 파일만 CDN 1회 다운로드 후 브라우저 캐시
- 사용자 안면 사진 서버 전송 일체 없음

**3) 기대효과**

| 항목 | 종래 기술 | 본 발명 |
|---|---|---|
| 정수리 인식 | 이마 랜드마크 기반, 오차 큼 | 양안대칭 반전, 3점 최소 |
| 처리 위치 | 서버 업로드 필수 | 완전 클라이언트 (제로 전송) |
| 규격 대응 | 단일 규격 or 수동 입력 | 규격 DB 자동 대응 |
| 적합성 판정 | 사후 확인 | 실시간 3단계 + 다운로드 차단 |
| 개인정보 | 서버 저장 리스크 | 원천 차단 |
| 국제 확장 | 재개발 필요 | 데이터 추가만으로 즉시 대응 |

### 신청기술의 도면 (간략 설명)

**【 도1 】 전체 시스템 흐름도**
사용자 사진 입력 → MediaPipe FaceMesh 478점 랜드마크 추출 → 양안대칭 정수리 추정 → 규격 DB 조회 → autoPlace 자동 배치 → SVG 오버레이 프리뷰 → 실시간 3단계 적합성 판정 → Canvas API JPEG 출력 → 로컬 다운로드 (서버 전송 없음)

**【 도2 】 양안대칭 정수리 추정 알고리즘**
좌표 기반 수식 시각화. 눈 중심(좌동공+우동공 평균 좌표)과 턱(152번 랜드마크) 좌표로부터 정수리 Y 좌표를 상방 반전하여 산출. 이마·모자·히잡 영향을 받지 않는 최소 3점 알고리즘.

**【 도3 】 실시간 3단계 적합성 판정 UI**
프레임 내 정수리선·턱선·눈 위치선·중심선이 적합성 판정에 따라 녹/황/적 색상 동적 변환. 하단 ICAO 범위 바에 현재 얼굴 크기(mm)가 점으로 표시되어 허용 구간(32~36mm) 내 위치를 시각화.
