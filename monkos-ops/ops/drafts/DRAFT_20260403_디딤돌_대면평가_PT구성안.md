# 디딤돌 이의신청 대면평가 — PT 구성안

**전략: 10분 방어 + 5분 공격 전환**

---

## 파트 A: 반박 (10분)

> 핵심 메시지: "8건 중 7건은 제안서를 읽지 않은 평가"

### A-1. 오프닝 (1분)

- 인사 + 과제 한 줄 소개
- "본 소명은 평가 보완이 아닌 **해석 오류 7건 + 과잉 판단 1건**에 대한 이의입니다"
- 스크린 or 보드에 **8건 지적 → 3개 오독 유형**으로 분류한 표 제시

| 오독 유형 | 해당 지적 | 한 줄 요약 |
|----------|---------|-----------|
| **과제 자체를 오독** | ①③ | "발색"은 제안서에 없다 / "편향"의 기준이 없다 |
| **기술 구조를 오독** | ②④⑥⑦ | GPU=서버로 전제 / API 사용=차별성 부재 / 원가 $0.04를 비용 모순으로 |
| **평가 범위 초과** | ⑤⑧ | 크롤링 수익배분 요구 / R&D 과제에 투자심사 잣대 |

### A-2. 과제 오독 반박 (3분)

**지적 ① "발색 수치 구현 정확성"**
- 제안서 1-1항 원문 발췌 — **"발색" 0회 기재**
- 핵심 연구과제는 "인물 정체성 유지율 90% 달성"
- "K-뷰티 = 화장품 발색"이라는 선입견

**지적 ③ "전문가 편향 우려"**
- RLHF(인간 피드백 강화학습)는 GPT·Gemini 등 글로벌 AI의 표준 방법론
- 뷰티에 "절대 정답"이 없으므로 "편향" 판단 기준 자체가 부재
- K-뷰티는 서구 중심 모델의 편향을 교정하는 연구 목적

### A-3. 기술 구조 오독 반박 (4분)

**지적 ② "GPU 처리 속도 방안 부족"**
- 평가자: GPU = 서비스 서버
- 실제: GPU = 자체 모델 적재·파인튜닝용 연구장비
- 클라우드 API(프로덕션) + 로컬 GPU(R&D) 병렬 구조

**지적 ④ "범용 GenAI 대비 차별성"**
- 자가 진화 파이프라인은 "차별점"이 아니라 AI 서비스의 기본 동력
- 이미 운영 중: RAG 챗봇 + FAQ 학습 + 휴먼 코멘트 가중 업데이트
- 증명사진·크롭앱·포토랩 등 종합 포털 자체 개발

**지적 ⑥ "빅테크 대비 경쟁력"**
- Adobe Firefly(크리에이티브 도구), Runway(영상 생성), Stitch Fix(의류 추천)
- → 시장·고객·가치제안이 **전혀 겹치지 않는 범주 오류**
- 빅테크는 공급자(엔진)이지 경쟁자가 아님
- "이 논리면 빅테크가 못하는 것만 R&D해야 디딤돌 통과"

**지적 ⑦ "고해상도 비용 vs 저비용 모순"**
- 제안서 작성(25.12) 시점: AI 출력 1024×1024 → 독자 업스케일 연구 필요
- 현재: AI 엔진 자체가 멀티모듈 업스케일 도입
- **실측: 1회 원가 $0.04 vs 판매가 $10 → 마진 99.6%**
- 모순이 아니라 기술 진화가 문제를 해소한 사례

### A-4. 평가 범위 초과 (2분)

**지적 ⑤ "크롤링 저작권 리스크"**
- 크롤링 = 데이터 수집의 일반명사 (Google·네이버 전부 크롤링 기업)
- 당사: 공식 오픈 API 경유, 서비스 이미지는 100% 사용자 본인 저작물
- R&D 계획서에 수익 배분까지 요구하는 것은 평가 범위 초과

**지적 ⑧ "사업화 전략 구체성"**
- 디딤돌은 R&D 연구과제이지 투자 심사가 아님
- 제안서 이후 **이미 실행한 것**: 6개 서비스 배포, 결제 정착, KOITA 인증, OAuth 3종, 25개 SNS
