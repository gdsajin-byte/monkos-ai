## 1. 서비스 개요

스마트폰이나 PC 브라우저에서 증명사진을 여권/비자 규격에 맞춰 자동으로 크롭하는 웹 서비스입니다.

핵심은 **모든 처리가 사용자의 기기(브라우저) 안에서만 이루어지며, 사진이 외부 서버로 전송되지 않는다**는 점입니다. 서버 없이 동작하므로 이용자 수에 관계없이 서버 비용이 발생하지 않고, 개인정보(얼굴 사진) 보호가 구조적으로 보장됩니다.

현재 한국어·일본어 버전이 서비스 중이며, 무료로 제공하고 있습니다.
- 서비스 URL: https://monkos.ai/crop

## 2. 핵심 기술 구성

### (1) AI 얼굴 인식 — MediaPipe Face Mesh

Google의 MediaPipe Face Mesh 모델을 브라우저 내에서 구동하여, 얼굴의 478개 특징점(랜드마크)을 실시간으로 감지합니다.

이 중 핵심 5개 지점(양쪽 눈 중심, 턱 최하단, 좌우 윤곽)을 추출하고, **해부학적 비율(눈~턱 거리 ≈ 눈~정수리 거리)을 이용하여 정수리 위치를 자동 추산**합니다.

### (2) ICAO 국제 규격 자동 검증 — 3단계 실시간 판정

국제민간항공기구(ICAO) 증명사진 규격을 기준으로, 다음 항목을 실시간 검증합니다:

| 검증 항목 | 기준 (여권 35×45mm) |
|-----------|-------------------|
| 얼굴 크기 (정수리~턱) | 32~36mm (최적 33~35mm) |
| 눈 위치 (프레임 상단 기준) | 40~48% (최적 43~45%) |

판정 결과를 **3단계 색상(녹색=최적 / 노랑=허용 경계 / 레드=범위 이탈)**으로 시각화하며, 레드 구간이 1개라도 있으면 다운로드를 차단하여 규격 미달 사진의 제출을 원천 방지합니다.

### (3) 눈 앵커 기반 자동 배치 알고리즘 — autoPlace

얼굴 인식 결과를 바탕으로, 사진의 크기와 위치를 자동으로 최적 배치합니다:

1. 양쪽 눈 중심점을 프레임 높이의 43% 지점에 고정(앵커링)
2. 얼굴 크기(정수리~턱)가 규격 목표치(34mm)에 맞도록 스케일 자동 조정
3. 얼굴 좌우 중심이 프레임 중앙에 오도록 수평 보정

사용자는 자동 배치 후 핀 드래그, 사진 이동/확대로 미세 조정만 하면 됩니다.

### (4) 완전 클라이언트 아키텍처

위 모든 처리(얼굴 인식 → 자동 배치 → 규격 검증 → 크롭 출력)가 **서버 호출 없이 브라우저 내에서 완결**됩니다.

- 얼굴 인식: MediaPipe CDN에서 모델 로드 → 브라우저 내 추론
- 크롭 출력: Canvas 2D API로 원본 해상도 유지 + 300dpi JPEG 생성
- 네트워크 전송: 없음 (사진이 기기 밖으로 나가지 않음)

| 구분 | 기존 증명사진 크롭 앱 | MONKOS Crop |

| 배치 방식 | 수동 크롭 | **눈 앵커 43% + 해부학적 정수리 추산 자동 배치** |
| 프라이버시 | 사진 서버 전송 | **기기 내 처리, 전송 없음** |
| 비용 모델 | 유료 또는 서버 비용 발생 | **완전 무료, 서버 비용 제로** |

## 4. 특허 청구 가능 포인트 (검토 요청)

아래 기술 요소들의 특허 출원 가능성을 검토해주시면 감사하겠습니다:

1. **클라이언트 완결형 증명사진 자동 규격 검증 시스템** — 얼굴 인식·규격 검증·크롭 출력 전 과정을 서버 없이 브라우저에서 처리하는 구조
2. **ICAO 규격 3단계 실시간 판정 + 다운로드 차단** — 녹색/노랑/레드 단계별 판정과 규격 미달 시 출력 차단
3. **눈 앵커 기반 자동 배치 알고리즘** — 478 랜드마크에서 눈 위치를 앵커로 사용하고, 해부학적 비율로 정수리를 추산하여 규격 프레임에 자동 배치
