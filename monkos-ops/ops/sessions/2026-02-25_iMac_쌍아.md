- 철창이(코웍)가 "리모트로 상주하는 지능형 라우터"라고 표현한 건 **트리거 → 실행 → 종료의 스위치 리모트 개념**이지, 지능형 상주 서버가 아님

**발단**: 전 세션이 4.2MB 스크린캡처 이미지 입력으로 컨텍스트 사망.
PNG 무압축(1206x2622)이 원인 — 해상도 유지하면서 JPEG 60%로 변환하면 228KB.

**작가님 요구**: "폰 캡처 → 에어드랍 → 폴더 드래그" 워크플로우에서 리사이즈까지 끼워넣는 건 비현실적. 자동화 필요.

**구현 — `scripts/철창이_watcher.sh`**:
- `fswatch`로 `~/Desktop/철창이/` 루트 감시
- 이미지 → `images/`로 원본 이동 + `_input_` JPEG 리사이즈 복사본을 루트에 생성
- MD/TXT → `docs/`로 자동 이동
- launchd 등록 → iMac 로그인 시 자동 시작

**삽질 기록**:
1. launchd 환경에서 brew PATH 안 잡힘 → fswatch 절대경로(`/usr/local/bin/fswatch`)
2. iCloud Desktop `mv` 권한 차단 → Finder(`osascript`) 경유로 해결
3. macOS 한글 NFD/NFC 인코딩 차이 → 문자열 비교 전면 불신, depth 비교로 우회
4. 한글 접두사 `입력용_`도 NFD 재귀 폭탄 → 영문 `_input_`으로 변경

**최종 결과**: 4.2MB PNG → 228KB JPEG, 해상도 동일, 자동 처리 확인.

**산출물**:
