> **정본 선언**: 이 폴더가 세션 로그의 유일한 정본입니다.
> docs/corpus/sessions/는 읽기전용 아카이브입니다. 참조하지 마세요.
> 최신 문서는 이 폴더의 가장 최근 월별 서브폴더에 있습니다.

## 분산 기록 원칙 (헌법 제1조 2항)

- 모든 에이전트는 **자기 세션 로그를 자체 기록**한다.
- 타 에이전트의 세션 로그 파일을 편집하지 않는다.
- 쌍아는 세션 인덱스(본 README) 관리 + 보고 파일 수거 시 자기 로그에 통합 기록.

## 정본 규칙

- 네이밍: `YYYY-MM-DD_{device}_{agent}.md` (ch4 3조 #7)
- 다중 세션 접미어: `_새벽`, `_오전`, `_오후`, `_저녁`, `_2차`, `_3차` (ch4 3조 #7a)
- 통합 로그: `YYYY-MM-DD_{agent}_통합.md`
- 1일 1파일 원칙, append only, Q&A 번호 연속 증가
- 월별 서브폴더: `YYYY-MM/` — 매월 1일 이관 + README 작성 (ch3 1조)

## 어펜드 포맷

세션 로그는 **append only** — 기록된 내용의 수정·삭제 절대 금지.

**턴 구분자:**
```markdown
### [HH:MM] 작업 주제
```

**타임스탬프 형식:**
- 시스템 명령(`date`)으로 취득한 KST만 사용. 추정/기억 기반 금지.
- `~` 추정 표기 금지 — 역추적하여 정확한 값 기입 (ch3 4조).

**작가님 발언 인용:**
```markdown
**작가님**: "중요 발언 직접 인용"
```

## 태그 체계

| 태그 | 용도 | 필수 조건 |
|------|------|----------|
| `[직접지시]` | 작가님 직접 지시로 수행한 작업 | 작가님 지시 원문 인용 필수 |
| `[추인]` | 쌍아가 직접지시 작업을 사후 확인 완료 | — |
| `[개헌]` | 헌법 충돌 승인 후 진행 | 조항 인용 + 승인 기록 |
| `[예외]` | 법률 충돌 승인 후 진행 | 조항 인용 + 예외 기록 |
| `[log]` | 세션 로그 포함 커밋 태그 | 커밋 메시지 접두어 |
