## 배경

MONKOS 결제 전환율 6% (106명 가입 → 63명 사용 → 외부 결제 4명). 5월 결제 0건.
퀄리티는 검증됨. 크레딧 시스템 + 단가 구조가 전환 장벽으로 작용.
**크레딧 폐지 → 직접결제 전환**을 검토 중이며, 시장 단가 데이터가 필요.

## 임무

### 막내1: 글로벌 AI 증명사진 서비스 전수조사

**조사 대상 (기존 29개 + 추가)**
- 기존 경쟁사 29개 (PF_PORTAL 또는 이전 조사 참조)
- **필수 추가**: 증명한컷, 인핸즈(InHands), Passport Photo Online, IDPhoto4You, PhotoBooth Online, Fotor ID Photo, Remini, PhotoAiD, Cutout.pro, 123PassportPhoto, ePassportPhoto, Snap2Pass, PersoFoto, Biometric Passport Photo, 여권사진AI, 패스포토, 其他日本語サービス
- 위 외에도 발견되는 AI 증명사진 서비스 전부 포함

**조사 항목 (서비스당)**

| 항목 | 설명 |
|------|------|
| 서비스명 | 정식 명칭 |
| URL | 공식 사이트 |
| 국가/언어 | 서비스 대상 국가 |
| 과금 모델 | 크레딧/구독/건별/프리미엄 등 |
| 무료 범위 | 프리뷰? 저해상도? 워터마크? 완전무료? |
| 최소 결제 금액 | 1장 기준 최저가 (USD 환산) |
| 벌크 할인 | 다수 구매 시 단가 |
| 앱 유무 | iOS / Android / 웹 전용 |
| Apple IAP 가격 | 앱 있으면 IAP Tier 확인 |
| AI 기능 범위 | 배경제거만 / 보정 / 생성 / 크롭 |
| 결제 수단 | 카드/PayPal/Apple Pay/토스 등 |
| 특이사항 | 구독 유도, 환불정책, 리뷰 평점 등 |

### 막내2: 최적 단가 + 과금 모델 제안

막내1 조사 결과를 바탕으로:

1. **시장 단가 분포 분석** — 최저/최고/중앙값/최빈값
2. **과금 모델 분류** — 건별 vs 크레딧 vs 구독, 각 모델의 전환율 특성
3. **MONKOS 포지셔닝** — 우리 퀄리티 대비 적정 단가 레인지
4. **추천안 3가지** — 보수적/중간/공격적 시나리오
   - 각 안의 예상 전환율, 객단가, 월 매출 시뮬레이션
5. **무료 체험 설계** — 첫 결제 유도를 위한 최적 무료 범위
