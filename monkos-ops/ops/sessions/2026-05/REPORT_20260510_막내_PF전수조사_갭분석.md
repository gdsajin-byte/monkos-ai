```
Phase A (즉시, 재료 충분):
  PF_PHOTOPRO — devlog 5편 + 사업화 프레임
  PF_CROP     — devlog 5편 + 사업화 프레임
  PF_PROFILES — 사업화 프레임 (devlog는 실행 후)

Phase B (재료 풍부, 정리 필요):
  PF_CDP      — devlog 5편 (사업화는 R&D 증빙 형태)
  PF_CITADEL  — devlog 5편 + 사업화 프레임

Phase C (추가 리서치 후):
  PF_PORTAL, PF_STUDIO, PF_PRESENTATION, PF_VIDEO, PF_SPREAD
```

### 부가 의견 — 구조 정비 우선 PF

| PF | 문제 | 제안 |
|-----|------|------|
| EVENT | 9섹션 구조와 완전 불일치 | 전면 재작성 (비전+Phase 추가) |
| DOCS | 도구 추적 문서 — PF 성격 불일치 | 템플릿 구조로 정규화 or ops/guides/ 이관 |
| SPREAD | §7~§12 독자 섹션 비대 | 핵심을 §4(아키텍처)에 정리, 나머지 PF_SPREAD/ 폴더형 분리 |

## 부록: §4 아키텍처 현황

| PF | 현재 §4 라벨 | 아키텍처 포함 가능 재료 |
|----|-------------|---------------------|
| PHOTOPRO | 성과 | Vertex AI 파이프라인, photo.js 패턴, QC 흐름 |
| PORTAL | 성과 | render.js fragment 구조, CMS→SSR 흐름, 블록 에디터 |
| CROP | 성과 | FaceMesh→ICAO 검증→크롭 파이프라인, 오프라인 아키텍처 |
| CDP | 기술 참조 (§8) | CDP 연결 구조, PageProfiler, MCP 4서버 |
| CHATBOT | ✅ 아키텍처 | chatWithMonkos 6채널 + RAG + 온디바이스 |
