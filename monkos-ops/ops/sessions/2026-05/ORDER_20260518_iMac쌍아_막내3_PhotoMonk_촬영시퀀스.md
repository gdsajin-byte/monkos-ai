# 지시서: PhotoMonk — 스튜디오 촬영 시퀀스 구현

## 배경

현재 PoC는 "전 항목 🟢 → 카운트다운 → 자동촬영"이지만, 실제 스튜디오 촬영처럼 **작가가 모델을 안내하는 시퀀스**가 빠져 있음. 이 시퀀스가 앱의 체감 품질을 결정한다.

## 전체 플로우

### Phase 1 — 카메라 ON + Vision 즉시 추적

시작 버튼 누르는 즉시:
- 카메라 활성화
- Vision 실시간 추적 시작
- **눈/코/턱 랜드마크 가이드 오버레이** 화면에 표시 (반투명 도트 또는 라인)
- 타원형 얼굴 가이드 프레임

### Phase 2 — 포지셔닝 코칭 (우선순위 단일 메시지)

기존 우선순위 코칭 그대로:
1. 얼굴 감지
2. 카메라 각도 ("카메라를 눈높이로 올려주세요")
3. 정면성 ("정면을 봐주세요")
4. 거리 ("조금 뒤로 물러나주세요")
5. 조명/그림자
6. 선명도
7. 눈 감김

**한 번에 하나씩, 해결되면 다음.**

### Phase 3 — 전 항목 통과 → 촬영 시퀀스 (핵심 신규)

전 항목 🟢 통과 후 **자동으로** 아래 시퀀스 진행:

| 시점 | 화면 | TTS 음성 | 비고 |
|------|------|---------|------|
| 0.0s | 🟢 "좋아요, 촬영합니다" | "좋아요, 촬영합니다" | 상태 전환 — 코칭 종료, 촬영 모드 진입 |
| 1.0s | "그대로~ 표정 부드럽게" | "그대로 표정 부드럽게" | 긴장 풀어주기 |
| 2.5s | "카메라 봐주세요" | "카메라 봐주세요" | 시선 유도 |
| 4.0s | **"3"** (큰 숫자 오버레이) | "삼" | 카운트다운 시작 |
| 5.0s | **"2"** | "이" | |
| 6.0s | **"1"** | "일" | |
| 6.5s | ⚡ 화면 플래시(하얀색 0.1초) | 셔터음 | 📸 자동 캡처 |
| 7.0s | 캡처된 사진 프리뷰 | — | 결과 확인 |

### Phase 3 중단 조건

촬영 시퀀스 진행 중에도 **Vision은 계속 감시**:
- 얼굴 이탈 / 눈 감김 / 급격한 움직임 감지 시 → 시퀀스 중단
- "앗, 다시 한번 준비해주세요" → Phase 2로 복귀
- 재차 🟢 통과 시 Phase 3 처음부터 재시작

### 랜드마크 오버레이 상세

| 요소 | 표시 방식 | 색상 |
|------|----------|------|
| 눈 위치 | 좌/우 눈 중심 도트 | 초록 (통과 시) / 빨강 (미통과) |
| 코 위치 | 코 중심 도트 | 동일 |
| 턱 라인 | 턱 포인트 연결선 | 동일 |
| 얼굴 가이드 | 타원형 프레임 | 🔴/🟡/🟢 색상 연동 |
| 정수리 추산선 | 점선 | 연한 회색 |

오버레이는 **Phase 3 카운트다운 시작(4.0s) 시 페이드아웃** — 촬영 순간에는 깨끗한 화면.

### 디바이스 화각 기반 적정 거리

| 카메라 | 화각 | 적정 얼굴 비율 (프레임 대비) |
|--------|------|---------------------------|
| iPhone 전면 (12MP, 26mm eq.) | ~78° | 35~50% |
| iPhone 전면 (TrueDepth) | ~65° | 40~55% |

Vision bbox 높이 / 프레임 높이로 계산. 범위 밖이면 "가까이"/"뒤로" 코칭.
