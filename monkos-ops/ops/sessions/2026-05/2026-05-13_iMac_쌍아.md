## **[2026-05-13 11:28 KST]** Vision 얼굴 인식 디버깅

**문제:** 사진 선택 후 "얼굴을 찾을 수 없습니다" 에러

**디버깅 과정:**

1. **orientation 문제 의심** → `CGImagePropertyOrientation` 전달 + `normalizedImage()` 추가 → 실패
2. **CheckedContinuation 이중 resume 크래시** → 크래시 로그 분석:
   - `_assertionFailure → CheckedContinuation.resume(returning:)` — continuation이 두 번 호출됨
   - `try?`가 에러를 삼키면서 콜백+catch 양쪽에서 resume 가능
   - **해결**: `withCheckedContinuation` 제거, Vision의 `perform`은 동기 메서드이므로 직접 호출로 단순화
3. **여전히 얼굴 미인식** → 디버그 정보 화면 표시:
   - 이미지 정상: `size:(1024,1024) orient:0 cgImage:true jpeg:true`
   - CLI에서 같은 이미지로 Vision 테스트 → **얼굴 1개 정상 감지**
4. **3방식 동시 테스트** (cgImage+up, cgImage+default, CIImage):
   - **결과: `rect.up:ERR(Could not create inference context) rect.def:ERR ci:ERR`**
   - **원인 확정: iOS 26.5 시뮬레이터에서 Vision CoreML 추론 엔진 미지원**
5. **CIDetector fallback 적용** → 구형 얼굴 인식 엔진, CoreML 불필요
   - 얼굴 인식 성공! 다만 **이미지 상하 반전** 발생
6. **상하 반전 해결**: `context.draw(cgImage)` → `UIImage.draw(in:)` 전환
   - Core Graphics는 좌표 원점이 좌하단 → UIKit의 `draw(in:)`으로 정상 렌더링

**최종 구조:**
```
detectFace() → Vision(CoreML) 시도 → 실패 시 CIDetector(구형) fallback
```
