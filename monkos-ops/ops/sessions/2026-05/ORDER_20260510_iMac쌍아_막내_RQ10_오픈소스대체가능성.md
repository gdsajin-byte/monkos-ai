## 지시 사항

### 산출물 1: 오픈소스 모델 전 구간 비교 테이블

**4개 구간 × 모델별 상세**. 막내2 조사를 확장하되, 서빙 비용과 실제 운용 시나리오를 추가한다.

#### 구간 분류

| 구간 | 파라미터 | 용도 | 대표 모델 |
|------|---------|------|----------|
| **소형** | 1~4B | USB 포터블, 모바일, 엣지 | EXAONE 3.5 2.4B, Qwen3 4B, Phi-4-mini |
| **중형** | 7~14B | 노트북/데스크톱, 경량 서버 | EXAONE 3.5 7.8B, Qwen3 8B/14B, Gemma 3 12B |
| **대형** | 20~70B | GPU 서버, 셀프호스팅 | Qwen3 32B, Llama 3.3 70B, EXAONE 3.5 32B |
| **특대** | 100B+ / MoE | 클라우드 전용, API 대체 수준 | Qwen3 235B-A22B, DeepSeek-V3, Kimi K2 |

#### 테이블 열 (각 구간 공통)

```markdown
| 모델 | 파라미터 | 양자화 | 파일 크기 | 컨텍스트 | 한국어 품질 | 라이선스 | GGUF | vLLM | 서빙 방식 | 서빙 비용/월 | M1 tok/s | GPU 요구 | 비고 |
```

**서빙 방식별 비용 산출 (MONKOS 트래픽: 월 입력 2.7M + 출력 1.8M 토큰)**:

| 서빙 방식 | 설명 | 비용 산출 방법 |
|----------|------|-------------|
| **로컬** | M1/M4 Mac, llamafile/Ollama | $0 (기존 장비 활용) |
| **Cloudflare Workers AI** | 서버리스 GPU 추론 | Workers AI 가격표 기준 |
| **Together AI** | 서버리스 API (오픈소스 호스팅) | 공식 가격표 $/1M tok |
| **Groq** | LPU 추론, 초고속 | 공식 가격표 |
| **Fireworks AI** | 서버리스 GPU | 공식 가격표 |
| **AWS Bedrock** | 관리형 | 공식 가격표 |
| **GCP Vertex AI (오픈 모델)** | Gemma 등 Google Cloud 네이티브 | Vertex AI Model Garden 가격 |
| **셀프호스팅 (GPU 서버)** | RunPod/Vast.ai/자체 서버 | GPU 시간당 × 가동 시간 |

#### 비교의 핵심 축

각 모델에 대해 아래 질문에 답할 수 있어야 한다:

1. **gemini-3.1-flash-lite(월 $3~14)를 이기는가?** — 비용 OR 품질 OR 둘 다
2. **6채널 프로덕션 서빙이 가능한가?** — 동시 요청, 안정성, SLA
3. **상용 라이선스인가?** — Apache 2.0 / MIT / 기타
4. **MONKOS 인프라(GCP)에 자연스럽게 붙는가?** — Vertex AI Model Garden, Cloud Run GPU 등
