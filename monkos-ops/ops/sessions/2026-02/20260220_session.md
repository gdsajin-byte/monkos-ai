| 항목 | 값 |
|------|-----|

| main 마지막 갱신 | 2/18 (기술명세서 v1.1) |
| 자동빌드 Preview 누적 | 수십 개 |

### 해결: 자동빌드 OFF + 수동 배포 전환

**작가님 결정**: "C안 — 푸시는 허용하되 배포는 수동으로"

이유: 과거에는 에이전트 1명과 직접 작업 → push=배포 합리적.
현재는 수십 에이전트 자동화 → push마다 배포하면 통제 불가.

#### 실행
1. **CF Dashboard → monk-kr → Settings → Branch control**
   - Production: Enable automatic deployments **체크 해제**
   - Preview: **None** 선택 (자동빌드 전면 중단)
   - 결과: "Automatic deployments paused" 확인

2. **Production 수동 배포**
   - `wrangler pages deploy` 실행 → **경로 공백 에러 발생**
   - 프로젝트 경로 `monk_project /` (후행 공백) → wrangler tmp 경로 해석 실패
   - **우회**: `/tmp`에서 심링크 경유 배포
   ```bash
   ln -sfn "/Users/developer/monk_project/MONK_kr" /tmp/monk-kr-deploy
   cd /tmp && npx wrangler pages deploy /tmp/monk-kr-deploy --project-name monk-kr --branch main --commit-dirty=true
   ```
   - Production 배포 성공, monk.kr 반영 확인
