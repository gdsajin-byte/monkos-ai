## 타임라인

### AI 콘텐츠 생태계 현실 인식

**작가님**: "건전하고 진지한 콘텐츠가 클릭 경쟁에서 노출될 수 있는 구조적 방법이 있느냐"

- SNS 피드: CivitAI NSFW 3단계 수준 AI 생성물로 포화
- 클릭 기반 알고리즘 = 선정성이 노출 독점 → 게임의 룰 자체가 문제
- "블로그 열심히 쓰세요, 건전한 콘텐츠로" = 실패성 조언
- 결론: 채널 선택이 아닌 **게임 자체를 다르게 접근**해야 함

### 철창의 한계 인식과 역할 재정의

**작가님 지적:**
- AI 에이전트가 개발에서는 탁월하나 마케팅은 **교과서적 원리만 반복**
- "SEO 하세요, 블로그 쓰세요, 타겟을 좁히세요" = 마케팅 입문서 1장
- 개발 = 결정론적(입력→처리→출력), 마케팅 = 확률론적(같은 입력에 다른 결과)

**전환:**
- 마케팅의 감이 아닌 **데이터 파이프라인**으로 접근 — 에이전트 강점 활용
- "트렌드를 크롤링하고, 어떤 패턴이 먹히는지 분석하고, 벤치마크를 하는 구조"

### @monk_photo 현황 진단 (철창 직접 시각 분석)

- 게시물 40개 / 팔로워 27명 / 팔로잉 60
- 오프라인 실제 촬영물 + 초기 이미지엔 생성물 혼재
- 카테고리 산발적 → 알고리즘이 계정 정체성 분류 불가
- 에이징 자산: 가치 없음 (신규 계정과 차이 미미)
- 결론: 리포지셔닝 vs 신계정 판단 필요

### AI 증명사진의 구조적 마케팅 병목

**작가님 핵심 발언:**
> "카페/배달/음식은 무한한 콘텐츠를 뽑아낼 수 있으나, AI 증명사진은 비포(원본)가 정말 극한으로 어렵다"

- AI 증명사진 소재 = **사람의 얼굴**
- 비포 확보 경로: 유료 고객 제공(닭과 달걀) / 내부 인력(제한적) / AI 생성(가짜 의혹)
- 팔로워 27 → 고객 전무 → 비포 없음 → 콘텐츠 못 만듦 → 성장 정체 **(악순환)**
- **이 병목이 인스타 성장 실패의 근본 원인** — 몽크스만의 문제가 아닌 카테고리 구조적 한계

### 전략 수립: 2개월 테스트 + 자동화 파이프라인

**블로그 실전 검증된 전략 적용:**
> "포스팅 2개월 올려보고 반응 없으면 버리고 다시 시작하라" — 멘토 조언

**이중 파이프라인:**
1. **Pipeline A (벤치마크 크롤링)**: Apify → 경쟁 채널 데이터 수집 → 패턴 분석 → 주간 리포트
2. **Pipeline B (n8n 콘텐츠 자동화)**: 병목 없는 콘텐츠 5유형 설계 → n8n 자동 생산 → 검수 → 포스팅

**콘텐츠 유형 (병목 해소 설계):**
| 유형 | 내용 | 얼굴 소재 병목 |
|------|------|--------------|
| TYPE A | 결과물 쇼케이스 (내부 인력 활용) | 낮음 |
| TYPE B | 스타일 비교 캐러셀 | 낮음 |
| TYPE C | 프로세스 릴스 (앱 사용 과정) | 중간 |
| TYPE D | 정보성 콘텐츠 (규격 가이드 등) | **없음** |
| TYPE E | 시즌 콘텐츠 (취활/여권 시즌) | **없음** |

**멀티 계정:**
