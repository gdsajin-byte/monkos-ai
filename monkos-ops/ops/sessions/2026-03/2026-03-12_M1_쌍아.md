## 핵심 설계 결정

### 1. 크롭앱 = 사용자가 정수리를 정의하는 도구
- 자동 크롭 발급보장 → **사용자 결정 + 도구 제공** 으로 전환
- 발급보장 리스크를 우리가 떠안지 않는 구조
- 사용자 정의 정수리 = human label → 학습 데이터 수집 + 동의 플로우

### 2. 레이어 구조
```
Layer 1: 프레임 (35×45mm 고정)
Layer 2: 사진 (드래그 이동)
Layer 3: 오버레이 (사진에 올라탄 도구 세트)
  ├ 8점 스플라인 타원 (FaceMesh 맞춤형)
  ├ 정수리 핀 (독립 드래그)
  ├ 턱끝 핀 (고정)
  ├ 눈 가이드선
  ├ 십자 가이드
  └ 스케일 핸들 (사진 위)
```

### 3. 타원 = FaceMesh 분석 결과물
- 고정 템플릿이 아닌 **사진별 맞춤형 가이드**
- 7개 입력 포인트: 동공2 + 턱1 + 광대2 + 모퉁이4
- SVG path 8점 스플라인 (단순 ellipse 아님)

### 4. 수치 피드백 (확정값)
| 수치 | 허용범위 | 범위 내 | 범위 밖 |
|------|---------|--------|--------|
| 정수리~턱 | 32~36mm | 초록 | 빨강 |
| 눈 위치 | 40~46% | 초록 | 빨강 |

### 5. 디폴트 배치
- 얼굴 34mm (중앙값), 상단 5mm, 하단 6mm
- 정수리 초기값: 눈↔턱 1:1 대칭 or ppp 계수

### 6. 추가 기능
- 십자 가이드 (프레임 정중앙)
- 미리보기 모드 (가이드 숨김)
- AI 검수 버튼 (비전 AI: 눈썹/귀/이빨/어깨선/정수리 체크)

### 7. 다운로드 플로우
- [필수] 크롭 결과 책임 동의
- [선택] 데이터 활용 동의
- 산출물: 크롭 사진 + 가이드 오버레이 캡처 (항변 근거)

### 8. 기술 스택
- 프론트: **vanilla HTML + JS** (기존 앱 스택 통일)
- 배치: `public/crop.html` + `public/crop.js`
- 엔진: crop-engine (별도 Cloud Run)
- 프론트 = 가이드 UI + 좌표 결정 / 엔진 = 최종 크롭 연산
