## 기술 명세

### 1. 여권 크롭 규격 정합 (KR)

| 항목 | 변경 전 | 변경 후 | 근거 |
|------|---------|---------|------|
| faceRatio | 0.65 | 0.75 | 외교부 규정 머리길이 3.2~3.6cm / 4.5cm = 71~80% |
| topMargin | 0.08 | 0.12 | 정수리~사진상단 여백 확보 |
| 얼굴감지 기준점 | foreheadTop (이마) | headTop (정수리) | 외교부 기준 = 정수리~턱 |

- 파일: `monkos_AI/idphoto-kr/gcs-save.js` SPECS 수정
- 파일: `monkos_AI/idphoto-kr/server.js` FACE_DETECT_PROMPT headTop 변경
- Number() 타입 강제 변환 추가 (Gemini가 문자열 반환 시 대응)

## 서버단 처리 흐름 (현행 아키텍처)

```
[클라이언트] 촬영 → /api/idgen
    ↓
[서버] Gemini I2I 생성 → GCS 저장(원본+생성본) → addWatermark → 워터마크본 반환 (gcsPath 포함)
    ↓
[클라이언트] 결과 표시 → 다운로드 버튼 → /api/download
    ↓
[서버] GCS에서 원본 가져오기 → detectFace(headTop) → cropToSpec(여권규격) → 크레딧 70c 차감 → 크롭본 + Signed URL(원본) 반환
    ↓
[클라이언트] thankyou 화면 — 크롭본 다운로드 + 원본(노크롭) 무료 다운로드
```
