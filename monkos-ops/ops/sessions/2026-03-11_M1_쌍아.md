## 핵심 논의 — 정수리 추산 문제의 본질 (작가님 도출)

### 1. FaceMesh의 태생적 한계
- 478 랜드마크는 AR 필터용 — **얼굴 피부 표면**만 커버
- `#10`은 이마 중간이지 정수리가 아님. 헤어라인·정수리는 감지 범위 밖

### 2. 확실한 좌표는 눈+턱 2점뿐
- 눈(#159/#386), 턱(#152) = 해부학적으로 명확한 특징점
- 이마(#10) = 이마의 "어디"인지 정의 불명 → 모호
- 정수리 = 2D 사진에서 직접 관측 불가
- 헤어탑(segmentation) = 스타일에 따라 가변, 정수리 아님

### 3. 타원 가설 (작가님 제안)
- 공무원도 정수리를 직접 못 봄 → 얼굴 윤곽에서 무의식적 타원을 그려 추정
- 인간은 머리를 팽이형이 아닌 타원형으로 인식하는 관성
- 해부학적 정확이 아닌 **심사관의 시각적 판단을 모사**하는 접근
- 턱+좌우윤곽 3점 → 얼굴형에 자연 적응 (긴/둥근/넓은)

### 4. 실용적 결론
- 규격 허용범위(3.2~3.6cm, 4mm 폭) 자체가 "정확히 못 재는 걸 안다"는 선언
- 독일은 27~40mm (13mm 폭)으로 더 솔직
- **목표: 정수리의 정확한 점이 아니라, 허용 범위 중앙을 안정적으로 찍는 배치**
- 일본 외무성 1:1 = 정밀해서가 아니라 실무 관용 기준

### 5. 작가님 발언 — "논문감"
- 랜드마크 + 헤어탑 실루엣 + 타원 모델 삼각검증으로 정수리 역추산 알고리즘이 정립되면 논문 수준
- 대머리 사진 = ground truth (정수리 실측 가능한 유일 케이스)
