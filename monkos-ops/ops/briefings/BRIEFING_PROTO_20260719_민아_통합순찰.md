## C. 판정 — 무엇을 기획해야 실익인가 (우선순위)

1. **순찰 자동화가 기획 1순위 — 오늘 두 번 증명됨.** ① 오전: L1로는 안 잡히는 P0(200 OK 데드 퍼널)를 L2 실주행이 적발 ② 지금: 순찰 1회가 ads.sh 결함을 즉석 적발. 죽은 퍼널 하루 = GSC 상위 랭킹 트래픽 전량 증발이므로 ROI 자명. **설계 스펙 실측 확정: L1 15URL(1분·curl) 매일 + L2/L3 유색·신규 로테이션 1슬러그(무료 티어, 비용 0) 매일 + 결과 파일 레포 적재 → 웹 민아 브리핑 pull.** 이미 돌아가는 러너 코드가 오늘 확립돼 있어 설계서→데몬화만 남음.
2. **ads.sh CID 수리 (소형, 즉시)** — 검색어 보고서가 막혀 있으면 애즈 제안서의 자산화 파이프라인(B1)·콘텐츠 주제 공급(C1)이 전부 공회전. 클라이언트 계정 ID 분기 1건.
3. **specs→가입 동선 기획 (매출 직결 후보)** — 가입 7명 중 5명이 카메라 퍼널 출신, specs 출신 0~2명. 오늘 살아난 specs 퍼널의 결과 화면(다운로드+10c 이벤트)이 가입 전환기로 작동하는지가 다음 병목. 전환 액션 정의(애즈 제안 D4)와 한 묶음으로 기획해야 측정-개선 루프가 닫힘.
4. **블로그→specs 내부 링크 강화 (콘텐츠 기획)** — 클릭은 블로그가 벌고 전환기는 specs·카메라에 있음. 블로그 본문의 specs CTA 밀도가 실측상 가장 싼 트래픽 이전 수단. 꾸 트랙(kku-blog CTA 공식)과 정합.
5. **GA4 내부 필터 (전제 정리)** — 위 3·4의 측정 신뢰도가 여기 걸림. 순찰 utm 태깅과 한 번에.
