## 안건 생애주기

```
발의 → 어젠다 등록 (AGENDA 파일 생성)
  → 공론·조율
  → 결의
  → 이관 (적정 문서 → 적정 위치) + README 장부에 처리 이력 1줄
```

**이관 목적지**:
- 법률 개정 → `governance/` (PETITION → amendment)
- 전략·기획 확정 → `monkos-ops/contents/` 또는 `marketing/`
- 기술 설계 확정 → `monkos-ops/tech/specs/` 또는 `tech/designs/`
- 운용 규칙 정착 → `CLAUDE.md` 또는 `MEMORY.md` 반영
- 실행 지시 → `monkos-ops/ops/orders/` (지시서 발행)
- 프로젝트 생애주기 → `monkos-ops/ops/projects/` (PROJECT 파일)
- 자연 해소/폐기 → 장부에만 기록

AGENDA 파일 자체는 이관 후에도 이 폴더에 잔류 (논의 경위 아카이브).
