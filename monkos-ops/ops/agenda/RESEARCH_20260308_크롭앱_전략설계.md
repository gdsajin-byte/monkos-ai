# MONKOS 크롭앱 전략 설계서

> **2026-03-05 | 신작가님 구상 → 철창이 정리**
> **상태**: 아이디어 기록. 본체(idphoto-kr) 안정 + JP 클론 완료 후 착수.

---

## 1. 컨셉

증명사진 규격 크롭만 해주는 **완전 무료 앱**. 서버 없음. 클라이언트 디바이스 엔진만으로 동작. 로그인 없음. 광고 없음.

이 앱이 MONKOS 본체의 **전초 기지**(유입)이자 **후방 서비스**(다운로드 후 활용).

---

## 2. 왜 만드는가

시장에 "크롭만 해주고 돈 받는" 앱들이 있다. 사진 규격에 맞춰 잘라주는 것뿐인데 결제를 요구한다. MONKOS는 이걸 무료로 풀어버린다. 서버 비용이 제로이므로 유저가 백만 명이 써도 손해가 없다. 오히려 트래픽이 많을수록 본체로의 유입이 늘어난다.

핵심은 **품질 비교 장치**. 유저가 직접 크롭한 사진이 레퍼런스로 존재하는 상태에서 MONKOS 리터칭 결과물을 보게 된다. "내가 한 것"과 "20년 사진작가가 한 것"의 차이를 유저 스스로 체감하는 구조.

## 3. 앱 스펙

### 3-1. 기술 구조

| 항목 | 사양 |
|------|------|
| 서버 | **없음** — 클라이언트 전용 |
| 엔진 | 디바이스 내 이미지 처리 (Canvas API / WebAssembly) |
| 로그인 | **없음** |
| 과금 | **없음** — 완전 무료 |
| 배포 | 웹앱 (PWA) + 포털 서비스 카드 |
| 서버 비용 | 정적 호스팅만 (CDN) — 사실상 제로 |

### 3-2. 기능

**Tier 1 — 규격 크롭**
- 사진 선택 (카메라 / 갤러리)
- 규격 선택 (여권 3.5×4.5, 반명함 3×4, 비자별 규격 등)
- 얼굴 자동 감지 → 규격에 맞는 크롭 가이드
- 수동 미세 조정 (확대/축소/이동)
- 다운로드 (원본 해상도 유지)
- **다중 규격 크롭** — 한 사진에서 여러 규격 한 번에 추출

**Tier 2 — 누끼 따기 (배경 제거)**
- Transformers.js + RMBG-1.4 모델 (브라우저 내 실행)
- WebGPU 가속 (지원 기기) / WASM 폴백 (범용)
- 모델 최초 1회 다운로드 → 이후 브라우저 캐시 (재다운로드 없음)
- 인물 세그멘테이션 → 투명 배경 PNG 출력

**Tier 3 — 배경 교체**
- 누끼 결과 + Canvas 합성
- 단색 배경 (흰색, 회색, 파랑, 베이지 — 증명사진 규격 대응)
- 그라데이션 배경
- 사용자 커스텀 이미지 배경

세 기능 전부 클라이언트 전용. 서버 호출 제로. API 키 제로.

### 3-3. 기술 스택

| 레이어 | 기술 | 역할 |
|--------|------|------|
| 크롭 엔진 | Canvas API | 규격 크롭, 합성, 출력 |
| 얼굴 감지 | MediaPipe Face Detection (WASM) | 크롭 가이드 자동 위치 |
| 누끼 엔진 | Transformers.js + RMBG-1.4 | 인물 세그멘테이션 |
| GPU 가속 | WebGPU (지원 시) / WASM (폴백) | 누끼 처리 속도 |
| UI | Vanilla JS + PWA | 경량, 설치 가능 |
| 호스팅 | CDN 정적 호스팅 | 서버 비용 사실상 제로 |

### 3-4. 작업 기간

| 일차 | 작업 |
|------|------|
| Day 1 | 코어 엔진 (크롭 + 누끼 + 배경 교체) + 모델 로딩/캐싱 |
| Day 2 | UI + MONKOS 연결 버튼 + PWA 세팅 + 배포 |

Transformers.js가 모델 로딩/추론/폴백을 전부 추상화해주므로, 실질적 개발은 UI와 Canvas 합성 로직.

### 3-5. 경쟁사 대비

| 항목 | 경쟁 크롭앱 | 경쟁 누끼앱 | MONKOS 크롭앱 |
|------|-----------|-----------|-------------|
| 가격 | 유료 | 유료/API 과금 | **완전 무료** |
| 서버 | 있음 | 있음 (서버 AI) | **없음** (디바이스 처리) |
| 프라이버시 | 사진 서버 전송 | 사진 서버 전송 | **디바이스에서만 처리** |
| 크롭 | 기본 | 없음 | **규격 DB + 얼굴 감지 정밀 크롭** |
| 누끼 | 없음 | 있음 | **있음 (Transformers.js)** |
| 배경 교체 | 없음 | 유료 | **무료 (Canvas 합성)** |
| MONKOS 연결 | 없음 | 없음 | **리터칭 무료 체험 버튼** |

## 4. 퍼널 — 전초 기지 역할 (유입)

```
[스토어/포털에서 크롭앱 발견]
  ↓ 무료니까 설치/진입
  ↓
[자기 사진을 규격 크롭]
  ↓ "이 정도면 되겠지" → 저장
  ↓
[앱 하단: "증명사진 무료 체험" 버튼]
  ↓ 무료라니까 탭
  ↓
[MONKOS 본체 → 소셜 로그인 → 10c 증정]
  ↓
[같은 사진으로 AI 리터칭]
  ↓
[프리뷰: 방금 자기가 크롭한 것 vs MONKOS 결과물]
  ↓ 차원이 다름. 배경 정리, 피부 보정, 조명 보정, 의상 정리.
  ↓
[₩9,900 결제 → 다운로드 → 10c 잔여]
```

**전환 트리거**: 유저가 "내가 한 크롭"과 "AI 리터칭"을 직접 비교한 순간. 이 비교가 자발적으로 발생하는 구조. 우리가 "우리가 더 낫다"고 말하는 게 아니라, 유저가 스스로 체감한다.

## 5. 퍼널 — 후방 서비스 역할 (다운로드 후)

```
[MONKOS에서 증명사진 다운로드 완료]
  ↓ 잔고 10c 남음
  ↓
[엔딩 페이지 → "다른 규격이 필요하면?"]
  ↓
[크롭앱으로 이동]
  ↓ 논크롭 원본(풀샷 10c)을 크롭앱에서 로딩
  ↓
[여러 규격으로 무료 크롭]
  ↓ 여권용, 이력서용, 비자용 — 한 장에서 전부 추출
  ↓ 무료. 무제한.
```

**후방 가치**: MONKOS에서 받은 고품질 원본 + 크롭앱의 정밀 규격 크롭 = 유저가 다양한 용도로 활용 가능. "₩9,900에 모든 규격을 다 해결했다"는 만족감. 이게 재방문과 입소문의 엔진.

## 6. 비즈니스 모델

크롭앱 자체는 수익이 제로. **MONKOS 본체로의 유입 채널**이 비즈니스 모델.

| 항목 | 비용 | 수익 |
|------|------|------|
| 크롭앱 운영 | CDN 호스팅만 (월 수천원) | 0 |
| 크롭앱 → MONKOS 전환 | 0 (앱 내 버튼) | ₩9,900 × 전환율 |
| 스토어 유기 트래픽 | 0 (무료 앱 = 높은 설치율) | 브랜드 인지도 |

**핵심**: 경쟁 크롭앱들이 크롭 자체에서 돈을 벌려고 하는데, MONKOS는 크롭을 무료로 풀어서 리터칭 서비스의 유입 채널로 쓴다. 수익은 본체에서 발생.

## 9. 확장 가능성

크롭앱의 규격 DB는 MONKOS 본체와 공유. 새 규격(비자별, 국가별)이 추가되면 크롭앱에도 자동 반영. 크롭앱에서 수집되는 "어떤 규격이 많이 쓰이는가" 데이터는 MONKOS 본체의 규격 우선순위에 반영 가능.

나아가 크롭앱은 증명사진뿐 아니라 프로필 사진, SNS 규격(인스타 1:1, 유튜브 썸네일 16:9 등)으로 확장 가능. MONKOS의 서비스 라인이 확장될 때 크롭앱도 함께 확장.
