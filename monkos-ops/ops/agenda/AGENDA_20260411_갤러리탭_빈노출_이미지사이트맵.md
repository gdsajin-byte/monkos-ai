# 갤러리 탭 빈 노출 + 이미지 사이트맵 누락 연동 어젠다

> **[2026-04-11 19:22 KST] iMac/민아 → (작가님 지시로 어젠다 등록)**
> 작가님 직접 지시: "갤러리 탭이 비어있는 것과도 연동되니 우선 어젠다로 등록할 것"

---

## 1. 배경 (오늘 세션 대화에서 도출된 구조)

MONKOS의 구글 오가닉 노출이 보수적인 근본 원인 중 하나로 **"이미지 검색 경로의 허들"**이 식별됨. 특히 작가님이 짚은 **"어 이 사진이 AI야?"** 경로 — 구글/네이버 이미지 검색에서 우연히 MONKOS 결과를 만나고 호기심이 발동되어 사이트 탭으로 진입하는 경로 — 가 현재 작동하지 않는 것으로 추정.

## 2. 문제의 연동성

### 2-1. 갤러리 탭 (monkos.ai/gallery)

- **빈 상태** (작가님 증언)
- 갤러리가 MONKOS의 **실제 AI 생성 결과물 전시 공간**이어야 함
- 이미지 검색 인덱스에 등록되려면 **공개 페이지에 이미지가 임베드되어 있어야** 함
- 갤러리가 비어 있다면 → 이미지 검색 경로의 **출발점이 없는 상태**

### 2-2. 이미지 사이트맵

- 현재 sitemap.xml에 이미지 사이트맵이 포함되어 있는지 **미확인**
- 일반 sitemap만으로는 구글이 이미지 URL을 별도 인덱스로 가져가지 않음
- `image:image` 태그를 포함한 전용 이미지 사이트맵 제출 필요
- Google Search Console 이미지 검색 인덱스 등록 여부 확인 필요

### 2-3. 두 문제의 연동

```
갤러리 탭 빈 상태
     ↓
이미지 검색 인덱스에 올릴 이미지 자체가 부족
     ↓
이미지 사이트맵이 있어도 실효 없음
     ↓
구글/네이버 이미지 검색 → MONKOS 노출 0
     ↓
"어 이 사진이 AI야?" 호기심 유발 경로 차단
     ↓
광고 외 유입 경로 사실상 부재
```

## 3. 확인·실행 과제

### 3-1. 실측 필요 항목 (민아/쌍아)

- [ ] 현재 `monkos.ai/gallery` 실제 렌더링 상태 (CDP 확인)
- [ ] Firestore `gallery_items` 컬렉션 문서 수
- [ ] sitemap.xml에 이미지 사이트맵(`<image:image>`) 포함 여부
- [ ] GSC 이미지 검색 탭 노출수 (gsc mcp 복구 이후)
- [ ] 블로그 본문 이미지들이 구글 이미지 인덱스에 들어가 있는지 (site:monkos.ai 이미지 검색)

### 3-2. 해결 방향 (쌍아 설계 필요)

- [ ] 갤러리 콘텐츠 시딩 전략 — AI 생성 샘플 N건 어떻게 채울 것인가 (권한/동의/품질)
- [ ] 이미지 사이트맵 생성 — portal/lib/cms/render.js에서 동적 생성 or 정적 파일
- [ ] GSC에 이미지 사이트맵 제출
- [ ] 블로그 본문 이미지의 alt·캡션·주변 텍스트 SEO 강화 (이미 Phase 1에서 일부 처리)

### 3-3. 우선순위

이 어젠다는 **CITADEL의 리드타임을 줄이는 실효적 가속 수단** 중 하나. 도메인 에이지·카테고리 경쟁은 견뎌야 하지만, 이미지 검색 경로는 **작업으로 열 수 있는 문**.
