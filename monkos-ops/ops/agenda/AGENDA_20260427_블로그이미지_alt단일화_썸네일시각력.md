## 2. 작업 범위

### 2-1. alt 차별화 (코드 작업)
- 블로그 템플릿(추정: `monkos.ai/blog/*` 렌더 컴포넌트)에서 이미지마다 고유 alt 부여 로직 추가
- 마크다운 작성 시 이미지별 alt 입력 필드 강제
- 1회 수정으로 vol1~vol30+ 일괄 적용 가능

### 2-2. 썸네일 시각력 (콘텐츠 작업)
- 핵심 페이지(vol29/vol19/vol22/vol23-qa-5/vol30)의 OG 이미지/대표 이미지를 인물 중심으로 재설계
- 표/도형 그래픽 → 얼굴이 보이는 인물 사진 또는 전후 비교

### 2-3. 강제 재크롤
- URL Inspection의 "색인 요청" 수동 트리거 (vol19 26일째 미크롤 등)

## 3. 우선순위 P2 사유 (작가님 판단)

- 현재 자산화는 **롱테일 키워드 1페이지 진입 단계** (vol30 P2, vol29 P2.83 + 첫 클릭). 클릭 누적이 시작되고 있음

- 콘텐츠 시리즈 확장(vol23-qa-5 자매 콘텐츠 등)이 더 큰 단기 효과

→ **자산화 가속 단계에 도달했을 때 한 번에 처리** (이미지 노출 일평균 100+ 안정 시)
