## B. 예외 처리의 4단계 레벨 구조

현행 법체계의 예외 조항들을 분석하면, 다음과 같은 계층 구조가 **암묵적으로** 존재한다:

```
┌─ 레벨 1: 자동 예외 (규칙 내장, 승인 불요)
│  - 헌법 제13조: 긴급 장애(INCIDENT) → 24시간 내 보정
│  - ch4 2조: _archive/ 언더스코어 폴더 허용
│  - ch8 1조: 내부 로그의 기술명 사용 허용
│
├─ 레벨 2: 지시서 기반 예외 (쌍아 권한)
│  - ch7 1조: 마무리 절차 [예외] 명시
│  - ch6 1조: 별도 브랜치 지정
│
├─ 레벨 3: 합의 기반 예외 (작가님+쌍아)
│  - ch5 3조: prod 배포 권한 위임
│  - ch5 4조: 프로덕션 동결 해제
│
└─ 레벨 4: 단독 승인 예외 (작가님)
   - 헌법 제8조: 파괴적 명령 실행
   - 헌법 제10조: 프록시 우회 임시 허용
   - ch2 1조/5조: 기술 스택 변경
```

**핵심 관찰**: 이 계층 구조는 법률 원문에 명시되어 있지 않으며, 조항별로 분산되어 있다.
