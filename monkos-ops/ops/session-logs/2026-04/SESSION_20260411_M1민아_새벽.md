### 네트워크 경계 실체
| 경로 | 정책 |
|------|------|
| bash 셸 (`curl`, `wget`, `ping`) | **차단** — 임의 아웃바운드 격리 (정상 보안 경계) |
| 네이티브 도구 (`WebFetch`, `WebSearch`) | **허용** — 앤스 게이트 경유 |
| MCP 커넥터 (GSC/Gmail/Drive) | **허용** — OAuth 기반 |

- bash curl 차단은 버그가 아니라 **설계**. 임의 셸이 나가면 샌드박스 의미 증발
- 앤스는 "감사 가능한 네이티브 도구로 나가라"는 전제로 /schedule을 전면에 내세운 것
- 쌍아의 오진단 → 설계서(WebFetch 명시)와 PoC 실행(bash curl 사용) 사이의 **추상화 붕괴**
