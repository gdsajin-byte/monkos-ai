## 6. Top 5 추천 + 근거

### 🥇 1위: Flux Kontext Pro (API)

**적합성: ★★★★★**

- **정체성 보존 특화**: 12B 파라미터 멀티모달 트랜스포머. 의상/배경/헤어 변경 시에도 얼굴 ID 완벽 유지
- **멀티턴 편집**: 의상 변경 → 배경 변경 → 헤어 변경을 순차 적용해도 일관성 유지
- **자연어 지시**: "change outfit to navy suit" 등 프롬프트 키워드와 직결
- **비용**: $0.04/image (fal.ai). 볼륨 할인 가능
- **약점**: API 의존 (로컬 불가), 오픈소스 아님

> **우리 서비스 "90% 유지 + 10% 향상" 원칙에 가장 부합하는 모델.**
> 의상 스키마 20종 프롬프트를 Kontext에 직접 투입하는 파이프라인 설계 가능.

---

### 🥈 2위: InstantID + SDXL (오픈소스 파이프라인)

**적합성: ★★★★★**

- **단일 참조 이미지로 ID 보존 최강**: IdentityNet + IP-Adapter 조합
- **비용**: Replicate ~$0.01/image, RunPod ~$0.005
- **유연성**: ControlNet + LoRA 조합으로 스타일 무한 확장
- **약점**: 4060 로컬은 양자화 필요 (품질 하락), 파이프라인 구성 복잡
- **활용**: Flux Kontext의 백업/저가 옵션. 볼륨 처리 시 비용 우위

---

### 🥉 3위: CatVTON (가상 피팅 특화)

**적합성: ★★★★☆**

- **4060 구동 가능 유일한 고품질 VTON**: 899M 파라미터, <8GB VRAM
- **의상 변경 전문**: 의상 레퍼런스 이미지 → 인물에 피팅
- **비용**: 로컬 구동 시 사실상 무료
- **약점**: 의상 변경만 가능 (헤어/배경 별도), 상반신 최적화 필요
- **활용**: 의상 스키마 20종 레퍼런스와 직접 연동. "이 의상을 이 사람에게" 파이프라인

---

### 4위: Imagen 4 Standard (GCP 생태계)

**적합성: ★★★★☆**

- **이미 GCP 인프라 위에 있음**: monkos-studio 배포 환경과 직결
- **I2I 편집 API**: 마스크 기반 편집 + 텍스트 지시
- **해상도**: 네이티브 2048×2048 (프로필 사진 충분)
- **비용**: $0.04/image (Standard), 배치 API 50% 할인으로 $0.02
- **약점**: 정체성 보존이 Flux Kontext 대비 약함. 범용 I2I라 얼굴 특화 아님
- **활용**: Gemini 3 Pro의 자연스러운 업그레이드 경로. 전환 비용 최소

---

### 5위: CodeFormer++ (후처리 필수)

**적합성: ★★★★☆ (필수 보조)**

- **4060 로컬 구동**: <4GB VRAM. 어디에든 추가 가능
- **최고 품질 얼굴 복원**: FID/LPIPS 최고 점수. 이산 표현 + Transformer
- **용도**: 어떤 I2I 모델을 쓰든 최종 단계에서 얼굴 디테일 복원
- **비용**: 로컬 무료
- **약점**: 복원 전용. 스타일 변환/의상 변경 불가

> **메인 모델과 무관하게 파이프라인 마지막 단계에 반드시 배치.**
