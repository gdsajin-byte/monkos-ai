### 크롭 로직 흐름

```
사진 업로드 → Image 객체 생성
  → FaceMesh.send(image) → 478 랜드마크 (normalized 0~1)
  → extractLandmarks() → 10개 핵심 포인트 (이미지 px 좌표)
  → autoPlace() → faceTarget mm에 맞춰 imgScale/imgPos 계산 + 프레임 좌표 변환
  → render() → SVG 오버레이 + 수치 표시
  → 사용자 수동 조정 (정수리 드래그, 사진 이동, 스케일)
  → performCrop() → Canvas에 CSS transform 재현 → JPEG 0.95 품질 다운로드
```

## §2 정수리 인식 로직 상세

### 방식: MediaPipe FaceMesh 기반 **계산** (직접 감지 아님)

**정수리(crown)는 FaceMesh가 직접 감지하지 않는다.** FaceMesh 478 랜드마크에 정수리 포인트는 없음.

크롭앱의 정수리 계산 방식 (crop.js L703-707):

```js
// 정수리: 눈~턱 1:1 반전
const eyeCenterY = (leftPupil.y + rightPupil.y) / 2;
const eyeCenterX = (leftPupil.x + rightPupil.x) / 2;
const crownY = eyeCenterY - (chin.y - eyeCenterY);
const crown = { x: eyeCenterX, y: crownY };
```

**공식**: `정수리Y = 눈중심Y - (턱Y - 눈중심Y)`

즉, **눈~턱 거리를 눈 위로 동일하게 반전**하여 정수리 위치를 추정한다.

### 사용되는 FaceMesh 인덱스 (crop.js L199-206)

| 인덱스 | 용도 |
|--------|------|
| 159 | 좌눈 중심 (LEFT_PUPIL) |
| 386 | 우눈 중심 (RIGHT_PUPIL) |
| 152 | 턱 최하단 (CHIN) |
| 234 | 좌측 윤곽 (LEFT_CHEEK) |
| 454 | 우측 윤곽 (RIGHT_CHEEK) |

### 정확도 평가

- **인체 비율 기반 합리적 추정**: 정면 기준 눈~턱 ≈ 눈~정수리는 대략 맞음 (정확히는 눈~정수리가 약간 더 짧음)
- **한계**: 머리카락 볼륨, 헤어스타일에 따라 실제 정수리 라인과 차이 발생
- **수동 보정 제공**: 정수리 핀(crownPin)을 사용자가 드래그하여 조정 가능 (L605-607)
- **한계 보완**: "↕ 드래그" 힌트 UI로 사용자에게 수동 보정 유도

### SAMPLE_POINTS 폴백

FaceMesh 미로드 / WebGL 미지원 시 하드코딩된 SAMPLE_POINTS(L143-153)로 폴백. 이 경우 자동 배치 없이 고정 위치.

|-------------------|------|--------------------------|------|
| `wMm` | 출력 폭 mm | `size` (파싱 필요: "3.5 × 4.5cm" → 35, 45) | 단위 변환 필요 |

### specs-data.json → SPECS 변환 로직

specs-data.json을 직접 import하려면 파싱 함수 필요:

```
size "3.5 × 4.5cm" → wMm: 35, hMm: 45
pixels "413 × 531px" → pxW: 413, pxH: 531
headHeight "3.2~3.6cm" → faceMin: 32, faceMax: 36
headHeight "34±2mm" → faceMin: 32, faceMax: 36
headHeight "머리 70~80%" → faceMin: hMm*0.7, faceMax: hMm*0.8
headHeight "-" → faceMin: null (ICAO 검증 비활성)
```

또는: specs-data.json에 `cropConfig` 필드를 추가하여 크롭앱 전용 수치(wMm, hMm, pxW, pxH, faceMin, faceMax, faceTarget)를 명시.
