## Firestore 신규 필드

### `users/{userId}`
| 필드 | 타입 | 용도 |
|------|------|------|
| `telegramId` | string | 텔레그램 user ID (getChatMember용) |
| `telegramChatId` | string | 텔레그램 chat ID |
| `telegramUsername` | string | 텔레그램 username |
| `telegramLinkedAt` | string | 연동 시각 |
| `events.telegram_join` | string | 텔레그램 가입 이벤트 수령 시각 |
| `snsConsentSigned` | boolean | SNS 동의서 서명 여부 |
| `snsConsentAt` | string | 동의 시각 |
| `missionImageReceived` | boolean | 미션 이미지 수신 여부 |
| `missionImageFileId` | string | 텔레그램 이미지 file_id |
| `missionImageAt` | string | 이미지 수신 시각 |
| `missionBonusClaimed` | boolean | 100c 미션 보너스 수령 여부 |
| `missionBonusAt` | string | 미션 보너스 수령 시각 |

| 필드 | 타입 | 용도 |
