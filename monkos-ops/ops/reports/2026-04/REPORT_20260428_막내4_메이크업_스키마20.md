## 프롬프트 사용 가이드

각 스타일의 프롬프트 키워드는 Gemini I2I 파이프라인에서 다음과 같이 조합:

```
"Apply {프롬프트 키워드} to this portrait photo while preserving the subject's identity and facial features"
```

강도 조절 시 `subtle/moderate/enhanced` 접두어 추가:
```
"Apply subtle {키워드}..."   → 가벼운 적용
"Apply moderate {키워드}..." → 표준 적용
"Apply enhanced {키워드}..." → 또렷한 적용
```
