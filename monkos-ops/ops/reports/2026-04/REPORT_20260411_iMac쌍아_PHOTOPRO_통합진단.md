# [통합 진단] PHOTOPRO — "500 클릭 0 결제"의 구조 귀속

**[2026-04-11 16:35 KST] iMac/쌍아 → 작가님**

---

## 0. 한 줄 결론

> **구조적 복합 원인. 단일 버튼 수정으로 풀리지 않는다.**
>
> "500 클릭 0 결제"는 (1) **자연검색 0 노출로 유료 단일 채널 의존**, (2) **랜딩이 결과물 프리뷰 없이 6관문 선요구**, (3) **도달한 14명 전원이 첫 generate 1회 후 복귀 0**의 3층이 연쇄로 만든 결과다. 기술 결함·가격·성능은 문제가 아니며, 문제는 **"시장 인식 → 랜딩 → 첫 결과 → 결제"의 전 파이프에 걸친 설계-시장 마찰**이다.

## 1. 3축 교차 매트릭스

| 축 | 담당 | 발견한 결정적 사실 | 교차 확증 |
|---|------|-----------------|---------|
| **정량** | 민아 (Firestore 전수) | 4월 신규 14명 100%가 첫 generate 1회 후 복귀 0 / 결제 0. 기존 charge 71%가 단일 내부 추정 계정 | 막내1의 "첫 관문부터 과중" 근거와 일치 |
| **정성** | 막내1 (CDP 20장) | 기술 결함 0, 관문 9개 중 6개가 결과 전 요구, 업로드 UI 부재 | 민아의 "복귀 0" 원인을 구조적으로 설명 |

**3축 모두가 서로를 증명한다**. 각축의 발견이 다른 두 축의 귀속을 지지하는 방식으로 맞물려 있다. 이는 진단의 강도를 상승시킨다.

1. **500 → 14 구간** (광고 → 가입): GA4 없이 확증 불가. 막내1의 "6관문 선요구" 실측과 막내2의 "유료 단일 채널"이 간접 증거이지만 **직접 수치가 없는 블랙박스**.
2. **`payment_started` 관측 공백**: 결제창 진입 자체를 서버가 기록하지 않음. "결제창 이탈"과 "결제창 미도달"을 구분할 수 없어 광고 ROI 최적화가 구조적으로 어렵다.

## 3. 결정적 원인 — 3층 연쇄

### 🔴 층 1 — 채널 단일 의존 (막내2 축)
- Google 10/10, 네이버 자연 9/10, 네이버 광고 10/10 **전부 미노출·미입찰**
- 간접 노출 1건(제3자 블로그 "한연구원 매거진 vol.21")만 존재
- 결과: **신규 획득이 오직 유료 광고 단일 채널** → 재방문·검색 복귀 0 → 광고 클릭 한 번 사라지면 영영 사라짐
- 경쟁사는 네이버 광고(인핸즈) + SEO 블로그 노출(증명한컷)을 **병행 장악**

### 🔴 층 2 — 랜딩 CTA-기대 불일치 (막내1 축)
- **광고 착지 사용자 기대**: "사진 한 장 넣어보고 결과 확인 → 마음에 들면 결제" (경쟁사 기본 경험)
- **우리 제공 플로우**: 위저드 STEP 1~4(규격·성별·연령) → 로그인 강제 → OAuth → 카메라 권한 → 실시간 셀카 → 생성 → 결제
- **관문 9개 중 6개가 "결과물 한 장 보기 전"**에 요구
- 결정적: **업로드 UI 완전 부재**. 랜딩에서 "실시간 촬영 전용"임을 명시 선언도 없음. 5초 이내 기대 불일치 이탈 유발
- 특히 **모바일 + 실시간 카메라 권한**: 회사·지하철·카페 환경에서 물리적으로 불가능
- 헌법 1조 3항(정체성 보존) + 4조 5항(본인인증·실시간촬영) 원칙의 **의도된 설계**이지만 **시장과의 접점이 설계되지 않음**

### 🔴 층 3 — 결제 결심 근거 부재 (3축 공통)
- 도달한 14명: **100%가 첫 generate 1회 후 복귀 0** (민아)
- 랜딩 카피: 가격(₩9,900), 첫 로그인 10c 보너스 어필만 있음 (막내1·막내2)
- **없는 것**: 환불 보장, 실 생성 수/이용자 수, 공공기관 제출 가능 여부, 사용 후기
- 경쟁사 대비:
  - 인핸즈: "1시간 완성 · 100% 환불 · 2,000명 / 60,000장 · 40% 마감 임박"
  - 증명한컷: "공공기관 제출 가능 · 무료체험 · 100% 환불"
- 우리는 **"처음 본 사람이 지갑을 열 근거"**를 랜딩·결과 페이지 어디에도 제시하지 않음
- 복귀 유인(이메일·알림·세션 재개 유도) **전무**

## 4. 기술 결함 부재 확증

- CORS/CSP 경고 0, 404/500 0
- 성능: TTFB 264ms, FCP 740ms, **LCP 1.6s (Core Web Vitals "Good")**, HTML 36KB
- **Slow 3G도 정상 로드** — 느린 망은 원인이 아님
- 토스 v2 SDK 로드 정상, 결제창 UI 정상
- 데스크탑·모바일 동등 동작

### 유일한 기술 수정 대상 (실존)
- `/prep` 위저드 STEP 3/4 — 막내1 자동화 중 "열기" 버튼이 STEP 1 리셋 유발. **코드 리뷰 필요**

## 5. 교차 결과 — 꾸 "생성 에러" 건

- 막내1: CDP 자동화로 `/api/idgen` **실제 호출 자체가 불가능** (계정+실촬영 필요). 재현 불가
- 쌍아 아침 실측: Cloud Run `monkos-idphoto-kr` /health 정상, 최근 24h 에러 로그 0건, 환경변수 정상
- 민아 아침 진단: `monk-image-engine`의 `/api/upload` 404 12건 → 지시서 작성 후 **self-retract**
- **결론**: 현재 prod 생성 파이프라인 자체에 관측되는 고장은 없음. 꾸가 본 에러는 (a) 특정 시점의 일시 장애, (b) 꾸 환경 고유(쿠키·세션·캐시), (c) 실제 UX 막힘을 사용자가 "에러"로 귀속 중 하나. **실측 재현이 있기 전까지 이 건을 별도 버그로 처리하지 않는다**. 서버 로그 직접 조회 1회로 확정 가능(쌍아 향후 과제).

## 9. 관측 공백 고지

- **GA4/GSC MCP 전부 실패**. 민아 Firestore가 유일한 확증 데이터
- **Google Ads 직접 데이터 미확보**. "500 클릭"은 작가님 구두 수치이며 어느 키워드·어느 랜딩으로 갔는지 모른다

- **꾸 "생성 에러" 실재 여부는 확정되지 않음** (CDP 재현 불가)

이 공백은 본 보고서의 결론을 흔들지 않는다 (3축 교차로 구조 귀속이 견고함). 그러나 **A안 설계 정밀도**는 Ads 데이터가 확보되면 향상된다.
