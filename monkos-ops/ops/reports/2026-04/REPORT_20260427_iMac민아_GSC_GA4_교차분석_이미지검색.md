→ Organic Search 1.9% — GSC 클릭 16 vs GA4 organic 45는 **격차 정상** (GSC는 노출/클릭 임계 필터링, GA4는 referrer 기반 풀카운트).

### 2-2. **이미지 노출 → 트래픽 전환 현황** 🔴

| 페이지 | 이미지 노출(GSC) | 웹 노출(GSC) | GA4 랜딩 세션 |
|--------|----------------|-------------|-------------|
| /blog/vol29 | 198 | 18 | **2** |
| /blog/vol19 | 149 | 56 | **2** |
| /blog/vol21 | 78 | 15 | 1 |
| /blog/vol22 | 62 | 10 | — (랜딩 0) |
| /blog/jumin-online-reissue | 52 | 7 | — |

→ **이미지 노출 폭증해도 클릭 0 = 트래픽 0**. 평균 포지션 50대로 너무 깊어 사용자 시야 밖.
→ 자산은 인덱스됐고 노출은 시작됐으나, 1페이지 진입 전까지는 트래픽화 안 됨.

### 2-3. 랜딩 페이지 압도적 1위는 `/` (홈)

- `/` 2,230 세션 (전체의 95%) ← **광고 랜딩이 거의 다 홈으로 묶임**
- 블로그/specs 등 콘텐츠 페이지의 GA4 랜딩은 1~10 세션 수준
- → 광고는 홈으로, 콘텐츠는 SEO로 — 두 경로가 완전 분리. 콘텐츠 자산이 트래픽으로 이어지는 구조 미작동

### 2-4. 지역 — GA4 vs GSC web

| 지역 | GA4 세션 | GA4 비중 | GSC web 노출 비중 |
|------|---------|---------|-----------------|
| KOR | 1,936 | 82% | 28% |
| JPN | 289 | 12% | 7% |
| USA | 49 | 2% | 9% |

→ GA4는 광고 타겟 지역(KOR/JPN) 중심, GSC는 영문권 노출도 분산 — **광고와 오가닉의 청중이 다름**.

### 2-5. 디바이스 — 모바일 압도

| | GA4 세션 | 비중 |
|---|---------|------|
| Mobile | 2,058 | 87% |
| Desktop | 246 | 10% |
| Tablet | 41 | 2% |

→ GSC web에서는 desktop 노출 비중 83%지만 GA4 실제 트래픽은 모바일 87%. **노출은 데스크톱에서 받고, 클릭/방문은 모바일이 한다** = GSC 디바이스 분석에서도 동일 결론(모바일 CTR이 데스크톱의 3.7배) 재확인.
