## 6. 쌍아 최종 액션 제안 (Rev 2)

### [P0 — 이번 주·반나절 안에 가능]

1. **Lemon Squeezy 스토어 설정 재확인 + 변경** (자동번역 OFF 상태로 재실측 먼저):
   - 스토어 브랜드명 "MONKOS AI KR" 확인 (LS 관리자 콘솔에서 Store Name 확인)
   - KR 접미사 실재 시: "MONKOS AI" 또는 "MONKOS AI Japan" 중립형으로 변경
   - Paidy 활성화 설정 (지역별 결제수단 설정)
   - 상품명 "MONKOS 70 Credits" → 일본어 `証明写真 80クレジット(1枚分)` 등 현지화
   - **막내 지시서 1건이면 완료 가능한 범위**

2. **PayPal locale 파라미터 버그 수정**:
   - 현재: `locale.country=KR&locale.lang=ko` (JP 페이지에서도)
   - 기대: JP 페이지에서 `locale.country=JP&locale.lang=ja`
   - LS 스토어 지역 설정 또는 결제 요청 측 코드 점검 필요
   - **1~2줄 수정 범위 가능성**

3. **JP 결제수단 라인업 보강**:
   - Lemon Squeezy: Apple Pay/Google Pay(자동), Paidy(활성화 필요) 순으로 우선 처리
   - 장기: PayPay/LINE Pay/콘비니 통합 플랜 검토 (LS 플랜 업그레이드 or 별도 PG)

4. **자동번역 OFF 재실측** (오늘 20:00 이전):
   - JP 사이트 원본 텍스트가 어떤 일본어 품질인지 재확인
   - Lemon Squeezy 체크아웃 원본 언어/브랜드 재확인
   - 재실측 없이는 Rev 2도 잠정 결론에 가까움

### [P1 — 다음 주]

4. **신규 크레딧 보너스 재설계**:
   - 현: 10c 무료 → 리터칭만 가능
   - 안 A: 신규 80c 무료 (1장 완전 체험, 단 워터마크 삽입)
   - 안 B: 1회 무료 생성+다운로드, 이후는 전부 유료
   - **증명한컷 대응 카피**: "무료로 1장 + 100% 공공기관 통과 보증"

5. **결제 Two-touch → One-touch**:
   - 카드 클릭 즉시 결제 뷰로 전환
   - 또는 카드에 "결제하기" 버튼을 바로 포함
   - **1~2줄 JS 수정으로 가능할 영역**

6. **광고 랜딩 URL 매핑 감사**:
   - Google Ads 콘솔 > 광고 메뉴 > 각 광고의 "최종 URL" 열람
   - 본 REPORT §3 가설 검증

### [P2 — 2주 이내]

7. **KR 충전 페이지 "소액 10c" 제거** 또는 "리터칭 추가권" 으로 라벨 변경
8. **credits-policy.html 에 "신규 가입 10c" 조항 명시** (정책 문서 정합성)
9. **결제 완료 후 체류 유도**: 다음 1장 할인 쿠폰 / 친구 초대 포인트 등 2차 결제 설계
