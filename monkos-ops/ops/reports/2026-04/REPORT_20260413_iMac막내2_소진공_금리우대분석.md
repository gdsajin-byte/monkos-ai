## § 3. 금리우대 5유형 — 몽크사진관 해당 여부

> 공고 원문 (p.5~6 §우대금리 표)

| 유형 | 조건 | 우대폭 | 몽크사진관 해당 | 확인 방법 |
|------|------|-------|-------------|---------|
| **정책우대** | 소진공* 또는 은행권** 컨설팅 이수, 제로페이 가맹점, 디지털 온누리상품권 가맹점 | △0.1%p | ❓ **작가님 확인** | 소진공 역량강화 컨설팅 3년 이내 이수 이력 / 제로페이 가맹 상태 / 온누리상품권 가맹 상태 |
| **정책배려** | 여성기업, 장애인기업, 일회용품 사용규제 적응 우수기업 | △0.1%p | ❌ | 해당 없음 |
| **사회안전망** | 자영업자 고용보험, 전통시장 화재공제, 풍수해보험, 노란우산공제 | △0.1%p | ❓ **작가님 확인** | 4종 중 1개 이상 가입 증빙 |
| **성실상환** | 소진공 직접대출 성실상환 소상공인 (최근 3년 내 10일 이상 연체 0건, 원금분할상환 중 또는 완제) | **△0.3%p** | ✅ **확정** | 2021-2026.01 5년간 연체 0건 완제 — 공단 직접 확인 (별도 서류 제출 불요) |
| **지역 격차해소** | 비수도권 소상공인 (수도권 내 인구감소지역: 경기도 가평군·연천군 / 인천 강화군·옹진군 포함) | △0.2%p | ❌ | 경기도 하남시는 수도권 + 인구감소지역 非 해당 |

> **중복 규칙**: 동일 유형 내 중복 적용 불가. 서로 다른 유형 간은 합산 가능 (최대 0.8%p 한도).
> **성실상환 판단**: 개인기업은 대표자 주민번호 기준 × 대출계좌별. 사고기업·자율상환제·손실보상선지급 제외.

## § 4. 작가님 확인 필요 2항목 — 체크리스트

### 4-1. 정책우대 (△0.1%p) 확인 질문

- [ ] 소진공 **역량강화 컨설팅**을 2023-04-13 이후 이수한 이력이 있는가?
  * 대상: 소상공인시장진흥공단이 직접 실시한 무료 컨설팅
  * 소진공 공단 직접 확인 → 별도 서류 불요
- [ ] 은행권 컨설팅 이수 확인서 보유 여부
  * 신청일 기준 3년 전 연도부터 당해연도 컨설팅 3시간 이상 수료 이력
  * 은행권 이수 시 **수료 확인서 제출 필요** (증빙서류 ➊ 정책우대)
- [ ] 제로페이 가맹점인가? (모바일 QR 결제)
- [ ] 디지털 온누리상품권(카드형·모바일형) 가맹점인가?

> 위 4개 중 1개라도 해당 → 정책우대 △0.1%p 적용 가능

### 4-2. 사회안전망 (△0.1%p) 확인 질문

- [ ] **자영업자 고용보험** 가입 중인가? (대표자 본인 가입)
- [ ] 전통시장 화재공제 가입? (해당 없음 — 하남 미사는 전통시장 아님)
- [ ] 풍수해보험 가입?
- [ ] **노란우산공제** 가입 중인가? (중기중앙회)

> 위 4개 중 1개라도 해당 → 사회안전망 △0.1%p 적용 가능. 가입 확인서 1부 제출 필요.

## § 5. 가점 사항 (공고 p.21 §금리우대·기업평가 추가제출 자료)

> 가점은 우대금리와 별개. **기업평가 점수 상승 → 대출 승인 확률·한도 상향**에 기여.

| 가점 사항 | 증빙 | 몽크사진관 해당 | 비고 |
|---------|------|-------------|------|
| **수출 실적** | 수출실적증명원 (한국무역통계진흥원, 무역협회, 시중은행, KTNET) | ❓ **작가님 확인** | 일본 KOMOJU 결제 발생 시 → 시중은행 발행 수출실적증명원 가능. 단, 최근 1년 내 **1천 달러 이상** 필요 (혁신형 자격 요건). 현재 2026.03 일본 서비스 론칭 → 3월 매출 기준 1천 달러 초과 여부 확인 |
| **고용 증가** | 최근 1개월 이내 상시근로자수 확인 서류 (월별원천징수이행상황신고서, 건강보험 등) | ✅ **확정** | 배재인 사원 **2026.02 신규 채용** → 근로자수 증가 입증 가능. 기업평가 가점 |
| **기술혁신 (KOITA)** | KOITA 연구개발전담부서 인정서 사본 | ✅ **확정** | 2026.02 취득 보유 |

> ⚠️ 혁신형 자격 트랙별 우선순위: 몽크사진관은 **❻ 직접대출 성실상환 소상공인** 트랙으로 신청. ➊ 수출 트랙은 자격 중복 시 **복수 증빙**으로 강화 (단일 유형 내 중복 우대 불가이나, **자격 근거 강화**와 **기업평가 가점**에 기여).

## § 7. 제출 시 서류 관점 정리

| 금리우대 | 제출 필요 여부 | 증빙 방법 |
|---------|-----------|---------|
| 성실상환 | **제출 불요** | 공단 직접 확인 (대표자 주민번호 기준) |
| 지역 격차해소 | **제출 불요** | 공단 직접 확인 (사업자등록증 주소) → 하남시 해당 없음 |

| 정책우대 (은행권 컨설팅) | **이수 확인서 제출** | 해당 은행에서 발급 |
| 정책우대 (제로페이·온누리) | **가맹 확인서 제출** | 해당 운영기관 |
