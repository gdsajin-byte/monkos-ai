## 2. Google 이미지 검색 직접 시각 검증

### 2-1. 검색어: "일본 취업 증명사진"

> 스크린샷: `assets/2026-04-27/google_image_japan_idphoto.png`

**발견 위치**:
- 3행 1열 / 3행 4열 / 4행 우측 끝 — 우리 MONKOS AI 이미지 3건 노출 확인
- 평균 게재순위 P53과 일치 (행당 6장 × 약 9행 = 54번째 즈음)

**썸네일 비교**:
| 우리 이미지 | 경쟁 이미지 |
|-----------|-----------|
| 검정 배경 + "MONKOS AI" 로고 + 텍스트 그래픽 | 인물 사진(LIME STUDIO 등) |
| 비교 표 / 가이드 일러스트 | 한일 비교 인물 사진 |
| 시각적 임팩트 약함 | 얼굴/표정 직관적 |

→ 클릭 욕구 차이 명확

### 2-2. 검색어: "증명사진 배경색 추천"

> 스크린샷: `assets/2026-04-27/google_image_bgcolor.png`

**발견 위치**:
- 2행 4열: "Monkos AI Studio" — 표 형태
- 3행 1열: 컬러 팔레트 무지개색 일러스트
- 3행 2열: 회색 배경 점 3개 미니멀 그래픽 (vol30 추정)

→ **노출 OK, 클릭 의욕 X**. 옆 결과는 인물 사진 + 배경색 비교(시각적 직관)인데 우리는 표·도형

### 2-3. CDP DOM 추출 — alt 텍스트 정밀 확인

```
"한연구원 매거진vol.29] 일본 취활 증명사진, 이것만큼은 꼭 지켜야 해요 — 규정 완전 정리 | MONKOS AI" × 5
"한연구원 매거진 vol.23] 일본 취준생이 가장 많이 묻는 증명사진 Q&A 5가지 | MONKOS AI"
```

**핵심 진단**:
- **6장의 이미지가 모두 같은 alt 텍스트** = **이미지별 차별화 alt 부재**
- alt가 **페이지 제목 그대로** = "한연구원 매거진vol.29]" 같은 내부 시리즈명이 alt 자리 차지
- 이미지가 무엇을 보여주는지(인물? 비교? 가이드?) **alt에 없음** → Google이 시각 컨텍스트 파악 불가
- 검색 키워드 매칭은 페이지 제목 의존 → 이미지 SEO가 본질적으로 작동 안 함
