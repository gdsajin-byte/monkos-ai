## 2. 실사 품질 평가

### SadTalker 256px
- **자연스러움**: 머리 끄덕임, 미세 표정 변화 있음. 말하는 사람처럼 보임
- **입모양**: 3DMM 기반이라 정밀도 중간. 한국어 모음 구분이 다소 뭉개짐
- **화질**: 256px로 인해 얼굴 디테일 손실 심각. 실서비스 부적합
- **아이덴티티**: 원본과 유사하나 3DMM 매핑 과정에서 미세 변형 있음
- **종합**: 자연스럽지만 해상도가 치명적

### SadTalker 512px + GFPGAN
- **자연스러움**: 256과 동일한 머리·표정 움직임 유지
- **입모양**: 256과 동일 (3DMM 출력은 같고 후처리만 다름)
- **화질**: GFPGAN이 2048까지 업스케일. 피부 질감·눈동자 선명도 대폭 향상
- **아이덴티티**: GFPGAN 후처리로 얼굴이 "예뻐짐" — **원본과 다른 사람으로 변형되는 위험**. 피부가 지나치게 매끄럽고, 이목구비 비율이 미세하게 달라짐. 헌법 1조 3항(정체성 보존 최우선) 관점에서 주의 필요
- **속도**: 0.91fps — 6.4초 영상 생성에 ~7초 렌더링 + GFPGAN 후처리 추가. 가장 느림
- **종합**: 화질은 최고이나 정체성 보존 위험 + 속도 저하

### MuseTalk V15
- **자연스러움**: **입만 움직임**. 머리 정면 고정, 눈 깜빡임 없음, 표정 변화 없음. "말하는 사진"처럼 보여 어색함이 큼
- **입모양**: Latent diffusion으로 입 영역을 프레임마다 생성. 립싱크 정밀도는 3종 중 가장 높음
- **화질**: 512 네이티브, 선명. 입 영역과 주변부 경계가 대체로 자연스러움
- **아이덴티티**: 입 이외 영역은 원본 그대로 → 정체성 보존 최상
- **종합**: 입 품질은 최고이나 단독 사용 시 부자연스러움이 치명적

### LivePortrait
- **자연스러움**: 표정 모방이 매우 자연스러움. 미소, 눈 움직임, 고개 기울임 모두 재현
- **입모양**: 드라이빙 영상의 입 움직임을 모방 — 오디오 기반이 아니라 립싱크 불가
- **화질**: 1024 네이티브. 4종 중 최고 해상도
- **아이덴티티**: 원본 아이덴티티 보존 우수 (emotion-aware 아키텍처)
- **한계**: 오디오 입력 불가 → TTS 나레이터 파이프라인에 단독 사용 불가. 드라이빙 영상을 별도로 준비해야 함
- **종합**: 자연스러움 최고이나 Audio-driven이 아니라 용도 불일치

## 3. 막내1 리서치 보고서 vs 실사 괴리

| 막내1 보고서 평가 | 실사 확인 결과 | 괴리 |
|---|---|---|
| MuseTalk ★★★★★ 최상 (FID/CSIM 1위) | 입만 움직여 어색. 단독 사용 부적합 | **과대평가** — 벤치마크는 입 영역 생성 품질만 측정 |
| SadTalker ★★★☆☆ 안정적이나 입술 부정확 | 자연스러움은 4종 중 최고 (Audio-driven 한정) | **과소평가** — 자연스러움을 평가 항목에서 누락 |
| "MuseTalk 실시간 30fps+" | 4060에서 2.72fps (V100 기준 수치를 그대로 인용) | **환경 미반영** |
| "256px 얼굴 영역" → 리스크로만 표기 | 영상 전체가 입만 움직이는 근본 한계 | **핵심 한계 축소** |

**교훈**: 논문 벤치마크 순위를 그대로 추천 순위로 전환하면 안 됨. 실사용 평가 항목(자연스러움, 정체성 보존, 환경 적합성)을 별도로 잡아야 함.

## 4. PT 나레이터 영상 용도 — 실사 기반 추천

### 즉시 활용 가능: SadTalker (512+후처리 주의)
- 사진+오디오 → 자연스러운 나레이터 영상 자동 생성
- 256px 기본 출력 → 후처리 업스케일 필요하나, GFPGAN은 정체성 변형 위험
- **대안 후처리**: GFPGAN 대신 정체성 보존 우선 업스케일러 탐색 필요 (Real-ESRGAN 등 비얼굴 특화 모델)

### 검증 필요: EchoMimic (Ant Group)
- 막내1 리서치 3위. Audio-driven + 랜드마크 편집 → 표정 미세 제어 가능
- 4060 8GB 가속 모드 실구동 미검증
- V2는 반신 지원 (CVPR 2025) — 나레이터 영상에 적합할 가능성

### 조합 파이프라인 (중장기)
- TTS → SadTalker/EchoMimic(립싱크) + LivePortrait(자연스러운 모션) 조합
- 복잡도 높음 — 개별 모델 검증 완료 후 검토
