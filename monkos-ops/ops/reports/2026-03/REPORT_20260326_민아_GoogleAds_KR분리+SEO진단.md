## 2. SEO 진단 — "여권사진 규격" 키워드

### 핵심 발견
**Google Search Console 3개월 데이터: "여권사진" 포함 검색어 → 노출 0, 클릭 0**

콘텐츠(블로그, FAQ, 크롭앱)가 존재하고 색인도 되어 있으나, 구글이 "여권사진 규격" 검색 의도에 monkos.ai를 후보로 올리지 않고 있음.

### 구글 SERP 현황 ("여권사진 규격" 검색)
| 순위 | 사이트 | 유형 |
|------|--------|------|
| AI 개요 | 구글 자체 요약 | - |
| 1 | passport.go.kr | 정부 |
| 2 | mofa.go.kr | 정부 |
| 3 | 용인시청 | 지자체 |
| 4 | passport.go.kr (하위 페이지) | 정부 |
| 5~ | 네이버 블로그, 수영구청 | 지자체/블로그 |

민간 서비스는 1페이지에 거의 없음 → 기회 영역.

### 원인 분석
1. **타이틀/H1 키워드 불일치** — 블로그 제목이 브랜드 중심, "여권사진 규격"이 타이틀에 직접 안 들어감
2. **검색 의도 매칭 전용 페이지 부재** — 규격 정보가 여러 페이지에 분산
3. **도메인 나이** — monkos.ai가 아직 젊어 정부/지자체 대비 도메인 권위 부족
4. **내부 링크 클러스터 미구축** — 블로그/FAQ/크롭앱이 토픽 허브로 연결 안 됨

## 3. 대응 방안

### Phase A — 즉시 실행 (내일)
- 기존 블로그/FAQ 타이틀·메타 디스크립션 최적화
  - 예: "여권사진 규격 3.5×4.5cm 완벽 가이드 | 무료 크롭앱 MONKOS"
- FAQ 페이지에 FAQPage JSON-LD 스키마 추가
- llms.txt에 증명사진 규격 정보 보강

### Phase B — 포털 규격 허브 페이지 신설 (3~5일)
- `/specs/passport-photo-kr` 등 국가별·용도별 규격 전용 페이지
- 국가 분기 구조 (KR 여권, KR 반명함, JP 여권, 미국 비자 등)
- FAQPage + HowTo JSON-LD 트리플 스택
- 하단 CTA → AI 증명사진 서비스 + 크롭앱
- 기존 블로그와 내부 링크 클러스터 구축 (허브-스포크 구조)

### Phase C — 외부 플랫폼 백링크 강화 (병행)
- note.com, 네이버 블로그 등에서 규격 관련 콘텐츠 → monkos.ai 링크
- Google 비즈니스 프로필 포스트 발행
- 기존 다플랫폼 전략(한/민아 콘텐츠 패키지)과 연동

### 일정 감안
- 일본 취활 피크 4~5월 → Phase B를 4월 초까지 완료 목표
- KR은 상시 수요이므로 빠를수록 유리
