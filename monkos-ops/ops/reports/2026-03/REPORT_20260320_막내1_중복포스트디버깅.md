## 2. 중복 원인 분석

**근본 원인**: 네이버 크롤러(`naver.js`)와 note.com 크롤러(`note.js`)의 `isDuplicate()` 함수가 `sourceUrl` 필드로만 중복 체크.

- note.com에서 먼저 이관된 일본어 포스트 → `sourceUrl`이 `note.com/...` 형식
- 동일 포스트가 네이버 블로그에도 게시됨 → `sourceUrl`이 `blog.naver.com/...` 형식
- `isDuplicate(sourceUrl)` 통과 → `generateSlug(title)` 동일 slug 생성 → `ensureUniqueSlug()`가 timestamp suffix 붙여서 **새 문서 생성**
- 결과: `monkosai` (naver)와 `手のひらの写真館-monkosai-の使い方をご紹介します` (note)가 동일 내용의 중복

**홈 오염 원인**: `home.js`에서 `displayPosts`에 thumbnail/번역본 필터가 없어서 빈 카드가 상위 노출.

### 수정 파일

#### `lib/cms/importer/naver.js`
- `isDuplicate(sourceUrl)` → `isDuplicate(sourceUrl, title, slug)` 3중 체크
  - sourceUrl 일치 → 중복
  - title 정규화 비교 (공백/특수문자 제거) → 중복
  - slug 문서 존재 → 중복
- `ensureUniqueSlug()` 제거 — 중복 시 생성 자체를 스킵
- `normalizeTitle()` 헬퍼 추가

#### `lib/cms/importer/note.js`
- naver.js와 동일한 3중 `isDuplicate()` 패턴 적용
- `ensureUniqueSlug()` 제거

#### `lib/cms/home.js`
- `displayPosts` 생성 후 2개 필터 추가:
  - `.filter(p => !p.autoTranslated)` — 홈에는 원본만 표시
  - `.filter(p => p.thumbnail && p.thumbnail.length > 0)` — thumbnail 없는 문서 제외

#### `lib/cms/render.js`
- `blogListFragment()` 내 `originalSlug` 기반 중복 제거 추가
  - 같은 `originalSlug`(또는 자기 slug)의 첫 번째 포스트만 표시
  - 언어 필터와 함께 동작하여 해당 언어 포스트만 남김
