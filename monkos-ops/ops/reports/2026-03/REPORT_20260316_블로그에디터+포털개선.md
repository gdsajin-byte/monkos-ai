## 수정 상세

### 수정 1: 메타 정보 접기
- Title 상시 노출, 나머지 메타 필드를 `.meta-panel` 접기 패널로 묶음
- 기본 상태: 접힘 (편집 모드) / 펼침 (신규 글)
- 토글 버튼: "설정 펼치기 ▼" / "설정 접기 ▲"

### 수정 2: Slug 안내 문구
- 라벨: `Slug (auto-generated)` → `URL 주소`
- placeholder: `제목에서 자동 생성됩니다 (수정 가능)`
- 안내문: `블로그 주소에 사용됩니다. 특수문자($ / 등)는 사용할 수 없습니다.`

### 수정 3: Slug 세니타이징
- `sanitizeSlug()` 함수 신규 생성 — `/ $ # [ ] .` 문자 제거
- `handleBlogCreate`에서 slug 저장 전 세니타이징 적용 + 빈 slug 방어
- `extractSlug()`에서도 세니타이징 적용 (URL 경유 방어)
- 프론트엔드: slug input `oninput` 이벤트로 실시간 특수문자 제거

### 수정 4: 썸네일 업로드 버튼
- Thumbnail URL input 옆에 "업로드" 버튼 + hidden file input 추가
- 클릭 → 파일 선택 → `/api/admin/upload` POST → 반환 URL 자동 세팅
- 업로드 중 "업로드 중..." 표시 + disabled

### 수정 5: 내 글 목록 드롭다운
- nav 영역에 "내 글 목록 ▾" 버튼 추가
- 클릭 시 `/api/admin/blog` 호출, 최근 10건 표시 (Draft/Published 뱃지)
- 클릭 시 `?slug=` 파라미터로 이동
- "전체 목록 →" 링크로 blog-list.html 연결
- 외부 클릭 시 자동 닫힘

### 수정 6: 폰트 통일
- 적용 대상: portal.css, blog-edit.html, blog-list.html, render.js, index.html
- `font-family: 'Pretendard', 'Noto Sans JP', -apple-system, sans-serif`
- Pretendard CDN: `cdn.jsdelivr.net/gh/orioncactus/pretendard`
- index.html: Noto Sans KR → Noto Sans JP (일본어 폴백)

### 수정 7: 에디터 크기 확대
- Toast UI Editor `height: '450px'` → `height: '70vh'`
- `.container { max-width: 1000px }` → `max-width: 1200px`

### 수정 8: 홈 레이아웃 매니저
- `/admin/layout.html` 신규 생성 — 테이블 UI (섹션명 / 표시 토글 / 순서 ↑↓ / 사이즈 S/M/L)
- `home.js`에 `handleLayoutGet`, `handleLayoutPut` API 핸들러 추가
- Firestore `site_config/layout` 문서에 sections 배열 저장
- `server.js`에 `GET/PUT /api/admin/layout` 라우트 추가
- 초기 섹션: hero, beforeAfter, magazine, blog, guide, credit, tags

## 특이사항

- 수정 8(레이아웃 매니저)은 현재 설정 저장/조회 기능까지 구현. `renderHome()`에서 config를 읽어 실제 렌더링 순서에 반영하는 로직은 점진적 적용 대상으로 남겨둠 (기존 홈 렌더링에 영향 없음)
- Pretendard CDN은 variable font로 로드하여 파일 크기 최소화 (woff2 ~300KB)
- 헌법 3조 2항 준수 — 어드민 페이지에 내부 호칭 없음
- 헌법 5조 1항 준수 — 기존 에디터 저장/발행 플로우 전혀 변경 없음
