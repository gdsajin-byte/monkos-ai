## 6. 핵심 진단

### 반복되는 패턴

**기획은 쌓이고 있는데 실행 투입이 안 되고 있다.**

- 코웍이 3/15 hreflang 지적 → 10일 후 민아 3/25 동일 문제 재발견
- 코웍이 3/17 CITADEL 기획 → 8일 후 Phase 1 단 1건도 미실행
- 코웍이 3/24 긴급 시정 3건 → 쌍아 검증까지만 완료, 막내 미투입
- 철창이 3/19 noindex 권고 → 6일 후 민아 3/25 동일 권고

### 병목

1. **기획→실행 전환 부재**: 기획서/지시서는 발행되지만 막내 투입이 안 됨
2. **코드 수정 인력 집중**: 막내가 다른 작업(블록 에디터, 긴급 장애 등)에 묶임
3. **SEO는 "긴급"으로 느끼기 어려움**: 기능 장애와 달리 눈에 안 보여서 계속 밀림

### 실측 데이터가 말하는 것

- **72개 비색인** = 매일 3개국어 블로그를 쌓아도 ja/en은 구글에 안 잡힘
- **151명 → 3명 전환** = 메인 페이지에서 92% 이탈
- **일본 +122%** = 유일하게 실질 성장 중인 시장인데, 검색에서 안 잡힘
