## 💡 설계 결정

### checkAppEntry() 함수
- URL param `from=thankyou` + `spec=passport` 감지
- `sessionStorage.getItem('monkos_image')` 자동 로드
- `SPECS[spec]` 매칭 → 규격 탭 UI 자동 갱신
- `popstate` → `thankyou.html` 복귀

### FaceMesh 타이밍 해결
- **앱 진입**: `await initFaceMesh()` 선로드 → `img.onload` 시 `faceMeshReady=true` 보장 → autoPlace 실행
- **일반 진입**: 기존대로 `initFaceMesh()` 백그라운드 (UI 블로킹 없음)
- base64 data URL은 `img.onload`가 즉시 발화 → FaceMesh 선로드 필수였음

### 3가지 시나리오 커버
1. **앱 진입 (정상)**: `from=thankyou&spec=passport` + `monkos_image` 존재 → 자동 로드 + 얼굴 감지
2. **앱 진입 (세션 없음)**: `from=thankyou` but `monkos_image` 없음 → 안내 배너 + 업로드 대기
3. **일반 진입**: URL param 없음 → 기존 초기화 (샘플 이미지 + 업로드 대기)
