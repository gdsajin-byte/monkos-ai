# v5 촬영준비 스키마 → 프롬프트 스택 과정 검증 테이블

> **[2026-03-03 05:59 KST] M1/막내1 → M1/쌍아**
> 용도: 철창이 검증용. prep.js 사용자 입력이 buildPromptV5()를 거쳐 최종 프롬프트로 변환되는 전 과정.

---

## 0. 프롬프트 구조 (고정 프레임)

모든 v5 프롬프트는 아래 골격을 따른다. `buildPromptV5()` (server.js:318-387) 출력.

```
IDENTITY RULE: 90% SAME PERSON + 10% ENHANCEMENT

PRESERVE (90%):
- Face shape, eye shape, nose, lips, skin tone
- Overall facial structure and unique characteristics
- The person must be clearly recognizable as the SAME individual

ENHANCE (10% creative freedom):
- Slightly smoother skin, subtle beauty enhancement
- Optimal lighting and flattering angles
- Minor imperfections can be softened
- Make them look their BEST version (not a different person)

DO NOT:
- Change gender, ethnicity, or age by more than 2-3 years
- Alter fundamental facial features
- Make them unrecognizable

GOAL: "This is ME, but on my best day" - perfectly front-facing, studio flat lighting, 90% accuracy, 10% professional retouching.

[IMAGE-TO-IMAGE TRANSFORM]
[FORMAT] ...        ← 항상 출력
[SUBJECT] ...       ← 항상 출력
[OUTFIT] ...        ← 항상 출력
[HAIR] ...          ← 조건부 (teen/adult + default 아닌 경우만)
[BACKGROUND] ...    ← 항상 출력
[CONSTRAINT] ...    ← 항상 출력 (고정문)
```

## 1. [FORMAT] — 규격 선택 (prep.js STEP 1)

| 사용자 선택 (UI) | store.format | 서버 프롬프트 출력 |
|---|---|---|
| 여권/신분증 | `passport` | `[FORMAT] Official passport/visa photo. Head centered, face taking 70-80% of frame height. Forehead and eyebrows must be visible. Neutral composed expression. White background mandatory.` |
| 증명사진 | `id` | `[FORMAT] Professional ID photo. Head centered, face taking 70-80% of frame height. Approachable yet professional expression.` |

**분기 조건**: `format === 'passport'` 여부로 단순 분기. 예외 없음.

---

## 2. [SUBJECT] — 성별 × 연령 (prep.js STEP 2)

8개 조합, 1:1 매핑. fallback: 매핑 실패 시 `This person is an adult.`

| store.gender | store.age | UI 표시 | 서버 프롬프트 출력 |
|---|---|---|---|
| `f` | `baby` | 여성 · 영유아 | `[SUBJECT] This person is a baby girl (infant/toddler).` |
| `f` | `child` | 여성 · 어린이 | `[SUBJECT] This person is a young girl (child, under 12).` |
| `f` | `teen` | 여성 · 중고생 | `[SUBJECT] This person is a teenage girl (13-18).` |
| `f` | `adult` | 여성 · 성인 | `[SUBJECT] This person is an adult woman.` |
| `m` | `baby` | 남성 · 영유아 | `[SUBJECT] This person is a baby boy (infant/toddler).` |
| `m` | `child` | 남성 · 어린이 | `[SUBJECT] This person is a young boy (child, under 12).` |
| `m` | `teen` | 남성 · 중고생 | `[SUBJECT] This person is a teenage boy (13-18).` |
| `m` | `adult` | 남성 · 성인 | `[SUBJECT] This person is an adult man.` |

**연령 변경 시 사이드이펙트** (prep.js:191-199):
- clothing → `default` 초기화
- clothingColor, suitColor, shirtColor, tieColor, tiePattern → 전부 클리어
- hair → `default` 초기화

## 3. [OUTFIT] — 의상 (prep.js STEP 3 아코디언)

### 3-1. 연령별 허용 옵션 (config.js CLOTHING_BY_AGE)

| store.age | UI 표시 | 허용 clothing 값 |
|---|---|---|
| `baby` | 영유아 | `default`, `change` |
| `child` | 어린이 | `default`, `change` |
| `teen` | 중고생 | `default`, `casual`, `suit` |
| `adult` | 성인 | `default`, `casual`, `suit` |

### 3-2. clothing별 프롬프트 분기

| store.clothing | UI 표시 | 필요 서브필드 | 서버 프롬프트 출력 |
|---|---|---|---|
| `default` | 그대로 | 없음 | `[OUTFIT] Keep current clothing as-is. Only ensure it looks neat and tidy.` |
| `change` | 의상변경 | `clothingColor` | `[OUTFIT] Dress this child in a clean {clothingColor\|white} top, age-appropriate and neat.` |
| `casual` | 캐주얼 | `clothingColor` | `[OUTFIT] Dress this person in a {clothingColor\|beige} smart casual top, clean and neat.` |
| `suit` | 정장 | `suitColor`, `shirtColor`, `tieColor`, `tiePattern` | 아래 3-3 상세 참조 |

> `{값\|기본값}` = 값이 없으면 기본값 적용

### 3-3. suit 프롬프트 조합 상세

**프롬프트 템플릿:**
```
[OUTFIT] Dress this person in a {suitColor} formal business suit with a {shirtColor} {top}{tieClause}.
```

| 서브필드 | 기본값 | 허용값 | 프롬프트 반영 |
|---|---|---|---|
| `suitColor` | `navy` | navy, brown, gray, black | 그대로 삽입 |
| `shirtColor` | `white` | white, lightblue, lightpink, lightbeige | 그대로 삽입 |
| `top` (성별 분기) | — | `f` → `blouse` / `m` → `dress shirt` | gender에 의해 자동 결정 |
| `tieColor` | `navy` (UI 초기) | notie, navy, wine, black | notie → tieClause 생략 |
| `tiePattern` | `solid` | solid, stripe | solid → `solid` / stripe → `striped` |

**tieClause 조건:**
- `tieColor === 'notie'` 또는 미설정 → **tieClause 없음** (프롬프트에서 생략)
- 그 외 → ` and a {pattern} {tieColor} tie` 추가

**suit 선택 시 UI 초기값** (prep.js:440-445):
```
suitColor: 'navy', shirtColor: 'white', tieColor: 'navy', tiePattern: 'solid'
```

### 3-4. clothingColor 연령별 팔레트 (change/casual 공용)

| 연령 그룹 | 팔레트 (config.js V5_OPTIONS.clothingColor) |
|---|---|
| baby, child | `skyblue`, `pink`, `lemon`, `green` |
| teen, adult | `beige`, `blue`, `wine`, `green` |

## 4. [HAIR] — 헤어 (조건부 섹션)

**UI 표시 조건**: `HAIR_VISIBLE_AGES = ['teen', 'adult']`
→ baby/child는 아코디언 자체가 미표시. store.hair = `default` 유지.

**프롬프트 출력 조건**: `hair`가 존재하고 `default`가 아닐 때만 출력.

| store.hair | UI 표시 | 프롬프트 출력 | 비고 |
|---|---|---|---|
| `default` | 그대로 | **(출력 안 함 — [HAIR] 섹션 자체 생략)** | baby/child는 여기 고정 |
| `tidy` | 깔끔 정리 | `[HAIR] neatly groomed and tidy hair` | teen/adult만 선택 가능 |
| `updo` | 올림머리 | `[HAIR] hair styled up neatly (updo)` | teen/adult만 선택 가능 |

## 5. [BACKGROUND] — 배경

**passport 강제 조건**: 이중 체크
1. prep.js (STEP 3 진입 시 + nextPage 시): `store.bgColor = PASSPORT_FORCED_BG` (`white`)
2. server.js: `format === 'passport'` → `finalBg = 'white'` (클라이언트 값 무시)

| store.bgColor | UI 표시 | 프롬프트 출력 | 선택 가능 조건 |
|---|---|---|---|
| `white` | 흰색 | `[BACKGROUND] pure white (#FFFFFF) background` | 항상 (passport 강제) |
| `gray` | 회색 | `[BACKGROUND] neutral gray (#9CA3AF) studio background` | format=id만 |
| `blue` | 파랑 | `[BACKGROUND] soft blue (#4A90D9) studio background` | format=id만 |
| `beige` | 베이지 | `[BACKGROUND] warm beige (#D4B896) studio background` | format=id만 |

> passport 선택 시 배경 아코디언은 `opacity:0.5; pointer-events:none` 처리 (잠금)
