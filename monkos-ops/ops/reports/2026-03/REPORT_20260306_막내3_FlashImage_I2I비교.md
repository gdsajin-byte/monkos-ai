## 4. 부수 발견 사항

### MIME type 미스매치 (기존 코드)

`server.js:604`:
```js
res.json({ image: `data:image/png;base64,${imagePart.inlineData.data}` });
```

현행 Pro 모델은 **JPEG**을 반환하는데, 코드에서 `image/png`으로 하드코딩. 브라우저가 MIME 무시하고 바이너리로 판별하여 정상 동작 중이나, 기술적으로는 미스매치 상태.

**권장**: `imagePart.inlineData.mimeType`을 동적으로 사용하도록 수정.

```js
const mime = imagePart.inlineData.mimeType || 'image/png';
res.json({ image: `data:${mime};base64,${imagePart.inlineData.data}` });
```
