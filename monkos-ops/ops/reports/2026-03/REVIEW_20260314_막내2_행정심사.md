```
sessions/2026-03/2026-03-09/

  ├── M1_막내1.md         ← M1에서 기록
```

| 충돌 시나리오 | 가능성 | 해소 |
|------------|--------|------|
| 같은 디바이스+같은 에이전트가 동시 실행 | **불가** | 물리적으로 1디바이스 1에이전트 |
| 다른 디바이스가 같은 파일에 기록 | **불가** | 파일명에 디바이스 포함 → 유니크 |
| 다른 디바이스가 같은 폴더에 push | **발생 가능** | 다른 파일이므로 **Git 자동 머지 가능**. pull 선행 필수 (현행과 동일) |
| 일간 폴더 미생성 상태에서 동시 생성 | **발생 가능** | mkdir은 멱등. 이미 존재하면 무시. 충돌 없음 |

**결론**: 멀티 디바이스 동시 기록은 파일명 유니크성(디바이스+에이전트)에 의해 충돌 원천 차단. Git push 시 pull 선행만 준수하면 안전.
