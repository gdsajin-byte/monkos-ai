## 5. 가격-만족도 매트릭스

```
만족도 ↑
  80% ┤ ★사진관           ★스마트폰앱
      │  (2,000~30,000엔)    (30~200엔)
  70% ┤
      │
  63% ┤           ★스피드사진기
      │            (700~1,000엔)
  60% ┤
      └──────────────────────────────→ 가격 ↑
         30엔   200엔  700엔  2,000엔  10,000엔+
```

**구조적 역전 발생**:
- 스마트폰앱 = **최저가(30~200엔) + 고만족(77.5%)** → 가성비 최강
- 스피드사진기 = **중간가(700~1,000엔) + 최저만족(62.8%)** → 가성비 최악
- 사진관 = **고가(2,000엔~) + 최고만족(80.3%)** → 프리미엄 확보

## 6. 시장 구조 변화 트렌드

### 스마트폰 앱이 스피드사진기를 잠식하는 구도

| 요인 | 스피드사진기 → 앱 이동 동인 |
|------|--------------------------|
| **비용** | 700엔 → 30~200엔 (70~96% 절감) |
| **재촬영** | 유료 재시도 → 무제한 무료 |
| **미피 보정** | 제한적 자동 → AI 기반 세밀 보정 |
| **편의성** | 설치 장소 이동 필요 → 자택 촬영 |
| **데이터** | 일부 기종만 → 항상 디지털 데이터 |

### 사진관은 프리미엄으로 방어

| 요인 | 사진관 존속 동인 |
|------|----------------|
| **취활 시장** | 인생 좌우 → 프로 촬영 투자 심리 (취활팩 5,000~10,000엔) |
| **프로 메이크업** | 앱으로 대체 불가 (물리적 HM) |
| **촬영 지도** | 표정·각도 코칭 |
| **신뢰** | 규격 보증 (여권·비자 반려 방지) |

## 7. MONKOS 포지셔닝 관점

| 경쟁 채널 | 가격 | 만족도 | MONKOS 우위 가능 영역 |
|----------|------|--------|---------------------|
| 스피드사진기 | 700~1,000엔 | 62.8% | AI 보정 품질 + 가격 파괴 |
| 편의점 앱 | 30~200엔 | 77.5% | **증명사진 규격 자동화** + 품질 차별화 |
| 사진관 | 2,000~30,000엔 | 80.3% | 가격 1/10 이하로 근접 품질 |

**일본 시장 진입 시 포지션**:
- 스피드사진기의 **만족도 갭**(57% 이용 vs 62.8% 만족)을 공략
- 편의점 앱 가격대(200엔 이하)에서 **사진관급 품질**을 제공
- 특히 **여성 불만층**(스피드사진기 불만 26.1%)이 1차 타깃
