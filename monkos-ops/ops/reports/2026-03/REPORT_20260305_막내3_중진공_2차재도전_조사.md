## 1. 기술보증기금 (KIBO) — ⭐ 최우선 권고

### 왜 기보인가

AI 기반 서비스 기업에 **가장 적합한 보증기관**이다. 기술력 중심 평가이므로 MONKOS의 AI 기술(Gemini Live 코칭, Imagen I2I)이 직접적 가점이 된다.

### 1-1. 기술보증 개요

| 항목 | 내용 |
|------|------|
| **성격** | 보증서 발급 → 금융기관에서 대출 (기보가 보증인) |
| **대상** | 신기술사업을 영위하는 중소기업 (상시종업원 1,000명 이하, 총자산 1,000억 이하) |
| **기본 보증한도** | 최고 **30억원** |
| **보증비율** | 85~100% (창업기업·청년대표 우대) |
| **보증료율** | **0.5~3.0%** (기술등급·신용도에 따라 차등) |
| **접수** | **연중 상시** (디지털지점 온라인 또는 영업점 방문) |
| **심사 기간** | 약 2~4주 (기술평가 포함 시 1개월+) |
| **문의** | 기술보증기금 디지털지점 (kibo.or.kr) / 1544-1120 |

### 1-2. 기술사업평가등급별 보증한도

| 등급 | 보증한도 |
|------|---------|
| AAA, AA | 70억원 |
| A | 60억원 |
| BBB | 50억원 |
| BB | 40억원 |
| **B** | **30억원** |
| 미평가 | 20억원 |
| CCC, CC, C | 10억원 |
| D | 5억원 |

> 초기 AI 스타트업은 보통 **B~BBB 등급** → 30~50억 한도 가능성. 실제 초기 기업은 **1~3억원** 수준에서 시작하는 경우가 많다.

### 1-3. 신청 절차

```
1. 디지털지점(kibo.or.kr/dbranch) 회원가입
   ↓
2. 온라인 보증 신청 + 기업정보 입력
   ↓
3. 담당자 배정 → 상담 → 서류 제출
   ↓
4. 기술평가 (기술성·시장성·사업성 종합평가)
   ↓
5. 보증심사 → 보증서 발급
   ↓
6. 보증서를 금융기관(은행)에 제출 → 대출 실행
```

## F. MONKOS 전용 기보 로드맵 — 실행 순서

```
[즉시] 지방세 6.2만원 납부
  ↓
[1주차] 기보 디지털지점 가입 → 일반보증 신청 (1~3억 목표)
  ↓   ⤷ 기술사업평가 동시 진행 (SW모형, 33만원)
  ↓   ⤷ 벤처확인평가 동시 신청 (혁신성장유형, 45만원)
  ↓
[2~4주] 기술평가 결과 → 보증서 발급 → 은행 대출 실행
  ↓   ⤷ 벤처기업 확인서 발급 → 세제 혜택 즉시 적용
  ↓
[1~2개월] SW저작권 등록 완료 → IP담보보증 추가 검토
  ↓
[3~6개월] 이노비즈 인증 검토 (설립 3년↑ 충족 시)
  ↓
[중장기] 기보벤처캠프 / 보증연계투자 / 아기유니콘 단계적 추진
```

### 초기 비용 예상

| 항목 | 비용 |
|------|------|
| 기술사업평가료 | 33만원 |
| 벤처확인평가료 | 45만원 (정부지원 10만원 포함) |
| 지방세 납부 | 6.2만원 |
| **합계** | **약 84만원** |

→ 보증서 발급 → 은행 대출 1~3억 + 벤처인증 혜택(소득세 50% 감면 5년) = **투자 대비 수익 극대**
