# 종합 분석: 일본 증명사진 시장 — Google Ads 키워드 기반

> **[2026-03-09 07:12 KST] M1/쌍아 → 작가님**
> 막내1/2/3 보고서 3건 종합. 철창이+작가님 Google Ads 세팅 중 발견한 키워드 트렌드 대응.

## 1. 핵심 발견: "기계를 검색하지만, 기계에 불만인 시장"

Google Ads 상위 키워드가 `証明写真機`, `コンビニ 証明写真`, `証明写真 安い` 등 **기계·편의점 중심**으로 배치되는 이유가 데이터로 확인됨:

| 지표 | 수치 | 의미 |
|------|------|------|
| 스피드사진기 이용률 | **57%** (1위) | 아직 시장 중심축 |
| 스피드사진기 만족도 | **62.8%** (최저) | 쓰지만 불만. 특히 여성 26.1% 불만 |
| 스마트폰앱 이용률 | **39.7%** (급성장) | 이미 4할이 앱으로 이동 |
| 스마트폰앱 만족도 | **77.5%** | 기계보다 15%p 높음 |
| 사진관 만족도 | **80.3%** (최고) | 프리미엄은 건재 |

**구조적 역전이 진행 중**: 기계(57% 이용, 62.8% 만족) → 앱(39.7% 이용, 77.5% 만족). 기계를 검색하는 유저의 상당수가 "더 나은 대안"을 원하고 있다.

## 5. 전략 제안: 3단계 편의점 공략

### Phase A: L판 레이아웃 (즉시 — 프론트엔드 변경만)

**이것 하나로 시장 최저가 포지셔닝 가능.**

```
현재: 촬영 → AI보정 → 단일 사진 DL → (끝)
Phase A: 촬영 → AI보정 → L판 레이아웃 합성(4~6장) → DL → 편의점 ¥30~40 출력
```

| 수치 | 내용 |
|------|------|
| 구현 범위 | 89×127mm(1,051×1,500px@300dpi) 캔버스에 자동 배치 |
| 결과 가격 | **1매당 ¥5~10** (L판 ¥30~40 / 6매) |
| 경쟁 비교 | 피쿠챤 ¥200, 기계 ¥700, 사진관 ¥2,000 |
| 차별화 | FreeDPE(30엔)는 AI 보정 없음 → **MONKOS만 AI보정+최저가 동시 달성** |

### Phase B: 편의점 가이드 UI + 사이즈 확장

- 다운로드 후 "コンビニで印刷する方法" 화면 (세븐/로손·패마 분기)
- 면허(3.0×2.4cm), 마이넘버(4.5×3.5cm), 국가자격(6.0×4.0cm) 추가
- 각 사이즈별 L판 배치 매수 자동 계산

### Phase C: API 연동 → 원스톱 UX

- 시샤프 ネットワークプリント Web API 연동 (존재 확인됨)
- 앱 내 QR 발급 → 편의점 즉시 출력
- 피쿠챤과 동일한 UX에 AI 보정 품질 추가

## 7. 핵심 결론

1. **시장은 기계→앱 전환기**. 57%가 기계를 쓰지만 만족도 62.8%(최저). 앱 이용 39.7%에 만족도 77.5%. 역전 진행 중.

2. **경쟁자 공백 존재**: 피쿠챤(900만)은 AI보정 없음, AI증명사진앱은 편의점 연동 없음. **AI보정 + 편의점 최저가를 동시에 달성하는 서비스가 일본에 아직 없음.**

3. **Phase A(L판 레이아웃)만으로 즉시 전환 가능**: 프론트엔드 캔버스 합성 1건 추가. 구현 후 편의점 L판 ¥30~40 출력 대응 → 1매당 ¥5~10.

4. **Google Ads 키워드는 의도가 명확**: "지금 당장 증명사진 필요" → 전환율 높은 키워드. "기계보다 싸고 예쁘다"가 킬 메시지.

5. **여성 불만층이 1차 타깃**: 스피드사진기 여성 불만률 26.1%. "사진관급 품질을 앱 가격에" — 이 층이 가장 먼저 전환할 가능성.
