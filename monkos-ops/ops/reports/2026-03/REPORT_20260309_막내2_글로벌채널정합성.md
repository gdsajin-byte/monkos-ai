## 수정 제안

### 우선순위 1 (높음): JP/글로벌 가격표 업데이트

**파일**: `portal/lib/prompts.js` SYSTEM_PROMPT 내 가격 섹션 (line 35 부근)

**현행**:
```
Global (Lemon Squeezy): 10c/$10 | 30c/$25 | 50c/$40
```

**제안**:
```
日本 (Lemon Squeezy): ¥150/10c | ¥990/80c(70+10) | ¥1,490/130c(100+30) | ¥3,990/420c(300+120)⭐推奨 | ¥5,990/750c(500+250)
```

### 우선순위 2 (중간): kakao 채널 프롬프트 전환

**파일**: `portal/lib/chat-engine.js` line 176

**현행**:
```javascript
systemPrompt: SYSTEM_PROMPT + '\n\n[중요] 이 채널은 카카오톡입니다...'
```

**제안**: `SYSTEM_PROMPT_KR`로 전환. 한국 전용 정보(카카오 보너스 40c, KR 법적 페이지, KR 가격) 자동 반영.


### 우선순위 3 (중간): 로그인 수단 안내 추가

**파일**: `portal/lib/prompts.js`

- SYSTEM_PROMPT에 추가: `ログイン方法: LINE(日本)、カカオ(韓国)、Googleアカウント(共通)`
- SYSTEM_PROMPT_KR에 추가: `로그인 방법: 카카오(한국), LINE(일본), Google 계정(공통)`

### 우선순위 4 (낮음): JP 법적 페이지 URL 명시

**현행**: SYSTEM_PROMPT에서 법적 페이지는 `monkos.ai/terms.html` 등 포털 URL만 안내
