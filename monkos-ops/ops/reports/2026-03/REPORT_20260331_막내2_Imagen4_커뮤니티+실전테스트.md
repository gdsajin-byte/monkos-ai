## 2. fast/ultra 실 호출 테스트

### 테스트 조건

```
프롬프트: "professional headshot portrait of a young Korean woman, studio lighting, white background, photography style"
```

### 결과

| 모델 | HTTP | 응답시간 | 파일크기 | 출력 스타일 | 소견 |
|------|------|---------|---------|-----------|------|
| `fast` (allow_all) | 200 | 5.1s | 909KB | **사진** | 깨끗한 스튜디오 사진. 매우 매끈한 피부 — AI 특유의 과보정 느낌. 캐주얼 화이트 탑 |
| `ultra` (allow_all) | 200 | 10.8s | 1.2MB | **사진** | 비즈니스 정장 차림. fast보다 높은 디테일. 역시 매끈한 피부이나 좀 더 자연스러움 |
| `ultra` (allow_adult) | 200 | 12.7s | 1.0MB | **사진** | allow_all과 거의 동일한 품질. 검은 블레이저, 자연스러운 표정 |

### 시각적 소견

**fast 모델**:
- 사진 출력 (일러스트 아님)
- 피부가 극도로 매끈 — 모공·질감이 거의 없음
- "AI가 만든 사진"임이 즉시 인지됨
- 커뮤니티 보고의 "smooth AI look"과 일치

**ultra 모델**:
- 사진 출력 (일러스트 아님)
- fast보다 디테일이 풍부하나, 여전히 AI 특유의 과광택
- 테스트 시점에서는 일러스트/그림체 출력 **재현 불가**
- 작가님이 보고한 "일러스트 변질"은 **프롬프트 의존적**일 가능성

**일러스트 변질 미재현에 대한 분석**:
- 단순 인물 프롬프트에서는 사진 출력 확인
- K-뷰티/스튜디오 관련 복잡한 프롬프트에서 발생했을 가능성
- `enhancePrompt` 기본값(true 추정)이 복잡 프롬프트를 변형하여 스타일 편향 유발 가능
- 특정 키워드 조합이 모델의 "아트" 모드를 트리거했을 수 있음

## 3. personGeneration 파라미터 비교

### `allow_all` vs `allow_adult` (ultra 모델)

| 항목 | allow_all | allow_adult |
|------|----------|-------------|
| HTTP | 200 | 200 |
| 출력 스타일 | 사진 | 사진 |
| 품질 차이 | — | **차이 없음** |
| 인물 표현 | 성인 여성 | 성인 여성 |
| 파일크기 | 1.2MB | 1.0MB |
| 소견 | 동일 프롬프트 기준 품질 차이 미미 | |

**판정**: 성인 인물 프롬프트 기준, `allow_all`과 `allow_adult`의 실질적 차이 없음. `allow_all`은 미성년자 포함 허용, `allow_adult`는 성인만 — 성인 프롬프트에서는 동일하게 동작.

가능한 원인 시나리오:

| 순위 | 원인 | 근거 |

| **2순위** | **Imagen 4 자체의 스타일 편향** | 커뮤니티에서 지속 보고되는 "카투니쉬/일러스트" 출력 경향. 특정 프롬프트 조합에서 발현 |
| **3순위** | **Google 서버 측 미공지 업데이트** | 모델 가중치 미세 조정이 공지 없이 적용되었을 가능성 (확인 불가) |
