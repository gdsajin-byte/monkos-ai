# MONKOS Crop App — 기술명세 v1

> **[2026-03-12] iMac/쌍아 작성**
> 파일 위치: `monkos_AI/idphoto-kr/public/crop.html` + `crop.js` + `crop.css`

---

## 1. 개요

ICAO 규격 증명사진 크롭 도구. 브라우저 단독 실행 (서버 의존 없음).
사진 업로드 → FaceMesh 자동 랜드마크 감지 → 규격 자동 배치 → 사용자 미세 조정 → Canvas 크롭 다운로드.

### 핵심 차별점
- **FaceMesh 브라우저 실행**: MediaPipe WASM/WebGL, 서버 왕복 없이 478점 랜드마크 추출
- **반자동 워크플로**: AI 자동 배치 + 사용자 최종 확정 (정수리 핀 드래그)
- **실시간 규격 피드백**: 3단계 색상 체계 + mm 단위 정밀 수치
- **좌우 중심 가이드**: 세로 중심선 색상 반응 + 이탈 경고

## 4. FaceMesh 브라우저 연동

### 4-1. 초기화
- `@mediapipe/face_mesh` CDN 로드 (첫 실행 ~5MB, 이후 캐시)
- `maxNumFaces: 1`, `refineLandmarks: true` (478점 모드)
- WebGL 미지원 브라우저: SAMPLE_POINTS 폴백

### 4-2. 핵심 랜드마크 인덱스

| 포인트 | FaceMesh 인덱스 | 용도 |
|--------|----------------|------|
| leftPupil | #159 | 좌눈 중심 |
| rightPupil | #386 | 우눈 중심 |
| chin | #152 | 턱 최하단 |
| leftCheek | #234 | 좌측 윤곽 |
| rightCheek | #454 | 우측 윤곽 |

### 4-3. 정수리 추산
```
crownY = eyeCenterY - (chinY - eyeCenterY)   // 눈~턱 1:1 반전
```
디폴트 추산값. 사용자가 정수리 핀 드래그로 최종 확정.

### 4-4. 모퉁이 4점 보간
FaceMesh에서 직접 대응하지 않는 tlCorner/trCorner/blCorner/brCorner는 광대~정수리/턱 보간으로 산출.

### 4-5. 좌표 변환 체인
```
FaceMesh (0~1 정규화) → 이미지 픽셀 → cover 좌표 → 프레임 좌표
```

---

## 5. 자동 배치 (autoPlace)

사진 업로드 후 FaceMesh 랜드마크 기반 자동 배치:

1. **imgScale**: 얼굴 높이가 `faceTarget`mm에 맞도록 산출
2. **imgPos.y**: 눈이 프레임 상단 43%에 오도록 산출
3. **imgPos.x**: 얼굴 중심이 프레임 좌우 중앙에 오도록 산출
4. **pts**: 모든 랜드마크를 프레임 좌표로 변환

### cover 좌표 변환
```
coverScale = max(FW / natW, FH / natH)
toCover(pt) = { x: pt.x * coverScale - offsetX, y: pt.y * coverScale - offsetY }
```

### 프레임 좌표 공식
```
frame_x = FW/2 + (cover_x - FW/2) * imgScale + imgPos.x
frame_y = FH/2 + (cover_y - FH/2) * imgScale + imgPos.y
```

---

## 6. 드래그 시스템

### 6-1. 사진 이동 (img)
- imgPos += delta
- 모든 pts += delta (1:1 동기)

### 6-2. 정수리 핀 (crown)
- crown.y만 변경 (수직 이동)
- 턱~정수리 최소 간격 20px 보장

### 6-3. 스케일 핸들 (scale)
- 대각선 드래그 거리로 imgScale 산출
- **스케일 피벗 = 사진 시각 중심** `(FW/2 + imgPos.x, FH/2 + imgPos.y)`
- 모든 pts를 피벗 기준으로 비례 변환 → 턱/눈이 얼굴에 고정

## 7. 3단계 색상 판정

### 얼굴 크기 (여권 기준)

| 구간 | 색상 | 의미 |
|------|------|------|
| 33~35mm | 녹색 `#00B894` | 최적 |
| 32~33mm, 35~36mm | 노랑 `#FDCB6E` | 허용 (경계) |
| <32mm, >36mm | 레드 `#E17055` | 범위 이탈 |

### 눈 위치

| 구간 | 색상 | 의미 |
|------|------|------|
| 43~45% | 녹색 | 최적 |
| 40~43%, 45~48% | 노랑 | 허용 |
| <40%, >48% | 레드 | 범위 이탈 |

### 좌우 중심

| 구간 | 중심선 색상 | 경고 |
|------|------------|------|
| <1mm | 녹색 | 없음 |
| 1~2mm | 노랑 | 1.5mm부터 경고 텍스트 |
| >2mm | 레드 | 경고 + 방향 안내 |

### 다운로드 차단
레드(범위 완전 이탈) 시 다운로드 버튼 비활성화 + 구체적 사유 텍스트 제시.

## 8. Canvas 크롭 다운로드

### 출력 사양
- 여권: 413×531px JPEG (300dpi)
- 반명함: 354×472px JPEG (300dpi)
- 품질: 95%

### 렌더링 파이프라인
```
Canvas(spec.pxW × spec.pxH)
  → scale(outScale)                              // 프레임→출력 해상도
  → translate(FW/2 + imgPos.x, FH/2 + imgPos.y)  // CSS transform 재현
  → scale(imgScale)
  → translate(-FW/2, -FH/2)
  → drawImage(cover 배치)                         // object-fit:cover 재현
```

CSS `translate(calc(-50% + X), calc(-50% + Y)) scale(S)` 과 동일한 변환 체인.
프레임에 보이는 그대로가 크롭 결과물.

## 9. SVG 오버레이 구조

| 요소 | 역할 |
|------|------|
| maskTop/maskBottom | 정수리 위/턱 아래 반투명 마스크 |
| crossH/crossV | 십자 가이드 (수직선은 중심 이탈도 반응) |
| ellipsePath | 8점 스플라인 타원 (cp=0.55 cubic bezier) |
| crownLine/chinLine | 정수리/턱 수평 가이드선 |
| eyeLine | 눈 높이 가이드선 |
| dimLineV/TopH/BotH | 우측 치수선 |
| pupilL/pupilR | 동공 포인트 마커 |
| crownLabel/chinLabel/eyeLabel | SVG 텍스트 라벨 |
