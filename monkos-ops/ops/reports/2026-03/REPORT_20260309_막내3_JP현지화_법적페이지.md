## ⚠️ 법적 검토 필요 사항

### 1. JP 패키지 가격 미확정 (우선순위: 높음)
- KR은 4개 패키지(₩9,900~₩49,900)가 확정되어 credits-policy에 표시
- JP는 엔화 패키지 가격이 미확정 → credits-policy에서 "각 상품의 가격은チャージページに表示" 으로 대체
- **필요 조치**: JP 크레딧 패키지 가격 확정 후 credits-policy.html에 price-grid 추가

### 2. 資金決済法 届出 관련 (우선순위: 중간)
- 현재 표기: "自家型前払式支払手段に該当, 適正に管理・運用"
- 미사용 잔고 1,000만엔 미만 시 届出 면제 (資金決済法 第5条)
- **필요 조치**: 사업 성장에 따라 잔고 1,000만엔 도달 시 届出 의무 발생 → 정기 모니터링 필요

### 3. 電話番号 表示 방식 (우선순위: 낮음)
- 特定商取引法上 전화번호 표시 의무 있으나, "請求があった場合に遅滞なく開示" 방식도 인정
- 현재 tokusho에 이 방식 채택
- **필요 조치**: 향후 일본 소비자 민원이 발생할 경우 전화번호 직접 표시 전환 검토

### 4. 返品特約 7日 기간의 적정성 (우선순위: 낮음)
- 特定商取引法 通信販売은 클링오프 비적용, 返品特約이 없으면 8일 이내 반품 가능
- 현재 7日로 설정 (KR과 동일) → 법적으로는 返品特約으로 유효
- 8日 이상으로 설정하면 소비자 보호 관점에서 더 유리하나, 현행 7日도 적법

### 5. APPI 제3자 제공 동의 방식 (우선순위: 낮음)
- 현재 프라이버시 정책에 제3자 제공 목록을 공시
- APPI는 원칙적으로 제3자 제공 시 본인 동의 필요
- LINE/Google 로그인 시 동의 절차가 각 플랫폼에서 처리되므로 현재 구조로 적법
- **필요 조치**: 향후 새로운 제3자 제공처 추가 시 동의 절차 검토
