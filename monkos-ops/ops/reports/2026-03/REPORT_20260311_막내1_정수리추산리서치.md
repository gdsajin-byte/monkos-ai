## 2. 두개안면 계측 데이터

### 2-1. 핵심 정의

| 측정명 | 랜드마크 | 의미 |
|--------|----------|------|
| **두개안면높이 (v-gn)** | vertex → gnathion | 정수리~턱. **ID 사진의 "얼굴길이"** |
| 형태학적 얼굴높이 (n-gn) | nasion → gnathion | 미간~턱. 두개관(cranial vault) 미포함 |
| 생리학적 얼굴높이 (tr-gn) | trichion → gnathion | 헤어라인~턱 |

### 2-2. 한국인 두상 데이터 (Size Korea)

| 측정 | 남성 | 여성 | 출처 |
|------|------|------|------|
| 두상높이 (v-gn) | 236mm | 223mm | KFDA 2007-2010 (n=691) |
| 얼굴높이 (n-gn) | 116.1mm (SD 9.8) | 114.0mm (SD 9.7) | Size Korea 6차 (n=5,110) |
| 관골폭 (zy-zy) | 150.1mm (SD 9.7) | 147.1mm (SD 10.1) | Size Korea 6차 |

**비율 도출**: 얼굴높이(n-gn) / 두상높이(v-gn) ≈ 116/236 = **49.2%** (남성)
→ nasion~vertex = 두상높이의 약 51% = 약 120mm
→ 눈 위치는 nasion보다 아래이므로, **눈~정수리 > 눈~턱** (1:1보다 상반부가 김)

### 2-3. 인종별 비교

| 측정 | 한국인(M) | 중국인(M) | 미국인(M) |
|------|-----------|-----------|-----------|
| 관골폭 | 150.1mm | 147.5mm | 143.5mm |
| 얼굴높이(n-gn) | 116.1mm | 117.3mm | 122.7mm |
| 특성 | 넓고 짧음 | 중간 | 좁고 긺 |

→ 한국인은 얼굴이 넓고 짧아 facial index가 낮음 (euryprosopic 경향)
→ **고정 비율 적용 시 인종별 편차 불가피**

### 2-4. 1:1 비율 (눈~정수리 = 눈~턱) 검증

**Farkas 1985 결론**: 고전 캐논(눈이 두상 높이의 정확히 1/2)은 **대다수에서 불일치**.
- 상반부(v→eye)가 하반부(eye→gn)보다 **더 긴 경향** (특히 여성)
- 9개 신고전적 캐논 중 수직 비율이 **가장 낮은 일치율**
- 수평 캐논(동공간거리 = 코폭)은 ~40% 일치, 수직 캐논은 그 이하

**실용적 판단**: 1:1은 **근사치로 유효하나 정밀 엔진엔 부족**. 상반부가 평균적으로 더 김.

## 3. 오픈소스 크롭 엔진 비교

| 프로젝트 | 정수리 추산 방식 | 모델 | 핵심 비율/계수 | 정확도 |
|----------|-----------------|------|---------------|--------|
| **HivisionIDPhotos** | **하이브리드**: 매팅 alpha 상단 스캔 + 랜드마크 초기 배치 | MODNet/BiRefNet + MTCNN/RetinaFace | head_top_range: 10-12% | 높음 (픽셀 정밀) |
| **dpar39/ppp** | **순수 랜드마크 외삽**: 4점 기하학 계산 | MediaPipe FaceMesh 468 | chinCrownCoeff = 1.7699, chinFrownCoeff = 0.8945 | ±5.88% 허용오차 |
| **passportpix** | **고정 비율**: 눈 위치 = 프레임의 7/12 | OpenCV Haar Cascades | 눈 = 7/12 높이 | 낮음 (적응성 없음) |
| **DeepLab-Passport** | **세그멘테이션 bbox**: DeepLab v3 마스크 + Haar bbox | DeepLab v3 (COCO) | bbox 직접 사용 | 중간 |

### 3-1. HivisionIDPhotos (가장 정교)

**3단계 하이브리드**:
1. 얼굴 랜드마크로 초기 크롭 위치 설정 (`head_height_ratio = 0.45`)
2. 매팅 모델(MODNet 등)로 alpha mask 생성 → `get_box()`로 마스크 최상단 y좌표 = 머리 꼭대기
3. `detect_distance()`로 머리~프레임 상단 갭 검증 (10-12% 범위 내 조정)

→ **세그멘테이션 마스크로 헤어 포함 실측**. 랜드마크 단독보다 정확.

### 3-2. dpar39/ppp (가장 수학적)

**알고리즘**:
- A,B = 좌우 동공, C,D = 입꼬리, M = AB 중점, N = CD 중점
- `KK = |AB| + |MN|` (정규화 거리)
- **정수리~턱 = 1.7699 × KK** (SCFace DB 130명 기반 최적화)
- **미간~턱 = 0.8945 × KK**
- 상관계수: alpha 0.7954, beta 0.8426

→ **세그멘테이션 불필요. 랜드마크만으로 추산. 헤어 볼륨 미반영이 약점.**

## 5. 여권 규격과 정수리 정의

### 5-1. 규격별 비교

| 규격 | 얼굴높이 | 상단 기준 | 하단 기준 | 헤어 포함? | 헤어 차폐 시 추산법 |
|------|---------|-----------|-----------|-----------|-------------------|
| **ISO 19794-5** | % 기반 | 두개골 정점(skull vertex) | 턱 | **제외** | "머리카락 없다면 두개골이 어디인지 추산" |
| **ICAO 9303 (인쇄)** | 70-80% (31.5-36mm) | crown (skull) | 턱 | **제외** | ISO 준용 |
| **한국 여권/면허** | 3.2-3.6cm | **정수리 (머리카락 제외)** | 턱 | **제외** | 미명시 |
| **일본 여권** | 32-36mm | 頭頂部 | 顎先 | **실무상 포함** | **눈~턱 = 눈~정수리 (1:1 공식 대체법)** |
| **미국 (인쇄)** | 25-35mm | top of head | 턱 | 모호 | 미명시 |
| **미국 (디지털)** | 50-69% | top of head incl. hair | 턱 | **포함** | 미명시 |
| **캐나다** | 31-36mm | crown (skull) | 턱 | **제외** | "머리카락 없다면 두개골이 어디인지" |
| **독일** | 32-36mm (허용 27-40mm) | crown (skull) | 턱 | **제외** | **허용 범위 확대로 대응** |

### 5-2. 핵심 발견

1. **정석 (ISO/ICAO/한국/캐나다)**: 정수리 = **두개골 정점, 헤어 제외**
2. **독일의 현실 인정**: "헤어 아래 두개골 위치 판별이 어렵다" → 허용 범위를 27-40mm로 확대
3. **일본의 실용적 대체법**: 볼륨 헤어 시 **눈~턱 거리를 눈 위로 동일 적용 = 1:1 비율을 공식 추산법으로 명시**
4. **한국 여권이 가장 엄격**: "머리카락을 제외한 머리 최상부" — 추산법 미제공

## 6. 현재 crop.js v2 분석

### 현재 로직 (`crop.js` lines 43-46)

```javascript
const eyeToChin = chin.y - eyeCenterY;
const crownY = eyeCenterY - eyeToChin;  // 눈 위로 눈~턱 거리만큼
const faceHeight = chin.y - crownY;     // = eyeToChin * 2
```

- **방식**: 눈~턱 거리를 눈 위로 1:1 반전 → 정수리 추산
- **보정**: `HAIR_VOLUME_RATIO = 0.08` (얼굴높이의 8%를 헤어 볼륨으로 추가)
- **상수**: `EYE_POSITION_RATIO = 0.43`, `FACE_TARGET_MM = 33`, `HAIR_MARGIN_MIN = 0.044`

### 알려진 한계

- 1:1 비율에 개인차 있음 (이마 긴/짧은 사람)
- 헤어 스타일 미반영 (고정 8%)
- `face-detect.js`의 `CROWN_OFFSET_RATIO = 0.30`은 v2에서 미사용 (역할 정리 필요)

### 단기 (v2 튜닝, 모델 추가 없음)

| 개선 | 내용 | 근거 |

| **dpar39/ppp 계수 도입** | `chinCrownCoeff = 1.7699 × KK` | SCFace DB 130명 최적화, ±5.88% 허용오차 검증 |
| **일본 대체법 채택** | 눈~턱 = 눈~정수리 (1:1) as fallback | 일본 외무성 공식 인정. 가장 보수적이고 안전한 추산 |

### 중기 (segmentation 추가)

| 추천 | 모델 | 크기 | 추론시간 | 효과 |
|------|------|------|---------|------|
| **1순위** | BiSeNet face-parsing (ResNet18, ONNX) | ~43MB | ~50-100ms | hair mask y-min = 실측 헤어탑 |
| **2순위** | MODNet portrait matting (ONNX) | ~7MB | ~30-80ms | alpha mask 상단 = 머리 꼭대기 |
| **3순위** | PP-HumanSeg Lite | ~1-5MB | ~10-50ms | 초경량, 정밀도↓ |

**추천 파이프라인**:
```
입력 이미지
  ├→ MediaPipe FaceMesh → 눈/턱/코 랜드마크 (배치 앵커, 현행 유지)
  └→ BiSeNet face-parsing → hair mask → y-min = 실측 헤어탑
       → crownY를 추산값 대신 실측값으로 대체
       → fallback: 세그멘테이션 실패 시 1:1 비율 (일본 대체법)
```

### 핵심 판단

| 쟁점 | 판단 | 근거 |
|------|------|------|
