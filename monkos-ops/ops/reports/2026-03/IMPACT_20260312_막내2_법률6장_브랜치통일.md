### 실행 절차 (순서 엄수)

```bash
# ── Step 1: 최신 상태 동기화 ──
git fetch --all

# ── Step 2: develop 커밋을 main에 머지 ──
git checkout main
git pull origin main
git merge develop --no-ff -m "[merge] develop→main 최종 통합 — 브랜치 단일화"
git push origin main

# ── Step 3: develop 리모트 삭제 ──
git push origin --delete develop

# ── Step 4: develop 로컬 삭제 ──
git branch -d develop

# ── Step 5: 불필요 로컬 브랜치 정리 (선택) ──
git branch -d dev-home    # 사용 안 하는 로컬 브랜치
git branch -d dev-office  # 사용 안 하는 로컬 브랜치

# ── Step 6: 리모트 참조 정리 ──
git remote prune origin

# ── Step 7: 검증 ──
git branch -a              # main만 존재 확인
git log --oneline -5       # develop 커밋 포함 확인
```

### git 히스토리 보존 확인

- develop 삭제 시 **히스토리 손실 없음**: develop의 모든 커밋이 main에 머지되면 git 히스토리 그래프에 그대로 보존됨
- `--no-ff` 머지 사용 시 머지 커밋이 생성되어 "여기까지가 develop에서 작업한 이력"이 명시적으로 기록됨
- 브랜치 포인터만 삭제되는 것이지 커밋 객체는 영구 보존됨
