### 문제 발견 항목 (수정 필요)

#### 2-1. H1 중복 (블로그 포스트)

**현상**: 블로그 글 1개에 H1이 2개 존재
```
<h1>20년 경력 사진작가가 AI로 만든 증명사진 서비스 | Monkos.ai</h1>  ← 페이지 타이틀
<h1>20년 사진작가가 AI로 만든 증명사진 서비스 | Monkos.ai</h1>        ← 본문 내 반복
```

**영향**: Google이 콘텐츠 주제를 혼동. SEO 점수 감점.
**수정**: 본문 내 H1 → `<h2>` 변경. 페이지당 H1은 1개만 유지.

#### 2-2. H2/H3 heading 구조 전무 (블로그 포스트)

**현상**: 블로그 본문에서 섹션 구분을 이모지(`📌`)로만 함. HTML heading 태그 없음.
```
현재: 📌 서비스 탄생  (텍스트)
필요: <h2>서비스 탄생</h2>
```

**영향**: Google이 글의 구조를 파악 못함 → 키워드별 섹션 매칭 불가 → 랭킹 불이익.
**수정**: 모든 블로그 포스트의 섹션 제목을 `<h2>`, 하위 섹션을 `<h3>`으로 마크업.

#### 2-3. 블로그 리스트 페이지 메타 영문

**현상**:
```
<meta name="description" content="AI ID Photo tips, guides, and news">
<meta property="og:description" content="AI ID Photo tips, guides, and news">
```

**영향**: 한국어 검색에서 관련성 점수 하락.
**수정**: `"AI 증명사진 팁, 가이드, 최신 뉴스 | MONKOS AI 블로그"` 등 한국어로 변경.

#### 2-4. `<article>` 태그 콘텐츠 감지 이상

**현상**: JavaScript로 `document.querySelector('article').textContent` 실행 시 wordCount = 0
**가능 원인**: article 태그가 있으나 실제 본문이 article 바깥에 렌더링되거나, CSR 후 삽입되는 구조
**영향**: 구조화 데이터(Article schema)와 실제 DOM이 불일치하면 Google이 리치 결과에서 제외 가능
**수정**: article 태그 안에 본문 전체가 포함되는지 확인. SSR/SSG 렌더링 시점 점검.
