### 1-2. 선행기술 조사 (KIPRIS)

- **직접 경쟁 특허: 0건** — "양안대칭 정수리 추정" + "클라이언트 완결" 조합은 선행기술 없음
- **관련 특허 1건**: 다온크리에이션스 (10-2024-0132879) — 증명사진 자동 생성 시스템
  - 코(nose) 기반 고정 계수 방식 → 우리 기술과 접근법 자체가 다름
  - 서버 전송 필수 구조 → 우리는 완전 클라이언트
  - 외교부 여권발급기 납품 업체로 추정 (B2G)
- **해외 (PhotoAid 등)**: 주요 글로벌 증명사진 서비스들도 특허 출원 없이 운영 중

### 1-3. 출원 전략

```
한국 출원 (4월 중)
  ↓ 우선심사 (6~10개월 내 결과)
  ↓
12개월 내 일본 출원 결정 (직접 or PCT)
```

**일본 출원이 특히 중요한 이유:**
- 일본 외무성 여권규격에 "眼~顎 = 眼~頭頂" (눈~턱 = 눈~정수리) **1:1 비율을 공식 명시**
- 우리 알고리즘 `crownY = eyeCenterY - (chin.y - eyeCenterY)`이 **일본 공식 규격의 구현체**
- 일본 시장이 핵심 타겟 → 일본 업체의 카피 후 선출원 차단 필수
- 한국 특허만으로는 일본에서 방어 불가 (속지주의)

**일본 출원 비용**: 약 300~450만원 (번역비 + 현지 대리인비 + JPO 수수료)
- 일본 법인 불필요, 한국 변리사 → 일본 제휴 사무소 연계로 진행 가능

### 1-4. 우선심사 필요성

| 항목 | 이유 |
|------|------|
| **일본 출원 판단** | 한국 심사 결과를 보고 일본 출원 여부·전략 결정 가능 |
| **코드 노출** | monkos.ai/crop의 crop.js가 브라우저에서 그대로 노출 — 카피 위험 |
| **IR/투자유치** | "특허 등록 완료"와 "출원 중"의 무게감 차이 |
| **비용** | 견적에 이미 포함 (추가 비용 없음) |

### 1-5. 특허 비용 지원금

| 항목 | 내용 |
|------|------|
| **프로그램** | 하남시 지역 기술지원기반 (특허 지원) |
| **지원금** | 최대 180만원 |
| **일정** | 1차 마감 → 2차 공고 4월 중순~5월 예정 |
| **확인 방법** | 4월 6일경 담당 직원에게 전화 (1379 전문가 상담 연계) |
| **판단** | 지원금 트랙 가능 시 실부담 약 20만원. 불확실하면 자비 출원 |

### 1-6. 긴급성 판단

**즉시 출원이 정석인 이유:**
- 서비스가 이미 퍼블릭 (monkos.ai/crop)
- 브라우저 기반 → 개발자 도구로 코드 분석 즉시 가능
- 무료 배포 + 광고 확대 예정 → 노출 증가
- 특허출원 = 광고 시 "특허출원 기술" 문구 사용 가능
- 벤처인증, IR/투자유치 등 모든 절차에 특허 실적 활용

**현실적 판단:** 자금 상황을 고려하여 4/6 지원금 확인 후 결정. 다만 4월 중 출원은 반드시 진행.

## 5. 자금 현황 및 파이프라인

### 5-1. 현재 상황

- 자금이 가장 조여있는 시기
- 1차 투자 1천만원 (박정순 대표) → 이달말까지 회수 독촉
- 소진공 직접대출 → 지방세(등록면허세) 6만원 갑작스러운 체납으로 탈락
  - 원인: 통신판매업 재개 시 등록면허세 발생 → 미인지 상태에서 자동연동 체납 처리
  - 해결 완료: 원인 파악됨, 재발 방지

### 5-2. 대기 중 파이프라인

| 건 | 금액 | 상태 | 예상 시점 |
|----|------|------|----------|
| **중진공 자금** | **2억원 신청** | 심사 중 | **이번~다음 주 결과** |
| 소진공 직접대출 | - | 4월 초 재신청 예정 | 4월 |
| 경기신보 (4건 한번에) | 최대 수천만원 | 방문 상담 필요 | 벤처인증 접수 후 |

### 5-3. 병목 분석

> "3천만원만 있으면 2~3개월간 달릴 속도를 생각하면 뭐가 터져도 터질 것"

- 특허출원 + 일본출원 + 광고비 + 운영비 커버 가능
- 중진공 2억에서 일부라도 열리면 즉시 돌파구
- 벤처인증 + 특허출원 완료 시 투자유치(IR) 자격도 갖춰짐
