| 시간대 | 내용 유형 | 이유 |
|--------|----------|------|

### 2-3. 인스타그램 — 쇼윈도우 (신뢰 구축)

#### 일본 인스타 특성

- 이미지 안에 **텍스트를 크게** (카드뉴스형)
- "예뻐 보여요"가 아닌 **"이유를 알 수 있어요"** → 논리적 설명 필수
- 캡션 길게 + 정보 충실 작성
- 저장(保存) = 알고리즘 노출의 **핵심 지표**
- 얼굴 없는 텍스트 리뷰도 일본에서는 자연스러움

#### 캐러셀 표준 구조 (6장)

| 장 | 내용 | 디자인 |
|----|------|--------|
| **1장** | Before/After + 큰 제목 "なぜこんなに違う？" | 임팩트 최대, 스와이프 유도 |
| **2장** | 이유 ① AI리얼타임コーチング | 아이콘 + 1줄 설명 |
| **3장** | 이유 ② 韓国プロ写真館20年の技術 | 아이콘 + 1줄 설명 |
| **4장** | 이유 ③ 本人の顔をそのまま活かす | 비교 이미지 |
| **5장** | 使い方 3ステップ (촬영→AI처리→다운로드) | 스텝 인포그래픽 |
| **6장** | CTA "プロフィールのリンクから無料体験 →" | 로고 + 링크 유도 |

1. **"保存して就活に使ってね"** — 캡션 마지막에 명시적 저장 요청

4. **슬라이드 수 6장 이상**: 더 많은 정보 = 저장 확률 상승

## 6. 컨텐츠 제작 가이드 (일본어)

### 6-1. X 트윗 표준 (280자 일본어)

**구조:**
```
[フック] — 1행. 놀라움/의문/숫자. 즉시 멈추게 만드는 한 줄.
  例: "え、これAI!?" / "写真館8,000円、MONKOS 0円。" / "【就活生必見】"

[本文] — 2~3행. 소구점 명확히.
  - ✅/📸/💰 등 이모지로 가독성 확보
  - です/ます 경어 사용
  - 구체적 숫자 포함 ("3分完成", "20年の技術")

[CTA] — 1행. 행동 유도.
  例: "プロフィールのリンクから →" / "詳しくはリプ欄で"

[ハッシュタグ] — 3~5개
  기본: #証明写真 #就活 #AI写真
  시즌: #27卒 #ES写真
```

**톤**: 정보성, 간결, 경어(です/ます), 과장 없이 사실 기반

### 6-2. 인스타 캐러셀 표준 (일본어 텍스트 카드)

**6장 표준:**

| 장 | 역할 | 텍스트 크기 | 디자인 |
|----|------|-----------|--------|
| 1장 | **히어로 (스크롤 멈춤)** | 제목 48pt+ | B/A 이미지 + 대형 질문 |
| 2~4장 | **논리 전개** | 본문 24pt+ | 아이콘 + 1줄 핵심 + 2줄 설명 |
| 5장 | **사용법** | 스텝 번호 32pt | 1→2→3 인포그래픽 |
| 6장 | **CTA** | CTA 36pt | 로고 + "プロフィールのリンクから →" |

**디자인 가이드:**
- 배경: 흰색 or 라이트 그레이 (깔끔한 일본 감성)
- 폰트: ゴシック体 (고딕체) — 가독성 우선
- 색상: 브랜드 컬러 + 네이비/그레이 (전문성)
- 여백: 충분히 (일본 = 여백의 미학)
