# 디딤돌 서면평가 이의신청 — R&D 실증 데이터셋

**작성일**: 2026-03-29
**대상**: 디딤돌 서면평가 이의신청 첨부자료
**연구 환경**: RTX 4060 (8GB VRAM) — AI Factory (4060 서버)
**연구 기간**: 2026-01 ~ 2026-03 (3개월)
**정본 위치**: `monkos-ops/ops/reports/2026-03/`

## 1. 연구 개요

MONKOS.AI 서비스(AI 증명사진·K-Beauty 룩북·모델 에이전시)의 핵심 엔진으로 활용할 오픈소스 생성형 AI 모델의 **자체 벤치마크 연구**를 수행하였다. RTX 4060 (8GB VRAM) 환경에서 이미지 생성·LLM·영상 생성 3개 분야, 총 28종 모델을 대상으로 표준화된 스키마 기반의 정량 평가를 실시하고, 현 장비의 한계와 차세대 GPU(RTX 5090) 도입의 필요성을 데이터로 입증하였다.

### 2-4. 핵심 발견

1. **데이터 베이스가 프롬프트보다 중요**: 서구권 학습 데이터 기반 모델(Juggernaut)은 'Korean' 프롬프트를 추가해도 K-Beauty 피부 표현에 한계. 동양인 특화 데이터로 학습된 HelloWorld XL은 별도 프롬프트 없이 자연스러운 한국형 미인 생성.
2. **4060의 SDXL 생성은 안정적이나 LoRA 파인튜닝은 빡빡**: 8GB VRAM으로 추론은 가능하지만, 자사 모델 커스터마이징(LoRA/QLoRA)에는 VRAM 부족.
3. **차세대 아키텍처(FLUX, SD3.5)는 4060 불가**: DiT 기반 모델(FLUX.1-dev 12GB, SD3.5 Large 13GB)은 8GB 벽에 막혀 실행 자체 불가.

## 4. RTX 4060 vs RTX 5090 — 도입 필요성 비교표

### 4-1. 하드웨어 스펙 직접 비교

| 항목 | RTX 4060 (현재) | RTX 5090 (도입 목표) | 배율 |
|------|:--------------:|:------------------:|:----:|
| VRAM | 8GB GDDR6 | 32GB GDDR7 | **×4** |
| 메모리 대역폭 | 272 GB/s | 1,792 GB/s | **×6.6** |
| CUDA 코어 | 3,072 | 21,760 | **×7.1** |
| TDP | 115W | 575W | ×5 |
| PCIe | Gen 4.0 | Gen 5.0 | ×2 |
| 실매가 (2026.02) | ~40만원 | ~400만원+ | — |

### 4-2. 작업별 가능/불가 매트릭스

| 작업 | RTX 4060 (8GB) | RTX 5090 (32GB) | RTX 5090 ×2 (64GB) |
|------|:--------------:|:---------------:|:------------------:|
| **SDXL 추론 (1024²)** | ✅ ~25초 | ✅ ~5초 (추정) | ✅ (과잉) |
| **FLUX.1-dev 추론** | ❌ (12GB 필요) | ✅ | ✅ |
| **SD 3.5 Large 추론** | ❌ (13GB 필요) | ✅ | ✅ |
| **SDXL LoRA 학습** | ⚠️ 빡빡 | ✅ 여유 | ✅ |
| **FLUX LoRA 학습** | ❌ | ✅ (~23GB) | ✅ |
| **7B LLM 추론 (Q4)** | ✅ 40+ tok/s | ✅ 100+ tok/s | ✅ |
| **14B LLM 추론 (Q4)** | ❌ (9GB>8GB) | ✅ 60+ tok/s | ✅ |
| **30B LLM 추론 (Q4)** | ❌ | ⚠️ 35+ tok/s | ✅ 50+ tok/s |

| **7B QLoRA 파인튜닝** | ⚠️ (5GB/8GB) | ✅ 여유 | ✅ |

### 4-3. 5090 도입 필요성 — 4060 한계 실증 요약

| # | 한계 조건 | 4060 상태 | 5090 해소 여부 | 비고 |

> **5개 항목 중 4개 ❌, 1개 ⚠️** → 5090 도입 정당성 충분
