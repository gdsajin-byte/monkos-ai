## Phase 2: camera.js 음성 코칭 복구 (JP 패턴 이식) ✅

### 수정 파일
- `monkos_AI/idphoto-kr/public/camera.js` — speakKo, activateTTS, voiceEnabled 초기화, toggleVoice 제거
- `monkos_AI/idphoto-kr/public/camera.html` — #btn-voice 버튼 제거

### 변경 내역

#### 2-A: speakKo() JP 패턴 교체
```
Before: if (!koVoice) return;        ← iOS 차단의 원흉
After:  if (koVoice) u.voice = koVoice;  ← 있으면 사용, 없으면 시스템 기본
```
- `setTimeout(100ms)` 딜레이 제거 (JP에도 없음)
- `speechSynthesis.speaking` 가드 제거 (cancel() 후 즉시 speak)

#### 2-B: voiceEnabled 초기화
```
Before: store.voiceEnabled = true;                       ← 무조건 ON
After:  store.voiceEnabled = (store.coachingMode === 'voice');  ← prep 선택 반영
```

#### 2-C: toggleVoice() 완전 제거
- `toggleVoice()` 함수 삭제 (라인 76-84)
- `window.toggleVoice` 노출 삭제
- camera.html `#btn-voice` 버튼 삭제
- 모드 전환은 prep에서 완료, 촬영 중 토글 불필요

#### 2-D: activateTTS() 분기
```
Before: if (ttsActivated || ...)
After:  if (!store.voiceEnabled || ttsActivated || ...)
```
- 텍스트 모드에서 불필요한 TTS warmup 방지
