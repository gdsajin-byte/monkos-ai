## 4. 종합 발견 사항

### 근본 원인 (작가님 발견 현상의 기술적 원인)

**현상**: 다운로드 완료 후 규격 탭 클릭 → charge.html → 복귀 시 다운로드 전 상태로 롤백

**원인 체인**:
1. `store.downloadComplete`가 sessionStorage에 **미저장** (shared.js L79 디폴트 `false`, 어디서도 persist 안 함)
2. `_specCache`, `_currentSpec`, `_fullOriginal`이 모듈 스코프 JS 변수 → 페이지 이동 시 **전부 소실**
3. `monkos_pending_action`이 `downloadResult()` 경로에서만 설정 → 포스트DL 단계의 charge.html 이동에는 **자동 복귀 로직 없음**
4. init()의 복귀 분기가 `store.generated` 유무만 확인 → **포스트DL 상태를 인지할 수 없음**
5. 결과: 항상 step3(다운로드 버튼 활성) 상태로 복원

### 설계 불일치

| 항목 | v5 설계 | 현행 코드 | 비고 |
|------|---------|----------|------|
| 다운로드 후 목적지 | thankyou.html | result.js 인페이지 | `showThankYou()`는 이름만 thankyou — 5초 오버레이 |
| 규격 탭 | v5 제외 | result.html L248-258, result.js L499-579 | TECH_SPEC 이슈#4에서 이중과금 문제도 지적됨 |
