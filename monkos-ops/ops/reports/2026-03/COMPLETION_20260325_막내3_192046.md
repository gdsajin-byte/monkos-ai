- AI Discovery 주석 (llms.txt, llms-full.txt 참조 안내)

### 🔴 Cloudflare Managed Content 차단 발견

**프로드 robots.txt (`curl -s https://monk.kr/robots.txt`)에서 Cloudflare가 CDN 레벨로 주입하는 규칙 발견:**

```
# BEGIN Cloudflare Managed content
User-agent: ClaudeBot
Disallow: /

User-agent: GPTBot
Disallow: /

User-agent: Google-Extended
Disallow: /

(+ Amazonbot, Applebot-Extended, Bytespider, CCBot, meta-externalagent)
# END Cloudflare Managed Content
```

**영향**: 로컬 robots.txt에 Allow를 추가해도 Cloudflare Managed Content의 Disallow가 먼저 적용됨. robots.txt 표준상 동일 User-agent에 대해 첫 번째 매칭 블록이 우선.

**해결 방법**: Cloudflare Dashboard → AI → Bot 관리 설정에서 AI 크롤러 차단 해제 필요.
- 경로: Cloudflare Dashboard → monk-kr 프로젝트 → Security → Bots (또는 AI Bots)
- "Block AI crawlers" 또는 유사 설정 OFF
