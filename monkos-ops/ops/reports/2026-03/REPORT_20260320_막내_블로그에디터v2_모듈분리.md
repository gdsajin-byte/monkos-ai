
## 7. 특이사항/리스크

### 7.1 줄 수 미세 차이

blog-edit.html 목표 ~175줄 대비 188줄로 13줄 초과. HTML 마크업(153줄)은 원본 그대로 보존하되, ESM import 초기화 블록이 15줄로 예상(22줄)보다 컴팩트. 초과분은 `<head>` CSS link 추가(2줄)와 줄바꿈 정리로 인한 것.

### 7.2 blog-research.js 내부 변수 접근

원본에서 `onclick="researchPage++;doResearch(true)"`로 직접 접근하던 `researchPage`가 모듈 로컬 스코프로 이동. `loadMoreResearch()` 래퍼 함수를 추가하여 해결. renderResearchResults 내 생성 HTML에서 `loadMoreResearch()` 호출로 변경.

### 7.3 MIME 타입 확인 완료

`lib/shared/config.js` — `.js` → `application/javascript; charset=utf-8` 매핑 확인. ESM 모듈 서빙에 문제 없음.

### 7.4 crop/, tg/ 미접촉 확인

지시서 ⚠️ 준수 조항 준수. crop/ 및 tg/ 디렉토리 어떠한 파일도 수정/접근하지 않음.

### 7.5 브라우저 실행 검증 필요

코드 레벨 검증은 완료했으나, 로컬 서버 기동 후 브라우저 전수 테스트가 필요. 특히:
- ESM `<script type="module">`의 CORS 동작 (로컬 file:// 아닌 HTTP 서빙 필수)
- Toast UI CDN 로딩 후 ESM 모듈 실행 순서
- window 전역 등록 시점과 onclick 호출 시점 동기화
