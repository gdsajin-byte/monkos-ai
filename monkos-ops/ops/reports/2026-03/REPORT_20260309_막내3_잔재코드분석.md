### v079에만 있고 현행에 없는 기능

- **없음**. v079의 모든 기능은 현행에 흡수·개선됨.
- 차이점은 v079가 SPA(단일 index.html), 현행이 MPA(멀티 페이지).
- v079의 Imagen 프롬프트가 조명 중심이고, 현행은 정체성 보존 90% 원칙 반영.

### 삭제 판단 근거

1. **Cloud Run 미배포**: 서비스명 `monkos-idphoto-jp`는 더 이상 존재하지 않음
2. **엔드포인트 불호환**: `/api/generate` → `/api/idgen`으로 변경되어 v079 프론트엔드가 현행 백엔드와 동작 불가
3. **코드 참조 없음**: grep 전수조사 — 활성 코드에서 v079 import/require 0건
4. **지시서 참조 완료**: 3/9 지시서에서 톤·가격 참조 용도로 인용되었으나, 해당 작업 완료 시 더 이상 불필요
5. **기능 완전 흡수**: 모든 API, 코칭, 결제 기능이 현행 JP에 포함

> **결론: 삭제 가능 (232K)**
