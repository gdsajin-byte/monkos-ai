### 2026 벤치마크 핵심 수치

| AI 엔진 | 인용률 | 선호 포맷 |
|---------|--------|----------|
| Perplexity | 97% | 불릿 리스트 |

## 3. 작가님 질의 ① — 색인 수 증가가 무조건 유리한가

**결론: 아니다.**

### 리스크

- **Thin Content 패널티**: 내용 빈약 페이지 대량 색인 → 사이트 전체 품질 평가 하락
- **Crawl Budget 낭비**: 불필요 페이지에 크롤링 예산 소모 → 핵심 페이지 발견 지연
- **키워드 카니발라이제이션**: 유사 페이지끼리 동일 키워드 경쟁 → 양쪽 순위 하락
- **이탈률 급등**: 검색 유입 후 빈 콘텐츠 → 랭킹 시그널 악화

### MONKOS 적용 판단

MONKOS의 프로그래매틱 SEO는 유리한 편:
- 국가별·용도별 규격이 실제로 상이 (고유 콘텐츠 보장)
- 각 규격 페이지가 실제 검색 수요에 매칭
- 규격 확인 → 서비스 전환 CTA가 자연스러움

### 필수 가드레일

- 페이지당 최소 800자 이상 (규격 + 팁 + FAQ)
- 유사도 높은 페이지 canonical 처리
- 검색 볼륨 없는 키워드는 noindex 또는 미생성

## 4. 작가님 질의 ② — 블로그 배포 vs 포털 페이지 생성의 차이

**결론: 역할이 다르며, 둘 다 필요.**

| | 블로그 | 포털 페이지 (specs) |
|---|---|---|
| 성격 | 읽히는 글 (가이드, 스토리) | 참조되는 정보 (규격, 데이터) |
| 검색 의도 | Informational | Transactional/Navigational |
| 전환 거리 | 멂 (읽기 → 관심 → 서비스) | 짧음 (규격 확인 → 바로 서비스) |
| 생산 방식 | 수동 (월 4~8개 현실적) | 자동화 (한 번에 수백 개) |
| 수명 | 시의성 (트렌드, 시즌) | 반영구 (규격 변동 적음) |
| GEO 관점 | 서술형 → AI 인용 가능하나 구조화 약함 | 구조화 데이터 → AI 인용 확률 높음 |

### 전략적 역할 분담

```
포털 페이지 (specs)  →  직접 전환 (하단 깔때기, 작살)
       ↑↓ 내부 링크
블로그 (guide/tips)   →  토픽 권위 + 유입 확장 (상단 깔때기, 그물)
```

Phase 1에서 포털 페이지로 볼륨을 깔고, 블로그가 토픽 클러스터로 엮는 구조가 로드맵의 설계 의도.
