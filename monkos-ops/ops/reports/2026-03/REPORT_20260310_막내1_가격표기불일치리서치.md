## 불일치 상세 분석

### 1. JP server.js — idgen 에러 응답 `required: 1` (CRITICAL)

```js
// idphoto-jp/server.js:540
required: 1,   // ← 실제 차감은 Portal credits.js에서 10c
```

- 실제 크레딧 차감은 Portal API (`/api/credits/use`, type='generate')에서 **10c** 차감
- JP server.js의 `required: 1`은 402 에러 응답에 포함되는 값
- 사용자가 크레딧 부족 시 "1c만 있으면 됩니다" 로 오해 가능
- **KR server.js는 `required: 10` (정상)**

### 2. Portal index.html — 텔레그램 보너스 30c (MEDIUM)

```js
// portal/public/index.html:1990, 2014, 2042
'Telegram友達追加 → 30c GET'     // JP
'텔레그램 친구 추가 → 30c 받기'    // KR
'Add on Telegram → get 30c'      // EN
```

- events.js 정본: `telegram_join = 40c`
- 30c는 폐지된 구 CS봇 보너스 (index.html:2535에 주석 잔존: `v2에서 제거됨 — CS봇 30c 폐지`)
- 포털 메인 페이지에서 잘못된 보너스 금액을 안내 중

### 3. Portal index.html — 구형 v2 크레딧 패키지 (MEDIUM)

```js
// portal/public/index.html:1903-1905
{ id: 'credit_10', credits: 10, price: 12900 },    // 현행에 없는 패키지
{ id: 'credit_30', credits: 30, price: 29900 },    // 현행에 없는 패키지
{ id: 'credit_50', credits: 50, price: 45900 },    // 현행에 없는 패키지
```

- 현행 v3 패키지(70c/100c/300c/500c)와 완전 불일치
- 포털 크레딧 모달에서 사용되는 구형 데이터로 추정
- 이 패키지로 결제 시도 시 서버 측 검증에서 불일치 발생 가능

### 4. CS_SYSTEM_PROMPT — 구형 $ 가격 (LOW)

```
購入（グローバル）: 10c/$10 | 30c/$25 | 50c/$40
```

- Telegram CS봇이 고객에게 존재하지 않는 달러 가격을 안내
- 현행 JP ¥ 패키지와 완전 불일치

### 5. Portal credits.js — 구형 $ 단가 (LOW)

```js
// portal/lib/credits.js:30
res.end(JSON.stringify({ credits, userId, unit: '$0.10/c', krwRate: 145 }));
```

- API 응답에 구형 달러 단가 `$0.10/c` 포함
- 프론트엔드에서 이 값을 표시하지는 않으나 API 인터페이스로 잔존
