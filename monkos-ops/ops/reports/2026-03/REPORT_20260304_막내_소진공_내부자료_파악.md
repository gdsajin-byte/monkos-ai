## 2. 신청 매뉴얼 / 작성 가이드

### 2-1. 온라인 신청 절차 (5단계)

```
1단계: 공고 확인
  ├── 소진공/중기부/기업마당 홈페이지에서 최신 공고 확인
  └── 자금 유형별 자격 요건 사전 확인
      │
      ▼
2단계: 온라인 자격 진단
  ├── ols.semas.or.kr 접속
  └── 사업자번호 입력 → 자동 자격 검증
      │
      ▼
3단계: 온라인 신청 접수
  ├── 자금 목적 선택 (운전자금/시설자금)
  ├── 필수 서류 스캔 업로드
  └── ⚠️ 60분 내 완료 필수 (시간 초과 시 재접수)
      │
      ▼
4단계: 서류 및 현장 심사
  ├── 소진공 담당자가 직접 심사
  └── 필요 시 사업장 방문 현장 실사
      │
      ▼
5단계: 승인 및 대출 실행
  ├── 약정 체결
  └── 영업일 3~5일 내 계좌 입금
```

### 2-2. 필수 제출 서류

| 구분 | 서류 | 심사 초점 |
|------|------|----------|
| 사업자 기본 | 사업자등록증, 대표자 신분증 | 실체 확인 |
| 매출 증빙 | 부가가치세 과세표준증명원 (최근 2년) | 매출 규모, 현금흐름 |
| 세금 완납 | 국세/지방세 납세증명서 | **체납 시 즉시 탈락** |
| 사업장 | 임대차계약서 또는 등기부등본 | 실제 영업 여부 |
| 부채 현황 | 기존 대출 증빙 | 상환 여력 판단 |
| 근로자 확인 | 건강보험 자격득실확인서 등 | 소상공인 요건 (5인/10인 미만) |
| **사업계획서** | 자금 용도, 사업 비전, 기대 효과 | **직접대출 핵심 서류** |

시설자금 신청 시 추가: 견적서/계약서, 구체적 자금집행계획, 배치도

### 2-3. 사업계획서 작성 핵심 가이드

**소진공 심사자가 보는 것:**
1. "자금이 **왜** 필요한가"
2. "투입 후 **어떤 변화**가 일어나는가"

**작성 핵심 팁:**

| # | 포인트 | 설명 |
|---|--------|------|
| 1 | **수치와 객관적 근거** | "AI 기술 도입 후 생산성 20% 향상 예상" — 구체적 숫자 필수 |
| 2 | **자금 용도 세분화** | 원부자재, 인건비, 임차료, 서버비용 등 항목별 구분 기재 |
| 3 | **사업 관련 용도만** | 사업과 직접 관련된 용도임을 명확히 서술 |
| 4 | **매출 감소 시 사유 설명** | 미설명 = 주요 탈락 사유 |
| 5 | **성장 가능성 제시** | AI/IT 시장 성장 데이터 + 자사 서비스 경쟁력 |

|-----------|------|

### 2-5. FAQ 주요 항목 정리

**Q: 소상공인 기준은?**
A: 상시근로자 5명 미만 (제조/건설/운수/광업은 10명 미만)

**Q: 기존 정책자금 대출이 있어도 신청 가능한가?**
A: 가능하나, 기존 대출 잔액이 한도에서 차감됨. 부채비율 500% 초과 시 불가.

**Q: 신용점수가 낮아도 가능한가?**
A: 직접대출은 신용점수보다 **사업 지속성**을 중시. 단, 30일 이상 연체 이력 시 제외.

**Q: 접수 후 결과까지 기간은?**
A: 평균 **2~3주** (서류 보완 시 4~6주)

**Q: 대출금을 어디에 써야 하는가?**
A: 사업 관련 용도만 (원부자재, 인건비, 임차료 등). 타 대출 상환, 개인 용도 절대 금지.

## 3. 심사 프로세스 상세

### 3-1. 단계별 프로세스 (직접대출 기준)

```
온라인 접수 → 서류 심사 → 현장 실사(필요시) → 최종 승인/부결 → 약정 체결 → 자금 집행
```

| 단계 | 내용 | 소요 기간 |
|------|------|----------|
| **서류 심사** | 재무 상태 분석, 매출/수익성/현금흐름 평가 | 접수 후 **1~2주** |
| **현장 실사** | 사업장 방문, 실제 영업상황/시설/담보능력 확인 | 필요 시 **추가 1주** |
| **최종 결정** | 보증심사위원회 종합 평가 후 승인/부결 통보 | 현장 실사 후 **1~2주** |
| **자금 집행** | 약정 체결 후 계좌 입금 | 승인 후 **영업일 3~5일** |

**총 소요 기간: 평균 2~3주 (서류 보완 시 4~6주)**

### 3-2. 심사 평가 기준

| 평가 영역 | 세부 항목 | 가중치 |
|-----------|----------|--------|
| **결격 리스크** | 체납, 서류 불일치, 허위 제출 | 즉시 탈락 |
| **상환 능력** | 매출 규모, 현금흐름, 기존 부채, ICR(이자보상배율) | 높음 |
| **사업 지속성** | 운영 실태, 성장 가능성, 자금 투입 후 개선 전망 | 높음 |
| **신용도** | NICE/KCB 점수, 연체 이력 | 중간 (사업성 더 중시) |
| **업종 적합성** | 표준산업분류 코드, 제한업종 여부 | 기본 |

### 3-3. 직접대출 vs 대리대출 비교

| 구분 | 직접대출 | 대리대출 |
|------|---------|---------|
| 심사 주체 | **소진공** 직접 | 보증기관 + 시중은행 |
| 핵심 서류 | **사업계획서** | 보증서 |
| 심사 절차 | 간소화 (보증기관/은행 심사 생략) | 이중 심사 (보증+은행) |
| 서류 제출 | 소진공 온라인 시스템 업로드 | 보증기관 앱/창구 + 은행 |
| 확인서 유효기간 | — | 발급일로부터 60일 |
| 장점 | 절차 단순, 사업성 중시 | 한도 유연 |

## 4. 자금 집행 및 사후 관리

### 4-1. 자금 사용 증빙 방법

**운전자금 인정 증빙 자료:**

| 사용 항목 | 인정되는 증빙 |
|----------|-------------|
| 물품/원자재 구입 | 전자세금계산서, 카드 영수증, 현금영수증 |
| 사업장 임대료 | 임대차계약서 사본, 이체확인증 |
| 직원 인건비 | 급여 이체 내역, 급여대장, 4대 보험 납부 내역 |
| 공과금/광고비 | 요금 고지서, 납부영수증, 결제 내역 |
| 서버/클라우드 비용 | 카드 결제 내역, 인보이스 |

**증빙 핵심 원칙:**
1. **정책자금 전용 계좌를 별도 관리** (권장)
2. 모든 지출은 **계좌이체 또는 카드 결제**로 기록 (현금 지출 후 증빙 없음 = 부정)
3. 대출 기간 종료까지 영수증/세금계산서 **철저히 보관**

### 4-2. 사후 모니터링/점검 주기

| 시점 | 내용 |
|------|------|
| 대출 후 **3개월 이내** | 1차 점검 안내 발송 |
| 대출 후 **6개월 이내** | 서면 점검 (자금사용내역서 제출 요청) |
| **상시** | 무작위 선정 점검 |
| **합동현장점검** | 2026년 **700건** (전년 600건에서 확대) |
| **특별현장점검** | 매년 **100건 이상** (91.5% 적발률) |

- 일반적 방식: **서면 점검** (알림톡/문자로 '자금사용내역서' 제출 요청)
- 서류 미비/영업 불투명 시: **현장 점검** (공단 직원 사업장 방문)

### 4-3. 중도 상환

| 항목 | 내용 |
|------|------|
| 중도상환 수수료율 | **0.08%** (시중은행 1.0~1.5% 대비 매우 낮음) |
| 계산 방식 | 중도상환원금 × 0.08% × (잔존일수 / 대출기간) |
| 면제 조건 | 대출 후 **3년 경과** 시 면제 |
| 일부상환 면제 | 연간 대출총액의 10~20% 이내 상환 시 면제 가능 |
| 보증료 환급 | 조기상환 시 남은 기간 보증료 **일할 계산 환급** |

**상환 조건:**

| 자금 유형 | 총 기간 | 거치기간 | 상환기간 |
|----------|---------|---------|---------|
| **운전자금** | 5년 | 2년 | 3년 |
| 시설자금 | 8년 | — | 8년 |

- 상환 방식: 원금 70% 원금균등분할 + 30% 최종회차 일시상환
- 거치기간: **이자만 납부**, 원금 상환 유예
- 상환기간 최대 5년까지 연장 가능 (경영 어려움 사유)
