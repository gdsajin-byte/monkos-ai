## 3. 토스 위젯화 리서치

### 현재 구현 상태

| 파일 | SDK 버전 | 방식 | 상세 |
|------|---------|------|------|
| idphoto-kr/shared.js | **V1** | 리다이렉트 | `requestPayment('카드', {...})` (line 154-164) |
| portal/credits.html | **V1** | 리다이렉트 | `requestPayment('카드', {...})` (line 351-361) |
| portal/index.html | **V2** 로드 | 미완성 | v2/standard 로드만 됨 (부분 마이그레이션 흔적) |

### 현재 V1 결제 흐름

```
사용자 → buyCreditsKR() → TossPayments(clientKey).requestPayment('카드', {
  amount, orderId, orderName,
  successUrl: ?toss=success,
  failUrl: ?toss=fail,
  customerEmail, customerName
})
→ Toss 결제 페이지 리다이렉트
→ 성공 시 ?toss=success&paymentKey=...&orderId=...&amount=... 리다이렉트
→ initFromTossResult() → POST /api/payments/toss/confirm
→ 백엔드: Toss API /v1/payments/confirm → Firestore 크레딧 적립
```

### V1 vs V2 Widget 비교

| 구분 | V1 (현재) | V2 Widget |
|------|----------|----------|
| SDK | `js.tosspayments.com/v1/payment` | `js.tosspayments.com/v2/standard` |
| 초기화 | `TossPayments(clientKey)` | `TossPayments(clientKey)` |
| 호출 | `requestPayment('카드', {...})` | `payment.requestPayment({method:'CARD',...})` |
| UX | 페이지 이탈 → Toss → 리다이렉트 복귀 | **인앱 모달/오버레이** (페이지 유지) |
| customerKey | 미사용 | `customer.customerId = userId` → 카드 자동 저장 |
| 재결제 | 매번 카드 재입력 | 저장된 카드 자동 표시 |
| 백엔드 변경 | — | 불필요 (동일 confirm 엔드포인트 사용 가능) |
