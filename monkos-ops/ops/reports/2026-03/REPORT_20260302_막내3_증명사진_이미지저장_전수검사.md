## 5. 이미지 처리 파이프라인 요약

```
[고객 브라우저]
  ① 카메라 촬영 → canvas.toDataURL → base64 (sessionStorage 임시 보관)
  ② WebSocket/HTTP로 base64 전송
       ↓
[Cloud Run 서버 / CF Worker]
  ③ 요청 수신 → base64 인메모리 보유
  ④ Gemini API 호출 (base64 전달)
  ⑤ Gemini 응답 base64 수신
  ⑥ JSON 응답으로 base64 반환 → **메모리에서 해제 (저장 없음)**
       ↓
[고객 브라우저]
  ⑦ 응답 base64 → <img> 표시 (워터마크 버전)
  ⑧ 결제 완료 후 → <a download> / Web Share API로 직접 다운로드
```

> **서버 체류 시간**: 요청 처리 중 인메모리만. 요청 완료 후 GC에 의해 해제.
> **영구 저장 지점**: 없음.
