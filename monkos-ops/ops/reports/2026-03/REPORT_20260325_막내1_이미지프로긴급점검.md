### 2-2. 다운로드 엔드포인트 (2개)

**(A) `POST https://idphoto-kr.monkos.ai/api/download`** — 이미지 프로 핵심 다운로드
- 파일: `monkos_AI/idphoto-kr/server.js` (613행)
- 검증 순서: userId → gcsPath → 경로 권한(`service/idphoto/kr/{userId}/`) → 크레딧 70c 차감 → GCS 다운로드 + Signed URL
- **응답 형식: 항상 JSON** (`application/json`)

**(B) `GET https://monkos.ai/api/download/direct?token={token}`** — 비로그인 직접결제
- 파일: `monkos_AI/portal/lib/payments.js` (334행)
- 1회용 토큰 검증
- **응답 형식: 항상 JSON**

### 2-4. HTML 반환 가능 시나리오 (코드 분석 기반)

| **GET 요청으로 잘못 접근** | 🟡 중간 | POST가 아닌 GET으로 `/api/download` 접근 시 정적 파일 fallback |
| **Cloud Run cold start 중 타임아웃** | 🟡 중간 | 컨테이너 기동 중 요청 시 Cloud Run 자체 에러 페이지(HTML) |
| **GCS 접근 권한 만료** | 🟡 중간 | `downloadFromGCS()` 실패 → 500 에러 → 클라이언트 에러 핸들링 이상 |
| **크레딧 API(Portal) 연결 실패** | 🟡 중간 | `useCredits()` 호출 시 Portal 서비스 다운 → 예외 → HTML 에러 |

## 3. Task 1-2: 어드민 인증 이상 조사

- **방식**: 쿠키 기반 (`monkos_session`) + Bearer 토큰 (에이전트용)

- **쿠키 도메인**: `.monkos.ai` (서브도메인 공유)
