## 1. 웹 크롭 엔진 정밀 분석

### 1.1 핵심 상수 & 상태

```
FH = 400                            // 프레임 고정 높이 (px)
FW = FH * spec.wMm / spec.hMm       // 프레임 너비 (여권: 311px, 반명함: 300px)
MM = FH / spec.hMm                   // 1mm당 픽셀 수 (여권: 400/45 ≈ 8.889)

상태:
  imgPos = {x, y}                    // 사진 이동 오프셋 (CSS transform 기준)
  imgScale = 1.0                     // 사진 확대/축소 배율
  pts = {crown, chin, leftPupil, rightPupil, leftCheek, rightCheek,
         tlCorner, trCorner, blCorner, brCorner}  // 프레임 좌표계 랜드마크
```

### 1.2 좌표계 설명

```
┌──────────────────────────────── 프레임 좌표계 ────────────────────────────────┐
│                                                                              │
│  (0,0) ─────────────────────────────────────────── (FW, 0)                  │
│   │                    ↑ topMm                                              │
│   │                ┌── crown.y ──┐                                          │
│   │                │   CROWN     │  ← 정수리 (드래그 가능)                  │
│   │                │             │                                          │
│   │                │   ● ─── ●  │  ← leftPupil, rightPupil                 │
│   │                │   eyeY     │  ← eyeRatio = eyeY / FH                  │
│   │                │  faceMm    │  ← (chin.y - crown.y) / MM               │
│   │                │             │                                          │
│   │                └── chin.y ──┘  ← 턱끝 (고정)                           │
│   │                    ↓ bottomMm                                           │
│  (0, FH) ──────────────────────────────────────── (FW, FH)                  │
│                                                                              │
│  사진: CSS transform: translate(calc(-50% + imgPos.x), calc(-50% + imgPos.y))│
│         scale(imgScale)                                                      │
│  → 사진이 움직이면 pts 전체가 함께 이동                                      │
│  → 프레임(FW × FH)은 절대 이동하지 않음                                      │
└──────────────────────────────────────────────────────────────────────────────┘
```

**3개의 좌표계:**

| 좌표계 | 원점 | 용도 | 변환 |
|--------|------|------|------|
| **프레임 좌표** | 프레임 좌상(0,0) | pts 저장, 수치 계산, SVG 렌더 | MM = FH / spec.hMm |
| **이미지 좌표** | 원본 이미지 좌상(0,0) | FaceMesh 원시 출력 (natW × natH) | cover → 프레임 (autoPlace) |
| **출력 좌표** | 최종 파일 좌상(0,0) | spec.pxW × spec.pxH | outScale = spec.pxH / FH |

### 1.3 render() 로직 흐름도

```
render()
  ├─ 1. 수치 계산
  │    ├─ faceMm = (pts.chin.y - pts.crown.y) / MM
  │    ├─ topMm = pts.crown.y / MM
  │    ├─ bottomMm = spec.hMm - topMm - faceMm
  │    ├─ eyeY = avg(leftPupil.y, rightPupil.y)
  │    ├─ eyeRatio = eyeY / FH
  │    └─ centerOffsetMm = |avg(leftPupil.x, rightPupil.x) - FW/2| / MM
  │
  ├─ 2. 신호등 판정
  │    ├─ getFaceColor(faceMm, spec)
  │    │    ├─ 33~35mm → green (최적)
  │    │    ├─ spec.faceMin~faceMax → yellow (허용)
  │    │    └─ 그 외 → red (이탈)
  │    ├─ getEyeColor(eyeRatio)
  │    │    ├─ 0.43~0.45 → green
  │    │    ├─ 0.40~0.48 → yellow
  │    │    └─ 그 외 → red
  │    └─ isBlocked() → face범위이탈 || eye범위이탈 → 다운로드 차단
  │
  ├─ 3. DOM 업데이트 (SVG 오버레이, 마스크, 가이드선, 핀, 배지, 메트릭)
  │
  ├─ 4. 코칭 메시지 분기
  │    ├─ [여권] 눈 위치 경고 (red/yellow)
  │    ├─ [여권] 좌우 중심 경고 (1.5mm+ 이탈)
  │    ├─ [여권] 다운로드 차단 사유 (face/eye 범위 이탈)
  │    └─ [반명함] 간소화 3종 (중심/상단/얼굴비중)
  │
  └─ 5. 다운로드 버튼 상태 (isSample || blocked → disabled)
```

### 1.4 수치 계산 공식 (핵심)

| 수치 | 공식 | 단위 | 의미 |
|------|------|------|------|
| `faceMm` | `(pts.chin.y - pts.crown.y) / MM` | mm | 정수리~턱끝 거리 |
| `topMm` | `pts.crown.y / MM` | mm | 프레임 상단~정수리 |
| `bottomMm` | `spec.hMm - topMm - faceMm` | mm | 턱끝~프레임 하단 |
| `eyeRatio` | `avg(leftPupil.y, rightPupil.y) / FH` | 0~1 | 눈 위치 비율 |
| `eyePct` | `eyeRatio * 100` | % | 눈 위치 백분율 |
| `faceRatio` | `faceMm / spec.hMm` | 0~1 | 얼굴/프레임 비중 |
| `centerOffsetMm` | `\|faceCenterX - FW/2\| / MM` | mm | 좌우 중심 이탈 |
| `MM` | `FH / spec.hMm` | px/mm | 변환 계수 |

### 1.5 autoPlace 로직

```
autoPlace(imgLandmarks, natW, natH)
  │
  ├─ 1. cover 스케일 계산 (object-fit: cover 모사)
  │    coverScale = max(FW / natW, FH / natH)
  │    displayW = natW * coverScale
  │    displayH = natH * coverScale
  │    offsetX = (displayW - FW) / 2
  │    offsetY = (displayH - FH) / 2
  │
  ├─ 2. 이미지 좌표 → cover 좌표 변환
  │    toCover(pt) = { x: pt.x * coverScale - offsetX,
  │                    y: pt.y * coverScale - offsetY }
  │
  ├─ 3. imgScale 결정 (얼굴이 faceTarget mm에 맞도록)
  │    targetFacePx = spec.faceTarget * MM     (여권: 34 * 8.889 ≈ 302.2px)
  │    faceHCover = chinCover.y - crownCover.y
  │    imgScale = targetFacePx / faceHCover
  │
  ├─ 4. imgPos.y 결정 (눈이 43%에 오도록)
  │    imgPos.y = 0.43 * FH - FH/2 - (eyeYCover - FH/2) * imgScale
  │
  ├─ 5. imgPos.x 결정 (얼굴 중심이 프레임 중앙에 오도록)
  │    imgPos.x = -(faceCenterXCover - FW/2) * imgScale
  │
  └─ 6. 모든 랜드마크를 프레임 좌표로 변환
       result[key] = {
         x: FW/2 + (cover.x - FW/2) * imgScale + imgPos.x,
         y: FH/2 + (cover.y - FH/2) * imgScale + imgPos.y
       }
```

### 1.6 드래그/스케일 조작이 수치에 미치는 영향

| 조작 | imgPos 변화 | imgScale 변화 | pts 변화 | 수치 영향 |
|------|------------|--------------|---------|----------|
| **사진 이동** (img drag) | +dx, +dy | 불변 | 전체 +dx, +dy | faceMm 불변, topMm/bottomMm/eyeRatio 변동, centerOffset 변동 |
| **정수리 드래그** (crown drag) | 불변 | 불변 | crown.y만 변동 | faceMm 변동, topMm 변동, bottomMm 변동. eyeRatio 불변 |
| **스케일** (scale drag) | 불변 | ±0.004/px | 스케일 중심으로 전체 재배치 | faceMm/topMm/bottomMm/eyeRatio 전부 변동 |

**스케일 재배치 공식:**

```javascript
ratio = newScale / dragStart.imgScale
cx = FW/2 + dragStart.imgPos.x   // 사진의 시각 중심
cy = FH/2 + dragStart.imgPos.y
pts[key] = {
  x: cx + (dragStart.pts[key].x - cx) * ratio,
  y: cy + (dragStart.pts[key].y - cy) * ratio
}
```

### 1.7 performCrop() — 최종 트리밍

```
performCrop()
  ├─ outScale = spec.pxH / FH          (531 / 400 = 1.3275)
  ├─ canvas: spec.pxW × spec.pxH       (413 × 531)
  │
  ├─ CSS transform 재현:
  │    ctx.scale(outScale, outScale)
  │    ctx.translate(FW/2 + imgPos.x, FH/2 + imgPos.y)
  │    ctx.scale(imgScale, imgScale)
  │    ctx.translate(-FW/2, -FH/2)
  │
  └─ object-fit: cover 재현:
       coverScale = max(FW/natW, FH/natH)
       ctx.drawImage(img, (FW-dw)/2, (FH-dh)/2, dw, dh)
```

## 2. iOS CropEngine vs 웹 엔진 차이점

### 2.1 패러다임 차이 (가장 중요)

| 관점 | 웹 (crop.js) | iOS (CropEngine.swift) |
|------|-------------|----------------------|
| **핵심 패러다임** | **프레임 고정 + 사진 이동** | **사진 고정 + 영역 잘라냄** |
| 사용자 조작 | 프레임 안에서 사진을 드래그/줌 | crop() 후 결과에 슬라이더/패닝 |
| 수치 계산 시점 | 매 render() 호출 시 실시간 | crop() 계산 시 1회 → 이후 비율 환산 |
| 랜드마크 위치 | 프레임 좌표계에 직접 배치 | 이미지 좌표 → crop 좌표로 변환 |
| 실시간 피드백 | 모든 조작에 수치 즉시 갱신 | 검수 시퀀스 후 결과만 표시 |

### 2.2 랜드마크 소스 차이

| 속성 | 웹 (FaceMesh) | iOS (Vision) |
|------|--------------|-------------|
| **포인트 수** | 478점 (refineLandmarks) | 76점 (Revision3) |
| **좌표계 원점** | 좌상 (0,0) | 좌하 (0,0) — `1-y` 변환 필요 |
| **정규화** | 0~1 (이미지 비율) | boundingBox 상대 (0~1) |
| **사용 포인트** | LEFT_PUPIL(159), RIGHT_PUPIL(386), CHIN(152), LEFT_CHEEK(234), RIGHT_CHEEK(454) | leftPupil, rightPupil, faceContour (최하점=턱) |
| **정수리** | 웹: `eyeY - (chinY - eyeY)` 1:1 반전 | iOS: 동일 공식 (`eyeToChin * 2`) |
| **정확도** | 동공 직접 감지 | 동공 1점 or leftEye 평균 (열화) |

### 2.3 좌표 변환 차이

**웹:**
```
FaceMesh normalized (0~1) → 이미지 px → cover 좌표 → 프레임 좌표
  lp.x * natW → pt.x * coverScale - offsetX → FW/2 + (cover.x - FW/2) * imgScale + imgPos.x
```

**iOS:**
```
Vision normalized (boundingBox 상대) → 이미지 px (y 반전)
  (bounds.origin.x + pt.x * bounds.width) * imageW → x
  (1 - (bounds.origin.y + pt.y * bounds.height)) * imageH → y
```

### 2.4 crop() 함수의 접근 방식 차이

**웹 performCrop():**
- CSS transform을 Canvas에 그대로 재현
- 사용자가 보는 것 === 출력 (WYSIWYG)
- 프레임 좌표계 → 출력 해상도 직선 변환

**iOS CropEngine.crop():**
- 가상 프레임 (1000px 높이) 기반 독립 계산
- `FACE_TARGET_RATIO = 33/45` → 목표 얼굴 비율
- `EYE_POSITION_RATIO = 0.43` → 눈 위치 고정
- 머리 여백 + 하단 여백 보정 루프 (`while newScale * fullFaceH > minTargetFaceH`)
- 출력: 600px 폭 고정
- **사용자 조작과 무관하게** 자동 계산 → 1회성 크롭

### 2.5 배경 제거 (iOS에만 존재)

```
iOS:
  generatePersonMask() → VNGeneratePersonSegmentationRequest (.accurate)
  compositeBackground() → CIBlendWithMask 필터
  → 원본 + 마스크 + 배경색 합성

웹:
  배경 제거 없음. 원본 그대로 크롭.
```

### 2.6 현재 iOS Step4의 문제점

1. **CropEngine.crop()이 먼저 실행** → `lastCropX/Y/W/H`에 의존 → 이미지가 이미 "잘린" 상태에서 시작
2. **패닝/줌이 좌표계에서 분리** — `panOffset`, `zoomAdjust`가 crop 좌표와 별개로 동작
3. **수치(metricFaceMM 등)가 비율 환산** — 프레임 좌표 직접 계산이 아닌 %로 역산
4. **검수 시퀀스가 자동 진행** — 사용자 조작 전에 측정이 끝남 (새 플로우에서는 조작 중 실시간 측정 필요)

struct CropState {
    // 프레임 좌표계 랜드마크 (웹 pts에 대응)

### 3.4 프레임 고정 + 이미지 이동/스케일 상태 관리

**Step3 → Step4 전환 시 (초기 배치):**

```swift
func autoPlace(face: FaceDetectionResult, frameW: CGFloat, frameH: CGFloat, spec: PhotoSpec) -> CropState {
    let MM = frameH / spec.heightMM
    let natW = face.imageWidth
    let natH = face.imageHeight

    // 1. cover 스케일 (object-fit: cover 모사)
    let coverScale = max(frameW / natW, frameH / natH)
    let displayW = natW * coverScale
    let displayH = natH * coverScale
    let offsetX = (displayW - frameW) / 2
    let offsetY = (displayH - frameH) / 2

    func toCover(_ pt: CGPoint) -> CGPoint {
        CGPoint(x: pt.x * coverScale - offsetX, y: pt.y * coverScale - offsetY)
    }

    // 이미지 좌표 → cover 좌표
    let eyeImg = CGPoint(x: face.eyeCenterX, y: face.eyeCenterY)
    let chinImg = CGPoint(x: face.eyeCenterX, y: face.chinY)
    let crownY = face.eyeCenterY - (face.chinY - face.eyeCenterY)
    let crownImg = CGPoint(x: face.eyeCenterX, y: crownY)

    let eyeCover = toCover(eyeImg)
    let chinCover = toCover(chinImg)
    let crownCover = toCover(crownImg)

    let faceHCover = chinCover.y - crownCover.y

    // 2. imgScale: 얼굴이 faceTarget mm에 맞도록
    let faceTargetMM: CGFloat = 34.0  // 여권 기준
    let targetFacePx = faceTargetMM * MM
    let newScale = targetFacePx / faceHCover

    // 3. imgOffset.y: 눈이 43%에 오도록
    let newOffsetY = 0.43 * frameH - frameH / 2 - (eyeCover.y - frameH / 2) * newScale

    // 4. imgOffset.x: 얼굴 중심이 프레임 중앙에 오도록
    let faceCenterXCover = (toCover(CGPoint(x: face.leftEyeX, y: 0)).x
                          + toCover(CGPoint(x: face.rightEyeX, y: 0)).x) / 2
    let newOffsetX = -(faceCenterXCover - frameW / 2) * newScale

    // 5. 모든 랜드마크를 프레임 좌표로 변환
    func toFrame(_ coverPt: CGPoint) -> CGPoint {
        CGPoint(
            x: frameW / 2 + (coverPt.x - frameW / 2) * newScale + newOffsetX,
            y: frameH / 2 + (coverPt.y - frameH / 2) * newScale + newOffsetY
        )
    }

    return CropState(
        crown: toFrame(crownCover),
        chin: toFrame(chinCover),
        leftPupil: toFrame(toCover(CGPoint(x: face.leftEyeX, y: face.leftEyeY))),
        rightPupil: toFrame(toCover(CGPoint(x: face.rightEyeX, y: face.rightEyeY))),
        leftCheek: ..., rightCheek: ...,  // face.landmarks 활용
        imgOffset: CGSize(width: newOffsetX, height: newOffsetY),
        imgScale: newScale,
        natW: natW, natH: natH
    )
}
```

### 3.5 라인 좌표 계산 (프레임 기준 고정 → 이미지 이동에 따른 수치 변동)

```swift
// 프레임 좌표계에서 실시간 수치 계산
// (웹 render() 직역)

struct CropMetrics {
    let faceMm: CGFloat      // 정수리~턱끝 mm
    let topMm: CGFloat       // 프레임 상단~정수리 mm
    let bottomMm: CGFloat    // 턱끝~프레임 하단 mm
    let eyeRatio: CGFloat    // 눈 위치 비율 (0~1)
    let eyePct: CGFloat      // 눈 위치 %
    let centerOffsetMm: CGFloat  // 좌우 중심 이탈 mm
    let faceSignal: Signal   // 얼굴 크기 신호등
    let eyeSignal: Signal    // 눈 위치 신호등
    let isBlocked: Bool      // 크롭 차단 여부
}

func computeMetrics(state: CropState, frameH: CGFloat, spec: PhotoSpec) -> CropMetrics {
    let MM = frameH / spec.heightMM
    let frameW = frameH * spec.widthMM / spec.heightMM

    let faceMm = (state.chin.y - state.crown.y) / MM
    let topMm = state.crown.y / MM
    let bottomMm = spec.heightMM - topMm - faceMm
    let eyeY = (state.leftPupil.y + state.rightPupil.y) / 2
    let eyeRatio = eyeY / frameH
    let faceCenterX = (state.leftPupil.x + state.rightPupil.x) / 2
    let centerOffsetMm = abs(faceCenterX - frameW / 2) / MM

    let faceSignal: Signal = {
        if faceMm >= 33 && faceMm <= 35 { return .pass }
        if faceMm >= spec.faceMin && faceMm <= spec.faceMax { return .warn }
        return .fail
    }()
    let eyeSignal: Signal = {
        if eyeRatio >= 0.43 && eyeRatio <= 0.45 { return .pass }
        if eyeRatio >= 0.40 && eyeRatio <= 0.48 { return .warn }
        return .fail
    }()
    let isBlocked = faceMm < spec.faceMin || faceMm > spec.faceMax
                 || eyeRatio < 0.40 || eyeRatio > 0.48

    return CropMetrics(
        faceMm: faceMm, topMm: topMm, bottomMm: bottomMm,
        eyeRatio: eyeRatio, eyePct: eyeRatio * 100,
        centerOffsetMm: centerOffsetMm,
        faceSignal: faceSignal, eyeSignal: eyeSignal,
        isBlocked: isBlocked
    )
}
```

func coachingMessage(metrics: CropMetrics, spec: PhotoSpec) -> String? {
    // 우선순위: 얼굴 크기 > 눈 위치 > 좌우 중심
    if metrics.faceMm < spec.faceMin {
        return "얼굴 크기 \(f1(metrics.faceMm))mm — 범위(\(spec.faceMin)~\(spec.faceMax)mm) 미달. 확대하세요."
    }
    if metrics.faceMm > spec.faceMax {
        return "얼굴 크기 \(f1(metrics.faceMm))mm — 범위(\(spec.faceMin)~\(spec.faceMax)mm) 초과. 축소하세요."

    if metrics.eyeRatio < 0.40 {
        return "눈 위치 \(f0(metrics.eyePct))% — 허용(40~48%) 미달. 아래로 이동하세요."
    }
    if metrics.eyeRatio > 0.48 {
        return "눈 위치 \(f0(metrics.eyePct))% — 허용(40~48%) 초과. 위로 이동하세요."
    }

### 3.9 최종 트리밍 시점의 좌표 변환

```swift
// 웹 performCrop() 직역 — "이대로 크롭" 버튼 탭 시 실행

func performFinalCrop(image: PlatformImage, state: CropState, spec: PhotoSpec,
                       frameW: CGFloat, frameH: CGFloat) -> PlatformImage? {
    let outScale = CGFloat(spec.pxH) / frameH
    let outputW = spec.pxW
    let outputH = spec.pxH

    // Canvas
    UIGraphicsBeginImageContextWithOptions(CGSize(width: outputW, height: outputH), true, 1.0)
    guard let ctx = UIGraphicsGetCurrentContext() else { return nil }

    ctx.setFillColor(UIColor.white.cgColor)
    ctx.fill(CGRect(origin: .zero, size: CGSize(width: outputW, height: outputH)))

    // CSS transform 재현
    ctx.scaleBy(x: outScale, y: outScale)
    ctx.translateBy(x: frameW / 2 + state.imgOffset.width,
                    y: frameH / 2 + state.imgOffset.height)
    ctx.scaleBy(x: state.imgScale, y: state.imgScale)
    ctx.translateBy(x: -frameW / 2, y: -frameH / 2)

    // object-fit: cover 재현
    let natW = state.natW
    let natH = state.natH
    let coverScale = max(frameW / natW, frameH / natH)
    let dw = natW * coverScale
    let dh = natH * coverScale

    UIImage(cgImage: image.platformCGImage!).draw(
        in: CGRect(x: (frameW - dw) / 2, y: (frameH - dh) / 2, width: dw, height: dh)
    )

    let result = UIGraphicsGetImageFromCurrentImageContext()
    UIGraphicsEndImageContext()
    return result
}
```
