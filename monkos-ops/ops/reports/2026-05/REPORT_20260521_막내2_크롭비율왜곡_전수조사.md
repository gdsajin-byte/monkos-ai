## 발견사항

### 원인 1 (근본 원인): ContentView.swift:960-972 — performFinalCrop() px/mm 비율 불일치

- **코드**:
```swift
// ContentView.swift:960-961
let outputW = spec.pxW   // ← JSONL에서 파싱된 px 가로
let outputH = spec.pxH   // ← JSONL에서 파싱된 px 세로

// ContentView.swift:968-969
let sx = outputW / cw    // cw/ch = Step4 프레임 비율 = widthMM/heightMM
let sy = outputH / ch    // sx ≠ sy if pxW/pxH ≠ widthMM/heightMM
```

- **왜곡 메커니즘**:
  1. Step 4 프레임의 `.aspectRatio`는 `widthMM/heightMM`으로 설정 (ContentView.swift:851)
  2. 따라서 크롭 영역(`cw/ch`)의 비율 = `widthMM/heightMM`
  3. 최종 출력 크기는 `spec.pxW × spec.pxH`
  4. `pxW/pxH ≠ widthMM/heightMM`이면 `sx ≠ sy` → **비균일 스케일링 → 왜곡**

- **중국 비자 구체적 수치**:
  - mm: 33×48 → 비율 0.6875 (11:16)
  - px: 354×472 → 비율 0.7500 (3:4)
  - **9.1% 차이** → sx/sy = 1.091 → 얼굴이 가로로 ~9% 늘어남

- **대조군 — CropEngine.crop() (CropEngine.swift:309-310)**:
  ```swift
  let outputW: CGFloat = 600
  let outputH = outputW / frameAspect  // ← mm 비율에서 직접 계산
  ```
  이 코드는 항상 `sx == sy`를 보장. **왜곡 없음.**
  `performFinalCrop()`만 이 패턴을 따르지 않음.

- **영향 규격**: JSONL 전체 187건 스캔 결과 **4건** 불일치:

| ID | mm | px | mm 비율 | px 비율 | 차이 | 왜곡 방향 |
|----|----|----|---------|---------|------|----------|
| **cn-visa** | 33×48 | 354×472 | 0.6875 | 0.7500 | **9.1%** | 가로 확대 |
| **jp-id** | 35×45 | 480×480 | 0.7778 | 1.0000 | **28.6%** | 가로 극대 확대 |
| **uk-passport** | 35×45 | 600×750 | 0.7778 | 0.8000 | **2.9%** | 가로 소폭 확대 |
| **uk-license** | 35×45 | 600×750 | 0.7778 | 0.8000 | **2.9%** | 가로 소폭 확대 |

- **수정 제안**: `performFinalCrop()`에서 `outputW/outputH`를 JSONL px 값 대신 mm 비율 기반으로 계산 (CropEngine.crop() 패턴 준용). 혹은 `sx == sy` 강제 (uniform scale).

```swift
// 수정안 A: mm 비율 기반 출력
let outputH = spec.pxH
let outputW = outputH * (spec.widthMM / spec.heightMM)

// 수정안 B: 균일 스케일 강제
let uniformScale = min(outputW / cw, outputH / ch)
let sx = uniformScale
let sy = uniformScale
```

### 원인 3 (코드 엣지케이스): ContentView.swift:955-958 — 독립적 크롭 영역 클램핑

- **코드**:
```swift
// ContentView.swift:955-958
let cx = max(0, cropX)
let cy = max(0, cropY)
let cw = min(cropW, natW - cx)   // 가로 독립 클램핑
let ch = min(cropH, natH - cy)   // 세로 독립 클램핑
```

- **왜곡 메커니즘**: 사용자가 극단적으로 축소(zoom out)하여 크롭 영역이 원본 이미지를 초과할 때, 가로/세로가 각각 독립적으로 잘림 → `cw/ch ≠ cropW/cropH` → 비율 왜곡. 정상 사용에서는 autoPlace가 이를 방지하지만, 수동 조작 시 발생 가능.

- **영향 규격**: 모든 규격 (수동 조작 시)

- **수정 제안**: 클램핑 후 비율 보정 추가
```swift
let targetAspect = cropW / cropH
let clampedAspect = cw / ch
if abs(clampedAspect - targetAspect) > 0.001 {
    if cw / ch > targetAspect {
        cw = ch * targetAspect
    } else {
        ch = cw / targetAspect
    }
}
```

## 결론

### 근본 원인

**`performFinalCrop()`가 JSONL의 px 값을 출력 크기로 직접 사용하는데, px 비율이 mm 비율과 다르면 비균일 스케일링(sx ≠ sy)이 발생하여 얼굴이 왜곡된다.**

이는 코드 결함(px/mm 비율 미검증)과 데이터 결함(cn-visa 등 4건 px 오류)의 복합 원인이다.
