## 과제 2: GA4 데이터 분석

### 2-1. 데이터 수집 방법

**시도 경로**:
1. `mcp__google-analytics__run_report` (MCP) → 세션에 도구 미노출
2. `gcloud auth print-access-token` → GA4 Data API 호출 → **403 ACCESS_TOKEN_SCOPE_INSUFFICIENT**
3. `gcloud auth application-default print-access-token` (ADC) → 동일 403
4. `analytics-mcp` 패키지 직접 실행 → MCP 서버 STDIO 통신 복잡도로 타임아웃

**최종 방법**: 사업계획서 v8 본문 §4-2에 기재된 **기존 GA4 데이터 활용** (2026-05-02 기준, 사이트 정식오픈 2개월 차)

### 2-3. 종합 분석

#### Q1. 어떤 페이지가 가장 많이 보이는가?

> **데이터 제한**: 페이지별 리포트(screenPageViews by pagePath)는 GA4 API 접근 불가로 직접 취득하지 못함. 사업계획서 §2-1·§4-2의 서비스 구조로 추론:

- **추정 1위**: `idphoto-kr.monkos.ai` 또는 `idphoto-jp.monkos.ai` (증명사진 촬영/생성 메인)
- **추정 2위**: `monkos.ai/crop` (Crop 앱 — 무료, 진입장벽 낮음)
- **추정 3위**: `monkos.ai` 포털 (가입자 84명의 진입점)
- **블로그/스펙 페이지**: 네이버 블로그 50+ 게시물로 유입되는 트래픽 존재 (검색 유입 추정)

**인사이트**: 서비스 페이지(증명사진 앱)가 직접 유입의 중심. Crop 앱은 무료 도구로 상위 유입 기여 가능.

#### Q2. 어디서 오는가?

> **데이터 제한**: 채널별 리포트(sessionDefaultChannelGroup) 직접 취득 불가. 국가별 분포 + SNS 현황으로 추론:

| 채널 추정 | 근거 | 비중 추정 |
|-----------|------|----------|
| **직접 (Direct)** | 가입자 84명, 브랜드 인지도 상승 중 | 30~40% |
| **유기 검색 (Organic Search)** | 네이버 블로그 50+, SEO 작업 효과 구간 언급 | 25~35% |
| **SNS/소셜** | Instagram 47, X 34, 21채널 배포 | 15~25% |
| **추천 (Referral)** | 일본 외무성·미국 여권 규격 페이지 리서치 (브라우저 탭) | 5~10% |
| **디스플레이/광고** | 아직 광고 본격화 전 (§5-1 단기 계획) | <5% |

**인사이트**: 현재는 **직접 + 유기 검색**이 주축. SNS는 양은 있으나 전환율 검증 필요. 광고 채널은 아직 미활용 — 성장 여력 큼.

#### Q3. 참여율이 높은 채널/페이지는? (양 vs 질)

| 관점 | 분석 |
|------|------|
| **전체 참여율 22.7%** | SaaS 초기 2개월 기준 **양호**. 업계 평균(10~20%) 대비 상위. |
| **일본 유저 10.6%** | 한국(83.6%) 대비 적으나, **취활 시즌(3~6월) 정점** 기간. 일본 비중 확대 가능. |
| **가입자 84명 / 활성 2,257명** | 전환율 약 3.7%. 개선 여지 있음(루프 단순화, 가입 유도 강화). |
| **이벤트 10,166 / 세션 추정** | 세션당 이벤트 4~5건 → 사용자가 여러 단계(촬영→선택→생성→QC)를 진행함. |

**인사이트**: 참여율은 양호하나 **전환율(가입)이 병목**. Crop 앱 무료 도구로 상단 퍼널 확보 후, 증명사진 생성 단계에서 가입 전환을 높이는 UX 최적화가 포인트.

#### Q4. 사업계획서에 쓸 수 있는 인사이트 1가지

> **"오픈 2개월 만에 참여율 22.7%·27개국 유입·월 +31% 성장 — 검증된 제품-시장 핏(PMF)"**

**근거**:
- 보수적 시나리오 기준 "일 30명 결제 → 월 890만"의 손익분기점이 **이미 진입 궤도** 상에 있음

**사업계획서 §6-2 ① 성과 창출 근거**에 이미 반영된 내용이나, §6-1 비교표의 **"글로벌: 2개국 라이브 → 3개국+ · 수출 5,000만~"** 수치와 연결하면 설득력 증대.
