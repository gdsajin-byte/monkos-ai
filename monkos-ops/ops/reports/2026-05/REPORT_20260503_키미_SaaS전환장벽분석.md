## 2. 구조적 원인 5가지

### ① 공적 서류용 → "통과 불확실성"이 최대 리스크

증명사진은 **미용품이 아니다**. 여권·비자·취업 지원서에 붙여서 관리자가 검수하는 공적 서류다.

- 사용자의 손익계산: `₩9,900 + (불합격 시 재촬영 비용 + 시간 + 기회비용)`
- 실제 지불 용의 비용: ₩9,900이 아니라 **₩9,900 + α(리스크 프리미엄)**
- 스튜디오 ₩30,000~50,000이 "보증된 통과"라면, AI ₩9,900은 "실험"이다.

**→ 사용자는 싸다고 느끼지 않는다. 불확실하다고 느낀다.**

### ② 1회성 구매 → 리텐션 없음 → 입소문 없음

- 구독형 SaaS가 아니다. 증명사진은 평균 1~2년에 1회 필요.
- 첫 구매가 만족스러워도 **다음 필요 시점이 너무 멀다**.
- 입소문 효과: "A 써봤는데 괜찮더라"는 전파가 2년 후에야 발생.

**→ 퍼널이 좁다(funnel top narrow). 획득 비용이 전환 가치보다 높아질 수 있다.**

### ③ 완성도가 아니라 "완성된 느낌"이 부족

- 300dpi·ICAO 규격·AI QC는 개발자 관점의 스펙.
- 사용자가 보는 것: "이 사진을 민원실/대사관/인사팀에 제출해도 되는가?"
- **확신을 주는 UI 요소** (정부 인증 마크, 통과 사례 수, 심사관 승인 문구 등)의 부재.

**→ 기술적 완성도 ≠ 지각적 완성도(perceived completeness).**

### ④ 한국 시장의 구조적 위축

- §2-1③, §5-1에 언급: **블라인드 채용 정착화**로 취업사진 수요 자체가 감소.
- 한국 취준생의 증명사진 필요 시점: 여권·비자 신청(비정기) 외에는 급감.
- 일본 취활생 40만+는 실제 타겟이나, **한국 서비스가 일본 사용자에게 도달하는 채널이 없다.**

**→ 타깃 시장(한국)이 쪼그라들고, 타깃 시장(일본)에 닿지 못한다.**

### ⑤ 대안의 존재감

| 대안 | 비용 | 신뢰도 | 접근성 |
|------|------|--------|--------|
| 스튜디오 | ₩30,000~50,000 | 높음 | 중간 |
| 셀카 + 보정앱(무료) | ₩0 | 중간 | 매우 높음 |
| 셀카 + 편의점 출력 | ₩1,000~2,000 | 중간 | 높음 |
| MONKOS AI | ₩9,900 | **낮음(미검증)** | 높음 |

**→ MONKOS의 유일한 차별성(AI 코칭·딥페이크 차단·ICAO 크롭)이 결제 직전의 사용자에게 전달되지 않는다.**

## 3. 사업계획서 영향 평가

### §4-1 "AI 서비스 매출 발생 초기"

- **현실**: 매출이 거의 없다.
- **문서상 해석**: "초기"라는 표현이 사실상 매출 부재를 가린다.
- **리스크**: 심사위원이 "그래서 얼마인가"를 물으면 답할 수 없다.
- **그러나**: 강한소상공인 사업은 **초기 매출보다 사업화 가능성**을 평가한다. §5-3 유닛이코노믹스가 이론적 검증 역할.

### §5-3 유닛이코노믹스 "건당 마진 ₩9,000"

- **현실**: 마진 91%는 맞으나, **매출이 0이면 마진은 의미 없다**.
- **시나리오 3단계**: 보수적 30명/일 = 현재와 90배 이상 차이.
- **해석**: 이것은 "성과 예측"이 아니라 **"규모의 경제 도달 시 수익 구조"**다. 현재와의 갭을 메울 전략이 §5에 없음.

### §6-2 "오픈 2개월 만에 가입자 84명, 월 +31% 성장"

- **가입자 ≠ 결제자**. 84명 중 유료 전환율이 핵심.
- **월 +31% 성장**: 가입자 기준. 매출 기준 성장은 미미.
- **인사이트**: 가입자가 늘어도 결제로 안 넘어간다면 **퍼널 하단(결제 페이지)이 막혀 있다**는 뜻.

### 옵션 A: 무료→유료 퍼널 재설계 (전환율 우선)

| 현재 | 제안 |
|------|------|

| 크레딧 시스템(₩9,900/1회) | **3장 패키지 ₩19,900** (장당 ₩6,600) |
| 결제 후 생성 | **저해상도 미리보기 → 결제 후 고해상도** |

- **근거**: 신뢰를 사야 한다. 첫 경험이 무료면 "통과 불확실성" 리스크가 0이 된다.
- **부작용**: 단기 매출 감소. 그러나 현재 매출이 거의 0이므로 손실이 미미.
- **적용 시점**: D+7일 내. 개발 비용 없음(크레딧 시스템 이미 존재).

### 옵션 B: B2B 우선 전환 (매출 확보 우선)

| 현재 | 제안 |
|------|------|
| B2C 집중 | **B2B(기업 출장 촬영·AI 모델 납품) 비중 확대** |
| 개인 사용자 1건 ₩9,900 | **기업 월 구독 ₩300,000~500,000** |

- **근거**: §1-2에 B2B 항목 존재. §2-3 이해관계자 표에 B2C만 있고 B2B 고객 누락.
- **장점**: 기업은 AI 생성의 "불확실성"을 내부 QA로 흡수 가능. 계약 단위가 크다.
- **사례**: 프랜차이즈 사진관 AI 모델 공급, 쇼핑몰 상세페이지 AI 모델 일괄 생성.

### 옵션 C: 일본 시장 집중 채널 투입 (시장 확장)

| 현재 | 제안 |
|------|------|
| 한·일 URL 분리만 존재 | **일본 취활생 채널(X·LINE·Instagram) 직접 진입** |
| 국내 마케팅 4,000만 집행 | **일본 마케팅 비중 50% 이상** |

- **근거**: 한국은 블라인드 채용으로 취업사진 시장 축소. 일본은 취활시즌(3~6월) 명확.
- **장점**: 일본 사용자는 한국식 미감(깔끔)에 긍정적 인식. 편의점 출력 문화 정착.
- **리스크**: 현지 채널 운영 파트너 없음. §7-2 희망 파트너사 ③번(현지 채널 운영)이 정확히 이것.

## 5. 핵심 인사이트

> **₩9,900의 문제는 가격이 아니라 "신뢰의 공백"이다.**
>
> 사용자는 만원이 아까워서 안 사는 것이 아니라, **이 만원으로 공적 서류가 통과할지 확신이 없어서** 안 산다.
>
> 이 확신을 주려면 3가지 중 하나가 필요하다:
> 1. **무료 체험**으로 직접 통과시켜보게 하거나,
> 2. **정부/기관 인증**으로 보증을 받거나,
> 3. **오프라인 백업**으로 실패 시 안전망을 보여주거나.
>
> v8의 §3-1 "ON/OFF 이중 구조"가 바로 3번이다. 그러나 §2-3 서비스 흐름과 §5-2 자금집행표에서는 이 "오프라인 AS 백업"이 결제 전환 퍼널의 일부로 노출되지 않는다.
>
> **"AI로 촬영 → 불안 → 오프라인에서 확인·인화"가 아니라, "AI로 촬영 → 불안 → 오프라인에서 무료 재촬영 보장"으로 메시지를 바꿔야 한다.**
