### 3-4. 핵심 진단: 광고와 오가닉이 다른 사용자 잡고 있음

```
광고 funnel  : 사진 촬영 / 만들기 / 보정 / AI / 앱  → /(홈) 랜딩 → 결제 의도
오가닉 funnel: 여권사이즈 / 배경색 / 셀카 / 셔츠 / 일본 취업 → /blog/* 랜딩 → 정보 의도
```

작가님 "광고=오가닉 부스터" 프레임 적용 시:
- 현재: 광고 트래픽이 오가닉 신호(브랜드 검색·내부 회유·재방문)에 영향 미미
- 이상: 광고로 들어온 사용자가 콘텐츠 기억 → 다음에 오가닉 검색으로 재방문 → 검색 의도 다양화 → SEO 신호 강화
- 갭: **광고 랜딩이 95% 홈으로 묶여 있어** 콘텐츠 노출 안 됨. 광고→블로그/specs 분기 필요 (트랙 E의 P2와 동일)
