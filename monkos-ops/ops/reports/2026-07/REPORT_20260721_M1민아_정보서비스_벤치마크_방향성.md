## 2. 구조 판독 4

1. **전 카테고리 공통 공백 = 해석층.** 모두 숫자를 팔고 판독은 사용자 몫. 금일 §8("취업 -60% = 블라인드 채용 시기 정합") 같은 산출물은 이 시장 어디서도 상품이 아님. Exploding Topics가 큐레이션 반보로 $39 성립 — 해석의 상품성 방증.
2. **해자는 2종**: (a) 자체 수집 인프라(Ahrefs 크롤러·Similarweb 패널 = 자본 게임) (b) **시계열 적립**(수년치 자체 DB). 우리가 만들 수 있는 건 (b)+수직 도메인 깊이.
3. **원천은 커머디티** — 블랙키위류가 우리와 같은 네이버 API 재가공으로 사업 성립 = 차이는 원천이 아니라 **가공·표시·해석**에서 남.
4. **가격 스펙트럼의 빈 칸**: 원자재 종량($50) < 신호($29~39) < 도구($117~449) < 엔터프라이즈($1,499+) < 컨설팅($수천). **도구와 컨설팅 사이 = "판독 리포트" 자리 공백.**

## 4. 방향성 — "대시보드를 팔지 않는다. 판독을 판다."

1. **포지션**: 범용 도구 경쟁 진입 금지(Ahrefs와 크롤러 전쟁 ✗, 블랙키위와 저가 대시보드 전쟁 ✗). 카테고리 빈 칸인 **수직 시장 판독 리포트** 점유 — "검색 수요의 오픈업"(7/20 기판독) 계승, 단 정확도는 테넌트 0 실측 캘리브레이션으로 차별(오픈업 반면교사).
2. **상품 형태 3종** (L5 = 쌍아 브랜딩 평가 "MONKOS Market Eye 리포트"):
   - ⓐ 정기 브리프 (주간/월간: 계기판 수치 + 판독 — 자사 데일리 브리핑의 상품화)
   - ⓑ 온디맨드 진단 ("미니 감사 자동화 = 진단 모드", 7/20 루커 판독 계승)
   - ⓒ 원데이터는 판매 안 함 (부록 지위) — 원자재 시장은 DataForSEO가 이미 바닥가
3. **해자 구축 = 시간 선점**: L3 크론 가동 즉시 시계열이 쌓임 — 3개월 후 "우리 수직의 추세 DB"는 경쟁사가 소급 불가. **오늘 시작이 곧 해자.**
4. **테넌트 0→1 경로**: 금일 §1~§10을 표준 템플릿(코드) 승격 → 자사 운용 검증 → 동종 수직 사업자(사진관·스튜디오·뷰티)에 납품. 오픈업의 "식당 사장" 타겟 구조의 검색수요판.
5. **가격 가설** (S2~S3 실측 결정): 신호와 도구 사이 구독 + 진단 건당 병행. 근거: 해석 포함 시 $39(신호) 상방·$117(도구) 대비 대체재 아닌 보완재.
