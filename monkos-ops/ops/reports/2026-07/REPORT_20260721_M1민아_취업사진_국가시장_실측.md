## 2. 판정 4군

**1군 — 즉시 실익 (관습 확고 + 볼륨 + 자산 정합)**
- **JP** (92k): 단 채널 = **idphoto-jp 전선** (레지스트리 就活写真 기배정). 履歴書写真 60,500을 idphoto-jp가 실제 무는지 T3 확인이 선결. JP 구글 점유 ~60%·Bing 36% → Bing WMT 병행 필수
- **DE** (62k): de-resume 슬러그 **기보유** — specs 확장 최우선. 유럽 CPC 상급 = 수익화 여지
- **ID** (12k): CPC 0원 무주공산 + id어 라이브 기개방(7/19) + 배경색 관습 = 기술 정합. id-resume 슬러그만 신설하면 즉발
- **KR** (7.8k): 포털 취업 랜딩 신설 (금일 확정 흐름)

**2군 — 중형 (specs 롱테일로 흡수)**
- **TH** (11k): th 언어 지원 여부 확인 필요 (9언어 체계 내 유무) — 신설 비용 대비 판단
- **FR** (11.8k): "avec ou sans photo" 담론 자체가 콘텐츠 앵글 (통념형 CTR 42% 공식 이식 후보)
- **IN** (9.1k)·**BR** (9k): 볼륨 있으나 CPC 최저 = 수익성 후순위. 구글 점유 97%(IN)는 색인 효율 강점

**3군 — 특수**
- **PH**: 취업 카테고리가 아니라 **2x2 picture 22,200**이 진짜 시장 — specs 2x2/필리핀 슬러그로 잡는다 (취업 랜딩 아님)
