## 2. 7/16에 달랐던 것 (기록 확정분)

- **실사용 점화**: ca-passport 무료 4생성+5시도(16:13~38) + 작가님 mx 테스트·T1 생성(12:58~13:04) + "직후 3건 더" + 저녁 실시간 KR 2명 활성 (신호판독 2차).
- **콜드오류 최소 2건 기록**(12:58 mx, 16:15 ca) + 작가님 증언 "오늘 여러번" — 기록 밖 추가 발생.
- **matte 재시도 패치 prod 라이브**(~18:47 선탑승, 19:20 검증 합격): abort당 재시도 1회 = 콜드오류당 런팟 잡 1개 추가 적재.
- prod 13단 배포(00486→00498)·크레딧 E2E 실검증 — 단 이들 검증 트래픽은 SSR·API 위주로 매팅 비경유.

## 3. 콜드오류가 반복되는 구조 (버그 아님, 설계 산물)

7/7 작가님 결정으로 **런팟 단일 집중**(4060·L4 배제, deploy.sh:77 `MATTE_API_URLS`=런팟 단독) + min worker 0 + idleTimeout 90s + 워밍은 **업로드 시점 발화**(페이지 진입 워밍은 7/7 ₩12/구경꾼 절약으로 제거).

→ 유입이 90초 이상 끊긴 뒤 오는 **첫 유저는 구조적으로 콜드스타트**(부트 실측 30s~3분 > 클라이언트 60s 예산 → abort). 테스트기엔 트래픽이 없어 안 보였고, **어제 실유저가 오기 시작하면서 "보이기" 시작한 것**. 재시도 패치가 유저 결말은 살리지만(2/2 실측) 콜드 자체는 남는다.

## 4. 과금 역학 — 코드에서 확인된 누수 2건 + 미해명 잔여

단가 기록: 워커 $0.17~0.25/hr(7/7 생성 시 16GB 티어) ~ $0.58/hr(7/12 민아 기록). 유휴 테일 90s ≈ ₩9/활성화.

**① abort된 runsync 잡은 취소 불가 (matte.js:147~169)**
클라이언트 60s abort 시 응답이 없어 **잡 id를 못 받는다** → 기존 cancel 로직(비완료 응답용)이 못 잡는 사각 → 잡은 서버측에서 계속 실행·과금. 7/7 IN_QUEUE 좀비 5건 실측 때 넣은 cancel의 사각지대. 재시도 패치는 이 미아 잡을 콜드오류당 1개 더 만든다.

**② 워밍 실잡 스핀업 비용**
precheck 통과 + 생성 시점마다 발화(인스턴스별 60s 쿨다운) — 산발 유입에선 스핀업마다 부트+유휴테일이 통째로 과금. 7/8에도 "누적 주범=웜업" 판정 전례.

**③ 미해명 잔여 — 콘솔 실측 필요**
①+②를 다 합쳐도 코드상 사용량으론 $0.5~1.0 수준. **$1.3+를 다 설명하려면 워커 2.2~5.4시간 가동이 필요** — 후보: (a) 고착 잡이 엔드포인트 executionTimeout(기본 600s)까지 도는 반복 (b) 계정 내 다른 소비자(팟 재생성 등 — 7/7 팟 2개·볼륨 삭제 후 기록상 없음) (c) 단가/워커 설정 변동(workersMax 1이 유지 중인지). **런팟 콘솔 Billing 일별 내역이 결정적 증거.**
