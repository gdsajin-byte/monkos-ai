## 1. 결론: SKIP (비연결 권고)

Ubersuggest MCP 연결을 **비권고**한다. 5가지 근거:

1. **한국 시장 사각지대** — Ubersuggest는 Google 데이터만 사용. 네이버(한국 검색 63%)를 커버하지 못함
2. **기존 스택과 중복** — GSC API + GA4 API로 자사 도메인 실측 데이터(추정치 아닌 실제) 이미 확보 중
3. **비용 대비 가치 부족** — 유일한 고유 기능은 경쟁사 분석이나, 데이터 품질이 "방향성 수준"(directional, not precise)
4. **MCP 성숙도 우려** — 공식 가격 페이지에 "API 플랜 미제공" 명시. 37개 도구의 공개 문서 부재
5. **무료 대안이 70%+ 커버** — GSC/GA4/Ads KP/네이버 검색광고 API/PageSpeed/Bing WMT 조합으로 대부분 대체

**경쟁사 분석이 필요해질 경우**: Ubersuggest($12/월, 얕은 데이터) 대신 Ahrefs($99/월, 업계 최고 백링크 데이터) MCP 고려 권장.

## 4. 핵심 한계

### 4-1. 네이버 커버리지 = 0

Ubersuggest는 **Google 데이터만** 사용한다. 한국 검색 시장의 63%를 차지하는 네이버 데이터를 전혀 제공하지 않는다. monkos.ai의 한국 시장 SEO에는 네이버 검색광고 API가 필수이며, Ubersuggest로 대체 불가.

### 4-2. 데이터 정밀도

- 트래픽 추정치: "directional, not precise" (리뷰 다수 일치)
- SEO 난이도: "백링크만 기반한 대략적 추정" — 콘텐츠 품질, 온페이지, 페이지 속도 미반영
- 백링크 인텔리전스: "업계 최고 수준 아님" — Ahrefs/Semrush 대비 열세

### 4-3. MCP 성숙도

- 공식 비공식 MCP 혼재 (공식: `ubersuggest-mcp.neilpatelapi.com`, 비공식: `madebyaris` 역공학)
- 37개 도구 개별 파라미터 문서 미공개
- OAuth 연동 방식에 대한 상세 기술 문서 부재
