# REVIEW: 크롭 제약 최적화 — 확정 구조 검증 (ORDER_20260709 무료티어통합설계 Task 3)

## 결론: 방향 유효, 단 **구조 미완결 — 하향 경계 부재**

확정 구조(변수 1개 + 두상 hard + 헤어탑 soft + 눈·여백=종속)는 올바른 골격이나,
현재 제약만으로는 **"헤어 잘림 허용"이 수학적으로 발동 불능**이고, 볼륨 헤어에서 턱이 프레임 바닥에 붙는다.

## 핵심 검산: 하향 경계가 없으면 무슨 일이 일어나는가

확정 구조의 제약을 그대로 풀면:

- hard "두상 프레임 밖 금지"는 extractTop의 **상한**만 만든다 (피사체가 너무 위로 가는 것 방지)
- soft "헤어탑 위 2~3mm"는 배치를 결정한다: extractTop = hairTop×scale − 2.5mm
- 피사체가 너무 **아래로** 가는 것을 막는 제약이 없다

결과 (KR여권 45mm, 얼굴 33mm, 타겟 여백 2.5mm 기준):

| 헤어볼륨 | 상단(헤어 위) | 하단(턱 아래) | 판정 |
|---------|-------------|-------------|------|
| 0 (대머리) | 2.5mm | 9.5mm | ✅ 정상 |
| 3mm | 2.5mm | 6.5mm | ⚠️ 어깨 경계 |
| 5mm | 2.5mm | 4.5mm | ❌ 어깨 소실 |
| 8mm | 2.5mm | 1.5mm | ❌ 턱이 바닥 직전 |
| 10mm | 2.5mm | −0.5mm | ❌ 턱 잘림 |

즉 헤어는 **영원히 잘리지 않고**(잘릴 계기가 없음), 대신 턱이 바닥으로 내려간다.
"헤어 잘림 = 허용 (규격 우선)"이라는 확정 사항 자체가, 헤어를 잘리게 **만드는** 반대편 제약이 존재할 때만 성립한다.
작가님이 16시대에 지적하신 "하단 5mm는 어깨 노출이 안 된다"는 그 반대편 제약의 존재 근거였다.

## 보완안: 어깨선을 "고정 mm"가 아닌 "실측 hard"로

"하단 여백 = 종속 변수(고정값 아님)" 확정 사항과 충돌하지 않는 해법:

```
hard 제약 ①: 두상(정수리) 프레임 밖 금지        → extractTop ≤ crownY×scale
hard 제약 ②: 어깨선 프레임 안 (실측)            → extractTop ≥ shoulderY×scale − frameH
soft 타겟:   헤어탑 위 2~3mm (잘려도 됨)
결과:        눈 위치, 상단 여백, 하단 여백 — 전부 종속 (고정 mm 없음)
```

- **어깨선 실측**: 매팅 알파 실루엣의 폭 프로파일에서 급확장 지점 = 어깨선. 헤어탑과 동일하게 "실측 or 폴백" 체계 — 고정 계수 제거 철학과 정합. T0 파이프라인에 BiRefNet 매팅이 이미 포함되므로 최종 크롭 시점에 알파가 존재한다.
- **폴백** (매팅 前 fit 프리뷰, 알파 불가 시): 어깨선 ≈ 턱 + 얼굴높이×0.25 추정 (헤어볼륨 0 폴백과 동급의 보수 추정).
- 이 경계가 생기면 비로소 "헤어 잘림"이 발동한다: 볼륨이 예산을 넘으면 어깨 hard에 걸려 프레임이 더 못 내려가고, 초과분 헤어가 잘린다. 눈 위치도 자연 상한이 생긴다 (어깨 폴백 기준 ≈ 45~48%).

**배치식 (F1 clamp 구조 그대로, 경계만 확정)**:
```javascript
const idealTop = hairTopY * scale - hairTargetPx;            // soft: 헤어탑 위 2~3mm
const topMax   = crownY * scale;                             // hard①: 두상 잘림 금지
const topMin   = shoulderY * scale - frameH;                 // hard②: 어깨선 프레임 안 (실측)
extractTop = Math.max(topMin, Math.min(topMax, Math.round(idealTop)));
```

## 검증 포인트 회신 (지시서 §Task 3)

**1. F1 (폴백 방향) — clamp 한 줄 대체**: ✅ 확인. 위 식으로 분기·타이브레이크 소멸, 해 유일.
단 topMin이 정의되어야 clamp가 성립한다 — 상기 보완안 필요조건.

**2. F2 (cropToSpecV2) — 판단: 폐기·단일화**.
배치 산식이 3곳(cropToFrame·cropToSpecV2·fitSpecGeometry)에 병존하는 것이 7월 실사고들의 공통 배경.
권고: 순수 함수 `resolvePlacement(landmarks, spec, {hairTopY, shoulderY})` 1개를 신설하고 3개 함수가 전부 이를 경유.
cropToSpecV2의 눈 44% 앵커·축소 루프(scale×=0.99), cropToFrame의 43% 앵커·축소 루프, EYE_POSITION_RATIO·HAIR_VOLUME_RATIO·BOTTOM_MIN_RATIO 전부 삭제. export 시그니처는 유지(호출측 무변경).

**3. 검산**:
- **한국 여권** (45/33): 대머리 → 상단 2.5mm·눈 42.2%·하단 9.5mm ✅. 볼륨 5mm(어깨 폴백 8mm 기준) → 헤어 0.5mm 잘림·눈 45.6% ✅. 현행 43% 대비 회귀 위험 낮음.
- **반명함** (40/26): 대머리 → 상단 2.5mm·눈 38.8%·하단 11.5mm ✅. 볼륨 여유 큼(슬랙 14mm).
- **미국 여권**: ✅ 제외 확인 — formats.js 미등재 + 정방형(하단 개념 상이) + 눈높이 기준(하단에서 28~35mm) 제약이라 형태가 다름. 이번 범위 제외 타당, 차기 스펙 확장 시 제약식 별도 정의.

## 추가 발견: 32~33mm 동적 조정의 발동 조건 미정의

확정 사항에 "32~33mm 동적 조정 가능"과 "헤어 때문에 얼굴 축소 금지"가 병기되어 있다.
그런데 hard 두 개(두상+어깨)는 33mm에서 항상 동시 만족 가능(33+8 = 41 ≤ 45)이므로, **축소가 필요한 상황은 헤어 수용뿐** — 금지 사유와 동일하다.
권고: **33mm 고정, 32mm 하한은 예약(미사용)으로 명시**. 슬랙이 더 좁은 규격이 추가될 때만 발동.
