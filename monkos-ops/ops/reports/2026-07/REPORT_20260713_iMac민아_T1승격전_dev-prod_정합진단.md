## 1. 지금 dev와 prod는 정확히 무엇이 다른가

**코드 차이 = 커밋 1개뿐이다.** 둘 다 같은 main에서 배포되며, 배포 시점만 다르다.

| | prod (monkos-portal) | dev (monkos-portal-dev) |
|---|---|---|
| 리비전 | 00463-qns (오늘 16:30) | 00115-vx9 (오늘 16:34) |
| 코드 시점 | `b0543b79` (CSS 이스케이프 수정까지) | `24a953cd` (**+T1 표정 프롬프트 원본보존·eyeOpen 완화**) |
| 코드 차이 | — | idphoto-generate.js 표정 2줄 + eyeOpen 게이트 (쌍아 오늘 커밋) |

**env 차이 = 3개뿐이며, 전부 deploy.sh 분기가 자동 관장한다** (승격 시 dev 값이 prod로 새어들 경로 없음 — 실측 대조 완료):

| env | prod | dev | 관장 |
|-----|------|-----|------|
| FREE_QUOTA_BYPASS (무료 횟수 우회) | **0** | 1 | deploy.sh dev 분기만 1 |
| TOSS_CLIENT_KEY | 라이브 (Secret 참조) | 테스트 (plain) | deploy.sh 분기 |
| TOSS_SECRET_KEY | 라이브 v2 (Secret 참조, 오늘 정본화) | TOSS_SECRET_KEY_TEST | deploy.sh 분기 |
| PILOT_T1_RETOUCH / MATTE_SLUGS / CROP_ENGINE_URL | 1 / 빈값(전 슬러그) / 동일 | 동일 | 공통 |

→ **"dev 전용치가 prod에 딸려 나가는" 유형의 사고는 구조적으로 차단돼 있다.** 결제 키는 오늘 Secret Manager 정본 체계로 정리 완료(v2 단일, 테스트키 파기).

## 2. 어제 서버 분리(퍼널 분리)가 바꾼 것과 그 잔재

`3ec70b3e` (7/12): render-specs.js **4,163→1,749줄**. 인라인 CSS/JS를 `specs-funnel.css`·`specs-funnel.js` 정적 파일로 추출, HTML -71%, 캐시버스트 `?v=리비전` 도입.

**이 수술의 잔재 버그 부류 = "JS 문자열 → 정적 파일" 이스케이프 변환 누락.** 실제 2건 발생, 2건 모두 수정 완료:

| 잔재 | 증상 | 수정 |
|------|------|------|
| 정규식 이스케이프 | 업로드 불가 (파일 타입 판정 실패) | `fc8d1cd9` 쌍아 (7/12) |
| CSS content 이스케이프 `\\25BE` 4곳 | 화살표·돋보기가 "\25BE" 텍스트로 노출 (작가님 실캡처) | `b0543b79` 민아 (오늘, funnel 2+base 2 전수) |

**동일 패턴 잔여 스캔 (오늘)**: CSS 3파일 이중 백슬래시 **0건**, dev·prod 라이브 콘솔 에러 **0건**, 업로드 UI·탭·아코디언 렌더 정상 (dev 브라우저 실측). 같은 부류의 알려진 잔여는 없다 — 단 이 부류의 특성상 "실행해야 드러나는" 것이므로 §5 승격 스모크에 실주행 항목을 넣었다.

## 3. T1 흐름의 현재 잠금 상태 (게이트 지도)

T1은 env가 아니라 **코드 속 슬러그 게이트 2곳**이 실제 잠금이다 (PILOT_T1_RETOUCH=1은 이미 양쪽 공통):
