## 2. Firestore 스키마 맵

```

│
├── gallery_items/{auto-id}
│   ├── imageUrl, caption, order, published
│   └── 홈 갤러리 strip용
│
├── board_posts/{auto-id}
│   ├── title, content, author, password
│   ├── isSecret, reply, repliedAt, createdAt

│
├── site_config/layout
```

## 8. 현재 발견된 문제점

### 8-1. 구조적 문제

| 문제 | 영향 | 심각도 |
|------|------|--------|
| 어드민 8페이지가 각자 CSS+JS 인라인 독립 | 공통 로직 공유 불가, 수정 시 8곳 반복 | 높음 |
| blog-edit.html 1,495줄 단일 파일 | 이벤트 충돌 추적 어려움 | 높음 |
| render.js 1,301줄 정규식 replace 기반 SSR | 템플릿 변경 시 정규식 깨짐 위험 | 중 |
| 프레임워크/빌드 도구 없음 | 모듈화, 타입체크, 트리쉐이킹 불가 | 중 |
| 크롤러 중복 방지 불완전 | 데이터 오염 (현재 발생 중) | 높음 |
| 번역 set() 전체 덮어쓰기 | 기존 번역본 viewCount/상태 초기화 | 중 |

### 8-2. 현재 버그 (막내 디버깅 중)

| 버그 | 원인 | 담당 |
|------|------|------|
| 이미지 2중 삽입 | 클릭+드래그 이벤트 동시 발동 | 막내2 |
| 이미지 삭제 시 깨짐 | DOM 직접 조작 → ProseMirror 불일치 | 막내2 |
| 자동번역 덮어쓰기 | set() merge 없음 | 막내2 |
| 중복 포스트 대량 발생 | sourceUrl만 체크 | 막내1 |
| 홈 빈 카드 표출 | thumbnail 없는 포스트 미필터 | 막내1 |
