## 🟠 P2 — 같은 화면에서 숫자가 엇갈림

### 3. 회원 수 이중 집계
`summary.totalUsers = 197` (상단 카드·고객360° 헤더) vs `users.total = 200`. 같은 페이지에서 두 숫자가 공존

### 4. "활성 0" vs 트래픽 차트 모순
상단 카드 `활성 0`인데, 같은 화면 트래픽 차트의 08-26 `activeUsers = 11`. 지표 정의가 다르면 라벨이 달라야 한다

### 5. 트래픽 차트 — 범례 잘림 + 진행 중인 오늘이 급락으로 보임
- `Sessions / New` 범례가 패널 하단 경계에 반쯤 잘림 (컨테이너 높이 부족)
- 우측 끝이 수직 급락 — 오늘(진행 중)을 완결일과 같은 점으로 찍은 결과. 매일 아침 "폭락"으로 오독됨

### 6. 가입 채널 도넛에 범례 없음
`google 80 / kakao 102 / line 18`인데 화면엔 색만 있고 라벨·수치 없음

## 🟡 P3 — 기타

### 9. 에이전트 로그인이 죽어 있음 (작가님 지적 건)
`POST /auth/agent`는 세션 쿠키를 정상 발급하지만(200 + Set-Cookie), `getAdminUser`의 쿠키 경로가 `ADMIN_UIDS.includes(userId)`만 통과시켜 **자기가 발급한 `agent_*` 쿠키를 자기가 거부**한다(실측 401).
→ 그래서 오늘 리뷰도 작가님 수동 로그인에 의존했다. 서명 토큰이라 `agent_` 접두사 허용 한 줄이면 복구

### 10. 포토리뷰 — 이미지 81장 동시 요청
40건 × 2장. `loading=lazy`는 걸려 있으나 그리드가 전부 뷰포트 근처라 실효 낮음(30초 시점 42/81 로드). 서명 URL 1시간 만료 안내는 명시돼 있어 양호

### 11. GCS 저장 경로는 여전히 `specs-visitor`
어제 교정은 Firestore 기록 귀속만 바꿨고, 파일 경로(`idphoto/{gateUserId}/...`)는 그대로다. 무료 트랙 파일이 한 폴더에 섞이는 상태 — 데이터 정합엔 영향 없으나 추후 정리 대상
