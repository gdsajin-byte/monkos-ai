## 1. 판독 3원칙 (모든 콜에 적용)

1. **진짜 단가 = 실수익 ÷ (접근 + 운행 + 복귀 + 대기 총시간)** — 표시 금액으로 판단 금지.
   - 실증: 운정 40,000/4h = 시간당 1만 vs 상일→미사 14,400/20분 = 시간당 4만대.
2. **방향 > 요금.** 같은 27,000원 콜도 착지가 집이면 시간당 3~4배.
3. **살아남은 콜은 이유가 있다.** 순삭 세상에서 몇 초 넘게 보이는 콜 = 시장이 기피 판정한 콜 (방향 함정 확률 높음).

## 4. 플랫폼 메커니즘 (카카오T)

- **실제수익 표시 = 고객가 × 0.8** (수수료 20% 기공제 — 첫날 6건 검산 전부 일치). 고객가 역산 = ÷0.8.
- **최종 입금 ≈ 표시액 × 0.95** (원천세 3.3% + 고용·산재 노무제공자분 ~1.7% 추가 공제. 3.3%는 내년 5월 이월결손금 통산 환급 대상). → 첫 정산 명세 캡처로 요율 확정 예정.
- 대리운전(배상)보험 = 수수료 내 포함. 별도 부담 0.
- **법인 콜** = 기업 계정 호출 — 자격 제한 없음, 정산 확실·취소 적음 = 우량.
- **제휴 콜** = 외부 전화콜 물량 — 노쇼·현장 변수 확률 ↑. 판별은 라벨이 아니라 **결제 표시** (카드|확정 = 안전). 배정 후 고객 전화 1통 = 주소 확정+도착 양해+노쇼 방어 3역.
- **현금 콜**: 수금 주체 = 기사. **고객에게 받는 돈은 수수료 전 전액**(예: 표시 14,400 → 수금 18,000). 수수료는 예치금 차감 — 예치금 잔액 유지 필요. 룰: 내리기 전 수금 / 이체는 입금 확인 후 종료 / 소액권 잔돈 휴대.
- **예약콜** = 순삭 경쟁 우회로. 동향 예약으로 "마지막 콜" 사전 확보 = 초보 정석. 단 출발지 접근 비용 선계산.
- **프로단독배정권 (주 2매)**: 아무 콜에 쓰지 않는다 — **"원정지에서 집 방향 실수익 3만+" 리턴 콜 전용** (실증: 초월읍 48,000 놓침 사례).

## 5. 이동·복귀 인프라

- 픽업 거리별: ~1km 도보 / 1~3km 공유 킥보드·**카카오T바이크**(하남·남양주권 운영) / 3km+ = 이동비·시간을 실수익에서 차감 후 판단 (픽업 거리 = 제3의 판독 변수).
- 공유기기 반납 3규칙: 앱 지도 초록 구역만 / **권역 경계**(하남↔서울) 밖 반납 = 추가요금 / 반납 완료 알림 확인 후 이동.
- **5호선 = 포지션 레일**: 공덕~왕십리~천호~강동~미사 — 콜 사냥지와 퇴근 레일을 겹치는 축. 공덕 = "실패해도 무손실" 포지션 실증.
- 광역버스: M7731(일산→홍대), 잠실환승센터 = 남양주 전역·하남행 허브 (막차 시각 실측 필요).
- **대리 셔틀** (심야 승합, 회당 2~5천): 잠실·강동↔하남·남양주 노선표 확보 = 미결 숙제 1순위 (지역 기사 단톡방·셔틀 앱).
- 자차 소렌토 = 거점 주차용 (콜별 이동 아님). 수급 관점 렌트 유지 필수 (차량 취득 = 탈락 리스크).

## 6. 순삭 대응

- 판독 압축: **목적지 방면 앞 2글자 → 요금** 순. 출발지 무시. 엄지는 수락 위 대기.
- 좋은 콜 생존 시간 0.5~2초 = 정상. 낮·이른 저녁이 경쟁 최악 (콜 희소·기사 유휴).
- 기사 밀집 대기 스팟 이탈 — 수요지(술집 골목) 쪽 100~200m 접근.
- 자동수락·추천콜 조건 기능 확인 (미확인 — 숙제).
- **iOS 핸디캡 가설**: 업계 통설 "콜은 안드" (백그라운드·팝업 제약). 세팅 4 — 앱 전면 고정·화면 상시 켜짐·저전력 OFF·알림 지속형. 구조 해법 = **중고 안드 공기계 10~15만 (투폰)** — 첫 정산 후 2주차 투자 판단. 단 첫날 "콜 없음"은 시간대·이동 중(지하 신호)·iOS 3변수 중첩이라 미판정 — 목요일 정지 관측으로 분리 검증.
