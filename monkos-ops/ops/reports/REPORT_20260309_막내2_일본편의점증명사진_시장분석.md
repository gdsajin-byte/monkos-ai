## 4. 편의점 출력 연동 방식

### 4-1. 2가지 출력 경로

**경로 A: "사진 프린트(写真プリント)" 활용 — L판 ¥30~40**
1. 유저가 앱에서 L판(89×127mm) 레이아웃 이미지를 다운로드
2. 편의점에서 "写真プリント" → L판 선택 → 출력
3. **장점**: 6매 기준 1매당 ¥5~7 (시장 최저가)
4. **조건**: 앱 측에서 L판 레이아웃 합성 필요

**경로 B: 네트워크 프린트 연동 — ¥200~250**
1. 유저가 앱에서 사진 업로드 → 예약번호/QR코드 발급
2. 편의점에서 번호 입력 → 증명사진 전용 출력
3. **장점**: 고품질, 자동 배치, 미하다 보정 적용
4. **조건**: 네트워크 프린트 API 연동 필요

### 4-2. 네트워크 프린트 시스템

| 시스템 | 대상 체인 | 운영사 | API |
|--------|----------|--------|-----|
| **ネットプリント** | 세븐일레븐 | 후지필름 BI | 공개 API 없음 (앱 경유만) |
| **ネットワークプリント** | 로손/패마/미니스톱 | 시샤프 마케팅 재팬 | **Web API 존재 확인** |

### 4-3. netprint 업로드 제한 (세븐일레븐)

| 항목 | 스펙 |
|------|------|
| 포맷 | **JPEG만** (사진용지) |
| 최대 파일 | 10MB (사진 5장 합계) |
| 최소 해상도 | L판: **1,074×1,524px** (150만 화소) |
| 최대 해상도 | 6,144×4,388px |
| 종횡비 | 1:1.3 ~ 1:1.5 |
| 보존 기한 | 등록 후 7일 |

### 4-4. ネットワークプリント QR코드 대응 (2023~)
- 시샤프가 2023년부터 QR코드 대응 추가
- 스마호에 표시된 QR을 마치코피기 리더에 직접 스캔 → 출력
- 회원등록·전용 앱 없이 이용 가능한 신규 서비스도 개시

## 7. 전략 제안

### Phase A: 즉시 가능 (프론트엔드 코드 변경만)

**L판 레이아웃 합성 기능 추가**
- 89×127mm (1,051×1,500px @300dpi) 캔버스 생성
- 4매 배치 (4×3cm) 또는 6매 배치 (3×2.4cm) 자동 레이아웃
- JPEG 0.92로 다운로드
- 유저가 편의점에서 "写真プリント" → L판 → **¥30~40으로 출력**
- **이것만으로 FreeDPE와 동일 포지셔닝 + AI 보정 차별화**

### Phase B: 중기 (UI + 가이드)

- 다운로드 후 "コンビニで印刷する方法" 가이드 화면
- 세븐(かんたんnetprint) / 로손·패마(ネットワークプリント) 분기 안내
- 앱 없이 웹에서 바로 업로드 가능한 링크 제공
- 사이즈 바리에이션 추가 (면허 3.0×2.4cm, 국가자격 6.0×4.0cm)

### Phase C: 장기 (API 연동)

- 시샤프 ネットワークプリント Web API 연동 (API 존재 확인됨)
- 앱 내에서 QR코드 직접 발급 → 편의점 즉시 출력
- ピクチャン과 동일한 원스톱 UX (촬영→AI보정→QR발급→출력)

### 가격 경쟁력 비교

| 수단 | 가격 | 1매당 단가 |
|------|------|-----------|
| 사진관 | ¥2,000~7,000 | ¥2,000+ |
| 스피드 사진기 (Ki-Re-i) | ¥800~1,000 | ¥200~250 |
| ピクチャン + 편의점 | ¥200 | ¥50 |
| **MONKOS + L판 출력 (Phase A)** | **¥30~40** | **¥5~10** |

> **Phase A만으로도 시장 최저가 포지셔닝 가능. AI 보정 품질은 스피드 사진기 이상.**

## 8. 핵심 수치 요약

- 일본 편의점 **54,000점** 이상에서 즉시 출력 가능한 인프라 구축됨
- 편의점 증명사진 전용 출력 **¥200~250** vs L판 사진프린트 **¥30~40**
- 경쟁 앱 ピクチャン **900만 이용자** — 우리의 AI 보정은 차별 우위
- 프린터 입력 해상도 300dpi — **우리 앱 현재 300dpi로 완전 호환**
- L판 레이아웃 합성 1건만 추가하면 **즉시 편의점 출력 대응 가능**
