# 전략회의실 — 업계가 어디까지 왔나 (2026-09-30)

**[2026-09-30 15:54 KST]** iMac/민아 → 작가님

## 0. 결론 (1줄)

**"서로 다른 벤더의 에이전트 N명 + 사람이 한 방에서 실시간 발화"를 규격이나 제품으로 주는 곳은 아직 없다.** 단일 벤더 안(Claude끼리)은 올해 실험 기능으로 열렸고, 벤더 간은 1:1 태스크 위임(A2A)까지만 표준이며, 다자 대화 버스는 직접 세워야 한다. 우리는 02-17부터 작가님이 중계하는 방식으로 회의실을 이미 돌려 왔고, 09-26 실패의 원인은 능력 부재가 아니라 **설정 1줄**이었다.

## 4. 한계 실증 (2026) — 회의실 설계 제약으로 삼을 것

- 토큰: 멀티에이전트 = 단일 채팅의 약 15배(Anthropic 자체 실측) → **소집형**.
- 핸드오프 복리: 95%/단계 → 4단계 86%, 10단계 60% → **의장 1 + 발언 2단 이내**.
- 실패 분류(1,600 트레이스): 설계 44% · 에이전트 간 불일치 32% · 검증 부재 24% → **검수 노드 분리** 유지.
- 인젝션 전파: 6-에이전트 시스템 67% 취약, 에이전트 간 메시지 경유 벡터 4/14, **서명·출처 추적으로 91% 감소** → 메시지에 발신 세션·서명 태그.
