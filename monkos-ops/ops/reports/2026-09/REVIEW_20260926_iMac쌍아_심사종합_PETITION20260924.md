## 3. 합의안 v2 — 조문 전문

### 3-1. ch5 1조 (전문 교체)

```
### 1조: monk.kr 배포 (CF Pages)

1. 자동빌드 OFF. Git push = 코드 저장만. 배포 ≠ push.
   배포 워크플로에 push·schedule·repository_dispatch 트리거를 두지 않는다.

2. 배포 = 승인자 트리거 2경로.
   ① [기본] 버튼 배포 — `.github/workflows/deploy-monk-kr.yml` workflow_dispatch
   ② [예비] `wrangler pages deploy` 수동 실행 — ①이 불능일 때만.
      사용 시 세션 로그에 `[1조 예비경로: 사유]`를 기재한다.

3. 트리거 권한: 작가님. 에이전트는 ch1 7조 2항에 따라 새 사용자 턴으로 도착한
   작가님 승인을 수신한 뒤에만 트리거한다. 같은 응답 블록 안에서 생성한 승인은
   승인이 아니다. 1회 승인 = 1회 트리거(당일 한정). 동일 사유·동일 커밋의 즉시
   재시도는 1승인 내로 본다. 무인 맥락(데몬·크론·Routines) 트리거를 금지한다.
   한계: 에이전트 자격증명은 작가님 계정을 공유하므로 본 항은 트리거 주체를
   기계적으로 검증하지 못한다(ch1 7조 4항 준용). 주체 식별은 4항의 흔적에 의존한다.

4. 흔적 의무.
   - 사유 입력은 `{주체} | {승인 수신 시각} | {사유}` 서식을 따른다. 워크플로가
     서식을 검증하고 불일치 시 배포하지 않는다. 작가님 직접 실행은 승인 시각에 `직접`.
   - 에이전트가 트리거한 경우 세션 로그에 run ID · 배포 커밋 SHA · 승인 수신 시각을 기재한다.
     미기재 트리거는 무승인 배포로 간주한다.

5. 배포 대상.
   - 버튼: 기본은 main HEAD. 선택 입력 `sha` 지정 시 해당 커밋을 배포한다.
   - 예비 경로: 배포 전 `git status MONK_kr/ functions/`가 클린이어야 한다.
     미커밋 상태 배포는 장애 대응에 한하며 세션 로그에 사유를 기재한다.
   - 배포 페이로드 규율(미추적 입력 자산)은 6조 게이트 6을 따른다.

6. 표준 명령(예비 경로): `npx wrangler pages deploy MONK_kr/ --project-name monk-kr --branch main --commit-dirty=true`
   CWD = 프로젝트 루트. 정본 = 루트 `functions/`. `MONK_kr/functions/`는 없다.
   Production = `--branch main`, Preview = 미지정. 이 명령 외의 배포 진입점을 두지 않는다.
   wrangler 버전 정본 = `package.json` 정확 고정(범위 지정 금지). 버튼 배포도 같은 버전을 쓴다. [v2.1 — 막내2 이의 수용]

7. 스모크 판정: 상태코드 단독 판정을 금지한다. CF Pages는 미존재 경로에도 200을
   반환한다(09-26 음성 대조군 3인 실측). 판정은 콘텐츠 어서션으로 한다.
   공개 도메인(monk.kr) 최종 판정은 승인자 기기의 2회 히트로 한다 — 러너는 존 정책상
   403을 받으므로 CI green은 배포 도달의 증거일 뿐 monk.kr 반영의 증거가 아니다.

8. 배포 실패 표기는 미배포의 증거가 아니다. 스모크는 배포 이후에 실행되므로
   run failure 시 스텝 단위로 배포 반영 여부를 확인한 뒤 재배포·롤백을 판단한다.

9. 롤백: 버튼에 직전 정상 커밋 `sha`를 지정해 재배포한다. 불능 시 CF 대시보드에서
   직전 배포로 되돌린다. 롤백 단위 = 커밋.

10. 배포 대기 알림: `MONK_kr/`·`functions/` 변경이 main에 푸시되면 작가님에게
    "배포 대기" 알림을 보낸다(기존 텔레그램 경로). 알림 자체는 배포하지 않는다.

> 근거: 2026-02-20 자동빌드 OFF 결정. 작가님 원문: "깃을 훅킹하는 자동프로덕션이 푸시할때마다 혼돈을 초래하고 있다"
> 개정: 2026-09-__ — PETITION_20260924(민아 청구, 삼권심사 3인 조건부 찬성 → v2 합의, 작가님 승인).
>   발단: M2 푸시분 09-19~09-24 5일 미배포. 설계: M2 푸시 → 작가님 버튼 승인.
> 위반 시: 미검증 코드 프로덕션 도달, 라이브 상태 추적 불가.
> 상위 헌법: 제4조(구속·윤리)
```
