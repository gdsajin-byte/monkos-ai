## 2. 실측 결함

### 🔴 P1 — #1 배경색 교정이 한국어에만 적용됨 (유저 대면, 라이브, 8일 잔존)

**사실**: `d7912a77`은 "specs 14키 배경색 오기재 **170건** 교정"으로 보고됐다. 실제 diff는 `specs-data.json` 170행 치환이며 **전량 한국어 FAQ 문자열**("흰색" → "회색")이다.

**쌍아 독립 실측** (2026-09-02 12:10, `lib/cms/specs-data.json` 직접 파싱):

```
backgroundEn == "Gray" 인 엔트리        : 14
그중 영어 FAQ에 "White"가 남은 엔트리  : 14  (100%)
ko / ja / es FAQ 모순                   : 0
```

대상 14건: `at·ch·de·dk·gr·kz·nz` × `passport·visa`

**실물 확인** (`de-passport` en FAQ 원문):
> "…Passport photo size is 3.5 × 4.5cm. The background must be **White**."
> "A Germany Passport photo requires a **White** background."

같은 엔트리의 필드는 `backgroundEn: "Gray"`다. **필드와 본문이 정면으로 모순**되며, 영어 사용자가 보는 표면은 틀린 값이다.

**판정**: 교정 자체는 정확했고 한국어 표면은 완결됐다. 결함은 **모집단 산정** — 언어 축을 세지 않았다. `background`(ko)만 정본으로 보고 파생 필드(`backgroundEn`·`backgroundJa`·`backgroundEs`)와 각 언어 FAQ를 대조하지 않았다.

**계보**: MEMORY `feedback_single_finding_to_pattern`(단건 적발 → 모집단부터 센다, 08-27 등재)의 **언어 축 변종**이다. 그때는 "1건만 고치고 424건 잔존", 이번은 "1개 언어만 고치고 3개 언어 미점검". 교훈이 등재됐으나 축이 바뀌자 재발했다.

**웹민아 교차 확인**: 09-02 E2E가 §🔴②로 동일 14건을 독립 재적발했다(`/en/specs/passport/de` 2회 히트 = `White` ×2). 두 경로의 숫자가 일치하므로 확정.

**조치**: 롤백 불요. 보정 지시서 발행 — en FAQ 14건 치환 + **동일 파일의 전 언어 축 모순 전수 스캔**(배경색 외 headHeight·validity 등 파생 필드 포함) + 엣지 재배포. 웹민아 승계 ㉗(한국어 표면 번역 누락 81키)와 **같은 파일이므로 1개 지시서로 병합**한다.

### 🟠 P2 — #4 G2 콘텐츠 어서션이 상시 스킵 상태

**사실**: `edge/deploy.sh:39-59`의 콘텐츠 어서션은 구현이 정확하다 — 2회 히트 규칙(1차 버림 → 2차 판정), `+`/`-` 부호 처리, 실패 시 `exit 1`. 코드 자체에 이의 없다.

그러나 판정 입력인 `edge/smoke_assert.txt`가 **존재하지 않는다**(2026-09-02 12:10 실측). 설계상 "파일 없으면 스킵"이므로 오작동은 아니나, 결과적으로 **G2는 만들어진 이후 한 번도 발동하지 않았다.**

**문제**: 스킵 경로에 출력이 없다. 배포자는 "어서션 없이 배포됐다"는 사실을 볼 수 없다. `.claude/rules/references.md` 도구 3요건 중 **§3(실패 가시화 — 무음 강등 금지)** 의 경계에 걸린다. 도구 맵에는 G2가 등재돼 있어 **인지상으로는 작동 중**으로 읽힌다.

**조치**: ① 스킵 시 `"⚠ 콘텐츠 어서션 파일 없음 — 내용 검증 미실시"` 1행 출력 추가 ② `smoke_assert.txt`를 임시 파일이 아니라 **상주 파일**로 승격하고 최소 3행(specs 대표 슬러그 1 + CMS 표면 1 + 부재 어서션 1) 상시 유지. 개정 2(ch5 6조) 통과 시 "무음 강등 금지"가 법률 근거가 된다.
