## 3. 적발한 행정상 문제점

### ① 청구안 `:91` 수치 오류 — §1 참조 (🔴 개정 2 조건부)

### ② 🟢 `-u` 파손 위험은 실측상 거의 없다 — 1b 권고 강등은 **과소 규제**

과제 3 답변. `bash -u` **실행**으로 12본 전수 × 분기(dev/prod/preview/무인자/잘못된 인자) × 빈 환경(`env -i`, CI 러너 모사)을 측정했다.

**확인된 파손: 1본 1건.**

```
apps/idphoto-jp-v079/deploy.sh: line 74: GEMINI_API_KEY: unbound variable
```

- 원인: `:68-72`에서 `.env` 두 곳을 조건부로 읽고, `:74`에서 `[ -z "$GEMINI_API_KEY" ]`로 검사한다. 두 `.env` 모두 없으면 변수가 미정의 상태로 `-z` 테스트에 진입한다.
- **성질**: 이미 **에러 경로**다. `-u` 없이도 `:75`에서 일본어 에러 후 `exit 1`한다. `-u`가 바꾸는 것은 종료 사유 메시지뿐이며, 정상 배포를 깨지 않는다.
- 이 스크립트는 이중 소스의 **비정본 쪽**이다(정본 `monkos_AI/idphoto-jp`에는 같은 코드가 없다).

**지시서는 "최소 2본 지목"을 요구했으나, 실측으로 뒷받침되는 것은 1본뿐이다.** 없는 위험을 채워 넣지 않고 그대로 보고한다. 추가로 검증한 항목:

- `set -e`만 있는 2본에 **pipefail을 승급**해도 파손 0 (`bash -o pipefail` 실행 검증). 두 스크립트의 파이프라인은 G4 게이트의 `git status | head -5` 하나뿐이다.
- 조건부 할당 후보 변수(`SERVICE_NAME`·`MEMORY`·`CPU`·`MAX_INSTANCES` 등)는 전부 **if/elif/else 전수 분기**이거나 ENV 사전 검증으로 차단된다. 잘못된 인자(`staging`) 투입 시 12본 모두 `-u` 유무와 무관하게 exit 1.
- `GEN_DELIVERY_DEADLINE_MS`는 `${...:-115000}` 기본값 보유 → 안전. (1차 스캐너가 오탐한 건으로, 실행 검증으로 배제했다.)

**의견**: 09-01 실행자의 "기존 스크립트 변수 관행상 파손 위험" 보류는 **측정되지 않은 예방조치**였다. 1b를 권고로 두면 "스크립트별 실배포 1회 통과 실측 기록"이라는 **12본치 장부 작업**이 새로 생기는데, 그 장부가 막는 사고는 실측상 1건, 그것도 에러 경로다. 규제 비용이 편익을 넘는다.

**수정 문구 제안**:

> | 1b | **미정의 변수 가드** | `set -u`. **1a와 동시 적용**한다. 단 `apps/idphoto-jp-v079`처럼 조건부 `.env` 로드에 의존하는 스크립트는 `${VAR:-}` 기본값을 부여한 뒤 적용한다. |

### ③ 🔴 게이트 4 미충족 7본 중 4본은 "health URL을 **출력만** 한다"

`idphoto-kr`·`idphoto-jp`·`studio`·`image-pro`(및 쌍둥이 `monk_imagen4`)는 배포 말미에 다음을 출력한다.

```bash
echo -e "헬스 체크: ${YELLOW}${SERVICE_URL}/health${NC}"
```

**호출하지 않는다.** `grep curl`이 히트하는 `image-pro:119`도 실체는 사용법 안내 `echo`다 — `live-verify.md` §3 "1건 ≠ 존재"의 교과서적 사례이며, 예비심사가 사후스모크를 3/12로 센 것도 이 착시일 가능성이 높다.

**긍정적 함의**: 엔드포인트는 이미 있고 URL도 이미 조립돼 있다. `echo` → `curl -fsS --max-time 20 "${SERVICE_URL}/health" || exit 1` 치환 5행이면 게이트 4가 충족된다. 이행 난도는 낮다.

### ④ 🔴 `portal/deploy.sh` 드리프트 게이트는 **무음 강등**한다 — 개정 2 자기 조항 위반

`portal/deploy.sh:266-285` 구조:

```bash
if [ -f "$EDGE_MANIFEST" ]; then
  SSG_REV=$(grep -o '"gitRev": ...' "$EDGE_MANIFEST" | sed ...)
  if [ -n "$SSG_REV" ] && git cat-file -e "${SSG_REV}^{commit}" 2>/dev/null; then
    ... 판정 ...
  fi                      # ← else 없음
else
  echo "⚠️ 매니페스트 없음"   # ← 이쪽만 경고가 있다
fi
```

격리 재현 실측 (4조건):

| 조건 | 출력 | 종료 |
|---|---|---|
| A 매니페스트 부재 (대조군) | ⚠️ 경고 정상 출력 | 0 |
| B `gitRev`가 로컬에 없는 커밋 | **무출력** | 0 |
| C `gitRev` 빈 문자열 | **무출력** | 0 |
| D `gitRev` 필드 자체 없음 | **무출력** | **1** |
