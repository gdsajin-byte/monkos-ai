## 사용법 가이드

### showEventCard(title, amount, subtitle, tag)
```javascript
// 카카오 로그인 30c 적립 시
showEventCard('카카오 로그인 완료', '+30 Cr', '가입 이벤트', 'EVENT');

// 텔레그램 가입 40c 적립 시
showEventCard('텔레그램 채널 가입', '+40 Cr', '다운로드가 활성화됩니다', 'EVENT');

// 100c 미션 완료 시
showEventCard('텔레그램 미션 완료', '+100 Cr', '캡쳐 전송 + 동의서 서명 완료', 'EVENT');
```
- 4.5초 후 DOM 자동 제거
- `window.showEventCard()`로 어디서든 호출 가능
- `.event-container`가 있는 페이지에서만 동작 (현재 result.html)

### showThankYou(amount, message)
```javascript
// 100c 미션 완료 축하
showThankYou('+100 Cr', '텔레그램 미션을 완료했습니다');

// 결제 완료 축하
showThankYou('+300 Cr', '크레딧이 충전되었습니다');
```
- 5초 후 DOM 자동 제거
- 전체 화면 오버레이 (z-index: 10000)
- `window.showThankYou()`로 어디서든 호출 가능
