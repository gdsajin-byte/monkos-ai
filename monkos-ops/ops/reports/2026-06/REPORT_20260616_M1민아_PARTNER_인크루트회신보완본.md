# Part B — 핵심 취지 / 내부 협상 설계 (외부 발송 절대 금지)

> 본 섹션은 **우리 측 협상 카드·가격 바닥선·전략 의도**다. 인크루트에 노출되면 협상력 전체가 붕괴한다. 미팅 브리핑·계약 체크리스트 용도로만 사용.

## B-1. 회신의 단 하나의 목적 — "완전 떠보기(숫자 0)"

- 이 회신은 **숫자를 일절 노출하지 않는다.** 단가·MG·티어·포함건수 전부 미노출.
- 이유: 인크루트가 우리 단가를 ₩500~1,000으로 보는지, 매출 30% 쉐어(≈건당 ₩2,000+)로 보는지 **우리는 모른다.** 먼저 숫자를 까면 그게 더 높든 낮든 손해.
- 인크루트가 먼저 "CPA 매출 쉐어"를 제안했다 = 그들은 **% 프레임**으로 생각 중. 우리가 ₩1,000 도매를 먼저 던지면 그들이 줄 생각이던 금액의 절반을 자기 손으로 후려치는 사고가 될 수 있다.
- 따라서 회신은 **그들의 패(정산모델/판매가/용도/예상물량/독점범위)를 먼저 끌어내는 5개 역질문**으로만 구성.

## B-2. 내부 가격 바닥선 (협상 카드 — 절대 비노출)

| 항목 | 내부 기준 |
|------|----------|
| 생성 원가 | **건당 약 ₩200** (자동생성, 인력 0) |
| 도매 기준 단가 | **건당 ₩1,000** (마진 80%, 트래픽 우선 전략가) |
| MG 기준점 | **1만 건/월 = ₩1,000만** (= 독점의 가격표) |
| 초과분 | 건당 ₩1,000 동일 (종량) |
| 폴백 티어 | S(1,000건/₩3,000) · M(5,000건/₩1,400) · L(1만건/₩1,000) — 인크루트가 부담스러워하면 단계 하향 카드 |
| 프리미엄 AS | **몽크사진관 별도 ₩5,000** (도매와 분리) |

→ ₩1,000은 **트래픽을 사는 전략가**다(수익 극대화 아님). 인크루트가 더 높게 생각했다면 협상 중 위로 올린다.

## B-3. 독점 = MG (작가님 확정 방침)

- **독점은 공짜로 안 준다. 독점의 가격표 = MG(최소 물량 보장).**
- 독점 원하면 → MG 보장 전제. MG 지불 의향이 곧 독점 진정성의 리트머스.
- 범위: **채용 플랫폼 카테고리 한정.** monkos.ai 본진 직판 + 비자/여권 등 타 SKU는 독점 대상 제외(별도 서버 완전 분리).
- 독점 강도 ↔ MG 수준 연동: 막는 경쟁사 범위가 넓을수록 우리 기회비용↑ → MG↑.
- ※ 어제(6/15) 전략분석은 "독점 기본 거절"이었으나, **작가님 최신 방침은 "조건부 독점 적극 검토(MG 전제)"** — 최신 방침 우선.

## B-4. AS 2레이어 분리 (회신서 "다 무료"로 오해되지 않게 사수)

```
레이어 1: 자동 생성 (인력 0)  → 인크루트 도매 ₩1,000. 기본 재생성 N회 포함 가능
레이어 2: 프리미엄 AS (인력 O) → "맘에 들 때까지" 사람 보정 = 몽크사진관 별도 ₩5,000
```
- 회신 4번에서 "기본 CS·재생성은 흡수 / 고급 보정은 옵션"으로 **여지를 남겼다.** "모든 AS 무료 흡수"로 약속하면 나중에 ₩5,000 업셀이 말 바꾸기가 된다.
- 계약서에 **AS 범위 상한**(재생성 N회, CS 채널 한정, "맘에 들 때까지" 무제한 금지) 명시 필수.

## B-5. ⚠️ 엔진 리스크 면책 — 회신엔 뺐으나 계약 단계 필수

정액 = 우리의 안정 공급 의무. 나노바나나(Gemini 이미지) 정책 차단 시 우리가 독박. **계약서 필수 3조항:**
1. 제3자(AI 엔진 제공사) 정책 변경·중단은 불가항력 → MONKOS 단독 배상책임 아님
2. 베스트에포트 SLA (100% 가용성 보장 아님)
3. 대안 엔진 전환 유예기간 허용
- 헤지: 멀티엔진 추상화(나노바나나 + 대안 1개) 사전 구축 — 쌍아 설계 영역.

## B-6. PG(고객접점) 통찰 — 독점 시 되사야 할 마케팅 무기

- 독점 + [대안 A] 결제 양도 = **고객접점(PG)을 인크루트가 독점** → 우리 직접 마케팅·리텐션·본진 유입 무기 상실.
- 독점의 대가 = MG(금전) + **브랜드 노출 사수**(코브랜딩) + **AS 업셀 채널**(몽크사진관) + 데이터 공유.
- 비독점이면 우리가 마케팅 무기 전부 보유 → 독점은 그 무기들을 협상으로 되사는 비싼 선택.

## B-7. 시장 포지셔닝 — commodity와 다른 리그

- 시장 2분절: **저가 대량(만원 20컷=복불복, AS 없음)** vs **프리미엄 보장(우리: 정체성보존+AS)**.
- 도매 ₩2,000도 인크루트엔 안 비쌈(소매 ₩7,000 대비 마진 71%). "비싸 보이게" 만드는 건 우리가 낮은 앵커를 흘릴 때뿐 → **회신에서 "파격적 단가" 표현 삭제**(저가 앵커 누수 차단).
- 앵커 반박: "20장 복불복 vs 보장된 1장 — 채용 플랫폼 신뢰도엔 답이 분명".

## B-8. 무료 미끼(loss leader) 시나리오 — 인크루트의 진짜 용도일 수 있음

- 인크루트가 증명사진을 **회원 무료 혜택**으로 뿌릴 경우: 소매 매출 0 → 매출 쉐어 불가 → **정액 MG+종량이 유일 정산** = 우리 모델과 정합.
- 무료 = 트래픽 폭발 + AS 업셀 퍼널 + 본진 인지 → 우리에게 유리. MG는 인크루트 마케팅비로 치환(매출 343억의 0.35%, 부담 없음).
- 안전장치: 무료 어뷰징(1인 다회) → 멱등/1인1회 제한 필수.
- → 회신 5번 "용도(유료/무료)" 떠보기로 이 시나리오 여부를 확인한다.

## B-9. 인맥 메모 (대외비)

- 인크루트 대표 ↔ 작가님 = **약한 연결**(지인=공인중개사, "동네·통화 사이"). 직접 라인 아님, 과대평가 금물.
- 활용: **백채널·신뢰 윤활유로만.** 실무(신솔민 팀장) 패싱 절대 금지(한국 비즈니스 치명).
- 6/25 **지인 만남**(인크루트 미팅 아님)에서 인맥 양해·사실확인 → 미팅 전 라인 정비.
- 미팅 라포 단계에서 "발견되는" 톤으로 가볍게. "납품" 단정 금지, "인연 있다고 들었다" 수준.

## B-10. 떠보기 5개 항목 ↔ 우리 결정 매핑

| 회신 역질문 | 우리가 알아내려는 것 |
|------------|-------------------|
| 정산 모델 (쉐어 vs 정액) | 인크루트 프레임 — % 사고면 우리 ₩1,000 위로 협상 |
| 회원 판매가 포지셔닝 | 소매가 → 우리 도매 적정선 |
| **용도 (유료/무료)** | 무료면 정액 MG가 유일 → 우리 모델 확정 |
| 독점 경쟁사 범위 | 기회비용 → MG 산정 입력값 |
| 예상 월 거래량 | 고정(MG) vs 변동 판가름 + 티어 선택 유도 |
