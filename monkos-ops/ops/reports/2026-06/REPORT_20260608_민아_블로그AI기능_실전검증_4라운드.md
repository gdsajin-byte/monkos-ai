## 4. 핵심 교훈 — 출력 토큰 한계 과소 (2회 반복)

오늘 **같은 근본 원인이 두 기능에서** 나왔다:

| 기능 | maxOutputTokens | 증상 |
|------|-----------------|------|
| EN 자동번역 (translate.js) | 8192 | 장문 EN 번역 JSON truncation → 번역 누락 ([별도 REPORT](REPORT_20260608_민아_블로그EN번역누락_근본원인.md)) |
| SEO 제안 (ai.js suggest) | 256 | 한국어 메타 JSON truncation → `"{"` |

> **공통 패턴**: JSON 강제 출력 + 한국어/장문 + thinking 토큰 → 출력 한계 초과 → 미완결 JSON.
> **표준화 권고**: Gemini로 JSON/번역/메타 등 *구조화 장문*을 생성할 때 `maxOutputTokens`는 예상 출력의 **3~4배 + thinking 여유**로 책정. `thinkingConfig: {thinkingBudget: 0}` 검토. 신규 기능 작성 시 체크리스트화.
