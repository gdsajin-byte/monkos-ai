## 배경

철창이(Claude Web)는 샌드박스 환경으로 프로젝트 로컬 파일에 직접 접근 불가. 시스템 타임스탬프도 부정확. 현재 작가님이 철창이 세션에서 생성된 공문/지시서를 **수동으로** 바탕화면 `~/Desktop/철창이/` 폴더에 저장하는 방식.

이 수동 과정을 자동화하여, 철창이 ↔ 프로젝트 간 파일 전달 통로를 구축한다.

## 작업 1: 철창이 채널 폴더 구축

프로젝트 내 철창이 채널 생성.

**경로**: `monkos-ops/teams/cheolchang/`

```
monkos-ops/teams/cheolchang/
├── inbox/          # 철창이 → 우리 (공문/보고서 수거)
├── outbox/         # 우리 → 철창이 (지시/참조 전달 대기)
├── reference/      # 읽기전용 참조자료
└── README.md       # 채널 설명
```

README.md 내용:
```markdown
# cheolchang — 철창이(Claude Web) 채널

| 폴더 | 방향 | 용도 |
|------|------|------|
| inbox/ | 철창이→우리 | 바탕화면에서 수거한 공문/보고서 |
| outbox/ | 우리→철창이 | 철창이에게 전달할 참조/피드백 |
| reference/ | 읽기전용 | 참고자료 |

통신: AppleScript Folder Action (~/Desktop/철창이/ 감시)
특이사항: 철창이는 Claude Web 샌드박스. 로컬 직접 접근 불가. 작가님이 브라우저에서 파일 저장 → 바탕화면 폴더로 수거.
```

## 작업 2: AppleScript Folder Action 연구 + 구현

`~/Desktop/철창이/` 폴더에 파일이 추가되면 자동으로 프로젝트 inbox로 복사하는 메커니즘.

### 조사 항목
1. **macOS Folder Actions**: `~/Library/Scripts/Folder Action Scripts/` 또는 Automator
2. **방식 비교**: Folder Action vs launchd WatchPaths vs FSEvents
3. **기존 참조**: `~/MONKOS_ADS/` 광고 시스템이 launchd WatchPaths 사용 중 (com.monkos.ads-sync.plist)

### 구현 요구사항
- `~/Desktop/철창이/`에 `.md` 파일 추가 감지
- 감지 시 → `monkos-ops/teams/cheolchang/inbox/`로 복사 (원본 유지)
- 복사 완료 로그 기록
- (선택) 반대 방향: outbox → `~/Desktop/철창이/` 복사도 연구

### 산출물

| 순번 | 산출물 | 경로 |
|------|--------|------|
| ① | Folder Action 스크립트 | `monkos-ops/scripts/cheolchang_watcher.sh` 또는 `.scpt` |
| ② | (launchd 방식 시) plist | `monkos-ops/scripts/com.monkos.cheolchang-sync.plist` |
| ③ | 방식 비교 메모 | `monkos-ops/teams/cheolchang/reference/통로_연구.md` |

> **주의**: plist를 `~/Library/LaunchAgents/`에 등록하는 것은 보고만 하고 **작가님 승인 후 실행**.
> 스크립트 작성 + 수동 테스트까지만 이 지시서 범위.
