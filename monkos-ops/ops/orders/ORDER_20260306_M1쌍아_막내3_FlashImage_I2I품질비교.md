> **[2026-03-06 06:02 KST] M1/쌍아 → 막내3**

## 배경

T2I 더미 테스트에서 `gemini-3.1-flash-image-preview`가 API 호환·해상도 동일 확인됨. 그러나 I2I 정체성 보존 품질(헌법 9조: 90%+ 보존)은 실제 사진으로만 판단 가능.

GCS에 있는 증명사진 샘플로 I2I 비교 테스트 실시.

## 테스트 방법

### 1. 프롬프트

현행 `buildPromptV5()` (server.js)와 동일한 프롬프트를 사용. 규격은 **여권(passport)** 기준.

server.js의 `buildPromptV5()` 로직을 참고하여 동일한 프롬프트 텍스트를 구성할 것.

### 2. 각 이미지 × 각 모델 = 총 8회 호출

| # | 입력 이미지 | 모델 |
|---|-----------|------|
| 1 | 이력서 샘플 | Pro (현행) |
| 2 | 이력서 샘플 | Flash (신규) |
| 3 | 학생증 샘플 | Pro (현행) |
| 4 | 학생증 샘플 | Flash (신규) |
| 5 | 컬러증명 샘플 | Pro (현행) |
| 6 | 컬러증명 샘플 | Flash (신규) |
| 7 | 여권 샘플 | Pro (현행) |
| 8 | 여권 샘플 | Flash (신규) |

### 3. 비교 항목

각 쌍(Pro vs Flash)에 대해:

| 항목 | 판정 기준 |
|------|----------|
| 정체성 보존 | 얼굴 특징(눈·코·입·얼굴형) 동일성 — 헌법 9조 90%+ |
| 프롬프트 준수 | 배경색·의상·구도 지시 이행 |
| 해상도 | 출력 크기 비교 |
| 파일 크기 | bytes 비교 (PNG vs JPEG 차이 포함) |
| 출력 포맷 | MIME type 확인 |
| 세부 품질 | 피부 텍스처, 머리카락, 경계선 자연스러움 |
| 안경·악세서리 보존 | 입력에 안경 있으면 출력에도 유지되는지 |
