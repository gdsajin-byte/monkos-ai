## 작업 내용

### 1. `lib/auth.js` — OAuth 인증 (~570줄)

본인 보고서의 인증 API 8개 엔드포인트를 이관:
- Google OAuth (콜백, 토큰 검증)
- 카카오 OAuth (콜백, 토큰 검증, scope)
- LINE OAuth (콜백, 토큰 검증)
- 유저 생성/조회 (Firestore users)
- 토큰 발급/검증

```javascript
const { db, log, ... } = require('./shared/config');
// auth 핸들러들
module.exports = { handleGoogleAuth, handleKakaoAuth, handleLineAuth, verifyToken, ... };
```

### 2. `lib/credits.js` — 크레딧 관리

본인 보고서의 크레딧 API 7개 엔드포인트:
- 잔액 조회/차감/충전
- 무료 생성 제한
- 크레딧 트랜잭션 로깅

### 3. `lib/payments.js` — 결제 처리

본인 보고서의 결제 API 7개 엔드포인트:
- 토스페이먼츠 (요청→승인→크레딧 충전)
- Lemon Squeezy (일본 결제)
- 결제 웹훅
- 직접결제(비로그인)

### 4. `lib/events.js` — 이벤트/게이트

본인 보고서의 이벤트 API 4개 엔드포인트:
- 텔레그램 게이트 코드 생성/검증
- 카카오 채널 추가 검증
- SNS 미션 완료
- 이벤트 중복 방지

**주의**: credits.js에서 events.js를 호출하는 구조 (본인 보고서 권고대로 위임 호출)
