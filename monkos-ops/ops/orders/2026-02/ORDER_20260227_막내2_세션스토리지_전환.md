# 로그인 상태 sessionStorage 전환

> **[2026-02-27 09:45 KST] M1/쌍아 → 막내2**
> 현재 로그인 정보가 localStorage에 영구 저장되어 세션 종료 후에도 로그인 유지.
> 재방문 시 GateModule(70c 이벤트)이 표시되지 않는 구조적 문제.
> `monkos_user` + `monkos_token`을 sessionStorage로 전환하여 세션 종료 시 자동 로그아웃.

---

## 변경 원칙

- `monkos_user`, `monkos_token` → **sessionStorage** (세션 종료 시 삭제)
- `monkos_free_gen` 등 기타 localStorage 항목 → **변경하지 않음**
- API: `localStorage.setItem` → `sessionStorage.setItem` (동일 API, 문자열 치환)
