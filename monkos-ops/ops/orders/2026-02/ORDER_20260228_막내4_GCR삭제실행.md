## 실행 순서

### Step 1. 삭제 전 이미지 목록 아카이브

```bash
# 삭제 대상 이미지 목록을 기록 (기술회고용)
mkdir -p monkos-ops/tech/archive/gcr_legacy/

# 레거시 레포
gcloud container images list-tags gcr.io/monkos/idphoto-kr --format="table(digest,tags,timestamp)" \
  > monkos-ops/tech/archive/gcr_legacy/idphoto-kr_images_before_cleanup.txt

gcloud container images list-tags gcr.io/monkos/portal --format="table(digest,tags,timestamp)" \
  > monkos-ops/tech/archive/gcr_legacy/portal_images_before_cleanup.txt

# 운영 레포 (정리 대상 포함 전체)
gcloud container images list-tags gcr.io/monkos/monkos-idphoto-kr --format="table(digest,tags,timestamp)" \
  > monkos-ops/tech/archive/gcr_legacy/monkos-idphoto-kr_all_images.txt

gcloud container images list-tags gcr.io/monkos/monkos-portal --format="table(digest,tags,timestamp)" \
  > monkos-ops/tech/archive/gcr_legacy/monkos-portal_all_images.txt

gcloud container images list-tags gcr.io/monkos/monkos-idphoto-jp --format="table(digest,tags,timestamp)" \
  > monkos-ops/tech/archive/gcr_legacy/monkos-idphoto-jp_all_images.txt
```

### Step 2. 레거시 레포 전체 삭제

```bash
# idphoto-kr 구 레포 (42개)
gcloud container images list-tags gcr.io/monkos/idphoto-kr --format="get(digest)" | \
  while read digest; do
    gcloud container images delete "gcr.io/monkos/idphoto-kr@$digest" --quiet --force-delete-tags
  done

# portal 구 레포 (3개)
gcloud container images list-tags gcr.io/monkos/portal --format="get(digest)" | \
  while read digest; do
    gcloud container images delete "gcr.io/monkos/portal@$digest" --quiet --force-delete-tags
  done
```

```bash
  done

    gcloud container images delete "gcr.io/monkos/monkos-idphoto-jp@$digest" --quiet --force-delete-tags
```

### Step 4. 삭제 결과 검증

```bash
# 각 레포별 남은 이미지 수 확인
echo "=== 레거시 레포 ==="
gcloud container images list-tags gcr.io/monkos/idphoto-kr 2>&1
gcloud container images list-tags gcr.io/monkos/portal 2>&1

echo "=== 운영 레포 ==="
gcloud container images list-tags gcr.io/monkos/monkos-idphoto-kr --format="table(digest,tags,timestamp)" | wc -l
```
