## 작업 내용

### 1단계: 현재 상태 파악 (코드 수정 없이 조사만)

```bash
# 1-1. iphone_capture 폴더 존재 여부 + 내부 파일 목록
ls -la /mnt/c/Users/smuse73/developer/monk_project/iphone_capture/

# 1-2. upload_server.js (원본) 존재 확인
cat /mnt/c/Users/smuse73/developer/monk_project/iphone_capture/upload_server.js 2>/dev/null | head -5

# 1-3. upload_server_local.js (4060 전용 복사본) 존재 확인
cat /mnt/c/Users/smuse73/developer/monk_project/iphone_capture/upload_server_local.js 2>/dev/null | head -5

# 1-4. SSL 인증서 존재 확인
ls -la /mnt/c/Users/smuse73/developer/monk_project/iphone_capture/*.pem

# 1-5. 서버 프로세스 실행 여부
ps aux | grep upload_server
# 또는 tmux 세션 확인
tmux list-sessions 2>/dev/null

# 1-6. 포트 9000 리스닝 여부
ss -tlnp | grep 9000
# 또는
lsof -i :9000
```

### 2단계: 서버 기동 (미실행 시)

1-5, 1-6에서 서버가 안 돌고 있으면:

```bash
# tmux 세션에서 서버 구동 (백그라운드 유지)
tmux new -s upload
node /mnt/c/Users/smuse73/developer/monk_project/iphone_capture/upload_server_local.js
# Ctrl+B, D 로 분리
```

만약 `upload_server_local.js`가 없으면 → 원본 `upload_server.js`가 있는지 확인 후, 지시서(`TASK_20260218_4060_upload_server.md`)의 4단계 절차대로 복사+수정.

만약 `upload_server.js` 원본 자체가 없으면 → **중단, 보고** (에스컬레이션).

### 3단계: 접속 테스트

```bash
# 로컬에서 HTTPS 응답 확인
curl -sk https://localhost:9000
# 기대: HTML 업로드 페이지 응답

# Tailscale IP로도 확인
curl -sk https://100.118.31.62:9000
```

- 200 응답 + HTML 페이지가 오면 성공
- 연결 거부/타임아웃이면 원인 파악 (포트, 방화벽, SSL 등)

### 4단계: 업로드 기능 테스트

curl로 테스트 파일을 업로드해본다:

```bash
# 테스트 이미지 생성
echo "test" > /tmp/test_upload.txt

# 업로드 엔드포인트 테스트 (upload_server.js의 POST 경로에 맞춰서)
# 서버 코드를 먼저 확인하여 정확한 엔드포인트/필드명 파악 후 실행
curl -sk -X POST https://localhost:9000/upload \
  -F "file=@/tmp/test_upload.txt"
```

- 업로드 성공 → `iphone_capture/` 폴더에 파일 저장 확인
- 실패 → 에러 메시지 보고
