# [2026-02-26 18:32 KST] iMac/쌍아 → 막내3

## 지시: MONKOS Cr(크립) 코인 모션 시스템 구현

### 배경

철창이(웹 Claude, 디자인/기획)가 Cr 코인 모션 시스템을 설계하고 작가님이 승인했다. 4단계 모션 강도 체계로, 크레딧 관련 모든 UI에 골드 메탈릭 코인 모션을 적용한다.

**원본 설계 문서**: 작가님이 세션에서 전달한 `MONKOS_Cr_Motion_System_Directive.md` (전체 CSS/HTML/JS 명세 포함)
**동작 데모**: 작가님이 세션에서 전달한 `monkos_cr_system.html` (브라우저에서 열어 확인)

### 모션 4단계 체계

| 레벨 | 모션 타입 | 적용 위치 | 강도 | 코인 크기 |
|------|-----------|-----------|------|----------|
| ① | Idle Spin Shimmer | 헤더 잔액 코인 | 최소 | 28×28px |
| ② | 3D Flip + Card Slide | 이벤트 적립/미션 알림 | 중간 | 52×52px |
| ③ | Feed Card Stack | 라이브 피드 (소셜 프루프) | 중간 | 38×38px |
| ④ | Big Flip + Burst | 결제 완료 / 큰 이벤트 | 최대 | 100×100px |

### 작업 항목

#### P0-1. 디자인 토큰 CSS 파일 생성

**신규 파일**: `monkos_AI/idphoto-kr/public/cr-coin.css`

원본 directive의 **섹션 2. 공통 디자인 토큰** 전체를 CSS 파일로 생성:
- `:root` CSS 변수 (골드 팔레트, 그라디언트, 그림자, 타이밍)
- `.cr-coin-face` 공통 구조
- `.cr-symbol` 텍스트 스타일

**폰트 로드**: Space Mono (Google Fonts)
```html
<link href="https://fonts.googleapis.com/css2?family=Space+Mono:wght@700&display=swap" rel="stylesheet">
```
→ `result.html`, `thankyou.html` 등 관련 HTML의 `<head>`에 추가

**CSS 파일 로드**:
```html
<link rel="stylesheet" href="cr-coin.css">
```
→ `result.html`, `thankyou.html` 등에 추가

#### P0-2. ① 헤더 Idle Spin Shimmer — 크레딧 배지 교체

**대상**: `result.html`, `thankyou.html`의 기존 `.credit-badge`

**현재**:
```html
<div class="credit-badge" id="creditBadge">
    <span>💎</span>
    <span data-bind="user.credits">0</span>c
</div>
```

**변경**:
```html
<div class="header-balance" id="creditBadge" data-show="user.id">
  <div class="header-coin-wrap">
    <div class="header-sparkle"></div>
    <div class="header-sparkle"></div>
    <div class="header-coin">
      <div class="header-coin-face">
        <div class="header-shimmer"></div>
        <span class="cr-sym">Cr</span>
      </div>
    </div>
  </div>
  <span class="balance-amount" data-bind="user.credits">0</span>
  <span class="balance-unit">Cr</span>
</div>
```

**CSS**: 원본 directive **섹션 3 ①** 전체 (`.header-coin-wrap`, `.header-coin`, 애니메이션 등)

**기존 `.credit-badge` CSS**: `app.css`에서 제거하지 말고, 신규 `.header-balance` 스타일과 공존 가능하도록. 기존 코드가 `.credit-badge`를 참조하는 곳이 있으면 `id="creditBadge"`를 유지하여 JS 호환.

**shared.js 호환**: `creditBadge` 클릭 핸들러가 id 기반이므로, `id="creditBadge"` 유지하면 기존 JS 그대로 동작.

#### P1-1. ② 이벤트 카드 + 3D Flip — 알림 컴포넌트

**신규 함수**: `showEventCard(title, amount, subtitle, tag)`

원본 directive **섹션 3 ②** 전체 구현:
- 카드 슬라이드인 + 코인 3D 플립(Cr↔M) + 파티클 방출
- 4.5초 후 DOM 자동 제거
- `animation: infinite` 사용 금지 — JS 트리거 기반 1회 실행

**이벤트 카드 컨테이너** 추가 (result.html):
```html
<div class="event-container" style="position:fixed;bottom:20px;left:50%;transform:translateX(-50%);z-index:9998;width:380px;max-width:calc(100vw-32px);"></div>
```

**호출 예시** (막내2가 게이트/미션 코드에서 사용):
```javascript
// 카카오 로그인 30c 적립 시
showEventCard('카카오 로그인 완료', '+30 Cr', '가입 이벤트', 'EVENT');

// 텔레그램 가입 40c 적립 시
showEventCard('텔레그램 채널 가입', '+40 Cr', '다운로드가 활성화됩니다', 'EVENT');

// 100c 미션 완료 시
showEventCard('텔레그램 미션 완료', '+100 Cr', '캡쳐 전송 + 동의서 서명 완료', 'EVENT');
```

#### P1-2. ④ Thank You — Big Flip + Burst 축하 컴포넌트

**신규 함수**: `showThankYou(amount, message)`

원본 directive **섹션 3 ④** 전체 구현:
- 배경 글로우 확장 + 코인 720° 더블 플립 + 8방향 광선 버스트
- "Thank You!" + 금액 텍스트
- 5초 후 DOM 자동 제거
- 전체 화면 오버레이

**호출 예시**:
```javascript
// 100c 미션 완료 시 (이벤트 카드 후 빅 축하)
showThankYou('+100 Cr', '텔레그램 미션을 완료했습니다');

// 결제 완료 시
showThankYou('+300 Cr', '크레딧이 충전되었습니다');
```

### ⚠️ 준수 조항

- **코인 디자인은 철창이 원본 그대로** 구현. 색상/크기/타이밍 임의 변경 금지
- 헌법 6조: API 키 하드코딩 금지
- `animation: infinite`는 **헤더 Idle(①)에만** 사용. 나머지(②③④)는 JS 트리거 기반 1회 실행
- `prefers-reduced-motion` 미디어 쿼리 반드시 포함 (접근성)
- 기존 `.credit-badge` CSS 삭제 금지 — 점진 교체
- 게이트 팝업/미션 UI 로직은 건드리지 않음 (막내2 영역)
