크레딧 게이트 시스템(2026-02-25 배포)의 마케팅 퍼널 논리, 사용자 동선, 이벤트 구조의 정합성을 검수한다. 작가님이 "정합성과 마케팅구조상 논리구조, 리다이렉트 등 섬세하게" 조사를 지시.

- 합산 시 170c = 2장 이상 무료 → **"첫 1장 무료" 설계 의도 파괴**

### 검수 항목 (6건)

#### 1. 사용자 동선 (User Journey) 전수 추적

**5가지 시나리오별 실제 화면 흐름을 코드에서 추출**:

| 시나리오 | 설명 |
|---------|------|
| A | 비로그인 → 첫 촬영 → 생성 → 프리뷰 → 다운로드 시도 → 게이트 팝업 |
| B | 게이트 팝업 → 카카오 로그인(30c) → SNS 공유(40c) → 다운로드 성공 |
| C | 게이트 팝업 → 바로 결제(₩10,150) → 다운로드 성공 |
| D | 로그인 사용자(잔액 부족) → 충전 모달 → 결제 → 다운로드 |
| E | 로그인 사용자(잔액 충분) → 생성 → 다운로드 → **프리뷰 화면에서 SNS 100c 이벤트 카드 노출** |

**각 시나리오에서**:
- 어떤 화면이 어떤 순서로 나타나는가
- 리다이렉트/팝업/모달의 동선이 자연스러운가
- 사용자가 "뒤로 가기"를 누르면 어떻게 되는가
- 이벤트 카드가 노출되는 조건은 무엇인가 (로그인 여부? 다운로드 완료 여부?)

#### 2. 이벤트 크레딧 경제학 분석

**현재 크레딧 수지 시뮬레이션**:

| 경로 | 수입(크레딧) | 지출(생성+다운로드) | 잔액 | 가능 행동 |
|------|------------|-------------------|------|----------|
| 가입만 | 30c | - | 30c | ? |
| 가입 + SNS/동의 | 70c | - | 70c | ? |
| 가입 + SNS/동의 + SNS 100c | 170c | - | 170c | ? |
| 가입 + 텔레그램 + SNS 100c | ???c | - | ???c | ? |

**검증 질문**:
- 사용자가 이벤트를 모두 수령하면 **실제 몇 장을 무료로** 받을 수 있는가?
- "첫 1장 무료" 설계 의도와 실제 코드가 일치하는가?
- 이벤트 조건이 적절한가 (SNS 공유를 실제로 했는지 검증하는가? 아니면 버튼만 누르면 지급?)

#### 3. 게이트 팝업 ↔ 프리뷰 이벤트 카드 역할 충돌 분석

- 게이트 팝업: "가입하면 첫 1장 무료" — **진입 장벽 해소 목적**
- 프리뷰 이벤트 카드: "SNS 공유하면 100c" — **확산 유도 목적**
- **두 이벤트의 타겟이 같은 사용자인가, 다른 사용자인가?**
- 시간순으로: 게이트 팝업(미가입) → 가입 → 프리뷰(이미 가입) → 100c 이벤트 → 합산 과잉
- **설계서의 원래 의도와 현재 코드의 괴리** 분석

#### 4. 충전 모달 가격 정책 합리성

| 옵션 | 금액 | 크레딧 | 단가(원/c) | 할인율 |
|------|------|--------|-----------|--------|
| 1장 구매 | ₩11,600 | 80c | 145 | 0% |
| 10c | ₩1,450 | 10c | 145 | 0% |
| 100c | ₩13,050 | 100c | 130.5 | 10% |
| 300c | ₩34,800 | 300c | 116 | 20% |
| 500c | ₩50,750 | 500c | 101.5 | 30% |

**검증**:
- 비로그인 직접결제 ₩10,150 = 80c (단가 ₩126.9) vs 로그인 1장 구매 ₩11,600 = 80c (단가 ₩145) — **비로그인이 더 싸다?** 모순 아닌지
- 게이트 팝업에서 "바로 결제 ₩10,150"이 왜 로그인 후 "1장 구매 ₩11,600"보다 싼지 근거
- 1장 = 생성(10c) + 다운로드(70c) = 80c — 이 산식이 모든 UI에서 일관되는지

#### 5. SNS 공유 검증 로직 진위 확인

- "텔레그램으로 100c 받기" 버튼을 누르면 **실제로 공유했는지 검증하는가?**
- 텔레그램 링크만 열고 바로 돌아와도 크레딧이 지급되는가?
- `sns_share` vs `share-bonus` — 두 이벤트가 별개 시스템이면 둘 다 수령 가능한가?
- 악용 시나리오: 가입 → 30c → SNS 40c → SNS 100c → 170c로 2장+ 무료

#### 6. UI 텍스트 ↔ 실제 동작 불일치

- 게이트 팝업 텍스트: "카카오 로그인 30c 증정" — 실제 지급이 `signup_bonus`인지 `login_bonus`인지
- "SNS 공유 또는 동의 +40c" — "또는"의 택1이 사용자에게 명확히 전달되는지
- 프리뷰 화면 "고화질 다운로드 (70c)" — 잔액 부족 시 동작
- "다시 찍기" 버튼 — 크레딧 차감 없이 재촬영 가능한지? 생성은 10c인데?
