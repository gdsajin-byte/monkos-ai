### 2-2. 점검 항목

#### A. `store.user` null safety 전수 점검

`store.user`가 `{ id: null, ... }` 형태인 상황(비로그인)에서 모든 접근이 안전한지 확인.

점검 패턴:
```
store.user.id
store.user.credits
store.user.email
store.user.name
store.user.avatar
store.user?.id  (이건 안전)
```

**이미 알려진 위험 지점:**
- `result.js:165` — `!store.user.id` (수정됨이나 재확인)
- `result.js:218` — `userId: store.user.id`
- `result.js:335` — `!store.user.id`
- `result.js:343` — `store.user.credits`
- `result.js:441` — `!!store.user.id`
- `result.js:500` — `!store.user.id`
- `result.js:541` — `!store.user.id`
- `shared.js:261` — `downloadGate()` 내 `!store.user.id`
- 기타 modules/*.js 전체

#### B. localStorage/sessionStorage 잔존 데이터 점검

쿠키 단일화 전에 사용하던 키가 아직 코드에 남아있거나, 브라우저에 잔존하여 동작에 영향을 주는 경우:

| 키 | 이전 용도 | 현재 상태 | 영향 |
|----|----------|----------|------|
| `monkos_user` (sessionStorage) | 사용자 정보 저장 | 코드에서 제거됨 | 잔존 데이터 무해 |
| `monkos_token` (sessionStorage) | 인증 토큰 | 코드에서 제거됨 | 잔존 데이터 무해 |
| `monkos_user` (localStorage) | credits.html에서 사용 | 코드에서 제거됨 | 잔존 데이터 무해 |
| **`monkos_free_gen`** (localStorage) | 비로그인 1회 제한 | **코드에 남아있음** | **⚠️ 영구 차단 문제** |
| `monkos_generated` (sessionStorage) | 생성 이미지 캐시 | 코드에 남아있음 | 점검 필요 |
| `monkos_credits_from` (sessionStorage) | credits 리턴 URL | 코드에 남아있음 | 점검 필요 |

#### C. 비로그인 E2E 전체 흐름 코드 추적

아래 흐름의 **모든 분기점**에서 비로그인 시 정상 동작하는지 코드 레벨로 추적:

```
1. 메인(index.html) 진입 → 쿠키 인증 실패 → 비로그인 UI
2. 촬영(camera.html) → 촬영 완료 → sessionStorage에 캡처 저장
3. 분석(result.html) → showOriginal() → 캡처 로드 → 버튼 표시
4. "이 사진으로 생성" 클릭 → confirmAndGenerate()
   4a. store.user.id 체크 → null → 비로그인 분기
   4b. monkos_free_gen 체크 → 1회 제한
   4c. pipe.run('precheck') → 사전분석
   4d. pipe.run('generate') → userId:null → 서버 [FREE-GEN]
   4e. 생성 완료 → 워터마크 → 비교컷 표시
5. "고화질 다운로드" 클릭 → downloadResult()
   5a. 비로그인 → GateModule.show() → 로그인/결제 게이트
6. 로그아웃 → 쿠키 삭제 → UI 초기화
```

각 단계에서 에러 발생 가능성, 조용히 return하는 경우, UI 미갱신 등 모두 기록.

#### D. `monkos_free_gen` 비로그인 1회 제한 로직 개선

현재 문제:
- localStorage에 **영구 저장** → 브라우저 데이터 삭제 전까지 재시도 불가
- 계정 삭제/리셋 시에도 클라이언트 데이터는 남음

개선 방향 (택1, 근거와 함께 선택):
- **A) 만료 시간 추가**: 24시간 후 자동 만료 → `JSON.stringify({ ts: Date.now(), expires: Date.now() + 86400000 })`
- **B) sessionStorage로 이동**: 탭 닫으면 초기화
- **C) 로그인 시 삭제**: 로그인 성공 → `localStorage.removeItem('monkos_free_gen')`
