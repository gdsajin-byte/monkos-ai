## 수정

### Task 1: scope=plusfriends 제거

**파일**: `monkos_AI/portal/server.js` (line 860)

**현재:**
```javascript
const authUrl = `https://kauth.kakao.com/oauth/authorize?client_id=${KAKAO_REST_API_KEY}&redirect_uri=${encodeURIComponent(effectiveRedirect)}&response_type=code&scope=plusfriends&state=${state}`;
```

**변경:**
```javascript
const authUrl = `https://kauth.kakao.com/oauth/authorize?client_id=${KAKAO_REST_API_KEY}&redirect_uri=${encodeURIComponent(effectiveRedirect)}&response_type=code&state=${state}`;
```

`&scope=plusfriends` 부분만 제거. 나머지 파라미터는 그대로 유지.

**이것이 전부다. 다른 코드는 수정하지 않는다.**
