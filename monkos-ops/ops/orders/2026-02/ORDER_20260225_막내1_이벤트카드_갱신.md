# 지시서: 이벤트 카드 갱신 (크레딧 게이트 반영)

## 배경

크레딧 게이트 시스템 구현(868f806, fdc30de, 704e6c7)으로 이벤트 체계가 변경됨. 기존 이벤트 카드 내용이 구체계를 반영하고 있어 갱신 필요.

### 구체계 → 신체계

| 항목 | 구체계 | 신체계 |
|------|--------|--------|
| 가입 보너스 | 80c (Google 로그인) | 30c (카카오 로그인) |
| 텔레그램 보너스 | 30c (친구 추가) | 폐지 → 게이트 팝업 통합 |
| SNS 공유 보너스 | 100c (캡처→텔레그램 전송) | 40c (텔레그램 공유, 다운로드 게이트에서 처리) |
| 전후사진 동의 | 없음 | 40c (SNS 공유와 택1) |
| 1장 무료 경로 | 가입 80c로 자동 달성 | 가입 30c + 이벤트 40c = 70c |

## 작업 2: 수령처(thankyou) 이벤트 섹션

**파일**: `monkos_AI/idphoto-kr/public/thankyou.html`
**위치**: line 136~147 (SNS 공유 이벤트)

### 현재:
```html
<p class="ty-share-title">🎁 SNS 공유하고 100크레딧 받기!</p>

    <div class="ty-step"><span class="step-num">1</span> 이 화면을 캡처하세요 📸</div>

    <span class="tg-icon">✈️</span> 텔레그램으로 100c 받기
</a>
```
