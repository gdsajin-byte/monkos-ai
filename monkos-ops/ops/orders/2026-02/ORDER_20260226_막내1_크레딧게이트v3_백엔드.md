# [2026-02-26 21:49 KST] M1/쌍아 → 막내1

## 지시: 크레딧 게이트 v3 백엔드 — 멀티채널 + P0 수정

막내3(내부 점검) + 막내4(플랫폼 비교) 리서치 완료. 작가님 확정 방향:

- **워터마크 프리뷰**: 미션 이미지 원본 대신 워터마크 버전 활용

### 작업 항목

#### P0-1. 동의서 미서명 시 미션 이미지 수신 거부

**현황** (막내3 발견): `server.js` 봇 이미지 수신 시 `msg.photo` 있으면 바로 `missionImageReceived: true` — 동의서 체크 없음

**수정**:
- 봇 이미지 수신 핸들러에서 해당 userId의 `missionConsentSigned` 확인
- 미서명 상태면 이미지 저장하지 않고 봇 메시지로 안내: "SNS 활용 동의서를 먼저 서명해주세요"
- 서명 완료 상태면 기존 플로우 유지

**대상 파일**: `monkos_AI/portal/server.js` (봇 이미지 수신 핸들러 부근)

#### P0-2. 동의서 내용 보강

**현황** (막내3 발견): "마케팅 목적으로 결과 사진을 SNS에 게시" — 플랫폼/기간/철회 불명시

**수정**: `/api/consent/sns` 저장 시 동의 내역에 아래 필드 추가
```json
{
  "consentVersion": "v2",
  "platforms": ["instagram", "telegram_channel", "x", "youtube"],
  "duration": "동의 철회 시까지",
  "withdrawMethod": "고객센터 문의 (텔레그램 @monkos_support_bot)",
  "imageType": "watermark_preview"
}
```

#### P1-1. 카카오 채널 검증 API 신규

**핵심**: 카카오 로그인 scope에 `plusfriends` 추가 → 채널 친구추가 relation 검증

**신규 엔드포인트**: `POST /api/credits/event` — type: `kakao_channel_add`

**플로우**:
1. 프론트에서 `{type: 'kakao_channel_add', userId}` 전송
2. 서버: 해당 userId의 카카오 액세스 토큰으로 `GET https://kapi.kakao.com/v2/api/talk/channels` 호출
3. 응답에서 MONKOS 채널의 `relation` 확인
4. `relation === 'ADDED'` → 40c 지급 + `events.kakao_channel_add = true`
5. `relation !== 'ADDED'` → 에러 응답 (프론트에서 followChannel 유도)

**카카오 로그인 수정**:
- authorize URL의 scope에 `plusfriends` 추가
- 콜백에서 받은 토큰을 사용자 문서에 저장 (이미 하고 있다면 확인)

**환경변수 확인 필요**:
- 카카오 채널 ID (콘솔에서 확인) — 변수명 제안: `KAKAO_CHANNEL_ID`
- 비즈앱 전환 완료 여부

#### P1-2. 워터마크 프리뷰 활용 로직

**맥락**: 미션 이미지를 마케팅 소재로 활용 시, 원본 대신 워터마크 프리뷰 사용

**수정**:
- 봇 이미지 수신 시 `missionImageFileId`에 저장하되, 마케팅 활용 플래그 `imageType: 'user_upload'` 기록
- 향후 마케팅 소재 추출 시 서버에서 워터마크 오버레이 적용 (현 단계에서는 플래그만)
- 또는 프론트에서 `generateWatermarkPreview()` 결과를 base64로 봇에 전송하는 방식 (막내2와 협의)

#### P1-3. 게이트 크레딧 이벤트 타입 확장

**현황**: `EVENT_CREDITS`에 `telegram_join: 40` 존재

**추가**:
```javascript
EVENT_CREDITS: {
  signup_bonus: 30,
  telegram_join: 40,
  kakao_channel_add: 40,  // 신규
  mission_complete: 100
}
```

- `kakao_channel_add`와 `telegram_join`은 **택1** — 둘 다 수령 불가
- 검증 로직: `events.kakao_channel_add || events.telegram_join` 중 하나라도 true면 Phase 2 완료
