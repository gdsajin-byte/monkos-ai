# 지시서: monk.kr ↔ monkos.ai API 교차 오염 전수 점검

> **[2026-02-28 18:47 KST] iMac/쌍아 → 막내4**

---

## 배경 — 무엇이 일어났는가

### 발단
monk.kr에서 정상 운영되던 MONKOS Image Pro가 갑자기 500 에러를 뱉기 시작했다.

### 직접 원인
프론트엔드 빌드 파일 `index-v6.js`에서 API 엔드포인트가 변경됨:
```
v1~v5: Gf="/api"         → CF Workers 직접 호출 (정상)
v6:    Gf="https://image.monkos.ai"  → Cloud Run 교차 호출 (오류)
```
monk.kr의 프론트가 아직 세팅이 완료되지 않은 image.monkos.ai를 호출하면서 Vertex AI `INVALID_ARGUMENT` 에러 발생.

### 내재 원인 (핵심)
"monk.kr 정적화 → monkos.ai 엔진 이관" 설계 논의 과정에서 **두 시스템의 경계가 혼동**됐다:
- 설계 의도: 향후 monk.kr이 필요할 때 monkos.ai API를 호출할 수 있다
- 오해: monk.kr의 기존 기능까지 monkos.ai 라인으로 전환해야 한다
- 결과: v6 빌드에서 CF Workers 호출을 image.monkos.ai로 교체 → 프로덕션 장애

이 오해가 v6 한 곳에만 있는 것이 아니라 **Phase 1~3 이관 작업 전반에 걸쳐 침투했을 가능성**이 있다.

---

## 대원칙 — 작가님 직접 선언

> **monk.kr과 monkos.ai는 완전히 분리 체계로 간다.**
> **서로 교차 호출은 절대 금한다.**
> (헌법 10조 프록시 금지 원칙과 동일 맥락)

| 시스템 | 인프라 | API 호출 | 용도 |
|--------|--------|---------|------|
| monk.kr | CF Pages + CF Workers | CF Workers 직접 | 내부용 풀팩 |
| monkos.ai | Cloud Run | Cloud Run 자체 | 외부용 (향후) |

- monk.kr → monkos.ai 호출 ❌
- monkos.ai → monk.kr 호출 ❌
- 향후 API 연동 필요 시 **작가님 별도 설계 지시** 후에만

## 작업 1: 교차 오염 전수 점검

### 1-1. monk.kr 프론트엔드 전수 스캔

monk.kr 전체에서 `monkos.ai` 도메인을 호출하는 코드를 찾아라.

```bash
grep -rn "monkos.ai" MONK_kr/ --include="*.js" --include="*.html" --include="*.json" | grep -v node_modules
```

**각 발견건에 대해:**
- 파일명 + 라인번호
- 원래 어떤 CF Workers 경로였어야 하는지
- 현재 잘못된 값
- 영향 범위 (어떤 기능이 깨지는지)

### 1-2. monkos.ai 백엔드에서 monk.kr 의존 확인

image.monkos.ai(Cloud Run) 코드에서 monk.kr을 참조하는 부분이 있는지 확인.

```bash
grep -rn "monk.kr" apps/monk_imagen4/ --include="*.js" --include="*.json" | grep -v node_modules
```

### 1-3. 인프라 설정 교차 확인

- CF Workers 라우트가 정상인지 (monk.kr/api/* → Workers)
- Cloud Run 서비스가 독립적인지 (monk.kr 의존 없음)
- DNS 레코드에 교차 참조 없는지
