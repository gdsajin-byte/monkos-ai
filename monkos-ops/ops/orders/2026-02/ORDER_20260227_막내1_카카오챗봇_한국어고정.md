# 카카오 챗봇 한국어 고정

> **[2026-02-27 15:12 KST] iMac/쌍아 → 막내1**
> 카카오 챗봇이 일본어로 응답하는 문제. kakao 채널은 한국어 100%이므로 고정.

---

## 원인

- `CHANNEL_CONFIG.kakao.systemPrompt`가 `SYSTEM_PROMPT`(웹용 다국어)를 사용
- 웹 프롬프트는 사용자 언어를 감지하여 해당 언어로 응답
- 카카오 요청에 lang 정보가 없어 기본값(일본어)로 빠짐

## 수정

`lib/chat-engine.js`의 `CHANNEL_CONFIG.kakao` 수정:

```javascript
kakao: {
  systemPrompt: SYSTEM_PROMPT + '\n\n[중요] 이 채널은 카카오톡입니다. 반드시 한국어로만 응답하세요.',
  temperature: 0.7,
  maxOutputTokens: 300,
  historyMap: chatHistories,
  historyTTL: 30 * 60 * 1000,
  maxHistory: 20,
  logCollection: 'kakao_conversations',
},
```
