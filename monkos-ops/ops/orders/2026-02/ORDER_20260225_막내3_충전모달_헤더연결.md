**파일**: `monkos_AI/idphoto-kr/public/shared.js`

### UI

```

│         크레딧 충전                  │
│                                     │
│  ┌─────────────────────────────┐   │
│  │  📸 1장 구매    ₩11,600     │   │  ← 강조 (추천)
│  │  생성+다운로드 1회분          │   │

└─────────────────────────────────────┘
```

### 동작

1. 옵션 선택 (라디오 버튼, 기본값: 1장 구매)
2. "토스페이먼츠로 결제" 클릭 → `buyCreditsKR(amount, credits)` 호출
3. 결제 완료 → 기존 토스 결제 플로우 (리다이렉트 → confirm → 크레딧 적립)

### 매핑 테이블 (모달 내부)

```javascript
const CHARGE_OPTIONS = [

```

### 스타일

- 기존 OAuth 모달과 동일한 오버레이 + 중앙 카드 패턴
- 디자인 시스템 준수 (docs/infrastructure/guides/DESIGN_SYSTEM.md)
- 모바일 퍼스트 (하단 시트)
- 1장 구매 옵션은 시각적 강조 (배경색, 테두리, "추천" 뱃지)
