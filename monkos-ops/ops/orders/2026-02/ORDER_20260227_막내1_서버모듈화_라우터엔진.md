## 분석 범위 (막내1 담당)

### 1. 서버 부트스트랩 (L1~210)
- 임포트 목록 전수 파악 (어떤 모듈이 어떤 기능에 쓰이는지)
- 환경변수 전수 목록 + 각 변수가 어디서 참조되는지 맵핑
- 초기화 순서 의존성 (어떤 것이 먼저 로드돼야 하는지)

### 2. 라우터 구조 (전체)
- 모든 라우트 엔드포인트 전수 목록 (URL, 메서드, 줄 번호, 기능 설명)
- 라우트 간 의존성 (공유 미들웨어, 인증 체크 등)
- 라우트를 기능별로 그룹핑한 분류표

### 3. 공통 유틸리티
- 여러 기능에서 공유하는 함수 전수 목록 (함수명, 줄 번호, 호출처)
- Firestore 초기화, GCS 클라이언트, Gemini AI 초기화 등 싱글톤 객체
- 로깅 함수, 에러 핸들링 패턴

### 4. 정적 파일 서빙 + 서버 시작 (L2837~2981)
- 정적 파일 라우팅 로직
- 서버 리스닝, 헬스체크

### 5. 모듈 분리 계획 제안
- server.js에 남아야 하는 것 (라우터 + 서버 시작 + 공통 초기화)
- lib/로 빼야 하는 것 (기능별 핸들러)
- 공유 객체(db, ai, gcs 등)를 각 모듈에 어떻게 전달할 것인지 (DI? 싱글톤 export?)
