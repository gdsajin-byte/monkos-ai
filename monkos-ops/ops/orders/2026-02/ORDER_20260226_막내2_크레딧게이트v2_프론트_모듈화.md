### 모듈 설계 원칙

1. **각 모듈이 자기 HTML을 자체 생성** — result.html에는 `<div id="gate-mount"></div>` 같은 마운트 포인트만
2. **모듈 간 통신은 store + 콜백** — 직접 참조 금지
3. **각 모듈은 init/destroy 패턴** — 마운트/언마운트 가능
4. **CSS는 모듈 내부 또는 cr-coin.css 참조** — result.html/app.css에 모듈 전용 스타일 넣지 않음

### 작업 항목

#### P0-1. result.html 마운트 포인트 정리

기존 인라인 HTML (게이트 팝업, 이벤트 카드, 미션 UI 등) **전부 제거**.
마운트 포인트만 남김:

```html
<!-- 게이트 팝업 마운트 -->
<div id="gate-mount"></div>

<!-- 다운로드 후 영역 마운트 -->
<div id="post-download-mount"></div>

<!-- 충전 모달 마운트 -->
<div id="charge-mount"></div>

<!-- 이벤트 알림 마운트 (fixed position) -->
<div id="event-notification-mount"></div>
```

#### P0-2. result.js 슬림화

result.js에서 게이트/미션/충전 로직을 **전부 제거**하고, 모듈 import + 호출만 남김:

```javascript
// result.js — 메인 흐름만
import { GateModule } from './modules/gate.js';
import { MissionModule } from './modules/mission.js';
import { ChargeModule } from './modules/charge.js';
import { PremiumModule } from './modules/premium.js';

// 다운로드 버튼 클릭 시
function onDownloadClick() {
  if (!store.user.id) {
    GateModule.show({
      onComplete: () => doDownload()  // 70c 달성 시 콜백
    });
    return;
  }
  if (store.user.credits < 70) {
    ChargeModule.show();
    return;
  }
  doDownload();
}

// 다운로드 완료 후
function onDownloadComplete() {
  PremiumModule.mount('#post-download-mount');   // ① 프리미엄 옵션 (위)
  MissionModule.mount('#post-download-mount');    // ② 100c 미션 (아래)
  ChargeModule.mountInline('#post-download-mount'); // ③ 충전 (최하단)
}
```

**주의**: ES module (`import/export`) 사용. result.html의 script 태그에 `type="module"` 추가.

#### P0-3. 생성 이미지 sessionStorage 보관 (P0 버그 수정)

이건 result.js 메인 흐름에 속하므로 모듈이 아닌 result.js에서 직접 처리:

```javascript
// 생성 완료 시
store.generated = genResult.image;
try { sessionStorage.setItem('monkos_generated', genResult.image); } catch(e) {}

// 페이지 초기화 시
if (!store.generated && sessionStorage.getItem('monkos_generated')) {
  store.generated = sessionStorage.getItem('monkos_generated');
}
```

#### P1-1. modules/gate.js — 게이트 팝업 모듈

```javascript
// gate.js
export const GateModule = {
  show(options) { /* 게이트 팝업 생성 + 마운트 */ },
  close() { /* 팝업 제거 */ },
  // 내부:
  // - Phase 1: 카카오 로그인 → 30c
  // - Phase 2: 텔레그램 가입 → 40c (딥링크 + 서버 검증)
  // - 바로 결제 옵션
  // - 70c 달성 시 options.onComplete() 콜백
};
```

**Phase 2 상세** (텔레그램 가입):
1. "텔레그램 채널 가입하기" 버튼 → `POST /api/telegram/gate-code` → 딥링크 오픈
2. "가입 확인하기" 버튼 → `POST /api/credits/event { type: 'telegram_join' }` → 서버 getChatMember 검증
3. 성공 → 40c 지급 → 크레딧 배지 갱신 → 70c 도달 시 onComplete 콜백

**게이트 UI**: 기존 bottom-sheet 스타일 유지. HTML은 모듈 내부에서 생성.

### 서버 API 참조 (막내1 구현 중)

| API | Method | 설명 |
|-----|--------|------|
| `/api/telegram/gate-code` | POST | 게이트 딥링크 코드 생성 |
| `/api/telegram/mission-code` | POST | 미션 딥링크 코드 생성 |
