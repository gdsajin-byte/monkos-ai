## 작업 지시

### Task 1: 전수조사 (먼저 실행)

모든 HTML/JS/CSS 파일에서 크레딧 관련 UI를 전수조사하고, 아래 기준으로 분류할 것:

**A. Cr 디자인 미적용 — 교체 필요:**
- 💎 이모지를 Cr 코인 아이콘으로 교체
- `credit-btn`, `credit-badge` 등 구형 클래스를 `header-balance` 등 신규 클래스로 교체
- 크레딧 표기 `Nc` → `N Cr` 통일

**B. 이미 적용됨 — 스킵:**
- result.html, thankyou.html

**C. 크레딧 UI 없음 — 스킵:**
- privacy.html, terms.html, refund.html

### Task 2: cr-coin.css 로드 추가

cr-coin.css 미로드 페이지에 추가:
- `index.html`
- `prep.html`
- `camera.html`
- Space Mono 폰트 로드도 함께 확인 (`<link href="https://fonts.googleapis.com/css2?family=Space+Mono:wght@400;700&display=swap" rel="stylesheet">`)

### Task 3: 헤더 크레딧 배지 통일

**현재 (index.html 693행 기준):**
```html
<button class="credit-btn" id="creditBtn">
  <span class="credit-diamond">💎</span>
  <span class="credit-count" id="creditCount">0</span>
</button>
```

**변경 후 (철창이 디자인 기준):**
```html
<div class="header-balance" id="creditBtn">
  <div class="header-coin-wrap">
    <div class="header-sparkle"></div>
    <div class="header-sparkle"></div>
    <div class="header-coin">
      <div class="header-coin-face">
        <div class="header-shimmer"></div>
        <span class="cr-sym">Cr</span>
      </div>
    </div>
  </div>
  <span class="balance-amount" id="creditCount">0</span>
  <span class="balance-unit">Cr</span>
</div>
```

- prep.html, camera.html의 `credit-badge`도 동일하게 교체
- 기존 JS의 `creditBtn`, `creditCount` id 참조는 유지하여 기능 호환성 보장

### Task 4: 충전 모달/크레딧 부족 모달 디자인 통일

- prep.html, camera.html의 `credit-modal` 내부에서:
  - `credit-modal-icon` 💎 → Cr 코인 아이콘으로 교체
  - `pkg-credits` 표기 `10c` → `10 Cr` 통일
  - 충전 패키지 카드에 `.cr-badge` 스타일 적용 검토

- index.html의 이벤트 배너(`pkg-credits`)도 동일 통일

### Task 5: 이벤트 모션 연동 확인

- `showEventCard()`, `showThankYou()` 함수가 index.html에서도 호출 가능한지 확인
- shared.js가 index.html에서 로드되는지 확인. 안 되면 추가
- gate.js, mission.js에서 이벤트 발생 시 showEventCard() 호출이 연결되어 있는지 확인

### Task 6: 구형 CSS 정리

- `credit-btn`, `credit-diamond`, `credit-count`, `credit-empty` 등 구형 클래스의 CSS를 제거하거나, 신규 디자인으로 대체
- 중복 스타일이 남지 않도록 정리
- **단, 구형 CSS 제거 전에 해당 클래스를 참조하는 모든 곳이 교체되었는지 반드시 확인**
