## 1. 분석 범위

idphoto-kr 클라이언트 전체 파일 (`monkos_AI/idphoto-kr/public/`):

### A. localStorage / sessionStorage 잔재

모든 JS 파일에서 `localStorage`, `sessionStorage` 사용을 전수 추출하고:

1. **현재 사용 중인 키 목록** — 용도, 읽기/쓰기 위치, 생존 주기
2. **쿠키 단일화 후 불필요해진 키** — 코드에서 참조하지만 실질적으로 dead인 것
3. **코드에서 제거됐지만 브라우저에 잔존할 키** — 이전 사용자 브라우저에 남아 영향을 줄 수 있는 것
4. **초기화 시 정리 필요 여부** — 오래된 키를 sharedInit()에서 명시적으로 제거해야 하는지

### B. 쿠키 관련 잔재

1. `document.cookie` 직접 접근 코드 — HttpOnly 쿠키 전환 후 불필요한 것
2. `credentials: 'include'` 누락된 fetch 호출 — 쿠키 인증이 필요한데 빠진 것
3. 이전 토큰 기반 인증 코드 (`token`, `verify?token=`) — dead code 여부

### C. 이벤트 리스너 / window 객체 잔재

1. `window.loginGoogle`, `window.loginKakao` 등 — 정의 위치와 호출 위치 매칭
2. `postMessage` 리스너 — OAuth 팝업 콜백이 올바르게 등록/제거되는지
3. 사용하지 않는 전역 함수 — window에 노출됐지만 아무도 호출하지 않는 것

### D. import/export 정합성

1. shared.js에서 export하지만 아무도 import하지 않는 함수
2. 모듈 간 순환 참조 또는 누락된 import
3. config.js에 정의됐지만 사용되지 않는 상수

### E. HTML 인라인 스크립트 잔재

1. `index.html`, `result.html`, `camera.html`, `prep.html`, `thankyou.html`의 인라인 `<script>` 내부
2. 이전 sessionStorage 기반 인증 코드가 남아있는지
3. 인라인 스크립트와 모듈 스크립트 간 타이밍 이슈
