### 작업 항목

#### P0-1. 구 이벤트 시스템 제거

**대상 파일**: `monkos_AI/portal/server.js`

| 제거 대상 | 위치(참고) | 설명 |
|----------|-----------|------|
| `/api/credits/share-bonus` 엔드포인트 | ~1345-1396 | 구 100c SNS 보너스 |
| `TELEGRAM_BONUS` 상수 및 관련 코드 | ~1399 | CS봇 30c |
| `/api/telegram-bonus/generate` 엔드포인트 | ~1402-1443 | CS봇 보너스 코드 생성 |

**주의**: 엔드포인트 제거 시 404 반환하도록 처리 (프론트 오류 방지). 프론트 제거는 막내2가 병렬 수행.

#### P0-2. EVENT_CREDITS 수정

```
현재:
EVENT_CREDITS = { signup_bonus: 30, sns_share: 40, photo_consent: 40 }

변경:
EVENT_CREDITS = { signup_bonus: 30, telegram_join: 40 }
```

- `sns_share`, `photo_consent` 제거
- `telegram_join: 40` 추가

#### P1-1. 텔레그램 게이트 코드 생성 API

**신규 엔드포인트**: `POST /api/telegram/gate-code`

```
Request: { userId }
Response: { deeplink: "t.me/{봇이름}?start=GATE_{code}" }
```

- 고유 코드 생성 (UUID 또는 랜덤 문자열)
- Firestore에 저장: `telegramGateCodes/{code}` → `{ userId, type: 'gate', createdAt, used: false }`
- 기존 CS봇 딥링크 생성 로직(`/api/telegram-bonus/generate`)을 참고하여 유사하게 구현

#### P1-2. 텔레그램 가입 검증 (`/api/credits/event` 수정)

**대상**: `/api/credits/event` 엔드포인트 내 `telegram_join` 타입 처리

```
type: 'telegram_join' 수신 시:
1. userId로 Firestore에서 telegramId 조회 (봇이 매핑 저장한 것)
2. Telegram Bot API: getChatMember(CHANNEL_ID, telegramId) 호출
3. status가 'member', 'administrator', 'creator' 중 하나면 → 검증 성공
4. events.telegram_join = true + 40c 지급
5. 이미 지급된 경우 → 409 Conflict (기존 중복 방지 로직 유지)
```

**필요 환경변수**:
- `TELEGRAM_BOT_TOKEN` (기존 CS봇 토큰 재활용 가능한지 확인)
- `TELEGRAM_CHANNEL_ID` (@MonkosChannel 또는 해당 채널 chat_id)

**getChatMember API 호출**:
```
GET https://api.telegram.org/bot{token}/getChatMember?chat_id={channel_id}&user_id={telegram_user_id}
```

#### P1-3. 봇 /start 핸들러 수정

**대상**: 텔레그램 봇 코드 (기존 CS봇 코드 위치 확인 필요)

```
/start GATE_{code} 수신 시:
1. code로 Firestore 조회 → userId 확인
2. 발신자의 telegramId ↔ userId 매핑 저장 (Firestore: users/{userId}/telegramId)
3. 응답: "MONKOS 채널에 가입해주세요! 가입 후 웹으로 돌아가 '확인' 버튼을 눌러주세요."
4. 채널 초대 링크 포함

/start MISSION_{code} 수신 시:
1. code로 Firestore 조회 → userId 확인
2. 응답: "증명사진 결과물을 보내주세요! 📸"
3. 다음 이미지 메시지 수신 → 저장 + 수신 플래그 설정
   (Firestore: users/{userId}/missionImageReceived = true, missionImageUrl = GCS경로)
```

#### P1-4. 100c 미션 엔드포인트

**신규 엔드포인트**: `POST /api/credits/mission-complete`

```
Request: { userId }

검증:
1. Firestore users/{userId}/snsConsentSigned === true (동의서 서명 확인)
2. Firestore users/{userId}/missionImageReceived === true (봇 이미지 수신 확인)
3. Firestore users/{userId}/missionBonusClaimed !== true (중복 방지)

성공 시:
- 100c 지급
- missionBonusClaimed = true
- 응답: { success: true, credited: 100 }

실패 시:
- 미충족 조건 명시
- 응답: { success: false, missing: ['consent' | 'image'] }
```

#### P1-5. SNS 활용 동의서 저장 API

**신규 엔드포인트**: `POST /api/consent/sns`

```
Request: { userId, agreed: true, timestamp }

처리:
1. Firestore users/{userId}/snsConsentSigned = true
2. Firestore users/{userId}/snsConsentAt = timestamp
3. 응답: { success: true }
```
