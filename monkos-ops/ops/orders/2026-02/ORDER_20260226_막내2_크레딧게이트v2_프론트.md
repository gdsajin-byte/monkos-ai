- 제거: 구 SNS 100c 이벤트 카드, 구 SNS 공유/동의 택1 UI

#### P0-1. 생성 이미지 sessionStorage 보관 (이미지 소실 수정)

**대상 파일**: `monkos_AI/idphoto-kr/public/result.js` (~라인 593)

```
현재: store.generated = genResult.image  (메모리만)

변경:
store.generated = genResult.image;
try { sessionStorage.setItem('monkos_generated', genResult.image); } catch(e) {}
```

**페이지 로드 시 복원 로직 추가**:
```
// 페이지 초기화 시
if (!store.generated && sessionStorage.getItem('monkos_generated')) {
  store.generated = sessionStorage.getItem('monkos_generated');
}
```

이렇게 하면 토스 결제 리다이렉트 후 복귀 시 이미지가 보존된다.

#### P1-3. 다운로드 후 결과 화면 — 100c 미션 UI 신설

**대상 파일**: `monkos_AI/idphoto-kr/public/result.js`

**UI 배치 순서 (중요!)**: 욕구 먼저, 해결책 뒤에

```
[다운로드 완료 후 결과 화면]

┌─────────────────────────────────────┐
│  ✨ 프리미엄 옵션                    │  ← ① 먼저 보여서 욕구 자극
│                                     │
│  [정밀 크롭] [배경 추가] [보정]      │
│  이 기능에는 크레딧이 필요합니다      │
│  현재 잔액: 0c                       │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│  🎁 100c 미션                        │  ← ② 아래에서 해결책 제시
│                                     │
│  결과물을 텔레그램으로 보내고         │
│  SNS 활용에 동의하면 100c!           │
│                                     │
│  □ SNS 활용 동의                     │  ← 체크박스
│    "MONKOS가 마케팅 목적으로          │
│     결과 사진을 SNS에 게시할 수       │
│     있음에 동의합니다"               │
│                                     │
│  [✅ 동의 완료]                      │  ← 동의서 제출 버튼
│                                     │
│  [📸 텔레그램으로 캡쳐 보내기]       │  ← 봇 딥링크
│                                     │
│  [🎉 미션 완료 확인]                 │  ← 서버 검증 + 100c 지급
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│  💰 또는 크레딧 충전                  │  ← ③ 결제 옵션
│  [충전하기]                          │
└─────────────────────────────────────┘
```

**동작 흐름**:

1. **동의서 서명**:
   - 체크박스 체크 → "동의 완료" 클릭
   - `POST /api/consent/sns { userId, agreed: true }`
   - 성공 → 체크 아이콘 표시, 버튼 비활성

2. **캡쳐본 전송**:
   - "텔레그램으로 캡쳐 보내기" 클릭
   - `POST /api/telegram/gate-code { userId, type: 'mission' }` → 딥링크 수신
   - 딥링크 열기 → 봇으로 이동 → 사용자가 이미지 전송
   - 웹 복귀

3. **미션 완료 확인**:
   - "미션 완료 확인" 클릭
   - `POST /api/credits/mission-complete { userId }`
   - 성공 → 100c 지급 → 크레딧 배지 갱신 → 프리미엄 옵션 활성
   - 실패 → 미충족 조건 안내 ("동의서를 서명해주세요" 또는 "사진을 전송해주세요")

#### P1-4. 100c 미션 노출 조건

- **로그인 사용자만** 표시 (게이트를 통과해야 하므로 자동 충족)
- **missionBonusClaimed !== true** 일 때만 표시 (이미 수령한 경우 미표시)
- 다운로드 완료 후에만 표시 (다운로드 전에는 게이트가 우선)
