### 작업 항목

#### P0-1. 동의서 서명 전 이미지 전송 버튼 비활성화

**현황** (막내3 발견): `mission.js`에서 3개 버튼(동의/전송/확인)이 동시 활성 — 순서 강제 없음

**수정** (`modules/mission.js`):
- 초기 상태: "텔레그램으로 캡쳐 보내기" 버튼 `disabled` + 회색 처리
- 동의서 서명 완료(`missionConsentDone === true`) 시 전송 버튼 활성화
- "미션 완료 확인" 버튼은 동의 + 이미지 전송 둘 다 완료 후 활성화
- 비활성 상태에서 클릭 시 안내 텍스트: "먼저 SNS 활용 동의서에 서명해주세요"

#### P0-2. Cr 모션 연동

**현황** (막내3 발견): `showEventCard()`, `showThankYou()`가 `shared.js`에 정의되어 있으나, gate.js/mission.js 어디에서도 호출하지 않음

**수정**:

| 이벤트 | 파일 | 호출 함수 | 시점 |
|--------|------|----------|------|
| 로그인 30c 지급 | `gate.js` | `showEventCard({amount: 30, label: '가입 보너스'})` | signup_bonus API 성공 응답 직후 |
| 채널 가입 40c 지급 | `gate.js` | `showEventCard({amount: 40, label: '채널 가입 보너스'})` | telegram_join 또는 kakao_channel_add 성공 직후 |
| 다운로드 완료 | `result.js` | `showThankYou()` | 다운로드 함수 성공 직후 (70c 차감 후) |
| 미션 100c 완료 | `mission.js` | `showThankYou()` | mission-complete 성공 직후 |

- `showEventCard`, `showThankYou` 함수가 `shared.js`에서 export되어 있는지 확인. 안 되어 있으면 export 추가
- 각 모듈에서 `import` 후 호출

#### P1-1. 게이트 Phase 2 멀티채널 UI

**현황**: Phase 2는 텔레그램 가입 단일 경로

**수정** (`modules/gate.js`):
- Phase 2 영역에 **선택 UI** 추가:

```
┌──────────────────────────────────────┐
│  +40c 받기 — 채널 하나를 선택하세요   │
│                                      │
│  ┌──────────────┐ ┌──────────────┐  │
│  │ 💬 카카오톡   │ │ ✈️ 텔레그램   │  │
│  │ 채널 추가    │ │ 채널 가입    │  │
│  └──────────────┘ └──────────────┘  │
│                                      │
│  카카오톡 채널을 추가하면 40c!        │
└──────────────────────────────────────┘
```

- 디폴트 추천: locale이 `ko` → 카카오 하이라이트 / 그 외 → 텔레그램 하이라이트
- 카카오 선택 시:
  1. Kakao JS SDK `followChannel(channelId)` 호출
  2. 성공 콜백 → `POST /api/credits/event {type: 'kakao_channel_add'}` 호출
  3. 서버 검증 성공 → 40c 지급 → showEventCard + Phase 2 완료
- 텔레그램 선택 시: 기존 플로우 유지 (딥링크 → getChatMember)
- 둘 중 하나 완료 시 다른 버튼 비활성화 (택1)
