### ⏳ 추가 필요 사항

1. **CUDA Toolkit 설치** → MuseTalk mmcv 풀버전 빌드 가능. onnxruntime GPU 가속도 활성화됨.
2. **Visual Studio Build Tools 설치** → xtcocotools/mmcv 등 C 확장 빌드 가능. MuseTalk 완전 동작 예상.
3. **SadTalker 512px 테스트** → `SadTalker_V0.0.2_512.safetensors` 체크포인트 이미 다운로드됨. `--size 512` 옵션으로 고해상도 테스트 가능.

5. **iMac 전송** → SSH 키 인증 미정비로 iMac 자동 전송 미실행. 수동 전송 또는 SSH 키 설정 필요.
