# 지시서: 데이터 보관 정책 법규 리서치 + 약관·개인정보처리방침 개정 초안

**[2026-03-08 13:50 KST] iMac/쌍아 → 막내1**

## 배경

MONKOS AI 증명사진 서비스의 데이터 보관 정책을 전환한다.

**현행**: 촬영 사진 → AI 생성 완료 즉시 서버 삭제 (비보관)
**전환**: 2단계 보관 정책 (L1 기본보관 + L2 활용동의)

| 등급 | 성격 | 보관 기간 | 동의 방식 |
|------|------|-----------|-----------|
| **L1 (기본)** | 서비스 운영 보관 | 30일 자동삭제 | 이용약관 명시 (별도 체크 불필요) |
| **L2 (활용)** | 마케팅·품질 개선 | 90일 자동삭제 | 체크박스 옵트인 |

### L1 보관 근거 (서비스 운영상 필수)
- 7일 환불 대응
- 여권 반려 시 재발급
- 미다운로드 고객 CS 대응
- 서비스 장애 시 복구
- (참고: 오프라인 사진관은 1년 보관 고지가 업계 표준)

### L2 활용 범위
- 전후 비교 이벤트 (고객이 캡처해서 올릴 필요 없이 체크만)
- 서비스 품질 분석 (before/after)
- 마케팅 소재 (비식별 처리 후)

### 적용 대상 데이터
1. **촬영 사진 (얼굴 이미지)** — 입력 원본 + 생성 결과물
2. **챗봇 대화 로그** — 현재 Firestore에 무기한 저장 중 (chat_conversations, cs_conversations, kakao_conversations 등). 이것도 L1/L2 정책 적용 대상

## Phase A: 각국 데이터 보관 법규 리서치

### 대상 국가 (서비스 운영 지역)
1. **한국** — 개인정보 보호법, 정보통신망법
2. **일본** — APPI (個人情報保護法)
3. **EU** — GDPR (향후 진출 대비)
4. **미국** — CCPA/CPRA (캘리포니아), 연방 수준

### 각 국가별 조사 항목
- 얼굴 이미지의 법적 분류 (생체정보? 민감정보? 일반 개인정보?)
- 서비스 운영 목적 보관 시 의무 사항 (동의 방식, 고지 내용)
- 보관 기간 제한 또는 권장 기준
- 자동 삭제 정책의 법적 유효성
- 마케팅 활용 동의의 요건 (옵트인/옵트아웃 차이)
- 아동 데이터 특별 규정 (증명사진 특성상 미성년자 이용 가능)
- 위반 시 제재 수준

### 업계 벤치마크
- Photoroom, Remove.bg, Passport Photo Online 등 경쟁 서비스의 데이터 정책
- 대형 LLM (Google Gemini 3개월, OpenAI 30일 등)과의 비교

## Phase B: 현행 약관·개인정보처리방침 분석

### 현행 파일 위치
- `monkos_AI/idphoto-kr/public/terms.html` (한국어 이용약관)
- `monkos_AI/idphoto-kr/public/privacy.html` (한국어 개인정보처리방침)
- `monkos_AI/idphoto-jp/public/terms.html` (일본어 利用規約)
- `monkos_AI/idphoto-jp/public/privacy.html` (일본語 プライバシーポリシー)
- `monkos_AI/portal/public/terms.html` (포털 약관)
- `monkos_AI/portal/public/privacy.html` (포털 개인정보처리방침)

### 분석 항목
1. **현행 모순점 식별**: "즉시 삭제" 명시 → L1 전환 시 충돌 조항
2. **현행 누락 사항**: 챗봇 대화 데이터 보관에 대한 고지가 없음
3. **제3자 제공 테이블**: GCS 일시적 보관 → R2 전환 시 변경 필요
4. 각 국가 법률 요건과 현행 약관의 갭(gap) 분석

## Phase C: 개정 초안 작성

### 산출물
각 국가별 약관·개인정보처리방침 **개정 초안**을 보고서에 포함할 것:

1. **privacy.html 개정안** (KR/JP 각각)
   - 제3항(보유 및 파기) 전면 개정: L1/L2 보관 기간 명시
   - 촬영 사진 보관 근거 및 자동 삭제 정책
   - 챗봇 대화 데이터 보관 근거 추가
   - 제3자 제공 테이블 갱신 (R2 추가 여부)

2. **terms.html 개정안** (KR/JP 각각)
   - 데이터 보관 관련 조항 신설 or 기존 조항 수정
   - L2 활용 동의 관련 조항

3. **동의 UI 문구 초안**
   - L2 체크박스 문구 (한국어/일본어)
   - 이용약관 내 L1 고지 문구

### 보고서 형식 주의
- 법률 원문 인용 시 조문 번호 명시
- "~할 수 있다" vs "~해야 한다" 구분 명확히
- 불확실한 해석에는 **법률 자문 권고** 표시

## ⚠️ 준수 조항
