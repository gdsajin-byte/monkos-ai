## Phase D: 토스 리다이렉트 블랙스크린 수정

### 현황
- 토스 결제 완료 → 리다이렉트 → 블랙스크린 약 5초 → 알림
- 원인: `sharedInit()` (shared.js:374-378)에서 3개 순차 await:
  1. `initFromUrlToken()` — URL 파라미터 인증
  2. `initCredits()` — 쿠키 인증 + 크레딧 조회
  3. `initFromTossResult()` — 토스 confirm API 호출
- body 배경 `#030508` (near-black), 페이지 렌더가 `sharedInit()` 완료 후에야 실행
- 유저에게 아무 피드백 없이 검은 화면만 보임

### 수정

**파일:** `idphoto-kr/public/shared.js` — `initFromTossResult()` (L162-199)

토스 success 감지 시 **confirm API 호출 전**에 로딩 UI 즉시 표시:

```javascript
if (params.get('toss') === 'success') {
  // 즉시 로딩 UI 표시
  _showTossLoading();

  const paymentKey = params.get('paymentKey');
  // ... (기존 로직)

  _hideTossLoading();
}
```

**로딩 UI 헬퍼 (shared.js 내부):**

```javascript
function _showTossLoading() {
  const el = document.createElement('div');
  el.id = 'toss-loading';
  el.style.cssText = 'position:fixed;inset:0;background:#030508;display:flex;align-items:center;justify-content:center;z-index:9999;';
  el.innerHTML = '<div style="text-align:center;"><div style="color:#a78bfa;font-size:1.1rem;font-weight:600;">결제 확인 중...</div><div style="color:#8892a8;font-size:0.85rem;margin-top:8px;">잠시만 기다려 주세요</div></div>';
  document.body.appendChild(el);
}

function _hideTossLoading() {
  const el = document.getElementById('toss-loading');
  if (el) el.remove();
}
```

- 실패 시에도 `_hideTossLoading()` 호출 (catch/finally)
- 기존 `alert()` 동작은 그대로 유지 — 로딩 오버레이 위에 alert가 뜨면 자동으로 가려짐

## 검증 (완료 조건)

### Phase A: 뒤로가기
1. 1단계에서 "← 돌아가기" 버튼 표시 + 탭 → 랜딩(index.html) 이동
2. 2~4단계에서 "이전" 버튼 표시 + 탭 → 이전 단계 이동 (현행 동작 유지)

### Phase B: 로고 → 챗봇
3. 헤더 MONKOS 로고 탭 → 챗봇 활성화
4. 챗봇 닫기 후 정상 동작

### Phase C: 안내 문구
5. 1단계 상단에 "용도에 맞는..." 안내 문구 표시
6. 2~4단계에는 안내 문구 없음 (1단계만)
7. 3단계 스타일 페이지에서만 리터칭 관련 언급

8. 토스 결제 완료 → 리다이렉트 시 "결제 확인 중..." 로딩 표시
9. confirm 완료 후 로딩 제거 + alert 정상 동작
10. 결제 실패 시에도 로딩 제거 + 에러 메시지 정상
