## 검토 항목

### 1. 과금 정합성 (최우선)

과금은 실수하면 매출에 직접 영향. 다음을 전수 확인하라:

- `config.js`(프론트)와 `shared/config.js`(백엔드)의 **PRODUCTS 구조가 일치**하는가?
- 각 상품의 크레딧 단가가 프론트/백엔드/KB 데이터에서 **동일한 값**인가?
- `credits.js`의 차감 로직이 새 단가와 맞는가?
- `payments.js`의 결제 금액 계산이 새 PRODUCTS 구조와 맞는가?
- `events.js`의 이벤트/프로모션 단가가 정상인가?
- `credits.test.js` 테스트가 새 단가 기준으로 **전부 통과**하는가? (실제 실행)

### 2. ChargePanel 모달 동작

- `charge.js`의 ChargePanel이 정상 열림/닫힘 하는가?
- 충전 상품 목록이 `config.js` PRODUCTS에서 정확히 렌더링되는가?
- 결제 완료 후 크레딧 잔액 갱신이 정상인가?

### 3. 카피 전환 일관성

- "생성"→"리터칭" 전환이 **모든 파일에서 일관**되는가?
- 빠뜨린 곳이 없는가? (grep으로 "생성" 잔재 탐색)

### 4. 랜딩 페이지

- `index.html` v3 히어로 섹션 마크업 구조 확인
- `hero.webp` 이미지 로딩 경로가 정확한가?
- 가격 섹션의 표시 금액이 config.js PRODUCTS와 일치하는가?

### 5. 챗봇 KB 데이터

- `prompts.js`, `seed_cs_knowledge.js` 등의 가격/보너스 정보가 과금 구조와 일치하는가?
- 어제 P0 수정(커밋 59abbda)과 오늘 M1 변경이 충돌하지 않는가?
