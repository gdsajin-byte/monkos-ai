### 분석 항목

**1. rules → skills 이관 판정**
현행 9개 rules를 아래 기준으로 분류:

| 기준 | 판정 |
|------|------|
| 어떤 작업이든 위반하면 사고(보안·파괴·기밀) | rules 유지 |
| 특정 행위(배포·PF·세션·CDP 등) 시에만 필요 | skills 이관 |
| 헌법과 중복 | 삭제 |

각 rules 파일에 대해:
```
| 파일 | 줄 | 판정 | 사유 | 이관 시 skills 파일명 |
```
