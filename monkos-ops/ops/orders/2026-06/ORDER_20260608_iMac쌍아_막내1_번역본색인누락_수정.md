# 지시서 — 번역본(ja/en) 색인 요청 누락 수정

**[2026-06-08 14:33 KST] iMac/쌍아 → iMac/막내1**

---

## 배경

6/7 세션에서 Indexing API + llms.txt 자동화를 구현했으나, **번역본(ja/en)에 색인 체이닝이 누락**되어 있었다. 민아가 GSC 실측으로 확인 — kr/ja 모두 "URL is unknown to Google".

**원인:** `blog.js`의 `handleBlogCreate`(215행)와 `handleBlogUpdate`(289행)에만 `requestIndexing` + `sitemap ping` + `appendToLlmsTxt`가 붙어 있고, `translate.js`의 저장부(184행 update, 197행 set)에는 **아무것도 없다.**

번역본은 Firestore에 저장만 되고 구글에 알려지지 않는 구조적 사각지대.

---

## 임무

### Task 1: 색인 유틸 분리 (blog.js → seo.js)

현재 `blog.js`에 비export 내부 함수로 있는 2개를 별도 모듈로 분리:

**`monkos_AI/portal/lib/cms/seo.js` 신규 생성:**

```js
// blog.js:46~59의 requestIndexing 이동
export async function requestIndexing(url) { ... }

// blog.js:61~79의 appendToLlmsTxt 이동
export function appendToLlmsTxt(slug, title) { ... }

// sitemap ping 유틸 추가
export function pingSitemap() {
  fetch('https://www.google.com/ping?sitemap=https://monkos.ai/sitemap.xml').catch(() => {});
}
```

**`blog.js` 수정:**
- `requestIndexing`, `appendToLlmsTxt` 내부 정의 삭제
- `import { requestIndexing, appendToLlmsTxt, pingSitemap } from './seo.js';` 추가
- 기존 호출부(215~219행, 289~293행)에서 `fetch(sitemap ping)` → `pingSitemap()` 으로 교체

### Task 2: translate.js에 색인 체이닝 추가

`translate.js`의 번역본 저장 완료 시점에 색인 3종 추가:

```js
import { requestIndexing, appendToLlmsTxt, pingSitemap } from './seo.js';
```

`translateAndSaveBlogPost` 함수 내, 번역본 저장 성공 후(216행 `log` 직전):

```js
// 번역본이 published 상태이면 색인 요청
if (originalDoc.published) {
  const translatedUrl = `https://monkos.ai/blog/${translatedSlug}`;
  requestIndexing(translatedUrl);
  appendToLlmsTxt(translatedSlug, translated.title);
  pingSitemap();
}
```

### Task 3: 검증

1. 로컬 `node server.js` 기동
2. 테스트 블로그 발행 (published=true, lang=ko)
3. 서버 로그에서 확인:
   - `[SEO] Indexing API 성공: .../blog/{slug}` (kr 원본)
   - `[SEO] Indexing API 성공: .../blog/{slug}-ja` (번역본)
   - `[SEO] Indexing API 성공: .../blog/{slug}-en` (번역본)
   - `[SEO] llms.txt 갱신: {slug}-ja`
   - `[SEO] llms.txt 갱신: {slug}-en`
4. 기존 동작 미파괴 확인 — 번역 실패 시 색인도 skip 되는지 (try-catch 내부이므로 자연스럽게 skip)
