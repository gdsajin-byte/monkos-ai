### Task 2: Qwen 3.5 4B 모델 로드

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "Qwen/Qwen3.5-4B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype="auto",
    device_map="auto"
)
```

### Task 3: 블로그 에디터 시나리오 4종 테스트

각 시나리오별 입력→출력 품질 + 속도(초) + VRAM 사용량 측정.

#### 시나리오 1: SEO 제안

```
입력: 제목 "증명사진 배경색 완벽 가이드 — 흰색, 파란색, 회색 언제 쓸까"
기대 출력: { summary: "160자 요약", tags: "5개 태그", ogTitle: "60자 OG 제목" }
```

#### 시나리오 2: 이미지 프롬프트 생성

```
입력: 제목 + 본문 키워드 5개 + 카테고리
기대 출력: 영문 이미지 프롬프트 (Imagen 최적화, 200단어 이내)
```

#### 시나리오 3: 글감 정리 (시드 → 블로그 개요)

```
입력: 에피소드 카탈로그 1건 (title + summary + insight)
기대 출력: 블로그 개요 (제목 + 서론 + 본문 3섹션 + 결론 구조)
```

#### 시나리오 4: slug 생성

```
입력: 한글 제목 "증명사진 배경색 완벽 가이드"
기대 출력: 영문 URL slug (예: id-photo-background-color-guide)
```
