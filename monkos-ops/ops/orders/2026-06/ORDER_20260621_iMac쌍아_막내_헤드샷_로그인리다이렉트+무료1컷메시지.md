# 헤드샷 로그인 리다이렉트 수정 + 무료 1컷 메시지

> **[2026-06-21 16:55 KST]** iMac/쌍아 → 막내
> 작가님 지시: /headshot에서 로그인 후 원래 페이지로 돌아오게 하고, 로그인 모달에 무료 1컷 유도 메시지를 추가하라.

## 1. 현재 문제

### 문제 A: 로그인 후 포털 홈(/)으로 리다이렉트

- `/headshot`에서 "Generate Headshot" 클릭 → 로그인 모달 → Google/Kakao/LINE 클릭
- 로그인 완료 후 **포털 홈(/)으로 이동** — `/headshot`으로 안 돌아옴
- **원인**: `public/js/auth.js`의 `googleLogin()`, `loginKakao()`, `loginLine()` 함수가 `source_page`만 전달하고 `redirect_app`을 안 보냄
- 서버 `lib/auth.js`에서 `redirectApp`이 빈 문자열 → `returnUrl = '/'`

### 문제 B: 무료 1컷 유도 메시지 없음

- 현재 로그인 모달에 "로그인" 타이틀 + Google 버튼만 존재
- 가입 시 10c 무료 보너스가 있지만 유저에게 **알려주지 않고 있음**

## 2. 수정 사항

### 수정 A: redirect_app 전달 (auth.js 클라이언트)

**파일**: `monkos_AI/portal/public/js/auth.js`

```javascript
// 변경 전 (L109-111)
window.googleLogin = function() {
  var params = 'source_page=' + encodeURIComponent(window.location.hostname + window.location.pathname);
  location.href = '/auth/google?' + params;
};

// 변경 후
window.googleLogin = function() {
  var params = 'source_page=' + encodeURIComponent(window.location.hostname + window.location.pathname)
    + '&redirect_app=' + encodeURIComponent(window.location.pathname);
  location.href = '/auth/google?' + params;
};
```

동일하게 Kakao, LINE도 수정:

```javascript
// 변경 전 (L89-90)
window.loginKakao = function() { location.href = '/auth/kakao?source_page=' + encodeURIComponent(window.location.hostname + window.location.pathname); };
window.loginLine = function() { location.href = '/auth/line?source_page=' + encodeURIComponent(window.location.hostname + window.location.pathname); };

// 변경 후
window.loginKakao = function() {
  location.href = '/auth/kakao?source_page=' + encodeURIComponent(window.location.hostname + window.location.pathname)
    + '&redirect_app=' + encodeURIComponent(window.location.pathname);
};
window.loginLine = function() {
  location.href = '/auth/line?source_page=' + encodeURIComponent(window.location.hostname + window.location.pathname)
    + '&redirect_app=' + encodeURIComponent(window.location.pathname);
};
```

**서버 측 변경 불필요** — `lib/auth.js`는 이미 `redirect_app` 파라미터를 처리하는 로직이 있음. 단, `ALLOWED_POPUP_ORIGINS` 체크를 통과해야 하므로 아래 확인:

```javascript
// lib/auth.js L155
const returnUrl = ALLOWED_POPUP_ORIGINS.includes(redirectApp) ? redirectApp : '/';
```

`redirectApp`이 `/headshot`(경로)인데 `ALLOWED_POPUP_ORIGINS`는 호스트 목록이므로 **매칭 안 됨**. 서버 로직도 수정 필요:

**파일**: `monkos_AI/portal/lib/auth.js`

리다이렉트 경로 판정 로직을 찾아서 (Kakao: ~L155, LINE: ~L300대, Google: ~L460대) `redirectApp`이 `/`로 시작하는 내부 경로일 때도 허용하도록 수정:

```javascript
// 패턴: 기존
const returnUrl = ALLOWED_POPUP_ORIGINS.includes(redirectApp) ? redirectApp : '/';

// 패턴: 수정
const returnUrl = redirectApp.startsWith('/') ? redirectApp
  : ALLOWED_POPUP_ORIGINS.includes(redirectApp) ? redirectApp
  : '/';
```

⚠️ **보안**: `redirectApp`이 `/`로 시작하는 내부 경로만 허용. 외부 URL이나 `//evil.com` 같은 프로토콜 상대 URL은 차단해야 함:

```javascript
const isSafeInternalPath = redirectApp.startsWith('/') && !redirectApp.startsWith('//');
const returnUrl = isSafeInternalPath ? redirectApp
  : ALLOWED_POPUP_ORIGINS.includes(redirectApp) ? redirectApp
  : '/';
```

이 패턴을 **Kakao, LINE, Google redirect 콜백 3곳** 모두 적용.
