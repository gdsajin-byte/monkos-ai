## Task 4: 블로그 og:image 폴백 보강 + twitter:image 추가

**파일**: `lib/cms/render-blog.js` (283~295행 부근)

**현재** (286행):
```javascript
<meta property="og:image" content="${escapeHtml(post.ogImage || post.thumbnail || '')}">
```

**변경 후** — 빈 문자열 폴백을 사이트 공통 이미지로 교체 + twitter:image 추가:
```javascript
<meta property="og:image" content="${escapeHtml(post.ogImage || post.thumbnail || 'https://monkos.ai/og-image.png')}">
<meta property="og:image:alt" content="${escapeHtml(post.title)}">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:image" content="${escapeHtml(post.ogImage || post.thumbnail || 'https://monkos.ai/og-image.png')}">
```

**핵심**: `|| ''` → `|| 'https://monkos.ai/og-image.png'` 로 변경. ogImage/thumbnail 미설정 블로그도 항상 썸네일 보장.

## Task 5: 사이트맵 image:image 추가

**파일**: `lib/cms/render-sitemap.js`

**변경 사항**:

1. XML 네임스페이스에 이미지 추가:
```javascript
// 변경 전
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">

// 변경 후
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"
        xmlns:image="http://www.google.com/schemas/sitemap-image/1.1">
```

2. 정적 URL 구조에 image 필드 추가 (홈·주요 페이지):
```javascript
// 예시: 홈 URL
{ loc: 'https://monkos.ai/', lastmod: today, changefreq: 'weekly', priority: '1.0',
  image: 'https://monkos.ai/og-image.png', imageTitle: 'MONKOS AI 증명사진' },
```

3. URL 출력부에 이미지 태그 삽입:
```javascript
// 변경 전
${allUrls.map(u => `  <url>
    <loc>${u.loc}</loc>
    ${u.lastmod ? `<lastmod>${u.lastmod}</lastmod>` : ''}
    <changefreq>${u.changefreq}</changefreq>
    <priority>${u.priority}</priority>
  </url>`).join('\n')}

// 변경 후
${allUrls.map(u => `  <url>
    <loc>${u.loc}</loc>
    ${u.lastmod ? `<lastmod>${u.lastmod}</lastmod>` : ''}
    <changefreq>${u.changefreq}</changefreq>
    <priority>${u.priority}</priority>${u.image ? `
    <image:image>
      <image:loc>${u.image}</image:loc>
      ${u.imageTitle ? `<image:title>${u.imageTitle}</image:title>` : ''}
    </image:image>` : ''}
  </url>`).join('\n')}
```

4. 블로그 URL에도 thumbnail 연동:
```javascript
const blogUrls = snapshot.docs.map(doc => {
  const data = doc.data();
  // ... 기존 코드 ...
  return {
    loc: `https://monkos.ai${langPrefix}/blog/${baseSlug}`,
    lastmod: (data.updatedAt || data.createdAt || '').substring(0, 10),
    changefreq: 'weekly',
    priority: '0.7',
    image: data.ogImage || data.thumbnail || '',
    imageTitle: data.title || '',
  };
});
```
