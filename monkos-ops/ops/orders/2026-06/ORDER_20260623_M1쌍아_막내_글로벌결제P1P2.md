## Task 1 — EN 증명사진 CTA 링크 수정 (P1-a)

EN 유저가 증명사진 CTA 누르면 idphoto-kr로 빠지는 문제 수정.

### 1-1. `monkos_AI/portal/lib/cms/home.js:395`

**현재:**
```js
const idphotoUrl = lang === 'ja' ? 'https://idphoto-jp.monkos.ai/' : 'https://idphoto-kr.monkos.ai/';
```

**변경:**
```js
const idphotoUrl = req.paymentRegion === 'kr' ? 'https://idphoto-kr.monkos.ai/'
  : req.paymentRegion === 'jp' ? 'https://idphoto-jp.monkos.ai/'
  : `${prefix}/headshot`;
```

### 1-2. `monkos_AI/portal/public/js/i18n.js:115-118`

**현재:**
```js
function getCtaUrl() {
  return (region === 'kr')
    ? 'https://idphoto-kr.monkos.ai/'
    : 'https://idphoto-jp.monkos.ai/';
}
```

**변경:**
```js
function getCtaUrl() {
  if (region === 'kr') return 'https://idphoto-kr.monkos.ai/';
  var prefix = (lang === 'ko') ? '' : '/' + lang;
  return prefix + '/headshot';
}
```

## Task 3 — 인증 프로바이더 분기 geoip 일원화 (P2)

`lang` 조건을 `paymentRegion` 조건으로 교체. 어떤 언어 페이지에 있든 IP 리전에 맞는 로그인 버튼만 보이도록.

### 3-1. `monkos_AI/portal/lib/cms/home.js`

**라인 361 카카오:**
```js
// 현재
${lang === 'ko' ? '<button class="login-btn" onclick="loginKakao();closeLoginModal();" ...' : ''}
// 변경
${req.paymentRegion === 'kr' ? '<button class="login-btn" onclick="loginKakao();closeLoginModal();" ...' : ''}
```

**라인 362 LINE:**
```js
// 현재
${lang === 'ja' ? '<button class="login-btn" onclick="loginLine();closeLoginModal();" ...' : ''}
// 변경
${req.paymentRegion === 'jp' ? '<button class="login-btn" onclick="loginLine();closeLoginModal();" ...' : ''}
```

`tailHtml` 함수에 `req` 전달 필요 — 현재 `tailHtml(lang)` → `tailHtml(lang, req)` 로 시그니처 확장. 호출부(라인 445 부근)도 동시 수정.

### 3-2. `monkos_AI/portal/lib/cms/render-headshot.js`

**라인 321 카카오:**
```js
// 현재

// 변경
${paymentRegion === 'kr' ? `<button class="login-btn" onclick="loginKakao(); closeLoginModal();" ...` : ''}
```

**라인 324 LINE:**
```js
// 현재
${lang === 'ja' ? `<button class="login-btn" onclick="loginLine(); closeLoginModal();" ...` : ''}
// 변경
${paymentRegion === 'jp' ? `<button class="login-btn" onclick="loginLine(); closeLoginModal();" ...` : ''}
```
