### 2. git 이력 완벽 추적 (포렌식)
- image_pro 관련 경로의 **최근 변경 커밋 전수**: `git log --date=short --pretty="%h %ad %an %s"` (날짜·주체·내용).
- 핵심 라인(모델명·API 키 참조·엔드포인트·인증 방식) **`git log -L` / `git blame`**으로 변경 추적 — **언제 무엇으로 바뀌었나**.
- **망가지기 시작한 시점 특정**: 정상 동작 마지막 커밋 ↔ 최초 장애 유발 커밋.

### 3. 변경별 영향 분석 (무엇이 무엇을 깼나)
다음을 우선 점검:
- **EOL 마이그(2.0→2.5) 영향**: image_pro 모델도 코칭처럼 오변경됐는지 (Live/generateContent 모델명 혼동).
- **6/2 키 삭제 영향**: image_pro가 삭제된 키(monkosimagepro 등)를 참조했는지.
- **AI Studio 크레딧 소진(429)**: `/refine`이 GEMINI_API_KEY(AI Studio) 사용 → 크레딧 소진 영향. (단 이건 충전으로 별도 복구 중 — 코드 문제와 분리해서 봐라.)
- **배포/번들/엔드포인트 변경**: app 번들(index-v6.js 등) 교체, image.monkos.ai 라우팅 변경.

### 4. 현재 실제 에러 확정 (추론 금지)
