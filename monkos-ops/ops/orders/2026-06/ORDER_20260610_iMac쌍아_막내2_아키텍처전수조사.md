## 임무

### Task 1: 데드 코드 전수 검증

Fable 5가 제거 대상으로 지목한 아래 경로를 직접 확인하여, **실제 사용 여부·다른 코드에서의 import/참조 여부**를 판정한다.

| 경로 | Fable 보고 사유 | 검증 항목 |
|------|---------------|----------|
| `apps/MonkosCrop/` | 초기 실험 + 바이너리 (131M) | 라이브 서비스에서 참조 여부, .build/ 이미 추적 해제 확인 |
| `apps/MonkosChat/` | portal chat으로 통합 완료 (1.7M) | 실제 통합 완료 여부, 키 노출원(보안 C-1)과 연관 |
| `apps/idphoto-jp-v079/` | monkos_AI/idphoto-jp로 통합 (320K) | 현행 idphoto-jp와의 차이 |
| `apps/photolab-monkkr-legacy/` | 중단된 재설계 | 참조 코드 존재 여부 |
| `apps/photolab-monkkr-mpa-0219/` | 중단된 재설계 | 참조 코드 존재 여부 |
| `apps/crop-app/` | monkos_AI/crop-app과 분기 중복 (17M) | 양쪽 파일 diff, 어느 쪽이 정본인지 판정 |
| `apps/idpass-android/` | 미활용 프로토타입 (4.1M) | 실제 활용 계획 유무 |

### Task 2: 라이브 서비스 코드 품질 점검

대상: `monkos_AI/` 하위 전 서비스 (portal, idphoto-kr, idphoto-jp, studio, crop-engine, crop-app)

- **의존성 버전 현황표** 작성: 각 서비스의 `package.json`에서 주요 패키지(@google/genai, express, cors 등) 버전 비교
- **코드 중복도**: idphoto-kr과 idphoto-jp 간 diff 통계 (몇 % 동일한지)
- **Dockerfile 위생**: 멀티스테이지 빌드, 불필요 레이어, 난독화 상태
- **테스트 현황**: 각 서비스별 테스트 파일 존재 여부·커버리지

### Task 3: CI/CD 현황

- `.github/workflows/` 전체 파일 목록 및 각각의 트리거·역할 정리
- deploy.sh 경유 배포 외에 자동화된 배포 경로 존재 여부
- GitHub Actions에서 빌드·테스트·배포 파이프라인 구성 여부
