## 작업 목록

### 1. 해시태그(v2-tags) 위치 이동
- **현재**: L1668~1676 — breadcrumb 아래, H1(`v2-header`) **위**에 위치
- **변경**: `v2-tags` 블록을 `v2-header` **아래**로 이동 (H1 → subtitle → tags 순서)

### 2. "그룹 A" 배지 삭제
- **현재**: L1614 — 사이즈 행에 `<span class="v2-badge v2-badge-a">그룹 A</span>` 하드코딩
- **변경**: 해당 배지 문자열 삭제. `''`(빈 문자열)로 교체.
- 사유: 내부 분류 체계이며 사용자에게 의미 없음.

### 3. 상세규정/반려사유 → 아코디언(드롭다운) 전환
- **현재**: L1791~1801 — `v2-detail-grid` 2컬럼, 항목이 모두 펼쳐져 있어 컨테이너가 과대
- **변경**:
  - 상세규정, 반려사유 각각을 **아코디언(접기/펴기)**으로 변환
  - 기본 상태: **접힌 채로** 렌더링 (클릭 시 펼침)
  - FAQ 섹션의 `v2-faq-item` / `v2-faq-q` 패턴을 재활용하면 됨
  - 2컬럼 그리드(`v2-detail-grid`)는 유지하되, 각 카드 내용만 접기

### 4. "같은 사진으로 제출 가능한 서류" 필터 수정
- **현재**: L1642~1644 — `s.country === specData.country`만 필터 (같은 나라면 규격 불문 전부 포함)
- **변경**: **사이즈 동일 조건 추가** — `s.size === specData.size` (또는 locField 비교)
- 사유: 한국 여권(3.5×4.5)과 한국 반명함(3×4)은 규격이 다르므로 "같은 사진" 아님
- 필터 후 결과가 0건이면 섹션 전체 미렌더링 (기존 `sameSize.length > 0` 조건 유지)

### 5. 하단 CTA → 크로스셀 카드로 교체
- **현재**: L1816~1821 — "규격에 맞는 여권사진, AI로 자동 완성" + `#v2-steps` 앵커
- **변경**: 같은 자리에 **다른 서비스 크로스셀 카드** 렌더링
  - 카드 2~3개: 헤드샷(`/headshot`), AI 프로필(`/`), 증명사진 전체 규격(`/specs`)
  - 각 카드: 제목 + 한 줄 설명 + 링크
  - 예시:
    ```
    ┌─────────────────────┐ ┌─────────────────────┐
    │ 💼 취업·이력서 사진   │ │ 📷 프로필 사진       │
    │ AI 헤드샷으로 완성    │ │ SNS·링크드인용       │
    │ 바로가기 →           │ │ 바로가기 →           │
    └─────────────────────┘ └─────────────────────┘
    ```
  - 링크: `/headshot` (헤드샷), `/` (메인), `/specs` (규격 전체)
  - 스타일: 기존 `v2-same-card` 패턴 재활용 가능
