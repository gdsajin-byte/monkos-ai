## 배경

보안 전수조사에서 확인된 공격 체인:

```
N-1(토큰 무인증 발급) → C-4(전원 관리자) → C-2(크레딧 무인증) → H-1(무제한 AI 생성)
```

아무나 관리자 토큰 발급 → CMS 전체 접근 → 무한 크레딧 충전 → 무제한 AI 이미지 생성이 가능한 상태. **실서비스에서 즉시 악용 가능.** 본 지시서는 근본 해결(마이페이지)이 아닌 **응급 페일클로즈 패치**.

## Task 1: N-1 — `/api/auth/token` 무인증 토큰 발급 차단

**위치**: `monkos_AI/portal/lib/auth.js` — `handleAuthToken` 함수

**현황**: `POST /api/auth/token {"userId":"아무값"}` → 해당 userId의 유효 토큰 즉시 발급. 인증 검증 없음.

**수정**:
- 요청자의 세션 쿠키 또는 기존 인증 토큰을 검증하여, **자기 자신의 userId에 대해서만** 토큰 발급 허용
- 세션 쿠키가 없거나 userId 불일치 시 **403 반환**
- 세션 검증이 구조적으로 어려우면 **최소한 요청 Origin 검증 + 레이트리밋(IP당 분당 5회)** 적용

## Task 2: C-4 — ADMIN_UIDS 페일오픈 → 페일클로즈 전환

**위치**: `monkos_AI/portal/lib/cms/admin-auth.js:14` 외 `auth.js:460,597,793`

**현황**:
```javascript
if (payload && (ADMIN_UIDS.length === 0 || ADMIN_UIDS.includes(payload.userId))) {
```
→ `ADMIN_UIDS` 미설정 시 **모든 인증 사용자가 관리자**

**수정**:
```javascript
if (payload && ADMIN_UIDS.length > 0 && ADMIN_UIDS.includes(payload.userId)) {
```
→ `ADMIN_UIDS` 미설정 시 **관리자 0명** (페일클로즈)

- `admin-auth.js`의 `requireAdmin()` 함수
- `auth.js`의 OAuth 응답 내 `isAdmin` 판정 3개소 (460, 597, 793행)
- 총 4개소 모두 동일 패턴 수정

## Task 3: C-2 — 크레딧 API 인증 미들웨어 추가

**위치**:
- `monkos_AI/portal/lib/credits.js` — `handleCreditsGet`, `handleCreditsUse`, `handleCreditsRefund`
- `monkos_AI/portal/server.js:132-134` — 라우트
- `monkos_AI/idphoto-kr/server.js:652,664` — `/api/credit/use`, `/api/credit/refund`
- `monkos_AI/idphoto-jp/server.js` — 동일 패턴 (kr과 동일 구조)

**현황**: `req.body.userId` 또는 `req.query.userId`를 직접 신뢰. 토큰 검증 없음.

**수정**:
- portal: server.js 라우트에서 크레딧 API 호출 전 **인증 토큰 검증** 추가. `verifyAuthToken()` (config.js에 이미 존재) 활용
- 토큰에서 추출한 userId와 요청 body의 userId 일치 여부 검증
- 불일치 시 **403 반환**
- idphoto-kr/jp: 동일 패턴 적용. portal의 `verifyAuthToken`을 import하거나 동일 로직 복제

## Task 4: C-3 — AUTH_SECRET 폴백 하드코딩 제거

**위치**: `monkos_AI/portal/lib/shared/config.js:31`

**현황**:
```javascript
const authSecret = AUTH_SECRET || LEMONSQUEEZY_WEBHOOK_SECRET || 'monkos-default-secret';
```

**수정**:
```javascript
const authSecret = AUTH_SECRET || LEMONSQUEEZY_WEBHOOK_SECRET;
if (!authSecret) {
  console.error('[FATAL] AUTH_SECRET 환경변수 미설정. 서버 시작 불가.');
  process.exit(1);
}
```
→ 폴백 제거. env 미설정 시 **서버 시작 차단** (페일클로즈)
