# 구조화 데이터 + UI 언어 미분기 전수 감사

> **[2026-06-14 15:28 KST] iMac/쌍아 → 막내**
> 귀속: PF_SPECS
> 배경: GSC 검색어 28일간 전부 한국어 — 영/일 검색 노출 0. 원인 = 구조화 데이터·UI에 한국어 하드코딩이 영/일 페이지에 노출

---

## 목표

monkos.ai의 영문(/en)·일문(/ja) 페이지에서 한국어가 노출되는 모든 지점을 **전수 파악**하여 보고한다. 수정은 하지 않는다 (감사만).

---

## 감사 대상

### 1. 구조화 데이터 (JSON-LD) — 최우선

specs 렌더링 코드에서 JSON-LD를 생성하는 부분을 전수 확인:

| 스키마 | 확인 항목 | 알려진 문제 |
|---|---|---|
| **Article** | `headline`, `description`, `inLanguage` 유무 | `inLanguage` 필드 누락 |
| **FAQPage** | `Question.name`, `Answer.text` | EN/JA에서 언어 분기 여부 |
| **HowTo** | `step[].name`, `step[].text` | 🔴 전 언어 "균일 흰색" 한국어 하드코딩 확인됨 |

검증 방법:
- **코드 레벨**: `render-specs.js` 또는 해당 템플릿에서 JSON-LD 생성 로직 확인
- **prod 실측**: `/en/specs/passport/korea`, `/ja/specs/passport/korea` + 최소 2개 다른 문서(비자, ID카드)에서 JSON-LD 추출하여 한국어 혼입 확인

### 2. UI 텍스트 — 한국어 하드코딩

HTML 본문에서 언어 분기 안 된 한국어 텍스트 전수 확인:

| 위치 | 예시 | 확인 방법 |
|---|---|---|
| 간판/히어로 | "20년 사진작가..." | EN/JA 페이지에서 한국어 텍스트 grep |
| 버튼/CTA | "무료로 만들기" 등 | 〃 |
| 푸터/헤더 | 회사 정보, 약관 링크 | 〃 |
| 에러/빈 상태 | "데이터가 없습니다" 등 | 〃 |

검증 방법:
- prod에서 EN/JA 페이지 5종 이상 curl → 한국어 유니코드 범위(가-힣, ㄱ-ㅎ) grep
- 코드에서 하드코딩된 한국어 문자열 탐색

### 3. 사이트맵 내 언어 신호

- `sitemap-specs.xml`에서 EN/JA URL의 `<lastmod>` 등 메타데이터 확인
- 사이트맵에 hreflang `<xhtml:link>` 포함 여부
