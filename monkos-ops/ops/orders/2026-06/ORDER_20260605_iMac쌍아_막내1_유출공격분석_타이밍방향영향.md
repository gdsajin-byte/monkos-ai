## 배경 (작가님 확정 사실 — 2026-06-05)

`monkosimagepro` API 키가 유출돼 외부에서 호출당해 왔다. 작가님 정리 타임라인:
- **3/29**: Google Cloud compliance가 "MONKOS 프로젝트에 공개 액세스 가능한 API 키" 통보 (유출 감지).
- **⭐ 5/26 = 발생 변곡점**: 이날 이후 호출 **폭증**. 그리고 **묘하게 같은 시점에 키 관련 이슈들이 동시에 터졌다.** 유출이 먼저라 키 이슈가 눈에 띈 것인지, 그날 무슨 변경이 공격을 부른 것인지 — **인과를 집중 규명할 것** (집중 파악 핵심).
- **삭제 전(~6/2)**: 외부에서 **monkosimagepro(유출키)**로 대량 호출.
- **06-02 = 분기점**: 쌍아 유출 보고 → 작가님이 API 키 3개(monkosimagepro 포함) 삭제.
- **삭제 후(6/2~현재)**: 동일 공격이 **unknown key**로 표시 전환 → **403 Forbidden으로 차단**되며 계속 들이침.

> ⚠️ **"대만"은 확정 아님**: 출처가 대만이라는 건 M1/쌍아의 추정이다. **로그의 실제 IP/지역으로 검증**하라. 추정을 사실로 옮기지 마라.

**의심**: 이 유출 대량 호출이 그 달 결제원/한도/쿼터를 소진시켜, 정상 서비스(MONKOS NEW 키)까지 **429**로 멈춘 이번 라이브 장애의 **뿌리**일 가능성. (단 이는 가설 — 너의 포렌식으로 확정한다.)

> 🔴 **이 분석이 복구의 전제다**: 공격을 막지 못한 채 충전·한도상향하면 충전분도 공격자가 소진 → 위험 가중. **차단책이 서기 전까지 막내2 충전 금지.** 너의 차단 권고 + 작가님 승인이 복구의 게이트.

> ⚠️ **역할 분리**: 막내2가 **복구(결제원 회복)**를 담당한다. 너는 **공격 자체의 포렌식·위협 분석·방어 전략** 전담이다. 결제 복구는 건드리지 마라.
> ⚠️ **추론 금지**: 이 INCIDENT에서 화면 일부 기반 추론이 5회 빗나갔다. **Cloud Logging raw 로그·실측 숫자만** 근거로 삼아라.

## 작업

### 1. 공격 타임라인 포렌식 (Cloud Logging raw)
- `gcloud logging read` / Cloud Logging 콘솔로 유출키 호출 이력을 시간순 추출:
  - 최초 유출 호출 시점, 호출량 추이(일별/시간별), 피크 시점
  - **06-02 삭제 전후 변화** (monkosimagepro → unknown 전환 정확 시각)
  - 현재(6/5)까지 지속 여부 + 현재 빈도

### 2. 공격 방향·특성
- **출처**: IP/지역(대만 확인), ASN, User-Agent 등 식별 가능 지표
- **대상**: 어느 엔드포인트(ListModels 프로빙 vs generateContent 도용), 어느 모델, 어느 프로젝트
- **패턴**: 단순 키 유효성 프로빙인가, 실제 생성 호출 도용(비용 발생)인가, 호출 빈도·규모

### 3. 영향 정량화 (핵심)
- 유출 호출이 **비용/쿼터/한도에 미친 실제 영향**을 숫자로: 얼마를 소진시켰나.
- **삭제 후 현재도** 잠식이 지속되는가: 403으로 튕기는 호출이 **rate limit/쿼터/한도에 카운트**되어 정상 서비스를 계속 방해하는지.
- **정상 서비스 429와의 인과 기여도**: 유출 호출 급증 시점 ↔ 결제원/한도 소진 시점 대조 (막내2 빌링 분석과 교차).

### 4. 향후 위협·방어 전략 (권고안 — 작가님 승인 게이트)
- **6/19 데드라인**: "Unrestricted API keys will stop working on June 19, 2026" — 남은 키(MONKOS NEW) **제한 적용** 계획(application/IP/referrer/API 제한). 06-02 멈춘 키제한 오더와 연계.
- **공격 차단**: IP 차단 / Cloud Armor / WAF / API 제한 등 검토 + 적용 우선순위.
- **잔존 위험**: 다른 키 유출 가능성, 남은 MONKOS NEW 키 노출 경로 점검(어디에 박혀 있나, 클라이언트 노출 여부).

  - **차단됨 2개** (monk-data-factory: `검색기능key`·`data_factory_APIkey`, 둘 다 제한없음) — **차단 사유 규명**(유출·남용으로 Google 자동 차단? 5/26 공격과 연관?). 이게 단서일 수 있다.
  - **삭제 완결**: 06-02 삭제 3개(monkosimagepro·monkos_key·monk-aistudio-consol)는 AI Studio 목록엔 없으나 GCP soft-delete 상태 → **영구 처리 + 콘솔/다른 프로젝트 잔재 확인**.
  - **제한없음 3개** (검색기능key·data_factory_APIkey·67LQ) — 6/19 작동중지 데드라인 → 제한 추가 or 미사용 삭제.
  - **분산 = 공격 표면**: 4개 프로젝트 분산 키의 정리·통합 권고.
  - ⚠️ 키 삭제·제한·통합 실행은 작가님 승인(헌법 4조). 인벤토리·권고까지.
