# [긴급] 블로그 중복 포스트 정리 + 크롤러 중복 방지 + 홈 표출 정상화

**[2026-03-20 11:54 KST] iMac/쌍아 → 막내1**

## 상황

한송이가 실무 중 보고: 블로그에 사진 없는 과거 포스팅이 대량 중복 생성되어 최신 블로그·매거진 영역을 오염시키고 있음. 크롤러 재실행 또는 번역 로직 과정에서 기존 포스팅이 중복 생성된 것으로 추정.

## 버그 증상

1. **Firestore `blog_posts` 컬렉션에 중복 문서 대량 존재** — 같은 내용의 포스트가 slug-timestamp 형태로 복수 생성
2. **중복 포스트에 thumbnail 없음** — 크롤러의 `extractThumbnail()` 실패 또는 빈 문자열
3. **홈 매거진/최신블로그 영역에 빈 카드 배치** — thumbnail 없는 중복 포스트가 상위 노출

## 작업 1: Firestore 중복 포스트 조사 및 정리

### 1-1. 현황 파악 스크립트 작성

`scripts/blog-audit.js` 신규 작성 (일회용 감사 스크립트):

```
역할:
- blog_posts 전체 문서 조회
- 동일 title 또는 동일 originalSlug 기준 그룹핑
- 중복 그룹 리스트 출력 (slug, title, lang, thumbnail 유무, createdAt, sourceUrl)
- thumbnail 빈 문서 리스트 출력
- published=true인데 thumbnail 없는 문서 리스트 출력
```

**실행 후 결과를 보고서에 포함할 것.**

### 1-2. 중복 문서 정리

감사 결과를 기반으로:
- **원본 보존**: 가장 오래된 createdAt + thumbnail 있는 문서를 원본으로 인정
- **중복본 비발행 처리**: `published: false`로 변경 (삭제가 아닌 비발행)
- **정리 대상 목록을 보고서에 명시** (slug 목록)

⚠️ **문서 삭제(delete) 절대 금지** — 비발행 처리만. 작가님 확인 후 삭제 여부 결정.

### 1-3. 번역본 정합성 점검

- `autoTranslated: true`인 문서 중 `originalSlug`이 존재하지 않는 원본을 가리키는 경우 → 비발행
- 원본 1건에 JA/EN 각 1건만 존재하는지 확인
- 원본 slug과 번역본 slug 매핑 테이블 출력

## 작업 2: 크롤러 중복 방지 강화

### 2-1. `lib/cms/importer/naver.js` 수정

**현재 문제**: `isDuplicate()` (라인 90-99)가 `sourceUrl` 필드로만 중복 체크 → 기존 수동 작성 포스트에는 `sourceUrl` 없으므로 같은 제목의 포스트가 중복 생성됨.

**수정**:
```
isDuplicate() 함수에 3중 체크 추가:
1. sourceUrl 일치 → 중복
2. 동일 title 존재 → 중복 (정규화 후 비교: 공백·특수문자 제거)
3. 동일 slug 존재 → 중복 (ensureUniqueSlug로 넘기지 말고 스킵)
```

`ensureUniqueSlug()`의 timestamp suffix 로직 → **중복 시 생성 자체를 스킵**하도록 변경.

### 2-2. `lib/cms/importer/note.js` 동일 적용

note.js에도 같은 중복 방지 패턴 적용.

## 작업 3: 홈 표출 정상화

### 3-1. `lib/cms/home.js` 수정

**라인 84-90 부근**, `displayPosts` 생성 후:
- thumbnail 빈 문서 필터링: `filter(p => p.thumbnail && p.thumbnail.length > 0)`
- 번역본 제외: `filter(p => !p.autoTranslated)` (홈에는 원본만 표시)
- 최종 `blogs = displayPosts.slice(0, 4)` 전에 위 필터 적용

### 3-2. `lib/cms/render.js` 블로그 목록 수정

**라인 202-227 부근**, 블로그 목록 렌더링:
- `originalSlug` 기반 중복 제거 (같은 원본의 번역본이 혼재하지 않도록)
- 현재 요청 언어와 일치하는 포스트만 표시 (이미 구현되어 있으면 확인)
