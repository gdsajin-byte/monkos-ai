### Task 1: CLOTHING_FILTER — 연령 교차 필터 (P0 #1, #2)

**파일**: `monkos_AI/idphoto-kr/public/prep.js`

**현재**: CLOTHING_FILTER는 용도(purpose)만 기준. 연령 무관.

**수정**: `getFilteredOptions('clothing')` 내부에서 연령 후필터 추가.

CLOTHING_FILTER 테이블은 그대로 두고, `getFilteredOptions` 함수에서 연령 후필터를 적용:

```javascript
// getFilteredOptions 함수 내 clothing 분기 (약 line 191)

// 현재
if (key === 'clothing') return all.filter(o => (CLOTHING_FILTER[p] || []).includes(o.val));

// 변경
if (key === 'clothing') {
  let filtered = all.filter(o => (CLOTHING_FILTER[p] || []).includes(o.val));
  // 연령 후필터: baby/preschool → as_is만 허용
  if (['baby', 'preschool'].includes(selections.age)) {
    filtered = filtered.filter(o => o.val === 'as_is');
  }
  return filtered;
}
```

**효과**: passport×baby, color_portrait×baby 등에서 suit/shirt/casual/uniform 제거. as_is만 남음.
