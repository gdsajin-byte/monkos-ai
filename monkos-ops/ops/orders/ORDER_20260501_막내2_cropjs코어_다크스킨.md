# [2026-05-01 17:55 KST] iMac/쌍아 → 막내2

## 방향 전환 (작가님 직접 지시)

지금까지의 접근이 잘못됐다. HUD 프로토에 기능을 얹는 게 아니라, **이미 완성된 crop.js를 그대로 돌리고 CSS만 다크로 바꾸는 것**이다.

crop.js는 검증 완료된 크롭 엔진이다. 이걸 새로 짜는 게 아니라 그대로 가져온다.

## 작업

### 1단계: crop.js 그대로 작동시키기

`monkos_AI/crop-app/public/` 에서 아래 파일을 `apps/crop-app/`으로 **복사**:
- `crop.js` (엔진 전체)
- `crop.css` (기존 스타일)
- `index.html` (기존 HTML)
- `mediapipe/` (이미 복사됨)

복사 후 `apps/crop-app/`에서 `localhost:8080` 열어서 **기존과 동일하게 작동하는지 확인**.
- 35×45 판 잡히는지
- 8포인트 감지되는지
- 자동 배치(눈 43%, 얼굴 34mm) 되는지
- 정수리 조정 되는지
- 드래그 보정 되는지
- Canvas 크롭 출력 정확한지

**이 단계가 100% 통과해야 다음으로 간다.**

### 2단계: 다크 스킨 씌우기 (CSS만)

작동 확인 후, CSS만 변경하여 다크 HUD 디자인 적용:

```css
/* 기존 화이트 → 다크 전환 */
--bg: #05080E;
--panel: #0A0F18;
--accent: #00D4AA;
/* 등등 — style.css의 디자인 토큰 활용 */
```

변경 대상:
- 배경색 (화이트 → 다크)
- 텍스트색 (다크 → 라이트)
- SVG 오버레이 색상 (기존 Green/Yellow/Red 유지, 배경에 맞게 밝기 조정)
- 버튼/카드 스타일
- 판 밖 영역: 다크/블랙 (이미 다크 배경이니 자연스럽게 처리)

**엔진 로직(crop.js)은 한 줄도 수정하지 않는다.**

### 3단계: 5스텝 UX 전환

다크 스킨 확인 후, 기존 단일 페이지 → 5스텝으로 분리:

```
Step 1: 국가/문서 선택 (specs-data-v2 연동)
Step 2: 사진 업로드
Step 3: 크롭 (crop.js 코어 — 판 잡기 + 8포인트 + 자동 배치 + 수치 표시 + 조정)
Step 4: 배경 제거 (@imgly)
Step 5: 완료 + 다운로드 + 퍼널
```

Step 3이 crop.js의 핵심 화면 전체를 담는다:
- 규격별 판 (35×45, 51×51, 50×70 등)
- 판 밖 블랙
- 8포인트 SVG 오버레이
- 수치 패널 (즉시 표시)
- "조정하기" 선택 시 → 정수리 핀, 스케일, 드래그 활성화
- 조정 후 수치 실시간 갱신

### 4단계: specs-data-v2 연동

Step 1에서 선택한 규격이 crop.js의 SPECS를 오버라이드:
- `getSpec()` 반환값을 선택된 규격으로 교체
- FH, FW, MM 자동 재계산

## 원칙

1. **정확성 먼저** — 수치가 맞아야 그 다음이 있다
2. **crop.js 로직 수정 금지** — CSS만 변경
3. **단계별 검증** — 1단계 통과 전 2단계 진행 금지
