## 작업 1: EU Reg. 2252/2004 — 26국 B→A 일괄 승격 (§26)

EU Council Regulation (EC) No 2252/2004 기반. 기존 A 5국(de, fr, ee, gr + 기존) 제외 **26국 신규 승격**:

```
it, es, nl, pl, se, be, at, pt, cz, ro, dk, ie, hu, bg, hr, sk, si, lv, lt, lu, mt, cy, fi, no, is, ch, li
```

각 doc에:
- `"grade": "A"`
- `"source": "https://eur-lex.europa.eu/legal-content/EN/ALL/?uri=celex:32004R2252"`
- `"sourceName": "EU Reg. 2252/2004"`

## 작업 4: 기존 시트 A등급 국가 반영 (§36 리스트 교차)

§36에 명시된 **개별 .gov 확인 32국** 중 아직 A가 아닌 것들 전부 승격:

```
미국(us), 터키(tr), 홍콩(hk), 말레이시아(my), 카자흐스탄(kz), 
몰디브(mv), 라오스(la), 콜롬비아(co), 벨리즈(bz), 도미니카연방(dm),
자메이카(jm), 쿠웨이트(kw), 바레인(bh), 예멘(ye), 이라크(iq),
케냐(ke→이미 B+), 모리셔스(mu), 중국 비자(cn-visa)
```

- 각각 보고서에서 해당 국가의 source URL을 찾아 반영
- 보고서에 URL이 없는 경우 `"grade": "A"` + `"sourceName"` 만 기입

## 작업 6: 검증 + seed 재생성

```bash
# 등급 통계 출력
python3 -c "
import json
from collections import Counter
grades = Counter()
with open('apps/MonkosCrop/MonkosCrop/Resources/countries.jsonl') as f:
    for line in f:
        for d in json.loads(line).get('docs', []):
            grades[d.get('grade', 'none')] += 1
for g, c in sorted(grades.items()):
    print(f'{g}: {c}')
"
```
