# 지시서: Gemini 2.0 모델 아웃 정보 확보 + Gemini 3.1 Flash 도입방안 종합 보고

## 배경

- 2026-06-01 Gemini 2.0 모델 공식 아웃(서비스 종료/디프리케이션) 예정
- 현재 MONK OS 서비스에서 Gemini 모델 활용 중 (Imagen, AI 증명사진 파이프라인 등)
- 후속 모델 Gemini 3.1 Flash 등으로의 전환 전략 수립 필요
- 6/1까지 3주 — 사전 준비 시간 확보가 목적

## 임무

### 1. Gemini 2.0 아웃 정보 수집

WebSearch로 다음을 조사:

1. **공식 타임라인**: Gemini 2.0 디프리케이션 정확한 일정 (cutoff date, sunset date)
2. **영향 범위**: 어떤 API 엔드포인트가 영향 받는지 (generateContent, embedContent, etc.)
3. **마이그레이션 가이드**: Google 공식 마이그레이션 문서 존재 여부 + URL
4. **호환성**: 2.0 → 3.x 전환 시 API 호환/비호환 사항
5. **가격 변동**: 3.x 모델의 가격 체계 변화

### 2. Gemini 3.1 Flash 정보 수집

1. **모델 스펙**: 컨텍스트 윈도우, 입출력 토큰 한도, 멀티모달 지원 범위
2. **성능 벤치마크**: 2.0 대비 성능 변화 (텍스트/이미지/코드)
3. **가격**: 입력/출력 토큰 단가, 무료 티어
4. **API 변경사항**: SDK 버전 요구, 엔드포인트 변경, 파라미터 변경
5. **Flash vs Pro vs Ultra 라인업**: 현행 사용 모델 대체 매핑

### 3. 현행 MONK OS Gemini 의존성 파악

본진 코드에서 Gemini 사용처를 전수 스캔:

```bash
grep -rn "gemini\|generativeai\|google.generativeai\|genai" \
  monkos_AI/ apps/ functions/ scripts/ \
  --include="*.js" --include="*.py" --include="*.json" --include="*.env.example"
```

각 사용처에 대해:
| 파일 | 모델명 | 용도 | 영향도 | 전환 난이도 |
