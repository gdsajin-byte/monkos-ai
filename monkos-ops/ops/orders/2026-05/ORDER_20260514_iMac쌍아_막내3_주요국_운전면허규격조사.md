# 지시서: 주요국 운전면허 사진 규격 조사

## 목적

여권/비자에 이어 **운전면허(Driver's License)** 사진 규격을 주요 10개국에 대해 조사한다. 인구 많고 한국과 교류 많은 국가 위주.

## 대상 국가 (10개국)

한국, 일본, 미국, 중국, EU(독일 대표), 영국, 호주, 인도, 인도네시아, 베트남

## 산출물 구조

```
1. 전체 비교 테이블 (10국 × 15필드)
2. 여권 규격과 동일한 국가 목록
3. 운전면허 고유 규격 국가 목록
4. 현장촬영 전용 국가 (앱 대상 제외)
5. 앱 반영용 요약 테이블
```

## 조사 원칙

- **1차 출처(정부 공식)만**. 추정·환산 절대 금지
- 공식 미명시 = `미규정`
- 운전면허만. 국제운전면허(IDP)는 별도 기재 가능하나 구분할 것
- 많은 국가가 현장촬영 — 사진 제출 자체가 없는 경우도 명확히 기재

## ⚠️ 준수 조항

- 호주 1200×1600px 건처럼 **2차 출처 값을 공식으로 기재하지 말 것**
