## 작업

### T1. MediaPipe FaceMesh 통합
- `monkos_AI/crop-app/public/mediapipe/` 폴더를 `apps/crop-app/mediapipe/`로 복사
- `crop.js`의 FaceMesh 초기화 + 랜드마크 추출 로직 이식
- Step 2(업로드) 시점에 FaceMesh 분석 실행
- 결과: 눈 좌표, 턱 좌표, 정수리 추정, 얼굴 크기(mm)

### T2. 검수 연출 실데이터 연동
- 프로토의 더미 메트릭 → FaceMesh 실측값으로 교체
- 기울기: 양쪽 눈 Y좌표 차이
- 정면: 코끝 vs 좌우 볼 거리
- 얼굴 크기: (턱-정수리) / px-per-mm
- 밝기: Canvas getImageData로 얼굴 영역 평균 휘도

### T3. 배경 제거 연동
- 막내1의 `src/bg-remove.js` import (없으면 직접 @imgly 호출)
- Step 3에서 실제 배경 제거 실행
- 프로그레스 바 실진행률 표시
- 배경색 선택 → Canvas 합성

### T4. specs-data-v2 연동
- Step 1 국가 리스트 → `data/specs-data-v2.json`에서 로딩 (없으면 프로토 더미 데이터 유지)
- 국가/문서 선택 → 크롭 파라미터(사이즈, 비율) 자동 로딩
- 크롭 프레임 비율 실반영

### T5. Canvas 크롭 + 다운로드
- `crop.js`의 Canvas 크롭 파이프라인 이식:
  - CSS transform → Canvas 재현
  - object-fit: cover 재현
  - 규격 px 출력 (예: 413×531)
- Step 5 Download 버튼 → 실제 JPEG 다운로드 (`MONKOS_crop_{규격}_{px}.jpg`)

### T6. 오프라인 동작 확인
- MediaPipe WASM + 모델: 로컬 번들 (CDN 아님)
- @imgly: CDN 첫 로딩 후 IndexedDB 캐시
- 두 번째 실행부터 완전 오프라인 가능 확인
