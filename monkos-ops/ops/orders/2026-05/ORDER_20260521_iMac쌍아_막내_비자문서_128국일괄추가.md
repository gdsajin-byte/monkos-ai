# 지시서: 비자 문서 128국 일괄 추가

> **[2026-05-21 14:15 KST] iMac/쌍아 → iMac/막내**

## 배경

현재 151국 중 24국만 비자 문서 보유. 나머지 128국은 비자 탭에서 안 보임.
3그룹으로 나눠 일괄 추가한다.

## ⚠️ 준수 조항

- 정본: `apps/MonkosCrop/MonkosCrop/Resources/countries.jsonl`
- 기존 docs 훼손 금지. visa doc **추가만**.
- 이미 visa가 있는 24국은 건드리지 않는다.

---

## 그룹 1: EU/쉥겐 27국 — 쉥겐 비자 일괄 (35×45)

대상: de, fr, it, es, nl, pl, se, be, at, pt, cz, ro, dk, ie, hu, bg, hr, sk, si, lv, lu, mt, fi, no, is, ch, li

각 국가 docs에 추가:
```json
{
  "id": "{국가id}-visa",
  "type": "visa",
  "ko": "쉥겐 비자",
  "en": "Schengen Visa",
  "ja": "シェンゲンビザ",
  "size": "35x45",
  "head": "32-36",
  "std": "EU Reg. 2252/2004"
}
```

- grade: 해당 국가 passport와 동일 (대부분 A)
- bg: 해당 국가 passport의 bg 값 그대로 (프랑스=light-gray, 덴마크=gray 등)
- ie(아일랜드): 비쉥겐이지만 EU이므로 포함. std는 "INIS" 가능하나 35×45 동일이므로 쉥겐으로 표기해도 무방.

## 그룹 3: 나머지 ~93국 — 여권 규격 복사

비자 규격이 별도 확인되지 않은 국가. 여권 doc을 복제하여 visa doc 생성.

### 규칙

1. 해당 국가의 passport doc에서 `size`, `head`, `std`, `bg`, `faceTarget`, `dpi` 복사
2. id: `{국가id}-visa`
3. type: `"visa"`
4. 다국어: `"ko": "비자", "en": "Visa", "ja": "ビザ"`
5. grade: passport와 동일
6. warning, maxKB, minKB 등: 복사하지 않음 (비자별 미확인)
7. 현장촬영국(onsite=true): 비자는 onsite 미적용 (비자는 사전 제출)

### 제외 대상

- docs가 아예 없는 국가 (51국) — 건드리지 않음
- 이미 visa가 있는 24국 — 건드리지 않음

### 스크립트 로직

```python
for country in jsonl:
    if country has no docs: skip
    if country already has visa doc: skip
    if country in schengen_group: skip (그룹1에서 처리)
    if country in individual_group: skip (그룹2에서 처리)
    
    passport_doc = find doc with type="passport"
    if not passport_doc: skip
    
    visa_doc = copy passport_doc
    visa_doc.id = f"{country.id}-visa"
    visa_doc.type = "visa"
    visa_doc.names = {"ko": "비자", "en": "Visa", "ja": "ビザ"}
    # faceTarget, bg, grade, dpi 유지
    # warning, onsite, maxKB, minKB 제거
    
    country.docs.append(visa_doc)
```
