# [2026-05-01 17:10 KST] iMac/쌍아 → 막내2

## 문제 (작가님 확인, 쌍아 원인 특정)

사진 업로드 시 규격 프레임에 "탁" 안착하지 않음. 눈 높이 35%로 찍히고 배치가 안 맞음.

**원인**: 기존 `crop.js`의 렌더링 패턴과 현재 `app.js`의 CSS transform 좌표계가 불일치.

## 차이점

### 기존 crop.js (정상 동작)

```js
// 프레임: 고정 픽셀
frame.style.height = FH + 'px';  // 400px
frame.style.width = FW + 'px';   // FH * ratio

// 이미지: 중앙 기준 + 오프셋
photo.style.position = 'absolute';
photo.style.top = '50%';
photo.style.left = '50%';
photo.style.width = '100%';
photo.style.objectFit = 'cover';
photo.style.transform = `translate(calc(-50% + ${imgPos.x}px), calc(-50% + ${imgPos.y}px)) scale(${imgScale})`;
```

### 현재 app.js (깨짐)

```js
// 프레임: 퍼센트 기반 (72% 등)
frame.style.width = '72%';
frame.style.height = '72%';  // or h/ratio

// 이미지: -50% 누락
cropImg.style.transform = `translate(${state.imgPos.x}px, ${state.imgPos.y}px) scale(${state.imgScale})`;
```

## 수정 사항

### F1. 크롭 프레임을 고정 픽셀로 전환

```js
// autoPlaceFace()와 동일한 좌표계 사용
const FH = state.cropFrameH;  // 400
const FW = Math.round(FH * spec.wMm / spec.hMm);

frame.style.height = FH + 'px';
frame.style.width = FW + 'px';
// 뷰포트 내 중앙 정렬은 CSS flexbox/margin으로
```

### F2. 이미지 transform을 crop.js 패턴으로 교체

```js
cropImg.style.position = 'absolute';
cropImg.style.top = '50%';
cropImg.style.left = '50%';
cropImg.style.width = '100%';
cropImg.style.objectFit = 'cover';
cropImg.style.transform = `translate(calc(-50% + ${state.imgPos.x}px), calc(-50% + ${state.imgPos.y}px)) scale(${state.imgScale})`;
```

### F3. 프레임 밖 다크 마스킹 유지

프레임이 고정 픽셀로 바뀌어도 `box-shadow` 또는 `::after` 오버레이로 밖을 블랙 마스킹 유지.

### F4. 검증

수정 후 아래 확인:
1. 한국 여권(35×45) 선택 → 사진 업로드 → 눈이 프레임 상단 43% 근처에 자동 배치
2. 미국 여권(51×51) 선택 → 정사각형 프레임 + 자동 배치
3. 드래그로 미세 보정 가능
4. Canvas 크롭 출력이 프레임과 정확히 일치
