### 3. SEO 스캔 — 기존 이슈 억제 + 신규만 긴급

**현상**: monkos.ai/kr(404), monk.kr(403) 등 4건이 매일 반복 → "긴급"의 의미 퇴색
**위치**: `seo_scan()` (L131~140) + `detect_anomalies()` (L210~228)

**수정 방향**:

`KNOWN_ISSUES` 목록을 스크립트 상단에 정의:
```python
KNOWN_SEO_ISSUES = {
    "https://monkos.ai/kr": 404,
    "https://monkos.ai/jp": 404,
    "https://monk.kr": 403,
    "https://monk.kr/blog": 403,
}
```

`seo_scan()`에서:
- 기존 이슈(KNOWN)는 `🟡` (참고)로 분류, `🔴` (긴급) 아님
- KNOWN에 없는 **신규** 이슈만 `🔴`로 보고
- KNOWN 이슈가 **해소**되면(200 복귀) `✅ 복구됨` 보고

`detect_anomalies()`에서:
- SEO 이상 카운트를 신규 이슈 수로만 계산

**출력 예시** (신규 없을 때):
```
## 🔧 SEO 스캔
- ✅ 신규 이상 없음
- 🟡 기존 이슈 4건 유지 (monkos.ai/kr 404, monkos.ai/jp 404, monk.kr 403, monk.kr/blog 403)
```

### 6. 소규모 트래픽 변동 — 절대 수치 병기

**현상**: GSC 클릭 4→2 = "-50%" — 퍼센트만 보면 급락처럼 보이지만 절대 수치가 미미
**위치**: `pct_change()` (L231~236) + 성과 테이블 (L263~266)

**수정**: `pct_change()`에 절대 수치 임계값 로직 추가:
```python
def pct_change(now, before):
    if before == 0:
        return "N/A" if now == 0 else "+∞"
    change = (now - before) / before * 100
    sign = "+" if change >= 0 else ""
    # 절대 수치가 10 미만이면 퍼센트 대신 절대 변동 표시
    if before < 10 and now < 10:
        diff = now - before
        sign = "+" if diff >= 0 else ""
        return f"{sign}{diff}"
    return f"{sign}{change:.0f}%"
```
