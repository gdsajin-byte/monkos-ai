# 지시서: 가이드 이미지 좌표 보정 — 크롭 후 얼굴 좌표 재계산

> **[2026-05-20 15:28 KST] iMac/쌍아 → iMac/막내1**

## 문제

생성된 가이드 이미지에서 **가이드라인이 실제 얼굴 위치와 안 맞음:**
- HEAD TOP이 정수리보다 훨씬 위
- CHIN이 턱이 아니라 사진 하단
- EYE LINE이 눈보다 아래 (코 위치)

## 원인

`generate-guide-images.js` 117~158행. 크롭 로직(scale, cropX/Y/W/H)은 올바르지만, **가이드라인 Y좌표를 `outH * 비율`로 그리고 있음.** 크롭 후 출력 이미지에서의 실제 얼굴 좌표로 변환해야 함.

## 수정

가이드라인 Y좌표는 크롭+리사이즈 변환을 적용해서 계산해야 함:

```javascript
// 크롭 후 → 출력 이미지 좌표 변환
const mappedCrownY = (FACE.crownY - cropY) / cropH * outH;
const mappedEyeY   = (FACE.eyeY   - cropY) / cropH * outH;
const mappedChinY  = (FACE.chinY  - cropY) / cropH * outH;
const mappedShoulderY = (FACE.shoulderY - cropY) / cropH * outH;
```

이 mapped 좌표를 가이드라인 drawGuideLine()에 전달.

## 검증

- korea-passport.webp: HEAD TOP이 정수리 바로 위, CHIN이 턱 위치, EYE LINE이 눈높이
- united-states-visa.webp: 1:1 정사각에서도 동일하게 정확
- canada-passport.webp: 5:7 세로장형에서도 정확
