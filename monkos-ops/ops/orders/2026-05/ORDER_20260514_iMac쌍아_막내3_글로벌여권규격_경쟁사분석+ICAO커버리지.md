# 지시서: 글로벌 여권 규격 경쟁사 현황 + ICAO 커버리지

## 목적

경쟁사들이 "150개국 지원" 등을 광고하고 있다. 실제로 몇 개국을 지원하는지, 어떤 방식으로 커버하는지, ICAO 9303 기본 규정으로 실질적으로 몇 개국이 커버되는지를 파악한다.

## 작업

### 1. 경쟁사 현황 분석

아래 주요 경쟁 서비스 사이트에 직접 들어가서 조사:

- **passport-photo.online** (가장 많은 국가 광고)
- **visafoto.com**
- **iVisa Photos**
- **PhotoAiD**
- **IDPhotoDIY**
- **기타 발견되는 주요 서비스**

각 서비스별:
| 항목 | 조사 내용 |
|------|----------|
| 광고 국가 수 | "150+ countries" 등 어떻게 표기하는지 |
| 실제 규격 DB | 몇 종류의 규격을 실제 보유하는지 (사이즈 종류 수) |
| 커버 방식 | 국가별 독자 규격인지, ICAO 기본으로 뭉치는지 |
| 수익 모델 | 무료/유료/구독/컷당 과금 |
| AI 사용 여부 | 배경 제거, 자동 크롭, AI 보정 등 |
| 품질 | 실제 결과물 품질 평가 (스크린샷 불필요, 텍스트 평가) |
| 특이사항 | |

### 2. ICAO 커버리지 분석

UN 회원국 193국 + 주요 비회원 영토 기준:

**질문 1**: ICAO 9303 기본 규정(35×45mm, 32~36mm 얼굴)으로 여권 사진이 통과되는 국가는 실질적으로 몇 개국인가?

**질문 2**: ICAO와 다른 독자 규격을 쓰는 국가는 총 몇 개국인가? 전수 리스트 작성.

**질문 3**: 경쟁사들의 "150개국"이 실제로 150종 규격인지, 아니면 ICAO 1종 + 독자 규격 N종을 합산한 것인지?

### 3. ICAO 기본으로 커버 불가능한 국가 전수 리스트

막내2 보고서(v2)의 20개국 외에 **ICAO와 다른 독자 규격**을 쓰는 나라를 추가 발굴:

```
| 국가 | 사이즈 | ICAO와 차이점 | 출처 |
```

웹서치 적극 활용. 경쟁사 사이트의 규격 DB도 2차 참조로 활용 가능하되, 공식 출처와 교차 확인.
