## 임무

### 1. 전수 스캔 상세화

위 사전 스캔을 기반으로 각 폴더/파일을 읽고 다음을 판정:

| 판정 | 기준 |
|------|------|
| **본진 이관** | monk_project 레포에 정본이 있어야 할 문서 (R&D 산출물, 전략 문서 등) |
| **GDrive 이관** | 바이너리 원본 (PDF, 이미지) — Git 부적합, GDrive 보관 대상 |
| **현위치 유지** | 로컬 필수 (앱 데이터, 진행 중 서류) |
| **삭제** | 빈 폴더, 중복, 임시 파일 |
| **아카이브** | 종결된 프로젝트의 증빙 (소송, 이의신청 — 삭제 불가, 별도 보관) |

### 2. 폴더별 정리 제안

각 폴더에 대해:
- 현재 상태 요약
- 정리 방향 (이관/삭제/유지/아카이브)
- 이관 시 대상 위치 (본진 경로 또는 GDrive 경로)

### 3. 레거시 폴더 처리안

- `쌍아/`: 본진 이관 완료된 것 vs 미이관 판별
- `철창이/` (`cheolchang/`): 동일
- 두 폴더 병합 가능 여부
