# 지시서: 증명사진 규격 전수조사 — 아프리카 (54국)

## 목적

`apps/MonkosCrop/MonkosCrop/Resources/countries.jsonl`에 등록된 200개국 데이터의 정확성을 1차 출처 기반으로 검증한다. 본 지시서는 **아프리카 54국 + 미등록 1국 = 55국**을 담당한다.

## 대상 국가

JSONL에서 `"continent":"africa"`인 전 국가.

### 미등록 국가 추가 등록 (아프리카)
아래 1국을 JSONL에 직접 추가한다 (africa, docs 빈 배열 = ICAO 기본):
- **상투메프린시페** (São Tomé and Príncipe, サントメ・プリンシペ) — id: `st`

※ 해외 영토·속령(레위니옹, 마요트 등)은 본국(프랑스) 규격 준용이므로 별도 등록 불필요.

## 검증 항목

### 1. 국가명 3개 국어 정확성
- `ko` (한국어), `en` (영어), `ja` (일본어) 국가명 확인
- 오타, 구버전 명칭(예: 에스와티니↔스와질란드), 비공식 표기 색출

### 2. ICAO 기본 적용 국가 (전 국가 해당)
- 해당 국가가 실제로 ICAO 35×45mm 규격을 사용하는지 확인
- **비표준 국가 색출**: 특히 주의:
  - 프랑스권 아프리카: 35×45 유지 가능성 높으나 확인 필요
  - 영국권 아프리카: 독자 규격 가능 (남아공 등)
  - 나이지리아, 이집트 등 주요국 독자 규격 여부
- 얼굴 높이 범위가 ICAO 기본(32–36mm)과 다른 경우 보고

### 3. 특이점 조사 (핵심 — 각국 카드 데이터용)

본 조사는 크롭앱뿐 아니라 **본진 monk.kr/monkos.ai specs 페이지의 각국 카드를 대대적으로 강화**하기 위한 기초 데이터다. 기본 규격 외에 아래 특이점을 반드시 조사·기록한다:

- **발급 위치별 규격 차이**: 국내 신청 vs 현지 발급 규격이 다른 경우
- **비자 유형별 차이**: 관광/취업/학생 비자 간 규격이 다른 경우
- **여권 vs 비자 규격 분기**: 동일국에서 여권과 비자의 사이즈가 다른 경우
- **배경색 제한**: 백색 필수, 파란색 필수, 빨간색 금지 등 특수 배경 요구
- **안경 규정**: 착용 금지 여부 (ICAO 2021 이후 원칙적 금지이나 국가별 차이)
- **AI 생성/보정 금지**: 명시적 AI 금지 규정이 있는 국가
- **전문 사진사 필수**: 공인 사진사 촬영 의무 국가
- **최근 규격 변경**: 2024년 이후 규격이 변경된 경우 (변경 전/후 기록)
- **디지털 제출 규격**: 온라인 제출 시 별도 px/용량 제한이 있는 경우
- **기타 특이사항**: 머리 스카프/히잡 허용, 유아 사진 별도 규정, 유효기간 제한 등

각국 1건 이상의 특이점이 발견되면 기록. 특이점이 없는 국가는 "특이점 없음 (순수 ICAO)" 표기.

### 4. 누락 국가
- 아프리카에서 JSONL에 빠진 국가가 있으면 보고 (AU 회원국 55국 기준)
