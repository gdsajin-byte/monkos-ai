# [2026-05-01 17:35 KST] iMac/쌍아 → 막내2

## 문제

노란 눈 포인트가 눈이 아니라 **눈썹 위에** 찍히고 있음 (작가님 확인).
FaceMesh 인덱스(#159, #386)는 정상 — 기존 crop.js에서 같은 인덱스로 정확히 동작함.

**원인**: 검수 오버레이(눈 점, 눈 라인, 정수리/턱 라인, 얼굴 타원)의 좌표가 auto-placement 변환(`toFrame()`)을 거치지 않고 **원본 이미지 비율**로 직접 찍히고 있음.

## 구체적 버그 위치

### 832행: 눈 라인
```js
// 현재 (잘못됨) — 원본 비율 그대로 퍼센트로
eyeLine.style.top = `${(faceData.eyeCenterY * 100).toFixed(1)}%`;

// 수정 — toFrame 변환 후 프레임 내 좌표
const eyeFrameY = toFrame({ x: 0, y: faceData.eyeCenterY }).y;
eyeLine.style.top = `${eyeFrameY}px`;
```

### 노란 눈 포인트, 정수리/턱 라인, 얼굴 타원 등
검수 시퀀스에서 그리는 **모든 오버레이 좌표**가 같은 문제.
`faceData`의 raw 좌표를 직접 사용하지 말고, `toFrame()`으로 변환한 프레임 좌표를 사용해야 함.

## 수정 방법

1. `computeMetrics()` 함수에 이미 `toFrame()` 로직이 있음 (235~241행)
2. 검수 시퀀스(`runInspection`)에서도 동일한 `toFrame()`으로 좌표 변환
3. 변환된 좌표를 오버레이 요소의 `top/left` 또는 SVG `cx/cy`에 적용

## 기존 crop.js 참조

기존 crop.js(350~351행)에서 눈 포인트 렌더링:
```js
setAttrs('pupilL', { cx: pts.leftPupil.x, cy: pts.leftPupil.y, fill: ec });
setAttrs('pupilR', { cx: pts.rightPupil.x, cy: pts.rightPupil.y, fill: ec });
```
여기서 `pts`는 `autoPlace()`의 반환값 — 이미 프레임 좌표로 변환된 상태.

## 검증

수정 후:
1. 노란 점이 **눈(홍채) 위에 정확히** 위치
2. 눈 라인이 양쪽 눈을 관통
3. 정수리/턱 라인이 실제 위치에 대응
4. 얼굴 타원이 얼굴 윤곽에 맞음
