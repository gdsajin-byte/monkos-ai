# 지시서: PhotoMonk PoC 보강 — 카메라 각도 + Core Image + 우선순위 코칭

## 배경

PoC 기본 구조 완료. 작가님 실무 경험 기반 추가 요구사항 3건 반영.

버킷 저장된 실제 촬영본 분석 결과: **폰을 아래에 놓고 올려다보는 각도**로 찍은 케이스가 대다수(특히 남성). 이 각도 문제를 AI가 보정하기엔 한계가 있어 촬영 시점에서 잡아야 함.

## 임무

### 1. 카메라 각도 감지 (신규 규칙 추가)

| 규칙 | Vision 데이터 | 조건 | 메시지 |
|------|-------------|------|--------|
| 아래에서 올려봄 (pitch up) | 눈~턱 랜드마크 y비율 + 이마 비율 축소 | 이마:턱하단 비율 < 0.4 | **"카메라를 눈높이로 올려주세요"** |
| 위에서 내려봄 (pitch down) | 이마 비율 과대 | 이마:턱하단 비율 > 0.7 | "카메라를 살짝 내려주세요" |
| 턱 돌출 | 턱 y좌표가 프레임 하단 75% 이하 | bbox 기준 | "턱을 살짝 당겨주세요" |

### 2. Core Image 조명/선명도 분석

Gemini 사전분석의 조명/선명도 항목을 온디바이스로 대체.

| 항목 | Core Image 방법 | 판단 기준 | 메시지 |
|------|---------------|----------|--------|
| **밝기 부족** | CIImage → CIAreaAverage → 평균 밝기 추출 | luminance < 0.3 | "조명이 어둡습니다. 밝은 곳으로 이동해주세요" |
| **역광** | 얼굴 bbox 영역 밝기 vs 배경 밝기 비교 | 배경이 1.5배+ 밝으면 | "역광입니다. 빛을 등지지 마세요" |
| **흔들림/초점** | Laplacian variance (CIFilter convolution) | variance < threshold | "흔들림이 감지됩니다. 카메라를 고정해주세요" |
| **그림자** | 얼굴 좌/우 반쪽 밝기 차이 | 차이 > 30% | "얼굴에 그림자가 있습니다. 조명을 조정해주세요" |

### 3. 우선순위 코칭 (단계별 안내)

현재: 모든 문제를 동시에 표시 → 정신없음
변경: **가장 중요한 1개만 표시, 해결되면 다음**

우선순위 (높은 것부터):
1. 얼굴 없음
2. 다수 얼굴
3. 카메라 각도 (눈높이)
4. 정면성 (yaw/roll)
5. 얼굴 크기 (거리)
6. 조명 (밝기/역광/그림자)
7. 선명도 (흔들림)
8. 눈 감김
9. 전부 통과 → 🟢 "촬영하세요!"

구현:
- CoachingEngine에서 규칙을 우선순위 순으로 평가
- 첫 번째 실패 규칙의 메시지만 UI에 표시
- 🔴 = 상위 3개 중 하나라도 실패
- 🟡 = 4~8번 중 실패
- 🟢 = 전부 통과

### 4. 기존 코드 수정 사항

- `CoachingEngine.swift` — 규칙 추가 + 우선순위 로직
- `CameraManager.swift` — Core Image 분석 파이프라인 추가 (프레임 콜백에서)
- `CoachingView.swift` — 단일 메시지 표시로 변경 (여러 개 → 1개)
- `SpeechCoach.swift` — 우선순위 변경 시에만 음성 (같은 메시지 반복 방지)
