# [2026-05-01 16:53 KST] iMac/쌍아 → 막내2

## 문제 (작가님 직접 지적)

1. **자동 배치 없음**: 사진이 규격 프레임에 "탁" 안착하는 과정이 빠져 있다. 분석기만 돌아가는 상태.
2. **규격 미반영**: 미국 여권(51×51)을 선택해도 35×45 프레임이 나온다. 선택한 규격이 크롭 프레임을 결정해야 한다.
3. **스텝 순서 틀림**: 틀(크롭)을 먼저 잡고 → 배경 교체가 맞다. 현재 BG(3) → CROP(4) 순서를 뒤집어야 한다.

## 보정 작업

### B1. 스텝 순서 교체

```
현재:  SELECT → UPLOAD → BG(3) → CROP(4) → DONE
수정:  SELECT → UPLOAD → CROP(3) → BG(4) → DONE
```

- 프로그레스 바 라벨도 교체
- 스텝 전환 로직(goToStep) 순서 반영

### B2. 규격 프레임 동적 생성

Step 1에서 국가/문서 선택 시 → `specs-data-v2.json`의 해당 항목 로딩:

```js
// 예: 미국 여권 선택 시
state.spec = { w_mm: 51, h_mm: 51, px: { w: 600, h: 600 } }  // 정사각형
// 예: 한국 여권 선택 시
state.spec = { w_mm: 35, h_mm: 45, px: { w: 413, h: 531 } }  // 직사각형
```

Step 3(크롭) 진입 시 → `state.spec.w_mm / h_mm` 비율로 크롭 프레임 렌더링.
51×51이면 정사각형 프레임, 35×45면 직사각형 프레임.

### B3. FaceMesh 자동 배치 (핵심 — crop.js에서 이식)

기존 `monkos_AI/crop-app/public/crop.js`의 auto-placement 로직:

```
1. FaceMesh로 눈 좌표(#159, #386 중점), 턱(#152) 감지
2. 정수리 추정: crownY = eyeY - (chinY - eyeY)
3. 얼굴 크기(mm) 계산: (chin - crown) / px_per_mm
4. 스케일: 얼굴이 faceTarget mm가 되도록 이미지 확대/축소
5. 포지션: 눈이 프레임 상단 43% 지점에 오도록 Y 배치
6. 센터: 얼굴 중심이 프레임 수평 중앙에 오도록 X 배치
```

이 로직이 Step 2(업로드) 직후 자동 실행되어, Step 3(크롭) 진입 시 사진이 프레임에 **"탁" 맞춰진 상태**로 표시되어야 한다.

사용자는 이미 맞춰진 결과를 보고 → 필요 시 미세 보정(드래그) → 검수 실행.

### B4. Canvas 크롭 출력 규격 반영

Step 5(완료) 다운로드 시 → `state.spec.px`로 출력:
- 한국 여권: 413×531px JPEG
- 미국 여권: 600×600px JPEG
- 파일명: `MONKOS_crop_{규격id}_{w}x{h}.jpg`

### B5. 크롭 프레임 시각 강조

- 프레임 **밖**은 블랙(또는 반투명 다크) 마스킹 — 프레임 안만 밝게
- 인화지 위에 사진이 올라간 느낌: 프레임에 미세 그림자/엣지 글로우
- 다크 HUD 배경과 자연스럽게 연결 — 프레임 밖 = 앱 배경과 동화
- 사용자 시선이 프레임 안쪽(크롭 결과)에 집중되는 구조

### B6. 검수 메트릭 규격 반영

- 얼굴 크기 판정: 규격별 headHeight (min/max mm) 기준
- 눈 위치 판정: 공식 규정 있는 4건은 해당 값, 나머지는 ICAO 권장 가이드(40~48%)
- "ICAO 이내" 같은 고정 문구 → 실제 선택된 표준명 표시
