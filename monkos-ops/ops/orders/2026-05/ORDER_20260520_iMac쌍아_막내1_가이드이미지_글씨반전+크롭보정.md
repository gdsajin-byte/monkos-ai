# 지시서: 가이드 이미지 — 글씨 반전 수정 + 크롭 비율 보정

> **[2026-05-20 16:59 KST] iMac/쌍아 → iMac/막내1**

## 문제 2건

### 1. 글씨 좌우 반전

"정수리", "턱", 치수 라벨, 스펙 배지 텍스트가 전부 좌우 반전되어 출력됨. CropView 또는 Core Graphics 렌더링 시 좌표계 flip 처리가 안 된 것. CGContext의 좌표계가 뒤집혀 있을 가능성 — `textMatrix` 또는 `scaleBy(x:1, y:-1)` 확인.

### 2. 크롭 과도 — 얼굴이 너무 큼

현재: 얼굴이 프레임을 거의 가득 채움. 어깨가 거의 안 보이거나 잘림.

**기준**: IDPASS 크롭 화면 스크린샷 (미국 51×51) 참조:
- 정수리 위에 **적절한 여백** (프레임 상단의 약 10~12%)
- 턱 아래에 **어깨·옷깃이 충분히 보임** (프레임 하단의 약 15~20%)
- 얼굴 길이가 프레임 세로의 약 **65~70%** 수준 (규격의 head_max_mm/h_mm 비율 그대로가 아니라, 보기 좋게 약간 여유 있게)

즉 CropEngine의 crop() 결과 그대로가 아니라, **가이드 표시용으로 약간 줌아웃**해서 전체 모습이 보이도록.

## 수정 방향

### 글씨 반전
- Core Graphics에서 텍스트 렌더링 전 `context.saveGState()` → `context.textMatrix = .identity` 확인
- 또는 이미지 export 시 최종 `UIImage`를 `draw(in:)` 할 때 좌표 변환 확인

### 크롭 보정
- export 모드에서 scale을 **0.85배** 줄이기 (현재 크롭 영역을 바깥으로 15% 확장)
- 또는 `topMargin`과 `bottomMargin`을 늘려서 여유 확보
- 목표: 정수리~턱 = 프레임 세로의 약 65~70%, 나머지 위아래 여백

## 검증

- 35x45: 글씨 정상 출력 + 정수리 위 여백 + 어깨 보임
- 51x51: 1:1 정사각에서도 동일
- 50x70: 세로 장형에서 어깨·상체 충분히 보임
