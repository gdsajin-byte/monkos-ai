# 지시서: 가격 전수조사 보정 — 컷당 단가 추가

## 배경

전수조사 보고서에 서비스별 최소 결제 금액은 있으나, **1컷당 실질 단가**가 빠져 있음.
$5에 1장과 $5에 6장은 전혀 다른 포지셔닝이므로 보정 필수.

## 임무

`REPORT_20260518_막내1_AI증명사진_가격전수조사.md`에 다음을 추가:

1. **전수조사 테이블 2-A/B/C 각 행에 열 추가**: `컷당 단가 (USD)` — 최소 결제 시 받는 컷 수로 나눈 실질 장당 가격
   - 예: $5/6장 = $0.83/장, ₩2,500/8장 = $0.23/장
   - 1장 = 1장이면 그대로 기재
   - 미확인 시 "미확인" 표기

2. **§3 가격 분포 분석도 컷당 기준으로 재정렬** — 서비스 단위가 아닌 장당 단가 기준 분포

3. **§8 포지셔닝 맵도 컷당 단가 기준으로 보정**

4. **기능 유형별 분리 테이블** — 47개 서비스를 아래 3카테고리로 분리하여 각각 독립 테이블 제시:
   - **A. 단순 크롭** (L1) — 크롭/가이드라인만 제공, AI 없음
   - **B. 배경제거 + 크롭** (L2~L3) — AI 배경제거 + 규격크롭 + 규정검증. 원본 사진 기반
   - **C. AI 생성/보정** (L4) — AI로 의상/헤어/피부 보정 또는 이미지 자체를 생성. 원본과 다른 결과물
   - 각 테이블에 컷당 단가 포함
   - 카테고리별 중앙값/최빈값/평균 별도 산출
   - MONKOS가 속하는 카테고리 명시
