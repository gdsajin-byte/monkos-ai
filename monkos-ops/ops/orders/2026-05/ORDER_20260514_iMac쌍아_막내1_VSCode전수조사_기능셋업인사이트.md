# 지시서: VSCode 최신 업데이트 전수조사 + MONK 도입 인사이트

## 목적

VSCode가 최근 수개월간 빈번하게 릴리즈되며 기능적 변화가 많았다. 확장(Extension)도 대거 업데이트된 것으로 추정. **현재 MONK 환경(iMac 워크스테이션, Claude Code 연동, 멀티에이전트 운용)에 도입할 수 있는 인사이트를 채굴**하라.

## 조사 범위

### 1. VSCode 코어 업데이트 (2025-12 ~ 2026-05)

- **릴리즈 노트 전수 스캔**: 최근 6개월간 major/minor 릴리즈
  - 새 기능, 변경된 기능, deprecated 기능
  - 에디터/터미널/디버깅/Git 관련 변화
  - AI/Copilot 통합 관련 변화 (특히 Claude Code와의 시너지/충돌 가능성)
  - 멀티루트 워크스페이스, 프로파일, 설정 동기화 관련

### 2. 확장(Extension) 생태계 변화

- **현재 설치된 확장 목록** 수집 (`code --list-extensions`)
- 각 확장의 최근 업데이트 내역 중 주요 변경점
- **새로 주목할 만한 확장** (AI 관련, 생산성, Git, 마크다운, 한국어 지원 등)
- deprecated되거나 대체된 확장 파악

### 3. MONK 환경 셋업 진단

- 현재 VSCode 버전 및 설정 상태 확인
- `.vscode/settings.json`, `*.code-workspace` 설정 점검
- Claude Code 확장 연동 상태 및 최적화 여부
- 키바인딩, 스니펫, 프로파일 활용 상태

### 4. MONK 도입 인사이트 (핵심)

조사 결과를 바탕으로 **아래 관점에서** 인사이트 도출:

| 관점 | 질문 |
|------|------|
| **멀티에이전트 효율** | 쌍아/막내 동시 작업 시 VSCode 기능으로 개선할 수 있는 점? |
| **세션 관리** | 세션 로그 작성, 타임스탬프, 문서 네이밍 자동화에 활용 가능한 기능? |
| **Claude Code 시너지** | Claude Code 확장의 최신 기능 중 활용 미흡한 부분? |
| **코딩 품질** | 린팅, 포맷팅, 타입체크 등 코드 품질 자동화 도입 여부? |
| **보안/비밀정보** | `.env` 보호, 시크릿 감지 확장 등 헌법 4조 보강 수단? |
