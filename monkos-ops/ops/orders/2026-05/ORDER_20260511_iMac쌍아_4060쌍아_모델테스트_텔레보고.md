2/14에 동일한 SSH 문제 발생 + 해결 기록 있음:
- Windows OpenSSH는 **관리자 계정이면 `~/.ssh/authorized_keys` 무시**
- `C:\ProgramData\ssh\administrators_authorized_keys`에 등록해야 함

```powershell
# 관리자 PowerShell에서 실행
Add-Content "C:\ProgramData\ssh\administrators_authorized_keys" "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAICstbhz9x1KMT00ZxMVZKK5Rhsn4yoSP0KC3u0p+cXCd jeong-kyushin@monk.kr"
icacls "C:\ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "SYSTEM:(F)" /grant "Administrators:(F)"
```

이번에 확실히 해결하고 iMac에서 `ssh 4060 "echo ok"` 테스트까지 완료할 것.

## 임무 3: 텍스트 모델 벤치마크

추적 테이블(`PF_FACTORY/data/model_tracking.csv`)에서 **4060 VRAM 8GB로 구동 가능한** 텍스트 모델 3~5개를 선별하여 벤치마크.

### 테스트 대상 (추천)

| 모델 | 파라미터 | 이유 |
|------|---------|------|
| EXAONE-3.5-2.4B | 2.4B | 이미 로컬에 GGUF 존재. 한국어 특화 |
| Qwen3-1.7B 또는 4B | 1.7B/4B | 추적 테이블에 있을 것. MoE 경량 |
| Gemma 3 4B | 4B | 다국어, 4060 적합 |
| Phi-4-mini (3.8B) | 3.8B | 추론 강점 |

추적 테이블에서 8GB VRAM 이내 모델을 자체 판단으로 선별해도 좋음.

### 벤치마크 항목

```python
# 각 모델에 대해:
1. 모델 로드 시간 (초)
2. VRAM 사용량 (MB)
3. 추론 속도 (tokens/sec) — 동일 프롬프트 3회 평균
4. 한국어 품질 테스트:
   - "증명사진 촬영 시 주의사항 3가지를 알려주세요" → 응답 품질 주관 평가 (1~5점)
   - "MONKOS AI 서비스를 한 문장으로 소개해주세요" → 응답 품질
5. 영어 품질 테스트:
   - "List 3 tips for taking a passport photo" → 응답 품질
```
