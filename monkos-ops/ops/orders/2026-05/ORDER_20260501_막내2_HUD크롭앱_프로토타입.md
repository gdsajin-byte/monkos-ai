## 작업

### T1. 프레임워크 선정 + 근거
아래 옵션 비교 후 하나 선택:

| 옵션 | 장점 | 단점 |
|------|------|------|
| Vanilla HTML/CSS/JS | 의존성 0, 번들 최소 | 스텝 전환 상태 관리 수동 |
| Svelte | 컴파일 결과 = vanilla 수준, 컴포넌트 분리 | 빌드 필요 |
| Preact | React 호환 3KB, 철창이 JSX 활용 | JSX 컨셉이므로 코드 직접 사용은 제한적 |

판단 기준: 번들 사이즈 + 모바일 성능 + 개발 생산성. 제안과 근거 제시.

### T2. 5스텝 UX 프로토 구현
PF_CROP 기획서 기준:

```
[Step 1] 국가 + 문서 선택 — 국기 리스트 + 검색 + 규격 카드
[Step 2] 사진 업로드 — 가이드 일러스트 + 촬영 팁
[Step 3] 배경 제거 — 색상 선택 (디폴트 흰색)
[Step 4] 크롭 조정 — 프레임 표시 + FaceMesh 자동 + 보정 옵션
[Step 5] 완료 + 퍼널 — 다운로드 + 텔레그램 공유 + MONKOS OG
```

- 각 스텝의 UI 레이아웃 + 전환 애니메이션
- FaceMesh/배경제거 실제 연동은 불필요 — UI 목업 + 더미 데이터로 플로우 시연

### T3. MONKOS 검수 연출 시퀀스

```

  양쪽 눈 점 + 사선 점선 → "기울기 0.3° — 양호 ✓"
  정면 판정선 → "정면 확인 ✓"
```
