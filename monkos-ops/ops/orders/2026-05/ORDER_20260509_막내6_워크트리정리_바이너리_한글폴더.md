## 임무

### 1. 워크트리 잔해 처리 (./monk_project/)

#### 1-1. 산출물 스캔

`./monk_project/` 하위 20개 디렉토리를 순회하며, 본진에 없는 파일을 탐지:

```bash
# 각 워크트리에서 본진과 다른 파일 추출
for d in ./monk_project/*/; do
  echo "=== $(basename $d) ==="
  diff -rq "$d/monk_project" . --exclude=".git" --exclude="monk_project" --exclude="node_modules" 2>/dev/null | grep "Only in $d" | head -20
done
```

- 본진에 없는 md/코드 파일 → 본진 적절 위치에 이관
- 본진과 동일한 파일 → 무시
- 바이너리/node_modules/캐시 → 무시

#### 1-2. 삭제

산출물 이관 확인 후 워크트리 20개 전체 삭제:

```bash
# 워크트리 등록 해제
git worktree list  # 등록된 워크트리 확인
git worktree prune  # 이미 삭제된 경로 정리

# 물리 삭제 (개별 rm -r, rm -rf 금지)
# 각 디렉토리 안의 파일을 먼저 삭제 후 rmdir
```

⚠️ `rm -rf` 금지. 파일 단위 삭제 또는 `find ... -delete` 사용.
⚠️ 삭제 전 `git worktree list`로 활성 워크트리 아닌지 확인.
