# 지시서: 규격별 가이드 이미지 일괄 생성 (Node Canvas)

> **[2026-05-20 15:15 KST] iMac/쌍아 → iMac/막내1**

## 배경

specs 상세 페이지의 규격 가이드를 **클라이언트 Canvas 실시간 렌더링**에서 **서버사이드 사전 생성 이미지**로 전환한다. 브라우저 얼굴 감지 없이 정확한 가이드 오버레이를 구현하기 위함.

## 핵심 로직

1. 샘플 인물 사진(ref.jpg)의 **얼굴 좌표를 한번만 측정**
2. 각 규격(35×45, 51×51, 50×70 등)에 맞게 **크롭 영역 계산** — 머리 높이가 규격 비율에 맞도록 줌/위치 조정
3. 크롭된 이미지 위에 **IDPASS 스타일 가이드 오버레이** 렌더링
4. WebP로 출력 → R2 또는 로컬 에셋에 저장

## 사전 컨텍스트 파악

1. **샘플 사진**: `~/Desktop/CROP APP/ref.jpg` — 정면 인물 사진 (1024×1024 추정)
2. **D1 규격 데이터**: 리모트 monk-db documents 테이블 — 112개 문서의 size_w_mm, size_h_mm, head_height_min_mm, head_height_max_mm, eye_position 데이터
3. **Canvas 데모 참조**: `/tmp/specs_multi.html` — 가이드 오버레이 스타일 (코너 브래킷, 정수리/눈/턱 라인, 치수 라벨, 스펙 배지)
4. **template.js 기존 Canvas 코드**: `functions/specs/_lib/template.js` — GUIDE_CANVAS_SCRIPT (참조만, 이번에는 Node에서 실행)

## 작업 1: ref.jpg 얼굴 좌표 측정

ref.jpg를 열어서 아래 좌표를 **픽셀 기준으로 측정** (이미지 편집 도구 또는 수동 측정):

```javascript
const FACE = {
  imgWidth: ???,    // 원본 가로
  imgHeight: ???,   // 원본 세로
  crownY: ???,      // 정수리 Y (px)
  eyeY: ???,        // 양 눈 중심 Y (px)
  chinY: ???,       // 턱 끝 Y (px)
  shoulderY: ???,   // 어깨선 Y (px)
  centerX: ???,     // 얼굴 중심 X (px)
};
```

측정 방법: Node sharp로 이미지 메타데이터 확인 + 육안 측정. 또는 `face-api.js` / `@mediapipe/face_detection` 으로 한번만 실행해서 좌표 추출.

## 작업 2: 생성 스크립트

`scripts/d1-migration/generate-guide-images.js`

### 의존성
```bash
npm install canvas sharp
```

### 로직

```
D1에서 112개 문서 조회 (size_w_mm, size_h_mm, head_min_mm, head_max_mm, standard, 국가명)
  ↓
각 문서에 대해:
  1. 규격 비율 계산 (w_mm / h_mm)
  2. 머리 높이 비율 = head_max_mm / h_mm
  3. ref.jpg에서 크롭 영역 계산:
     - 정수리~턱이 프레임 세로의 head_max_mm/h_mm 비율이 되도록
     - 상단 여백 = (h_mm - head_max_mm) * 0.3 정도 (ICAO 상단여백 비율)
     - 좌우 중심 = FACE.centerX 기준
  4. Sharp로 크롭 + 리사이즈 (출력: 600px 기준 너비)
  5. Node Canvas로 가이드 오버레이:
     - 코너 브래킷 4개
     - 정수리 라인 + 라벨
     - 눈 라인 + 라벨 (eye_position 있으면)
     - 턱 라인 + 라벨
     - 머리높이 디멘션 (우측, min~max mm)
     - 프레임 너비/높이 (cm 단위)
     - 스펙 배지 (사이즈 + 표준명)
     - 머리 영역 반투명 하이라이트
  6. WebP 출력 (quality 85)
```

### 출력 경로

```
MONK_kr/images/specs/guides/
  ├── korea-passport.webp
  ├── korea-visa.webp
  ├── korea-national-id.webp
  ├── korea-drivers-license.webp
  ├── korea-resume.webp
  ├── united-states-passport.webp
  ├── united-states-visa.webp
  ├── japan-passport.webp
  ...
  └── (112개 파일)
```

파일명 패턴: `{country_slug}-{doc_slug}.webp`

### D1 데이터 가져오기

```bash
npx wrangler d1 execute monk-db --remote --command="SELECT d.id, d.slug as doc_slug, d.size_w_mm, d.size_h_mm, d.head_height_min_mm, d.head_height_max_mm, d.eye_position_min_pct, d.standard, d.name_ko, c.slug as country_slug, c.name_ko as country_name FROM documents d JOIN countries c ON c.id=d.country_id WHERE d.is_published=1" --json > /tmp/specs_for_images.json
```

또는 스크립트 내에서 wrangler CLI 호출.

## 작업 3: template.js 수정

기존 Canvas 인라인 JS를 **정적 이미지 호출**로 교체:

```html
<!-- 기존: <canvas id="spec-guide"></canvas> + <script>...</script> -->
<!-- 변경: -->
<img src="/images/specs/guides/${countrySlug}-${docSlug}.webp" 
     alt="${countryName} ${docName} 사진 규격 가이드"
     width="300" loading="lazy"
     class="specs-guide-img">
```

- Canvas 관련 인라인 JS 전부 제거 (GUIDE_CANVAS_SCRIPT)
- `<img>` 태그로 교체 — SEO에도 유리 (alt 텍스트 + Google 이미지 검색 노출)
- `loading="lazy"` 적용

## 작업 4: 검증

1. 생성된 이미지 112개 전수 확인 — 파일 존재 + 파일 사이즈 > 0
2. 주요 3건 육안 검증:
   - korea-passport.webp (35×45, 3:4)
   - united-states-visa.webp (51×51, 1:1)
   - canada-passport.webp (50×70, 5:7)
3. 가이드라인이 얼굴에 정확히 매칭되는지 확인
4. 로컬 테스트에서 이미지 로드 확인

## ⚠️ 준수 조항

- ref.jpg는 리포에 커밋하지 않음 (저작권 미확인 샘플)
- 생성된 가이드 이미지(webp)는 MONK_kr에 커밋 (CF Pages 에셋으로 배포)
- 이미지 alt 텍스트에 국가명+문서명+규격 포함 (이미지 SEO)
- 기존 functions/api/* 무수정
