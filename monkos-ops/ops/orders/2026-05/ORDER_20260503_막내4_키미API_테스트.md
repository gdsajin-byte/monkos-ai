# 지시서: Kimi API 테스트

## 목적

Kimi(Moonshot AI) API의 실사용 가능성을 검증한다. 가격, 성능, 응답 품질을 실측하고 Claude/GPT 대비 포지셔닝을 판단한다.

## API 키

```bash
source ~/developer/monk_project/.env
echo $KIMI_API_KEY
```

또는 Secret Manager:
```bash
gcloud secrets versions access latest --secret="KIMI_API_KEY"
```

## 테스트 항목

### 1. API 연결 + 모델 목록 확인
- 엔드포인트, 사용 가능 모델, rate limit 확인
- Kimi API 문서 참조 (OpenAI 호환 형식일 가능성 높음)

### 2. 응답 품질 테스트 (3개 프롬프트)
- 한국어 자연어 처리: "MONKOS AI 증명사진 서비스를 3줄로 설명해줘"
- 코드 생성: "Python으로 Google Docs API에서 문서를 읽는 함수 작성"
- 추론: "마진 91% SaaS 사업에서 일 30명 결제 시 월 매출과 연 매출을 계산하고, 손익분기점을 분석해"

### 3. 성능 측정
- 각 프롬프트별 응답 시간 (초)
- 토큰 수 (input/output)
- 에러율

### 4. 가격 조사
- 모델별 input/output 토큰 단가
- Claude Opus, Sonnet, GPT-4o 대비 가격 비교표
- 무료 티어 / 월 한도 확인
