# 포털 언어 경로 301 리다이렉트 추가

## 배경

SEO 스캔에서 `monkos.ai/kr`(404), `monkos.ai/jp`(404)가 반복 보고됨.
포털 다국어 체계는 한국어=`/`, 일본어=`/ja`, 영어=`/en`이나, 봇·사용자가 직관적으로 `/kr`, `/jp`를 시도할 수 있으므로 301 리다이렉트로 안내한다.

## 작업

**파일**: `monkos_AI/portal/server.js`

**위치**: 310행 (`/app` 리다이렉트 블록 종료) 바로 다음, 312행 (`/` 홈 라우트) 바로 위

**추가 코드**:
```javascript
  if ((urlPath === '/kr' || urlPath === '/kr/') && req.method === 'GET') { res.writeHead(301, { 'Location': '/' }); return res.end(); }
  if ((urlPath === '/jp' || urlPath === '/jp/') && req.method === 'GET') { res.writeHead(301, { 'Location': '/ja' }); return res.end(); }
```

## 배포

- `./deploy.sh prod` (`monkos_AI/portal/deploy.sh`)

## 검증

```bash
curl -sI https://monkos.ai/kr | head -3   # 301 → /
curl -sI https://monkos.ai/jp | head -3   # 301 → /ja
curl -sI https://monkos.ai/kr/ | head -3  # 301 → /
curl -sI https://monkos.ai/jp/ | head -3  # 301 → /ja
```

## ⚠️ 준수 조항

- 배포는 반드시 `deploy.sh` 경유 (법률 ch5 2조)
- 기존 라우트(`/ja`, `/en`, `/`) 동작에 영향 없음을 확인할 것
