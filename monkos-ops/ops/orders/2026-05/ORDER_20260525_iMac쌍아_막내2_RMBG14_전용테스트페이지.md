# 지시서: RMBG-1.4 전용 테스트 페이지

## 배경

벤치마크 결과 RMBG-1.4가 품질 1등. 다양한 이미지로 추가 테스트 필요. 결과를 크게 보면서 비교할 수 있는 전용 페이지 제작.

## Task

`apps/crop-app/benchmark/rmbg-test.html` — 단일 HTML 파일

### 레이아웃

```
┌─────────────────────────────────────────┐
│  RMBG-1.4 배경 제거 테스트               │
├──────────────────┬──────────────────────┤
│                  │                      │
│  [사진 업로드]    │   [카메라 촬영]       │
│  드래그 앤 드롭   │                      │
│                  │                      │
├──────────────────┴──────────────────────┤
│                                         │
│  ┌─────────────┐  ┌─────────────┐      │
│  │   원본       │  │  배경 제거   │      │
│  │  (큰 사이즈)  │  │ (흰배경 합성) │      │
│  │             │  │             │      │
│  └─────────────┘  └─────────────┘      │
│                                         │
│  처리 시간: Xs · 이미지 크기: WxH        │
├─────────────────────────────────────────┤
│  히스토리 (이전 테스트 결과 썸네일 나열)  │
└─────────────────────────────────────────┘
```

### 기능 요구사항

1. **업로드**: 파일 선택 + 드래그 앤 드롭 + 카메라 촬영 (모바일 대응)
2. **결과 표시**: 원본과 배경 제거 결과를 나란히 큰 사이즈로 표시
3. **흰배경 합성**: 배경 제거 후 #FFFFFF 배경 합성 (증명사진 최종 형태)
4. **투명/흰색 토글**: 투명 배경과 흰배경 전환 버튼
5. **처리 시간 표시**: Cold/Warm 구분
6. **히스토리**: 여러 장 테스트 시 아래에 썸네일로 누적
7. **다운로드**: 결과 이미지 다운로드 버튼
8. **슬라이더 비교**: 원본↔결과 사이 슬라이더로 비교 (before/after)
9. **엔진**: Transformers.js + RMBG-1.4 (quantized) 단일 — 기존 벤치마크 코드 재사용

### 스타일
- 다크 테마 (기존 벤치마크와 통일)
- 결과 이미지 최대한 크게 (화면 폭 기준 50:50)
- 모바일 대응 (세로 스택)
