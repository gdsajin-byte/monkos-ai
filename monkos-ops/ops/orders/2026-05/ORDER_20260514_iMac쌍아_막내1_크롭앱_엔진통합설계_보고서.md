# 지시서: 크롭앱 엔진 통합 설계 보고서

## 목적

현재 3개 소스가 분리되어 있다:

1. **웹 크롭앱** (`monkos_AI/crop-app/public/crop.js`) — 핵심 엔진 로직 (프레임 고정 + 사진 이동/스케일 + 눈/턱/정수리 라인 고정 + 실시간 mm 수치 + 신호등 + 코칭 메시지 + autoPlace)
2. **iOS 앱 현재 코드** (`apps/MonkosCrop/MonkosCrop/`) — V1 다크 HUD 디자인 + Apple Vision 76pt + PersonSegmentation 배경 제거 + 검수 시퀀스 + SwiftUI
3. **V1 디자인 원본** (`~/Desktop/CROP APP/`) — 클로드 디자인 JSX 3시안 (V1 Safe 채택)

이 3개를 통합하여 **iOS V1 디자인 위에 웹 크롭 엔진의 핵심 로직이 동작하는 설계서**를 작성하라.

## 분석 대상

### A. 웹 크롭앱 엔진 (`crop.js`) — 정밀 분석 필수

- `render()` 함수 전체 로직: 프레임 좌표계에서 수치 계산 방식
- `initOverlay()`: 초기 랜드마크 → 프레임 좌표 변환
- `autoPlace()`: 얼굴 감지 후 사진을 프레임에 자동 배치하는 로직
- `onPtrMove()` / `onPtrDown()` / `onPtrUp()`: 드래그(정수리 핀, 사진 이동, 스케일 핸들) 조작
- `performCrop()`: 최종 트리밍 시점의 좌표 변환
- `pts` 객체: crown/chin/leftPupil/rightPupil 등 좌표 관리
- `imgPos` / `imgScale`: 사진 위치/스케일 상태
- `MM` (1px = ?mm) 변환 계수
- 코칭 메시지 분기 로직 (눈 위치, 얼굴 크기, 좌우 중심 이탈)
- SVG 오버레이: 마스크(상단/하단), 가이드선, 핀, 라벨, 배지

### B. iOS 앱 현재 코드 — 현황 파악

- `CropEngine.swift`: `crop()` 함수의 좌표 계산 로직 (웹 엔진과의 차이점)
- `CropEngine.swift`: `detectFace()` — Vision 76pt 랜드마크 (웹 FaceMesh와의 매핑)
- `CropEngine.swift`: `generatePersonMask()` / `compositeBackground()` — 배경 제거
- `ContentView.swift`: 현재 Step 구조 (1~5), 검수 시퀀스 (InspectionState), 메트릭 계산
- `CropView.swift`: FaceLandmarksOverlay, MetricBox, CornerBrackets 등 UI 컴포넌트
- `SpecData.swift`: PhotoSpec 구조, 국가/규격 데이터

### C. 현재 앱의 새 플로우 (5/14 작가님 확정)

```
Step1: 규격 선택
Step2: 사진 업로드 (얼굴 감지)
Step3: 배경 처리 (배경색 선택 → 원본 전체 누끼)
Step4: 측정 + 검수 + 교정 ← 이 단계가 핵심
Step5: 완료 + 다운로드 + AI OG카드
```

**Step4의 요구사항** (작가님 디렉션):
- 프레임 고정 (규격 비율)
- 누끼 원본을 프레임 안에 자동 배치 (웹 `autoPlace` 상당)
- **눈/턱/정수리 라인이 프레임에 고정** — 사진 이동 시 수치가 실시간 변동
- 드래그로 사진 이동 + 슬라이더로 줌 (기존 웹의 버튼 대신)
- 매 이동마다 mm 수치 재계산 + 신호등 판정 + 코칭 메시지
- 규격 맞으면 "이대로 크롭" 활성 → **최종 트리밍은 이 시점**
- 정밀 교정 옵션: 정수리 핀 드래그 (기존 웹과 동일)
