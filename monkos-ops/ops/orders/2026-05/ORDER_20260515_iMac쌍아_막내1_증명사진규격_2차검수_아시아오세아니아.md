# 지시서: 증명사진 규격 2차 검수 — 아시아 + 오세아니아

## 목적

1차 보고서(`REPORT_20260515_막내1_증명사진규격검증_아시아오세아니아.md`)에서 보고된 비표준 국가 및 특이점의 **출처 신뢰도를 재검증**한다.

**원칙: 없는 사실을 말하는 것보다 숫자를 줄이는 게 낫다.** 공식 출처로 확인할 수 없는 내용은 "미확인"으로 표기하고 반영 대상에서 제외한다. visafoto.com 등 대행 사이트만으로는 확정하지 않는다.

## 작업 내용

1차 보고서에서 보고한 **비표준 국가 + 특이점** 전건에 대해 아래 테이블 형식으로 재정리한다.

### 산출물 테이블 형식

```markdown
## 여권 규격 검증

| 국가 id | 국가명 | 규정 (사이즈/얼굴높이) | 특이점 | 출처 구분 | 비공식 시 사유 | 확인 링크 | 사이트명 | 신뢰등급 |
|---------|--------|----------------------|--------|----------|-------------|----------|---------|---------|

## 비자 규격 검증

| 국가 id | 국가명 | 규정 (사이즈/얼굴높이) | 특이점 | 출처 구분 | 비공식 시 사유 | 확인 링크 | 사이트명 | 신뢰등급 |
|---------|--------|----------------------|--------|----------|-------------|----------|---------|---------|
```

### 필드 정의

- **규정**: 사이즈(mm) + 얼굴높이(mm) + 배경색 요구
- **특이점**: 발급위치별 차이, AI 금지, 사진사 필수, 최근 변경 등
- **출처 구분**: `공식` 또는 `비공식`
  - 공식 = 해당국 정부기관(외교부, 출입국, 경찰청 등) 웹사이트 또는 공보
  - 비공식 = 대행 사이트, 위키, 블로그 등
- **비공식 시 사유**: 왜 공식 출처를 확인하지 못했는지 (예: "정부 사이트 미운영", "해당 페이지 404", "영어/한국어 페이지 없음")
- **확인 링크**: 실제 접속 가능한 URL (깨진 링크 금지)
- **사이트명**: 기관명 또는 사이트명
- **신뢰등급**:
  - `A` = 공식 정부 출처에서 직접 확인
  - `B` = 비공식이나 2개 이상 교차 확인 일치
  - `C` = 단일 비공식 출처만 존재
  - `X` = 확인 불가 (반영하지 않음)

### 규칙

1. **A/B 등급만 JSONL 반영 대상**. C/X는 제외.
2. 1차 보고서에서 "복수 출처", "출처별 차이"로 표기한 항목은 반드시 구체 링크를 제시하거나 X 처리.
3. ICAO 35×45로 확인된 국가(정상)는 테이블에 포함하지 않아도 됨. **비표준 + 특이점이 있는 국가만 대상.**
4. 1차에서 보고했으나 이번 검증에서 출처를 확보 못 한 항목은 솔직하게 X 처리. 숫자를 줄이는 게 낫다.
