# 지시서: 여권/비자 규격 전수조사 v2

## 목적

4/30 전수조사는 여권+신분증+이력서 혼재. 이번에는 **여권과 비자만** 타겟으로, ICAO 9303 기본 규정으로 통과되는 그룹과 별도 규정 국가를 명확히 분리한다.

## 조사 원칙

1. **1차 출처(정부 공식 사이트)만**. 추정·환산 절대 금지
2. 공식 미명시 항목은 `미규정`으로 기재. 2차 출처 값을 추정으로 채우지 않는다
3. 여권(passport)과 비자(visa)만. 신분증/이력서/운전면허 제외
4. 출처 URL 필수

## 조사 대상 국가

현재 앱 등록 9국 + 주요 수요국 추가:

한국, 일본, 미국, EU(쉥겐), 영국, 중국, 캐나다, 호주, 인도, 싱가포르, 태국, 베트남, 인도네시아, 필리핀, 대만, 브라질, 러시아, 터키, 사우디아라비아, UAE

## 산출물 구조

### 테이블 1: ICAO 기본 규정

먼저 ICAO 9303 기본 규격을 명시:

```
| 항목 | ICAO 9303 기본 |
| 사이즈 | 35 × 45 mm |
| 얼굴 높이 | 32~36 mm |
| 눈 위치 | 미규정 (관행 40~48%) |
| 배경 | 흰색 또는 연한 색 |
| px | 미규정 |
| DPI | 미규정 |
| ... |
```

### 테이블 2: ICAO 기본으로 통과되는 국가 목록

ICAO 9303 기본 규정을 그대로 따르며 **추가 요구사항이 없는** 국가 목록.

```
| 국가 | 문서 | 추가 요구 | 출처 |
```

### 테이블 3: 별도 규정 국가 — 전체 필드 테이블

ICAO와 다르거나 추가 규정이 있는 국가. **한 국가당 한 행이 아니라 전체 필드를 죄다 기재**:

```
| 필드 | 한국 여권 | 미국 여권 | 미국 비자 | UK 여권 | 중국 여권 | 중국 비자 | 캐나다 여권 | ... |
|------|----------|----------|----------|--------|----------|----------|------------|-----|
```

### 테이블 4: 앱 반영용 요약

```
| 국가 | 문서 | mm | px | head_mm | faceMin | faceMax | faceTarget | 배경 | warning | group |
```

group 분류:
- A: ICAO 기본 (35×45)
- B: ICAO 크기 동일하나 세부 규정 차이 (UK 등)
- C: 독자 사이즈 (미국 51×51, 캐나다 50×70 등)

## ⚠️ 준수 조항

- 추측 금지. 공식 미명시 = `미규정`
- 2차 출처(visafoto, passport-photo.online 등)의 값을 공식 규정으로 기재 금지
- 여권/비자만. 신분증·이력서·운전면허 조사 금지
- 코드 수정 금지. 보고서만
