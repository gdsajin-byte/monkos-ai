# 지시서: Gemini 3.1 Flash-Lite 챗봇 품질 테스트

## 배경

- gemini-2.0-flash(현행) → 6/1 EOL
- gemini-3-flash: 성능↑ 비용 5~7x↑
- gemini-3.1-flash-lite: 비용 2.5x↑ — **적정 대안 후보**
- 작가님 지시: 우리 챗봇 기준으로 3.1-flash-lite 수준 검증

## 임무

### 1. 현행 챗봇 시스템 프롬프트 확인

1. `monkos_AI/portal/lib/chat-engine.js`를 Read하여 현행 시스템 프롬프트, 모델 파라미터(temperature, topP, maxTokens 등)를 확인한다.
2. 챗봇이 어떤 질문 유형을 받는지 파악 (서비스 안내, 가격, 촬영 방법 등).

### 2. 테스트 시나리오 설계

아래 5개 시나리오로 각 모델을 테스트:

| # | 시나리오 | 검증 포인트 |
|---|---------|-----------|
| 1 | "증명사진 가격이 얼마예요?" | 정확한 가격 응답, 헌법 4조 4항(되는 것만 응답) |
| 2 | "여권사진 규격이 어떻게 되나요?" | 구체적 수치(3.5x4.5cm 등) 정확도 |
| 3 | "AI로 증명사진 만들면 실물과 다르지 않나요?" | 정체성 보존 원칙 반영, 신뢰감 있는 응답 |
| 4 | "일본 취업 비자 사진 규격 알려주세요" | 다국어 대응, 일본 규격 정확도 |
| 5 | "메이크업이나 보정은 어디까지 되나요?" | 서비스 범위 안내, 과장 없는 응답 |

### 3. 모델별 테스트 실행

Gemini API를 직접 호출하여 동일 시스템 프롬프트 + 동일 질문으로 3개 모델 비교:

```python
import google.generativeai as genai

models = [
    "gemini-2.0-flash",          # 현행 (기준선)
    "gemini-3-flash",            # 고성능 대안
    "gemini-3.1-flash-lite",     # 비용 절약 대안
]
```

각 모델 × 5개 시나리오 = 15건 응답 수집.

### 4. 평가 기준

| 기준 | 가중치 | 설명 |
|------|--------|------|
| 정확도 | 30% | 사실 오류 없는지 |
| 한국어 자연스러움 | 25% | 번역체 아닌지, 존댓말 적절한지 |
| 응답 길이 적정성 | 15% | 너무 짧거나 과하지 않은지 |
| 응답 속도 (TTFT) | 15% | 체감 속도 |
| 헌법 준수 | 15% | 미출시/미확정 표현 없는지, 과장 없는지 |

각 시나리오별 5점 만점으로 채점.
