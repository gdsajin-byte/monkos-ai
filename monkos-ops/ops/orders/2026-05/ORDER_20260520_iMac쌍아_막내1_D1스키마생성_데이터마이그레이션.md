## 작업 2: 마이그레이션 스크립트 작성

`scripts/d1-migration/migrate-specs.js` — Node.js 스크립트. 3개 소스를 파싱하여 INSERT SQL 생성.

### 2-1. countries 테이블 시딩

- `countries.jsonl` 202줄 파싱
- `country-slugs.json`에서 slug 매핑
- flag는 jsonl에 없으므로 `flag-emoji.json` 별도 작성 또는 인라인 매핑
- `is_published`: docs가 1건 이상인 국가 = 1 (72국), 빈 국가 = 0
- `priority`: 한국=1, 일본=2, 미국=3, 나머지 대륙순+알파벳순

### 2-2. documents 테이블 시딩

- `countries.jsonl`의 docs[] 배열 파싱 (101건)
- size 파싱: "35x45" → size_w_mm=35, size_h_mm=45, size_display="35x45"
- px 파싱: "413x531" → px_w=413, px_h=531
- head 파싱: "32-36" → head_height_min_mm=32, head_height_max_mm=36
- slug: type 필드 그대로 ("passport", "visa", "id"→"national-id", "license"→"drivers-license", "resume")
- `is_published`: 기본 1 (데이터 있는 문서)

### 2-3. specs-data-v2.json 보강

- ID 매핑: "korea-passport" → "kr-passport" (COUNTRY_ID_MAP + DOC_SLUG_MAP 활용)
- 오버레이 필드: officialSource → official_source_url, aiRestriction → ai_restriction, eyePosition → eye_position_*, group → group_tier
- 매칭 안 되는 문서는 v2에만 있는 항목 — 신규 INSERT

### 2-4. specs-data.json SEO 콘텐츠

- seo_content 테이블에 INSERT
- 매핑: "korea-passport" 슬러그 → documents.id ("kr-passport") 역매핑
- 필드: details(3lang), rejectionReasons(3lang) → JSON 문자열, faqs(3lang) → JSON 문자열, seoTitle/seoDescription(3lang)

### 2-5. slug_aliases 테이블

- specs-data.json의 26개 slug → country_slug + document_slug 매핑
- 예: "korea-passport" → ("korea", "passport"), "japan-mynumber" → ("japan", "mynumber")

### 2-6. common_requirements 시딩

- ICAO 기본 요구사항 6건 (document_id=NULL, type='required'):
  - 정면 응시 / 무표정 / 입 다문 상태 / 밝은 배경 / 그림자 없음 / 6개월 이내
- ICAO 기본 금지사항 4건 (document_id=NULL, type='forbidden'):
  - 모자/머리장식 / 선글라스 / 과도한 보정 / 얼굴 가림

## 작업 3: 시드 실행 및 검증

```bash
node scripts/d1-migration/migrate-specs.js > scripts/d1-migration/seed.sql
wrangler d1 execute monk-db --file=scripts/d1-migration/seed.sql
```

검증 쿼리:
```bash
wrangler d1 execute monk-db --command="SELECT COUNT(*) as cnt FROM countries"
wrangler d1 execute monk-db --command="SELECT COUNT(*) as cnt FROM documents"
wrangler d1 execute monk-db --command="SELECT COUNT(*) as cnt FROM seo_content"
wrangler d1 execute monk-db --command="SELECT c.slug, COUNT(d.id) as docs FROM countries c LEFT JOIN documents d ON d.country_id=c.id WHERE c.is_published=1 GROUP BY c.id ORDER BY docs DESC LIMIT 10"
```

기대값:
- countries: 202
- documents: 101+ (v2 추가분 포함)
- seo_content: 26
- 한국 최다 (4~5종)
