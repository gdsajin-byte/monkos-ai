# 지시서: 배경 제거 벤치마크 수정

## 작가님 피드백 (즉시 반영)

### 1. MediaPipe — 인물을 벗기고 배경을 남겼다
반대로 동작 중. **배경을 제거하고 인물을 남기도록** 마스크 반전 처리할 것.
MediaPipe Selfie Segmenter는 foreground(인물) 마스크를 반환하므로 해당 마스크로 인물을 보존해야 한다.

### 2. rembg 170MB 모델 누락
5/1 벤치마크에서 rembg의 **u2net 풀모델(~170MB)**이 있었다. u2netp(4.7MB 경량)만 테스트하고 풀모델을 빠뜨렸다.
- `rembg`의 u2net 풀모델 또는 Python rembg 서버 기반 테스트 추가
- CDN에서 401이면 자체 호스팅으로 모델 서빙
- 또는 Python `pip install rembg` → 로컬 HTTP 서버로 테스트

### 3. 배경 제거 후 흰색 배경 합성
현재 투명(체크) 배경으로 결과 표시 중. **흰색(#FFFFFF) 배경판을 합성**하여 증명사진 최종 형태로 보여줄 것.
- Canvas에서 배경 흰색 fill → 인물 합성 → 결과 표시
- 모든 엔진 결과에 동일 적용

### 4. Warm 추론 측정
Cold만 나오고 Warm이 `-`로 표시됨. 단독 실행 버튼으로 2회차 추론 시 Warm 시간 측정 필수.
