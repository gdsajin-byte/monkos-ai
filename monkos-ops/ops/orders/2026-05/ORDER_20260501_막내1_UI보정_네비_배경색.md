### U3. 배경색 클릭 시 누끼 버그 수정

현재(step-nav.js 467~477행): `fillRect`로 캔버스를 색으로 덮어씌우고 **누끼 이미지를 다시 안 그림** → 사진이 사라짐.

```js
// 현재 (잘못됨)
ctx.fillStyle = btn.dataset.color;
ctx.fillRect(0, 0, canvas.width, canvas.height);
// ← 여기서 끝. 누끼 이미지가 안 올라감

// 수정
ctx.fillStyle = btn.dataset.color;
ctx.fillRect(0, 0, canvas.width, canvas.height);
ctx.drawImage(누끼이미지, 0, 0);  // ← 배경 위에 누끼 다시 그리기
```

- 배경 제거 결과(누끼)를 변수에 보관해두고, 색 변경 시마다 배경+누끼 재합성
- 배경색 변경이 실시간으로 프리뷰에 반영되어야 함
