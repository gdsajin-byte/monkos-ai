# 지시서: 텔레그램 알림 허브 Action

## 배경

- 텔레그램 = 작가님 신경계. 브리핑·이상 감지가 텔레그램으로 바로 와야 체감 최대
- 텔레그램 봇 토큰 이미 보유: `TELEGRAM_BOT_TOKEN` (monkos_AI/.env)
- 팀 채팅 ID: `TEAM_CHAT_ID` (monkos_AI/.env)
- GitHub Issue 푸시도 되지만, 텔레그램이 더 즉각적

## 임무

### 1. GitHub Secrets 등록

아래 2개를 등록:

```bash
# monkos_AI/.env에서 값 추출 (출력하지 말고 바로 파이프)
grep "^TELEGRAM_BOT_TOKEN=" monkos_AI/.env | cut -d'=' -f2 | gh secret set TELEGRAM_BOT_TOKEN --repo gdsajin-byte/monk_project
grep "^TEAM_CHAT_ID=" monkos_AI/.env | cut -d'=' -f2 | gh secret set TELEGRAM_CHAT_ID --repo gdsajin-byte/monk_project
```

### 2. 알림 스크립트 — `.github/scripts/telegram_notify.py`

범용 텔레그램 발신 스크립트. 다른 워크플로우에서 재사용 가능하도록 설계.

```python
# 사용법: python telegram_notify.py "메시지 내용"
# 환경변수: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID

import os, sys, requests

def send(message):
    token = os.environ["TELEGRAM_BOT_TOKEN"]
    chat_id = os.environ["TELEGRAM_CHAT_ID"]
    url = f"https://api.telegram.org/bot{token}/sendMessage"
    resp = requests.post(url, json={
        "chat_id": chat_id,
        "text": message,
        "parse_mode": "Markdown",
    })
    resp.raise_for_status()

if __name__ == "__main__":
    send(sys.argv[1] if len(sys.argv) > 1 else "AUTOPILOT 테스트 알림")
```

### 3. 브리핑 워크플로우에 텔레그램 알림 추가

`daily-briefing.yml`에 텔레그램 발신 step 추가 (Issue 생성 step 뒤):

```yaml
      - name: Telegram notification
        if: success()
        env:
          TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
        run: |
          DATE=$(date +%Y-%m-%d)
          # 긴급 건만 추출
          ALERTS=$(grep "^- 🔴" monkos-ops/ops/briefings/BRIEFING_${DATE}.md || echo "없음")
          python .github/scripts/telegram_notify.py "📊 *데일리 브리핑 ${DATE}*

${ALERTS}

전문: GitHub Issue #${ISSUE_NUMBER} 참조"
```

### 4. 범용 알림 워크플로우 — `.github/workflows/notify.yml`

다른 워크플로우에서 호출 가능한 reusable workflow:

```yaml
name: Telegram Notify

on:
  workflow_call:
    inputs:
      message:
        required: true
        type: string

jobs:
  notify:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'
      - run: pip install requests
      - env:
          TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
        run: python .github/scripts/telegram_notify.py "${{ inputs.message }}"
```
