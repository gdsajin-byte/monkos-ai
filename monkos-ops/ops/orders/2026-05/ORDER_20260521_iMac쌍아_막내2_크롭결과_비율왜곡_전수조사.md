## 현상

중국 비자(33×48mm) 결과물에서 **얼굴이 가로로 퍼지는 비율 왜곡** 발생.
Step 5 완료 화면에서 원본 대비 가로 비율이 늘어나 보임.
다른 규격에서도 동일 현상이 있을 수 있음.

## 작업 내용

### 1. 비율 왜곡이 발생할 수 있는 모든 지점 전수 조사

아래 파일을 **전부 읽고** 비율 왜곡을 유발할 수 있는 코드를 모두 식별:

| 파일 | 라인 | 역할 |
|------|------|------|
| `apps/MonkosCrop/MonkosCrop/CropEngine.swift` | 363줄 | 크롭 + 배경제거 + 이미지 합성 |
| `apps/MonkosCrop/MonkosCrop/CropView.swift` | 515줄 | 크롭 결과 프레임 렌더링 |
| `apps/MonkosCrop/MonkosCrop/ContentView.swift` | 1264줄 | 전체 5스텝 UI + 결과 표시 |

### 2. 조사 체크리스트

비율 왜곡의 일반적 원인:

- [ ] **CIImage crop 좌표 변환**: cropH > imageH 일 때 클리핑 → sx≠sy 스케일링
- [ ] **minScaleForFit 로직**: 05/20에 수정된 이력 있음 — 모든 비율에서 정상 동작하는지
- [ ] **CGContext/CIContext 렌더링**: draw 시 rect 비율이 원본과 불일치
- [ ] **SwiftUI Image resizable/aspectRatio**: `.fill` vs `.fit` 모드 혼용
- [ ] **Step 4 → Step 5 이미지 전달**: 크롭 결과 이미지의 실제 px 비율 vs 표시 비율
- [ ] **px 출력 계산**: spec의 px 값(354×472)으로 리사이즈할 때 원본 비율 무시
- [ ] **배경 합성 시**: 마스크 스케일(sx/sy)과 원본 비율 불일치
- [ ] **가이드 이미지 표시**: Step 2 가이드와 무관하게 Step 5 결과가 왜곡되는지
- [ ] **세로 긴 규격 전반**: 33×48, 35×50, 40×60, 50×70 등에서 공통인지 확인
