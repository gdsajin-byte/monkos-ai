# 지시서: 세션로그·보고서·지시서 루트 방치 파일 월별 폴더 이동

## 배경

- 4월 이후 세션로그·보고서·지시서가 월별 폴더에 들어가지 않고 루트에 방치
- 세션로그: 4~5월 70건 루트 방치
- 보고서: 4~5월 75건 루트 방치
- 지시서: 5월 106건 루트 방치
- 법률 ch4 규정상 월별 폴더 정리가 원칙

## 임무

### 1. 세션로그 (monkos-ops/ops/sessions/)

루트 직하의 `2026-*.md` 파일들을 날짜 기준 월별 폴더로 이동:

```bash
# 패턴: 2026-MM-DD_*.md → 2026-MM/ 폴더로 이동
# 예: 2026-04-07_iMac_쌍아.md → 2026-04/
# 예: 2026-05-08_iMac_쌍아.md → 2026-05/ (폴더 없으면 생성)
```

**주의사항:**
- `README.md`는 이동하지 않는다
- 비MD 파일 (`2026-04-07_naver_crawl_log.txt` 등)도 해당 월별 폴더로 이동
- `2026-05/` 폴더가 없으면 생성
- `git mv` 사용하여 git 이력 보존

### 2. 보고서 (monkos-ops/ops/reports/)

루트 직하의 `COMPLETION_*.md`, `REPORT_*.md` 파일들을 날짜 기준 월별 폴더로 이동:

```bash
# 패턴: {TYPE}_YYYYMMDD_*.md에서 YYYYMMDD 추출 → 2026-MM/ 폴더로
# 예: COMPLETION_20260417_막내2_171059.md → 2026-04/
# 예: REPORT_20260430_막내2_*.md → 2026-04/
```

**주의사항:**
- `README.md`는 이동하지 않는다
- `assets/` 폴더는 건드리지 않는다
- 2026-05/ 폴더가 없으면 생성

### 3. 지시서 (monkos-ops/ops/orders/)

루트 직하의 `ORDER_*.md` 파일들을 날짜 기준 월별 폴더로 이동:

```bash
# 패턴: ORDER_YYYYMMDD_*.md에서 YYYYMMDD 추출 → 2026-MM/ 폴더로
# 예: ORDER_20260509_막내1_*.md → 2026-05/
```

**주의사항:**
- `README.md`는 이동하지 않는다
- **오늘(20260509) 발행 지시서도 포함** — 본 지시서 자기 자신도 이동 대상

### 4. 검증

이동 완료 후:
- 각 폴더(sessions/, reports/, orders/) 루트에 README.md 외 파일이 남아있지 않은지 확인
- 월별 폴더별 파일 수 집계
- `git status`로 이동 결과 확인

### 5. 산출물

`monkos-ops/ops/reports/COMPLETION_20260509_막내5_월별정리.md` — 이동 결과 집계표

```markdown
| 영역 | 이동 전 루트 | 이동 후 루트 | 월별 분배 |
|------|------------|------------|----------|
| sessions | N건 | 0건 | 04: X, 05: Y |
| reports | N건 | 0건 | 04: X, 05: Y |
| orders | N건 | 0건 | 05: X |
```

## 실행 방법

bash 스크립트로 일괄 처리 권장. 예시:

```bash
# sessions 예시
for f in monkos-ops/ops/sessions/2026-*.md; do
  month=$(echo "$f" | grep -o '2026-[0-9][0-9]')
  dir="monkos-ops/ops/sessions/${month}"
  mkdir -p "$dir"
  git mv "$f" "$dir/"
done
```

보고서·지시서도 동일 패턴 (파일명에서 날짜 추출 → 월 폴더로).

## 준수 조항

- ⚠️ 헌법 제3조 1항: 타임스탬프 절대 준수
- ⚠️ 헌법 제4조 2항: `rm -rf` 금지
- ⚠️ `git mv` 사용 (이력 보존). `mv` + `git add` 조합도 허용
- README.md, assets/ 등 고정 파일은 절대 이동 금지
