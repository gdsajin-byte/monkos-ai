# 지시서: 배경 제거 엔진 실측 비교

## 배경

iOS는 Apple Vision(네이티브)으로 확정. Android + 웹용 배경 제거 엔진을 선정해야 한다. 5/1 벤치마크에서 imgly(★4)와 RMBG-1.4(★5)가 상위 2개로 나왔다. 최신 버전으로 실측 비교한다.

서버에 올려놓고 웹/Android 모두 불러쓰는 구조를 전제로 테스트.

## 선행 참조

- `apps/crop-app/benchmark/REPORT_배경제거_벤치마크.md` — 5/1 벤치마크 결과

## Task: 웹 테스트 페이지 제작 + 실측

### 1. 테스트 페이지 제작

`apps/crop-app/benchmark/bg-remove-test.html` 에 단일 HTML 테스트 페이지를 만든다.

기능:
- 사진 업로드 (파일 선택 + 카메라)
- 엔진 선택 (imgly / RMBG-1.4)
- 실행 → 결과 나란히 표시 (원본 | 배경 제거 결과)
- 소요 시간 표시 (Cold / Warm)
- 두 엔진 동시 실행 → 비교 뷰 모드

### 2. 엔진별 설정

#### A. @imgly/background-removal
- 최신 버전 확인 (v1.5.x CDN 가능 vs v1.7.x npm 필요)
- CDN-only로 동작하는 최신 안정 버전 사용
- `removeBackground(file)` 단일 API

#### B. Transformers.js + RMBG-1.4
- HuggingFace `pipeline('image-segmentation', 'briaai/RMBG-1.4')` 패턴
- quantized 모델 사용 (q8)
- RMBG-2.0 ONNX 브라우저 지원 여부도 확인 — 5/1 당시 onnxruntime-web 버그로 불가였음. 현재 해결됐는지 체크

### 3. 테스트 이미지

실제 증명사진 촬영 환경 시뮬레이션:
- 단색 배경 (흰벽) 정면 인물
- 복잡 배경 (실내) 인물
- 밝은/어두운 조명 각각

테스트 이미지가 없으면 샘플 이미지 3장을 `/benchmark/samples/`에 준비 (무료 스톡 또는 AI 생성).

### 4. 측정 항목

| 항목 | 측정 방법 |
|------|----------|
| Cold Start | 모델 첫 로드 포함 전체 시간 |
| Warm 추론 | 캐시 후 추론만 시간 |
| 모델 크기 | 네트워크 탭에서 실 다운로드 MB |
| 엣지 품질 | 머리카락/어깨/귀 경계 시각 판정 |
| 마스크 노이즈 | 배경-피부 유사 시 노이즈 여부 |
| 메모리 사용 | Chrome DevTools Memory |

### 5. 서버 호스팅 구조 검토

테스트 결과가 좋으면 서버에 올려서 API로 제공하는 구조를 제안:
- Cloud Run에 Python(rembg/RMBG) 또는 Node.js(imgly) 서버
- 또는 CF Workers AI에 해당 모델이 있는지 확인
- API: `POST /api/remove-bg` → 이미지 업로드 → 배경 제거 결과 반환
- 웹/Android 모두 같은 API 호출
