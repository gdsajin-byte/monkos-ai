# 지시서: 현행 헌법 체계 진단 — PF 운용과의 정합성 감사

## 배경

- 헌법 5축 + 법률 8장 체계는 2026-03-25 재편 이후 2개월 운용됨
- PF(포트폴리오) 체계는 2026-03-26 개헌으로 신설됨
- 실운용 과정에서 **정본 위치 이원화**, **히스토리 적립 규율 이완**, **PF 인덱스 누락** 등 구조적 갭 발견
- 이 진단이 개정안(막내3)의 근거가 됨

## 임무

### 1. 헌법·법률 구조 스캔

아래를 읽고 현행 체계의 **PF 관련 조항**을 전수 추출하라:

- `CLAUDE.md` — 헌법 5축 (특히 제3조 적립, 제5조 메타)
- `governance/laws/ch3_session_log.md` — 세션로그 규칙
- `governance/laws/ch4_docs_structure.md` — 문서/폴더 구조 (특히 PF 운용 조항)
- `governance/laws/ch7_makne_code.md` — 막내 행동강령
- `monkos-ops/ops/portfolios/README.md` — PF 운용 원칙
- `monkos-ops/ops/portfolios/PF_TEMPLATE.md` — PF 표준 템플릿

### 2. 정합성 갭 진단

다음 질문에 답하라:

1. **정본 위치 규칙**: 법률에 "PF 정본은 어디"라고 명시되어 있는가? 루트 md vs 폴더/README.md 분기 기준이 정의되어 있는가?
2. **히스토리 갱신 의무**: 누가, 언제, 어떤 조건에서 PF 히스토리를 갱신해야 하는지 법률상 명확한가?
3. **히스토리 테이블 스키마**: 현재 열 구성(`날짜|주체|내용|산출물|상태`)이 법률/템플릿에 정의되어 있는가? 카테고리 분류 열이 있는가?
4. **세션로그→PF 환류**: 세션 마감 시 PF 갱신 체크가 법률상 의무인가, 권고인가?
5. **PF 인덱스 관리**: 인덱스(README) 갱신 주체/주기가 정의되어 있는가?
6. **폴더형 vs 파일형 PF**: 어떤 PF가 폴더를 갖고 어떤 PF가 단일 md인지 기준이 있는가?
