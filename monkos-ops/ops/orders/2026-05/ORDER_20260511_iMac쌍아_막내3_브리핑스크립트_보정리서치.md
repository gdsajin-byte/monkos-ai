### 이슈 1: 기업마당 크롤링 — 셀렉터 과잉 + URL 조립 오류

**현상**: `javascript:void(0)` URL 혼입, 텍스트 파싱 불완전
**원인 코드**: `daily_briefing.py:179` — `soup.select("tr, li, .list-item, a")`, `:183` — URL 조립

**리서치 항목**:
- 기업마당(bizinfo.go.kr) 실제 페이지 구조 파악 — 공고 목록의 정확한 HTML 셀렉터
- 기업마당 API(공공데이터포털 등)가 존재하는지 확인 — HTML 크롤링 대신 API가 있다면 그쪽이 안정적
- GitHub에서 bizinfo.go.kr 크롤링 케이스 스터디 검색

### 이슈 2: RSS 날짜 잘림

**현상**: `Fri, 08 Ma` (10자 잘림)
**원인 코드**: `daily_briefing.py:169` — `pub_date.text.strip()[:10]`

**리서치 항목**:
- RSS 2.0 pubDate 표준 형식 (RFC 2822)
- Python에서 RFC 2822 날짜 파싱 베스트 프랙티스 (dateutil, email.utils 등)
- 출력 형식: `YYYY-MM-DD`로 변환하는 가장 안정적인 방법

### 이슈 3: Anthropic RSS URL 미존재

**현상**: Anthropic 뉴스 수집 0건 (실패 시 조용히 스킵)
**원인 코드**: `daily_briefing.py:47` — `https://www.anthropic.com/rss.xml`

**리서치 항목**:
- Anthropic 공식 블로그의 실제 RSS/Atom feed URL 확인 (WebSearch + WebFetch로 실측)
- 만약 RSS가 없다면: Anthropic 블로그 페이지의 HTML 구조 파악 → 크롤링 셀렉터 도출
- Google AI Blog RSS URL도 재확인: `https://blog.google/technology/ai/rss/` 실제 동작 여부

### 이슈 4: GSC 데이터 지연 미처리

**현상**: GSC 어제 데이터 0 → "긴급: -100% 하락" 오탐
**원인 코드**: `daily_briefing.py:308` — `yesterday = date.today() - timedelta(days=1)`

**리서치 항목**:
- Google Search Console API 공식 문서에서 데이터 지연(freshness) 사양 확인 — 정확히 며칠?
- 업계 케이스 스터디: GSC 자동 보고서 구현 시 날짜를 어떻게 잡는가 (3일 전? 최신 가용일 자동 감지?)
- GSC API에서 "데이터 있는 가장 최근 날짜"를 자동 감지하는 방법이 있는지
