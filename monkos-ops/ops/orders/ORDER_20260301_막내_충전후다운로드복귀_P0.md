# 지시서: 충전 후 다운로드 복귀 + 충전 단위 보정

**[2026-03-01 05:03 KST] M1/쌍아 → 막내2**

## 배경

생성(10c) 완료 후 → 다운로드(70c) 클릭 → 크레딧 부족 → 충전 → 토스 결제 완료 → **다시 생성 화면으로 돌아감**. 생성 결과가 사라지고 원본 확인(step 2)으로 리셋됨.

원인: 토스 결제는 페이지를 떠났다 돌아오는 리다이렉트 방식. 복귀 시 `init()` → `showOriginal()`이 `store.generated = null`로 초기화해버림.

## 수정 1: 충전 후 결과 화면 복원 (result.js init)

### 현재 코드 (result.js 약 695~699행)

```js
// 원본 표시
showOriginal();
```

### 문제

sessionStorage에서 생성 이미지 복원(685~691행) 후, `showOriginal()`(699행)이 `store.generated = null`(139행)로 덮어씀.

### 수정 방향

`init()` 말미에서 `store.generated`가 이미 존재하면 `showOriginal()` 대신 결과 화면(step 3)을 복원할 것.

```js
// === 수정: 생성 이미지 존재 시 결과 화면 복원 ===
if (store.generated) {
  // 원본도 표시 (비교컷용)
  const captured = loadSessionData('captured');
  if (captured) {
    store.captured = captured;
    const imgEl = document.querySelector('#photo-original');
    if (imgEl) imgEl.src = captured;
  }

  const genImg = document.querySelector('#photo-generated');
  if (genImg) genImg.src = store.generated;

  store.step = 3;
  store.stepLabel = TX.resultDone;
  store.resultTitle = TX.resultDone;
  store.resultSubtitle = TX.resultDoneSub;
  store.showStep3Actions = true;
  store.showStep2Actions = false;
  store.watermarkPreview = store.generated;

  const btnDownload = document.querySelector('#btn-download');
  if (btnDownload) btnDownload.disabled = false;

  Monk.log('생성 결과 복원 (토스 충전 후 복귀)');
} else {
  showOriginal();
}
```

### 보충: 충전 의도 플래그로 자동 다운로드

충전 목적이 다운로드였다면 복귀 후 자동으로 다운로드를 진행하는 것이 이상적.

**downloadResult()** — ChargeModule.show() 호출 직전:
```js
sessionStorage.setItem('monkos_pending_action', 'download');
```

**init()** — 결과 화면 복원 직후:
```js
const pendingAction = sessionStorage.getItem('monkos_pending_action');
if (pendingAction === 'download' && store.generated && store.user.credits >= CREDIT_COST.download) {
  sessionStorage.removeItem('monkos_pending_action');
  setTimeout(() => downloadResult(), 300);
}
```
