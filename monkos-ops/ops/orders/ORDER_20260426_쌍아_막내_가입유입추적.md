# 가입 유입 페이지 추적 + GA sign_up 이벤트

> **목적**: 사용자가 어떤 서비스/페이지에서 가입했는지 Firestore에 기록하고, GA에 sign_up 커스텀 이벤트를 전송하여 퍼널 분석을 가능하게 한다.

## 배경

- 현재 Firestore `users` 컬렉션에 `signupSource` 필드 없음
- GA에 `sign_up` 커스텀 이벤트 미전송 (기본 4종만 수집 중)
- 가입자가 어떤 페이지에서 왔는지 추적 불가

## 작업 범위

### 1. 서버 — `monkos_AI/portal/lib/auth.js`

**Google Auth (341행 `handleGoogleAuth`)**:
- POST body에서 `signup_source` 필드 수신
- 신규 가입(`isNewUser`) 시 Firestore에 `signupSource` 저장

```js
// 346행 부근, body 파싱 후
const { credential, access_token, signup_source } = JSON.parse(body);

// 407행 부근, isNewUser 블록 안에 추가
...(isNewUser ? {
  createdAt: new Date().toISOString(),
  credits: 10,
  signupSource: signup_source || '',
} : {}),
```

**Kakao Auth (27행 `handleKakaoCallback`)**:
- state 파라미터에서 `sourcePage` 추출
- 신규 가입 시 Firestore에 `signupSource` 저장

```js
// 113행 부근, stateData 파싱 후
const sourcePage = stateData.sourcePage || '';

// 74행 부근, 신규 가입 set() 안에 추가
signupSource: sourcePage,
```

**LINE Auth** (동일 패턴):
- state 파라미터에서 `sourcePage` 추출
- 신규 가입 시 `signupSource` 저장
- LINE 핸들러 위치 확인 후 Kakao와 동일 적용

### 2. 클라이언트 — 포털 `monkos_AI/portal/public/js/auth.js`

**Google 로그인 2곳** (129행, 148행):
- POST body에 `signup_source` 추가

```js
// 133행 — handleGoogleTokenCallback
body: JSON.stringify({ 
  access_token: tokenResponse.access_token,
  signup_source: window.location.hostname + window.location.pathname
}),

// 152행 — handleGoogleCallback
body: JSON.stringify({ 
  credential: response.credential,
  signup_source: window.location.hostname + window.location.pathname
}),
```

**GA sign_up 이벤트** (두 함수 모두):
- 로그인 성공 후 `data.isNewUser`일 때 gtag 전송

```js
if (data.user) {
  currentUser = data.user;
  updateAuthUI();
  if (data.isNewUser && typeof gtag === 'function') {
    gtag('event', 'sign_up', {
      method: data.user.provider,
      signup_source: window.location.hostname + window.location.pathname
    });
  }
}
```

**Kakao 리다이렉트** (71, 74행):

```js
// 기존

```

**LINE 리다이렉트**: 동일 패턴

**GA sign_up**: Google 로그인 성공 콜백(203행 부근)에서 `data.isNewUser` 시 gtag 전송

### 5. 서버 보정 — Kakao/LINE auth 라우트

- `/auth/kakao` 라우트에서 `req.query.source_page`를 state JSON에 `sourcePage`로 포함
- `/auth/line` 라우트 동일
