# 포털 어드민 모듈 분리 — 설계안 수립

**[2026-03-20 12:13 KST] iMac/쌍아 → 막내3**

## 배경

V4 포털이 16,000줄 / 58개 파일로 성장했으나 **프레임워크 없는 바닐라 구조**로 인해 어드민 8개 페이지가 각각 CSS+JS 인라인 독립. 특히 blog-edit.html이 1,495줄 단일 파일로 이미지 시스템, 시드 카탈로그, 리서치 탭, 공유 버튼이 전부 한 곳에 있어 버그 연쇄 발생 중.

**현재 문제**: 한 곳 수정 → 다른 곳 깨짐 → 79악몽 구조 형성

## 목표

기존 바닐라 스택을 **유지하면서** (프레임워크 전환은 하지 않음), 파일 단위 모듈 분리로 유지보수성 확보.

## 제약 조건

- **프레임워크 도입 안 함** — React/Vue/Svelte 전환은 현 단계에서 과도
- **빌드 도구 안 씀** — Webpack/Vite 등 도입 안 함. ESM import로 해결
- **기존 작동 코드 깨뜨리지 않음** — 점진적 분리
- **크롭앱(crop/)은 건드리지 않음** — 별도 도메인, 안정 운영 중
- **텔레그램 미니앱(tg/)도 건드리지 않음** — 이미 자체 공유 구조

## 작업: 현재 구조 분석 + 분리안 설계

### 1단계: 현재 종속 관계 분석

각 어드민 페이지가 호출하는 API 목록과 공통 패턴을 분석하라.

```
조사 대상: admin/ 8개 페이지
추출할 정보:
- 각 페이지가 fetch()하는 API 엔드포인트 목록
- 인라인 JS에서 공통으로 사용하는 함수 (showToast, auth 체크 등)
- 인라인 CSS에서 공통으로 사용하는 변수/클래스
- 각 페이지 고유 기능 (그 페이지에서만 쓰는 JS)
```

### 2단계: 분리안 설계

위 분석을 기반으로 **폴더 구조 설계안** 제시:

```
제안 구조 (검토용 — 이것을 참고하되 분석 결과에 맞게 조정):

public/
├── admin/
│   ├── css/
│   │   └── admin-common.css         ← 공통 변수 + 레이아웃
│   ├── js/
│   │   ├── admin-common.js          ← showToast, auth, fetch 래퍼
│   │   ├── blog-editor.js           ← Toast UI 초기화, 저장/발행
│   │   ├── blog-image.js            ← 이미지 뱅크, 업로드, 플로팅 툴바
│   │   ├── blog-seed.js             ← 시드 카탈로그
│   │   ├── blog-research.js         ← 리서치 탭
│   │   └── blog-share.js            ← 공유 버튼
│   ├── blog-edit.html               ← HTML만 남음 (JS/CSS 외부 참조)
│   ├── blog-list.html
│   ├── board.html
│   ├── faq.html
│   ├── gallery.html
│   ├── index.html
│   ├── layout.html
│   └── settings.html
```

### 3단계: blog-edit.html 분리 상세 설계

blog-edit.html을 기준으로 구체적 분리 명세를 작성하라:

```
현재 1,495줄을 다음과 같이 분리:

1. admin-common.css (공통)
   - CSS 변수 (:root)
   - 기본 리셋 + body + .nav
   - .btn 시리즈
   - .toast
   - .sidebar-section

2. blog-editor.css (블로그 에디터 전용)
   - .editor-layout (3컬럼)
   - .title-input
   - Toast UI 오버라이드
   - 이미지 관련 (.img-thumb, .img-float-toolbar)
   - 시드/리서치/공유 스타일

3. admin-common.js (공통)
   - showToast()
   - fetch 래퍼 (인증 헤더 자동 포함)
   - requireAuth() 패턴

4. blog-editor.js (에디터 코어)
   - Toast UI 초기화
   - save(), loadPost(), preview()
   - updatePreview(), updateShareButtons()
   - slug 자동생성

5. blog-image.js (이미지 시스템)
   - loadImageLibrary()
   - insertImage() — 단일 진입점으로 통일
   - deleteImage()
   - showLibraryToolbar(), showEditorImageToolbar()
   - createFloatToolbar(), removeFloatToolbar()
   - uploadToLibrary(), uploadThumbnail()
   - 드래그&드롭 핸들러
   - ⚠️ 이벤트 중복 바인딩 방지 패턴 적용

6. blog-seed.js (시드 카탈로그)
   - loadSeedCatalog(), filterSeeds(), renderSeeds()
   - showSeedDetail(), useSeedAsContent()

7. blog-research.js (리서치 탭)
   - doResearch(), renderResearchResults()
   - switchResearchSource()
   - 검색 기록, 자동 제안
```

### 4단계: 백엔드 분리 제안

현재 백엔드는 이미 잘 분리되어 있으나, 다음 개선점을 검토:

```
검토 항목:
- render.js (1,301줄): Fragment 함수별 파일 분리 가능성

- importer/: 중복 방지 공통 유틸 추출
```
