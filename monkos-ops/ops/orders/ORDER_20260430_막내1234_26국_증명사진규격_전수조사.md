# 지시서 — 26국 증명사진 규격 전수조사 (여권/비자 분리)

> 각국 정부 공식 문서를 1차 출처로, **여권과 비자를 분리**하여 전수조사한다.
> 추정·환산 금지. 공식 규정에 명시된 수치만 기재. 없으면 "미규정"으로 표기.

---

## 원칙

1. **1차 출처만**: 각국 외교부/내무부/이민국 공식 사이트. 블로그·앱 사이트 참조 금지
2. **여권과 비자 별도 행**: 동일 국가라도 여권/비자 규격이 다르면 분리
3. **추정 금지**: "35×45mm를 300dpi로 환산하면 413×531" 같은 계산 기재 금지
4. **미규정 표기**: 공식 문서에 해당 항목이 없으면 `미규정`으로 명시
5. **출처 URL 필수**: 모든 수치 옆에 공식 문서 URL 기재

---

## 조사 항목 (행마다)

| 필드 | 설명 |
|------|------|
| country | 국가명 (영문) |
| doc_type | `passport` / `visa` / `national_id` / `drivers_license` / `resume` |
| size_mm | 가로 × 세로 mm (공식 규정) |
| size_inch | 인치 표기 있으면 병기 |
| pixels | **공식 규정된 px**. 없으면 `미규정` |
| dpi | 공식 규정된 해상도. 없으면 `미규정` |
| file_format | JPEG/PNG 등 |
| file_size_limit | KB/MB 제한 |
| head_height_mm | 턱~정수리 mm (공식) |
| head_height_pct | 사진 높이 대비 % (공식) |
| eye_position_mm | 사진 하단~눈 mm (공식) |
| eye_position_pct | 사진 하단~눈 % (공식) |
| background | 배경색 규정 |
| glasses | 안경 허용 여부 |
| validity | 촬영 유효기간 |
| ai_policy | AI 보정 관련 규정 (있으면) |
| source_url | 공식 문서 URL |
| note | 특이사항 |

## 담당 배분

### 막내1 — 한국 + 일본 (8건)

| 국가 | 문서 유형 |
|------|----------|
| 한국 | 여권, 주민등록증, 운전면허, 반명함(관행 규격 표기) |
| 일본 | 여권(パスポート), 마이나번호, 재류카드, 이력서(관행 규격 표기) |

- 한국: 외교부 여권안내, 도로교통공단, 주민등록법 시행규칙
- 일본: 外務省, 総務省(マイナンバー), 法務省(在留カード)

### 막내2 — 미국 + 캐나다 + 호주 + UK (8건)

| 국가 | 문서 유형 |
|------|----------|
| 미국 | 여권, 비자(DS-160), 헤드샷(관행) |
| 캐나다 | 여권 |
| 호주 | 여권 |
| UK | 여권 |

- 미국: travel.state.gov (여권/비자 각각)
- 캐나다: canada.ca/passport
- 호주: homeaffairs.gov.au
- UK: gov.uk/passport

### 막내3 — EU + 아시아 (8건)

| 국가 | 문서 유형 |
|------|----------|
| EU 공통 | 여권/ID |
| 독일 | 여권 (EU와 다르면 분리) |
| 스페인 | 여권/DNI |
| 싱가포르 | 여권 |
| 태국 | 여권 |
| 인도 | 여권, 비자 (정사각형 여부 확인) |

- EU: ec.europa.eu 또는 각국 외교부
- 싱가포르: ica.gov.sg
- 태국: consular.mfa.go.th
- 인도: passportindia.gov.in, indianvisaonline.gov.in

### 막내4 — 중국 + 동남아 + 추가 발굴 (6건+α)

| 국가 | 문서 유형 |
|------|----------|
| 중국 | 여권(护照), 비자, 이력서(1寸/2寸) |
| 베트남 | 여권 |
| 인도네시아 | 여권 |

**추가 발굴**: 위 26국에 포함되지 않았지만 수요 높은 국가 규격이 있으면 note에 추가 제안 (예: 필리핀, 대만, 브라질, 러시아, 사우디 등)

## 준수 조항

⚠️ **추정 수치 기재 금지**: "300dpi 기준 환산" 같은 계산값을 공식 규정처럼 적지 말 것. 공식 px 규정이 없으면 `미규정`
⚠️ **블로그/앱 사이트 출처 금지**: photoaid, visafoto, snap2pass 등은 2차 출처. 반드시 정부 공식 URL
⚠️ **여권/비자 분리 필수**: 같은 나라라도 규격이 다르면 별도 행
