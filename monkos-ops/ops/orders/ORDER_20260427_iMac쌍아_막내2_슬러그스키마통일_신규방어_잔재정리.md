## 1. 배경

### 현재 문제
- translate.js에서 Gemini slug 생성 실패 시 한글 원본 slug + `-ja`/`-en` → 교차오염 25건
- Gemini 성공 시에도 언어별 독립 slug 생성 → 원본과 번역본 연결고리 없음
- blog.js에서 KO 글 작성 시 한글 제목이 slug로 통과됨

### 확정 스키마 (작가님 설계)

```
베이스: {영문slug}
  ├ /blog/{영문slug}-kr        (한국어)
  ├ /ja/blog/{영문slug}-ja     (일본어)
  └ /en/blog/{영문slug}-en     (영어)
```

**원칙**:
- 베이스 slug는 반드시 영문 ASCII
- 언어 접미사(`-kr`, `-ja`, `-en`)로 분기
- 하나의 베이스에서 3개 언어가 파생 — hreflang 자동 매칭
- Gemini는 베이스 slug 1회만 생성 (번역 시 재생성 안 함)

## 2. 작업 A: 신규 글 방어 (코드 수정)

### A-1. blog.js — KO 글 생성 시 영문 베이스 slug 강제

**파일**: `monkos_AI/portal/lib/cms/blog.js`

**현재 (122~126행)**:
```javascript
let slug = sanitizeSlug(body.slug || generateSlug(title));
if (!slug) {
  slug = await generateSlugFromAI(title);
  log(`[CMS] AI slug 생성: "${title}" → "${slug}"`);
}
```

**문제**: `generateSlug(title)`이 한글 제목을 그대로 통과시킴. `sanitizeSlug`가 한글을 제거하지 않음.

**변경 로직**:
```
1. body.slug가 명시적으로 제공된 경우 → sanitizeSlug 후 사용
2. 미제공 시 → generateSlugFromAI(title)로 영문 slug 생성 (Gemini)
3. Gemini 실패 시 → fallback: 'post-' + timestamp
4. 최종 slug에 언어 접미사 추가: slug + '-' + (lang || 'kr')
5. 한글 문자 최종 방어: /[가-힣ㄱ-ㅎㅏ-ㅣ]/ 감지 시 강제로 generateSlugFromAI 재시도
```

**핵심 변경점**:
- KO 글이면 항상 `generateSlugFromAI` 경유
- 최종 slug에 `-kr` 접미사 추가 (`lang` 필드 기반)
- 한글이 slug에 남아있으면 차단 (저장 거부 or 재생성)

### A-2. translate.js — 번역 시 베이스 slug 재사용

**파일**: `monkos_AI/portal/lib/cms/translate.js`

**현재 (126~139행)**:
```javascript
let translatedSlug;
if (translated.slug) {
  translatedSlug = translated.slug
    .toLowerCase()
    .replace(/[^a-z0-9-]/g, '')
    .replace(/-+/g, '-')
    .replace(/^-|-$/g, '')
    .substring(0, 60);
  translatedSlug = `${translatedSlug}-${lang}`;
} else {
  translatedSlug = `${slug}-${lang}`;
}
```

**변경 로직**:
```javascript
// 원본 slug에서 언어 접미사 제거 → 베이스 추출
const baseSlug = slug.replace(/-(kr|ja|en)$/, '');
const translatedSlug = `${baseSlug}-${lang}`;
```

**핵심 변경점**:
- Gemini의 `translated.slug` **무시** — 더 이상 번역 시 slug를 독립 생성하지 않음
- 원본 베이스 slug + 타깃 언어 접미사만 사용
- Gemini 프롬프트에서 slug 생성 지시를 제거해도 됨 (선택)

### A-3. JSON_INSTRUCTION 프롬프트 정리 (선택)

**파일**: `monkos_AI/portal/lib/cms/translate.js` 44~51행

slug 필드를 프롬프트에서 제거하거나, `"slug": "IGNORE - auto-generated"` 로 변경.
번역 시 Gemini가 slug를 만들어도 쓰지 않으므로, 토큰 낭비 방지.
