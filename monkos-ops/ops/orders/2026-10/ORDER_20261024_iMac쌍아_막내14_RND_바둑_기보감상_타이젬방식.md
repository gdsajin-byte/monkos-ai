## 6. 외부 기보 불러오기 (SGF · GIB)

- 대기실 '기보 불러오기': 파일 선택 + 대기실 화면에 끌어다 놓기. 여러 개 한 번에 가능.
- 서버 `POST /api/import`(본문 = 파일 내용 + 파일명, 1MB 상한) → 파싱 → **보기 전용 방** 생성(`imported` 계열, 출처 구분 필드 예: `source: "upload"`, 원본 파일명 보관) → 지난 대국 목록에 `불러온 기보 · 흑 {PB} vs 백 {PW}`로 표시. 같은 내용(해시) 재업로드는 기존 방으로 안내.
- **SGF**: 메인 라인만(변화도는 버림, 버렸다는 표시 1줄), `SZ[19]`만 허용(그 외 크기는 사유와 함께 거부), `HA`·`AB`·`KM`·`RE`·`PB`·`PW`·`BR`·`WR`·`DT` 읽기, `CA` 인코딩 존중.
- **GIB(타이젬)**: 헤더 `\[GAMEBLACKNAME=…\]` 류 + `STO 0 n 색 x y` 수순 라인 파싱(색·좌표 규약은 실파일로 확인). **인코딩 UTF-8 실패 시 CP949(EUC-KR) 폴백** — 한글 대국자명이 깨지면 불합격.
- 파싱 실패는 무음 금지: 화면에 `❌ 불러오기 실패: {파일명} — {사유}`.
- 픽스처: `apps/go-board-web/fixtures/`에 SGF(호선·접바둑·변화도 포함·CP949) 각 1개, GIB 1개 이상. **GIB 실파일을 구하지 못하면 '미실증'으로 보고**하고 작가님께 타이젬 기보 1개를 요청한다(합성 파일로 합격 처리 금지).
