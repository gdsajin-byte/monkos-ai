```javascript
// 중복 지시사항을 한 곳에서 관리

- 크레딧 시스템 안내: ...

`;

const SYSTEM_PROMPT = SHARED_RULES + `...`; // web/kakao
const CS_SYSTEM_PROMPT = SHARED_RULES + `...`; // telegram
// ...

module.exports = { SYSTEM_PROMPT, CS_SYSTEM_PROMPT, PREP_SYSTEM_PROMPT, buildCoachingPrompt, buildQCInstruction };
```

### 4. `lib/telegram.js` — 텔레그램 통합 봇 (~300줄)

**CS봇 + 이벤트봇 통합** (본인 보고서의 TG 통합 설계안 기반):

```javascript
const { db, log, TELEGRAM_CS_API, TELEGRAM_EVENT_API } = require('./shared/config');
const { chatWithMonkos } = require('./chat-engine');

// 단일 웹훅 핸들러 — 메시지 타입으로 분기
function handleTelegramWebhook(req, res) {
  // /start GATE_{code} → 게이트 검증
  // /start MISSION_{code} → 미션 처리
  // /start (일반) → 환영 메시지
  // 이미지 → 미션 이미지 수신
  // 텍스트 → CS AI 응답
}

module.exports = { handleTelegramWebhook };
```

**주의**: 당장은 기존 2개 웹훅 그대로 유지하되, 통합 래퍼만 준비. 실제 봇 통합(텔레그램 웹훅 변경)은 별도 단계.
