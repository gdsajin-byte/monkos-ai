# 지시서: 무료 티어 통합 설계 — UX 퍼널 + UI + 크롭 최적화

**[2026-07-09 17:29 KST]** iMac/쌍아 → 민아

## 배경

오늘 세션에서 작가님과 확정한 방향:
1. 무료 티어 도입 (크롭+배경제거)
2. 가격 사다리: 무료 → AI 보정 ₩2,000 → 발급보장 ₩9,900 → 인화 ₩15,000
3. 크롭 고정 계수 제거 (8% 헤어볼륨, 43% 눈위치 → 제약 최적화)
4. "규격 안착" UX 변경 → 문제점만 표시

## 작가님 확정 사항 (변경 불가)

- 얼굴 크기 33mm = 타겟. 32~33mm 범위에서 동적 조정 가능. 32mm 미만 축소 금지.
- 정수리 = 눈~턱 1:1 미러 (해부학 기준, 현행 유지)
- 헤어볼륨 8% 고정 = 폐기. 실측 또는 0 폴백.
- 눈 위치 = 고정값이 아닌 종속 변수 (제약 최적화의 결과)
- 하단 여백 = 고정값이 아닌 종속 변수
- 헤어 잘림 = 허용 (규격 우선, 헤어 때문에 얼굴 축소 금지)
- 발급보장 = 로그인 필수 (결제 정보 = 본인 식별)
- 비로그인 = 총 3회 체험 (IP 기반, 리셋 없음)
- 로그인 = 월 10회 무료

## Task 1 — UX 퍼널 설계

### 전체 흐름

```
[specs 페이지 진입] → 규격 선택 (또는 URL에서 자동)
  ↓
[사진 업로드] → precheck (측정 가능성 판단)
  ↓ 통과
[fit 시어터] → 규격 안착 미리보기 + 포스트 검수 뱃지
  ↓
[분기 선택]
  ├─ "무료 다운로드" → 크롭+배경제거 → 결과+포스트검수 → 다운로드
  ├─ "AI 보정 ₩2,000" → + AI 보정생성 → 결과 → 다운로드
  └─ "발급보장 ₩9,900" → + AI 보정+스튜디오 검수 → 결과 → 다운로드
      └─ [옵션] "인화 +₩5,100" → 배송지 입력 → 인화 발송
```

### 무료 제한 UX

```
비로그인 총 3회 소진 시:
  "무료 체험을 모두 사용했어요. 가입하면 매월 10회 무료로 사용할 수 있어요."
  [가입하기] [AI 보정 ₩2,000]

로그인 월 10회 소진 시:
  "이번 달 무료 횟수를 모두 사용했어요."
  [AI 보정 ₩2,000] [크레딧 충전 (10c = ₩1,500)]
```

### 발급보장 → 인화 업셀

```
발급보장 결과 화면:
  "발급보장 완료 — 반려 시 재제작 보장"
  [다운로드] [인화 주문 +₩5,100 (배송 별도)]
```

## Task 2 — UI 디자인 방향

### fit 시어터 개선

현행 "규격 안착 — 규격에 안착했습니다. 이대로 만들 수 있어요." → 변경:

- 통과 시: 전 항목 나열 대신 **문제점만** 표시. 문제 없으면 바로 분기 선택.
- 경고 시: 뱃지로 표시 (기울기, 입 벌림 등) + "AI 보정으로 개선 가능"

### 분기 선택 UI

3개 카드 또는 버튼:
```
[무료 다운로드]        [AI 보정 ₩2,000]      [발급보장 ₩9,900]
 크롭+배경제거          +피부보정+정장합성       +스튜디오검수+재제작보장
```

### 포스트 검수 결과 화면 (무료 포함)

```

✅ 얼굴 33mm (허용 32~36mm)
✅ 눈 위치 44%
⚠️ 기울기 3° — AI 보정으로 교정 가능
⚠️ 입 벌림 — AI 보정으로 교정 가능

[다운로드]  [AI 보정으로 개선 ₩2,000]
```

## Task 3 — 크롭 제약 최적화 검증

설계서 `DESIGN_20260709_크롭제약최적화_IDPASS산술화.md`를 검증.

### 작가님 확정 원칙 (민아 이전 검증과 달라진 점)

- **정수리 3mm hard 철회** — hard는 "두상 잘림 금지(여백≥0)" + 하단은 고정 아님
- **하단 7/8mm 결정 불필요** — 하단도 종속 변수 (최적화 결과)
- **헤어 vs 눈 위치 우선순위(F3) 소멸** — 둘 다 종속 변수

### 최적화 구조 (확정)

```
고정: scale → 얼굴 33mm 타겟 (32~33mm 범위에서 조정 가능)
변수: extractTop (수직 이동)
hard 제약: 두상(정수리) 프레임 밖 금지
soft 타겟: 헤어탑 위 2~3mm (잘려도 됨)
결과: 눈 위치, 상단 여백, 하단 여백
```

### 검증 포인트

1. F1(폴백 방향) — clamp 한 줄로 대체 확인
2. F2(cropToSpecV2) — 포함 or 폐기 판단
3. 의사코드 검산 — 한국 여권 + 반명함 + 미국 여권(제외 확인)
