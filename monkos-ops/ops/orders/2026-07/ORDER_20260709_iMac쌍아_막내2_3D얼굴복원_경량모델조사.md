# 지시서: 3D 얼굴 복원 경량 모델 조사 (R&D)

**[2026-07-09 18:10 KST]** iMac/쌍아 → 막내2

## ⚠️ 준수 조항

- 헌법 4조 1항(비밀정보 보호)
- 리서치 과제 — 프로덕션 코드 변경 없음. 웹 검색 활용.

## 배경

현행 정수리 추정은 1:1 미러(해부학적 추정)에 의존한다. 정수리 랜드마크를 직접 제공하는 모델이 없어서 추정의 한계가 있다.

3D 얼굴 복원 모델(3DDFA, FLAME, DECA 등)은 2D 사진에서 3D 메시를 생성하며, 메시의 꼭대기 점(vertex)이 정수리 좌표를 제공할 수 있다. 이 기술은 증명사진 정수리 추정뿐 아니라, 가상 피팅·얼굴 합성·AR·아바타 등 장기 확장의 기반이 된다.

경량 ONNX 모델의 존재 여부와 정수리 좌표 추출 가능성을 조사한다.

## Task 1 — 3D 얼굴 복원 모델 후보 조사

### 조사 대상

| 모델 | 특징 | 예상 크기 |
|------|------|----------|
| 3DDFA_V2 | 3D Dense Face Alignment. 2D→3D 메시. 경량. | ~10MB? |
| DECA | Detailed Expression Capture and Animation. FLAME 기반. | ~50MB? |
| FLAME | Faces Learned with an Articulated Model and Expressions. 통계 모델. | 파라미터만 |
| PRNet | Position Map Regression. 2D→3D UV 맵. | ~10MB? |
| SynergyNet | 3DMM 파라미터 회귀. 경량. | ~15MB? |
| MediaPipe Face Landmarker | 478점 (468+10 iris). 이마 위 포인트 포함 여부 확인. | ~2MB |

### 조사 항목

각 모델별:
1. **ONNX 변환본 존재 여부** + 파일 크기
2. **정수리(vertex/crown) 좌표 추출 가능 여부** — 메시 꼭대기 점이 정수리인지
3. **추론 시간** (CPU 기준, 논문/벤치마크 참고)
4. **입력 사양** (이미지 크기, 전처리)
5. **출력 형태** (3D 좌표 배열, UV 맵, 파라미터 등)
6. **라이센스** (상용 가능 여부)

### 특별 확인: MediaPipe Face Landmarker 478점

468점 FaceMesh는 정수리를 안 주지만, **2023년 업데이트된 Face Landmarker**에서 478점으로 확장됨. 이마 위/정수리 포인트가 추가되었는지 확인.

## Task 2 — 정수리 좌표 정의 확인

3D 메시에서 "정수리"에 해당하는 vertex가:
- **실제 두개골 꼭대기(anatomical vertex)**인지
- **메시의 수학적 최상단**인지
- **헤어라인 위 이마**까지만인지

모델별로 메시 커버리지가 다를 수 있음. 얼굴 메시가 이마 위까지 올라가는지, 두개골 전체를 커버하는지 확인.

## Task 3 — 증명사진 이외 활용 가능성

3D 복원 모델이 제공하는 것들 정리:
- 정수리 좌표 (증명사진 크롭)
- 3D 포즈 (pitch/yaw/roll — 6DRepNet 대체 가능?)
- 얼굴 형태 파라미터 (개인화)
- 표정 파라미터 (입 벌림/눈 감김 — 현행 gate 대체?)
- 텍스처 맵 (가상 피팅, 합성)
- depth map (AR, 리라이팅)
