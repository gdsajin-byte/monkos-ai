# 지시서: V2 퍼널 게이트 개방 + gray T1 비노출

**[2026-07-18 17:32 KST]** iMac/쌍아 → 막내2

## 배경

배경색을 회색으로 교정한 16슬러그가 V2 퍼널에서 V1 정보 페이지로 강등됐다. 원인: `isEngineCompatibleSpec`(render-specs.js:377)이 "배경=흰색만 V2 허용"으로 막고 있었다. matte 파이프라인이 이미 배경색 합성을 하고 있으므로 이 게이트는 낡은 전제. T0는 즉시 개방, T1은 gray 국가만 임시 비노출.

## ⚠️ 준수 조항

- 전 지시서와 동일. jest 녹색 후 배포. deploy.sh 경유.

## 작업 3건

### 1. V2 퍼널 게이트 개방 (render-specs.js)

`isEngineCompatibleSpec` (L367-379)의 배경색 체크를 확장:

**현행 (L377-378)**:
```javascript
const bg = String(specData.background || '').trim();
return bg.startsWith('흰') || /^white/i.test(bg);
```

**변경 — 파랑·빨강만 제외, 나머지 허용**:
```javascript
const bg = String(specData.background || '').trim();
if (/파란|빨간|blue|red/i.test(bg)) return false;
return true;
```

이로써:
- 회색 16슬러그 (kz·ch·at·dk·gr·de·nz·jm) → V2 복구
- uk·fr·au·fi·ru(비자) 등 light-gray 17슬러그 → V2 신규 개방
- kw·om(파랑)·id(빨강) → V1 유지 (보수)

### 2. gray 국가 T1 업셀 비노출

T1(나노)은 흰 배경 고정 생성이고 매팅을 안 거치므로, 회색국 T1 산출물은 배경 규정 위반이 된다. 재채색 트랙 구현 전까지 gray 국가에서 T1 업셀 카드를 숨긴다.

**specs-funnel.js 또는 render-specs.js V2 프래그먼트**:
- `specData.background`가 회색 계열이면 T1 업셀 카드 비노출
- T0 무료 생성은 정상 노출 (matte가 배경색 합성)

### 3. SEO 문구 "흰색" 잔존 정정

specs-data.json의 해당 슬러그들에서 유저 대면 텍스트에 "흰색 배경" 안내가 남아있으면 → 교정된 배경색에 맞게 수정.
