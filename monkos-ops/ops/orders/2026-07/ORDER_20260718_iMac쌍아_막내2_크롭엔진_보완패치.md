## 작업 5건

### 1. vn headHeight 범위 제거 (P0 — 자기모순 재라이브)

**문제**: faceTargetExplicitMm=42를 복원했는데 headHeightMin=36, headHeightMax=40이 그대로라 face 게이트가 42를 차단한다. 어제 인시던트와 동일한 자기모순.

**수정** (specs-data.json):
- vn-passport: `headHeightMin`, `headHeightMax` 필드 제거 (B급 웹텍스트 유래, §6 우선순위 규칙에 의해 명시값 42가 우선)
- vn-visa: 동일

**수정** (관련 테스트):
- vn 관련 가드 테스트가 36~40 범위를 기대하고 있다면 → 명시값 42 기준으로 갱신

### 2. T1 실패 응답 정비 (유저 노출 수정)

**문제**: 서버가 `code` 필드 없이 응답해서 퍼널이 `T1_GENERATE_FAILED` 원시 문자열을 유저에게 노출. 4언어 message가 클라이언트에 안 도달.

**수정**:
- 서버 응답에 `code: 'T1_GENERATE_FAILED'` 필드 추가
- 퍼널(specs-funnel.js)에서 `code` 분기 → 4언어 message 표시
- "결제는 소모되지 않았습니다" 안내 문구 추가 (§3-3 확정):
  ```javascript
  const T1_FAIL_USER_MSG = {
    ko: '사진 생성에 실패했습니다. 크레딧은 소모되지 않았습니다. 다른 사진으로 다시 시도해 주세요.',
    en: 'Photo generation failed. No credits were used. Please try again with a different photo.',
    ja: '写真の生成に失敗しました。クレジットは消費されていません。別の写真でもう一度お試しください。',
    es: 'Error en la generación de la foto. No se consumieron créditos. Inténtelo de nuevo con otra foto.'
  };
  ```

### 3. bg 3언어 텍스트 정리

**문제**: de-passport, kz 등의 `backgroundEn/Ja/Es`가 "White" 그대로. 실합성은 맞지만 유저 대면 표시와 모순.

**수정** (specs-data.json):
- bg를 "회색"으로 바꾼 슬러그들의 `backgroundEn`을 `"Gray"`, `backgroundJa`를 `"グレー"`, `backgroundEs`를 `"Gris"`로 통일
- de-passport: `background`를 `"회색"` (현재 "독일 규정 회색"은 유저 대면 카피로 부적절), matte.js에서 슬러그 오버라이드로 #CCCCCC 적용 (BG_OVERRIDE 맵 확인)

### 4. 경고 배너 렌더링

**문제**: warning·onsite·digitalOnly가 데이터에 있지만 render-specs에서 참조 0. 유저에게 안 보임.

**수정** (portal/lib/cms/render-specs.js 또는 해당 렌더러):
- `onsite: true`인 슬러그: 퍼널 상단에 경고 배너 표시 (warning 텍스트 사용, 언어별)
- `digitalOnly: true`: 해당 안내 표시
- warning 필드가 있는 슬러그: specs 상세 페이지에 경고 섹션 표시

**배너 스타일**: 기존 경고/안내 UI 패턴 준용. 새 컴포넌트 불필요 시 인라인.
