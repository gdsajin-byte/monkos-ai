# 지시서: 크롭 제약 최적화 — 8% 제거 + clamp 배치

**[2026-07-09 17:58 KST]** iMac/쌍아 → 막내

## ⚠️ 준수 조항

- 헌법 4조 1항(비밀정보 보호), 4조 2항(파괴적 명령 금지)
- ch5 2조(배포는 deploy.sh 경유)

## 배경

현행 크롭 로직의 `HAIR_VOLUME_RATIO = 0.08` (정수리 위 8% 일괄 가산)이
대머리~볼륨펌을 동일 취급하여 상단 여백 과대/과소를 유발한다.
작가님 경험칙을 산술화하여 고정 계수를 제거하고, 제약 기반 clamp 배치로 교체한다.

## 작가님 확정 원칙

1. 얼굴 33mm 타겟. 필요 시 32.5mm까지 축소. 32mm 터치 금지.
2. 정수리(두상) 잘림 = 절대 불가 (hard)
3. 헤어 잘림 = 허용 (정수리 위 약간의 헤어만 살리면 됨)
4. 어깨 = 최대한 보이게 (soft)
5. 눈 위치 = 고정값 아님, 결과값
6. 하단 여백 = 고정값 아님, 결과값
7. 헤어 때문에 얼굴을 32mm 미만으로 축소 금지

## Task 1 — HAIR_VOLUME_RATIO 제거 + clamp 배치

파일: `crop-engine/lib/crop.js` — `cropToFrame()` 함수

### 1-1. 상수 변경

```javascript
// 삭제:
const HAIR_VOLUME_RATIO = 0.08;

// 유지:
const HAIR_MARGIN_MIN = 0.044;  // → 용도 변경: soft 타겟 여백 (2mm/45mm)
const FACE_TARGET_MM = 33;
const FACE_MIN_MM = 32.5;       // 변경: 32 → 32.5 (32mm 터치 금지)
```

### 1-2. 헤어탑 추산 변경

현행:
```javascript
const hairTopY = crownY - (faceHeight * HAIR_VOLUME_RATIO);
```

변경:
```javascript
// 헤어탑 = 정수리 그대로 (8% 폐기. 실측 준비되면 교체)
const hairTopY = landmarks.hairTop ?? crownY;
```

### 1-3. 배치 로직 교체

현행 Step 5~6 (43% 앵커 + 헤어 잘림 시 밀기 + 축소 루프) 전체를 교체:

```javascript
// ─── 5. 제약 기반 clamp 배치 ───
const mmPx = frameH / FRAME_MM;
const softMarginPx = 2 * mmPx;  // 헤어 위 soft 타겟 2mm

// hard 제약: 정수리 잘림 금지 (여백 ≥ 0)
const topMax = Math.round(crownY * scale);

// soft 타겟: 헤어탑 위 2mm
const topTarget = Math.round(hairTopY * scale - softMarginPx);

// 하한: 프레임 하단 = 이미지 하단 (어깨 최대 노출)
const topMin = Math.max(0, Math.round(chin.y * scale - frameH * 0.95));

let extractTop = Math.max(topMin, Math.min(topMax, topTarget));

// 스케일 축소 시도: 헤어탑이 프레임 밖이면 32.5mm까지
if (hairTopY * scale - extractTop < 0) {
  const faceMinRatio = FACE_MIN_MM / FRAME_MM;
  let newScale = scale;
  while (newScale * faceHeight > frameH * faceMinRatio) {
    newScale *= 0.995;
    const newTopMax = Math.round(crownY * newScale);
    const newTopTarget = Math.round(hairTopY * newScale - softMarginPx);
    const newTopMin = Math.max(0, Math.round(chin.y * newScale - frameH * 0.95));
    const newExtractTop = Math.max(newTopMin, Math.min(newTopMax, newTopTarget));
    if (hairTopY * newScale - newExtractTop >= 0) {
      scale = newScale;
      extractTop = newExtractTop;
      break;
    }
  }
  // 32.5mm에서도 안 되면 → 33mm 유지, 헤어 잘림 허용
  if (scale === targetFaceH / faceHeight) {
    extractTop = topMax;  // 정수리 여백 0 = 헤어 최대 잘림
  }
}
```

### 1-4. EYE_POSITION_RATIO 사용 제거

`EYE_POSITION_RATIO`를 배치에 사용하지 않는다. 눈 위치는 결과값으로 meta에만 포함.
