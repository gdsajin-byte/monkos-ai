## 작업 4건

### 1. 경고 배너 V2 프래그먼트 이동 (P1)

render-specs.js:887의 배너 블록이 V1 레거시 프래그먼트 안에 있다. 실서빙은 V2(396~660)로 조기 반환되므로 배너가 어떤 페이지에도 안 나온다.

**수정**: 배너 블록(onsite 📍 / warning ⚠️ / digitalOnly 💻)을 V2 프래그먼트 내부로 이동. 라이브에서 br-passport·ph-passport·mx-passport·pe-passport에 배너 노출 확인.

### 2. FACE_NOT_DETECTED 코드 관통 + 퍼널 4언어 (P1)

커버 크롭 제거로 엔진이 `FACE_NOT_DETECTED`를 반환하는데, matte 층에서 이 코드가 버려지고 무료 503 "현재 이용자가 많습니다"로 나간다. 사진 문제를 혼잡으로 오도.

**수정**:
- matte.js: `FACE_NOT_DETECTED` 코드를 상위로 관통 반환
- specs-funnel.js: 해당 코드 분기 + 4언어 메시지:
  ```javascript
  const FACE_NOT_DETECTED_MSG = {
    ko: '얼굴을 찾을 수 없습니다. 다른 사진으로 다시 시도해 주세요.',
    en: 'No face detected. Please try again with a different photo.',
    ja: '顔が検出できませんでした。別の写真でもう一度お試しください。',
    es: 'No se detectó un rostro. Inténtelo de nuevo con otra foto.'
  };
  ```

### 3. de-visa 배경 + warning es 폴백 (소건)

- de-visa: background를 de-passport와 동일하게 "회색" + 3언어 Gray/グレー/Gris. BG_OVERRIDE에 `'de-visa': '#CCCCCC'` 추가.
- warning 필드에 es 키가 없는 경우: en 폴백 체인 추가 (es가 없으면 en 표시)

### 4. 라이브 실측 확인

배포 후 직접 확인:
- br-passport 페이지에 onsite 배너 표시되는지
- vn-visa 무료 생성에서 감지 실패 시 "얼굴을 찾을 수 없습니다" 표시되는지
- de-visa 배경이 #CCCCCC인지
