## 1. 배경 (작가님 ES 실캡처 기반 실측, 이 문서만 읽으면 됨)

prod 피커의 미완 3종이 실측 확정됐다:
1. **카탈로그 이미지 4/37장만 실존** — GCS 원본 자체가 4장(charcoal 수트 m/f·흰 블라우스·네이비타이 셔츠), 나머지 33장은 swatch 색 원으로 폴백 중. 각 아이템에 `attire_desc`(생성 프롬프트)는 완비, 생성기 [tools/attire-assets/generate_samples.mjs](../../../../monkos_AI/portal/tools/attire-assets/generate_samples.mjs)도 완비(고스트 마네킹 t2i, `--ids` 생략 시 thumbnail 빈 active 전부 대상).
2. **es 페이지 피커에 한국어 노출** — attire-picker.js UI_TEXT가 ko/ja/en뿐(es 없음 → ko 폴백: "의상 선택"·"내 옷 사진 올리기·곧 열려요"·"AI 합성 연출…"), attire-presets.json labels도 ko/ja/en뿐 → **raw id 노출**("m_suit_navy_", "m_suit_charco" 잘림).
3. **카테고리 필터 칩** "전체/suit/shirt" — 전체=ko 고정, suit·shirt=raw id.

## 2. 작업

**A. i18n·폴백 마감 (선행 — 빠름)**
1. attire-picker.js `UI_TEXT.es` 추가 (ko 구조 미러, 중남미 중립·usted 톤): title 'Elegir atuendo', gm/gf/all, upload/uploadOn/soon, notice, warnLight, uploadBad.
2. attire-presets.json: 37 아이템 `labels.es` + categories의 라벨에 es (suit→Traje, shirt→Camisa 계열). '전체' 칩이 UI_TEXT.all인지 확인 후 es 연결.
3. **폴백 체인 수정**: `(it.labels && it.labels[lang]) || it.id` → `|| labels.en ||` 삽입 — raw id 노출 금지 (cat.labels 동일).

**B. 카탈로그 이미지 33장 생성·적재**
1. `PROJECT_ID=monkos node tools/attire-assets/generate_samples.mjs` (ids 생략 = 빈 썸네일 전량) — Vertex ADC 환경.
2. 자체 1차 검수: 고스트 마네킹 형식·3:4·배경 일관(기존 4장 레퍼런스와 대조). 형식 이탈분은 해당 id 재생성(최대 2회), 그래도 이탈 시 목록 보고.
3. 통과분: GCS `assets/attire/` 적재 + 로컬 `public/images/attire/{id}_thumb.webp` 제작(기존 4장과 동일 규격 — 크기·품질 파라미터 맞춤).
4. attire-presets.json thumbnail 경로는 기존 참조 그대로 — 파일만 채우면 됨.
