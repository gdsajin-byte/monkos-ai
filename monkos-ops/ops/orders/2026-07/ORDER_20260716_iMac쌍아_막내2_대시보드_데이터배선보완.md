## 작업 1: deploy.sh 시크릿 주입 4종 추가

`monkos_AI/portal/deploy.sh`의 `--set-secrets` 라인에 4건 추가:

```
NAVER_SEARCHAD_API_KEY=NAVER_SEARCHAD_API_KEY:latest
NAVER_SEARCHAD_SECRET_KEY=NAVER_SEARCHAD_SECRET_KEY:latest
NAVER_SEARCHAD_CUSTOMER_ID=NAVER_SEARCHAD_CUSTOMER_ID:latest
BING_WMT_API_KEY=BING_WMT_API_KEY:latest
```

네이버 DataLab은 .env의 NAVER_CLIENT_ID + SM의 NAVER_CLIENT_SECRET으로 이미 가용 — deploy.sh에 추가 주입 불필요한지 확인. 필요하면 추가:

```
NAVER_DATALAB_CLIENT_ID=NAVER_DATALAB_CLIENT_ID:latest
NAVER_DATALAB_CLIENT_SECRET=NAVER_DATALAB_CLIENT_SECRET:latest
```

## 작업 2: performance 빈캐시 가드

dashboard.js의 performance 핸들러에서:
- 빈 결과(`results.length === 0` 또는 에러)는 **캐시하지 않는다**
- 캐시 저장 조건에 `if (results.length > 0)` 가드 추가
