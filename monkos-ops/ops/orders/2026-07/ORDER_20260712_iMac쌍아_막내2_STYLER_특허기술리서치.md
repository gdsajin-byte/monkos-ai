## 목적

MONKOS의 서비스 진화선 — **증명사진(IDPASS) → 헤드샷(PROFILES) → 모델스(VTON) → 스타일러(커머스 중개) → 앱(온디바이스)** — 전체를 하나의 기술 파이프라인으로 볼 때, 특허 출원 가능한 기술 요소·방법·시스템을 포괄적으로 리서치한다.

핵심 구성요소:
- **정체성 보존 AI 변환** (얼굴 정체성 90% 유지 + 10% 보정)
- **의상 피커 → 프롬프트 합성 → 생성** (텍스트형/이미지 레퍼런스형)
- **규격 게이트** (ICAO 등 국제규격 자동 크롭 + 프레이밍 검증)
- **ArcFace 정체성 게이트** (원본 vs 생성 동일인 검증)
- **VTON 파이프라인** (CatVTON/Flux 기반 가상 피팅)
- **옵션 스택 커머스** (AI 생성 → 의상 선택 → 인화 → 배송 일괄 결제)
- **온디바이스 얼굴 인식 + 서버 사이드 생성 분리 아키텍처**
- **멀티서비스 공유 피커** (증명사진/헤드샷/모델스/스타일러 공용 의상 스키마)

## 리서치 범위

### A. 선행 기술 조사 (Prior Art)

1. **특허 DB 검색** — 한국(KIPRIS), 미국(USPTO), 국제(WIPO/PCT)
   - 키워드: AI passport photo, identity-preserving image generation, virtual try-on commerce, attire picker AI, face-preserving style transfer, automated document photo compliance
   - 주요 출원인: Google, Apple, Samsung, Meitu/BeautyPlus, Perfect Corp, DressX, Zeekit/Walmart, PhotoAiD, Aragon AI

2. **경쟁사 IP 현황**
   - 증명한컷, 인핸즈, AI SuitUp 등 A카테고리 업체의 특허 보유 여부
   - Kling AI, FASHN.ai 등 VTON 업체의 특허/오픈소스 라이선스 현황
   - Perfect Corp, ModiFace(L'Oreal) 등 AR 뷰티 업체의 특허 포트폴리오 범위

### B. MONKOS 특허 가능 영역 분석

각 영역에 대해 **특허성 3요소(신규성/진보성/산업적 이용 가능성)** 관점으로 평가:

1. **정체성 보존 규격 사진 자동 생성 시스템**
   - 입력(셀카) → 정체성 보존(90/10) → 규격 자동 크롭 → 프레이밍 게이트(재생성 로직) → 출력
   - 특히 "프레이밍 게이트"(규격 초과 시 재생성 1회, 재이탈 시 폴백) 로직

2. **멀티서비스 공유 의상 피커 + 프롬프트 생성**
   - 단일 스키마가 증명사진/헤드샷/모델스/커머스에 걸쳐 서비스되는 구조
   - 태그 기반 의상 스키마 → 자연어 프롬프트 자동 합성 → i2i 모델 입력

3. **정체성 게이트 (ArcFace 기반 동일인 검증)**
   - 생성 결과가 원본과 동일인인지 자동 검증 → 미통과 시 재생성/폴백
   - "AI 생성 사진의 정체성 보장"이라는 방법 특허

4. **AI 생성 + 인화 + 배송 통합 옵션 스택**
   - 온라인 AI 사진 생성 → 규격 인화지 자동 배치 → 인화 주문 → 배송까지 일괄 처리
   - 사진관 O2O 모델의 AI 전환 방법

5. **온디바이스 얼굴 인식 + 서버 사이드 생성 분리 아키텍처**
   - 개인 데이터(얼굴)는 디바이스에 잔류, 서버에는 스타일 요청만 전송
   - 프라이버시 보존 AI 스타일링 시스템

6. **가상 피팅 + 커머스 중개 B2C 통합**
   - VTON 결과 → 해당 상품 구매 링크 → 어필리에이트/직접 중개
   - "AI 가상 피팅 + 어필리에이트 커미션 중개" 결합 (벤치마크상 현존 사례 없음)

7. **규격 도해 자동 생성 시스템**
   - 국가별·문서별 규격 데이터 → 대표 이미지 + 치수선 → 다국어 브랜딩 자동 생성
   - 1,278종 자동 생성 실적

### C. 특허 전략 제언

- 출원 우선순위 (방어 vs 공격 vs 라이선싱)
- 특허 vs 영업비밀 판단 (공개해도 괜찮은 것 vs 비공개 유지해야 하는 것)
- 한국 우선 출원 → PCT 국제 출원 타임라인
- 비용 개략 추정 (한국 출원 / PCT / 미국 진입)
- 스타트업 IP 전략 관점 (투자유치·매각 시 IP 포트폴리오 가치)

### D. 리스크 분석

- 기존 특허 침해 리스크가 있는 영역 (우리가 밟을 수 있는 지뢰)
- 오픈소스 라이선스 충돌 (CatVTON Apache 2.0, IDM-VTON CC BY-NC-SA 등)
- AI 생성물의 특허 적격성 논쟁 (AI가 발명자가 될 수 있는가)
