## 작업 3건

### 1. hairTop 새니티 캡 (crop-engine/lib/crop.js)

**문제**: 나노 생성 이미지의 배경 아티팩트를 hairTop 스캐너(subjectTopRow)가 "머리카락"으로 오검출. 단발 인물에게 crown 위 13mm는 해부학적 불가.

**수정**: resolvePlacement()에서 hairTop 사용 전에 새니티 체크 추가.

```javascript
// hairTop 새니티: crown 대비 헤어 볼륨 상한 (IDPASS HAIR_VOLUME_RATIO = 0.08)
// crown 위로 fullFaceH * 0.08 이상 올라가면 오검출로 판정 → hairTop 무시
const HAIR_VOLUME_MAX = 0.15; // 여유 포함
if (hasHairTop) {
  const maxHairExtent = crownY - facePx * HAIR_VOLUME_MAX;
  if (hairTopY < maxHairExtent) {
    // 해부학적 불가 — 배경 아티팩트 오검출
    hasHairTop = false;
  }
}
```

이 체크는 T0(원본 사진)와 T1(나노 생성) 모두에 적용되어 전 경로를 방어한다.

### 2. 가드 순서 IDPASS 정합 (crop-engine/lib/crop.js)

**문제**: 현행 순서가 눈앵커→헤어가드→하단가드→헤어재확인이라, 마지막 헤어 재확인이 하단 가드를 무효화.

**IDPASS 원본 순서 (CropEngine.swift L263-294)**:
```
① 눈 앵커 배치 (extractTop = eye - targetEyeY)
② 헤어 가드 체크 (hairTop이 프레임 밖이면 extractTop 조정)
③ 하단 마진 체크 (bottomMargin < 12%이면)
④ 스케일 축소 루프 — 눈 앵커를 유지하면서 스케일을 줄여 하단 확보
   (faceMin까지 줄여도 안 되면 ②의 위치 유지)
```

**핵심**: ④에서 스케일 축소 시 `extractTop = eyeY * newScale - targetEyeY`로 **눈을 재앵커**한다. 헤어 가드와 하단 가드가 충돌하면 스케일을 줄여서 양쪽을 동시에 만족시키는 구조.

**현행 코드를 이 순서로 정합할 것.** 헤어 가드 후에 하단을 체크하고, 부족하면 스케일 축소 루프에서 눈 재앵커 + 하단 보장. 루프 후 헤어를 다시 체크하지 않는다.

### 3. grayBg 판정 축소 (render-specs.js)

**문제**: L411 `/회색|gray|グレー|gris/i`가 `연회색`, `밝은 회색`, `Cream or light grey`까지 매칭 → UK·FR·AU·FI·RU의 T1이 부당 비노출.

**수정**: gray(#D5D5D5) 대상만 T1 비노출. light-gray(#F0F0F0)는 흰색과 차이가 미미하므로 T1 허용.

```javascript
// gray T1 비노출: BG_OVERRIDE 맵의 대상(진한 회색)만
const grayBg = BG_OVERRIDE[slug] != null;
// 또는 명시적:
const grayBg = /^회색$|^독일/.test(String(specData.background || '').trim());
```

`밝은 회색`, `연회색`, `크림 또는 연회색`은 매칭하지 않도록. BG_OVERRIDE 맵을 import해서 쓰는 것이 가장 정확 — matte.js에서 export 필요 시 추가.
