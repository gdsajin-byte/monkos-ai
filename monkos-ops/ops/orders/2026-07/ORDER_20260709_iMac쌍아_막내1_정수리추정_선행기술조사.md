# 지시서: 정수리 추정·크롭 보정 선행기술 조사 (특허 근거)

**[2026-07-09 14:00 KST]** iMac/쌍아 → 막내1

- 헌법 4조 1항(비밀정보 보호)
- 리서치 과제 — 프로덕션 코드 변경 없음

## 배경

MONKOS 크롭 엔진이 "촬영 각도 적응형 자동 정수리 추정 + 크롭 배치"를 구현했다:
- 해부학적 1:1 미러 (눈~턱 ↔ 눈~정수리)
- 6DRepNet pitch에 의한 미러 계수 보정 (0.90~1.10)
- 규격 제약 기반 눈위치 동적 연산
- (예정) 픽셀 통계 기반 헤어라인 감지

크롭앱 특허 출원 시 선행기술 대비 신규성을 논증해야 한다.
이 기술 조합의 학술적 근거와 기존 특허·논문을 조사하여 차별화 포인트를 정리한다.

## Task 1 — 해부학적 안면 비율 문헌 조사

조사 대상:
- Leonardo da Vinci / Vitruvian 비율 (눈 = 두상 1/2 규칙)의 현대 검증 연구
- 인체측정학(anthropometry) 안면 비율 실측 데이터 — 인종·성별·연령별 편차
- "눈~턱 = 눈~정수리" 1:1 규칙의 실측 정확도와 한계

산출물: 주요 논문 5건 이상의 제목·저자·연도·핵심 수치 정리

## Task 2 — Head Pose와 2D 투영 왜곡 문헌 조사

조사 대상:
- Weak Perspective Projection 기반 얼굴 정수리 추정
- Head pose에 따른 안면 랜드마크 2D 투영 변형 연구
- pitch 각도에 의한 눈~턱, 눈~정수리 비율 변화 실측 데이터
- 6DRepNet, WHENet, FSA-Net 등 경량 포즈 모델 원논문

산출물: 주요 논문 5건 이상 + pitch → 미러 계수 관계의 기존 공식이 있는지 여부

## Task 3 — 증명사진 자동 크롭 관련 특허·논문 조사

조사 대상:
- 증명사진/여권사진 자동 크롭 기존 특허 (한국·미국·국제)
- 정수리 추정 방법 특허 (landmark 기반, segmentation 기반)
- 촬영 각도 보정 + 자동 배치 결합 특허
- 이보토(Evoto), Passport Photo Online 등 상용 서비스의 기술 접근법

검색 키워드: "passport photo crop", "crown estimation", "head pose correction crop", "face landmark crown", "증명사진 자동", "정수리 추정"

산출물: 기존 특허 5건 이상의 출원번호·요약 + 상용 서비스 기술 접근법 정리
