## 올바른 플로우

### T0 무료 (기존 그대로)
```
업로드 → 사진확인 → [무료로 만들기] → 생성 중 → T0 결과
                                                    ├─ [다운로드]
                                                    ├─ [다른 사진으로 만들기]
                                                    ├─ AI 보정 ₩2,000 카드
                                                    └─ 발급보장 ₩9,900 카드
```

### T1 유료 (업셀 진입 시)
```
T0 결과에서 [AI 보정으로 업그레이드] 클릭
    ↓
피사체 선택 (성인/청소년/영유아 × 남/여)
    +
의상 선택 (그대로/정장/블라우스/캐주얼 + 서브옵션)
    +
결제 카드 (₩2,000 카드결제 / 크레딧)
    ↓
결제 → T1 생성 → T1 결과
```

### 직접 결제 진입 (무료 소진 후)
```
업로드 → 사진확인 → 무료 소진 표시 → [유료로 만들기]
    ↓
피사체 선택 + 의상 선택 + 결제 카드
    ↓
결제 → T1 생성 → T1 결과
```

## 구체 작업

### 1. T0 무료 플로우 원복

- `v2-phase-free` (T0 결과 화면): **기존 코드 그대로 유지**. 피사체/의상 삽입 금지.
- fit phase: 피사체 칩 제거 (T0에서 의미 없음)
- 무료로 만들기 → 생성 → 결과 경로에 피사체/의상 로직이 끼어들지 않도록 확인

### 2. pay phase 피사체+의상 = T1 진입 시에만

- pay phase(`v2-phase-pay`)에 넣은 피사체 칩 + 의상 인라인은 **유지하되**
- 이 phase에 도달하는 경로가 **T1 유료 진입일 때만** 되도록 분기:
  - 경로 A: T0 결과 → "AI 보정으로 업그레이드" 클릭 → pay phase (피사체+의상+결제)
  - 경로 B: 무료 소진 → "유료로 만들기" → pay phase
- T0 무료 경로에서는 pay phase를 절대 거치지 않음

### 3. doGenerate body 분기

```js
// T0: 기존대로 하드코딩 (매팅+크롭만, 프롬프트 무관)
if (gateMode === 'free') {
  body.gender = 'm';
  body.age = 'adult';
  // attireDesc 없음
}
// T1: 피사체 칩 + 의상 선택 값 사용
else {
  body.gender = subjectSelection.gender || 'm';
  body.age = subjectSelection.age || 'adult';
  if (attireDesc) body.attireDesc = attireDesc;
}
```
