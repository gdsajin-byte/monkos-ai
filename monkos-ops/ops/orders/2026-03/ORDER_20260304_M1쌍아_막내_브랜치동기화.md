## 절차

### 1. 사전 확인
```bash
git fetch origin
git log --oneline origin/develop..main   # main에만 있는 커밋
git log --oneline main..origin/develop   # develop에만 있는 커밋
```

### 2. develop에 main 머지
```bash
git checkout develop
git pull origin develop
git merge main
```
- 충돌 발생 시 **중단하고 보고**. 강제 해소 금지.

### 3. main에 develop 머지
```bash
git checkout main
git pull origin main
git merge develop --ff-only
```
- fast-forward 불가 시 **중단하고 보고**.

### 4. push
```bash
git push origin main develop
```

### 5. 동기화 확인
```bash
git log --oneline main..develop    # 비어 있어야 함
git log --oneline develop..main    # 비어 있어야 함
```
