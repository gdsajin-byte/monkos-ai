# 지시서: 글로벌 채널 (web/kakao) 프롬프트 정합성 점검

**[2026-03-09 22:22 KST] M1/쌍아 → 막내2**

## 배경

JP 론칭 + KR v3 가격 체계 전환이 완료된 상태. 챗봇 시스템 프롬프트가
현행 서비스 체계를 정확히 반영하고 있는지 정밀 점검이 필요.

## 대상 채널

| 채널 | 프롬프트 | 용도 |
|------|---------|------|
| `web` | `SYSTEM_PROMPT` | 포털 웹 챗봇 (일본어 기반, 다국어 응답) |
| `kakao` | `SYSTEM_PROMPT` + 카카오 추가 | 카카오톡 챗봇 (한국어 강제) |

두 채널이 **동일 프롬프트(SYSTEM_PROMPT)**를 공유하므로, 하나의 프롬프트를 점검하면 양쪽에 영향.

## 임무: SYSTEM_PROMPT 정합성 점검

### 대상 파일
- `monkos_AI/portal/lib/prompts.js` — `SYSTEM_PROMPT` (line 7~64)
- 비교 대상: `monkos_AI/idphoto-jp/public/config.js` (JP 현행 가격)
- 비교 대상: `monkos_AI/idphoto-kr/public/config.js` (KR 현행 가격)
- 비교 대상: `monkos_AI/portal/lib/payments.js` (결제 처리 실제 값)

### 점검 항목 (항목별 ✅/❌ 판정)

**1. JP 가격표 정합성**
- [ ] 프롬프트 기재 글로벌 LS 가격 (`10c/$10 | 30c/$25 | 50c/$40`) vs JP config.js 현행 가격 비교
- [ ] 현행 JP 패키지: ¥990(80c) / ¥150(10c) / ¥1,490(130c) / ¥3,990(420c) / ¥5,990(750c)
- [ ] 불일치 항목 목록화

**2. KR 가격표 정합성**
- [ ] 프롬프트 기재 KR 가격 vs KR config.js 현행 가격 비교
- [ ] 현행 KR 패키지: ₩9,900(80c) / ₩1,450(10c) / ₩12,900(130c) / ₩34,900(420c) / ₩49,900(750c)
- [ ] 불일치 항목 목록화

**3. 크레딧 시스템 정합성**
- [ ] 리터칭/다운로드 크레딧 비용이 config.js `CREDIT_COST`와 일치하는지
- [ ] 가입 보너스 10c가 실제 적용되는지 (Portal 코드 확인)
- [ ] SNS 보너스 100c, 텔레그램 보너스 40c가 실제 코드와 일치하는지

**4. 결제 수단 정합성**
- [ ] "Toss Payments（韓国）/ Lemon Squeezy（グローバル）" 기재 — 현행과 일치하는지
- [ ] LS 결제 수단 (카ード/PayPal/Apple Pay/Google Pay) 확인

**5. URL 정합성**
- [ ] `https://monkos.ai` (포털)
- [ ] `https://idphoto-jp.monkos.ai/app` (JP)
- [ ] `https://idphoto-kr.monkos.ai/app` (KR)
- [ ] 법적 페이지 URL (`terms.html`, `privacy.html`, `refund.html`)
- [ ] 각 URL이 실제 접근 가능한지 (curl 또는 서버 라우트 확인)

**6. 로그인 수단 정합성**
- [ ] 프롬프트에 로그인 수단 안내가 있는지
- [ ] 현행: 카카오(한국), LINE(일본), Google(공통)
- [ ] web 프롬프트에 LINE 안내 누락 여부

**7. 서비스 설명 정합성**
- [ ] 「独自のAIエンジン」 표현 일관성 (내부 기술명 노출 없는지)
- [ ] 서비스 목록이 현행과 일치하는지

**8. kakao 채널 추가 프롬프트**
- [ ] `[중요] 이 채널은 카카오톡입니다. 반드시 한국어로만 응답하세요.` — 적절한지
- [ ] kakao 전용 추가 정보 필요 여부 (카카오 채널 보너스 40c 안내 등)
