## 수정 1: 배지 복원 (텍스트 교체)

**파일:** `idphoto-kr/public/index.html` — 히어로 HTML

현행 (배지 없음):
```html
<div class="hero-content">
  <h1>사진관 품질의<br><span>AI 증명사진</span></h1>
```

수정:
```html
<div class="hero-content">
  <div class="hero-badge">20년 경력 사진작가가 직접 개발</div>
  <h1>사진관 품질의<br><span>AI 증명사진</span></h1>
```

**CSS:** `.hero-badge` 스타일 복원 (이전 커밋에서 삭제됨)

```css
.hero-badge {
  display: inline-flex; align-items: center; gap: 6px;
  background: rgba(167, 139, 250, 0.15); border: 1px solid rgba(167, 139, 250, 0.25);
  padding: 6px 14px; border-radius: 20px;
  font-size: 0.75rem; color: var(--accent); font-weight: 600;
  margin-bottom: 12px; letter-spacing: 0.3px;
  backdrop-filter: blur(8px);
}
```

> 이전의 🛡 이모지 `::before`는 복원하지 않음. 💡도 불필요 — 텍스트만으로 충분.

## 수정 2: 히어로 컨텐츠 수직 중앙 정렬

**파일:** `idphoto-kr/public/index.html` — CSS `.hero-content`

현행:
```css
.hero-content {
  position: absolute;
  bottom: 0; left: 0; right: 0;
  padding: 0 24px 28px;
  text-align: center;
}
```

수정:
```css
.hero-content {
  position: absolute;
  inset: 0;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  padding: 0 24px;
  text-align: center;
}
```

> `bottom: 0` + padding-bottom → `inset: 0` + flex center. 컨텐츠가 히어로 영역 수직 중앙에 배치됨.
