# 지시서: 세션 로그 정합성 전수 점검

> **너는 막내1호다. 쌍아가 아니다.**

## 배경

세션 로그가 `monkos-ops/ops/sessions/`에 65개 이상 축적되었다. 법률 제3장(세션 로그)과 제4장(문서 구조) 기준으로 정합성을 전수 점검하고, 월단위 정리 필요성을 판단해야 한다.

## 관련 법률

- **법률 제3장**: 세션 로그 형식(2조), 마감 절차(3조), 시작 절차(5조)
- **법률 제4장 3조**: 세션 로그 네이밍 — `YYYY-MM-DD_{device}_{agent}.md`
- **법률 제4장 4조**: 정본 위치 `monkos-ops/ops/sessions/`, 아카이브 `docs/corpus/sessions/`
- **법률 제4장 7조**: YAML frontmatter 규격

## 작업 지시

### Phase 1: 전수 스캔 (리서치)

1. `monkos-ops/ops/sessions/` 전체 파일 목록 생성
2. 파일별 아래 항목 점검:
   - **네이밍 규칙 준수 여부** (YYYY-MM-DD_Device_Agent.md)
   - **YAML frontmatter 유무 및 필수 필드** (type, date, device, agent)
   - **frontmatter type 값 통일** — `session-log` vs `SESSION_LOG` 혼재 여부
   - **세션 시작/종료 시각 기재 여부**
   - **완료 보고 형식** (✅❌💡⏳📁🔀) 존재 여부
3. 시계열 연속성 점검:
   - 날짜 공백 (세션 없는 날) 식별
   - 동일 날짜 다중 세션 식별 (새벽/오전/오후 등 구분)
   - 커밋 해시와 세션 로그 기록의 교차 검증 (git log 대조)

### Phase 2: 월단위 정리 필요성 판단

1. 2월(37개) vs 3월(28개+) 파일 수 집계
2. 현재 flat 구조 유지 시 예상 문제:
   - 월 30~50개 축적 → 연간 400~600개 → flat 폴더 관리 가능 여부
3. 월별 하위 폴더 분리 방안 검토:
   - `sessions/2026-02/`, `sessions/2026-03/` 등
   - ch4 4조 정본 경로 변경 필요 여부
   - 기존 `docs/corpus/sessions/`(아카이브)과의 관계
4. 대안 검토:
   - 월단위 폴더 vs 분기단위 vs 현행 유지
   - 아카이브 이관 주기 (월별? 분기별?)
