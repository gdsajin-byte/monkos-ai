# idphoto KR/JP — 레이아웃 폭 탐색 + 개선안 보고

## 배경
- 현재 KR/JP 모두 `.container { max-width: 480px }` 단일 기준
- 미디어 쿼리 **없음** — 데스크탑에서도 480px 고정
- 모바일 기반 디자인이나, 데스크탑 푸터에서 줄바꿈 발생할 정도로 폭이 타이트
- 작가님 지시: **모바일 구성이 깨지지 않는 범위에서 폭을 보기좋게 넓히자**

## 작업 내용: 리서치+보고 (코드 수정 아님)

### 1단계: 현재 상태 분석

다음을 데스크탑/모바일 양쪽에서 검토:

**a) 전체 페이지 구조 스캔**
- `monkos_AI/idphoto-kr/public/index.html` 전체
- `monkos_AI/idphoto-jp/public/index.html` 전체
- 각 섹션별 실제 렌더링 폭, 여백, 잘림 여부

**b) 480px에서 문제되는 지점 리스트**
- 푸터 텍스트 줄바꿈
- 가격 카드 레이아웃 (좁은 공간에서 깨짐 여부)
- 쇼케이스 이미지 크기
- 기능 소개 3열 그리드 (480px - 40px = 440px에 3열은 각 ~147px → 작음)
- 히어로 텍스트/버튼 여백

**c) 마진 네거티브 사용 지점**
- `.hero { margin: 0 -20px }` — 뷰포트 확장
- `.showcase-track-wrap { margin: 0 -20px }` — 뷰포트 확장
- `.event-banner { margin: 0 -20px }` — 삭제 예정이므로 무시
- 이들이 폭 변경 시 어떤 영향을 받는지 분석

### 2단계: 개선안 설계

다음 옵션들을 검토하고 **추천안 1개** 제시:

**옵션 A: 단순 확장**
- `.container { max-width: 520px }` 또는 `560px`로 변경
- 장점: 최소 변경
- 리스크: 3열 그리드가 넓어지면서 비율 변화

**옵션 B: 데스크탑 미디어 쿼리 추가**
```css
/* 모바일: 기존 유지 */
.container { max-width: 480px; }

/* 데스크탑: 확장 */
@media (min-width: 768px) {
  .container { max-width: 600px; }
}
```
- 장점: 모바일 무영향 보장
- 리스크: 반응형 추가 시 다른 요소도 조정 필요할 수 있음

**옵션 C: clamp 기반**
```css
.container { max-width: clamp(480px, 80vw, 600px); }
```
- 장점: 부드러운 전환
- 리스크: 브라우저 호환성
