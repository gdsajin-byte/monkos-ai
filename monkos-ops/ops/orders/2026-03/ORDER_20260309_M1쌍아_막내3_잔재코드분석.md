# 지시서: 불필요 잔재코드 분석

**[2026-03-09 20:38 KST] M1/쌍아 → 막내3**

## 배경

JP 론칭 완료로 v079 레거시 코드와 각종 백업 파일들이 잔재하고 있음.
삭제 전 반드시 영향 범위 분석이 필요하며, 삭제 결정은 작가님+쌍아 합의 후 진행.

## 임무 A: apps/idphoto-jp-v079/ 분석

```
apps/idphoto-jp-v079/
├── server.js
├── index.html
├── package.json
└── ...
```

### 확인 항목
- [ ] 현재 배포된 서비스와의 차이점 (`monkos_AI/idphoto-jp` 대비)
- [ ] v079에만 있고 현재 JP에 없는 기능 있는지
- [ ] `apps/idphoto-jp-v079/deploy.sh` 내 PROJECT_ID, SERVICE_NAME — Cloud Run에 현재 v079가 배포되어 있는지
- [ ] `apps/idphoto-jp-v079/package.json` 의존성이 현재 JP와 다른지
- [ ] 삭제 시 영향 없는지 판단 근거 정리

## 임무 B: 백업 폴더 확인

- [ ] `monkos_AI/idphoto-kr/` 내 `_backup_79/` 또는 유사 폴더 존재 확인
- [ ] `monkos_AI/idphoto-jp/` 내 동일 확인
- [ ] 백업 파일들의 최종 수정일 확인

## 임무 C: 전체 프로젝트 잔재 탐색

아래 패턴으로 잔재 후보 목록화:
- `_old`, `_backup`, `_bak`, `_v0`, `_legacy`, `_deprecated` 패턴 파일/폴더
- `TODO: remove`, `FIXME: delete`, `// 삭제 예정` 주석
- 사용되지 않는 HTML 페이지 (서버 라우트에 없는 것)

탐색 범위: `monkos_AI/idphoto-kr/public/`, `monkos_AI/idphoto-jp/public/`, `apps/` 전체

## 임무 D: 삭제 우선순위 분류

| 단계 | 기준 | 예시 |
|------|------|------|
| **즉시 삭제 가능** | 현재 코드와 완전 분리, 참조 없음 | v079 전체 |
| **확인 후 삭제** | 일부 참조 가능성 있음 | 특정 백업 파일 |
| **보존 필요** | 히스토리/레퍼런스 가치 있음 | - |
