## 수정 1: 히어로 텍스트 보정

**파일:** `idphoto-kr/public/index.html` — 히어로 섹션

### 1-A. 배지 삭제

현행:
```html
<div class="hero-badge">발급 보장 — 반려 시 100c 환급</div>
```

→ **삭제.** (하단 배지에 동일 내용 존재, 중복 제거)

### 1-B. 서브 텍스트 교체

현행:
```html
<p class="hero-sub">10년 촬영 노하우를 AI에 담았습니다.<br>여권·이력서·비자 — 어디든 통과하는 증명사진.</p>
```

수정:
```html
<p class="hero-sub">여권 · 신분증 발급 보장</p>
```

### 1-C. CSS 정리

`.hero-badge` 관련 CSS 삭제 (더 이상 사용 안 함):
- `.hero-badge` 스타일 블록
- `.hero-badge::before` 스타일 블록
- `@keyframes pulse-dot` (hero-badge 전용이었으면 삭제, 다른 곳에서 사용 시 유지)

## 수정 2: 히어로↔갤러리 사이 무료체험 이벤트 배너

**파일:** `idphoto-kr/public/index.html`

히어로 `</section>`과 쇼케이스 `<section class="showcase">` 사이에 이벤트 배너 삽입:

```html
<!-- 오픈 이벤트 배너 -->
<div class="event-banner">
  🎉 오픈 이벤트 — 가입만 해도 무료 체험 가능!
</div>
```

**CSS:**
```css
.event-banner {
  text-align: center;
  padding: 12px 16px;
  margin: 0 -20px;
  background: linear-gradient(135deg, #7c3aed, #6366f1);
  color: #fff;
  font-size: 0.85rem;
  font-weight: 700;
  letter-spacing: 0.3px;
}
```

> 별도 컬러(보라~인디고 그라디언트)로 시선 유도. 차후 이벤트 종료 시 이 블록만 제거.
