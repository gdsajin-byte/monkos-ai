# 지시서: 법률 개편 A안 — 점진적 개정 (중복 제거)

> 현행 8장 38조 구조를 유지하면서, 중복·산재된 조항을 정리하는 최소 개입 방안을 설계한다.

## 배경

3건 리서치(막내1·2·3) 결과, 법률 체계의 구조적 비효율이 확인됨:
- 동일 규칙이 3~6곳에 산재 (타임스탬프 4곳, 보고형식 5곳, 민감정보 5곳)
- 헌법과 법률이 "참조"가 아니라 "복사" 관계
- MEMORY에만 있는 실질 규칙 10건이 법률보다 구속력 강함
- 상위법 참조 오류 2건 (ch5, ch8)

## A안의 원칙

**현행 8장 구조 유지. 장 통합/삭제 없음.** 다음만 수행:
1. 중복 조항 → 정본 1곳 지정 + 나머지는 "→ 헌법/법률 N조 참조" 교체
2. 상위법 참조 오류 수정
3. 자기모순 해소 (ch2 1조 vs 4조)
4. 사문화 조항 주석 처리 또는 "미시행" 명시
5. MEMORY 실질 규칙 중 법률화 적합한 것 편입

## 산출물

각 중복 규칙에 대해:

| 규칙 | 현재 등장 위치 | 정본 지정 | 나머지 처리 |
|------|--------------|----------|------------|

대상 규칙 (최소):
- 타임스탬프 (헌법1조, ch3 4조, ch4 7조, ch7 1조)
- 보고 형식 (헌법2조, ch1 4조, ch3 2조, ch6 4조, ch7 1조)
- 민감정보 보호 (헌법4조, 헌법6조, ch4 8조, ch7 1조, ch8 1조)
- 배포 권한 (ch5 2~3조, ch7 2~3조)
- 파일 네이밍 (ch1 3조, ch4 3조, ch4 7조, ch7 1조)

### 2. 조항별 개정 diff

각 장별로 현행 → 개정안 diff 제시. 예시:
```

```
