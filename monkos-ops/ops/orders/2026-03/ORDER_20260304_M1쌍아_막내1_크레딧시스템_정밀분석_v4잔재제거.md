## 배경

### 1. 크레딧 시스템 설계 의도 (작가님 확정)

```
[가입] → 10c 보너스 지급
[생성] → 10c 소비 → 프리뷰(워터마크) 확인
[결제] → ₩9,900 → 80c 충전 (70c + 10c 추가 보너스)
[다운로드] → 70c 소비
[잔액] → 10c (재생성/추가옵션 활용)
```

**수학적 검증 포인트**: 최소 구매(₩9,900) 1회만 한 사용자의 잔액은 반드시 **10c**이어야 한다.

| 시점 | 행위 | 증감 | 잔액 |
|------|------|------|------|
| 가입 | 보너스 지급 | +10c | 10c |
| 생성 | 프리뷰 생성 | -10c | 0c |
| 결제 | ₩9,900 충전 | +80c | 80c |
| 다운로드 | 워터마크 제거 | -70c | **10c** |

**핵심 원칙**:
- 가입 보너스 = **10c** (전 프로바이더 동일)
- 생성 비용 = **10c** (1회 프리뷰 생성)
- 다운로드 비용 = **70c** (워터마크 제거 + 고해상도)
- 1장 최소 비용 = **80c** = 생성(10c) + 다운로드(70c)
- 최소 결제 단위 = **₩9,900 → 80c** (70c + 10c 추가 보너스)
- 로그인 강제 시점 = 촬영준비실 진입 전. 랜딩은 비로그인 접근 가능
- 로그인 시 10c 지급 → 프리뷰 1회 무료 체험 가능
