## 임무

### 1. 일본 시장 환경 분석 (최신화)
- 일본 AI 증명사진(AI証明写真) 시장 2026 현황
- 경쟁사: 한국/일본/글로벌 AI 증명사진 서비스 현재 마케팅 현황
- 일본 취활(就活) 시즌 캘린더: 3~6월 피크, 사진 필요 시점
- 일본 소비자 결제 행동: KOMOJU 거절 후 대안 (Lemon Squeezy 글로벌 카드)
- 일본 SNS 사용 패턴: X 압도적, LINE 전환, 인스타 보조

### 2. 한송이 3채널 전략 정밀 확장

#### X (Twitter) — 기폭장치
- 일본어 카피 패턴: 280자 구조 (훅 + 소구점 + CTA)
- 비포/애프터 최적 이미지 포맷
- 포스팅 빈도 + 골든타임 (JST 기준)
- RT/인용 유도 전술
- 해시태그 전략: #証明写真 #就活 #AI写真 + 시즌 태그

#### 인스타그램 — 쇼윈도우 (신뢰 구축)
- 일본 인스타 특성: 텍스트 카드뉴스형, 논리적 설명 필수
- 캐러셀 표준 구조 (4~8장)
- "왜 좋아지는가" 논리 프레임
- 저장(保存) 유도 전략 (알고리즘 핵심)

#### LINE — 매장 (전환)
- 리치메뉴 설계
- 자동 메시지 플로우: 友達追加 → 무료 촬영 → 결제 → 공유 유도
- LINE Official Account 운영 가이드
- 리텐션: 재방문 트리거 (시즌 알림 등)

### 3. n8n 자동화 파이프라인 설계 (철창 v2 기반 확장)

#### 벤치마크 크롤링 (파이프라인 A)
- 일본 벤치마크 대상 채널 리스트 15~20개 제안
- Apify 크롤링 스케줄 + 데이터 구조
- 주간 리포트 자동화 흐름

#### 콘텐츠 자동 생산 (파이프라인 B)
- TYPE A~E별 일본 시장 맞춤 조정
- 한 소재 → X/인스타/LINE 3채널 변환 자동화 흐름
- Claude API 일본어 캡션 생성 프롬프트 가이드
- 예약 포스팅 스케줄 (JST 골든타임 기준)

#### 통합 피드백 루프
- 크롤링 → 분석 → 전략 조정 → 콘텐츠 최적화 사이클

### 4. 글로벌 확장 로드맵
- Tistory → 구글 SEO (글로벌 영어 시장)
- 영어권 채널 진출 타이밍 + 최소 준비사항
- 동남아 시장 가능성 (저비용 고성장)

### 5. 스토리라인 설계 (일본 특화)
- 일본 소비자 심리: 논리 → 신뢰 → 전환
- 한국 사진관 20년 → AI 혁신 스토리의 일본 버전
- 월간 테마 캘린더 (3월~6월)
- 취활 시즌 집중 공략 시나리오

### 6. 컨텐츠 제작 가이드 (일본어)
- X 트윗 표준 (280자 일본어, 훅/본문/CTA)
- 인스타 캐러셀 표준 (일본어 텍스트 카드)
- LINE 메시지 표준
- 이미지 내 일본어 텍스트 스타일 가이드

### 7. KPI 프레임워크
- 채널별 목표 (2개월 후 판단 기준)
- X: 팔로워 + RT율 + 프로필 클릭
- 인스타: 저장수 + 프로필 방문 + 링크 클릭
- LINE: 友達数 + 촬영 전환율 + 결제 전환율
