## 지시서: 갤러리 슬라이드 — 모바일 세로 비율 + 자동 스크롤 삭제

### 배경
- 데스크탑 갤러리 슬라이드는 세로 비율(120×160)로 정상 적용됨
- 모바일에서는 가로 비율로 표시되는 문제 발생
- 자동 스크롤 애니메이션이 흐르다가 멈추고 반대로 끌어오는 현상 — 삭제 대상

|------|----------|
| `monkos_AI/portal/public/css/portal.css` | 모바일 미디어쿼리에 `.gi` 세로 비율 강제 |

### 상세 지시

#### 1. CSS — 모바일 갤러리 세로 비율 (`portal.css`)

`@media (max-width: 768px)` 블록 안에 아래 추가:

```css
.gi {
  min-width: 100px; height: 140px;
}
```

- 데스크탑(120×160)보다 약간 작게, 비율은 동일하게 세로 유지
- `height`가 모바일 flex 컨텍스트에서 무시되지 않도록 명시 선언

#### 2. JS — 자동 스크롤 로직 제거 (`main.js`)

106~126행의 `// === 갤러리 자동 스크롤 (무한 루프) ===` 블록 **전체 삭제**.

```javascript
// 삭제 대상 (106~126행)
document.addEventListener('DOMContentLoaded', function() {
  var gt = document.getElementById('gt');
  if (gt) {
    var items = gt.querySelectorAll('.gi');
    items.forEach(function(item) {
      var clone = item.cloneNode(true);
      clone.setAttribute('aria-hidden', 'true');
      gt.appendChild(clone);
    });
    var sp = 0;
    var originalWidth = 0;
    items.forEach(function(item) { originalWidth += item.offsetWidth + 8; });
    setInterval(function() {
      sp += 0.8;
      if (sp >= originalWidth) sp -= originalWidth;
      gt.scrollLeft = sp;
    }, 30);
  }
});
```

삭제 후 갤러리 스트립은 **수동 터치/마우스 스크롤만** 동작.
