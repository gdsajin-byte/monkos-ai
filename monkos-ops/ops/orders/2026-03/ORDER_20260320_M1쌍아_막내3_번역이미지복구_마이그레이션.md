# 번역 이미지 복구 + 썸네일 마이그레이션

## 전제

- 막내2(유령글+중복 삭제) 완료 — 정리된 데이터 기준으로 작업

## 작업 D: 기존 번역글 이미지 복구

### 스크립트 작성
- 경로: `monkos_AI/portal/scripts/restore_translation_images.js`

### 로직
1. `autoTranslated: true`인 문서 전체 조회
2. 각 문서의 `originalSlug`로 원본 문서 조회
3. 원본 content의 이미지 마크다운(`![alt](URL)`) 추출
4. 번역본 content에 해당 이미지 URL이 없으면 → 본문 끝에 추가
5. thumbnail이 비어있으면 원본 thumbnail 복사

### 실행 흐름
1. **dry-run (기본)**: 복구 대상 목록 출력 (slug, 누락 이미지 수, thumbnail 상태)
2. 보고서 작성 → 작가님 확인 대기
3. `--execute` 시 실행

## 작업 E: 썸네일 마이그레이션 보완

### 기존 스크립트 활용
- `monkos_AI/portal/scripts/migrate_blog_thumbnail.js` 재실행
- 대상: published이면서 thumbnail 비어있는 글 전체 (번역본 포함)
- content 첫 이미지 추출 → thumbnail 채움

## 실행 순서

```
1. 작업 D dry-run → 보고

3. 작업 E 실행 (기존 스크립트)
4. 최종 확인: thumbnail 비어있는 published 글 = 0건
```
