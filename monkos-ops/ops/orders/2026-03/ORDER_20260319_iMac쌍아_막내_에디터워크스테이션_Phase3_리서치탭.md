## Task 1: 네이버 검색 API 프록시 엔드포인트

어드민 프론트에서 직접 네이버 API 호출은 CORS 제한. 서버에 프록시 엔드포인트 생성.

```
GET /api/admin/search?query={검색어}&type={news|blog|image}&start=1&display=10
```

**서버 구현** (`server.js` 또는 별도 `lib/cms/search.js`):

```javascript
// 네이버 검색 API 프록시
// type: news (뉴스), blog (블로그), image (이미지)
// 헤더: X-Naver-Client-Id, X-Naver-Client-Secret (.env에서)
// API: https://openapi.naver.com/v1/search/{type}
```

**반환 형식** (프론트용 정제):
```json
{
  "type": "news",
  "total": 1234,
  "items": [
    {
      "title": "여권사진 규격 변경 안내...",
      "link": "https://...",
      "description": "...",
      "pubDate": "2026-03-19",
      "thumbnail": "https://..." // 이미지 타입만
    }
  ]
}
```

**인증**: 어드민 인증된 사용자만 접근 가능 (기존 어드민 인증 체계 활용)

│                              │
│ 📰 뉴스 결과                  │

### 기능

| 기능 | 설명 |
|------|------|
| **검색** | 키워드 입력 → 뉴스/블로그/이미지 동시 검색 |
| **소스 토글** | 뉴스/블로그/이미지 탭 전환 |
| **[열기↗]** | 새 탭에서 원본 URL 열기 |
| **[참조📋]** | 제목+URL을 클립보드 복사 (에디터에서 인용/링크 삽입용) |
| **이미지 클릭** | 원본 크기로 미리보기 팝업 + 출처 URL |
| **연관 검색어** | 네이버 API 연관 검색어 표시 (있으면) |
| **검색 히스토리** | 최근 검색어 5개 로컬 저장 (localStorage) |

## Task 3: 에디터 제목 기반 자동 추천 (선택)

에디터에 제목을 입력하면, 해당 키워드로 리서치 탭이 **자동 검색 제안**.

```
제목: "AI 증명사진으로 여권사진 만들기"
  → 리서치 탭에 "AI 증명사진 여권사진" 자동 입력 + "검색하시겠습니까?" 토스트
```

자동 실행은 아님 — 토스트 클릭 시에만 검색.
