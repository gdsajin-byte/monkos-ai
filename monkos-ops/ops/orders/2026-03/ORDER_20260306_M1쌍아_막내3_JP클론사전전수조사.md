## Phase B: 멘트 현지화 전수 점검

### B-1. 하드코딩된 한국어 멘트 전수 추출

KR 코드에서 사용자에게 노출되는 모든 한국어 텍스트를 추출:

| 파일 | 라인 | 현행 (KR) | JP 번역 필요 여부 |
|------|------|----------|-----------------|
| (전수 기입) | | | |

대상:
- HTML 내 텍스트 (제목, 설명, 버튼, 라벨, placeholder)
- JS 내 alert(), 동적 innerHTML, 에러 메시지
- CSS 내 content 속성
- 프롬프트 (server.js — AI에게 보내는 텍스트)
- 챗봇 KB (seed 파일)

### B-2. 이미 현지화된 부분 vs 미현지화

JP 코드에서 이미 일본어로 번역된 멘트와 아직 한국어가 남아있는 멘트를 구분.

### B-3. 현지화 전략 제안

- i18n 라이브러리 도입 필요성 vs 파일 분기로 충분한지
- 프롬프트 현지화: 일본어 프롬프트가 모델 품질에 영향을 주는지 (영어 유지가 나을 수 있음)
- 규격 데이터(PHOTO_SPECS): 일본 여권·이력서·마이넘버 규격 존재 여부
