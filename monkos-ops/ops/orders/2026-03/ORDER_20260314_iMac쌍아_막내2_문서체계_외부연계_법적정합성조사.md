# 지시서: 문서 체계 외부 연계 + 법적 정합성 조사

> 코웍이·한·꾸 등 외부 채널의 문서 경로가 법률과 정합하는지, 현행 ch4가 현실을 반영하는지 종합 리서치한다.

## 배경

- ops/cowork/ 신설됐으나 ch4 미등록 (6조 폴더 편입 절차 미이행)
- marketing/han, marketing/kku 채널이 운용 중이나 어젠다 #8(팀 채널 일괄관리)은 미결
- 어젠다 이관 체계가 ch4에 없음 (README에만 정의)
- contents/ 폴더의 위상이 모호 (전략서가 여기 들어감)

## 조사 범위

### 1. 외부 채널 경로 현황

| 채널 | 현재 경로 | 파일 수 | 활성도 | 법적 근거 |
|------|----------|---------|--------|----------|

대상:
- `monkos-ops/marketing/han/` — 한송이
- `monkos-ops/marketing/kku/` — 꾸
- `monkos-ops/ops/cowork/` — 코웍이 (신규)
- `~/Desktop/철창이/` — 철창이 (로컬, Git 외)
- `~/Desktop/쌍아/` — 작가님 전달 폴더 (로컬, Git 외)
- `~/developer/monk-han/` — 한송이 위성 레포
- `~/developer/monk-kku/` — 꾸 위성 레포

각 경로의:
- 실제 파일 현황
- 마지막 활동 일자
- 어떤 법률/규정에 근거하는지 (또는 무근거인지)
- mailbox_watcher.sh 등 자동화 연동 여부

### 2. ch4 법률 vs 현실 괴리 분석

ch4 전 조항(1~8조)을 하나씩 읽고 현실과 대조:

| 조 | 규정 내용 | 현실 | 괴리 여부 | 개정 필요 |

특히:
- 1조 monkos-ops/ 구조: 번호 폴더 "이관 후 삭제" — 실태는?
- 2조 금지사항: docs/monkos/ 동결 — 준수 여부
- 3조 네이밍: 14종 패턴 — cowork/ 파일은 어떤 패턴?
- 4조 정본 테이블: cowork/, contents/ 미등록
- 5조 서비스 약칭: crop-engine 등 신규 서비스 미등록 여부
- 6조 편입 절차: cowork/ 폴더 편입 미이행 확인

### 3. 어젠다 이관 체계의 법적 위치

- 현재 어젠다 README에만 "이관 목적지" 정의
- ch4에 어젠다 → 이관 절차를 신설할 필요가 있는지
- 어젠다가 처리되면 산출물이 가는 곳의 법적 근거

### 4. contents/ 위상 명확화

- ch4 1조에 contents/ = "콘텐츠 (아카데미, 출판, 다국어)"로 정의
- 실제: CONTENT_STRATEGY_2026Q1.md (전략서) + academy/ + publications/
- 전략서는 ops/인지 contents/인지
- blog seeds, 다국어 콘텐츠 등 향후 쌓일 곳의 명확화

### 5. 통합 최적화 권고

모든 조사 결과를 종합하여:
- ch4 개정이 필요한 조항 목록
- 신규 등록이 필요한 폴더/서비스/파일유형 목록
- 팀 채널 구조 권고 (현행 유지 vs 통합)
- 어젠다 이관 체계 법률화 방안
