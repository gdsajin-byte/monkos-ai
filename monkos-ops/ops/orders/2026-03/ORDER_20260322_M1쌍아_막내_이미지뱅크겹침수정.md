# [지시서] 이미지 뱅크 겹침 수정 — 이중 스크롤 컨테이너 해소

`[2026-03-22 05:26 KST] M1/쌍아 → 막내`

---

## 현상

이미지 뱅크 썸네일이 세로로 겹쳐 표시됨. 하드 새로고침 후에도 동일.

## 원인

`388253e` ([portal] 에디터 워크스테이션 Phase 1~3) 에서 우측 사이드바에 탭 구조(이미지/시드/리서치)를 추가하면서, `.tab-content` 래퍼가 이미지 그리드와 `.editor-right` 사이에 끼어듦.

### 현재 구조 (문제)

```
.editor-right          ← sticky, max-height: calc(100vh-100px), overflow-y: auto
  └── .sidebar-tabs    ← 탭 버튼
  └── .tab-content     ← border + padding 14px, 높이 제약 없음 ★ 원인
        └── 헤더 (이미지 저장소 + 버튼들)
        └── #imageLibrary  ← grid, max-height: 60vh, overflow-y: auto
```

`.tab-content`가 높이 제약 없이 끼어들어 이중 overflow 컨테이너가 됨.
내부 그리드 셀의 `aspect-ratio: 1` 계산이 컨테이너 높이와 충돌하여 이미지가 겹침.

## 수정 방향

`.tab-content`가 `.editor-right`의 남은 공간을 채우되 넘치지 않도록 제약.
`#imageLibrary`의 `max-height: 60vh`는 제거하고 `.tab-content` 내에서 자연 스크롤.

### 수정 대상

| 파일 | 수정 |
|------|------|
| `public/admin/css/blog-editor.css` | `.editor-right`를 flex column으로 변경, `.tab-content`에 `flex: 1; min-height: 0; overflow-y: auto` |
| `public/admin/blog-edit.html` | `#imageLibrary` 인라인 스타일에서 `max-height:60vh;overflow-y:auto` 제거 |

### 구현 참고

```css
/* blog-editor.css */
.editor-right {
  /* 기존 유지: position: sticky; top: 80px; align-self: start; max-height: calc(100vh - 100px); */
  display: flex;
  flex-direction: column;
  overflow-y: hidden;  /* 기존 overflow-y: auto → hidden 변경. 스크롤은 .tab-content에서 처리 */
}

.tab-content {
  /* 기존 유지: background, border, border-radius, padding */
  flex: 1;
  min-height: 0;       /* flex 자식이 축소 가능하도록 */
  overflow-y: auto;    /* 스크롤을 여기서 처리 */
}
```

```html
<!-- blog-edit.html: #imageLibrary 인라인 스타일 변경 -->
<!-- 변경 전 -->
<div id="imageLibrary" style="display:grid;grid-template-columns:repeat(4, 1fr);gap:6px;max-height:60vh;overflow-y:auto;transition:max-height 0.3s">

<!-- 변경 후 -->
<div id="imageLibrary" style="display:grid;grid-template-columns:repeat(4, 1fr);gap:6px">
```

### 주의사항

- `toggleImageLibrary()` 함수가 `lib.style.maxHeight`를 조작함 → `maxHeight` 제거 시 이 함수도 수정 필요
- 시드 탭, 리서치 탭의 스크롤도 `.tab-content`에서 처리되므로 별도 작업 불필요
- `.sidebar-tabs`는 flex column에서 고정 높이로 자연 배치
