## 행정 심사 검토 항목

1. **운영 실태 점검**: 현재 세션 시작/마감이 실제로 어떻게 운영되고 있는가? 세션 로그를 분석하여 실태 파악
2. **행정 비용**: 세션 시작마다 `git fetch --all` + 양쪽 브랜치 확인을 의무화하면, 매 세션 시작에 추가되는 행정 비용은?
3. **monkos-ops 영향**: 세션 로그 파일명, 지시서/보고서 경로, MEMORY 관리 등 ops 체계에 미치는 영향 전수 파악
4. **ch3과의 관계**: 세션 마감이 ch3에 있는데, 시작이 헌법으로 올라가면 위계 불균형이 생기지 않는가?
5. **멀티디바이스 현실**: M1(집)/iMac(사무실) 간 세션 인수인계가 실제로 어떻게 이뤄지고 있는가? 개정 후 개선 예상 효과
6. **안건 B 행정 영향**: 리서치 선행 의무가 심사 프로세스에 추가하는 행정 부하와 그 가치
