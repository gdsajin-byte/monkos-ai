## Task 1: 구글 로그인 시 어드민 탭 즉시 미표시 (1줄 수정)

### 현상
- 카카오 로그인 → 프로필 탭에 어드민 **즉시** 표시 ✅
- 구글 로그인 → 어드민 안 보임 → **새로고침하면** 표시 ❌

### 원인
`lib/auth.js` — `handleGoogleAuth()` 응답에 `isAdmin` 필드 누락.

카카오는 redirect 후 `verify-cookie` 엔드포인트를 타면서 `isAdmin`을 받지만,
구글은 JSON 직접 응답인데 거기에 `isAdmin`이 빠져있음.

### 수정 대상
`lib/auth.js` 약 426~437행

### AS-IS
```js
res.end(JSON.stringify({
  success: true,
  isNewUser,
  user: {
    id: user.id,
    email: user.email,
    name: user.name,
    picture: user.picture,
    credits,
    provider: 'google',
  }
}));
```

### TO-BE
```js
res.end(JSON.stringify({
  success: true,
  isNewUser,
  user: {
    id: user.id,
    email: user.email,
    name: user.name,
    picture: user.picture,
    credits,
    provider: 'google',
    isAdmin: ADMIN_UIDS.length === 0 || ADMIN_UIDS.includes(user.id),
  }
}));
```

### 참고 (정상 동작하는 verify-cookie 엔드포인트)
`lib/auth.js` 631행: `const isAdmin = ADMIN_UIDS.length === 0 || ADMIN_UIDS.includes(result.userId);`
— 동일 로직을 Google 응답에도 적용.

### 검증
1. 구글 계정으로 로그인
2. 새로고침 없이 프로필 탭에 어드민 즉시 표시 확인
3. 카카오 로그인도 기존처럼 정상 동작 확인

## Task 2: 홈 메인 썸네일 미표시 (데이터 확인 + SSR 보강)

### 현상
- 홈 좌측 매거진 카드 (`.mag-img`) — gradient + 이모지만 표시, 사진 없음
- 홈 중앙 블로그 리스트 (`.bi-thumb`) — 이모지만 표시, 사진 없음
- 블로그 상세 페이지에서는 이미지 정상 표시

### 원인 분석
SSR 렌더 코드(`lib/cms/home.js` 50~67행)에 `p.thumbnail` 체크 로직은 **이미 존재**.
그런데 프로덕션에서 안 보이므로 원인은 **Firestore 데이터**:
- `blog.js:112` — `thumbnail: thumbnail || ''` (빈 문자열 저장)
- 3/16 에디터 리뉴얼 전 작성된 글은 썸네일 자동추출 미지원이었음
- 빈 문자열 `''`은 JS에서 falsy → 이모지 fallback

### 수정 내용

#### Step 1: Firestore 데이터 현황 확인
```js
// 서버 시작 시 또는 별도 스크립트로 확인
const snap = await blogCollection.where('published', '==', true).get();
snap.docs.forEach(d => {
  const data = d.data();
  console.log(`[${d.id}] thumbnail: "${data.thumbnail || '(empty)'}" | content 첫img: ${(data.content?.match(/<img[^>]+src="([^"]+)"/)?.[1] || 'none').substring(0, 50)}`);
});
```

#### Step 2: 기존 글 thumbnail 소급 채우기 (마이그레이션)
- `published: true`인 글 중 `thumbnail`이 비어있는 문서 대상
- `content` 본문에서 첫 번째 `<img src="...">` 추출
- 해당 URL로 `thumbnail` 필드 업데이트

```js
// 마이그레이션 로직 (1회성)
const snap = await blogCollection.where('published', '==', true).get();
const batch = db.batch();
let count = 0;

for (const doc of snap.docs) {
  const data = doc.data();
  if (!data.thumbnail) {
    // WYSIWYG HTML에서 첫 이미지 추출
    const imgMatch = (data.content || '').match(/<img[^>]+src="([^"]+)"/);
    if (imgMatch) {
      batch.update(doc.ref, { thumbnail: imgMatch[1] });
      count++;
    }
  }
}

if (count > 0) {
  await batch.commit();
  console.log(`[Migration] ${count}건 thumbnail 소급 완료`);
}
```

#### Step 3: 향후 방어 (선택)
`blog.js` — `handleBlogCreate()`에서 thumbnail이 비어있을 때 content에서 자동 추출하는 서버 사이드 fallback 추가 (에디터 클라이언트 의존 제거).

### 검증
1. 마이그레이션 실행 후 Firestore에서 thumbnail 필드 값 확인
2. 홈 메인 새로고침 → 매거진 카드에 썸네일 이미지 표시
3. 블로그 리스트에 썸네일 이미지 표시
4. thumbnail이 없는 글은 기존 이모지 fallback 유지
