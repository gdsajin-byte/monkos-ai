## 조사 항목

### 1. 파일 현황 인벤토리

| 조사 대상 | 수집 정보 |
|----------|----------|
| `docs/monkos/tasks/` | 파일 수, 최근 파일 날짜, 월별 분포 |
| `docs/monkos/reports/` | 파일 수, 최근 파일 날짜, 월별 분포 |

| `docs/monkos/sprints/` | 파일 수 |
| `monkos-ops/ops/orders/` | 파일 수, 최초 파일 날짜 |
| `monkos-ops/ops/reports/` | 파일 수 (COMPLETION, REVIEW, REPORT 각각) |
| `monkos-ops/ops/sessions/` | 파일 수 |

### 2. 이중화 실태

- docs/와 monkos-ops/ 양쪽에 **동일 또는 유사한** 파일이 존재하는 경우를 탐지
- 파일명 기준 대조 (TASK_*, REPORT_* 등)
- 발견 시 건수 + 대표 사례 3건 이상 제시

### 3. 참조 경로 분석

아래 파일들이 `docs/monkos/tasks/` 또는 `docs/monkos/reports/` 경로를 **직접 참조**하는지 검색:
- `governance/laws/*.md` — 법률 조문 내 경로 언급
- `CLAUDE.md` — 헌법 내 경로 언급
- `monkos-ops/**/*.md` — 지시서/보고서 내 상호 참조
- `*.sh`, `*.js`, `*.py` — 코드 내 경로 하드코딩

### 4. 이관 영향도 분석

위 조사 결과를 바탕으로:
- 이관 시 변경해야 하는 참조 경로 건수
- `git mv` 대상 파일 총수
- 이관 후 docs/monkos/ 에 남는 파일 유무
- 단계적 이관 시 권장 단계 구분 (예: 날짜 기준, 유형 기준 등)
