# 지시서: 서비스 멘트/안내 문구 + 법적 정합성 리서치

> **[2026-03-10 20:51 KST] M1/쌍아 → 막내3**

## 목적

모든 페이지·프롬프트·모달에 포함된 서비스 설명 문구(멘트)의 일관성을 점검하고, 법적 페이지(이용약관/개인정보/환불/특상법)의 정합성과 누락을 조사하라.

## 조사 범위

### 1. 서비스 설명 멘트 일관성

모든 위치에서 MONKOS 서비스를 설명하는 문구 수집:

| 대상 | 수집 항목 |
|------|----------|
| KR index.html | 히어로 카피, 기능 설명, CTA 문구 |
| JP index.html | 동일 — KR과 톤/내용 비교 |
| KR/JP camera.html | 촬영 안내 문구 |
| KR/JP prep.html | 준비 안내 문구 |
| KR/JP result.html | 결과 안내 문구 |
| KR/JP thankyou.html | 완료 안내 문구 |
| KR/JP charge.html | 충전 안내 문구 |
| Portal index.html | 포털 메인 카피 |
| Portal prompts.js | 챗봇 SYSTEM_PROMPT — 서비스 설명 부분 |
| KR/JP server.js | 코칭 프롬프트 내 서비스 언급 |

**점검 기준**:
- "AI 증명사진"/"AI 証明写真" 일관성
- 기능 설명이 현행과 맞는지 (QC 삭제됨, 서버 크롭 도입됨, GCS 저장 도입됨 등)
- 과장/오해 유발 문구 여부
- KR↔JP 간 톤·수준 차이 (KR=캐주얼, JP=丁寧語 — 의도적 차이 vs 불일치)

### 2. 법적 페이지 정합성

| 페이지 | KR | JP | 점검 항목 |
|--------|----|----|----------|
| 이용약관 | terms.html | terms.html | 서비스 범위·면책·분쟁해결 |
| 개인정보 | privacy.html | privacy.html | 수집항목·보관기간·GCS 저장 반영 여부 |
| 환불정책 | refund.html | refund.html | credits-policy.html 내용과 일치 여부 |
| 크레딧정책 | credits-policy.html | credits-policy.html | 현행 코드 동작과 일치 여부 |
| 특상법 | — | tokusho.html | 필수 기재 항목 누락 여부 |
| 사업자정보 | credits-policy.html 내 | tokusho.html | 사업자등록번호·통신판매업 일치 |

**특히 확인할 것**:
- GCS 이미지 저장이 도입됨 → privacy.html에 "이미지 보관" 관련 고지가 갱신됐는지
- 서버 크롭이 도입됨 → 서비스 설명에 "서버에서 규격 크롭" 관련 언급 필요 여부
- JP tokusho.html의 특정상거래법 필수항목 16개 — 누락 여부

### 3. 광고 멘트 vs 현실 괴리

| 위치 | 광고 멘트 | 현실 | 괴리 여부 |
|------|----------|------|----------|

특히:
- "AI 코칭" — 실제 동작하는지 (Live WebSocket 정상 여부)
- "90일 보관" — GCS 저장 구현됐지만 재다운로드 API는 아직 없음
- "무료 크레딧" — 실제 지급 경로와 조건
- "관공서 접수" 면책 — 적절히 표기돼 있는지
