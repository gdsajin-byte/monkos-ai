## Task 1: 서비스 현황 긴급 점검

### 1-1. 이미지 프로 다운로드 장애 확인
- `monkos_AI/` 내 이미지 프로 관련 코드 확인 — 다운로드 엔드포인트 동작 점검
- Cloud Run 서비스 상태 확인 (`gcloud run services describe`)
- 다운로드 URL을 curl로 직접 호출하여 응답 헤더(Content-Type) 확인
- HTML이 반환되는 경우 해당 HTML 내용 캡처 (에러 페이지인지, 로그인 리다이렉트인지)

### 1-2. 어드민 인증 이상 확인
- 어드민 접속 경로의 인증 체계 확인 (Firebase Auth? 자체 인증?)
- Firestore 또는 인증 DB에서 어드민 계정 상태 점검
- 최근 인증 관련 코드 변경 이력 확인 (`git log --oneline -20 -- **/auth*`)
- 외부 변경 흔적 확인: deploy 이력, 환경변수 변경, Cloud Run revision 확인

### 1-3. 보안 점검
- Cloud Run 최근 배포 이력 확인 — 우리가 배포하지 않은 revision이 있는지
- GCS 버킷 접근 로그 이상 여부 (가능한 범위)
- `.env`, `secrets/` 변경 여부 (`git diff` + 파일 타임스탬프)
- Firestore 보안 규칙 변경 여부
