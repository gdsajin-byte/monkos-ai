# 지시서: 챗봇 프롬프트 + KB 데이터 — 폐지 이벤트 제거 & 신규 콘텐츠 반영

## 배경
현재 운영 중인 이벤트는 **"첫 로그인 10c"만** 남아있다.
SNS 공유 100c, 텔레그램 채널 40c, 카카오 채널 40c, 미션 100c — 전부 폐지.
그러나 챗봇 프롬프트와 KB seed 데이터에 폐지된 이벤트가 그대로 남아 있어 사용자에게 오안내 발생.

## 작업 대상

### 1. `monkos_AI/portal/lib/prompts.js` — 4개 프롬프트 수정

#### (A) SYSTEM_PROMPT (L7~74) — 포털/카카오 통합 프롬프트
- **L32 제거**: `- SNS共有ボーナス: SNSで共有 or Googleレビュー → 100クレジット獲得（1回限定）`
- **L33 제거**: `- Telegramボーナス: @monkos_event_bot経由でチャンネル登録すると40クレジット（1回限定）`
- **L48~53 블록 제거**: `[SNS共有ボーナス案内 — 言語別に切り替えること]` 전체 블록

#### (B) SYSTEM_PROMPT_KR (L76~131) — 한국어 전용
- **L102 제거**: `- SNS 공유 보너스: 인스타그램에 공유하면 100크레딧 (1회 한정)`
- **L103 제거**: `- 텔레그램 보너스: @monkos_event_bot 경유 채널 가입 시 40크레딧 (1회 한정)`
- **L104 제거**: `- 카카오 채널 보너스: 카카오 채널 친구추가 시 40크레딧 (텔레그램과 택1)`

#### (C) SYSTEM_PROMPT_JP (L133~189) — 일본어 전용
- **L159 제거**: `- SNS共有ボーナス: X(Twitter)で共有 → 100クレジット (1回限定)`
- **L160 제거**: `- Telegramボーナス: @monkos_event_bot経由でチャンネル登録 → 40クレジット (1回限定)`

#### (D) CS_SYSTEM_PROMPT (L191~265) — Telegram CS봇
- **L221 제거**: `- SNS共有ボーナス: 100クレジット（1回限定）`
- **L222 제거**: `- Telegramボーナス: @monkos_event_bot経由でチャンネル登録すると40クレジット（1回限定）`
- **L223 제거**: `- カカオチャンネルボーナス: カカオチャンネル友達追加で40クレジット（Telegramと択一、1回限定）`

### 2. `monkos_AI/portal/seed_cs_knowledge.js` — KB 데이터

#### (A) credit_system (L13~23)
- **L20 제거/수정**: `- 이벤트 보너스: 채널가입(텔레그램/카카오 택1) 40c + 미션완료 100c + SNS공유 100c`
  → 이 줄 전체 삭제. 현재는 가입 보너스 10c만 존재.
- **L22 keywords**: `'이벤트'` 키워드는 유지해도 무방 (향후 재활성화 가능)

#### (B) credit_purchase (L25~46)
- **L37~40 수정**: 글로벌 Lemon Squeezy 가격이 구버전 ($10/10c, $25/30c, $40/50c)
  → 현행 JP config.js 기준으로 교체:
  ```
  [글로벌/일본 — Lemon Squeezy]
  - 📸 1장분: ¥990 (70c + 보너스 10c = 80c)
  - 10c 충전: ¥150
  - 130c 패키지: ¥1,490 (100c + 보너스 30c)
  - 420c 패키지: ¥3,990 (300c + 보너스 120c) — 추천
  - 750c 패키지: ¥5,990 (500c + 보너스 250c)
  ```
