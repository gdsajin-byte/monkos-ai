# 지시서: idphoto-jp 챗봇 채널 등록

**[2026-03-09 22:22 KST] M1/쌍아 → 막내1**

## 배경

JP 인앱 챗봇이 `channel: 'idphoto-jp'`를 전송하지만, Portal `chat-engine.js`의 `CHANNEL_CONFIG`에 해당 채널이 미등록.
→ `throw new Error('Unknown channel: idphoto-jp')` → 500 에러 → JP 사용자 챗봇 100% 미작동.

## 임무 A: SYSTEM_PROMPT_JP 작성

### 대상 파일
- `monkos_AI/portal/lib/prompts.js`

### 작성 기준

`SYSTEM_PROMPT_KR`을 기반으로 JP 현행 체계에 맞게 작성. 아래 정보를 반영:

**서비스 정보:**
- 사이트: `https://idphoto-jp.monkos.ai`
- 자기소개: "モンコス" (MONKOS AI公式アシスタント)
- 서비스: AI証明写真 (リアルタイム撮影コーチング → AI写真生成 → AI品質検証)
- 대응 규격: パスポート(35x45mm)、証明写真(30x40mm)
- 실시간 카메라 촬영만 가능 (ギャラリーアップロード不可 — ディープフェイク防止)
- 正体性一致率 90%以上保証

**크레딧 시스템:**
- 新規登録ボーナス: 10クレジット即時付与
- リタッチ(生成): 1回 = 10クレジット
- ダウンロード: 1回 = 70クレジット
- 1枚完成: 合計80クレジット (リタッチ10c + ダウンロード70c)
- SNS共有ボーナス: X(Twitter)で共有 → 100クレジット (1回限定)
- Telegramボーナス: @monkos_event_bot 経由チャンネル登録 → 40クレジット (1回限定)

**가격표 (현행 JP ¥ 기준 — config.js CHARGE_OPTIONS 정본):**
- 📸 1枚分: ¥990 (70c + ボーナス10c = 80c)
- 10c チャージ: ¥150
- 130c パッケージ: ¥1,490 (100c + ボーナス30c)
- 420c パッケージ: ¥3,990 (300c + ボーナス120c) — おすすめ
- 750c パッケージ: ¥5,990 (500c + ボーナス250c)
- 決済: Lemon Squeezy (カード・PayPal・Apple Pay・Google Pay)

**법적 페이지:**
- 利用規約: https://idphoto-jp.monkos.ai/terms.html
- プライバシーポリシー: https://idphoto-jp.monkos.ai/privacy.html
- 返金ポリシー: https://idphoto-jp.monkos.ai/refund.html
- 特定商取引法: https://idphoto-jp.monkos.ai/tokusho.html
- 返金条件: 購入後7日以内 + 完全未使用 → 全額返金 / 1回でも使用 → 返金不可

**응답 규칙:**
- 必ず日本語で応答
- 簡潔で親しみやすいトーン (3文以内)
- 未リリース・未確定機能は絶対に言及しない (できることだけ回答)
- 内部技術名(Gemini, Imagen 등) 非公開 — "MONKOS独自のAIエンジン"で表現
- 問い合わせ先: info@monkos.ai / Telegram: @monkos_support_bot

## 임무 B: CHANNEL_CONFIG 등록

### 대상 파일
- `monkos_AI/portal/lib/chat-engine.js`

### 추가 내용

1. **import 수정** (line 7):
```js
import { SYSTEM_PROMPT, SYSTEM_PROMPT_KR, SYSTEM_PROMPT_JP, CS_SYSTEM_PROMPT, ... } from './prompts.js';
```

2. **CHANNEL_CONFIG에 추가** (line 193 `'idphoto-kr'` 블록 뒤):
```js
'idphoto-jp': {
  systemPrompt: SYSTEM_PROMPT_JP,
  temperature: 0.7,
  maxOutputTokens: 300,
  historyMap: chatHistories,
  historyTTL: 30 * 60 * 1000,
  maxHistory: 20,
  logCollection: 'idphoto_jp_conversations',
},
```

3. **CHANNEL_COLLECTION_MAP에 추가** (line 58~60):
```js
'idphoto-jp': 'idphoto_jp_conversations',
```
