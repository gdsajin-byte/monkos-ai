## 현상

블로그 에디터 우측 사이드바 "이미지 저장소" (이미지 뱅크) 기능 장애:

1. **업로드 불가** — 새 이미지 업로드 시 저장소에 쌓이지 않음
2. **이미지 겹침** — 기존 이미지가 겹쳐서 표시됨
3. **시점**: 2026-03-21 네이버 GCS 마이그레이션(137건 `blog/` 경로 업로드) 이후 발생 추정

## 관련 파일

- 이미지 뱅크 UI: `monkos_AI/portal/public/admin/blog-edit.html` (v2.0 모듈 분리 후)
- 이미지 업로드 로직: `monkos_AI/portal/lib/cms/upload.js`
- GCS 버킷: `monk-ai-images` (lib/shared/config.js → GCS_BUCKET)
- 마이그레이션 스크립트: `monkos_AI/portal/scripts/migrate_naver_full_content.js`

## 조사 과제

### 1. 이미지 뱅크 로직 파악
- 이미지 뱅크가 GCS에서 어떤 경로를 읽어오는지 (API 엔드포인트, 리스트 로직)
- 날짜별 그룹핑 로직 (스크린샷에 2026-03-18, 2026-03-17, 2026-03-16 등 표시)
- 업로드 시 GCS 저장 경로 패턴

### 2. 겹침 원인 분석
- 마이그레이션으로 `blog/{slug}/` 경로에 올린 137건이 이미지 뱅크 리스트에 혼입되는지
- 기존 이미지 뱅크 경로와 마이그레이션 경로가 겹치는지
- 날짜 메타데이터 충돌 여부

### 3. 업로드 불가 원인 분석
- 업로드 API가 정상 동작하는지 (네트워크 에러, GCS 권한 등)
- v2.0 모듈 분리 시 이미지 업로드 핸들러가 깨졌는지

### 4. 에셋 레지스트리 현행화
