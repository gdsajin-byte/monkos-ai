# 지시서 — 404 리디렉션 수정

**[2026-03-27 02:39 KST] M1/민아 → M1/막내**

---

## 배경

Google Search Console 세부 검토 결과, `https://monkos.ai/idphoto-kr/` 경로가 **404 상태로 유효성 검사 실패** 확인.

- 원인: 서브도메인 전환 이전 구 경로가 Google에 색인 잔존
- 최종 크롤: 2026-03-13
- 유효성 검사: 3/9 시작 → 3/15 실패
- 현재 정상 경로: `https://idphoto-kr.monkos.ai/`

SEO 관점에서 404는 크롤 예산 낭비 + 링크 에퀴티 손실. 즉시 301 리디렉션 설정 필요.

---

## 작업 내용

### 수정 대상

`monkos_AI/portal/server.js`

### 수정 사항

server.js의 URL 라우팅 분기에 아래 301 리디렉션 추가:

```javascript
// 구 경로 → 서브도메인 301 리디렉션 (SEO 404 해소)
if (urlPath === '/idphoto-kr' || urlPath === '/idphoto-kr/') {
  res.writeHead(301, { Location: 'https://idphoto-kr.monkos.ai/' });
  res.end();
  return;
}

if (urlPath === '/idphoto-jp' || urlPath === '/idphoto-jp/') {
  res.writeHead(301, { Location: 'https://idphoto-jp.monkos.ai/' });
  res.end();
  return;
}
```

> idphoto-jp도 동일 패턴 예방 차원으로 함께 추가.

### 삽입 위치

- 기존 라우팅 분기(health check, API 등) **앞쪽**에 배치
- 정적 파일 서빙 로직보다 **앞**에 위치해야 함
