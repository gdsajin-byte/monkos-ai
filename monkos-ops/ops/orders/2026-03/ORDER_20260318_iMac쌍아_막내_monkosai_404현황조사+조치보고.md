## 1. 조사 범위

### A. 색인 등록 현황 파악
- `monkos_AI/portal/` 내 **sitemap.xml** 파일이 존재하는지 확인
- **robots.txt** 내용 확인
- index.html, server.js 등에서 **sitemap/SEO 메타태그** 확인
- `/guide`가 어디서 유래한 건지 추적: sitemap에 등록? index.html 링크? 외부 제출?

### B. 라우트별 실제 응답 상태 확인
아래 경로에 대해 **server.js 라우트 존재 여부 + public/ 정적 파일 존재 여부** 전수 확인:

| 경로 | 확인 사항 |
|------|----------|
| `/pricing` | 라우트? 파일? main.js 가로채기만 있는지? |
| `/guide` | 라우트? 파일? 어디서 이 경로가 나온 건지? |
| `/blog` | SSR 라우트 정상? Firestore 데이터 실제로 있는지? |

### C. index.html 내비게이션/링크 전수 대조
- index.html에서 `href=` 로 참조하는 **모든 내부 경로** 목록 추출
- 각 경로가 실제로 서버에서 응답하는지 대조
- **dead link 목록** 작성

### D. 홈 vs /blog 데이터 불일치
- 홈(index.html)의 블로그 카드가 정적 목업인지, API 호출인지 확인
