# 지시서: 헌법·법률 사문화 조항 전수점검

> 헌법 13조 + 법률 8장 38조 전 조항을 읽고, 사문화·레거시·실무 무시 조항을 식별한다.

## 배경

- 법체계가 2월 초부터 급속 성장 — 헌법 13조, 법률 8장 38조
- 그 사이 실무가 법보다 빠르게 진화 — 법이 현실을 못 따라가는 조항 존재
- "법이 있어도 읽히지 않으면 없는 것" (어젠다 #12-3)
- 개정 전에 먼저 어떤 조항이 죽어있는지 파악해야 함

## 조사 대상

### 헌법 (CLAUDE.md 내 13조)

전 조항을 읽고 아래 기준으로 판정:

| 판정 | 기준 |
|------|------|
| ✅ 활성 | 실무에서 실제 준수되고 있음 |
| ⚠️ 형해화 | 조문은 있으나 실무에서 부분적으로 무시됨 |
| 💀 사문화 | 실무에서 완전 무시되거나 전제 자체가 소멸 |
| 🔄 개정 필요 | 내용은 유효하나 문구가 현실과 불일치 |
| 🗑️ 레거시 | 이미 다른 조항/관례로 대체되어 존재 이유 소멸 |

### 법률 8장 (governance/laws/ch1~ch8)

전 조항 동일 기준 판정. 특히:

- **ch1 (에이전트 체계)**: 에이전트 목록·역할이 현실과 맞는지 (코웍이 미등록, 철창이 역할 변화 등)
- **ch2 (코딩 규칙)**: 실제 코딩에서 준수되고 있는지
- **ch3 (세션 로그)**: 세션 로그 형식·절차가 현행과 맞는지
- **ch4 (문서/폴더)**: 번호 폴더 언급, 정본 테이블 정합성 (막내1·2 조사와 상호보완)
- **ch5 (배포 규칙)**: 배포 프로세스가 현행과 맞는지 (쌍아/막내 직접 배포 관례화)
- **ch6 (브랜치/커밋)**: 브랜치 통일 이후 조항 정합성
- **ch7 (막내 행동강령)**: 실제 막내 운용과 괴리
- **ch8 (브랜딩/마케팅)**: 현행 마케팅 전략과 정합

## 조사 방법

### Step 1: 전 조항 읽기
- CLAUDE.md 헌법 13조 전문
- governance/laws/ch1~ch8 전문

### Step 2: 실태 대조
각 조항에 대해:
1. 조문 원문 (1줄 요약)
2. 실태 (실제 어떻게 운용되는지)
3. 판정 (✅/⚠️/💀/🔄/🗑️)
4. 근거 (왜 그렇게 판정했는지)
5. 권고 (유지/개정/삭제/통합)

### Step 3: MEMORY.md 대조
- MEMORY.md에 기록된 운용 원칙이 법률과 충돌하는 부분
- MEMORY에는 있는데 법률에 없는 규칙 (역으로 법률화 필요한 것)
- 법률에는 있는데 MEMORY/CLAUDE.md에서 누락된 것
