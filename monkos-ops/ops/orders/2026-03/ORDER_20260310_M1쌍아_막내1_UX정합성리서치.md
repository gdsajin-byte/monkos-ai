# 지시서: UX 관점 전체 정합성 리서치

> **[2026-03-10 20:51 KST] M1/쌍아 → 막내1**

## 목적

KR/JP 서비스의 사용자 경험(UX) 관점에서 모든 페이지·모달·흐름의 정합성과 모순을 찾아라.

## 조사 범위

### 1. 로그인 경험
- KR: index.html 인라인 로그인 모달 vs gate.js GateModule — 패턴 2가지 공존. 사용자 관점에서 차이 여부
- JP: 동일 조사
- 로그인 모달에 표시되는 메시지 (KR/JP 각각): "첫 로그인 시 10c" 등 — 실제 지급량과 일치하는지
- 로그인 후 헤더 상태 변화: 로그인 버튼 → 크레딧 배지 전환이 매끄러운지
- 미로그인 상태에서 각 기능(촬영/리터칭/다운로드/충전) 시도 시 게이트 메시지 일관성

### 2. 충전 모달(ChargeModule) UX
- 상품 카드 표시: 가격, 보너스, BEST 배지 — KR/JP 각각 확인
- 두 번 탭(선택→결제) UX: 사용자에게 직관적인지, 안내 문구 존재 여부
- 소액 스테퍼: 최소/최대 범위, 단가 표시
- 크레딧 부족 모달 → 충전 모달 전환 흐름

### 3. 결과 페이지(result) UX
- 생성 완료 후 비교컷 표시 흐름
- 다운로드 흐름: 크레딧 차감 → 크롭 → thankyou 전환
- 서버 크롭 vs 클라이언트 크롭 — 사용자에게 보이는 차이
- 에러 시 안내 메시지 적절성

### 4. thankyou 페이지 UX
- KR: 다운로드 카드 구성 (크롭본/원본/추가크롭)
- JP: 동일 구성인지, 미지원 섹션 정리 여부
- 이벤트 카드: 현재 표시되는 내용이 실제로 작동하는지
- 재방문 시 동작 (sessionStorage 의존 → 탭 닫으면 소멸)

### 5. 페이지 간 내비게이션 일관성
- 헤더 구성: 로고/크레딧 배지 — 모든 페이지에서 동일한지
- footer 링크: 정책 페이지(privacy/terms/refund/credits-policy) 링크 일관성
- 뒤로가기 시 동작 (SPA가 아닌 MPA — 상태 유실 여부)
