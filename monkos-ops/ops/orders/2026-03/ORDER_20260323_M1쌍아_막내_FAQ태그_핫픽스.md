## 1. FAQ 프리뷰 — 컬렉션명 오류

### 현상
홈 FAQ 프리뷰가 JA/EN에서 한국어 고정. SSR lang 필터가 동작하지 않음.

### 원인
`home.js` line 140: `firestore.collection('faq')` ← **존재하지 않는 컬렉션**
`render.js` line 13: `firestore.collection('faq_items')` ← **정본**

`.catch(() => ({ docs: [] }))` 로 에러가 묵살되어 0건 → 하드코딩 한국어 유지.

### 수정

`monkos_AI/portal/lib/cms/home.js` line 140:

```js
// 기존
const faqSnap = await firestore.collection('faq')

// 수정
const faqSnap = await firestore.collection('faq_items')
```

추가로 `render.js`의 `faqFragment`와 동일하게 `published` 필터 추가:

```js
const faqSnap = await firestore.collection('faq_items')
  .where('published', '==', true)
  .where('lang', '==', lang)
  .orderBy('order', 'asc')
  .limit(3)
  .get()
  .catch(() => ({ docs: [] }));
```

## 2. 태그 — regex 매칭 실패

### 현상
태그가 언어 전환 시에도 한국어 고정.

### 원인
`home.js` line 124 regex:
```js
/<div class="sb-tags">[\s\S]*?<\/div>/
```

홈 i18n 보강에서 `index.html`에 `id="sbTags"`가 추가됨:
```html
<div class="sb-tags" id="sbTags">
```

regex가 `class="sb-tags">`만 기대 → `class="sb-tags" id="sbTags">`와 불일치 → 교체 실패.

### 수정

`monkos_AI/portal/lib/cms/home.js` line 123~126:

```js
// 기존
html = html.replace(
  /<div class="sb-tags">[\s\S]*?<\/div>/,
  `<div class="sb-tags">\n        ${tags.map(...).join('')}\n      </div>`
);

// 수정 — id 속성 포함 매칭
html = html.replace(
  /<div class="sb-tags"[^>]*>[\s\S]*?<\/div>/,
  `<div class="sb-tags" id="sbTags">\n        ${tags.map(t => `<span class="sb-tag">${esc(t)}</span>`).join('')}\n      </div>`
);
```

> `[^>]*`로 추가 속성 허용 + 교체 결과에도 `id="sbTags"` 유지.
