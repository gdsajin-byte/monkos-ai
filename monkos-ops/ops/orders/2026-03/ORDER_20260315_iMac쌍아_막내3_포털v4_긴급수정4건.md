## 수정 2: 챗봇 입력창 iOS Safari 하단 가려짐

모바일에서 챗봇 바가 iOS Safari 홈 인디케이터 바에 가려지는 현상.

**현재** (`portal.css` 618~622줄):
```css
.chatbot-bar {
    width: calc(100% - 24px); min-width: 0; max-width: 100%;
    bottom: 0; border-radius: 16px 16px 0 0;
    padding: 8px 12px; padding-bottom: max(12px, env(safe-area-inset-bottom));
}
```

**조치 방향:**
- `bottom: 0` → `bottom: env(safe-area-inset-bottom, 0px)` 로 변경하거나
- 하단 여백을 추가로 확보하여 홈바와 겹치지 않도록 조정
- **실제 iOS Safari에서 테스트하여 가려지지 않는지 확인** (시뮬레이터 불가 시 padding-bottom 값을 넉넉히)

## 수정 3: 슬라이드 사진 비율 — 눈 커트 이슈

현재 갤러리 슬라이드 컨테이너가 `min-width: 90px; height: 115px` (약 3:4)이나, 이미지가 가로형이면 `object-fit: cover`로 상하가 잘려 얼굴 눈 부분이 커트됩니다.

**조치 방향:**
- 슬라이드 이미지 원본 비율 확인 (GCS URL: `monk-ai-images/assets/portal/slide/0311_*.webp`)
- 이미지가 세로형(3:4 또는 2:3)이면 컨테이너 비율을 이미지에 맞춤
- 이미지가 가로형이면 `object-position: top` 적용하여 얼굴 상단 우선 표시
- 또는 컨테이너 높이를 이미지 비율에 맞게 조정

## 수정 4: 슬라이드 역방향 점프 삭제

현재 갤러리 자동 스크롤이 끝에 도달하면 `sp = 0`으로 처음으로 점프합니다.

**현재** (`main.js` 106~117줄):
```js
// === 갤러리 자동 스크롤 ===
document.addEventListener('DOMContentLoaded', function() {
  var gt = document.getElementById('gt');
  if (gt) {
    var sp = 0;
    setInterval(function() {
      sp += 0.8;
      if (sp >= gt.scrollWidth - gt.clientWidth) sp = 0;
      gt.scrollLeft = sp;
    }, 30);
  }
});
```

**수정:**
- 끝에 도달 시 처음으로 점프하지 않고 **무한 루프 스크롤** 구현
- 방법: 갤러리 트랙 내 이미지를 복제(clone)하여 이어붙이고, 원본 끝 지점에서 seamless하게 처음으로 리셋
- 또는 끝에 도달하면 자연스럽게 **정지**

**작가님 지시: "빽하는 액션 삭제"** — 점프 제거가 핵심.
