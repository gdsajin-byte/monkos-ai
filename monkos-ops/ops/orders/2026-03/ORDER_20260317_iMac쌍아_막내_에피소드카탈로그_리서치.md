# 지시서: MONKOS 에피소드 카탈로그 — 연구노트 추출 리서치

## 목적

MONK.KR 프로젝트의 전 이력(세션로그·거버넌스·디버깅기록·커밋히스토리)에서 **연구노트급 에피소드**를 추출하여 카탈로그화한다. 각 에피소드는 향후 ① 블로그 콘텐츠 ② GitHub 공개 소재 ③ 연구개발서 근거 자료로 3중 활용된다.

## 배경

- 이전에 유사 시도가 있었으나 범위 과대로 미완. 이번에는 **에피소드 단위**로 분리하여 개별 활용 가능한 형태로 정리
- 작가님 핵심 의도: "에피소드 하나씩 블로깅하여 GitHub 소재로 삼고 연구 자료로 확장"

## 에피소드 분류 체계

각 에피소드를 아래 카테고리로 분류:

| 카테고리 | 설명 | 예시 |
|----------|------|------|
| **ARCH** | 아키텍처 결정·인프라 전환 | 포트 79 차단 → 서비스 분할, CF→Cloud Run 전환 |
| **DEBUG** | 실전 디버깅·장애 대응 | l/I 크레덴셜 혼동, responseModalities 이슈 |
| **GOV** | AI 거버넌스·법체계 진화 | 헌법 수립, 삼권심사, 멀티에이전트 역할 분화 |
| **PRODUCT** | 프로덕트 빌딩·UX 진화 | 에디터 1~4차, 포털 v4 전환, 크롭 앱 탄생 |
| **TEAM** | 팀 협업·워크플로우 혁신 | 우체통 시스템, 코웍이 연동, 지시서 체계 |
| **BIZ** | 사업·마케팅·전략 | 디딤돌 R&D 신청, GEO 전략, 일본 시장 진출 |

## 조사 범위

### 1차 소스 (전수 확인)

- **세션 로그 전체**: `monkos-ops/ops/sessions/` 하위 모든 파일
- **거버넌스 이력**: `governance/` 하위 (특히 `constitution/`, `history/`, `amendments/`)
- **보고서**: `monkos-ops/ops/reports/` 하위 전체
- **코웍이 세션**: `monkos-ops/works/ops/sessions/` 하위

### 2차 소스 (키워드 기반)

- **git log 전체**: `git log --oneline --all` — 커밋 메시지에서 전환점·장애·마일스톤 추출
- **MEMORY.md 교훈 섹션**: 이미 정제된 인사이트 → 원본 에피소드 역추적
- **기존 정리 시도**: `docs/` 및 `monkos-ops/` 내 유사 문서 (이전 리서치 결과물) 탐색

### 3차 소스 (보완)

- **지시서 아카이브**: `monkos-ops/ops/orders/` — 복잡한 작업의 설계 의도 확인
- **기안서**: `monkos-ops/ops/proposals/` — 전략적 결정의 배경

## 추출 기준

에피소드로 인정하는 기준:
1. **문제 → 해결 구조**가 있을 것 (단순 작업 기록 제외)
2. **인사이트·교훈**이 도출될 것 ("이렇게 했더니 이렇게 됐다" 수준 이상)
3. **재현 가능한 지식**일 것 (다른 프로젝트에도 적용 가능)
4. **시간적 맥락**이 있을 것 (날짜, 소요 기간, 전후 관계)

## 산출물
