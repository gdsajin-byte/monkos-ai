### 2. 환불 정책 정합성
- credits-policy.html (KR/JP) 환불 조건 ↔ 실제 코드 로직
- refund.html (KR/JP) 내용 ↔ credits-policy 내용 일치 여부
- 토스 환불 vs LS 환불 — 각각의 실제 구현 상태

### 3. 토스 위젯화 리서치
- 현재: `TossPayments().requestPayment('카드', {...})` → 리다이렉트 방식
- 토스 위젯 SDK v2: 인앱 결제 가능 여부, customerKey=uid 사용 가능 여부
- 막내4 이전 리서치(REPORT_20260309_토스위젯리서치) 참조하여 구현 난이도 평가
- KR에 토스 위젯 적용 시 수정 범위 산출

### 4. KR↔JP 가격 체계 비교
- KR: 원화(KRW) + 토스페이먼츠
- JP: 엔화(JPY) + Lemon Squeezy
- 동일 상품(70c 기본)의 양국 가격이 환율 대비 합리적인지
- 보너스 비율 양국 동일한지
