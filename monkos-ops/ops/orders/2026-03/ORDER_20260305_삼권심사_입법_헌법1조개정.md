## 맥락 브리핑

### 현행 문제
1. **세션 시작 절차 부재**: 헌법·법률 어디에도 "세션 시작 시 무엇을 할 것인가" 규정 없음
2. **프로토콜 산재**: 타임스탬프(헌법1조), 보고양식(헌법2조), 세션마감(ch3 3조), 지시서(ch1+MEMORY) — 하나의 체계인데 조문이 흩어져 있음
3. **헌법 1조의 협소함**: "타임스탬프를 시스템 명령으로 찍어라"라는 단일 행위 규정. 실제로는 타임스탬프, 세션 생명주기, 수발신 체계가 하나의 운영 프로토콜

### 개정안 2건 (동시 심사)

**안건 A: 헌법 1조 → "운영 프로토콜" 격상**
- 현행: 타임스탬프 절대 준수 (단일 행위)
- 개정: 운영 프로토콜 정의 (타임스탬프 + 세션 생명주기 + 수발신 체계)
- 세션 시작 절차(git fetch --all → develop+main 확인 → 머지 → 보고) 포함
- 세션 마감 절차(ch3 3조 내용) 상위 원칙으로 격상 or 참조

**안건 B: amendment.md "리서치 선행" 규정 추가**
- 현행: 삼권 심사 단계에 리서치가 암묵적으로 포함
- 개정: 심사 전 충분한 리서치 의무를 명시. "심사 의견 제출 전, 관련 헌법·법률·규정을 전수 파악할 것"
