블로그 에디터 우측 사이드바 "이미지 저장소" (이미지 뱅크):

| 현상 | 상세 |
|------|------|
| **업로드 불가** | 새 이미지 업로드해도 뱅킹 안 됨 — 기존 이미지만 고정 표시 |
| **이미지 겹침** | 기존 이미지가 억눌리며 겹쳐 표시되는 UX |

## 2. 원인 분석

### 핵심 문제: GCS 경로 혼입

**이미지 뱅크 리스트 API** (`upload.js:104`):
```javascript
const [files] = await bucket.getFiles({ prefix: 'blog/', maxResults: 50 });
```

- `blog/` 프리픽스로 **모든 하위 경로** 포함 조회
- 에디터 업로드: `blog/{timestamp}_{name}.webp` (flat)
- 네이버 마이그레이션: `blog/{slug}/{filename}` (nested)
- **137건 네이버 이미지가 50건 제한을 채워버려 신규 업로드 이미지가 리스트에 안 나옴**
- 네이버 이미지 = 저화질/깨진 파일 → 기존 정상 이미지와 겹쳐 표시

### 부차 문제

| 문제 | 원인 |
|------|------|
| maxResults 50 고정 | 페이지네이션 미구현 — 이미지 누적 시 최신 파일이 밀림 |
| 썸네일 클릭 시 원본 확인 불가 | 확대 뷰 미구현 — 삽입 판단에 불편 |
| 날짜 그룹핑 UX | 인라인 스타일 하드코딩, 스크롤 시 겹침 현상 |

## 3. 수정 범위

### A. 이미지 리스트 필터링 (백엔드 — `upload.js`)

| 항목 | 현재 | 수정 |
|------|------|------|
| GCS 쿼리 | `prefix: 'blog/'`, `maxResults: 50` | `prefix: 'blog/'`, **maxResults 제거** (전체 조회) |
| 필터 로직 | 확장자만 체크 | `blog/` 직후에 `/`가 없는 파일만 (`blog/{slug}/` 패턴 제외) |

구현 방향:
```javascript
// maxResults 제거 + blog/ 직하 flat 파일만
const [files] = await bucket.getFiles({ prefix: 'blog/' });
const images = files
  .filter(f => /\.(jpg|jpeg|png|webp|gif)$/i.test(f.name))
  .filter(f => !f.name.replace('blog/', '').includes('/'))  // nested 제외
  .sort(...)
```

이미지는 계속 쌓이는 것이 정상. 사이드바에서 스크롤로 탐색하는 갤러리형 UI가 자연스러움.

### B. 이미지 확대 뷰 (프론트엔드 — `blog-image.js`)

| 항목 | 현재 | 수정 |
|------|------|------|
| 썸네일 클릭 | 바로 플로팅 툴바 (삽입/썸네일 지정) | **확대 뷰 모달** → 툴바 버튼 포함 |

구현 방향:
- 썸네일 클릭 → 라이트박스 스타일 확대 뷰 (max-width: 80vw, max-height: 70vh)
- 확대 뷰 안에 액션 버튼: `본문 삽입` / `썸네일 지정` / `삭제` / `닫기`
- ESC 또는 배경 클릭으로 닫기
- 기존 플로팅 툴바 구조(`createFloatToolbar`) 재활용 가능

### C. 이미지 그리드 UX 개선 (프론트엔드 — `blog-image.js`)

| 항목 | 현재 | 수정 |
|------|------|------|
| 날짜 헤더 | 인라인 스타일 하드코딩 | CSS 클래스 분리 (`blog-editor.css`) |
| 그리드 | 4열 고정 | 유지 (사이드바 폭에 적합) |
| 빈 상태 | 텍스트만 | 업로드 유도 UI |
