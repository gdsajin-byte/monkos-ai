# 헤더 프레임 교정 — 컨테이너 벗어남 수정

## 배경
- 코웍이 v4 레이아웃 설계에서 **"헤더 포함 전체가 site-wrapper 안"** 확정
- 현재 v3: hero, user-bar, gallery-strip, nav 가 뷰포트 풀블리드 (`.layout` 바깥)
- 문제: 와이드 모니터에서 헤더만 화면 전체로 늘어나고 본문은 1280px — T자 실루엣 발생
- 본 지시서는 Phase 0 선행작업으로, `.site-wrapper` 도입 없이 CSS만으로 헤더 영역을 1280px로 제한

## 대상 파일
- `monkos_AI/portal/public/css/portal.css`

## 작업 내용

### 1. 히어로 컨테이너 제한

**현재 (60행~):**
```css
.hero {
  background: linear-gradient(135deg, #08081a, #12103a 35%, #1e1660 60%, #12103a);
  padding: 24px 0 18px;
  text-align: center;
  position: relative;
  overflow: hidden;
}
```

**변경:**
```css
.hero {
  background: linear-gradient(135deg, #08081a, #12103a 35%, #1e1660 60%, #12103a);
  padding: 24px 0 18px;
  text-align: center;
  position: relative;
  overflow: hidden;
  max-width: 1280px;
  margin: 0 auto;
}
```

### 2. 유저바 컨테이너 제한

**현재 유저바 CSS에 추가:**
```css
.user-bar {
  /* 기존 속성 유지 + 아래 추가 */
  max-width: 1280px;
  margin: 0 auto;
}
```

### 3. 갤러리 스트립 컨테이너 제한

**현재 갤러리 CSS에 추가:**
```css
.gallery-strip {
  /* 기존 속성 유지 + 아래 추가 */
  max-width: 1280px;
  margin: 0 auto;
}
```

### 4. 네비게이션 컨테이너 제한

**현재 nav CSS에 추가:**
```css
nav {
  /* 기존 속성 유지 + 아래 추가 */
  max-width: 1280px;
  margin: 0 auto;
}
```

## 요약
| 셀렉터 | 추가 속성 |
|---------|----------|
| `.hero` | `max-width: 1280px; margin: 0 auto;` |
| `.user-bar` | `max-width: 1280px; margin: 0 auto;` |
| `.gallery-strip` | `max-width: 1280px; margin: 0 auto;` |
| `nav` | `max-width: 1280px; margin: 0 auto;` |

## 주의
- `.layout`에는 이미 `max-width: 1280px`이 있으므로 건드리지 않음
- `footer`에도 이미 있으므로 건드리지 않음
- `nav`의 `position: sticky; top: 0`은 유지 — `max-width`와 충돌 없음
- `.hero`의 배경 그라데이션이 1280px로 잘리는 게 맞음 (site-wrapper 내부 풀블리드 = v4 확정)

## 완료 조건
- [ ] 와이드 모니터(1440px+)에서 hero~nav 영역이 1280px로 제한
- [ ] hero 배경 그라데이션이 1280px 박스 안에서만 표시
- [ ] nav sticky 동작 정상
- [ ] 모바일(768px 이하) 렌더링 영향 없음 확인
- [ ] 갤러리 스트립 가로 스크롤 정상 동작
