# 블로그 에디터 + 포털 개선 — 8건

## 배경

블로그 에디터 실사용 중 발견된 UX 이슈 4건 + 코웍이 전달서(2026-03-15) 디자인 개선안 4건을 통합 처리합니다.

---

## 수정 1: 에디터 레이아웃 — 메타 정보 접기 + 에디터 확대

대상: `monkos_AI/portal/public/admin/blog-edit.html`

**현재:** 메타 필드(Title, Slug, Language, Summary, Category, Tags, Thumbnail)가 화면 상단 절반을 차지. Content 에디터까지 스크롤 필요.

**수정:**
- Title은 항상 노출 (글의 핵심)
- 나머지 메타 필드(Slug~Thumbnail)를 **접을 수 있는 패널**로 묶기. 기본 상태: **접힘**
- 토글 버튼: "설정 펼치기 ▼" / "설정 접기 ▲"
- Content 에디터 영역: `min-height: 70vh`로 확대
- 편집 모드(기존 글)에서는 메타 패널 접힌 채로 시작, 신규 글에서는 펼쳐진 채로 시작

---

## 수정 2: Slug 필드 안내 문구

대상: `monkos_AI/portal/public/admin/blog-edit.html` (90줄 부근)

**현재:** `<label>Slug (auto-generated)</label>` — 비개발자에게 slug가 뭔지 알 수 없음

**수정:**
- 라벨: `URL 주소`
- placeholder: `제목에서 자동 생성됩니다 (수정 가능)`
- 라벨 아래 작은 안내문: `"블로그 주소에 사용됩니다. 특수문자($ / 등)는 사용할 수 없습니다."`
- 스타일: `font-size: 11px; color: var(--text-dim);`

---

## 수정 3: Slug 백엔드 세니타이징

대상: `monkos_AI/portal/lib/cms/blog.js` — `handleBlogCreate` (72줄~), `handleBlogUpdate` (128줄~)

**현재:** 프론트엔드 자동생성 slug는 정규식으로 특수문자 제거하지만, 사용자가 수동 입력한 slug는 그대로 Firestore 문서 ID로 사용. `$`, `/` 등이 포함되면 Firestore 경로 에러 발생.

**수정:**
- `handleBlogCreate`에서 slug 저장 전, `generateSlug()` 함수와 동일한 세니타이징 적용
- 추가로 `/` 문자를 명시적으로 제거 (Firestore 경로 구분자)
- `handleBlogUpdate`의 `extractSlug()`에서도 동일 방어
- 프론트엔드 slug input에도 `oninput` 이벤트로 `/`, `$` 실시간 제거

## 수정 4: 썸네일 업로드 버튼

대상: `monkos_AI/portal/public/admin/blog-edit.html` (130~133줄)

**현재:** Thumbnail URL 필드에 GCS URL을 직접 복붙해야 함. 본문 이미지 업로드(`/api/admin/upload`)는 이미 구현되어 있으나 썸네일에는 연결 안 됨.

**수정:**
- Thumbnail URL input 옆에 **업로드 버튼** 추가
- 클릭 시 파일 선택 다이얼로그 → 선택된 이미지를 `/api/admin/upload`로 전송 → 반환된 URL을 thumbnail input에 자동 세팅
- 업로드 중 버튼 텍스트: "업로드 중..." (disabled)
- 기존 URL 직접 입력도 유지 (둘 다 가능)

## 수정 5: 임시저장 글 접근성

대상: `monkos_AI/portal/public/admin/blog-edit.html`

**현재:** Save Draft 후 해당 글을 다시 열려면 Blog List 페이지로 이동해야 함. 에디터에서 바로 접근 불가.

**수정:**
- 에디터 상단 (Title 위 또는 nav 영역)에 **"내 글 목록" 드롭다운** 추가
- `/api/admin/blog` 호출하여 최근 글 목록 로드 (Draft/Published 구분 뱃지)
- 클릭 시 해당 slug로 `?slug=` 파라미터 붙여 현재 페이지 리로드
- 최대 10건 표시, "전체 목록 →" 링크로 blog-list.html 연결

## 수정 6: 포털 폰트 통일

대상:
- `monkos_AI/portal/public/css/portal.css`
- `monkos_AI/portal/public/admin/blog-edit.html` (인라인 스타일)
- `monkos_AI/portal/public/admin/blog-list.html` (인라인 스타일)

**현재:** `'Noto Sans KR', -apple-system, sans-serif` — 페이지마다 불일치

**수정:**
```css
font-family: 'Pretendard', 'Noto Sans JP', -apple-system, sans-serif;
```

- Pretendard CDN 로드 추가 (한/영 커버, 무료, 가독성)
- Noto Sans JP (일본어 폴백)
- 포털 전체 + 블로그 본문 + 어드민 에디터에 통일 적용
- Pretendard CDN: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/variable/pretendardvariable.css`

대상: `monkos_AI/portal/public/admin/blog-edit.html`

## 수정 8: 홈 레이아웃 매니저 (어드민)

대상: 신규 파일 + `monkos_AI/portal/lib/cms/home.js` 수정

**현재:** 홈 섹션 배치가 코드에 하드코딩. 순서/표시 변경 시 코드 수정+배포 필요.

**수정:**
- 어드민에 `/admin/layout.html` 페이지 신규 생성
- 테이블 형태 UI: 섹션명 | 표시 토글(ON/OFF) | 순서(↑↓) | 사이즈(S/M/L)
- 설정값을 Firestore `site_config` 컬렉션에 저장
- `home.js`에서 config 읽어 렌더링 순서·표시 반영
- 초기 섹션 목록: hero, beforeAfter, magazine, blog, guide, credit, tags

**데이터 구조:**
```json
{
  "sections": [
    { "id": "hero", "visible": true, "size": "L", "order": 1 },
    { "id": "beforeAfter", "visible": true, "size": "M", "order": 2 },
    { "id": "magazine", "visible": true, "size": "M", "order": 3 },
    { "id": "blog", "visible": true, "size": "M", "order": 4 },
    { "id": "guide", "visible": true, "size": "S", "order": 5 },
    { "id": "credit", "visible": true, "size": "S", "order": 6 },
    { "id": "tags", "visible": true, "size": "S", "order": 7 }
  ]
}
```

**API:**
- GET `/api/admin/layout` — 현재 설정 조회
- PUT `/api/admin/layout` — 설정 저장
