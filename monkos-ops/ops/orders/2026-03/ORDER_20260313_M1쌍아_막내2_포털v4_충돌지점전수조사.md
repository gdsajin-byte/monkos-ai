# 포털 v4 — 충돌지점 전수조사

## 배경

포털 v4 프로토에서 대규모 UI/UX 변경이 예정되어 있다. 현재 프로덕션 코드와의 충돌 지점을 사전에 전수 파악한다.

프로토 파일:
- `/Users/macmini/Desktop/쌍아/files 2/MONKOS_Portal_v4_3col.html`
- `/Users/macmini/Desktop/쌍아/files 2/MONKOS_포털v4_쌍아전달_최종.md`

## 조사 범위

### 1. 다크→라이트 테마 충돌

현재 포털의 CSS 변수 체계 (`--bg: #0a0a1a` 등)를 전수 나열하고, v4 라이트 테마 (`--bg: #FAFAF8` 등)와 **1:1 매핑 테이블** 작성.

추가 확인:
- index.html 외에 다크 테마 하드코딩된 파일이 있는지 (admin 페이지 등)
- 오늘 iMac 세션에서 admin 6개 파일을 라이트 테마로 전환함 (커밋 `421a4c4`) — 이것과의 정합성
- idphoto-kr/jp 앱은 다크 유지 — 포털만 라이트로 갈 때 공유 CSS가 있는지

### 2. 오늘 구현된 CMS와의 충돌

오늘 iMac 세션에서 구현된 CMS 기능 (커밋 `742490d` ~ `a41ac5f`):

| 기능 | 파일 | v4와의 관계 |
|------|------|------------|
| 블로그 SSR | `lib/cms/render.js` | v4에서 메인 영역에 로드 방식 변경? |
| FAQ SSR | `lib/cms/render.js` | 같은 이슈 |
| 갤러리/게시판 SSR | `lib/cms/render.js` | 같은 이슈 |
| Admin 페이지 6개 | `public/admin/` | v4 라이트 테마와 정합? |
| 다국어 URL (`/ja/blog/slug`) | `server.js` 라우트 | v4 SPA 라우팅과 충돌? |

각 SSR 렌더러가 반환하는 HTML 구조를 파악하고, 이것이 3컬럼 레이아웃의 메인 영역으로 들어갈 수 있는지 분석.

### 3. 네비게이션 변경 충돌

현재 네비:
- 오늘 구현: `홈 | 블로그 | FAQ | 갤러리 | 게시판 | 가격` + Admin 링크

v4 네비:
- `홈 | 블로그 | FAQ | 갤러리 | 게시판 | 크롭앱 | 가격`

차이점:
- **크롭앱** 추가 — `/crop` 라우트 신규
- Admin 링크 위치 변경?

### 4. 포지셔닝 카피 충돌

v4 문서 §15에서 `"AI 생성이 아닌 AI 리터칭" → 삭제` 지시.

전체 코드베이스에서 이 카피가 사용된 위치를 **전수 검색**:
- index.html
- 챗봇 프롬프트 (`lib/prompts.js`, `lib/chat-engine.js`)
- KB 시드 데이터
- SSR 렌더러의 메타 태그/JSON-LD
- idphoto-kr/jp 랜딩 페이지
- 프로토 HTML 자체 (FAQ JSON-LD에 남아있음 — 모순 확인)

### 5. 챗봇 UI 충돌

현재 챗봇:
- index.html 하단에 인라인 구현
- WebSocket 기반? fetch 기반? 방식 확인
- 모바일 키보드 올라올 때 동작

v4 챗봇:
- 하단 고정 바 + 모달 올라옴 방식
- 입력 → 모달 전개 → 대화

현재 챗봇 코드를 전수 파악하고, v4 모달 방식으로 전환 시 영향 범위 도출.

### 6. 언어 스위치 충돌

현재: 모든 사용자에게 KO/JA/EN 스위치 노출
v4 §12: **관리자 계정에서만** 스위치 노출, 일반 사용자는 IP 기반 자동

- 현재 언어 스위치 로직 위치 (index.html 내 JS)
- IP 기반 분기를 구현하려면 server.js에서 어디를 수정해야 하는지
- 기존 다국어 URL 라우팅 (`/ja/blog/slug`)과의 정합성

## 산출물

1. **CSS 변수 매핑 테이블** — 다크 → 라이트 1:1 대응
2. **CMS SSR 충돌 분석표** — 각 렌더러별 3컬럼 적합성
3. **카피 전수 검색 결과** — "AI 생성이 아닌 AI 리터칭" 사용 위치 목록
4. **챗봇 현재 구조 분석** — 코드 위치, 방식, 전환 영향
5. **충돌 위험도 매트릭스** — 항목별 위험도(H/M/L) + 해결 방향
