# 지시서: 문서 체계 활성 경로 전수조사

> monkos-ops/ 전 경로의 실질 활용 현황을 파악하고, 죽은 경로 삭제·이관·최적화 방안을 도출한다.

## 배경

- monkos-ops/ 안에 번호 폴더(01~06) 레거시와 4부서 체제가 병존
- 어떤 폴더가 실제로 참조되고 있는지(코드/법률/MEMORY) 파악 안 됨
- 삭제 시 어딘가에서 경로를 참조하고 있으면 깨짐 → 삭제 전 전수 조사 필수

## 조사 범위

### 1. 경로 참조 전수조사

아래 폴더들이 **프로젝트 내 어디에서 참조되는지** 전수 조사:

**대상 폴더**:
```
monkos-ops/01_전략/
monkos-ops/02_리서치/
monkos-ops/03_개발/
monkos-ops/04_문서/
monkos-ops/05_공유/
monkos-ops/06_로그/
monkos-ops/ops/decisions/
docs/monkos/          (동결 선언인데 03-10에 활동 감지)
docs/infrastructure/  (아카이브인데 03-14에 신규 파일 추가)
docs/corpus/
docs/archives/
```

**조사 방법**:
- `grep -r` 로 해당 경로 문자열이 등장하는 모든 파일 검색
  - CLAUDE.md, MEMORY.md, governance/laws/*.md, monkos-ops/ 전체, scripts/ 전체
- 법률(ch1~ch8) 내 해당 경로 참조 여부
- MEMORY.md 내 해당 경로 참조 여부
- README.md 들 내 해당 경로 참조 여부
- 코드(server.js, deploy.sh 등) 내 해당 경로 참조 여부

### 2. 파일 활용 현황

각 대상 폴더 내 파일별:
- 최종 수정일
- git log로 마지막 commit 일자
- 내용 요약 (첫 5줄)
- 다른 문서에서 참조하는지 여부

### 3. docs/infrastructure/ 위상 재검토

- ch4 1조에 "보물창고, 변경 없음"으로 정의되어 있으나 실제 신규 파일이 계속 추가됨
- `docs/infrastructure/architecture/PORTAL_V4_TECHNICAL_SPEC.md` (03-14 신규)
- 원칙 위반인지, 아니면 이 폴더의 성격 재정의가 필요한지 판단 근거 제시

### 4. docs/monkos/ 동결 위반 조사

- 03-10에 어떤 파일이 추가/수정되었는지 git log로 확인
- 의도적 위반인지 실수인지 판별

## 산출물

### 보고서 형식

```markdown
## 1. 경로 참조 맵
| 대상 폴더 | 참조하는 파일 (경로:줄번호) | 참조 유형 (법률/MEMORY/README/코드) |

## 2. 파일별 활용 현황
| 폴더 | 파일 | 최종 수정 | 최종 커밋 | 참조 여부 | 삭제 가능 |

## 3. 삭제/이관 영향 분석
| 대상 | 현재 파일 수 | 삭제 시 깨지는 참조 | 이관 대안 | 권고 |

## 4. docs/infrastructure 위상 판단
- 현행 원칙 vs 실태 괴리
- 재정의 제안 or 위반 파일 이관 제안

## 5. docs/monkos 동결 위반 내역
- git log 기반 03월 변경 목록
- 각 변경의 의도 판단

## 6. 최적화 권고안
- 즉시 삭제 가능 목록
- 이관 필요 목록 (원본 → 대상)
- ch4 법률 개정 필요 사항
```
