<footer>

    <strong>MONK STUDIO</strong><br>
    대표: 신정규 | 사업자등록번호: 636-15-00574<br>
    경기도 하남시 미사강변동로 95 B1029<br>

  </div>
  <div class="ft-links">

    <a href="/terms">이용약관</a>

**변경 사항:**
- `ft-biz`: 사업자 정보를 줄바꿈으로 정리 (한 줄 나열 → 구조화)
- `@monkos_support_bot | Google Cloud Platform` 삭제 (내부 정보 노출 불필요)
- crop.monkos.ai 외부 링크 → `/crop` 내부 경로 (서브디렉토리 정책)
- 링크 텍스트 `crop.monkos.ai` → `AI 크롭` (서비스명으로 표기)
