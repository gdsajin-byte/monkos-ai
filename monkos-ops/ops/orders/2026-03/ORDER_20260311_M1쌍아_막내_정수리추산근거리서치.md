# 지시서: 정수리 추산 근거 리서치

**[2026-03-11 23:21 KST] M1/쌍아 → 막내(any)**

---

## 배경

증명사진 크롭 엔진(crop-engine)에서 **정수리 위치 추산**이 핵심 과제.
현재 MediaPipe FaceMesh 478 랜드마크는 **이마 중간(#10)까지만 감지** — 헤어라인·정수리는 감지 범위 밖.

현재 v2 방식: `눈~턱 거리 = 눈~정수리 거리` (1:1 고정비) → 개인차 미반영, 과추산 경향.
작가님 제안: **턱(#152) + 좌우 윤곽(#234/#454)으로 정타원 피팅 → 타원 상단 = 정수리** → 얼굴형 반영 가능하나 여전히 추산.

**필요한 것**: 턱에서 정수리까지의 거리를 수학적·통계적으로 추정할 수 있는 학술적 근거.

---

## 리서치 범위

### 1. 두개안면 계측학 (Cephalometric / Craniofacial Anthropometry)

- **턱(menton) → 정수리(vertex)** 거리의 인종별·성별별·연령별 통계 데이터
- 눈(pupil/biocular) → 턱, 눈 → 정수리 비율 통계
- 대표 논문/교과서: Farkas 계측학, Leslie G. Farkas "Anthropometry of the Head and Face"
- ICAO 9303 (여권 사진 규격)에서 참조하는 얼굴 비율 근거
- 한국인/동아시아인 두개안면 계측 데이터 (Size Korea 등 국가 인체측정 DB)

### 2. 얼굴 비율 수학 모델

- 눈~턱 vs 눈~정수리 실측 비율 (1:1인가? 실제 분포는?)
- 얼굴폭 vs 얼굴높이(턱~정수리) 비율 — 타원 피팅의 수학적 타당성
- 성별·인종별 얼굴 종횡비(facial index) 통계
- 황금비(golden ratio) 기반 얼굴 비례 연구 (해당 시)

### 3. 증명사진/ID Photo 크롭 기술

- 기존 오픈소스 크롭 엔진의 정수리 추산 방식:
  - **HivisionIDPhotos** (GitHub)
  - **dpar39/ppp** (GitHub)
  - 기타 ID photo 자동 크롭 도구
- 각각 어떤 모델·어떤 비율·어떤 근거로 정수리를 잡는가
- segmentation 기반(머리 영역 마스크) vs landmark 기반 vs 하이브리드

### 4. Head Segmentation / Pose Estimation

- 정수리를 **실측**하는 기술적 접근법:
  - Head segmentation 모델 (머리카락 포함 두상 영역 검출)
  - Head pose estimation에서 두상 상단 추산
  - Portrait matting/segmentation → 두상 바운딩박스 상단
- 경량 모델 존재 여부 (Cloud Run CPU 환경 기준)
- MediaPipe 외 대안: DLIB 68점, InsightFace, 3DDFA 등

### 5. 여권 규격과 얼굴 비율 관계

- ICAO 9303 / ISO/IEC 19794-5 — 얼굴 영역 비율 정의
- 한국 여권 규격: 얼굴 길이 3.2~3.6cm (전체 4.5cm 중)
- 일본 여권 규격: 동일 참조
- 규격서가 "얼굴 길이"를 턱~정수리로 정의할 때의 정수리 기준점

### 6. 인간 시각 판단 모사 — 타원 가설 (작가님 제안)

**핵심 전제**: 여권 심사관(공무원)도 정수리를 직접 보지 못한다. 볼륨 헤어 등에서 정수리는 가려져 있으며, 심사관 역시 얼굴 윤곽에서 무의식적으로 타원을 그려 정수리를 추정한다. 인간은 머리를 팽이형이 아닌 타원형으로 인식하는 관성이 있다.

- **알고리즘의 목표는 해부학적 정확이 아니라, 심사관이 "괜찮다"고 느끼는 비율**
- 턱(#152) + 좌우 윤곽(#234/#454)으로 정타원 피팅 → 타원 상단 꼭지점 = 정수리 추산
- 이 방식은 얼굴형(긴/둥근/넓은)에 자연스럽게 적응 — 타원 장단비가 개인차를 흡수
- 리서치 포인트:
  - 인지심리학/시각인류학에서 "얼굴 형태 인식"과 타원 모델 연구
  - 여권 심사 가이드라인에서 "얼굴 길이" 판단 기준 (심사관 매뉴얼 등)
  - ICAO가 제시하는 얼굴 비율 가이드라인의 실무 적용 방식
