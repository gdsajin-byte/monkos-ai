# 지시서 #5: i18n.js 정리 + 통합 검증 + 배포

## 1. 목적

SSR 블록 렌더링으로 이관된 i18n 키를 제거하고, `applyLang()` DOM 조작 코드를 정리한다. 이후 전체 통합 검증 → dev 배포 → 작가님 확인 → prod 배포.

## 2. 작업 내용

### 2-1. i18n.js 키 제거

**파일**: `monkos_AI/portal/public/js/i18n.js`

아래 키를 ko/ja/en 세 언어 모두에서 제거:

```
제거 대상 (~40개):
heroTag, ctaText,
navHome, navBlog, navFaq, navGallery, navBoard, navPricing,
svcPhotoTitle, svcPhotoDesc, svcPhotoLink,
svcCropTitle, svcCropDesc, svcCropLink,
introText,
howto1, howto1d, howto2, howto2d, howto3, howto3d,
secHowto, secHowtoAll, secFaq, secFaqAll,
secBoard, secBoardAll, secBlog, secBlogAll,
secNews, secNewsMore,
sbMagazine, sbTags, sbTagMore, sbTagLess, sbGuide,
guide1Title, guide1Desc, guideStatus,
guide2Title, guide2Desc,
sbCredit, creditExchange, creditGen, creditDl, creditTotal,
creditOld, creditNew, creditBonus
```

**반드시 유지할 키:**
```
유지 대상:
login, loginGoogle, loginKakao, loginLine, loginClose  (로그인 모달)
chatPlaceholder, chatHint, chatWelcome, chatTitle      (챗봇 모달)
consentTexts 전체                                       (동의 모달)
```

### 2-2. applyLang() 코드 정리

제거된 키에 대응하는 DOM 조작 코드를 `applyLang()`에서 제거:

- `.hero-tag` innerHTML 조작
- `.btn-shoot` textContent 조작
- `.n-links a` forEach (텍스트 + href)
- `.intro-text` innerHTML 조작
- `.svc.live/.svc.free` 내부 h3/p/link 조작
- `.howto` forEach (h4/p)
- `#sec-howto/faq/board/blog` h2/a 조작
- `#sb-magazine/sb-tags` textContent
- `#sbTagToggle` textContent + onclick 재바인딩
- `#sb-guide` textContent
- `#guide1/2-title/desc/status` textContent
- `#sb-credit` textContent
- `#credit-*` 7개 textContent

**유지할 applyLang() 코드:**
- `.lang-sw button` 활성화 토글 (언어 버튼 하이라이트)
- `#headerLoginBtn`, `#loginModalTitle` 등 로그인 모달
- `#cbInput` placeholder 등 챗봇 모달
- consent 모달
- `#loginLineBtn` display 토글 (region 기반)
- `document.documentElement.lang` 설정

### 2-3. navHrefs 객체 제거

`applyLang()` 내 `navHrefs` 객체와 nav href 매핑 코드도 제거 (SSR nav 블록이 언어별 href를 직접 렌더링하므로).

### 2-4. setLang() 검증

`setLang()` 함수의 `window.location.href = '/?lang=...'` 리다이렉트 경로가 SSR 블록 렌더링과 정상 연동되는지 확인. 변경 불필요해야 하지만, 만약 i18n 키 제거 후 깜빡임이 발생하면 보고.

## 3. 통합 검증 체크리스트

### 3-1. 언어별 렌더링 (3개 언어 × 전체 블록)

| URL | 확인 항목 |
|-----|-----------|
| `/?lang=ko` (또는 `/`) | 전 블록 한국어 정상 |
| `/?lang=ja` | 전 블록 일본어 정상 |
| `/?lang=en` | 전 블록 영어 정상 |

### 3-2. 기능 동작

| 기능 | 확인 |
|------|------|
| CTA 버튼 (.btn-shoot) 클릭 | getCtaUrl() 이동 |
| 서비스 카드 (.svc.live) 클릭 | getCtaUrl() 이동 |
| 크롭앱 카드 (.svc.free) 클릭 | /crop 이동 |
| 로그인 버튼 | 모달 열기 |
| 크레딧 뱃지 | 크레딧샵 모달 열기 |
| 챗봇 FAB | 챗봇 모달 열기 |
| 언어 전환 (KO→JA→EN) | 리다이렉트 + SSR 정상 |
| FAQ 프리뷰 카드 클릭 | /faq#앵커 이동 + 자동 열기 |
| nav 링크 전체 | 각 페이지 정상 이동 |

### 3-3. 어드민

| 기능 | 확인 |
|------|------|
| /admin/ 대시보드 | Home Layout 카드 표시 |
| /admin/layout.html | 14개 블록 로드 |
| 블록 편집 모달 | 텍스트 수정 → 저장 → 홈 반영 |
| 블록 표시 토글 | visible:false → 홈에서 미표시 |

### 3-4. fallback

| 상황 | 예상 동작 |
|------|-----------|
| layout 문서 없음 | 기존 하드코딩 HTML 유지 |
| layout 문서 일부 블록 누락 | 해당 블록만 하드코딩 유지 |

## 4. 배포

검증 완료 후:
1. `deploy.sh dev` → dev 환경 배포
2. 작가님 확인 요청
3. 승인 시 `deploy.sh prod` → prod 배포

## 5. 유의 사항

⚠️ **i18n.js 키 제거는 SSR 렌더링(#2) 확인 후에만 실행**: SSR이 정상 동작하지 않는 상태에서 키를 제거하면 텍스트가 사라짐
⚠️ **제거 전 3개 언어 모두 테스트**: SSR이 ko/ja/en 전부 정상 렌더링하는지 확인 후 제거
⚠️ **헌법 제1조 1항**: 타임스탬프 `date` 취득
⚠️ **헌법 제2조 1항**: 완료 보고 필수
⚠️ **배포는 작가님 승인 후**: dev 배포 후 보고 → 작가님 확인 → prod 승인
