# i18n 섹션 타이틀 인덱스 기반 매핑 버그 수정

**[2026-03-22 23:28 KST] M1/쌍아 → 막내(any)**

---

## 1. 현상

메인 페이지(`monkos.ai`)에서 섹션 타이틀이 한 칸씩 밀려서 표시됨:

| 섹션 콘텐츠 | 기대 타이틀 | 실제 표시 타이틀 |
|------------|-----------|---------------|
| FAQ (Q&A) | 자주 묻는 질문 | **최근 블로그** |
| 블로그 포스트 | 최근 블로그 | **업계 소식** |

## 2. 원인

`monkos_AI/portal/public/js/i18n.js` 241~254행 — `applyLang()`이 `.sec-h` 요소를 **DOM 인덱스 순서**로 순회하며 타이틀을 덮어씌움:

```js
// 현재 코드 (버그)
var secData = [
  { h: t.secHowto, a: t.secHowtoAll },   // [0] → 활용법 ✓
  { h: t.secBlog, a: t.secBlogAll },      // [1] → FAQ에 적용 ✗
  { h: t.secNews, a: t.secNewsMore }      // [2] → 게시판 or 블로그에 적용 ✗
];
secHeaders.forEach(function(sh, i) { ... });
```

HTML `.sec-h`는 4개 (활용법 → FAQ → 게시판 → 블로그), secData는 3개 → 인덱스 불일치.
추가로 SSR(`home.js:170-174`)이 게시글 없으면 게시판 섹션을 제거 → 인덱스 추가 틀어짐.

**applyLang() 섹션 헤더 부분 교체 (line 240~254):**

기존 forEach 인덱스 매핑을 **제거**하고, ID 기반 개별 적용으로 교체:

```js
// 섹션 헤더 (ID 기반 — SSR 섹션 제거에 영향받지 않음)
var secMap = {
  'sec-howto': { h: t.secHowto, a: t.secHowtoAll },
  'sec-faq':   { h: t.secFaq,   a: t.secFaqAll },
  'sec-board': { h: t.secBoard, a: t.secBoardAll },
  'sec-blog':  { h: t.secBlog,  a: t.secBlogAll }
};
Object.keys(secMap).forEach(function(id) {
  var el = document.getElementById(id);
  if (el) {
    var h2 = el.querySelector('h2');
    var a = el.querySelector('a');
    if (h2) h2.textContent = secMap[id].h;
    if (a) a.textContent = secMap[id].a;
  }
});
```

### 3-3. `monkos_AI/portal/lib/cms/home.js` — regex 패턴에 id 속성 반영

**line 134-136** (블로그 카드 교체):
```
기존: /(최근 블로그<\/h2>...)/
수정: /(최근 블로그<\/h2>...)/ — id 추가 후에도 h2 텍스트 매칭이라 변경 불필요
```

**line 147** (FAQ 프리뷰):
```
기존: /(<div class="faq-list" id="faqPreview">)...(<\/div>\n\n\s*<div class="sec-h"><h2>고객 게시판)/
수정: /(<div class="faq-list" id="faqPreview">)...(<\/div>\n\n\s*<div class="sec-h" id="sec-board"><h2>고객 게시판)/
```

**line 166** (게시판 프리뷰 — 있을 때):
```
기존: /(<div class="board-preview" id="boardPreview">)...(<\/div>\n\n\s*<div class="sec-h"><h2>최근 블로그)/
수정: /(<div class="board-preview" id="boardPreview">)...(<\/div>\n\n\s*<div class="sec-h" id="sec-blog"><h2>최근 블로그)/
```

**line 172** (게시판 프리뷰 — 없을 때, 섹션 제거):
```
기존: /\s*<div class="sec-h"><h2>고객 게시판<\/h2>...(\s*<div class="sec-h"><h2>최근 블로그)/
수정: /\s*<div class="sec-h" id="sec-board"><h2>고객 게시판<\/h2>...(\s*<div class="sec-h" id="sec-blog"><h2>최근 블로그)/
```

> **주의**: regex에서 `id="sec-board"` 등이 추가되므로 공백·순서 정확히 맞출 것. 수정 전 기존 regex가 실제 HTML과 매칭되는지 확인 필수.

## 4. 수정 제외 (건드리지 말 것)

- `secNews` / `secNewsMore` 키: 현재 HTML에 "업계 소식" 섹션이 별도로 존재하지 않음. i18n 키만 유지하고 DOM 적용은 하지 않음 (향후 섹션 추가 대비)
- FAQ 콘텐츠, 블로그 콘텐츠 자체는 건드리지 않음 — 타이틀만 수정
