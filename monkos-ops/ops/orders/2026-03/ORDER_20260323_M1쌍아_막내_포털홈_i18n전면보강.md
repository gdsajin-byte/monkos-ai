### 2-1. `monkos_AI/portal/lib/cms/home.js` — SSR 언어 필터 보강

**(A) FAQ 프리뷰 (line 139~150) — lang 필터 추가**

현재:
```js
const faqSnap = await firestore.collection('faq').orderBy('order', 'asc').limit(3).get()
```

수정:
```js
const faqSnap = await firestore.collection('faq')
  .where('lang', '==', lang)
  .orderBy('order', 'asc')
  .limit(3)
  .get()
  .catch(() => ({ docs: [] }));
```

> `lang` 변수는 line 84에서 이미 `reqUrl.searchParams.get('lang') || 'ko'`로 취득 중.

**(B) 태그 (line 118~127) — allPosts → displayPosts 전환**

현재:
```js
for (const p of allPosts) for (const t of (p.tags || [])) tagMap[t] = ...
```

수정:
```js
for (const p of displayPosts) for (const t of (p.tags || [])) tagMap[t] = ...
```

> `displayPosts`는 line 86~88에서 이미 언어 필터링된 상태.

**(C) 매거진 regex (line 113) — 한국어 '매거진'·'태그' 하드코딩**

// 수정
