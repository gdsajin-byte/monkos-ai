## Task 3: 정본 위치 정합성 검증

ch4 4조 정본 테이블 기준으로 각 문서 유형이 정본 위치에 있는지 검증.

### 3-1. 검증 항목

| 유형 | 정본 위치 | 검증 방법 |
|------|----------|----------|
| 지시서 (ORDER_) | `ops/orders/YYYY-MM/` | 루트에 잔류 파일 없는지 (막내1이 이동 후) |
| 보고서 (REPORT_, COMPLETION_) | `ops/reports/YYYY-MM/` | 루트에 잔류 파일 없는지 (막내1이 이동 후) |
| 세션 로그 | `ops/sessions/YYYY-MM/` | 루트에 잔류 파일 없는지 (막내1이 이동 후) |
| 기안서 (PROPOSAL_) | `ops/proposals/` | 현재 flat 구조 — 전부 있는지 확인 |
| 기술 스펙 (SPEC_) | `tech/specs/` | 다른 위치에 산재 없는지 |
| 설계 (DESIGN_) | `tech/designs/` | 다른 위치에 산재 없는지 |
| 청구안 (PETITION_) | `governance/constitution/petitions/` | 전부 있는지 |

### 3-2. SPEC 산재 확인

```bash
# ops/reports/ 안에 SPEC 파일이 있는지
find monkos-ops/ops/reports/ -name "SPEC_*"
# docs/ 안에 최근(3월) SPEC이 있는지
find docs/ -name "SPEC_*" -newer monkos-ops/ops/sessions/2026-03/2026-03-01_M1_쌍아.md
```

### 3-3. 검증 결과 보고

정합성 검증 결과를 완료 보고에 테이블로 포함:

```markdown
| 유형 | 정본 위치 | 건수 | 이탈 건수 | 이탈 파일 |
```
