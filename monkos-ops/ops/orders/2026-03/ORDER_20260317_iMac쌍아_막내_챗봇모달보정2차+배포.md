# 지시서: 챗봇 모달 보정 2차 — 작가님 피드백 반영

## Task 1: FAB 버튼 위치 (데스크탑)

- 현행: `right: max(24px, calc((100vw - 1280px) / 2 + 24px))` → 아직 컨테이너 바깥 느낌
- 변경: 메인 콘텐츠 컨테이너(`max-width: 1280px`) **안쪽**에 위치하도록 보정
- 모바일과 동일한 느낌으로 — 콘텐츠 우측 가장자리 기준

## Task 2: 모달 헤더 색감 톤다운

- 현행: `linear-gradient(135deg, var(--accent), var(--accent-l))` → 전체 감성 대비 채도가 높고 뜨는 느낌
- 변경: **채도 낮추고 명도 어둡게** — 차분한 딥 퍼플 톤
  - 예: `linear-gradient(135deg, #4a1d96, #5b2da8)` 또는 `hsl(268, 60%, 30%)` ~ `hsl(268, 55%, 38%)` 범위
- FAB 버튼 · 모달 헤더 · 보내기 버튼 등 보라색 계열 요소들이 자연스러운 그라데이션으로 연결되도록 배치

## Task 3: 입력 placeholder 수정 (미적용 건)

- **현재 배포판 확인**: placeholder가 여전히 "MONKOS AI에게 질문하세요 — 증명사진, 규격, 크롭, 가격 등" 상태
- **변경**: `"MONKOS AI에게 질문하세요"` — 뒤 설명("— 증명사진, 규격, 크롭, 가격 등") 완전 삭제
- 대상: `monkos_AI/portal/public/index.html` 내 `<textarea>` 또는 `<input>` placeholder 속성
- `chat.js`에서 동적으로 세팅하는 경우도 확인하여 수정
