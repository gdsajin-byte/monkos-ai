# 지시서: CS_SYSTEM_PROMPT JP 가격 현행화 + 카카오 보너스 추가

**[2026-03-09 22:37 KST] M1/쌍아 → 막내2**

## 배경

Telegram CS봇의 `CS_SYSTEM_PROMPT`에 JP 가격이 구 USD 체계(`$10/$25/$40`)로 잔존.
JP 고객이 Telegram CS로 가격 문의 시 존재하지 않는 달러 가격 안내 위험.
추가로 카카오 채널 보너스 40c(텔레그램과 택1)가 누락되어 KR 고객 안내 불가.

## 수정 대상

### 파일: `monkos_AI/portal/lib/prompts.js`

### 수정 1: `CS_SYSTEM_PROMPT` 내 `[クレジットシステム]` — JP 가격 교체

#### 현재 (구형):
```
- 購入（韓国）: 10c/₩1,450 | 80c(70+ボーナス10)/₩9,900（📸1枚パック） | 130c(100+ボーナス30)/₩12,900 | 420c(300+ボーナス120)/₩34,900（おすすめ） | 750c(500+ボーナス250)/₩49,900
- 購入（グローバル）: 10c/$10 | 30c/$25 | 50c/$40
- 決済: Toss Payments（韓国）/ Lemon Squeezy（グローバル）
```

#### 변경 후:
```
- 購入（韓国・Toss Payments）:
  · 📸 1枚パック: ₩9,900 (70c + ボーナス10c = 80c)
  · 10c チャージ: ₩1,450
  · 130c パッケージ: ₩12,900 (100c + ボーナス30c)
  · 420c パッケージ: ₩34,900 (300c + ボーナス120c) — おすすめ
  · 750c パッケージ: ₩49,900 (500c + ボーナス250c)
- 購入（日本・Lemon Squeezy）:
  · 📸 1枚分: ¥990 (70c + ボーナス10c = 80c)
  · 10c チャージ: ¥150
  · 130c パッケージ: ¥1,490 (100c + ボーナス30c)
  · 420c パッケージ: ¥3,990 (300c + ボーナス120c) — おすすめ
  · 750c パッケージ: ¥5,990 (500c + ボーナス250c)
- 決済: Toss Payments（韓国）/ Lemon Squeezy（日本・グローバル、カード・PayPal・Apple Pay・Google Pay）
```

### 수정 2: `CS_SYSTEM_PROMPT` 내 `[クレジットシステム]` — 카카오 보너스 추가

#### 현재:
```
- Telegramボーナス: @monkos_event_bot経由でチャンネル登録すると40クレジット（1回限定）
```

#### 변경 후 (텔레그램 라인 바로 아래에 추가):
```
- Telegramボーナス: @monkos_event_bot経由でチャンネル登録すると40クレジット（1回限定）
- カカオチャンネルボーナス: カカオチャンネル友達追加で40クレジット（Telegramと択一、1回限定）
```

### 수정 3: `[よくある問い合わせ]` 4번 — 로그인 안내 현행 확인

현재 기재:
```
4. 「ログインできない」→ カカオ(韓国)、LINE(日本)、Googleアカウントに対応。
```
→ ✅ 이미 현행과 일치. 수정 불필요.
