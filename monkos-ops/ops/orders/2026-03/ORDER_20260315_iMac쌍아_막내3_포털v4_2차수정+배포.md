## 수정 2: 갤러리 슬라이드 비율 조정 — 세로형으로 변경

현재 `min-width: 90px; height: 115px`인데 이미지가 가로형이라 얼굴 눈 위로만 보임. 1차 수정에서 `object-position: top`으로 헤드 쪽으로 잘랐으나 비율 자체가 부족.

**현재** (`portal.css`):
```css
.gi {
  min-width: 90px; height: 115px;
  ...
}
```

**수정:** 컨테이너를 키워서 증명사진 비율에 맞춤
```css
.gi {
  min-width: 120px; height: 160px;  /* 3:4 비율 */
  ...
}
```

또는 1:1도 고려:
```css
.gi {
  min-width: 130px; height: 130px;  /* 1:1 비율 */
  ...
}
```

**판단 기준:** 슬라이드 이미지 원본 비율 확인 후 3:4 우선 적용. 모바일에서도 자연스러운지 확인.
