# 지시서: JP 현실 난이도 정리 + 애프터서비스 리서치

> **[2026-03-10 20:51 KST] M1/쌍아 → 막내4**

## 목적

JP 서비스에서 **현 시점 현실적으로 동작하지 않거나 구현 난이도가 높은 기능**을 식별하고, 당장 제거/숨김 처리해야 할 항목과 유지할 항목을 분류하라. 추가로 KR/JP 애프터서비스(고객 지원) 체계의 현황과 개선점을 조사하라.

## 조사 범위

### 1. JP 미구현/미검증 기능 전수 조사

JP 코드와 페이지에서 선언만 되고 실제 E2E 동작 확인이 안 된 기능:

| 카테고리 | 조사 항목 |
|----------|----------|
| **이벤트** | telegram_join, kakao_channel_add, mission_complete, sns_share, passport_rejection — 각각 JP에서 실제 트리거 가능한지 |
| **카카오** | JP에 카카오 관련 코드 잔재 여부 (카카오는 KR 전용) |
| **텔레그램** | JP에서 텔레그램 이벤트 봇 연동 상태 — 실제 가입 검증 가능한지 |
| **LINE 이벤트** | LINE 채널 추가 보너스 — 구현 상태 |
| **공유 보너스** | JP에서 SNS 공유 → 크레딧 지급 경로가 존재하는지 |
| **재다운로드** | GCS에 저장은 됨 — 재다운로드 API/UI 존재 여부 |
| **추가 크롭** | thankyou에서 다른 규격 크롭 — JP에서 동작하는지 |
| **챗봇** | idphoto-jp 채널 챗봇 — Portal 연동 정상 여부 |
| **프리뷰** | prep 페이지 — JP에서 의미 있는지 (촬영 준비 가이드) |

### 2. JP 페이지/UI에서 제거/숨김 검토 대상

thankyou.html 사무실 세션에서 일부 정리됨. 아직 남아있는 것:

- 이벤트 카드: 어떤 이벤트가 표시되고 있는지, 실제 동작하는 것만 남기기 위한 목록
- index.html: 기능 소개 섹션에 미구현 기능이 나열돼 있는지
- charge.html: JP 전용으로 적합하지 않은 내용
- 로그인 모달: "카카오 로그인" 버튼이 JP에 노출되는지
