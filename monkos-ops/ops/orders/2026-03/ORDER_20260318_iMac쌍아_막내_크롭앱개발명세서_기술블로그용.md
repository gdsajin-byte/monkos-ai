### B. 아키텍처 진화 서술

3단계 진화를 **문제→해결→결과** 구조로:

1. **v0 — 서버 LLM 크롭** (03-10)
   - Gemini 2.0 Flash로 얼굴 좌표 추출 → cropToSpec
   - 문제: LLM 특성상 픽셀 정밀도 부족, 턱 잘림 빈발

2. **v1 — crop-engine 재설계** (03-11)
   - tfjs-node FaceMesh 478 랜드마크 기반으로 전환 시도
   - 문제: 서버 콜드스타트, 비용, 프라이버시

3. **v2 — 클라이언트 완결** (03-12)
   - MediaPipe FaceMesh CDN + Canvas 2D
   - 서버 비용 제로, 프라이버시 완전 보호, 레이턴시 최소

### C. 기술 상세

#### 핵심 기술
- **얼굴 감지**: MediaPipe Face Mesh (478 랜드마크)
- **정수리 추산**: 눈~턱 1:1 반전 (디폴트)
- **크롭 엔진**: Canvas 2D API (원본 해상도 유지, 300dpi)
- **색상 판정**: ICAO 규격 기반 3단계 (녹색/노랑/레드)

#### 규격 데이터
```javascript
SPECS = {
  passport: { wMm: 35, hMm: 45, faceMin: 32, faceMax: 36, pxW: 413, pxH: 531 },
  id:       { wMm: 30, hMm: 40, faceMin: 24, faceMax: 32, pxW: 354, pxH: 472 }
}
```

#### 다운로드 차단 로직
- 레드 구간 1개 이상 → 다운로드 버튼 비활성화
- 노랑 → 경고 + 활성화
- 전체 녹색 → 즉시 다운로드

#### 파일 구조
```
portal/public/crop/
├── index.html    # UI 레이아웃 + SVG 오버레이
├── crop.js       # 비즈니스 로직 (FaceMesh, 판정, Canvas)
└── crop.css      # 화이트 테마
```
