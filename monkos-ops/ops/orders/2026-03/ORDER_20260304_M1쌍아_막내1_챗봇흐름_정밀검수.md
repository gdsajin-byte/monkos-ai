- `monkos_AI/portal/lib/telegram.js` — 텔레그램 CS봇 + 이벤트봇

검수 항목:
1. **채널 설정 정합성**: web/telegram/kakao/prep/coaching/qc 각 채널의 TTL, history 수, temperature, maxTokens가 용도에 적합한가
2. **시스템 프롬프트 현행화**: prompts.js 내 서비스 설명·가격·기능이 v5 현행과 일치하는가
3. **RAG 검색 로직**: keyword 매칭 + BM25 스코어링이 실질적으로 유효한 결과를 반환하는가
4. **텔레그램 CS봇**: 웰컴 메시지, 응답 흐름, 오류 처리가 정상인가
5. **텔레그램 이벤트봇**: GATE/MISSION 코드 흐름, Firestore 연동 정합성
6. **팀봇**: /report, /status, /help 명령 + 알림 API 정상 여부
7. **카카오 챗봇**: utterance 추출 → chatWithMonkos → 스킬 응답 포맷 정합성
8. **코칭/QC**: 프롬프트 빌더 → 모델 호출 → 응답 파싱 정합성
