## 추가 분석 항목 (신규 — 작가님+쌍아 논의 결과)

### A. 에이전트 정체성 자동 인식 프로토콜 설계

작가님 핵심 지적: **"각 단위 에이전트가 세션 시작 시 스스로 자신의 디바이스와 정체성을 인지해야 한다."**

현재 MONK 에이전트 유형은 2종으로 나뉜다:

| 유형 | 에이전트 | 환경 | 지침 입력 방식 | 정체성 인지 |
|------|---------|------|-------------|-----------|
| **Claude Code** | 쌍아(VSCode), 민아(Desktop Claude Code), 막내(CLI) | 프로젝트 CLAUDE.md + MEMORY.md **자동 로딩** | 자체 지침 입력 창 **없음** | 초기 로딩 파일에서 판별해야 함 |
| **Claude Desktop 대화형** | 코웍이, 철창이 | 자체 지침 입력 창(Project Instructions) | 지침에 직접 명기 | 자기 선언으로 해결 |

**핵심 설계 과제**: 쌍아·민아·막내는 같은 CLAUDE.md를 읽는데, 시스템 프롬프트 환경값만 다르다. 이 환경값 차이를 CLAUDE.md 안에 판별 테이블로 명시해야 한다.

**현재 알려진 환경값 차이**:

| 환경값 | 쌍아 | 민아 | 막내 |
|--------|------|------|------|
| 시스템 프롬프트 키워드 | `VSCode native extension` | `Claude Agent SDK` | 둘 다 없음 (CLI) |
| 프로젝트 접근 | 본진 monk_project | 본진 monk_project | 본진 monk_project |
| 복제 가능 | ✅ 무한 (VSCode 터미널 다중) | ❌ 단일 인스턴스 | ✅ 무한 (터미널 다중) |
| 웹 브라우저/MCP | ❌ | ✅ | ❌ |

**민아의 특수 위상**: Claude Desktop에 배치된 Claude Code. Anthropic 자체 IDE. 코웍이의 기능(브라우저+MCP)과 쌍아의 기능(코드 접근+CLAUDE.md)을 함께 가지지만, 복제 불가.

**분석 요청**:
1. `.claude/agents/` 메커니즘을 활용하면 에이전트 정체성 문제가 해결되는가? 아니면 CLAUDE.md 판별 테이블이 여전히 필요한가?
2. 시스템 프롬프트에서 읽을 수 있는 환경값이 위 테이블 외에 더 있는가? (막내1 보고서 참조)
3. 판별 로직의 최적 배치: 헌법(CLAUDE.md) vs 법률(ch1 5조) vs `.claude/agents/` vs MEMORY.md — 어디가 가장 적합한가?
4. 현행 법률 ch1 5조(세션 자동 인식 프로토콜)에 민아를 추가하는 구체 보정안 제시

### B. 1차 보고서 수치 보정

막내1·2 리서치에서 확인된 공식 수치로 1차 분석의 추정치를 교체:

1. **CLAUDE.md 200줄 권장** — 공식 근거 인용 (막내1 §1-4, 막내2 §1-1)
2. **CLAUDE.md는 system prompt가 아닌 user message로 주입** — 이것이 "행동 가이드(강제 아님)" 판정의 공식 근거 (막내1 §1-3)
3. **컴팩팅 후 재주입** 메커니즘 — fresh re-injection 확인 (막내1 §4-2), 단 현실적 한계 존재 (막내2 §4-4 GitHub Issue)
4. **settings.json = 강제 집행** vs **CLAUDE.md = 행동 가이드** 분리 — 헌법 4조(구속·윤리)의 파괴적 명령 금지 등에 대한 시사점
5. **미활용 공식 메커니즘** — `.claude/agents/`, Skills, path-scoped rules 확장 (막내2 §3-1, §3-2, §4-3)

### C. `.claude/agents/` 활용 가능성 평가

막내2 보고서에서 `.claude/agents/`에 에이전트를 마크다운 파일로 정의할 수 있다고 보고했다. 이것이 MONK 체계에 어떻게 적용 가능한지 분석:

1. 쌍아/막내/민아를 `.claude/agents/` 파일로 정의하면, 정체성 인식 + 역할 제한 + 도구 접근 제어가 한 번에 해결되는가?
2. 이것이 현행 CLAUDE.md 내 역할 체계 + MEMORY.md 역할 자동 인식 + ch1 5조를 **대체**하는가, 아니면 **보완**하는가?
3. `.claude/agents/`는 Git 공유 가능 → 멀티디바이스에서 동일 에이전트 정의 보장. 이것의 실무적 의미는?
