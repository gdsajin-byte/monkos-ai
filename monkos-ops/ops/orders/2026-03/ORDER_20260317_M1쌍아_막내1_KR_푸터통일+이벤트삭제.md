# idphoto-kr — 푸터 통일 + 이벤트/배지 전체 삭제

## 배경
- 포탈과 idphoto 푸터가 불일치 → idphoto-kr 기준으로 통일 (전화번호/호스팅 제거)
- 여권사진 발급보장 배지: 삭제 확정
- 오픈 이벤트 배너: 삭제 확정
- 신뢰 배지 섹션: 통째 삭제 (첫 로그인 안내는 히어로+가격카드에서 충분)
- 이벤트는 앱 밖에서 처리. 앱 내 고정 이벤트는 첫 로그인 10c만 유지

## 대상 파일
- `monkos_AI/idphoto-kr/public/index.html`

### 1-5. 히어로 서브 "발급 보장" 문구 삭제
- 위치: ~L701
```html
<!-- 삭제 대상 -->
<p class="hero-sub">여권 · 신분증 발급 보장</p>
```
- 히어로 서브를 삭제하거나, 발급보장이 아닌 다른 문구로 교체
- 교체 제안: `<p class="hero-sub">사진관 품질 AI 리터칭</p>` (판단은 작가님 몫 — 우선 삭제)

### 1-6. JSON-LD 발급보장 문구 수정
- 위치: ~L41 (description)
  - `"사진관 품질의 AI 리터칭과 발급 보장."` → `"사진관 품질의 AI 리터칭."`
- 위치: ~L67 (FAQ)
  - `"발급 보장을 제공합니다."` → 해당 FAQ 항목 삭제 또는 수정

### 1-7. mission.js 삭제
- `monkos_AI/idphoto-kr/public/modules/mission.js` (DEPRECATED 사문화 모듈)
- 이 파일을 import하는 곳이 있으면 import도 제거
