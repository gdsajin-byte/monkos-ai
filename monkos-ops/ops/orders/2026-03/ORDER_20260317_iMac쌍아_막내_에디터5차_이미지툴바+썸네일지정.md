# 지시서: 에디터 5차 — 이미지 툴바 + 썸네일 지정 + 태그 접기 + 챗봇 모달 전환

## 배경

현행 블로그 에디터의 이미지 인터랙션 개선. 본문 이미지 클릭 시 바로 삭제 confirm이 뜨는 거친 UX를 플로팅 툴바로 교체하고, 썸네일 수동 지정 기능을 추가한다.

## 대상 파일

- `monkos_AI/portal/public/admin/blog-edit.html` (에디터 UI + JS)
- `monkos_AI/portal/public/css/portal.css` (필요 시 스타일)

## Task 1: 본문 이미지 플로팅 툴바

### 현행
- 본문(WYSIWYG) 내 이미지 클릭 → `confirm("이미지를 삭제하시겠습니까?")` 즉시 발동

### 변경
- 이미지 클릭 → 이미지 상단에 **플로팅 툴바** 생성
- 다른 곳 클릭 시 툴바 사라짐
- 툴바 버튼 2개:
  - **[📌 썸네일 지정]** — 클릭 시 해당 이미지 URL을 좌 사이드바 썸네일 필드에 세팅 + 미리보기 갱신
  - **[🗑 삭제]** — 클릭 시 기존 삭제 로직 실행 (confirm 유지 OK)

### 디자인 가이드
- 툴바: `position: absolute`, 이미지 상단 중앙 정렬
- 배경: `rgba(0,0,0,0.7)`, 둥근 모서리, 패딩 4px 8px
- 버튼: 흰색 텍스트/아이콘, 호버 시 밝기 변화
- 크기: 작고 미니멀 (높이 28~32px)

## Task 2: 이미지 라이브러리 플로팅 툴바

### 현행
- 우측 이미지 라이브러리에서 이미지 클릭 → 본문 커서 위치에 삽입 (드래그로도 가능)
- 각 이미지에 X 버튼으로 삭제

### 변경
- 이미지 클릭 → 이미지 위에 **플로팅 툴바** 생성
- 툴바 버튼 2개:
  - **[📝 본문 삽입]** — 기존 삽입 로직 (커서 위치에 `<img>` 삽입)
  - **[📌 썸네일 지정]** — 해당 이미지 URL을 썸네일 필드에 세팅 (본문에는 삽입하지 않음)
- 기존 X 삭제 버튼은 그대로 유지 (툴바와 별도)

## Task 3: 썸네일 지정 로직

- 썸네일 지정 시: 좌 사이드바의 `thumbnail` input에 URL 세팅
- 좌 사이드바 썸네일 미리보기 즉시 갱신
- 저장 시 `thumbnail` 필드가 있으면 그 값 사용, 비어있으면 기존 fallback (본문 첫 `<img src>` 자동 추출)
- 썸네일 지정된 이미지에 시각적 표시 (본문 내: 좌상단 📌 배지 또는 보라색 테두리)

## Task 4: 포털 홈 태그 컨테이너 접기

### 대상 파일
- `monkos_AI/portal/public/index.html` (태그 섹션)
- `monkos_AI/portal/public/css/portal.css` (스타일)

### 현행
- 좌하단 태그 컨테이너가 전체 노출 → 너무 길어서 레이아웃을 과도하게 차지

### 변경
- 기본: **4줄**까지만 노출 + `overflow: hidden`
- 4줄 초과 시: 하단에 **"더보기 ▼"** 토글 버튼 표시
- 클릭 시 전체 펼침, 다시 클릭 시 4줄로 접기 ("접기 ▲")
- 태그가 4줄 이하면 토글 버튼 숨김

## Task 5: 포털 챗봇 — 모달 전환 (idphoto 패턴)

### 대상 파일
- `monkos_AI/portal/public/index.html` (chatbot-bar 영역)
- `monkos_AI/portal/public/css/portal.css` (챗봇 스타일)
- `monkos_AI/portal/public/js/chat.js` (챗봇 로직)

### 현행 문제
1. 하단 고정 입력바(`chatbot-bar`)가 항상 노출 → 컨텐츠와 같은 흰색이라 구분 안 됨
2. 모바일에서 스크롤 시 널뜀 (fixed 포지셔닝 + 가상키보드 충돌)

### 변경 — idphoto-kr 챗봇 패턴 참조
- **하단 입력바 제거** → 대신 **플로팅 챗봇 버튼** (우하단, 원형 아이콘)
- 버튼 클릭 → **모달로 올라옴** (배경 `backdrop-filter: blur(4px)` + 반투명 오버레이)
- 모달 내부: 입력창 + 대화 영역 (기존 `chat-modal` 구조 활용)
- 모바일: 모달이 `position: fixed; inset: 0`으로 풀스크린 (스크롤 널뜀 해결)
- 참조 파일: `monkos_AI/idphoto-kr/public/index.html` 의 `logo-chat-trigger` + chatbot 모듈 패턴

### 디자인 가이드
- 플로팅 버튼: 우하단 `bottom: 24px; right: 24px`, 56px 원형, 보라색(`var(--accent)`)
- 아이콘: MONKOS 아이콘 또는 💬 말풍선
- 모달: 기존 `chat-modal` 스타일 재활용 (이미 blur + 둥근 모서리 있음)
