## Part B: 포탈 푸터 보정

### B-1. AI 크롭 링크 제거
- 파일: `monkos_AI/portal/public/index.html`
- 위치: ft-links 섹션

**현재:**
```html
<div class="ft-links">
  <a href="/privacy">개인정보처리방침</a>
  <a href="/terms">이용약관</a>
  <a href="/refund">환불정책</a>
  <a href="https://t.me/monkos_bot">고객센터</a>
  <a href="/crop" class="hl">AI 크롭</a>
</div>
```

**변경:**
```html
<div class="ft-links">
  <a href="/privacy">개인정보처리방침</a>

  <a href="/refund">환불정책</a>
```
