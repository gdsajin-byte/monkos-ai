## Task 1 — mag-card 썸네일 렌더링 수정

### 원인

`lib/cms/home.js` 53행 `magCard()` 함수에서 `p.thumbnail`을 체크하지 않고 항상 gradient + emoji fallback만 사용.

### 수정

`lib/cms/home.js` — `magCard()` 함수:

```js
// AS-IS (53행)
return `...><div class="mag-img" style="background:${GRADIENTS[i % 4]}"><span class="icon">${emoji}</span>${tag}</div>...`;

// TO-BE
const thumbStyle = p.thumbnail
  ? `background:url('${esc(p.thumbnail)}') center/cover no-repeat; background-color:${GRADIENTS[i % 4].match(/#\w+/)?.[0] || '#f0eee8'}`
  : `background:${GRADIENTS[i % 4]}`;
const thumbContent = p.thumbnail ? tag : `<span class="icon">${emoji}</span>${tag}`;

return `...><div class="mag-img" style="${thumbStyle}">${thumbContent}</div>...`;
```

핵심: thumbnail 있으면 이미지 배경, 없으면 기존 gradient. `background-color`로 로드 실패 시 fallback.

## Task 3 — 크롤링 자동번역 연동

### 원인

note.com 크롤링이 JA 원문만 저장. translate.js는 KO→JA/EN만 지원.

### 수정

`lib/cms/translate.js` — JA→KO/EN 프롬프트 추가:

```js
const TRANSLATE_PROMPT = {
  // 기존 (KO 원본용)
  ja: `あなたは韓国語→日本語の...`,
  en: `You are a professional Korean→English...`,

  // 신규 (JA 원본용)
  ja_to_ko: `あなたは日本語→韓国語の専門翻訳者です。...`,
  ja_to_en: `You are a professional Japanese→English translator. ...`,
};
```

`translateAndSaveBlogPost()` 수정 — 원본 언어에 따라 번역 대상 결정:

```js
export async function translateAndSaveBlogPost(slug, originalDoc) {
  const srcLang = originalDoc.lang || 'ko';
  let targetLangs;
  let promptKey;

  if (srcLang === 'ko') {
    targetLangs = ['ja', 'en'];  // 기존
  } else if (srcLang === 'ja') {
    targetLangs = ['ko', 'en'];  // 신규
  } else {
    targetLangs = ['ko', 'ja'];  // EN 원본 (미래용)
  }
  // 각 target에 맞는 프롬프트 사용
}
```

`lib/cms/importer/note.js` — 이관 후 자동번역 호출 추가:

```js
await blogCollection.doc(slug).set(post);
stats.imported++;

// 자동번역 (비동기, 실패해도 이관은 유지)
translateAndSaveBlogPost(slug, post).catch(err => {
  log(`[note.com] 번역 실패: ${title} — ${err.message}`, 'WARNING');
});
```

`lib/cms/importer/naver.js` — 동일하게 이관 후 자동번역 호출 추가.
