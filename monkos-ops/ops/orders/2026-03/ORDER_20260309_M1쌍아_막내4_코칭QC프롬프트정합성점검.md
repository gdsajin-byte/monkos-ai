# 지시서: 코칭/QC/Prep 프롬프트 정합성 점검

**[2026-03-09 22:22 KST] M1/쌍아 → 막내4**

## 배경

촬영 준비(prep), 실시간 코칭(coaching), 품질 검증(qc)은 stateless 또는 경량 stateful 채널로
사용자 경험의 핵심 루프를 구성. 프롬프트가 현행 기능과 정확히 맞는지 점검 필요.

## 대상 채널

| 채널 | 프롬프트 | 유형 | 용도 |
|------|---------|------|------|
| `prep` | `PREP_SYSTEM_PROMPT` | stateful | 촬영 전 준비 코칭 |
| `coaching` | `COACHING_INSTRUCTIONS.id_photo` / `.resume` | stateless | 실시간 카메라 코칭 |
| `qc` | `buildQCInstruction()` 동적 생성 | stateless | AI 생성물 품질 판정 |

## 임무 A: PREP_SYSTEM_PROMPT 점검

### 대상 파일
- `monkos_AI/portal/lib/prompts.js` — `PREP_SYSTEM_PROMPT` (line 188~207)

### 점검 항목
- [ ] "용도 선택 (여권/이력서/학생증 등)" — 실제 v5 옵션과 일치?
  - KR config.js `V5_OPTIONS.format`: `['passport', 'id']`
  - JP config.js 동일
  - 프롬프트에 "학생증" 기재 — 실제로 학생증 규격이 있는지?
- [ ] "한국/일본 증명사진 규격 차이 안내 가능" — 실제 규격 데이터 확인
  - KR: 여권 35x45mm, 증명사진 30x40mm
  - JP: パスポート 35x45mm, 証明写真 30x40mm (동일)
  - 규격이 동일한데 "차이 안내"가 적절한지
- [ ] "사용자 언어에 맞춰 응답 (한국어/일본어/영어)" — prep 채널이 실제로 다국어 사용되는지
  - KR 앱에서만 호출되는지, JP에서도 호출되는지 확인
  - 호출 코드: `monkos_AI/idphoto-kr/public/modules/prep.js` 및 JP 쪽 확인
- [ ] 내부 기술명 노출 없는지
