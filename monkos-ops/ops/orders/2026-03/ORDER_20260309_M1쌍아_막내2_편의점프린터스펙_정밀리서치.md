# 지시서: 일본 편의점 마치코피기(マルチコピー機) 프린터 정밀 스펙 리서치

> **[2026-03-09 07:29 KST] M1/쌍아 → M1/막내2**

---

## 배경

직전 보고서(REPORT_20260309_막내2_일본편의점증명사진_시장분석)에서 편의점 프린터 스펙을 다뤘으나, 모델명 특정이 불완전함:
- 로손/패마: `시샤프 MX-3631DS` 기재 → 2020년 발표 모델. 현행 기종인지 검증 필요
- 세븐일레븐: `후지필름 BI` 제조사만 기재 → **모델명 미특정**

Google Ads 키워드 전략 및 idphoto-jp 편의점 출력 대응 설계의 기반 데이터로, 현행 프린터의 정확한 하드웨어 스펙이 필요함.

---

## 조사 항목

### 1. 세븐일레븐 마치코피기
- **현행 기종 모델명** (후지필름 BI 커스텀 납품 모델 특정)
- 도입 시기 / 세대 구분 (구형↔신형 병존 여부)
- 사진 인쇄 모듈 스펙: 해상도(dpi), 색공간, 인쇄 방식 상세
- 지원 입력 포맷 및 해상도 제한 (최소/최대 px)
- 파일 사이즈 제한
- 사진 용지 규격 (두께, 광택도, 재질)

### 2. 로손/패밀리마트/미니스톱 마치코피기
- **현행 기종 모델명 검증** (MX-3631DS가 현행인지, 후속 모델 존재 여부)
- 도입 시기 / 세대 구분
- 사진 인쇄 모듈 스펙: 해상도(dpi), 색공간, 인쇄 방식 상세
- 지원 입력 포맷 및 해상도 제한
- 파일 사이즈 제한
- 사진 용지 규격

### 3. 일본 인화지 규격 체계 정밀 조사
- **L판(L判)과 R 규격(3R/4R/5R)의 관계** 정확히 정리
  - L判 = 89×127mm는 3R(3.5×5inch)과 동일한가?
  - 2L判 = 127×178mm는 5R과 동일한가?
  - KG判과 4R(4×6inch)의 관계
- **편의점 프린터가 실제로 사용하는 인화지 규격명과 물리적 사이즈**
  - 체인별 "L판"으로 표기되는 용지의 실제 mm/inch 사이즈
  - 인화지 재단 규격이 L判인지 R 규격 기반인지
  - 포토용지 제조사 및 제품 스펙 (가능한 범위)
- 일본 사진 업계 표준 규격표 (JIS 등 공식 규격 존재 여부)

### 4. 체인별 차이 비교 테이블
- 세븐 vs 로손 vs 패마 vs 미니스톱: 동일 기종인지 체인별 커스텀 차이 존재 여부
- 사진 출력 품질 차이에 대한 유저 평가/비교 리뷰

### 5. 우리 앱(idphoto-jp) 호환성 검증
- 현재 출력 스펙(300dpi, JPEG 0.92, 413×531px 단일 / L판 레이아웃 시 1,051×1,500px)이 각 프린터의 입력 조건을 충족하는지 판정
- 충족하지 않는 항목이 있으면 필요 보정 사항 명시
