## 배경

레몬스퀴지 가맹점 심사 12일째 무응답. 글로벌(일본) 결제 라인 확보 차질 발생.
토스페이먼츠 해외카드(VISA/MASTER/JCB) + PayPal 추가 계약으로 일부 커버 가능하나,
**일본 로컬 결제수단(편의점 결제, PayPay)은 토스 미지원** 확인됨.

일본 취활 시즌 타겟(대학생) 특성상 신용카드 미보유 비율이 높아,
편의점 결제·PayPay 미지원 시 결제 전환율 급락 우려.

→ **KOMOJU(코모주)**를 일본 로컬 결제 솔루션으로 대안 검토.

## 조사 항목

### A. 개요 및 계약
1. 계정 생성 절차 (Sandbox 접근 조건 포함)
2. Live 전환 시 필요 서류 목록 (한국 사업자 기준)
3. 심사 예상 기간 (결제수단별: 카드, PayPay, 편의점)
4. 한국 법인/개인사업자 계약 가능 여부 확인
5. 정산 통화 및 정산 주기 (한국 은행 계좌 수령 가능 여부)

### B. 기술 연동
1. API 구조 (REST/SDK/Widget 등)
2. Node.js SDK 존재 여부 및 버전
3. Google Cloud Run 환경 호환성
4. Webhook 콜백 구조
5. 테스트(Sandbox) 환경 제공 범위
6. 기존 토스페이먼츠 연동 코드와의 변환 가능성 평가

### C. 지원 결제수단 (일본)
1. 편의점 결제 (コンビニ決済): 지원 편의점 목록, 결제 한도, 수수료
2. PayPay: 연동 방식, 수수료, 정산 주기
3. 신용카드 (JCB/VISA/MASTER): 3D Secure 지원 여부
4. 기타 일본 로컬 결제수단 (LINE Pay, 메루페이 등)

### D. 수수료 체계
1. 결제수단별 수수료율
2. 월정액/초기비용 유무
3. 환율 수수료 구조
4. 정산 시 차감 항목

### E. 리스크
1. 서비스 안정성 (SLA, 장애 이력)
2. 한국 사업자 실제 운용 사례 및 레퍼런스
3. 계약 해지 조건 및 정산금 동결 리스크
4. 레몬스퀴지 대비 장단점 비교
