## Phase A: 히어로 배경 교체

### 현황


```html

  <div class="hero-bg"></div>
```

**파일:** `idphoto-kr/public/index.html` — CSS `.hero-bg` (L105-111)

현행:

수정:

현행 `.showcase-grid` 관련 CSS 전체를 아래로 교체:

```css
/* === 쇼케이스 슬라이드 === */
.showcase {
  padding: 32px 0 8px;

  overflow: hidden;
  margin: 0 -20px;     /* 컨테이너 밖까지 확장 */
}
.showcase-track {
  display: flex;
  gap: 12px;
  width: max-content;
  animation: slide 20s linear infinite;
}
@keyframes slide {
  0% { transform: translateX(0); }
  100% { transform: translateX(-50%); }
}
.showcase-card {
  position: relative;
  border-radius: 12px;
  overflow: hidden;
  border: 1px solid var(--border);
  flex-shrink: 0;
  width: 140px;
}
.showcase-card img {
  width: 100%;
  aspect-ratio: 3 / 4;
  object-fit: cover;
  display: block;
}
.showcase-label {
  position: absolute;
  bottom: 0; left: 0; right: 0;
  padding: 24px 8px 10px;
  background: linear-gradient(transparent, rgba(10, 10, 26, 0.9));
  font-size: 0.75rem;
  font-weight: 600;
  color: var(--text-bright);
  text-align: center;
  letter-spacing: 0.3px;
}
```

### 슬라이드 원리
- 원본 4장 + 복제 4장 = 8장을 flex로 나열
- `translateX(-50%)` = 원본 4장 너비만큼 이동 → 복제본 시작점 = 원본 시작점 → 무한 루프
- `animation: slide 20s linear infinite` — JS 불필요, 순수 CSS
- `width: 140px` — 모바일에서 카드 2.5~3장 보이는 크기 (조정 가능)

### 삭제할 CSS
- `.showcase-grid` (grid 레이아웃 → flex 슬라이드로 교체)
- `.showcase-card:active` (슬라이드에서 터치 불필요)
