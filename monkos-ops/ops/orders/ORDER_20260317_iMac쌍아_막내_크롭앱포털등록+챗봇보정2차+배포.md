# 지시서: 크롭앱 포털 `/crop` 등록 + 챗봇 모달 2차 보정

## Part A: 크롭앱 포털 `/crop` 등록

### 배경
크롭앱이 `idphoto-kr`에서 `crop.monkos.ai` 서브도메인으로 운영 중. 이를 포털에 `/crop` 내부 경로로 정식 귀속시킨다.

### Task A-1: 크롭앱 파일 이식

- 소스: `monkos_AI/idphoto-kr/public/crop.html`, `crop.js`, `crop.css`
- 대상: `monkos_AI/portal/public/crop/index.html`, `crop.js`, `crop.css`
- `crop.html` → `crop/index.html`로 이름 변경
- 내부 경로 참조(`./crop.js`, `./crop.css`) 정상 동작 확인
- 외부 리소스(GCS 이미지 등)가 있으면 절대 URL 유지

### Task A-2: server.js `/crop` 라우트 추가

- `monkos_AI/portal/server.js`에 라우트 추가:
  - `/crop` → `public/crop/index.html` 서빙
  - `/crop/*` → `public/crop/` 하위 정적 파일 서빙
- 기존 정적 파일 서빙 패턴 참조 (`/css/`, `/js/` 등)

### Task A-3: 링크 통일

- `monkos_AI/portal/public/index.html`:
  - 서비스 카드 `crop.monkos.ai →` → `/crop →` 변경
  - JSON-LD `"url": "https://crop.monkos.ai"` → `"url": "https://monkos.ai/crop"` 변경
- 푸터: 이미 `/crop`으로 변경됨 (확인만)
- i18n.js: 크롭 관련 텍스트 있으면 링크 변경

### Task A-4: 크롭앱 동작 검증

- `/crop` 접속 시 크롭앱 정상 로드
- 이미지 업로드 → 크롭 → 다운로드 플로우 정상 (서버 전송 없는 클라이언트 전용이므로 별도 API 불필요)

## Part B: 챗봇 모달 2차 보정

### Task B-1: FAB 버튼 위치 (데스크탑)

- 메인 콘텐츠 컨테이너(`max-width: 1280px`) **안쪽** 우하단으로 보정
- 모바일과 동일한 느낌

### Task B-2: 모달 헤더 색감 톤다운

- 현행 보라 그라데이션 → 채도 낮추고 명도 어둡게 (딥 퍼플)
- 예: `linear-gradient(135deg, #4a1d96, #5b2da8)` 범위
- FAB·헤더·보내기 버튼 보라색 계열 자연스러운 그라데이션 연결

### Task B-3: 입력 placeholder 수정

- **반드시 확인**: `index.html` + `chat.js` 양쪽에서 placeholder 검색
- 변경: `"MONKOS AI에게 질문하세요"` (뒤 "— 증명사진, 규격, 크롭, 가격 등" 완전 삭제)
