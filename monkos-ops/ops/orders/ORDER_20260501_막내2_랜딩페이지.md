## 미션

크롭앱의 Step 1(규격 선택) + Step 2(사진 입력) 랜딩 페이지를 구현하라.
다크 HUD 디자인 기반. `apps/crop-app/` 에서 작업.

## Step 1: 규격 선택

### 구조 (국기 나열 ❌ → 용도+국가 드롭다운)

```
[용도 선택]
  여권 | 비자 | 신분증 | 이력서 | 커스텀

[국가 드롭다운]
  🇰🇷 대한민국 ▼  (검색 가능)

[커스터마이즈 입력]  ← "커스텀" 선택 시만 표시
  가로 mm [___]  세로 mm [___]  또는 px 입력
```

- 용도 버튼 → 국가 드롭다운 → 규격 자동 결정
- 150개국 국기를 쭉 나열하지 않음 — 드롭다운 검색으로 깔끔하게
- specs-data-v2.json에서 국가/문서 데이터 로딩

### 규격 컨테이너 (선택 후 팝업)

국가 + 용도 선택하면 **규격 상세 컨테이너**가 열림:

```
┌─────────────────────────────────┐
│ 🇰🇷 대한민국 — 여권                │
│                                 │
│  ┌──────┐  규격: 35×45mm        │
│  │예시  │  출력: 413×531px      │
│  │사진  │  해상도: 300dpi       │
│  │      │  배경: 흰색           │
│  └──────┘  표준: ICAO 9303      │
│                                 │
│  • 얼굴 크기: 32~36mm           │
│  • 눈 위치: 40~48% (최적 43%)   │
│  • AI 보정 금지 ⚠️              │
│                                 │
│  출처: passport.go.kr ↗         │
│                                 │
│        [ 이 규격으로 크롭 → ]    │
└─────────────────────────────────┘
```

- 예시 사진: 규격에 맞는 샘플 (가이드라인 오버레이 포함)
- 공식 출처 링크 (specs-data-v2의 officialSource)
- AI 보정 금지 국가는 경고 표시
- **"이 규격으로 크롭 →"** 승인 버튼 → Step 2로 진행

## Step 2: 사진 입력

### 구조

```
┌─────────────────────────────────┐
│ 🇰🇷 여권 · 35×45mm  (배지)      │
│                                 │
│  ┌─────────────────────────┐    │
│  │                         │    │
│  │   📷 사진 선택 또는 촬영  │    │
│  │                         │    │
│  └─────────────────────────┘    │
│                                 │
│  📋 촬영 팁                      │
│  • 밝은 곳에서 촬영              │
│  • 흰색 또는 단색 배경           │
│  • 모자, 선글라스 금지           │
│  • 정면 응시, 입 다물기          │
│  • 어깨선까지 보이게             │
│  • 그림자 없이 균일한 조명       │
│                                 │
└─────────────────────────────────┘
```

- 사진 선택 (갤러리) + 촬영 (카메라) 버튼 분리
- `<input type="file" accept="image/*" capture="user">` 로 카메라 직접 열기 옵션
- 선택된 규격 정보를 상단 배지로 표시
- 사진 선택 즉시 → FaceMesh 분석 → Step 3(크롭)으로 자동 진행

## 다국어

- navigator.language 기반 한/일/영 분기
- 촬영 팁, 규격 설명, 버튼 텍스트 전부 i18n
- specs-data-v2의 name 필드 활용 (ko/ja/en)
