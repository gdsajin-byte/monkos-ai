## Phase A: 스탠바이 화면 추가

camera.html 진입 시 **카메라 즉시 ON이 아니라** 설명 화면을 먼저 보여주고, "촬영 시작하기" 버튼을 누르면 카메라+코칭 시작.

### A-2. camera.js — 스탠바이 → 세션 전환

현행 `init()` 함수에서 카메라 즉시 시작하는 부분을 분리:

**현행** (init 끝부분):
```javascript
// 카메라 화면 활성화
document.querySelector('#camera-area')?.classList.add('active');
store.step = 1;
// ...
await media.start();
startCoachingLoop();
```

**수정**:
```javascript
// 스탠바이 화면 표시 (카메라는 아직 OFF)
document.querySelector('#standby-screen')?.classList.add('active');

// 시작 버튼 핸들러
document.getElementById('btn-start-camera')?.addEventListener('click', async () => {
    // 스탠바이 숨기기
    document.querySelector('#standby-screen')?.classList.remove('active');

    // 카메라 화면 활성화
    document.querySelector('#camera-area')?.classList.add('active');
    store.step = 1;
    store.stepLabel = TX.step1;
    store.voiceEnabled = (store.coachingMode === 'voice');
    store.coaching = { text: TX.coachingCheck, ready: false, active: true };

    try {
        await media.start();
        startCoachingLoop();
        document.querySelector('#controls')?.classList.add('active');
        Monk.log('촬영실 초기화 완료');
    } catch (err) {
        alert(TX.cameraError);
        Monk.log('카메라 시작 실패: ' + err.message);
    }
});
```

## Phase B: 코칭 오버레이 하단 → 상단 이동

### B-1. CSS 위치 변경

**파일:** `app.css`

현행 (`#coaching-overlay`, L366~L372):
```css
#coaching-overlay {
    position: absolute; bottom: 0; left: 0; right: 0;
    background: linear-gradient(0deg, rgba(0,0,0,0.95) 0%, rgba(0,0,0,0.8) 70%, transparent 100%);
    padding: 40px 20px 20px;
    z-index: 10; display: none;
    transition: opacity 0.3s;
}
```

수정:
```css
#coaching-overlay {
    position: absolute; top: 0; left: 0; right: 0;
    background: linear-gradient(180deg, rgba(0,0,0,0.9) 0%, rgba(0,0,0,0.7) 70%, transparent 100%);
    padding: 12px 16px 32px;
    z-index: 10; display: none;
    transition: opacity 0.3s;
}
```

변경 포인트:
- `bottom: 0` → `top: 0`
- `linear-gradient(0deg, ...)` → `linear-gradient(180deg, ...)` (그라디언트 방향 반전: 위에서 아래로 페이드)
- `padding: 40px 20px 20px` → `padding: 12px 16px 32px` (상단 여백 축소, 하단 페이드 여유)

### B-2. ready 상태 그라디언트도 방향 반전

## 전체 흐름 (변경 후)

```
prep.html → "촬영 시작하기" → camera.html

camera.html:
  ┌─ [스탠바이] ──────────────────────┐
  │  "촬영 준비가 되셨나요?"            │
  │  더미 오벌 + 체크리스트             │
  │  "촬영 시작하기 →" 버튼             │
  └───────────────────────────────────┘
         ↓ 버튼 탭
  ┌─ [세션] ──────────────────────────┐
  │  카메라 ON + 얼굴 가이드            │
  │  ┌ 코칭 (상단) ─────────────────┐  │
  │  │ AI 코치: 고개를 정면으로     │  │
  │  └──────────────────────────────┘  │
  │                                    │
  │     [카메라 피드 + 오벌 가이드]      │
  │                                    │
  │  ready → 3→2→1 → 자동 촬영         │
  └───────────────────────────────────┘
         ↓ 캡처
  result.html
```
