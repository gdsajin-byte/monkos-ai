# 지시서: 챗봇 RAG 지식베이스 갱신 (크레딧 게이트 반영)

## 배경

크레딧 게이트 시스템 구현으로 가격 체계, 이벤트 조건, 비회원 결제 경로가 변경됨. 챗봇 RAG 지식베이스(`cs_knowledge` 컬렉션)의 seed 데이터를 갱신하여 챗봇이 정확한 정보를 응답하도록 함.

## 작업 3: Firestore 시드 실행

seed 파일 수정 후, **실제 Firestore에 반영**해야 챗봇이 신규 정보를 응답함.

```bash
cd monkos_AI/portal && node seed_cs_knowledge.js
```

> 기존 문서를 `set()`으로 덮어쓰므로 안전. `updatedAt` 타임스탬프 갱신됨.
> 서버의 cs_knowledge 캐시 TTL이 10분이므로, 시드 후 최대 10분 이내 반영.
