## 작업

### 1. 지시서 전수 스캔

```bash
grep -rn "gcloud run deploy\|gcloud builds submit\|--region=" monkos-ops/ops/orders/ --include="*.md"
```

### 2. 분류

각 건을 아래 기준으로 분류:

| 분류 | 기준 |
|------|------|
| **위반** | deploy.sh 미경유, gcloud 명령 직접 기재 |
| **경계** | deploy.sh 경유 지시이나 리전을 별도 명시 |
| **정상** | deploy.sh 경유, 리전 미지정 |
| **예외** | pt.monkos.ai 등 deploy.sh 미존재 서비스 |

### 3. 영향 범위 산출

- 위반 건수 / 전체 배포 지시서 건수
- 위반으로 인해 실제 유령 서비스가 생성된 건수
- 현재 잔존 유령 서비스 (4/8 정리 이후 기준)

### 4. 개정안 적용 시 영향 의견

- 개정안이 기존 운영에 미치는 부작용 여부
- 막내 실행 관점에서 deploy.sh 경유가 더 편한지/불편한지
- 추가 보완 필요 사항
