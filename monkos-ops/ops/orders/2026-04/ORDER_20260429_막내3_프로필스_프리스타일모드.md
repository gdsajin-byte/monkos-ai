# 지시서: 프로필스 프리스타일 모드

**[2026-04-29 15:15 KST] iMac/쌍아 발행 (작가님 구두 지시)**

---

## 배경

프로필스 앱에서 뷰티클로즈업 레퍼런스를 넣고 자유롭게 프롬프트를 써서 이미지를 생성 테스트하려 한다. 현재 코드는 증명사진용 IDENTITY_PRESERVATION 프롬프트가 하드코딩되어 있어 프로필 스타일 실험이 불가.

**목표**: 작가님이 레퍼런스 이미지 + 자유 프롬프트로 바로 테스트할 수 있는 환경 구성.

## 변경 범위

`monkos_AI/studio/` — 서버 + 프론트 양쪽.

### 1. 백엔드 — buildProfilePrompt 프리스타일 분기

`server.js` `buildProfilePrompt()` (line ~300):

- `body.mode === 'freestyle'`이면 IDENTITY_PRESERVATION 프롬프트 **생략**
- `[CONSTRAINT] Keep the person's face...` 도 생략
- `customPrompt`를 메인 프롬프트로 사용
- 기존 모드(`profile`)는 변경 없이 유지

```javascript
// buildProfilePrompt 마지막 return 부분
if (body.mode === 'freestyle') {
  // 프리스타일: customPrompt가 메인, 증명 프롬프트 없음
  const freeParts = [];
  if (customPrompt) freeParts.push(customPrompt);
  // framing/background/lighting은 유지 (선택사항)
  if (framing) freeParts.push(`[FRAMING] ${PROFILE_FRAMING_MAP[framing] || ''}`);
  if (background) freeParts.push(`[BACKGROUND] ${PROFILE_BG_MAP[background] || ''}`);
  return freeParts.join('\n') || customPrompt || 'Generate a professional portrait photo.';
}
// 기존 프로필 모드
return `${IDENTITY_PRESERVATION}\n\n[IMAGE-TO-IMAGE PROFILE TRANSFORM]\n${parts.join('\n')}`;
```

### 2. 백엔드 — 유저 사진 선택적

`/api/profiles/generate` 엔드포인트 (line ~515):

- `image`가 없어도 에러 안 내고 레퍼런스만으로 생성 가능하게
- 유저 사진 없으면 contentParts에서 "main person" 파트 스킵
- 레퍼런스 이미지만 있으면 그걸로 스타일 참고 생성 (T2I에 가까운 모드)

### 3. 프론트 — 레퍼런스 직접 업로드

`profiles/` UI에 추가:

- **레퍼런스 이미지 업로드 영역** — 드래그&드롭 또는 파일 선택으로 1~5장 업로드 가능
- 업로드된 레퍼런스는 `referenceImages` 배열에 `{ category: 'style', data: base64 }` 형태로 추가
- 기존 샘플 그리드(404 나는)는 그대로 두되, 직접 업로드가 우선

### 4. 프론트 — 모드 토글

- UI 상단에 **"프로필 / 프리스타일"** 토글 추가
- 프리스타일 모드에서는:
  - 유저 사진 업로드 선택적 (없으면 레퍼런스 + 프롬프트만으로 생성)
  - customPrompt 입력란 확대 (현재 1줄 → 여러 줄 textarea)
  - `state.mode = 'freestyle'` → API 요청에 포함

### 5. 프론트 — history-count 버그 수정

`ui-gallery.js:152`:
