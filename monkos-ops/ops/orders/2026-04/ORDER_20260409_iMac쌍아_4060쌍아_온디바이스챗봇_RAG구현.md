## 2. index.html 수정

### 2-1. RAG 검색 함수 추가 (script 블록 상단)

`const API_URL = ...` 줄 바로 위에 추가:

```javascript
// === RAG: 지식 검색 ===
let knowledgeBase = [];
fetch('data/knowledge.json')
  .then(r => r.json())
  .then(data => { knowledgeBase = data; console.log('[RAG] 지식 로드:', data.length + '건'); })
  .catch(() => console.log('[RAG] knowledge.json 없음 — RAG 비활성'));

function searchKnowledge(query) {
  const words = query.toLowerCase().split(/\s+/).filter(w => w.length > 1);
  if (!words.length || !knowledgeBase.length) return [];
  return knowledgeBase
    .map(doc => {
      let score = 0;
      for (const w of words) {
        if (doc.keywords.some(k => k.includes(w) || w.includes(k))) score += 10;
        if (doc.title.toLowerCase().includes(w)) score += 5;
        if (doc.content.toLowerCase().includes(w)) score += 2;
      }
      return { ...doc, score };
    })
    .filter(d => d.score > 0)
    .sort((a, b) => b.score - a.score)
    .slice(0, 3);
}
```

### 2-2. send() 함수 내 RAG 주입

기존:
```javascript
const messages = [
  { role: 'system', content: SYSTEM_PROMPT },
  ...history
];
```

변경:
```javascript
// RAG 검색 → 동적 지식 주입
const ragDocs = searchKnowledge(text);
let ragBlock = '';
if (ragDocs.length > 0) {
  ragBlock = '\n\n[참고 지식 — 아래 내용을 바탕으로 답변하세요]\n' +
    ragDocs.map(d => '## ' + d.title + '\n' + d.content).join('\n\n');
}
const messages = [
  { role: 'system', content: SYSTEM_PROMPT + ragBlock },
  ...history
];
```

## 3. 시스템 프롬프트 응답 규칙 수정

`index.html` 내 `SYSTEM_PROMPT` 하단의 `===== 응답 규칙 =====` 을 아래로 교체:

```
===== 응답 규칙 =====

1. 한국어로 답변. 2~3문장 이내로 간결하게.
2. [참고 지식] 블록이 있으면 해당 내용을 바탕으로 정확하게 답변.
3. [참고 지식]에 없고, 위 도메인 지식(제안서/반박서)에도 없는 내용은:
   "죄송합니다, 해당 내용은 현재 제가 보유한 정보에 없습니다. info@monkos.ai로 문의 부탁드립니다."로 정중히 거절.
4. 미출시·미확정 기능 언급 금지. 현재 가동 중인 것만 답변.
5. 기술적 질문에는 구체적 수치와 증거 포함.
6. 추측하지 마세요. 모르면 모른다고 답변.
```

동일하게 `data/system_prompt.txt`도 같은 내용으로 갱신 (llamafile `--system-prompt-file` 옵션 대비).
