## 리서치 2: React 프레젠테이션 프레임워크 조사

### 후보

| 후보 | 조사 포인트 |
|------|-----------|
| reveal.js + React wrapper | React 통합 수준, iframe 임베드 자유도, 커뮤니티 |
| mdx-deck | MDX 기반 장단점, 인터랙티브 슬라이드 지원 여부 |
| Spectacle (Formidable) | React 네이티브, 커스텀 컴포넌트 자유도 |
| 커스텀 경량 구현 | 12장이면 프레임워크 없이 가능한가? 개발 속도 vs 유지보수 |

### 판단 기준 (우선순위순)

1. **iframe 임베드 자유도** — S12에서 monkos.ai, 크롭앱, 챗봇을 iframe으로 띄울 수 있는가
2. **인터랙티브 슬라이드** — S7 애니메이션, S10 카운트업, S11 화살표 연결 구현 난이도
3. **빌드 속도** — D-6 일정에서 학습 비용 최소화
4. **CF Pages 배포** — 정적 빌드 → CF Pages 즉시 배포 가능한가
5. **키보드/리모컨 네비게이션** — 화살표 키 + WebSocket 외부 제어

### 산출물

- 후보별 비교표 (위 5개 기준으로 ◎/○/△/✕ 평가)
- **추천안 1개 + 근거** (명확하게 하나를 고를 것)
- 추천 프레임워크로 "Hello World" 12슬라이드 뼈대 코드 스니펫 (실행 불필요, 구조만)

## 리서치 3: 라이브 임베드 기술 검증

### 검증 항목

1. **monkos.ai iframe 임베드**
   - `X-Frame-Options` / `Content-Security-Policy frame-ancestors` 현재 설정 확인
   - 임베드 불가 시: CF Workers에서 헤더 수정으로 해결 가능한가
   - 3개국어(KO/EN/JA) 전환 URL 파라미터 존재 여부

2. **크롭앱 FaceMesh 임베드**
   - 크롭앱 현재 배포 URL 및 독립 실행 가능 여부
   - iframe 내 카메라 권한(allow="camera") 동작 여부

3. **RAG 챗봇 임베드**
   - 챗봇 컴포넌트 단독 URL 존재 여부
   - 없으면: 챗봇 API 엔드포인트 + 경량 UI 래핑으로 별도 페이지 만들기 가능한가

4. **증명사진 생성 임베드**
   - API 호출 흐름 (업로드 → 생성 → 결과) 확인
   - 라이브 시연 시 소요 시간 예측

5. **대안 (iframe 불가 시)**
   - 서비스 화면 스크린샷 + 녹화 영상 대체
   - 컴포넌트 직접 포팅 (비용 대비 효과)

### 산출물

- 임베드 가능 여부 매트릭스 (서비스 × 방식)
- 불가 항목의 대안 + 구현 난이도
- S12 슬라이드 구성 최종 추천안
