# 보정 지시서 3차: 보이스 셀렉터 + 연동 확인

**[2026-04-03 14:55 KST] iMac/쌍아 → iMac/막내3**

---

## 문제

작가님 시연 시 "목소리가 그대로" — ElevenLabs가 실제로 동작하고 있는지 불확실. Web Speech API 폴백으로 빠졌을 가능성.

---

## 작업 1: ElevenLabs 연동 디버그

- 콘솔에 ElevenLabs 호출 성공/실패 로그를 **명확하게** 출력
  - 성공 시: `[TTS] ElevenLabs: voice={name}, text={처음20자}...`
  - 실패 시: `[TTS] ElevenLabs FAILED: {에러}, falling back to Web Speech`
- Vite proxy가 정상 동작하는지 확인 (API 키가 proxyReq에 주입되고 있는지)
- 실패 원인 파악 후 수정

---
