## 항목 3: Firestore 빈 DB 삭제

### 사전 체크
- 대상: `monkos-3c6e4` 프로젝트의 `default` DB (us-central1)
- 컬렉션 0개 확인됨 (막내3 조사 완료)
- 정본 `(default)` nam5와 **별개 DB** — 삭제해도 정본 영향 없음
- 되돌림: 불가 (삭제 후 복구 안 됨). 단, 빈 DB이므로 데이터 손실 없음.

### 실행
```bash
# 삭제 전 최종 확인 — 컬렉션 0개인지
curl -s -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  "https://firestore.googleapis.com/v1/projects/monkos-3c6e4/databases/default/documents:listCollectionIds" \
  -X POST -H "Content-Type: application/json" -d '{}'

# 삭제
gcloud firestore databases delete --database=default --project=monkos-3c6e4 --quiet
```

### 사후 검증
```bash
gcloud firestore databases list --project=monkos-3c6e4
# (default) nam5만 남아있어야 함
```

```bash
# 2. Firestore 대응 문서가 있으면 삭제 (REST API)
```

⚠️ UID를 세션 로그에는 기록하되, 보고서에는 마스킹 처리 (4조 1항)

### 4-2. Anonymous 프로바이더 비활성

#### 사전 체크
- 현행 코드에서 signInAnonymously 호출 0건 확인됨 (막내3 조사)
- 비활성해도 서비스 영향 없음

#### 실행
```bash
# REST API로 Anonymous 프로바이더 비활성
curl -s -X PATCH \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  "https://identitytoolkit.googleapis.com/admin/v2/projects/monkos-3c6e4/config?updateMask=signIn.anonymous.enabled" \
  -d '{"signIn":{"anonymous":{"enabled":false}}}'
```

#### 사후 검증
```bash
# Auth 설정 재확인
curl -s -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  "https://identitytoolkit.googleapis.com/admin/v2/projects/monkos-3c6e4/config" | python3 -m json.tool
```

### 사전 체크
- 대상: origin/claude/* 7개 (워크트리 잔재)
- 각 브랜치가 main에 머지되었는지 확인 필수

#### 확인
```bash
for branch in claude/agitated-edison-87c652 claude/elegant-rhodes claude/goofy-dubinsky claude/nervous-jennings claude/serene-knuth claude/wizardly-swartz claude/zealous-ride; do
  echo "=== $branch ==="
  git log main..$branch --oneline 2>/dev/null | head -3
  echo "---"
done
```

- 머지 안 된 커밋이 있으면: 해당 브랜치는 보류 + 보고

#### 실행 (머지 확인된 것만)
