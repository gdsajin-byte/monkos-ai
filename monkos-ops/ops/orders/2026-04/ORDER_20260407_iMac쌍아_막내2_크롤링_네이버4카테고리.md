# 지시서: 크롤링 파이프라인 — 네이버 4카테고리 실행

> **note.com 크롤링은 완료. 네이버 코드는 있으나 실행 0건.**
> 기존 크롤링 코드를 찾아서 네이버 4카테고리를 실행하고 결과를 저장.

---

## 1. 사전 조사

1. 프로젝트 내 네이버 크롤링 관련 코드를 탐색 (scripts/, _saga/, apps/ 등)
2. note.com 크롤링 코드 패턴 확인 → 네이버에 동일 구조 적용
3. 네이버 4카테고리가 무엇인지 기존 문서/코드에서 파악

## 2. 실행

1. 네이버 크롤링 코드가 있으면 그대로 실행
2. 없거나 미완성이면 note.com 패턴 기반으로 구현
3. 4카테고리별 결과를 구조화하여 저장

## 3. 산출물

- 크롤링 결과 데이터 (JSON/MD)
- 실행 로그
- 완료 보고 (✅❌💡⏳📁🔀 형식)

## ⚠️ 준수 조항

- 헌법 4조 4항: 불법/비윤리 자동화 금지. robots.txt 준수
- 헌법 4조 1항: API 키 하드코딩 금지
- 크롤링 결과에 개인정보 포함 시 즉시 삭제
