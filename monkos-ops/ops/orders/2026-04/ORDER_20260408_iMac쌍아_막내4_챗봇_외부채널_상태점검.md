구현은 되어있으나 실운영 검증 기록이 없는 상태.

## 작업

### 1. 코드 기반 채널 조사

server.js 및 관련 파일에서 외부 채널 엔드포인트 전수 조사:

```bash
grep -rn "telegram\|line\|kakao\|webhook\|/api/.*bot" monkos_AI/portal/server.js
grep -rn "telegram\|line\|kakao" monkos_AI/portal/lib/ --include="*.js"
```

각 채널에 대해:
- 엔드포인트 경로
- 인증 방식 (토큰, 시크릿)
- 프롬프트/지식 베이스 (portal과 동일한지, 별도인지)
- 마지막 코드 변경일

### 3. 웹훅 활성 상태 확인

코드에서 웹훅 URL 패턴을 확인하고, 해당 엔드포인트가 prod에서 응답하는지 curl로 테스트:

```bash
# 예시 (실제 경로는 코드에서 확인)
curl -s -o /dev/null -w "%{http_code}" https://monkos.ai/api/telegram/webhook
```

### 4. 팀챗 봇 상태

`MONK_TeamChat` 봇 관련 코드 확인:
- 엔드포인트

- 현재 활성 상태
