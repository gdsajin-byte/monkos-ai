# 지시서 — 우측 사이드바 쇼츠 썸네일 교체

## 0. 목적

우측 사이드바의 가이드 영상 목업(검은 폰 모형 + 가짜 상태바)을 **실제 유튜브 쇼츠 썸네일 카드**로 교체한다.
VideoObject JSON-LD를 추가하여 Google 동영상 카운트에도 잡히게 한다.

## 2. 수정 대상

### 2-1. index.html — 우측 사이드바 (`.right-sb` 내 `.guide-card` 영역)

**현재** (목업):
```html
<div class="guide-card">
  <div class="guide-phone"><!-- 검은 폰 모형 --></div>
  <h4 id="guide1-title">...</h4>
  <p id="guide1-desc">...</p>
</div>
```

### 2-2. portal.css — 썸네일 카드 스타일

기존 `.guide-phone` 관련 CSS를 `.guide-thumb` 스타일로 교체:

```css
.guide-card {
  display: block;
  text-decoration: none;
  color: inherit;
  margin-bottom: 12px;
  border-radius: 12px;
  overflow: hidden;
  transition: box-shadow 0.2s;
}
.guide-card:hover { box-shadow: 0 2px 8px rgba(0,0,0,0.1); }
.guide-thumb {
  width: 100%;
  aspect-ratio: 9/16;
  background-size: cover;
  background-position: center;
  position: relative;
  border-radius: 8px;
}
.play-overlay {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
  width: 32px; height: 32px;
  border-radius: 50%;
  background: rgba(0,0,0,0.5);
  color: white;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 14px;
}
.guide-label { padding: 8px 4px; }
.guide-label h4 { font-size: 11px; font-weight: 600; line-height: 1.4; }
.guide-meta { font-size: 9px; color: var(--ink-l); margin-top: 2px; }
```

기존 `.guide-phone`, `.guide-phone .dot`, `.guide-phone .bar` 등 목업 CSS는 삭제 가능.

### 2-5. home.js — SSR 동기화

home.js에서 우측 사이드바를 SSR로 렌더하는 부분이 있다면, 동일하게 썸네일 카드로 교체. 
목업 HTML을 생성하는 코드가 있으면 위 카드 HTML로 대체.

## 3. 검증

```bash
# 로컬
cd monkos_AI/portal && node server.js
# 우측 사이드바에 썸네일 2개 표시 확인
# 클릭 → 유튜브 이동 확인
# JSON-LD VideoObject 존재 확인
curl -s http://localhost:8080/ | grep -c 'VideoObject'
```
