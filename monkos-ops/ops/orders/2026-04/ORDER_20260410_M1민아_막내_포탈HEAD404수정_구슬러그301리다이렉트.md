## 건 1: HEAD 요청 전면 404 [P0 — 오가닉 색인의 직접 차단 원인]

### 현상

```
GET  /blog                → 200 ✅
HEAD /blog                → 404 ❌
GET  /ja/blog/slug        → 200 ✅
HEAD /ja/blog/slug        → 404 ❌
```

**Googlebot은 크롤링 전 HEAD로 상태 확인** → HEAD 404면 "페이지 없음"으로 판정 → 색인 안 함/제거.
monkos.ai의 SSR 전 페이지(블로그, FAQ, 가이드, 프라이싱, 스펙스, 갤러리, 보드)가 영향.

### 원인

`monkos_AI/portal/server.js` L222~260 모든 SSR 라우트가 `req.method === 'GET'`으로만 매칭. HEAD 요청이 폴스루 → 404.

### 수정

**파일**: `monkos_AI/portal/server.js`

SSR 라우트 블록(L221~260) 상단에 HEAD→GET 변환 미들웨어 1줄 추가:

```js
  // === CMS 공개 페이지 (SSR) ===
  // HEAD 요청을 GET으로 처리 — Googlebot HEAD 404 방지 (2026-04-10)
  if (req.method === 'HEAD') req.method = 'GET';
```

이 1줄을 L221 `// === CMS 공개 페이지 (SSR) ===` **바로 아래** (L222 `if ((urlPath === '/' ...` **바로 위**)에 삽입.

> Node.js HTTP 서버에서 HEAD 응답 시 body는 자동으로 전송되지 않으므로 (HTTP 스펙), `req.method = 'GET'`으로 바꿔도 응답 body가 클라이언트에 전달되지 않음. 안전한 패턴.

### 검증

```bash
# 수정 후 로컬 서버에서:
curl -sI http://localhost:{PORT}/blog -o /dev/null -w '%{http_code}\n'       # 200 확인
curl -sI http://localhost:{PORT}/ja/blog -o /dev/null -w '%{http_code}\n'    # 200 확인
curl -sI http://localhost:{PORT}/faq -o /dev/null -w '%{http_code}\n'        # 200 확인
curl -sI http://localhost:{PORT}/pricing -o /dev/null -w '%{http_code}\n'    # 200 확인
curl -sI http://localhost:{PORT}/guide -o /dev/null -w '%{http_code}\n'      # 200 확인
```

## 건 2: 블로그 구 슬러그 301 리다이렉트 [P1]

### 현상

GSC에서 16개 URL이 404로 보고됨 (유효성 검사 실패 상태). 블로그 슬러그가 vol 넘버링 → 서술형으로 변경되었으나 리다이렉트 미설정.

### 수정

**파일**: `monkos_AI/portal/server.js`

건 1에서 추가한 HEAD 미들웨어 바로 아래, SSR 블로그 라우트 바로 위에 301 리다이렉트 맵 추가:

```js
  // 구 슬러그 → 신규 슬러그 301 리다이렉트 (2026-04-10, GSC 404 해소)
  const blogRedirects = {
    // JA
    '/ja/blog/vol23-qa-5':     '/ja/blog/ai-de-shomei-shashin-geneki-shashinkan-review',
    '/ja/blog/vol22':          '/ja/blog/job-interview-updo-hair-5-steps',
    '/ja/blog/vol21-ai-monkosai': '/ja/blog/20-year-photographer-ai-id-photo-monkos-ai-birth',
    '/ja/blog/vol20-vs':       '/ja/blog/korea-vs-japan-job-photo-hair',
    // EN
    '/en/blog/vol23-qa-5':     '/en/blog/ai-id-photo-review-photography-studio-owner',
    '/en/blog/vol22':          '/en/blog/interview-updo-flight-attendant-hair-5-steps',
    '/en/blog/vol21-ai-monkosai': '/en/blog/ai-id-photo-created-by-a-20-year-photographer-monkos-ai',
    '/en/blog/vol20-vs':       '/en/blog/korean-vs-japanese-job-application-photos-hairstyle',
    '/en/blog/vol19':          '/en/blog/id-photo-job-application-photo-makeup-for-each-skin-tone',
    // KO
    '/blog/vol23-qa-5':        '/blog/vol24-20-ai-monkosai',
  };
  if (blogRedirects[urlPath]) {
    res.writeHead(301, { 'Location': blogRedirects[urlPath] });
    return res.end();
  }
```

> 나머지 GSC 404 중 한국어 슬러그가 /ja/, /en/ 경로에 들어간 건(예: `/ja/blog/증명사진-헤어스타일...`)은 hreflang 잘못 생성이 원인. HEAD 수정 후 자연 해소 예상이므로 리다이렉트 대상에서 제외.

### 검증

```bash
curl -sI http://localhost:{PORT}/ja/blog/vol20-vs -w '%{http_code}\n' | grep -E 'Location|HTTP'
# HTTP/1.1 301 Moved Permanently
# Location: /ja/blog/korea-vs-japan-job-photo-hair
```
