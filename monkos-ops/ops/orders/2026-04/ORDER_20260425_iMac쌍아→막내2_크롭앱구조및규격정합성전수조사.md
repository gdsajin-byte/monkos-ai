# 지시서 — 크롭앱 코드 구조 + 규격 데이터 정합성 전수 조사

## 0. 배경

크롭앱은 현재 여권(3.5×4.5cm)과 반명함(3×4cm) 2종이 하드코딩되어 있다.
specs-data.json에는 26국 규격이 px·mm·DPI 데이터로 완비.
이 26국 규격을 크롭앱 프리셋으로 연결하려면, **현재 크롭앱이 규격을 어떻게 처리하는지** + **specs 데이터와 크롭 로직이 정합하는지** 전수 파악이 선행되어야 한다.

## 1. 조사 범위

### 1-1. 크롭앱 코드 구조 분석

**파일 3개 전문 읽기:**
- `public/crop/index.html` (324줄)
- `public/crop/crop.js` (1,158줄)
- `public/crop/crop.css` (379줄)

**파악 항목:**
- 규격 데이터가 어디에 하드코딩되어 있는지 (변수명, 행 번호, 값)
- 현재 지원 규격 목록 (여권 3.5×4.5, 반명함 3×4 외 더 있는지)
- 크롭 로직 흐름: 사진 업로드 → 얼굴 감지 → 크롭 영역 계산 → 출력
- **정수리 인식 로직**: 정수리(머리 꼭대기) 감지가 구현되어 있는지, 어떤 방식인지 (face-api.js? TensorFlow.js? 자체 로직?)
- 얼굴 랜드마크 기반 크롭 계산 공식 (머리 상단 여백, 턱선 하단 여백, 좌우 중앙 정렬)
- 출력 해상도/DPI 처리 방식
- 규격 전환 UI (드롭다운? 버튼? URL 파라미터?)
- 외부 라이브러리 의존 목록

### 1-2. specs-data.json 26국 데이터 vs 크롭 로직 정합성

specs-data.json의 각 규격에서 크롭앱이 필요로 하는 필드를 매핑:

| specs-data 필드 | 크롭앱 필요 여부 | 비고 |
|----------------|----------------|------|
| size (mm) | ✅ | 출력 물리 사이즈 |
| pixels (px) | ✅ | 출력 해상도 |
| dpi | ✅ | 해상도 계산 |
| headHeight | ✅ | 정수리~턱 비율 |
| background | △ | 배경색 (크롭앱은 배경 제거 안 함?) |

**26국 전수 매핑 표 작성:**
각 규격별로 현재 크롭앱 로직으로 **바로 대응 가능한지** / **별도 세팅이 필요한지** 분류.

### 1-3. 정수리 관련 규정 전수 조사

각 국가별 증명사진 규정에서 **머리(정수리) 관련 세부 규정** 파악:
- 정수리~사진 상단 여백 규정 (mm 또는 비율)
- 얼굴 비율(사진 높이 대비 얼굴 높이) 규정
- 머리 잘림 허용/불허
- 모자/히잡 등 머리 가림 관련 규정
- 이 규정이 specs-data.json에 정확히 반영되어 있는지
