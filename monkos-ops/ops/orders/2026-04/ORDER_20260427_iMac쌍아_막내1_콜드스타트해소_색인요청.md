## 배경

4/27 새벽 실측에서 Cloud Run cold-start가 SEO 색인 실패의 원흉으로 확정됨.

- 1차 요청: monkos.ai **503 에러**, /blog **503**, /gallery TTFB **4.7초**
- 2차 요청(warm): 전 페이지 200 OK, TTFB 0.07~0.67초

## 작업 3: cold-start 해소 실측 검증

재배포 완료 후, 30분 대기 → 아래 검증 실행:

```bash
# 1차: 콜드 상태 시뮬레이션 (30분 무트래픽 후)
for url in https://monkos.ai/ https://monkos.ai/blog https://monkos.ai/gallery https://monkos.ai/specs/korea-passport https://monkos.ai/ja/ https://monkos.ai/en/; do
  echo "--- $url ---"
  curl -sS -o /dev/null -w "HTTP: %{http_code}, TTFB: %{time_starttransfer}s\n" --max-time 15 "$url"
done

# idphoto 서브도메인
for url in https://idphoto-jp.monkos.ai/ https://idphoto-kr.monkos.ai/; do
  echo "--- $url ---"
  curl -sS -o /dev/null -w "HTTP: %{http_code}, TTFB: %{time_starttransfer}s\n" --max-time 15 "$url"
done
```

**합격 기준**: 전 URL HTTP 200, TTFB 3초 이내. 503 발생 시 실패 → 원인 보고.
