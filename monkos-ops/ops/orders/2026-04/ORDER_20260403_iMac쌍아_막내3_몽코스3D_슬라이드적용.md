## 1. 슬라이드 12장 구현

싱크맵의 "화면" 열 기반. 텍스트 슬라이드로 구현 (이미지/캡처는 추후).

| # | 제목 | 핵심 비주얼 |
|---|------|-----------|
| S1 | 표지 | 과제명, 대표명, "이의신청 대면평가" |
| S2 | 3류 분류표 | 8건→3유형 컬러 분류표 (빨강/주황/파랑) |
| S3 | "발색" 오독 | 평가 의견 원문 + 제안서 원문 대비. "Ctrl+F '발색' → 0건" |
| S4 | "편향" 오독 | RLHF 설명 텍스트 + "K-뷰티 = 편향 교정" |
| S5 | GPU 오독 | 2트랙 구조 텍스트 (클라우드=프로덕션, GPU=R&D) |
| S6 | 차별성+빅테크 | 경쟁사 비교표 (Adobe/Runway/Stitch Fix ❌) |
| S7 | 비용 해소 | 타임라인 + "$0.04 → $10, 마진 99.6%" 강조 |
| S8 | 범위 초과 | "R&D ≠ 투자심사" 큰 텍스트 + 크롤링 반박 |
| S9 | 반박 종합 | S2 표 재등장 + "한 가지 더 보여드릴 것이 있습니다" |
| S10 | 실적 비교 | 비포/애프터 대비표 (프로토→6개, 0→1,421커밋 등) |
| S11 | AX 매핑 ★ | 디딤돌 지적 → AX 필수과제 매핑표 (킬링 포인트) |
| S12 | 시연+클로징 | "디딤돌은 이미 달리고 있는 연구의 발판입니다" |

### 스타일 가이드

- 배경: #0a0a0a (다크)
- 텍스트: #fff, 강조: #a78bfa (몽코스 색), 위험: #ef4444 (빨강), 경고: #f59e0b (주황), 정보: #3b82f6 (파랑)
- 표는 HTML/CSS로 직접 구현 (깔끔하게)
- 슬라이드 제목은 상단 좌측, 큰 폰트
- S2 분류표의 3색 코딩은 S3~S8에서 해당 유형 색상을 헤더에 반영

## 2. TTS 대본 매핑

싱크맵의 "대본" 열 → 각 슬라이드에 TTS 대사 배열로 매핑.

```javascript
// 예시 구조
const slideScripts = {
  0: [ // S1 표지
    "안녕하십니까. 몽크사진관 대표 신정규입니다.",
    "본 소명은 서면평가 의견 8건에 대한 이의입니다.",
    "재평가 보완이 아닌, 해석 오류의 지적임을 먼저 말씀드립니다."
  ],
  1: [ // S2 분류표
    "8건 지적을 분석한 결과, 세 가지 유형으로 분류됩니다.",
    "첫째, 제안서에 없는 내용을 지적한 경우가 2건.",
    "둘째, 기술 구조를 잘못 이해한 경우가 4건.",
    "셋째, R&D 평가 범위를 넘는 판단이 2건입니다.",
    "순서대로 말씀드리겠습니다."
  ],
  // ... 이하 싱크맵 전체 대본 반영
};
```

- 슬라이드 전환 시 해당 대본을 순차 TTS 발화
- 몽코스가 말하는 동안 립싱크 + 적절한 액션 (시선, 가리키기 등)

---

## 3. 몽코스 액션 싱크

슬라이드별로 몽코스의 행동을 자연스럽게 배치:

| 슬라이드 | 몽코스 액션 |
|---------|-----------|
| S1 | 정면 응시 + 가벼운 바운스 (인사) |
| S2 | 슬라이드 쪽 시선 + 가리키기 |
| S3~S8 | 슬라이드 쪽 시선 (설명 중), 강조 시 정면 전환 |
| S9 | 정면 + 멈춤 → "한 가지 더" 때 바운스 |
| S10 | 슬라이드 쪽 가리키기 |
| S11 | ★ 킬링포인트 — 정면 응시 고정 |
| S12 | 가벼운 좌우 이동 + 바운스 (마무리) |

- 세션 로그 기록 (헌법 3조 2항)
