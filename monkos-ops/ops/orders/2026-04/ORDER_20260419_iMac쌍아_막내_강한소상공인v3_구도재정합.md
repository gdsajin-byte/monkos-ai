## 분석 관점 — 단순 비교가 아닌 3축 정합

### 축 1: 서식 정합 (서식 요구 vs Docs 현재)

서식 원본의 9개 구분 × 세부 요구사항 vs Docs 현재 구조를 1:1 매핑:

```
서식 구분 → Docs 어디에 해당하는가?
서식 세부 요구 → Docs에 있는가 / 빠졌는가 / 과잉인가?
서식 구분명·제목 → Docs 제목과 일치하는가?
```

### 축 2: 작가님 의도 정합

작가님이 서식 재편을 지시한 이유는 **서식 원본의 흐름을 따르되 내용은 업버전하려는 것**:
- "서식 원본 그대로 하라" = **구분명·제목·세부항목의 존재와 순서**를 서식에 맞춰라
- ≠ 내용을 서식 예시 수준으로 축소하라
- ≠ 구조를 재발명하라

따라서:
- §3-1 작가님 수동 작성 → 보존 (이동 가능하나 내용 변경 금지)
- §2 3블록 재편 (시장성/경쟁력/서비스) → 서식 원본 구조와 일치하므로 유지
- 유닛이코노믹스 §5-1 이동 → 이것이 맞는 배치인지 서식 관점에서 판단

### 축 3: 완성도 정합

10페이지 사업계획서로서의 완성도:
- **배점 가중치**: 성장성 50점(최대) > 사업성 40점 > 사업적합도 10점
- **60% 탈락선**: 각 대분류 배점의 60% 미만이면 종합점수 무관 탈락
- 분량 배분: 배점 가중치에 비례해야 함
- 심사위원 관점: "이 기업이 성장할 수 있는가"가 핵심 질문
