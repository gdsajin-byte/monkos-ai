# 지시서: 프로필스 3컬럼 재배치 + 마스터 레퍼런스 구조

**[2026-04-29 16:37 KST] iMac/쌍아 발행 (작가님 설계)**

---

## 배경

프로필스 UI를 기안서 퍼널(갤러리 → 스택 → 생성)에 맞게 3컬럼 재배치한다.
동시에 레퍼런스 프롬프트를 "마스터 + 파트별 오버라이드" 구조로 전환한다.

---

## A. UI 재배치

### 좌측 사이드바 — 카테고리 탭

현재 좌측에 있는 사진업로드/성별/용도/트리밍/배경/생성버튼을 **카테고리 탭 네비게이션**으로 교체.

```
좌측 사이드바:
├── 용도 (장르) — LinkedIn / SNS / 기업 / 매칭앱 / 아티스트 / 연사
├── ── 구분선 ──
├── 헤어       ← 탭 클릭 시 중앙에 헤어 레퍼런스 그리드
├── 패션       ← 탭 클릭 시 중앙에 패션 레퍼런스 그리드
├── 메이크업   ← 탭 클릭 시 중앙에 메이크업 레퍼런스 그리드
└── 배경       ← 탭 클릭 시 중앙에 배경 레퍼런스 그리드
```

- **트리밍 제거** — 마스터 레퍼런스의 프레이밍에 종속
- **성별**: 용도 아래 또는 우측 사이드바에 간소하게 배치 (칩 2개)
- 좌측 탭은 **하이라이트 표시** — 현재 선택된 카테고리, 해당 카테고리에 레퍼런스가 스택에 있으면 뱃지/도트

### 중앙 워크스페이스 — 레퍼런스 갤러리

현재 Before/After 패널 + 하단 스타일 샘플을 **레퍼런스 갤러리**로 교체.

```
중앙 워크스페이스:
├── 상단: 결과 프리뷰 (생성 후 표시, 생성 전에는 숨김 또는 작게)
└── 메인: 레퍼런스 그리드
    ├── 좌측 탭에서 선택한 카테고리의 레퍼런스 이미지 그리드
    ├── 각 카드: 썸네일 + 간단 라벨
    ├── 클릭 → 우측 스택에 추가
    └── 드래그&드롭으로 직접 업로드한 이미지도 그리드에 임시 추가 가능
```

- 기본 상태(카테고리 미선택 시): "마스터" 그리드 표시 — 전체 무드 레퍼런스
- 좌측에서 헤어/패션/메이크업/배경 탭 누르면 해당 카테고리 그리드로 전환
- 현재 샘플 이미지는 404 상태이므로 **직접 업로드 영역을 각 카테고리 그리드 상단에 배치** (파일 선택 또는 드래그&드롭)

### 우측 사이드바 — 스택 + 생성

현재 우측의 레퍼런스/태깅/히스토리 탭을 **스택 중심**으로 재구성.

```
우측 사이드바:
├── 1행: 내 사진 업로드 (좌측에서 이동)
│   ├── 드래그&드롭 / 파일선택
│   └── 업로드 후 썸네일 표시 + "다른 사진" 버튼
├── ── 구분선 ──
├── 2행: 마스터 레퍼런스 (첫 번째 선택이 자동으로 마스터)
│   └── 썸네일 + "마스터" 뱃지 + 삭제 버튼
├── 3행~: 파트별 오버라이드 (선택적)
│   ├── [패션] 썸네일 + 삭제
│   ├── [헤어] 썸네일 + 삭제
│   ├── [메이크업] 썸네일 + 삭제
│   └── [배경] 썸네일 + 삭제
├── ── 구분선 ──
├── 성별 (칩 2개: 여성/남성)
├── 모델 선택 (나노바나나2 / Pro)
├── 커스텀 프롬프트 (textarea, 선택적)
└── 생성 버튼 + 비용 표시
```

- 헤더의 모델 선택 드롭다운은 우측 사이드바로 이동
- 생성 버튼도 좌측에서 우측으로 이동 — 스택 확인 후 바로 생성
- **스택 순서가 프롬프트 순서를 결정** — 1:내사진, 2:마스터, 3~:오버라이드

## B. 백엔드 — 마스터 레퍼런스 오버라이드 프롬프트

`server.js`의 `/api/profiles/generate` 엔드포인트 및 프롬프트 빌더 수정.

### 레퍼런스 이미지 역할 정의

```javascript
// contentParts 구성 순서:
// 1. 유저 사진 (있으면)
contentParts.push({ inlineData: { mimeType: 'image/jpeg', data: userPhoto } });
contentParts.push({ text: 'Image 1: This is the subject person. Preserve their face and identity.' });

// 2. 마스터 레퍼런스 (필수)
contentParts.push({ inlineData: { mimeType: 'image/jpeg', data: masterRef } });
contentParts.push({ text: 'Image 2: MASTER REFERENCE. Apply everything from this image — pose, framing, clothing, hair, makeup, background, lighting, and overall mood. This is the target style.' });

// 3. 파트별 오버라이드 (선택적, 있는 것만)
if (fashionRef) {
  contentParts.push({ inlineData: { ... } });
  contentParts.push({ text: 'Image 3: FASHION OVERRIDE. Use this clothing/outfit style INSTEAD of the master reference clothing.' });
}
if (hairRef) {
  contentParts.push({ inlineData: { ... } });
  contentParts.push({ text: 'Image N: HAIR OVERRIDE. Use this hairstyle INSTEAD of the master reference hair.' });
}
if (makeupRef) {
  contentParts.push({ inlineData: { ... } });
  contentParts.push({ text: 'Image N: MAKEUP OVERRIDE. Use this makeup style INSTEAD of the master reference makeup.' });
}
if (backgroundRef) {
  contentParts.push({ inlineData: { ... } });
  contentParts.push({ text: 'Image N: BACKGROUND OVERRIDE. Use this background/setting INSTEAD of the master reference background.' });
}
```

### API 요청 body 변경

프론트에서 보내는 `referenceImages` 배열 구조 변경:

```javascript
// 기존: [{ category: 'style', data: base64 }]
// 변경:
referenceImages: [
  { role: 'master', data: base64 },           // 필수
  { role: 'fashion', data: base64 },          // 선택
  { role: 'hair', data: base64 },             // 선택
  { role: 'makeup', data: base64 },           // 선택
  { role: 'background', data: base64 },       // 선택
]
```

### buildProfilePrompt 수정

- 프리스타일 모드: 마스터 레퍼런스가 있으면 framing/background/lighting 등 텍스트 프리셋 제거 — 마스터 레퍼런스가 모든 것을 담당
- 오버라이드가 있는 파트만 텍스트로 보강 ("Use the fashion override image for clothing")
- `IDENTITY_PRESERVATION` — 프리스타일이면 제거 (기존 로직 유지)
- `customPrompt`는 마지막에 `[ADDITIONAL]`로 추가 (기존 유지)

## 검증

1. 좌측 탭 클릭 → 중앙 그리드 전환 확인
2. 중앙에서 이미지 클릭 → 우측 스택 추가 확인 (첫 선택 = 마스터)
3. 파트별 오버라이드 추가/삭제 확인
4. 내 사진 + 마스터만으로 생성 → 마스터 전체 스타일 적용 확인
5. 내 사진 + 마스터 + 헤어 오버라이드 → 헤어만 교체 확인
6. dev 배포 → 검증 → prod 배포
