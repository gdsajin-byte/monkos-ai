> 26국 specs 연동은 별도 지시서(Phase 1.5-B~G)에서 처리. 본 지시서는 **인프라 준비**에 집중.

## 배경

- Google Play 개발자 계정 등록 완료 (MONKOS AI, 계정 ID: 70112966655193837)
- 크롭앱 오프라인 버전이 `~/Desktop/쌍아/crop-offline/`에 레거시 위치로 존재
- 앱스토어 등재 목적: 검색 생태계 편입 (SEO) + 브랜드 인지도 + 무료 앱 교두보

## 작업 트랙

### T1 — 본진 편입

`~/Desktop/쌍아/crop-offline/` → `monkos_AI/crop-app/` 으로 이관.

```
monkos_AI/crop-app/
├── public/
│   ├── index.html
│   ├── crop.js
│   ├── crop.css
│   ├── mediapipe/          ← FaceMesh WASM+모델 로컬 번들
│   ├── icons/              ← 앱 아이콘 세트 (T3에서 생성)
│   ├── manifest.json       ← T2에서 생성
│   ├── sw.js               ← T2에서 생성
│   ├── monkos-icon.svg
│   ├── favicon-32.png
│   └── apple-touch-icon.png
├── package.json            ← 빌드/난독화 스크립트
└── README.md
```

- Electron 관련 파일(main.js, electron 의존성)은 가져오지 않음
- `crop-offline/start.command`도 제외
- 기존 `monkos_AI/crop-engine/`(서버사이드)는 건드리지 않음

### T2 — PWA 기반 구축

**manifest.json 생성:**

```json
{
  "name": "MONKOS Crop — 증명사진 규격 크롭",
  "short_name": "MONKOS Crop",
  "description": "ICAO 국제 규격 증명사진 자동 크롭 — 오프라인, 무료, 개인정보 보호",
  "start_url": "/index.html",
  "display": "standalone",
  "orientation": "portrait",
  "background_color": "#f5f5f5",
  "theme_color": "#f5f5f5",
  "icons": [
    { "src": "icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "icons/icon-512.png", "sizes": "512x512", "type": "image/png" },
    { "src": "icons/icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ],
  "categories": ["photo", "utilities"],
  "lang": "ko",
  "dir": "ltr"
}
```

**Service Worker (sw.js):**
- 전체 에셋 프리캐시 (HTML, JS, CSS, MediaPipe WASM, 모델, 아이콘)
- 오프라인 완전 동작 보장 (Cache First 전략)
- 버전 관리 (`CACHE_NAME = 'monkos-crop-v1'`)

**index.html 수정:**
- `<link rel="manifest" href="manifest.json">` 추가
- Service Worker 등록 스크립트 추가

### T3 — 아이콘 세트 생성

기존 `monkos-icon.svg` 기반으로:
- `icon-192.png` (192×192)
- `icon-512.png` (512×512)
- `icon-maskable-512.png` (512×512, safe zone 내 여백 포함)
- `favicon-192.png` (기존 것 복사)

sips 또는 rsvg-convert로 SVG → PNG 변환.

### T4 — 다국어 시스템 언어 감지 강화

현재 `localStorage.getItem('monkos_lang') || 'ko'`로 하드코딩 폴백.

변경:
```javascript
const cropLang = localStorage.getItem('monkos_lang')
  || navigator.language?.slice(0, 2)
  || 'ko';
```

- 시스템 언어 자동 감지 (한/일/영 분기)
- 지원 외 언어 → 영어 폴백
- manifest.json의 `lang` 필드도 동적 대응 불필요 (스토어 localization에서 처리)

### T5 — 난독화

`obfuscate.mjs` 참조하여 crop.js 난독화 빌드 추가.

```json
// package.json scripts
{
  "build": "node obfuscate.mjs",
  "build:clean": "node obfuscate.mjs && rm -f public/crop.src.js"
}
```

- 원본 `crop.js` → 난독화 → `public/crop.js` 덮어쓰기
- 개발 시에는 원본 유지, 배포/빌드 시에만 난독화 적용

### T6 — TWA 빌드 준비

**Digital Asset Links (assetlinks.json):**
- `public/.well-known/assetlinks.json` 생성
- TWA 앱 서명 키와 도메인 검증용 (실제 값은 빌드 시 채움)

**Bubblewrap 설정:**
- `twa-manifest.json` 생성 (앱 패키지명, start_url, 아이콘 경로 등)
- 패키지명 제안: `ai.monkos.crop`
- 실제 AAB 빌드는 별도 지시 (Google Play 본인 확인 완료 후)
