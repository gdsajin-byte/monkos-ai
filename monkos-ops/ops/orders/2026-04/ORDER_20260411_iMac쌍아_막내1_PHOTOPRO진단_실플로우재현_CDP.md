## 2. 환경 세팅

### CDP 포트
- **포트 9224 고정 사용** 
  - 9222 = 작가님/쌍아 기본
  - 9223 = iMac 워크트리(민아)
  - 9224 = 빈 포트 (현재 탭 0개)
- 사전 확인: `scripts/tools/cdp_setup.sh status` — 9224가 살아있는지. 죽어있으면 `scripts/tools/cdp_setup.sh start 9224`

### 도구
- **`scripts/tools/cdp_utils.py`** 사용 (Python). `cdp.sh`는 디바이스명 감지 버그 존재 → 금지
- 사용 예:
  ```python
  import sys; sys.path.insert(0, 'scripts/tools')
  from cdp_utils import CDP
  import asyncio
  async def main():
      async with CDP(port=9224) as cdp:
          await cdp.navigate("https://idphoto-kr.monkos.ai/")
          ...
  asyncio.run(main())
  ```
- 스크린샷 저장: `monkos-ops/ops/reports/2026-04/shots_20260411_photopro/`

### 뷰포트
- **데스크탑** (기본) + **모바일** (375x667, iPhone SE/8 기준) 양쪽 재현
- 광고 착지 사용자의 다수는 모바일일 가능성이 높음

### 조건
- **시크릿/새 컨텍스트** 에서 신규 사용자 관점으로 시작
- 느린 네트워크 조건도 1회 측정 (Chrome DevTools Network Throttling "Slow 3G") — 광고 유입 체감
- 쌍아/작가님 계정·쿠키 간섭 금지

## 3. 플로우 체크리스트 (A~F 전수)

각 단계마다 **스크린샷 + 콘솔 에러 + 네트워크 탭 + 로딩 시간** 수집.

### A. 랜딩

1. `https://idphoto-kr.monkos.ai/` 접속
2. 로드 시간 측정: TTFB, FCP, LCP (performance.timing)
3. 첫 화면 스크린샷 (데스크탑 + 모바일)
4. "무엇을 하는 앱인지" 3초 안에 이해되는가?
5. CTA 버튼 명확성 (위치·크기·라벨)
6. 콘솔 에러·404·경고 전수

### B. 로그인 (선택적, UI 노출까지만)

- Google / Kakao / Line / Email 중 어느 것이 제공되나
- 각 로그인 버튼 클릭 시 콘솔·네트워크 에러
- **실제 로그인하지 말 것** — 로그인 UI 노출 스크린샷까지

### C. 사진 업로드·촬영

1. `/prep` 또는 `/camera` 진입
2. 업로드 영역 명확성
3. **샘플 이미지 1장 준비해 업로드**
   - AI 생성 얼굴 이미지 (thispersondoesnotexist.com 등) 또는 본인 아바타
   - **작가님/팀원 개인 사진 금지**
4. `/api/precheck` 호출 → status / 응답시간 / 응답 본문
5. 실패 시 사용자에게 어떤 메시지가 뜨는지 (에러 UX)

### D. 생성 (이미지 AI)

1. 생성 버튼 클릭
2. `/api/idgen` 호출 → status / 응답시간 / 응답 본문
3. 대기 시간 (로딩 인디케이터 유무, 총 소요)
4. 실패 시 사용자 메시지
5. **중요**: 생성이 **실제 성공**하는가 — 꾸가 보고한 "생성 에러"의 실존 여부 교차검증

### E. 결과·저장

1. `/result` 진입
2. 결과 이미지 품질·포맷·크기 (원본 대비 보존율은 평가하지 말 것 — 쌍아 판단 영역)
3. 다운로드 / 저장 버튼 동작
4. 프리미엄·티어 유도 UI 존재 여부 (꾸의 "프리미엄/스탠다드" 용어 매칭)

### F. 결제창 진입

1. `/charge.html` 또는 결제 버튼 클릭
2. 토스 결제창 로딩 (`js.tosspayments.com/v2/standard` SDK 로드 성공)
3. 가격 표시 명확성 (₩ 숫자)
4. 결제 수단 선택 UI까지
5. **실제 결제 완료 금지** — 결제창 로드까지만 스크린샷 후 중단
