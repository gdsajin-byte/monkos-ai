# 프로필스 엔진 연결 — Nano Banana 2 + 프로필 프롬프트 빌더

## 목표

monkos-studio의 server.js에 프로필 사진 생성 엔드포인트를 추가한다.
기존 증명사진 엔진(`/api/idgen`)은 건드리지 않는다.

## 현재 상태

- `POST /api/idgen` — 증명사진 전용, `gemini-3-pro-image-preview` (Nano Banana Pro), `buildPromptV5`
- `GET /profiles` — 프로필스 UI 페이지 (배포 완료, 엔진 미연결)
- 프론트엔드(`profiles/api.js`)가 서버에 보내는 요청 바디:

```javascript
{
  image: "base64...",        // 고객 사진
  mode: "profile",
  model: "nano-banana-2",   // 또는 "nano-banana-pro"
  gender: "f",
  age: "adult",
  purpose: "linkedin",      // 용도
  framing: "headshot",      // 트리밍
  background: "studio-gray",// 배경
  outfit: "suit-navy-w",    // 스타일 샘플 ID (선택)
  hair: "c-curl-bob-f",     // 스타일 샘플 ID (선택)
  pose: "three-quarter-right", // (선택)
  makeup: "natural-minimal",   // (선택)
  customPrompt: "따뜻한 조명, 자연스러운 미소", // 자유 텍스트 (선택)
  lighting: "soft-studio",  // 엔진 자동 매핑
  mood: "clean",            // 엔진 자동 매핑
}
```

## 구현 사항

### 1. 모델 ID 매핑

| 프론트 값 | API 모델 ID |
|----------|------------|
| `nano-banana-2` | `gemini-3.1-flash-image-preview` |
| `nano-banana-pro` | `gemini-3-pro-image-preview` |

### 2. 엔드포인트 추가 — `POST /api/profiles/generate`

server.js에 추가. 기존 `/api/idgen` 코드 패턴을 따르되:

- 모델 ID를 `req.body.model`에 따라 분기 (기본: `gemini-3.1-flash-image-preview`)
- 프롬프트를 `buildProfilePrompt(body)`로 생성 (신규 함수)
- 레퍼런스 이미지가 있으면 `contents[0].parts`에 다중 이미지 추가
- 응답 포맷은 기존과 동일 (`{ image: "data:image/png;base64,..." }`)

### 3. 프로필 프롬프트 빌더 — `buildProfilePrompt(body)`

기존 `buildPromptV5`와 분리된 별도 함수. 구조:

```javascript
function buildProfilePrompt(body) {
  const { gender, framing, background, outfit, hair, pose, makeup,
          lighting, mood, customPrompt } = body;

  const parts = [];

  // 정체성 보존 (증명사진과 동일 원칙)
  // IDENTITY_PRESERVATION 상수 재사용

  // 트리밍
  const FRAMING_MAP = {
    'beauty-closeup': 'Beauty close-up portrait. Face fills 80% of frame, collarbone to forehead.',
    'headshot': 'Professional headshot. Head and shoulders, face centered.',
    'bust': 'Bust shot. Chest to top of head visible.',
    'waist-up': 'Waist-up portrait. Waist to top of head visible.',
  };

  // 배경
  const BG_MAP = {
    'studio-white': 'pure white (#FFFFFF) studio background',
    'studio-gray': 'neutral gray studio background',
    'office': 'modern office interior, soft bokeh background',
    'cafe': 'warm cafe interior, natural light, soft bokeh',
    'outdoor-urban': 'urban street background, shallow depth of field',
    'outdoor-nature': 'natural outdoor setting, soft sunlight, green bokeh',
  };

  // 조명 (엔진 자동 매핑)
  const LIGHTING_MAP = {
    'flat': 'flat even lighting, minimal shadows',
    'soft-studio': 'soft diffused studio lighting, gentle shadows',
    'rembrandt': 'Rembrandt lighting, triangle shadow on cheek',
    'butterfly': 'butterfly lighting, shadow under nose, beauty style',
    'rim': 'rim light on edges, dramatic separation from background',
    'natural': 'natural window light, soft and warm',
    'high-key': 'high-key lighting, bright and airy, minimal shadows',
    'low-key': 'low-key dramatic lighting, dark background, face highlighted',
  };

  // 무드
  const MOOD_MAP = {
    'clean': 'clean natural color grading, minimal post-processing',
    'warm': 'warm golden tones, inviting and friendly feel',
    'cool': 'cool blue-silver tones, sleek and modern',
    'cinematic': 'cinematic color grading, teal and orange, shallow depth',
    'editorial': 'editorial magazine style, high contrast, fashion feel',
    'glamour': 'glamour lighting, skin glow, highlights emphasized',
    'moody': 'moody dark tones, film grain, emotional atmosphere',
    'fresh': 'bright fresh tones, high white balance, airy summer feel',
  };

  parts.push(`[FRAMING] ${FRAMING_MAP[framing] || FRAMING_MAP.headshot}`);
  parts.push(`[BACKGROUND] ${BG_MAP[background] || BG_MAP['studio-white']}`);
  parts.push(`[LIGHTING] ${LIGHTING_MAP[lighting] || LIGHTING_MAP['soft-studio']}`);
  parts.push(`[MOOD] ${MOOD_MAP[mood] || MOOD_MAP.clean}`);

  // 스타일 샘플 선택이 있으면 텍스트 지시 추가
  // (레퍼런스 이미지는 별도로 parts에 inlineData로 추가)
  if (outfit) parts.push(`[OUTFIT] Apply the outfit style from the reference image labeled "outfit". Keep the person's body exactly the same.`);
  if (hair) parts.push(`[HAIR] Apply the hairstyle from the reference image labeled "hair". Keep the face exactly the same.`);
  if (pose) parts.push(`[POSE] Match the pose and angle from the reference image labeled "pose". Keep the person's identity.`);
  if (makeup) parts.push(`[MAKEUP] Apply the makeup style from the reference image labeled "makeup". Subtle and natural.`);

  // 커스텀 프롬프트
  if (customPrompt) parts.push(`[ADDITIONAL] ${customPrompt}`);

  // 제약
  parts.push('[CONSTRAINT] Keep the person\'s face and identity exactly the same — only apply the specified styling.');

  return `${IDENTITY_PRESERVATION}\n\n[IMAGE-TO-IMAGE PROFILE TRANSFORM]\n${parts.join('\n')}`;
}
```

### 4. 다중 레퍼런스 이미지 입력

프론트에서 레퍼런스 슬롯에 있는 이미지를 base64로 보내면, `contents[0].parts`에 추가:

```javascript
const contentParts = [
  // 1. 고객 사진 (메인, 1024px)
  { inlineData: { mimeType: 'image/jpeg', data: customerBase64 } },
  { text: 'This is the main person. Preserve their face 90%.' },
];

// 2. 스타일 레퍼런스 (각 512px)
if (outfitRef) {
  contentParts.push({ inlineData: { mimeType: 'image/jpeg', data: outfitRef } });
  contentParts.push({ text: 'Reference for outfit style only.' });
}
if (hairRef) {
  contentParts.push({ inlineData: { mimeType: 'image/jpeg', data: hairRef } });
  contentParts.push({ text: 'Reference for hair style only.' });
}
// ... pose, makeup 동일 패턴

// 마지막에 프롬프트
contentParts.push({ text: instruction });
```

### 5. 프론트엔드 수정 (`profiles/api.js`)

- 엔드포인트를 `/api/idgen` → `/api/profiles/generate`로 변경
- 레퍼런스 슬롯에 있는 이미지를 base64로 수집하여 body에 포함:

```javascript
body: JSON.stringify({
  ...existingParams,
  referenceImages: [
    { category: 'outfit', data: outfitBase64 },
    { category: 'hair', data: hairBase64 },
  ]
})
```

### 6. aspect ratio

프로필 사진 용도별 기본 비율:

| 용도 | 비율 |
|------|------|
| linkedin | 1:1 |
| sns | 1:1 |
| corporate | 3:4 |
| dating | 3:4 |
| artist | 자유 (프롬프트 따름) |
| speaker | 16:9 |

`generationConfig.imageConfig.aspectRatio`를 용도에 따라 분기.
