### USB 구조 (확정안)

```
USB/ (exFAT 포맷 권장)
├── monkos-chat.exe              # llamafile v0.10.0 (~30MB)
├── model/
│   └── exaone-3.5-2.4b-q4_k_m.gguf  # EXAONE 3.5 2.4B (~1.64GB)
├── data/
│   └── system_prompt.txt        # MONKOS 도메인 지식 + 제안서 전문
├── start.bat                    # Windows 원클릭 실행
├── start.sh                     # Mac 대비용
└── README.txt                   # 실행 방법 (비상용)
```

### start.bat

```bat
@echo off
chcp 65001 >nul
echo.
echo  ==========================================
echo   MONKOS AI - On-Device Chatbot Starting...
echo  ==========================================
echo.
cd /d "%~dp0"
monkos-chat.exe -m model\exaone-3.5-2.4b-q4_k_m.gguf --server --ctx-size 32768 --system-prompt-file data\system_prompt.txt --port 8080 --threads 4
pause
```

### 시연 플로우

```
1. USB 꽂기
2. start.bat 더블클릭
3. SmartScreen 경고 → "추가 정보" → "실행" (2클릭, 사전 연습)
4. 방화벽 팝업 → "허용" (1클릭)
5. 터미널 창에 "listening on 127.0.0.1:8080" 확인
6. 브라우저에서 http://localhost:8080 접속
7. 시스템 프롬프트 자동 로드 확인
8. 시연 질문:
   - "이 과제의 핵심 기술이 뭡니까?"
   - "기존 AI 뷰티 서비스와 차별점은?"
   - "온디바이스로 가능한 이유는?"
```

## 4. 현장 리스크

| 리스크 | 확률 | 심각도 | 대응 |
|--------|------|--------|------|
| **SmartScreen 경고** | 높음 | 낮음 | "추가 정보" → "실행". 사전 연습 필수. "보안 확인 절차"로 자연스럽게 |
| **방화벽 팝업** | 중간 | 낮음 | "허용" 클릭. localhost 루프백이라 대부분 통과 |
| **방화벽 localhost 완전 차단** | 낮음 | 중간 | 대안: `--chat` 플래그로 터미널 CLI 모드 시연 |
| **AVX 미지원 (2011년 이전 CPU)** | 매우 낮음 | 높음 | 정부 PC는 2013년+ i5/i7 대부분. 해당 시 시연 불가 |
| **RAM 부족 (4GB 이하)** | 낮음 | 높음 | 3B Q4 모델은 ~3GB RAM 필요. 4GB PC면 스왑 발생 |
| **USB 2.0 (느린 로딩)** | 중간 | 낮음 | 모델 로딩 2분 소요. "AI 모델을 메모리에 적재 중"으로 설명 |
| **CrowdStrike/EDR 차단** | 낮음 | 높음 | 정부 기관 PC에 설치 가능. 차단 시 대안 없음. 사전 확인 요청 |
| **한국어 응답 품질 미흡** | 낮음 | 중간 | EXAONE이 KoMT 7.24로 검증됨. 시스템 프롬프트로 도메인 고정 |
