# 지시서: 온디바이스 AI 챗봇 — 현장 시연용 리서치

> **상황**: 디딤돌 이의신청 대면평가(4/9). 인터넷 차단 + 노트북 반입 금지. USB 반입 가능, 현장 PC 사용 가능.
> **목표**: USB 하나에 LLM + RAG + UI를 담아 현장 PC에 꽂으면 즉시 가동되는 온디바이스 챗봇 프로토타입.
> **핵심**: 인터넷 없이도 AI가 돌아간다 — 온디바이스 AI의 실물 증명.

---

## 1. 리서치 항목

### A. 모델 선택

| 후보 | 크기 | 특징 | 리서치 포인트 |
|------|------|------|------------|
| DeepSeek R1 3B (GGUF) | ~2GB | 추론 특화, 한국어 가능 | CPU 추론 속도, 한국어 품질 |
| Qwen 2.5 3B (GGUF) | ~2GB | 다국어 강점 | 한국어 품질 비교 |
| Phi-3 Mini 3.8B (GGUF) | ~2.3GB | MS, 추론 강점 | CPU 성능 |
| Gemma 2 2B (GGUF) | ~1.5GB | Google, 경량 | 가장 가벼움, 품질 트레이드오프 |

**평가 기준:**
- 한국어 응답 품질 (제안서/반박서 기반 Q&A)
- CPU only 추론 속도 (GPU 없는 현장 PC 가정)
- GGUF 양자화 후 파일 크기 (USB 용량 고려)
- llama.cpp 호환성

### B. 추론 엔진

| 후보 | 특징 | 리서치 포인트 |
|------|------|------------|
| llama.cpp | C++, CPU 최적화, 포터블 | Windows/Mac 크로스 빌드 가능? |
| ollama | Go, 간편 | 포터블 실행 가능? 설치 불필요? |
| llamafile | 단일 실행파일 (모델+엔진 통합) | USB에 .exe 하나로 끝? |

**핵심**: 현장 PC에 **아무것도 설치하지 않고** USB에서 바로 실행 가능해야 함.
llamafile이 가장 유력 — 모델 가중치 + 추론 엔진이 단일 실행파일로 합쳐짐.

### C. RAG 구성 (오프라인)

| 항목 | 방식 | 리서치 포인트 |
|------|------|------------|
| 벡터 DB | SQLite + numpy (설치 불필요) | 포터블 가능? |
| 임베딩 | all-MiniLM 또는 모델 자체 임베딩 | 오프라인 임베딩 모델 크기 |
| 문서 소스 | 제안서, 반박서, 서비스 설명, FAQ | 사전 벡터화하여 USB에 포함 |

**대안**: RAG 없이 **시스템 프롬프트에 핵심 정보를 직접 주입** (3B 모델의 컨텍스트 윈도우 활용). 문서가 제한적이니 벡터 검색 없이도 가능할 수 있음.

### D. UI

| 후보 | 특징 | 리서치 포인트 |
|------|------|------------|
| llamafile 내장 웹UI | 브라우저에서 localhost 접속 | 추가 설치 불필요 |
| 터미널 CLI | 가장 단순 | 시연 임팩트 부족 |
| 포터블 HTML + WebSocket | 커스텀 UI | MONKOS 브랜딩 가능 |

**추천**: llamafile 내장 웹UI → 브라우저에서 `localhost:8080` 접속. 현장 PC 브라우저만 있으면 됨.

### E. 현장 PC 호환성

| 항목 | 리서치 포인트 |
|------|------------|
| OS | Windows 10/11 가정 (TIPA 현장 PC). Mac도 대비? |
| CPU | Intel i5급 이상 가정. AVX2 지원 여부 |
| RAM | 8GB 이상 가정. 3B 모델 메모리 사용량 |
| USB | USB 3.0 가정. 읽기 속도로 모델 로딩 시간 |
| 방화벽 | localhost 접속 차단 가능성 (현장 보안 정책) |

## 2. PoC 시나리오

### USB 구조 (목표)
```
USB/
├── monkos-chat.exe          # llamafile (모델+엔진 통합) 또는
├── monkos-chat.bat          # 실행 스크립트
├── model/
│   └── deepseek-3b-q4.gguf  # 양자화 모델 (~2GB)
├── data/
│   ├── system_prompt.txt     # MONKOS 도메인 지식
│   ├── proposal.txt          # 제안서 핵심
│   └── rebuttal.txt          # 반박서 핵심
└── README.txt                # 실행 방법
```

### 시연 플로우
```
1. USB 꽂기
2. monkos-chat.exe 더블클릭 (또는 .bat 실행)
3. 브라우저에서 localhost:8080 접속
4. "MONKOS AI 챗봇입니다" 인사
5. 평가위원 질문 → 즉시 답변
   예: "이 과제의 핵심 기술이 뭡니까?"
   → "본 과제의 핵심은 K-뷰티 도메인 특화 자가 진화 파이프라인입니다..."
```
