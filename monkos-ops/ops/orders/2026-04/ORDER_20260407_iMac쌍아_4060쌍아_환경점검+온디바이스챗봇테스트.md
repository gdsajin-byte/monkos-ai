## 1. 환경 점검 (선행 필수)

4060 서버를 한동안 안 들여다봤다. 아래 점검 후 보고.

### 1-1. Tailscale 상태
```bash
tailscale status
# iMac(100.118.x.x)과 핑 가능한지 확인
tailscale ping 100.92.253.45  # iMac IP (확인 필요)
```
- Tailscale 데몬이 꺼져있으면 재시작: `sudo systemctl restart tailscaled`
- 로그인 만료 시 `tailscale up` 재인증

### 1-2. 시스템 상태
```bash
nvidia-smi                    # GPU 상태 + VRAM 확인
df -h                         # 디스크 여유 공간
free -h                       # RAM
uptime                        # 얼마나 오래 켜져있었나
```

### 1-3. CUDA 환경
```bash
nvcc --version 2>/dev/null || echo "CUDA 미설치"
ls /usr/local/cuda/lib64/libcudart* 2>/dev/null || echo "CUDA 런타임 없음"
```
- llamafile은 CUDA 런타임이 있으면 자동으로 GPU 사용
- 없으면 CPU 폴백 (그래도 iMac보다는 빠름)

### 1-4. SSH/네트워크
```bash
# iMac에서 접속 가능하도록 sshd 확인
systemctl status sshd
# 방화벽에 22번, 8080번 포트 열려있는지
sudo ufw status 2>/dev/null || sudo iptables -L -n 2>/dev/null | head -20
```

## 2. 온디바이스 챗봇 수신 + GPU 테스트

### 2-1. 파일 수신
작가님이 메일로 보내신 파일을 `~/monkos-chat/`에 배치:

```
~/monkos-chat/
├── monkos-chat.exe              # llamafile (721MB)
├── model/
│   └── EXAONE-3.5-2.4B-Instruct-Q4_K_M.gguf  (1.5GB)
├── data/
│   └── system_prompt.txt        (6KB)
├── index.html                   (11KB)
├── start.bat                    (Windows용)
└── start.sh                     (Linux/Mac용)
```

### 2-2. GPU 모드 실행
```bash
cd ~/monkos-chat
chmod +x monkos-chat.exe
./monkos-chat.exe -m model/EXAONE-3.5-2.4B-Instruct-Q4_K_M.gguf --server --ctx-size 4096 --port 8080 --threads 4 -ngl 99
```
- `-ngl 99`: GPU에 모든 레이어 오프로드 (핵심 플래그)
- CUDA 감지 시 자동 GPU 사용. 로그에 `using CUDA` 확인

### 2-3. 벤치마크
```bash
# 서버 뜨면 API로 테스트
curl -s http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [{"role":"user","content":"이 과제의 핵심 기술이 뭡니까?"}],
    "max_tokens": 200,
    "temperature": 0.7
  }' | python3 -m json.tool
```

### 2-4. 측정 항목

| 항목 | iMac (참고) | 4060 목표 |
|------|------------|----------|
| 모델 로딩 | 8초 | < 5초 |
| 첫 응답 TTFT | 168초 → 6~8초 | < 3초 |
| 생성 속도 | ~1 tok/s | 30~50 tok/s |
| VRAM 사용량 | N/A | 측정 |
| 한국어 품질 | 5/5 | 동일 확인 |
