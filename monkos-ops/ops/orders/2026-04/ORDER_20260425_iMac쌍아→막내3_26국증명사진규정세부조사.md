# 지시서 — 26국 증명사진 공식 규정 세부 조사

## 0. 배경

크롭앱을 26국 규격으로 확장하려면, 각 국가의 **공식 증명사진 규정**을 정확히 알아야 한다.
specs-data.json에 기본 데이터(사이즈·px·DPI·배경·headHeight)가 있으나,
**크롭 알고리즘에 필요한 세부 규정**(정수리 여백, 얼굴 비율, 턱선 위치 등)이 충분한지 검증 필요.

## 1. 조사 범위

### 1-1. 26국 전수 — 공식 규정 세부 조사

각 국가별로 **공식 출처**(정부 사이트, ICAO 문서, 대사관 안내)에서 아래 항목 조사:

| 조사 항목 | 설명 |
|----------|------|
| **사진 사이즈** | 가로×세로 (mm) |
| **해상도** | px 또는 DPI |
| **배경** | 색상, 균일도 |
| **얼굴 비율** | 사진 높이 대비 얼굴(턱~정수리) 높이 비율 또는 mm |
| **정수리~상단 여백** | mm 또는 비율, 최소/최대 |
| **턱~하단 여백** | mm 또는 비율 |
| **눈 높이** | 사진 하단에서 눈까지 높이 (일부 국가 규정) |
| **머리 잘림** | 허용/불허 (정수리 포함 필수 여부) |
| **어깨 노출** | 필수/권장/무관 |
| **정면 각도** | 허용 오차 (틸트, 로테이션) |
| **모자/히잡** | 종교적 예외 규정 |
| **안경** | 허용/금지 (반사 규정) |
| **특수 규정** | 국가별 고유 요구사항 (미국 2×2인치 정사각형, 중국 적색 배경 옵션 등) |

### 1-2. 26국 목록

한국 5종: passport, resume, halfcard, resident, drivers-license
일본 5종: passport, mynumber, zairyu, resume, halfcard
미국 2종: passport, headshot
유럽 5종: eu-passport, spain-passport, germany-resume, eu-resume, uk-passport
기타 9종: australia, canada, singapore, thailand, india, china-passport, china-resume, vietnam, indonesia

### 1-3. specs-data.json 검증

각 국가 공식 규정과 specs-data.json의 현재 값을 **1:1 대조**:
- size(mm) 일치 여부
- pixels/DPI 정합성 (계산: px = mm × DPI / 25.4)
- headHeight 값이 공식 규정과 일치하는지
- background 설명이 정확한지
- 누락된 중요 규정이 있는지

### 1-4. 크롭 알고리즘 관점 분류

26국을 3그룹으로 분류:

**A그룹 — ICAO 표준 준수 (크롭 로직 공통 적용 가능)**
- ICAO 기본 규격(35×45mm, 얼굴 70~80%)을 따르는 국가

**B그룹 — 사이즈만 다름 (크롭 비율 조정으로 대응)**
- 미국 2×2인치, 중국 33×48mm 등 사이즈만 다르고 비율 규정은 유사

**C그룹 — 특수 규정 (별도 로직 필요)**
- 얼굴 비율·여백·눈 높이 등 고유 규정이 있어 별도 파라미터 필요
