## 수집 대상

### 1. Git 통계
```bash
git log --oneline | wc -l          # 총 커밋 수
git log --format='%aN' | sort -u   # 커밋터 목록
git diff --stat $(git log --reverse --format=%H | head -1) HEAD | tail -1  # 코드 순증가
```
- 총 커밋 수, 코드 순증가 줄수, 최초 커밋 날짜
