# 지시서 — 챗봇 지식 베이스 + 시스템 프롬프트 감사

> **[2026-04-08 15:20 KST]** iMac/쌍아 → iMac/막내1

## 목적

프로덕션 챗봇(monkos.ai `/api/chat`)의 지식 베이스와 시스템 프롬프트가 현재 서비스 상태와 얼마나 괴리되어 있는지 전수 조사한다.

## 작업

### 1. seed_faq.js 전수 분석

`monkos_AI/portal/seed_faq.js` 읽고:
- FAQ 항목 수, 카테고리 분류
- 각 항목의 정보가 현재 서비스와 일치하는지 대조
- 가격/크레딧/기능 설명이 현행과 다른 항목 식별

### 2. 시스템 프롬프트 분석

server.js 내 챗봇 시스템 프롬프트(`/api/chat` 핸들러) 읽고:
- 프롬프트에 명시된 서비스/기능 목록
- 실제 서비스 현황과의 괴리 (4월 기준 신규 기능: specs 26종, 크롭앱, PT 시스템 등)
- "되는 것만 응답" 원칙(헌법 4조 4항) 준수 여부 — 미출시 기능을 안내하고 있진 않은지

### 3. 미반영 서비스 목록

2월 이후 추가/변경된 서비스 중 챗봇 지식에 없는 것:
- specs 26종 규격 페이지
- 크롭앱 (monkos.ai/crop)
- PT 시스템 (pt.monkos.ai)
- 가격 변경 여부
- 다국어 라우팅 변경 (/ja/, /en/)
- 기타 발견 사항

### 4. 외부 채널 프롬프트 정합성

텔레그램/LINE/카카오 채널별 프롬프트가 portal과 동일한지, 아니면 각각 다른지 확인.
