# 지시서 — specs-data.json 오류 판정 정밀 재검증

## 0. 배경

선행 리포트에서 specs-data.json 오류로 판정한 항목 중, **여권과 비자 규격을 혼동**했을 가능성이 지적되었다.

우리 specs-data.json의 슬러그는 `india-passport`, `indonesia-passport` 등 **여권(passport)** 규격이다.
"51×51mm" 같은 규격은 **비자(visa)** 규격일 수 있다. 이 구분이 정확하지 않으면 현행 데이터를 잘못 고치게 된다.

**"우리가 틀렸다"고 하려면 정부 공식 출처 링크 + 여권/비자 구분을 명확히 제시해야 한다.**

## 1. 재검증 대상 4건

### 1-1. india-passport
- **현행**: 35×45mm, 413×531px, 흰색 배경
- **선행 판정**: 51×51mm 정사각형으로 수정 필요
- **의문**: 51×51mm(2×2인치)는 **인도 비자** 규격 아닌가? 인도 **여권**은 ICAO 35×45mm가 맞는 거 아닌가?
- **요구**: 인도 정부 공식 사이트(passportindia.gov.in 또는 mea.gov.in)에서 **여권 전용** 사진 규격 확인. 비자 규격과 명확히 구분.

### 1-2. indonesia-passport
- **현행**: 35×45mm, 흰색 배경
- **선행 판정**: 여권 51×51 적색배경으로 수정 필요
- **의문**: 51×51 적색은 **인도네시아 비자** 규격 아닌가? 인도네시아 **여권**은 ICAO 표준이 맞는 거 아닌가?
- **요구**: 인도네시아 이민국(imigrasi.go.id) 또는 대사관 공식 안내에서 **여권 전용** 사진 규격 확인.

### 1-3. uk-passport
- **현행**: 35×45mm, 413×531px
- **선행 판정**: 최소 600×750px로 수정 필요
- **의문**: 600×750px는 **온라인 디지털 제출** 규격이고, **인화 제출**은 35×45mm/300DPI(=413×531px)가 맞는 거 아닌가?
- **요구**: gov.uk 공식 페이지에서 인화/디지털 각각의 규격 확인.

### 1-4. korea-passport 안경
- **현행**: "안경 착용 가능(렌즈 반사·프레임 주의)"
- **선행 판정**: 2020년부터 전면 금지
- **작가님 확인**: 안경 착용 가능이 맞다
- **요구**: 외교부 또는 여권과 공식 안내 링크로 현행 규정 재확인. **이 건은 현행 데이터가 맞을 가능성 높음.**

## 2. 산출물 형식

각 건에 대해:

```
### [슬러그]
- 공식 출처 URL: (정부/대사관 직링크)
- 해당 페이지의 규격 원문 인용 (영문 또는 현지어)
- 이것이 여권인지 비자인지 명시
- 현행 specs-data.json 값: [값]
- 공식 규정 값: [값]
- 판정: ✅ 현행 정확 / ❌ 현행 오류 (수정값 제시)
- 비고: 인화/디지털 구분이 있다면 명시
```

## 3. 주의

- **정부 공식 사이트 1차 출처 필수**. passport-photo.online 같은 3자 사이트는 교차검증용으로만.
- 공식 사이트 접근 불가 시 "접근 불가, 대안 출처: [URL]"로 명시.
- 추측 판정 금지. 출처 없으면 "미확인" 표기.
