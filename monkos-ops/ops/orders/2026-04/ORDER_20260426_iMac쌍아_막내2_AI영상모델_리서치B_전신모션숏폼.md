# AI 영상 모델 리서치 B — 전신 모션 / 숏폼 생성

> **목적**: 전신 사진 1장으로 모션+립싱크 영상을 생성하는 모델을 조사하고, MONK 디바이스별 구동 가능 여부를 테이블링한다.

## 배경

- 전신 사진 하나로 숏폼/릴스 만드는 앱들이 범용화됨 (HeyGen, Synthesia, Hedra 등)
- 오픈소스/오픈웨이트 대안이 CivitAI, HuggingFace에 올라오고 있음
- MONKOS PT앱에서 캐릭터(실사/캐릭터/동물)가 대본을 읽는 프레젠테이션 → 영상 콘텐츠 파이프라인 구축 목표

## 조사 범위

### 전신 모션 / 댄스 / 제스처
- **사진→영상**: MagicAnimate, Animate Anyone, MimicMotion, MusePose, Champ 등
- **전신 립싱크**: 상반신+손 제스처 포함 립싱크 모델
- **캐릭터 애니메이션**: 비실사(일러스트, 3D, 동물) 지원 모델

### 숏폼/영상 생성 워크플로우
- **ComfyUI 워크플로우**: CivitAI에서 인기 video generation 워크플로우
- **AnimateDiff + ControlNet 조합**: 모션 제어 영상 생성
- **CivitAI 비디오 카테고리**: 인기순 상위 모델/LoRA
