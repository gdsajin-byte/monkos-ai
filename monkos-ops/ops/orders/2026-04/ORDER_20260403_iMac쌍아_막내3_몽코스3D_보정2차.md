## 보정 1: ElevenLabs TTS 연동

Web Speech API → ElevenLabs API로 교체.

### API 정보

- **API 키**: `.env`의 `ELEVENLABS_API_KEY` (Secret Manager에도 등록 완료)
- **엔드포인트**: `https://api.elevenlabs.io/v1/text-to-speech/{voice_id}`
- **응답**: MP3/PCM 오디오 스트림

### 구현 방식

```
1. 대사 텍스트 → ElevenLabs REST API 호출
2. 응답 오디오(MP3) → AudioContext로 디코딩
3. AudioBufferSourceNode로 재생
4. AnalyserNode 연결 → 볼륨 추출 → 립싱크 (이번엔 진짜 오디오 기반)
```

### 보이스 선택

- 먼저 사용 가능한 보이스 목록 조회: `GET /v1/voices`
- 한국어 지원 + 밝고 친근한 톤 우선 (몽코스 캐릭터에 맞게)
- 보이스 ID 확정 후 하드코딩 (보이스 선택은 보고서에 후보 3개 제시)

### 주의사항

- ElevenLabs Starter 플랜: 월 $15 크레딧 (약 2,500분 Base TTS)
- 테스트 시 과도한 호출 자제. 슬라이드 1장씩 테스트
- API 키는 `.env`에서 로딩. 프론트에서 직접 호출하지 말고 **로컬 프록시 서버** 경유 (키 노출 방지)
  - Vite dev server의 proxy 설정 또는 간이 Express 서버

### 폴백

- ElevenLabs 호출 실패 시 Web Speech API로 자동 폴백 (기존 코드 유지)

## 보정 2: 슬라이드 텍스트 시인성 대폭 강화

- **현재 문제**: 텍스트가 너무 작다
- **목표**: 창에 거의 꽉 찰 정도로 크게
- 구체적으로:
  - 슬라이드 제목: **3rem 이상** (현재 대비 2배+)
  - 본문 텍스트: **1.8rem 이상**
  - 표/리스트 항목: **1.4rem 이상**
  - 강조 텍스트 ($0.04, 99.6% 등): **4rem+ 볼드**
  - padding/margin 최소화 → 콘텐츠가 화면을 채우도록
  - S8의 "R&D ≠ 투자심사" 같은 큰 글자 슬라이드: **5rem+ 센터 배치**
