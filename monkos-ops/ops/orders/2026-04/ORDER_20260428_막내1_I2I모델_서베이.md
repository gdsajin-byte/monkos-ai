# I2I 이미지 생성 모델 서베이 — 프로필 사진 서비스용

## 배경

- 현재 monkos-studio는 `gemini-3-pro-image-preview` 단일 모델로 I2I 생성 중
- 나노바나나 2가 이미지 메인 엔진으로 가동 중
- 모델 스왑 아키텍처 도입 예정 → 후보 모델 조사 필요
- **용도**: 증명사진 I2I 보정 + 프로필 사진 생성 + 룩북/패션매거진급 스타일링

## 목표

I2I(Image-to-Image) 가능한 모델들을 폭넓게 조사하고, 우리 서비스 적합성 기준으로 평가한다.

### 조사 범위

**1. 상용 API**
- Google Imagen 4 (Vertex AI)
- OpenAI DALL-E 4 / GPT-Image
- Midjourney API (있다면)
- Recraft
- Ideogram
- Leonardo AI
- 기타 발견 모델

**2. 오픈소스 / 셀프호스팅**
- Flux (Black Forest Labs) — Dev / Pro / Schnell
- Stable Diffusion XL + ControlNet + IP-Adapter
- InstantID / PhotoMaker / IP-Adapter FaceID
- SDXL Turbo / LCM
- Stable Cascade
- 기타 최신 I2I 특화 모델

**3. 특수 목적**
- 가상 피팅 (의상 변경 특화) — IDM-VTON, OOTDiffusion, CatVTON 등
- 헤어스타일 변경 특화 모델
- 메이크업 트랜스퍼 특화 모델
- 배경 교체 특화 (Inpainting)
- 얼굴 복원/향상 — GFPGAN, CodeFormer, RestoreFormer

### 정체성 보존력 평가

- 우리 서비스 핵심은 **"90% 원본 유지 + 10% 향상"**
- 얼굴 구조·피부톤·고유 특징을 유지하면서 스타일링만 변경할 수 있는가
- 이게 안 되면 아무리 품질 좋아도 부적합

### 추가 조사

- 각 모델의 **가상 피팅(Virtual Try-On)** 가능 여부 특별 표기
- Replicate / Hugging Face / RunPod 등 호스팅 플랫폼 가격 비교
- 4060 서버(RTX 4060) 로컬 구동 가능 여부 (VRAM 8GB 기준)
