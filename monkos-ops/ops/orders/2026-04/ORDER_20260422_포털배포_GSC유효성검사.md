## 4. GSC 유효성 검사 요청

배포 검증 완료 후 GSC에서 재크롤 요청:

### 방법 A — URL 검사 도구 (권장)
1. https://search.google.com/search-console?resource_id=sc-domain:monkos.ai
2. 상단 검색창에 영향 URL 입력 (monkos.ai/, monkos.ai/faq 등)
3. "실제 URL 테스트" → "색인 생성 요청"

### 방법 B — CDP로 자동화 (가능하면)
```bash
scripts/tools/cdp.sh navigate "https://search.google.com/search-console/inspect?resource_id=sc-domain%3Amonkos.ai" 0
```
→ URL 입력 → 테스트 → 색인 요청

### 검사 대상 URL
- `https://monkos.ai/`
- `https://monkos.ai/faq`
- `https://monkos.ai/ja/faq`
- `https://monkos.ai/en/faq`
