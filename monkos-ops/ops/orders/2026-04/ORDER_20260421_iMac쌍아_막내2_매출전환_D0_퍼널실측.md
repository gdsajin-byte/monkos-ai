## 2. 실측 항목

### A. 결제 퍼널 전 구간 실측 (CDP)

idphoto-kr + idphoto-jp 각각:

| 단계 | 확인 | 스크린샷 |
|------|------|:---:|
| 랜딩 → 가입 | OAuth 버튼 위치·클릭 수 | ✅ |
| 가입 → 크레딧 잔액 확인 | 신규 가입 시 초기 크레딧 몇 c? | ✅ |
| 크레딧 → 촬영 시도 | 무료 c로 뭘 할 수 있는가 | ✅ |
| 촬영 → 결과물 확인 | 결과물을 보려면 결제가 필요한 시점은? | ✅ |
| 결과물 → 다운로드 | 다운로드 버튼 → 크레딧 부족 → 결제 유도 경로 | ✅ |
| 결제 유도 → 결제창 | 결제 버튼이 존재하는가, 클릭 시 결제창이 뜨는가 | ✅ |

- LINE Pay / Apple Pay 지원 여부
