# 지시서: 이미지 에셋 스키마 설계 + 최적화 방안 보고서

**[2026-03-08 11:45 KST] iMac/쌍아 → 막내2**

## 배경

MONK 프로젝트의 이미지 에셋이 카테고리 구분 없이 축적되고 있다.
앞으로 모델, 배경, 광고, 갤러리 등 대량 에셋이 쌓일 것이므로
**분류 체계(스키마) + 포맷/최적화 전략**을 확정해야 한다.

## Phase A: 현재 이미지 에셋 전수 파악

### 조사 범위
프로젝트 전체에서 이미지 파일 및 이미지 참조를 전수 조사:

1. **로컬 이미지 파일**: 프로젝트 내 모든 이미지 파일 (jpg, png, webp, svg, ico)
   - MONK_kr/ 하위 각 폴더의 images/
   - monkos_AI/idphoto-kr/public/images/
   - monkos_AI/portal/public/
   - 기타 산재된 이미지

2. **외부 참조**: HTML/JS/CSS에서 외부 URL로 로드하는 이미지
   - Unsplash (images.unsplash.com)
   - GCS (storage.googleapis.com)
   - 기타 외부 CDN

3. **GCS 광고 에셋**: monk-ai-images/ads/ 의 현재 이미지 목록 + manifest.json 구조

### 각 이미지에 대해
- 위치 (로컬 경로 / GCS URL / 외부 URL)
- 용도 (히어로, 갤러리, 광고, 아이콘, OG이미지 등)
- 포맷 + 파일 크기
- 로딩 방식 (정적 HTML, JS 동적 로드, manifest 기반)
- 최적화 적용 여부 (lazy loading, decoding async, srcset 등)

## Phase B: 카테고리 스키마 설계

아래 카테고리에 대해 **디렉토리 구조 + 네이밍 규칙 + 메타데이터 스키마** 설계:

### 카테고리 정의

| 카테고리 | 설명 | 변경 빈도 | 예시 |
|----------|------|----------|------|
| **model** | AI 모델 포트폴리오, 룩북 | 낮음 | 민아방 전시용 |
| **background** | 촬영/합성용 배경 | 낮음 | 스튜디오, 자연, 카페 |
| **ad** | 시머링 로테이션 광고, 배너 | 높음 | result.html 대기 광고 |
| **gallery** | 페이지별 쇼케이스 | 중간 | 랜딩 카드, 쇼케이스 그리드 |
| **brand** | 파비콘, 아이콘, OG이미지, 로고 | 매우 낮음 | monkos-icon.svg, favicon-32.png |
| **user** | 사용자 생성 이미지 (증명사진 결과) | N/A | base64, 저장 안 함 |

### 설계 포함 사항
- 폴더 구조 (각 프로젝트 내 images/ 하위)
- 파일 네이밍 규칙 (법률 ch4 문서 규격과 정합성)
- 메타데이터: manifest.json 확장 스키마 (v2)
  - 현재 v1: `{images: [url, ...], rotate, transition, updated, count}`
  - v2 제안: 카테고리, alt, 포맷, 크기, 용도 등 메타데이터 포함

## Phase C: 포맷 + 최적화 방안

### 포맷 전략
아래 포맷별 **용도, 호환성, 압축률, 권장 사용처**를 정리:
- JPEG (현행 주력)
- WebP (hero.webp 이미 사용 중)
- AVIF (차세대)
- SVG (아이콘/로고)
- PNG (투명 배경 필요 시)

### 최적화 기법
각 기법의 **적용 대상, 기대 효과, 구현 복잡도** 평가:
- `<picture>` + `<source>` (WebP 우선, JPG 폴백)
- `srcset` + `sizes` (디바이스별 최적 크기)
- `loading="lazy"` + `decoding="async"` (현재 부분 적용)
- `<link rel="preload">` (히어로/ATF 이미지)
- 이미지 리사이징 기준 (모바일 480px, 데스크톱 800px, 2x 레티나 등)
- Cache-Control 헤더 전략

### 변환 자동화
- cwebp / squoosh-cli 등 빌드타임 변환
- ads_upload.sh에 WebP 자동 변환 통합 가능성
