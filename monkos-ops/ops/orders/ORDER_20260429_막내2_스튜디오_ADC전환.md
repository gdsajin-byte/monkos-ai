# 지시서: 스튜디오 API Key → Vertex AI ADC 전환

**[2026-04-29 12:55 KST] iMac/쌍아 발행 (작가님 지시)**

---

## 배경

스튜디오(`monkos_AI/studio`)는 내부용 서비스. 라이브 증명앱 전에 여기서 먼저 Vertex AI ADC 전환을 검증한다.

현재 스튜디오의 I2I(`/api/idgen`)와 프로필스(`/api/profiles/generate`)는 Google AI Studio API Key + REST 직접 호출(`generativelanguage.googleapis.com`)을 사용 중. 이걸 기존에 이미 초기화되어 있는 `ai` 클라이언트(Vertex AI ADC 모드)로 전환한다.

## 사전 확인 완료 (쌍아 실측)

- `gemini-3-pro-image-preview`, `gemini-3.1-flash-image-preview` 모두 Vertex AI ADC 접근 OK
- 엔드포인트: `aiplatform.googleapis.com` + `locations/us-central1` (스튜디오 기본 LOCATION) — 실측 OK
- Cloud Run SA `monk-image-engine@monkos.iam.gserviceaccount.com`에 `roles/aiplatform.user` 부여 확인

## 변경 범위

`monkos_AI/studio/server.js` 1파일.

### 1. `/api/idgen` (line ~450-523) — REST fetch → SDK

**현재:**
```javascript
const apiKey = GEMINI_API_KEY;
const response = await fetch(
  `https://generativelanguage.googleapis.com/v1beta/models/gemini-3-pro-image-preview:generateContent?key=${apiKey}`,
  { method: 'POST', headers: {...}, body: JSON.stringify({...}) }
);
```

**변경 후:**
```javascript
const response = await ai.models.generateContent({
  model: 'gemini-3-pro-image-preview',
  contents: [{ role: 'user', parts: [
    { inlineData: { mimeType: 'image/jpeg', data: base64Data } },
    { text: instruction },
  ]}],
  config: {
    responseModalities: ['TEXT', 'IMAGE'],
    generationConfig: { imageConfig: { aspectRatio: '3:4' } },
    safetySettings: [
      { category: 'HARM_CATEGORY_HARASSMENT', threshold: 'BLOCK_NONE' },
      { category: 'HARM_CATEGORY_HATE_SPEECH', threshold: 'BLOCK_NONE' },
      { category: 'HARM_CATEGORY_SEXUALLY_EXPLICIT', threshold: 'BLOCK_NONE' },
      { category: 'HARM_CATEGORY_DANGEROUS_CONTENT', threshold: 'BLOCK_NONE' },
    ],
  },
});
```

### 2. `/api/profiles/generate` (line ~526-609) — 동일 패턴 전환

- REST fetch → `ai.models.generateContent()` 사용
- `PROFILE_MODEL_MAP`의 모델 ID 그대로 사용
- `referenceImages` 멀티 이미지 입력 패턴 유지
- `responseModalities: ['TEXT', 'IMAGE']` 필수 추가

### 3. `imagenAI` 클라이언트 제거

- line 52: `const imagenAI = new GoogleGenAI({ apiKey: GEMINI_API_KEY });` — 삭제
- line 55: 관련 로그 삭제
- `GEMINI_API_KEY` 참조 전부 제거 (idgen, profiles 양쪽)
- **단, `GEMINI_API_KEY` 환경변수는 Cloud Run에서 아직 삭제하지 마라** — 검증 완료 후 별도 지시

### 4. `ai` 클라이언트 확인

기존 line 46-50 그대로 사용:
```javascript

  vertexai: true,

```

## 검증 방법

1. 로컬에서 `node server.js` 실행
2. `/api/idgen`에 테스트 이미지 POST → 이미지 생성 확인
3. `/api/profiles/generate`에 테스트 이미지 + 레퍼런스 POST → 이미지 생성 확인
4. 에러 없이 동작하면 `monkos-studio-dev`(dev)에 먼저 배포 → 동일 테스트
5. dev 검증 완료 후 `monkos-studio`(prod) 배포

## 주의사항

- **`responseModalities: ['TEXT', 'IMAGE']` 필수.** 이거 빠지면 텍스트만 반환됨
- SDK `generateContent` 응답 구조가 REST와 다를 수 있음 — `response.candidates[0].content.parts` 접근 패턴 확인
- `@google/genai` SDK 버전 확인: `package.json`에서 현재 버전 확인 후 최신인지 체크
- 증명앱(idphoto-kr/jp)은 **절대 건드리지 마라** — 스튜디오만
