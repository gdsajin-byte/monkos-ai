## 보정 1: 자동 캡처 예고 시퀀스

### 현행 문제
코치가 "촬영하세요!" 발화 → 즉시 `capturePhoto()` 호출 → **너무 갑자기 찍히는 느낌**

### 목표
코치 승인 → **시각적 예고** → 캡처

### 시퀀스
```
코치: "촬영하세요!" (ai-coaching 메시지)
  ↓
가이드 원 초록 전환 + 코칭 뱃지 "촬영합니다!" (ready 상태)
  ↓ 2초 대기
자동 캡처 실행
```

### 구현

**camera.js** — WS `onmessage`에서 `auto-capture` 수신 시:

```javascript
if (msg.type === 'auto-capture') {
  // 예고 시퀀스: 초록 전환 → 2초 후 캡처
  showCoaching('촬영합니다!', true);  // ready=true → 원 초록 + 뱃지 초록
  setTimeout(() => {
    capturePhoto();
  }, 2000);
}
```

- `showCoaching('촬영합니다!', true)` → 가이드 원 초록, 코칭 뱃지 초록, 셔터 초록
- 2초 후 `capturePhoto()` — 사용자가 준비할 시간 확보
- 이 2초 동안 사용자는 자세를 유지하면 됨

## 보정 2: 코칭 텍스트 크기 확대

### 현행 문제
뱃지형 코칭 텍스트 14px → **너무 작아서 읽기 어려움**

### 변경

**camera.html** `<style>` 내 `#coaching-badge #coaching-text`:

```css
/* 변경 전 */
font-size: 14px;

/* 변경 후 */
font-size: 17px;
```

- 17px = 본문 가독성 확보하면서 뱃지 형태 유지
- 필요 시 `max-width: 90%`로 조정하여 긴 텍스트 잘림 방지

## 보정 3: 셔터 버튼 위치 조정

### 현행 문제
상단 우측 배치 → 한 손 셀카 시 엄지가 안 닿음

### 변경
셔터를 **우측 중하단**에 플로팅 배치:

```css
#btn-capture {
  position: fixed;
  bottom: 25%;       /* 화면 하단 25% 지점 = 중하단 */
  right: 20px;
  z-index: 30;
}
```

- 카메라 헤더에서 분리 → fixed 플로팅
- `bottom: 25%` = 한 손 잡고 엄지가 자연스럽게 닿는 높이
- 자동 캡처가 메인이고 수동 셔터는 보조이므로, 크기는 현행 52px 유지
