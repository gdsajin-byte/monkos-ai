## 작업 2: 비로그인 직접결제 엔드포인트

**파일**: `monkos_AI/portal/server.js`

비로그인 사용자가 크레딧 시스템 없이 **결제 → 즉시 다운로드**하는 경로.

### 엔드포인트: `POST /api/payments/toss/direct`

**요청**:
```json
{
  "paymentKey": "토스 paymentKey",
  "orderId": "DIRECT_sessionId_timestamp",
  "amount": 10150
}
```

**처리 흐름**:
1. 토스 API로 결제 승인 (`/v1/payments/confirm`)
2. 성공 시 → `{ success: true, downloadToken: "일회용토큰" }` 반환
3. downloadToken은 서버 메모리(Map)에 5분 TTL로 저장
4. 실패 시 → `{ success: false, error: "..." }` 반환

**userId 불필요** — Firestore 크레딧 적립 없음. 결제 기록만 Firestore `payments/` 컬렉션에 로깅.

### 엔드포인트: `GET /api/download/direct?token=xxx`

**처리 흐름**:
1. token이 서버 메모리 Map에 존재하는지 확인
2. 존재 → 토큰 삭제 (1회용) + `{ success: true }` 반환
3. 미존재/만료 → `{ success: false, error: "만료된 토큰" }` 반환

> 프론트(막내2)가 이 응답을 받아 sessionStorage의 원본 이미지를 해제합니다.

### 비로그인 결제 금액

- 다운로드만: ₩10,150 (70c × 145원)
- 생성은 이미 무료 제공됨

### CORS

기존 ALLOWED_ORIGINS에 이미 `idphoto-kr.monkos.ai` 포함 → 추가 작업 불필요.

## 작업 3: 이벤트 크레딧 지급 (가입 보너스)

**파일**: `monkos_AI/portal/server.js`

### 엔드포인트: `POST /api/credits/event`

**요청**:
```json
{
  "userId": "xxx",
  "eventType": "signup_bonus" | "sns_share" | "photo_consent",
  "eventData": {}
}
```

**처리 흐름**:

| eventType | 크레딧 | 조건 |
|-----------|--------|------|
| `signup_bonus` | +30c | 최초 1회 (Firestore `users/{userId}.events.signup_bonus` 체크) |
| `sns_share` | +40c | 최초 1회 (`users/{userId}.events.sns_share` 체크) |
| `photo_consent` | +40c | 최초 1회 (`users/{userId}.events.photo_consent` 체크) |

- `sns_share`와 `photo_consent`는 택 1 (둘 중 하나만 지급, 중복 불가)
- Firestore 트랜잭션으로 원자적 처리
- 성공 시: `{ success: true, credits: 갱신잔액, granted: N }`
- `logTransaction()` 기록 (type: 'event')
