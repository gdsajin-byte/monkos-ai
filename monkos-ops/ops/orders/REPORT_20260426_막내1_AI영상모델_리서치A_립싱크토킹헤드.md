## 핵심 발견

### 1. Apple Silicon 호환성 — 치명적 갭
- **Audio-driven 모델 전원 CUDA 전용**. M1/M2/M4에서 네이티브 추론 불가.
- Video-driven 중 **LivePortrait만 macOS MPS 공식 지원** (유일).
- SadTalker/FOMM/DaGAN은 CPU fallback 가능하나 실용 불가 속도.

### 2. 4060 (8GB VRAM) 적합 모델
- **확실**: MuseTalk (fp16), LivePortrait (~6GB), LatentSync v1.5 (8GB), FOMM, SadTalker
- **조건부**: EchoMimic (가속 모드), AniPortrait (512px), V-Express
- **불가**: Hallo3 (H100 최적화), HunyuanVideo-Avatar (24GB 권장)

### 3. PT앱 나레이터 영상 파이프라인 관점
- **요구사항**: 사진 1장 + TTS 오디오 → 나레이터 영상 (Audio-driven 필수)
- **현실 구동 환경**: 4060 (8GB)
- Audio-driven + 4060 구동 가능 + 고퀄리티 = 선택지가 좁음

## 추천 Top 3 + 근거

### 🥇 1위: MuseTalk (Tencent)
- **근거**: 4GB fp16으로 4060 안정 구동. 실시간 30fps+ 달성. FID/CSIM 벤치마크 1위. MIT 상용 가능. 커뮤니티 가장 활발.
- **리스크**: 256px 얼굴 영역 (업스케일 필요). CUDA 전용 (Mac 불가).

### 🥈 2위: LatentSync v1.5 (ByteDance)
- **근거**: 8GB VRAM 추론. Apache-2.0 상용 가능. end-to-end (중간 모션 표현 없음 = 파이프라인 단순). Whisper 기반 오디오 인코딩.
- **리스크**: 256px (v1.5). v1.6은 512px이나 18GB 필요. CUDA 전용.

### 🥉 3위: EchoMimic (Ant Group)
- **근거**: 가속 모드 10x (V100에서 240프레임 50초). 랜드마크 편집 가능 (표정 미세 제어). Apache-2.0. EchoMimic V2는 반신 지원 (CVPR 2025).
- **리스크**: 4060 8GB 가속 모드 검증 필요. CUDA 전용.

### 참고: LivePortrait (Video-driven 1위)
- Audio-driven은 아니지만 4060 PoC 검증 완료 + **유일한 macOS 지원** 모델.
- TTS → 드라이빙 영상 생성 → LivePortrait 파이프라인도 가능 (2단계 구성).
