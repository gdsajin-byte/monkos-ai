# 지시서: 어드민 수정 커밋 + 포털 배포

## 배경

작가님 직접 지시로 iMac/쌍아가 어드민 대시보드를 수정함 (Google 로그인 추가 + 포털 복귀 버튼). 로컬 수정 완료 상태이며, 커밋·push·배포가 필요하다.

- 사후 오더: `ORDER_20260317_작가님_iMac쌍아_어드민구글로그인+포털복귀버튼.md`

## Task 1: 수정 내용 검증

수정 파일: `monkos_AI/portal/public/admin/index.html`

아래 항목이 정상 반영되었는지 확인:
1. `<script>var region = 'kr'; var lang = 'ko';</script>` — auth.js 의존 변수 선언
2. `<script src="/js/auth.js"></script>` — GIS + Google OAuth 로직 로드
3. Google 로그인 버튼: `<button class="google-btn" onclick="googleLogin()">Google 로그인</button>`
4. `← 포털로 돌아가기` nav 링크: `<a href="/" class="nav-back">`
5. `updateAuthUI` 오버라이드: Google 로그인 성공 시 `location.reload()`
6. `loadGISWithRetry()` + `initGoogleAuth()` 호출이 `init()` 함수 내 첫 줄

## Task 2: 커밋 + push

```bash
git add monkos_AI/portal/public/admin/index.html
git commit -m "[portal] 어드민 Google 로그인 추가 + 포털 복귀 버튼"
git push origin main
```

## Task 3: 포털 배포

```bash
cd monkos_AI/portal
bash deploy.sh prod
```

배포 완료 후 리비전 번호 기록.

## Task 4: 배포 검증

배포 후 아래 확인:
1. `https://monkos.ai/admin/` 접속 → Google 로그인 버튼 + 카카오 로그인 버튼 둘 다 표시
2. nav 우측에 `← 포털로 돌아가기` 링크 표시
3. Google 로그인 클릭 시 GIS 팝업 정상 동작 (로그인 후 페이지 새로고침)
