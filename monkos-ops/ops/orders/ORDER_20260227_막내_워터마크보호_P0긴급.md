```

생성 API 응답 (풀 원본 data URL)
```

## 구현 명세

### Task 1: 원본 격리 (result.js)

**현재 코드 (result.js:214~215):**
```javascript
store.generated = genResult.image;
try { sessionStorage.setItem('monkos_generated', genResult.image); } catch(e) {}
```

**변경:**
```javascript
// 풀 원본은 모듈 스코프 private 변수에만 보관
let _fullOriginal = null;

// 생성 완료 시
_fullOriginal = genResult.image;

// 워터마크 버전 생성 후 store/sessionStorage에 저장
const watermarked = await generateWatermarkPreview(genResult.image);
store.generated = watermarked;
try { sessionStorage.setItem('monkos_generated', watermarked); } catch(e) {}
```

### Task 2: 비교컷 이미지도 워터마크 버전으로 (result.js:224~225)

**현재:**
```javascript
const genImg = document.querySelector('#photo-generated');
if (genImg) genImg.src = genResult.image;  // 풀 원본!
```

**변경:**
```javascript
const genImg = document.querySelector('#photo-generated');
if (genImg) genImg.src = watermarked;  // 워터마크 버전
```

### Task 3: 다운로드 시 원본 접근 (result.js doDownload)

**현재 doDownload():**
```javascript
async function doDownload() {
  // ... 크레딧 차감
  await cropAndShowPostDownload();
}
```

**변경:**
```javascript
async function doDownload() {
  // ... 크레딧 차감 성공 후
  // 결제 완료 시점에 store.generated를 원본으로 교체
  store.generated = _fullOriginal;
  // 비교컷 이미지도 원본으로 교체 (결제 후이므로 안전)
  const genImg = document.querySelector('#photo-generated');
  if (genImg) genImg.src = _fullOriginal;

  await cropAndShowPostDownload();
}
```

### Task 4: sessionStorage 복원 시에도 워터마크 (result.js:443~449)

**현재:**
```javascript
if (!store.generated) {
  const savedGen = sessionStorage.getItem('monkos_generated');
  if (savedGen) {
    store.generated = savedGen;  // 워터마크 버전이 저장되므로 안전
  }
}
```

이 부분은 Task 1에서 sessionStorage에 워터마크 버전을 저장하면 자동으로 안전해짐. 단, `_fullOriginal`은 복원 불가 → 토스 리다이렉트 후 원본 재요청 로직 필요 여부 검토.

**판단 필요**: 토스 결제 리다이렉트 후 복귀 시 원본이 없는 경우:
- A안: 서버에 생성 결과 캐싱 (userId+sessionId 기반) → 재다운로드
- B안: 결제 완료 직후 즉시 크롭+저장 → 리다이렉트 전에 완료
- **추천: B안** (서버 캐싱 없이 클라이언트에서 해결)

### Task 5: CSS 보조 방어 (result.html)

비교컷 이미지에 추가:
```css
#photo-generated, #spec-photo {
  -webkit-touch-callout: none;  /* iOS 길게 누르기 메뉴 차단 */
  -webkit-user-select: none;
  user-select: none;
  pointer-events: none;          /* 터치 이벤트 차단 */
}
```

+ JS 보조:
```javascript
document.querySelectorAll('#photo-generated, #spec-photo').forEach(img => {
  img.addEventListener('contextmenu', e => e.preventDefault());
});
```

**주의**: pointer-events: none은 비교컷 이미지에만 적용. 버튼 등 인터랙션 요소에는 적용하지 않을 것.

### Task 6: 워터마크 강도 조정

현재 `generateWatermarkPreview()`의 워터마크:
- `globalAlpha = 0.15` (매우 연함)
- "MONKOS" 텍스트만

**개선:**
- `globalAlpha = 0.25` (적절히 보이되 프리뷰 기능은 유지)
- 텍스트 간격을 좀 더 촘촘하게 (현재 `img.height / 4` → `img.height / 5`)
- 워터마크가 "충분히 보여서 원본이 아님을 인지"할 수 있되, "사진 품질 확인은 가능"한 수준

## 주의사항

- **`_fullOriginal` 변수는 window에 노출하지 않을 것** — 모듈 스코프(let)로만 보관
- 개발자 도구에서의 접근은 완전 차단 불가 (기술적 한계) — 그러나 일반 사용자의 쉬운 우회는 차단됨
- 원본 img를 비교컷에서 제거할 때 QC 판단이 되는지 확인 — 워터마크가 너무 강하면 사진 품질 확인이 어려움
- **기존 비로그인 1회 무료 생성**도 워터마크 적용 대상 (생성 자체는 무료, 다운로드가 유료)
- 커밋 메시지: `[fix] 다운로드 과금 우회 차단 — 비교컷 워터마크 보호`
- 커밋 후 push 승인 요청
- **이 작업은 크립 디자인 통일(CR_DESIGN_UNIFICATION)과 독립 — 병행 실행 가능**
