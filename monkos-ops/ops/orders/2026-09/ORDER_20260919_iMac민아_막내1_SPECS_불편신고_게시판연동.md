## 3. 상세 설계

### 3-1. 신고 입구 (specs 퍼널)

- **에러 발생 지점**: 에러 문구가 표시될 때 그 옆에 "안 되나요? 바로 알려주세요" 링크 노출(업로드·검수·결제·생성·다운로드 전 단계 공통).
- **결제 단계 상시**: 결제하기 버튼 아래 작은 텍스트 링크.
- **페이지 하단 상시**: "의견·불편 신고" 링크.
- 클릭 시 페이지 이탈 없이 **인라인 시트(모달)**: 내용(필수, 한 줄이어도 됨) + 연락받을 이메일(선택) + 제출. 닉네임·제목·비밀번호는 요구하지 않는다(신고 모드 자동 채움 — 제목은 `[신고] {slug} · {단계}`). 제출 후 "접수했습니다. 답글은 이 링크에서 확인하세요" + 글 링크.
- 고객 대면 호칭은 **"고객님"**(작가님 08-13 지적). 내부 호칭·엔진명 노출 금지.

### 3-2. 맥락 자동 첨부 (핵심)

제출 시 클라이언트가 수집해 `context`로 전송:

```
slug, lang, market, phase(현재 단계: upload/check/fit/pay/generating/result/free),
lastError(마지막 표시 에러 문구 200자), lastErrorStage, orderId(있으면),
payProvider, widgetOpened(bool), confirmClicked(bool),
vw, vh, dpr, inApp(인앱 브라우저 판정 — specs-funnel.js:108 정규식 재사용), referrerHost
```

서버가 덧붙임: `userAgent`(요청 헤더), `createdAt`. **IP는 저장하지 않는다**(스팸 차단용 메모리 맵만 기존대로).

- `context`는 **관리자 API에서만 반환**. 공개 API(`handleBoardPublicList/Get`)에서는 절대 미포함 — 응답 필드를 화이트리스트로 구성할 것.
- 업로드 사진·결제 토큰·`paymentToken`·이메일 외 개인정보는 `context`에 넣지 않는다.

### 3-3. 비공개 글 (민아 권고 기본값 — 작가님 변경 가능)

- `category: '신고'` 글은 `visibility: 'private'` 기본. 공개 목록에는 "비공개 글입니다"로 마스킹(제목·내용·작성자 미노출), 상세는 **글 작성 시 발급한 열람 링크(추측 불가 토큰 포함)** 로만 열람.
- 후기·의견은 기존대로 공개.
- 열람 토큰은 `crypto.randomBytes` 기반. 해시만 저장하는 기존 비밀번호 관례(`hashPassword`) 준용.

### 3-4. 즉시 알림 + 접수 자동 답글

- 새 글 작성 시 `sendTelegramMessage(TEAM_CHAT_ID, ..., TELEGRAM_TEAM_API)` — 카테고리·slug·단계·기기 요약·마지막 에러·관리자 링크. 본문은 200자 절단, 이메일 미포함. 호출 관례는 `lib/spec-crop.js:141` 참조. 전송 실패는 글 작성을 막지 않되 `log(..., 'WARNING')`(무음 강등 금지).
- **접수 자동 답글(무인, 즉시)**: 신고 글에 한해 `replies`에 1건 자동 추가. 명의 **"MONKOS 지원"**. 내용은 **고정 문안**(LLM 생성 아님): 접수 확인 + 단계별 임시 해결법(예: 결제 단계 → "크롬/사파리 기본 브라우저에서 다시 시도", 다운로드 단계 → "사진 길게 눌러 저장") + 답변 예정 안내. 문안은 `specs-i18n.js`에 단계별 키로 두고 ko/en/ja/es 전부 작성.
  - ⚠️ 문안에 **환불·보상·출시 예정 기능·처리 기한 약속 금지**(헌법 4조 4항 — 되는 것만 응답).

### 3-5. 에이전트 본답글 — **본 지시서 범위 밖** (경계만 정의)

- 본답글은 당분간 **알림 수신 → 민아/막내 세션이 맥락으로 진단 → 작가님 승인 → 관리자 답글 API(`POST /api/admin/board/:id/reply`)로 게시**. 무인 LLM 자동 게시는 본 지시서에서 구현하지 않는다(2주 승인 게시 운영 후 별도 설계 — ch1 7조 무인 맥락 제약).
- 본 지시서에서 할 일은 하나: 관리자 답글에 `authorLabel`(기본 "MONKOS 지원") 필드를 받아 표시하도록 `handleBoardAdminReply`와 렌더를 보강. 답글이 달리면 작성자가 이메일을 남긴 경우 `lib/mailer.js`로 "답글이 달렸습니다 + 열람 링크" 1통 발송(발신 info@monkos.ai).

### 3-6. 관리자 화면

- `public/admin/board.html`: 글 상세에 **맥락 패널**(기기·브라우저·화면·단계·에러·주문번호), **미답변 필터**, 신고 카테고리 배지.

### 3-7. 배포

- `deploy.sh dev` → 검증 → **작가님 승인 후** `deploy.sh prod` → **`edge/deploy.sh` 엣지 재배포 필수**(specs 페이지·`/js/specs-funnel.js`는 CF Worker 정적 자산). `/board`·`/api/board`는 오리진 서빙 — 엣지 캐시 대상 여부를 `edge/worker.mjs`에서 확인하고, 캐시된다면 신고 글이 캐시에 남지 않도록 조치.
