# 지시서: §6 기대효과 재구성 + Google Docs 직접 수정

## 목적

v8 사업계획서의 §6(기대효과, 15점)을 재구성하고, Google Docs에 직접 반영한다.
너의 Google Docs MCP 사용 능력 테스트를 겸한다.

## 대상 문서

Google Docs ID: `1By3CgBmFkiu0t4b7EydoxOAerJ90AuaQpwRstoPw34g`

## MCP 도구

이 프로젝트에는 Google Docs MCP가 연결되어 있다:
- `readGoogleDoc` — 문서 읽기 (markdown, json, text)
- `insertText` — 텍스트 삽입
- `deleteRange` — 범위 삭제
- `insertTable` — 표 삽입

json 포맷으로 읽으면 각 요소의 startIndex/endIndex를 알 수 있다.
수정 시 하단→상단 순서로 해야 인덱스 시프트를 방지한다.

## 배점 질문

§6은 **"사업참여를 통한 기대효과 및 성과 창출 가능성"** (15점)을 묻는다.
핵심: "이 사업(강한소상공인 사업화자금 1억 + 파트너 매칭)에 참여하면 뭐가 달라지는가"

## 현재 문제

- §6-1이 일반적 불릿 5개 — 어떤 기업이든 쓸 수 있는 문구
- §6-2 정량 목표 표가 2025→2028 장기 로드맵 — §5 투자유치 로드맵과 중복
- 배점 질문에 직답이 안 됨

## 재구성 방향

### §6-1 → 사업 전/후 비교표 (1개)

현재 5개 일반 불릿을 삭제하고, **사업화자금 1억 전/후 비교표**로 교체:

| 항목 | 현재 (사업 전) | 사업 후 12개월 |
|------|---|---|
| 매출 | 오프라인 6,500만 only | AI+오프라인 1.72~4.56억 |
| 고용 | 2명 (신규) | 3~5명 (마케팅·영업 채용) |
| 인증 | KOITA | +특허 출원+벤처인증+기보 기술보증 |
| 글로벌 | 2개국 라이브 | 3개국+ · 수출 5,000만~ |
| 콘텐츠 | 자체 21채널 | +파트너 숏폼 30편/분기 |

### §6-2 → 성과 창출 근거 (5줄 유지)

현재 ① 성과 창출 근거 5줄은 좋다 — 그대로 유지.
② 정량 목표 장기 표는 삭제 (§5와 중복).

## 실행 순서

1. `readGoogleDoc` (markdown)으로 현재 §6 전체 확인

3. 하단→상단 순서로:

   - §6-1 불릿 5개 삭제
   - §6-1에 비교표 삽입
4. `readGoogleDoc` (markdown)으로 결과 확인
