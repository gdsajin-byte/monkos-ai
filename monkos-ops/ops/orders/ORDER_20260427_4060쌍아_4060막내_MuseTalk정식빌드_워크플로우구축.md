# MuseTalk 정식 빌드 + 워크플로우 구축

> **목적**: 우회 패치 3건을 제거하고 MuseTalk을 정식 빌드 상태로 전환한다. 이후 TTS→MuseTalk→출력까지 완전한 워크플로우를 구축하여 생성물 품질을 제대로 판단할 수 있게 한다.
> **배경**: 현재 MuseTalk은 xtcocotools 심, mmpose try/except, mmcv ext_loader 스텁 등 우회 패치 3건으로 "일단 돌아가는" 상태. 우회 상태에서는 mmcv.ops가 비활성이므로 생성물 품질이 정식 빌드와 다를 수 있다. 제대로 된 평가를 위해 정식 빌드가 선행되어야 한다.

## Phase 2 — 우회 패치 제거 + 정식 빌드

### 2-1. xtcocotools 정식 설치
```bash
conda activate musetalk
# 심(shim) 제거
pip uninstall xtcocotools -y
# 소스 빌드 (MSVC 필요)
pip install xtcocotools --no-binary :all: --force-reinstall
```
- 검증: `python -c "from xtcocotools.coco import COCO; print('OK')"`

### 2-2. mmcv 풀버전 빌드
```bash
pip uninstall mmcv mmcv-lite -y
# CUDA Toolkit 12.6 + MSVC 환경에서 소스 빌드
pip install mmcv==2.0.0 -f https://download.openmmlab.com/mmcv/dist/cu126/torch2.6/index.html
# 또는
mim install "mmcv>=2.0.0"
```
- 검증: `python -c "from mmcv.ops import nms; print('OK')"`

### 2-3. 패치 제거
1. mmpose `__init__.py` — try/except 제거, 원본 import 복원
2. mmcv `ext_loader.py` — 스텁 오버라이드 제거, 원본 복원
3. xtcocotools 심 폴더 — 정식 패키지로 대체됨

### 2-4. 추론 검증
```bash
cd C:\Users\smuse73\ai-tools\MuseTalk
python -m scripts.inference --inference_config configs/inference/test_model.yaml --unet_config ./models/musetalkV15/musetalk.json --use_float16 --ffmpeg_path C:\Users\smuse73\ai-tools\ffmpeg_temp\ffmpeg-8.1-essentials_build\bin --result_dir C:\Users\smuse73\ai-tools\output\lipsync\v15_clean
```
- 동일 입력(model.jpg + edge_ko.wav)으로 추론
- 우회 버전 결과물(`v15/`)과 정식 빌드 결과물(`v15_clean/`) 비교용 보존
