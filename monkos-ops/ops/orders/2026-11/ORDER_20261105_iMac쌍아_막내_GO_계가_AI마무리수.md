## 2. 할 일

1. **계가 신청 시 마무리 수** — `start_scoring()`(`server.py:1422`) 진입 시, 양쪽 패스로 끝난 판이 아니면:

   - 규칙: 마무리는 경계가 확실히 닫히도록 둔다. 한국 규칙(집 계산)으로 엔진이 공배를 남긴 채 패스하면 열린 경계가 남을 수 있다 → **마무리 동안만 `kata-set-rules`로 면적 규칙(chinese 등)** 을 쓰고 끝나면 korean으로 되돌리는 안을 시험하고, 두 방식(korean 마무리 / 면적 마무리) 결과를 아래 판정 표로 비교해 채택 근거를 보고에 적는다.
   - 수읽기: 빠른 설정(예: visits 50~200, 수당 상한 0.3초). 전체 **10초 이내** 목표, 실측 시간 기록. 진행 중 화면에 "AI가 끝까지 두는 중 (N수)".
   - 엔진 락: 대국 엔진·그래프 양보 규칙(GRAPH_YIELD 등) 기존 틀을 따른다. 다른 판의 대국 요청을 막지 않는다.
2. **계가 재료** — 마무리 끝 국면에서 `final_status_list dead`·`final_score`를 받고, 기존 `count()`(닫힌 집 + 따낸 돌 + 사석 + 덤)로 센다. 마무리 수에서 따낸 돌도 포로에 포함. 사석 토글(`toggle_dead`)은 마무리 끝 국면 기준으로 동작.
3. **화면** — 마무리 수는 반투명 돌 + 수순 번호로 실제 수와 구분 표시. 계가 패널에 "AI 마무리 N수 후 계가" 1줄. 앱 계가와 KataGo 판정이 1집 넘게 다르면 지금처럼 차이 문구 유지.
4. **불변** — 실제 판(`self.moves`)·기보(SGF)·대국 기록에는 마무리 수를 넣지 않는다. 계가 확정 시 결과만 기록하고, 기보 주석에 "AI 마무리 N수 후 계가"만 남긴다. **계가 취소 → 마무리 수 전부 사라지고 원래 국면에서 이어 두기.**
5. **양쪽 패스로 끝난 판**은 지금 동작 그대로(마무리 없음).
