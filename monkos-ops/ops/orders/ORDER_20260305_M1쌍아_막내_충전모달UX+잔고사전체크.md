# 지시서: 충전 모달 UX 개선 + 리터칭 잔고 사전체크

> **[2026-03-05 22:02 KST] M1/쌍아 → 막내**

---

## 배경

- 충전 모달(ChargeModule)이 바텀시트에 카드 4장 + 스테퍼 + 결제버튼 + 닫기 = 스크롤 필요
- 유저가 결제 버튼/닫기 버튼을 볼 수 없음 (뷰포트 밖)
- 카드 탭 → 즉시 결제는 오터치 리스크 → **투터치(확인 후 결제)** 확정
- 리터칭(생성) 시 잔고 부족이어도 시머링 오버레이가 먼저 시작됨 → 서버 402 후 뒤늦은 충전 모달

---

## 핵심 UX 원칙: 투터치 결제 (5개 상품 동일)

```
탭 1회 → 가격 블록이 초록색 "₩N,NNN 결제"로 전환 (확인 상태)
탭 2회 → 토스 결제 진입
다른 곳 탭 → 확인 해제, 원래 상태 복귀
```

카드 4장 + 소액 스테퍼 가운데 버튼 = 전부 동일 패턴.

## Phase A: 충전 모달 UX 개선

> 적용 대상: `modules/charge.js` (모달)

### A-1. 헤더 추가 + 하단 버튼 제거

**현행 제거:**
- `<h3>크레딧 충전</h3>` (L117)
- `<button id="chargePayBtn">토스페이먼츠로 결제</button>` (L133)
- `<button id="chargeCloseBtn">닫기</button>` (L134)

**신규 헤더 (모달 컨텐츠 최상단):**
```html
<div style="display:flex;align-items:center;justify-content:space-between;margin:0 0 16px;">
  <button id="cm-back-btn" type="button" style="background:none;border:none;color:#a78bfa;font-size:0.95rem;font-weight:600;cursor:pointer;padding:4px 0;">← 이전</button>
  <span style="font-size:0.85rem;font-weight:600;color:#8892a8;">크레딧 충전</span>

    <span style="color:#a78bfa;font-size:0.85rem;font-weight:700;">Cr</span>

```

- "← 이전" 탭 → `ChargeModule.close()`
- 우측 Cr 표시: `store.user.credits` 값 바인딩
- 오버레이 배경 탭 → close 유지

### A-2. 카드 투터치 결제

**현행:** 카드 탭 → 테두리 강조(선택) → 하단 결제 버튼 클릭
**변경:** 카드 탭 → 확인 상태 → 재탭 → 결제

`renderChargeCards()` 변경:
- `<label>` → `<div>` 로 변경 (라디오 인풋 제거)
- `<input type="radio">` 제거
- 각 카드에 `data-price`, `data-credits` 속성 추가

**투터치 인터랙션:**

1. **탭 1회 (확인 진입):**
   - 해당 카드의 우측 가격 블록 전환:
     - 배경: `linear-gradient(135deg, rgba(34,197,94,0.4), rgba(34,197,94,0.2))` (초록)
     - BEST 카드도 동일 초록 (골드 → 초록 전환)
     - 취소선 가격 숨김
     - 텍스트: `₩{price} 결제` (color: #f8fafc; font-weight:700)
   - 다른 카드가 확인 상태이면 해제 (동시 확인 1개만)
   - 스테퍼 확인 상태도 해제

2. **탭 2회 (결제):**
   - `ChargeModule.close()`
   - `buyCreditsKR(opt.price, opt.credits + opt.bonus)`

3. **다른 곳 탭 (해제):**
   - 가격 블록 원래 스타일로 복귀 (보라/골드 그라디언트 + 취소선+실가격)

**카드 사이즈 최적화** (스크롤 방지):
- padding: `16px` → `12px 16px`
- margin-bottom: `8px` → `6px`
- 크레딧 폰트: `1.5rem` → `1.3rem`
- 가격 블록 padding: `12px 16px` → `8px 14px`
- 섹션 레이블 margin 축소

### A-3. 스테퍼 투터치 결제

**현행:** `[−]` 숫자 `[+]` → 별도 결제 버튼 필요
**변경:** `[−]` **[숫자 버튼]** `[+]` — 가운데가 투터치 결제 버튼

가운데 영역을 카드 가격블록과 동일 스타일의 버튼으로:

```html
<div style="display:flex;align-items:center;justify-content:center;gap:12px;margin-bottom:4px;">
  <button id="cm-stepper-minus" ...>−</button>
  <button id="cm-stepper-pay" type="button" style="
    background:linear-gradient(135deg,rgba(167,139,250,0.3),rgba(129,140,248,0.2));
    border:none; border-radius:12px; padding:10px 20px; min-width:120px;
    text-align:center; cursor:pointer;
  ">
    <div id="cm-stepper-qty" style="color:#f8fafc;font-weight:700;font-size:1.05rem;">10c</div>
    <div id="cm-stepper-price" style="color:#a78bfa;font-size:0.8rem;margin-top:2px;">₩1,450</div>
  </button>
  <button id="cm-stepper-plus" ...>+</button>
</div>
```

**투터치 인터랙션 (카드와 동일):**

1. **탭 1회 (확인 진입):**
   - 가운데 버튼 배경 → 초록 그라디언트
   - 텍스트: `{qty}c` + `₩{amount} 결제`
   - 다른 카드 확인 상태 해제

2. **탭 2회 (결제):**
   - `ChargeModule.close()`
   - `buyCreditsKR(qty * STEP_PRICE, qty * STEP_UNIT)`

3. **−/+ 탭 (수량 변경):**
   - 수량 변경 + 디스플레이 갱신 (현행 `_updateStepperDisplay` 로직)
   - **확인 상태 해제** (수량 바꿨으니 다시 확인 필요)

4. **다른 곳 탭 (해제):**
   - 보라 그라디언트로 복귀

### A-4. 상태 관리 단순화

기존 `_chargeIdx`, `_stepperActive`, `_activateStepper()`, `_deactivateStepper()` **전부 제거**.

신규 상태:
```javascript
let _confirmedIdx = -1;    // 확인 상태인 카드 인덱스 (-1: 없음, 0~3: 카드, 4: 스테퍼)
```

- 카드/스테퍼 탭 시: `_confirmedIdx === 자신` 이면 결제 실행, 아니면 `_confirmedIdx = 자신` 설정 + UI 전환
- 다른 곳 탭, −/+ 탭, 오버레이 탭 시: `_confirmedIdx = -1` + UI 복귀

### A-5. "최소 10c · 최대 100c" 안내 유지

- 현행 위치·스타일 그대로 `0.7rem; color:#666`

### A-6. ChargeModule.show() 초기화

```javascript
show() {
  _buildModal();
  _confirmedIdx = -1;           // 확인 상태 초기화
  _stepperQty = 1;
  _updateStepperDisplay();
  _resetAllCards();              // 전 카드 기본 스타일 복귀
  // cm-credit-display에 store.user.credits 바인딩
  _chargeEl.querySelector('#cm-credit-display').textContent = store.user.credits;
  _chargeEl.style.display = 'flex';
}
```
