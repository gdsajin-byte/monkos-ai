**[2026-03-08 17:55 KST] iMac/쌍아 → 막내1, 막내2, 막내3 (전원 동원)**

## 목표

크레딧 사용 설명, 책임 한계, 환불 방식, 거래 장부 보관 규정을 **한 페이지**로 통합한 정책 페이지를 만든다. 현행 `terms.html`, `refund.html`, `privacy.html`에 흩어진 크레딧 관련 내용을 하나로 모아 고객이 한 곳에서 전부 확인할 수 있도록 한다.

## 현행 파악 (필수 읽기)

### 기존 페이지
| 파일 | 내용 | 크레딧 관련 |
|------|------|------------|
| `idphoto-kr/public/terms.html` | 이용약관 전체 | 제4조(크레딧 시스템), 제5조(결제) |
| `idphoto-kr/public/refund.html` | 환불정책 | 전문 — 환불 기준, 자동복구, 사업자 정보 |

### 진입점 (링크 버튼 설치 대상)
1. **포털** (`portal/public/`) — 메인 내비게이션 또는 푸터
2. **랜딩** (`idphoto-kr/public/index.html`) — 푸터 또는 CTA 영역
3. **충전 모달/페이지** (`charge.html`) — 충전 UI 하단
4. **헤더 동전** (크레딧 잔액 표시 영역) — 클릭 시 정책 페이지 링크
5. **땡큐 페이지** (`thankyou.html`) — "크레딧 정책 보기" 버튼

## 역할 분배

### 막내1: 법규 리서치 + 법적 문구 작성
- 전자상거래법 크레딧(선불전자지급수단/포인트) 관련 규정 전수 파악
- 장부 3년/5년 보관 의무 조항 정확한 인용 (시행령 제6조)
- 우리 시스템이 해당 법을 어떻게 준수하는지 구체적 매핑:
  - `payments` 컬렉션 = 대금결제 기록 (5년 보관)
  - `transactions` 컬렉션 = 크레딧 거래 원장 (5년 보관)
  - 토스페이먼츠 측 결제 기록 보관
- 책임 한계 문구: AI 생성물의 관공서 접수, 디지털 콘텐츠 청약철회 제한
- 일본 특정상거래법 관련 크레딧 규정 (idphoto-jp 대응)
- 환불 불가 사유의 법적 근거 명확화

### 막내2: 페이지 디자인 + 프론트엔드 구현
- `idphoto-kr/public/credits-policy.html` 신규 생성
- 디자인: 기존 `refund.html`, `terms.html`과 동일한 다크 테마 스타일
  - CSS 변수: `--bg: #0f0f23; --surface: #1a1a2e; --accent: #a78bfa;` 등 기존 패턴 준수
- **페이지 구조** (섹션 구성):

```
1. 크레딧이란?
   - 크레딧 = MONKOS 서비스 이용 단위
   - 1크레딧의 가치, 생성(10c), 다운로드(70c) 비용
   - 유효기간 1년, 양도/현금 교환 불가

2. 충전 방법
   - 토스페이먼츠 (신용카드, 간편결제)
   - 충전 상품 목록 (가격표)
   - 무료 크레딧 지급 조건 (가입 보너스, SNS 공유)

3. 사용 내역
   - 생성 1회 = 10c, 다운로드 1회 = 70c
   - 공유 보너스 = +70c
   - 생성 실패 시 자동 환불 (+10c)
   - 다운로드 실패 시 자동 환불 (+70c) ← 신규 추가

4. 환불 정책
   - 기존 refund.html 내용 통합
   - 7일 이내 미사용 전액 환불
   - 사용 후 환불 불가 (디지털 콘텐츠)
   - 환불 절차 (이메일, 3영업일)

5. 거래 기록 보관
   - "MONKOS는 전자상거래법에 따라 거래 기록을 안전하게 보관합니다"
   - 대금결제 기록: 5년 (전자상거래법 시행령 제6조 제1항 제3호)
   - 소비자 불만·분쟁 처리 기록: 3년 (동 시행령 제4호)
   - 보관 방식: 암호화된 클라우드 데이터베이스
   - 고객 열람 요청 가능 (info@monkos.ai)

6. 책임 한계
   - AI 생성물의 관공서 접수 여부: 해당 기관 기준
   - 서비스 장애 시 크레딧 자동 복구
   - 디지털 콘텐츠 청약철회 제한 (전자상거래법 17조 2항 5호)

7. 사업자 정보
   - 기존 refund.html 하단 사업자 정보 동일
```

- **반응형**: 모바일 우선 (max-width: 720px)
- 각 섹션 접이식(accordion) 또는 앵커 내비게이션 — 한 페이지지만 빠르게 탐색 가능
