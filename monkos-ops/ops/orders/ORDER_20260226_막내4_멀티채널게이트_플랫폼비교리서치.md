# [2026-02-26 21:15 KST] M1/쌍아 → 막내4

## 지시: 멀티채널 게이트 전략 — 플랫폼 비교 리서치

### 배경

크레딧 게이트 v2는 현재 **텔레그램 채널 가입**을 40c 조건으로 설계했다.
그런데 작가님의 지적: **"텔레그램만 고집하는 것이 과연 적정한가?"**

MONKOS의 타겟 시장:
- **한국**: 카카오톡 지배적, 텔레그램 사용률 상대적 저조
- **일본**: 라인 지배적, 텔레그램 사용률 더 낮음

한국은 카톡채널+텔레, 일본은 라인채널+텔레로 **초기 유입 요인을 높이는 멀티채널 전략**이 가능한지 리서치한다.

본 지시서는 기존 `ORDER_20260226_막내4_텔레그램봇채널_논리구조분석.md`(미시행)를 흡수·확장한다.

### 작업 항목

#### 1. 기존 텔레그램 인프라 전수조사 (원래 지시서 계승)

기존 지시서의 항목을 그대로 수행한다:
- 봇 5개 · 채널/그룹 2개의 현황·활성도·통합 가능성
- getChatMember 대상 채널 추천
- 봇/채널 정리 추천안

**코드 조사 대상**:
```
monkos_AI/portal/server.js          ← 3봇 통합 (CS/이벤트/팀)
functions/api/telegram.js            ← 용아봇 (CF Workers)
functions/api/telegram-webhook.js    ← 용아봇 웹훅
apps/MonkosChat/functions/index.js   ← 팩토리봇 (Firebase)
```

#### 2. 카카오톡 채널 — 게이트 연동 가능성 리서치

**핵심 질문**: 카카오톡 채널 "친구추가" 여부를 서버에서 검증할 수 있는가?

**조사 항목**:
| 항목 | 상세 |
|------|------|
| 카카오 채널 API | 친구추가 여부 확인 API 존재 여부 (카카오 디벨로퍼 문서 기반) |
| 인증 흐름 | 카카오 로그인 → 채널 친구추가 → 서버 검증의 기술적 가능성 |
| 비용 | API 호출 과금, 채널 운영 비용 (무료/유료 티어) |
| 한국 시장 침투율 | 카카오톡 MAU, 채널 친구추가 수용도 (증명사진 타겟층 기준) |
| 구현 난이도 | 현재 카카오 로그인은 이미 구현 — 확장 가능성 |
| 유저 경험 | 카톡은 이미 설치됨 → 마찰 최소 vs 텔레그램 앱 설치 필요 |

**참고**: 현재 게이트 Phase 1이 이미 카카오 로그인이므로, 카카오 채널 친구추가를 Phase 2로 넣으면 **앱 전환 없이 인앱 동선**이 가능할 수 있다.

#### 3. 라인 공식계정 — 게이트 연동 가능성 리서치

**핵심 질문**: 라인 공식계정 "친구추가" 여부를 서버에서 검증할 수 있는가?

**조사 항목**:
| 항목 | 상세 |
|------|------|
| LINE Messaging API | 친구추가(follow) 이벤트 수신 가능 여부 |
| LINE Login | 라인 로그인 → friendship_status_changed 파라미터 |
| 비용 | API 호출 과금, 공식계정 운영 비용 (무료 메시지 한도) |
| 일본 시장 침투율 | LINE MAU, 공식계정 친구추가 수용도 (취활 증명사진 타겟층) |
| 구현 난이도 | 라인 로그인 신규 구현 필요 여부 |
| 유저 경험 | 일본 유저에게 라인은 자연스러운 접점 |
