## Task 1: 업로드 문구 변경

### 현행
- "샘플 이미지 — 직접 사진을 업로드하세요"

### 변경
- "정면 얼굴 사진(어깨~가슴선 노출)을 업로드하세요"
- "업로드" 버튼 텍스트는 유지

## Task 2: 정수리/스케일 버튼 크기 보정 + 아이콘 식별성

### 현행
- 정수리 드래그 버튼, 스케일 핸들 버튼이 시각적으로 너무 큼
- 버튼 내 화살표 아이콘이 너무 작아서 무슨 버튼인지 식별 안 됨
- "드래그" 텍스트 폰트도 너무 작음

### 변경
- **버튼 시각 크기**: 현재 대비 70~80% 축소 (원형이면 직경 줄이기)
- **터치 영역(hit area)**: 최소 44x44px 유지 — `padding` 또는 투명 영역으로 확보 (모바일 대응)
- **화살표 아이콘**: 버튼 내부에서 상대적으로 키우기 (아이콘 크기 1.5배 이상)
- **"드래그" 텍스트**: font-size 키우기 (최소 12px, 현재보다 2~3px 증가)
- 스케일 핸들도 동일 원칙 적용

## Task 3: "가이드 오버레이 캡처" 버튼 삭제

- 다운로드 확인 모달 내 "가이드 오버레이 캡처 (항변 근거용)" 버튼 완전 제거
- HTML + 관련 JS 이벤트 핸들러 + CSS 모두 삭제
- "크롭 결과 다운로드" 버튼 + "취소" 버튼만 남기기

## Task 4: 조작 가이드 텍스트 간결화

### 현행
- "● 정수리 — 드래그 / ● 턱끝 — 고정 / ● 스케일 핸들" (3개 범례)

### 변경
- 범례 텍스트를 간결하게:
  - "● 정수리 드래그" / "● 턱끝 고정" / "● 스케일"
  - 또는 아이콘 + 한 단어 방식으로 최소화
