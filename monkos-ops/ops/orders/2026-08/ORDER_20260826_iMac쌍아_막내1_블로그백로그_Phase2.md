## 2. Task 1 — `publish.mjs` 필드 소멸 방지 일반화 (**category 통일보다 먼저**)

### 2-1. 선행 — 미선언 필드 보존 (착수 전 필수)

쌍아 코드 실측: `post` 객체가 `ctaTitle: fm.cta_title || ''` 형태로 **미선언 필드를 빈 문자열로 덮어쓴다.** 에세이 원본 25건은 `cta_*`를 하나도 갖고 있지 않으므로, 지금 상태로 `--update`를 돌리면 **민아가 16:41에 넣은 뉴트럴 CTA 25건이 전부 소멸**한다(전역 증명사진 CTA로 원복).

`ogImage` 보존(`a6d29c73`)은 같은 사고의 1개 필드 대응이었다. **이를 일반화한다.**

- 규칙: **원본 frontmatter가 선언하지 않은 선택 필드는 기존 문서 값을 유지한다.**
- 대상: `thumbnail` `category` `summary` `tags` `ctaEnabled` `ctaImage` `ctaTitle` `ctaDescription` `ctaButtonText` `ctaLink` (+ 기존 `ogImage` `createdAt` `viewCount`)
- 원본이 **선언한** 필드는 종전대로 원본이 이긴다. 선언 여부는 `fm`에 키가 있는지로 판정한다(빈 문자열 선언과 미선언을 구분할 것).
- 신규 문서(기존 문서 없음)는 종전 동작 유지.

**실증 의무**: 픽스처로 ①미선언 필드가 보존되는지 ②선언 필드가 원본으로 갱신되는지 **양방향** 확인. 한쪽만 보고 완료 처리 금지.

## 3. Task 2 — B군 34건 판정 근거 수집 (**판정 금지, 자료만**)

B군 34건은 발행 여부 판정이 필요하나, **판정은 막내 소관이 아니다.** 아래 자료만 수집해 표로 제출한다.

각 건에 대해:

| 열 | 내용 |
|---|---|
| slug / 제목 / 본문 길이 | 원본 md 실측 |
| **초안 선존** | `blog_posts` 문서 존재 여부 + `published` 값 (읽기 전용 조회) |
| **본문 동일성** | 초안 존재 시 원본 md와 차이 요약 (H1 1줄뿐인지, 실질 상이인지) |
| **specs 대응 URL** | 해당 의도의 `/specs/{type}/kr`이 라이브에 존재하는지 (URL 명기) |
| **계약 결손** | `lang` 표기 / `head_term` / `cta_link` / `category` 유무 |

> 기계적 키워드 매핑으로 "규격 중복"을 단정하지 말 것. 예: `job-photo-expression-guide`는 슬러그에 '취업'이 있어 `specs/resume/kr`에 걸리지만, 글의 의도는 **표정(행위)**이고 specs는 **규격**이라 경쟁 관계가 아니다. **의도 판정은 쌍아·민아가 한다.**
