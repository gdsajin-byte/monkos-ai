## 1. 배경 — 파일럿이 드러낸 것

캐나다 흡수 과정에서 **지시서·설계서의 전제가 공식과 어긋난 사실**이 확인됐다(쌍아 오류). 캐나다 여권은 종이·온라인 양쪽 모두 상업 사진사 대면 촬영이 필수이고 AI 편집본은 반려된다.

문제는 캐나다가 예외인지 아닌지를 **우리가 검증한 적이 없다**는 것이다. 쌍아 전수 실측:

| 항목 | 실측 (429 엔트리) |
|---|---|
| `faqs.ko`에 "집에서 찍을 수 있나요?" 문항 | **427건** |
| 그중 **"네, 셀프 촬영 가능" + MONKOS 권유** | **424건** |
| 실질 부정 답변 | **ca-passport·ca-visa 2건뿐** (08-26 교정분) |

즉 **424개 페이지가 검증 없이 "가능하다"고 답하고 있다.** 이는 CTR 문제가 아니라 **오안내 리스크**다 — 고객이 우리 안내를 믿고 신청했다가 반려당하는 경로이며, 헌법 4조 4항("되는 것만 응답")에 직결한다.

**본 감사는 흡수(1건 57분)가 아니다.** 단일 질문만 확인하는 경량 작업이다.

## 5. 출처 취득 — 제약 고지

쌍아 환경에서 `canada.ca` 직접 취득이 **WebFetch 403 / curl 차단**으로 실패했다. 접근 경로가 환경마다 다르다.

- **1순위**: `officialSource` 원문 직접 취득
- **2순위**: 원문 불가 시 검색 교차 확인 — 단 **"2차 출처"임을 판정 기록에 명시**하고, 1차로 승격하지 말 것
- 어느 쪽도 안 되면 **⚠️ 불명** 처리. 추측 금지
- **취득 방법을 건별로 기록**한다 (다음 Phase의 도구 선택 근거가 된다)
