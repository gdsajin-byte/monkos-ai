### 2. 초기화 + 결제 요청 변경 (line 342~355)

```javascript
// 변경 전
  try {
    var tossPayments = TossPayments(TOSS_CLIENT_KEY);
    var payment = tossPayments.payment({ customerKey: currentUser.id });

    payment.requestPayment({
      method: 'CARD',
      amount: { currency: 'KRW', value: pkg.amount },
      orderId: orderId,
      orderName: 'MONKOS ' + pkg.credits + ' 크레딧',
      successUrl: window.location.origin + '/credits?toss=success',
      failUrl: window.location.origin + '/credits?toss=fail',
      customerEmail: currentUser.email || undefined,
      customerName: currentUser.name || undefined,
    });

// 변경 후
  try {
    var tossPayments = TossPayments(TOSS_CLIENT_KEY);

    tossPayments.requestPayment('카드', {
      amount: pkg.amount,
      orderId: orderId,
      orderName: 'MONKOS ' + pkg.credits + ' 크레딧',
      successUrl: window.location.origin + '/credits?toss=success',
      failUrl: window.location.origin + '/credits?toss=fail',
      customerEmail: currentUser.email || undefined,
      customerName: currentUser.name || undefined,
    });
```

**변경 포인트:**
- `tossPayments.payment({ customerKey })` 제거 (v2 전용 메서드)
- `payment.requestPayment({method: 'CARD', amount: {currency, value}})` → `tossPayments.requestPayment('카드', {amount: value})`
- amount 형식: `{ currency: 'KRW', value: N }` → 단순 숫자 `N`
