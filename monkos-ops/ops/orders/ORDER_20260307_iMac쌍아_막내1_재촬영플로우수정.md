## 작업 내용

### Phase 1: retakePhoto() 수정

**파일**: `monkos_AI/idphoto-kr/public/result.js`

현행 `retakePhoto()` (라인 146-155)를 아래로 교체:

```javascript
// ─── 재촬영 ───
function retakePhoto() {
  // Step 2 (리터칭 전): 확인 없이 바로 준비실 이동
  if (!store.generated) {
    clearForRetake();
    return;
  }

  // Step 3 (리터칭 후): 확인 모달
  const ok = confirm(
    '현재 사진을 삭제하고 다시 촬영하시겠습니까?\n리터칭 비용(10c)은 복구되지 않습니다.'
  );
  if (!ok) return;

  clearForRetake();
}

function clearForRetake() {
  // store 초기화
  store.captured = null;
  store.generated = null;
  store.cropped = null;
  store.statusText = '';
  store.showStep2Actions = false;
  store.showStep3Actions = false;

  // sessionStorage 이전 결과 제거
  sessionStorage.removeItem('monkos_generated');
  sessionStorage.removeItem('monkos_compare');
  sessionStorage.removeItem('monkos_pending_action');
  try { sessionStorage.removeItem('_mo_p'); } catch(e) {}

  // 촬영 준비실로 이동 (옵션 재선택 가능)
  navigateTo('prep.html');
}
```

**핵심 변경:**
1. 리터칭 후(`store.generated` 존재): `confirm()` 확인 모달 표시
2. `sessionStorage` 이전 결과 전량 제거 (`monkos_generated`, `_mo_p`, `monkos_compare`, `monkos_pending_action`)
3. `camera.html` → **`prep.html`** (촬영 준비실)로 이동 경로 변경
