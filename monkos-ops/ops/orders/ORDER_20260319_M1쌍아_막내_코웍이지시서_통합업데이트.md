## Task 2 — 블로그 목록 카테고리 탭 + 언어 필터

### 맥락
코웍이 목업(`DESIGN_blog_mockup.html`, 3/15)에 카테고리 탭과 언어 필터가 설계됐으나,
3/15 막내 처리 시 "라이트 테마 전환"만 완료됨. 탭/필터 구조가 미구현인 채로 포스트 수가 늘어난 상태.

### 지금은?
- `/blog` 목록: 라이트 테마 그리드 카드 + 페이지네이션 (정상 작동)
- 필터: `?lang=ja` URL 파라미터는 존재하지만 UI 없음
- 카테고리 탭: 없음
- 파일: `lib/cms/render.js` → `blogListFragment` 함수

### 무엇을?
`/blog` 목록 상단에 언어 필터 탭 + 카테고리 필터 추가

### 어떻게?

**2-A. 언어 필터 탭** (기존 `?lang=` 파라미터 활용)

`blogListFragment` 내 `cardsHtml` 생성 바로 위에 탭 HTML 삽입:

```js
const langTabs = [
  { code: null, label: 'ALL' },
  { code: 'ko', label: 'KO' },
  { code: 'ja', label: 'JA' },
  { code: 'en', label: 'EN' },
].map(t => {
  const isActive = (lang === t.code) || (!lang && !t.code);
  const href = t.code ? `${prefix}/blog?lang=${t.code}` : `${prefix}/blog`;
  return `<a href="${href}" class="lang-tab${isActive ? ' active' : ''}">${t.label}</a>`;
}).join('');
```

**2-B. 카테고리 필터** (Firestore `category` 필드 기반)

```js
// URL 파라미터 추가
const catFilter = url.searchParams.get('cat');

// 쿼리에 category 필터 추가 (lang과 병행)
if (catFilter) query = query.where('category', '==', catFilter);
```

카테고리 목록: `AI`, `메이크업`, `사진`, `여권·비자`, `취업·이력서` (현재 Firestore 실제 값 기준)

**2-C. 필터 UI 구조**

```html
<div class="blog-filters">
  <div class="filter-row">
    <span class="filter-label">언어</span>
    <div class="lang-tabs"><!-- langTabs 삽입 --></div>
  </div>
</div>
```

CSS는 기존 라이트 테마 변수(`--accent`, `--border`) 준수.

**주의**: Firestore 복합 쿼리(lang + category 동시 필터)는 복합 인덱스 필요.
동시 필터 구현 전 인덱스 생성 필요 여부 확인 후 단계적 적용.

### 완료 조건
- `/blog?lang=ja` → JA 포스트만 표시, 탭에 JA 활성화
- `/blog?cat=메이크업` → 해당 카테고리만 표시
- 필터 없을 때 ALL 탭 활성화
- dev 배포 후 URL 보고
