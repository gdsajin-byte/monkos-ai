### 팝업 동작

**경로 A: 카카오 로그인으로 무료 받기**

1. 카카오 로그인 실행 (기존 `openAuthPopup()` 재사용)
2. 로그인 성공 콜백:
   - `POST /api/credits/event` → `eventType: "signup_bonus"` → 30c 지급
   - 팝업 UI 업데이트: "✅ 카카오 로그인 30c 증정 완료"
3. 이벤트 선택지 표시:
   - "SNS 공유" 버튼 클릭 → 텔레그램 공유 실행 → 완료 확인 → `POST /api/credits/event` → `eventType: "sns_share"` → 40c 지급
   - "전후사진 활용 동의" 체크 → `POST /api/credits/event` → `eventType: "photo_consent"` → 40c 지급
4. 30c + 40c = 70c 달성 → `cropAndGoToThankyou()` 실행 (크레딧 차감은 서버에서 정상 처리)

**경로 B: 바로 결제 ₩10,150**

1. 토스 결제 실행: `buyCreditsKR(10150, 0)` — amount=10150, credits=0 (크레딧 적립 아님)
   - orderId: `DIRECT_${Date.now()}_${random}`
   - successUrl/failUrl: 현재 페이지
2. 결제 성공 리다이렉트 → `?toss=direct&paymentKey=...&orderId=...&amount=...`
3. `initFromTossResult()` 에서 `toss=direct` 감지:
   - `POST /api/payments/toss/direct` → downloadToken 수령
   - `GET /api/download/direct?token=xxx` → 성공 시 `cropAndGoToThankyou()` 실행
4. 결제 실패 → alert 표시

### 팝업 스타일

- 기존 OAuth 모달 스타일 재사용 (반투명 오버레이 + 중앙 카드)
- 디자인 시스템 준수 (docs/infrastructure/DESIGN_SYSTEM.md 참조)
- 모바일 퍼스트 (화면 하단 시트 스타일)
