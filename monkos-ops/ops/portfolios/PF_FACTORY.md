# PF_FACTORY — 4060 GPU 팩토리

> 4060이 밤새 돌고, 아침에 결과물이 쌓여 있다.
> GPU 생산 설비 + 모델 연구소 + 텔레그램 보고/지시 체계.

---

## 1. 비전

**"GPU는 소모품이고 연구 체계가 본체 — 데이터가 쌓일수록 진화하는 AI 연구소"**

### 왜 이것을 하는가

- **4060 GPU 유휴**: RTX 4060이 커밋 봇 하나 돌리고 놀고 있음. n8n도 빈 껍데기
- **팩토리 봇 체계 존재**: Firebase Functions 기반 양방향 통신(보고/상태/지시)이 이미 뼈대로 있으나 방치 상태
- **GPU 작업 수요**: 모델 테스트, 비교 자료 생성, 오픈소스 에셋 제작, 파인튜닝 — 전부 GPU 필요
- **AUTOPILOT과 짝**: AUTOPILOT = 클라우드 접착 레이어, FACTORY = 로컬 GPU 생산 라인
- **살아있는 연구소**: 매일 반복적인 테스트·학습·축적이 돌아가면서 스키마가 정밀해지고 비교 테이블이 완성 → PF_RND에 결정적 자료 제공

### 핵심 원칙

> **하드웨어는 교체된다. 5090이 오면 GPU만 바뀌고, 스키마·데이터·파이프라인은 그대로 계승된다.**
> 4060은 첫 번째 인스턴스일 뿐, 연구 체계 자체가 본체.

### 4060 팩토리의 4대 역할

**① 오픈소스 추적 (데이터 축적)**
- HuggingFace / Civitai 신규 모델 자동 추적
- 벤치마크 자동 실행 → 비교 테이블 축적
- PF_CHATBOT devlog 체계(RQ 레지스트리 + 서론 6단계) 준용
- 데이터가 쌓일수록 스키마 업그레이드 → 데이터 정합성 → 비교 테이블 완성

**② 모델 연구소 (R&D)**
- 1~2B급 모델 파인튜닝 (4060 VRAM 8GB 범위, LoRA/양자화)
- 다양한 모델 테스트 + 벤치마크 비교 자료 생성
- 결과 → PF_CHATBOT / PF_PHOTOPRO / PF_RND에 환류
- 지원사업 시 "이 팀의 연구 역량" = 이 데이터

**③ 야간 생산 (배치 작업)**
- 이미지 생성 배치 (ComfyUI / n8n 파이프라인)
- 콘텐츠 에셋 대량 생산 (배너, 프로필 변환, 룩북)
- 오픈소스 모델로 에셋 만들기

**④ 텔레그램 보고/지시 (팩토리 봇)**
- Firebase `/notifyWriter` → MONKOS.AI 채팅방으로 보고
- 작업 완료/에러/질문 실시간 알림
- 향후 `getCommands` 활성화 시 텔레그램에서 원격 지시

### AUTOPILOT과의 관계

```
PF_AUTOPILOT (클라우드)          PF_FACTORY (로컬 GPU)
  GitHub Actions                   4060 RTX 4060
  Workers AI                      ComfyUI / PyTorch
  CF / Cloud Run                  파인튜닝 / 추론
       │                               │
       └──────── Firebase ──────────────┘
                (팩토리 봇)
              MONKOS.AI 채팅방
                    │
                 작가님
```

- AUTOPILOT: 클라우드 자동화 (수집, 브리핑, 배포, 동기화)
- FACTORY: 로컬 GPU 생산 (이미지, 모델, 에셋)
- Firebase 팩토리 봇: 둘의 보고를 하나의 채팅방으로 통합

### 성공 지표

| 지표 | 시작점 | 4주 목표 | 12주 목표 |
|------|--------|---------|----------|
| 4060 야간 가동률 | 0% | 주 3회 야간 배치 | 매일 야간 자동 |
| 팩토리 봇 보고 | 방치 | 작업 완료/에러 보고 가동 | 양방향 (지시 수신) |
| 모델 테스트 건수 | 0 | 월 2건 비교 보고서 | 월 4건+ |
| 파인튜닝 실험 | 0 | 1~2B 1건 PoC | 서비스 투입 |
| 에셋 생산량 | 수동 | 주 1배치 | 일일 자동 배치 |
