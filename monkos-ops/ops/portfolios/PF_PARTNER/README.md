## 1. 비전

**"MONKOS AI 증명사진을 채용플랫폼 안에서 네이티브로 제공한다. 화이트라벨이 아닌 코브랜딩 — 우리 브랜드가 노출된다."**

### 핵심 원칙

- **코브랜딩**: "Incruit x MONKOS AI" — 화이트라벨(브랜드 숨김) 거부. MONKOS 인지도 확보가 입점의 전제
- **독점 = 교환재**: 채용/이력서 SKU 한정 독점을 줄 수 있으나, 대가는 코브랜딩 전면노출 + 적극 홍보 + MG
- **MG 없는 독점 절대 불가**: MG가 독점의 가격. "독점 주면 MG 사라"
- **서비스 경계 분리**: 채용/이력서 SKU 한정. 비자대행·여권사진은 본진 별도 서버 완전 분리
- **침투가격 전략**: 월 정액 + 포함 건수 + 초과 쉐어. 구체 숫자는 미팅 카드

### 사업 맥락

- 인크루트: MAU 41만(앱), 웹 350~540만/월, 채용플랫폼 4위. 연매출 ~343억
- 잡코리아: 554만/월, 사람인: 487만/월 — Phase 2~3 확장 대상
- 언더독 × 언더독: 인크루트도 업계 4위. 서로의 무기가 되는 구조

## 1.5 카테고리 맵 (침투 세그먼트)

> 증명사진/AI사진이 B2B 가치를 갖는 7개 세그먼트. 채용/구직만 P1 디테일, 나머지는 확장 슬롯. 상세: 플레이북 §2.

| 카테고리 | 대표 타겟 | 사진 용도 | 침투 앵글 | 가격 성격 | 우선순위 |
|---------|----------|----------|----------|----------|---------|
| **채용/구직** | 인크루트·잡코리아·사람인·원티드 | 이력서 | 회원혜택·차별화 | 침투가 | **P1 (진행)** |
| 교육/자격 | 시험원서·자격증·학원·대학 | 원서 | 규격 자동화 | 중립 | P2 (슬롯) |
| 공공/여권 | 여권대행·비자·민원 | 여권·신분증 | 규격·반려 방지 | 중립 | P2 (슬롯) |
| 금융/KYC | 비대면계좌·증권·보험 | 신분증 인증 | 본인확인 UX | 프리미엄 | P3 (슬롯) |
| HR/기업 | 사원증·인트라넷·헤드헌팅 | 사원증·프로필 | 온보딩 자동화 | 프리미엄 | P3 (슬롯) |
| 결혼/프로필 | 결혼정보·소개팅 | 프로필 | 첫인상 품질 | 중립 | P3 (슬롯) |
| 플랫폼/긱 | 배달·대리·셀러등록 | 등록사진 | 대량 온보딩 | 침투가 | P2 (슬롯) |

> 카테고리는 좁히지 않는다 — 퀄리티만 받쳐주면 수요처는 넓다. 슬롯은 우선순위일 뿐 배제가 아니며, 발굴은 전 카테고리 병렬. 타겟 명단: [TARGET_CONTACTS.md](TARGET_CONTACTS.md)

## 1.6 플레이북 5축 요약

> 인크루트 1건에서 추출한 재사용 자산. 전문은 플레이북 본문 참조.

- **5대 교훈(L1~L5)**: ①숫자 0의 역설(방향성 시그널은 흘려라) ②네이티브 강제 부메랑(통합 깊이 옵션화) ③매출 프레임 함정(마케팅비/회원혜택 리프레임) ④독점=MG ⑤3층 격리 신뢰
- **① 제안서 시스템**: [공통 코어]+[카테고리 모듈]+[상대별 커스텀] 3블록 조립 + 사명 오기 방지 체크리스트
- **② 판매전략**: 월정액+포함건수+초과종량(도매단가 기반)·S/M/L 티어·독점=MG·MAP 자기잠식 방어·2단계 가격 공개
- **③ 침투전략**: 진입경로 4종(콜드/백채널/파일럿/인바운드)·언더독×언더독·거절 대응 5단 플로우
- **④ 배포전략**: 비독점 → 카테고리 병렬. 템플릿 복제비 ≈ 0. "P1 안정화 → 차 카테고리 PoC → 확산"
- **⑤ 로드맵**: 메타-0(플레이북 확정) → 채용-P1 → 채용-P1.5(구현) → 차카테고리 PoC

## 4. 기술 설계 요약

### 4.1 3층 격리 아키텍처

```
[인크루트 프론트]          [MONKOS]
     │                     │
     └─── ① iframe 감옥 ───┘  ← 프론트 격리
              │
         ② Partner API GW      ← 결과물만 전달
              │
         ③ 엔진 격리            ← 프롬프트·모델·원가 금고
```

- 인크루트에 전달하는 것: iframe URL + API 명세서 + 에러 코드표
- 인크루트가 볼 수 없는 것: 코드, 프롬프트, 모델명, 원가, 아키텍처

### 4.2 원가 구조

| 항목 | 단가 |
|------|------|
| API 원가 (Pre-check + 생성) | ~₩58/건 |
| 인프라 포함 실원가 | ~₩100~120/건 |
| 작가님 기준 마진 포함 | ~₩200/건 |

### 4.3 인프라 여력

- Cloud Run: max_instances 10, concurrency 80 → 월 ~100만 건 가능
- 인크루트 예상: 월 ~2만 건 = 인프라 사용률 2%
- Gemini API Tier 2: RPM 500 vs 인크루트 분당 ~1건 = 0.2%
- K8s 불필요

### 4.4 현행 노출 표면 (선행 보강 필수)

| 취약점 | 심각도 | 상태 |
|--------|--------|------|
| `/health` 모델명 노출 | 극심각 | ⏳ |
| `err.message` 직통 반환 | 극심각 | ⏳ |
| 관리자 API 프롬프트 반환 | 극심각 | ⏳ |
| (4번째 항목 — 6/16 세션 상세 참조) | 심각 | ⏳ |
