# PF_PARTNER — B2B 코브랜딩 입점

> 채용플랫폼 B2B 코브랜딩 입점의 정본 PF. 인크루트가 Phase 1이며, 동일 템플릿으로 잡코리아·사람인 등 멀티 플랫폼 복제 확장.

---

## 1. 비전

**"MONKOS AI 증명사진을 채용플랫폼 안에서 네이티브로 제공한다. 화이트라벨이 아닌 코브랜딩 — 우리 브랜드가 노출된다."**

### 핵심 원칙

- **코브랜딩**: "Incruit x MONKOS AI" — 화이트라벨(브랜드 숨김) 거부. MONKOS 인지도 확보가 입점의 전제
- **독점 = 교환재**: 채용/이력서 SKU 한정 독점을 줄 수 있으나, 대가는 코브랜딩 전면노출 + 적극 홍보 + MG
- **MG 없는 독점 절대 불가**: MG가 독점의 가격. "독점 주면 MG 사라"
- **서비스 경계 분리**: 채용/이력서 SKU 한정. 비자대행·여권사진은 본진 별도 서버 완전 분리
- **침투가격 전략**: 월 정액 + 포함 건수 + 초과 쉐어. 구체 숫자는 미팅 카드

### 사업 맥락

- 인크루트: MAU 41만(앱), 웹 350~540만/월, 채용플랫폼 4위. 연매출 ~343억
- 잡코리아: 554만/월, 사람인: 487만/월 — Phase 2~3 확장 대상
- 언더독 × 언더독: 인크루트도 업계 4위. 서로의 무기가 되는 구조

## 4. 기술 설계 요약

### 4.1 3층 격리 아키텍처

```
[인크루트 프론트]          [MONKOS]
     │                     │
     └─── ① iframe 감옥 ───┘  ← 프론트 격리
              │
         ② Partner API GW      ← 결과물만 전달
              │
         ③ 엔진 격리            ← 프롬프트·모델·원가 금고
```

- 인크루트에 전달하는 것: iframe URL + API 명세서 + 에러 코드표
- 인크루트가 볼 수 없는 것: 코드, 프롬프트, 모델명, 원가, 아키텍처

### 4.2 원가 구조

| 항목 | 단가 |
|------|------|
| API 원가 (Pre-check + 생성) | ~₩58/건 |
| 인프라 포함 실원가 | ~₩100~120/건 |
| 작가님 기준 마진 포함 | ~₩200/건 |

### 4.3 인프라 여력

- Cloud Run: max_instances 10, concurrency 80 → 월 ~100만 건 가능
- 인크루트 예상: 월 ~2만 건 = 인프라 사용률 2%
- Gemini API Tier 2: RPM 500 vs 인크루트 분당 ~1건 = 0.2%
- K8s 불필요

### 4.4 현행 노출 표면 (선행 보강 필수)

| 취약점 | 심각도 | 상태 |
|--------|--------|------|
| `/health` 모델명 노출 | 극심각 | ⏳ |
| `err.message` 직통 반환 | 극심각 | ⏳ |
| 관리자 API 프롬프트 반환 | 극심각 | ⏳ |
| (4번째 항목 — 6/16 세션 상세 참조) | 심각 | ⏳ |
