# B2B 타겟 컨택 DB (시드)

> PF_PARTNER 부속 데이터. 카테고리별 침투 대상 + 컨택 채널 골격.
> ⚠️ **이메일·연락처는 공개 출처 확인 후에만 기입(헌법 4조 1항 — 추측·생성 금지).** 미수집은 `TBD`.
> 갱신: 발굴 파이프라인이 신규 타겟 append, status는 협상 진행에 따라 갱신. (append 우선, status는 상태반영 갱신)

## 우선순위 스코어링 기준
`규모·트래픽` + `퀄리티 수요 강도`(증명사진이 핵심 마찰점인가) + `백채널 유무` + `B2B 예산 여력` → P1(즉시) / P2(근시일) / P3(중장기)

## 상태 라이프사이클
`미접촉 → 1차발송 → 회신 → 협상 → 계약 → 보류/실패`
