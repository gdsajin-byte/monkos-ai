# PF_IDPHOTO — MONKOS 증명사진 통합 포트폴리오

> MONKOS의 주력 상품. 크롭(무료)으로 유입하고 AI 생성(유료)으로 전환하는 이중 구조.
> **PF_PHOTOPRO**(AI 증명사진 웹 서비스) + **PF_CROP**(IDPASS 크롭앱)을 통합 승격.
> Image Pro MVP(01/11) → idphoto-kr/jp(01/16) → 결제 퍼널 v5(03/05) → IDPASS iOS 앱(05/12~) → 통합 리팩토링(05/18~).

**"AI로 누구나 전문가 수준의 증명사진을 30초 안에 완성 — 크롭은 무료, AI 생성은 $2"**

### 포지셔닝

| 구분 | 경쟁사 | MONKOS |
|------|--------|--------|
| 크롭 | $1.50~$8.90/컷 | **무료** (IDPASS) |
| AI 생성 | $2.33~$13.95/컷 | **$1.99/컷** (시장 중앙값 $2.33 이하) |
| 서버 의존 | 사진 업로드 필수 | **온디바이스** (Vision+PersonSegmentation, 서버 전송 0) |

### 수익 구조

```
IDPASS (무료 iOS 앱) ──→ AI 증명사진 생성 ($1.99 IAP)
```

## 5. 복기

### 교훈 1: 제1원칙 — 동일인 유지
AI 생성 이미지에서 원본과 다른 인물이 나올 수 있음. 제1원칙(정체성 보존) 최우선. photo.js 패턴 준수.

### 교훈 2: SEO 사각지대 (04/11 진단)
286 sitemap URL → Google 색인 1개. CSR + 메타 부재 = 광고비 증발. 자산 완성과 노출 동선은 같은 사이클에 묶어야.

### 교훈 3: iOS 시뮬레이터 Vision 미지원 (05/13)
시뮬레이터에서 Vision CoreML 추론 불가. CIDetector fallback 적용. 실기기에서 Vision 정상 동작 확인됨.

### 교훈 4: CGContext 좌표계 — 땜질 금지 (05/13)
CGContext bottom-left origin에서 UIKit drawRect 좌표 불일치. 보정 상수 얹는 건 항상 틀린 방향. **CIImage 기반 렌더링으로 전면 교체**하여 근본 해결.

### 교훈 5: Apple Vision > ISNet (05/13)
PersonSegmentation: 시스템 내장(0MB), 1~2초, 품질 ISNet(40MB) 대비 우위. 네이티브 앱에서는 플랫폼 내장 API를 먼저 평가할 것.

### 교훈 6: 기본 UX는 간결, 전문가 기능은 옵션 (05/13)
크롭앱은 "정확함"과 "쉬움" 동시 보장. 2트랙 분리(기본=자동→다운로드, 정밀=프레임+줌+패닝).

### 교훈 7: 시장 가격 구조 (05/18 전수조사)
