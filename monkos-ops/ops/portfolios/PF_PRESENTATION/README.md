# PF_PRESENTATION — 몽코스 프레젠테이션 시스템

> 몽코스 3D 캐릭터가 브리핑하는 프레젠테이션 시스템. 당면 목표는 디딤돌 대면평가(4/9)이나, 본질은 유튜브/릴스/틱톡까지 확장 가능한 콘텐츠 파이프라인 구축.

---

## 1. 비전

**"자료를 넣으면 몽코스가 브리핑한다 — NotebookLM 위의 단계"**

### 왜 이것을 하는가

- 같은 메시지도 몽코스가 브리핑하면 크리티컬하게 다르다 — 기술력의 시각적 증명
- PT 하나로 끝나지 않음: 디딤돌(4/9) → 강한소상공인(4/24) → AX(4/21) → 유튜브/릴스/틱톡 재활용
- "앱을 만드는 것이 아니라, 앱을 만들어내는 시스템을 만드는 것" — 그 자체를 보여주는 수단
- 향후 Gemini Live + 멀티에이전트 백엔드 연결 시, 실시간 Q&A까지 확장
- **핵심 파이프라인**: 자료 입력 → AI 슬라이드+대본 자동 생성 → 몽코스 3D 자동 브리핑 → 영상/실시간 PT
- NotebookLM = 오디오 오버뷰(팟캐스트), MONKOS = **3D 캐릭터 시각 브리핑** — 한 단계 위
- **PT ≠ 프레젠테이션 전용**: 유튜브 영상, 교육 콘텐츠, 뉴스 등 콘텐츠 자동화 엔진
- **렌더링 레이어 교체**: 몽코스 3D → 실사 모델(다인, 세나 등) 교체 시 뉴스/교육/다양한 콘텐츠로 즉시 확장
- 도메인: **pt.monkos.ai** (Cloud Run)

### 성공 지표

| 지표 | 시작점 | 4주 목표 | 12주 목표 |
|------|--------|---------|----------|
| 3D 캐릭터 액션 종류 | 6종 (프로토) | 10종+ | 풀 리깅 |
| TTS 엔진 | Web Speech API | Gemini Native Audio / ElevenLabs | 커스텀 보이스 확정 |
| 콘텐츠 산출물 | 0 | 디딤돌 PT 영상 1건 | 유튜브 3건+ |
| 슬라이드 시스템 | 더미 5장 | 12장 실제 콘텐츠 | 범용 슬라이드 엔진 |

### Phase 1.5 — 콘텐츠 정밀 수정 ✅ 완료 (04/07)

> 04/03 피드백 → 04/05 8시퀀스 전면 교체 + TTS 발음 교정 전건 반영 → 04/07 시연 완료.

#### 피드백 ①: S7 원가 소명 논리 전환

**기존 (삭제)**: "$0.04 vs $10, 마진 99.6%" — 팩트 불일치 (증명사진 앱 가격 80원~8불)
**수정 방향**: 비용 자랑이 아니라 **퀄리티 보장으로 전환**
- 4K 고화질에 해당하는 이미지가 혁신적으로 파일 용량이 줄었다
- 비용이 문제가 아니라 **퀄리티의 보장이 MONKOS의 차별점**
- 정체성 보존율, ICAO 규격 자동 검증, 478포인트 얼굴 분석
- "싸게 만드는 게 아니라 정확하게 만드는 것"

#### 피드백 ②: TTS 발음 교정

- "RAG"를 "락"으로 발음하는 등 영문 약어 발음 문제
- 대본 TTS용 변환 테이블 필요: RAG→래그, LLM→엘엘엠, API→에이피아이, RLHF→알엘에이치에프 등

#### 피드백 ③: S12 시연 슬라이드 재구성

**기존**: 4칸 카드에 키워드만 나열
**수정 방향**: 각 서비스마다 **캡처 화면 + 제안서 원문 인용 + AX 과제 연결 + 한 줄 펀치**
- 예: RAG 챗봇 → 캡처 + "나보다 우리 가게를 잘 아는 챗봇"(제안서 원문) + "에티버스 RAG 기반 지식검색 엔진"(AX 과제) + "래그 시스템은 모호한 개념이 아니라 혁신과제로 평가받는 기술 분야"

#### 피드백 ④: 발표 구조 확정

```
작가님 직접 (2~3분): 인사 + 전반적 흐름 세팅
몽코스 자동 (10분): 논리 제시 + 캡처/데이터 근거 화면 동시 표시
작가님 직접 (2~3분): 마무리 + 재평가 요청
Q&A (15분): 작가님 구두 답변 + 몽코스가 보조 자료 화면 전환
  → Q&A용 슬라이드 별도 세트 필요 (원문 vs 평가 비교차트, 상세 증빙)
```

- 현재 러닝타임 약 7분 30초 → **10분 언저리로 조정** 필요
- 슬라이드 내 캡처 사진/데이터 삽입으로 PT 자체 퀄리티 향상
