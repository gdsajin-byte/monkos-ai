# PF_EVENT — 매출 전환 이벤트 포트폴리오

> **목표**: 5월 첫 결제 발생. Phase A(cash burn) → B(임계점 10~20만 후기) 돌파 엔진.
> **원칙**: "결제와 후기를 사는 전략" — zero margin 의도. 얻는 것은 paying customer + UGC + 파이프 검증.

---

## §1. 이벤트 구조

```
채널 이벤트 광고 (카카오/LINE/X/유튜브/인스타/note)
  → 쿠폰 코드 수령
  → ₩9,900 결제 (KR 토스 / JP 레몬스퀴즈)
  → AI 증명사진 촬영·생성 (원본+비교본 GCS 자동 저장)
  → 스벅 2잔 증정 + 추가 100c (친구소개용)
  → 포털 후기 방 → 전후 비교사진 버킷에서 자동 로딩
  → 텔레그램 봇 즉시 알림 → 작가님 즉각 확인·처리
  → 후기 외부 공유 (GBP·네이버 플레이스·X) → 추가 보너스
```
