# PF_FACEREAD — 사주×관상 리포트

> **전략 정본 (2026-08-01 작가님 확정): "취업사진으로 들어오는 사람에겐 관상을 팔고, 관상으로 들어오는 사람에겐 좋은 관상의 사진을 판다."**
> A문 = 사진 구매자 → 관상 리포트 업셀 (마찰 0 ARPU 부스터) / B문 = 관상 유입 → "인상 보증" 사진 판매. A문 리포트 공유 → B문 유입 재귀.

## 원칙 (불변)

1. **정통 기반** — 해석은 원전(마의상법·유장상법·신상전편, 퍼블릭 도메인) 인용 필수. 인용 없는 룰 등재 금지. LLM 자유생성 금지, 룰 텍스트 렌더만 (7/24 어젠다 "엉터리 금지")
2. **측정 없는 해석 금지** — 모든 판정은 랜드마크+공식에 명시 바인딩
3. **연출 가변축만 판다** — 표정·헤어·그루밍·조명·각도는 가변, 골격(삼정·오행형·코·턱·광대·대칭)은 불변. 골격 변형 = 헌법 1조 3항 정체성 보존 위반
4. **판정관이 아니라 이야기꾼** — 취업 연결은 연출 코칭만. "관상=채용 근거" 프레임 금지. 엔터테인먼트 디스클레이머 + 타인 평가 용도 금지 문구 상시
5. **정직하지만 부드럽게** — tone 필드로 부정 단정 금지, 주의 환기형만. 미검증 기능 미출고(웹캠·기색·절대 퍼스널컬러 진단)
