# PF_FACEREAD — 사주×관상 리포트

> **전략 정본 (2026-08-01 작가님 확정): "취업사진으로 들어오는 사람에겐 관상을 팔고, 관상으로 들어오는 사람에겐 좋은 관상의 사진을 판다."**
> A문 = 사진 구매자 → 관상 리포트 업셀 (마찰 0 ARPU 부스터) / B문 = 관상 유입 → "인상 보증" 사진 판매. A문 리포트 공유 → B문 유입 재귀.

## 원칙 (불변)

1. **정통 기반** — 해석은 원전(마의상법·유장상법·신상전편, 퍼블릭 도메인) 인용 필수. 인용 없는 룰 등재 금지. LLM 자유생성 금지, 룰 텍스트 렌더만 (7/24 어젠다 "엉터리 금지")
2. **측정 없는 해석 금지** — 모든 판정은 랜드마크+공식에 명시 바인딩
3. **연출 가변축만 판다** — 표정·헤어·그루밍·조명·각도는 가변, 골격(삼정·오행형·코·턱·광대·대칭)은 불변. 골격 변형 = 헌법 1조 3항 정체성 보존 위반
4. **판정관이 아니라 이야기꾼** — 취업 연결은 연출 코칭만. "관상=채용 근거" 프레임 금지. 엔터테인먼트 디스클레이머 + 타인 평가 용도 금지 문구 상시
5. **정직하지만 부드럽게** — tone 필드로 부정 단정 금지, 주의 환기형만. 미검증 기능 미출고(웹캠·기색·절대 퍼스널컬러 진단)

## 시장 전략 (2026-08-01 쌍아 설계 · 작가님 지시 기록)

### 구조 — 문은 셋, 도착지는 하나

| 층 | 판단 | 근거 |
|----|------|------|
| 엔진·DB·검증·총평 프롬프트 | **분리** | 원전에 "사주 X + 관상 Y = 결론 Z" 결합 규칙표 **없음** → 교차 해석 = 창작 = 원칙 1 위반. 또한 사주는 만세력 공표값이라는 **외부 정답지가 있고** 관상은 없다. 섞으면 사주의 검증 가능성이 관상의 불확실성에 오염되어 "공표값 대조 검증" 셀링을 못 쓴다 |
| 유입(랜딩·키워드·SEO) | **분리** | 사주·관상·취업사진은 각각 다른 검색 수요층. 사주는 얼굴 없이 생년월일만으로 성립 → **제3의 문**(사진 없는 사용자 유입) |
| 리포트·상품·과금 | **병합** | 쪼개면 각각 얇아 단가 미달(사주 단독은 무료가 시장 표준) + 얼굴 실측이라는 유일 차별점 상실 + 양문형 교차판매 동선 붕괴 + 운영 2벌 |

- **유일한 정당 접점 = 오행(五行)**. 관상 오행형과 사주 오행이 같은 5원소를 공유 → "두 관법이 같은 방향을 가리킨다"는 **일치/불일치 표시까지만** 허용. 새 사실 생성 금지
- ⚠️ **p8 종합 통변 총평 AI 입력을 관상 카드로 한정**할 것. 두 축을 한 프롬프트에 넣으면 LLM이 시키지 않아도 연결 서술을 만들어 교차 해석이 발생하며, 화이트리스트 검사로는 잡히지 않는다(어휘가 전부 입력 안에 있음)

### 서구 원칙 (진출 전제조건)

- **"physiognomy" 직역 금지** — 19세기 골상학·우생학과 연결된 오염어. "AI가 얼굴로 사람을 판정"은 최근 AI 윤리 논쟁 정중앙
- 관상 표기는 **"Face Reading"**(중국 전통 面相 계보) — 뉴에이지·웰니스 카테고리에 이미 정착, 동양 지혜 프레임으로 소비
- 사주 표기는 **"Chinese astrology / BaZi"** — 생년월일 기반 운세 프레임이 이미 익숙, 문화 장벽 없음. 띠(zodiac animal) 인지도 높음
- **원칙 4(판정관 아닌 이야기꾼) + 엔터테인먼트 디스클레이머는 서구에서 장식이 아니라 생명줄**

### 우선순위

1. 한중일 + 화교권·베트남 — 번역만. **원문이 한문이라 ZH가 가장 싸고 정확**(다국어 비용이 거꾸로 감). 바이두·샤오홍슈 바이럴 소재
2. 서구 **사주 단독**(BaZi) — 관상 없이 먼저 진입
3. 서구 관상(Face Reading) + 라틴아메리카
4. 인도 후순위 / 이슬람권 회피

### 정면 2D 단독 커버리지 (뷰 확장 투자 판단 근거)

- **형태 판정의 약 8할이 정면 1장으로 커버됨** — 십이궁 완전 8·부분 3(재백·질액=코 높이, 처첩=함몰 깊이), 삼정 3 전부, 오행형 5 전부, 오관 4관(귀 불가), 십삼부위 위치 전부(산근·연상·수상 **높이**만 불가)
- **고전 관상 자체가 정면 서술** — 십이궁도·십삼부위총도·백세유년도가 모두 정면 도판. 정면 1장은 원전의 반쪽이 아니라 원전이 선 자리
- **진짜 결손은 뷰가 아니라 기색(氣色)과 신(神)** — 둘 다 사진 장수로 해결 불가. 기색은 조명이 결과를 뒤집고(표준조명 사진관에서만 해소), 신은 정지 이미지가 원리적으로 못 담음
- **다각도 수집(액티브 라이브니스) 안 → 하향 이연.** 셀카는 90° 불가·45° 한계이며, 억지 자세는 목빗근 긴장으로 하악·입꼬리가 끌려가 **평상(平常) 샘플이 깨진다**(작가님 지적, 08-01). 자세를 잡아주는 **실물 사진관 티어에서만 유효**
- 실무 규칙: **못 보는 항목을 리포트에 명시할 것**("귀·코 높이·기색은 측정 범위 밖"). 엉터리가 아님을 증명하는 가장 강한 신호이자 상위 티어 훅

> 권역 판단은 도메인 지식 기반 추정 — 실측 아님. 실측 신호는 GSC뿐(민아 07-29 분석: India·Indonesia·Philippines·Vietnam 실클릭 + 스페인어권 쿼리 1페이지 진입). 진출 전 권역별 검색량 실측(`/market-eye`) 선행 필요.
