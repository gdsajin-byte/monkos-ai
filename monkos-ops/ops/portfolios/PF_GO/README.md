## 1. 비전

- **입구**: 혼자서도 바로 두는 AI 대국(KataGo 최강·급수 상대) — 타이젬 수준의 대기실·대국실·기보 감상을 기본기로.
- **차별**: "가장 인간적인 시스템" — 엔진 사실 + 인문학·바둑 언어로 해설하는 바둑 해설 LLM(메모리 project_go_commentary_llm_vision). 자산 = 짝 데이터 + 작가님 감수.
- **원칙**: 기본기능 먼저, 작은 단위(1건 반영 → 실사용 확인 → 다음 건). 타 서비스 체험은 사이트 카드로 축적(PF_CDP).
- **서비스 형태 (작가님 11-05 07:01)**: 앱을 깔아도 되고 웹에서 대국해도 되는 하나의 서비스. **대국실은 웹이 지원**해 모바일·PC 어디서든 타이젬처럼 사람끼리 서로 대국이 된다(웹 = 대국실·대기실·관전의 정본 서버). 앱은 같은 대국실에 들어오는 클라이언트 + 오프라인 AI 대국(MONK 봇 온디바이스, 아이폰 17 Pro 1500v 1.5초 실측). AI 대국 엔진 위치: 웹 = 서버 엔진 / 앱 = 기기 엔진(유료 KataGo 다운로드 포함).
- **출시 전 교체 필수 자산**: 타이젬 참조 팩 `tygem-ref` — 소리(`DEFAULT_PACK`, index.html 508행)와 **판·돌 스킨**(같은 상수로 기본값, 511행) 둘 다. 자체 소리 팩 8종 후보는 11-05 반영, 스킨은 미착수.
  - 11-05 10:3x: 자체 목소리 팩 `monk-annakim`(Anna Kim, 목소리는 자체)의 **착수·따냄음 = tygem-ref `stone*.mp3` 심볼릭 링크**(작가님 10:36 "돌소리는 당분간 타이젬 유지") — 출시 전 자체 녹음으로 교체. 팩 note에 '내부' 표기 → 목록에 "(내부 실험 — 출시 전 교체)".
