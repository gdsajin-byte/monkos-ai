# PF_STUDIO — AI 촬영실 UX + 내부 스튜디오

> 사용자가 스마트폰으로 증명사진을 촬영하는 과정의 UX 전반 + 내부 B/A 대량 생산 스튜디오 앱.
> "촬영 → 코칭 → 크롭 → 결과" 흐름에서 코칭·촬영실 부분을 담당.

---

## 1. 비전

**"AI가 코칭하는 촬영실에서 누구나 규격 맞는 증명사진을 한 번에 찍는다"**

### 왜 이것을 하는가

- 메인 페이지 → camera 전환율 92% 이탈. 촬영실 UX가 서비스 전환의 핵심 병목
- 음성 코칭(Gemini Live)으로 "머리 좀 돌려주세요" 같은 실시간 안내가 가능해짐
- 내부 스튜디오(T2I→I2I SPA)로 마케팅용 B/A 샘플을 무한 생산 가능
- 20년 사진관 경험(작가님)을 AI 코칭 프롬프트로 전이 — 경쟁사 불가 영역

### 성공 지표

| 지표 | 시작점 (3/6) | 4주 목표 | 12주 목표 |
|------|-------------|---------|----------|
| camera→result 완주율 | 미측정 | 측정 체계 구축 | 60%+ |
| 코칭 사용률 (옵트인) | 미측정 | 측정 체계 구축 | 30%+ |
| 평균 촬영 횟수/세션 | 미측정 | 측정 체계 구축 | 1.5회 이하 |
| 스튜디오 B/A 생산 | 0 | 50+쌍 | 200+쌍 |

## 5. 복기

### 교훈 1: TTS vs Gemini Live 선택 (3/6~7)

**현상**: 초기 음성 코칭을 TTS 기반으로 구현했으나, 일방향이라 촬영 타이밍 안내에 부적합.
**원인**: Gemini Live Native Audio가 검증 전이었고, TTS가 빠르게 구현 가능했기 때문.
**대응**: Gemini Live 검증 완료 → TTS 삭제, Gemini Live로 전환. "빠른 구현 < 맞는 기술" 교훈.
