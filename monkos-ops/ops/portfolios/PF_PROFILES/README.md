# PF_PROFILES — AI 프로필 사진 서비스

> 증명사진과 분리된 독립 앱으로 스타일링 템플릿 기반 AI 프로필 사진 생성 서비스를 구축한다. 증명사진(무료 미끼) → 프로필스(수익 상품) 전환 전략의 핵심 수익 엔진.

---

## 1. 비전

**전문 프로필 사진을 AI로 — 스타일링 템플릿 선택만으로 완성**

### 왜 이것을 하는가

- 증명사진 무료 체험 → 프로필스 전환이 수익 구조의 핵심 (증명사진 단독으로는 LS 수수료·광고비 대비 수익 불가)
- 초기 SPA 시절 4배치(증명 2 + 프로필 2) 구조 → 검증 완료. 엔진·크롭·배경 파이프라인 안정화된 지금이 재구축 적기
- 증명사진과 UX가 완전히 다름 — 스타일링 템플릿, 갤러리, 다양한 용도별 출력. 독립 앱이 맞음

### 성공 지표

| 지표 | 시작점 | 4주 목표 | 12주 목표 |
|------|--------|---------|----------|
| 프로필스 생성 수 | 0 | MVP 내부 테스트 | 일 50건 |
| 증명사진→프로필스 전환율 | 0% | 측정 시작 | 10% |
| 프로필스 결제 전환율 | 0% | 측정 시작 | 15% |

## 5. 복기

### 교훈 1: SPA 시절 4배치 구조

**현상**: 초기에 증명 2컷 + 프로필 2컷을 한 번에 생성하는 구조로 운영
**원인**: 하나의 앱에서 모든 걸 처리 → UX 혼재
**대응**: 프로필은 독립 앱으로 분리. 전문성 있는 스타일링 템플릿 + 갤러리 제공

### 교훈 2: 소액 결제 수수료 구조

**현상**: 10c(₩1,450) 단위 결제 시 LS 수수료 비율이 과다 → 수익 불가
**원인**: 생성 원가 ≈₩100 + LS 수수료 + 광고비 = 적자
**대응**: 증명사진은 무료 미끼(10c 증정), 프로필스에서 고단가 회수
