# PF_SPREAD — 콘텐츠 제작·배포·마케팅 종합 전략

> **SPREAD** = Strategic Publishing, Reach, Engagement, And Distribution.
> 콘텐츠를 한 번 만들면 21개 채널로 전방위 배포하는 오케스트레이션 체계.

---

## 1. 비전

**"한 번 쓰면 전방위로 퍼진다 — 21채널 콘텐츠 오케스트레이션"**

### 왜 이것을 하는가

- monk.kr/monkos.ai 블로그 원본이 있어도 외부 유입 채널이 부재하면 트래픽 성장 한계
- 채널별 톤·포맷이 다르므로 단순 복사가 아닌 **채널 최적화 가공**이 필요
- 에이전트(코웍이) 기반 배포로 n8n 코드 파이프라인의 한계(톤 획일화, API 미제공 채널) 돌파
- 작가님 20년 사진관 경험 + 42건 에피소드 카탈로그 = 콘텐츠 소재 풀 확보
- 한송이(JP 마케팅) + 꾸(스튜디오) + 코웍이(전략) 인력 구조가 멀티 채널 운영 가능

### 성공 지표

| 지표 | 시작점 (3/4) | 4주 목표 | 12주 목표 |
|------|-------------|---------|----------|
| 활성 배포 채널 수 | 3 (블로그, 네이버, 인스타) | 8+ | 15+ |
| 주간 콘텐츠 발행량 | 1~2건 | 5+건 | 10+건 |
| 외부 채널 유입 비율 | 미측정 | 측정 체계 구축 | 30%+ |
| 콘텐츠 재활용률 (원본→파생) | 1:1 | 1:3 | 1:5 |
