# PF_RND — 정부 R&D·IP·창업 지원사업 통합 추적

> 정부·공공 R&D·IP·창업·컨설팅 지원사업의 생애주기(기안→접수→선정→수행→정산)를 통합 관리하는 허브.
> Phase 1 실무는 각 트랙 담당 라인이 수행하며, 이 PF는 추적·교차점검 허브일 뿐이다.

---

## 1. 비전

**"정부 R&D·IP 사업을 다중 트랙으로 병렬 관리 — 마감·중복·정산 누락 0건"**

### 왜 이것을 하는가

- 다수의 정부 지원사업이 동시 진행 → 마감·제출·상태 추적이 분산
- 사업 간 중복지원 위반 여부 교차 점검 필요
- 정부지원금 수령·분담금·정산 현황 통합 조회 불가
- 에이전트(쌍아·민아·막내) 간 "현재 어느 사업 어느 단계" 실시간 공유 부재

### 성공 지표

| 지표 | 시작점 (04/24) | 단기 (~05/31) | 중기 (~12/31) |
|------|---------------|--------------|--------------|
| 추적 중 사업 수 | 2 | 3 | 5+ |
| 접수 완료 사업 수 | 0 | 2 (강한소상공인 + RIPC 2건) | 3~5 |
| 정부지원금 수령액 | 0 | 선정 결과 대기 | 선정 시 ~1,000만원+ |
