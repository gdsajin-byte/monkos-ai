# PF_CHATBOT — MONKOS 통합 AI 챗봇

> 작가님이 없는 시간에도 MONKOS가 사용자와 대화한다.
> 하나의 엔진(chatWithMonkos)이 6채널을 서빙하고, 같은 지식을 공유하며, 각 채널의 맥락에 맞게 응답한다.
> 온라인은 Gemini, 오프라인은 EXAONE — 어디서든 MONKOS는 말할 수 있다.

---

## 1. 비전

**"하나의 뇌, 여섯 개의 입 — 어디서든 MONKOS와 대화하는 경험"**

### 왜 이것을 하는가

- 고객 접점이 웹·텔레그램·카카오·LINE·인앱으로 분산 — 채널마다 별도 봇을 만들면 지식 불일치 발생
- 작가님 원칙: "RAG로 전체를 공유하고 각자 위치에 맞는 시스템 프롬프트로 엔진시스템을 만들면 되잖아?" (02-19)
- 헌법 4조 4항: "되는 것만 응답" — 챗봇은 MONKOS의 얼굴, 거짓말하면 브랜드 신뢰 붕괴
- 온디바이스 분기: 네트워크 없이도 AI 시연 가능해야 한다 (지원사업 대면평가 등)

### 성공 지표

| 지표 | 시작점 | 현재 | 목표 |
|------|--------|------|------|
| 채널 수 | 1 (웹) | 6+1(온디바이스) | 8+ |
| 응답 정확도 | 미측정 | 체감 양호 | 정량 평가 체계 |
| 모델 비용/월 | ~$5 | ~$5 | ≤$25 (3.1-flash-lite 전환 후) |
| 응답 지연 | 미측정 | ~2초 | ≤1.5초 |

**현상**: Gemini 2.5/3.0에서 응답이 10~26자로 절삭 (05/09)
**원인**: thinking 기본 활성화 → maxOutputTokens 300을 사고 토큰에 전부 소비
**대응**: thinkingConfig: { thinkingBudget: 0 } 또는 maxOutputTokens 1024+. 3.1-flash-lite는 thinking 없음

### 교훈 3: 모델 벤더 의존성은 리스크다

**현상**: Gemini 2.0 Flash EOL 공지 — 21건 의존성, 23일 마감 (05/09)

## 7. 사업화 프레임

### 차별성 — 뭐가 다른데?

**하나의 엔진, 여섯 개의 채널 — 경쟁사에 없는 구조**

| 차별점 | MONKOS | 경쟁사 (29개사 전수조사 기준) |
|--------|--------|---------------------------|
| 채널 통합 | 6채널 1엔진 (웹·텔레그램·카카오·LINE·인앱코칭·QC) | 웹 챗봇 1개 또는 없음 |
| RAG 지식 공유 | 전 채널 동일 지식베이스 + 채널별 프롬프트 분기 | 채널별 별도 구축 (지식 불일치) |
| 온디바이스 AI | USB 포터블 챗봇 (EXAONE 3.5, 네트워크 불요) | 해당 없음 |
| 도메인 특화 | 증명사진 ICAO 규격·촬영 코칭·QC 판정 일체 | 범용 CS봇 |
| 온/오프라인 연결 | AI 실패 → 오프라인 AS 즉시 전환 (손실→매출) | AI 전용 또는 오프라인 전용 |

**핵심 MOAT**: 증명사진 도메인 지식(ICAO 규격 DB + 국가별 규정) + 6채널 통합 엔진 + 온/오프 전환. 이 조합을 갖춘 경쟁사는 29개사 중 0개사.

### 사업 모델 — 어떻게 돈 버는데?

| 수익 경로 | 메커니즘 | 현재 상태 |
|----------|---------|----------|
| **전환 유도** | 챗봇이 서비스 안내 → 크레딧 구매 퍼널로 자연 유도 | 가동 중 |
| **CS 자동화** | 24시간 무인 응대 → 인건비 절감 (CS 1명 = 월 200만원+) | 가동 중 |
| **이탈 방지** | 촬영 코칭 채널이 실시간 가이드 → 실패율↓ 재구매율↑ | 가동 중 |
| **다국어 확장** | 동일 엔진에 JP/EN 프롬프트만 추가 → 해외 시장 한계비용 ≈ 0 | KR·JP 가동 |
| **B2B 라이센싱** | 통합 엔진을 타 사진 서비스에 API 제공 (향후) | 계획 |

**BM 핵심**: 챗봇 자체가 과금 대상이 아니라, **서비스 전환율을 높이는 엔진**. 비용 센터가 아닌 매출 증폭기.

### 수익 전망 — 얼마 벌 거 같아?

| 항목 | 현재 | 6개월 후 | 12개월 후 |
|------|------|---------|----------|
| 챗봇 운영비/월 | ~$5 (Gemini 2.0) | ~$15 (3.1-flash-lite) | ~$25 (트래픽 성장) |
| CS 인건비 절감/월 | 추정 50~100만원 | 100~150만원 | 200만원+ |
| 전환율 기여 | 미측정 | 정량화 목표 | A/B 테스트 |
| 이탈 방지 효과 | 체감 | 코칭 채널 데이터 분석 | 정량 보고 |

**BEP 관점**: 챗봇 운영비 월 2~3만원 vs CS 인건비 절감 월 100만원+ → **이미 ROI 양수**. 트래픽 증가 시 비용은 선형, 절감은 지수적.

### 확장성 — 더 커질 수 있어?

| 확장 축 | 방향 | 난이도 | 기대 효과 |
|---------|------|--------|----------|
| **채널** | 인스타그램 DM, 네이버 톡톡, 웹 위젯 | 낮음 (CHANNEL_CONFIG 1행 추가) | 접점 2배 |
| **언어** | EN, ZH 프롬프트 추가 | 낮음 | 글로벌 시장 |
| **도메인** | 프로필 사진, 여권 사진, 이력서 사진 | 중간 (RAG 시드 추가) | TAM 3배 |
| **B2B** | API 서비스화 → 타 사진관/무인부스 업체에 제공 | 높음 | 신규 매출 |
| **온디바이스** | USB 배포 → 전시회·대면평가·오프라인 키오스크 | 완료 | 오프라인 데모 |
| **대화 데이터** | 축적된 대화 → 사용자 불만/니즈 분석 → 서비스 개선 | 중간 | 데이터 자산 |

**확장의 본질**: chatWithMonkos 아키텍처가 **채널 추가 = 설정 1행**으로 설계되어 있음. 엔진을 다시 만들 필요 없이 프롬프트만 추가하면 새 채널이 열린다. 이것이 "하나의 뇌, 여섯 개의 입"의 사업적 의미.
