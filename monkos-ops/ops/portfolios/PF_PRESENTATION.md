# PF_PRESENTATION — 몽코스 프레젠테이션 시스템

> 몽코스 3D 캐릭터가 브리핑하는 프레젠테이션 시스템. 당면 목표는 디딤돌 대면평가(4/9)이나, 본질은 유튜브/릴스/틱톡까지 확장 가능한 콘텐츠 파이프라인 구축.

---

## 1. 비전

**"자료를 넣으면 몽코스가 브리핑한다 — NotebookLM 위의 단계"**

### 왜 이것을 하는가

- 같은 메시지도 몽코스가 브리핑하면 크리티컬하게 다르다 — 기술력의 시각적 증명
- PT 하나로 끝나지 않음: 디딤돌(4/9) → 강한소상공인(4/24) → AX(4/21) → 유튜브/릴스/틱톡 재활용
- "앱을 만드는 것이 아니라, 앱을 만들어내는 시스템을 만드는 것" — 그 자체를 보여주는 수단
- 향후 Gemini Live + 멀티에이전트 백엔드 연결 시, 실시간 Q&A까지 확장
- **핵심 파이프라인**: 자료 입력 → AI 슬라이드+대본 자동 생성 → 몽코스 3D 자동 브리핑 → 영상/실시간 PT
- NotebookLM = 오디오 오버뷰(팟캐스트), MONKOS = **3D 캐릭터 시각 브리핑** — 한 단계 위
- **PT ≠ 프레젠테이션 전용**: 유튜브 영상, 교육 콘텐츠, 뉴스 등 콘텐츠 자동화 엔진
- **렌더링 레이어 교체**: 몽코스 3D → 실사 모델(다인, 세나 등) 교체 시 뉴스/교육/다양한 콘텐츠로 즉시 확장
- 도메인: **pt.monkos.ai** (Cloud Run)

### 성공 지표

| 지표 | 시작점 | 4주 목표 | 12주 목표 |
|------|--------|---------|----------|
| 3D 캐릭터 액션 종류 | 6종 (프로토) | 10종+ | 풀 리깅 |
| TTS 엔진 | Web Speech API | Gemini Native Audio / ElevenLabs | 커스텀 보이스 확정 |
| 콘텐츠 산출물 | 0 | 디딤돌 PT 영상 1건 | 유튜브 3건+ |
| 슬라이드 시스템 | 더미 5장 | 12장 실제 콘텐츠 | 범용 슬라이드 엔진 |
