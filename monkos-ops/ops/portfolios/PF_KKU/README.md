# PF_KKU — 꾸 콘텐츠 + Specs 디자인 허브

> 꾸와 M2/쌍아의 협업 허브. 네이버 블로그 콘텐츠 생산 + monkos.ai/specs 페이지 디자인을 양축으로 운영한다.

---

## 1. 비전

**네이버 블로그(유입) ↔ specs 페이지(전환) 양축 전략**

### 왜 이것을 하는가

- 몽크사진관 온라인 노출 확대 (네이버 검색 + AI 검색)
- 꾸의 하루 콘텐츠 루틴 체계화
- 채널별 최적 포맷 자동화로 생산성 향상
- **specs 페이지를 콘텐츠 착지점으로 가꿔 콘텐츠→전환 루프 완결**

### 2축 분업 구조 (2026-06-12 확정)

| 축 | 담당 | 내용 |
|----|------|------|
| **글로벌/소셜 배포** | 작가님 | 블로그 생성 루틴 시스템 → X·스레드·노트닷컴 등 다채널 살포 |
| **네이버+specs 디자인** | 꾸+M2/쌍아 | 네이버 블로그 원본 생산 + specs 페이지 디자인·콘텐츠 가꾸기 |

### 성장 경로

1. **미국비자사진** 하나로 패턴 확립 (네이버 블로그 ↔ `/specs/us-visa` 양축)
2. 패턴 잡히면 수백 국가·용도로 복제 (SEO/GEO 자동 업데이트)
3. 각 specs 페이지에 크롭앱·증명생성앱을 백엔드로 붙여 콘텐츠→서비스 자연 전환 (Photo Aid 모델)

### specs 현황 (2026-06-12)

- 총 **445개** 규격 등록 (`specs-data.json`)
- SSR 렌더링 + 3티어 전환 퍼널 (무료크롭 → AI프리미어 → 스튜디오)
- 라우트: `/specs`, `/specs/{slug}`, `/ja/specs/...`, `/en/specs/...`

### 하루 루틴

| 순서 | 채널 | 포맷 |
|------|------|------|
| 1 | 네이버 블로그 | 원본 글 (SEO+AIO 최적화) |
| 2 | 네이버 새소식 | 요약 버전 |
| 3 | 구글 게시물 | Google Business 포맷 |
| 4 | 인스타그램 | 카드뉴스 또는 영상 |
| 5 | 유튜브 | 영상 |
| 6 | 핀터레스트 | 핀 이미지 |
| 7 | 페이스북 | 공유 포맷 |

### 콘텐츠 작성 기준

- **PSSR 공식**: 문제 → 고통 → 해결 → 결과
- **고객이 주인공**, 브랜드는 조력자
- **한 문장 24자 이하**, 간결함 원칙
- **가치사다리** 인식 → 다음 단계 연결
- **네이버 검색 SEO + AI 검색(AIO) 최적화 필수**
- 상세: `Documents/Claude/Projects/꾸 전용 프로젝트/CLAUDE.md`
- 스토리텔링: `Documents/Claude/Projects/MONKOS AI 블로그/지침/스토리텔링_지침.md`
