# PF_ANCHOR — 사진관·가계 존속 × 꾸 체납 정리

> MONKOS의 모든 세션은 "작가님 가용시간 파편·수익 전환 최우선·신규 고정비 신중"이라는 전제 위에 선다. 그 전제를 만드는 실물 조건 — 사진관 임대 존속, 가계 현금흐름, 복지·부채 조정, 꾸 명의 체납 — 을 한 문서에서 추적한다. 배가 떠내려가지 않게 잡는 앵커.
> **개인정보 경계**: 본 PF는 결정·수치·메타만 담는다. 주민번호·계좌 등이 든 원문 서류는 레포 밖(작가님 데스크탑 `꾸세무관련/`)에 두고 여기서는 존재만 가리킨다.

## 1. 비전

**"2027-05 윈도우까지 사진관을 옵션으로 살려두고, 그 안에서 가계 안전망(수급·부채 조정)과 꾸 체납 소멸 경로를 완성한다."**

### 왜 이것을 하는가

- 사진관 존속 여부가 MONKOS 인화 통합·오프전환 실증·꾸 콘텍츠 루틴의 전제를 바꾼다 — 결정이 세션 로그에 흩어지면 전제가 세션마다 재발견된다
- 재계약 12개월·특례 기한 2028-12·시효 2031까지 **다년 과제**이며 게이트·체크리스트·결정 근거를 상태로 봐야 한다 (세션 로그는 시간순, 메모리는 200줄 상한)
- 두 트랙이 구조적으로 얽혀 있다: **보증금 = 꾸 특례 자금원 / 사업장 = 꾸 노동의 압류 무풍 통로 / 수급 실태조사 = 두 트랙을 동시에 본다**. 분리하면 연결이 문서 사이에 떨어진다

**현상**: 09-01 "압류 있음 + 채권 없음 = 시효 소멸 방증" 가설 → 09-02 국세 압류 8건 연속으로 기각. **원인**: 상담원이 읽어준 1건을 전량으로 가정. **대응**: 압류권자·사건번호 전건 서면 확보가 판정 선행 조건.

### 교훈 2: 수치가 크기를 정한다
**현상**: 금 시세·부가세 25만·-u 파손 위험 등 부수 변수에 시간 소모. **원인**: 결정 변수(계약 성립·매출 궤적)와 두 자리 뒤 변수의 크기 비교 누락. **대응**: 변수 제기 시 "이 협상에서 몇 만 원짜리인가"를 먼저 잰다.

### 교훈 3: 임차인이 먼저 낼 조항이 아니다
**현상**: 민아가 답신 초안에 미이행 시 해지·명도 동의 특약을 권함. **원인**: 신뢰 장치를 임차인 비용으로 선제 제공. **대응**: 작가님이 걸러냄 — 불리 조항은 상대 요구 시 검토. 협상 문서 검수 시 "누가 낼 조항인가" 축 추가.
