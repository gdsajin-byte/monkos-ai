# 대리 운영 규칙 — 축적본

> **취지 (작가님 2026-09-04)**: 대리는 소득만이 아니다 — 걷고 자전거 타고, 선선한 저녁에 이른 식사·금주·운동이 붙는 루틴. 낮에 개발해 수익을 만들기 시작하고 퇴근길에 월 ~200을 얹는 구조. §10 #15(건강 단일 실패점)의 방어책이 #8(소득 램프)에 내장된 형태. 목표는 310 push가 아니라 **200~250(밸런스 상한) + 건강**으로 읽는다. 전업 몰빵이면 300+ 가능하나 낮 개발·사진관·건강 밸런스를 깬다(작가님 09-04). 산식: 어제형(순 ~9만) 평일 16~18일 + 주말·운 좋은 날(20만+) 2~4일 ≈ 216~240.

> 작가님 현장 실측이 정본. 민아 추정은 `(추정)` 표기, 운행내역으로 확인되면 표기 제거.

## 1. 수락 기준

- **시급 2만** = 콜 수락 기준. 분모는 **픽업 접근 + 운행 + 복귀** 총시간. 분자는 **실수익**(수급액 아님 — 카카오 화면 큰 글씨=수급액, 작은 글씨=수익. 수수료 20%).
- 월 계획 평균은 **1.7만**(대기·공차 포함). 150만 = 하루 4~5콜(주 4일) / 3.4~4콜(주 5일).
- 3줄 규칙:
  1. **3만+ 시내행** → 잡는다.
  2. **2~3만** → 도착지가 복귀 불가 동(가래여울마을·강변 외곽·조안·수동·퇴촌·남종)이면 거른다.
  3. **2만 미만** → 판정 기준은 금액이 아니라 **기회비용**: 이 콜이 더 큰 콜을 놓치게 하는가.
     - 콜 빈번 구간(피크 잠실·천호) = 거른다(운행 40분간 노출 차단).
     - 콜 희소 구간(화도 20~22시, 공백 시간) = **잡는다**. 대기 시간의 기회비용 0 → 순 1만도 이득 (작가님 09-03 교정).
     - 단, 접근·복귀비가 요금의 40%를 넘으면 거른다. **택시 접근은 요금의 20% 이내**(4.1만 콜에 7천 = OK / 1.6만 콜에 6.4천 = 과다).
- 러시아워(18~20:30) **서울 동서 횡단 콜은 거른다** — 요금은 거리, 시간은 정체. 5만 이상만 예외.
- **정체 2시간 콜은 돈보다 체력을 태운다** (09-04 공릉행 실증: 낮 11만 후 정체 2h 운행 → 밤 피크에 이동 에너지 소진, 미사 회귀만 바라게 됨). 낮 블록을 뛴 날은 러시아워 장거리를 요금 불문 거르고, 밤 블록은 사무실 반경에서만.
- 서쪽(강서·양천·부천) = **21시 이후 & 3.5만+**. 복귀는 5호선 단일선(까치산·신정→미사)이라 쉬움.
- 원거리 예약콜(설악·청평·양평) = **이미 그 권역에 있을 때만.** 미사 출발 이동 2h + 운행 1.5h = 1.3~1.5만/h.
- 자차 대기 전술(차 세워두고 도는 것)은 **사무실 20분 반경**에서만. 원거리 회수는 막차·고립 리스크.

## 4. 픽업 접근

- **공유 킥보드·전기자전거**(지쿠·빔·카카오T 바이크): 1~3km에 **2.5~3천**(잠금해제 500~1,000 + 분당 150~200). 택시의 절반이라 생각보다 비쌈(작가님 09-04). 하루 2회면 월 ~13만.
  - **서울권(천호·고덕·강일·잠실) = 따릉이 정기권** — 30일 5,000원, 1시간 이내 무제한. 접근비 사실상 0. 하남·남양주엔 대여소 없음.
  - **하남·남양주권 = 공유 앱 정기권/패스** 검토(월 1~2만, 회당 ~1천 수준) 또는 **사무실 비치 접이식 자전거**(20~30만, 하루 2회 기준 2개월 회수).
  - 판단 규칙: 접근 거리 ≤1.5km 도보 / 1.5~4km 자전거·킥보드 / 그 이상은 요금 20% 이내 택시.
- 가래여울은 반납 구역 밖 → **강빛초교 라인**까지 타고 도보 10분(총 ~15분). 앱별 경계 상이 — 강일 방향 경계 가장 넓은 앱 1개 고정.
- 야간은 킥보드보다 **전기자전거**, 가방에 **접이식 헬멧**(KC/CE EN1078). §10 #15 단일 실패점.

## 4.5 퇴근 복귀 (하남 → 화도)

- **동승·셔틀이 최선** (작가님 09-04): 같은 방향 기사와 동승 또는 기사 셔틀(경춘·구리·남양주 노선, 정액 2~5천). 이득 = 귀가 택시비 회피(~2만) + 마지막 콜을 귀가 방향에 묶지 않아도 됨(+1콜). 합 ~2만/일.
- 찾는 곳: 대리기사 커뮤니티·오픈채팅의 하남/남양주 라인 셔틀, 자주 마주치는 동료.
- **역방향 카드 (작가님 09-04, 급하지 않음)**: 사무실에 자차가 있으니 퇴근 때 같은 방향 기사를 **내 차에 태워** 함께 퇴근 → 무상 동승이라 법적 회색 0, 친분 → 정보(콜 밀도 높은 동네·시간대, 셔틀 라인, 앱 팁)·상호 동승·비상 시 도움. 사진관 유입 네트워크로도 연결 가능(기사 = 지역 정보 허브). 비용 = 기름값 소폭. 관계 자산은 급하게 만들지 않는다.
- 주의: 심야 유상 카풀은 법적 회색(자가용 유상운송) — **실비 분담 선**에서. 셔틀은 업계 관행이나 단속 사례 있음.
- 차선: 귀가 방향 콜(화도·마석·평내) → 없으면 경춘선 막차(상봉 환승) → 없으면 사무실 취침(미사).

## 5.5 개선 여지 (2026-09-04 작가님)

09-03 순 89,200은 **무투자·고정비 0 조건**의 바닥값: 로지·안드로이드 없음, 개인 모빌리티 없음, 카카오T·티맵 아이폰 2앱만, 체력 안배로 택시 과감히 사용(접근비 21%). 개선 레버(비용 순):

| 레버 | 기대 효과 | 비용 | 판정 |
|---|---|---|---|
| 접근비 21% → 10% (공유 바이크 우선, 택시는 요금 20% 이내) | 순 +1만/일 | 0 | 즉시 |
| 낮 가든 블록 활성(15~17시, 평일) | +1~2콜/일 | 0 (수업 없는 날) | 이번 주 검증 |
| 티맵 비중 확대(경쟁 낮음) + 카카오 등급 상승 | 콜 확보율 ↑ | 0 (시간) | 자연 누적 |
| 로지(로지소프트) 추가 = 콜 풀 확장 | 콜 수 ↑ | 안드로이드 기기 필요(중고 10~20만) + 월 프로그램비 | **보류** — 200~250 밸런스 목표에선 불필요, 300 지향 시만 |
| 개인 접이식 자전거 | 하남권 접근비 → 0 | 20~30만 | **보류 확정**(작가님 09-04: 자전거 적재는 무리). 따릉이는 무동력이라 평지 단거리 보조만 |

> 원칙: 고정비 0 유지. 투자는 "그 투자 없이는 못 잡는 콜"이 주 3회 이상 확인될 때만.
> **경로 (작가님 09-04)**: 지금은 신규라 선호콜·우선배차 등 짬 대우가 없음 → 경력이 쌓이면 콜 밀도·품질이 자연 개선. **9월 하루 순 10만 언저리로 족하고, 연말쯤 15만 언저리** — 편하게 마음먹고 가는 램프. 월 환산: 10만×20일 = 200 / 15만×20일 = 300(주말 포함 시). 등급 효과는 이번 주가 아니라 10~11월 데이터에서 판독.
> **개선 목표(작가님 09-04): 장비 투자 없이 어제 방식 그대로 +20%** — 이동 방식 최적화(거리별 도보/공유/택시 규칙) · 체력 상승 · 콜 확대(낮 블록·티맵) · 대응력(규칙 반사). 순 89,200 → ~107,000/일 = 월 200 라인.
