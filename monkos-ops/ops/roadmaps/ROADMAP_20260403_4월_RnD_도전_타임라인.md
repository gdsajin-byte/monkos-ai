## 5. 마스터 사업계획서 전략 (4/1 합의사항)

> "쐐기 전략" — 멀티 서비스 나열 ❌ → 확장 로드맵 ✅

```
증명사진 (쐐기·진입) → Image Pro (업셀) → B2B API → 교육 Academy → 글로벌 SaaS
```

**데이터셋 우선순위**: D1(론칭 후 실적) > D2(유닛이코노믹스) > D4(비용구조) > D3(일본검증) > D6(특허) > D5(경쟁사)

**리스크**: 일본 시장 매출 0 → 소액 광고 테스트로 CAC 데이터 확보 필수

**공통 프레임**: 마스터 사업계획서 1개 → 트랙별 비중 조절
- 소진공: 상환능력·현금흐름 비중 ↑
- 강한소상공인: 성장성·혁신성 비중 ↑

## 6. 2주 병렬 전략 (4/2 작가님 방향 제시)

> "사업계획서도 결국 컨텐츠와 자료가 뒷받침해줘야 보는이에게 메시지가 전달되지."

| 트랙 | 내용 | 사업계획서 반영 |
|------|------|----------------|
| 서비스 개선 | Studio 안정화, UX 개선 | "이미 운영 중인 서비스" 실적 |
| SPREAD | 콘텐츠 발행, 채널 확장 | "마케팅 채널 N개 운영 중" |
| 포털 UI | 블록 에디터, 디자인 고도화 | "전문성 있는 플랫폼" 인상 |
| SEO/GEO | 색인 개선, 백링크 확보 | "검색 노출 성장률" 데이터 |

**목표**: "하겠다"가 아니라 **"이미 하고 있고, 여기까지 왔다"**
