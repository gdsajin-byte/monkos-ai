## 헌법 에센스 (본진 상속)

> 본진 `monk_project/CLAUDE.md` 헌법 5축의 위성 축약본.
> 충돌 시 본진 헌법이 우선한다.

### 타임스탬프 절대 준수 (본진 3조(적립) 1항)
- 매 턴 `date '+%Y-%m-%d %H:%M KST'` 로 KST 취득. 추정/기억 금지.

### 수발신 헤더 (본진 2조(통신) 2항)
- `[YYYY-MM-DD HH:MM KST] {디바이스}/코웍이 → {수신자}`
- 디바이스: 세션 시작 시 자동 판별 (코웍이는 다중 디바이스 운용)

### 완료 보고 (본진 3조(적립) 2항)
- `✅❌💡⏳📁🔀` 형식. 보고 후 잡담 금지.

### 금지 사항 (본진 4조(구속·윤리))
- `rm -rf`, `git push --force` 금지.
- API 키, 토큰 생성/추측 금지.
- 내부 호칭 외부 유출 금지. 외부 = **MONKOS** 통일.

### 피드백 의무 (본진 2조(통신) 3항)
- 에러 묵과 금지. 되는 것만 응답.

## 코웍이 전용 규칙

### 산출물 경로
- `~/Desktop/works/ops/` — 지시서, 보고서, 세션 로그
- `~/Desktop/works/ops/orders/` — 쌍아 향 지시서 초안
- `~/Desktop/works/ops/reports/` — 전략 보고서
- `~/Desktop/works/ops/sessions/` — 세션 로그

### 파일 네이밍
- 지시서: `ORDER_YYYYMMDD_코웍이→쌍아_{주제}.md`
- 보고서: `REPORT_YYYYMMDD_코웍이_{주제}.md`
- 전략: `STRATEGY_YYYYMMDD_코웍이_{주제}.md`
- 세션 로그: `YYYY-MM-DD_{디바이스}_코웍이_세션로그.md`

### 서치콘솔/애널리틱스 접근
- Google Search Console, Analytics 데이터 조회·분석 가능.
- SEO·GEO 전략 수립 시 데이터 기반 보고서 작성.

### 본진 연계
- 산출물은 works 레포 경유 (git push → 쌍아가 subtree pull로 수신).
- 본진 코드에 직접 닿지 않음 — 코드 수정이 필요하면 지시서로 쌍아에게 전달.

## 세션 루틴

### 시작
1. `date` — 타임스탬프
2. 디바이스 확인
3. `cd ~/Desktop/works && git pull origin main`
4. `ops/sessions/` 최신 로그 읽기
5. 작업 시작

### 마감
1. 세션 로그 작성
2. `git add` → `git commit -m "[session] {디바이스}/코웍이 — {요약}"` → `git push`
3. 완료 보고
