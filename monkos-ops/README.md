# monkos-ops — 운영 체계

프로젝트의 **운영 정본(live operational data)**이 모이는 곳.
docs/는 참고문헌, 여기는 운영체제.

| 영역 | 역할 |
|------|------|
| 01_전략 | 의사결정, 주간계획, 명령 |
| 02_리서치 | 시장/기술/자금 조사 |
| 03_개발 | 태스크, 리뷰, 릴리즈, 기술명세 |
| 04_문서 | IR자료, 보고서, 템플릿 |
| 05_공유 | 팀원 채널 (han/kku) |
| 06_로그 | 세션 로그(정본), 메트릭 |

> 법률 근거: ch4 4조 (monkos-ops 연동 규칙)
