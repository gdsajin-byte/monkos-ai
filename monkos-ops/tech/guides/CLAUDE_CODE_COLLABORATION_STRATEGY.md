## 🤖 Claude Code란?

### **터미널 기반 자동 코드 생성 도구**

```
Claude Code 실행
  ↓
프로젝트 파일 자동 분석
  ↓
요구사항 파악
  ↓
코드 자동 생성
  ↓
테스트 자동 실행
```

**특징**:
- ✅ Opus 4.5 무제한 사용 (Claude Max 계정)
- ✅ 파일 전체 컨텍스트 자동 분석
- ✅ 대규모 리팩토링에 강함
- ✅ 명령 기반 (대화 아님)

## 🛠️ Claude Code 설정 및 사용법

### **1. Cursor에서 Claude Code 확인**

```bash
# Cursor Settings 확인
Cmd + , (설정)
  → Extensions
  → "Claude Code" 검색
  → 설치 확인
```

### **2. Claude Max API 키 연결**

```bash
# Cursor Settings
  → AI Models
  → Claude API
  → Claude Max 계정 API 키 입력
```

### **3. 터미널에서 Claude Code 실행**

```bash
# 기본 사용법
claude-code --help

# 프로젝트 분석
claude-code --analyze

# 특정 작업 실행
claude-code --task "모든 HTML 파일에 Tailwind 클래스 추가"

# 리팩토링
claude-code --refactor --typescript

# 테스트 생성
claude-code --generate-tests
```

```markdown
<!-- .cursorrules에 추가 -->

## Claude Code 사용 규칙

- .cursorrules 규칙 준수
- 변경 사항은 세션 로그에 기록
```

#### **방법 3: 작업 계획서 작성**

```markdown
<!-- _plans/claude_code_task.md -->

# Claude Code 작업 계획

## 목적
전체 프로젝트 TypeScript 변환

## 맥락
- 작가님과 대화로 결정
- 세션: 2026-01-23 13:47
- 규칙: .cursorrules 참조

## 제약사항
- 기존 API 호환성 유지
- 테스트 자동 생성
```

## ⚠️ 주의사항

### **대화 맥락 유지**

```
❌ Claude Code만 사용
  → 의사결정 과정 기록 안 됨
  → 세션 로그 공백

✅ 대화 → Claude Code → 대화
  → 전체 과정 기록됨
  → 맥락 유지
```

### **규칙 준수**

```
❌ Claude Code가 .cursorrules 무시
  → 프로젝트 정책 위반

✅ .cursorrules를 Claude Code에 전달
  → 규칙 준수
```

### **변경 사항 추적**

```
❌ Claude Code 실행 후 그냥 넘어감
  → 무엇이 바뀌었는지 모름

✅ 변경 사항 세션 로그에 기록
  → 추적 가능
```
