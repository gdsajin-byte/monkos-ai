# 프로필스 UI 재설계 — 스타일북 브라우저 + 다중 레퍼런스 입력

## 1. 설계 원칙

- 증명사진 패턴(옵션 칩 → 1장 입력 → 생성) **탈피**
- **스타일북 브라우징 → 다중 레퍼런스 입력 → 생성** 플로우
- 좌측 = 카테고리 네비게이션, 중앙 = 이미지 브라우저/결과, 우측 = 레퍼런스 입력 슬롯
- 프롬프트는 증명사진 정본(`IDENTITY_PRESERVATION`) 사용 금지 — 프로필 전용 프리앰블 별도

## 2. 3컬럼 레이아웃

```
┌──────────────┬────────────────────────────────┬──────────────────┐
│  카테고리 NAV  │  메인 영역                      │  레퍼런스 입력     │
│  (320px)      │  (1fr)                         │  (300px)          │
│               │                                │                   │
│  ▶ 스타일     │  [이미지 그리드 or B/A 결과]     │  7슬롯 + 프리뷰   │
│  ▷ 의상       │  [프롬프트 입력바]               │  [태깅][히스토리]  │
│  ▷ 헤어       │                                │                   │
│  ▷ 포즈       │                                │                   │
│  ▷ 메이크업    │                                │                   │
└──────────────┴────────────────────────────────┴──────────────────┘
```

## 3. 좌측 — 카테고리 네비게이션 (320px)

### 구조

```html
  <div class="cat-item active" data-cat="style">

      <button data-sub="beauty-closeup">뷰티 클로즈업</button>
      <button data-sub="linkedin">링크드인</button>
      <button data-sub="bust-shot">상반신</button>
      <button data-sub="full-body">전신</button>
      <button data-sub="artist">아티스트</button>

    </div>
```

### 동작

- 카테고리 클릭 → 메인 영역에 해당 카테고리의 이미지 그리드 로드
- "스타일"은 서브 카테고리 있음 (뷰티 클로즈업, 링크드인 등) — 완성 샘플 이미지
- 의상/헤어/포즈/메이크업은 개별 레퍼런스 이미지
- 활성 카테고리 하이라이트
- 사이드바 폭 320px (기존 260px보다 확대)

### 성별 토글

좌측 상단에 성별 토글. 선택 시 메인 그리드가 해당 성별 필터링.

```html
<div class="gender-toggle">
  <button class="active" data-val="f">여성</button>
  <button data-val="m">남성</button>
</div>
```

## 4. 중앙 — 메인 영역 (1fr)

### 4-1. 생성 전: 이미지 브라우저

좌측에서 카테고리 선택 → 메인에 이미지 그리드 표시.

```
┌────────────────────────────────────────────────┐
│  의상 — 여성 (7)                          정렬 ▼│
│                                                │
│  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐      │
│  │      │  │      │  │      │  │      │      │
│  │네이비 │  │차콜  │  │블랙  │  │실크  │      │
│  │정장  │  │정장  │  │정장  │  │블라우스│      │
│  └──────┘  └──────┘  └──────┘  └──────┘      │
│                                                │
│  ┌──────┐  ┌──────┐  ┌──────┐                 │
│  │      │  │      │  │      │                 │
│  │터틀넥 │  │데님  │  │브이넥│                 │
│  │      │  │자켓  │  │니트  │                 │
│  └──────┘  └──────┘  └──────┘                 │
│                                                │
│  이미지 클릭 → 우측 레퍼런스 슬롯에 자동 추가    │
└────────────────────────────────────────────────┘
```

- 이미지 카드: 썸네일(120×160) + 라벨
- 클릭 시: 우측 해당 카테고리 슬롯에 추가 + 카드에 체크 표시
- 호버: 확대 프리뷰 (선택)
- 성별 필터 연동

### 4-2. 스타일 카테고리 (완성 샘플)

"스타일" 선택 시 메인에 완성 프로필 사진 샘플이 뜸.
이건 레퍼런스가 아니라 **"이런 느낌으로 만들어줘"** 전체 스타일 지정.
클릭 → 해당 스타일의 프리셋(트리밍+배경+조명+무드)이 자동 적용.

### 4-3. 생성 후: Before / After

생성 버튼 클릭 후 메인이 B/A 뷰로 전환.

```
┌────────────────────────────────────────────────┐
│                                                │
│  ┌─────────────┐     ┌─────────────┐          │
│  │             │     │             │          │
│  │   원본      │     │   생성본     │          │
│  │             │     │             │          │
│  └─────────────┘     └─────────────┘          │
│                                                │
│  [← 스타일북] [다시 생성] [다운로드] [비교컷]    │
│                                                │
└────────────────────────────────────────────────┘
```

- "← 스타일북" 버튼으로 다시 브라우저로 복귀
- B/A 비교컷 Canvas 합성 다운로드 (기존 기능 유지)

### 4-4. 하단: 프롬프트 입력바

생성 전/후 모두 표시. 하단 고정.

```
┌──────────────────────────────────────────┬──┐
│ 추가 지시사항을 자유롭게 입력하세요...      │ ▶ │
└──────────────────────────────────────────┴──┘
 스타일을 선택하거나 직접 설명하세요    NB2 · ~₩92/장
```

## 5. 우측 — 레퍼런스 입력 패널 (300px)

### 5-1. 레퍼런스 슬롯 (최대 7장)

```
┌─ 레퍼런스 입력 ──────────────────┐
│ 적용 레퍼런스               3/7  │
│                                 │
│ ① 👤 내 사진 (필수)             │
│    ┌──────────┐                 │
│    │          │  1024px         │
│    │  드래그   │  메인 정체성     │
│    │  또는    │  [교체] [×]     │
│    │  클릭    │                 │
│    └──────────┘                 │
│                                 │
│ ② 👔 의상                       │
│    ┌────┐ 네이비 정장            │
│    │    │ 512px  [×]            │
│    └────┘                       │
│                                 │
│ ③ 💇 헤어                       │
│    ┌────┐ C컬 단발              │
│    │    │ 512px  [×]            │
│    └────┘                       │
│                                 │
│ ④ 🤳 포즈                       │
│    ┌─ ─ ─┐                     │
│    │  +  │ 드래그 또는 메인에서 선택│
│    └─ ─ ─┘                     │
│                                 │
│ ⑤ 💄 메이크업                    │
│    ┌─ ─ ─┐                     │
│    │  +  │                     │
│    └─ ─ ─┘                     │
│                                 │
│ ⑥ 🖼 추가 ref                   │
│    ┌─ ─ ─┐                     │
│    │  +  │ 자유 레퍼런스         │
│    └─ ─ ─┘                     │
│                                 │
│ ⑦ 🖼 추가 ref                   │
│    ┌─ ─ ─┐                     │
│    │  +  │                     │
│    └─ ─ ─┘                     │
│─────────────────────────────────│
│ [태깅] [히스토리]   탭 스위치     │
└─────────────────────────────────┘
```

### 입력 방법 (각 슬롯)

1. **메인 이미지 브라우저에서 클릭** → 해당 카테고리 슬롯에 자동 추가
2. **직접 드래그앤드롭** — 로컬 파일을 슬롯에 드래그
3. **클릭 → 파일 선택** — 빈 슬롯 클릭 시 파일 다이얼로그

### 슬롯 동작

- 내 사진(①) = 필수. 없으면 생성 버튼 비활성
- 의상~메이크업(②~⑤) = 선택. 있으면 레퍼런스 이미지로 API 전송, 없으면 텍스트 키워드만
- 추가 ref(⑥~⑦) = 자유 슬롯. 분위기 레퍼런스 등 용도 무관
- [×] = 슬롯에서 제거
- 같은 카테고리 재선택 → 기존 교체

### 해상도 정책

| 슬롯 | 입력 해상도 | API 전송 |
|------|-----------|---------|
| 내 사진 | 원본 유지 | 1024px 리사이즈 |
| 의상/헤어/포즈/메이크업 | 원본 유지 | 512px 리사이즈 |
| 추가 ref | 원본 유지 | 512px 리사이즈 |

### 5-2. 하단 탭 (태깅/히스토리)

기존 구현 유지. 슬롯 영역 아래에 작은 탭으로.

## 6. 프로필 전용 프롬프트 (엔진 변경)

### AS-IS (증명사진 정본 — 사용 금지)

```
IDENTITY RULE: 90% SAME PERSON + 10% ENHANCEMENT
... perfectly front-facing, studio flat lighting ...
```

### TO-BE (프로필 전용)

```
PROFILE PHOTO TRANSFORMATION RULES:

IDENTITY: Keep the person's face recognizable — same face shape, eyes, nose, lips, skin tone.
Allow natural variation in expression, angle, and styling.

STYLING: Apply the specified outfit, hairstyle, makeup, and pose from reference images.
The styling should look natural and professionally photographed — not digitally composited.

COMPOSITION: Follow the specified framing (close-up / headshot / bust / waist-up).
The photo should look like it was taken by a professional portrait photographer.

QUALITY: High-resolution, professional studio or lifestyle photography quality.
Natural skin texture, realistic lighting, no artificial smoothing.
```

- 정면 고정 없음 (앵글 자유)
- 스타일 변주 폭 확대 (의상/헤어/포즈 변경 허용)
- 정체성 보존은 유지하되 표현이 유연

### 레퍼런스 이미지 전달 포맷

```javascript
contents: [{ parts: [
  // 1. 메인 사진 (정체성)
  { inlineData: { mimeType: 'image/jpeg', data: mainPhoto } },
  { text: 'This is the main person. Keep their face and identity.' },

  // 2~N. 레퍼런스 (각 역할 명시)
  { inlineData: { mimeType: 'image/jpeg', data: outfitRef } },
  { text: 'Outfit reference: dress the person in this outfit style.' },

  { inlineData: { mimeType: 'image/jpeg', data: hairRef } },
  { text: 'Hair reference: style the hair like this.' },

  // 마지막. 통합 프롬프트
  { text: profilePrompt },
]}]
```

