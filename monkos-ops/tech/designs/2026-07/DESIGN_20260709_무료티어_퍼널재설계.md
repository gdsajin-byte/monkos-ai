# 무료 티어 신설 — "규격 맞추기 완전 무료" 퍼널 재설계

**[2026-07-09 05:07 KST]** M1/쌍아 → 작가님

> 근거: 7/9 새벽 작가님 구두 설계
> 전제: InsightFace 2단 완료 (검출+측량 결정론 확보, Gemini fit 퇴출) → 무료 구간 원가 ~₩20/건
> 관련: DESIGN_20260704_specs_2tier_가격체계.md (기존 T1 ₩2,000 / T2 ₩9,900)

---

## 0. 핵심 전환

기존 가격 장벽이 **결과 확인 전**에 있었다. 사용자는 "이 사진으로 되는지"도 모른 채 결제해야 했다.

```
기존:  업로드 → precheck → [결제] → fit → 배경제거 → 결과
변경:  업로드 → precheck → fit → 배경제거 → postcheck → [결제 분기] → 결과
```

결과를 **확인한 후** 결제하므로 전환율 상승 + "결제했는데 안 됐다" 클레임 구조적 소멸.

## 1. 3-티어 상품 체계

| 티어 | 이름 | 가격 | 내용 | 엔진 |
|------|------|------|------|------|
| **T0 무료** | 규격 맞추기 | **₩0** | 규격 크롭 + 배경 제거 + postcheck + 다운로드 | InsightFace + BiRefNet (코드 결정론) |
| **T1 셀프** | AI 보정 | **₩2,000** | T0 + 피부·조명·정장 AI 보정 | + Gemini/Imagen 생성 |
| **T2 보장** | 발급보장 | **₩9,900** | T1 + 규격 적합 보증 + 반려 시 환불 | + QC 판정 |

- T0 = IDPASS 앱이 무료로 하던 것의 웹 버전. 마케팅 앵커: **"증명사진 규격 맞추기 — 완전 무료"**
- 사다리 원칙 유지: ₩0 < ₩2,000 < ₩9,900. 역전 없음.
- T0→T1 업셀: 무료 결과 화면에서 "AI 보정하면 이렇게 달라져요" 비교 프리뷰.

## 2. 무료 구간 상세

### 2-1. 파이프라인 (T0)

```
사진 업로드
    │
    ▼
① precheck (코드 게이트)
   - 얼굴 비율 20~50%
   - 위치: 상단 5%↑, 하단 5%↑, 중심 15% 이내
   - 조명: 밝기 40~240
   - 검출: 1인 필수
   거부 → 사유 표시 + "다시 올리기"
   통과 → 무언으로 다음 단계
    │
    ▼
② fit 안착 (InsightFace 106점 + fitSpecGeometry)
   - 규격 프레임 기하 계산
   - 시어터 연출 (줌인 → 가이드 라인 → 안착)
    │
    ▼
③ 배경 제거 (BiRefNet)
   - 배경 → 흰색 합성
    │
    ▼
④ postcheck (코드 판정)
   - 머리 높이 mm (규격 범위 내?)
   - 눈 위치 % (40~48%?)
   - 기울기 / 좌우회전 / 눈감김 / 입벌림
   - 뱃지로 pass/warn/fail 표시
    │
    ▼
⑤ 결과 화면 — 원본 vs 완성 비교
   - [무료 다운로드] ← T0 완료
   - [AI 보정으로 더 좋게 — ₩2,000] ← T1 업셀
   - [발급보장 — ₩9,900] ← T2 업셀
```

### 2-2. 원가

| 항목 | 건당 비용 | 비고 |
|------|----------|------|
| normalizeImage (sharp) | ~₩0 | CPU 연산 |
| SCRFD 검출 + 106점 | ~₩1 | Cloud Run CPU ~0.5초 |
| fitSpecGeometry | ~₩0 | 순수 기하 연산 |
| BiRefNet 매팅 | ~₩15~20 | RunPod 대기열 |
| postcheck 판정 | ~₩0 | 코드 연산 |
| **합계** | **~₩20/건** | Gemini 호출 0건 |

- 5회/일 제한 시: 최악 ₩100/사용자/일
- 월 1,000 유니크 × 평균 2회 = ₩40,000/월 — 마케팅 비용으로 무시할 수준

### 2-3. 무료 다운로드 사양

| 항목 | 무료 (T0) | 유료 (T1/T2) |
|------|----------|-------------|
| 해상도 | 원본 화질 기반 (최대 2048px 정규화) | 동일 |
| DPI | 300 | 300 |
| 포맷 | JPEG | JPEG + PNG |
| 배경 | 흰색 (규격 표준) | 흰색 + 커스텀 색상 |
| AI 보정 | ✗ | ✓ (피부·조명·정장) |
| 워터마크 | ✗ (없음) | ✗ |

무료에 워터마크 **없음** — "완전 무료"의 신뢰. 워터마크가 있으면 "무료라고 해놓고 사실 유료"로 읽힌다.

## 3. 유료 분기 (T1/T2)

### 3-1. T1 (AI 보정 ₩2,000)

무료 결과물을 기반으로 **Gemini/Imagen 보정 1회** 실행:
- 피부 톤 균일화
- 조명 보정 (그림자 제거)
- 정장 합성 (선택)
- 동일인 검증 (ArcFace — 향후 3단)

결제 시점: 무료 결과 확인 후 "AI 보정" 버튼 클릭 시.

### 3-2. T2 (발급보장 ₩9,900)

T1 + 규격 적합 보증:
- 규격 판정 전항목 pass 확인
- 반려 시 무료 재제작 또는 환불
- 보장 약관은 별도 법적 검토 필요 (기존 설계서 참조)

## 4. UX 플로우 변경점

### 4-1. 결제 장벽 이동

```
현행:  업로드 → precheck("측정 가능") → [토스 결제] → 생성 → 결과
변경:  업로드 → precheck(무언) → fit 시어터 → 배경제거 → postcheck → 결과
       └─ [무료 다운로드] 또는 [AI 보정 ₩2,000] 또는 [발급보장 ₩9,900]
```

### 4-2. 마케팅 표면

- 스펙스 상세 페이지 상단: **"증명사진 규격 맞추기 — 완전 무료, 로그인 불요"**
- SEO 타이틀: "여권사진 규격 무료 — MONKOS"
- 경쟁사 대비: 대부분 무료라 해놓고 워터마크 또는 저화질 → 우리는 **진짜 무료**

### 4-3. 횟수 제한

| 사용자 | 일일 한도 | 근거 |
|--------|----------|------|
| 비로그인 | 5회 | IP 기반, 원가 ~₩100 |
| 로그인 | 20회 | 계정 기반 |
| 남용 방지 | rate limit 유지 (현행 10req/분) | 봇·크롤러 차단 |

## 6. 이것이 가능해진 이유

| 시점 | Gemini 개입 | 무료 제공 가능성 |
|------|-----------|----------------|
| 6월 | precheck + fit + 소견 + 생성 | ❌ 건당 ₩200+ |
| 7/8 | precheck 퇴출 | ❌ 여전히 fit+소견+생성 |
| 7/9 (현재) | fit + 소견 퇴출 | **✅ 크롭+매팅만이면 ₩20** |

InsightFace 일원화 + Gemini 판정 코드화가 **비즈니스 모델 전환의 전제 조건**이었다.
