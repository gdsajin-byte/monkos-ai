## 0. 핵심 전환

기존 가격 장벽이 **결과 확인 전**에 있었다. 사용자는 "이 사진으로 되는지"도 모른 채 결제해야 했다.

```
기존:  업로드 → precheck → [결제] → fit → 배경제거 → 결과
변경:  업로드 → precheck → fit → 배경제거 → postcheck → [결제 분기] → 결과
```

결과를 **확인한 후** 결제하므로 전환율 상승 + "결제했는데 안 됐다" 클레임 구조적 소멸.

## 1. 3-티어 상품 체계

| 티어 | 이름 | 가격 | 내용 | 엔진 |
|------|------|------|------|------|
| **T0 무료** | 규격 맞추기 | **₩0** | 규격 크롭 + 배경 제거 + postcheck + 다운로드 | InsightFace + BiRefNet (코드 결정론) |
| **T1 셀프** | AI 보정 | **₩2,000** | T0 + 피부·조명·정장 AI 보정 | + Gemini/Imagen 생성 |
| **T2 보장** | 발급보장 | **₩9,900** | T1 + 규격 적합 보증 + 반려 시 환불 | + QC 판정 |

- T0 = IDPASS 앱이 무료로 하던 것의 웹 버전. 마케팅 앵커: **"증명사진 규격 맞추기 — 완전 무료"**
- 사다리 원칙: **₩0 < ₩2,000 < ₩9,900 < ₩15,000(인화)**. 역전 없음.
- T0→T1 업셀: 무료 결과 화면에서 "AI 보정하면 이렇게 달라져요" 비교 프리뷰.
- **T2→인화 업셀** (지시서 확정): 발급보장 결과 화면에서 "인화 주문 +₩5,100 (배송 별도)" → 배송지 입력 → 인화 발송. 합계 ₩15,000.
- **T2 발급보장 = 로그인 필수** (결제 정보 = 본인 식별). T0/T1은 비로그인 가능.

## 2. 무료 구간 상세

### 2-1. 파이프라인 (T0)

```
사진 업로드
    │
    ▼
① precheck (코드 게이트) — 현행 유지
   - 얼굴 비율 20~50% / 위치 / 조명 40~240 / 1인 필수
   거부 → 사유 표시 + "다시 올리기"
   통과 → 무언으로 다음 단계
    │
    ▼
② fit 시어터 (InsightFace 106점 + 배치 기하)
   - 규격 안착 미리보기 (줌인 → 가이드 라인 → 안착)
   - 판정 표시: 문제점만 (§7-1) — 문제 없으면 뱃지 없이 분기로
    │
    ▼
③ 분기 선택 (§7-2) — 처리 전에 선택. 선택한 티어만큼만 연산
   ├─ [무료 다운로드]      → ④로 (T0)
   ├─ [AI 보정 ₩2,000]    → 결제 → ④+보정 (T1)
   └─ [발급보장 ₩9,900]   → 로그인+결제 → ④+보정+검수 (T2)
    │
    ▼
④ 처리 파이프라인
   - BiRefNet 매팅 → 알파 실측 (헤어탑·어깨선) → 제약 최적화 크롭 → 흰배경 합성
   - 순서 주의: 매팅이 크롭보다 먼저 — 크롭 최적화가 알파 실측값을 입력으로 사용
   - T1/T2: + Gemini/Imagen 보정 (T2: + QC 판정)
    │
    ▼
⑤ postcheck (코드 판정) — 최종 결과 기준
   - 얼굴 mm / 눈 위치 % / 기울기 / 눈감김 / 입벌림
   - pass는 요약 1줄, warn/fail만 뱃지 (§7-3)
    │
    ▼
⑥ 결과 화면 — 원본 vs 완성 비교 + 업셀 CTA (§7-3, §7-5)
```

### 2-2. 원가

| 항목 | 건당 비용 | 비고 |
|------|----------|------|
| normalizeImage (sharp) | ~₩0 | CPU 연산 |
| SCRFD 검출 + 106점 | ~₩1 | Cloud Run CPU ~0.5초 |
| fitSpecGeometry | ~₩0 | 순수 기하 연산 |
| BiRefNet 매팅 | ~₩15~20 | RunPod 대기열 |
| postcheck 판정 | ~₩0 | 코드 연산 |
| **합계** | **~₩20/건** | Gemini 호출 0건 |

- 5회/일 제한 시: 최악 ₩100/사용자/일
- 월 1,000 유니크 × 평균 2회 = ₩40,000/월 — 마케팅 비용으로 무시할 수준

### 2-3. 무료 다운로드 사양

| 항목 | 무료 (T0) | 유료 (T1/T2) |
|------|----------|-------------|
| 해상도 | 원본 화질 기반 (최대 2048px 정규화) | 동일 |
| DPI | 300 | 300 |
| 포맷 | JPEG | JPEG + PNG |
| 배경 | 흰색 (규격 표준) | 흰색 + 커스텀 색상 |
| AI 보정 | ✗ | ✓ (피부·조명·정장) |
| 워터마크 | ✗ (없음) | ✗ |

무료에 워터마크 **없음** — "완전 무료"의 신뢰. 워터마크가 있으면 "무료라고 해놓고 사실 유료"로 읽힌다.

## 3. 유료 분기 (T1/T2)

### 3-1. T1 (AI 보정 ₩2,000)

무료 결과물을 기반으로 **Gemini/Imagen 보정 1회** 실행:

- 규격 판정 전항목 pass 확인
- 반려 시 무료 재제작 또는 환불
- 보장 약관은 별도 법적 검토 필요 (기존 설계서 참조)

## 4. UX 플로우 변경점

### 4-1. 결제 장벽 이동

```
현행:  업로드 → precheck("측정 가능") → [토스 결제] → 생성 → 결과
변경:  업로드 → precheck(무언) → fit 시어터 → 배경제거 → postcheck → 결과
       └─ [무료 다운로드] 또는 [AI 보정 ₩2,000] 또는 [발급보장 ₩9,900]
```

### 4-2. 마케팅 표면

- 스펙스 상세 페이지 상단: **"증명사진 규격 맞추기 — 완전 무료, 로그인 불요"**
- SEO 타이틀: "여권사진 규격 무료 — MONKOS"
- 경쟁사 대비: 대부분 무료라 해놓고 워터마크 또는 저화질 → 우리는 **진짜 무료**

### 4-3. 횟수 제한 (지시서 확정 — 초안의 5회/일·20회/일 대체)

| 사용자 | 한도 | 방식 |
|--------|------|------|
| 비로그인 | **총 3회** (리셋 없음) | IP 기반 |
| 로그인 | **월 10회** | 계정 기반, 매월 리셋 |
| 남용 방지 | rate limit 유지 (현행 10req/분) | 봇·크롤러 차단 |

소진 시 UX (지시서 원문):

```
비로그인 총 3회 소진:
  "무료 체험을 모두 사용했어요. 가입하면 매월 10회 무료로 사용할 수 있어요."
  [가입하기] [AI 보정 ₩2,000]

로그인 월 10회 소진:
  "이번 달 무료 횟수를 모두 사용했어요."
  [AI 보정 ₩2,000] [크레딧 충전 (10c = ₩1,500)]
```

- 무료 소진은 유료 경로를 막지 않는다 — T1/T2 결제는 횟수와 무관하게 항상 가능.
- 비로그인 3회는 "가입 전 맛보기" 예산: 가입 전환의 트리거이지 사용량 상한이 아니다.

## 7. UI 설계 (지시서 Task 2 — iMac/민아)

### 7-1. fit 시어터 — "문제점만" 원칙

현행: 통과 시에도 전 항목 뱃지(얼굴mm·눈%·상단·하단) 나열 + "규격에 안착했습니다. 이대로 만들 수 있어요."
변경: **pass 항목은 침묵. 문제(warn/fail)만 발화.**

```
[전 항목 통과]
  ✓ 규격에 안착했어요                      ← 요약 1줄만, 뱃지 없음
  → 즉시 분기 카드 노출

[경고 있음]
  규격에는 맞아요. 다만 —
  ⚠️ 기울기 3°   ⚠️ 입 벌림               ← 문제 뱃지만
  "AI 보정으로 개선할 수 있어요"           ← 업셀 연결 문구
  → 분기 카드 노출 (무료도 진행 가능)

[차단]
  ✕ 규격 허용 범위를 벗어났어요. 다른 사진을 권장해요.
  → [다시 올리기]만 노출
```

- 구현 지점: `render-specs.js` `renderFitVerdict()` — pass 뱃지 생성 억제, warn/fail만 append.
- 근거: 통과 사용자에게 숫자 나열은 인지 비용. 문제 사용자에게만 문제를 — 그리고 그 문제가 곧 T1 업셀 사유.

### 7-2. 분기 선택 카드 (fit 통과 직후)

```
┌─────────────────┬──────────────────────┬──────────────────────┐
│  무료 다운로드    │  AI 보정  ₩2,000     │  발급보장  ₩9,900     │
│  크롭+배경제거    │  +피부·조명·정장 보정  │  +스튜디오 검수        │
│                 │                      │  +반려 시 재제작 보장   │
│  [무료로 받기]    │  [보정하고 받기]       │  [보장받기] 🔒로그인    │
└─────────────────┴──────────────────────┴──────────────────────┘
```

- 3열 카드 (모바일: 세로 스택, 무료가 최상단 — 앵커 상품이 먼저).
- 발급보장 카드에 로그인 필수 표기. 비로그인 클릭 시 로그인 유도 → 복귀.
- 무료 잔여 횟수 표기: "무료 3회 중 2회 남음" (비로그인) / "이번 달 7회 남음" (로그인).

### 7-3. 결과 화면 — postcheck + 업셀 CTA (무료 포함)

```
[완성 사진 | 원본 비교 토글]

규격 판정 — 문제점만 (pass는 접힌 요약):
  ✓ 규격 통과 (얼굴 33mm · 눈 44%)        ← 1줄 요약, 탭하면 전 항목 펼침
  ⚠️ 기울기 3° — AI 보정으로 교정 가능
  ⚠️ 입 벌림 — AI 보정으로 교정 가능

[다운로드]   [AI 보정으로 개선 ₩2,000]
```

- 전 항목 상세는 접힘(collapsed) — 신뢰 근거로 존재하되 기본 화면을 점유하지 않음.
- warn 뱃지의 교정 가능 문구가 T1 CTA와 문장으로 연결 — "문제 표시 = 업셀 사유"의 UI 구현.
