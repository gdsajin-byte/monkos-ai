## 3. 결제 흐름 (확정)

```
[KR ko] 업로드 → precheck(무료·레이트리밋) → ₩2,000 버튼
  → Toss SDK requestPayment (서버 발급 orderId, 금액 서버 고정)
  → /api/payments/toss/direct confirm (서버가 ₩2,000 강제, slug 기록)
  → paymentToken(Firestore, 1회성) → generate(토큰 검증) → 다운로드
[글로벌/JP en·ja] 동일 구조, PG만 레몬 체크아웃($2 단건) → 웹훅 → 토큰
```

- **생성은 결제 뒤**: 무결제 generate 호출은 402 거부. 크레딧 경로(로그인)는 기존대로.
- 토큰: Firestore `directTokens` — 1회성 소모, TTL 24h(결제 후 다운로드 여유), 결제 orderId 연결.

## 4. 작가님 액션 (에이전트 불가 항목)
