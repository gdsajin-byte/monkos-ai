### 작가님 확정 방향

1. 비로그인 1회 무료 생성 → 워터마크 프리뷰 → 다운로드 시 로그인 강제
2. 로그인 후 잔액 부족 → 충전 모달 (단건 ₩11,600 + 패키지)
3. 헤더 크레딧 표시 = 충전샵 버튼 (전 페이지)
4. 생성 10c + 다운로드 70c 분리 유지
5. thankyou 원본 무한 재다운로드 = 정상
