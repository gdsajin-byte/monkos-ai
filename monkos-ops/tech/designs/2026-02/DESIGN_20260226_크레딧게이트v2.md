## 개정 배경

v1(2026-02-25) 배포 후 감사에서 발견된 문제:

| # | 문제 | 심각도 |
|---|------|--------|
| 1 | 이벤트 크레딧 3중 중복 (게이트 70c + SNS 100c + CS봇 30c = 200c) | P0 |
| 2 | 토스 결제 리다이렉트 시 생성 이미지 소실 (store.generated 메모리만 보관) | P0 |
| 3 | SNS 공유 검증 없이 즉시 지급 (클릭=40c) | P1 |

### 작가님 확정 방향 (2026-02-26)

1. **게이트 = 로그인 30c + 텔레그램 가입 40c = 70c** (단일 경로, 택1 폐지)
2. **후속 100c 미션**: 다운로드 후 결과물 캡쳐 텔레그램 전송 + SNS 활용 동의서 서명
3. **제거**: 구 SNS 100c (`/api/credits/share-bonus`), CS봇 30c (`/api/telegram-bonus/*`)
4. 텔레그램 가입 = Bot API `getChatMember`로 서버 검증

## 텔레그램 봇 플로우 상세

### 게이트 Phase 2 (40c)

```
1. 프론트: "텔레그램 가입 40c" 버튼 클릭
2. 프론트 → 서버: POST /api/telegram/gate-code {userId}
3. 서버: 고유 코드 생성 → Firestore 저장 {code, userId, type: 'gate', used: false}
4. 서버 → 프론트: {deeplink: "t.me/MonkosBot?start=GATE_<code>"}
5. 프론트: 딥링크 오픈 → 텔레그램 앱 전환
6. 봇: /start GATE_<code> 수신 → 코드 검증 → userId ↔ telegramId 매핑 저장
7. 봇: "MONKOS 채널에 가입해주세요! [채널 링크]" 메시지
8. 유저: 채널 가입 → 웹 복귀 → "가입 확인" 버튼 클릭
9. 프론트 → 서버: POST /api/credits/event {type: 'telegram_join', userId}
10. 서버: getChatMember(channelId, telegramId) 호출
11. 검증 성공 → 40c 지급 + events.telegram_join = true
```

### 100c 미션 (다운로드 후)

```
1. 프론트: 프리미엄 옵션 표시 → 아래에 100c 미션 카드
2. 조건A — SNS 동의서:
   → 웹 폼에서 체크 + 서명 → POST /api/consent/sns {userId, agreed: true}
   → 서버: Firestore에 동의 기록
3. 조건B — 캡쳐본 전송:
   → "텔레그램으로 보내기" 버튼 → t.me/MonkosBot?start=MISSION_<code>
   → 봇: "결과물 사진을 보내주세요!" 메시지
   → 유저: 사진 전송 → 봇: 이미지 저장 + 수신 플래그 설정
4. 웹 복귀 → "미션 완료 확인" 클릭
5. 서버: 동의서 확인 + 봇 이미지 수신 확인 → 100c 지급
```
