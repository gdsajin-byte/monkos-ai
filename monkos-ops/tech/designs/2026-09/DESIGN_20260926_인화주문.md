```
① 사진 종류 고르기       여권 / 반명함 / 신분증 / 자유 규격
        ↓                (specs 데이터에서 규격 자동 결정)
② 파일 올리기            JPG·PNG. 해상도 경고 표시
        ↓
③ 미리보기 확인          crop 엔진이 규격에 맞춰 배치한 결과를 보여줌
        ↓                "이대로 인화됩니다"
④ 매수·용지 고르기        4×6 / 5×7 등, 매수
        ↓
⑤ 수령 방법              매장 수령 / 우편 발송(준등기) + 주소 입력
        ↓
⑥ 이름·연락처·결제        토스
        ↓
⑦ 주문번호 + 확인 메일
```

**핵심 장치는 ③이다.** 손님이 올린 파일이 규격에 맞는지 **결제 전에** 눈으로 확인시킨다. 반려·재작업이 줄고, 이것이 우리가 경쟁사보다 나은 지점이다(crop 엔진 보유).

### 6-1. 브랜드 분리 원칙 (꾸 지적 2026-09-26 — 설계 전제)

> **몽크사진관(오프라인 사진관)과 MONKOS AI(온라인 서비스)는 손님에게 별개 브랜드다.**
> 인화 주문은 **100% 몽크사진관 건**이다. 뒷단에서 포털 인프라를 빌려 쓰더라도 **손님 눈에 MONKOS가 보이면 안 된다.**

| 손님이 보는 것 | 반드시 | 금지 |
|---|---|---|
| 도메인 | monk.kr | monkos.ai 노출·리디렉트 |
| 화면 상호·로고 | 몽크사진관 | MONKOS 로고·워드마크 |
| 결제 승인 문자의 가맹점명 | 몽크사진관(사업자 등록 상호) | MONKOS |
| 주문 확인 메일 발신자·서명 | 몽크사진관 (전용 주소 필요) | `info@monkos.ai` |
| 업로드·미리보기 이미지 URL | monk.kr 경유 | `*.run.app` / monkos.ai 직노출 |
| 개인정보 처리방침 주체 | 몽크사진관 사업자 | MONKOS |
| 기술 표기 | 표기하지 않음 | crop 엔진·Imagen·Gemini 등 내부 엔진명 (헌법 4조 3항) |

- 계정·로그인은 **붙이지 않는다.** MONKOS 로그인을 끌어오면 두 브랜드가 한 몸으로 보인다. 인화 주문은 **비회원 주문**(이름·연락처·주문번호)으로 간다.
- 크레딧도 쓰지 않는다. 인화는 **현금 결제 단품**이다. MONKOS 크레딧 원장과 섞지 않는다.
- 결제 가맹점 분리가 기술적으로 불가하면 **3항(가격)보다 먼저 작가님 판단**을 받는다. 승인 문자에 MONKOS가 찍히는 것이 가장 큰 누출 지점이다.

> 근거: 헌법 4조 3항(내부 기밀·브랜드 표기) + 꾸 지적 — "몽크사진관(오프라인)과 monkos.ai(온라인)를 한 설명에 섞으면 고객이 맥락을 놓친다."

## 12. 가격표 (꾸 확정 2026-09-26)

| 품목 | 규격 | 가격 | 우편(준등기) |
|---|---|---|---|
| 여권 · 운전 | 3.5 × 4.5cm | 10,000원 | ⭕ 매수 무관 |
| 민증 | 3.5 × 4.5cm | 10,000원 | ⭕ 매수 무관 |

- **일반 인화 10매 미만은 매장 수령만.** 소액 주문에 우편요금이 얹히면 역마진이 난다 (4×6 1장 = 1,000원 < 준등기 요금)
- **표시 가격 = 매장에서 실제 받는 가격** (꾸 확정 2026-09-26). 우편 수령을 고르면 **우편요금을 더해 합산 결제**한다.
  - 매장 수령: 표시 가격 그대로
  - 우편 수령: 표시 가격 + 준등기 요금 (결제 화면에서 합산해 한 금액으로 보여준다)
  - 화면 문구: "표시 가격은 매장 수령 기준입니다. 우편으로 받으시면 우편요금이 더해진 금액으로 결제됩니다."
- ⚠️ 포함 결정에 따른 검산 필요: 4×6 최소 주문 10매 = 10,000원. 여기서 준등기 요금이 빠지면 실수령이 줄어든다. **우체국 요금 확인 후 10매 기준이 적정한지 재검토** (기준 상향 또는 4×6 단가 조정 여지)
- 꾸 표현은 "택배 가능"이었으나 실제 수단은 **준등기 우편**. 화면 표기는 10항에 따라 "우편"으로 통일한다.

> **확정 (2026-09-26).** 출처: 우정사업본부 공식 요금표 「국내통상우편요금 및 우편이용에 관한 수수료」 PDF — 꾸 확인.
> 원문: `준등기 | 1통 | 1,800원 | 중량 200g(소형포장물은 500g)까지 접수 가능하며, 단일요금 적용 (접수에서 운송은 등기취급, 배달은 우편수취함에 투함)`
> 단일요금이므로 **무게·지역에 따른 변동 없음**. 가격 계산이 단순해진다.

### 결제 예시

| 주문 | 인화 | 우편 | 총액 |
|---|---|---|---|
| 증명 1건 · 매장 | 10,000 | — | **10,000원** |
| 증명 1건 · 우편 | 10,000 | 1,800 | **11,800원** |
| 4×6 10매 · 우편 | 10,000 | 1,800 | **11,800원** |
| 5×7 10매 · 우편 | 20,000 | 1,800 | **21,800원** |

- 우편요금은 **주문 1건당 1통 기준.** 여러 항목을 한 봉투에 넣어도 1,800원 1회. 항목 수가 늘어도 우편요금은 늘지 않는다 → 항목 추가(여러 사이즈 동시 주문)가 손님에게 유리하다.
- 중량 200g은 인화물 기준 여유. 대형 인화는 용적 제한(45cm)에 걸릴 수 있어 전화·상담 경로가 맞다.
- 화면 소요일 표기는 "2~3일" → **"3일 내외, 주말·공휴일 제외"**로 정정.

## 14. 채널 분리 (꾸 확정 2026-09-26)

**매장에서 이미 카카오톡 채널로 일반 인화를 받고 있다** (꾸 확인). 신규 도입이 아니라 **기존 운영의 웹 노출**이다.

| 품목 | 접수 경로 | 사유 |
|---|---|---|
| 증명·서류 (여권·운전·민증·반명함·비자) | **웹 주문 폼** | 규격 자동 확인의 값이 크고, 단가 10,000원으로 자동화 원가를 감당 |
| 일반 인화 (4×6 1,000 / 5×7 2,000) | **네이버 톡톡** | 장수·재단 여부 등 대화 필요. 단가 낮아 자동화 가치 낮음. **이미 운영 중** |
| 대형 인화 (8×10 이상) | 네이버 톡톡 / 전화 | 크기·용지·액자 상담 + 소포 요금 개별 산정 |

- 웹 페이지 제목을 **"증명 · 서류사진 인화 주문"**으로 좁히고, 일반·대형은 네이버 톡톡 버튼으로 유도한다.
- **화질 경고 필수**: 메신저 사진 전송은 자동 압축된다. "사진은 꼭 '원본'으로 보내주세요" 문구를 버튼 위에 고정 노출. 이것이 재작업의 최대 원인이 된다.
- **창구는 네이버 톡톡으로 단일화 (꾸 최종 확정 2026-09-26).** 카카오 채널 전환은 검토했으나 철회 — 네이버 유입 손님의 동선이 끊기고, 매장이 창구 두 곳을 보게 되는 부담이 더 크다고 판단.
- monk.kr 몽크사진관 7개 톡톡 링크는 **현행 유지**. 교체 작업 없음.
