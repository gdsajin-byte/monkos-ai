## 3. 전면에 세워야 할 것 — 1:1 맞춤 보정

경쟁사는 `1:1 맞춤 리터칭`을 프리미엄 서비스로 **전면 노출**한다.
몽크사진관도 **고급증명 = 1:1 보정**을 이미 하고 있으나 가격표 안에 묻혀 있다.

→ **촬영 상품·가격 페이지에서 "작가와 함께 보면서 보정"을 별도 항목으로 끌어올린다.**
   이것이 3만원 증명사진과 그 위 상품을 가르는 실제 차이다.

### 5-1. 가격 정본이 플레이스라는 것의 의미

- 가격 정본 = **네이버 플레이스** (변경도 거기서 일어난다)
- 홈페이지 가격 페이지에 숫자를 그대로 박으면 **두 곳을 따로 고쳐야 한다.** 1인 운영에서 반드시 어긋난다
- **방침**: 가격 페이지는 **상품 구성·차이를 설명**하는 자리로 만들고, 실제 금액은 대표가만 표기 + "최신 가격·예약은 플레이스에서" 로 연결
- 이렇게 하면 가격이 바뀌어도 **플레이스만 고치면 된다.** 홈페이지는 구성 설명이라 자주 바뀌지 않는다
- 꾸의 기존 방침(블로그에 가격 미기재, 플레이스로 유도)과도 같은 방향

### 페이지 구성 (제안서 기반)

1. **10년 넘게, 50곳 이상** — 수입차 브랜드 전국 전시장 10년 거래. **거래처 실명은 쓰지 않는다 (꾸 확정 09-26)**
2. **이런 상황이신가요** — 직원 사진 제각각, 담당자가 일일이 재요청
3. **서비스 소개** — 장비·조명 일체 지참, 이동 없이 촬영, 통일 보정, 사원증 규격 납품
4. **진행 조건** — **최소 30명**, 하루 50명 기준
5. **함께 진행 가능** — 정면 증명 / 상반신 프로필 / 단체
6. **30명 미만이면 매장 방문** — 출장비 없음 + 1:1 개별 보정 (전환 유도)
7. **진행 절차 4단계** — 문의·협의 → 계약 → 현장 촬영 → 3~5일 내 납품
8. **왜 몽크사진관인가** — **출장(신작가)과 매장(꾸) 담당 분리 → 날짜를 회사에 맞춤.** 전국 업체 대비 유일한 우위
9. **견적 문의** — 인원·희망 날짜 받기 (전화 / 톡톡 / 메일)

### 주의

- **가격 미표기.** 인원·종류·방문 횟수·보정 범위에 따라 달라진다 → 견적 대응 (제안서 방침 그대로)
- **거래처 실명 미사용 확정 (꾸 09-26).** 홈페이지는 노출 범위가 메일 제안서와 다르다. '수입차 브랜드'로만 표기

| 항목 | 내용 |
|---|---|
| 현행 | `/monk_studio/monk_studio`, `/monk_studio/id_photo/id_photo` — 폴더명과 파일명이 같다 |
| 검토안 | `index.html` 로 변경 → `/monk_studio/`, `/monk_studio/id_photo/` |
| 결정 | **현행 유지.** monk.kr 본진 아래 사진관이 들어가는 구조가 맞다는 판단 |
| 부수 효과 | 기존 링크(블로그·플레이스·검색) 전부 그대로 살아있다. 리다이렉트 작업 불필요 |

## 8. 블로그 섹션 — 네이버 블로그 자동 연동 (꾸 확정 2026-09-27)

### 결정

**RSS 자동 연동만 한다 (수동 교체 없음).** 대표이미지는 꾸가 블로그에 올릴 때 이미 고른 사진이므로, 홈페이지에서 다시 고를 이유가 없다.

### 실측 (2026-09-27)

| 항목 | 결과 |
|---|---|
| 블로그 주소 | `blog.naver.com/studio_monk` (플레이스에서 확인) |
| RSS | `rss.blog.naver.com/studio_monk.xml` — **정상. 최근 50편** |
| 제공 필드 | title · link · pubDate · category · description(약 350자) · 대표이미지 1장 |
| 카테고리 | 최근 50편 전량 `몽크사진관` — 그래도 **카테고리 필터 적용**(다른 카테고리 유입 차단) |
| ⚠️ 이미지 핫링크 | **monk.kr referer → 403.** 네이버가 외부 참조 차단. **중계(프록시) 필요** |

### 구현 방향

- monk.kr은 CF Pages → **Pages Functions**로 엔드포인트 1개:
  1. RSS 가져오기 + 카테고리 필터 + 파싱 → JSON
  2. 이미지 중계 (referer 문제 해소)
- 캐시 10~30분. 실패 시 **무음 금지** — 목록 대신 "블로그 보러 가기" 버튼 노출
- 화면: 대표이미지(16:9) 위 · 제목 · 요약 3줄 · 이어서 읽기. PC 2열 / 모바일 1열
- 본문 전문 미러링은 **하지 않는다** (네이버 원본과 검색 경쟁 우려)

### 승인 필요

신규 서버 코드(Functions) 추가 + 배포 → **작가님 승인 대상**
