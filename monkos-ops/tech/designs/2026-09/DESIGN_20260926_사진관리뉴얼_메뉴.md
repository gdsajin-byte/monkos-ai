## 1. 메뉴 (5 + CTA)

### 현행 대비 변경

- `Philosophy` → **메뉴에서 내림.** 메인 페이지 안 섹션으로 존치. 예약하러 온 사람이 누르는 항목이 아니다.
- `갤러리` → **메뉴에서 내림.** 각 촬영 상품 페이지 안으로 흡수. 사진은 상품 옆에 있을 때 설득력이 있다.
- `가격`·`이용안내`·`온라인 스토어` 신설.

## 2. 만들지 않는 것 (경쟁사에는 있으나 우리는 제외)

| 항목 | 제외 사유 |
|---|---|
| 헤어&메이크업 | 외부 샵 협업 구조가 없다. 없는 서비스를 메뉴에 두면 문의만 늘고 응대 부담이 된다 |
| 무료 정장 대여 | 보유·관리 확인 안 됨. 있다면 **이용안내 안 한 줄**로 충분 |
| 퍼스널 컬러 진단 | 운영 인력 없음 |
| 이벤트 페이지 | 월별 갱신이 필요한 페이지는 1인 운영에서 방치된다. 할인은 **플레이스 쿠폰**으로 운영 (현행 유지) |
| 다국어 12종 | 종로=외국인 상권이라 성립. 미사·하남은 지역 고객 중심. **비자 규정 페이지만** 필요 시 영문 검토 |

## 3. 전면에 세워야 할 것 — 1:1 맞춤 보정

경쟁사는 `1:1 맞춤 리터칭`을 프리미엄 서비스로 **전면 노출**한다.
몽크사진관도 **고급증명 = 1:1 보정**을 이미 하고 있으나 가격표 안에 묻혀 있다.

→ **촬영 상품·가격 페이지에서 "작가와 함께 보면서 보정"을 별도 항목으로 끌어올린다.**
   이것이 3만원 증명사진과 그 위 상품을 가르는 실제 차이다.
