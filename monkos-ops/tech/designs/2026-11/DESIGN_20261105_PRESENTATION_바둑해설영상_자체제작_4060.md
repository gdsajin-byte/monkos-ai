## 0. 결론

화면은 **판 90% + 사이드 얼굴 작은 창**(개인 채널 형식). 이러면 비싼 것은 목소리뿐이고, 목소리도 캐릭터가 잡히면 **오픈소스 음성 복제를 4060에서** 돌려 편당 비용을 전기료 수준으로 내린다. ElevenLabs는 **목소리 기준 잡기·비교 기준**으로만 쓴다. 얼굴 창은 **사진형(유니) = 오픈소스 입모양 합성, 3D형 = 기존 monkos-3d(브라우저, GPU 불요)** 두 길을 시험한다. 4060은 음성 합성·입모양 합성·자막 인식·음성 학습까지 덮고, 전신 영상 생성만 못 덮는다(필요하면 Kling 구독분).

## 1. ElevenLabs 비용 구조 — 답

- **대본 전체 글자 수로 과금**된다(생성한 글자 수만큼 크레딧 차감, 요금제별 월 한도 — 모델에 따라 글자당 크레딧이 다름). 다시 생성하면 또 차감.
- 우리 대본 분량(막내2 실측 환산): 이현욱 10분 ≈ 3,600자 → **1시간 해설 ≈ 2만 자**, 10분 하이라이트 ≈ 3~4천 자.
- 작가님 보유: Starter(04-03 가입, 월 $5). 정확한 월 한도·글자당 단가·목소리 복제 가능 등급은 **현재 요금제 페이지 확인 후** 수치화(이 문서는 구조만 — 숫자 추정 금지).
- 판단: 하루 1편(10분)이면 월 10만 자 안팎 — 상위 요금제가 필요할 수 있다. 영상 수가 늘수록 자체 제작이 유리.

## 2. 구성 층과 4060 커버리지

| 층 | 자체 제작안 | 4060(8GB) | 대안·비교 기준 |
|---|---|---|---|
| ① 대본 | 형세봇·해설 사전·해설 LLM(PF_GO) | 판정은 CPU·KataGo, 문장 생성은 클라우드 LLM(소형 로컬 LLM은 품질 확인 전 보류) | — |
| ② 목소리 | 오픈소스 음성 복제(후보: GPT-SoVITS · CosyVoice2 · F5-TTS 한국어 미세조정본) — 작가님 목소리(본인 녹음 5~30분), 유니 목소리(설계한 가상 음색) | **추론 ○**(실시간 근처 예상) · **음성 미세조정 학습 ○**(수십 분~수 시간) | ElevenLabs = 기준 음질·비교군 |
| ③ 얼굴 창(사진형 유니) | 한 장 사진 + 음성 → 입모양·고개 움직임(후보: MuseTalk · LivePortrait 계열) — 화면 1/6 크기라 저해상(256~512px)로 충분 | **○ 예상**(작은 창이라 부담 낮음 — 실측 필요) | Kling 립싱크(구독분) |
| ③′ 얼굴 창(3D형) | 기존 `apps/monkos-3d`(Three.js 캐릭터·애니 6종·TTS 립싱크, pt.monkos.ai) | **불요**(브라우저 렌더) | — |
| ④ 판 화면 | go-board-web 재생(수순·참고도·적청 형세·마무리 수) 헤드리스 녹화 | 불요(CPU) | — |
| ⑤ 자막·편집 | 대본 → 자막, ffmpeg 합성(판 + 얼굴 창 + 자막 + 음성) | 불요(CPU) — 인코딩은 4060 하드웨어 인코더로 가속 가능 | — |
| ⑥ 수집 | 무료 자동 자막 + 교정 사전, whisper(필요분) | ○ | — |
| ✕ | 전신·실사 장면 영상 생성 | ✕(8GB로 품질 불가) | Kling·Flow 구독(가끔 오프닝용) |

- **시간 창**: 4060은 바둑 학습·실수 사전(23:00~07:30)과 아이들 게임(하교~23:00)이 있다 → 영상 제작은 **평일 낮 학교 시간** 배치가 기본. 음성 학습처럼 긴 작업은 바둑 학습 없는 밤.

## 3. 단계 (작은 단위)

1. **목소리 비교(V0)**: 같은 대본 30문장(오늘 해설 예문 포함)을 ElevenLabs(보유 Starter 한도 안) vs 오픈소스 2종(4060)으로 → 작가님 블라인드 청취 순위 + 4060 속도 실측. 작가님 목소리 복제는 본인 녹음 10분부터.
2. **얼굴 창(F0)**: 유니 사진 1장 + V0 음성 30초 → 사진형 2종 vs 3D형 → 작가님 판정 + 4060 속도.
3. **10분 하이라이트 1편 자동 생성(E0)**: 작가님 대국 1판 → 형세봇 전환 장면 → 대본(캐스터 유니·해설 작가님) → 음성 → 판 녹화 → 얼굴 창 → 합성. 편당 시간·비용 실측.
4. 반응 보고 → 유튜브·숏폼.

## 4. 출시 전 확인 칸

- 오픈소스 모델별 **가중치 라이선스**(비상업 조항 여부) — 채택 전 1차 출처 확인.
- 유니 캐릭터·목소리 = 우리 창작물. 작가님 목소리 = 본인 동의(본인).
- 프로 해설 데이터로 배운 말투는 특정 해설자 흉내로 보이지 않게(유튜브 수집은 내부 연구 — 출시 전 허락·약관 표식 유지).
