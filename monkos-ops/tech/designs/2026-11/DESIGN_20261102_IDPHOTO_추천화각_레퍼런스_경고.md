## 0. 결론 1줄

업로드 전에는 **우리 레퍼런스 사진 1장 위에 "이렇게 찍으세요" 틀**을 보여주고, 업로드 후에는 **고객 사진 위에 이 규격의 잘림 틀**을 그려 "넘치면 빨강·여유 부족이면 주황"으로 무엇을 어떻게 다시 찍을지 보여준다. 판정은 지금의 고정 비율(얼굴 20~80%)과 정수리 추정을 버리고, 규격별 프레임 기하 하나로 통일한다.

## 1. 근거 (19:41 쌍아 계산, 규격 428개 — `spec-crop.js` 파라미터 그대로)

두상(정수리~턱, 성인 약 23cm) 1개 기준으로 규격 프레임이 요구하는 여백:

| 기준 | 머리 위 | 턱 아래 | 좌우 폭 | 덮는 규격 |
|---|---|---|---|---|
| 여권 기본(kr-passport형) | 0.09 (≈2cm) | 0.28 (≈6cm) | 1.06 (≈25cm) | 285/428 |
| 미국 비자형(31mm) | 0.21 | 0.44 | 1.64 | 379/428 |
| **전 규격 최대치** | **0.34 (≈8cm, 주먹 하나)** | **0.66 (≈15cm, 가슴 윗부분)** | **1.96 (≈45cm, 양어깨+여유)** | **428/428** |

→ **추천 화각 = 전 규격 최대치 + 안전 여유.** 넓게 찍힌 사진은 우리가 잘라내면 되고, 해상도는 휴대폰 원본이면 얼굴이 화면 1/3이어도 충분하다. 고객에게 두 종류를 고르게 하지 않는다(선택 부담 = 이탈). 규격별 차이는 업로드 후 판정이 흡수한다.

## 2. 업로드 전 — 추천 화각 레퍼런스

### 2-1. 무엇을 보여주나
- 업로드 영역 옆(모바일은 위)에 **레퍼런스 사진 1장**. 추천 화각(§1 최대치 + 여유)으로 찍힌 실사 구도.
- 그 위에 두 겹 오버레이(SVG, 이미지 위 절대 좌표):
  - **바깥 점선(초록) = 추천 촬영 범위** — "이만큼 나오게 찍어주세요".
  - **안쪽 실선(흰) = 이 규격의 완성 사진 범위** — 규격마다 다르게. 레퍼런스 사진의 눈·턱·정수리 좌표(사전 측정값 1회 저장)와 규격 파라미터로 서버 렌더 시 계산 → 페이지마다 "미국 비자는 여기까지 잘려요"가 보인다.
- 아래 한 줄: "가슴 위까지, 양어깨가 다 나오게, 머리 위에 주먹 하나 여유" + 기존 칩(정면·1인·선명·입 다물기).
- 기존 칩 "가슴 위 구도"는 이 문구로 대체(중복 제거).

## 3. 업로드 후 — 판정 (전 규격 공통, 규격별 프레임 기하)

판정 입력은 하나: `/fit`이 이미 계산하는 **원본 좌표 프레임**(`computeFitGeometry`) + 원본 크기 + 매팅 알파(머리끝 실측, 막내3 진행 중).

| 코드 | 조건 | 수준 | 의미 |
|---|---|---|---|
| `fov_tight_top` | 실측 머리끝이 원본 맨 위에 닿음(알파) | block | 정수리 실제 잘림 |
| `fov_tight_side` | 프레임 좌·우·아래 이탈 최댓값 > 8% | block | 어깨·몸 부족 |
| 〃 | 5~8% | warn | 일부 배경색 채움 |
| `fov_off_center` | 한쪽만 이탈(반대쪽·아래 ≤3%) | block/warn | 치우침 (현행 `narrow_fov_off_center` 일반화) |
| `fov_wide` | 규격 크기로 자르면 확대 배율 > 1.5 | block | 얼굴이 너무 작게 찍힘(멀리서) |
| 〃 | 1.0~1.5 | warn | 화질 저하 가능 |

- 확대 배율 = 규격 출력 px ÷ 원본 안의 프레임 px(한 변). 민아 제안서의 업스케일 판정과 같은 식 — 해상도가 아니라 "얼마나 멀리서 찍었나"의 지표로 쓴다.
- **폐지**: 얼굴 비율 20~80% 고정 게이트(`server.js:638-640`), 정수리 추정 게이트(`:652-660`, 막내3 실측 전환 중), 얼굴 박스 윗변 5% 게이트(`:643`). 셋 다 위 표가 규격별로 대체.
- 판정 순서: 얼굴 없음·여러 명·기울기 등 **사람 조건 먼저**, 그다음 화각. (현행처럼 정수리 추정이 화각 판정을 가로막지 않게.)
- 기하 계산 실패·타임아웃 → 판정 없이 통과 + WARNING 로그(무음 강등 금지). 고객에게 근거 없는 문구를 띄우지 않는다.
- 로그에 `outside`·확대 배율·얼굴 비율을 숫자로 남긴다(지금은 얼굴 px만 남아 분포를 못 본다).

## 4. 경고 메시지 (ko 초안 — 4언어+id·vi 동시)

화면: **고객 사진 위에 규격 틀을 그린다.** 틀 밖으로 넘친 영역은 빨간 반투명, 여유가 부족한 쪽 테두리는 주황. 문구는 그 아래 1~2줄 + 버튼.

| 코드 | 문구 | 버튼 |
|---|---|---|
| fov_tight_top | 머리 윗부분이 사진 밖으로 잘렸어요. 머리 위에 주먹 하나 정도 여유가 있게 다시 찍어주세요. | 다른 사진 |
| fov_tight_side (block) | 너무 가까이서 찍혔어요. {규격} 사진에는 어깨까지 들어가야 해요. 휴대폰을 조금 더 멀리 두고 가슴 위까지 나오게 찍어주세요. | 다른 사진 |
| fov_tight_side (warn) | 어깨나 몸 아래쪽 일부가 배경색으로 채워져요. 자연스러운 결과를 원하시면 조금 더 멀리서 찍어주세요. | 그대로 만들기 / 다른 사진 |
| fov_off_center | 얼굴이 한쪽으로 치우쳐 {왼쪽/오른쪽}이 모자라요. 얼굴이 화면 가운데 오게 다시 찍어주세요. | (block) 다른 사진 / (warn) 둘 다 |
| fov_wide (block) | 얼굴이 너무 작게 찍혔어요. 조금 더 가까이서, 가슴 위까지만 나오게 찍어주세요. | 다른 사진 |
| fov_wide (warn) | 얼굴이 작게 찍혀 완성 사진이 덜 선명할 수 있어요. 조금 더 가까이서 찍으면 더 선명해요. | 그대로 만들기 / 다른 사진 |
| (공통 보조) | 카톡·문자로 받은 사진은 작게 줄어 있어요. 갤러리의 원본 사진을 올려주세요. | fov_wide에만 덧붙임 |

- `{규격}`은 페이지 규격명(예: 미국 비자). 근거 없는 수치는 넣지 않는다.
- 기존 키 재사용: `rej_narrow_fov`→`fov_tight_side`, `rej_narrow_fov_off_center`→`fov_off_center`(키 이전·별칭 유지), `rej_crown_cropped`→`fov_tight_top`.
