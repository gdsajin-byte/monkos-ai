## 1. 이벤트 스키마 (7종)

> GA4 표준 이벤트명은 표준 유지(sign_up·begin_checkout·purchase) → GA4 기본 리포트·전자상거래 자동 연계. 커스텀은 snake_case.

| # | 이벤트명 | 트리거 시점 (DOM/로직) | 측정 누수 | 표준/커스텀 |
|---|---------|---------------------|----------|------------|
| 1 | `spec_select` | 규격(이력서/여권/비자/국가) 선택 시 | 의도 분포 | 커스텀 |
| 2 | `photo_upload` | 셀카 업로드 완료 시 | 진입 마찰 | 커스텀 |
| 3 | `sign_up` ✓ | OAuth 가입 완료 (이미 존재) | 방문→가입 | 표준 |
| 4 | `generate_click` | "생성/AI 보정" 버튼 클릭 시 | **누수①** | 커스텀 |
| 5 | `preview_view` | 프리뷰 이미지 렌더 완료 시 | 크레딧0 지점 | 커스텀 |
| 6 | `begin_checkout` | 다운로드/결제 버튼 클릭 시 | **누수②** | 표준 |
| 7 | `purchase` | 결제 완료 (thankyou 진입) | 매출 | 표준(value/currency/transaction_id) |

> `generate_click`(4)과 `preview_view`(5) 사이의 이탈 = 생성 실패/타임아웃. 둘을 분리해야 "눌렀는데 결과가 안 나온" 기술 이탈과 "결과를 봤는데 나간" 만족도 이탈을 구분한다.

## 2. 공통 파라미터 (4종 — 전 이벤트 부착)

| 파라미터 | 값 예시 | 분석 용도 |
|----------|--------|----------|
| `spec_type` | resume / passport / visa / us_visa | 규격별 전환차 (여권 vs 이력서) |
| `auth_method` | google / kakao / line | 인증수단별 이탈 (일본 line 특이점) |
| `lang` | ko / ja | 한·일 행동양식 분리 |
| `service` | idphoto-kr / idphoto-jp | 서비스별 퍼널 |

> 이 4종 덕에 *"일본 line 유저가 generate_click에서 이탈"*, *"여권은 결제까지 가는데 이력서는 프리뷰서 멈춤"* 같은 교차 분석이 가능해진다.

`purchase` 추가 파라미터: `value`(금액), `currency`(KRW), `transaction_id`.

## 3. 구현 가이드 (막내 지시 입력)

- **삽입 위치**: `monkos_AI/idphoto-kr/` + `idphoto-jp/` 프론트엔드. 각 단계 핸들러에 `gtag('event', ...)` 1줄.
- **GA4 연동**: 이미 활성(page_view 수집 중) → measurement ID 재사용. 신규 태그 불요.
- **코드 패턴**:
```js
gtag('event', 'generate_click', {
  spec_type: state.specType,   // 'passport'
  auth_method: user.provider,  // 'kakao'
  lang: document.documentElement.lang,
  service: 'idphoto-kr'
});
```
- **표준 이벤트**(sign_up·begin_checkout·purchase)는 GA4 권장 파라미터 스펙 준수.
- **DebugView 검증**: 삽입 후 GA4 DebugView로 각 이벤트 실시간 발화 확인 → 누락/중복 점검.

## 4. 산출물 — GA4 Funnel 리포트

심은 이벤트로 구성할 표준 퍼널 (GA4 탐색 또는 run_funnel_report):

```
landing(page_view) → spec_select → photo_upload → sign_up
  → generate_click → preview_view → begin_checkout → purchase
```

- 각 단계 전환율·이탈수 자동 산출 → 크레딧 역추론 폐기
- `funnel_breakdown`으로 lang/auth_method/spec_type 세분
- 어드민 대시보드(PF_PORTAL)에 핵심 단계 위젯 연계 가능
