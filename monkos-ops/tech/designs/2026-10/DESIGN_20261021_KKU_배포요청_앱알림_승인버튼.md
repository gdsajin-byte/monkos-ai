## 5. 리스크

- **위조·오발 메시지**: 세션 간 메시지는 누구나 보낼 수 있다. 최악의 결과는 점검·알림·박스 표시까지이고, 배포는 사람 턴 없이는 불가 → 수용.
- **iMac 민아 세션 미가동**: 전제 유지 조건(요청서 §3-3). 텔레그램이 백업.
- **텔레그램 링크 버튼 오남용**: 버튼은 세션 URL만 연다. 승인은 세션 안 사람 턴으로만 성립 → 채팅방 구성원이 눌러도 배포 불가.
- **보완 청구(별건)**: 포털 Cloud Run env 평문 시크릿 4종(TELEGRAM_*_TOKEN 3 + TEAM_NOTIFY_SECRET) → SM secretKeyRef 전환 (`INCIDENT_20261021_portal-env-telegram-token-exposure.md`, 로테이션 불요 판정). 프로덕션 배포 동반 → 별도 지시서·작가님 승인.
- **권한 모드 불일치**: 보류·5분 만료. 양쪽 bypass 유지가 전제 — 세션 시작 절차에서 모드 확인 1줄은 3단계 결과 보고 범위.
