# KataGo 의도 해설 → 소형 LLM 이식 설계서

**[2026-10-23 10:43 KST]** iMac/쌍아 → 작가님

> 출처: 작가님 2026-10-23 10:4x (iMac 쌍아 세션 사람 턴) "결국은 llm이 카타고의 의도를 설명할수있어야해 카타고는 참고도는 보여주지만 왜인지 무엇이 실수인지 왜 블루스팟인지 설명을 안해 그게 핵심이고 너희가 학습해보고 방법을 찾아서 오픈소스 llm소형모델에 이식해주는 방안으로" → 쌍아 10:42 방안 → 작가님 "ㅇㅇ".
> 위치: 연구 시드(본진 비대상). 같은 3층 구조를 보정 판정기·관상 해설에 역이식하는 것이 본업 연결점.

## 1. 원칙

- **판단은 엔진, 말은 LLM.** LLM에게 판을 보여 주고 판단시키지 않는다(그럴듯한 엉터리). LLM은 사실 목록만 말로 옮긴다.
- **"왜"는 반사실 대조에서 나온다.** 블루스팟(최선수)과 실제 수의 미래를 나란히 놓으면 차이가 곧 이유다.

## 2. 파이프라인

```
기보 ─▶ KataGo analysis(국면별) ─▶ ① 사실 추출(규칙·계산) ─▶ 사실 목록 JSON
                                                         │
                     ② 교사(Claude) 해설 3수준 ◀─────────┘
                                │
                     ③ 검증기: 문장별 근거 사실 ID 대조, 무근거 문장 제거
                                │
                     ④ 작가님 검수(정확·재미) → 골드 라벨
                                │
                     ⑤ 데이터셋(사실 → 해설) ─▶ 소형 오픈 LLM LoRA 증류 ─▶ 로컬 추론
```

## 3. ① 사실 추출 — 무엇을 뽑는가

| 사실 | 원천 | 예 |
|---|---|---|
| 손익 | 실제 수 vs 최선 수 scoreLead 차 | "6.2집 손해" |
| 손익 위치 | 두 수 이후 ownership 차이를 영역(귀·변·중앙·그룹)별로 집계 | "우상귀에서 −5.8" |
| 그룹 상태 전환 | 그룹 단위 ownership 평균의 부호 반전 | "흑 우상 대마: 삶 → 죽음" |
| 응징 수순 | 실제 수 이후 PV 앞 3~6수 + 각 수의 ownership 변화 | "백 14 끊음 → 세 점 단수" |
| 최선수의 목적 | 최선 수 이후 PV에서 지켜지는/얻어지는 영역 | "우상 연결 + 좌하 세력 확보" |
| 급함 vs 큼 | 지역 손익과 전국 손익 비교, 손 뺀 경우 PV | "큰 곳보다 급한 곳" |
| 수준 맥락 | (후속) 급수별 정책망 확률 — 이 급수가 흔히 두는 수인가 | "1급 70%가 여기를 둔다" |

전부 결정적 계산 — 같은 입력이면 같은 사실.

## 4. ② 교사 · ③ 검증기 · ④ 검수

- 교사 프롬프트: 사실 목록(ID 부여) + 판 렌더 이미지(참고) → 아이/아마/유단 3수준, 각 문장 끝에 근거 사실 ID 태그.
- 검증기: 태그 없는 문장·사실과 모순(손익 수치·좌표·그룹명) 문장 제거, 통과율 기록.
- 작가님 검수: 파일럿 20편 → "맞는 말인가 / 재미있나 / 이해되나"(3점 척도). 이것이 품질 기준선.

## 5. ⑤ 증류

- 데이터: KGS 공개 기보(막내12 조사 1순위)에서 실수 국면(손실 ≥ 2집) 수천 개. KataGo는 iMac OpenCL(119 visits/s, 국면당 ~1.5초)로 야간 생성.
- 학생 모델: 1~8B 오픈 LLM(Qwen·Gemma·Llama 계열 중 라이선스 확인 후 택1), 입력 = 사실 JSON(판 이미지 없음) → 해설. LoRA, RunPod 시간 단위.
- 평가: 검증기 통과율(사실 정합) + 작가님 블라인드 비교(교사 vs 학생).
- 배치: iMac/M1 로컬 → 이후 모바일 온디바이스.

## 6. 단계

| 단계 | 내용 | 주체 | 판정 |
|---|---|---|---|
| P | 파일럿: KGS 3판 → 실수 국면 20 → ①~③ → 작가님 ④ | 막내 + 작가님 | 작가님 "맞는 말" ≥ 16/20 |
| 1 | 사실 추출기 확장(급함/큼·그룹 인식 정교화) | 막내 | 파일럿 오답 유형별 개선 |
| 2 | 데이터셋 2,000~5,000 | 막내(야간) | 검증기 통과율 |
| 3 | 소형 모델 증류 + 블라인드 평가 | 막내 | 학생이 교사의 80% 이상 |
