# 바둑 UI 전체 그림 — 타이젬 체험으로 찾은 우리 개선점

**[2026-10-24 23:01 KST]** iMac/쌍아-막내15 → iMac/쌍아

> 출처: 작가님 2026-10-24 21:58 KST 쌍아 세션 사람 턴 "직접 대국해보고 우리 ui와의 차이를 극복… 대국실과 대기실 시스템, 형세판단·계가 기능 등 ui 전체에 대한 그림" · 22:53 "체험을 통해 우리 ui 개선점을 찾아내야지" (쌍아 경로① 전달).
> 비교 방법: 같은 기능을 **타이젬(web.tygem.com, CDP 9227 고정 창 CSS 1571×1328)** 과 **우리(go-board-web origin/main b89dd7c5, `run.sh --test 8768`, 같은 창)** 에서 차례로 눌러 클릭 수·지연·막힘을 잰다. 지연은 스크립트로 잼(클릭 → 화면 변화 감지).
> 이 문서는 우리 서비스 코드를 고치지 않는다. 각 개선점은 지시서 1건 크기로 쪼갰다(쌍아가 아침에 지시서화).

## ① 화면 지도

```
타이젬                                                우리 (go.monkos.ai)
┌──────────── 대기실 ────────────┐                    ┌──────── 대기실 / ────────┐
│ 좌메뉴 · 대국 카드 그리드(관전) │                    │ 내 진행 중 대국(목록)     │
│ 우측 내 정보 · 접속자 목록      │                    │ 지난 대국(목록)           │
│ 상단 [인공지능▾] [···▾]         │                    │ [기보 불러오기] [새 대국] │
└──┬──────────┬──────────┬───────┘                    └──┬─────────┬──────────┬───┘
   │카드 클릭  │인공지능   │··· 기보감상                    │행 클릭   │새 대국    │지난 대국 행
   ▼          ▼          ▼                               ▼         ▼          ▼
 관전실     신청 창 →  기보감상(같은 틀)               대국실   신청 창 →  감상 모드
 (같은 틀)   대국실      └ 기보 불러오기 창            /room/id   대국실      /room/id?review=1
   │          │ 계가신청 → 집계산 모달(예/아니요·20초)    │         │ 계가신청 → 계가중(사석 클릭) → 계가 확정
   │          ▼ 예 → 종국(헤더 결과)                     │         ▼ 종국 → '기보 감상' 버튼
   └─ 나가기(확인 없음) → 대기실 ─────────────          └─ '대기실'(확인 없음) → 대기실
```

- 타이젬은 **대국실·관전실·기보감상이 한 틀**(판 + 우측 시계·대국자·탭·메시지)이고, 상황에 따라 버튼 줄만 바뀐다. 우리도 대국실·감상 모드가 같은 `index.html` 한 틀 — 방향 같음.
- 타이젬의 '열려있는 대국실' 서랍 = 내가 들어가 있는 방 목록(여러 방 동시). 우리 '내 진행 중 대국'이 같은 자리.

## ② 기능별 짝 실측 (타이젬 vs 우리)

| 기능 | 타이젬 (실측) | 우리 (실측, 8768 main) | 판정 |
|---|---|---|---|
| 판 크기(1571×1328 창) | 792×792 CSS = 창 높이 60% · 칸 41px · 판 끝→첫 줄 0.62칸 · **좌표 없음**(검토 때만 오른쪽·아래, ··· '좌표보기' 토글) | 730×730 = 55% · 칸 36.5px · 판 끝→첫 줄 1.0칸 + **좌표 글자 위·왼쪽**. `.board max-width: min(90vh, 780px)` + `.wrap max-width 1280` | 다름 — 우리 칸이 11% 작다 |
| 착수 반응 | 클릭 후 0.3초 캡처에 이미 돌 | 클릭 → 판 갱신 **0.07초** | 같음(좋음) |
| 상대 응수 | P9단 3~11초 | 최강 **11.3초**(1수 실측) · 1단 0.9~2.0초 | 최강이 느린 편 — 결정 항목 |
| 마지막 수 표시 | 돌 우하단 작은 삼각(파랑/흰) | 돌 가운데 원(흰/빨강) | 같음 |
| 차례 표시 | 차례인 대국자 아바타에 파란 링 | 대국자 카드 파란 테두리 + 헤더 '작가님(흑) 차례' | 같음 |
| 무르기 | 상대 응수 뒤 활성 · 확인 없이 2수 되돌림 · "남은 무르기 무료 횟수: 49" | 확인 없이 2수 되돌림 · 메시지 "**한 수** 물렀습니다." | 문구가 실제(2수)와 다름 |
| 형세판단(대국 중) | 버튼 → 일반/정밀 선택 → **판 위에 집 네모**(사석 표시 포함) + 띠 "반면 백 18집 유리"(x로 닫음). 평소엔 숨김 | 헤더에 **항상** '형세 흑 9.3집 우세' + 형세 탭 막대·그래프. **판 위 집 표시 없음**(계가 때만) | 다름 — 판 위 표시 없음 |
| AI 판정 | 2회 눌러도 반응·안내 없음(나쁜 예) | 결과가 `#msg`에 쓰였다가 `render()`가 곧 덮어씀 → 엔진 바쁠 때 흔적 없음(1회 재현, 한가할 때 재확인 예정) | 둘 다 약함 |
| 계가 | 계가신청 1클릭 → **즉시** 판 위 집·사석 표시 + 모달 '집계산 결과'(백집·흑사석·덤·결과) + 동의? 예/아니요 + 20초 카운트다운 → 예 1클릭 = 종국. **2클릭·대기 0초**. 사석 수정 단계 없음. 모달이 판 가운데를 가림 | (자동 두기 종국 후 실측 예정) 계가신청 → 계가중(사석 엔진 판정·돌 클릭 수정) → 계가 확정 | 측정 중 |
| 종국 표시 | 결과 팝업 없음 · 헤더가 "백 46집반 승"으로 · 대국 버튼 줄 사라짐 | 헤더 '대국종료(결과)' · '기보 감상' 버튼 | 같음 |
| 대기실→새 대국 | 인공지능 → 19줄 인공지능 → 신청 = 기본값 3클릭(수준 바꾸면 +2, 호선 되돌리기 +3). **설정 기억 안 함** | 새 대국 → 신청 = **2클릭**, 직전 설정 기억 | 우리가 나음 |
| 신청 → 대국 시작 | ≤4초 | 신청 클릭 → `/room/{id}` 판 표시 ≤2.5초 | 같음 |
| 대국실 → 대기실 | 나가기 확인 없음, 0.09~0.20초(8회) | '대기실' 확인 없음 — **진행 중 판을 두고 나가면 5분 뒤 접속 장애패**인데 경고 없음 | 위험 — 개선 |
| 대기실 정보 | 대국 카드(관전자 수·승률 %)·접속자 목록·내 정보(급수·전적) | 내 판 목록만. 테스트 저장소에서 '0:00 남음'인데 진행 중으로 남은 방 관찰 | 다름 |
| 관전 | 카드 1클릭 0.14~0.35초 입장 · 관전자 목록 · 관전 채팅 · 형세/AI분석 사용 가능 | 없음(1인 서비스) | 단계 ③ 이후 |
| 채팅 | 관전실: 우측 아래 큰 칸 + '대화입력'·'인사말' — 판 안 가림. AI 대국실: 입력줄 없음, 시스템 메시지·**광고 문구**가 섞임 | 없음 | 단계 ③ 이후 |
| 기보 감상 | 대기실 ··· → 기보감상 → 불러오기 창(내 기보 표: 날짜·백·흑·종류·치수·결과·수 / 이긴 판 빨강) → 더블클릭 → **마지막 수로 열림** · 수순 이동·슬라이더·해설 칸. 기보열기 다시 누르면 '프로 기보' 탭으로(기억 안 함). 분석 errCode 12 | (실측 예정) 대기실 지난 대국 행 → 감상 모드 | 측정 중 |
| 실시간 분석판(우리만) | — | 대국 중 승률·추천수가 늘 보임(접기 가능) + 시스템 칩에 **'측정 오류 [Errno 2] … ioreg'** 그대로 노출 | 개선 |
| 기본 탭(대국 중) | 탭은 누를 때만 판 위/떠 있는 창으로 열림 | 대국 중 기본 탭 'AI분석' = '이 판 해설 만들기'(종국 후 기능)가 먼저 보임 | 개선 |
