## 1. 기술개발 목표

K-뷰티 전문 지식과 AI 기술을 융합한 소상공인 맞춤형 룩북 제작 및 지능형 비주얼 큐레이션 플랫폼 monk.kr 개발 및 사업화

### 1-1. AI 이미지 정체성 유지율 90% 달성, 외부API 의존율 50% 이하로 기술 자립화

| 지표 | 현재 | 목표 |
|------|------|------|
| 인물 정체성 유지율 | 85% | 90% 이상 |
| 외부API 의존율 | 100% | 50% 이하 |

### 1-2. 자체 고해상도 파이프라인으로 인쇄품질(300dpi) 실사 이미지 대형 출력 실현

| 지표 | 현재 | 목표 |
|------|------|------|
| 출력 해상도 | 72 dpi(웹용) | 300dpi (인쇄용) |

### 1-3. Human-AI 협업 기반 자가 진화형 K-뷰티 특화 지능 파이프라인 구축

**Human-AI 협업 순환 학습 구조:**

[데이터 수집] → [이미지 생성] → [지능형 검수] → [자동 태깅] → [전문가 큐레이션] → [재학습] → (순환)

K-뷰티 전문가의 고밀도 큐레이션과 AI 자동화가 협업하는 자가 지능 증식형 파이프라인 구축. 사용할수록 K-뷰티 도메인에 특화 되어 스스로 진화하는 지능을 실현.

### 1-4. 소상공인 맞춤AI 챗봇 탑재 저비용 홈페이지 서비스 사업화

소상공인, 1인 창업자, 청년 창업자를 대상으로 **클라이언트별 특화 파인튜닝된 AI 챗봇 서비스**를 제공

| 항목 | 내용 |
|------|------|
| 콘셉트 | 나보다 내 가게를 더 잘 아는 챗봇 |
| 핵심기술 | 할루시네이션 제거(학습된 정보만 응답) |
| 서비스 형태 | 지능형 챗봇 탑재 홈페이지 저비용 구축 |

**차별성 비교:**

| 구분 | 기준 | 본 과제 |
|------|------|--------|
| AI 기술 | 빅테크 100% 의존 | 자체 기술 50% 이상 |
| 이미지 품질 | 웹용 한정 | 인쇄용 고해상도 |
| 지능 특성 | 범용/고정 | K-뷰티 특화/진화형 |
| 서비스 타겟 | 대기업 중심 | 소상공인 맞춤 |

## 2. 연구개발 방법

### [1] AI 이미지 생성 기술 자립화

- 현재 100% 의존 중인 외부 **API의 의존도를 50% 이하로 감축**
- 오픈소스 모델(Stable Diffusion, FLUX 등) 기반 파이프라인 구축
- K-뷰티 도메인 특화 파인튜닝

**연구계획:**

| 단계 | 내용 | 기간 |
|------|------|------|
| 1단계 | 오픈소스 모델 벤치마킹 및 선정 | 1~2월 |
| 2단계 | K-뷰티 학습 데이터셋 구축 (20,000장 이상) | 2~4월 |
| 3단계 | 하이브리드 파이프라인 구축 (Cloud API + Local 5090×2) | 4~7월 |
| 4단계 | 모델 파인튜닝 및 최적화 | 7~9월 |
| 5단계 | 성능 검증 및 안정화 | 9~12월 |

**검증방법:**

| 지표 | 측정 방법 | 목표 |
|------|----------|------|
| 정체성유지율 | 원본 vs 생성 모델 유사도 측정 | 90% 이상 |
| API 의존율 | 월간 API 호출 비율 모니터링 | 50% 이하 |
| 생성 품질 | 전문가 블라인드 평가(5점 척도) | 4.0 이상 |

### [2] 인쇄 품질 고해상도 이미지 생성

- 단순 업스케일링이 아닌 **디테일 보존형 고해상도 이미지 출력**
- 피부결, 의상 텍스쳐 등 미세 디테일 재현
- A3 이상 대형 인쇄물 대응(4K, 300dpi)

**연구계획:**

| 단계 | 내용 | 기간 |
|------|------|------|
| 1 | 기존 업스케일러 한계 분석 및 최적화 코드 탐색 | 1~2월 |
| 2 | 분할-생성-합성 파이프라인 설계 | 2~4월 |
| 3 | 타일 기반 고해상도 생성 알고리즘 개발 | 4~6월 |
| 4 | 자동 합성 후처리 모듈 개발 | 6~8월 |
| 5 | 실제 인쇄 테스트 및 품질 검증 | 8~10월 |

**검증방법:**

| 지표 | 측정 방법 | 목표 |
|------|----------|------|
| 출력해상도 | 생성 이미지 DPI 측정 | 4K, 300dpi |
| 디테일 품질 | A3 인쇄물 육안검수(전문가 5인) | 5점척도 4.0 이상 |
| 처리시간 | 고해상도 1장 생성 소요시간 | 30초 이내 |

### [3] 자가 진화형 AI 파이프라인 구축

- 데이터 수집부터 재학습까지 자동화된 순환 파이프라인 구축
- K-뷰티 전문가 큐레이션과 AI 자동태깅의 협업 체계 완성
- 사용량 증가에 따른 지능 품질 자동 향상

**파이프라인 흐름:**

```
<1. 데이터 수집>    K-뷰티 트렌드 크롤링, CloudRun
       ↓
<2. 전처리 및 벡터화>  GCS 저장, Vertex AI 임베딩
       ↓
<3. 지능형 검수>     AI가 검수, 자동 태깅 (VertexAI Vision+Gemini)
       ↓
<4. 이미지 생성>     태깅기반 프롬프트로 룩북형 이미지 생성
       ↓
<5. 2차 지능형검수>   헤어, 패션스타일등 태그부여 및 AI평가
       ↓
<6. 전문가 큐레이션>  K-뷰티 전문 연구원의 고밀도 검수, 가중치부여
       ↓
<7. 스키마 데이터베이스 벡터라이즈 및 JSON파일 코퍼스 임베딩>
```

- [별첨 1] 이미지 참조

**연구방법:**

| 단계 | 내용 | 기간 |
|------|------|------|
| 1 | 데이터 수집 자동화(크롤러, API) | 1~3월 |
| 2 | 벡터DB 및 RAG시스템 구축 | 3~5월 |
| 3 | 지능형 검수 모듈 개발 | 5~7월 |
| 4 | 자동 태깅 시스템 개발 | 7~9월 |
| 5 | 피드백 루프 연동 및 자동화 | 9~11월 |
| 6 | 전체 파이프라인 통합테스트 | 11~12월 |

**검증방법:**

| 지표 | 측정방법 | 목표 |
|------|----------|------|
| 자동화율 | 수동 개입 필요비율 측정 | 80% 자동 |
| 품질 향상률 | 월별 생성 이미지 평균점수 추이 | 월 2% 향상 |
| 태깅정확도 | 전문가 검수 대비 일치율 | 90% 이상 |

### [4] 소상공인 맞춤형 AI챗봇 서비스

- "나보다 내 가게를 더 잘아는" 클라이언트 특화 챗봇 개발
- 할루시네이션 제거(학습된 정보만 응답)
- 저비용 홈페이지 + 챗봇 패키지 서비스 구축

**연구방법:**

| 단계 | 내용 | 기간 |

| 1 | 소형 LLM모델선정(3B~8B급) | 1~2월 |

**검증방법:**

| 고객 만족도 | 베타 테스터 설문(5점 척도) | 4.0 이상 |

## 3. 선행연구개발

### (1) 선행 연구개발 이력

**과제명**: K-뷰티 AI 이미지 생성 및 지능형 서비스 플랫폼 연구

**1. AI 이미지 생성 서비스 개발**
- MONKOS Image Pro 개발 완료 [별첨2 이미지참조]
- AI 증명사진/프로필 사진 서비스 개발완료 [별첨3 이미지참조]
- monk.kr 플랫폼 구축 및 서비스 구동중

**2. 개발 인프라 구축** [별첨4 이미지 참조]
- 다양한 플랫폼을 연동한 WorkSpace 완성
- Cloudflare + GCS + GitHub + Cursor 통합 환경
- 원터치 백업 + 배포 시스템 구현

**3. AI 모델 비교 분석 연구**
- 소형 LLM (3B, 8B급) 테스트(추론능력 및 한국어 정밀도)
- 이미지 생성 모델 비교: SDXL, FLUX, Imagen
- I2I 기반 정체성 유지율 분석
- AI 아티팩트 품질 비교 (모델별 탁월성 분석)

**4. 지능형 챗봇 개발**
- RAG 기반 챗봇 구동 (Vertex AI Search), 텔레그램 챗봇테스트
- 할루시네이션 발생율 체크 및 최적 기반지능 탐색

### (2) 선행연구개발 결과 활용계획

**[활용 1] 서비스 플랫폼 승계**
- monk.kr 플랫폼 → 룩북 및 교육 서비스 확장 기반
- MONKOS Image Pro → 이미지 생성 엔진 고도화
- AI 증명사진 서비스 → 상용화 및 유료 전환(현 베타서비스 중)

**[활용 2] 인프라 자산 승계**
- Cloudflare+GCS+GitHub+Cursor → 개발 인프라 그대로 활용
- 원터치 배포 시스템 → 빠른 서비스 업데이트
- 세션 연속성 환경 → 컨텍스트 유지 효율성 극대화

**[활용 3] 기술 연구 결과 승계**
- 이미지 모델 비교 분석 → 최적 엔진 선정 근거
- I2I 정체성 유지 연구 → 90% 목표 달성 전략
- 아티팩트 분석 → 품질 검수 기준 수립

**[활용 4] 챗봇 기술 승계**
- RAG 기반 챗봇 → 소상공인 챗봇 서비스 기반
- 할루시네이션 제거 연구 → "아는 것만 답변" 기술 고도화

**[이전 중기부 R&D 과제와의 차별성]**
- 이전 중기부 R&D 수행 이력 없음 (신규 과제)
- 본 과제는 순수 자체 연구 기반의 신규 도전
