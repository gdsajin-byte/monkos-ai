## Phase 0: 문제 발견 (03-10 이전)

### 핵심 과제

증명사진 규격은 **정수리~턱 끝** 거리로 얼굴 크기를 정의한다. 그러나 AI 얼굴 인식(MediaPipe FaceMesh 478점)은 이마까지만 커버하며 **정수리를 직접 감지하지 못한다**. 이 간극을 어떻게 메울 것인가.

## Phase 1: v0 — Gemini LLM 기반 서버 크롭 (03-10)

**커밋**: `6496aa9` — "Gemini 얼굴감지 기반 정밀 여권크롭 — detectFace + cropToSpec"

### 접근 방식
- Gemini 2.0 Flash(비전 모델)에 사진을 보내 4개 좌표(이마 상단, 턱, 좌안, 우안) 추출
- 추출된 좌표로 `cropToSpec()` 함수가 크롭 영역을 역산
- Sharp 라이브러리로 서버에서 JPEG 출력

### 발견된 문제
1. **정밀도 부족**: LLM이 반환하는 좌표는 근사치. 픽셀 수준 정확도 미달
2. **구조적 결함**: 좌표에서 크롭 영역을 역산하면 엣지 케이스 발생 (`cropH > srcH` → 턱 잘림)
3. **워크플로우 역전**: 사진을 프레임에 맞추는 방식 ← 실제 사진관은 프레임을 먼저 정하고 사진을 맞춤
4. **비용·지연**: 서버 전송 + LLM 호출 오버헤드

### 핵심 깨달음
> "실제 사진관에서는 프레임(규격)을 먼저 정하고, 그 안에 사진을 배치한다. 좌표에서 프레임을 역산하는 건 순서가 거꾸로다."

**→ "가이드 프레임 기반" 접근으로 전환 결정**

### 정수리 추정 — 3가지 방법 비교 연구

지시서 `ORDER_20260311_M1쌍아_막내_정수리추산근거리서치.md` 발행 → 막내1 실행

**연구 보고서**: `REPORT_20260311_막내1_정수리추산리서치.md` (252줄)

#### 방법 1: 양안대칭 1:1 반전법 ← **최종 채택**

```javascript
const eyeCenterY = (landmark[159].y + landmark[386].y) / 2;
const chinY = landmark[152].y;
const crownY = eyeCenterY - (chinY - eyeCenterY);
```

- **원리**: 눈 중심~턱 거리 = 눈 중심~정수리 거리 (해부학적 양안대칭)
- **장점**: 안정적, 헤어스타일 영향 최소, 최소 3점(양 동공+턱)만 필요
- **근거**: 일본 외무성 여권규격 공식 기재 "眼~顎 = 眼~頭頂"

#### 방법 2: 타원 피팅법 (작가님 제안)

- 턱(#152) + 좌측 윤곽(#234) + 우측 윤곽(#454) 3점으로 타원 근사
- 타원의 상단 꼭짓점 = 정수리
- **장점**: 얼굴 형태(긴 얼굴/둥근 얼굴) 적응
- **한계**: 여전히 추정치, 3점만으로는 타원 정밀도 부족

#### 방법 3: 랜드마크 #10 중간점법

- FaceMesh #10번(이마 중앙) 활용
- **한계**: #10은 이마 피부이지 정수리가 아님. 이마 넓이에 따라 편차 큼

## Phase 2b: 철학적 전환점 — 작가님 야간 세션 (03-11 밤)

**세션 로그**: `2026-03-11_M1_쌍아.md` (23:05~23:51 KST)

### 작가님 핵심 통찰

> **"정수리는 공무원도 직접 못 본다."**

여권 심사 공무원도 머리카락에 가려진 정수리를 직접 보지 못한다. 그들도 무의식적으로 **타원형 머리 형태를 상상하며 정수리 위치를 추정**한다.

### 결론

1. **목표는 해부학적 정확도가 아니다** → **공식 심사 기준과 일치하는 것**이 목표
2. ICAO 허용 범위(32~36mm = 4mm 폭)가 존재하는 이유 자체가 "정밀 측정이 불가능함"을 인정하는 것
3. 독일은 허용 범위를 27~40mm로 더 넓게 설정 — 정밀도 한계를 인정
4. 일본은 공식 규격에 "눈~턱 = 눈~정수리"를 명시 — **1:1 비율법을 공식 인정**

**→ 1:1 양안대칭법이 가장 합리적이고 공식 근거가 있는 방법으로 최종 확정**

function extractLandmarks(rawLandmarks, natW, natH) {
  const lp = rawLandmarks[FM_IDX.LEFT_PUPIL];   // #159
  const rp = rawLandmarks[FM_IDX.RIGHT_PUPIL];  // #386
  const ch = rawLandmarks[FM_IDX.CHIN];          // #152

  const leftPupil  = { x: lp.x * natW, y: lp.y * natH };
  const rightPupil = { x: rp.x * natW, y: rp.y * natH };
  const chin       = { x: ch.x * natW, y: ch.y * natH };

  // 정수리: 눈~턱 1:1 반전 (양안대칭 원리)
  const eyeCenterY = (leftPupil.y + rightPupil.y) / 2;
  const eyeCenterX = (leftPupil.x + rightPupil.x) / 2;
  const crownY = eyeCenterY - (chin.y - eyeCenterY);
  const crown = { x: eyeCenterX, y: crownY };

  return { crown, chin, leftPupil, rightPupil, ... };
}

## 발명의 핵심 포인트 — 변리사 미팅용 정리

### 1. 양안대칭 정수리 추정법의 고유성

**과제**: AI 얼굴 인식(478점 메쉬)이 정수리를 직접 감지하지 못하는 한계를 극복

**해결**: 눈 중심~턱 거리를 상방 반전하여 정수리 추정

```
crownY = eyeCenter − (chin − eyeCenter)
```

**종래 기술과의 차이**:
- 이마 랜드마크(#10) 기반 → 헤어스타일·이마 넓이 영향 큼
- 세그멘테이션 기반 → 서버 필요, 비용·지연 발생
- 본 발명 → **3점(양 동공+턱)만으로 추정**, 클라이언트 완결

### 2. 공식 근거

- **일본 외무성 여권규격**: "眼~顎 = 眼~頭頂" — 1:1 비율을 공식 채택
- **ICAO 허용 범위(32~36mm)**: 4mm 폭 자체가 "정밀 측정 불가"를 인정
- **Farkas 두개안면계측학**: 해부학적 비례 근거 (2,326명 표본)
