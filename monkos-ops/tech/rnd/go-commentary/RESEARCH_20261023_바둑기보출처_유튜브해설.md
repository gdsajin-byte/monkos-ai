# 바둑 기보 출처 분류 + 유튜브 해설 학습 방안

> 바둑 해설 봇 연구 시드용 사실 수집. **본진(서비스) 비대상.**
> 방법: 공개 페이지·사람 속도(요청 간 1~2초)·로그인 0회·대량 수집 0건. 총 요청 약 40회.
> 표기: **[실측]** = 이번 세션에서 직접 받은 응답 · **[2차]** = 검색·포럼·제3자 문서 · **[미확보]** = 원문을 얻지 못함.
> 이 문서는 법률 자문이 아니다. "판정"은 약관 문구를 보수적으로 읽은 결과다.

### A-2. 출처별 상세

#### ① 타이젬 (tygem.com) — 10:23 1차 조사 결과 재사용
- **탐색 경로 [실측]**: 목록 `http://news.tygem.com/news/tnews/gibo.asp` (전체·국내·세계·해외 탭, 대국자·백·흑·기전명 검색) → 뷰어 `http://service.tygem.com/service/gibo2/?seq={N}`.
- **형식 [실측]**: 뷰어 HTML 안에 `var sgf = "(;GM[1]FF[4]GN[…]PB[…]BR[6단]PW[…]WR[9단]…)"`로 SGF 원문이 인라인으로 들어 있다(seq=37752, 제31기 여자국수전 4강). 다운로드 버튼은 없다.
- **아마 기보**: 웹에는 없다. PC 클라이언트(Windows용, 고객센터 "대국실 다운로드")가 `.gib`로 로컬에 저장하고, SGF로 쓰려면 변환해야 한다 [2차 — lifein19x19 사용자 보고]. 웹대국실 `web.tygem.com`, 모바일 앱은 iOS 3종·Android 3종 [실측 — 홈 링크]. macOS 네이티브 클라이언트는 확인되지 않았다.
- **급수**: 프로 기보는 SGF BR/WR에 단수가 들어 있다 [실측]. 아마 `.gib`에도 급수 필드가 있다는 보고가 있으나 [2차] 실측하지 못했다.
- **약관** (http://board.tygem.com/help/customer/agreement.asp, 2022-05-09 시행) [실측]
  - 제11조 10) ⑫ "본 서비스를 통해 얻은 정보를 회사의 사전 승낙 없이 서비스 이용 외의 목적으로 복제하거나, 이를 출판 및 방송 등에 사용하거나, 제 3자에게 제공하는 행위"
  - 제14조 2) "회원은 서비스를 이용하여 취득한 정보를 임의 가공, 판매하는 행위 등 서비스에 게재된 자료를 상업적으로 사용할 수 없습니다."
- **판정**: 열람은 가능하다. 복제·가공(학습 데이터화 포함)은 **승낙 필요**. ⑫는 영리 여부를 묻지 않는다.

#### ② 사이버오로 (cyberoro.com)
- **탐색 경로 [실측]**: 홈에서 `/cyber_js/gibo.js`를 로드한다. 뷰어는 `https://www.cyberoro.com/gibo/gibo_view.oro?gibo={path}&gibonum={N}`(팝업). 홈 메뉴에 별도 "기보" 목록 링크는 보이지 않았고, 기보는 뉴스·중계(`/bcast/N_index.oro`) 기사에서 호출하는 구조로 보인다. 개별 기보 응답은 받아 보지 않았다.
- **클라이언트 [실측]**: Windows 실행 파일 `down.cyberoro.com/download/OroBaduk_20260414A.exe`, 모바일 버전 링크가 있다.
- **robots [실측]**: `Allow: /news/` · `Disallow: /admin /action /record /eventch /community /useradmin`. **`/record` 차단**.
- **약관** (https://www.cyberoro.com/company/N_agreement.oro, 2020-10-26 시행) [실측]
  - 제2조 (6) "“저작자”라 함은 … 대국시 기보발생 당사자, 문제 출제자, 대국 해설 및 기보 해설자 등을 말합니다." → **대국자를 기보의 저작자로 정의**한다(다른 사이트와 다른 점).
  - 서비스 목록 "(3) 국내외 프로기사 및 아마기사의 기보감상 서비스"
  - 금지 행위 "(6) 회사가 제공 또는 승인하지 않은 컴퓨터 프로그램이나 기기 또는 장치를 제작, 배포, 이용, 광고하는 행위" / "(10) 회사의 동의 없이 영리, 영업, 광고, 정치활동 등을 목적으로 서비스를 사용하는 행위"
  - 제18조 2. "회원은 … 얻은 정보 중 회사 또는 제공업체에 지적재산권이 귀속된 정보를 회사 또는 제공업체의 사전 승낙 없이 복제, 전송, 출판, 배포, 방송 기타 방법에 의하여 영리 목적으로 이용하거나 제3자에게 이용하게 하여서는 안됩니다."
- **판정**: 영리 목적이면 **승낙 필요**. 비영리 연구라도 미승인 프로그램 조항((6))과 `/record` 차단 때문에 자동 수집은 불가로 본다.

#### ③ 한큐바둑
- `https://www.hanqbaduk.com/`은 응답하지 않았다(000) [실측]. "국내 서비스 종료, 원조 플랫폼 예후(폭스)로 접속" [2차, 단일 출처·신뢰도 미상].

#### ④ 폭스 / 野狐围棋 (foxwq.com)
- **탐색 경로 [2차 — WebFetch 요약]**: 기보 메뉴 `https://www.foxwq.com/qipu.html`, 대회 기보는 `https://h5.foxwq.com/yehunewshare/?chessid={id}`(H5 공유 뷰어).
- **클라이언트 [2차]**: Windows `FoxWeiQi.exe`, Mac `/soft/mac.html`, 모바일 `/soft/app.html`. 웹 대국 클라이언트는 표기되지 않았다.
- **robots**: 404(파일 없음) [실측]. 파일이 없다고 수집이 허용된다는 뜻은 아니다.
- **약관**: 홈·다운로드 페이지에서 用户协议 링크를 찾지 못했다 [미확보]. 앱 내 약관일 가능성이 있다.
- **판정**: **불명**. 아마 저급~프로까지 규모가 가장 큰 후보지만, 약관을 확보하기 전에는 열람만 한다.

#### ⑤ KGS — u-go.net 아카이브
- **경로**: `https://www.u-go.net/gamerecords/` — 2001~2015년 연 단위, 2016-01~2019-04 월 단위. 연간 2,298~19,099국. zip·tar.gz·tar.bz2 형식 [2차 — WebFetch 요약].
- **급수 필터**: "either one of the players (or both) is 7d or stronger, or both are 6d" → **고단자 전용**. 해설·변화도는 제거되어 있다.
- **라이선스**: 정식 라이선스 문구는 없다. "grateful to Bill Shubert, who created KGS, for the permission to use these files." 만 있다.
- **원본 KGS**: `gokgs.com/robots.txt` `Disallow: /gameArchives.jsp` [실측]. 원본 아카이브는 자동 수집할 수 없다.
- **판정**: **불명**이지만 연구 커뮤니티에서 관용적으로 써 온 표준 시드(AlphaGo 계열 논문 등). 재배포는 피하고 출처를 표기한다.

#### ⑥ OGS (online-go.com)
- **API [실측]**: `GET https://online-go.com/api/v1/games/{id}`는 로그인 없이 200을 주고 JSON에 `ranked`, `black_player_rank`, `handicap` 등을 담는다. `GET …/games/{id}/sgf`는 SGF 원문(BR/WR 포함)을 준다. 시험 대상은 1건(id 1000000)이었다.
- **급수**: 입문(25k)~9d와 프로 표기가 모두 있다. **급수 분포 면에서 유일하게 입문~고단을 다 덮는 공개 경로.**
- **robots [실측]**: `Disallow: /bad-robots`만 있다.
- **약관**: `https://online-go.com/docs/terms-of-service`는 JS 렌더링이라 원문을 얻지 못했다 [미확보]. 공식 전체 덤프도 찾지 못했다 [2차].
- **판정**: **불명**. 다음 단계는 약관 원문을 확보하고(브라우저 렌더 또는 운영자 문의) API 요청 한도를 확인하는 것이다.

## B. 유튜브 해설 학습

### B-1. 채널 유형과 예시
> 채널명은 검색으로 확인한 것 [2차]이고 현행 활동 여부는 실측하지 않았다.

|---|---|---|
| 방송 해설 (생중계·기전) | 바둑TV(한국기원 계열 — 이현욱 등 프로 해설자), Official AGA, European Go Federation | 실시간 중계 말투, 형세 판단 어휘, 승부처 강조 |
| 프로 강좌 | Go Pro Yeonwoo(영어), Haylee's World of Go/Baduk, 연금바둑(문국현, 이창호 명국 해설) | 수순 설명 구조, 왜 이 수인가에 대한 논리 |
| AI 대국 해설 | (특정 채널은 확인 못 함 — 카타고 분석 기반 해설은 개인 유튜버에 분산) | 승률 그래프와 말을 연결하는 법 |

### B-2. 활용 단계

1. **자막·전사로 말투와 어휘 확보** — 해설 문체 사전(형세 표현, 감탄, 전환어), 급수별 어휘 수준.
2. **기보 정렬로 장면-발화 짝 만들기** — 영상 시점 t ↔ 수순 n. 기전 이름·대국자로 기보(타이젬·사이버오로·한국기원 열람분)를 찾아 수순과 맞춘다. 결과물은 "이 국면에서 이런 말을 한다"는 쌍.
3. **하이라이트 감각** — 해설자가 시간을 많이 쓰는 수, 목소리 톤이 바뀌는 지점을 카타고 승률 변동과 겹쳐 본다. "어디를 짚을지" 고르는 기준을 배운다.

### B-3. 필요 도구

| 단계 | 도구 | 비고 |
|---|---|---|
| 자막 | YouTube Data API `captions.download` | **"requires the user to have permission to edit the video"** — 남의 영상 자막은 공식 API로 받을 수 없다 [실측 — 공식 문서]. 자동 생성 자막은 브라우저 열람만 가능 |
| 전사 | 음성 인식(Whisper 계열·Gemini) | 오디오를 확보해야 하므로 아래 다운로드 금지 조항과 충돌 |
| 보드 인식 | 영상 프레임 → 판 인식(돌 좌표) | 기보를 찾지 못한 대국에만. 공개 도구(예: 사진→SGF 계열)는 별도 검증 필요 |
| 정렬 | 수순 시점 매칭 스크립트 | 자체 작성. 기보와 판 인식을 대조 |
| 하이라이트 | KataGo 분석 | 승률·점수 변동 계산 |

### B-4. 법적 경계

- **유튜브 약관** (https://www.youtube.com/t/terms, 2022-01-05 기준) [2차 — WebFetch 인용] — 금지 사항:
  - "access, reproduce, download, distribute, transmit, broadcast, display, sell, license, alter, modify … " (서비스가 허용하거나 권리자 서면 허락이 있는 경우 제외)
  - "access the Service using any automated means (such as robots, botnets or scrapers)"
  - "collect or harvest any information that might identify a person (for example, usernames or faces)"
  - AI 학습을 명시한 조항은 이번 판에서 찾지 못했다.
- **저작권**: 해설 발화는 해설자(또는 방송사)의 저작물이다. 전사본을 그대로 학습·재배포하면 복제·2차적 저작물 작성에 해당할 수 있다. 문체 분석(통계·어휘 빈도)과 원문 복제는 위험도가 다르다.
- **퍼블리시티**: 특정 해설자의 말투·목소리를 흉내 낸 봇을 "누구 스타일"로 내세우면 퍼블리시티권·부정경쟁 위험이 있다. 헌법 4조 4항(되는 것만)·브랜드 안전 기준과도 충돌한다.
- **기보 쪽**: A의 판정을 그대로 적용한다. 영상 속 기보도 출처 사이트 약관의 적용을 받는다.

### B-5. 권고 방안

1. **사람 열람 기반 소량 분석부터** — 대표 영상 10~20편을 사람이 보고 해설 패턴(국면 유형 × 발화 유형)을 코드북으로 만든다. 다운로드·자동 수집 없이 가능하다.
2. **제휴 경로가 정공법** — 바둑TV(한국기원 계열)·프로 유튜버에게 자막·전사 데이터 제공 또는 공동 연구를 제안한다. 한국기원은 기보 승낙 창구와 같은 기관이라 한 번에 묶을 수 있다.
3. **자체 해설 코퍼스 생성** — OGS·KGS 기보 + KataGo 분석 + LLM으로 해설 초안을 만들고, 프로·고단자가 교정해 정답 세트를 만든다. 권리 문제가 가장 적다.
4. 유튜브 자동 다운로드·전사 파이프라인은 **만들지 않는다**(약관 직접 위반).

## C. 권고 요약 (5줄)

1. **급수 분포가 필요한 학습 시드는 OGS API가 1순위**다(로그인 불필요·SGF·25k~9d [실측]). 단, 약관 원문 확보와 요청 한도 확인이 선행돼야 한다.
2. **고단자 시드는 KGS u-go.net**(정적 아카이브, 관용적 연구 사용)으로 하고, 재배포 없이 출처를 표기한다.
3. **국내 프로 기보(타이젬·사이버오로·한국기원)는 열람만** 한다. 학습·가공은 세 곳 모두 사전 승낙 대상이고, 일본기원은 개인 감상으로 한정된다.
4. **유튜브는 사람 열람으로 해설 코드북을 만드는 단계까지만** 한다. 자막·오디오 자동 수집은 약관상 불가이므로 데이터는 제휴(바둑TV·프로 유튜버)로 받는다.
5. **정답 해설 코퍼스는 자체 생성 + 전문가 교정**으로 만드는 것이 권리상 가장 깨끗하다. 폭스는 약관을 확보하면 저급 구간의 보강 후보가 된다.
