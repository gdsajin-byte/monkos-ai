## 1. 플랫폼 개요

MONKOS는 AI 실시간 코칭 + 증명사진 자동 생성 + 품질검증을 하나의 파이프라인으로 통합한 서비스입니다.

### 서비스 현황

| 서비스 | URL | 상태 | 대상 시장 |
|--------|-----|------|----------|
| MONKOS Portal | monkos.ai | 운영 중 | 글로벌 (일본어 기본) |
| ID Photo KR | idphoto-kr.monkos.ai | 운영 중 | 한국 |
| ID Photo JP | idphoto-jp.monkos.ai | 운영 중 | 일본 |

### 서비스 플로우

```
사용자 접속 → 로그인(OAuth) → 스타일 선택 → 카메라 ON
    ↓
AI 실시간 음성 코칭 (정면/조명/표정/자세 교정)
    ↓
촬영 완료 → 원본 업로드 → AI 이미지 재생성 (정체성 90% 보존)
    ↓
AI 품질 자동 검증(QC) → 규격 크롭 → 다운로드/공유
```

## 2. 핵심 기술 스택

### 2.1 실시간 AI 음성 코칭 (세계 최초)

| 항목 | 사양 |
|------|------|
| 엔진 | Gemini 2.0 Flash Live API |
| 프로토콜 | WebSocket 바이너리 스트리밍 |
| 프레임 분석 | 카메라 30fps → 서버 분석 → 음성 피드백 |
| RTT (왕복 지연) | 500~800ms (실측, 2026-02-08) |
| 지원 언어 | 한국어, 일본어 |
| 코칭 체크리스트 | 정면 향시 → 조명 균형 → 표정 → 눈썹 → 얼굴라인 (순차) |

**기존 서비스와의 차이점:**

| 구분 | 기존 (PhotoAiD, 픽미 등) | MONKOS |
|------|------------------------|--------|
| 방식 | 촬영 후 AI 보정 | 촬영 중 AI 코칭 |
| 원본 품질 | 나쁜 원본 → 한계 있는 보정 | 좋은 원본 → 최소 보정 |
| 음성 가이드 | 없음 | 실시간 음성 (한/일) |
| 정체성 보존 | 왜곡 빈번 | 90:10 비율 보존 |

### 2.2 AI 이미지 재생성 (정체성 보존)

| 항목 | 사양 |
|------|------|
| 엔진 | Vertex AI Imagen (Image-to-Image) |
| 핵심 파라미터 | IDENTITY_PRESERVATION 90:10 (정체성 90% + 보정 자유도 10%) |
| 프롬프트 규모 | 134줄 정밀 지시문 |
| 확립일 | 2026-01-16 (Git 커밋 `a6c6417`) |
| 생성 시간 | 3~5초/장 |

**90:10 비율의 의미:**
- 90%: 얼굴 구조, 피부톤, 눈 형태, 코/입 비율 등 인물 고유 특징 보존
- 10%: 조명 보정, 배경 처리, 미세 잡티 제거 등 증명사진 규격 최적화
- AI 세이프가드 우회를 위한 실전 테스트 기반 최적값 (100% 동일 시도 시 오히려 거부 발생)

### 2.3 AI 품질 자동 검증 (QC)

| 항목 | 사양 |
|------|------|
| 엔진 | Gemini 2.0 Flash (Vision) |
| 방식 | 원본-생성 이미지 비교 → JSON 자동 채점 |
| 검증 항목 | 정체성 일치도, 배경 균일성, 규격 적합성, 표정 자연스러움 |
| 응답 형식 | 구조화 JSON (pass/fail + 점수 + 사유) |

### 2.4 멀티에이전트 오케스트레이션

```
MONKOS 시스템 아키텍처:
├── Gemini Live API ─── 실시간 코칭 (WebSocket 바이너리 스트리밍)
├── Imagen I2I ──────── 증명사진 재생성 (정체성 보존 프롬프트)
├── Gemini Vision ───── QC 자동 판정 (JSON 채점 파이프라인)
├── Firestore ────────── 크레딧 원자적 트랜잭션 (생성/다운로드/공유)
├── 4중 OAuth ────────── Google / LINE / 카카오 / Telegram
├── 이중 결제 ────────── Lemon Squeezy (글로벌) + 토스페이먼츠 (한국)
├── Telegram Bot ×2 ─── 이벤트봇 (@monkos_event_bot) + CS봇 (@monkos_support_bot)
└── AI CS 챗봇 ────────── Gemini 기반 자동 고객 응대
```

## 3. 인프라 아키텍처

### 3.1 현재 운영 환경 (클라우드 퍼스트)

```
[유저] → [Cloudflare CDN/프록시] → [Cloud Run 서버리스]
                                          ↓
                              ┌───────────┼──────────┐
                              ↓           ↓          ↓
                        Vertex AI    Gemini API   Firestore
                       (Imagen I2I)  (코칭/QC)    (유저/크레딧)
```

| 항목 | 사양 |
|------|------|
| 컴퓨팅 | GCP Cloud Run (서버리스, 자동 스케일) |
| 스케일 | 0~10 인스턴스 (제로 스케일) |
| 동시성 | 80명/인스턴스 |
| 타임아웃 | 300초 |
| 메모리 | 512Mi ~ 1Gi |
| CDN/보안 | Cloudflare (DDoS 방어 + SSL) |
| DB | Firestore (NoSQL, 실시간 동기화) |
| 스토리지 | GCS (이미지 임시 저장) |
