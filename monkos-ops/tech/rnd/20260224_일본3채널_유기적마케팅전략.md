# MONKOS.ai 일본 3채널 유기적 마케팅 전략

## 1. 핵심 동선 (시각도 2/8 파트)

```
① X에서 비포/애프터 터짐 (기폭)
     ↓
② "이거 뭐야?" → X 프로필 → 인스타 링크 클릭
     ↓
③ 인스타에서 캐러셀 보며 신뢰 형성 (쇼윈도우)
     ↓
④ 프로필 링크 → LINE 友達追加 (매장 입장)
     ↓
⑤ LINE에서 촬영 → 결제 → 멘토
     ↓
⑥ 만족한 고객이 X에 결과물 올림 → ①로 돌아감
```

> 광고비 0원으로 돌아가는 자생적 구조

## 2. 각 채널 역할 분담

| 채널 | 역할 | 한국 대응 | 콘텐츠 성격 |
|---|---|---|---|
| **X** | 🔥 기폭장치 | (한국에선 없는 역할) | 짧고 강렬한 임팩트, RT 유도 |
| **인스타** | 🪟 쇼윈도우 | 네이버 블로그 | 정보형 카드뉴스, 신뢰 구축 |
| **LINE** | 🏪 매장(전환) | 카카오 채널+스마트스토어 | CS, 촬영, 결제, 리텐션 |

> ⚠️ 같은 소재를 3군데에 똑같이 올리면 안 됨. 각 채널 문법이 다름.

## 3. 하나의 소재 → 3채널 변환법

**소재 예시: 비포와 애프터 1세트 (스튜디오촬영 vs MONKOS AI)**

### X 버전 (기폭용)
- 이미지 2장 (Before/After) + 텍스트 3줄
- "韓国式AI証明写真。左がスタジオ、右がMONKOS。同じ人です。"
- 놀라움 유발 → RT 유도 → 프로필에 인스타 링크

### 인스타 버전 (신뢰 구축용)
- 캐러셀 4장 구성:
  - 1장: Before/After + 큰 제목 "なぜこんなに違う？"
  - 2장: 이유 3가지 (텍스트 카드) → 조명, AI코칭, 20년 프로 보정
  - 3장: 사용법 스텝 1-2-3
  - 4장: CTA "プロフィールのリンクから →"
- 캡션: 상세 설명 + 해시태그 #証明写真 #就活 #AI写真
- **일본의 핵심: "왜 좋아진" 논리적 설명 필수**

### LINE 버전 (전환용)
- 리치메뉴 탭 → "無料で撮影する"
- 자동 메시지: "今だけ無料で撮影できます！"
- 촬영 플로우 진입 → 결과물 멘토
- 멘토 후 "友達にシェアしてね" (친구에게 공유 유도)

## 4. 라인업 체크포인트

### ① 콘텐츠 생산 분업
- 비포/애프터 소재: MONKOS AI로 무한 생성 가능 (모델당 0원)
- 일본어 텍스트: MONKOS 번역 엔진 활용? 외부 감수 필요?
- 카드뉴스 디자인: 누가 제작할 것인지

### ② X → 인스타 → LINE 전환 동선
- X 프로필에 인스타 링크 넣기 (2단계 전환)
- vs X 프로필에 바로 LINE 링크 (1단계 전환)
- → 인스타 거치는 게 신뢰 형성에 유리할 수 있음

### ③ 포스팅 주기/타이밍
- 일본 취활 시즌: 3~6월 피크
- 지금부터 콘텐츠 축적 시작 필요
- 주 몇 회가 적절한지 결정 필요

### ④ 릴스/동영상 활용
- 2025 인스타 알고리즘: 릴스 노출 2배 높음
- 비포/애프터 짧은 영상 → 탐색 탭 노출에 유리
- 제작 여력 있는지 확인 필요

## 5. 일본 인스타 피드 전략 주의점 (조사)

- 이미지 안에 **텍스트를 크게** (카드뉴스형)
- "예뻐 보여요"가 아닌 **"이유를 알 수 있어요"** 구매하는 문화
- 캡션 길게, 정보 충실하게 작성
- 얼굴 없이 텍스트 리뷰도 일본에서는 자연스러움
- 일본어 해시태그 필수: #証明写真 #就活 #AI写真 #履歴書写真
- 저장(保存) 유도가 알고리즘 노출의 핵심

## 6. 결제 연동 (채널별)

| 채널 | 결제 방식 |
|---|---|
| LINE | LINE Pay + 코빈니 결제 (KOMOJU 연동) |
| 인스타 | 프로필 링크 → monk.kr/jp → Stripe or KOMOJU |
| X | 프로필 링크 → 인스타 or LINE으로 유도 |

> 일본 소비자 60%가 원하는 결제수단 없으면 구매 포기
> → 코빈니 + PayPay + 신용카드 최소 3종 지원 필요
