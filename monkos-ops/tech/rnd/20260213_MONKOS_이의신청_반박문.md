## 이의신청의 전제

본 이의신청은 경쟁 탈락에 대한 불만이 아닙니다.

경쟁률이 높아 점수에서 밀렸다면, 그것은 정당한 결과이며 수긍합니다. 그러나 실제 통보 내용은 **"다소 미흡함" 6회 반복과 상호 모순되는 지적 7건**으로 구성되어 있으며, 점수 경쟁이 아닌 **과제 내용의 오독과 논리적 오류에 기반한 기각**입니다.

본 문서는 평가 의견 7건 각각에 대한 구체적 반론을 제시하며, 서면이 아닌 **시현(데모) 기회를 요청**하는 것이 궁극적 목적입니다.

## 지적 ②③ 반박: "GPU 처리 방안 부족" + "기술자립 미흡"

### 평가의 구조적 모순

지적 ②와 ③은 동시에 성립할 수 없습니다.

```
지적 ③: "Google API만 쓰잖아, 자체 기술이 뭐냐"  →  API 의존 비판
지적 ②: "5090 왜 필요해, 현실성 없다"             →  GPU 자립화 비판
```

API만 쓰면 "기술자립 없다", 로컬 GPU로 내재화하면 "필요성 부족" — 제안자에게 **해법 자체를 부정**한 것입니다. 이는 건설적 평가가 아닌 기각을 위한 논리 구성입니다.

### 사실관계

제안서의 실제 구조는 **병렬 이중 전략**입니다:

| 전략 | 역할 | 시기 |
|------|------|------|
| 클라우드 API (Vertex AI/Gemini) | 현재 서비스 기반 | 운영 중 |
| 로컬 GPU (RTX 5090 ×2) | 비용 최적화 + 기술 내재화 | R&D 목표 |

평가자는 이 두 축을 하나로 합쳐 "5090으로 빅테크와 경쟁하겠다"로 오독하였고, 이 단일 오독에서 지적 ②③⑤ 3건이 파생되었습니다.

### 현재 운영 중인 실측 데이터

| 항목 | 수치 |
|------|------|
| 이미지 생성 | 3~5초/장 (Vertex AI) |
| 코칭 지연 | 500~800ms (Gemini Live) |
| 동시 사용자 | 80명/인스턴스 × 10인스턴스 |
| 서비스 안정성 | Cloud Run 자동 스케일 (0~10) |

### "대한민국에 데이터센터는 왜 짓는가"

평가자의 논리를 그대로 적용하면, Google/AWS API를 쓰면 되는데 자체 GPU 인프라가 왜 필요한지 설명할 수 없습니다. 그러나 대한민국은 AI 주권을 위해 국가 데이터센터를 건설하고 있습니다. 그 이유는 **API 의존도 감소 + 데이터 주권 + 비용 최적화** — 본 과제의 5090 도입 논거와 정확히 동일합니다.

| AI 생성 이미지 | Vertex AI API | Google 이용약관에 따라 사용자 소유 |

### 반박 논리

- **Google 자체가 웹 크롤링 기반입니다** — Googlebot이 전 세계 웹을 크롤링하여 검색 서비스를 제공합니다
- OpenAI의 GPT 학습 데이터도 웹 크롤링 기반입니다 (Common Crawl 등)
- 크롤링을 문제 삼으면 **현존하는 모든 AI 서비스가 법적 리스크**에 해당합니다
- 본 과제는 합법적 경로만 사용하며 (네이버 정식 검색 API, Pinterest 공개 API), 참고 데이터로만 활용할 뿐 도용하거나 재노출하지 않습니다
- 실제 서비스 이미지는 100% 사용자 본인 사진 기반 AI 재생성이므로, 원저작권자 분쟁의 여지가 구조적으로 없습니다

| **MONKOS** | **AI 증명사진 촬영 서비스** | **고유 카테고리** |

### 빅테크는 경쟁자가 아닌 공급자입니다

- Google/Adobe는 K-뷰티 증명사진 시장에 직접 진입할 의사가 없습니다
- 그들의 비즈니스 모델은 API 사용료 과금 — 개발자가 API를 많이 쓸수록 그들의 매출이 오르는 구조입니다
- MONKOS가 성공하면 Google Cloud 매출이 증가합니다. 이는 경쟁이 아닌 **공생 관계**입니다
- Google Gemini는 증명사진 비즈니스를 하지 않습니다. OpenAI ChatGPT는 모델 에이전시 사업을 하지 않습니다
- **디딤돌 창업과제에서 "빅테크를 정면으로 이길 수 있어서" 채택된 과제가 있습니까?** 있다면 이 잣대를 수긍하겠습니다

### K-뷰티 특화는 약점이 아닌 경쟁력입니다

20년 전 "한국 가수가 미국 빌보드를 장악할 경쟁력이 있다"고 판단한 심사위원은 없었을 것입니다. 그러나 K-POP은 빌보드를 장악했습니다. K-뷰티도 동일한 궤적 위에 있습니다 — 이미 화장품 수출 세계 3위입니다.

"K-뷰티만으로 부족"이라는 평가는 20년 전 "K-POP으로 빌보드는 무리"와 동일한 시각입니다.

## 평가 논리의 총체적 모순

평가 의견 7건의 논리를 이어붙이면 다음과 같습니다:

1. "K-뷰티 특화로는 빅테크를 못 이긴다" — 경쟁력 부정
2. "오픈소스(Flux)의 신뢰성도 부족하다" — 기술 역량 부정
3. "어차피 Google API 쓰는 거잖아" — 기술자립 부정
4. "그런데 5090은 왜 필요한가" — 자립화 노력 부정

빅테크에 의존해도 안 되고, 자립해도 안 되며, 특화해도 부족하고, 범용으로 가도 차별성이 없다면 — **어떤 AI 창업도 성립할 수 없는 논리**입니다. 이 논리가 성립하면 대한민국 AI 분야 디딤돌 창업과제 전체가 존재할 수 없습니다.

## "다소 미흡함"이라는 평가의 한계

### R&D 제안서의 본질적 모순

R&D 과제 제안서는 "이것을 연구하겠다"는 계획서이지, 완성된 결과물 발표가 아닙니다. "구체적 방안이 미흡"이라는 지적은 "결과를 미리 보여달라"는 요구와 같습니다. 결과가 이미 있으면 R&D가 아닙니다.

또한 AI/ML 분야에서 핵심 알고리즘, 프롬프트 엔지니어링, 파이프라인 구조를 공개 제안서에 상세 기술하는 것은 기술 유출에 해당합니다. 평가자가 요구하는 "구체성"의 수준은 R&D 과제의 본질과 기술 보호의 현실 사이에서 양립이 불가능합니다.

### HWP 20페이지의 구조적 한계

이미 가동 중인 플랫폼, 3개 서비스, 266건 커밋의 기술적 깊이를 20페이지 HWP 문서에 담는 것에는 한계가 있습니다. "구체적 방안이 미흡"이라는 평가는 **문서 분량의 한계를 과제의 한계로 오독**한 것입니다.

### 전문성 ≠ 편향

10년 사진관 경력 대표와 10년 메이크업 + 향장학 박사과정 연구원의 전문적 판단을 "편향"이라 한다면, 모든 AI 학습 데이터와 모든 브랜드가 "편향"입니다.

코코 샤넬 한 사람의 관점이 브랜드가 되었습니다. 전 세계 평균 취향의 대변이 아닌, 전문가의 철학과 관점이 가치를 만듭니다. AI 산업도 동일합니다 — Google의 RLHF, OpenAI의 human evaluator — 모든 AI는 전문가의 검수를 거쳐 발전합니다.

## 결론

### 본 과제가 요청하는 것

"당장 협약을 체결해달라"가 아닙니다. **시현(데모)할 기회를 달라**는 것입니다.

서면 20페이지로는 실시간 AI 음성 코칭, 3개국 서비스 전환, 결제 플로우를 설명할 수 없습니다. 이미 가동 중인 서비스를 HWP 양식에 끼워 맞추는 것에는 한계가 있으며, 경쟁력과 시장성은 서면 평가자가 아닌 현장이 판단하는 것입니다.

### 사실 대조

| 항목 | 평가 의견 | 현실 |
|------|----------|------|
| 기술력 | "다소 미흡" | 3개 서비스 가동 중, 266건 커밋, 실시간 코칭 E2E 완료 |
| 경쟁력 | "빅테크 대비 부족" | 빅테크는 증명사진 사업을 하지 않음 |
| 사업성 | "구체성 부족" | 결제 2종, 인증 4종, CS 봇, 법적 페이지까지 구현 완료 |
| GPU 필요성 | "의문" | 대한민국이 데이터센터를 짓는 이유와 동일 |

> **본 과제는 "계획"이 아닌 "이미 가동 중인 서비스"입니다.**
> **서면 20페이지가 아닌, 시현(데모)으로 판단해 주십시오.**
> **그것이 본 이의를 제기하는 궁극적 이유입니다.**
