## 2.2 세부 연구개발 방법

### [목표 1] AI 이미지 생성 기술 자립화

#### 연구 내용
- 현재 100% 의존 중인 외부 API(Vertex AI Imagen)의 의존도를 50% 이하로 감축
- 오픈소스 모델(Stable Diffusion, FLUX 등) 기반 자체 파이프라인 구축
- K-뷰티 도메인 특화 파인튜닝

#### 연구 방법

| 단계 | 내용 | 기간 |
|:----:|------|:----:|
| 1단계 | 오픈소스 모델 벤치마킹 및 선정 | 1~2월 |
| 2단계 | K-뷰티 학습 데이터셋 구축 (5,000장 이상) | 2~4월 |
| 3단계 | 모델 파인튜닝 및 최적화 | 4~7월 |
| 4단계 | 하이브리드 파이프라인 구축 (API + 자체) | 7~9월 |
| 5단계 | 성능 검증 및 안정화 | 9~12월 |

#### 검증 방법

| 지표 | 측정 방법 | 목표 |
|------|----------|:----:|
| 정체성 유지율 | 원본-생성 이미지 유사도 측정 (CLIP Score) | 85% 이상 |
| API 의존율 | 월간 API 호출 비율 모니터링 | 50% 이하 |
| 생성 품질 | 전문가 블라인드 평가 (5점 척도) | 4.0 이상 |

---

### [목표 2] 인쇄 품질 고해상도 이미지 생성

#### 연구 내용
- 단순 업스케일링이 아닌 디테일 보존형 고해상도 파이프라인 개발
- 피부결, 의상 텍스처 등 미세 디테일 재현
- A3 이상 대형 인쇄물 대응 (300dpi)

#### 연구 방법

| 단계 | 내용 | 기간 |
|:----:|------|:----:|
| 1단계 | 기존 업스케일러 한계 분석 | 1~2월 |
| 2단계 | 분할-생성-합성 파이프라인 설계 | 2~4월 |
| 3단계 | 타일 기반 고해상도 생성 알고리즘 개발 | 4~6월 |
| 4단계 | 디테일 보정 후처리 모듈 개발 | 6~8월 |
| 5단계 | 실제 인쇄 테스트 및 품질 검증 | 8~10월 |

#### 검증 방법

| 지표 | 측정 방법 | 목표 |
|------|----------|:----:|
| 출력 해상도 | 생성 이미지 DPI 측정 | 300dpi |
| 디테일 품질 | A3 인쇄물 육안 검수 (전문가 5인) | 합격률 90% |
| 처리 시간 | 고해상도 1장 생성 소요시간 | 60초 이내 |

---

### [목표 3] 자가 진화형 AI 파이프라인 구축

#### 연구 내용
- 데이터 수집부터 재학습까지 자동화된 순환 파이프라인 구축
- K-뷰티 전문가 큐레이션과 AI 자동화의 협업 체계
- 사용량 증가에 따른 지능 품질 자동 향상

#### 파이프라인 아키텍처

```
[1. 데이터 수집] K-뷰티 트렌드 크롤링, 사용자 업로드
       ↓
[2. 전처리 및 벡터화] GCS 저장, Vertex AI 임베딩
       ↓
[3. 이미지 생성] 프롬프트 기반 룩북 이미지 생성
       ↓
[4. 지능형 검수] Gemini 2.0 기반 품질/스타일 자동 평가
       ↓
[5. 자동 태깅] 패션/헤어/메이크업 전문 태그 부여
       ↓
[6. 전문가 큐레이션] K-뷰티 전문 연구원의 고밀도 검수
       ↓
[7. 피드백 학습] 검수 결과 → 프롬프트/모델 개선 → [1]로 순환
```

#### 연구 방법

| 단계 | 내용 | 기간 |
|:----:|------|:----:|
| 1단계 | 데이터 수집 자동화 (크롤러, API) | 1~3월 |
| 2단계 | 벡터 DB 및 RAG 시스템 구축 | 3~5월 |
| 3단계 | 지능형 검수 모듈 개발 | 5~7월 |
| 4단계 | 자동 태깅 시스템 개발 | 7~9월 |
| 5단계 | 피드백 루프 연동 및 자동화 | 9~11월 |
| 6단계 | 전체 파이프라인 통합 테스트 | 11~12월 |

#### 검증 방법

| 지표 | 측정 방법 | 목표 |
|------|----------|:----:|
| 자동화율 | 수동 개입 필요 비율 측정 | 80% 자동화 |
| 품질 향상률 | 월별 생성 이미지 평균 점수 추이 | 월 2% 향상 |
| 태깅 정확도 | 전문가 검수 대비 일치율 | 90% 이상 |

### [목표 4] 소상공인 맞춤형 AI 챗봇 서비스

#### 연구 내용
- "나보다 내 가게를 더 잘 아는" 특화 챗봇 개발
- 할루시네이션 제거 (학습된 정보만 응답)
- 저비용 홈페이지 + 챗봇 패키지 서비스화

#### 연구 방법

| 단계 | 내용 | 기간 |
|:----:|------|:----:|
| 1단계 | 소형 LLM 모델 선정 (3B~8B급) | 1~2월 |
| 2단계 | RAG 기반 지식 제한 아키텍처 설계 | 2~4월 |
| 3단계 | 클라이언트별 파인튜닝 파이프라인 개발 | 4~6월 |
| 4단계 | 할루시네이션 필터링 모듈 개발 | 6~8월 |
| 5단계 | 홈페이지 템플릿 + 챗봇 통합 패키지 | 8~10월 |
| 6단계 | 베타 서비스 및 피드백 반영 | 10~12월 |

#### 검증 방법

| 지표 | 측정 방법 | 목표 |
|------|----------|:----:|
| 할루시네이션율 | 100개 질문 대상 오답률 측정 | 5% 이하 |
| 응답 정확도 | 클라이언트 정보 기반 정답률 | 95% 이상 |
| 고객 만족도 | 베타 테스터 설문 (5점 척도) | 4.0 이상 |
