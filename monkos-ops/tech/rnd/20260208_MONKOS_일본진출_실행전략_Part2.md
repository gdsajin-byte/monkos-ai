| 구분 | 한국 | 일본 |
|------|------|------|
| 검색 | 네이버 | Google |
| 메신저 | 카카오톡 | LINE |

## 3. 결제 인프라 구조

### LINE Pay 종료

- 2025년 4월 30일 일본 국내 서비스 완전 종료
- LINEヤフー 합병 후 결제 영역 PayPay로 일원화
- 대만/태국 LINE Pay는 계속 운영

### 일본 결제 지형

| 결제수단 | 포지션 |
|----------|--------|
| PayPay | QR결제 1위, 압도적 |
| 크레딧카드 | 일본 결제 주류 |
| Stripe | 온라인 결제 API 표준 |

### MONKOS 결제 구조

```
[LINE 미니앱 안에서]
├─ Stripe 연동 → 크레딧카드 (일본인 주력)
├─ PayPay 연동 → QR결제 (젊은층)
└─ 편의점 결제 → 콘비니 결제 (현금파)
```

### 글로벌 결제 생태계 이해

```
소비자 브랜드:  PayPal = 카카오페이 (소비자가 아는 브랜드)
사업자 API:    Stripe = 토스페이먼츠 (사업자가 결제 붙일 때 쓰는 API)
```

ChatGPT Plus, Claude Pro, Notion, Figma 등 → 전부 Stripe가 뒤에서 결제 처리. 브랜드 노출 없이 작동.

### 한국 vs 글로벌 결제 분기

| | Stripe (한국) | 토스페이먼츠 |
|---|---|---|
| 카드 결제 | ✅ | ✅ |
| 카카오/네이버/삼성/토스 | ❌ | ✅ |
| 수수료 | 3.4%+ | 2.5~3.0% |

**MONKOS 분기 로직:**
```
if (고객 == 한국) → 토스페이먼츠
else → Stripe
```

## 4. 한국 = 글로벌 갈라파고스

### 플랫폼 비교

```
글로벌: Google 검색 + Visa/Master + Stripe + WhatsApp + Instagram/X
한국:   네이버 + 카카오페이/네이버페이/토스/삼성페이 + 카카오톡 + 네이버 블로그/카페
일본:   Google ✅ + 카드 + PayPay ✅ + LINE + X + Instagram ✅
```

**역설:** 일본 진출이 한국 사업보다 구조가 단순.  
한국은 네이버/카카오/토스/삼성페이 전부 맞춤 대응해야 하지만, 일본은 글로벌 표준 + LINE만 얹으면 됨.

> "고스톱 치다가 포커 치는 격. 한국 시장 밀도 속에서 10년 버틴 경험 → 단순한 글로벌 시장 진출."

## 5. Stripe 가입 및 일본 법인

### 한국 법인 직접 가입 불가

한국 금융규제로 Stripe 한국 지사 없음. 우회 루트:

| 방법 | 비용 | 비고 |
|------|------|------|
| Stripe Atlas (미국 법인) | 설립 $500 + 연간 $1,500~ | — |
| 싱가포르 법인 | 설립 $1,000~+ | — |
| **일본 법인** | 설립 6만엔~ | **MONKOS 최적** |

**일본 법인이 가장 자연스러움.** Stripe JP + LINE 미니앱 + PayPay 전부 한번에 해결.

### 당장은 법인 없이 MVP 가능

LINE 공식계정 + LIFF앱(웹앱) + PayPal/은행 이체로 테스트 → 매출 검증 후 법인 전환.

## 9. 초기 진입 실행 순서 (홍보)

### Step 0: 탄약 장전 [Week 1-2]

비포/애프터 사진 10세트 제작:
- 증명사진 5세트 (여권/취활)
- 프로필 사진 5세트
- **Imagen으로 가상 모델 생성 → 초상권 문제 원천 해결**
- 모델비 0원, 동의서 0장, 무한 생성 가능
- 경쟁사는 실제 고객 동의서 or 유료 모델 필요 → MONKOS만 마케팅 소재 자체를 AI가 무한 생산

> 이것이 MONKOS의 시작점이었다. 10년 사진관 운영 중 모델 사용 어려움 + 고객 초상권 이슈 → AI 생성 모델로 원천 해결.

### Step 1: 쇼윈도우 세팅 [Week 2-3]

인스타 계정 개설 (@monkos.jp):
- 비포/애프터 10세트 업로드
- 피드 그리드 예쁘게 정렬
- 해시태그: #証明写真 #就活写真 #韓国式写真
- 프로필에 LINE 공식계정 링크
- **"이 계정 뭐야 퀄리티 미쳤다" 상태 만들기**

### Step 2: 기폭 [Week 3-4]

X 계정에 임팩트 최강 1장 투하:
- 비포/애프터 4장 그리드
- "韓国式AI証明写真。同じ人です。"
- 용아가 일본어 문구 작성
- 리트윗 유도 (놀라움 → 공유)
- 반응 보고 2탄 3탄 연속 투하

### Step 3: 검색 보완 [동시 진행]

monk.kr/jp 페이지:
- "韓国式 証明写真 AI" 키워드
- Google 일본 검색 대응
- X에서 본 사람이 검색했을 때 잡히는 구조

### Step 4: 수확 [Week 4~]

```
X에서 터짐 → "어디서 해?"
    ↓
인스타 → "진짜네 퀄리티"
    ↓
LINE → "友達追加" → 촬영 시작
    ↓
monk.kr → 결제 → 납품
    ↓
만족한 고객이 X에 후기 → 재순환
```
