## 별첨 1: 오픈소스 AI 모델 벤치마크 검토 (1p)

### 검토 배경

MONKOS 서비스의 로컬 AI 추론 및 온디바이스 처리를 위해 오픈소스 경량 특화 모델을 지속적으로 벤치마크하고 있습니다.

### 시장 흐름 분석

| 트렌드 | 상세 |
|--------|------|
| 파라미터 경쟁 종료 | 거대 모델(100B+) → **특화 경량화(7B~30B)** 경쟁으로 전환 |
| 영역별 분화 | 코딩(Codestral), 다국어(Qwen), 이미지(Flux) 등 포지션별 특화 |
| 성능 역전 | "7B인데 특정 영역에서 70B급 성능" 모델 등장 |

### 벤치마크 대상 모델

| 모델 | 파라미터 | 특화 영역 | VRAM 요구 | 비고 |
|------|---------|----------|----------|------|
| **Llama 3 8B** | 8B | 범용 | ~6GB | Meta, 오픈소스 |
| **Mistral 7B** | 7B | 범용/추론 | ~6GB | 유럽 오픈소스 리더 |
| **Qwen 14B** | 14B | 다국어/한중일 | ~12GB | 알리바바, 아시아 강점 |
| **Codestral** | 22B | 코딩 전용 | ~18GB | Mistral, 코드 특화 |
| **Flux** | - | 이미지 생성 | ~23GB | 오픈소스 Stable Diffusion 계열 |
| **DeepSeek** | 7B~67B | 범용/코딩 | 가변 | 중국, 성능 대비 저비용 |

### MONKOS 적용 시나리오

```
[멀티 에이전트 동시 구동] 64GB VRAM 기준
├── 코딩 특화 7B (6GB)      → 개발 자동화
├── 범용 대화 7B (6GB)      → 고객 응대
├── 이미지 특화 Flux (23GB) → 비주얼 생성
├── 라우터/오케스트레이터 3B (3GB)
└── 여유 26GB              → QLoRA 튜닝 동시 가능
```

### 결론

- 오픈소스 경량 특화 모델이 증가할수록 MONKOS의 조합 가능성 확대
- 빅테크 API 의존 탈피 → 로컬 오케스트레이션으로 비용 절감 및 프라이버시 강화

## 별첨 2: 글로벌 공략국가 전략 비교 및 일본 선택 과정 (1p)

### 후보 국가 비교 분석

| 국가 | 수요 근거 | 인프라 갭 | K-뷰티 호감도 | 우선순위 |
|------|----------|----------|--------------|---------|
| **일본** | 재일 한국인 45만, 방일 200만+, 규격 혼동 빈발 | 사진관 비쌈, AI 앱 부재 | 수출 3위 ($10.87억) | **1순위** |
| 베트남 | 인구 1억+, 한국 비자 수요 폭발 | 지방 사진관 부재 | 82.9% (5위) | 2순위 |
| 인도네시아 | 인구 2.78억, 비자 필수 | 히잡 증명사진 니치 | 86.5% (2위) | 3순위 |
| 호주 | 순이민 46.8만, 아시안 다수 | PhotoAiD 규격 미달 사례 | 영어권 교두보 | 4순위 |

### 일본 선택 근거

**1. 즉각적 수요**
- 재일 한국인 45만 + 한국 방문 일본인 연간 200만+
- 일본 여권 45×45mm vs 한국 35×45mm → 규격 혼동 반려 빈발

**2. 인프라 갭**
- 일본 사진관(写真館): 1,500~3,000엔 (비쌈)
- 증명사진 기기(証明写真機): AI 코칭/보정 없음
- AI 증명사진 전문 앱 거의 없음, 중국산 앱 거부감 강함

**3. K-뷰티 프리미엄**
- "한국식 증명사진 = 깔끔하고 예쁜" 인식 이미 존재
- K-뷰티 수출 $10.87억 (글로벌 3위)

**4. 규제 환경**
- AI 규제 매우 관대 (OECD 최하위 수준)
- 여권 리터칭은 금지이나, **실시간 코칭은 규제 대상 아님**

### 진입 전략

| 단계 | 타겟 | 채널 |
|------|------|------|
| 1단계 | 재일 한국인 | LINE 채널, 한인 커뮤니티 |
| 2단계 | 한국 방문 일본인 | 일본어 LP, 리쿠르토 사진 특화 |
| 3단계 | 일본 현지 | 기존 写真館 패치(프랜차이즈) |

## 별첨 4: RTX 5090 / Mac Studio M5 도입 당위성 (1p)

### 도입 배경

- 클라우드 API 의존 → 비용 증가, 프라이버시 우려
- 로컬 AI 추론 → 비용 절감, 데이터 주권 확보
- 오픈소스 경량 모델 발전 → 로컬 구동 가능성 증가

### RTX 5090 선택 근거

| 항목 | RTX 5090 | RTX 4090 (비교) |
|------|---------|-----------------|
| CUDA 코어 | 21,760 | 16,384 |
| VRAM | 32GB GDDR7 | 24GB GDDR6X |
| 대역폭 | 1,792 GB/s | 1,008 GB/s |
| 멀티GPU 스케일링 | **0.91~0.97** | 0.76 (제한) |
| 가격 | ~$2,000 | ~$1,600 |

**핵심 포인트**: 5090은 4090 대비 멀티GPU 제한이 크게 완화됨

### 5090 x2 (64GB VRAM)로 가능한 작업

| 작업 | 가능 여부 |
|------|----------|
| 7B 풀 파인튜닝 | O |
| 7B~30B QLoRA 튜닝 | O |
| 70B 4bit 추론 | O |
| Flux 커스터마이징 | O |
| 멀티 에이전트 동시 구동 | O |

### Mac Studio M5 선택 근거

| 항목 | Mac Studio M5 Ultra (예상) |
|------|---------------------------|
| 통합 메모리 | 128~192GB |
| 대역폭 | ~30% 향상 (vs M4) |
| 출시 | 2026년 3~6월 예상 |
| 용도 | 70B 추론, MLX 개발 환경 |

**핵심 포인트**: TinyCorp 드라이버 + MLX CUDA 백엔드로 Mac ↔ NVIDIA 연결 가능

### 분리 세트 구조의 우위

| 항목 | 원보드 2GPU | 분리 세트 (채택) |
|------|------------|-----------------|
| 장애 격리 | 한 GPU 문제 → 전체 다운 | 세트별 독립 |
| 냉각 | 밀착, 폐열 간섭 | 독립 냉각 |
| 전력 | 1,500W+ 전용 회선 | 750W, 일반 콘센트 |
| 유연성 | 역할 전환 어려움 | 세트 단위 전환 자유 |

### 결론

> **2025년 12월 설계한 (5090 멀티 + Mac Studio M5) 구조가 2026년 2월 벤치마크 검증 결과 최적 시나리오로 확인됨.**

## 별첨 5: MONKOS 사업 로드맵 (1p)

### 4단계 성장 전략

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Stage 1: AI 앱 (무한 스케일)              [현재]          │
│  └── Gemini 코칭 → 규격 맞춤 → 디지털 파일                │
│                                                             │
│  Stage 2: 원격 검수 (프리미엄)             [2026 Q1]       │
│  └── 전문가 검수 → 발급보장 → 학습 데이터 축적            │
│                                                             │
│  Stage 3: 프랜차이즈 (국내)                [2026 Q2~]      │
│  └── 기존 사진관 패치 → AI 시스템 제공 → 로열티           │
│                                                             │
│  Stage 4: 글로벌 라이선스                  [2026 H2~]      │
│  └── 일본/베트남/인도네시아/호주 현지 파트너               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 기술 로드맵

| 시기 | 기술 목표 |
|------|----------|
| 2026 Q1 | Gemini Live 실시간 코칭 상용화 |
| 2026 Q2 | eKYC 본인확인 연동 |
| 2026 Q3 | AI 모델 에이전시 (가상 모델 생성) |
| 2026 Q4 | 영상 생성 파이프라인 (Veo 등) |
| 2027~ | 온디바이스 AI, 로컬 LLM |

### 하드웨어 로드맵

```
[현재] 4060
  └── 3B 튜닝, 7B 추론 테스트

[1차 — 2026 Q1] 5090 x2 + Mac Studio M5
  ├── 5090: 7B~30B 튜닝, Flux, 추론 서버
  └── Mac: 70B 추론, 개발 환경

[2차 — 2026 H2] 5090 x4 풀세트
  ├── 세트 A: 글로벌 서비스 (상시 온라인)
  └── 세트 B: ML 실험 (유동적)

[3차 — 2027~] PRO 6000 도입
  └── 안정적 추론 서버, 5090은 튜닝 전용
```
