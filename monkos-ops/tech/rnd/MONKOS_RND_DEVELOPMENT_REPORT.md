## 1. 연구 개요

### 1.1 연구 배경

현재 AI 이미지 생성 시장은 다음과 같은 한계에 직면해 있습니다:

| 문제점 | 현황 | 비즈니스 영향 |
|--------|------|--------------|
| **정체성 유지 불가** | I2I 시 얼굴/체형 왜곡 | K-뷰티 모델 상업화 불가 |
| **높은 Safety 제약** | 패션/이너웨어 생성 차단 | 합법적 콘텐츠도 제한 |
| **단편적 기능** | T2I, I2I, 분석 분리 | 워크플로우 비효율 |
| **학습 단절** | 생성 결과 DB화 안됨 | 품질 개선 불가 |

### 1.2 연구 목표

**MONK.KR**은 단순한 홈페이지가 아닌 **생명적 유기 시스템**입니다:

## 4. 핵심 기술 성과

### 4.1 ⭐ K뷰티 산업 특화 AI 데이터 파이프라인

**연구 방향**:
- 범용 AI 지능 개발이 아닌 **K뷰티 산업에 특화된 실용적 AI 시스템**
- 데이터 수집 → 검수 → 태깅 → 학습의 **완전 자동화 파이프라인**

**7단계 파이프라인 구축 완료**:

```
[STEP 1] 이미지 기반 데이터 크롤링
├── 네이버 API (25,000건/일 쿼터 확보)
├── Pinterest / Instagram 연동
├── K뷰티 쇼핑몰 (무신사, W컨셉, 29CM)
└── 결과: 7,897장 수집 완료 (2.8GB)
         │
         ▼
[STEP 2] Vertex Vision + Gemini 3.0 Pro 1차 검수
├── 이미지 품질 자동 판별
├── K뷰티 적합성 스코어링
├── 중복/저품질 자동 필터링
└── 학습 적합도 판정 (suitable_for_training)
         │
         ▼
[STEP 3] 자동 태깅 시스템
├── 헤어: style, length, texture, color, trend_name
├── 메이크업: eye, lip, blush, brow
├── 피부: type, texture, finish
├── 패션: style, silhouette, season, occasion
├── 포즈: type, mood, body_line
└── K뷰티 에스테틱: 청순, 걸크러시, 힙, 레트로, Y2K
         │
         ▼
[STEP 4] 리버스 프롬프팅
├── 태그 → 영문 프롬프트 자동 변환
├── BWYA 6대 학문 어휘 매핑
├── 기술적 설정 (조명, 카메라, 후처리) 추출
└── 네거티브 프롬프트 자동 생성
         │
         ▼
[STEP 5] 개발자 코멘트 추가 기능 ⭐
├── 실시간 품질 피드백 입력
├── 프롬프트 미세 조정 기록
├── 성공/실패 케이스 주석
└── 우선순위 메타데이터 (D1 저장)
         │
         ▼
[STEP 6] 데이터 품질 극대화
├── AI 자동 검수 + 인간 검수 하이브리드
├── 품질 점수 기반 자동 승인/보류/거절
└── 피드백 → 태깅 알고리즘 개선
         │
         ▼
[STEP 7] 무한 반복 학습 시스템 ♻️
├── 생성된 이미지 → STEP 2로 재투입
├── 성공 패턴 자동 학습
```

### 4.3 정체성 유지 I2I (IDENTITY_PRESERVATION)

**기술적 돌파**:
- Imagen 4 T2I는 신규 생성에 최적화
- **증명사진 등 I2I에는 Imagen 3 Pro + 특수 프롬프트 조합** 필요
- Vertex AI 프리미어 개발자 권한으로 **Safety 제어 가능**

**핵심 프롬프트**:

```javascript
const IDENTITY_PRESERVATION = {
  EN: "CRITICAL INSTRUCTION: Maintain the exact facial features, 
       body proportions, skin tone, facial structure, eye shape, 
       nose, lips, and overall model identity. 
       Preserve the person's unique characteristics 
       completely and precisely."
};
```

**적용 결과**:
- 동일 인물의 포즈/의상/배경 변경 시 정체성 유지
- K-뷰티 AI 모델 시리즈 생성 가능
- 이너웨어/패션 룩북 대량 생산 기반 확보

### 4.2 Safety Guard 최적화

**Vertex AI 프리미어 개발자 권한 활용**:

```javascript
function getSafetyThreshold(level) {
  const thresholds = {
    'BLOCK_LOW_AND_ABOVE': HarmBlockThreshold.BLOCK_LOW_AND_ABOVE,
    'BLOCK_MEDIUM_AND_ABOVE': HarmBlockThreshold.BLOCK_MEDIUM_AND_ABOVE,
    'BLOCK_ONLY_HIGH': HarmBlockThreshold.BLOCK_ONLY_HIGH,
    'BLOCK_NONE': HarmBlockThreshold.BLOCK_NONE  // ← 최대 자유도
  };
  return thresholds[level] || HarmBlockThreshold.BLOCK_ONLY_HIGH;
}
```

**적용 범위**:
- 패션/런웨이 이미지 생성
- 이너웨어/란제리 모델 생성
- K-뷰티 메이크업/스킨케어 콘텐츠
- **모든 합법적 상업 콘텐츠 생성 가능**

### 6.0 ⭐ 용아쌤 프로젝트 (AI 교육 시스템 혁신)

**"아이와 함께 만드는 AI 교과 과정 개발"**

#### 프로젝트 배경

| 항목 | 내용 |
|------|------|
| **공동 개발자** | 지후 (중2 진학, 대표 자녀) |
| **개발 환경** | RTX 4060 시스템 (로컬 AI) |
| **핵심 발견** | Gemini 중1 국어 정답률 **6/25 (24%)** - 심각한 할루시네이션 |
| **해결책** | RAG 시스템 도입 → 할루시네이션 제거 |

#### 문제 인식에서 해결까지

```
[문제] Gemini 국어 테스트 정답률 6/25 (24%) ❌
         │
         ▼
[원인] 교과서 기반 지식 없이 추론 → 할루시네이션
         │
         ▼
[해결] Vertex AI RAG + 교과서 벡터라이즈
         │
         ▼
[혁신] 학습자(지후)가 직접 AI를 훈련! (User = Builder)
```

#### 용아쌤 시스템 학습 루프

```
┌─────────────────────────────────────────────────────────────┐
│  [지후의 학습 + AI 빌더 루프]                               │
│                                                              │
│  1️⃣ 스스로 공부 계획 수립                                   │
│     "이번 주 국어 3단원 학습"                                │
│              │                                               │
│              ▼                                               │
│  2️⃣ 자료 선택 및 업로드                                     │
│     교과서 PDF, 문제집, 노트                                 │
│              │                                               │
│              ▼                                               │
│  3️⃣ AI(용아쌤)에게 질문                                     │
│     "이 문제 어떻게 풀어요?"                                 │
│              │                                               │
│              ▼                                               │
│  4️⃣ 피드백 제공                                             │
│     "이건 틀렸어요" → 할루시네이션 신고                     │

│              │                                               │

└─────────────────────────────────────────────────────────────┘
```

#### 교육적 가치 (차별화 포인트)

| 기존 AI 교육 | 용아쌤 방식 |
|-------------|------------|
| 학생 = 수동적 수신자 | 학생 = **능동적 AI 빌더** |
| AI = 만능 도구 | AI = **훈련 가능한 도구** |
| 할루시네이션 검증 불가 | **직접 목격 & 수정** |
| AI 의존성 증가 | **AI 활용 역량 체득** |

**5가지 교육 목표**:

1. **단순 교과 학습** → RAG 기반 정확한 정보
2. **AI 빌더 기초 소양** → 데이터 업로드/피드백 경험
3. **AI 본질 이해** → "AI는 완벽하지 않다" 체득
4. **AI 활용법 학습** → 프롬프트 엔지니어링 실습
5. **차세대 인재 양성** → User가 아닌 Builder로 성장
