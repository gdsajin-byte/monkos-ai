## 1. 서비스 파이프라인

### 핵심 구조

```
[고객 셀카/촬영]
      │
      ▼
[Gemini Live 실시간 코칭]  ← 조명, 배경, 포즈, 표정 실시간 피드백
      │
      ▼
[Imagen 3.0 규격 생성]    ← 국가별 규격 자동 맞춤 (크롭/리사이즈만)
      │
      ▼
[본인확인 + 규격 검증]    ← Gemini Vision 원본 대조
      │
      ├─ 기본 Tier → 디지털 파일 즉시 다운로드 (무료~저가)
      │
      └─ 프리미엄 Tier → 몽크사진관 휴먼 검수 → 발급보장 (유료)
```

### 기술 차별점 — "사후 보정" vs "사전 코칭"

- **경쟁 앱들**: 찍은 후 AI가 배경 제거, 피부 보정, 의상 교체 → **2026년 글로벌 AI 편집 규제에 정면 충돌**
- **MONKOS**: 찍기 전 AI가 실시간 코칭 → 규제 대상 자체가 아님

> "경쟁사들은 AI로 사진을 '고치는' 서비스입니다. MONKOS는 AI가 '찍는 방법을 가르치는' 서비스입니다. 규제가 강화될수록 사후 보정 앱은 죽고, 사전 코칭 서비스인 저희가 살아남습니다."

## 3. 2-Tier 비즈니스 모델

### 기본 Tier (무료~저가)

- Gemini Live 촬영 코칭 → AI 규격 맞춤 → 디지털 파일 즉시 다운로드
- 고객이 직접 현지 인화 or 온라인 제출
- 반려 시 MONKOS 면책 ("AI가 규격 맞춰드렸지만 최종 판단은 발급기관")

### 프리미엄 Tier (발급보장)

- 기본 전체 + 원본/출력본 몽크사진관 원격 검수 (1일 이내)
- 10년 경력 전문가(작가님/한송이 작가님)가 "통과/재촬영" 판정
- 재촬영 시 구체적 코칭 피드백 포함
- 반려 시 재촬영 보장

### 고객 심리 흐름

1. AI가 "규격 맞았습니다" → 자신감 있으면 바로 다운로드
2. "근데 이거 진짜 통과되나...?" 불안하면 → 프리미엄 검수 신청
3. 한번 반려 경험 있는 사람 → 처음부터 프리미엄

### 해외 시장에서 프리미엄 가치 상승

- "한국 사진관 전문가 검수" = K-뷰티 프리미엄과 시너지
- 현지 사진관 반려 경험자에게 "10년간 수만 명 99% 통과시킨 한국 전문가 검수"는 지불 의사 높음

### MONKOS 포지셔닝 — 규제 "외" 영역

**전 세계 금지**: 피부 보정, 주름 제거, 눈 색상 변경, AI 얼굴 생성/합성, 필터, 배경 AI 생성

**전 세계 허용**: 크롭/리사이즈, 해상도 조정, 밝기/대비 기본 조정, AI 규격 검증, **실시간 촬영 코칭**

Gemini Live는 사진 자체를 편집하지 않음 → 규제 대상 자체가 아님:
1. 조명 체크 → "왼쪽으로 10도 이동하세요" (편집 아님)
2. 배경 체크 → "뒤에 그림자 있어요, 위치 바꾸세요" (편집 아님)
3. 포즈 체크 → "턱을 살짝 당기세요" (편집 아님)
4. 규격 체크 → 크롭/리사이즈만 (전 세계 허용)

## 5. 글로벌 타겟 시장 분석

### 🥇 일본 — 압도적 1순위

**수요 근거**
- 재일 한국인 45만 + 한국 방문 일본인 연간 200만+
- 일본 여권 45×45mm vs 한국 35×45mm → 규격 혼동 반려 빈발
- K-뷰티 수출 $10.87억 (3위), 프리미엄 인식 검증

**인프라 갭**
- 사진관(写真館) 비쌈 (1,500~3,000엔)
- 증명사진 기기(証明写真機, Ki-Re-i) AI 코칭/보정 없음
- AI 증명사진 전문 앱 거의 없고 중국산 앱 거부감 강함

**진입 포인트**
- "한국식 증명사진 = 깔끔하고 예쁜" 인식 이미 존재
- LINE 채널 활용, 일본어+한국어 이중 지원

### 🥈 베트남 — 성장 잠재력 최고

**수요 근거**
- 인구 1억+, 중위연령 31세, 해외여행 급증
- 한국 방문 베트남인 비자 신청 수요 폭발
- 재한 베트남인 20만+ (유학생+노동자)
- 한류 호감도 82.9% (글로벌 5위)

**인프라 갭**
- 사진관 대도시 편중, 시골 지역 부재

**진입 포인트**
- Zalo(국민앱) 미니앱 진입

- 기본 tier 무료 → 가격 민감 시장 대응

**수요 근거**
- 인구 2.78억, 인스타 유저 1억+
- 여권 세계 64위 → 어디가든 비자 필요

**인프라 갭**

## 6. 중국 시장 진출 전략 (우회 루트)

### 직접 진출이 어려운 이유

1. **생성형 AI 서비스 관리 잠정방법 (2023)** — 중국 주민 대상 AI 콘텐츠 생성은 국내외 사업자 모두 적용, "사회주의 핵심 가치 견지" 요구
2. **AI 콘텐츠 라벨링 의무** — 2025.9부터 의무화, 4~6월 불법 AI 제품 3,500개 폐쇄
3. **데이터 주권** — 얼굴 데이터 해외 이전 사실상 금지

### 우회 루트 3가지

**루트 1: 위챗 미니프로그램 (크로스보더)**
- 중국 법인 없이 해외 법인으로 퍼블리시 가능
- 2025년 해외 미니프로그램 거래량 전년 대비 40%+ 성장
- 위챗 페이 결제, RMB → 원화 정산
- 한국 서버에서 AI 처리 → 중국 규제 대상 아님

**루트 2: 재한 중국인 + 한류 관광객 타겟**
- 중국 "안"에 안 들어가고 중국인을 잡는 전략
- 한국 체류 중국인(유학생, 주재원, 관광객) → 비자 갱신/여권 갱신 수요
- 위챗으로 소통, 위챗 페이로 결제, 서비스는 100% 한국 내 → 중국 규제 비대상

**루트 3: K-Beauty 증명사진 브랜딩 (간접 수출)**
- 샤오홍슈/더우인에서 "한국 사진관에서 찍은 증명사진 후기" 바이럴
- 위챗 미니프로그램으로 원격 주문 (셀카 업로드 → MONKOS AI 처리 → 택배)

### 단계별 접근

| 단계 | 타겟 | 채널 | 규제 리스크 |
|------|------|------|----------|
| 1단계 (지금) | 한국 내 중국인 | 위챗 공식계정 + 미니프로그램 | 없음 |
| 2단계 (6개월 후) | 한국 방문 중국 관광객 | 위챗 미니프로그램 크로스보더 | 낮음 |
| 3단계 (1년 후) | 중국 본토 원격 고객 | 크로스보더 e커머스 | 중간 |
| ❌ 비추 | 중국 본토 직접 서비스 | 중국 앱스토어 | 매우 높음 |

## 7. 10년 현장 경험 기반 검수 시스템

### 작가님 경력

- 10년간 수만 명 여권/비자 사진 촬영, 통과율 99%

### 경쟁 앱과의 차이

- 경쟁 앱: 규격표 스펙만 보고 크롭
- MONKOS: 실제 통과된 사진의 패턴 학습
- 규격표에 "배경 흰색"이라고만 써있지만 실제로는 "이 정도 아이보리는 통과되고 이 정도는 안 돼"라는 현장 그레이존을 아는 AI

### Gemini 학습 전략

| Phase | 내용 | 처리 방식 |
|-------|------|---------|
| Phase 1 (지금~초기) | 작가님/한송이 작가님 직접 검수 | 통과/반려 판정 데이터 축적 |
| Phase 2 (데이터 축적) | 국가별 통과/반려 케이스 Gemini 피딩 | 패턴 학습 자동화 |
| Phase 3 (자동화) | Gemini 국가별 규격 자동 판정 | 작가님은 엣지 케이스만 검수 |

### 데이터 보관 정책

- 원본/생성본 이미지: 72시간 임시 업로드 후 자동 삭제
- 통과/반려 메타데이터만 장기 보관 (국가, 규격, 조명조건, 판정결과)
- 얼굴 사진 미보관 → 각국 개인정보 규제 클리어
- 학습에 필요한 패턴 데이터만 추출

## 8. 검수 시스템 스케일링 로드맵

### 초기 (MVP): 텔레그램 기반 수동 검수

1. 고객 촬영 → AI 규격 맞춤
2. "검수 원하시면 텔레그램으로 전송" 버튼
3. 텔레 용아가 작가님한테 알림
4. 작가님/한송이 작가님 판정 (원본 + 생성본 비교)
5. 텔레로 회신 ("통과" or "재촬영 — 이유: 그림자")
- 추가 개발 거의 제로 (기존 텔레 + 용아 인프라 활용)
- 초기 고객 수 적을 때 충분히 소화 가능 (하루 10~20건)

### 스케일링 서킷브레이커

| 일 처리량 | 운영 방식 | 작가님 작업량 |
|----------|---------|-----------|
| ~100건 | 수동 검수 (텔레 접수) | 전수 검수 |
| 100~1,000건 | Gemini 1차 자동 판정, "판단 불가"만 검수 | 하루 50건 이내 |
| 1,000~10,000건 | Gemini 완전 자동, 프리미엄 예약제+대기열 | 슬롯 한정 |
| 50,000건+ | 기본 100% AI, 프리미엄 "마스터 검수" 브랜딩 | 검수원 채용+교육 |

## 9. 몽크 패치 — 프랜차이즈 플랫폼

### 개념

기존 사진관에 MONKOS AI 시스템을 "패치"하는 프랜차이즈 모델.

### 기존 사진관의 고통

- AI 앱들이 증명사진 시장 잠식 (6천원 앱 vs 1.5~2만원 사진관)
- 본인들은 AI 기술 없어서 손 놓고 당하는 중

### 몽크 패치가 주는 것

- 기존 간판 유지 + 몽크 인증 마크 추가
- 몽크 시스템 접근권 (AI 코칭 + 규격 자동화 + 검수 네트워크)
- 텔레 채널에서 원격 검수 물량 수주 → 건당 2~3천원 추가 수익

### 가맹 조건

- 가맹비 2천만원 + 몽크 간판
- 텔레그램 작업 채널 참여권
- AI가 프로세스 전체 처리, 가맹점은 현장 대응만
- 작가님 교육 커리큘럼으로 품질 표준화

### 진입장벽 파괴

- **기존 프랜차이즈**: 장비 → 기술 배우기 → 본인이 촬영 → 보정
- **몽크 프랜차이즈**: AI가 코칭 → AI가 규격 → AI가 판정 → 가맹점은 고객 접점만
- 사진 실력 없어도 시스템이 다 처리 → 가맹 대상 확대 (편의점, 무인부스, 인화점)

### 온라인-오프라인 하이브리드

```
[고객]
  ├─ 온라인: 앱으로 셀프 촬영 → AI 처리 → 다운로드
  │    └─ 불안하면 → 원격 검수 (몽크사진관 or 가맹점)
  │    └─ 반려되면 → 가까운 몽크 가맹점 방문
  │
  └─ 오프라인: 몽크 가맹점 직접 방문 → AI+사진사 하이브리드 촬영
       └─ 발급보장 + 현장 인화

[가맹점]
  ├─ 본인 고객: 기존 매출 + 몽크 프리미엄
  ├─ 온라인 물량: 텔레 채널에서 검수 건 수주 (건당 2~3천원)
  └─ 클레임 대응: 반려 고객 현장 재촬영 (추가 매출)

[MONKOS 본사]
  ├─ AI 시스템 운영/업그레이드
  ├─ 가맹비 + 월 로열티
  ├─ 품질 표준 관리 + 교육
  └─ 글로벌 확장
```

> "기존 사진관을 위협하는 게 아니라 기존 사진관을 살리는 AI 플랫폼입니다. AI 앱이 사진관의 적이었는데, MONKOS는 사진관에 AI를 쥐어주면서 '같이 싸우자'로 바꿉니다."

## 10. 글로벌 프랜차이즈 확장 모델

### 구조

```
MONKOS 본사 (하남)
  │
  ├─ AI 엔진 (Gemini + Imagen) ─── 전 세계 동일 시스템
  ├─ 품질 표준 ─── 작가님 10년 노하우 기반 매뉴얼
  ├─ 국가별 규격 DB ─── 계속 업데이트
  │
  ├─ 🇰🇷 한국 가맹점 (검증 완료)
  ├─ 🇯🇵 일본 가맹점 (기존 写真館 패치 + 한인 신규)
  ├─ 🇻🇳 베트남 가맹점 (한인 교민 + 현지인)
  ├─ 🇮🇩 인도네시아 가맹점 (히잡 전문)
  └─ 🇦🇺 호주 가맹점 (한인 + 이민 에이전시)
```

### 글로벌 시나리오

- 호치민 한국 교민 → "몽크 패치 달게요" → 재베트남 한국인 + 베트남 현지인 커버
- 오사카 기존 写真館 주인 → 매출 하락 → 몽크 시스템 도입 → AI가 다 처리, 본인은 고객 응대만
- 자카르타 히잡 전문 사진관 → 몽크 패치 → 인도네시아 최초 AI 히잡 증명사진 전문점
- 시드니 한인타운 사진관 → 몽크 패치 → 재호 한국인 + 아시안 이민자 전체 커버

### 수익 구조

| 수익원 | 단가 | 스케일 |
|--------|------|--------|
| 앱 기본 tier (광고/프리미엄) | 소액 | 무한 |
| 원격 검수 | 건당 5~10천원 | 일 수천 건 |
| 가맹비 | 2천만원/점 | 국가별 수십~수백 |
| 월 로열티/시스템 사용료 | 월 30~50만원/점 | 반복 |
| 텔레 물량 수수료 | 건당 2~3천원 | 가맹점 확대 비례 |
| 국가별 마스터 라이선스 | 대형 계약 | 국가 단위 |

## 11. 4단계 성장 로드맵

### Stage 1: AI 앱 (무한 스케일)

- 기본 tier. Gemini 코칭 → 규격 맞춤 → 다운로드
- 인원 제한 없음. 서버 비용만 비례

### Stage 2: 원격 검수 (작가님 팀)

- 프리미엄 tier. 텔레 접수 → 몽크사진관 직접 판정
- 초기 핵심 수익원 + 학습 데이터 축적

### Stage 3: 몽크 프랜차이즈 (국내 폭발 시)

- 가맹비 2천만원 + 몽크 간판
- AI 프로세스 전체 처리, 가맹점은 현장 대응만
- 작가님 교육 커리큘럼으로 품질 표준화

### Stage 4: 글로벌 라이선스

- 일본/베트남/인도네시아/호주 현지 사진관에 동일 모델 적용
- 각국 현지 파트너에게 라이선스 판매
- 건당 수수료 or 월 로열티

> "전문가가 AI를 가르치고, AI가 고객을 가르칩니다. 국가가 늘어나도 전문가는 추가 불필요합니다."

## 12. 디딤돌 인터뷰 핵심 메시지

### 기술 차별점

> "경쟁사들은 AI로 사진을 '고치는' 서비스입니다. MONKOS는 AI가 '찍는 방법을 가르치는' 서비스입니다. 규제가 강화될수록 사후 보정 앱은 죽고, 사전 코칭 서비스인 저희가 살아남습니다."

### 현장 경험

> "저는 10년간 수만 명의 여권사진을 찍고 99% 통과시킨 사람입니다. 그 노하우를 AI 코칭 엔진에 넣었고, 마지막은 제가 직접 검수합니다. 경쟁 앱들은 규격표만 보고 만들었지만, 저희는 실제 통과/반려 데이터로 만들었습니다."

### 플랫폼 비즈니스

> "기존 사진관을 위협하는 게 아니라 기존 사진관을 살리는 AI 플랫폼입니다. AI 앱이 사진관의 적이었는데, MONKOS는 사진관에 AI를 쥐어주면서 '같이 싸우자'로 바꿉니다."

### 스케일 전략

> "전문가가 AI를 가르치고, AI가 고객을 가르칩니다. 국가가 늘어나도 전문가는 추가 불필요합니다."

### 글로벌 프랜차이즈

> "AI 앱 하나 만들겠습니다가 아닙니다. 글로벌 AI 사진관 프랜차이즈 플랫폼을 구축하겠습니다."
