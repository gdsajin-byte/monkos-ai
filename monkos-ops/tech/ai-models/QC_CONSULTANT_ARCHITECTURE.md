# QC 컨설턴트 아키텍처 — Gemini 3 Flash 기반 포토 상담 시스템

**작성:** 2026-02-15 (세션24)
**상태:** 전략 설계 단계
**담당:** 쌍아 (설계) + 막내 (구현 예정)

## 1. 현재 아키텍처 (v1.0 — QC 검수관)

```
촬영 → Imagen 4.0 생성 → Gemini QC (PASS/FAIL) → 다운로드
                                    ↓
                          단발성 판정, 대화 없음
```

### 현재 QC 판정 항목 (세션24에서 강화)
- 동일 인물 여부 (얼굴 구조, 눈/코/입 비율)
- 유사도 % (0-100)
- **성별 일치** (gender_match) — 원본 외형 기준
- **연령대 일치** (age_match) — 10세 이상 차이 감지
- **과보정 감지** (over_retouched) — 윤곽/눈크기/헤어 변형
- 구도 분석 (bounding box, face_ratio, 중앙 정렬)

### 현재 한계
- FAIL이면 "다시 찍기"만 가능 — 원인 설명 없음
- 사용자가 왜 실패했는지 모름
- 재생성 시 같은 프롬프트 반복 → 같은 결과

## 2. 목표 아키텍처 (v2.0 — 포토 컨설턴트)

```
촬영 → Imagen 생성 → Gemini 분석
                         ↓
                   ┌─ PASS → 다운로드
                   └─ FAIL/개선가능 → Gemini 상담 대화
                                        ↓
                                  사용자와 멀티턴 상담
                                  "이마가 가려져 여권 부적합"
                                  "조명 보정해서 재생성할게요"
                                        ↓
                                  Gemini → Imagen 정밀 프롬프트 재구성
                                        ↓
                                  Imagen 재생성 → 다시 QC
                                        ↓
                                  만족할 때까지 반복
```

## 3. Gemini 3 Flash 역할 확장

### 기존: QC 검수관
- 원본 vs 생성물 비교
- JSON 결과 반환
- 단발성 요청/응답

### 확장: 포토 컨설턴트
| 역할 | 설명 |
|------|------|
| **규격 전문가** | 여권/비자/이력서별 규격 기준 판단 |
| **상담사** | 사용자에게 문제점과 해결방안 안내 |
| **프롬프트 엔지니어** | 분석 결과 기반 Imagen 프롬프트 자동 튜닝 |
| **품질 관리자** | 재생성 결과 재검증 |

### 상담 시나리오 예시

**시나리오 1: 여권 — 이마 가림**
```
Gemini: "여권 사진 규격상 이마가 최소 60% 이상 보여야 합니다.
         현재 앞머리가 이마를 가리고 있어요.
         옵션 1: 머리를 뒤로 넘기고 다시 촬영
         옵션 2: AI로 앞머리를 자연스럽게 정돈하여 재생성"
사용자: "옵션 2로 해주세요"
Gemini → Imagen: 기존 프롬프트 + "forehead fully visible, hair neatly swept back"
```

**시나리오 2: 성별 설정 오류**
```
Gemini: "설정이 '여성'으로 되어있는데, 원본은 남성으로 보입니다.
         성별을 '남성'으로 변경하고 재생성할까요?"
사용자: "네"
→ 자동으로 gender 변경 후 재생성
```

**시나리오 3: 과보정 감지**
```
Gemini: "피부 보정이 과도하게 적용되었습니다.
         여권/신분증 사진은 자연스러운 보정만 허용됩니다.
         보정 강도를 줄여서 재생성할게요."
→ IDENTITY_PRESERVATION 비율 조정하여 재생성
```

## 4. 기술 구현 방향

### Phase 1: 백엔드 상담 API (관리자용)
- `/api/qc/consult` — Gemini 멀티턴 대화 엔드포인트
- 세션 기반: QC 결과 + 원본/생성물 이미지를 컨텍스트로 유지
- 작가님이 직접 Gemini와 대화하며 QC 정책 튜닝

### Phase 2: 사용자 앱 통합
- QC FAIL 시 상담 UI 표시 (채팅 버블)
- Gemini 응답을 사용자 친화적 메시지로 변환
- "재생성" 버튼 클릭 시 Gemini가 튜닝한 프롬프트로 Imagen 재호출

### Phase 3: 자동 재생성 루프
- Gemini가 자동으로 프롬프트 수정 → Imagen 재생성 → 재QC
- 사용자 개입 없이 최적 결과 도출 (최대 3회 시도)
- 3회 실패 시 사용자에게 상담 대화 전환

## 5. Imagen 프롬프트 튜닝 전략

### Gemini가 조정 가능한 프롬프트 변수
| 변수 | 현재 | Gemini 조정 범위 |
|------|------|-----------------|
| IDENTITY_PRESERVATION | 90:10 | 85:15 ~ 95:5 |
| 헤어스타일 지시 | 고정 | "forehead visible", "hair neatly arranged" 등 추가 |
| 조명 보정 | 고정 | "even lighting", "reduce shadow on left" 등 |
| 표정 지시 | 고정 | "neutral expression", "slight smile" 등 |
| 의상 보정 | 스타일별 고정 | 규격 위반 시 구체적 지시 추가 |

### 프롬프트 재구성 흐름
```
1. Gemini QC 분석 결과 수신
2. 문제 항목 식별 (gender_match, age_match, over_retouched 등)
3. 문제별 프롬프트 보정 지시 생성
4. 기존 Imagen 프롬프트 + 보정 지시 합성
5. Imagen 재호출
```

## 6. 크레딧 정책

- QC 상담 자체: 무료 (Gemini Flash 비용 미미)
- 재생성: 추가 1c (사용자 동의 후)
- 자동 재생성 루프: 최초 1c로 최대 3회까지 포함
- 수동 상담 후 재생성: 별도 1c

3. **이후**: 사용자 앱 통합 (Phase 2)
