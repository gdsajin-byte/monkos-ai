## 0. 핵심 요약

마케팅을 감이 아닌 **데이터 기반 반복 실험**으로 전환한다.
두 개의 파이프라인을 동시에 구축한다:

1. **벤치마크 크롤링 파이프라인** — 경쟁 채널 데이터 수집 → 패턴 분석
2. **콘텐츠 자동 생산 파이프라인** — n8n 기반 콘텐츠 생성 → 예약 포스팅

블로그 시절 검증된 전략을 적용한다:
**"2개월 테스트 → 반응 없으면 버리고 → 다시 시작"**

## 1. 문제 정의

### 1-1. 시장 환경
- SNS 피드가 CivitAI NSFW 3단계 수준의 AI 생성물로 포화
- 클릭 기반 알고리즘 = 선정성이 노출 독점
- "건전한 콘텐츠 열심히 올리세요"는 실효성 없음

### 1-2. AI 증명사진의 구조적 마케팅 병목
- 카페/음식/여행 콘텐츠 = 소스 무한
- **AI 증명사진 콘텐츠 = 사람의 얼굴이 원재료**
- 비포(셀카) 수집이 극한으로 어려움:
  - 유입된 고객이 제공하지 않으면 없음 (닭과 달걀)
  - 내부 인력(작가님/한송이/꾸/모델들) 얼굴 수 한정
  - AI로 비포 생성 시 "가짜" 의심 리스크
- **이 병목이 인스타 성장 실패의 근본 원인**

### 1-3. 현재 계정 현황 (@monk_photo)
- 게시물 40개 / 팔로워 27명 / 인게이지먼트 거의 없음
- 오프라인 시절 사진 + 초기 이마젠 생성물 혼재
- 알고리즘이 계정 정체성을 분류 불가 상태
- 에이징 자산은 있으나, 리포지셔닝 vs 새 계정 판단 필요

## 3. 파이프라인 A: 벤치마크 크롤링 시스템

### 3-1. 목적
경쟁/참고 채널의 데이터를 수집하여 **어떤 패턴이 먹히는지** 추출

### 3-2. 기술 스택

```
Apify (Instagram Scraper Actors)
    │
    ├── Profile Scraper → 계정 메타데이터
    ├── Post Scraper → 게시물별 인게이지먼트
    ├── Hashtag Scraper → 해시태그 도달 데이터
    └── Reel Scraper → 릴스 성과 데이터
    │
    ▼
JSON/JSONL → 로컬 저장 (Tailscale 인프라)
    │
    ▼
분석 스크립트 (Python)
    │
    ├── 인게이지먼트율 = (likes + comments) / followers × 100
    ├── 콘텐츠 타입별 성과 비교
    ├── 해시태그 조합별 효과
    ├── 포스팅 시간대별 분석
    └── 팔로워 성장률 추적
    │
    ▼
주간 리포트 자동 생성 → 철창 분석 → 작가님 의사결정
```

### 3-3. 벤치마크 대상 (쌍아 서칭 요청)

**카테고리별 각 3~5개, 총 15~20개 확보 요청:**

- 국내 AI 증명사진/프로필 서비스 계정
- 해외 AI headshot 서비스 (HeadshotPro, Aragon AI 등)
- 국내 인기 프로필 사진관 (강남/홍대권)
- AI 기반 서비스로 인스타 성장 성공 사례
- 일본 AI 証明写真 관련 계정 (일본 계정 벤치마크용)

### 3-4. 크롤링 주기
- 일 1회 야간 배치 (Apify 스케줄러)
- Apify 무료 플랜: 월 $5 크레딧 (소규모 충분)

## 4. 파이프라인 B: n8n 콘텐츠 자동 생산 시스템

### 4-1. 목적
AI 증명사진의 **콘텐츠 원재료 병목**을 자동화로 돌파

### 4-2. 핵심 설계 사상

비포 셀카를 수집할 수 없으므로, **콘텐츠 유형 자체를 병목이 없는 방향으로 설계**한다.

### 4-3. 콘텐츠 유형별 자동화 설계

#### TYPE A: 결과물 쇼케이스 (병목: 낮음)
- 몽크스 앱으로 생성한 다양한 스타일의 증명사진 결과물
- 내부 인력(한송이/꾸/모델들)의 실제 결과물 활용
- n8n 흐름: 결과물 이미지 → 자동 리사이즈/워터마크 → 캡션 생성 → 예약 포스팅

#### TYPE B: 스타일 비교 캐러셀 (병목: 낮음)
- 같은 인물의 다양한 스타일 변환 (정장/캐주얼/의사/변호사 등)
- 1인으로 4~8장 캐러셀 제작 가능
- n8n 흐름: 스타일 세트 지정 → 몽크스 API 배치 처리 → 캐러셀 자동 조합 → 예약

#### TYPE C: 프로세스 릴스 (병목: 중간)
- 앱 사용 과정 화면 녹화 15초
- "셀카 1장 → 3분 → 증명사진 완성" 과정을 타임랩스로
- n8n 흐름: 화면 녹화 소스 → 자동 편집(배속/텍스트 오버레이) → 예약
- ⚠️ 이 부분은 반자동 — 녹화는 수동, 후처리만 자동화

#### TYPE D: 정보성 콘텐츠 (병목: 없음)
- "증명사진 규격 가이드" "여권사진 반려 사유 TOP5" 등
- 얼굴 원재료 불필요, 텍스트/인포그래픽 기반
- n8n 흐름: 주제 리스트 → AI 캡션 생성 → 템플릿 이미지 생성 → 예약

#### TYPE E: 시즌 콘텐츠 (병목: 없음)
- 취업 시즌(3-4월/9-10월), 여권 시즌, 졸업 시즌 연동
- Google Trends 데이터 연동하여 시즌 자동 감지
- n8n 흐름: Trends API → 시즌 키워드 감지 → 맞춤 콘텐츠 트리거

### 4-4. n8n 자동화 플로우 (전체)

```
[콘텐츠 소스]
    │
    ├── 내부 인력 촬영/생성 결과물 (수동 입력)
    ├── 몽크스 앱 배치 생성 (API 호출)
    ├── 정보성 콘텐츠 템플릿 (자동 생성)
    └── 시즌 트리거 (Google Trends 연동)
    │
    ▼
[n8n 처리 파이프라인]
    │
    ├── 이미지 리사이즈 + 워터마크 (monkos.ai 브랜딩)
    ├── AI 캡션 생성 (Claude API 호출)
    ├── 해시태그 자동 세팅 (벤치마크 데이터 기반 최적 조합)
    ├── 캐러셀 자동 조합 (TYPE B)
    └── 텍스트 오버레이 (TYPE D/E)
    │
    ▼
[검수 단계]
    │
    ├── 한송이님 / 꾸님이 최종 검수
    └── 승인 시 → 예약 큐로 이동
    │
    ▼
[포스팅]
    │
    ├── Instagram Graph API 또는 Meta Business Suite 연동
    ├── 계정별 스케줄 관리
    │   ├── @monk_photo: 주 5회 (월~금)
    │   ├── @monkos.ai: 주 3회
    │   └── 일본 계정: 주 3회
    └── 포스팅 후 인게이지먼트 데이터 자동 수집 → 파이프라인 A로 피드백
```

### 4-5. 주간 콘텐츠 믹스 (계정당)

| 요일 | monk_photo | monkos.ai | 일본 계정 |
|------|-----------|-----------|----------|
| 월 | TYPE A 결과물 | TYPE D 정보성 | TYPE A 결과물 |
| 화 | TYPE B 캐러셀 | - | TYPE D 정보성 |
| 수 | TYPE D 정보성 | TYPE A 결과물 | - |
| 목 | TYPE C 릴스 | - | TYPE B 캐러셀 |
| 금 | TYPE E 시즌 | TYPE C 릴스 | TYPE A 결과물 |

- 한송이님: monk_photo 메인 검수 + TYPE C 릴스 촬영 보조
- 꾸님: 일본 계정 검수 + 전체 스케줄 모니터링
- 자동화: TYPE D/E는 거의 풀 자동, TYPE A/B는 반자동

## 7. 기술 참고 사항

### 필요 API/서비스
- **Apify**: 인스타 크롤링 (월 $5 무료 크레딧)
- **Instagram Graph API**: 포스팅 자동화 (비즈니스 계정 필수)
- **n8n**: 전체 워크플로우 오케스트레이션 (자체 호스팅)
- **Claude API**: 캡션/해시태그 자동 생성
- **Google Trends API**: 시즌 감지

### 인프라 활용
- 기존 Tailscale VPN 네트워크 활용
- n8n은 기존 서버에서 구동
- 데이터 저장: JSONL → 추후 SQLite 확장 가능

### 법적 고려
- 인스타 공개 프로필 스크래핑: 공개 데이터로 법적 허용
- 결과물 게시 시 AI 생성 표기 권장 (메타 정책 준수)
- 내부 인력 초상권: 사전 동의서 확보
