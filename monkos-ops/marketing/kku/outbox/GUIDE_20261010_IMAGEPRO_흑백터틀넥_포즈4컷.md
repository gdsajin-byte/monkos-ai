# 흑백 터틀넥 프로필 — 포즈 4컷

참고 이미지 2×2를 왼쪽 위부터 순서대로 옮겼습니다. 공통 문장을 맨 앞에 붙이고 컷 문장을 이어 넣으세요. 비율 `4:5` · 모델 `ultra`. AI 가상 인물이므로 포즈·분위기 참고용으로만 쓰고 촬영 사례처럼 게시하지 않습니다.

## 한글판

**공통 문장**
```
한국인 30대 여성의 흑백 스튜디오 프로필 사진.
자연스러운 한국인 얼굴, 짙은 머리를 느슨하게 올려 묶고 얇은 시스루 앞머리와 옆머리가 얼굴선을 따라 흘러내린다.
몸에 붙는 검정 니트 터틀넥.
밝은 회색 무지 배경, 왼쪽에서 들어오는 부드러운 빛, 선명한 흑백 대비, 고운 필름 입자감,
차분하고 우아한 분위기, 상반신 구도.
```

**피할 것**
```
컬러, 글자, 워터마크, 로고, 손가락 개수 이상, 뒤틀린 손, 진한 화장, 플라스틱 같은 피부, 액세서리
```

1. **얼굴 클로즈업, 정면 응시**
```
얼굴과 어깨만 가까이. 몸은 살짝 옆으로 돌리고 얼굴은 카메라 쪽, 턱을 조금 당겨 깊은 눈빛으로 카메라를 똑바로 본다.
```
2. **목에 손 대기**
```
가슴 위까지. 한 손 손끝을 목 옆 터틀넥 깃에 가볍게 대고, 다른 팔은 허리 앞으로 감싼다. 카메라를 차분하게 본다.
```
3. **손을 어깨 높이로 올리고 옆 보기**
```
허리 위까지. 한 손을 어깨 높이로 들어 손가락을 부드럽게 구부리고, 다른 팔은 몸 앞으로 감싼다. 고개를 살짝 들어 카메라 옆 먼 곳을 본다.
```
4. **팔짱 끼고 고개 기울이기**
```
허리 위까지. 한 손으로 반대쪽 팔을 감싸 가볍게 팔짱을 끼고, 고개를 한쪽으로 살짝 기울여 카메라에서 살짝 비껴 본다.
```
