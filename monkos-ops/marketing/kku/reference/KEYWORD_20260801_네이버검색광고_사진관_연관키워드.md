# 네이버 검색광고 연관키워드 실측 — 사진관 / 미사역사진관

> 월간검색수 = PC + 모바일 합산. `< 10`은 5로 환산.
> M2에서 `/market-eye` 미가동(requests·gcloud 미설치) 상태에서 꾸가 직접 수집한 데이터.
> **본 문서가 키워드 판단의 실측 근거 정본.**

## 1. 지역 키워드 — 미사 vs 하남

### 총합

| 계열 | 합계 | 비고 |
|---|---|---|
| 미사 | 995 | 키워드 6종 |
| 하남 | 1,810 | 키워드 18종 |

총합은 하남이 1.8배. **다만 단일 키워드와 경쟁도를 보면 판단이 뒤집힌다.**

### 핵심 대조

| 키워드 | 검색량 | 경쟁 | 판정 |
|---|---|---|---|
| **미사역사진관** | **470** | **중간** | 미사 우세 |
| 하남사진관 | 430 | 높음 | |
| **미사증명사진** | **240** | **중간** | 미사 압도 |
| 하남증명사진 | 150 | 높음 | |
| **하남여권사진** | **130** | **중간** | **하남 전용** |
| 미사여권사진 | 데이터 없음 | — | |

**결론**
- 사진관·증명사진 → **미사**가 검색량 크고 경쟁 낮음
- 여권사진 → **하남만 존재.** "미사여권사진"은 검색 수요 없음
- → 블로그 프리픽스 `[미사역 사진관]` 유지. 여권 글 본문에만 하남 삽입

## 3. 노려볼 자리 — 검색량 1,000+ & 경쟁 중간 이하

| 키워드 | 검색량 | 경쟁 | 현황 |
|---|---|---|---|
| **운전면허증사진규격** | **12,100** | 중간 | 기존 글 109회만 획득 — **최대 기회** |
| **여권사진규정** | **9,410** | 중간 | 관련 글 다수 보유 |

| 노량진사진관 | 1,260 | 중간 | 지역 무관 |

### 1순위 — 운전면허증사진규격

- 검색량 12,100 (여권사진앞머리 7,150의 **1.7배**)
- 경쟁 **중간** (앞머리는 "높음"인데도 1,248 달성)
- **2026년 3월부터 여권 규격 적용**이라는 규정 변경 훅 보유
- 기존 글 존재: "운전면허 증명사진 규격과 잘 찍는 법 — 바뀐 규정 꼭 확인하세요" (2026-04-16, **109회**)

**조치**: 신규 집필 금지(카니발). 기존 글을 승리 공식 제목으로 **업데이트**.

```
현재: 운전면허 증명사진 규격과 잘 찍는 법 — 바뀐 규정 꼭 확인하세요
제안: 운전면허증 사진 규격, 2026년부터 바뀝니다 — 도로교통공단 규정 완벽정리
```

## 4. 주의

- 본 데이터는 네이버 검색광고 기준. 실제 블로그 노출은 경쟁 문서 품질·개수에 좌우된다
- 경쟁도(높음/중간/낮음)는 **광고 경쟁도**이지 블로그 SEO 경쟁도가 아니다. 참고 지표로만 사용
- `< 10` 구간은 5로 환산했으므로 소규모 키워드 합계는 과대 추정 가능
