## 1. 제안 요약 (Executive Summary)

귀사의 웹사이트를 **"만들어두는 홈페이지"가 아니라 "검색과 AI가 찾아 인용하는 영업 자산"**으로 구축합니다. 2026년의 검색은 세 갈래입니다 — 구글, 네이버, 그리고 ChatGPT·Perplexity·AI 오버뷰 같은 **AI 답변 엔진**. 대부분의 구축 업체 제안서는 아직 세 번째를 다루지 않습니다. 본 제안은 구축 단계부터 세 갈래 전부를 설계에 넣고, **약속이 아니라 측정으로** 성과를 보고합니다.

- 납품물: 반응형 웹사이트 + 기술 SEO 완비 + AI 검색(GEO/AEO) 대응 구조 + 계측 대시보드
- 운영: 월 단위 관리(순찰·리포트·콘텐츠) 3개 티어
- 원칙: **순위·인용을 보장하지 않습니다.** 보장을 약속하는 업체를 주의하십시오 — 저희는 측정 지표와 개선 프로세스를 계약합니다. (업계 표준 무보장 원칙)

## 3. 납품 스코프

### A. 구축 (프로젝트)

- 반응형 웹사이트 설계·개발 (모바일 우선)
- **성능 기준 명시 납품**: Core Web Vitals 통과 목표치(LCP·INP·CLS)를 검수 기준에 포함
- 정보 구조(IA) 설계 — 검색 수요 실측(§2-5)을 반영한 페이지 트리
- 스키마 마크업(조직·서비스·FAQ·리뷰 등 해당 유형) 기본 탑재
- 다국어 대응 설계(선택): hreflang·언어별 사이트맵 — 대상 언어별 견적

### B. 검색 최적화 (구축 포함분)

- 기술 SEO: 색인·크롤링 설계, canonical, 사이트맵 자동화, 리다이렉트 정책
- **구글·네이버 이원 대응**: 서치콘솔+네이버 서치어드바이저 등록·검증, 채널별 콘텐츠 톤 가이드(검색 의도가 채널별로 다름을 데이터로 확인해 반영)
- 초기 콘텐츠 세트: 핵심 페이지 [N]개 — 검색량 실측 기반 주제 선정(감이 아니라 데이터로)

### C. AI 검색 대응 (GEO/AEO) — 본 제안의 차별 항목

- AI 크롤러 접근 정책 설계(허용/차단을 목적에 맞게 — 검색 인용용 봇과 학습용 봇을 구분 운영)
- **인용 가능한 콘텐츠 구조**: 질문-답변 블록, FAQ 스키마, 출처 명시형 데이터 표 — AI가 발췌·인용하기 좋은 형태로 재구조화
- AI 가시성 측정 체계: 주요 AI 엔진에서의 인용 여부·빈도 주기 실측, 경쟁사 대비 비교
- AI 경유 유입 계측: 애널리틱스에서 AI 채널 유입 분리 추적

### D. 계측 (성과를 보는 눈)

- GA4 + 서치콘솔 연동 세팅, **전환 이벤트 정의·설치**(문의·구매 등 귀사 핵심 행동 2단)
- 내부 트래픽 필터(귀사 직원 접속 제외 — 데이터 오염 방지)
- 월간 대시보드: 노출·클릭·전환·AI 유입 한 장 요약

## 4. 성과 지표와 약속의 범위

**측정하는 것** (월간 리포트 고정 항목):
- 검색 노출·클릭·평균 순위 (구글·네이버 분리)
- 핵심 전환(정의된 이벤트) 수·전환율
- Core Web Vitals 상태
- **AI 답변 인용 여부·빈도, 경쟁사 대비 점유** (AI-VISIBILITY 티어)

**약속하지 않는 것**: 특정 키워드의 특정 순위, AI 답변 내 인용 보장, 획득한 순위의 영구 지속. 검색·AI 엔진의 알고리즘은 저희가 통제할 수 없으며, **이를 보장하는 제안은 업계에서 신뢰할 수 없는 신호로 분류됩니다.** 저희는 프로세스(감사→개선→측정→보고)와 투명한 데이터를 계약합니다.

## 6. 수행 실증 (제안사 레퍼런스)

- 자사 플랫폼에서 **6개 언어 × 400+ 규격 페이지**의 다국어 SEO 아키텍처(hreflang·언어별 사이트맵·정본 URL 체계)를 직접 설계·운영.

- 질문형 콘텐츠 전략으로 목표 검색어 **1위·CTR 42%** 실측 사례.
- AI 검색 대응: AI 크롤러 정책·인용 가능 구조·AI 유입 계측을 자사에서 상시 운영.
