## 2. 전략 판독 — 두 개의 공백이 우리 자리다

1. **AI 검색(GEO/AEO)이 범용 제안서 층위에 아직 없다.** 전문 에이전시 패키지에만 존재하고 템플릿 시장은 클래식 SEO에 멈춰 있다 → **GEO/AEO를 1급 섹션으로 내장한 제안서 자체가 차별화**다. 우리는 이미 자사 서비스에서 실전 운용 중(AI 봇 robots 정책·스키마·AI 유입 계측).
2. **한국 기업형 시장조사에 '검색 수요 실측'이 없다.** 39만~330만 원 상단 상품이 PEST·SWOT 프레임워크로 채워져 있고 검색량·키워드·TAM/SAM/SOM이 없다 → **우리의 3소스 수요 실측(키워드 플래너+자동완성+실노출 데이터)이 정확히 그 공백**이다. 7/19 롱테일 다국어 테이블이 실물 샘플.

## 3. 우리 자산 매핑 — "이 제안서를 우리가 이미 수행하고 있다"

| 제안서 약속 항목 | 우리 실증 (2026-07 실측) |
|-----------------|------------------------|
| 다국어 SEO 아키텍처 | 429 규격 × 6언어, hreflang·canonical·언어별 사이트맵 운영 |
| 수요 키워드 실측 | 3소스 교차(플래너·자동완성 6언어·실노출) — 당일 신시장(동남아) 수요 실증→당일 현지어 페이지 라이브 |
| 콘텐츠 전략 | 질문형·통념 교정 콘텐츠 검색 1위·CTR 42% 실측 공식 |
| GEO/AEO | AI 검색 봇 허용 정책, 인용 가능 구조(FAQ·스키마), AI 유입 채널 계측 실재 |
| 계측·전환 | GA4+GSC+광고 API 3원 + 2단 전환 추적 + 내부 트래픽 필터 운영 |
| 품질 순찰 | 상시 헬스체크+퍼널 실주행 검증 체계(200 OK여도 죽은 UI를 잡는 L2 검증) — 당일 P0 적발·당일 핫픽스 실적 |
| 무보장 원칙 | 데이터 기반 보고 문화(실측·정정 기록) — 업계 표준 조항과 동일 철학 |

**지향점 판독**: 이 킷은 판매용이기 이전에 거울이다 — 우리가 자사 서비스에 하는 일이 이미 글로벌 AEO 리테이너 미드마켓($5k~10k/월) 스코프에 해당한다. 부족분은 셋: ① 고객 대면 리포트 양식화(우리는 내부 보고만 존재) ② 사례의 외부 공개 가능 형태 가공 ③ 가격·계약 실무(정부지원 견적 관행 — 미확정 영역 추가 조사). 이 셋이 채워지면 B2B 부업 라인이 아니라 **우리 서비스 품질의 외부 검증 기준**이 된다.
