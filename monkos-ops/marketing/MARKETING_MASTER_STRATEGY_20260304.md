### 1-2. 페이즈 전환 선언

```
[리팩토링 페이즈] ─────→ [마케팅 페이즈]
  v5 안정화 완료              3~6월 시즌 공략
```

### 1-3. 전략 기조

**"결제 전까지는 콘텐츠 재고 축적 + 채널 신뢰 구축"**

- 결제 인프라 미완성 → 유료 전환 CTA 보류
- 무료 체험 유입 → 콘텐츠/팔로워 축적 → 결제 연동 시 즉시 전환
- 비용: 월 1만원 미만 (Claude API 캡션 + n8n 셀프호스팅)
- 인력: 한송이(SNS 운영 메인) + AI 에이전트(콘텐츠 생산/자동화) + 꾸(검수 보조)

## 2. 상충점 해소 (막내1 식별 8건)

> 18건 문서 간 상충을 여기서 단일 결정으로 확정한다. 이후 모든 실행은 이 결정을 따른다.

| # | 주제 | 상충 내용 | **확정 결정** |
|---|------|----------|--------------|
| 1 | **채널 수** | 9채널(channel_strategy) vs 3계정(pipeline_v2) | **9채널 = 플랫폼 수, 계정은 KR/JP별 분리 운영**. 인스타: KR(@monk_photo) + JP(신규). X: JP(@Photo_monkos 유지) + EN(추후) |
| 2 | **X 계정명** | @MONKOS_AI vs @monkos_jp vs @Photo_monkos | **@Photo_monkos 유지** (현 운영 계정). 글로벌 확장 시 @monkos_global 신설 |
| 3 | **인스타 계정** | monk_photo vs monkos.ai(신규) vs 일본(신규) | **@monk_photo 리포지셔닝** (4년 에이징 자산 활용). 일본: 추후 채널 안정화 후 개설 판단 |
| 4 | **포스팅 빈도** | X 2~3회/일 vs 주3~5회 | **X(JP): 일 2회 시작 → 반응 보고 3회 증가**. 인스타(KR): 주 5~6건. 블로그: 주 3회 |
| 5 | **자동화 도구** | n8n vs Buffer/Later/Hootsuite | **n8n 단독 확정**. 셀프호스팅 + 커스텀 파이프라인 = MONKOS 아키텍처 적합 |
| 6 | **LINE Pay** | "연동으로 마찰 제로" vs "종료(2025-04-30)" | **LINE Pay 삭제**. 결제: KOMOJU 재심사 → Stripe 크로스보더 → 하이브리드 |
| 7 | **일본 진입 타이밍** | "지금이 적기(2월)" → 이미 3월 | **2026 상반기 취활 시즌(27卒) 즉시 공략**. 3~4월이 절대 피크. 지금 시작해도 효과 있음 |
| 8 | **담당자 배분** | 한송이=촬영 vs SNS운영 이중정의 | **한송이 = SNS 운영 메인** + 촬영 보조. AI 에이전트 = 콘텐츠 초안 생산. 꾸 = 일본 검수 |

## 4. 한국 시장 실행 전략

### 4-1. 시장 환경 요약

- AI 증명사진 인지도 형성 중, 선점 기회
- 경쟁 공백: "AI + 실제 통과 사례 + 기술 심층 해설" 결합 콘텐츠 부재
- 3~4월 취업 시즌 = 최고 피크 (지금 발행해야 4월 노출)
- 소비자 핵심 불안: "실제로 여권 접수에 통과하는가"

### 4-2. 네이버 블로그 — 핵심 채널

**SEO 키워드 (주력 20 + 롱테일 30)**
- 주력: AI 증명사진, 증명사진 앱, 여권사진 셀프, 이력서사진, 증명사진 규격 등
- 롱테일: 규격·규정 10 + 비교·리뷰 10 + 시즌·상황 10
- 상세: 막내2 보고서 §2-1 참조

**포스팅 표준**: 1,500~2,500자 / 이미지 5~8장(전부 고유) / 발행 오전 9~11시

**서사 연재 3시리즈**:
1. **[증명사진의 모든 것]** — 10편 (SEO 유입, 규격 가이드 시리즈)
2. **[사진관 20년, AI를 만나다]** — 연재 (작가님 서사, 브랜드 차별화)
3. **[AI 시대의 사진 이야기]** — 월 1~2편 (철학 인용구집 기반 에세이, 팬 빌딩)

### 4-3. 인스타그램 — @monk_photo 리포지셔닝

**콘텐츠 믹스**: A(결과물 30%) + B(비포/애프터 25%) + C(프로세스 릴스 20%) + D(정보성 캐러셀 15%) + E(서사/브랜드 10%)

**릴스 최적 길이**: 20~40초 (저장+공유가 핵심 지표, 완전 시청률 중요)

**해시태그**: 고정 5개 + 시즌 로테이션 + 타입별 → 총 10~15개

### 4-4. 숏폼 (유튜브 쇼츠 + 틱톡)

**크로스포스팅 규칙**:
- 원본 세로 9:16 (1080×1920) 제작
- 배포 순서: 1일차 틱톡 → 2일차 릴스 → 3일차 쇼츠 (24~48시간 간격)
- 틱톡 워터마크 타 채널 업로드 절대 금지

### 4-5. 보조 채널

- **당근**: 주 1회 갱신, 주 10분 리소스
- **네이버 플레이스**: 물리적 주소 활용, 주 1~2회 투고
- **카카오 채널**: 유료 전환 고객 50명 이상 시 도입
