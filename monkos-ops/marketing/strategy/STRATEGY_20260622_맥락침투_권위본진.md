# STRATEGY: 맥락 침투 + 권위 본진

## 0. 출발점 — 우리가 못 가진 것

**유통(distribution)이 없다.** 돈으로 인플루언서를 태울 수도, 10만 팔로워도 없다. 스레드의 "메모앱으로 수천만원"은 거의 다 생존자 편향이고, 그 실체도 제품이 아니라 유통(팔로워·바이럴·광고비)이었다.

→ 유통을 **살 수 없으니, 유통을 만드는 기계**를 짓는다. 그것이 SEO·콘텐츠 권위·색인 인프라다. 6월에 인프라에 시간을 쓴 것은 이 처지의 논리적 귀결이다. 단, 그 비용은 **시장 피드백이 늦어진다**는 것 — 이를 B2B 직접영업·오프라인 사진관 자산 같은 *빠른 유통*으로 보완한다.

## 1. 핵심 전략 한 문장

**경쟁 키워드를 정면돌파하지 않고 수요자 동선에 옆치기로 침투하여, 얕고 넓은 본진으로 끌어와 "사진은 찐"이라는 권위를 입증하고, 벌크충전·낱개소비로 무마찰 횡적 회유를 일으켜 매출을 누적한다.**

## 2. 다섯 고리

### ① 맥락 침투 (옆문)
- "프로필사진" 같은 레드오션 키워드 정면 경쟁 ❌
- 수요자의 **실제 동선·맥락**에 콘텐츠를 놓는다: 부동산 중개사가 "부동산 명함" 검색할 때, 특정 직군이 자기 분야 검색할 때 걸리는 글. (예: 6/22 발행 "전문직 명함 가이드")
- 수요자가 모인 곳에 직접 진입(예: 취업 카페 가입) = 입구(유입 면적) 추가.
- 경쟁이 낮은 롱테일·틈새일수록 도메인 권위 낮아도 1등 가능.

### ② 권위 본진 ("여긴 사진 찐이네")
- 옆문으로 들어온 사람이 도착하는 **단일 본진**(monkos.ai 포털).
- "찐이네" 인상의 재료 = 작품의 폭(서비스 스펙트럼) + 20년 작가 이력·오프라인 사진관(몽크사진관) + 콘텐츠 깊이 + 디자인 완성도.
- 이것은 곧 구글의 **E-E-A-T**(경험·전문성·권위·신뢰). **권위 본진을 세우는 일 = 색인이 풀리는 일.** 두 문제가 한 해법. (현재 "Discovered, not indexed"의 근본 해소책)

### ③ 얕고 넓은 벤토 (깊이가 아닌 옆으로)
- **이전(KR/JP)**: "증명의 모든 것을 한 앱에" = 깊은 단일 퍼널. 입구 1개, 긴 퍼널, 결제 2회. 성능은 좋으나 횡적 이동이 없어 **유입 면적이 좁다.**
- **지금(아크릴 벤토)**: 가볍고 평평한 격자. "발견→가볍게 눌러봄→얻어감→옆에 프로필도 있네→옆칸". 메뉴 하나하나가 독립 검색 진입점이자 홍보 면 = **유입 면적 N배.**
- 6/22 포털 랜딩 벤토 디자인은 이 전략의 시각적 구현. 깊은 우물 하나 → 평평한 진열대 여러 칸.

### ④ 벌크 충전 · 낱개 소비 · 무마찰 회유 (가격 = 동선 설계)
- **충전(결제)은 묶음**: 9900원/70c. 일반 사진관 "만원에 10컷"을 크레딧으로 녹인 구조. 단건 1500원은 PG 수수료 비중이 과해 비효율 → 벌크가 정답.
- **소비(사용)는 낱개**: 10c/컷. 9900원 한 번에 ~7장. 가족 여권 전부, 헤드샷 컨셉 여러 개.
- **무마찰 횡적 회유**: 충전해두면 옆칸(헤드샷)도 **추가 결제 없이** 크레딧에서 차감. 이전 "결제 2회" 병목 해소 → 옆 진열장 진입 마찰 0 → 회유 자연발생.
- **소진 명분이 충전을 정당화**: "한 장"이 아니라 "가족·컨셉 단위로 여러 장" 메시지여야 9900원 선불이 설득됨 → 본진 카피 방향.
- **잔여 크레딧 = 재방문 훅**: 남은 크레딧이 "아까우니 또" 심리로 재방문·회유 동력. (kakao_4817724214의 87일 후 재방문 실증)
- **신규 무료 10c = 벌크 충전 미끼**: 무료 1장 체험 → 만족 → 충전.

### ⑤ 단일 도메인 누적 (도메인 연령 함정 회피)
- 다양한 서비스를 **별도 도메인/앱이 아니라 한 도메인 내부 메뉴로** 쌓는다.
- 이유: 서비스마다 새 도메인 = 매번 **도메인 연령(권위) 0에서 리셋**. "Discovered, not indexed"를 서비스 수만큼 N번 반복. 유통 자산(도메인 권위)을 분산하면 영원히 신생아.
- 한 본진에 누적 = **권위 복리.** 메뉴 추가 = 도메인 두께(콘텐츠 폭/E-E-A-T) 증가 + 새 메뉴는 기존 권위 상속.
- ⚠️ **안전장치**: 메뉴 확장은 "이미지/사진"이라는 **한 우산 안에서만** 권위가 복리가 된다. 증명사진→헤드샷→VTON→명함은 다 "사진 찐"의 증거. 무관한 메뉴(예: 메모앱)를 붙이면 도메인 정체성 희석 → 권위 약화. **본진 전략을 깨는 독.** 우리 게임은 우리 우산 안의 확장.

## 3. PF 매핑 — 왜 흩어진 PF가 한 몸인가

| 고리 | 담당 PF |
|------|---------|
| ① 맥락 침투 | PF_CITADEL(SEO/GEO) + PF_OPUS(콘텐츠) + PF_KKU(채널) |
| ② 권위 본진 | PF_PORTAL(본진) + PF_SPECS(스펙트럼 자산) + PF_STYLER(제품 폭) |
| ③ 얕고 넓은 벤토 | PF_PORTAL(랜딩) + PF_STYLER(서비스 스펙트럼=벤토 칸) |
| ④ 가격/회유 | PF_PROFILES·PF_IDPHOTO(서비스) + 크레딧 통합(10c) |
| ⑤ 단일 도메인 | PF_PORTAL + 전 서비스 PF(monkos.ai 단일 귀속) |
| 측정(전 고리 관통) | BQ 유저트래킹(오늘 D1~D4) + PF_RETRIEVAL |
| 빠른 유통(보완) | PF_PARTNER(B2B 직접영업) + 오프라인 사진관 |

→ 제품선(STYLER)·콘텐츠선(OPUS)·사업선(PARTNER) 3대 메타가 "사진 찐 본진"이라는 한 점으로 수렴.

## 4. 측정 — "감"이 아니라 숫자로

오늘 깐 BigQuery 트래킹이 이 전략의 검증 도구. 핵심 KPI:
- **입구별 유입** (침투 콘텐츠/메뉴별 진입 면적)
- **옆칸 회유율** (한 서비스→다른 서비스 횡적 이동) ← ③④의 생사
- **충전 1회당 소진 장수 / 교차 서비스 수** (벌크충전 효율)
- **잔여 크레딧 재방문율** (⑤ 재방문 훅)
- **신규 무료10c → 충전 전환율** (온보딩 스위치)
- **본진 체류·회유** ("찐이네" 인상의 정량화)

## 5. 리스크 / 안전장치

1. **객단가 하락 vs 회수**: 10c 가볍게 = 객단가↓. 10c×N ≥ 70c가 되려면 옆칸 회유가 *반드시* 발생해야. 회유 안 되고 단발이면 매출 오히려 감소 → 회유 장치(cross-link/추천)는 선택 아닌 생사.
2. **첫 결과물 품질 = 방아쇠**: 가벼운 가격일수록 첫 컷이 "오 됐네"여야 옆칸 간다. 첫 경험 품질이 전체 스위치.
3. **입구는 넓게, 전환은 깊게**: 면적은 벤토로 넓히되 각 칸의 결제 전환은 매끄럽고 깊게.
4. **도메인 주제 일관성**: 우산(이미지/사진) 밖 메뉴 금지(§2-⑤ 안전장치).
5. **느린 유통 단독 의존 금지**: SEO 권위는 6개월~1년. B2B·오프라인 같은 빠른 유통을 전면 병행.

## 6. 차후 로드맵 연결

- **Phase 1 (즉시)**: BQ D5~D7(어드민 대시보드) 완성 → 새 벤토 랜딩 전환율·옆칸 회유율 실측. Google Indexing API 제거(블로그 비대상), IndexNow·sitemap 유지.
- **Phase 2 (2~4주)**: B2B(PARTNER P1) + 영어권(PROFILES) 매출 실측 → 빠른 유통 검증.
- **Phase 3 (1~2개월)**: 측정 결과로 승자 더블다운. 정체 PF(FACTORY·EVENT·MUSE) 정리로 자원 회수.
