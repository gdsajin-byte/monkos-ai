## 1. 상품 정체성 (재정의)

- 고객 대면 상품은 하나: **"통과를 실측으로 증명하는 AI 증명사진."**
- 앞단(규격맞춤 = 구 증명사진 앱)은 상품이 아니라 **검수 엔진** — 후단(AI 처리)의 품질 보증 장치로 흡수.
- 처리 강도는 시스템이 사진 상태에 따라 **필요한 만큼만** 자동 결정: 크롭+배경 → +조명 보정 → 재생성. 고객에게 "보정 vs 무보정" 분기를 묻지 않는다.
- 상시 게이트는 하나: **동일인 식별** (헌법 1조 3항 — 보정 여부가 아니라 "고쳐도 나여야 한다"). 결과 화면에 적용 처리 내역 투명 표시.
- 카피 축: **"필요한 만큼만, 항상 나인 채로."** / 규제 현실: 보정 사진은 실무상 통과 — 금지선은 동일인 이탈뿐.

## 2. 시장 자리

- 스노우류: 예쁨, 규격 불안 (AI 반려 사례 발생 지대) / visafoto류: 규격, 무처리 / 증명한컷: KR 헤드텀 점유.
- **1분 사진관** (2026-07-08 작가님 발견, 신생·검색 미인덱스): 무료 일 3회 캡 + 얼굴비율 게이트(25~42%) + 의상 프리셋 + 동안 % 슬라이더. **모델 타당성 방증** (무료 캡 구조가 시장 작동 중). 약점 = 게이트가 고객에게 재촬영 노동 전가 (자동 크롭 부재 — 비율 미달 사진을 거부; 우리 fit은 자동 재단으로 통과시킴), 비율 % ≠ mm 실측, 발급보장 부재, 동일인 게이트 없이 보정·의상 노출.
- **1분 사진관 판매 방식** (2차 분석): 무료 생성(일3회) → **1회 생성으로 4용도 프리뷰 동시 렌더** (여권/주민등록·증명/토익·반명함/미국비자, 워터마크) → **용도 패키지 단위 과금** — 1개 3,900 / +1개당 1,000 / 전체 6,900 (한계원가 0의 번들 사다리 = 디코이 앵커). 패키지 구성 = 출력용+온라인제출용 파일 세트 (미국비자 240KB 최적화 등 제출 스펙 인지). 화법 = 규격 공포 소구(얼굴 높이 70~80%·정수리·눈높이 엄격 고지) → "정밀 보정으로 반려 위험 **최소화**" — **책임은 안 짐 (보장 부재)**. 즉 그들 벽 = 프리뷰 후 소유 잠금 (select-before-pay) — 시장 라이브 검증 사례.
- 대응 카드: ① 우리 무료 = 그들 3,900 유료의 무료화 (직접 언더컷 비교 카피) ② 그들 4용도 번들은 우리 유료 티어 구성으로 흡수 — ₩2,000 보정 티어에 "전 용도 파일 세트" 포함 시 그들 풀번들 6,900 대비 압도 ③ 그들의 "최소화" 화법이 우리 "보장 9,900"의 시장 교육을 대행 중 ④ 428 DB fileSpec(240KB 등)을 결과 화면·패키지 구성에 표면화.
- 우리 자리 = 그 사이의 빈 칸: **예쁘게 만들되 통과를 밀리미터로 증명.**
- 정면전 회피, 틈 3: ① 언어 교차 롱테일 (한국어·일본어로 외국 규격) ② GEO — 428 규격 DB 구조화 정답 ③ **발급보장 = 카테고리 재정의** ("생성"이 아닌 "통과" 판매 — 실측 엔진 없인 모방 불가).
- 구조: **엔진 1 + 문 N** — specs(웹 검색), 증명앱(직접 방문), IDPASS(앱스토어·무료층), 헤드샷·프로필스(창작·보정의 집, 가격사다리 상단 대기).

## 3. 퍼널 (specs 기준 7단계 — 선체험·후결제)

> **프론트 단순화 원칙** (2026-07-08 작가님, 1분사진관 교훈): **복잡함은 엔진에, 단순함은 화면에.** 무료 입력 단계는 분석 요구 0 — 판정 2개(얼굴 유무·측정 가능 여부)만 빨간 코치 문구로. 8항목 검수·mm 성적서·처리 내역은 **생성 후 결과 화면의 코멘트**로 이동. 전체 흐름이 한 페이지 안에.

1. **착지**: 검색 질문의 정답(규격 수치) 즉답 + 드롭존 히어로 "내 셀카가 되는지 무료 확인". 가격은 첫 화면에서 후퇴.
2. **투입**: 모바일 = 가이드 촬영 우선, 갤러리 = 보조. 무로그인.
3. **측정 극장**: 실측 성적서 (머리 mm·눈 %·항목 판정). 접수는 관대, 판정은 정직 — PASS 직진 / WARN 고지 후 본인 선택(보장 제외) / FAIL 차단 + 코치 화법 + 30초 가이드 재촬영. FAIL 기준 = 동일인 보증 불가 원자재 (측면·감은 눈·저해상).
4. **완성 (무료)**: 규격 크롭+배경 완성본 + 실측 성적서 = **무료 다운로드** (idPASS 기본층). 소유 효과는 업셀의 지렛대로 이동. *(개정: 작가님 확정 — 결제 벽을 이 단계에서 제거)*
5. **업셀 갈림길 (결과 화면)**: ① **AI 보정 ₩2,000** — "더 잘 나온 나" 비교 프리뷰 (보정 전/후) 후 결제 ② **발급보장 ₩9,900** ③ **인화 옵션**. 결제는 비로그인 토스/카드 단건. **결제 전 생성 완료 원칙 유지** (보정본도 프리뷰 후 잠금 해제) → 차감 후 미출고/불량 출고 구조 소멸.
6. **피크엔드**: 다운로드 + 180일 보관 + 크로스셀 (AI 증명사진·헤드샷·프로필스·취업사진 — 후단 유도). 반려-불안 키워드 유입은 보장 조기 노출.
7. **재방문**: 가족 갱신 유도, 규격 크로스링크.

- 증명앱 교훈 반영: 벽의 실패는 "프리뷰 후 결제"가 아니라 **선결제(약속에 지불)와 첫 완제품 무료(10c)** 두 구조였다. 단발 상품에서 완제품 무료 지급은 자기 파괴 — **폐지/개편 대상**.
