## Task 1 — 카드 클릭 버그 수정 (긴급)

### 원인 (확정)
- `main.js` — 블로그 카드 클릭 이벤트 리스너 없음
- 카드 HTML — `data-slug` 없음. render.js에서 SSR 시 누락

### 수정 1-A: `public/js/main.js`

`DOMContentLoaded` 블록에 아래 추가:

```js
// 홈 블로그 카드 클릭
document.querySelectorAll('.blog-list [data-slug]').forEach(function(card) {
  card.addEventListener('click', function() {
    var slug = card.dataset.slug;
    var lang = card.dataset.lang || 'ko';
    if (slug) window.location.href = (lang !== 'ko' ? '/' + lang : '') + '/blog/' + slug;
  });
});

// 매거진 카드 (좌측 사이드바)
document.querySelectorAll('.mag-card[data-slug]').forEach(function(card) {
  card.addEventListener('click', function() {
    var slug = card.dataset.slug;
    if (slug) window.location.href = '/blog/' + slug;
  });
});
```

### 수정 1-B: `lib/cms/render.js`

블로그 카드 렌더 함수에서 루트 엘리먼트에 `data-slug`, `data-lang` 추가:

```js
// 기존
`<div class="blog-list">...`

// 수정
`<div class="blog-list" data-slug="${post.slug}" data-lang="${post.lang || 'ko'}" style="cursor:pointer">...`
```

매거진 카드도 동일하게 `data-slug` 추가.

### 현재 /blog 문제

- 네비게이션 구조 다름 (홈 3컬럼 헤더 vs 서브페이지 별도 네비)
- "No posts yet." 단순 텍스트 — 목업 디자인으로 교체

### 적용할 목업 구조

#### 목록 페이지 (`/blog`)

```
[헤더] — 홈과 동일한 라이트 테마 헤더 사용
[서브 네비] — 카테고리 탭 + 언어 필터 + 글쓰기 버튼
  탭: 전체 / 증명사진 / 여권·비자 / 취업·이력서 / 헤어·메이크업
  언어: ALL / KO / JA / EN

[Featured 카드] — 최신 또는 pinned 포스트 1개, 좌우 분할 레이아웃
  - 좌: 그라디언트 썸네일 (이모지 + 제목)
  - 우: 배지 + 제목 + 요약 + 작성자/날짜/언어태그

[태그 스트립] — # 취업사진 # 여권사진 # AI리터칭 # 헤어메이크업 ...

[그리드 레이블] 최근 포스트

[포스트 그리드] — 3열 카드 그리드
  각 카드: 그라디언트 썸네일 + 언어태그 + 제목 + 요약 + 작성자 + 날짜
  클릭 → /blog/{slug}
```

#### 상세 페이지 (`/blog/:slug`)

```
[헤더] — 동일
[← 블로그 목록] 뒤로가기 링크
[태그들] + [제목] + [작성자/날짜/읽는시간] + [공유 버튼]
[히어로 이미지 영역]
[본문]
[하단 공유 + 관련 포스트 2개]
```
