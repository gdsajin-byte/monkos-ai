## 건1. 홈페이지 FAQ 프리뷰에 JSON-LD 삽입 (P0)

### 배경
- 서치콘솔: "mainEntity 입력란 누락" 오류
- `/faq` 전용 페이지 JSON-LD는 정상 (`render.js:569-580`)
- **원인**: 홈(`/`) FAQ 프리뷰에 FAQ 마크업은 있으나 JSON-LD 없음
- 구글이 홈 크롤링 시 FAQ 감지 → 구조화 데이터 없음 → 오류 리포트

### 수정 파일
`monkos_AI/portal/lib/cms/home.js`

### 수정 위치
`home.js:139-156` — FAQ 프리뷰 생성 블록 내부

### 수정 내용

현재 코드 (139-156):
```javascript
// 5. FAQ preview (상위 3건)
const faqSnap = await firestore.collection('faq_items')
  .where('published', '==', true)
  .where('lang', '==', lang)
  .orderBy('order', 'asc')
  .limit(3)
  .get()
  .catch(() => ({ docs: [] }));
if (faqSnap.docs.length > 0) {
  const faqHtml = faqSnap.docs.map(d => {
    const f = d.data();
    return `      <div class="faq-item"><h4>${esc(f.question)}</h4><p>${esc(f.answer)}</p></div>`;
  }).join('\n');
  html = html.replace(
    /(<div class="faq-list" id="faqPreview">)\n[\s\S]*?(<\/div>\n\n\s*<div class="sec-h" id="sec-board"><h2>고객 게시판)/,
    `$1\n${faqHtml}\n    $2`
  );
}
```

수정 후:
```javascript
// 5. FAQ preview (상위 3건)
const faqSnap = await firestore.collection('faq_items')
  .where('published', '==', true)
  .where('lang', '==', lang)
  .orderBy('order', 'asc')
  .limit(3)
  .get()
  .catch(() => ({ docs: [] }));
if (faqSnap.docs.length > 0) {
  const faqItems = faqSnap.docs.map(d => d.data());
  const faqHtml = faqItems.map(f =>
    `      <div class="faq-item"><h4>${esc(f.question)}</h4><p>${esc(f.answer)}</p></div>`
  ).join('\n');
  html = html.replace(
    /(<div class="faq-list" id="faqPreview">)\n[\s\S]*?(<\/div>\n\n\s*<div class="sec-h" id="sec-board"><h2>고객 게시판)/,
    `$1\n${faqHtml}\n    $2`
  );

  // FAQ 프리뷰 JSON-LD 삽입 (서치콘솔 mainEntity 오류 수정)
  const faqJsonLd = JSON.stringify({
    "@context": "https://schema.org",
    "@type": "FAQPage",
    "mainEntity": faqItems.map(f => ({
      "@type": "Question",
      "name": f.question,
      "acceptedAnswer": {
        "@type": "Answer",
        "text": f.answer
      }
    }))
  });
  html = html.replace(
    '</head>',
    `<script type="application/ld+json">${faqJsonLd}</script>\n</head>`
  );
}
```

### 핵심 변경점
1. `faqSnap.docs.map(d => d.data())`를 `faqItems`로 분리 — HTML과 JSON-LD에서 재사용
2. `</head>` 앞에 `FAQPage` JSON-LD `<script>` 삽입
3. 홈 프리뷰에 노출되는 3건만 포함 (전체 13건 아님)
4. KO/JA/EN 각각 해당 `lang` 파라미터의 데이터 사용 (기존 로직 그대로)

### 주의사항
- `/faq` 전용 페이지의 `render.js:569-580` JSON-LD는 **건드리지 말 것** — 정상 동작 중
- `</head>` replace는 index.html에 `</head>` 태그가 1개인 전제 (기존 패턴과 동일)
- `esc()` 함수는 HTML 이스케이프, JSON-LD 내부는 `JSON.stringify`가 처리하므로 별도 이스케이프 불필요

## 건3. 사이트맵 정리 (P1)

### 수정 파일
`monkos_AI/portal/lib/cms/render.js` — `renderSitemap()` 함수 (1276-1329행)

### 수정 내용

#### (A) 법적 페이지 4건 제거

현재 `staticUrls` 배열에서 **제거**:
```javascript
// 제거 대상 — 크롤링 예산 낭비, 색인 불필요
{ loc: 'https://monkos.ai/credits.html', changefreq: 'monthly', priority: '0.5' },
{ loc: 'https://monkos.ai/privacy.html', changefreq: 'monthly', priority: '0.3' },
{ loc: 'https://monkos.ai/terms.html', changefreq: 'monthly', priority: '0.3' },
{ loc: 'https://monkos.ai/refund.html', changefreq: 'monthly', priority: '0.3' },
```

#### (B) 정적 URL에 `lastmod` 추가

수정 전:
```javascript
{ loc: 'https://monkos.ai/', changefreq: 'weekly', priority: '1.0' },
```

수정 후 — 모든 정적 URL에 `lastmod` 추가:
```javascript
{ loc: 'https://monkos.ai/', lastmod: new Date().toISOString().substring(0, 10), changefreq: 'weekly', priority: '1.0' },
```

모든 정적 URL에 동일 패턴 적용. `new Date().toISOString().substring(0, 10)` → 요청 시점 날짜.

#### (C) 정적 sitemap.xml 파일 제거

```bash
rm monkos_AI/portal/public/sitemap.xml
```

동적 `renderSitemap()`이 `/sitemap.xml` 라우트를 처리하므로 정적 파일 불필요.
서버 라우팅 (`server.js:222`)이 정적 파일 서빙보다 먼저 매칭되는지 확인할 것.

#### (D) llms.txt 사이트맵 제외 검토

`llms.txt`는 AI 크롤러용이지 구글 색인 대상 아님. 사이트맵에서 제거 고려:
```javascript
// 제거 검토
{ loc: 'https://monkos.ai/llms.txt', changefreq: 'monthly', priority: '0.5' },
```
