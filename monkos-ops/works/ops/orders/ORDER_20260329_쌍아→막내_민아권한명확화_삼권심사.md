2026-03-29, 민아가 CDP로 monkos.ai SEO 크롤 후 발견한 이슈(JA 404 등)에 대해 `render.js`·`server.js`를 직접 수정했다. 작가님·쌍아 합동 리뷰 결과:

- **작가님 교시**: 민아에게 열어준 것은 눈과 판단력(CDP)이지, 손(코드 수정)이 아니다

> "지시서 체계는 능력의 제약이 아니라 맥락의 축적 장치다. 세션이 지나면 컨텍스트를 완전히 상실하기에, 문서체계 없는 역량은 휘발된다."

## 2. 심사 대상: ch1 개정안 (안)

### 현행

**ch1 1조 민아 권한표:**

| 권한 | 허용/금지 |
|------|----------|
| 본진(monk_project) 읽기·쓰기 | ✅ 자유 |
| 커밋·푸시·배포 | ❌ 쌍아 경유 또는 작가님 명시 승인 필요 |

**ch1 2조 5항 민아 경로:**
```
작가님 → 민아 직접 지시 → 민아 실행 → 완료 보고 → 쌍아 사후 보정
```

### 문제점

- "읽기·쓰기 자유"가 **코드 파일 직접 수정**까지 포함하는 것으로 해석 가능
- "민아 실행"의 범위가 불명확 — CDP 진단도 실행이고, 코딩도 실행
- 커밋은 금지되어 있으나, unstaged 코드 수정은 제도적 공백

### 개정안 (쌍아 초안)

**ch1 1조 민아 권한표 → 개정:**

| 권한 | 허용/금지 | 비고 |
|------|----------|------|
| 본진 읽기 | ✅ 자유 | 코드·문서·설정 전부 |
| CDP 크롤·진단·검증 | ✅ 자유 | 풀 퍼미션의 핵심 목적 |
| 문서 쓰기 (보고서·제안서·분석) | ✅ 자유 | `monkos-ops/` 산하 |
| **코드 수정·신규 기능 추가** | **❌ 지시서 경유** | 민아 → 제안서 → 승인 → 막내 실행 |
| 커밋·푸시·배포 | ❌ 쌍아 경유 또는 작가님 명시 승인 | 현행 유지 |
| governance/, CLAUDE.md 수정 | ❌ 쌍아 전권 | 현행 유지 |

**ch1 2조 5항 민아 경로 → 개정:**

```
[진단] 작가님 → 민아 CDP 진단/검증 → 분석 보고서 + 제안서 작성
[실행] 제안서 → 쌍아 설계 검토 → 정식 지시서 → 막내 실행
[검증] 배포 후 → 민아 CDP 재크롤 검증 → 검증 보고
```

- 민아의 고유 루프: **진단 → 제안 → (막내 실행) → 검증**
- 코드에 손대지 않아도 민아의 가치(CDP 진단+검증)는 온전
- 쌍아 사후 보정 → 쌍아 사전 설계 검토로 전환 (사후 보정은 예외 경로에만 존재)
