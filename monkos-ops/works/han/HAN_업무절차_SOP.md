
### STEP 2 — 이미지 생성
- MJ에서 생성
- `han/YYMMDD_{주제}/images/` 에 저장

### STEP 3 — 워터마크 적용 🔒 고정값
| 항목 | 값 |
|------|-----|
| 텍스트 | monkos.ai |
| 색상 | RGB(180, 180, 180) |
| 굵기 | Bold 700 |

## 🚨 주의사항

1. **정보 정확성 최우선** — 전문가 매거진 기준. 헤어 정보 오류 절대 금지
2. **워터마크 Bold 굵기** — 매 세션마다 확인 (얇아지는 오류 발생 이력 있음)
3. **배너 폰트 깨짐** — 일본어는 DroidSansFallbackFull / 숫자·영문은 NotoSansKR 세그먼트 분리 렌더링
4. **이미지 폴더 즉시 저장** — 생성 직후 해당 날짜 폴더에 저장
5. **git push 전 pull 필수**
