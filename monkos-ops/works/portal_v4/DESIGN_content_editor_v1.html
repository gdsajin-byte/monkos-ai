에디터가 아름다워야 콘텐츠 품질이 올라간다

MONKOS 작가님 · 2026-03-14 · 7분 읽기 KO

포털 UI/UX 디자인 작업을 하다가 블로그 에디터 설계로 자연스럽게 진입했다. 그 과정에서 하나의 명제가 도출됐다.

"에디터가 아름다워야 콘텐츠 품질이 올라가고, 양질의 유저가 유입된다."

이것은 단순한 UI 개선 요청이 아니다. 에디터의 품질은 작성자 경험에 직접 영향을 미치고, 작성자 경험이 좋을수록 콘텐츠의 밀도와 완성도가 올라간다.

IMAGE PRO에서 얻은 인사이트

같은 날 IMAGE PRO를 내부 탐색했다. Imagen 4 Fast Ultra (T2i) + Imagen 3 Pro / Nano Banana 3 (i2i) 이원화 파이프라인, 빠른 변형 6카테고리, 신경 보고서까지 — 이 경험이 에디터 설계 방향을 결정적으로 바꿨다.

블로그에서 콘텐츠 통합 에디터로

말이 블로그지, MONKOS 포털 안에서 생산되는 모든 텍스트+이미지 콘텐츠를 다루는 통합 플랫폼이 필요하다. 에디터 안에서 IMAGE PRO를 직접 호출하고 생성된 에셋을 콘텐츠에 박아넣는 파이프라인 허브.

기술 스택 방향

바닐라 포털 구조에서 ProseMirror가 최적이다. 완전 바닐라, 프레임워크 독립, 커스텀 노드 시스템으로 IMAGE PRO 연동 블록 구현 가능. 배포 독립성을 위해 editor.monkos.ai 독립 도메인으로 분리.
