## 1. 개요

### 목적
idphoto-kr 서비스의 퍼널 UX를 9스텝 키오스크(v4)에서 4페이지 선형 퍼널(v5)로 전면 전환. sessionStorage 스키마, 서버 프롬프트 빌더, API 요청 필드, WS 코칭 프로토콜을 동시 변경.

### 배경
- 철창이(전략 자문)가 v5 UI기획안 작성 (`monkos-ops/03_개발/MONKOS_퍼널_UI기획안_v5_쌍아전달.md`)
- 쌍아가 SCHEMA_v5_확정.md 정본 확정 (D1~D7 결정사항 7건)
- 2026-03-02 하루에 설계→구현→배포→E2E 테스트 완수

### 의사결정 경위 (D1~D7)
| ID | 결정 | 내용 |
|----|------|------|
| D1 | format 2값 | `passport` / `id` (v4 `id_photo`/`resume` 폐기) |
| D2 | gender 축약 | `f` / `m` (v4 `female`/`male` 폐기) |
| D3 | 넥타이 성별무관 | 성별 분기 = blouse/dress shirt만 |
| D4 | age 4분류 | `baby`/`child`/`teen`/`adult` |
| D5 | clothing 조건부 | `default`/`change`(영유아)/`casual`(중고생+)/`suit`(성인) |
| D6 | hair 조건부 | teen/adult만 표시 |
| D7 | expression 삭제 | format 프롬프트 내 표정 지시로 대체 |

## 2. v5 스키마 변경 사항

### sessionStorage 필드 매핑 (v4 → v5)

| v4 키 | v5 키 | 값 변경 | 비고 |
|--------|--------|---------|------|
| `style` | `format` | `id_photo`→`passport`, `resume`→`id` | 핵심 변경 |
| `gender` | `gender` | `male`→`m`, `female`→`f` | 축약 |
| `age` | `age` | `child`/`teen`/`adult` → + `baby` 추가 | 4분류 |
| `clothing` | `clothing` | (유지) | — |
| `clothingColor` | `clothingColor` | (유지) | 조건부 |
| `tie` | `tieColor` + `tiePattern` | 합산형→분리 | **구조 변경** |
| `background` | `bgColor` | (값 동일: white/gray/blue/beige) | 키 변경 |
| `expression` | (삭제) | — | D7: format 프롬프트에 포함 |
| `purpose` | (삭제) | — | format으로 통합 |
| (신규) | `suitColor` | navy/brown/gray/black | suit 서브옵션 |
| (신규) | `shirtColor` | white/lightblue/lightpink/lightbeige | suit 서브옵션 |
| (신규) | `tiePattern` | solid/stripe | tie 분리 |
| (신규) | `schemaVersion` | `v5` | 구키 정리 가드 |

### PHOTO_SPECS 키 변경 (config.js L79-94)
- `id_photo` → `passport` (35×45mm, 여권)
- `resume` → `id` (30×40mm, 증명사진)

### config.js 신규 상수 (L96-130)
- `V5_OPTIONS` — 전 필드 허용값 열거 (format/gender/age/clothing/.../bgColor)
- `CLOTHING_BY_AGE` — 연령별 clothing 제한 (baby/child: default+change, teen/adult: default+casual+suit)
- `HAIR_VISIBLE_AGES` — `['teen', 'adult']`
- `PASSPORT_FORCED_BG` — `'white'`
- `SCHEMA_VERSION` — `'v5'`

## 4. 서버 API 명세

### /api/idgen 엔드포인트 (server.js L700-799)

**v4 요청 필드:**
```json
{
  "image": "base64...",
  "style": "id_photo",
  "purpose": "주민등록증",
  "gender": "male",
  "age": "adult",
  "clothing": "suit",
  "clothingColor": "",
  "tie": "navy-solid",
  "hair": "tidy",
  "background": "white",
  "expression": "neutral",
  "userId": "..."
}
```

**v5 요청 필드:**
```json
{
  "image": "base64...",
  "format": "passport",
  "gender": "f",
  "age": "adult",
  "clothing": "suit",
  "clothingColor": "",
  "suitColor": "navy",
  "shirtColor": "white",
  "tieColor": "navy",
  "tiePattern": "solid",
  "hair": "tidy",
  "bgColor": "white",
  "userId": "...",
  "v": 5
}
```

**분기 로직 (L733-742):**
```javascript
const schemaVersion = body.v || 4;
if (schemaVersion >= 5) {
  if (!body.format || !body.gender || !body.age) {
    return res.status(400).json({ error: 'v5 필수값 누락: format, gender, age' });
  }
}
const instruction = schemaVersion >= 5
  ? buildPromptV5(body)
  : buildPrompt(body);  // 48시간 후 제거
```

**v4 메시지:**
```json

```

**v5 메시지:**

if (msg.type === 'set-format' || msg.type === 'set-style') {

### 이슈 #1: prep 3p 드롭다운 미반응 (중)

| 항목 | 내용 |

| 관련 코드 | prep.js L205-251 (`renderStylePage`), L424-470 (`handleStyleClick`), L588-591 (init 바인딩) |
| 수정 방향 | `renderStylePage()` 말미에 스타일 카드 이벤트 재바인딩, 또는 accordion header 이벤트도 위임 패턴으로 통합 |
