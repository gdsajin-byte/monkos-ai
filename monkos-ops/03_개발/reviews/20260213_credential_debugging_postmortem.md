# Credential 디버깅 포스트모템: 카카오 KOE010

**날짜:** 2026-02-13
**심각도:** 중간 (서비스 기능 장애, 데이터 손실 없음)
**영향:** 카카오 로그인 불가 ~10시간
**해결자:** 쌍아 (Claude Code Opus 4.6)

## 사건 요약

카카오 OAuth 토큰 발급 시 `KOE010 (invalid_client - Bad client credentials)` 에러가 지속 발생.
**근본 원인:** Client Secret 값의 1문자 오독 — `l`(소문자 L) vs `I`(대문자 i)

## 근본 원인 분석 (5 Whys)

1. **왜 KOE010?** → client_secret 값이 틀렸다
2. **왜 틀렸나?** → `l`(소문자 L)과 `I`(대문자 i)를 혼동
3. **왜 혼동?** → 카카오 콘솔 폰트에서 두 문자가 육안상 동일
4. **왜 못 잡았나?** → 스크린샷 OCR, 수동 타이핑, AI 이미지 분석 모두 동일 오독
5. **왜 10시간 걸렸나?** → "값이 맞다"는 전제 하에 다른 원인(비즈니스 인증, secret ON/OFF, 코드 소진)을 반복 탐색

## 실패 패턴: "같은 말만 반복"

```
세션14: "secret 값이 틀린 것 같다" → 스크린샷 복사 → 같은 오독값 반영
세션15: "secret 값 불일치 의심" → 콘솔 확인 요청 → 같은 오독값 확인
세션16: "정밀 분석" 지시 → hex 단위 비교 → 차이 발견
```

**핵심 실패:** "값 자체를 의심"하면서도 "값의 개별 문자를 검증"하지 않음
