# contents/ — SNS/블로그 콘텐츠 소재

> 정본(`01_전략/philosophy/PHILOSOPHY.md`)에서 파생된 즉시 활용 가능 콘텐츠

| 파일 | 용도 |
|------|------|
| `quotes_kr.md` | 한국어 SNS 인용구 (280자 이내, 해시태그 포함) |
| `quotes_jp.md` | 일본어 SNS 인용구 (X/Instagram/LINE VOOM) |
| `blog_seeds/` | 블로그 연재 시드 (주제별 기획) |

## 활용 가이드

1. 인용구를 그대로 복붙하여 X/인스타그램 게시
2. 해시태그 추천을 참고하여 채널별 최적화
3. `blog_seeds/`에 연재 기획 추가 시 파일명: `YYYYMMDD_주제.md`

## 갱신 원칙
