# 에스토니아 여권 사진 규격 — EU인데 왜 3.5×4.5cm가 아닐까요

유럽 여권 사진을 준비할 때 대부분 **3.5 × 4.5cm**부터 떠올리십니다. 한국 여권 사진과 같은 크기이고, 독일·스페인·네덜란드·폴란드·아일랜드까지 EU 다수 국가가 이 크기를 씁니다.

그래서 "유럽은 다 같겠지" 하고 여분의 사진을 그대로 들고 가면, 에스토니아에서 걸립니다. 에스토니아 여권 사진은 **4 × 5cm**입니다.

## TL;DR

- 크기 **4 × 5cm** — 한국·독일·폴란드의 3.5 × 4.5cm와 **다릅니다**
- 배경 **흰색**, 정면 응시, 무표정
- 얼굴(머리) 길이 **3.2~3.6cm**
- **6개월 이내에 촬영**한 사진
- 온라인 제출 시 **최소 1300 × 1600px** — 인쇄 규격(472 × 591px)의 약 7배
- **스캔본·화면 캡처 불가**, 보정하지 않은 컬러 JPEG, 용량 **1~5MB**

## 1. 규격표

| 항목 | 규격 |
|------|------|
| 사진 크기 | **4 × 5cm** (40 × 50mm) |
| 인쇄 픽셀 | 472 × 591px |
| 해상도 | 300dpi |
| 배경색 | 흰색 |
| 얼굴 길이 | 3.2~3.6cm |
| 촬영 시기 | 6개월 이내 |
| 표정 | 무표정, 정면 응시, 입 다물기 |
| 준거 기준 | ICAO 9303 / EU Reg. 2252/2004 |

## 2. 크기가 왜 다를까요 — "EU 표준"의 실제 범위

EU 규정(2252/2004)은 여권의 **생체정보와 보안 요소**를 통일합니다. 사진에 대해서는 ICAO 9303을 따르도록 하는데, ICAO 9303이 규정하는 것은 **얼굴이 프레임에서 차지하는 비율**이지 종이의 물리적 크기가 아닙니다.

그래서 얼굴 비율은 회원국이 대체로 같고(에스토니아 3.2~3.6cm는 독일·폴란드와 동일합니다), **종이 크기는 나라마다 다르게 남았습니다.**

유럽 안에서만 봐도 이렇게 갈립니다.

| 국가 | 사진 크기 |
|------|----------|
| 독일 · 스페인 · 네덜란드 · 폴란드 · 아일랜드 | 3.5 × 4.5cm |
| **에스토니아** | **4 × 5cm** |
| 리투아니아 | 4 × 6cm |
| 핀란드 | 3.6 × 4.7cm |

**"유럽 규격"이라는 단일 규격은 없습니다.** 얼굴 비율이 같다는 뜻이지, 사진 크기가 같다는 뜻이 아닙니다.

여기서 실수가 나오는 지점이 하나 더 있습니다. 3.5 × 4.5cm 사진을 4 × 5cm로 **확대해서 출력하면 얼굴도 같이 커집니다.** 얼굴 길이 상한 3.6cm를 넘겨 반려될 수 있어요. 크기를 맞추는 작업은 잘라내기가 아니라 **얼굴 비율을 유지한 채 여백을 다시 잡는 일**입니다.

## 3. 온라인 제출 — 여기가 진짜 관문입니다

에스토니아는 신청 상당수가 디지털 제출로 처리됩니다. 그리고 디지털 제출 요건이 인쇄 요건과 **숫자가 완전히 다릅니다.**

| 항목 | 요건 |
|------|------|
| 포맷 | JPEG |
| 색상 | 컬러 |
| 최소 픽셀 | **1300 × 1600px** |
| 파일 용량 | **1~5MB** |
| 보정 | 하지 않은 원본 |
| 금지 | **스캔본, 화면 캡처** |

주의하실 대목을 짚어 드립니다.

**① 최소 1300 × 1600px는 인쇄 규격보다 훨씬 큽니다.**
4 × 5cm를 300dpi로 출력하면 472 × 591px입니다. 인쇄용으로는 충분한 크기죠. 그런데 온라인 제출에서는 이 파일이 **최소 기준의 3분의 1 수준**이라 그대로 막힙니다. 규격대로 찍었는데 업로드가 안 되는 대표적인 경우입니다.

**② 스캔본이 안 됩니다.**
사진관에서 인화한 사진을 스캔해서 올리는 방식은 허용되지 않습니다. 인화본과 별개로 **원본 디지털 파일**이 필요합니다.

**③ 화면 캡처도 안 됩니다.**
휴대폰 사진첩을 띄워 캡처하면 픽셀이 화면 해상도로 줄고 압축이 한 번 더 들어갑니다. 파일을 그대로 내보내십시오.

**④ 용량 하한 1MB가 있습니다.**
용량 제한은 보통 상한만 신경 쓰는데, 여기는 **하한도 있습니다.** 카카오톡이나 메신저로 자신에게 전송한 사진은 자동 압축돼 1MB 아래로 떨어지는 경우가 많습니다. 파일 전송은 원본 옵션으로 하십시오.

## 4. 반려를 부르는 5가지

1. **3.5 × 4.5cm 사진 사용** — 가장 흔합니다. 다른 EU 국가 여권 사진과 여분을 섞어 쓰지 마십시오.
2. **배경 그림자** — 흰 벽 앞에서 찍어도 벽에 너무 붙으면 머리 윤곽을 따라 그림자가 생깁니다. 벽에서 50cm 이상 떨어지십시오.
3. **얼굴 크기 초과** — 확대 출력으로 3.6cm를 넘긴 경우.
4. **압축된 파일 업로드** — 메신저 경유 사진, 화면 캡처.
5. **보정본** — 피부 보정·얼굴형 변형이 들어간 사진은 원본으로 인정되지 않습니다.

## 5. 촬영 체크리스트

- [ ] 흰 벽에서 **50cm 이상** 떨어져 서기
- [ ] 정면 응시, 무표정, 입 다물기
- [ ] 안경 착용 시 반사·테 가림 없는지 확인
- [ ] 머리카락이 얼굴 윤곽을 가리지 않게
- [ ] 촬영일 기준 **6개월 이내**인지 확인
- [ ] 원본 파일이 **1300 × 1600px 이상 · 1~5MB**인지 확인
- [ ] 최종 출력 시 **4 × 5cm**, 얼굴 길이 **3.2~3.6cm**
