# 증명사진 앱 추천 2026 — 셀카 한 장으로 여권·이력서 사진 만들기

증명사진이 급하게 필요한데 사진관 갈 시간이 없다면, 스마트폰 앱으로 해결할 수 있습니다. 여권사진(3.5x4.5cm)부터 반명함(3x4cm)까지 — 규격만 정확히 맞으면 셀카로도 충분합니다.

## 증명사진 앱으로 해결되는 것과 안 되는 것

먼저 현실적인 기대치를 맞추겠습니다.

| 가능한 것 | 주의할 것 |
|-----------|-----------|
| 규격 자동 맞춤 (사이즈·비율) | 조명이 나쁘면 앱으로도 한계 |
| 배경색 변경 (흰색·파란색) | 여권사진은 외교부 규정 엄격 적용 |
| 기본 보정 (밝기·피부톤) | 과보정하면 본인 확인 불가로 반려 |
| 디지털 파일 즉시 다운로드 | 인화는 별도 (편의점 키오스크 등) |

핵심은 **규격 정확도**입니다. 사이즈만 맞추는 앱과 머리 위치·배경·해상도까지 잡아주는 앱은 결과물 차이가 큽니다.

## 증명사진 앱 고르는 기준 3가지

### 1. 규격 DB가 얼마나 넓은가

한국 여권(3.5x4.5cm)과 반명함(3x4cm)만 되면 될 것 같지만, 실제로는 생각보다 다양한 규격이 필요합니다.

| 용도 | 사이즈 | 배경 |
|------|--------|------|
| 여권·주민등록증 | 3.5 x 4.5cm | 흰색 필수 |
| 운전면허증 | 3.5 x 4.5cm | 흰색 필수 |
| 이력서·반명함 | 3 x 4cm | 흰색 권장 |
| 미국 비자 | 5.1 x 5.1cm (2x2인치) | 흰색 필수 |
| 일본 여권 | 3.5 x 4.5cm | 흰색 또는 연한 색 |

앱 하나로 이 규격들을 자동으로 맞춰주면 매번 검색할 필요가 없어집니다.

### 2. 배경 제거 품질

증명사진의 배경은 대부분 **균일한 흰색**이어야 합니다. 집에서 셀카를 찍으면 배경이 지저분하기 마련인데, 앱의 배경 제거 기술이 이 문제를 해결합니다. 다만 머리카락 경계선, 귀 주변 처리가 깔끔한지가 앱 품질을 가르는 기준입니다.

### 3. 보정의 한계를 지키는가

증명사진에서 **과도한 보정은 반려 사유**입니다. 특히 여권사진은 "실물과 동일"이 원칙이라, 얼굴형 변형·과도한 피부 보정·눈 확대 같은 필터는 써서는 안 됩니다. 좋은 앱은 밝기·대비 정도만 조정하고 골격을 건드리지 않습니다.

## 증명사진 앱 비교

### 일반 보정 앱 (셀카 후 직접 편집)

포토샵, 스냅스, 픽미 같은 서비스는 사진을 업로드하고 사이즈를 맞추는 방식입니다. 사진 편집에 익숙한 분에게 적합하지만, 규격을 직접 확인하고 수동으로 자르기·배경 처리를 해야 합니다.

- 장점: 세밀한 조정 가능
- 단점: 규격 실수 가능성, 배경 제거 수동, 시간 소요

### AI 증명사진 앱 (자동 규격 맞춤)

AI 기반 앱은 셀카를 올리면 규격 맞춤, 배경 제거, 머리 위치 조정까지 자동으로 처리합니다. 규격을 몰라도 용도만 선택하면 됩니다.

- 장점: 규격 자동 적용, 배경 자동 제거, 빠름
- 단점: 세밀한 수동 조정이 제한적일 수 있음
