# 여권사진, 웃으면 반려될까 — 나라별 '표정' 규정 총정리 (그리고 이력서 사진만 반대인 이유, 2026)

증명사진 찍을 때 가장 많이 듣는 질문이 **"웃어도 되나요?"** 입니다.

사진관에서 20년 동안 이 질문을 받아 왔는데, 정답이 하나가 아닙니다. **서류가 무엇인지, 어느 나라에 내는지에 따라 갈립니다.** 그리고 어떤 서류는 **웃는 쪽이 권장**입니다.

MONKOS가 정리한 **429개 국가별 규격** 중 표정 조항이 명시된 **158건**을 전수로 분류했습니다. 결과는 이렇게 나왔습니다.

| 분류 | 건수 | 뜻 |
|------|------|-----|
| **미소를 일부 허용**한다고 명시 | **12건** | 조건부로 웃어도 됨 |
| **미소 금지**를 명시 | **29건** | 웃으면 반려 사유 |
| **무표정 요건만** 기재 | **117건** | 미소 언급 자체가 없음 |

여기서 가장 많은 **117건**이 함정입니다. "웃지 마라"고 안 쓰여 있다고 **웃어도 된다는 뜻이 아닙니다.** 아래에서 이 셋을 하나씩 갈라 보겠습니다.

---

## 1. 한국 기준 — 무표정, 입 다물기, 이가 보이지 않을 것

먼저 국내 서류입니다. 한국 여권 규정의 표정 조항은 네 가지를 요구합니다.

- 자연스러운 **무표정**
- **입을 다물 것**
- **이가 보이지 않을 것**
- 눈을 뜨고 **정면 주시**

주민등록증도 같습니다(무표정·입 다물기·정면 주시). 여기에 **측면 촬영 불가**가 추가됩니다.

> 💡 **"이가 보이지 않을 것"이 핵심입니다.** 입을 다물고 찍어도 입꼬리가 올라가면서 이가 살짝 비치는 경우가 생깁니다. 한국 여권은 이 상태를 명시적으로 배제합니다. 영국처럼 "이가 약간 보이는 건 괜찮다"고 적어 둔 나라와 **정확히 반대 방향**입니다.

운전면허·국제운전면허 규정은 조금 다릅니다. 표정 조항에 **미소 관련 문구가 아예 없고**, 요구 사항이 "정면 촬영, 얼굴 기울임 금지, 시선 정면"뿐입니다. 그래서 위 표의 **117건(무표정 요건만 기재)** 쪽에 들어갑니다.

**이럴 때 실무 답은 하나입니다 — 무표정으로 찍으세요.** 규정에 안 쓰여 있다는 건 허용의 근거가 아니라 **판단이 접수 창구로 넘어간다는 뜻**입니다. 같은 사진이 어떤 담당자에게는 통과하고 어떤 담당자에게는 반려됩니다. 명시가 없으면 **가장 보수적인 쪽**이 안전합니다.

---

## 2. 미소를 공식적으로 허용하는 나라 — 12건

여기가 의외의 구간입니다. 공식 규정에 **미소 허용이 글로 적혀 있는** 곳들입니다.

| 국가·서류 | 규정에 적힌 내용 |
|----------|----------------|
| **미국 여권** | 무표정, 양쪽 눈을 뜨고 보일 것, 입은 다물 것. **눈을 뜨고 입을 다문 상태라면 자연스러운 미소는 허용** |
| **영국 여권** | 무표정(찡그리거나 웃지 않을 것), 입은 다물 것. **이가 약간 보이는 편안한 입 모양은 허용.** 얼굴 형태를 왜곡하는 표정(활짝 웃기, 입 내밀기, 찡그리기)은 불가. **6세 미만 아동은 면제** |
| **핀란드 여권** | 무표정, 입 다물기. **입술을 다문 상태의 가벼운 미소는 허용** |
| **필리핀 여권** | **옅은 미소(이른바 '모나리자' 포즈)는 허용.** 단 눈·입·볼이 일그러지거나 무표정 사진과 크게 달라 보이면 안 됨 |
| **파나마 여권** | **이가 보이지 않는 선에서 살짝 미소 짓는 것은 허용** (완전한 무표정만 요구하지는 않음) |
| **르완다 여권** | **무표정 또는 자연스러운 미소.** 활짝 웃거나 과장된 표정은 금지 |
| **도미니카연방 여권·비자** | 무표정 필수. **미소는 허용되나 입은 다물어야 함**(치아 노출 금지) |
| **에콰도르 비자** | **무표정을 권장하나 자연스러운 미소도 허용.** 양쪽 눈은 뜨고 있어야 함 |

### 허용이라고 해도 선은 똑같습니다

여덟 건을 나란히 놓으면 **공통된 선**이 보입니다.

1. **입은 다문다.** 거의 전부가 "mouth closed"를 유지합니다. 영국만 "이가 약간 보이는 편안한 입"까지 열어 둡니다.
2. **얼굴 형태가 변하면 안 된다.** 영국은 "얼굴 형태를 왜곡하는 표정", 필리핀은 "눈·입·볼이 일그러지면 안 됨"이라고 씁니다. 즉 허용되는 건 **활짝 웃기가 아니라 입꼬리 정도**입니다.
3. **눈이 가려지면 안 된다.** 웃을 때 눈이 가늘어지는 분들이 많습니다. 미소를 허용하는 규정도 "양쪽 눈을 뜨고 보일 것"은 예외 없이 요구합니다.

> 📌 **실무 조언**: "미소 허용"이라고 해서 웃는 사진을 내는 것이 **유리하지는 않습니다.** 자동 얼굴 인식 심사에서는 무표정이 기준 얼굴과 가장 잘 맞습니다. 허용 규정은 **"살짝 웃었다고 반려하지 않겠다"는 보험**으로 읽는 게 정확합니다.

## 3. 미소 금지를 못 박은 나라 — 29건

반대편입니다. 규정에 **"no smiling"이 직접 적혀 있는** 곳들입니다. 여행·이주 수요가 많은 나라부터 보겠습니다.

| 국가·서류 | 규정에 적힌 내용 |
|----------|----------------|
| **캐나다 여권** | 무표정, 웃거나 찡그리지 않을 것, 입을 다물 것 |
| **캐나다 비자** | 무표정, 찡그리거나 웃지 않을 것, 입을 다물 것 |
| **호주 여권** | 무표정 — **미소, 웃음 또는 찡그림 금지** |
| **뉴질랜드 여권** | 입을 다물고 양쪽 눈을 뜬 무표정. **이가 보이는 미소는 금지** |
| **독일 여권** | 무표정, 입 다물기, **미소 금지**, 카메라를 정면으로 응시 |
| **이탈리아 여권** | 무표정, 입 다물기, 미소 금지, 눈을 뜨고 선명하게 보이기 |
| **스페인 여권** | 무표정, **미소 또는 제스처 금지** |
| **벨기에 여권·쉥겐 비자** | 무표정, 입 다물기, 미소 금지 |
| **아일랜드 여권** | 무표정, 입 다물기, 미소 금지 |
| **그리스 비자** | 정면을 응시하며 무표정 유지. **미소 금지**, 입은 다물 것 |
| **영국 운전면허** | 자연스러운 표정, **웃거나 활짝 웃거나 찡그리지 않을 것**; 눈을 뜨고 입을 다물 것 |
| **이스라엘 여권** | 입을 다문 중립적 표정. **미소는 금지** |
| **모로코 여권** | 무표정 유지: 입을 다물고 미소 짓지 않을 것, 고개를 똑바로 세우고 시선은 렌즈 정면 |

이 밖에 **아르메니아·에리트레아·엘살바도르·과테말라·가이아나·나미비아·나우루·마다가스카르·모나코·바하마·벨리즈·파푸아뉴기니** 등이 같은 구간에 들어갑니다.

> ⚠️ **같은 나라에서도 서류에 따라 다릅니다.** 영국은 **여권은 "이가 약간 보여도 허용"인데 운전면허는 "웃지 말 것"** 입니다. 같은 영국 서류라고 같은 사진을 쓰면 한쪽에서 걸립니다. 영국 여권용으로 찍은 사진을 그대로 면허에 돌려쓰는 것이 전형적인 반려 경로입니다.

그리고 재미있는 지점이 하나 더 있습니다. **아르메니아 여권은 "눈썹 치켜올림"까지 금지**합니다. 미소만 조심하면 되는 게 아니라, **얼굴 근육을 쓰는 모든 동작**이 대상인 경우가 있습니다.

## 4. 방향이 뒤집히는 곳 — 이력서·취업 사진

여기가 이 글에서 가장 실용적인 부분입니다.

지금까지는 전부 여권·비자·면허였습니다. **신분 서류는 무표정이 기본**입니다. 그런데 **이력서 사진은 규정 자체가 반대 방향**입니다.

| 서류 | 규정에 적힌 내용 |
|------|----------------|
| **독일 이력서 사진** | 카메라를 정면으로 바라보며 **자연스럽게 미소 지을 것** — 여권사진과 달리 **무표정이 아닌 자연스러운 미소가 권장** |
| **중국 이력서 사진 (1寸)** | 자연스러운 표정, 눈 뜬 상태, 입술 다문 상태. **이력서 사진에는 가벼운 미소 허용** |
| **중국 이력서 사진 (2寸)** | 위와 동일 |

독일 규정은 **"여권사진과 달리"** 라는 말을 직접 씁니다. 신분 증명과 자기 소개는 사진의 목적이 다르다는 걸 규정이 스스로 구분해 둔 것입니다.

**국내 취업사진도 같은 논리로 봅니다.** 한국 이력서용 반명함(3 × 4cm)에는 규격 데이터상 표정 조항이 없습니다. 명시 기준이 없다는 건 **채용 관행이 기준이 된다는 뜻**이고, 실무에서는 **입을 다문 옅은 미소에 밝은 눈**이 가장 무난합니다. 신분증 사진의 무표정을 그대로 이력서에 쓰면 표정이 굳어 보입니다.

> 🎯 **그래서 결론은 사진을 두 종류로 관리하는 겁니다.**
> **① 신분 서류용** — 무표정, 입 다물기, 이 안 보이기. 여권·비자·주민등록증·면허 전부 커버.
> **② 이력서·취업용** — 입 다문 옅은 미소, 눈은 또렷하게. 독일·중국 이력서 규정이 명시로 요구하는 방향.
> 두 장을 따로 가지고 있으면 서류마다 고민할 일이 없어집니다.

## 5. 촬영 전 체크리스트

제출처가 어디든 공통으로 통하는 순서입니다.

- [ ] **제출처가 신분 서류인가, 자기 소개인가** — 신분 서류면 무표정, 이력서면 옅은 미소
- [ ] **규정에 미소 문구가 있는지 확인** — 없으면 무표정(명시 없음은 허용이 아님)
- [ ] **입을 다물었는가** — 미소를 허용하는 나라도 대부분 입은 다물라고 요구
- [ ] **이가 보이는가** — 한국·뉴질랜드·도미니카연방 등은 치아 노출을 직접 금지
- [ ] **양쪽 눈이 또렷하게 보이는가** — 웃을 때 눈이 가늘어지는 것이 가장 흔한 반려 원인
- [ ] **같은 나라라도 서류별로 다시 확인** — 영국 여권과 영국 면허는 표정 규정이 다름
- [ ] **최종 확인은 발급기관 공식 안내** — 규정은 개정됩니다. 제출 직전 원문을 한 번 더 보세요

## 마지막으로

표정은 규격 중에서 **가장 과소평가되는 항목**입니다. 크기와 배경은 다들 찾아보는데, 표정은 "무표정이면 되겠지" 하고 넘어갑니다. 그런데 158건을 늘어놓고 보면 **12건은 웃어도 되고, 29건은 웃으면 안 되고, 3건은 웃으라고 하고** 있습니다.

**MONKOS**는 나라·서류별 규격을 규격 페이지로 정리해 두고 있습니다. 증명사진이 필요할 때 제출처 규격을 먼저 확인하고, 그다음 사진을 만드시면 반려로 되돌아오는 일이 줄어듭니다.

> 본 글의 규정 내용은 MONKOS가 정리한 국가별 규격 데이터를 기준으로 작성했습니다. 각국 규정은 개정될 수 있으므로 **최종 확인은 반드시 해당 발급기관의 공식 안내**로 해 주세요.
