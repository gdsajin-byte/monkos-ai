# 여권·비자 사진에 모자나 히잡을 써도 되나요

증명사진은 맨머리로 찍는다. 대부분 맞는 말입니다. 모자를 쓰고 여권 사진을 내면 거의 모든 나라에서 반려돼요.

그런데 **종교적 머리 덮개는 이야기가 다릅니다.** 히잡, 터번, 키파처럼 일상적으로 쓰는 머리 덮개는 세계 대부분의 여권 기관이 예외로 인정하고 있어요. 문제는 **예외의 조건이 나라마다 제각각**이라는 점입니다. 어떤 나라는 그냥 허용하고, 어떤 나라는 서명한 진술서를 요구하고, 어떤 나라는 색깔까지 지정합니다. 그리고 **예외를 아예 두지 않은 나라도 있습니다.**

20년간 증명사진을 찍으면서 가장 설명하기 어려웠던 게 이 대목이었어요. "쓰셔도 됩니다"도 "안 됩니다"도 정답이 아니라서요.

그래서 이번에는 규정을 하나씩 검색하는 대신, **MONKOS가 관리하는 국가·용도별 증명사진 규격 429건을 머리 덮개 조항 기준으로 전수로 읽었습니다.**

## 먼저 밝혀 둘 것 — 모수

429건 전부에 머리 덮개 조항이 적혀 있는 건 아닙니다.

| 구분 | 건수 |
|------|------|
| 머리 덮개 조항이 **기재된** 규격 | **167건** |
| 조항이 **기재되지 않은** 규격 | 262건 |
| 합계 | 429건 |

**기재되지 않은 262건은 "허용"도 "금지"도 아닙니다.** 단지 저희가 확인한 공식 규정 문면에 해당 조항이 없다는 뜻이에요. 이 글의 모든 수치는 **기재된 167건 안에서의 이야기**입니다. 해당 국가의 규격이 아래 표에 없다면, 발급 기관 공지를 직접 확인해 주세요.

## 167건을 셋으로 갈랐습니다

| 유형 | 건수 | 비중 | 뜻 |
|------|------|------|-----|
| **예외를 명시한 곳** (종교·의료·관습) | **118건** | 71% | 조건을 지키면 착용 가능 |
| **예외 없이 전면 금지한 곳** | **28건** | 17% | 사유를 불문하고 맨머리 |
| 금지·허용을 단정하지 않고 상태만 기술 | 21건 | 13% | "맨머리로 촬영" 같은 서술형 |
| 합계 | **167건** | 100% | |

**10건 중 7건은 예외를 인정합니다.** 이게 큰 그림이에요. 다만 나머지 3건이 문제고, 그 3건에 한국의 일부 서류가 들어갑니다.

## 같은 한국 안에서도 기준이 갈립니다

이 부분이 가장 많이들 놓치는 지점이에요.

| 서류 | 머리 덮개 규정 |
|------|---------------|
| **대한민국 여권** | 모자·머리띠·헤어 액세서리 금지. **단, 일상적으로 착용하는 종교적 머리 덮개는 얼굴 전체(이마~턱)가 보이면 허용** |
| **대한민국 비자** | 모자 착용 금지 (예외 조항 없음) |
| **주민등록증** | 모자, 보닛, 머리 두건 착용 금지 (예외 조항 없음) |
| **운전면허증** | 모자 착용 금지. 2026년 3월 1일부터 여권 사진 기준 엄격 적용 |

여권은 예외를 두는데 **비자·주민등록증·운전면허증에는 예외 문구가 없습니다.** 여권 사진을 그대로 주민등록증에 재사용하려던 분들이 여기서 걸리는 경우가 있어요.

> 💡 운전면허증은 2026년 3월부터 여권 사진 기준을 엄격히 적용하고 있습니다. 예전에 통과하던 사진이 지금은 안 될 수 있어요.

## 예외를 인정하되, 조건이 붙는 나라들

여기부터가 실전입니다. "허용"이라는 같은 결론인데 조건이 전부 다릅니다.

| 국가·서류 | 조건 |
|-----------|------|
| **미국 여권** | 종교·의료 목적 외 금지. 착용 시 **서명한 진술서 필요**. 얼굴 전체 노출, 그림자 없을 것, **단색**일 것, 무늬·구멍 없을 것 |
| **미국 비자** | 종교적 목적의 일상 착용만 예외. **머리 덮개가 얼굴에 그림자를 만들면 안 됨** |
| **영국 여권** | 종교적 머리 덮개(얼굴 미가림) 또는 **의료용**(상처·탈모용 스카프, 붕대) 예외. 이목구비가 명확하면 헤어 액세서리도 허용 |
| **캐나다 여권** | 종교적 사유 허용. **의료용은 설명서 첨부 시** 허용 |
| **독일 여권** | 원칙 금지, 종교·의료 예외. 턱 아래~이마까지 얼굴 전체 노출 필수 |
| **인도 여권** | **터번·히잡 등** 일상적 종교 관행이면 허용. 턱 아래~이마 위 노출 |
| **말레이시아 여권** | 종교적 히잡 허용. 단 **이마가 보여야 하고, 히잡은 어두운 색(검정 권장)** |
| **중국 비자** | **종교적 사유에 한해서만** 허용. 이목구비 가림 금지 |
| **사우디아라비아 비자** | 원칙 금지, 종교적 사유는 **턱~이마 노출 조건**으로 예외 |
| **일본 여권** | 모자·머리띠·머리 덮개 금지. **얼굴 윤곽이 보이면** 종교·의료 예외 |
| **싱가포르 여권** | **종교적 또는 인종적 관습**에 따른 일상 착용이면 허용 |
| **필리핀 여권** | 모자·헤드기어 금지. 종교·의료 사유 머리스카프는 **눈썹과 눈을 가리지 않으면** 허용 |

조건을 한 줄로 압축하면 이렇습니다.

> **"얼굴이 다 보이고, 그림자가 안 지고, 시선을 끌지 않으면 된다."**

세부 문구는 달라도 요구하는 바는 거의 같아요. **이마부터 턱까지가 가려지지 않는 것**이 공통 기준입니다.

## 예외 없이 맨머리를 요구하는 나라들

아래는 **전면 금지 28건**과 **맨머리 상태만 서술한 21건**에서 대표 사례를 뽑은 것입니다. 두 유형 모두 예외 문구가 없다는 점은 같아요.

| 국가·서류 | 문면 |
|-----------|------|
| **프랑스 여권** | **맨머리 필수.** 모자·스카프·머리띠 착용 금지 |
| **베트남 여권** | 맨머리로, 모자·머리가리개 착용 불가 |
| **아랍에미리트 비자** | 모자 착용 불가 |
| **마카오 여권·비자** | 머리에 아무것도 쓰지 않은 상태 |
| **홍콩 여권** | 머리 장식 착용 금지 |
| **중국 운전면허** | 모자와 스카프 착용 금지 |

프랑스는 배경색도 "흰색 배경 금지"로 까다로운 나라인데, 머리 덮개도 예외 문구 없이 **맨머리 필수**입니다. ([프랑스 배경색 관련 정리 보기](/blog/passport-photo-background-color-by-country))

> ⚠️ 이 목록은 **저희가 확인한 규정 문면에 예외 문구가 없다**는 뜻입니다. 종교적 사유가 있으시다면 문면만 보고 포기하지 마시고 발급 기관에 직접 문의하시는 편이 확실합니다. 실무상 개별 심사로 처리되는 경우가 있어요.

## 예외적으로 관대한 사례 하나

전수로 읽다 보면 결이 다른 규정도 나옵니다.

**스리랑카 여권**은 이렇게 되어 있어요. "모자나 스카프 착용을 원하는 신청자는 착용할 수 있으나, **이마와 귀가 선명하게 보여야 하며** 스카프 그림자가 얼굴에 지지 않아야 한다."

종교적 사유를 조건으로 달지 않고 **본인이 원하면 착용 가능**하다고 적은, 167건 중 드문 경우입니다. 다만 조건(이마·귀 노출, 그림자 없음)은 다른 나라와 똑같아요. 결국 **어느 나라든 진짜 기준은 "덮개 자체"가 아니라 "얼굴 식별"** 이라는 걸 보여 줍니다.

## 촬영 전 체크리스트

머리 덮개를 착용하고 촬영하실 거라면 이 다섯 가지만 확인하세요.

- [ ] **이마가 보이나요?** — 거의 모든 예외 조항의 1번 조건입니다. 눈썹이 가리면 대부분 반려됩니다.
- [ ] **턱선까지 얼굴 윤곽이 드러나나요?** — "턱 아래부터 이마까지"가 표준 문구예요.
- [ ] **덮개가 얼굴에 그림자를 만들지 않나요?** — 미국 비자가 명시적으로 지적하는 항목입니다. 정면 조명으로 그림자를 없애세요.
- [ ] **무늬·장식이 없는 단색인가요?** — 미국 여권은 단색·무늬 없음을 요구하고, 말레이시아는 어두운 색을 권장합니다.
- [ ] **제출처의 예외 조항을 확인했나요?** — 같은 한국 서류인데도 여권은 되고 비자·주민등록증은 안 됩니다.

## 사진을 이미 찍으셨다면

머리 덮개 규정은 **재촬영으로만 해결됩니다.** 배경색이나 사이즈와 달리 후보정으로 바꿀 수 있는 항목이 아니에요. 이마가 가려진 사진을 보정으로 살릴 방법은 없습니다.

다만 **덮개 착용 자체는 규정에 맞는데 배경·크기·해상도가 어긋난 경우**라면 다시 찍지 않아도 됩니다. MONKOS AI 증명사진은 국가·용도별 규격에 맞춰 배경과 치수를 맞춰 드려요. 규격 선택 화면에서 나라와 서류를 고르시면 해당 규격의 요구사항을 함께 안내합니다.

## 정리

- MONKOS 규격 **429건 중 머리 덮개 조항이 기재된 건 167건**입니다. 나머지 262건은 미기재이며 허용·금지 어느 쪽도 아닙니다.
- 167건 중 **118건(71%)이 종교·의료·관습 예외를 명시**합니다. 전면 금지는 **28건(17%)** 입니다.
- 예외의 조건은 결국 하나로 모입니다 — **이마부터 턱까지 얼굴이 다 보이고, 그림자가 지지 않을 것.**
- **같은 한국 서류끼리도 갈립니다.** 여권은 예외를 두고, 비자·주민등록증·운전면허증에는 예외 문구가 없습니다.
- 머리 덮개는 후보정 대상이 아닙니다. **촬영 전에 확인하는 것이 유일한 방법**이에요.
