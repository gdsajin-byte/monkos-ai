# 증명사진 파일, 커도 반려되고 작아도 반려됩니다

온라인으로 여권을 재발급받거나 비자를 신청할 때, 사진 업로드에서 막혀 본 적 있으신가요?

현장에서 가장 많이 듣는 말이 이겁니다. "사진관에서 제대로 찍었는데 왜 파일이 안 올라가죠?"

**얼굴은 문제가 없었습니다.** 대부분은 파일이 문제입니다. 그리고 여기서 많은 분이 놓치는 지점이 하나 있어요 — **파일은 크기만 문제가 되는 게 아니라, 작아도 반려됩니다.**

---

## 1. 용량 상한은 나라마다 150배까지 벌어집니다

같은 여권 사진인데, 나라별로 허용하는 파일 크기가 이 정도로 다릅니다.

| 국가 / 종류 | 파일 용량 | 비고 |
|---|---|---|
| **싱가포르** 여권·비자 | **최대 60KB** | 전 세계에서 가장 빡빡한 축 |
| **프랑스** 쉥겐 비자 | 최대 120KB | 온라인 신청 기준 |
| **인도** 운전면허 | **10~20KB** | 상한·하한이 모두 있음 |
| **미국** 비자 | 최대 240KB | 24비트 컬러·sRGB 지정 |
| **핀란드** 여권·비자 | 최대 250KB | |
| **인도** 여권 | 최대 250KB | 온라인 접수 포털 기준 |
| **대한민국** 여권 | 500KB 이하 | 300DPI 이상 |
| **터키** 여권 | 최대 500KB | |
| **말레이시아** 여권 | 100KB~1MB | 온라인 여권 신청 |
| **폴란드** 여권 | 최대 2.5MB | 온라인 접수 |
| **라오스** 비자 | 최대 2MB | JPG·PNG·PDF 허용 |
| **호주** 여권 | 70KB~3.5MB | |
| **뉴질랜드** 비자 | **500KB~3MB** | 하한이 큼 |
| **캐나다** 여권 | **200KB~5MB** | 온라인 갱신 |
| **뉴질랜드** 여권 | 250KB~5MB | |
| **홍콩** 여권·비자 | 최대 5MB | |
| **대만** 여권·비자 | 최대 5MB | RGB 24비트 이상 |
| **영국** 비자 | 50KB~6MB | |
| **일본** 마이넘버카드 | 20KB~7MB | JPEG만 허용 |
| **아일랜드** 여권 | **최대 9MB** | 압축 흔적 없을 것 |

> ⚠️ 위 수치는 각국 공식 기관 안내를 기준으로 정리한 것입니다. **접수 시스템·창구·신청 경로에 따라 세부 요구가 달라질 수 있으니, 제출 직전에 해당 기관의 공식 안내를 반드시 확인하세요.**

싱가포르 60KB와 아일랜드 9MB는 **약 150배** 차이입니다. 같은 얼굴, 같은 규격(3.5 × 4.5cm)인데 파일 하나로 통과와 반려가 갈립니다.

---

## 2. 진짜 함정은 '최소 용량'입니다

파일이 안 올라가면 대부분 이렇게 하십니다. 이미지 편집 앱에서 화질을 낮추고, 크기를 줄이고, 다시 저장하고.

**그런데 그렇게 하면 오히려 걸리는 나라가 있습니다.**

| 국가 / 종류 | 최소 용량 | 최대 용량 |
|---|---|---|
| 뉴질랜드 비자 | **500KB** | 3MB |
| 뉴질랜드 여권 | 250KB | 5MB |
| 캐나다 여권 | **200KB** | 5MB |
| 호주 여권 | 70KB | 3.5MB |
| 영국 비자 | 50KB | 6MB |
| 중국 비자 | **40KB** | 120KB |
| 일본 마이넘버카드 | 20KB | 7MB |
| 인도 e-Visa | 10KB | 1MB |
| 인도 운전면허 | 10KB | 20KB |

최소 용량을 둔 이유는 단순합니다. **너무 압축된 파일은 얼굴 판독이 안 되기 때문**입니다. 여권·비자 사진은 사람이 눈으로만 보는 게 아니라 생체 인식 대조에도 쓰입니다. 화질을 깎아 용량을 맞추면 그 대조를 통과하지 못합니다.

특히 **중국 비자(40~120KB)**는 창이 좁습니다. 상한과 하한 사이가 3배밖에 안 되는데다 픽셀 범위(354~420 × 472~560px)까지 동시에 걸려 있어서, 감으로 맞추기 가장 어려운 축에 듭니다.

---

## 3. 픽셀 하한 + 용량 상한이 같이 걸리면

이 조합이 실무에서 제일 까다롭습니다. **해상도는 충분히 높아야 하는데, 파일은 작아야 하는 경우**입니다.

| 국가 / 종류 | 픽셀 요구 | 용량 요구 |
|---|---|---|
| 핀란드 여권·비자 | 500 × 653px | 최대 250KB |
| 인도 여권 | 630 × 810px | 최대 250KB |
| 미국 비자 | 600 × 600 ~ 1200 × 1200px | 최대 240KB |
| 영국 비자 | 최소 600 × 750px | 50KB~6MB |
| 아일랜드 여권 | 최소 715 × 951px | 최대 9MB |
| 폴란드 여권 | 최소 768 × 1004px | 최대 2.5MB |
| 홍콩 여권·비자 | 최소 1200 × 1600px | 최대 5MB |
| 에스토니아 여권 | 최소 1300 × 1600px | 1~5MB |
| 캐나다 여권 | 1200~3000 × 1800~4500px (3:2) | 200KB~5MB |
| 말레이시아 여권 | 413 × 591px (300DPI) | 100KB~1MB |
| 대만 여권·비자 | 최소 531 × 413px | 최대 5MB |
| 캐나다 비자 | 최소 420 × 540px | — |
| 라오스 비자 | 152 × 227px (300DPI) | 최대 2MB |
| 인도 운전면허 | 420 × 525px | 10~20KB |

**픽셀을 줄여서 용량을 맞추면 픽셀 하한에 걸리고, 픽셀을 유지한 채 압축률만 올리면 화질 요건에 걸립니다.** 정답은 픽셀은 그대로 두고 JPEG 품질만 단계적으로 조절하는 것인데, 이걸 손으로 맞추려면 저장 → 확인 → 다시 저장을 반복하게 됩니다.

---

## 4. "손대지 마세요" — 보정과 재압축을 금지하는 나라들

여기가 가장 덜 알려진 부분입니다. 몇몇 나라는 **파일을 편집했다는 흔적 자체를 반려 사유로 봅니다.**

| 국가 | 명시된 금지 사항 |
|---|---|
| **에스토니아** 여권 | 무보정(unedited) 컬러 JPEG. **스캔 사진·스크린샷 불가** |
| **핀란드** 여권 | **보정·리터칭 일체 금지** |
| **캐나다** 여권 | **카메라 원본 파일** 제출 |
| **아일랜드** 여권 | **압축 아티팩트(뭉개짐) 없을 것** |
| **일본** 마이넘버카드 | JPEG 전용, RGB 컬러 모드 |
| **미국** 비자 | 24비트 컬러, sRGB |

무슨 뜻이냐면, **"용량 맞추려고 여러 번 저장한 파일"이 그 자체로 걸릴 수 있다**는 겁니다. JPEG는 저장할 때마다 화질이 조금씩 깎이는데, 그 흔적이 남습니다.

그래서 순서가 중요합니다. **찍은 다음에 줄이는 게 아니라, 처음부터 규격에 맞게 만들어야 합니다.**

## 5. 인화 사진에도 파일 기준이 붙는 경우

디지털 제출이 아니어도 해상도 요건이 따라오는 나라가 있습니다. 인화물의 인쇄 품질을 규정하는 방식입니다.

| 국가 | 요구 해상도 |
|---|---|
| 네덜란드 여권·비자 | 최소 400dpi |
| 프랑스 쉥겐 비자 | 최소 400dpi (인쇄 기준) |
| 슬로베니아 여권 | 최소 600dpi, 광택 인화지 |
| 몰디브 여권·비자 | 최소 600dpi |
| 독일 여권 | 최소 600dpi ※ 현지 발급은 별도 절차 |
| 홍콩 (스캔 시) | 40 × 50mm 기준 600dpi |

집 프린터로 뽑은 사진이 반려되는 이유가 대개 여기 있습니다. 크기는 맞는데 **인쇄 해상도가 기준에 못 미치는** 경우예요.

> 독일 현지에서 발급받는 신분증·여권은 2025년부터 종이 사진 제출 방식 자체가 달라졌습니다. 이건 규격보다 절차의 문제라 [독일 편](/blog/germany-visa-passport-photo-spec-guide)에서 따로 다뤘습니다.

## 6. 제출 전 체크리스트

접수 화면을 열기 전에 이 순서로 확인해 보세요.

1. **포맷** — JPEG만 받는 곳이 대부분입니다 (일본 마이넘버카드, 에스토니아·핀란드 등은 JPEG 전용 명시). PNG·HEIC는 아예 안 올라갑니다.
2. **픽셀 하한** — 먼저 확인합니다. 이건 나중에 못 늘립니다.
3. **용량 상한과 하한** — **둘 다** 봅니다. 하한이 있으면 무작정 줄이면 안 됩니다.
4. **컬러 모드** — RGB / sRGB / 24비트 지정이 있는지.
5. **편집 제한** — 무보정·원본 요구가 있는지.
6. **아이폰 사용자라면 HEIC → JPEG 변환**을 먼저. 촬영 설정이 기본 HEIC면 업로드 자체가 막힙니다.

## 마무리

증명사진 반려의 원인을 물어보면 대부분 "표정이 이상했나", "배경이 문제였나"를 먼저 떠올리십니다.

그런데 **온라인 제출에서는 얼굴이 화면에 뜨기도 전에 막히는 경우가 더 많습니다.** 용량 60KB와 9MB 사이 어딘가에서, 픽셀 하한과 용량 상한 사이에서 걸립니다.

한 번 더 정리하면 이렇습니다.

- 용량은 **상한만 있는 게 아닙니다.** 하한을 확인하세요.
- 픽셀은 **나중에 못 늘립니다.** 처음부터 크게 찍으세요.
- **여러 번 저장하지 마세요.** 그 자체가 반려 사유인 나라가 있습니다.

제출 직전에는 해당 기관 공식 안내를 한 번 더 확인하시고요. 규정은 바뀝니다.
