# 콘텐츠 전략 정본 — 무엇을, 어떤 목소리로, 얼마나

> 생산 파이프라인(contents/blog → CMS 드래프트 → 게이트)의 **조향 장치**.
> 루틴·에이전트는 소재 선별과 작성 전에 본 문서를 참조한다. 발명 금지 — 여기 없는 톤·필러를 임의 신설하지 않는다.
> 원칙: 모든 톤·필러는 **기존 실전 발행물에서 검증된 것만** 정본화했다 (2026-06-11 기준).

## 0. 전략 정렬 (왜 이 구성인가)

- **[마케팅 기획 06-10](../ops/reports/2026-06/REPORT_20260610_M2쌍아_MONKOS_KR_마케팅기획_보고.md)** (M2/쌍아+꾸): 6월 = 콘텐츠 기반 완성, **블로그 매일 발행 20편+**, 타깃 4종(신분증/비자/시험·자격증/알바 이력서), 공통 키워드 **"증명사진 어플"**(네이버 월 6,170). → **P1 필러가 6월 최우선.**
- **PF_OPUS KPI**: 월 콘텐츠 20건(4주) → 50건(12주), 오가닉 클릭 120 → 400.
- **PF_CITADEL**(유입)·**PF_SPREAD**(배포 21채널)는 받을 준비 완료 — 생산이 병목이었다.
- 역할 경계: 본 문서 = 블로그(1차 생산) 전략. 채널별 2차 가공·배포 전략은 PF_SPREAD, 키워드·기술 SEO는 PF_CITADEL, 꾸 채널 7종은 PF_KKU가 정본.

## 3. 언어·채널 라우팅 (1차 생산 기준)

```
KO 원본 (contents/blog) → CMS 드래프트 → 작가님 발행
                                    └─ 발행 시 자동: JA/EN 번역 + 색인 (기존 체이닝)
P1: monkos.ai 블로그 + 네이버 동시 발행(수동, T2 변환) — 마케팅 기획 결정 사항
P2: monkos.ai 블로그 → EN(Medium/Reddit)·JA(note) 채널 가공은 PF_SPREAD 절차로
P3: monkos.ai 블로그 (EN 번역 자동)
```
- Reddit은 계정 karma 육성 전까지 단기 배포 무리 (06-08 교훈, PF_SPREAD).
- 네이버 동시 발행분은 본문 말미 monkos.ai 원본 링크로 정본 표시(중복 콘텐츠 방어).

## 4. 품질·금지 게이트 (모든 필러 공통)

1. **기밀 게이트** (헌법 4조 3항): 내부 호칭·기술 엔진명·계정명·키·미해결 보안 사항 금지. 외부 표기 MONKOS.
2. **"되는 것만"** (헌법 4조 4항): 미출시·미확정 기능 언급 금지. 가격·기능은 현행만.
3. **실측 우선**: 수치는 실측만 인용, 추정 금지. P3는 측정 조건 명기.
4. **소재 중복 금지**: 작성 전 contents/blog/ 기존 파일 대조. 같은 키워드 재공략은 다른 앵글로만.
5. **억지 생산 금지**: 소재 품질 미달이면 그날 생략 — 양은 KPI지만 스팸은 SEO 역효과.
6. **공개 발행 금지**: 모든 생산물은 드래프트까지. 발행 게이트 = 작가님.

## 5. 측정 (PF_OPUS 성과표로 환류)

- 주간: 생산 편수(필러별), 발행 전환율(드래프트→발행), 게이트 반려 사유.
- 월간: GSC 오가닉 클릭(필러별 페이지), "증명사진 어플" 순위, AI 인용(AEO) 스냅.
- 측정 주체: 데일리 루틴(수집) + 주간 정산(웹/민아) → PF_OPUS §4 성과표 갱신.
