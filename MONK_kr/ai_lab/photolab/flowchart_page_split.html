B-3. 분석실 (result.html + result.js)

페이지 로드 + 데이터 복원

▼ 자동 진행 (또는 사용자 확인 후)
프리체크 (Gemini 3 Flash REST)
촬영본 품질 판정: 조명, 각도, 해상도, 배경 → score + suitable 판정
pipe.run('precheck', {image: base64}) → Gemini 3 Flash
▼ suitable === true
← suitable === false → 재촬영 권유 → location.href = 'camera.html'
AI 증명사진 생성 (Imagen NB3 Pro REST)
원본 base64 + style/gender/age → Imagen I2I → 생성 결과 base64
pipe.run('generate', {image, style, gender, age, userId}) → 크레딧 -1c 자동 차감
▼
QC 검증 (Gemini 3 Flash REST)
원본 vs 생성물 비교 → identity PASS/FAIL + similarity % + 품질 노트
pipe.run('qc', {original, generated, gender, age}) → Gemini 3 Flash
▼ QC PASS
← QC FAIL → 재생성 or 재촬영 선택
다운로드 결제 (크레딧 차감)
크레딧 확인 (10c 필요) → 부족 시 결제 모달 → 충분 시 차감 API → 규격 크롭
checkCredits(10) → pipe.run('creditUse', {userId, type:'download'}) → media.crop(generated, spec)
분석실에 통합
▼
수령처 이동
cropped base64를 sessionStorage에 저장 → thankyou.html로 이동
sessionStorage.setItem('monkos_cropped', dataUrl) → location.href = 'thankyou.html'

출력: monkos_cropped (base64 PNG, ~80KB) → sessionStorage

E. sessionStorage 데이터 흐름

키 타입 크기 생산 소비 비고
monkos_user JSON ~200B 준비실 (인증) 전체 기존 사용 중 (변경 없음)
monkos_style string ~10B 준비실 촬영실, 분석실 'id_photo' | 'resume'
monkos_gender string ~6B 준비실 촬영실, 분석실 'male' | 'female'
monkos_age string ~5B 준비실 촬영실, 분석실 'child' | 'teen' | 'adult'
monkos_captured base64 ~100KB 촬영실 분석실 JPEG, 720px, quality 0.8
monkos_cropped base64 ~80KB 분석실 수령처 PNG, 300dpi 규격 크롭
합계 ~200KB — sessionStorage 5MB 제한 대비 충분한 여유. 정리 시점: 옵션 N에서 "추가 촬영" 시 captured/cropped 클리어.
