# 절기(24절기) 테이블 도구 — PF_FACEREAD

사주 년주·월주 판정에 쓰는 **절기 정본** `lib/gwansang/solar-terms.json`을 취득·검증한다.

## 실행

```bash
node fetch_solar_terms.mjs [시작연도] [끝연도]   # 기본 1899~2031, 결과: ../../lib/gwansang/solar-terms.json
node verify_solar_terms.mjs                     # 3단 교차 검증. 실패 시 exit 1
```

`.cache/`에 원문 응답을 남겨 재실행 시 네트워크를 다시 타지 않는다. 값을 다시 취득하려면 `.cache/`를 비운다.

## 출처 (값 생성 금지 원칙)

- **일본 국립천문대(NAOJ, 国立天文台) 역계산실 「天象 長期版」** 공표값을 표준시 UT+9로 지정해 취득한다.
- 절기는 태양 황경이 15° 배수에 도달하는 **천문 사건**이라 관측지와 무관하고, 일본 중앙표준시와 한국 표준시가 같은 UTC+9라 취득 시각이 그대로 KST가 된다.
- [이용규정](https://eco.mtk.nao.ac.jp/koyomi/site/): 자유 이용·신고 불요, 인용 시 출처 표기 → JSON `meta.source`에 (C) NAOJ 명기.
- **계산·보간·추정으로 값을 만들지 않는다.** 취득 실패는 스크립트가 그대로 던진다(무음 폴백 없음).

## 검증 (verify_solar_terms.mjs)

| 단계 | 내용 | 2026-08-01 실측 |
|------|------|----------------|
| A | 내부 정합성 — 연도별 24건·황경 순서·절기 간격 14~16.5일 연속성 | 3192건 통과 |
| B | NAOJ **暦要項** 二十四節気 공표표 대조 (CGI와 독립 발표 경로) | 2026년 24건 전량 일치 |
| C | 홍콩천문대(HKO) Gregorian-Lunar Calendar 절기 일자표(HKT=UTC+8) 대조 | 130개 연도 2590건 일치 |

**경계 기록**: HKO 대조에서 홍콩 표준시 자정 ±15분 구간 6건이 일자 불일치 →
값 오류가 아니라 기관 간 시각 정의(표준시 채택 이력·ΔT) 차이로 보고 NAOJ 공표값을 유지한다.
이 중 월주를 가르는 節은 1917 대설·1927 백로 2건뿐이며, 나머지 4건은 中氣라 월주에 영향이 없다.
스크립트가 이 목록을 **매 실행 출력**하고 `verification-report.json`에 남긴다 (무음 금지).
