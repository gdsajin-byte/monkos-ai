# 사주 4주 엔진 검증 도구 — PF_FACEREAD

`lib/gwansang/saju.js`의 년·월·일·시 산출을 **만세력 공표값**과 대조한다.

## 실행

```bash
node verify_saju.mjs      # 15케이스 대조. 불일치 1건이라도 있으면 exit 1
```

`.cache/`에 KASI 응답을 남긴다.

## 대조원 — 한국천문연구원(KASI) 음양력 변환 공표값

`https://astro.kasi.re.kr/life/solc?yyyy=&mm=&dd=` → `LUNC_PRCN`(세차)·`LUNC_WLGN`(월건)·`LUNC_ILJIN`(일진)

⚠️ **정의 차이를 반드시 구분한다.**

| 항목 | KASI | 사주 명식 | 직접 대조 |
|------|------|----------|----------|
| 일주 | 일진 — 날짜 기준 | 동일 | ✅ 전 케이스 |
| 년주 | 세차 — **음력 해(설날)** 기준 | **입춘** 기준 | 두 기준이 합치하는 구간만 |
| 월주 | 월건 — **음력 월(삭)** 기준 | **절기(節)** 기준 | 음력 월지 == 절기 월지인 구간만 |

정의가 갈리는 구간(예: 2026-02-10 = 입춘 후·설날 전 → 사주 병오년 / KASI 세차 을사)은
**불일치가 아니라 정의 분기**이므로 사유와 함께 출력하고 실패로 세지 않는다.

## 검증 항목

1. 만세력 대조 15케이스 (1950~2026 연대 분산 + 절기 경계 5건)
2. 오호둔(년간→인월 천간)·오서둔(일간→자시 천간) 고전 규칙표 대조
3. 시주 미입력 시 `hour: null` + 사유 문구 노출 (무음 강등 금지)
4. 절기 테이블 범위 밖 생년 → `out_of_range` 명시 오류
