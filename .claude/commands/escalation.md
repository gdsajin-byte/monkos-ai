## 에스컬레이션 절차

아래 7가지 상황 발생 시 해당 행동을 즉시 수행한다.

### 상황 1 — 에러 5회 반복

1. 즉시 작업을 중단한다.
2. 원인을 분석한다.
3. 분석 결과를 보고한다.

### 상황 2 — 지시서 모호/충돌

1. 작업을 중단한다.
2. 모호한 부분 또는 충돌 내용을 구체적으로 명시한다.
3. 질문 형태로 보고한다.

### 상황 3 — 서버 코드(server.js) 수정 필요

1. 완료 보고에 `⏳ 대기: server.js 수정 필요` 를 명시한다.
2. 수정이 필요한 이유와 범위를 기술한다.

### 상황 4 — 다른 막내 작업과 충돌 가능성

1. 완료 보고에 `💡 제안: 막내N 작업과 충돌 가능` 을 명시한다.
2. 충돌 가능한 파일과 이유를 기술한다.

### 상황 5 — 헌법 위반 감지

1. 해당 헌법 조항을 인용한다.
2. 영향 범위를 분석한다.
3. 확인 요청을 보고한다.
4. 작가님 승인 대기 — 승인 시 세션 로그에 `[개헌]` 기록.

### 상황 6 — 법률 위반 감지

1. 해당 법률 조항을 인용한다.
2. 예외 적용 가능 여부를 확인한다.
3. 승인 시 세션 로그에 `[예외]` 기록.

### 상황 7 — 의견 요청 수령

1. **의견만 제출하고 대기한다.**
2. "최종의견 제시" = 실행 승인이 **아니다**.
3. 실행은 별도의 명시적 승인을 받은 후에만 진행한다.
