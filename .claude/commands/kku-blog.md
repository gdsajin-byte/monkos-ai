## 1단계 — 주제 확인 + specs 데이터 로드

1. 작가님 또는 꾸가 지정한 주제를 확인한다 (예: "미국비자사진").
2. 해당 규격의 specs-data.json 항목을 Read한다:
   ```
   monkos_AI/portal/lib/cms/specs-data.json
   ```
   - 슬러그 예: `us-visa`, `us-passport`, `korea-passport`
   - 로드 항목: size, pixels, dpi, background, headHeight, details, rejectionReasons, faqs
3. 기존 블로그 글 중복 확인:
   ```
   monkos-ops/contents/blog/
   ```

## 2단계 — 블로그 초안 작성

### 구조 (PSSR 공식)

```
[제목] — 키워드 포함, 30자 이내
[소제목] — 검색 의도 반영

1. 문제(Problem): 고객이 겪는 구체적 고통
   "미국 비자 사진, 규격 틀려서 반려당한 경험 있으신가요?"

2. 고통(Suffering): 감정적 공감
   "대사관 재방문, 시간 낭비, 비용 추가..."

3. 해결(Solution): MONKOS가 어떻게 해결하는지
   - specs 데이터에서 정확한 규격 인용
   - MONKOS 무료 크롭 / AI 서비스 자연 언급

4. 결과(Result): 성공 시나리오
   "규격 맞는 사진, 집에서 5분이면 완성"
```

### 작성 원칙

- **한 문장 24자 이하**, 간결함
- **고객이 주인공**, 브랜드는 조력자
- **가치사다리**: 인식 → 관심 → 비교 → 전환
- 규격 수치는 **specs-data.json 정본**에서 인용 (추측 금지)
- 반려 사유 TOP 5를 콘텐츠에 자연 삽입

### 네이버 SEO 최적화

- **제목**: 핵심 키워드 앞배치 ("미국비자사진 규격 2x2인치 완벽가이드")
- **소제목(H2/H3)**: 검색 의도별 분리 ("사이즈는?", "배경색은?", "반려 사유는?")
- **이미지 alt**: 키워드 포함 ("미국비자사진-규격-사이즈-2x2")
- **본문 키워드 밀도**: 2~3% (과적재 금지)
- **내부링크**: 관련 specs 페이지로 연결

### AIO(AI 검색) 최적화

- **Q&A 구조**: "미국 비자 사진 사이즈는?" → "51 × 51mm (2 × 2인치)입니다."
- **요약 문단**: 글 서두에 핵심 정보 3줄 요약 (AI 스니펫 타겟)
- **정확한 수치**: AI가 인용할 수 있는 팩트 기반 문장

### specs 페이지 연동 CTA

블로그 본문에 자연스럽게 삽입:

```
📌 미국 비자 사진 규격 상세 보기 → monkos.ai/specs/us-visa
📸 무료 AI 크롭으로 규격 맞추기 → monkos.ai/crop
```

- CTA는 본문 중간 1회 + 글 말미 1회 (과다 금지)
- "더 자세한 규격 정보는" → specs 페이지 링크
- "지금 바로 만들어보세요" → 서비스 링크

## 3단계 — 7채널 변환 가이드

블로그 원본 완성 후 파생물 가이드:

| 채널 | 변환 포인트 |
|------|------------|
| 네이버 새소식 | 핵심 3문장 + 블로그 링크 |
| 구글 게시물 | 150자 요약 + CTA 버튼 + 이미지 1장 |
| 인스타그램 | 카드뉴스 5장 (규격표+반려사유+CTA) 또는 릴스 |
| 유튜브 | 블로그 내용 → 음성 스크립트 (60초~3분) |
| 핀터레스트 | 세로 이미지 (1000×1500) + 규격 인포그래픽 |
| 페이스북 | 블로그 URL 공유 + 썸네일 + 2줄 후킹 |
| X/스레드/노트닷컴 | 작가님 축 (블로그 생성 루틴 시스템 활용) |

## 레퍼런스 인사이트 — 경쟁사 콘텐츠 전략

> 꾸가 블로그 작성 시 참고할 경쟁사 패턴. 벤치마킹 대상이지 복제 대상이 아님.

### Photo Aid (passport-photo.online) — 콘텐츠 왕

- 상세 페이지당 **3,000단어 이상** 장문 콘텐츠
- 전문가 저자 + 검증자 바이라인 (BIPP 회원 등 자격 명시)
- 미디어 신뢰 배지 (Bloomberg, NYT, Forbes, CNN)
- **사이즈 키워드 페이지** 별도 생성 (`/photo-2x2-inch`, `/photo-35x45-mm`)
- **소매점 키워드 페이지** (`/walgreens-passport-photo`) — "near me" 검색 포착
- JSON-LD 7~8개/페이지 (Article + HowTo + AggregateRating 등)
- → **시사점**: 규격 수치를 다양한 단위(inch/mm/cm/px)로 모두 나열하면 롱테일 SEO 효과

### Visafoto — 도구+정보 일체형

- 규격 정보 페이지 = 업로드 도구 페이지 (분리 안 함)
- Before/After (Source vs Result) 나란히 배치
- `/requirements` 페이지: 전 국가×문서 유형 테이블 = **대량 롱테일 SEO 허브**
- 가격은 결과 미리보기 후 공개 ("Try before buy")
- → **시사점**: 정보 읽다가 자연스럽게 도구를 사용하게 되는 동선. MONKOS specs에서도 크롭 CTA를 정보 흐름 안에 녹이기
