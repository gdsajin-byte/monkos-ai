# Git·커밋 규칙 (ch6 발췌)

## 커밋 규칙
- 브랜치: **main** 단일. develop 폐기.
- 커밋 메시지: `[카테고리] 요약` 형식.
- 카테고리 14종: `feat`, `fix`, `refactor`, `docs`, `ops`, `cleanup`, `deploy`, `sync`, `research`, `정리`, `정산`, `헌법`, `log`, `briefing`

> 파괴적 명령 금지·비밀정보 보호는 헌법 4조 1-2항에 규정. deploy.sh 경유는 ch5에 규정. 상세: governance/laws/ch6_git.md
