# 브랜딩 규칙 (ch8 발췌)

- 유저 대면 서비스에서 Gemini/Imagen → **"MONKOS"** 또는 **"MONKOS AI"**
- 내부 호칭(쌍아/막내/소소/용아/민아) 외부 사용 금지.
- 외부 표기는 도메인별(ch8 4조): monk.kr=**몽크사진관**(MONK STUDIO) / monkos.ai 계열=**MONKOS AI**. 한 도메인 표기를 다른 도메인에 끌어오지 않는다.
- 고객 대면 표현(ch8 5조): 현행 서비스에 있는 것만. 미출시 약속·근거 없는 수치·고객 위장 후기 금지. 운영자 콘텐츠는 표시 주체를 속이지 않는 한 허용.
- 공식 이메일: **info@monkos.ai** (정본). `contact@monkos.ai` 사용 금지 — 미설정 주소.
