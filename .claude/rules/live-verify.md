# 라이브 검증 규칙

> 표면이 바뀌었다는 주장은 **라이브 실측**으로만 성립한다. 커밋·배포 성공·도구 exit 0은 반영의 증거가 아니다.
> 신설 2026-08-26 (쌍아 기안, 작가님 승인). 근거: 08-24~08-26 사흘간 동일 계열 오판 3건.

## 1. 단발 조회로 판정 금지 — URL당 2회 히트

monkos.ai는 CF 엣지 워커(`monkos-portal-edge`)를 경유하며 CMS 표면은 **SWR 캐시**다.

- **URL당 첫 히트는 stale을 반환**하고 백그라운드로 재검증한다.
- **`?cb=` 같은 쿼리 버스팅은 무효** — 캐시 키가 쿼리를 무시한다. "우회했다"는 착각을 만든다.
- **유효 대조 = URL당 2회 히트.** 1차는 재검증 트리거로 버리고 **2차로 판정**한다.

```bash
curl -s -o /dev/null "$URL"      # 1차: 재검증 트리거 (판정에 쓰지 않는다)
curl -s "$URL" | grep ...        # 2차: 판정
```

> 실증: 08-26 에세이 25건 CTA·OG 반영 검증. 1회 히트 스윕은 **22건 불일치**로 나왔고 2회 히트 재측정은 **25/25 정합**이었다. 단발 조회였다면 정상 작업을 실패로 오보할 뻔했다.

## 2. 브라우저 검증 — 캐시·캡처 함정

- CDP로 배포 확인 시 **`Page.reload{ignoreCache: true}` 필수**. 캐시된 구버전을 보고 "미반영" 오판이 난다.
- `captureBeyondViewport` 캡처 시 **canvas가 빈 흰색**으로 찍힌다 → "차트 미표시" 오판. **뷰포트 캡처 + canvas 픽셀 실측**으로 판정한다.

## 3. 대조군 의무 — 0건·404·1건은 아무것도 증명하지 않는다

- **0건·404 ≠ 부재.** 조회 자체가 유효한지 **양성 대조군 1회**로 먼저 배제한다.
- **1건 ≠ 존재.** grep 히트가 CSS 규칙·주석·스크립트 문자열일 수 있다. **실물 마크업**을 확인한다.
  > 실증: 전역 CTA 판정 시 `blog-cta-card` 1건이 잡혔으나 실체는 CSS 규칙이었다(카드 마크업 0).

## 4. 상태 주장은 보고 시점에 다시 잰다

과거 턴의 실측값을 **재측정 없이 보고에 이월 금지**. 병렬 에이전트가 그 사이에 상태를 바꾼다.
> 실증: 08-26 "전역 CTA 미결" 오기 — 14:57 측정값을 15:25 보고에 이월했으나 15:00에 이미 활성화돼 있었다.

## 5. 적용 대상

배포 후 / CMS·Firestore 쓰기 후 / 설정·토글 변경 후 / 캐시 계층 너머 표면을 "반영됐다"고 보고하기 전.

> 완료 보고에 라이브 판정을 쓸 때는 **판정 방법(2회 히트·대조군)을 함께 기재**한다. 방법 없는 판정은 미검증으로 간주한다.
