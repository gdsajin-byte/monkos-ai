# Cloud Run 배포 규칙

> **법률 제5장 2조 준수. 2026-04-08 개정.**

## 브랜치

- 기본 작업 브랜치: **main** (ch6 1조). develop 폐기 상태.
- 지시서에 develop 지정 금지.

## 필수

- Cloud Run 배포는 **반드시 deploy.sh 경유**. `gcloud run deploy` / `gcloud builds submit` 직접 실행 금지.
- 지시서에 배포용 gcloud 명령을 직접 기재 금지. `./deploy.sh {env}` 형태로만 기재.
- 리전 하드코딩 금지. deploy.sh 내 REGION 변수가 정본.

## 막내 방어 의무

지시서에 배포용 gcloud 명령이 직접 기재되어 있으면:
1. 실행 전 2조 위반 보고
2. deploy.sh 경유로 전환

## 예외

- **pt.monkos.ai**: deploy.sh 미존재. gcloud 직접 배포 허용하되 지시서에 `[2조 한시적 예외: pt]` 명기. deploy.sh 제작 시 자동 소멸.
- ~~monk-n8n~~: 2026-07-24 서비스 삭제 (작가님 승인 — SPREAD 3층 구조가 대체, 30일 무트래픽·영속 자산 0 실측). 예외 조항 소멸.
- **비배포 gcloud**(describe, list, domain-mappings 등): 금지 대상 아님.

## 배포 게이트 표준 (6조, 09-02 신설)

라이브 서비스로 배포되는 모든 `deploy.sh`는 아래를 갖춘다.

| # | 게이트 | 요건 |
|---|--------|------|
| 1 | 엄격 모드 | `set -euo pipefail`. 미정의 변수는 `${VAR:-}` 명시 처리 |
| 2 | 미커밋 게이트 | **해당 서비스 디렉터리** 미커밋 시 차단(exit 1). `--yes` 시 경고 후 진행. 비TTY 무입력이 진행이 되지 않을 것 |
| 3 | 드리프트 감지 | 정적 산출물을 별도 빌드·배포하는 서비스 한정. **gitignore 산출물 해시 제외** |
| 4 | 사후 스모크 | 공개 도메인 매핑 서비스 한정. 실패 시 exit≠0. **종료는 드리프트 원장 기록 이후** |
| 5 | 이중 소스 경고 | 동일 서비스 배포 디렉터리 복수 시 배포 전 경고 |

- **무음 강등 금지** — 건너뛸 때도 그 사실을 출력. 3·4 비적용 시 주석 1행으로 사유
- 게이트 미비 배포 시 **지시서 또는 세션 로그**에 `[5장 6조 예외: 사유]`
- 유예: 게이트 1·2·5 = 발효 후 14일 / 3·4 = 60일. 신규분은 즉시

## 라이브 검증 (7조, 09-02 신설)

- **2회 히트**는 **캐시 계층 경유 GET 표면 한정**. 1차 버리고 2차로 판정. 쿼리 캐시 버스팅 무효
- **비멱등 예외**: 계측·쿼터·발송·토큰 발급 엔드포인트엔 2회 히트 금지 → 로그·DB 직접 조회로 판정
- **콜드스타트 면책**: min-instances 0 오리진의 1차 히트 지연은 실패로 계상 안 함
- **브라우저**: CDP는 `Page.reload{ignoreCache:true}` 필수. 뷰포트 캡처 + 실픽셀 확인
- **대조군 의무** (0건·404 ≠ 부재) · **재측정 의무** (과거 실측값 이월 금지) · **판정 방법 병기** (없으면 미검증)
