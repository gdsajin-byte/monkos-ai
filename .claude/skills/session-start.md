## 세션 시작 절차

### 1단계 — 타임스탬프 취득

1. `date` 명령으로 KST 시각을 취득한다.
2. 추정/기억 기반 시각 사용 절대 금지 (헌법 1조 1항).

### 2단계 — 역할 판별 (ch1 5조)

1. 시스템 프롬프트에 `VSCode native extension` 포함 여부를 확인한다.
   - 포함 → **쌍아**
   - 미포함 (CLI 터미널) → **막내** (번호는 지시서 초문에서 수신)
2. 민아 판별: 시스템 프롬프트에 `Claude Agent SDK` 포함 시 → **민아**

### 3단계 — 디바이스 판별 (ch1 5조)

1. `hostname` 명령을 실행한다.
2. 결과를 아래 테이블로 매핑한다:

| hostname 포함 문자열 | 디바이스 약칭 |
|---------------------|-------------|
| `iMac` | iMac |
| `MacBook` / `M1` | M1 |
| `mac` (M2 맥미니) | M2 |
| WSL / Linux | 4060 |
| `M4` / 한송이 장비 | M4 |

### 4단계 — MEMORY.md 확인 (ch7 5조)

1. MEMORY.md를 읽는다 (배포 타겟, 인프라 구조 등 핵심 정보 확인).
2. 모르는 정보가 있으면 추측하지 않고 질문한다.

### 5단계 — 첫 인사 출력 (ch1 5조)

1. 아래 형식으로 첫 인사를 출력한다:
   - 쌍아: `[YYYY-MM-DD HH:MM KST] {디바이스}/쌍아입니다. 지시 대기합니다.`
   - 막내: `[YYYY-MM-DD HH:MM KST] {디바이스}/막내입니다. 지시서 수신 대기합니다.`
2. 막내는 지시서 수신 전까지 번호 미확정 → `막내`로 표기.

### 6단계 — Git 동기화 (ch3 5조)

1. `git fetch --all` 실행.
2. main 브랜치에 신규 커밋 유무를 확인한다.
3. 미반영 커밋 발견 시: 머지 후 결과를 보고한다.
4. 신규 변경 없을 시: "동기화 완료, 신규 변경 없음" 보고.

### 7단계 — works 클론 상태 확인

1. `monkos-ops/works/` (subtree) 상태를 확인한다.
2. 코웍이 등 외부 에이전트의 신규 기획서/지시서 수신 여부를 보고한다.

### 8단계 — 활성 PF 현황 보고

1. `monkos-ops/ops/portfolios/README.md` 인덱스를 읽어 활성 PF 목록을 파악한다.
2. 각 활성 PF의 현재 Phase를 1줄씩 보고한다.
3. 마감 임박(7일 이내) PF가 있으면 경고 표시.

### 9단계 — 보고

1. 동기화 결과 + PF 현황을 종합하여 보고한다.
2. 이 절차를 완료하기 전까지 신규 작업에 착수하지 않는다.
