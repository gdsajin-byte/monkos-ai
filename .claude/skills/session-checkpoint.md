> 원천: ch3 3조 (세션 마감 절차 준용) + ch6 (커밋 규칙)
> 세션 마감이 아닌 중간 시점에서의 부분 정산.

## 중간 정산 절차

### 1단계 — 타임스탬프 취득

1. `date` 명령으로 KST 시각을 취득한다.

### 2단계 — 변경 상태 확인

1. `git status --short`로 미커밋 변경 파일을 확인한다.
2. `git diff --stat`으로 변경 내역을 확인한다.

### 3단계 — PF 히스토리 갱신

1. 정산 시점까지 활성 PF 대상 작업이 있었으면 히스토리 어펜드.
2. 없었으면 스킵.

### 4단계 — 월별 폴더 검증

1. 미커밋 파일 중 세션로그/보고서/지시서가 루트에 있으면 월별 폴더로 이동.

### 5단계 — 커밋

1. 관련 파일을 스테이징한다.
2. 커밋 메시지: `[정산] {날짜} 중간 정산 — {요약}`

### 6단계 — push

1. `bash scripts/mk-push.sh` 실행.
2. push 완료 확인.

### 7단계 — 상태 보고

1. 아래 형식으로 보고:

```markdown
**[YYYY-MM-DD HH:MM KST] 중간 정산 완료.**
커밋: {해시} → 푸시 완료.
오늘 커밋 이력: (최근 N건 요약)
```
