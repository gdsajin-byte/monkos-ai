# 대화록 정제·분류 맥락 묶음 v1

> 매 분류 호출에 그대로 붙이는 문서다. 대상 = 유튜브 바둑 해설 방송 30편의 자동 자막 교정본.
> **v1 입력 단위 = 발화**: 자동 자막의 `>>`(화자 전환) 자리에서 코드가 구간을 미리 쪼갰고, 6자 이하 조각은 앞 발화에 붙였다. 한 행 = 한 사람의 한 차례 말(로 추정). `seg` = 원래 자막 구간 번호.
> `sfx` = 코드가 본문에서 뺀 효과음 표기([음악]·[웃음] 등). `text`가 비고 `sfx`만 있으면 효과음 행이다(MUSIC으로 버림).
> `speaker_guess`는 목소리 높이 추정이라 **틀린 경우가 많다** — 내용으로 다시 판단한다.
> 자동 자막이라 용어가 잘못 받아 적힌 곳이 있다(예: '마늘모'→'마늘 모', '가일수'→'가수'). 문맥으로 읽는다.

## 1. 해설 원칙 (작가님 감수 1·2에서)

- 해설은 **장면 유형 이름 → 정수 vs 실전 → 무엇을 얻고 잃었나(실리·두터움·대세) → 손해(집, 그리고 집보다 큰 것)** 의 언어다.
- 활로 몇 개·단수 몇 번 같은 기계적 수읽기 설명은 '내재적 수읽기'의 영역이다 — 해설의 핵심 문장으로 치지 않는다(수순·변화도 라벨로).
- 수의 이름(껴붙임·끼워 이음·두점머리 등)과 평가(고급 행마·맥점·일감 밖)·보통 수 대비가 붙은 문장이 가장 값지다.
- 감수 예문 #1(끼워 이음 뒤 귀와 변의 바꿔치기, "귀쪽 막고 한 점을 먹는 게 변쪽 흑이 약해지고 백이 강해지면서 손해", "집보다 백이 두텁게 되어 큰 손실") · #2(껴붙임 "일반인에게 떠오르는 일감은 아니야… 백 모양을 누르는 맥점") — 전문은 `COMMENTARY_GOLD_v0.md`.

| 라벨 | 뜻 | 들어가는 것 | 경계 사례 |
|---|---|---|---|

## 3. 버림(정제) — `keep: false` + 사유 코드

| 코드 | 버리는 것 |
|---|---|
| `MUSIC` | 효과음 표기만 있는 행(text 빔), 노래 가사 |
| `AD` | 광고·협찬·구독·좋아요·후원·이벤트 참여 안내 |
| `GREET` | 인사·방송 시작/끝 진행 멘트, **다음 순서·코너 예고**("잠시 후 …에게 들어 보겠습니다") — 대회·선수 정보가 있으면 `선수대회` |
| `SCREEN` | 화면·장비·방송 사고·초읽기 안내 |

| `NOISE` | 자막이 깨져 뜻을 알 수 없음, 뜻 없는 문장 조각, 외국어 원음(통역은 남김) |

## 4. 출력 형식 (발화마다 JSON 한 줄)

```json
{"i": 17, "keep": true, "drop": null, "role": "캐스터", "label": "Q", "qa": "c0-3", "board_dep": false, "terms": ["끼우다"], "concepts": ["바꿔치기"], "note": ""}
```
- `role`: 내용으로 판단한 화자(`캐스터`/`해설`/`선수`/`불명`). `qa`: 묶음 안 번호 문자열(예 "c0-3"), 없으면 null.
- `board_dep`(v1 신설, 쌍아 ⑦): 이 발화가 **판을 손으로 가리키는 지시어**(이렇게·이런 데·여기·이쪽·이 돌·요기 등)에 기대어 뜻이 통하면 `true`. 판 없이 글로만 읽어도 뜻이 서면 `false`. `국면`·`수순`·`A`에 특히 꼼꼼히. (판독 없는 영상에서 `board_dep: true` 문장은 장면 해설 예문이 아니라 말투 자료로만 쓴다.)
- `terms`: 아래 용어 사전(분류 1~7)의 **모양·수 이름**이 이 발화에서 바둑 용어로 쓰였을 때만, 표제어로 정규화('끊어서'→'끊다'). **넓은 말은 terms에 넣지 않는다**: 계가 · 공격 · 공배 · 끝내기 · 모양 · 사활 · 살다 · 수상전 · 수읽기 · 압박 · 잡다 · 정석 · 죽다 · 포석 · 행마. 이런 말이 평가로 쓰였으면 `concepts`로.
- `concepts`: 분류 8(개념) + 위 넓은 말 중 평가로 쓰인 것. **'선수' 주의**: "○○ 선수", "선수가", "당장 선수의 시선"처럼 **사람(대국자)** 을 가리키면 개념 '선수(先手)'가 아니다 — 넣지 않는다. 先手 뜻(상대가 받아야 하는 수)일 때만.
- `keep: false`면 `label`·`qa`는 null, `drop`에 코드.
