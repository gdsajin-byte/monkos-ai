# 법률 제2장: 코딩 규칙

> 상위 헌법: 제3조(프로젝트 정체성), 제6조(인프라 보호)
> 변경 권한: 작가님 승인 시 개정 가능

---

### 1조: 기술 스택

- 순수 JavaScript, async/await 패턴.
- 프레임워크 미사용 (순수 HTML, CSS, JS).

> 근거: 프로젝트 초기~현재 일관. 2026-01 ~ 02-08 CLAUDE.md 초기 규칙.
> 상위 헌법: 제3조(프로젝트 정체성 — 기술 철학)
> 위반 시: 프레임워크 혼재, 유지보수 비용 증가, 에이전트 간 코드 스타일 불일치
> 예외: 작가님 승인 시 변경 가능 (JS→TS 등)

---

### 2조: 네이밍 규칙

| 대상 | 규칙 |
|------|------|
| HTML/CSS | `kebab-case` |
| JavaScript | `camelCase` |
| 파일명 | `snake_case` |

> 근거: 2026-01 ~ 02-08 — CLAUDE.md 초기 규칙. 프로젝트 전반 일관 적용.
> 상위 헌법: 제3조
> 위반 시: 코드 검색/참조 실패, 에이전트 간 네이밍 혼동
> 예외: 외부 라이브러리 컨벤션 우선

### 3조: 언어 규칙

- **한국어 우선** (UI, 주석, 에러 메시지, 커밋 메시지).
- 일본 서비스(idphoto-jp)는 일본어 UI.

> 근거: 2026-01 ~ 02-08 — CLAUDE.md 초기 규칙. 프로젝트 초기 결정.
> 상위 헌법: 제3조(한국어 기본, 다국어 지원 EN/JA/ZH)
> 위반 시: 다국어 UI 혼재, 유저/에이전트 혼란
