# ch1 5조 민아 판별 키워드 실측 수정 청구안

> **[2026-04-09 11:21 KST] iMac/민아 → 작가님 (청구안)**

---

## 1. 현상

민아가 워크트리 환경에서 매 세션 자기 역할을 인식하지 못하고 쌍아로 자칭하는 문제가 **반복** 발생.
작가님이 여러 차례 직접 지적하셨으나 근본 해결되지 않음.

## 2. 근본원인 — 3중 실패

### 2-1. 법률 1차 판별 실패 (ch1 5조)

선행 청구안(PETITION_20260324)에서 민아 판별 조건이 신설되었으나, 키워드가 **실측 검증 없이** 채택됨.

| 항목 | 내용 |
|------|------|
| 현행 조건 | 시스템 프롬프트에 `Claude Agent SDK` 포함 |
| 실측 결과 | Desktop App 시스템 프롬프트에 `Claude Agent SDK` **미존재** |
| 5조 단서 | "실측 확인 전 잠정 적용. 미매칭 시 MEMORY.md 폴백" |
| 결론 | **1차 판별 항상 실패** → 폴백 발동 |

### 2-2. MEMORY.md 2차 폴백 실패

| 항목 | 내용 |
|------|------|
| 현행 조건 | CWD가 `.claude/worktrees/` 하위 |
| 실측 | 워크트리 경로는 `monk_project/{랜덤명}/` 등 다양 |
| 결론 | **경로 한정 너무 좁아 매칭 실패** |

### 2-3. 시스템 시그널 미활용

Desktop App이 워크트리를 자동 생성하면, 시스템 메타데이터에 다음이 **매 세션 명시적으로** 포함됨:

```
You are operating in a git worktree.
Worktree path: /Users/.../elastic-meninsky
Worktree name: elastic-meninsky
```

이 시그널을 판별 조건으로 활용하는 규칙이 법률에도 MEMORY에도 없음.

### 실패 흐름도

```
세션 시작
  ├─ 5조 1단계: "Claude Agent SDK" 검색 → 미존재 → MISS
  ├─ 5조 단서: MEMORY 폴백 → ".claude/worktrees/" 매칭? → 아님 → MISS
  ├─ "그 외" → 막내? → 지시서 없고 대화형 → 쌍아로 오인
  └─ "You are operating in a git worktree" → 규칙 없음 → 무시
```

## 3. 개정안

### 3-1. ch1 5조 1단계 역할 판별 테이블

**현행:**

| 조건 | 역할 |
|------|------|
| 시스템 프롬프트에 `VSCode native extension` 포함 | 쌍아 |
| 시스템 프롬프트에 `Claude Agent SDK` 포함 | 민아 |
| 그 외 (CLI 터미널) | 막내 |

**개정안:**

| 조건 | 역할 |
|------|------|
| 시스템 프롬프트에 `VSCode native extension` 포함 | **쌍아** |
| 시스템 메타데이터에 `You are operating in a git worktree` 포함 | **민아** |
| 그 외 (CLI 터미널, worktree 없음) | **막내** |

변경점:
- `Claude Agent SDK` → `You are operating in a git worktree` (실측 시그널로 교체)
- "잠정 적용" 단서 삭제 (실측 완료)
- 민아/코웍이 구분: 기존 운용대로 기본값 민아, 작가님 명시 시 코웍이 (변경 없음)

### 3-2. MEMORY.md 역할 자동 인식 섹션

**현행:**
```
- 시스템 프롬프트에 `VSCode native extension` → 쌍아
- CWD가 worktree 경로 (.claude/worktrees/ 하위 자동 생성) → 민아
- 그 외 (CLI 터미널, worktree 없음) → 막내
```

**개정안:**
```
- 시스템 프롬프트에 `VSCode native extension` → 쌍아
- 시스템 메타데이터에 `You are operating in a git worktree` → 민아 (경로 무관, 워크트리면 민아)
- 그 외 (CLI 터미널, worktree 없음) → 막내
```

### 3-3. 5조 부기 삭제

현행 5조 하단의 다음 단서를 삭제:
