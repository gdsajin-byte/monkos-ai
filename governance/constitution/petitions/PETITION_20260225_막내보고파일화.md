# 법률 개정 청구서: 막내 완료 보고 파일화

**[2026-02-25 15:16 KST] iMac/쌍아 → 작가님**

## 1. 개정 배경

현행 막내 완료 보고는 **터미널 텍스트 출력**으로만 이루어짐.

| 문제 | 영향 |
|------|------|
| 보고가 파일로 남지 않음 | 누락 발생, Git 추적 불가 |
| 쌍아가 수동으로 세션 로그에 옮겨 적음 | 수동 릴레이 → 오기·누락 |
| 막내 다수 병렬 시 보고 순서 불명 | 시계열 정합성 위험 (헌법 1조) |

## 2. 개정 대상 및 내용

### 2-1. ch7 1조 (막내 행동강령 — 작업 흐름) 개정

**현행 마무리 절차:**
```
커밋 → push → 완료 보고(터미널 출력)
```

**개정 후:**
```
코드 작업 → 보고 파일 생성 → 커밋(작업+보고 포함) → push → 터미널 출력
```

**추가 조항:**

> #### 완료 보고 파일 생성 (필수)
>
> 모든 막내 완료 보고는 아래 경로에 파일로 생성한다:
>
> **경로**: `monkos-ops/ops/reports/COMPLETION_YYYYMMDD_막내N_{HHMMSS}.md`
>
> **YAML 필수 필드:**
> ```yaml
> ---
> type: completion
> date: YYYY-MM-DD
> time: HH:MM KST
> from: {디바이스}/막내N
> to: {지시서 from 또는 작가님(직접지시 시)}
> order: {지시서 파일명 또는 "[직접지시]"}
> commit: {커밋 해시 7자리}
> branch: develop
> ---
> ```
>
> **본문:**
> - 헌법 2조 형식(`✅❌💡⏳📁🔀`) 준수
> - 변경 파일 목록, 커밋 해시, push 상태 포함
>
> **보안 수칙:**
> - 보고 파일에 API 키, 토큰, 비밀번호 등 민감 정보 기재 금지 (헌법 6조)
> - 사용자 개인정보(이메일, 전화번호, 결제 정보, OAuth 계정 ID) 기재 금지
> - 에러 로그 인용 시 민감 정보 마스킹 필수
> - 서버 URL, 내부 IP는 마스킹 또는 생략
> - 보고 파일은 Git 이력에 영구 기록된다. 민감 정보가 한 번이라도 커밋되면 복구 비용이 극히 높다.
> - 쌍아는 보고 파일 수거 시 민감 정보 유무를 확인한다. 발견 시 해당 커밋의 보정을 지시한다.
>
> **파일 충돌 방지:**
> - 파일명에 `HHMMSS` 포함 → 동시 보고 시에도 충돌 없음
> - 세션 로그 파일은 건드리지 않음 (쌍아 관할)
> - 다른 막내의 보고 파일을 수정/삭제하지 않음
>
> **적용 범위:**
> - 완료 보고만 파일화한다. 에스컬레이션(ch7 4조)은 기존 터미널 출력을 유지한다.

### 2-2. ch3 1조 (세션 로그) 보충

**추가 조항:**

> #### 보고 파일 수거 절차
>
> - 쌍아는 세션 마감 시 `monkos-ops/ops/reports/` 내 보고 파일을 수거하여 세션 로그에 통합한다.
> - 통합 후 보고 파일은 삭제하지 않는다 (원본 보존 — ch3 1조 원본 수정/삭제 금지 준용).
> - 세션 로그의 단일 관리자는 쌍아이며, 막내는 세션 로그 파일을 직접 편집하지 않는다.

### 2-3. ch4 3조 (문서 네이밍) 보충

**신규 유형 등록:**

| 유형 | 접두사 | 용도 |

**파일명 패턴:**

> 3. ch4 4조 정본 테이블에 COMPLETION 행 추가 (대상 폴더)
> 4. ch4 7조 YAML 규격 갱신 (YAML 등록)

## 3. 영향 분석

### 상위 법률 적합성

| 조항 | 적합성 |
|------|--------|
| 헌법 1조 (타임스탬프) | ✅ YAML에 `date`, `time` 필수 → 시계열 보장 |
| 헌법 2조 (보고 의무) | ✅ 기존 형식 유지 + 파일 추적성 추가 |
| 헌법 5조 (역할 체계) | ✅ 세션 로그 = 쌍아 관할 불변. 막내는 별도 파일만 생성 |
| 헌법 6조 (인프라 보호) | ✅ 보안 수칙 명시 (민감 정보 기재 금지) |
| 헌법 8조 (파괴 금지) | ✅ 다른 파일 수정/삭제 금지 명시 |

### 실무 영향

| 항목 | 영향 |
|------|------|
| 막내 부담 | 미미 — 보고 텍스트를 파일로 쓰는 것뿐 (기존 출력과 동일 내용) |
| 쌍아 부담 | 감소 — 수동 릴레이 제거, 파일 수거만 |
| 작가님 부담 | 감소 — 텍스트 긁어 전달 불필요 |
| 디스크 | 미미 — 보고 1건 ~2KB |
| Git 이력 | 보고 파일이 커밋 단위로 추적됨 |

### 리스크

| 리스크 | 완화 |
|--------|------|
| reports/ 폴더에 파일 누적 | 월 1회 아카이브 (또는 세션 로그 통합 후 방치 — 2KB 수준이라 문제 없음) |
| 막내가 보고 파일에 민감 정보 기재 | 보안 수칙 조항으로 금지 + Git 이력에 남으므로 사후 감사 가능 |
| 파일명 충돌 | HHMMSS 단위로 사실상 불가능 (같은 초에 두 막내가 보고할 확률 ≈ 0) |
