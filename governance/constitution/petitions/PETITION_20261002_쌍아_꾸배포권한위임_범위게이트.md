## 3. 설계 — 범위 게이트 (G-K)

### 3.1 판정 위치: 워크플로 스텝 (쟁점 J1)

- `deploy-monk-kr.yml`에 입력 `approver`(`작가님`|`꾸`, 기본값 `작가님`)를 추가한다.
- `approver=꾸`이면 **배포 스텝 앞에서** 범위 게이트를 돈다. 범위 밖이면 `exit 1` → 배포하지 않는다.
- 비교 기준(base)은 **직전 production 배포 커밋**이다. 출처는 CF Pages deployment 메타데이터(`wrangler pages deployment list` → 소스 커밋)를 1순위로, 직전 성공 run의 배포 커밋 기록을 2순위로 한다.
  - base를 구할 수 없으면 범위 밖으로 판정한다(fail-closed).
  - 직전 배포 이후 작가님 승인 없이 쌓인 커밋까지 포함해 base..target 전체를 본다. 범위 안 커밋에 범위 밖 커밋이 끼어 따라 나가는 것을 막기 위해서다.
- 판정을 M2 세션 스크립트가 아니라 러너에서 하는 이유는 판단 분리(ch1 1조) 때문이다. 만든 세션이 스스로 판정하지 않는다. 스크립트 사전 점검(`--dry-run`)은 M2 쌍아의 편의 도구로만 허용한다.

### 3.3 승인 인정 (쟁점 J2)

- **꾸의 승인 = M2 고정 세션에서 꾸가 입력한 턴의 "배포 승인"**이다. ch1 7조 2항의 사용자 턴 정의를 그대로 따르고, E10 토큰은 같은 훅이 발급한다.
- **꾸 턴과 작가님 원격 턴은 구분하지 않는다.** 이 위임은 "꾸가 승인할 수 있다"를 더할 뿐이다. 작가님 턴은 원래부터 상위 승인이다. 사유 서식의 `{주체}`에 `꾸` 또는 `작가님`을 적고, 이는 흔적으로만 쓰인다(ch5 1조 3항 한계 조문 승계).
- **선결 결함 (§6 P1)**: 10-02 14:58과 17:00, 두 번 확인됐다. 세션 간 메시지 본문에 "배포…승인" 패턴이 있으면 UserPromptSubmit 훅이 이를 사용자 턴으로 보고 E10 토큰을 발급한다(iMac 쌍아 세션 실측, 토큰 note에 `<cross-session-message` 원문이 남음). 같은 결함이 붙여넣기 본문(10-01 토큰 2건)에서도 났다. 꾸 경로는 M2에 쌍아 세션이 여럿이고 세션 간 메시지가 오가는 표면이라, **이 결함을 고치기 전에는 발효하지 않는다.**
- 같은 세션의 팀원·서브에이전트는 리드와 session_id를 공유한다(10-01·10-02 실측). 그래서 E10 토큰도 공유된다. 꾸 경로에서 배포를 트리거하는 것은 **M2 고정 세션의 본체 턴만** 한다. 서브에이전트·팀원에게는 배포 명령을 맡기지 않는다(조문).

### 3.4 1회 승인 = 1회 트리거 (쟁점 J3)

- **유지한다.** 범위 안에서도 묶음 승인은 두지 않는다. 묶음이 필요한 경우는 이미 "직전 배포 이후 누적분 1회 배포"로 충족된다(§3.1 base..target). 지금 막혀 있는 것은 승인의 횟수가 아니라 **승인자가 한 명이라는 점**이었다.

### 3.5 사후 보고 (쟁점 J4)

- 꾸 승인 run이 끝나면 워크플로가 기존 텔레그램 경로(`notify.yml` workflow_call)로 작가님에게 1줄을 보낸다. 내용은 `[꾸 배포] run {id} · {sha8} · 변경 {n}파일 · 사유 {…} · 범위 게이트 통과` 서식이다.
- **워크플로가 자동으로 보내므로 미보고는 구조적으로 생기지 않는다.** 알림 스텝이 실패하면 run을 실패로 표기한다. 이때 배포 반영 표는 그대로 남는다(ch5 1조 8항 준용). M2 쌍아 세션 로그에 run ID·SHA·승인 시각을 적는 것은 현행 4항 그대로다.

### 3.6 롤백 (쟁점 J5)

- **꾸 승인으로 하는 롤백을 허용한다. 단, 대상은 직전 꾸 승인 배포가 덮어쓴 그 base 커밋 하나다.**
  - 워크플로: `approver=꾸`이고 `sha`를 지정한 경우, `sha`가 직전 production 배포의 base와 일치할 때만 통과시킨다.
  - 이것은 "방금 꾸 승인으로 나간 것을 되돌리는 것"이라 범위를 넓히지 않는다. 그 밖의 SHA 지정은 범위 밖으로 판정한다.
- **발효 전에 롤백(`sha` 입력)을 1회 실증한다** (§6 P3, 민아 조건 ②, ch5 1조 부칙 미실증 항목).

### 3.8 M2 트리거 세션 고정 (민아 조건 ③)
