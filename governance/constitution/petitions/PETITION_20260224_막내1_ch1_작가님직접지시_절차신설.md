# 법률 개정 청구서 — ch1 「작가님 직접 지시 수령 절차」 신설

> **발견 경위**: 작가님이 유휴 막내에게 직접 지시하는 상황에서 법적 형식 근거 부재를 확인 (2026-02-24 02:24~02:32 세션 내 검토)

## 1. 문제

### 현행 ch1 2조 (핵심 흐름)

```
쌍아(설계/지시서) → 작가님이 막내에게 토스 → 막내 자율 실행 → 완료 보고
```

이 흐름은 **쌍아가 지시서를 발행하는 경로만 규정**한다.

### 작가님 직접 지시 시 공백

| 항목 | 지시서 경로 (현행 규정 있음) | 직접 지시 (규정 없음) |
|------|---------------------------|---------------------|
| 지시 헤더 | 쌍아가 작성 (ch1 3조) | **누가 작성하는지 미규정** |
| 역할 선언 | 지시서 초문에 포함 (ch1 3조) | **형식 미규정** |
| 엔드라인 | 지시서에 명시 (ch1 3조) | **기준 미규정** |
| 추적성 | 지시서(.md) 파일 존재 | **기록 의무 미규정** |

### 실무 영향

- 쌍아가 다른 업무에 바쁠 때 작가님이 유휴 막내에게 직접 지시하는 것은 **운용상 당연한 시나리오**
- 현행법은 이 경로에 형식을 부여하지 않아, 막내가 지시를 수령해도 **절차 근거가 없는 상태로 작업**하게 됨
- 작가님의 질문·지시 자체가 "위법 아닌가"라는 해석 여지가 생기는 것은 법의 결함

## 2. 개정안

### ch1에 신설: 「작가님 직접 지시 수령 절차」

> **작가님이 쌍아를 경유하지 않고 막내에게 직접 지시할 경우, 막내는 수령 즉시 아래 절차를 이행한다.**

**① 지시 기록 작성**

막내가 수령 즉시, 세션 내에 아래 형식으로 지시 기록을 남긴다:

```
[YYYY-MM-DD HH:MM KST] 작가님 직접지시 → {디바이스}/막내N 수령
지시 내용: {1~2줄 요약}
```

**② 사전 적합성 검토**

CLAUDE.md 대응 프로토콜과 동일 — 헌법·법률 충돌 여부를 검토한다. 이 의무는 지시서 경로와 차이 없다.

**③ 계획 제시 → 승인 → 실행**

헌법 제7조(응답 규칙)와 동일하게 적용한다.

**④ 엔드라인 확인**

지시서에 엔드라인이 명시되지 않으므로, 막내가 작가님에게 마무리 범위를 확인한다. 작가님이 별도 지정하지 않으면 기본값은 `커밋+push`로 한다.

**⑤ 완료 보고**

헌법 제2조 형식으로 보고한다. 수신자는 작가님.

### 위치

ch1 2조(핵심 흐름) 하단에 **2조의2** 또는 **2조 단서** 형태로 삽입.

기존 ch1 2조(쌍아 지시서 경로)를 **대체하지 않고 보충**한다.

## 3. 작가님 합의 사항

본 청구는 작가님과의 직접 논의에서 도출되었다.

| 시각 (KST) | 발화자 | 내용 |
|------------|--------|------|
| 02:24 | 작가님 | "작가가 막내에게 직접 지시할 케이스에 대한 법적 근거와 절차를 설명하라" |
| 02:27 | 막내1 | 현행법 분석 — 권한은 있으나 절차 규격이 없음을 보고 |
| 02:30 | 작가님 | "법적으로는 문제없으나 형식을 갖출 근거가 부족하다는 논제" — 문제 정의 확인 |
| 02:32 | 막내1 | 해법 제시 — 막내가 수령 즉시 지시 헤더를 자체 작성하면 추적성 확보 |
| 02:33 | 작가님 | "쌍아가 바쁠때 유휴 막내에게 직접 지시할 경우 질문할 경우가 위법이면 안되잖아" — **운용상 당연한 시나리오임을 확인** |
| 02:34 | 작가님 | "너의 명의로 개정 청구안을 제출하고 내용과 나의 합의점을 동시 제시하라" — **청구 승인** |

### 합의점 요약

1. 작가님 → 막내 직접 지시는 **운용상 당연한 경로**이며 법이 이를 수용해야 한다
2. 막내가 수령 즉시 **지시 기록을 자체 작성**함으로써 추적성을 확보한다
3. 이후 절차(적합성 검토, 실행, 보고)는 **지시서 수령과 완전 동일**하다
4. 기존 ch1 2조(쌍아 지시서 경로)를 대체하지 않고 **보충**한다
