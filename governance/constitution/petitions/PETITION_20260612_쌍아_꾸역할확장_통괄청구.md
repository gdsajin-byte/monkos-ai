# 통괄 청구안: 꾸 역할 확장 — 콘텐츠/마케팅 + specs 디자인 권한 편입

> **[2026-06-12 13:12 KST] iMac/쌍아 → 작가님**

---

## 1. 청구 사유

### 1-1. 현행

꾸는 2026-02-22 팀원 에이전트 카테고리 신설 시 편입되었으나, 역할이 **"생활/업무 자동화"**로만 정의되어 있다. 2026-06-12 작가님 직접 지시로 다음이 확정되었으나 헌법·법률에 미반영:

- 네이버 블로그 원본 생산 축 담당
- monkos.ai/specs 페이지 디자인 권한
- 7채널 멀티배포 루틴 운영
- M2/쌍아와의 2축 분업 구조

### 1-2. 문제

| 현상 | 원인 | 피해 |
|------|------|------|
| 타 에이전트가 꾸의 권한 범위를 모름 | 헌법 1조 2항에 꾸 없음 | specs 작업 시 권한 충돌 가능 |
| M2/쌍아 협업 구조 미명시 | ch1에 "생활/업무 자동화"만 | 막내가 specs 수정 시 꾸 작업과 겹칠 수 있음 |
| PF_KKU와 PF_SPECS 간 역할 경계 불명확 | 법률에 꾸의 specs 접근 범위 미규정 | 데이터 정합성 리스크 |

### 1-3. 해결

꾸의 역할을 "생활/업무 자동화" → **"콘텐츠/마케팅 + specs 콘텐츠 디자인"**으로 확장하고, 헌법·법률·규정에 일괄 반영한다.
