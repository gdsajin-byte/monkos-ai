### 2. settings.json deny 이동 충돌 검증

**현행 상태:**

| 파일 | Git 추적 | 내용 |
|------|---------|------|
| `.claude/settings.json` | O (공유) | allow 2건 (`Bash(dir:*)`, `Bash(gsutil ls:*)`) |
| `.claude/settings.local.json` | X (로컬) | allow 54건 + deny 5건 + additionalDirectories 1건 |

**이동 대상 deny 5건:**
```
Bash(rm -rf /*)
Bash(git push --force *)
Bash(git reset --hard *)
Bash(format *)
Bash(del /s /q C:*)
```

**충돌 분석:**

- Anthropic 공식 문서에 따르면 배열 값은 **병합(concat + dedup)** 된다. deny 규칙은 allow 규칙보다 우선한다.
- 현재 settings.json의 allow 2건(`dir:*`, `gsutil ls:*`)은 deny 대상 명령과 겹치지 않는다.
- settings.local.json의 allow 54건 중에도 deny 대상과 직접 충돌하는 패턴은 없다:
  - `Bash(git *)`: allow이지만 `Bash(git push --force *)`는 deny가 우선하여 차단됨. ✅ 의도한 동작.
  - 나머지 allow 패턴은 deny 5건과 무관.

**타 디바이스 영향:**

| 디바이스 | 영향 | 비고 |
|----------|------|------|
| M1 | 긍정적 — 동일 deny 규칙 자동 적용 | git pull 시 즉시 반영 |
| M2 (꾸) | 긍정적 — 파괴적 명령 보호 | 꾸 환경에도 안전망 |
| M4 (한) | 긍정적 — 파괴적 명령 보호 | 한 환경에도 안전망 |
| 4060 | 긍정적 | Windows 명령(`format`, `del`)도 포함 |

- `format *`과 `del /s /q C:*`는 Windows 전용이라 Mac에서 무의미하지만, **해가 없으며** 4060(Windows)에서는 필수 보호.

**결론**: 충돌 없음. 타 디바이스에 **긍정적** 영향만 존재. 헌법 4조의 기술적 강제력이 전 디바이스로 확대되므로 **적합.** ✅

### 4. ch1 5조 민아 행 추가 — `Claude Agent SDK` 키워드 검증

**현행 ch1 5조 세션 자동 인식:**

| 조건 | 역할 |
|------|------|
| 시스템 프롬프트에 `VSCode native extension` | 쌍아 |
| 그 외 (CLI) | 막내 |

**청구안 추가:**

| 조건 | 역할 |
|------|------|
| 시스템 프롬프트에 `Claude Agent SDK` | 민아 (신설) |

**검증 결과: ⚠️ 리스크 존재**

1. **`Claude Agent SDK`는 Claude Desktop App의 시스템 프롬프트에 포함되는 문자열이 아닐 수 있다.** Claude Agent SDK는 커스텀 에이전트 빌딩용 SDK로, Anthropic Desktop App(Claude for Desktop)과는 별개 제품이다.

2. **현재 검증 가능한 환경 문자열:**
   - CLI: `"Claude Code, Anthropic's official CLI for Claude"` — 현재 내 시스템 프롬프트에 포함 확인
   - VSCode: `VSCode native extension` — 쌍아 환경에서 확인 이력 있음
   - Desktop App: 미검증 — 민아 환경에서 어떤 문자열이 포함되는지 실측 데이터 없음

3. **미포함 시 대안:**
   - **대안 A**: `.claude/agents/mina.md` 서브에이전트 정의 + `claude --agent mina` 명령으로 실행. 시스템 프롬프트 의존 제거.
   - **대안 B**: `hostname` + 실행 환경 조합 판별. 민아가 고정 디바이스에서만 실행된다면 가능.
   - **대안 C**: 작가님이 민아 세션 시작 시 수동 선언 (`"민아 세션 시작"`). 가장 단순하나 자동 인식 원칙 위배.

**보정 조건 (필수):**
- 민아 환경(Anthropic Desktop App 또는 Claude Code Desktop)에서 **실제 시스템 프롬프트에 포함되는 식별 문자열을 실측**한 후, ch1 5조 조건을 확정해야 한다.
- 실측 전까지는 `Claude Agent SDK`를 **잠정 키워드**로 표기하고, 실측 후 보정하는 2단계 시행을 권고한다.
- 대안으로 `.claude/agents/mina.md` 서브에이전트 파일 생성 + `--agent` 플래그 방식 병행을 강력 권고한다. 이 방식은 시스템 프롬프트 의존 없이 역할을 확정할 수 있어 가장 견고하다.

**결론**: 키워드 실측 미완료. **보정 조건 1/3.** ⚠️
