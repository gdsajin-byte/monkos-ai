## 2. 블로그 에디터 UI 개선

현재 에디터 엔진: **Toast UI Editor** (ProseMirror 기반) 확인됨.

### 문제점
- 메타 정보 입력 영역(Title, Slug, Summary, Category, Tags, Thumbnail)이 화면 절반 이상 차지
- 정작 Content 에디터 영역이 너무 작아 스크롤해야 본문 보임
- 글쓰기 집중이 안 되는 구조

### 개선안
- **메타 정보 → 접을 수 있는 패널**(기본 접힘) 또는 **우측 사이드바**로 분리
- Content 에디터 영역 최대 확보 (min-height: 70vh)
- `WYSIWYG` 라벨 → **미리보기**로 변경 (비개발자 UX)

## 4. 어드민 홈 레이아웃 매니저

작가님 요구사항: 어드민에서 포털 홈 섹션 배치를 관리하고 싶다.

### 기능 범위 (레벨 2 합의)
1. **섹션 표시/숨김 토글** (ON/OFF)
2. **섹션 순서 변경** (위/아래 화살표)
3. **카드 사이즈 프리셋** (S / M / L)
4. **배치 영역 선택** (좌측 사이드바 / 메인 중앙 / 우측 사이드바)
- 자유 좌표 배치는 불필요 (합의)

### 데이터 구조 설계안

```json
{
  "sections": [
    { "id": "hero",        "visible": true,  "column": "center", "size": "L", "order": 1 },
    { "id": "beforeAfter", "visible": true,  "column": "center", "size": "M", "order": 2 },
    { "id": "magazine",    "visible": true,  "column": "left",   "size": "M", "order": 3 },
    { "id": "blog",        "visible": true,  "column": "center", "size": "M", "order": 4 },
    { "id": "guide",       "visible": true,  "column": "right",  "size": "S", "order": 5 },
    { "id": "credit",      "visible": true,  "column": "right",  "size": "S", "order": 6 },
    { "id": "tags",        "visible": true,  "column": "left",   "size": "S", "order": 7 }
  ]
}
```

### 구현 방향
- 어드민에 레이아웃 관리 페이지 추가
- 테이블 형태: 섹션명 | 표시 토글 | 컬럼 드롭다운 | 사이즈 드롭다운 | 순서 화살표
- JSON config를 DB(또는 GCS)에 저장
- 프론트(홈)에서 config 읽어서 렌더링 순서·컬럼·사이즈 반영
- 예상 공수: 1~2일
