## 수정 지시

### [Task 1] `render.js` — 카드 렌더 시 링크 정보 삽입

대상: `/lib/cms/render.js`

**블로그/매거진 카드 렌더 함수**에서 카드 루트 엘리먼트에 `data-slug` 또는 `data-url` 추가.

```js
// 예시 — 블로그 카드
`<div class="blog-card" data-slug="${post.slug}" data-lang="${post.lang}">...</div>`

// 예시 — 매거진 카드 (mag-card)
`<div class="mag-card" data-slug="${item.slug}">...</div>`
```

또는 카드 전체를 `<a href="/blog/${slug}">` 로 래핑하는 방식도 가능. 기존 v3 방식 확인 후 통일.

> **확인 필요**: `backup/v3/index.html` 에서 v3가 카드를 어떻게 렌더했는지 참고할 것.

### [Task 2] `main.js` — 카드 클릭 이벤트 리스너 추가

대상: `/public/js/main.js`

`DOMContentLoaded` 블록 안에 아래 이벤트 리스너 추가:

```js
// 매거진 카드 (사이드바)
document.querySelectorAll('.mag-card').forEach(function(card) {
  card.addEventListener('click', function() {
    var slug = card.dataset.slug;
    if (slug) window.location.href = '/blog/' + slug;
  });
});

// 블로그 카드 (홈 최근 블로그 섹션)
document.querySelectorAll('.blog-list .post-item, .blog-list [data-slug]').forEach(function(card) {
  card.addEventListener('click', function() {
    var slug = card.dataset.slug;
    var lang = card.dataset.lang || 'ko';
    if (slug) window.location.href = (lang !== 'ko' ? '/' + lang : '') + '/blog/' + slug;
  });
});
```

> **주의**: 실제 클래스명은 v3 백업 및 render.js 출력 HTML 기준으로 맞출 것. 위 코드는 방향 가이드.
