## 2. 확정 기준값

### 2-1. 레이아웃 그리드

```css
/* site-wrapper: 모든 것을 감싸는 박스 */
.site-wrapper {
  max-width: 1280px;   /* 기존 v3 유지 */
  margin: 0 auto;
}

/* 3컬럼 그리드 */
.layout {
  display: grid;
  grid-template-columns: 260px 1fr 260px;  /* 기존 200/180 → 260/260 균등으로 변경 */
}
```

**변경 전 v3:** `200px 1fr 180px` (비대칭)
**확정 v4:** `260px 1fr 260px` (균등)
**메인 최대:** 1280 - 260 - 260 = **760px**

### 2-2. site-wrapper 개념 (핵심 설계 결정)

- **헤더 포함 전체**가 `site-wrapper` 안에 들어간다
- max-width 박스 밖은 body 배경색/이미지만 표시
- 헤더는 wrapper 안에서 풀블리드 (viewport 기준 아님)
- 이유: 사이드바가 좁은데 헤더만 풀뷰포트로 늘어나면 T자 실루엣 문제 발생

```
[body background ← 외부 여백 →][site-wrapper 1280px][← 외부 여백 → body background]
 └─ 내부 구조:
    ├── site-header     (wrapper 안 100%)
    ├── photo-strip     (wrapper 안 100%)
    ├── site-nav        (wrapper 안 100%)
    └── .layout grid    (260px | 1fr | 260px)
```

### 2-3. 좌측 사이드바 카드 비율

```css
/* 기존 v3 */
.mag-img { height: 100px; }  /* ← 하드코딩, 교체 필요 */

/* v4 교체값 */
.mag-img {
  width: 100%;
  aspect-ratio: 200 / 105;  /* OGP 1.91:1 — 모든 SNS 대응 최적값 */
}
```

- 패딩 12px×2 = 24px 적용 시 카드 실제 크기: **236 × 124px**

### 2-4. 우측 사이드바 썸네일

- 비율: 어드민에서 제어 (9:16 기본값)
- 고정하지 않음 — 올리는 콘텐츠에 따라 결정
- 컨테이너: `aspect-ratio` CSS로 잡고 `object-fit: cover`

### 2-5. 브레이크포인트

```css
@media (max-width: 1024px) {
  .layout { grid-template-columns: 0 1fr 260px; }
  .sidebar-left { display: none; }  /* → 서랍(스와이프) 전환 */
}
@media (max-width: 768px) {
  .layout { grid-template-columns: 1fr; }
  .sidebar-left, .sidebar-right { display: none; }  /* → 양측 서랍 전환 */
}
```

## 3. 블록 에디터 아키텍처 (핵심 방향 결정)

### 3-1. 개념

네이버 블로그 블록 에디팅과 동일한 구조.
완전 자유 에디터(Gutenberg급) 아님 — **슬롯 고정 + 블록 타입 선택** 방식.
"자석판에 블록 붙이기" 메타포.

### 3-2. 슬롯 구조

```
site-wrapper
 ├── slot: header        [fullbleed] ← 블록 타입 선택 가능
 ├── slot: photo_strip   [fullbleed] ← 블록 타입 선택 가능
 ├── slot: nav           [fullbleed] ← 고정 (nav_bar)
 └── grid layout
      ├── slot: sidebar_left   [sidebar]
      ├── slot: main_1         [main]
      ├── slot: main_2         [main]
      ├── slot: main_3         [main]
      └── slot: sidebar_right  [sidebar]
```

### 3-3. 블록 타입 목록

| category | id | label | 비율 |
|---|---|---|---|
| fullbleed | site_header | 사이트 헤더 | — |
| fullbleed | gallery_slider | 갤러리 슬라이더 | — |
| main | hero | 히어로 | — |
| main | service_grid | 서비스 카드 | — |
| main | howto | 사용법 | — |
| main | blog_list | 블로그 목록 | — |
| main | credits | 크레딧 안내 | — |
| sidebar | ogp_cards | OGP 카드 | 200/105 |
| sidebar | video_cards | 영상 카드 | 9/16 |
| sidebar | guide_card | 가이드 카드 | 3/4 |
| sidebar | credit_mini | 크레딧 미니 | 1/1 |

### 3-5. 어드민 UI 구조 (최종)

기존 탭(Intro/Hero/Services/How-to/Credits)은 **Blocks 탭 안 서브 편집창으로 흡수**된다.

```
Blocks 탭
 ├── 상단 파라미터 바: max-width / 사이드바 너비 / 우측 비율 버튼
 ├── 슬롯 에디터 (좌): 현재 배치 시각화, 슬롯 클릭→선택
 │    └── 슬롯 선택 후 블록 배치 → 인라인으로 콘텐츠 편집창 펼침
 └── 블록 팔레트 (우): 카테고리별 블록 카드 (실제 비율로 시각화)
```

## 5. 쌍아에게 — 구현 지시 사항

### Priority 1: v4 CSS 기준값 반영

```css
/* 1. site-wrapper 추가 */
.site-wrapper {
  max-width: 1280px;
  margin: 0 auto;
  width: 100%;
}

/* 2. 그리드 수정 */
.layout {
  grid-template-columns: 260px 1fr 260px;
}

/* 3. mag-img 비율 교체 */
.mag-img {
  width: 100%;
  aspect-ratio: 200 / 105;
  /* height: 100px; ← 제거 */
}
```

### Priority 2: HTML 구조 수정

- 현재: 헤더/포토스트립이 `.layout` 바깥 뷰포트 풀블리드
- 변경: 모든 요소를 `.site-wrapper` 안으로 이동
- `body > .layout` → `body > .site-wrapper > .site-header + .site-nav + .layout`

### Priority 3: Firestore site_config 스키마 확장

- `layout` 필드 추가 (위 스키마 참조)
- `blocks` 배열 추가
- 기존 intro/hero/services 등 필드는 각 블록의 content 서브필드로 이관 가능

### Priority 4: 어드민 Blocks 탭 Firestore 연동

- 현재 프로토는 `beState` 로컬 객체 기반
- Firestore `site_config.main` 문서의 `layout` + `blocks` 필드와 연동
- 슬롯 배치 변경 → 즉시 Firestore 저장 → 포털 렌더러가 읽어서 반영
